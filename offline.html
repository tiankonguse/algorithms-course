离线查询

N 个区间查询「大于 v 的元素个数」——把询问按 v 排序后扫一遍数组，用树状数组在 O((n+m) log n) 内把所有答案一起算出来。

一、从一个问题说起

有一个长度为 n 的数组 a，给你 m 个询问，每个询问给出 (l, r, v)，要求回答：

在区间 a[l..r] 中，有多少个数严格大于 v？

例如 a = [3, 1, 4, 1, 5, 9, 2, 6]：

  • (1, 5, 2)：在 [3, 1, 4, 1, 5] 中大于 2 的有 3, 4, 5，共 3 个；
  • (2, 8, 4)：在 [1, 4, 1, 5, 9, 2, 6] 中大于 4 的有 5, 9, 6，共 3 个；
  • (3, 8, 5)：在 [4, 1, 5, 9, 2, 6] 中大于 5 的有 9, 6，共 2 个。

这种「区间 + 一个数值阈值」的问题看起来很朴素，但要做得快并不容易——这一节就讲它的经典解法：离线排序 + 树状数组。

二、朴素做法慢在哪

最直接的想法：对每个询问都枚举 [l, r]，数一遍大于 v 的元素。

for (int k = 0; k < m; k++) {
    int ans = 0;
    for (int i = q[k].l; i <= q[k].r; i++)
        if (a[i] > q[k].v) ans++;
    out[k] = ans;
}

每个询问 O(n)，总开销 O(n·m)。当 n = m = 10⁵，就是 10¹⁰，太慢。

矛盾在哪？ 朴素做法每次都从头到尾扫一遍 [l, r]，没有利用「v 不同、但用同一个数组」这一点。如果把所有询问一起处理，让扫描的状态在询问之间「复用」，就能省掉很多重复工作。

三、关键转化：把 "大于 v" 变成 "区间长度 - ≤ v"

第一刀：在区间 [l, r] 内，「> v」和「≤ v」刚好互补：

「> v」 的个数 = (r - l + 1) − 「≤ v」 的个数

「区间长度」一眼就能算出来，剩下的问题就变成：

在区间 a[l..r] 中，有多少个数 ≤ v？

这是一类经典前缀型问题，特别适合用「位置标记 + 前缀和」来数。

四、离线排序：把多询问压成一次扫描

第二刀：把所有询问离线地排个序——所谓「离线」就是「先全部读进来、按自己的规则排好，再按顺序处理」。

具体两步：

  • 把询问按 v 从小到大排：先回答 v 小的、再回答 v 大的；
  • 把数组元素也按 a[i] 从小到大排：依次把「当前询问 v 所允许加入」的更小的元素加入集合。
思路一句话：处理一个询问 (l, r, v) 时，「所有 ≤ v 的元素位置」已经全部被加入一棵树状数组；只要用 sum(r) - sum(l-1) 就能立刻拿到「区间 [l, r] 内 ≤ v 的元素个数」，再用 1️⃣ 里的减法就得答案。

五、树状数组登场

树状数组（又叫 Fenwick 树）这一节在前面已经讲过，这里只用它的两个操作：

  • add(pos, 1)：把「位置 pos」标记为「已加入」（值 +1）；
  • sum(pos)：求「位置 1..pos」里被标记的总数（前缀和）。

两个操作都是 O(log n)，代码见后文。

把上面的思路写成伪代码：

// 1. 把数组元素按值从小到大排，记下每个元素原本的位置
// 2. 把询问按 v 从小到大排
// 3. 双指针扫描
ptr = 0;
for 每个询问 q (按 v 升序):
    while (ptr < n and 元素[ptr].值 ≤ q.v):
        tree.add(元素[ptr].位置, 1);    // 把这个位置标进树状数组
        ptr++;
    le = tree.sum(q.r) - tree.sum(q.l - 1);  // ≤ v 的个数
    q.答案 = (q.r - q.l + 1) - le;            // > v 的个数

下面用 a = [3,1,4,1,5,9,2,6]、三个示例询问走一遍。点「下一步」观察：

  • 数组元素按值从小到大依次「加入」树状数组（绿色）；
  • 处理到当前询问时，已加入的就是所有「值 ≤ 询问 v」的元素；
  • 用 sum(r) - sum(l-1) 数区间里被加入的个数，再算答案。

六、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m;
int a[N];
int c[N];                     // 树状数组

int lowbit(int x) { return x & (-x); }

void add(int i, int delta) {
    while (i <= n) { c[i] += delta; i += lowbit(i); }
}

int sum(int i) {
    int s = 0;
    while (i > 0) { s += c[i]; i -= lowbit(i); }
    return s;
}

struct Elem { int val, pos; };             // (值, 位置)
struct Query { int l, r, v, id; };         // (l, r, v, 原询问编号)

bool cmpE(const Elem& x, const Elem& y) { return x.val < y.val; }
bool cmpQ(const Query& x, const Query& y) { return x.v < y.v; }

int ans[N];

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    vector<Elem> elems;
    elems.reserve(n);
    for (int i = 1; i <= n; i++) elems.push_back({a[i], i});
    sort(elems.begin(), elems.end(), cmpE);

    vector<Query> qs;
    qs.reserve(m);
    for (int i = 0; i < m; i++) {
        int l, r, v; cin >> l >> r >> v;
        qs.push_back({l, r, v, i});
    }
    sort(qs.begin(), qs.end(), cmpQ);

    int ptr = 0;
    for (const auto& q : qs) {
        while (ptr < n && elems[ptr].val <= q.v) {
            add(elems[ptr].pos, 1);
            ptr++;
        }
        int le = sum(q.r) - sum(q.l - 1);   // 区间 [l, r] 内 ≤ v 的个数
        ans[q.id] = (q.r - q.l + 1) - le;  // > v 的个数
    }

    for (int i = 0; i < m; i++) cout << ans[i] << '\n';
    return 0;
}

七、复杂度分析

  • 排序：元素排序 O(n log n)，询问排序 O(m log m)。
  • 扫描：指针 ptr 从 0 一路加到 n，每次 add 是 O(log n)，共 n 次 → O(n log n)。
  • 回答询问：m 个询问，每个两次 sum → O(m log n)。
操作时间复杂度
元素按值排序O(n log n)
询问按 v 排序O(m log m)
扫描 + add（共 n 次）O(n log n)
回答 m 个询问O(m log n)
总时间O((n + m) log n)
额外空间O(n)（树状数组 + 元素 / 询问副本）

对比朴素 O(n·m)，当 n = m = 10⁵ 时从 10¹⁰ 降到 ~3 × 10⁶，快了近 4 个数量级。

八、变体与拓展

  • 改成「≥ v」「< v」「≤ v」：只调整循环里的比较符号和最后的减法，几乎不用改结构。
  • 改成「等于 v」的个数：可以两次离线——一次算 ≤ v、一次算 < v，相减即可；也可以在元素排序时把「值 = v」也加进去、再相减。
  • 加入「单点修改」：朴素想法是每次修改后把所有询问重跑一遍；进阶做法是把修改也离线下来，用「CDQ 分治」或「树状数组套主席树 / BIT-of-sets」处理——这是另一个大专题。
  • 二维 / 三维：把树状数组扩展到多维，或者离线套离线，本质思想仍是「按某一维排序，把状态复用」。

九、小结

  • 「区间内大于 v 的元素个数」这类问题的关键是离线：把多询问排好序，把数组扫描的中间状态在询问之间复用。
  • 把「> v」变成「区间长度 − ≤ v」后，「<= v」用位置标记 + 树状数组前缀和即可数出。
  • 总时间 O((n + m) log n)，比朴素 O(n·m) 快几个数量级。
  • 这一套路和值域分治、莫队算法、CDQ 分治的核心思想一脉相承——「离线」+「排序」+「扫描时复用」。
