莫队算法

把一堆可以“离线”回答的区间查询先排个序，让左右指针在上一次查询的基础上“接力”滑动，从而把总耗时从 O(n×m) 降到 O((n+m)√n)。

一、从一个问题说起

有一个长度为 n 的数组 a，需要回答 m 次查询：每次给出区间 [l, r]，问这个区间里不同的数字有多少个。

例如 a = [1, 2, 1, 3, 2, 4, 1, 3]，查询 [0, 3] 里出现了 {1, 2, 3}，答案是 3。

这里的查询是离线的：我们可以先把所有查询都拿到手，再一起回答，而不必边问边答。

二、先试试朴素做法

对每个查询 [l, r]，从 l 扫到 r，用一个计数数组 cnt 记录每个数字出现次数，第一次出现时答案加一：

int query(int l, int r) {
    int cnt[MAXV] = {0}, ans = 0;
    for (int i = l; i <= r; i++) {
        if (cnt[a[i]] == 0) ans++;  // 第一次出现，答案加一
        cnt[a[i]]++;
    }
    return ans;
}

单次查询是 O(n)，一共 m 次，总耗时 O(n×m)。当 n、m 都达到 10⁵ 时，这就是 10¹⁰，太慢。

浪费在哪？ 每回答一次查询都从头扫一遍区间，相邻两次查询之间大量重复的扫描被白白浪费了。

三、移动窗口：让指针“接着用”

如果上一次查询是 [2, 5]，这一次是 [1, 6]，我们不必从头扫，只要：

  • 左指针 curL 从 2 左移到 1：把 a[1] 加进窗口；
  • 右指针 curR 从 5 右移到 6：把 a[6] 加进窗口。

这样两次查询“接力”，绝大部分元素都不用重新扫描。我们维护一个当前窗口 [curL, curR] 以及它对应的计数和答案，回答新查询时逐步移动指针，每移一步就更新答案。移动一步是 O(1)，只要总步数少，总时间就少。

“加入 / 移出”一个元素的增删函数：

void add(int x) {                // 把 a[x] 加进窗口
    if (cnt[a[x]] == 0) ans++;   // 之前没有，现在有了
    cnt[a[x]]++;
}
void del(int x) {                // 把 a[x] 移出窗口
    cnt[a[x]]--;
    if (cnt[a[x]] == 0) ans--;   // 移走后一个不剩，答案减一
}

四、顺序很重要：给查询排序

移动窗口本身很快，但总步数取决于查询的顺序。如果查询东一个西一个，指针来回横跳，总步数仍然是 O(n×m)。

既然查询是离线的，我们就可以先给查询重新排序，让指针尽量“少走弯路”。这里正好用上刚学的分块：把左端点 l 按块分组（每块大小约 √n）：

  • 第一关键字：l 所在的块编号（编号小的块在前）；
  • 第二关键字：同一块内，按 r 从小到大排。
int BS = sqrt(n);                // 块大小（约 √n）
bool cmp(Q a, Q b) {              // 查询的排序规则
    if (a.l / BS != b.l / BS)     // 先比较 l 所在的块
        return a.l / BS < b.l / BS;
    return a.r < b.r;             // 同一块内按 r 排
}
sort(q, q + m, cmp);

五、复杂度分析

设块大小为 B（约 √n），共 m 次查询。两个指针各自的总移动量：

  • 左指针 curL：同一块内的查询，curL 最多来回移动 B 步；跨块时最多 n 步。总计约 m×B + n = O(m√n)。
  • 右指针 curR：同一块内 r 只增不减，最多移动 n 步；共有约 n/B 个块，总计约 (n/B)×n = O(n√n)。

每次移动一步是 O(1)，于是总复杂度为：

O((n + m) √n)

操作时间复杂度
预处理 sort（排序）O(m log m)
移动一步（add / del）O(1)
单个查询（均摊）O(√n)
全部 m 次查询O((n + m)√n)

空间方面，需要一个计数数组 cnt（大小为值域 V）和存查询的数组（大小 m），即额外空间 O(V + m)。

对比朴素做法的 O(n×m)：当 n、m 同为 10⁵ 时，n×m = 10¹⁰，而 (n+m)√n ≈ 6×10⁷，快了三个数量级。

六、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100005, MAXV = 1000005;
int a[N], cnt[MAXV], ans = 0;

struct Q {
    int l, r, id;       // id 记住这是第几个查询
} q[N];
int res[N];             // 每个查询的最终答案
int BS;

bool cmp(Q a, Q b) {    // 排序规则
    if (a.l / BS != b.l / BS) return a.l / BS < b.l / BS;
    return a.r < b.r;
}

void add(int x) {
    if (cnt[a[x]] == 0) ans++;
    cnt[a[x]]++;
}
void del(int x) {
    cnt[a[x]]--;
    if (cnt[a[x]] == 0) ans--;
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < m; i++) {
        cin >> q[i].l >> q[i].r;
        q[i].l--; q[i].r--;      // 转成 0 下标
        q[i].id = i;
    }
    BS = max(1, (int)sqrt(n));
    sort(q, q + m, cmp);

    int curL = 0, curR = -1;    // 初始空窗口
    for (int i = 0; i < m; i++) {
        int l = q[i].l, r = q[i].r;
        while (curL > l) add(--curL);
        while (curR < r) add(++curR);
        while (curL < l) del(curL++);
        while (curR > r) del(curR--);
        res[q[i].id] = ans;
    }
    for (int i = 0; i < m; i++) cout << res[i] << endl;
    return 0;
}

七、小结

  • 莫队是离线算法：先把所有查询拿到手，统一排序、统一回答。
  • 核心是“移动窗口”：两个指针 curL、curR 在上一次查询的基础上滑动，每步 O(1) 增删。
  • 排序是关键：按“l 所在块”分组、块内按 r 排序，把指针总移动量压到 O((n+m)√n)。
  • 它直接建立在分块思想之上——用“块”给查询划分层级。
