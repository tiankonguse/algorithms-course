线段树

把区间建成一棵二叉树：根管整个数组，叶子管单个元素，中间节点把区间一分为二。于是区间查询、单点修改、区间修改都能做到 O(log n)。

一、从一个问题说起

还是那个老问题：有一个长度为 n 的数组 a，需要反复进行——

  • 查询：求区间 [l, r] 的和；
  • 修改：把某个 a[i] 改成一个新数。

前面学过的树状数组已经把这两种操作都做到了 O(log n)，代码也很短。那为什么还要再学一个线段树呢？

二、为什么还要线段树

因为树状数组有几个做不到的短板：

  • 不能「整段区间一起加」：树状数组擅长“单点修改”，可如果要把 a[2..100] 每个数都加上 10，它一次只能改一个点，就得改 99 次，退化成 O(n log n)。
  • 不能求「区间最大值」：树状数组靠“前缀和相减”来求区间和，而最大值没法像和那样被“减掉”——两个前缀最大值相减得不到区间最大值。
线段树是一张更“万能”的网：它的每个节点天然代表一段区间，所以区间修改、区间最大值、区间和……都能统一地用同一套递归框架解决。本节的完整代码里，你会看到“区间求和 + 区间修改”是如何一起塞进同一棵树的。

三、线段树的结构：把区间建成一棵二叉树

线段树的核心想法非常直观：用一个节点代表一段区间，再不断把区间一分为二，直到切成单个元素为止。

  • 根节点：管整段 [1, n]，存的是整个数组的和；
  • 叶子节点：管单个元素 [i, i]，存的是 a[i]；
  • 中间节点：管 [L, R]，取中点 mid = (L+R)/2，左儿子管 [L, mid]、右儿子管 [mid+1, R]，它的值 = 左儿子 + 右儿子。

整棵树不用指针，直接躺在一个数组里：节点 p 的左儿子是 2p，右儿子是 2p+1。这样“根是 1 号”就能一路顺藤摸瓜找到所有节点。

因为每个节点都“提前”存好了自己那一段的和，查询和修改就不用再从头扫到尾，而是顺着这棵树往下走。

四、建树 build：自底向上地算和

建树就是递归：先把整段 [1, n] 交给根节点，一路对半分下去，直到叶子。叶子直接取数组里的数，回来的时候每个内部节点把左右儿子的和加起来。

void build(int p, int l, int r) {
    if (l == r) {                  // 叶子：直接取数组里的数
        sum[p] = a[l];
        return;
    }
    int mid = (l + r) >> 1;
    build(p * 2, l, mid);         // 左儿子管 [l, mid]
    build(p * 2 + 1, mid + 1, r); // 右儿子管 [mid+1, r]
    sum[p] = sum[p * 2] + sum[p * 2 + 1];   // 内部节点 = 左右之和
}

每个节点只被填一次，整棵树一共约 2n 个节点，所以建树是 O(n)。

五、区间查询 query：三种情况

要查 [ql, qr] 的和，从根开始，每到一个节点都看它和查询区间的关系，分三种情况：

  • 完全包含：节点的 [L, R] 整个落在 [ql, qr] 里 —— 直接返回它存好的 sum[p]，不再往下；
  • 完全不相交：[L, R] 和 [ql, qr] 一点重叠都没有 —— 直接返回 0；
  • 部分相交：一半在里面一半在外面 —— 继续往左右儿子递归，把两边的结果加起来。

拖动 l、r，看一次查询里哪些节点被“整段取走”，哪些要继续“往下钻”，哪些被直接“跳过”：

演示 ②　区间查询 [l, r]：完全包含 / 部分相交 / 完全跳过

12
完全包含（直接取 sum） 部分相交（继续递归） 完全跳过

一棵树上每层最多只有 2 个“部分相交”的节点，剩下的要么整段取、要么整段跳，所以一次查询最多访问 O(log n) 个节点。

六、单点修改 update：一路下到底，再一路算回来

把 a[i] 改成一个新数，做法是：从根出发，每层判断 i 在左半边还是右半边，一路下到叶子改掉它；回程时把经过的每个内部节点都重新用“左 + 右”算一遍。

拖动滑条，看从根到叶子的这条“路径”上，哪些节点的和会跟着变：

演示 ③　单点修改 a[i]：根 → 叶子的路径
5
被改的叶子 a[i] 回程要重算的节点

因为树只有 O(log n) 层高，从根到叶子最多走 O(log n) 步，所以单点修改也是 O(log n)。

七、区间修改 + 懒标记：线段树的杀手锏

现在回到树状数组做不到的那件事：把 [ql, qr] 整段每个数都加上 delta。

直观的做法是“一路下到每个叶子都改一遍”，那样一次区间修改就是 O(n)，太慢。线段树的办法叫懒标记（lazy）：

  • 遇到一个节点被 [ql, qr] 完全包含，就不往下钻了，直接把整段的和加上 delta × 区间长度，再在这个节点上记一笔“我还欠着每个元素 delta 没传下去”（lazy[p] += delta）；
  • 以后真正需要访问它的儿子时（查询或修改），才把欠下的这笔账“下传”给儿子（pushdown），自己再把账清零。

这就是“能拖就拖”：先记着，等需要了再还。拖动 l、r 和 delta，看哪些节点被“整段打包打上懒标记”，哪些还得继续往下钻：

14
+2
完全包含（整段加 delta，打懒标记） 部分相交（继续递归） 完全跳过

一次区间修改，同样每层最多只有 2 个“部分相交”的节点需要往下钻，所以它也是 O(log n)——这正是懒标记的功劳。

八、复杂度分析

线段树是一棵约 2n 个节点、高约 log n 层的二叉树。查询和修改都只顺着树往下走，每层最多访问 O(1) 个“部分相交”的节点：

操作时间复杂度
建树 buildO(n)
区间查询 queryO(log n)
单点修改 updateO(log n)
区间修改 update_rangeO(log n)

空间方面，用数组存整棵树。为了给“对半分”留出余量，通常直接开 4n 的大小，即额外空间 O(n)（常数大约是 4）。虽然比树状数组的 O(n) 常数大一些，但换来了“区间修改、区间最大值”等更强的能力。

九、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 16;
int a[N + 1] = {0, 3,1,4,1,5,9,2,6,5,3,5,8,9,7,9,3};
int n = N;

int sum[4 * N];       // 每个节点的区间和
int lazy[4 * N];      // 懒标记：还欠着整段加的 delta

// 建树：把 [l,r] 的区间和算到节点 p 上
void build(int p, int l, int r) {
    if (l == r) { sum[p] = a[l]; return; }
    int mid = (l + r) >> 1;
    build(p * 2, l, mid);
    build(p * 2 + 1, mid + 1, r);
    sum[p] = sum[p * 2] + sum[p * 2 + 1];
}

// 下传懒标记：把节点 p 积压的增量传给两个儿子
void pushdown(int p, int l, int r) {
    if (lazy[p] == 0) return;
    int mid = (l + r) >> 1;
    sum[p * 2]     += lazy[p] * (mid - l + 1);  // 左儿子整段加
    lazy[p * 2]    += lazy[p];
    sum[p * 2 + 1] += lazy[p] * (r - mid);      // 右儿子整段加
    lazy[p * 2 + 1] += lazy[p];
    lazy[p] = 0;                                 // 账还清，清零
}

// 查询：[ql, qr] 的和
int query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[p];        // 完全包含，直接取
    if (qr < l || r < ql) return 0;                 // 完全不相交
    pushdown(p, l, r);                            // 部分相交：先下传，再往下
    int mid = (l + r) >> 1;
    return query(p * 2, l, mid, ql, qr)
         + query(p * 2 + 1, mid + 1, r, ql, qr);
}

// 单点修改：a[pos] += delta
void update(int p, int l, int r, int pos, int delta) {
    if (l == r) { sum[p] += delta; return; }   // 找到叶子
    int mid = (l + r) >> 1;
    if (pos <= mid) update(p * 2, l, mid, pos, delta);
    else            update(p * 2 + 1, mid + 1, r, pos, delta);
    sum[p] = sum[p * 2] + sum[p * 2 + 1];         // 回程重算
}

// 区间修改：把 [ql, qr] 整段加 delta
void update_range(int p, int l, int r, int ql, int qr, int delta) {
    if (ql <= l && r <= qr) {                    // 完全包含：整段加，打懒标记
        sum[p] += delta * (r - l + 1);
        lazy[p] += delta;
        return;
    }
    if (qr < l || r < ql) return;                 // 完全不相交
    pushdown(p, l, r);                            // 部分相交：先下传再递归
    int mid = (l + r) >> 1;
    update_range(p * 2, l, mid, ql, qr, delta);
    update_range(p * 2 + 1, mid + 1, r, ql, qr, delta);
    sum[p] = sum[p * 2] + sum[p * 2 + 1];
}

int main() {
    build(1, 1, n);
    cout << query(1, 1, n, 1, 8) << endl;      // 31
    update(1, 1, n, 5, -2);                      // a[5]：5 → 3
    cout << query(1, 1, n, 1, 8) << endl;      // 29
    update_range(1, 1, n, 2, 4, 10);             // a[2..4] 都加 10
    cout << query(1, 1, n, 1, 8) << endl;      // 59
    return 0;
}

十、小结

  • 线段树把区间建成二叉树：根管整段、叶子管单点、中间节点对半分，每个节点提前存好自己那段的和。
  • 查询和修改都靠递归往下走，按“完全包含 / 部分相交 / 完全不相交”三种情况处理，都能做到 O(log n)。
  • 它的杀手锏是区间修改 + 懒标记：整段被覆盖就先记一笔、不往下钻，需要时再下传，从而把区间修改也压到 O(log n)。
  • 比树状数组更通用（还能求区间最大值等），代价是代码更长、空间常数更大（约 4n）。
