树链剖分中的重链剖分，Heavy Light Decomposition，简称HLD1，树上每个节点都有如下信息：   fa  // 父节点   dep // 深度   siz // 子树大小   son // 重儿子，子树规模最大的儿子，如果多个子树都是最大规模，任选一个儿子成为重儿子   top // 所在重链的头节点   dfn // 递归序的编号，也就是dfn序号   seg // seg[i] = j，代表dfn序号为i的节点，原始节点编号为j2，dfs1的过程，设置fa、dep、siz、son，这个过程不分配dfn序号3，dfs2的过程，设置top、dfn、seg  先遍历重儿子，再遍历剩下的轻儿子，依次分配dfn序号   父节点和重儿子属于同一条重链，拥有同样的top；轻儿子新开一条重链，轻儿子作为新重链的头
