**修过的坑（防重踩）**：

- **暴力「全图连通」≠「x-y 连通」**：题1/2/7 判连通必须针对 x,y 对（connAB：x==y 且未删则连通；题1 必经 = 删 v 后 !connAB(x,y)）。全图 connected 会把「x==y 但图断」误判
- **题2 输出语义**：课程 `mustPass(x,y,z) → "yes"`——yes=断连（与题7 相反：mustPass → no）；且 x==z 或 y==z 时直接判断连（被删点本身在路径上）
- **题3 生成器 n 必须 ≥3**（需要 3 个互异点；n=2 时 rnd.sample(3) 崩溃）
- **题5 暴力 go 提前命中 c**：a→c→…→b→…→c 时在 c 处未到 b 就 return true——go 需带 reached 状态（u==c 且未到过 b → 无效）
- **connected 计数 bug**：BFS 访问到 present 外的中间点被误计入 seen，导致 seen==present.size() 巧合误判——只数 pm[v]（present 掩码）的点

**各题语义要点**（与课程一致）：题1 必经点 = d/2+1（d 树距离）；题2 删点 z 后 x,y 断连 = z 在树路径上（x==z||y==z 断连）；题3 存在 a→b→c 不重复路径 ⟺ b 的某个邻方点在 a-c 树路径上；题4 有序不连通对 = Σ 块内×(n−块内)（i 自己一块）；题5 固定 a,c 的 b 数 = 路径圆点数 + Σ(deg(f)−2)，多连通区 total 分开；题6 答案 = 路径上边数≥2 的方点边数之和（挂边到较深端父方点）；题7 删非割边连通、删割边=删方点、删点=mustPass；题8 方点表只收孩子、LCA 方点补查父圆点；题9 虚树圆点数 = Σ相邻 dist/2 + extra（根为圆点）+ − s；题10 无所谓点 = n − 虚树圆点数（sumDist 动态维护）
