## 对拍

- **8 题 × 12 种子 96 组全过**（12/12 每组）：
  - 题目1 删边方案数：暴力 = 判仙人掌（每边删后端点间简单路径数 ≤1）+ 枚举 2^m 删边子集数连通删法；课程 ∏(len+1)。**验证「删两条同环边必不连通」语义**（环只有环顶一个出口）
  - 题目2 加边方案数：暴力 = 枚举候选边（无现边点对）子集，加入后仍仙人掌则计数（mod 998244353）
  - 题目3 最长路线：暴力 = 枚举起点 + 边集 bitmask DFS 找 1 结束的最长不重边 trail
  - 题目4 独立集：2^n 枚举最大点权和
  - 题目5 直径：路径格式输入建图 + Floyd
  - 题目6 最短路：Floyd
  - 题目7 最短路最大值：Floyd 预计算 + 每查询两两取 max
  - 题目8 路径翻转：暴力真实图操作——最短路 BFS 深度回溯、最长路 DFS 枚举、翻转路径点颜色、**子仙人掌 = 删掉根到 x 的最短路与最长路（两条互补弧覆盖整个环）的边后含 x 的连通块**；验证课程 treel/treer 圆方树子树语义 ✓
- **四个坑（防重踩）**：
  1. **生成器构造环时环边必须不与已有边集冲突**（环替换树边，中间点随机取 → 可能与其它环共享边 → 非仙人掌 → 课程判 0 暴力判仙人掌大面积假 MISMATCH）；修：构造环时检查全部环边（含闭合边）去重且不在 used_edges
  2. **环构造失败（20 次重试不出）的树边必须保留为割边**（否则点孤立 → dfn==0 → 课程判非仙人掌输出 0，seed8 复现：n=5 只剩 2 条割边，点 2/5 孤立）
  3. **生成器首行「prob N」两个 token**（prob 编号 + 题号），暴力 `cin>>prob` 只读一个 → n 读错；统一 `cin>>prob; cin>>pid;`
  4. **brute2 的 isCactus 必须用 vis 数组防重复点**（无 vis 时环上无限递归 → 栈溢出 EXIT-11；且「删边后路径数」判定必须跳过被删的边本身，否则树边被判成「在环里」）
  5. **题8 最短路含根**：pathShort(1) 必须返回 {1}（课程 flip 循环 x=1 时 reverse(dfn[1],dfn[1]) 翻转根自己），空路径会漏翻根导致后续查询全错（seed2 复现 4 vs 2）
- 题1/题5 输入是**路径格式**（k 个点一条路径），暴力解析要按 k 展开成边，不能按边数直接读
