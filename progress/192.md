**修过的 bug（防重踩）**：

- **课程输入格式**：题1 的 `s t` 在**边之后**（n m / m 行边 / s t）；题4/5 的 `q` 在**边之后**（题4：n m / 边 / q / 查询；题5：n m / 点权 / 边 / q / 查询）——生成器与暴力初版按「n m q / n m s t」一行导致流错位、暴力段错误
- **题4「两点间重边只连一次」是题面语义**：课程 buildGraph 按端点排序去重（平行边不算桥）；暴力必须先去重再缩点，否则平行边把两点并进一个边双、距离少 1
- **题7 n=1 m=0 时课程 power2 只预计算到 m 越界输出 -1（UB）**：属于非法输入，生成器 n≥2 不触发；对拍不需处理

**各题语义要点**（与课程一致）：题1 check 从 s DFS 到 t、`ok |= val[u]`（边双内部商品）+ 树边权或上；题2 树形 dp `diameter = max(diameter, dist[u]+dist[v]+1)`；题3 check = 带权直径 < 便宜桥数、二分最小可行 limit、无解 -1；题4 getDist = dep 和 + 1、二进制输出；题5 RMQ LCA（区间 min dfn 的父亲）+ useCnt 四端点差分 + 子树和；题6 upCnt/downCnt 边差分、同边双要求恒满足、不同连通区 No；题7 dp 三类合并（v 侧无军营 2^bridge[v]·2 / 军营全在 v 侧 2^bridge[u]·dp[v] / 两侧都有 dp[u]·dp[v]）+ 枚举最浅军营 `dp[i]·2^(total-bridge[i]-1)` × 2^(m-total)
