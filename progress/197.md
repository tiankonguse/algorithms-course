**修过的坑（防重踩）**：

- **题1 二分下界语义**：课程二分 l 从 1 起（maxt ≥ 1），空摧毁集合法的用例课程输出 ansTime=1、暴力原实现输出 0——暴力改为与课程同语义「limit 从 1 起找最小可行」，ansTime 校验放宽为「≤ 最小可行 limit + 方案 max t 一致性」（2-SAT 任意解的实际耗时不唯一，不比精确值）。页面正文「外层套二分答案」无下界细节，无需改页
- **题4 暴力枚举位分配**：x 类 3^d 三进制与非 x 类 2^(n-d) 二进制**必须分开计数**（xv=st/2^(n-d)、yv=st%2^(n-d)），共用同一整数 st 会漏组合 → 课程 YES 暴力误判 -1（seed3/4/12）
- **题4 课程枚举语义**：枚举「禁 A 或禁 B」（stax bit 1→'a'、0→'b'），2^d 覆盖「x 用 A/B/C」全部方案（页面已有论证），暴力 3^d 全枚举等价——存在性一致
- **题2 同旗子两位置距离 < d**：课程连 u→¬v、v→¬u（同旗子互斥，任何赋值恒满足，无实际约束）；暴力按「不同旗子」判距离一致
- **题3 无 ? 串锁死**：addString 锁死（s[0]=='0'→强制 i 真，否则强制 i 假）+ 打印按 belong 选——暴力判定 YES/NO 与课程一致，打印串验证无前缀关系通过
- **题5 天生矛盾**：u==v 且 x!=y → L 与 ¬L 合并 → error 前缀和；first 单条限制永不冲突（非 error 时）保证贪心可推进——暴力 first + 贪心与课程整体二分+倍增表全 seed 一致

**各题语义要点**：题1 黑手党：变量=每条边 摧毁/幸存，t>limit 强制幸存 addEdge(i,i+m)，两条限制按「端点」「端点+颜色」分组对摧毁/幸存字面量做至多一个（groupLink 前后缀链正反两串，2k 辅助点 6k−4 边）；题2 旗帜：变量=每旗子 a[i]/b[i]，候选 2n 个按位置排序，冲突区间 [pos−d+1, pos+d] 挖自己拆两段，线段树建图叶子=否定字面量，xToRange O(log n) 边；题3 编码：变量=每串问号（真=0 假=1），前缀树 up/down 链管真前缀/后代互斥 + groupLink 管同节点同串互斥，无 ? 串锁死；题4 游戏：禁 A/禁 B 枚举 x（2^d），限制三情况（前提被禁跳过/结论被禁 id1→¬id1/都允许 id1→id2+逆否），取解 first[ground]/second[ground]；题5 布尔：双向蕴含=并查集两合并（L+M、¬L+¬M），error 前缀和，整体二分求 first[i]，倍增表贪心数段
