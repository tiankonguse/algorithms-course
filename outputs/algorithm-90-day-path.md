# 算法零基础 90 天学习路径

> 面向对象：零编程基础 / 刚学完一学期语法的初中生
> 实现语言：C++（OI 与信息学竞赛的默认语言；若学校用 Python，把「语法」阶段的练习换成 Python 即可，算法本体不受影响）

## 总览

- **目标**：90 天后能独立读懂普及组难度的题面，写出能过的代码，累计 AC 120 题以上
- **每日投入**：约 2 小时（工作日 1.5h + 周末各 3h，可浮动）
- **总学时**：约 180 小时
- **产出**：一份自己的算法笔记站 + 一个题解仓库 + 3 次模拟赛成绩单

```
Phase 1          Phase 2          Phase 3          Phase 4          Phase 5
语法地基          基础数据结构       搜索与图论        DP 与贪心        综合实战
Week 1-3         Week 4-6         Week 7-9         Week 10-11       Week 12-13
  能写能调          会选容器          会遍历状态        会建状态转移      会打比赛
```

### 每天 2 小时怎么切

| 时段 | 时长 | 做什么 |
|------|------|--------|
| 读 | 20 min | 看书 / OI Wiki / 教程，把概念过一遍 |
| 写 | 60 min | 动手写代码，不抄，边写边想 |
| 调 | 30 min | 造小数据、打印中间变量、改 bug |
| 记 | 10 min | 今天学会了什么、卡在哪，写进笔记 |

**写和调占了一半以上。** 算法不是看会的。

## Phase 1：语法地基（Week 1-3）

目标：不用查资料就能把「输入 → 处理 → 输出」写完整，并且敢用调试器。

### Week 1：把程序跑起来

**学习目标**：搭环境，掌握变量、运算、输入输出、分支与循环

| 知识点 | 说明 |
|--------|------|
| 环境 | Dev-C++ / VS Code + g++，会用命令行编译 `g++ a.cpp -o a && ./a` |
| 变量与类型 | int、long long、double、char、bool，什么时候会溢出 |
| 运算 | 算术、比较、逻辑；整数除法 `/` 与取模 `%` |
| 输入输出 | cin/cout、scanf/printf、多组数据 `while (cin >> n)` |
| 分支 | if / else if / else，嵌套别超过三层 |
| 循环 | for、while、break、continue |

**练习**
1. 输入两个 10⁹ 以内的整数，输出和与积（体会 long long）
2. 输入身高体重，输出 BMI（分支判断体型）
3. 输出九九乘法表（双重循环）

**资源**：洛谷「入门题单」、《深入浅出程序设计竞赛·基础篇》第 1 章

**检查点**
- [ ] 能独立写完第一个程序并编译通过
- [ ] 说得出 int 和 long long 的区别，知道 2147483647 这个数

### Week 2：数组、字符串与函数

**学习目标**：能处理一批数据，能把重复逻辑抽成函数

| 知识点 | 说明 |
|--------|------|
| 一维数组 | 下标从 0 开始，开数组要开够（`int a[100005]`） |
| 二维数组 | 行列遍历、矩阵转置 |
| 字符与字符串 | char 数组、string、cin.getline、字符串拼接与查找 |
| 函数 | 定义、参数、返回值、全局变量与局部变量 |
| 结构体 | struct 打包一组数据，排序时自定义比较 |
| 排序 | `sort(a, a+n)`、自定义 cmp、结构体排序 |

**练习**
1. 输入 n 个成绩，排序后输出最高、最低、平均分
2. 输入一行英文，统计每个字母出现次数
3. 写一函数判断质数，用它打印 100 以内所有质数

**资源**：洛谷题单「【算法1-2】排序」、OI Wiki「STL 容器」入门部分

### Week 3：递归、复杂度与二分

**学习目标**：理解递归，能估算自己写的程序会不会超时

| 知识点 | 说明 |
|--------|------|
| 递归 | 自己调自己，关键是「边界 + 递推式」 |
| 时间复杂度 | O(1)、O(n)、O(n²)、O(log n)，看懂循环嵌套层数 |
| 空间复杂度 | 数组开多大、递归深度多少 |
| 二分查找 | 有序序列上 `while (l <= r)`，注意中点写法不溢出 |
| 二分答案 | 把「求最优解」转成「判定能不能做到」 |
| 快速幂 | 递归 / 迭代两种写法，O(log n) |

**练习**
1. 递归求阶乘、斐波那契（并观察它为什么慢）
2. 在有序数组里找第一个 ≥ x 的位置
3. 洛谷 P2249 查找（二分模板题）

**里程碑 1**：能独立写出 100 行以内的完整程序，能说出自己代码的复杂度量级

## Phase 2：基础数据结构（Week 4-6）

目标：看到题就知道该用哪个容器装数据。

### Week 4：线性结构

| 知识点 | 说明 |
|--------|------|
| 栈 stack | 后进先出，括号匹配、表达式求值 |
| 队列 queue | 先进先出，模拟排队 |
| 单调栈 | 栈里保持单调，求「下一个更大元素」 |
| 单调队列 | 滑动窗口最值 |
| 链表 | 数组模拟链表（竞赛常用），前向星存图也用它 |
| STL | vector、pair、map、set、priority_queue |

**练习**
1. 括号序列合法性判断（栈）
2. 洛谷 P1044 栈（卡特兰数 / 搜索都行）
3. 给定数组，求每个元素右边第一个更大元素的下标（单调栈）

**资源**：本站配套页面 `algorithms/next_smaller.html`（下一个更小元素）、`algorithms/pq.html`（优先队列）

### Week 5：前缀和与差分

| 知识点 | 说明 |
|--------|------|
| 一维前缀和 | O(1) 求区间和 |
| 二维前缀和 | 子矩阵求和，注意容斥公式 |
| 一维差分 | 区间加减 O(1)，最后前缀和还原 |
| 二维差分 | 子矩阵加减 |
| 前缀和变形 | 前缀最大值、前缀异或和 |

**练习**
1. 洛谷 P1047 校门外的树（差分入门）
2. 洛谷 P1115 最大子段和（前缀和 + 贪心）
3. 输入 n×m 矩阵，回答 q 次「子矩阵和是多少」

### Week 6：哈希、离散化与位运算

| 知识点 | 说明 |
|--------|------|
| 哈希 | 把字符串 / 大数映射成整数，用 map 或 unordered_map |
| 字符串哈希 | 滚动哈希，判断两段是否相等 |
| 离散化 | 值域很大但个数不多，先排序去重再映射 |
| 位运算 | 与、或、异或、左移右移，`__builtin_popcount` |
| 状态压缩 | 用一个整数表示一个集合 |

**练习**
1. 洛谷 P1102 A-B 数对（哈希计数）
2. 手写离散化：把 10⁹ 范围的坐标压到 1..n
3. 判断一个数的二进制第 k 位是 0 还是 1

**资源**：本站 `algorithms/discretize.html`（离散化）、`algorithms/binary.html`（二进制与位运算）

**里程碑 2**：看到「区间求和」想到前缀和，看到「区间加减」想到差分，看到「值域大」想到离散化

## Phase 3：搜索与图论（Week 7-9）

目标：能把问题抽象成「状态」和「状态之间的边」。

### Week 7：DFS、BFS 与回溯

| 知识点 | 说明 |
|--------|------|
| DFS | 一条路走到底再回来，用递归写 |
| BFS | 一层层铺开，用队列写，第一次到达就是最短 |
| 回溯 | 选 / 不选、排列组合、剪枝 |
| 状态定义 | 什么算一个状态，怎么判重 |
| 剪枝 | 最优性剪枝、可行性剪枝 |

**练习**
1. 洛谷 P1605 迷宫（DFS/BFS 都写一遍）
2. 洛谷 P1443 马的遍历（BFS 求步数）
3. 洛谷 P1219 八皇后（回溯经典）

**资源**：本站 `algorithms/bfs.html`（BFS 广度优先搜索）

### Week 8：最短路

| 知识点 | 说明 |
|--------|------|
| 图的存储 | 邻接矩阵、邻接表、链式前向星 |
| Floyd | O(n³) 全源最短路，n ≤ 500 |
| Dijkstra | O(n²) 与堆优化 O(m log n)，边权非负 |
| SPFA / Bellman-Ford | 有负权边时，判负环 |
| 建图能力 | 很多题难点不在算法，在于怎么把题面变成图 |

**练习**
1. 洛谷 P3371 单源最短路径（弱化版）
2. 洛谷 P4779 单源最短路径（标准版，堆优化 Dijkstra）
3. 洛谷 P1629 邮递员送信（正反两次最短路）

### Week 9：并查集、生成树与拓扑排序

| 知识点 | 说明 |
|--------|------|
| 并查集 | 路径压缩 + 按秩合并，近乎 O(1) |
| 带权并查集 | 维护相对关系 |
| 最小生成树 | Kruskal（排序 + 并查集）、Prim |
| 拓扑排序 | DAG 上排顺序，判环 |
| DAG 上 DP | 拓扑序就是转移序 |

**练习**
1. 洛谷 P3367 并查集模板 / P1551 亲戚
2. 洛谷 P3366 最小生成树
3. 洛谷 P1113 杂物（拓扑排序 + DAG 上求最早完成时间）

**里程碑 3**：能独立完成一张图的建模、存储、遍历、求最短/连通/顺序

## Phase 4：专题实战——DP 与贪心（Week 10-11）

这两周是分水岭。前面靠套路，这里要靠想。

### Week 10：动态规划

| 知识点 | 说明 |
|--------|------|
| DP 三要素 | 状态定义、转移方程、边界与答案 |
| 线性 DP | 数字三角形、最长上升子序列、最大子段和 |
| 背包 | 01 背包、完全背包、多重背包、二维费用 |
| 区间 DP | 区间合并，枚举断点 |
| 记忆化搜索 | 写不出递推顺序时，先写搜索再记忆化 |

**练习**
1. 洛谷 P1216 数字三角形
2. 洛谷 P1048 采药（01 背包）/ P1616 疯狂的采药（完全背包）
3. 洛谷 P1049 装箱问题

**项目 A：搭一个「题解仓库」**
- 每个算法一个文件夹，每道题一份 `.cpp` + 一份简短题解
- README 里记录：题意一句话、状态怎么定的、复杂度多少、卡了多久
- 涉及知识：文件组织、Markdown

### Week 11：贪心

| 知识点 | 说明 |
|--------|------|
| 贪心思想 | 每步取当前最优，前提是能证明 |
| 证明方法 | 交换论证、反证、归纳 |
| 经典模型 | 区间调度、部分背包、哈夫曼、排队接水 |
| 贪心 vs DP | 贪心是 DP 的特例，拿不准就先写 DP |

**练习**
1. 洛谷 P1090 合并果子（哈夫曼）
2. 洛谷 P1223 排队接水
3. 洛谷 P1803 凌乱的 yyy（区间调度）

**里程碑 4**：DP 状态定义能一次想对，贪心知道要证明而不是「感觉对」

## 常见坑点提醒

| 坑 | 正确做法 |
|----|----------|
| 只看不写 | 看懂和写对之间差着 10 道题，必须动手 |
| 抄代码交上去就算过 | 抄完关掉原题重写一遍，写不出来就是没学会 |
| 数组开小 / 不开 long long | 一律 `const int N = 100005;` 开够，涉及乘法先想溢出 |
| 不看数据范围 | 先读约束，n ≤ 20 可以搜，n ≤ 10⁵ 要 O(n log n)，n ≤ 10⁷ 只能 O(n) |
| 递归不写边界 | 每个递归函数第一件事是写终止条件 |
| 二分死循环 | 固定一种写法：`while (l < r)` 配 `r = mid` / `l = mid + 1` |
| 一题卡一整天 | 卡 40 分钟没思路就去看题解的「思路」部分，不看代码 |
| 不造数据对拍 | 写一个暴力版 + 随机数据生成器，跑 1000 组比对 |
| 复杂度凭感觉 | 10⁸ 次运算大约 1 秒，按这个估算 |

## 坚持学习的实用技巧

1. **固定时间**：每天同一时段坐下来，比靠意志力撑着管用
2. **以输出倒逼输入**：每周写一篇题解或者给同学讲一道题
3. **加个圈子**：洛谷团队、学校的兴趣小组，别一个人闷头刷
4. **题目驱动**：语法够用就开始刷题，别陷在「永远在补基础」的循环里
5. **允许不完整**：代码能过就先提交，优化留给第二次
6. **错题要回头**：AC 之后隔两周再做一遍，做不出来说明没真会
