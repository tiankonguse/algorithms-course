# 坑录 §12 页面改写

> 从 `pitfalls.md` 拆出的单节副本（2026-10-14，为按需读降 token）。总索引见 `pitfalls.md`。

## §12 页面改写（完整版）

### Chrome 调试端口

主循环固定用 9333（脚本默认端口，`--user-data-dir=/tmp/cdpX`）。**不要用 `pkill -f "remote-debugging-port="` 清残留**——用户可能同时开着别的会话在跑同一个站（实测 2026-10-02 有 168/170/171 三课并发），pkill 会把它们的 Chrome 一起杀掉。改用没人占的端口（9401、9402…）加独立 `--user-data-dir`，启动参数里成对写 `CDP_PORT=940X`。

### s.index(a):s.index(b) 切片段（016，代价 80MB）

`s.index(b)` 默认从头找，b 如果在 a 之前先命中（同一个函数名在两个演示里各出现一次就会这样），切出来的是空串，`str.replace('', new)` 会把新块插进**每两个字符之间**，59KB 的页面瞬间涨到 80MB。写成 `i = s.index(a); j = s.index(b, i); assert i < j` 再替换；替换完立刻 `wc -c` 看一眼体积。真炸了也有救：`s.replace(NEW, '')` 能把文件还原（前提是 NEW 的原文还没被改过）。

### rebuild() 里不要写 st.step = st.steps.length - 1（016）

切换 select 触发的 rebuild 会把演示停在末帧，`verify_viz_steps.js` 只跑 1 帧就不再前进，看起来像「演示没生效」。rebuild 里固定回到第 0 步。（016 课把这个和上面那条一起踩了，靠 `step` 恒为末帧的打印才看出来。）

### 自写链表/数组模拟器要带保护

模拟「双链表只接了一半指针」这类错误时，链会断、`nodes[id]` 会变成 undefined；照 C++ 语义直写就是抛异常，整个演示从此卡死。做法是包一层 `at(id)`，取不到就 `broken = true`，后续操作统一返回「没有输出」，页面上显示「链已经断了，再删下去就会碰到空指针」。这比真崩更有教学价值。

### 演示的随机序列要加权（016）

六个操作等概率生成 16 步，实测整条序列一个「非空时的 deleteFront」都没落到，那一版 bug 演示从头到尾不现形。改成 40% 插 / 40% 删 / 20% 查之后，每个 bug 版本都能在演示里看到分叉。
