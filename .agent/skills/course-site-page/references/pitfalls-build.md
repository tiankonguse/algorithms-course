## §5 拼页与演示（完整版）

### mulberry32 与坏随机数（005 起反复踩）

演示里要用随机数时，一律用 mulberry32：

```js
seed = (seed + 0x6D2B79F5) | 0; t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61); return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
```

**别写 `seed = (seed * 1103515245 + 12345) % 2147483648`** 这类经典 LCG——JS 是双精度浮点，`seed * 1103515245` 到 2.4e18 已越过 2^53 的安全整数边界，低位被丢掉，实测 3000 轮里重复样本 1144 个，而 mulberry32 只有 683 个。讲随机/抽样/概率的页面自己用坏随机数发生器尤其难看。固定 seed 还能让截图与逐帧检查可复现（页面上配一个「重置」把 seed 打回去）。

**这段代码要整段照抄，不要凭记忆默写**（2026-10-05，027 课又默错一次：`var t = Math.imul(...)` 之后没用 t、反而 `a ^= a` 把种子清零，页面能跑但随机分支退化）。

### 演示要展示「某种结论」时，先让数据现形（029）

稳定性检查器想演示「快排不稳定」，但随机 6 个元素在旧种子 987654321 下碰巧稳定，18 个分支初跑 17/18。改随机种子不能瞎碰：用 Node 把页面的同款随机流与算法原样仿真一遍（同 mulberry32、同荷兰国旗 partition），遍历种子找出让所有想展示的现象都出现的那一个（029 搜到 `mulberry32(1)` 生成 `[2,0,2,3,3,1]`，选择/快排/堆排全现形不稳定、冒泡/插入/归并保持稳定），再把种子写回页面。固定种子的意义不只是可复现，还要保证「演示的剧本」成立；正文里「小数组有碰巧稳定」这类现象是真实行为，但演示的默认数据应选能让结论站住的。

### 绘图 helper 的命名遮蔽（115/116/117 连踩三次，最高频的一类 bug）

页面里画 SVG 都会现写几个 helper，名字极短：`T(x,y,s)` 写字、`R(x,y,w,h)` 画矩形、`LN(x1,y1,x2,y2)` 画线、`mount(id, svg)` 挂载。**演示变量与画图变量一撞名就整块空白**，而它偏偏绕得过 verify_pages（脚本只数 svg 数量、不看内容）：

- 115 课：`var R = cur.R`（当前区间的右端）盖掉 `R()` → `TypeError: R is not a function`，图全空，自检照样 PASS。
- 116 课：`var RS` 改名绕过，同一课里又踩一次。
- 117 课：**一课踩两回**——`st-rmq.html` 的 `var R`（查询右端）、`st-frequent-values.html` 图 2 的 `var L = 3, R = 14`。

两条硬规则：

1. **演示里的区间端点一律带前缀**：查询用 `QL/QR`，游标用 `curL/curR`，别用裸 `L/R/T/W/H`。`H` 还有个孪生坑：`var H = 300` 会撞哈希函数 `H()`，画布高度变量写 `HH`。
2. **出了 bug 别全局批量改名**。117 课想给 `var L` 改名，用了 `\bL\b` 正则，结果把 SVG `path` 的 `d="M 114 86 L 114 80"` 里的 `L` 命令一起换掉（报错 `Expected number, "M 114 86 QL2 114 80"`），图直接崩。**批量改名只在 `<script>` 段内做，画好的 SVG 字符串别碰**；改完一定用 CDP 抓一次 `Runtime.exceptionThrown`，别只靠 verify_pages。

### 画图预算要按「最长预设」算，不是默认预设（116/117）

- 116 课 n/k 演示：计数器卡片写死 `sx = 40 + si*210`、宽 190，k ≥ 4 时第 3 张画到 860，超出 viewBox 680；末帧候选列表 y=124 起每 34 一行，3 行就顶出 190 的画布。**默认预设（k=2）完全看不出问题**，官方 verify_pages 与只跑默认组合的逐帧脚本都放行，20 组 select 里 10 组 BAD。
- 117 课国旗计划图 2：环形复制段会画到 `16 + m = 28`，但 `unit = W/(2*m)` 按 24 算，右端顶到 740。**长度随预设变的时候，最后一格最容易冲出去**。

收口前把每个演示的 select **全组合**跑一遍（不是跑默认那组），逐图用 `getBBox()` 比对 viewBox。

### 文字自重叠：只有脚本抓得到（117）

overlap 脚本（逐图比 `text` 的 `getBBox()`，交集超过较小者 18% 就报）在 117 课抓到三处，**肉眼与截图全部看不出**：

1. 公式文字压住行标签（rmq 图 2，43%）→ 整块下移 14px。
2. **同一句表头写了两遍**（国旗计划图 2，100%）——数组 `['l','r','跳到','说明','——']` 后面又跟了一行「能接上的最后一条」，两个 text 完全重合。合进一个数组解决。
3. 英文标签 `bucket` 与第一格数字挤在一起（frequent-values 图 0，27%）→ 改中文「数组 / 段号」并缩到 10.5px。

第 2 类（重复写）在 SVG 里是「画了两遍」而不是「画错位置」，截图上和画一遍一模一样，**只有逐对 bbox 比对能发现**。overlap 脚本要覆盖演示的末帧，不只是静态图。

### 演示出「算出来的结果」时配自写 CDP 脚本（005）

控制区里是 select / 滑块而不是「下一步」按钮时，`shot_steps.js` 点不到；用 CDP 脚本先 `select.value = ...; dispatchEvent(new Event('change'))`、再按文字找按钮点击，最后 `Page.captureScreenshot` 带 clip 截 `.viz` 元素。判断「标色对不对」别只信截图缩略图（005 那次把橙色格子看成了蓝色），读回 DOM 的 `rect.getAttribute('fill')` 逐格核对最稳。

### 演示与绘图的几条细则（2026-10-14 从 SKILL.md 移入，SKILL.md 只留一行要点）

**演示的控制按钮容器统一写 `class="viz-controls"`**：shot_element.js 按 `.viz-controls button` 索引点击，自造名字会点空、截图停在初始帧。shared.css 已有该样式。

**演示里要用随机数时，一律用 mulberry32，整段照抄勿默写**（005 起反复踩，027 默错一次把种子清零）：

```js
seed = (seed + 0x6D2B79F5) | 0; t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61); return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
```

**演示要展示「某种结论」时，先让数据现形**（029）：改随机种子别瞎碰，用 Node 把页面同款随机流与算法原样仿真一遍，遍历种子找出让所有想展示现象都出现的那个，再写回页面（029 用 mulberry32(1) 让选择/快排/堆排全现形不稳定）。固定种子意义不只是可复现，还要保证「演示剧本」成立。

**演示出「算出来的结果」时配自写 CDP 脚本**（005）：控制区是 select/滑块时 shot_steps 点不到——先 `select.value = ...; dispatchEvent(new Event('change'))`，再按文字找按钮点击，最后截图。判断标色别只信缩略图（005 把橙色看成蓝色），读回 DOM 属性（`rect.getAttribute('fill')`）逐格核对最稳。

**绘图 helper 的命名遮蔽是最高频的一类 bug（115/116/117 连踩三次）**：画图 helper 名字极短（`T()` 写字、`R()` 矩形、`LN()` 线、`mount()` 挂载），演示变量一撞名就整块空白，而 verify_pages 只数 svg 数量、照样 PASS。区间端点一律带前缀（`QL/QR`、`curL/curR`），别用裸 `L/R/T/W/H`（`H` 还会撞哈希函数，画布高写 `HH`）。**出了 bug 别全局批量改名**：`\bL\b` 会把 SVG `path` 的 `d="M 114 86 L 114 80"` 里的 `L` 命令一起换掉，只在 `<script>` 段内改名，改完用 CDP 抓一次 `Runtime.exceptionThrown`。

**画图预算按「最长预设」算，不按默认预设**（116 的 n/k 演示 k ≥ 4 越界、117 的复制段画到 `16+m=28` 而 `unit` 按 24 算）——默认预设看不出问题，官方自检也放行，必须把 select **全组合**跑一遍。文字自重叠（尤其「同一句表头写了两遍」造成的 100% 重合，截图完全看不出）只有逐对 `getBBox()` 比对能发现，overlap 脚本要覆盖演示末帧。
