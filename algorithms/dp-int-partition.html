整数划分：同一个递推，两种限制

m 个苹果放 n 个盘子和 m 拆成 n 份，都是「把 m 拆成若干正整数、顺序无关」。差别只有一处：能不能空。而这个差别，用「每份先放 1 个」一行代码就抹平了。

零、背景

把 m 拆成若干个正整数的和，顺序无关，这种拆法叫整数划分。这一讲的两个题都是它的变体：苹果和盘子允许空盘，数的划分要求每份非空。盘子和份都没有编号，所以 (4, 1, 0)、(4, 0, 1)、(0, 4, 1) 是同一种放法。

关键观察：无空盘可以转成有空盘。每份先放 1 个，剩下的再随意分，空出来的份就等价于空盘。

一、苹果和盘子

f(m, n) 表示 m 个苹果放 n 个盘子、允许空盘、顺序无关的方案数。按「有没有空盘」分类：

有空盘：先占住一个空盘，剩下 m 个苹果放 n−1 个盘，f(m, n−1)。无空盘：每个盘先放 1 个，剩 m−n 个苹果再自由放，f(m−n, n)。

f(m, n) = f(m, n−1) + f(m−n, n)。边界：m = 0 时只有全空一种，返回 1；n = 0 却有苹果放不下，返回 0；n > m 时空盘不影响方案，直接 f(m, m)。

f(5, 3) 展开：f(5, 3) = f(5, 2) + f(2, 3) = f(5, 2) + f(2, 2) = (f(5, 1) + f(3, 2)) + (f(2, 1) + f(0, 2)) = (1 + (1 + f(1, 2))) + (1 + 1) = 3 + 2 = 5。五种放法是 5,0,0 / 4,1,0 / 3,2,0 / 3,1,1 / 2,2,1。

二、数的划分

m 分成恰 n 份、每份非空。先判两刀：m < n 分不成，返回 0；m = n 只有全 1 一种，返回 1。否则每份先扣掉 1 个，剩 m−n 个分到 n 个「份」里、允许空，就回到苹果和盘子：split(m, n) = f(m−n, n)。

7 分 3 份 = f(4, 3) = 4：1,1,5 / 1,2,4 / 1,3,3 / 2,2,3，和洛谷 P1025 样例一致。两个题的入口只差这一行，递推是同一个 f。

三、复杂度与边界

状态只有 (m+1) × (n+1) 个，每格 O(1) 转移，总 O(mn)。记忆化递归和自底向上填表等价，递归的话 n > m 那一支记得先折，不然会多做一层空转。

代码就一个函数两个入口：

#include <bits/stdc++.h>
    using namespace std;

    // f(m, n)：m 个苹果放 n 个盘子，允许空盘、盘子无差别
    long long f(int m, int n) {
        if (m == 0) {
            return 1;               // 没有苹果：所有盘子空着，只有一种
        }
        if (n == 0) {
            return 0;               // 没有盘子却有苹果：放不下
        }
        if (n > m) {
            return f(m, m);         // 盘子比苹果多，空盘不影响方案数
        }
        // 有空盘：f(m, n - 1)；无空盘：每盘先放 1 个，剩 m - n 个随意放
        return f(m, n - 1) + f(m - n, n);
    }

    // 数的划分：m 分成恰 n 份且每份非空 → 每份先扣 1 个，转成允许空盘
    long long split(int m, int n) {
        if (m < n) {
            return 0;
        }
        if (m == n) {
            return 1;
        }
        return f(m - n, n);
    }

答案长得比想象快：f(100, 10) = 6292069，f(500, 500) 连 long long 都装不下。本题数据范围（P1025 的 m ≤ 200）int 够用，但统一写 long long 不亏。

四、总结

无空盘先扣 1 个转成允许空盘，这一招把两个题并成一个递推。整数划分的状态是 (m, n) 两维，转移只有两个方向，O(mn)。看到「拆数、放盘、分份」这类词，先想清楚顺序有没有意义、能不能空，这两个属性直接决定递推长什么样。
