仙人掌圆方树

上一节的五道题，环都是在 Tarjan 的栈上现场弹出来算的。这一节换个思路：先把仙人掌一次性转成圆方树，环压缩成一个方点，之后所有问题都在树上做。树链剖分、虚树、线段树这些树上的重型工具，从这个时候开始才有地方下手。三道题，一道比一道狠。

零、背景

圆方树是把图按点双连通分量拆开建出来的树：原图的点是圆点，每个点双连通分量加一个方点，分量里的每个点连到这个方点上。

仙人掌往圆方树上放，性质格外好。一个简单环是一个点双连通分量，所以每个环正好对应一个方点。割边不属于任何环，直接变成圆点和圆点之间的树边。

于是圆方树的形状是：环顶连着方点，方点连着环上其余的点；割边照原样连。整棵树的高度和结构，跟「把每个环捏成一小簇」的直觉完全一致。

边权也可以搬过去。环顶到方点的边权设 0；方点到环上其他点的边权，设成环内该点到环顶的最短距离。这样一个环在树上就「摊平」了，从环顶进环，到任何一个环节点，树边权就是环内走短边的答案。

一、建树

建树用的是上一节那套改版 Tarjan，只是环被认出来的那一刻，不再现场做 DP，而是调用 cycleLink 把环改造成方点。

细节在边权上。Tarjan 过程中，每个环节点记一个 fromWeight：树边方向上，到环上父亲那条边的权值；回边那条闭合边，权值记在环顶身上。从栈顶（环上最深的点）往浅处扫，一路累加环长，顺手得到每个环节点的 cycleLen，沿回边方向绕回环顶的距离。

方点到环节点的边权取 min(cycleLen[x], cycleSum - cycleLen[x])，环总长减去它就是另一个方向的距离，取小者正是环内最短路。环顶那边连 0。

二、题目6：仙人掌最短路

n 个点 m 条边的带权仙人掌，q 次查询两点间最短路距离。没有自环重边。

建好圆方树之后，每个点到根的距离 len 一遍 DFS 就有了，树边权里环内短边已经算进去了。树上两点 x、y 的路径唯一，先找 LCA。

LCA 是圆点，路径不过任何环的内部，距离就是 len[x] + len[y] - 2 * len[lca]。

LCA 是方点，说明路径从两个方向穿过这个环。x 这边要找的是「进入环的入口」fx：x 到根的路径在方点下方最后经过的那个圆点。入口到根的树边已经是环内短边，但 x 和 y 的两个入口之间，环上还有一段没算，这段的树边权在两边各自被「截短」过，不能直接用 len 差。

这段用 cycleLen 直接算：两入口在环上的前缀差 d，与环总长减 d 取小。合起来是 len[x] - len[fx] + len[y] - len[fy] + min(d, cycleSum - d)。

入口怎么找？重链剖分之后，x 沿自己所在的重链往上跳，跳到和方点同一条重链为止。这时 x 要么就在方点下方，入口是方点的重儿子；要么已经跳过了方点，入口是最后一次跳的链顶。两种情况合成一个 find 函数。

整份代码把上一节的 Tarjan 原样搬过来，cycleLink 里换成建方点，后面接重链剖分和查询：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    int n, m, q, cntn;

    int head1[MAXN];
    int next1[MAXN];
    int to1[MAXN];
    int weight1[MAXN];
    int cnt1;

    int head2[MAXN];
    int next2[MAXN];
    int to2[MAXN];
    int weight2[MAXN];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int stasiz;

    int fromWeight[MAXN];
    int cycleLen[MAXN];
    int cycleSum[MAXN];

    int fa[MAXN];
    int dep[MAXN];
    int siz[MAXN];
    int len[MAXN];
    int son[MAXN];
    int top[MAXN];

    void addEdge1(int u, int v, int w) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        weight1[cnt1] = w;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v, int w) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        weight2[cnt2] = w;
        head2[u] = cnt2;
    }

    void cycleLink(int u, int v) {
        cntn++;
        cycleSum[cntn] = fromWeight[u];
        addEdge2(u, cntn, 0);
        int tmp = stasiz;
        int pop;
        do {
            pop = sta[tmp--];
            cycleLen[pop] = cycleSum[cntn];
            cycleSum[cntn] += fromWeight[pop];
        } while (pop != v);
        do {
            pop = sta[stasiz--];
            addEdge2(cntn, pop, min(cycleLen[pop], cycleSum[cntn] - cycleLen[pop]));
        } while (pop != v);
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++stasiz] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to1[e];
            int w = weight1[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                fromWeight[v] = w;
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    stasiz--;
                    addEdge2(u, v, w);
                } else {
                    cycleLink(u, v);
                }
            } else if (dfn[v] < dfn[u]) {
                fromWeight[v] = w;
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs1(int u, int f, int l) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        len[u] = l;
        for (int e = head2[u], v; e > 0; e = next2[e]) {
            v = to2[e];
            if (v != f) {
                dfs1(v, u, len[u] + weight2[e]);
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        if (son[u] != 0) {
            dfs2(son[u], t);
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    int lca(int a, int b) {
        while (top[a] != top[b]) {
            if (dep[top[a]] <= dep[top[b]]) {
                b = fa[top[b]];
            } else {
                a = fa[top[a]];
            }
        }
        return dep[a] <= dep[b] ? a : b;
    }

    int find(int x, int square) {
        int pre = 0;
        while (top[x] != top[square]) {
            pre = top[x];
            x = fa[pre];
        }
        return x == square ? pre : son[square];
    }

    int query(int x, int y) {
        int ans = 0;
        int xylca = lca(x, y);
        if (xylca <= n) {
            ans = len[x] + len[y] - (len[xylca] << 1);
        } else {
            int fx = find(x, xylca);
            int fy = find(y, xylca);
            ans = len[x] + len[y] - len[fx] - len[fy];
            int small = min(cycleLen[fx], cycleLen[fy]);
            int big = max(cycleLen[fx], cycleLen[fy]);
            ans += min(big - small, cycleSum[xylca] - (big - small));
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        cntn = n;
        cnt1 = 1;
        for (int i = 1, u, v, w; i <= m; i++) {
            cin >> u >> v >> w;
            addEdge1(u, v, w);
            addEdge1(v, u, w);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i, 0);
            }
        }
        dfs1(1, 0, 0);
        dfs2(1, 1);
        for (int i = 1, x, y; i <= q; i++) {
            cin >> x >> y;
            cout << query(x, y) << "\n";
        }
        return 0;
    }

三、题目7：最短路最大值

带权仙人掌，可能有重边。每次查询给 k 个点，问这 k 个点两两之间最短路的最大值。k 的总和到 3×10⁵。

一次查询只跟这 k 个点有关，但路径会经过它们祖先上的环，先建虚树，把 k 个点和它们两两的 LCA 全收进来。方点也是合法的 LCA，虚树里会出现方点，后面的 DP 得会处理它们。

虚树上的直径 DP，圆点部分是老套路：孩子往上传 dist，父亲拿两个孩子拼一下更新直径。len 差在这里可以直接用，因为虚树边在圆点之间的部分不涉及环内截短。

方点是新东西。方点的每个虚树孩子 v，代表「从 v 这个方向进入环」。真正参与环内计算的点是入口 f = find(v, 方点)：把 v 的 dist 折回到入口上，dist[f] = dist[v] + len[v] - len[f]。方点自己的 dist 取「绕过环顶出去」的最大值。

所有入口都折好之后，环内贡献是老朋友：按 cycleLen 排序、复制成两倍、单调队列限制不超过半圈，最大化 dist[i] + pre[i] + dist[j] - pre[j]。和上一节题目5 的滑窗一模一样，只是这里的 dist 是虚树上折回来的深度，数组按下标拼而已。

    void addEdge2(int u, int v, ll w) {

        to2[cnt2] = v;

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++stasiz] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            if ((e ^ 1) == preEdge) {
                continue;

            int v = to1[e];

                tarjan(v, e);
                fromWeight[v] = w;

                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    stasiz--;
                    addEdge2(u, v, w);
                } else {
                    cycleLink(u, v);
                }

                fromWeight[v] = w;

        dep[u] = dep[f] + 1;

        len[u] = l;
        for (int e = head2[u], v; e > 0; e = next2[e]) {

        while (top[a] != top[b]) {
            if (dep[top[a]] <= dep[top[b]]) {
                b = fa[top[b]];

                a = fa[top[a]];

        while (top[x] != top[square]) {

            x = fa[pre];

        return x == square ? pre : son[square];

    int buildVirtualTree() {
        sort(arr + 1, arr + k + 1, [](int a, int b) {
            return dfn[a] < dfn[b];
        });
        int len = 0;
        for (int i = 1; i < k; i++) {
            tmp[++len] = arr[i];
            tmp[++len] = lca(arr[i], arr[i + 1]);
        }
        tmp[++len] = arr[k];
        sort(tmp + 1, tmp + len + 1, [](int a, int b) {
            return dfn[a] < dfn[b];
        });
        int unique = 1;
        for (int i = 2; i <= len; i++) {
            if (tmp[unique] != tmp[i]) {
                tmp[++unique] = tmp[i];
            }
        }
        cnt3 = 0;
        for (int i = 1; i <= unique; i++) {
            head3[tmp[i]] = 0;
        }
        for (int i = 1; i < unique; i++) {
            addEdge3(lca(tmp[i], tmp[i + 1]), tmp[i + 1]);
        }
        return tmp[1];
    }

    void computeOnCycle(int u, int siz) {
        sort(idx + 1, idx + siz + 1, [](int a, int b) {
            return cycleLen[a] < cycleLen[b];
        });
        for (int i = 1; i <= siz; i++) {
            pre[i] = cycleLen[idx[i]];
            pre[i + siz] = pre[i] + cycleSum[u];
            val[i] = dist[idx[i]];
            val[i + siz] = val[i];
        }
        int l = 1;
        int r = 0;
        for (int i = 1; i <= siz * 2; i++) {
            while (l <= r && (pre[i] - pre[que[l]]) * 2 > cycleSum[u]) {
                l++;
            }
            if (l <= r) {
                diameter = max(diameter, val[que[l]] - pre[que[l]] + val[i] + pre[i]);
            }
            while (l <= r && val[que[r]] - pre[que[r]] <= val[i] - pre[i]) {
                r--;
            }
            que[++r] = i;
        }
    }

    void dpOnTree(int u) {
        dist[u] = 0;
        if (u <= n) {
            for (int e = head3[u]; e > 0; e = next3[e]) {
                int v = to3[e];
                dpOnTree(v);
                diameter = max(diameter, dist[u] + dist[v] + len[v] - len[u]);
                dist[u] = max(dist[u], dist[v] + len[v] - len[u]);
            }
        } else {
            for (int e = head3[u]; e > 0; e = next3[e]) {
                int v = to3[e];
                dpOnTree(v);
            }
            int siz = 0;
            for (int e = head3[u]; e > 0; e = next3[e]) {
                int v = to3[e];
                int f = find(v, u);
                dist[f] = dist[v] + len[v] - len[f];
                idx[++siz] = f;
                dist[u] = max(dist[u], dist[v] + len[v] - len[u]);
            }
            computeOnCycle(u, siz);
        }
    }

            addEdge1(u, v, w);
            addEdge1(v, u, w);

        dfs1(1, 0, 0);
        dfs2(1, 1);

            cin >> k;
            for (int j = 1; j <= k; j++) {
                cin >> arr[j];
            }
            diameter = 0;
            int tree = buildVirtualTree();
            dpOnTree(tree);
            cout << diameter << "\n";
        }
        return 0;
    }

四、题目8：仙人掌路径翻转

1 号点是根的仙人掌，每个简单环的边数都是奇数，所以任何点到根的最短路和最长路都是唯一的。每个点黑白两色，初始全黑。操作 1 x：x 到根的最短路上所有点颜色翻转；操作 2 x：x 到根的最长路上所有点翻转；操作 3 x：查询以 x 为头的子仙人掌里黑点数量。

圆方树上「到根的一条路径」是天然的链，链上加加减减是树剖加线段树的活。麻烦全在环上：最短路和最长路进同一个环时，走的是两条不同的弧。

第一步还是圆方树加重链剖分，但 dfn 的分配要重新设计。方点的重儿子是环上某个圆点 h。环上其余的点，从 h 出发沿环的一个方向依次编号，方向挑「环上离 h 更近的那一边」，pos[h] * 2 < cycleSum 时从小的一侧开始数。

这样编完号，环上任何一条「从入口走到环顶」的弧，要么是 dfn 上一段连续区间，要么是这段区间再补上 h 一个点。翻转一条链，最后在环上落成的形状永远是 1 到 2 段区间加至多一个单点，线段树区间翻转接得住。

第二步是记账。环上的点分到两本账：位于 h 一侧的记 dfnType 1，另一侧记 dfnType 2；不在环路径特殊位置的普通圆点记 dfnType 3。一棵线段树开三组槽位，build 时每个 dfn 按类型初始化，1、2 两本账加起来才是完整的环，3 是公共部分。

翻转的时候，操作 1（最短路）翻 type 1 槽和 type 3 槽，操作 2（最长路）翻 type 2 槽和 type 3 槽，type 3 是两条路都经过的部分，怎么都得翻。flip 沿重链一段段往上跳，跳到环顶所在的位置时调用 flipCycle，在环内翻出那 1 到 2 段区间。

查询以 x 为头的子仙人掌黑点数：x 自己一个点，加上 x 在圆方树上的子树区间。treel、treer 在剖分时按「圆点的子树范围」记录，方点的 dfn 槽位不进任何账本，计数自动只算圆点。

    int dfnType[MAXN];

    int all1[MAXN << 2];
    int black1[MAXN << 2];
    bool lazy1[MAXN << 2];

    int all2[MAXN << 2];
    int black2[MAXN << 2];
    bool lazy2[MAXN << 2];

    int all3[MAXN << 2];
    int black3[MAXN << 2];
    bool lazy3[MAXN << 2];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void cycleLink(int u, int v) {
        cntn++;
        cycleRoot[cntn] = u;
        addEdge2(u, cntn);
        int tmp = stasiz;
        int pop;
        int cnt = 0;
        do {
            pop = sta[tmp--];
            cnt++;
        } while (pop != v);
        cycleSum[cntn] = cnt + 1;
        do {
            pop = sta[stasiz--];
            belongCycle[pop] = cntn;
            pos[pop] = cnt--;
            addEdge2(cntn, pop);
        } while (pop != v);
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++stasiz] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    stasiz--;
                    addEdge2(u, v);
                } else {
                    cycleLink(u, v);
                }
            } else if (dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != f) {
                dfs1(v, u);
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void cycleDfn(int u) {
        int h = son[u];
        bool near = pos[h] * 2 < cycleSum[u];
        cyclel[u] = cntd + 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa[u] && v != h) {
                dfn[v] = ++cntd;
                if ((near && pos[v] < pos[h]) || (!near && pos[v] > pos[h])) {
                    dfnType[cntd] = 1;
                } else {
                    dfnType[cntd] = 2;
                }
            }
        }
        cycler[u] = cntd;
        dfn[h] = ++cntd;
    }

    void dfs2(int u, int t) {
        top[u] = t;
        if (dfn[u] == 0) {
            dfn[u] = ++cntd;
        }
        if (u > n) {
            cycleDfn(u);
        }
        if (u <= n) {
            treel[u] = cntd + 1;
        }
        if (son[u] != 0) {
            dfs2(son[u], t);
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
        if (u <= n) {
            treer[u] = cntd;
        }
    }

    void up(int i) {
        all1[i] = all1[i << 1] + all1[i << 1 | 1];
        all2[i] = all2[i << 1] + all2[i << 1 | 1];
        all3[i] = all3[i << 1] + all3[i << 1 | 1];
        black1[i] = black1[i << 1] + black1[i << 1 | 1];
        black2[i] = black2[i << 1] + black2[i << 1 | 1];
        black3[i] = black3[i << 1] + black3[i << 1 | 1];
    }

    void reverse1(int i) {
        black1[i] = all1[i] - black1[i];
        lazy1[i] = !lazy1[i];
    }

    void reverse2(int i) {
        black2[i] = all2[i] - black2[i];
        lazy2[i] = !lazy2[i];
    }

    void reverse3(int i) {
        black3[i] = all3[i] - black3[i];
        lazy3[i] = !lazy3[i];
    }

    void down(int i) {
        if (lazy1[i]) {
            reverse1(i << 1);
            reverse1(i << 1 | 1);
            lazy1[i] = false;
        }
        if (lazy2[i]) {
            reverse2(i << 1);
            reverse2(i << 1 | 1);
            lazy2[i] = false;
        }
        if (lazy3[i]) {
            reverse3(i << 1);
            reverse3(i << 1 | 1);
            lazy3[i] = false;
        }
    }

    void build(int l, int r, int i) {
        if (l == r) {
            if (dfnType[l] == 1) {
                all1[i] = black1[i] = 1;
            }
            if (dfnType[l] == 2) {
                all2[i] = black2[i] = 1;
            }
            if (dfnType[l] == 3) {
                all3[i] = black3[i] = 1;
            }
        } else {
            int mid = (l + r) >> 1;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            up(i);
        }
    }

    void reverse(int jobl, int jobr, int jobt, int l, int r, int i) {
        if (jobl > jobr) {
            return;
        }
        if (jobl <= l && r <= jobr) {
            if (jobt == 1 || jobt == 3) {
                reverse1(i);
            }
            if (jobt == 2 || jobt == 3) {
                reverse2(i);
            }
            reverse3(i);
            return;
        }
        down(i);
        int mid = (l + r) >> 1;
        if (jobl <= mid) {
            reverse(jobl, jobr, jobt, l, mid, i << 1);
        }
        if (mid < jobr) {
            reverse(jobl, jobr, jobt, mid + 1, r, i << 1 | 1);
        }
        up(i);
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl > jobr) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return black1[i] + black2[i] + black3[i];
        }
        down(i);
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, i << 1);
        }
        if (mid < jobr) {
            ans += query(jobl, jobr, mid + 1, r, i << 1 | 1);
        }
        return ans;
    }

    void flipCycle(int u, int x, int op) {
        int h = son[u];
        bool near = pos[x] * 2 < cycleSum[u];
        if ((near && op == 1) || (!near && op == 2)) {
            reverse(cyclel[u], dfn[x], 3, 1, cntn, 1);
            if (pos[h] < pos[x]) {
                reverse(dfn[h], dfn[h], 3, 1, cntn, 1);
            }
        } else {
            reverse(dfn[x], cycler[u], 3, 1, cntn, 1);
            if (pos[h] > pos[x]) {
                reverse(dfn[h], dfn[h], 3, 1, cntn, 1);
            }
        }
    }

    void flip(int x, int op) {
        while (x != 0) {
            int xtop = top[x];
            if (xtop > n || belongCycle[xtop] == 0) {
                reverse(dfn[xtop], dfn[x], op, 1, cntn, 1);
                x = fa[xtop];
            } else {
                if (x != xtop) {
                    reverse(dfn[son[xtop]], dfn[x], op, 1, cntn, 1);
                    x = xtop;
                }
                flipCycle(belongCycle[x], x, op);
                x = cycleRoot[belongCycle[x]];
            }
        }
    }

    void prepare() {
        tarjan(1, 0);
        cntd = 0;
        for (int i = 1; i <= n; i++) {
            dfn[i] = 0;
        }
        dfs1(1, 0);
        dfs2(1, 1);
        for (int i = 1; i <= n; i++) {
            if (dfnType[dfn[i]] == 0) {
                dfnType[dfn[i]] = 3;
            }
        }
        build(1, cntn, 1);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        cntn = n;
        cnt1 = 1;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        prepare();
        for (int i = 1, op, x; i <= q; i++) {
            cin >> op >> x;
            if (op == 1 || op == 2) {
                flip(x, op);
            } else {
                int ans = query(dfn[x], dfn[x], 1, cntn, 1);
                ans += query(treel[x], treer[x], 1, cntn, 1);
                cout << ans << "\n";
            }
        }
        return 0;
    }

五、复杂度分析

建圆方树是线性的一遍 Tarjan。三道题的额外开销都在查询上，重链剖分和线段树的对数因子是主要来源。

操作时间复杂度空间复杂度
建圆方树（含环内最短边权）O(n + m)O(n + m)
题目6 一次最短路查询O(log n)（LCA 跳链 + find）O(n) 级
题目7 一次查询（k 个关键点）O(k log k)（虚树 + 环上单调队列）
题目8 一次翻转 / 查询O(log² n)（链上区间翻转）

题目7 的环上单调队列是均摊线性的，入口个数不超过环长，排序是总查询里占主导的 k log k。题目8 的每次翻转沿重链跳 O(log n) 段，每段一次区间翻转 O(log n)。

空间方面，题目8 的线段树开四倍总点数，圆方树点数是 n 加环数，不超过 2n。

六、最后

三道题走下来，能看到圆方树带来的是什么样的自由：环被压成一个点之后，「树上工具箱」整个打开了，题目6 是重链剖分找 LCA，题目7 是虚树加直径 DP，题目8 是重新设计 dfn 之后的树剖加线段树。

设计 dfn 那一步值得多看一眼。数据结构要求操作对象是连续区间，于是反过来改造编号方式，让「环上的一条弧」这种弯曲的东西，落到区间里去。先定操作、再定编号，这个顺序在很多题上都能用。

和上一节对照着看更清楚：栈上现场算环，代码短、常数小，但只能做一遍 DFS 能顺手做完的事；转成圆方树要先付一遍建树的成本，换来的是之后任意次询问、任意树上算法都能上。两种姿势没有高下，看题目要什么。
