只增回滚莫队

加数字好维护、删数字没法维护的答案，就别让窗口删数字。右指针只往右走，左指针临时左扩、答完再退回去，答案靠一份备份还原。

零、背景

上一节的莫队能跑起来，靠的是窗口两端都能 O(1) 动：加一个数字 O(1)，删一个数字也 O(1)。

有不少题只有一半成立。加进来一个数字，答案顺着改一下就行；删掉一个数字，答案往哪改却说不清。

这节课处理这一类。办法是把「删」这个动作从窗口里赶出去：窗口只会变长，不会缩短。

一、问题

长度为 n 的数组 arr。如果数字 x 在某段范围上出现了 c 次，就说 x 在这段范围上的重要度是 x * c。一段范围的最大重要度，就是这段范围上每种数字的重要度取最大值。

一共 m 条查询，格式 l r，打印 arr[l..r] 上的最大重要度。

1 <= n、m <= 10^5，1 <= arr[i] <= 10^9。测试链接：AT_joisc2014_c。

二、朴素做法

每条查询扫一遍 l..r，用 cnt 记每个数字出现几次，扫完再从头取一遍最大值。

long long force(int l, int r) {
    for (int i = l; i <= r; i++) cnt[arr[i]]++;
    long long ret = 0;
    for (int i = l; i <= r; i++) ret = max(ret, 1LL * cnt[arr[i]] * arr[i]);
    for (int i = l; i <= r; i++) cnt[arr[i]]--;
    return ret;
}

一次 O(r - l + 1)，m 条最坏 O(nm)。n、m 都是 10^5 时是 10^10，交上去必然超时。

三、只让窗口加数字

加数字的时候，只有这一种数字的重要度在变，取个 max 就完事；删数字的时候，变小的那一列未必是原来最大的那一列，最大值到底降不降，得重新看一遍所有数字。

既然删不动，就让窗口只增不删。整个过程的骨架还是分块：查询按 l 所在块分组，块内按 r 从小到大排。区别在于每一组内部怎么走。

设 l 所在块的右边界是 br。这一组的任务分成两类。

第一类是 jobr <= br 的，整段都落在块内，长度不超过块长，直接暴力扫，扫完把 cnt 还原。

第二类才是重点。给这一组开一个空窗口，winl = br + 1，winr = br。同一组里 jobr 是不下降的，于是每个任务分四步走。

第一步，让 winr 走到 jobr。这一步只会往右，加数字，区间信息和答案都更新。

第二步，把此刻的答案存一份 backup。

第三步，让 winl 走到 jobl，继续加数字，答案更新完就是本任务的答案，记下来。

第四步，让 winl 退回 br + 1。这一步在删数字，但不碰答案，答案直接赋回 backup。

四步走完，窗口回到 [br + 1, winr]，cnt 也回到第二步那个状态，可以接着做下一个任务。下面这个图是一个任务走完四步的样子。

这里有个容易漏的地方：第四步删数字时只更新 cnt，不更新答案。答案靠 backup 直接赋值，所以「删」这个动作根本不需要写。

五、题目1 的代码

arr 的值域到 10^9，先离散化，之后 arr[i] 是「第几小」，真实值存在 sorted 里，重要度用 cnt * sorted。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 100001;
    const int MAXB = 401;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];
    int sorted[MAXN];
    int cntv;

    int blen, bnum;
    int bi[MAXN];
    int br[MAXB];

    int cnt[MAXN];
    long long curAns = 0;

    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r < b.r;
    }

    int kth(int num) {
        int left = 1, right = cntv, ret = 0;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] <= num) {
                ret = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ret;
    }

    long long force(int l, int r) {
        long long ret = 0;
        for (int i = l; i <= r; i++) {
            cnt[arr[i]]++;
        }
        for (int i = l; i <= r; i++) {
            ret = max(ret, 1LL * cnt[arr[i]] * sorted[arr[i]]);
        }
        for (int i = l; i <= r; i++) {
            cnt[arr[i]]--;
        }
        return ret;
    }

    void add(int num) {
        cnt[num]++;
        curAns = max(curAns, 1LL * cnt[num] * sorted[num]);
    }

    void del(int num) {
        cnt[num]--;
    }

    void compute() {
        for (int block = 1, qi = 1; block <= bnum && qi <= m; block++) {
            curAns = 0;
            fill(cnt + 1, cnt + cntv + 1, 0);
            int winl = br[block] + 1, winr = br[block];
            for (; qi <= m && bi[query[qi].l] == block; qi++) {
                int jobl = query[qi].l;
                int jobr = query[qi].r;
                int id = query[qi].id;
                if (jobr <= br[block]) {
                    ans[id] = force(jobl, jobr);
                } else {
                    while (winr < jobr) {
                        add(arr[++winr]);
                    }
                    long long backup = curAns;
                    while (winl > jobl) {
                        add(arr[--winl]);
                    }
                    ans[id] = curAns;
                    curAns = backup;
                    while (winl <= br[block]) {
                        del(arr[winl++]);
                    }
                }
            }
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
        	sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        cntv = 1;
        for (int i = 2; i <= n; i++) {
            if (sorted[cntv] != sorted[i]) {
            	sorted[++cntv] = sorted[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            br[i] = min(i * blen, n);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

六、达到阈值的最小众数

长度为 n 的数组，m 条查询 l r k。如果 arr[l..r] 上所有数字的出现次数都小于 k，打印 -1；否则打印这些数字里出现次数最多的那个，次数相同时取数值小的。1 <= n <= 10^4，1 <= m <= 5 * 10^4。测试链接：threshold-majority-queries。

加一个数字时，只有这一种数字的次数在涨，和当前最大次数比一下就能维护 maxCnt 和 minMode。删掉一个数字，次数降下来之后谁是新老大，同样说不清。还是只增回滚。

备份的内容变成两个数：backupCnt 和 backupNum。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, k, id;
    };

    const int MAXN = 10001;
    const int MAXM = 50001;
    const int MAXB = 301;

    int n, m;
    int arr[MAXN];
    Query query[MAXM];
    int sorted[MAXN];
    int cntv;

    int blen, bnum;
    int bi[MAXN];
    int br[MAXB];

    int cnt[MAXN];
    int maxCnt;
    int minMode;

    int ans[MAXM];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r < b.r;
    }

    int kth(int num) {
        int left = 1, right = cntv, ret = 0;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] <= num) {
                ret = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ret;
    }

    int force(int l, int r, int k) {
        int mx = 0, who = 0;
        for (int i = l; i <= r; i++) {
            cnt[arr[i]]++;
        }
        for (int i = l; i <= r; i++) {
            int num = arr[i];
            if (cnt[num] > mx || (cnt[num] == mx && num < who)) {
                mx = cnt[num];
                who = num;
            }
        }
        for (int i = l; i <= r; i++) {
            cnt[arr[i]]--;
        }
        return mx >= k ? sorted[who] : -1;
    }

    void add(int num) {
        cnt[num]++;
        if (cnt[num] > maxCnt || (cnt[num] == maxCnt && num < minMode)) {
            maxCnt = cnt[num];
            minMode = num;
        }
    }

    void del(int num) {
        cnt[num]--;
    }

    void compute() {
        for (int block = 1, qi = 1; block <= bnum && qi <= m; block++) {
            maxCnt = 0;
            minMode = 0;
            fill(cnt + 1, cnt + cntv + 1, 0);
            int winl = br[block] + 1, winr = br[block];
            for (; qi <= m && bi[query[qi].l] == block; qi++) {
                int jobl = query[qi].l;
                int jobr = query[qi].r;
                int jobk = query[qi].k;
                int id = query[qi].id;
                if (jobr <= br[block]) {
                    ans[id] = force(jobl, jobr, jobk);
                } else {
                    while (winr < jobr) {
                        add(arr[++winr]);
                    }
                    int backupCnt = maxCnt;
                    int backupNum = minMode;
                    while (winl > jobl) {
                        add(arr[--winl]);
                    }
                    if (maxCnt >= jobk) {
                        ans[id] = sorted[minMode];
                    } else {
                    	ans[id] = -1;
                    }
                    maxCnt = backupCnt;
                    minMode = backupNum;
                    while (winl <= br[block]) {
                        del(arr[winl++]);
                    }
                }
            }
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        cntv = 1;
        for (int i = 2; i <= n; i++) {
            if (sorted[cntv] != sorted[i]) {
                sorted[++cntv] = sorted[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            br[i] = min(i * blen, n);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    class Solution {
    public:
        vector<int> subarrayMajority(vector<int>& nums, vector<vector<int>>& queries) {
            n = (int)nums.size();
            m = (int)queries.size();
            for (int i = 1; i <= n; i++) {
                arr[i] = nums[i - 1];
            }
            for (int i = 1; i <= m; i++) {
                query[i].l = queries[i - 1][0] + 1;
                query[i].r = queries[i - 1][1] + 1;
                query[i].k = queries[i - 1][2];
                query[i].id = i;
            }
            prepare();
            compute();
            vector<int> ret(m);
            for (int i = 1; i <= m; i++) {
                ret[i - 1] = ans[i];
            }
            return ret;
        }
    };

七、相同数的最远距离

长度为 n 的数组，m 条查询 l r，打印 arr[l..r] 上相同数字的最远间隔距离，间隔距离指两个下标差的绝对值。1 <= n、m <= 2 * 10^5，1 <= arr[i] <= 2 * 10^9。测试链接：P5906。

答案还是只增不减的：窗口变大，最远距离只会变远。所以同样是只增回滚。有意思的是左右两侧扩的时候，更新逻辑并不一样。

右扩新来的下标是窗口里最大的，它只能和「这个数字在窗口里最靠左的位置」配对，所以维护 first，用 idx - first 更新答案。

左扩新来的下标是窗口里最小的，它只能和「这个数字在窗口里最靠右的位置」配对，所以维护 mostRight，用 mostRight - idx 更新答案。注意左扩不能去改 first，first 是右扩阶段定下来的窗口最左位置。

回滚删的是左扩加进来的那些下标，清 mostRight 时只清自己设的临时值：如果 mostRight[num] 就是当前下标，说明这个 num 在右侧根本没出现过，清成 0。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 200001;
    const int MAXB = 501;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];
    int sorted[MAXN];
    int cntv;

    int blen, bnum;
    int bi[MAXN];
    int br[MAXB];

    int first[MAXN];
    int mostRight[MAXN];
    int maxDist;

    int ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r < b.r;
    }

    int kth(int num) {
        int left = 1, right = cntv, ret = 0;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] <= num) {
                ret = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ret;
    }

    int force(int l, int r) {
        int ret = 0;
        for (int i = l; i <= r; i++) {
            if (first[arr[i]] == 0) {
                first[arr[i]] = i;
            } else {
                ret = max(ret, i - first[arr[i]]);
            }
        }
        for (int i = l; i <= r; i++) {
            first[arr[i]] = 0;
        }
        return ret;
    }

    void addRight(int idx) {
        int num = arr[idx];
        mostRight[num] = idx;
        if (first[num] == 0) {
            first[num] = idx;
        }
        maxDist = max(maxDist, idx - first[num]);
    }

    void addLeft(int idx) {
        int num = arr[idx];
        if (mostRight[num] == 0) {
            mostRight[num] = idx;
        } else {
            maxDist = max(maxDist, mostRight[num] - idx);
        }
    }

    void delLeft(int idx) {
        int num = arr[idx];
        if (mostRight[num] == idx) {
            mostRight[num] = 0;
        }
    }

    void compute() {
        for (int block = 1, qi = 1; block <= bnum && qi <= m; block++) {
            maxDist = 0;
            fill(first + 1, first + cntv + 1, 0);
            fill(mostRight + 1, mostRight + cntv + 1, 0);
            int winl = br[block] + 1, winr = br[block];
            for (; qi <= m && bi[query[qi].l] == block; qi++) {
                int jobl = query[qi].l;
                int jobr = query[qi].r;
                int id = query[qi].id;
                if (jobr <= br[block]) {
                    ans[id] = force(jobl, jobr);
                } else {
                    while (winr < jobr) {
                        addRight(++winr);
                    }
                    int backup = maxDist;
                    while (winl > jobl) {
                        addLeft(--winl);
                    }
                    ans[id] = maxDist;
                    maxDist = backup;
                    while (winl <= br[block]) {
                        delLeft(winl++);
                    }
                }
            }
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        cntv = 1;
        for (int i = 2; i <= n; i++) {
            if (sorted[cntv] != sorted[i]) {
                sorted[++cntv] = sorted[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            br[i] = min(i * blen, n);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        cin >> m;
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

八、累加和为 0 的最长子数组

长度为 n 的数组，里面只有 1 和 -1，m 条查询 l r，打印 arr[l..r] 上累加和为 0 的最长子数组长度。1 <= n、m <= 5 * 10^4。测试链接：SP20644。

前缀和转一下就是上一题。设 p[i] 是 arr[1..i] 的累加和，p[0] = 0。子数组 arr[i+1..j] 和为 0，等价于 p[i] = p[j]。于是「[l, r] 上和为 0 的最长子数组」变成「p[l-1..r] 这一段里相同数的最远距离」。

代码把 arr 原地变成前缀和再整体右移一位，查询的 r 加一，之后的逻辑和上一题一字不差。

// 题目4 与题目3 唯一的区别：读入后先把 arr 变成前缀和，整体右移一位，查询的 r 加一
    // 之后的离散化、分块、排序、compute 都和题目3 一字不差
    void prepare() {
        for (int i = 1; i <= n; i++) {
            arr[i] += arr[i - 1];
        }
        for (int i = n; i >= 0; i--) {
            arr[i + 1] = arr[i];
        }
        n++;
        for (int i = 1; i <= m; i++) {
            query[i].r++;
        }
        for (int i = 1; i <= n; i++) {
            sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        cntv = 1;
        for (int i = 2; i <= n; i++) {
            if (sorted[cntv] != sorted[i]) {
                sorted[++cntv] = sorted[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            br[i] = min(i * blen, n);
        }
        sort(query + 1, query + m + 1, QueryCmp);

    }

九、复杂度分析

环节复杂度说明
查询排序O(m log m)按 l 的块号、再按 r 排序
每组的右指针O(n)组内 jobr 不下降，winr 从 br 一路走到 n
全部组的右指针O(n√n)共 n / 块长 ≈ √n 组
每个任务的左指针O(√n)winl 只在块内移动，且每次都退回 br + 1
暴力任务O(√n)jobr <= br，区间长度不超过块长
总时间O((n + m)√n)m 条任务各自 O(√n)，加上全部组的右指针
额外空间O(n + m)计数数组 cnt 和查询数组

和普通莫队是同一个量级。多的只是每个任务结束时的那次回滚，回滚的长度不超过块长，不改变总量级。

十、最后

只增回滚莫队适用于「加容易、删难」的答案。判断的依据很简单：写下 add 和 del 两个函数，如果 del 需要重新扫一遍别的东西才能算，就走这条路。

反过来还有一类题，删容易、加回去难。那就是下一节的只删回滚莫队。
