缩点与 DAG 上的拓扑排序

上一讲把强连通分量找了出来，这一讲把每个分量压成一个点。压完之后环全没了，剩下的图一定是 DAG，于是拓扑序、线性 dp、最短路这些只在 DAG 上成立的手段全都能用。这一节的四道题都是「缩点 + 在 DAG 上扫一遍」，差别只在 dp 里维护的是什么：点权和、边收益、终点标记、还是路径上的最小价格。

零、背景

上篇讲的是怎么求强连通分量：一遍 Tarjan，用 dfn 和 low 把环找出来，栈里一次弹出来的一组点就是一个强连通分量。

求出分量之后，把每个分量当成一个点，分量之间的边就是原图里跨分量的边，这样得到的图叫缩点图。缩点图的点数是分量个数，边数不超过原来的边数。

缩点图最重要的性质是它没有环。如果缩点图里还有一个环，环上所有分量的点就互相可达，按定义它们本来就该是同一个强连通分量，矛盾。

一、缩点：把环压成一个点

没有环这件事，把「能不能到达」这个问题变简单了：判断 u 能否到 v，等价于判断 belong[u] 能否到 belong[v]，分量内部的细节全部被折叠掉。

分量内部点权的处理要按题目来。求路径点权和时，只要走进一个分量，就可以把它内部的点全部走一遍再出来，所以分量点权取内部点权之和；求路径上的最值时，分量内部可以随便走，所以只需要记内部的最小值和最大值。

缩点还会产生两种副作用，后面几道题会分别用到。一是同一个分量对之间可能出现多条边，也就是重边；二是缩点后可能留下入度为 0 的分量，这些点没有任何前驱。重边对「取最大值」的 dp 无害，对「计数」和「统计入度」却会重复累加。

二、题目1：缩点模板题

题目：n 个点 m 条边的有向图，每个点有非负点权，找一条路径让点权累加和最大，重复经过的点只算一次。

重复经过不算，说明绕圈毫无意义。于是把 SCC 缩掉，每个分量取内部点权之和，问题变成「DAG 上找一条路径让点权和最大」。DAG 上任何一条路径都是简单的，重边也不影响最大值。

接下来是 dp 顺序。这里有两种写法，结果一样，但道理要讲清。

第一种是老老实实做拓扑排序：先算每个缩点的入度，把所有入度为 0 的点放进队列，出队时用它去更新所有出边指向的点，同时把对方的入度减一，减到 0 就入队。队列里点的顺序就是拓扑序。

第二种不写队列，直接按 Tarjan 给出的分量编号从大到小扫一遍。原因是 Tarjan 是先确定「汇点」的：一个分量被弹出时，它能到达的分量都已经先被弹出了，所以编号小的分量更靠近汇，编号大的更靠近源。既然每条跨分量边都是从大编号指向小编号，那么从 sccCnt 倒着扫到 1，就是一次合法的拓扑序。

两种写法都写在下面这份代码里，topo() 是队列版，dpOnDAG() 是倒序扫描版。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 100001;
    int n, m;

    int arr[MAXN];
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sum[MAXN];
    int sccCnt;

    int indegree[MAXN];
    int que[MAXN];
    int dp[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sum[sccCnt] += arr[pop];
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 != scc2) {
                indegree[scc2]++;
                addEdge(scc1, scc2);
            }
        }
    }

    int topo() {
        int l = 1, r = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (indegree[i] == 0) {
                dp[i] = sum[i];
                que[++r] = i;
            }
        }
        while (l <= r) {
            int u = que[l++];
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                dp[v] = max(dp[v], dp[u] + sum[v]);
                if (--indegree[v] == 0) {
                    que[++r] = v;
                }
            }
        }
        int ans = 0;
        for (int i = 1; i <= sccCnt; i++) {
            ans = max(ans, dp[i]);
        }
        return ans;
    }

    int dpOnDAG() {
        for (int u = sccCnt; u > 0; u--) {
            if (indegree[u] == 0) {
                dp[u] = sum[u];
            }
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                dp[v] = max(dp[v], dp[u] + sum[v]);
            }
        }
        int ans = 0;
        for (int u = 1; u <= sccCnt; u++) {
            ans = max(ans, dp[u]);
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        condense();
        // int ans = topo();
        int ans = dpOnDAG();
        cout << ans << "\n";
        return 0;
    }

三、题目2：采蘑菇

题目：每条边有两个权值，初始收益和恢复系数，恢复系数在 0 到 0.8 之间且最多一位小数。同一条边第 k 次走时，收益是初始收益乘恢复系数的 k−1 次方再向下取整。给定起点 s，求一条从 s 出发的路径，让收益累加和最大。

先看一条边重复走时的收益。初始收益 10、恢复系数 0.6，依次拿到 10、6、3、1、0，之后再也没有了。这串数衰减很快，加下去只有 20，是个定值。

所以只要一条边落在某个分量内部，我们就一定能把它走到没有收益为止，它对答案的贡献就是这串收益的总和，可以预处理出来。

跨分量的边不一样。它连接两个不同的分量，一旦走过去，按 DAG 的性质就再也回不来了，所以每条跨分量边最多被走一次，收益就是它的初始收益。

实现上不用另开数组：缩点时枚举原图的每条边，如果两端属于同一个分量，就单独累加它的几何级数；否则按跨分量边加进新图，权值是初始收益。

起点固定这一条也有讲究。Tarjan 从 s 出发就够了，走不到的分量 belong 仍是 0，缩点时把它们跳过即可。dp 只在 belong[s] 处初始化，其余保持负无穷，最后对所有分量取最大值，就等价于「以 s 为起点的所有路径」。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 80001;
    const int MAXM = 200001;
    const int INF = 1000000001;
    int n, m, s;

    int a[MAXM];
    int b[MAXM];
    int init[MAXM];
    int recover[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int weight[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sum[MAXN];
    int sccCnt;

    int dp[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int popv;
            do {
                popv = sta[top--];
                belong[popv] = sccCnt;
            } while (popv != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 > 0 && scc2 > 0) {
                int val = init[i];
                int rec = recover[i];
                if (scc1 == scc2) {
                    while (val > 0) {
                        sum[scc1] += val;
                        val = val * rec / 10;
                    }
                } else {
                    addEdge(scc1, scc2, val);
                }
            }
        }
    }

    int dpOnDAG() {
        for (int u = 1; u <= sccCnt; u++) {
            dp[u] = -INF;
        }
        dp[belong[s]] = sum[belong[s]];
        for (int u = sccCnt; u > 0; u--) {
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                int w = weight[e];
                dp[v] = max(dp[v], dp[u] + w + sum[v]);
            }
        }
        int ans = 0;
        for (int u = 1; u <= sccCnt; u++) {
            ans = max(ans, dp[u]);
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        double rec;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i] >> init[i];
            cin >> rec;
            recover[i] = (int)(rec * 10);
            addEdge(a[i], b[i], 0);
        }
        cin >> s;
        tarjan(s);
        condense();
        int ans = dpOnDAG();
        cout << ans << "\n";
        return 0;
    }

四、题目3：劫掠计划

题目：n 个城市、m 条有向道路，每个城市有钱数。给定起点 s 和一批「有酒吧」的城市，终点必须是酒吧城市，重复经过的城市钱只拿一次，求最大钱数。

这就是题目1 加了两个约束：起点固定、终点必须带标记。钱数只拿一次，所以还是缩点后取分量内钱数之和。

终点标记也跟着缩点一起合并。一个分量只要有任意一个城市有酒吧，这个分量就能当终点，用一个或运算 hasBar[scc] |= isBar[u] 在弹栈时顺手维护。

最后的统计不能取全局最大，只能在这些有酒吧的分量里取最大。起点固定则和题目2 一样：Tarjan 只从 s 出发，dp 只在 belong[s] 初始化，其余是负无穷，这样走不到的分量天然不会贡献答案。

顺带一个细节：hasBar 是 bool 数组，而分量编号是从 1 开始的，每弹出一个新分量要先把它清成 false，否则会读到上一组数据的残留。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 500001;
    const int INF = 1000000001;
    int n, m, s, p;

    int money[MAXN];
    bool isBar[MAXN];
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sum[MAXN];
    bool hasBar[MAXN];
    int sccCnt;

    int dp[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sum[sccCnt] = 0;
            hasBar[sccCnt] = false;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sum[sccCnt] += money[pop];
                hasBar[sccCnt] |= isBar[pop];
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 > 0 && scc2 > 0 && scc1 != scc2) {
                addEdge(scc1, scc2);
            }
        }
    }

    int dpOnDAG() {
        for (int u = 1; u <= sccCnt; u++) {
            dp[u] = -INF;
        }
        dp[belong[s]] = sum[belong[s]];
        for (int u = sccCnt; u > 0; u--) {
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                dp[v] = max(dp[v], dp[u] + sum[v]);
            }
        }
        int ans = 0;
        for (int u = 1; u <= sccCnt; u++) {
            if (hasBar[u]) {
                ans = max(ans, dp[u]);
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            cin >> money[i];
        }
        cin >> s >> p;
        for (int i = 1, x; i <= p; i++) {
            cin >> x;
            isBar[x] = true;
        }
        tarjan(s);
        condense();
        int ans = dpOnDAG();
        cout << ans << "\n";
        return 0;
    }

五、题目4：最优贸易

题目：每个城市有一个水晶球价格，道路有单向也有双向。从 1 号城市走到 n 号城市，途中可以买入一次、卖出一次，求最大差价；走不到 n 就输出 0。

如果图是 DAG，只需要在拓扑序上维护两个量：走到 u 时见过的价格最小值 premin[u]，以及「卖在 u」能拿到的最大差价 dp[u]。转移就是 premin[v] = min(premin[v], premin[u]) 和 dp[v] = max(dp[v], value[v] − premin[v])。

但原图有环，而且卖点必须在买点之后。所以还是缩点，分量内部只关心价格的最小值和最大值：最小值用来承接买入，最大值用来承接卖出。

双向路会直接把两个城市揉成同一个分量，这一点很关键。看下面这个样例，5 号城市价格 1、4 号城市价格 6，本来可以走回头路「在 5 买入、回到 4 卖出」，赚 5 块；缩点之后 4 和 5 就是同一个分量，sccMax − sccMin = 6 − 1 = 5，回头路被自动处理掉了，不需要额外考虑。

另外注意「能不能到达 n」的判断。判的不是原图的 belong[n] 是否为 0 吗？是，但只要 belong[n] 非 0，就说明 Tarjan 从 1 出发能走到 n，此时 dp 一定被赋过值。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 500001;
    const int INF = 1000000001;
    int n, m;

    int val[MAXN];
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccMin[MAXN];
    int sccMax[MAXN];
    int sccCnt;

    int premin[MAXN];
    int dp[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sccMin[sccCnt] = INF;
            sccMax[sccCnt] = -INF;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccMin[sccCnt] = min(sccMin[sccCnt], val[pop]);
                sccMax[sccCnt] = max(sccMax[sccCnt], val[pop]);
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 > 0 && scc2 > 0 && scc1 != scc2) {
                addEdge(scc1, scc2);
            }
        }
    }

    int dpOnDAG() {
        for (int u = 1; u <= sccCnt; u++) {
            premin[u] = INF;
            dp[u] = -INF;
        }
        int s = belong[1];
        premin[s] = sccMin[s];
        dp[s] = sccMax[s] - sccMin[s];
        for (int u = sccCnt; u > 0; u--) {
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                premin[v] = min(premin[v], min(premin[u], sccMin[v]));
                dp[v] = max(dp[v], max(dp[u], sccMax[v] - premin[v]));
            }
        }
        return dp[belong[n]];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> val[i];
        }
        for (int i = 1, op; i <= m; i++) {
            cin >> a[i] >> b[i] >> op;
            if (op == 1) {
                addEdge(a[i], b[i]);
            } else {
                addEdge(a[i], b[i]);
                addEdge(b[i], a[i]);
            }
        }
        tarjan(1);
        if (belong[n] == 0) {
            cout << 0 << "\n";
        } else {
            condense();
            int ans = dpOnDAG();
            cout << ans << "\n";
        }
        return 0;
    }

缩点重建图（枚举每条原边）O(n + m)
题目1、3、4：拓扑序 / 按编号倒序扫一遍O(n + m)
题目2：分量内部边累加收益O(m · log C)O(n + m)

唯一不是纯线性的是题目2 的收益累加。while (val > 0) 每轮把 val 乘上恢复系数再除以 10，系数不超过 0.8，所以每一轮至少衰减两成，最多迭代一百来次就归零。这个常数极小，整段跑起来和线性没有区别。

空间上，dfn、low、栈、belong、dp 都是 O(n)，边长数组和重建成的新图是 O(m)，没有额外开销。

七、最后

四道题连起来看，套路是一致的：先缩点把环消掉，再在 DAG 上扫一遍，dp 里装的东西随题目变，点权和、边收益、终点标记、路径上的最小价格。真正需要想清楚的只有两件事，一个是分量内部的信息怎么合并，另一个是固定的起点或终点怎么在初始化里体现。

下一节换一类收口方式：同样是缩点后的 DAG，但 dp 里要开始数方案、跑最短路、套树上背包，还要用入度和出度做一些纯性质的分析。

《完》
