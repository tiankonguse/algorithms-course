前缀优化建图

上一节讲过 2-SAT：一条子句两条边。但有些限制天生是「一对多」，一个点要向一整段前缀里的每个点连边。逐条连边会让边数涨到平方级，n 到 10⁶ 时直接存不下。办法是给前缀配一串辅助点，把「连一整段」压成一条边。这一节讲这套构造，再配三道用到它的题。

零、背景

前面讲过 2-SAT 的基本做法：每个取值假设一个点，一条子句两条边，跑一遍强连通分量判定。

建图时会遇到一类麻烦的连边：某个点 p 一旦成立，就要求一整段位置里的每个点都跟着变。位置这一段通常是前缀。

线段树优化建图能处理这个问题，代价是每次连边 O(log n)，还要先搭一棵完整的线段树。前缀这种形状比任意区间规整得多，用一串辅助点就能压到 O(1) 条边，比线段树更省也更好写。

后缀是同样的事情反过来做，两者配合就能覆盖「一段区间」的限制。

一、问题

把限制写成有向边，就是「点 p → 前缀里每一个点」，或者反过来「前缀里每一个点 → 点 p」。

这类限制在 2-SAT 里很常见。拿集合来说：集合里有若干个点，要求至多选一个。等价的说法是，只要选了其中一个，就必须排除掉其余全部，这正是「一个点 → 一整个集合」。

麻烦在于数量。一段长 L 的前缀逐个连边要连 L 条；题里每个点都来一次，总边数就是 O(n²)。

二、朴素做法

就按字面连。当前要处理前缀 [1, x]，把它里面的点一一列出来，从 p 引出 x 条边。

每条这样的限制都做一遍，总边数是所有前缀长度之和。最坏情况（每次都是整个前缀）就是 O(n²)。

换线段树能压到 O(log n)，但要额外搭一棵树。前缀这种形状有更省的做法：造一串辅助点，让它们替 p 去连。

三、前缀优化：一串辅助点

给每个位置 i 配一个辅助点，记作 pre(i)。它承担「把连边引到前缀 [1, i] 全部点」的职责。

把辅助点串成一条链：pre(i) → pre(i−1)，同时 pre(i) → 点 i。

这样从 pre(x) 出发，沿链能走到 pre(x−1)、pre(x−2)、…、pre(1)，而每个 pre(j) 又有一条边通向点 j。于是「点 p 连到 [1, x] 里的每一个点」只需要一条边：p → pre(x)。

链是建图前一次性搭好的，与具体限制无关，总共约 2n 条边。之后每条前缀限制只花 1 条边。

反方向同理。「前缀 [1, x] 里的每个点到点 p」，把链的边反过来，让点 i 先接上自己的辅助点：点 i → t(i)、t(i) → t(i−1)，出口 t(1) → p。每个 i 都能沿链走到 t(1)，再走到 p。

还有一种「前缀 [1, x] 的每个点到前缀 [1, y] 的每个点」，两边各搭一串链，中间用一条边对接即可。

四、后缀与区间

后缀就是把前缀反过来。后缀 [x, f] 的每个点，用一串 suf 辅助点：suf(i) → suf(i+1)，点 i 接在自己的辅助点上，出口放在 suf(f)。

前缀和后缀配合，就能覆盖一段区间 [l, r] 的限制。2-SAT 里「挖掉」不方便直接做，但很多限制本来就拆成两半：一半是「位置 ≤ r 的一个前缀」，一半是「位置 ≥ l 的一个后缀」，左右各一条边就建完了。

本课三道用它的题，都是这个形态：要么是「集合里至多选一个」，要么是「单选的阈值开关」。

五、题目1：谜语

无向图有 n 个点、m 条边，一共 k 个阵营，每个点属于恰好一个阵营。选一些点当关键点，要求每个阵营恰好一个关键点，并且每条边至少有一个端点被选。

两条限制分开建图。变量是「点 i 是不是关键点」，节点 i 表示选，节点 i+n 表示不选。

每条边 (u, v) 至少一个端点被选，就是子句 (u ∨ v)，拆成两条边 ¬u → v、¬v → u。

「每个阵营恰好一个」拆两半。核心那半边是「阵营里不能同时选两个」：设阵营的点排成 arr[1..w]，只要 arr[i] 被选，前缀 arr[1..i−1] 和后缀 arr[i+1..w] 里就都不能有被选的点。

于是一组配两串辅助点。前缀链 A(i) 表示「arr[1..i] 里一个都没选」，边 A(i) → ¬arr[i]（前缀空则 arr[i] 不能选）、A(i) → A(i−1)（前缀更长也空）、arr[i] → A(i−1)（arr[i] 选了，前缀就必须空）。后缀链 B(i) 表示「arr[i..w] 里一个都没选」，边方向对称。

这样 link 一次给整组配好 O(w) 条边，替换掉原本的 w² 条。

另一半边，「至少一个」，不用建图。如果某个阵营一个都没选，随手把一个点改成关键点就行；而增加关键点只会让「每条边至少一个端点」更容易满足。所以判定可满足性时，只判「至多一个」就够了。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 5000001;
    const int MAXM = 10000001;
    int n, m, k, w, cntt;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void link() {
        cntt++;
        addEdge(cntt, arr[1] + n);
        for (int i = 2; i <= w; i++) {
            cntt++;
            addEdge(cntt, arr[i] + n);
            addEdge(arr[i], cntt - 1);
            addEdge(cntt, cntt - 1);
        }
        cntt++;
        addEdge(cntt, arr[w] + n);
        for (int i = w - 1; i >= 1; i--) {
            cntt++;
            addEdge(cntt, arr[i] + n);
            addEdge(arr[i], cntt - 1);
            addEdge(cntt, cntt - 1);
        }
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> k;
        cntt = n << 1;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u + n, v);
            addEdge(v + n, u);
        }
        for (int i = 1; i <= k; i++) {
            cin >> w;
            for (int j = 1; j <= w; j++) {
                cin >> arr[j];
            }
            link();
        }
        for (int i = 1; i <= cntt; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                check = false;
                break;
            }
        }
        cout << (check ? "TAK" : "NIE") << "\n";
        return 0;
    }

六、题目2：互质

n 张卡片，每张给两个待选数字，各选一个作为卡片的值。要求任意两张卡片的值都互质，问有没有方案。

变量是「卡片 i 选 a_i 还是 b_i」，两个假设就是节点 i 与 i+n。

两个数不互质，等价于它们共享一个质因子。于是换个角度按质因子分组：对每个质数 p，把所有「值能被 p 整除」的那一侧假设归成一组，这一组里最多只能有一个成立。

这又回到「集合里至多选一个」，用前缀加后缀链压边。做法是先用欧拉筛求出最小质因子表，把每张卡片的两个值分解成质因子，得到一堆（质因子 p，节点编号）的二元组。按 p 排序，同一个 p 的聚成一组，组内在节点顺序上套用上一节那串链。

每个节点只在自己所属的组里被约束一次，辅助点总数和总质因子个数同阶。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int p, i;
    };

    bool NodeCmp(Node a, Node b) {
        if (a.p != b.p) {
            return a.p < b.p;
        }
        return a.i < b.i;
    }

    const int MAXN = 1000001;
    const int MAXV = 2000001;
    const int MAXM = 3000001;
    int n, cntt, maxv;
    int ab[MAXN];

    bool vis[MAXV];
    int prime[MAXV];
    int minp[MAXV];
    int cntp;

    Node arr[MAXN];
    int cnta;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    int other(int x) {
        return x <= n ? (x + n) : (x - n);
    }

    void euler() {
        for (int i = 2; i <= maxv; i++) {
            if (!vis[i]) {
                prime[++cntp] = i;
                minp[i] = i;
            }
            for (int j = 1, p, v; j <= cntp; j++) {
                p = prime[j];
                v = i * p;
                if (v > maxv) {
                    break;
                }
                vis[v] = true;
                minp[v] = p;
                if (i % p == 0) {
                    break;
                }
            }
        }
    }

    void decompose() {
        for (int i = 1; i <= n << 1; i++) {
            for (int v = ab[i], p = minp[v]; v > 1; p = minp[v]) {
                arr[++cnta].p = p;
                arr[cnta].i = i;
                while (v % p == 0) {
                    v /= p;
                }
            }
        }
    }

    void link() {
        sort(arr + 1, arr + cnta + 1, NodeCmp);
        for (int l = 1, r = 1; l <= cnta; l = ++r) {
            while (r + 1 <= cnta && arr[l].p == arr[r + 1].p) {
                r++;
            }
            cntt++;
            addEdge(cntt, other(arr[l].i));
            for (int i = l + 1; i <= r; i++) {
                cntt++;
                addEdge(cntt, other(arr[i].i));
                addEdge(arr[i].i, cntt - 1);
                addEdge(cntt, cntt - 1);
            }
            cntt++;
            addEdge(cntt, other(arr[r].i));
            for (int i = r - 1; i >= l; i--) {
                cntt++;
                addEdge(cntt, other(arr[i].i));
                addEdge(arr[i].i, cntt - 1);
                addEdge(cntt, cntt - 1);
            }
        }
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        cntt = n << 1;
        for (int i = 1, a, b; i <= n; i++) {
            cin >> a >> b;
            ab[i] = a;
            ab[i + n] = b;
            maxv = max(maxv, max(a, b));
        }
        euler();
        decompose();
        link();
        for (int i = 1; i <= cntt; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                check = false;
                break;
            }
        }
        cout << (check ? "Yes" : "No") << "\n";
        return 0;
    }

七、题目3：电台

在 [1, f] 里选一个固定频率 ansx。p 个电台，每个给定频率范围 [l, r]，频率范围包含 ansx 的电台才能签约。签约还要满足 n 条「至少签 u 或 v」的要求、m 条「u 和 v 不能同时签」的限制。

变量是「电台 i 是否签约」，节点 i 表示签，i+p 表示不签。要求和限制都是常规子句：u ∨ v 拆成 ¬u → v、¬v → u；u 与 v 不能同时签拆成 u → ¬v、v → ¬u。

新东西是频率带来的约束，这里前缀链的含义和前面不一样：辅助点直接表示 ansx 与某个阈值的大小关系。pre(k) 表示「ansx ≤ k」，suf(k) 表示「ansx ≥ k」。

两串链负责传递单调性：pre(k−1) → pre(k)（ansx ≤ k−1 则当然 ansx ≤ k），suf(k+1) → suf(k)（ansx ≥ k+1 则 ansx ≥ k）。

电台 i 的约束「签了 i，ansx 就得落在 [l_i, r_i]」拆成两条边：i → pre(r_i) 和 i → suf(l_i)。

反过来「ansx 落在 [l_i, r_i] 外面就不能签 i」也要建：pre(l_i−1) → ¬i（频率太小，即 ansx ≤ l_i−1），suf(r_i+1) → ¬i（频率太大，即 ansx ≥ r_i+1）。这两条正是「一整段前缀 / 后缀到一个点」，靠链的走法各一条边搞定。

最后 ansx 不用显式求。一旦电台 i 入选就要求 ansx ≥ l_i，取所有入选电台 l_i 里的最大值作为 ansx 即可。链和那些通向 ¬i 的边会保证不会有某个入选电台的 r_i 小于这个最大值。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 400001;
    const int MAXT = 2000001;
    const int MAXM = 4000001;
    int n, p, f, m, cntt;

    int l[MAXN];
    int r[MAXN];

    int head[MAXT];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int pre[MAXN];
    int suf[MAXN];

    int ansx;
    int pick[MAXN];
    int siz;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void link() {
        pre[1] = ++cntt;
        for (int i = 2; i <= f; i++) {
            pre[i] = ++cntt;
            addEdge(pre[i - 1], pre[i]);
        }
        suf[f] = ++cntt;
        for (int i = f - 1; i >= 1; i--) {
            suf[i] = ++cntt;
            addEdge(suf[i + 1], suf[i]);
        }
        for (int i = 1; i <= p; i++) {
            addEdge(i, pre[r[i]]);
            addEdge(i, suf[l[i]]);
            if (l[i] - 1 >= 1) {
                addEdge(pre[l[i] - 1], i + p);
            }
            if (r[i] + 1 <= f) {
                addEdge(suf[r[i] + 1], i + p);
            }
        }
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    bool compute() {
        bool check = true;
        for (int i = 1; i <= p; i++) {
            if (belong[i] == belong[i + p]) {
                check = false;
                break;
            } else if (belong[i] < belong[i + p]) {
                ansx = max(ansx, l[i]);
                pick[++siz] = i;
            }
        }
        return check;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> p >> f >> m;
        cntt = p << 1;
        for (int i = 1, u, v; i <= n; i++) {
            cin >> u >> v;
            addEdge(u + p, v);
            addEdge(v + p, u);
        }
        for (int i = 1; i <= p; i++) {
            cin >> l[i] >> r[i];
        }
        link();
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v + p);
            addEdge(v, u + p);
        }
        for (int i = 1; i <= cntt; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = compute();
        if (check) {
            cout << siz << " " << ansx << "\n";
            for (int i = 1; i <= siz; i++) {
                cout << pick[i] << " ";
            }
        } else {
            cout << -1 << "\n";
        }
        return 0;
    }

八、复杂度分析

设原问题有 N 个 2-SAT 节点、M 条限制，前缀（后缀）链额外引入 O(N) 个辅助点。关键的差别在一次「点 ↔ 前缀」连边的代价。

做法一次「点 ↔ 前缀」连边总边数
逐个连边O(L)（L 为前缀长度）O(N²)
线段树优化建图O(log N)O((N + M) log N)
前缀 / 后缀优化建图O(1)O(N + M)

朴素做法最坏情况是 O(N²) 条边，N 到 10⁶ 时是 10¹² 条，时间和空间都撑不住。前缀链把它压回 O(N + M)：链本身只搭一次，共约 2N 条边，之后每条限制固定 1 条边。

整体流程是：O(N + M) 建图，Tarjan 求强连通分量 O(N + M) 时间、O(N + M) 空间，判定和取解 O(N)。点数变成原节点数加上辅助点数，仍是线性规模。

谜语题的辅助点是每个阵营各一串，总数与阵营里点的总数同阶，不超过 N；互质题的辅助点数与总质因子个数同阶；电台题的 pre、suf 各 f 个，f 与 p 同阶。

九、最后

前缀优化的卖点是一句话：把「连一整段」换成「连一个入口」。入口就是链头，链负责把一步拆成一路走到底，代价是预先花 O(n) 搭链。

和线段树优化建图对照着记：线段树管任意区间，每次 O(log n)；前缀链只管前缀和后缀，但每次 O(1)，代码也更短。

三道题的链长得不一样，骨架是同一个。谜语和互质是「集合里至多选一个」，链挂在集合内点的顺序上；电台是「单选的阈值开关」，链挂在频率轴上。看到「一旦选了某个，就要求一整段位置满足条件」，基本就是它。

这一节用到的原理在2-SAT那页，更多结合优化建图的题目在2-SAT 与优化建图的更多题目里接着讲。
