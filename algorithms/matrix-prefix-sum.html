二维前缀和：矩形区域和与边框正方形

一维前缀和把子数组和变成两个前缀和的差。矩阵里也能干同样的事：先 O(n·m) 预处理出一张前缀和表，之后任意矩形区域的和都是四个格子加减一次 O(1)。边框为 1 的最大正方形也靠它。

零、背景

「矩阵上反复问某个矩形区域的和」这类问题很常见：图像处理里的积分图、二维数组上的子矩阵统计。n、m 到 10^3 量级时，朴素做法每次查询把矩形里的格子一个个加起来，q 次查询就是 O(q·n·m)，扛不住。

一维的套路是「前缀和数组」，二维直接照搬：预处理出一张 sum，sum[i][j] 表示从 (0,0) 到 (i,j) 这个矩形的累加和。有了这张表，任意 (a,b) 到 (c,d) 的和都能靠容斥一次算出来。

一、sum 表怎么构造

sum[i][j] = sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1] + matrix[i][j]。左边那块加上面那块，重叠的左上角被加了两次要减回去。

上面的公式要按行从上到下、每行从左到右填，填 (i,j) 时它左边、上边、左上都已算好。

实际写代码往往在矩阵外面补一圈 0：sum 开成 (n+1)×(m+1)，第 0 行第 0 列全是 0。这样 i=0 或 j=0 时公式里的 sum[i-1][j]、sum[i][j-1] 都有值，不用特判边界。

二、查询：矩形和 = 四格容斥

要 (a,b) 到 (c,d) 的累加和。sum[c][d] 是从 (0,0) 到 (c,d) 的整块，多算了上面一块、左边一块，还多减了左上角那块，加回来：

sum[c][d] - sum[a-1][d] - sum[c][b-1] + sum[a-1][b-1]

查询里下标是原矩阵的 (a,b,c,d)，对应到补了 0 圈的 sum 数组要整体偏移：sum[c+1][d+1] - sum[a][d+1] - sum[c+1][b] + sum[a][b]。这一页的代码就这么写。

LeetCode 304 就是模版题：构造一次，之后任意区域查询 O(1)。

三、题 1：区域和检索（LeetCode 304）

构造 sum 表，sumRegion 返回四格容斥。构造 O(n·m)，每次查询 O(1)，空间 O(n·m)。

四、题 2：边框为 1 的最大正方形（LeetCode 1139）

给一个 01 矩阵，找边界全部由 1 组成的最大正方形，返回它的面积。

暴力想法：枚举所有左上角 (a,b) 和边长 k，检查边框是否全 1。检查边框 O(k)，枚举左上角 O(n·m)，边长最多 min(n,m)，整体 O(n·m·min(n,m))。

有了前缀和，「检查边框」也能 O(1)：整个正方形的和减去内部（去掉边框一圈）的和，差等于边框上 1 的个数。边框全 1 当且仅当这个差等于边框长度 4(k-1)。

代码里还有个小优化：ans 从 1 开始，只尝试比当前 ans 更大的边长。这样稀疏矩阵里答案小，内层循环会跑很多；全 1 矩阵里 ans 快速变大，内层循环立刻收缩。

实测（本机 g++ -O2，500×500）：稀疏矩阵（约 1/3 为 1）答案 16，检查了 4090 万次候选，51ms；全 1 矩阵答案 250000，只检查 499 次，0.07ms。差的不是常数，是 ans 提前变大后内层循环的终止条件立刻生效。

五、复杂度与实测

构造 O(n·m)，每次查询 O(1)，空间 O(n·m)。

实测（本机 g++ -O2，n=m=1000，随机矩阵，2 万次查询）：前缀和总耗时 0.209ms；朴素做法平均每个矩形 62933 个格子，总耗时 106.475ms，差了约 508 倍。查询越多、矩形越大，前缀和的优势越明显。

六、代码

#include <bits/stdc++.h>
    using namespace std;

    class NumMatrix {
    public:
        vector<vector<int>> sum;

        NumMatrix(vector<vector<int>>& matrix) {
            int n = matrix.size(), m = matrix[0].size();
            sum = vector<vector<int>>(n + 1, vector<int>(m + 1, 0));
            for (int i = 0; i < n; i++)
                for (int j = 0; j < m; j++)
                    sum[i + 1][j + 1] = matrix[i][j];
            for (int i = 1; i <= n; i++)
                for (int j = 1; j <= m; j++)
                    sum[i][j] += sum[i][j - 1] + sum[i - 1][j] - sum[i - 1][j - 1];
        }

        int sumRegion(int a, int b, int c, int d) {
            return sum[c + 1][d + 1] - sum[c + 1][b] - sum[a][d + 1] + sum[a][b];
        }
    };

题 2 的代码里 build 把 grid 原地变成自己的前缀和，不补 0 圈，越界当 0 读（get 函数）。两版写法等价，区别只在边界处理方式。

#include <bits/stdc++.h>
    using namespace std;

    // 边框为 1 的最大正方形：grid 原地变成自己的前缀和
    vector<vector<int>> G;
    int get(int i, int j) {
        return (i < 0 || j < 0) ? 0 : G[i][j];
    }
    void build(int n, int m) {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                G[i][j] += get(i, j - 1) + get(i - 1, j) - get(i - 1, j - 1);
    }
    int sum(int a, int b, int c, int d) {
        return a > c ? 0 : (G[c][d] - get(c, b - 1) - get(a - 1, d) + get(a - 1, b - 1));
    }
    int largest1BorderedSquare(vector<vector<int>>& g) {
        int n = g.size(), m = g[0].size();
        G = g;
        build(n, m);
        if (sum(0, 0, n - 1, m - 1) == 0) return 0;
        int ans = 1;
        for (int a = 0; a < n; a++)
            for (int b = 0; b < m; b++)
                for (int c = a + ans, d = b + ans, k = ans + 1; c < n && d < m; c++, d++, k++)
                    if (sum(a, b, c, d) - sum(a + 1, b + 1, c - 1, d - 1) == (k - 1) << 2)
                        ans = k;
        return ans * ans;
    }

总结

二维前缀和是一维的直接推广：构造时「左 + 上 - 左上 + 自己」，查询时「右下 - 上 - 左 + 左上」。补 0 圈让边界特判消失，代码短一截。

边框为 1 的正方形把「边框全 1」翻译成「外框和 - 内框和 = 4(k-1)」，检查 O(1)。下一讲二维差分，矩形批量加 v 也能 O(1) 处理。
