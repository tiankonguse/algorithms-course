边双缩点与树上统计

缩点把图变成树之后，树上能做的事情全能搬过来。这一节的四道题分别用上倍增 LCA、dfn 序 LCA 配点差分、边差分判方向、树形 dp 计数，全是上一节的缩点模版再加几行。题目本身都不算新，值钱的地方是「图上的哪句话对应到树上是哪件事」。

零、背景

还是那句老话：边双缩完点，桥变成树边，连通图变成一棵树。之后的所有问题都在这棵树上做。

树上常用的三件套，这几道题都会用到。求两点距离靠 LCA，dist(x,y) = dep[x] + dep[y] - 2 dep[lca]；一条路径上的点被覆盖多少次，靠点差分，在 x、y 处加、在 lca 及其父亲处减；一条路径上的边被覆盖多少次，靠边差分，在 x、y 处加、在 lca 处减两次。

点差分最后对子树求和，边差分同样对子树求和，只是边记在它下面的那个点上。这两套模板各题都会反复出现。

一、题目4：神会作弊

无向连通图，两点之间的重边只连一次。定义距离：如果 x、y 在同一个边双里，距离是 1；否则是先缩点，再取两点在树上简单路径经过的节点数。q 次询问 x、y 的距离，输出它的二进制形式。

「同一分量距离为 1」和「树上路径节点数」其实是一句话：路径上的节点数，等于边数加一。同分量时 x 缩点后等于 y，边数是 0，加一正好是 1。

重边要先处理。题目保证重边只连一次，所以按端点排序去重即可。这里的排序还有个附带好处：tarjan 里用边编号判父边，去重之后也不会有平行边来捣乱。

然后就是标准倍增 LCA。dfs 一遍求出深度和 stjump[u][p]，查询时先把深的那个提到同深度，再一起往上跳，得到 LCA，距离就是 dep[x] + dep[y] - 2 dep[lca] + 1。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int u, v;
    };

    bool EdgeCmp(Edge e1, Edge e2) {
        if (e1.u != e2.u) {
            return e1.u < e2.u;
        }
        return e1.v < e2.v;
    }

    const int MAXN = 10001;
    const int MAXM = 50001;
    const int MAXP = 15;
    int n, m, q;
    Edge edgeArr[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int ebccCnt;

    int dep[MAXN];
    int stjump[MAXN][MAXP];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void buildGraph() {
        sort(edgeArr + 1, edgeArr + m + 1, EdgeCmp);
        int k = 1;
        for (int i = 2; i <= m; i++) {
            if (edgeArr[k].u != edgeArr[i].u || edgeArr[k].v != edgeArr[i].v) {
                edgeArr[++k] = edgeArr[i];
            }
        }
        for (int i = 1; i <= k; i++) {
            addEdge(edgeArr[i].u, edgeArr[i].v);
            addEdge(edgeArr[i].v, edgeArr[i].u);
        }
        m = k;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[edgeArr[i].u];
            int ebcc2 = belong[edgeArr[i].v];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int getDist(int x, int y) {
        return dep[x] + dep[y] - 2 * dep[getLca(x, y)];
    }

    string toBinaryString(int x) {
        if (x == 0) {
            return "0";
        }
        string s;
        while (x > 0) {
            s.push_back((x & 1) ? '1' : '0');
            x >>= 1;
        }
        reverse(s.begin(), s.end());
        return s;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            edgeArr[i].u = min(u, v);
            edgeArr[i].v = max(u, v);
        }
        buildGraph();
        tarjan(1, 0);
        condense();
        dfs(1, 0);
        cin >> q;
        for (int i = 1, x, y; i <= q; i++) {
            cin >> x >> y;
            x = belong[x];
            y = belong[y];
            cout << toBinaryString(getDist(x, y) + 1) << "\n";
        }
        return 0;
    }

二、题目5：旅行家

无向连通图，每个点有点权。一条路径要求点可重复经过、边不能重复。q 次操作，每次从 x 出发到 y，把所有可能的路径都走一遍；某个点被任一条路径经过一次，点权就计入收益，之后再经过不重复计。求总收益。

「点可以重复、边不能重复」又一次把边双搬了出来：一个边双里的所有点，都能被从任一端进入的路径覆盖到。所以从 x 到 y 的所有可能路径，合起来覆盖的点，正好是缩点树上 x 到 y 路径上那些边双里的全部点。

先把每个边双的点权之和记在 sum[边双] 上，在 tarjan 弹栈时顺手累加。缩点之后，每次操作就是给树上一条路径打一个「访问标记」；一个边双只要被打过一次标记，它的 sum 就算进答案。

「路径打标记、最后看每个点被覆盖几次」是树上点差分的经典用法：cnt[x]++、cnt[y]++、cnt[lca]--、cnt[fa[lca]]--，然后对子树求和。和大于 0 的点就是被覆盖到的点。这里的 LCA 用 dfn 序加稀疏表求，做到 O(1)。

树上点差分怎么算路径覆盖

在缩点树上走一遍题目5。点「下一步」，看一条路径的四个端点标记怎么打、LCA 怎么找、子树求和后哪些点被判为覆盖。

路径经过的点 被覆盖（子树和 > 0） 未覆盖

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 2000001;
    const int MAXP = 20;
    int n, m, q;
    int arr[MAXN];
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sum[MAXN];
    int ebccCnt;

    int lg2[MAXN];
    int rmq[MAXN][MAXP];

    int useCnt[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
                sum[ebccCnt] += arr[pop];
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    int getUp(int x, int y) {
        return dfn[x] < dfn[y] ? x : y;
    }

    void dfs(int u, int fa) {
        dfn[u] = ++cntd;
        rmq[dfn[u]][0] = fa;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    void buildRmq() {
        cntd = 0;
        dfs(1, 0);
        for (int i = 2; i <= ebccCnt; i++) {
            lg2[i] = lg2[i >> 1] + 1;
        }
        for (int pre = 0, cur = 1; cur <= lg2[ebccCnt]; pre++, cur++) {
            for (int i = 1; i + (1 << cur) - 1 <= ebccCnt; i++) {
                rmq[i][cur] = getUp(rmq[i][pre], rmq[i + (1 << pre)][pre]);
            }
        }
    }

    int getFather(int x) {
        return rmq[dfn[x]][0];
    }

    int getLCA(int x, int y) {
        if (x == y) {
            return x;
        }
        x = dfn[x];
        y = dfn[y];
        if (x > y) {
            swap(x, y);
        }
        x++;
        int k = lg2[y - x + 1];
        return getUp(rmq[x][k], rmq[y - (1 << k) + 1][k]);
    }

    void dfsOnTree(int u, int fa) {
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfsOnTree(v, u);
                useCnt[u] += useCnt[v];
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
            addEdge(b[i], a[i]);
        }
        tarjan(1, 0);
        condense();
        buildRmq();
        cin >> q;
        for (int i = 1, x, y, xylca, lcafa; i <= q; i++) {
            cin >> x >> y;
            x = belong[x];
            y = belong[y];
            xylca = getLCA(x, y);
            lcafa = getFather(xylca);
            useCnt[x]++;
            useCnt[y]++;
            useCnt[xylca]--;
            useCnt[lcafa]--;
        }
        dfsOnTree(1, 0);
        int ans = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            if (useCnt[i] > 0) {
                ans += sum[i];
            }
        }
        cout << ans << "\n";
        return 0;
    }

三、题目6：只能一个方向

无向图，可能有多个连通块。q 条要求，每条是「从 x 出发能到 y」。要给每条无向边定一个唯一方向，问能否同时满足所有要求。

先看边双内部。边双里每条边都在某个环上，把环上的边顺次定向，内部就能互相到达。也就是说，一个边双内部的方向总能满足；需要操心的只有连接边双之间的桥。

缩点成森林。要求 x 能到 y，表示缩点树上 x 到 y 这条路径上的每条树边都要朝 y 那一侧；等价地，每条树边要么必须「向上」（朝根），要么必须「向下」。一条要求 x→y 会把它路径上的边全部要求成「x 到 y 的方向」。

于是对每条树边维护两个计数：upCnt 表示有多少要求要它向上，downCnt 表示要它向下。用边差分把每条要求的路径拆到两端：upCnt[x]++、upCnt[lca]--，downCnt[y]++、downCnt[lca]--，再对子树求和。

子树和出来之后，某条树边如果 upCnt 和 downCnt 都不为零，说明它被要求同时朝两个方向，矛盾，无解。另外要求的两端点如果不在同一连通块里，也无解。两个条件都过了就输出 Yes。

    int dep[MAXN];
    int stjump[MAXN][MAXP];

    bool vis[MAXN];
    int upCnt[MAXN];
    int downCnt[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {

            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    void dfs(int u, int fa, int bid) {
        block[u] = bid;
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u, bid);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {

        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {

        if (a == b) {
            return a;

            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];

    bool check(int u, int fa) {
        vis[u] = true;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                if (!check(v, u)) {
                    return false;
                }
                upCnt[u] += upCnt[v];
                downCnt[u] += downCnt[v];
            }
        }
        return upCnt[u] == 0 || downCnt[u] == 0;
    }

        cin >> n >> m >> q;

            if (dfn[i] == 0) {
                tarjan(i, 0);
            }
        }
        condense();
        for (int i = 1, b = 0; i <= ebccCnt; i++) {
            if (block[i] == 0) {
                dfs(i, 0, ++b);
            }
        }
        bool ans = true;
        for (int i = 1, x, y, xylca; i <= q; i++) {
            cin >> x >> y;
            x = belong[x];
            y = belong[y];
            if (block[x] != block[y]) {
                ans = false;
                break;
            }
            xylca = getLca(x, y);
            upCnt[x]++;
            upCnt[xylca]--;
            downCnt[y]++;
            downCnt[xylca]--;
        }
        if (ans) {
            for (int i = 1; i <= ebccCnt; i++) {
                if (!vis[i] && !check(i, 0)) {
                    ans = false;
                    break;
                }
            }
        }
        cout << (ans ? "Yes" : "No") << "\n";
        return 0;
    }

四、题目7：建造军营

无向连通图。选一个非空的城市集合建军营，再选一个道路集合派兵看守（可以不选）。敌人袭击任意一条没被看守的道路并切断它；如果出现两座军营不连通就算失败。求不败的方案数，对 1000000007 取余。

关键是把「哪些道路必须看守」想清楚。边双内部的边不用守：环上的边断一条还有别的路。真正要守的只有桥。选好军营之后，缩点树上由这些军营张出的最小连通子树里的每条桥都必须看守，其余的桥可守可不守。

于是树形 dp。dp[u] 记「子树 u 内军营非空、并且 u 到父亲那条桥强制看守」的方案数，bridge[u] 记子树 u 内的桥数。初值是 2^siz[u] - 1，即只在本边双里选非空军营，边双内部无边需要看守。

合并孩子 v（桥是 u-v）时分三类。v 侧没有军营：u-v 不用守、v 子树内的桥也都不用守，各有两种选择，贡献 dp[u] · 2^bridge[v] · 2。u 侧此前没有军营、军营全在 v 侧：u-v 必须守，u 侧旧桥自由，贡献 2^bridge[u] · dp[v]。两侧都有军营：u-v 必须守，贡献 dp[u] · dp[v]。三者相加更新 dp[u]，同时 bridge[u] 加上 bridge[v] + 1。

最后枚举「最浅的那个有军营的边双」i。i 之上的桥全都不需要守，可以自由选择，所以再乘上 2^(bridge[1] - bridge[i] - 1)；剩下的、不属于任何边双的桥也在末尾一次性乘 2^(m - bridge[1])。

        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            ebccSiz[ebccCnt] = 0;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
                ebccSiz[ebccCnt]++;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    void dpOnTree(int u, int fa) {
        dp[u] = power2[ebccSiz[u]] - 1;
        bridge[u] = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dpOnTree(v, u);
                dp[u] = (dp[u] * power2[bridge[v]] * 2 % MOD
                        + power2[bridge[u]] * dp[v] % MOD
                        + dp[u] * dp[v] % MOD) % MOD;
                bridge[u] += bridge[v] + 1;
            }
        }
    }

    ll compute() {
        power2[0] = 1;
        for (int i = 1; i <= m; i++) {
            power2[i] = power2[i - 1] * 2 % MOD;
        }
        dpOnTree(1, 0);
        int total = bridge[1];
        ll ans = dp[1];
        for (int i = 2; i <= ebccCnt; i++) {
            ans = (ans + dp[i] * power2[total - bridge[i] - 1] % MOD) % MOD;
        }
        ans = ans * power2[m - total] % MOD;
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
            addEdge(b[i], a[i]);
        }
        tarjan(1, 0);
        condense();
        ll ans = compute();
        cout << ans << "\n";
        return 0;
    }

五、复杂度分析

四道题都是先一遍 tarjan 缩点，再在缩点树上做一遍线性或对数级别的预处理，之后每条询问 O(log n) 或 O(1)。

操作时间复杂度空间复杂度
tarjan 求边双 + 缩点O(n + m)O(n + m)（倍增表 O(n log n)）
题目4 一次查询（倍增 LCA）O(log n)
题目5 一次操作（dfn 序 RMQ，O(1) LCA + 点差分）O(1) 均摊
题目6 一次要求 + 收尾判定（倍增 LCA + 边差分）O(log n) / O(n)
题目7 树形 dpO(n)O(n)

题目5 的 LCA 用 dfn 序加稀疏表，单次降到 O(1)，q 到 10⁶ 也扛得住。题目6 要先对每条要求判连通块、再边差分，最后对子树求一遍和，整体线性。题目7 的 power2 预处理到边数，dp 仍是每个点一次合并。

六、最后

四道题连着看，套路是一致的：先缩点，再在树上用 LCA、差分或 dp 收口。真正需要动脑的是把题目里的「路径 / 覆盖 / 定向 / 计数」翻译成树上的一句话，翻译对了，代码就是模板拼接。

边双这一支到这里告一段落，下一讲换割点和点双连通分量，圆方树那一套会重新把「点」而不是「边」压进方点里。

《完》
