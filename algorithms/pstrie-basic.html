可持久化 01Trie：版本差就是区间

可持久化线段树的思路是「两个版本相减等于一个区间」。把这套搬到 01Trie 上照样成立，只是管的东西变了：线段树的版本差给出一段下标，01Trie 的版本差给出一个数的集合。这一页讲它怎么建、怎么查，再讲第一道题里那个最容易写错的边界。

零、前缀版本

设 root[i] 是「只插入了 arr[1..i]」这一版 01Trie。插入第 i 个数时不能动旧节点，只能把根到叶子这一条路径复制一份，在副本上改。root[i] 和 root[i-1] 因此共享掉绝大部分节点，只多出 BIT + 2 个。

查询时两个版本一起往下走。某个儿子的 pass 之差大于 0，意思是「v 里有、u 里没有」，也就是这个数落在差集里。所以 query(num, u, v) 回答的是：在「v 的集合减去 u 的集合」里挑一个，与 num 异或最大是多少。

可以发现复制是「边下潜边做」的：pre 指向新建的上一层，i 在旧树的同一位置上同步往下走，每步把旧节点的两个儿子整块拷给新节点，然后 pass + 1。

一、题目1：最大异或和

非负序列 arr，初始长度 n，m 条操作。一种是 A x，往末尾追加 x；另一种是 Q l r x，在 [l, r] 里挑一个位置 p，让 arr[p] ^ arr[p+1] ^ ... ^ arr[n] ^ x 最大，打印这个最大值。n、m 到 3 × 10⁵，值不超过 10⁷。题目链接 P4735。

朴素做法是枚举每个 p，一路异或到 n，一次 O(n)。上万次操作就到 10¹⁰ 了，必须换工具。

记 pre[i] = arr[1] ^ ... ^ arr[i]，pre[0] = 0，eor = pre[n]。那么 arr[p] ^ ... ^ arr[n] = eor ^ pre[p-1]。查询变成：在 p ∈ [l, r] 中选一个，最大化 (eor ^ x) ^ pre[p-1]。

p 在 [l, r] 里走，p-1 就在 [l-1, r-1] 里走。要查的集合是 {pre[l-1], ..., pre[r-1]}，正好是 root[r-1] 减去 root[l-2]。

这里有个细节：pre[0] = 0 必须真的在某个版本里。代码开头写 root[0] = insert(eor, 0)，就是在空树里插入一次 0，让 root[0] 这个版本里有 pre[0]。之后 l = 1 的查询拿空树当 u、拿 root[r-1] 当 v，差集里自然带上 pre[0]。

二、怎么复制一条路径

    
int insert(int num, int i) {
        int rt = ++cnt;
        tree[rt][0] = tree[i][0];
        tree[rt][1] = tree[i][1];
        pass[rt] = pass[i] + 1;
        for (int b = BIT, path, pre = rt, cur; b >= 0; b--, pre = cur) {
            path = (num >> b) & 1;
            i = tree[i][path];
            cur = ++cnt;
            tree[cur][0] = tree[i][0];
            tree[cur][1] = tree[i][1];
            pass[cur] = pass[i] + 1;
            tree[pre][path] = cur;
        }
        return rt;
    }

i 是旧版本的节点编号，rt 是这一层新建的节点。循环里 pre 跟着新链走、i 跟着旧链走，拷贝两个儿子和 pass，最后把新节点挂到 tree[pre][path] 上。整棵旧树没有一处被改写。

三、怎么贪心往下走

    
int query(int num, int u, int v) {
        int ans = 0;
        for (int b = BIT, path, best; b >= 0; b--) {
            path = (num >> b) & 1;
            best = path ^ 1;
            if (pass[tree[v][best]] > pass[tree[u][best]]) {
                ans += 1 << b;
                u = tree[u][best];
                v = tree[v][best];
            } else {
                u = tree[u][path];
                v = tree[v][path];
            }
        }
        return ans;
    }

从最高位到最低位，每一位优先走「和 num 这一位相反」的儿子，那一支能让结果的这一位变成 1。走不成的条件是 pass[tree[v][best]] - pass[tree[u][best]] == 0，也就是差集里压根没有这一支的数，只能退而走同向。

下面这个演示用 3 位来跑：arr = [1, 2, 3]，查询 Q 2 3 5。此时 eor = pre[3] = 0，num = eor ^ x = 5，可选集合是 {pre[1], pre[2]} = {1, 3}。

一处是 root[0] 的初始化，前面说过了。另一处是 x == 1 的分支：l = 1 时 u 用空树 0，否则用 root[x - 2]。变量名有点乱，读进来是 x, y, z，实际含义是 l, r, x，eor 则在每次 A 操作后跟着异或一次。

复杂度分析

BIT 取 25，因为值不超过 10⁷，异或前缀和也在 2²⁴ 以内，多留一位保险。

项目时间空间
插入一个数O(BIT)O(BIT) 个新节点
一次 queryO(BIT)—
初始化 n 个数O(n · BIT)O(n · BIT)
m 条操作O(m · BIT)O((n + m) · BIT)

代码里 MAXN = 600001、MAXT = MAXN * 22。节点数是按「插入次数 × (BIT + 2)」估的，n 和 m 各 3 × 10⁵ 时插入次数最多 6 × 10⁵，这也是 MAXN 开到 6 × 10⁵ 的原因。

最后

这一页只有一棵树、两个函数。真正要记住的是那句「两个版本相减 = 一个集合」，后面几道题翻来覆去都在改一件事：这个「版本」按下标排、按 dfn 排，还是按别的东西排。
