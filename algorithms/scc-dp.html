缩点后 DAG 上的 dp 与性质分析

上一节把缩点后的路径类 dp 走了一遍，这一节换五种收口方式：数方案、跑最短路、套树上背包、做差分约束、还有只看入度出度的纯性质题。共同点还是先缩点，差别在于缩点图上究竟再跑什么算法，以及为什么缩点这一步非做不可。

零、背景

缩点的结论还是那几句：每个强连通分量压成一个点，缩点图是 DAG，分量内部的信息按题目需要预处理好再带进新图。

这一节的五道题里，有三道必须处理重边，有一道必须在缩点后换用最短路而不是 dp，还有一道的答案完全由入度和出度决定，连 dp 都不需要。先把每道题在缩点图上做什么想清楚，代码都是拼接。

一、题目5：最大半连通子图

题目：两点之间只要有一个能到达另一个，就叫半连通。一个点集，如果其中任意两点都半连通，就是半连通图。求原图的最大半连通子图的大小，以及这样的子图有多少个，数量对给定数字取余。

先想半连通的点集长什么样。同一个强连通分量里的点两两可达，肯定可以整块拿进去。两个分量之间，如果互相都到不了，那这两个分量不能同时出现在一个半连通点集里。

于是把分量当成带权点（权是分量大小），问题变成：在缩点 DAG 上找一条链，让链上权值和最大，并且数出这样的链有多少条。这就是最长路加计数。

dp 要同时维护两个量：dpSum[u] 是以 u 结尾的最长链权值和，dpCnt[u] 是达到这个和的方案数。转移时如果能把对方推得更长，方案数直接覆盖过来；如果正好相等，方案数相加取模。

剩下的坑是重边。同一对分量之间在原图里可能有很多条边，如果不去重，dpCnt 会被同一条链重复累加。做法是把所有跨分量边压成一个 64 位整数 (scc1 << 32) | scc2，排序之后相同的必然相邻，扫一遍只保留第一次出现的，顺便把入度也算对。

这里用 64 位整数当键，是因为分量编号不超过 10⁵，压在同一个数里既能排序又能还原两个端点，比开 vector 省得多。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXM = 1000001;
    int n, m, x;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccSiz[MAXN];
    int sccCnt;

    ll edgeArr[MAXM];
    int cnte;

    int indegree[MAXN];
    int dpSum[MAXN];
    int dpCnt[MAXN];

    int ans1, ans2;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sccSiz[sccCnt] = 0;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccSiz[sccCnt]++;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 != scc2) {
                edgeArr[++cnte] = ((1LL * scc1) << 32) | scc2;
            }
        }
        sort(edgeArr + 1, edgeArr + cnte + 1);
        ll pre = 0, cur;
        for (int i = 1; i <= cnte; i++) {
            cur = edgeArr[i];
            if (cur != pre) {
                int scc1 = (int)(cur >> 32);
                int scc2 = (int)(cur & 0xffffffffLL);
                indegree[scc2]++;
                addEdge(scc1, scc2);
                pre = cur;
            }
        }
    }

    void dpOnDAG() {
        for (int u = sccCnt; u > 0; u--) {
            if (indegree[u] == 0) {
                dpSum[u] = sccSiz[u];
                dpCnt[u] = 1;
            }
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                if (dpSum[v] < dpSum[u] + sccSiz[v]) {
                    dpSum[v] = dpSum[u] + sccSiz[v];
                    dpCnt[v] = dpCnt[u];
                } else if (dpSum[v] == dpSum[u] + sccSiz[v]) {
                    dpCnt[v] = (dpCnt[v] + dpCnt[u]) % x;
                }
            }
        }
        ans1 = ans2 = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (dpSum[i] > ans1) {
                ans1 = dpSum[i];
                ans2 = dpCnt[i];
            } else if (dpSum[i] == ans1) {
                ans2 = (ans2 + dpCnt[i]) % x;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> x;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        condense();
        dpOnDAG();
        cout << ans1 << "\n";
        cout << ans2 << "\n";
        return 0;
    }

二、题目6：缩点最短路

题目：有向图，每条边有非负权，并且规定如果两个点属于同一个强连通分量，那么互相到达的代价是 0。求 1 到 n 的最小边权和，到不了输出 −1。

「同分量之间代价为 0」这句话本身就在提示缩点：分量内部随便走都不要钱，那么一条从 1 到 n 的路径只需要关心它依次经过哪些分量，以及跨分量的那些边花多少。

所以先缩点，分量内部的边全部丢弃（代价 0，走了也不花一分），跨分量的边原样保留权值。缩点图是 DAG，理论上可以拓扑排序加 dp，但这里复用现成的最短路就行：源点设为 belong[1]，在缩点图上跑一遍 Dijkstra，答案取 dist[belong[n]]。

边权非负，Dijkstra 正好合适；点数是分量个数，比原来的 n 还小，跑起来只会更快。代价为 0 的那部分不需要显式建边，缩点的时候直接跳过就是。

如果 belong[n] 还是 0，说明 n 根本不在 1 能到达的分量里，直接输出 −1。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int x, cost;
        bool operator<(const Node &other) const {
            return cost > other.cost;
        }
    };

    const int MAXN = 200001;
    const int MAXM = 1000001;
    const int INF = 1000000001;
    int n, m;

    int a[MAXM];
    int b[MAXM];
    int val[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int weight[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    int dist[MAXN];
    bool vis[MAXN];
    priority_queue<Node> heap;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 > 0 && scc2 > 0 && scc1 != scc2) {
                addEdge(scc1, scc2, val[i]);
            }
        }
    }

    int dijkstra() {
        for (int i = 1; i <= sccCnt; i++) {
            dist[i] = INF;
            vis[i] = false;
        }
        dist[belong[1]] = 0;
        heap.push(Node{belong[1], 0});
        while (!heap.empty()) {
            Node cur = heap.top();
            heap.pop();
            int u = cur.x;
            int d = cur.cost;
            if (!vis[u]) {
                vis[u] = true;
                for (int e = head[u]; e > 0; e = nxt[e]) {
                    int v = to[e];
                    int w = weight[e];
                    if (!vis[v] && dist[v] > d + w) {
                        dist[v] = d + w;
                        heap.push(Node{v, dist[v]});
                    }
                }
            }
        }
        return dist[belong[n]];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i] >> val[i];
            addEdge(a[i], b[i], val[i]);
        }
        tarjan(1);
        if (belong[n] == 0) {
            cout << -1 << "\n";
        } else {
            condense();
            int ans = dijkstra();
            cout << ans << "\n";
        }
        return 0;
    }

三、题目7：软件安装

题目：n 个物品，背包容量 m。每个物品有重量 w 和价值 v，并且最多有一个依赖物品；不拿依赖物品就不能拿当前物品。如果一批物品循环依赖，要拿就只能全拿。求最大收益。

「循环依赖要拿就全拿」这句话就是缩点信号。把依赖关系建图，i 依赖 depend[i]，那就在 depend[i] 和 i 之间连边，环里的物品合成一个大物品，重量和价值分别相加。

缩点之后每个物品的依赖关系只剩一条，不再有环，于是依赖关系变成一片森林：每个分量要么没有依赖，要么依赖另一个分量。加一个虚拟根 0，让所有没有依赖的分量都指向它，森林就补成一棵树。

接下来是树上背包。这里用 dfn 序的写法：对树做一次 dfs，给每个点分配 dfn 编号，同时算出子树大小 siz[i]。有了 dfn 序，一个点的子树就是一段连续的区间，dp[i][j] 表示「在 dfn 序 i 到末尾这段里做容量 j 的背包」的最大收益。

转移只有两步：不选当前物品，直接继承 dp[i + siz[i]][j]（跳过整棵子树）；选当前物品，用 value[i] + dp[i + 1][j − weight[i]]。倒着按 dfn 序扫一遍就完成了。

注意下标：虚拟根不占容量也不产生收益，所以答案取 dp[2][m]，从根的 dfs 编号的后一位开始。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 301;
    const int MAXM = 601;
    int n, m;
    int w[MAXN];
    int v[MAXN];
    int depend[MAXN];

    int head[MAXN];
    int nxt[MAXN];
    int to[MAXN];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int wsum[MAXN];
    int vsum[MAXN];
    int sccCnt;

    int indegree[MAXN];

    int siz[MAXN];
    int weight[MAXN];
    int value[MAXN];
    int dfnCnt;
    int dp[MAXN][MAXM];

    void addEdge(int a, int b) {
        nxt[++cntg] = head[a];
        to[cntg] = b;
        head[a] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                wsum[sccCnt] += w[pop];
                vsum[sccCnt] += v[pop];
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 0; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= n; i++) {
            if (depend[i] > 0) {
                int scc1 = belong[depend[i]];
                int scc2 = belong[i];
                if (scc1 != scc2) {
                    indegree[scc2]++;
                    addEdge(scc1, scc2);
                }
            }
        }
        for (int i = 1; i <= sccCnt; i++) {
            if (indegree[i] == 0) {
                addEdge(0, i);
            }
        }
    }

    int dfs(int u) {
        int i = ++dfnCnt;
        siz[i] = 1;
        weight[i] = wsum[u];
        value[i] = vsum[u];
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            siz[i] += dfs(v);
        }
        return siz[i];
    }

    int knapsackOnTree() {
        dfs(0);
        for (int i = dfnCnt; i >= 2; i--) {
            for (int j = 1; j <= m; j++) {
                dp[i][j] = dp[i + siz[i]][j];
                if (j - weight[i] >= 0) {
                    dp[i][j] = max(dp[i][j], value[i] + dp[i + 1][j - weight[i]]);
                }
            }
        }
        return dp[2][m];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> w[i];
        }
        for (int i = 1; i <= n; i++) {
            cin >> v[i];
        }
        for (int i = 1; i <= n; i++) {
            cin >> depend[i];
            if (depend[i] > 0) {
                addEdge(depend[i], i);
            }
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        condense();
        int ans = knapsackOnTree();
        cout << ans << "\n";
        return 0;
    }

四、题目8：糖果

题目：n 个人每人至少一颗糖，k 条要求，形如相等、大于、大于等于、小于、小于等于。求满足全部要求的最少糖果数，无解输出 −1。

五条要求拆成差分约束的边。设边 x→y 的权值是 w，含义是 y ≥ x + w，那么五种操作分别对应：相等建两条权 0 的边，u 小于 v 就是 u→v 权 1，u 大于等于 v 就是 v→u 权 0，u 大于 v 就是 v→u 权 1，u 小于等于 v 就是 u→v 权 0。

建完图跑最长路，dp[v] = max(dp[u] + w)，源点初值为 1（每人至少一颗）。这和一般的差分约束不太一样，一般跑最短路判负环，这里跑最长路判正环。

判无解就落在缩点上：如果某条正权边居然落在分量内部，意思是 x ≥ x + 1，自相矛盾，直接输出 −1。权为 0 的内部边是「相等」，没有矛盾，可以忽略。所以缩点那一步顺便做完这个检查，返回值用 bool 表示，失败就提前结束。

最后答案不是某个点，而是所有人糖果数之和。有了每个分量的最长路值，分量里的每个人取值相同，乘上分量大小再累加即可。

这里还有个容易看反的地方：分量之间的重边全部保留，不需要去重。因为 dp 转移取的是最大值，权值小的那条边永远推不动 dp，去重反而多写一段代码。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXM = 200001;
    int n, k, m;
    int a[MAXM];
    int b[MAXM];
    int c[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int weight[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccSiz[MAXN];
    int sccCnt;

    int indegree[MAXN];
    ll dp[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sccSiz[sccCnt] = 0;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccSiz[sccCnt]++;
            } while (pop != u);
        }
    }

    bool condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            int w = c[i];
            if (scc1 == scc2 && w > 0) {
                return false;
            }
            if (scc1 != scc2) {
                indegree[scc2]++;
                addEdge(scc1, scc2, w);
            }
        }
        return true;
    }

    ll dpOnDAG() {
        for (int u = sccCnt; u > 0; u--) {
            if (indegree[u] == 0) {
                dp[u] = 1;
            }
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                int w = weight[e];
                dp[v] = max(dp[v], dp[u] + w);
            }
        }
        ll ans = 0;
        for (int i = 1; i <= sccCnt; i++) {
            ans += dp[i] * sccSiz[i];
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> k;
        m = 0;
        for (int i = 1, op, u, v; i <= k; i++) {
        	cin >> op >> u >> v;
            if (op == 1) {
                a[++m] = u; b[m] = v; c[m] = 0;
                a[++m] = v; b[m] = u; c[m] = 0;
            } else if (op == 2) {
                a[++m] = u; b[m] = v; c[m] = 1;
            } else if (op == 3) {
                a[++m] = v; b[m] = u; c[m] = 0;
            } else if (op == 4) {
                a[++m] = v; b[m] = u; c[m] = 1;
            } else {
                a[++m] = u; b[m] = v; c[m] = 0;
            }
        }
        for (int i = 1; i <= m; i++) {
            addEdge(a[i], b[i], c[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = condense();
        if (!check) {
            cout << -1 << "\n";
        } else {
            ll ans = dpOnDAG();
            cout << ans << "\n";
        }
        return 0;
    }

五、题目9：杀人游戏

题目：n 个人里只有一个杀手，每个人是杀手的概率均等。给定单向且可传递的知晓关系：如果 x 知晓 y，那么 y 是不是杀手，x 就知道。可以盘问任何人，盘问之后对方知晓的所有情况都能拿到；但盘问到杀手本人，所有人都会被炸死。要多确定所有人的身份，求最优策略下杀手不爆炸还能被揪出来的概率。

先看知晓关系的形状。x 知晓 y 就是一条 x 到 y 的边，而且知晓关系可传递，说明一个分量里的人互相知晓，缩点之后 DAG 上的边仍然表示「知道」。盘问一个人，等于获取他能到达的所有点的身份。

所以真正要盘问的是入度为 0 的分量：入度为 0 表示没有任何人可以间接告诉你这个分量的信息，想确定里面谁是谁，只能亲自去问。反过来，入度不为 0 的分量一定被某个源分量覆盖，问过源分量之后就顺带知道了。

于是需要盘问的次数一开始就是入度为 0 的分量个数 cnt。只有杀手的身份会暴露失败，而杀手在 n 个人里等概率出现，所以概率是 1 − cnt / n。

还要考虑一个可以省一次的例外：如果某个入度为 0 的分量只有一个点，并且它所有出边指向的分量都还有别的入边（也就是入度不恰好等于 1），那么最后轮到它时可以靠排除法确定，不必真的去盘问。此时 cnt 减一。

实现上还是先缩点，顺手用 (scc1 << 32) | scc2 去重算准每个分量的入度；然后找有没有满足例外的分量，找到就减一；最后输出 1 − cnt / n，保留六位小数。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXM = 300001;
    int n, m;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccSiz[MAXN];
    int sccCnt;

    ll edgeArr[MAXM];
    int cnte;

    int indegree[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sccSiz[sccCnt] = 0;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccSiz[sccCnt]++;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        cnte = 0;
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 != scc2) {
                edgeArr[++cnte] = ((1LL * scc1) << 32) | scc2;
            }
        }
        sort(edgeArr + 1, edgeArr + cnte + 1);
        ll pre = 0, cur;
        for (int i = 1; i <= cnte; i++) {
            cur = edgeArr[i];
            if (cur != pre) {
                int scc1 = (int)(cur >> 32);
                int scc2 = (int)(cur & 0xffffffffLL);
                indegree[scc2]++;
                addEdge(scc1, scc2);
                pre = cur;
            }
        }
    }

    bool isolated(int i) {
        if (indegree[i] > 0 || sccSiz[i] > 1) {
            return false;
        }
        if (head[i] == 0) {
            return true;
        }
        for (int e = head[i]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (indegree[v] == 1) {
                return false;
            }
        }
        return true;
    }

    double compute() {
        int inZero = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (indegree[i] == 0) {
                inZero++;
            }
        }
        for (int i = 1; i <= sccCnt; i++) {
            if (isolated(i)) {
                inZero--;
                break;
            }
        }
        return 1.0 - (double)inZero / (double)n;
    }

    int main() {
        scanf("%d%d", &n, &m);
        for (int i = 1; i <= m; i++) {
            scanf("%d%d", &a[i], &b[i]);
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        condense();
        double ans = compute();
        printf("%.6lf", ans);
        return 0;
    }

六、复杂度分析

五道题的骨架都是「Tarjan 缩点 + 在缩点图上跑一遍」，真正决定复杂度的只有缩点图上的那一步。

步骤时间复杂度空间复杂度
Tarjan 求强连通分量O(n + m)O(n + m)
题目5、9：重边排序去重O(m log m)
题目5 计数 / 题目6 建图 / 题目9 出入度统计O(n + m)
题目6：缩点图上一遍 DijkstraO(n log n + m)O(n + m)
题目8：建图 + 缩点 + 最长路O(n + m)O(n + m)
题目7：树上背包O(n m)O(n m)

重边去重是唯一带 log 的预处理，而且只有题目5 和题目9 需要。题目6 的 Dijkstra 复杂度里 n 是分量个数，比原图点数小；边权为 0 的分量内部边根本不进队。题目7 是这里唯一一个二维 dp，容量只有 500，n 也只有 100，O(n m) 完全够用。

其余几道题的数组都是「点数或边数那么多」，没有额外结构，空间就是 O(n + m)。

七、最后

这五道题恰好把缩点这张牌的五种用法摊开了：数方案时它是把环折成带权点，跑最短路时它是把环内代价抹成 0，做背包时它是把环合成一个大物品，判矛盾时它是把环内正权边挑出来，做性质分析时它是把「必须问谁」翻译成入度为 0。

写的时候有两件事值得记住。一是重边只在需要计数或统计度数时才要处理，取最值的 dp 直接忽略。二是同一份缩点模板几乎可以原样复制，真正要变的是分量内部要预处理什么信息、以及缩点图上接下来跑哪个算法。
