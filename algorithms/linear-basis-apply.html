线性基应用：贪心选基与亮灯计数

普通消元的线性基有两个高频用法：一个带权选最大线性无关组，一个数异或空间的大小。元素题是前者，彩灯题是后者。

零、元素（洛谷 P4570）

n 个魔法矿石，每个有状态和魔力。若干矿石组成的组合，内部一旦出现异或和为 0 的子集就无效。要求有效的组合里魔力和最大。

「内部没有异或和为 0 的子集」等价于「选出的状态线性无关」：线性相关的一组数，必然有非空子集异或成 0；反过来，能异或出 0 就说明某个数能被其它数线性表示，线性相关。

于是问题变成：按魔力挑一组线性无关的状态，魔力和最大。直觉是按魔力从大到小，能选就选。这个贪心对，因为线性无关集合构成拟阵（有遗传性：子集仍线性无关；有交换性：任何两组等大的独立集，总能把一个元素换进另一组而不破坏独立性），拟阵上的带权最大独立集，就是按权降序逐个尝试插入。

实现就是普通消元的 insert：插入成功（没被已有基消成 0）说明这个矿石和已选的矿石线性无关，累加它的魔力；插入失败说明它在线性空间里，选了反而引入 0 子集，跳过。

// 元素：按魔力降序，逐个尝试插入线性基
    // 插入成功说明这个矿石和已选的矿石线性无关，选它
    long long computeElement() {
      long long ans = 0;
      // 魔力大的先试
      sort(arr + 1, arr + n + 1, [](const Ore& a, const Ore& b) {
        return a.val > b.val;
      });
      for (int i = 1; i <= n; i++) {
        if (insert(arr[i].state)) {
          ans += arr[i].val;
        }
      }
      return ans;
    }

n ≤ 1000、状态 ≤ 1018，排序 O(n log n) + 插入 O(n × 60)。

一、彩灯（洛谷 P3857）

n 个灯泡初始全不亮，m 个开关，每个开关改变若干灯泡的状态（亮变不亮、不亮变亮），可任意使用开关，问有多少种不同的亮灯组合，答案对 2008 取模。

每个开关是一个位向量：字符串 XXOOO 表示第 0、1 位不改，第 2、3、4 位翻转。开关用几次都等价于「异或上这个位向量一次或零次」，因为两次使用相互抵消。所以不同的亮灯组合数 = 这些开关位向量的异或空间大小。

把每个开关转成 long 插入线性基，得到基大小 size。size 个线性无关的开关，任意组合出来的 2size 个结果两两不同，答案就是 2size mod 2008。全不亮（异或 0）也算一种，所以直接算 2size，不减 1。

// 彩灯：把开关字符串转成一个 long，再插入线性基
    // 开关 XXOOO：第 j 位是 O 就把这位设成 1
    long long num = 0;
    for (int j = 0; j <= n; j++) {
      if (s[j] == 'O') {
        num |= 1LL << j;
      }
    }
    if (insert(num)) {
      size++;
    }
// 亮灯组合数 = 2^size，全不亮也算一种
    // size 个线性无关的开关，任意组合 2^size 种结果都不同
    int ans = 1;
    for (int i = 0; i < size; i++) {
      ans = (ans * 2) % MOD;
    }
    printf("%d\n", ans);

n、m ≤ 50，输入解析 O(m × n)，建基 O(m × n)。

三、总结

两个应用都是普通消元。元素题把「选线性无关且权最大」变成按权降序贪心 + insert：插入成功就选，失败说明线性相关。彩灯题把「开关任意组合的不同结果数」变成 2线性基大小：基的个数就是异或空间的维度，维度定下来计数就是 2维度。共同点是线性基只表达「维度」和「能否得到」，有了这两个信息，计数和选基都变成简单操作。
