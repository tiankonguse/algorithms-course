边权转化为点权

重链剖分把树上路径拆成 O(log n) 段连续的 dfn 区间，靠的是「点权」。题目给的是边权时，先把它挪到点上。挪法只有一句：每条边的权给下方那个节点。

零、背景

重链剖分那一讲处理的是点权：子树是 dfn 上的一段区间，路径是 O(log n) 段区间。这一讲接着讲两个延伸，前半是边权怎么并进这套框架，后半是长链剖分。

边权的处理本身不难，难的是把「哪条边被算进去了」这件事一直盯住。子树、路径、单边三种操作各有一处要跳过，跳错了就会多算一条边。

一、边权为什么不直接维护

线段树下标是 dfn，一个 dfn 对应一个节点。边的编号和 dfn 没有任何对应关系，一条边两个端点在 dfn 上也未必相邻。所以「路径上所有边权加 1」没法直接翻译成区间操作。

换个角度：一棵 n 个点的树恰好 n − 1 条边。除根之外，每个节点正上方有且仅有一条边。把这条边的权记在这个节点上，边和节点就一一对应了。

于是「第 i 条边的权」变成「第 i 条边下端那个点的权」。查一条边，只要查它下端点的 dfn 位置。

二、三种操作各要跳过一处

子树操作最直观。子树 u 的边 = 子树 u 里的所有点，再去掉 u 自己，u 的点权是它头顶那条边，不在子树内部。所以区间是 [dfn[u] + 1, dfn[u] + siz[u] − 1]。

路径操作同理，最后一步落在同一条重链上时，区间左端从 min(dfn[x], dfn[y]) + 1 起步，就是把 LCA 自己跳过去。前面几条链的整段 [dfn[top], dfn[x]] 不含 LCA，不用处理。

单边操作最简单：题目给了两端点，取 dfn 较大的那个（一定在下），查这一个位置。

三、题目1：Grass Planting

n 个点的树，初始所有边权为 0。m 条操作：操作 P x y 把 x 到 y 路径上每条边的权加 1；操作 Q x y 询问 x 与 y 之间的边权，题目保证 x 与 y 直接相连。1 ≤ n、m ≤ 10⁵。测试链接：P3038。

线段树只要支持区间加和单点查。路径加就是 O(log n) 段区间加，单边查就是一个点查，取两端点里 dfn 大的那个。

剖分部分和点权版本完全一样，不做任何改动。

void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        dfn[u] = ++cntd;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

路径加与单边查。pathAdd 的骨架没变，末行左端加了 1；edgeQuery 只查一个位置。

void pathAdd(int x, int y, int v) {
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                add(dfn[top[y]], dfn[y], v, 1, n, 1);
                y = fa[top[y]];
            } else {
                add(dfn[top[x]], dfn[x], v, 1, n, 1);
                x = fa[top[x]];
            }
        }
        add(min(dfn[x], dfn[y]) + 1, max(dfn[x], dfn[y]), v, 1, n, 1);
    }

    int edgeQuery(int x, int y) {
        int down = max(dfn[x], dfn[y]);
        return query(down, 1, n, 1);
    }

复杂度分析

下放是 O(n) 的一次遍历，之后所有代价都来自重链剖分与线段树。剖分把任意路径拆成不超过 2 log₂ n 段，每段是一次线段树区间操作。

操作时间说明
dfs1 + dfs2 剖分O(n)两个递归各遍历整棵树一遍
边权下放O(n)每条边看一次，写进下方节点的点权
路径修改 / 查询O(log² n)最多 2 log₂ n 段，每段线段树 O(log n)
单边查O(log n)一次线段树单点查询
空间O(n)剖分数组 6n + 线段树 4n

这里 n = 10⁵，log² n 约 289，加上线段树常数是完全够的。真正决定能不能过的是线段树要支持哪些标记，下一节看两种更复杂的。

最后

边权转点权的规则就三条：下放给下方节点、子树跳过头节点、路径跳过 LCA。接下来两个题把线段树换成带标记的：一个要支持整段取反，一个要同时支持范围重置和范围增加。
