重构树上的子树计数

上一节只往内部节点挂了边权。这一节多挂一个数：每个节点的子树里有几个原始点。有了它，「边权受限时能到达多少个点」就是一次上跳的事。

零、换个方向排序

上一节按边权升序建树，节点越往上边权越大，回答的是「最大边权尽量小」。把排序反过来，按边权降序建树，节点越往上边权越小，回答的就是「只允许走边权 ≥ limit 的边」这一类问题。

两棵树的区别只在 cmp 里那个不等号。建完之后 dfs 一次，给每个节点记 leafsiz：叶子是 1，内部节点是所有儿子之和。这个数就是「以它为顶的这块连通区里有多少个原始点」。

一、题目2：youyou 的军训

图里有 n 个点、m 条无向边，每条边给定不同的边权，图里可能有若干个连通的部分。一开始 limit = 0，接下来有 q 条操作，格式如下。操作 1 x：所有修改操作生效，然后 limit 设置成 x；操作 2 x：从点 x 出发，只能走边权 ≥ limit 的边，查询最多到达几个点；操作 3 x y：第 x 条边的边权修改为 y，不是立刻生效，等到下次操作 1 发生时生效。题目保证边权不管如何修改，所有边权都不相等，并且每条边的边权排名不发生变化。测试链接：P9638。

排名不变这一条很关键。它表示不管边权怎么改，Kruskal 选中的边集合、以及每步合并的先后顺序都不变，重构树的形状是固定的。变的只有内部节点上那个 nodeKey。

所以修改操作根本不用重建树。建树时顺手记下 edgeToTree[边编号] = 它对应的内部节点编号（没被选中的边记 0），操作时把新边权攒在 pend 里，等到下一次操作 1 再统一写进 nodeKey。

从点 u 出发、只走边权 ≥ limit 的边，能到的所有点恰好是重构树上某个节点的整棵子树。这个节点就是「u 的祖先中，nodeKey ≥ limit 的最高的那个」。

四、题目3：边的最大编号的最小值

图里有 n 个点、m 条无向边，边的编号 1~m，没有边权，所有点都连通。一共有 q 条查询，格式如下：查询 x y z，从两个点 x 和 y 出发，希望经过的点数量等于 z，每个点可以重复经过但重复经过只计算一次，经过边的最大编号最小是多少。3 ≤ n、m、q ≤ 10⁵，3 ≤ z ≤ n。测试链接：AT_agc002_d。

没有边权，就把编号当边权，升序建树。这次是「最大编号尽量小」，和题目1 同向。

check(limit) 也好写：让 x 和 y 各自往上跳到 nodeKey ≤ limit 的最高祖先，得到两块连通区。两块要么是同一个节点（说明 x 和 y 已经连上了），要么不相交。前者取 leafsiz，后者取两者之和，和 z 比一下就行。

x 出发能到的点 y 出发能到的点 本次没覆盖到的点

答案对 limit 是单调的：limit 越大能到的点越多，一旦够了，再大也够。所以可以二分，每次 check 是两次上跳，O(log n)。

五、代码

dfs 里 leafsiz 的写法：先递归儿子，回来再把自己和儿子加起来。叶子记 1，内部节点从 0 开始加。

void dfs(int u, int fa) {
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            dfs(to[e], u);
        }
        if (u <= n) {
            leafsiz[u] = 1;
        } else {
            leafsiz[u] = 0;
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            leafsiz[u] += leafsiz[to[e]];
        }
    }

题目2 的查询就是那次上跳，方向是 nodeKey ≥ limit。

int query(int u, int limit) {
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[u][p] > 0 && nodeKey[stjump[u][p]] >= limit) {
                u = stjump[u][p];
            }
        }
        return leafsiz[u];
    }

题目3 的 check 和二分。注意 x 和 y 跳到同一个节点时只能算一次。

bool check(int x, int y, int z, int limit) {
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[x][p] > 0 && nodeKey[stjump[x][p]] <= limit) {
                x = stjump[x][p];
            }
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[y][p] > 0 && nodeKey[stjump[y][p]] <= limit) {
                y = stjump[y][p];
            }
        }
        if (x == y) {
            return leafsiz[x] >= z;
        } else {
            return leafsiz[x] + leafsiz[y] >= z;
        }
    }

    int query(int x, int y, int z) {
        int l = 1, r = m, ans = 0;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (check(x, y, z, mid)) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

复杂度分析

两道题的建树和 dfs 部分完全一样，差别只在查询。

步骤时间说明
边排序O(m log m)题目2 降序、题目3 按编号升序
Kruskal 建树O(m α(n))题目2 额外记 edgeToTree
dfs 建表 + leafsizO(n log n)最多 2n 个节点，各填 20 层
题目2 单次操作 2O(log n)一次倍增上跳，读 leafsiz
题目3 单次查询O(log m · log n)二分 log m 轮，每轮两次上跳
空间O(n log n)倍增表 (2n) × 20，加 leafsiz、nodeKey 各 2n

题目2 的操作 1 摊还下来是 O(修改条数)，每条改一个 nodeKey，不影响树形。
