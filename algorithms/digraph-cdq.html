CDQ 优化建图：偏序连边降到 O((n + m) log n) 条边

「a 和 b 都不超过我的点，都向我连边」，这类偏序约束连边朴素做是 O(n·m)。CDQ 分治先把 a 维切开：左半的点 a 一定不超过右半，跨半连边只剩 b 一维，归并时用一条前缀链把左半的点整体接到右半的操作上；三维偏序再往里塞一棵树状数组。

零、背景

前两页的连边对象都是「值域上的范围」：前缀交给树状数组，任意区间交给主席树。可持久化也好、槽位链也好，本质都在分解一维区间。

还有一类约束不是区间，是偏序关系。每个点带两三个权值，操作要求「所有各维都不超过我的点向我连边」。二维偏序在平面上就是左下矩形，线段树分解不出这种形状。

偏序有自己的结构：按 a 排序后，任何一个 a 更小的点都在任何一个 a 更大点的左边。把序列对半分治，左半对右半的偏序判断自动少掉一维，这是 CDQ 分治的老本行，只不过这次分治产出的不是统计值，是图的边。

一、问题

一共 n 个点，每个点给两个点权 a[i]、b[i]，初始时没有边。一共 m 个操作，格式 x w：每个满足 a[i] ≤ a[x] 且 b[i] ≤ b[x] 的点 i，都向 x 连一条权值为 w 的边。注意 x 自己也是达标的。

三维版本每个点给 a[i]、b[i]、c[i] 三个权，条件变成三维都 ≤。两个版本建完图都跑 dijkstra 对数器，和暴力建图逐对比较最短路。

二、朴素做法

每个操作扫一遍全部点，两个（或三个）不等式判断一遍，达标就连边。一次 O(n)，m 个操作 O(n·m)；n、m 到 10⁵ 时又是 10¹⁰ 条边的老问题。

三、相同的点先分组

动手分治之前先做一次去重。(a, b) 完全相同的点，支配条件完全一样，别人连它们时要么全连、要么全不连，它们挂在操作上的边也一模一样。把这样的点合并成组，组造一个虚点 g：每个成员向 g 连 0 权边；g 向每个成员连边，边权就是该成员上挂的每个操作。

操作本身也转移到组点上记账。这样跨组连边时，一条边连向组点 g 就等于连向了全组成员；「x 自己也达标」由成员 → g → 成员的环自然实现。重复点多的时候这一步省得很实在。

四、二维：分治切掉 a 维，归并处理 b 维

把去重后的点按 (a, b) 排序，然后 cdq(l, r)：递归处理左右两半，再 merge。排序保证了关键性质，左半任何一个点的 a 都不超过右半任何一个点（a 相等时排在前面的 b 更小）。于是跨半的支配判断里 a 维自动成立，只剩 b 一维要筛。

merge 之前，左右两半各自已经按 b 有序（更深的 merge 排好的）。双指针扫：对右半每个点 p2，新建一个链节点 cur；左半还没有被吸收的、b ≤ b(p2) 的点各连一条 0 权边到 cur；上一个 cur 向当前 cur 连 0 权边；p2 挂的每个操作从 cur 向目标连 w 边。

效果可以验证一下。左点 p1 被吸收进某个 cur 之后，链一直向前延伸，后面每个 cur 都挂着「b 更大的右点」的操作。所以 p1 顺着链走，恰好到达所有 b ≥ b(p1) 的右点的操作，正是 p1 支配的那批点；b 更小的右点在链的前面，够不着。每个左点在一层 merge 里只出一条边，一整层的跨半连边摊下来是线性的。

同半的点对不用管：它们会在更深一层的分治里相遇。任何一对点恰好在一个「分属左右两半」的层碰面，边不重不漏。

五、三维：再往里塞一棵树状数组

三维版本的第一维还是分治切 a，第二维还是归并处理 b，第三维 c 交给树状数组：merge 过程中，左半的点按吸收顺序往树状数组里 insert，插的就是第一页那条槽位版本链；右半的点 p2 查询前缀 [1..c(p2)]，链头向 p2 的操作目标连 w 边。整段处理完把槽位清零，给下一层复用。

这套组合和三维偏序计数的老套路完全同构，区别只是计数改成了连边。第四页 P7477 的 CDQ 实现里，被切的那一维是位置（时间），归并的维是值，同一个骨架换个语义直接用。

七、代码

二维版本：DataCmp 排序去重进 buildGraph，merge 里建链，cdq 递归。三维版本多了 tree 数组和 add、rangeToX、clear 三个函数，就是第一页的槽位链，insert 时建链、查询时连边、用完清零。

#include <bits/stdc++.h>

    using namespace std;

    struct Data {
        int i, a, b;
    };

    bool DataCmp(Data x, Data y) {
        if (x.a != y.a) {
            return x.a < y.a;
        }
        return x.b < y.b;
    }

    const int MAXN = 101;
    const int MAXM = 1001;
    const int MAXV = 10001;
    const int MAXT = 2000001;
    const int MAXE = 4000001;
    int n, m, cntt;
    int a[MAXN];
    int b[MAXN];

    Data arr[MAXN];
    Data tmp[MAXN];
    int cnta;

    int headg[MAXT];
    int nextg[MAXE];
    int tog[MAXE];
    int weightg[MAXE];
    int cntg;

    int headp[MAXT];
    int nextp[MAXM << 1];
    int top[MAXM << 1];
    int weightp[MAXM << 1];
    int cntp;

    void addEdge(int u, int v, int w) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        weightg[cntg] = w;
        headg[u] = cntg;
    }

    void addOp(int x, int u, int w) {
        nextp[++cntp] = headp[x];
        top[cntp] = u;
        weightp[cntp] = w;
        headp[x] = cntp;
    }

    void merge(int l, int mid, int r) {
        int pre = 0, cur = 0;
        for (int p1 = l - 1, p2 = mid + 1; p2 <= r; p2++) {
            cur = ++cntt;
            while (p1 + 1 <= mid && arr[p1 + 1].b <= arr[p2].b) {
                p1++;
                addEdge(arr[p1].i, cur, 0);
            }
            if (pre > 0) {
                addEdge(pre, cur, 0);
            }
            for (int e = headp[arr[p2].i]; e > 0; e = nextp[e]) {
                int u = top[e];
                int w = weightp[e];
                addEdge(cur, u, w);
            }
            pre = cur;
        }
        int p1 = l, p2 = mid + 1, ti = 0;
        while (p1 <= mid && p2 <= r) {
            if (arr[p1].b <= arr[p2].b) {
                tmp[++ti] = arr[p1++];
            } else {
                tmp[++ti] = arr[p2++];
            }
        }
        while (p1 <= mid) {
            tmp[++ti] = arr[p1++];
        }
        while (p2 <= r) {
            tmp[++ti] = arr[p2++];
        }
        for (int i = l, j = 1; i <= r; i++, j++) {
            arr[i] = tmp[j];
        }
    }

    void cdq(int l, int r) {
        if (l == r) {
            return;
        }
        int mid = (l + r) / 2;
        cdq(l, mid);
        cdq(mid + 1, r);
        merge(l, mid, r);
    }

    void buildGraph() {
        for (int i = 1; i <= n; i++) {
            arr[i] = {i,a[i],b[i]};
        }
        sort(arr + 1, arr + n + 1, DataCmp);
        cntt = n;
        for (int l = 1, r = 1; l <= n; l = ++r) {
            int a = arr[l].a;
            int b = arr[l].b;
            while (r + 1 <= n && a == arr[r + 1].a && b == arr[r + 1].b) {
                r++;
            }
            int x = ++cntt;
            for (int i = l; i <= r; i++) {
                int u = arr[i].i;
                addEdge(u, x, 0);
                for (int e = headp[u]; e > 0; e = nextp[e]) {
                    addEdge(x, u, weightp[e]);
                    addOp(x, u, weightp[e]);
                }
            }
            arr[++cnta] = {x, a, b};
        }
        cdq(1, cnta);
    }

三维版本的差异集中在这几处：排序键多了 c，merge 里左半点 insert(c)、右半点查前缀，最后按 b 归并。

#include <bits/stdc++.h>

    using namespace std;

    struct Data {
        int i, a, b, c;
    };

    bool CmpABC(Data x, Data y) {
        if (x.a != y.a) {
            return x.a < y.a;
        }
        if (x.b != y.b) {
            return x.b < y.b;
        }
        return x.c < y.c;
    }

    bool CmpB(Data x, Data y) {
        return x.b < y.b;
    }

    const int MAXN = 101;
    const int MAXM = 1001;
    const int MAXV = 10001;
    const int MAXT = 4000001;
    const int MAXE = 8000001;
    int n, m, maxc, cntt;
    int a[MAXN];
    int b[MAXN];
    int c[MAXN];

    Data arr[MAXN];
    int cnta;

    int headg[MAXT];
    int nextg[MAXE];
    int tog[MAXE];
    int weightg[MAXE];
    int cntg;

    int headp[MAXT];
    int nextp[MAXM << 1];
    int top[MAXM << 1];
    int weightp[MAXM << 1];
    int cntp;

    int tree[MAXV];

    void addEdge(int u, int v, int w) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        weightg[cntg] = w;
        headg[u] = cntg;
    }

    void addOp(int x, int u, int w) {
        nextp[++cntp] = headp[x];
        top[cntp] = u;
        weightp[cntp] = w;
        headp[x] = cntp;
    }

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int x) {
        while (i <= maxc) {
            int pre = tree[i];
            int cur = ++cntt;
            if (pre != 0) {
                addEdge(pre, cur, 0);
            }
            addEdge(x, cur, 0);
            tree[i] = cur;
            i += lowbit(i);
        }
    }

    void rangeToX(int i, int x, int w) {
        while (i > 0) {
            if (tree[i] > 0) {
                addEdge(tree[i], x, w);
            }
            i -= lowbit(i);
        }
    }

    void clear(int val) {
        while (val <= maxc) {
            tree[val] = 0;
            val += lowbit(val);
        }
    }

    void merge(int l, int m, int r) {
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].b <= arr[p2].b) {
                p1++;
                add(arr[p1].c, arr[p1].i);
            }
            for (int e = headp[arr[p2].i]; e > 0; e = nextp[e]) {
                int u = top[e];
                int w = weightp[e];
                rangeToX(arr[p2].c, u, w);
            }
        }
        for (int i = l; i <= p1; i++) {
            clear(arr[i].c);
        }
        sort(arr + l, arr + r + 1, CmpB);
    }

    void cdq(int l, int r) {
        if (l == r) {
            return;
        }
        int mid = (l + r) / 2;
        cdq(l, mid);
        cdq(mid + 1, r);
        merge(l, mid, r);
    }

    void buildGraph() {
        for (int i = 1; i <= n; i++) {
            arr[i] = {i, a[i], b[i], c[i]};
            maxc = max(maxc, c[i]);
        }
        sort(arr + 1, arr + n + 1, CmpABC);
        cntt = n;
        for (int l = 1, r = 1; l <= n; l = ++r) {
            int a = arr[l].a;
            int b = arr[l].b;
            int c = arr[l].c;
            while (r + 1 <= n && a == arr[r + 1].a && b == arr[r + 1].b && c == arr[r + 1].c) {
                r++;
            }
            int x = ++cntt;
            for (int i = l; i <= r; i++) {
                int u = arr[i].i;
                addEdge(u, x, 0);
                for (int e = headp[u]; e > 0; e = nextp[e]) {
                    addEdge(x, u, weightp[e]);
                    addOp(x, u, weightp[e]);
                }
            }
            arr[++cnta] = {x, a, b, c};
        }
        cdq(1, cnta);
    }

八、复杂度分析

项目二维偏序三维偏序
排序去重O(n log n)O(n log n)
虚点数O(n log n)（每层 ≤ 右半点数）O(n log n log c)（左点每层每槽一个）
边数O((n + m) log n)O((n + m) log n log c)
建图总时间O((n + m) log n)O((n + m) log n log c)
朴素建图（对照）O(n·m) 条边
额外空间O((n + m) log n)O((n + m) log n log c)

二维的边数账这么算：每个左点每层出一条入链边，n log n；每个操作在其目标的每一层各连一条 cur 到目标的边，m log n。三维把树状数组的 log c 乘上去，槽位链节点也从每点每层一个变成每点每层 log c 个。

空间上除了链式前向星，还有归并的 tmp 数组 O(n) 和树状数组槽位 O(c)（值域大就离散化）。虚图上的 dijkstra 是 O(E log V)，V、E 都按上表走。

九、最后

CDQ 优化建图把偏序连边拆成三层：分治白拿一维，归并加前缀链吃掉一维，剩下低维的丢给值域数据结构。它产出的图和朴素做法完全等价，对数器逐对比较最短路验证过。

三页的分工到这里齐了：前缀范围用树状数组，任意区间用主席树，偏序关系用 CDQ。三种结构在下一页合流，两道 2-SAT 综合题里，同一条蕴含边用三种方式建，图一模一样。
