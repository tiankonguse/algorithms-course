错排与集合计数：形式二与形式四落地

n 封信装进 n 个信封、每封信都不进自己信封，答案是 n!·Σ(−1)^i/i!，这个公式背得出也推得出：先数「钦定 i 封信放对」这个好算的量，再反演成「恰好 0 封放对」。集合计数题目反过来用形式四：钦定 i 个元素留在交集里直接数，反演成恰好 k 个。

零、错排（P1595）

n 封信和 n 个信封一一对应，要求每封信都不在自己的信封里，问多少种装法。n 到 20，答案 long long 装得下。

直接数「恰好 0 个固定点」不好数，先数「钦定 i 个固定点」：钦定哪 i 封信放对，剩下 n−i 封信随便放，一共 C(n,i)·(n−i)! = n!/i! 种。设 g(i) = n!/i!，这就是「钦定至少 i 个固定点」的计数。反演（形式二）后「恰好 0 个固定点」：

D(n) = Σi=0..n (−1)^i · n!/i!

i=0 的项是 n!（全排列），之后一项一项带符号累加。n=4：24 − 24 + 12 − 4 + 1 = 9，正好 9 种错排。

图上左边是钦定「c 放 c 信封」再随便配的计数，右边是错排配对的例子：a 进 2、b 进 3、c 进 4、d 进 1，四个位置全不在自己信封上。

#include <bits/stdc++.h>
    using namespace std;

    int main() {
        int n;
        cin >> n;
        // 二项式反演（形式二）：错排数 = 恰好 0 个固定点
        // 先算「钦定 i 个固定点」：C(n,i) * (n-i)! = n! / i!
        // 反演后恰好 0 个固定点 = Σ_{i=0..n} (-1)^i * n! / i!
        long long facn = 1;
        for (int i = 1; i <= n; i++) facn *= i;
        long long ans = facn; // i = 0 的项
        long long faci = 1;   // i!
        for (int i = 1; i <= n; i++) {
            faci *= i;
            if ((i & 1) == 0) ans += facn / faci;
            else ans -= facn / faci;
        }
        cout << ans << endl;
        return 0;
    }

facn 一路乘出 n!，faci 一路乘出 i!，每项 n!/i! 正好整除，符号按 i 的奇偶。n≤20 时 n! 约 2.4e18，long long 刚好装下。

一、集合计数（P10596）

给定 n 个元素，全部子集一共 2^n 个。从这些子集里选出至少 1 个，问交集大小恰好为 k 的方案数，模 1e9+7。n 到 1e6，k 任意。

先算钦定：钦定 i 个元素必须留在交集里。剩下 n−i 个元素组成 2^(n−i) 个子集，从中挑出至少一个集合组成一个家族，交集里包含钦定的那 i 个（还可能混进别的）→ 2^(2^(n−i)) − 1 种。再乘 C(n,i) 选是哪 i 个被钦定：

g(i) = (2^(2^(n−i)) − 1) · C(n,i)

「至少 i 个」到「恰好 k 个」用形式四反演：

f(k) = Σi=k..n (−1)^(i−k) · C(i,k) · g(i)

图上 n=2 的四个子集 { }, {1}, {2}, {1,2}。钦定元素 1 留在交集：挑 {1} 和 {1,2}，交集正好 {1}，对应恰好 1 个。若只挑 {1,2}，交集是 {1,2}，这就是「钦定 1 时混进了 2」，反演负责把这类多余的扣掉。

2^(2^(n−i)) 不能真做 2 的 2^(n−i) 次幂的幂运算：从 i=n 倒着走，tmp 从 2 开始每步自乘，i=n 时 2、i=n−1 时 4、i=n−2 时 16，正好是 2^(2^(n−i))。阶乘、逆元表到 n 就够，总复杂度 O(n)。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 1000001;
    const int MOD = 1000000007;

    long long fac[MAXN], inv[MAXN], g[MAXN];
    int n, k;

    long long power(long long x, long long p) {
        long long ans = 1;
        while (p > 0) {
            if ((p & 1) == 1) ans = ans * x % MOD;
            x = x * x % MOD;
            p >>= 1;
        }
        return ans;
    }

    void build() {
        fac[0] = inv[0] = 1;
        fac[1] = 1;
        for (int i = 2; i <= n; i++) fac[i] = (long long)i * fac[i - 1] % MOD;
        inv[n] = power(fac[n], MOD - 2);
        for (int i = n - 1; i >= 1; i--) inv[i] = (long long)(i + 1) * inv[i + 1] % MOD;
    }

    long long c(int nn, int kk) {
        return fac[nn] * inv[kk] % MOD * inv[nn - kk] % MOD;
    }

    int main() {
        cin >> n >> k;
        build();
        // g[i] = 钦定 i 个数留在交集里（至少挑一个集合）的方案数
        // 全集外 n-i 个数可自由取舍：2^(2^(n-i)) - 1
        long long tmp = 2;
        for (int i = n; i >= 0; i--) {
            g[i] = tmp;
            tmp = tmp * tmp % MOD;
        }
        for (int i = 0; i <= n; i++) g[i] = (g[i] + MOD - 1) * c(n, i) % MOD;
        // 形式四反演：恰好 k 个 = Σ (-1)^(i-k) * C(i,k) * g[i]
        long long ans = 0;
        for (int i = k; i <= n; i++) {
            if (((i - k) & 1) == 0) ans = (ans + c(i, k) * g[i]) % MOD;
            else ans = (ans + c(i, k) * g[i] % MOD * (MOD - 1)) % MOD;
        }
        cout << ans << endl;
        return 0;
    }

演示 · 错排逐项求和：D(n) = Σ (−1)^i · n!/i!

总结

错排把「钦定 i 个固定点」n!/i! 当 g，反演成恰好 0 个固定点，得到 Σ(−1)^i n!/i!；代码只需要两个累积量 facn 和 faci，O(n) 出答案。集合计数把「钦定 i 个元素在交集」(2^(2^(n−i))−1)·C(n,i) 当 g，形式四反演成恰好 k；2 的 2 的幂用平方累积求，阶乘逆元表 O(n) 建、O(1) 查。两道题的共同动作：先选一个好算的钦定方向，再反演。下一页分特产也是形式四，只是 g 的「钦定」换成了隔板法。
