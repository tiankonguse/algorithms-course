外星千足虫：位图高斯消元与最早确定时刻

外星虫的腿数是奇数，地球虫是偶数。现在有 n 种虫子、m 条测量记录，每条记录写「哪些虫参与了这次测量」和一个奇偶结果。记录可能有冗余，问：用到第几条记录就能确定每只虫的属性？如果全用上还确定不了，打印 Cannot Determine。n 到 1000，上一节的模板直接搬过来会慢在「一行有 1000 个系数」，这一节把行压进位图，顺便把「最早第几条」这个答案在消元过程中顺手记下来。

零、一条记录转一行方程

变量 xj：虫 j 是外星（1）还是地球（0）。一条测量记录「011 1」的意思是：1 号虫没参与、2 号和 3 号虫参与了，总腿数是奇数。它写成一个方程：

x2 ^ x3 = 1

参与了的虫，属性和（异或）必须等于总腿数的奇偶。每条记录一行：参与的位置是 1，没参与是 0，最后一格是常数。行号就是记录编号，这题的「第几条」答案直接挂在行号上。

一、一行 1000 位：位图

n 最大 1000，一行 1000 个系数。用 int 数组存，异或消元要逐格来，常数时间差一个数量级。位图把一行压进 long：一个 long 存 64 位，1000 位要 16 个 long。消元时整组 long 异或，一次处理 64 个系数。

位图里第 0 位永远不用，列 1..n 对应位 1..n，常数放在第 s+1 位（s = max(n, m)，比所有列都靠右）。辅助函数就这么几个：

// 位图辅助：一行状态用若干个 long 表示，每个 long 存 64 位
    // 第 0 位永远不用，列 1..n 对应位 1..n，常数列对应更高位
    void set(int row, int col, int v) {
      if (v == 0) {
        mat[row][col / 64] &= ~(1LL << (col % 64));
      } else {
        mat[row][col / 64] |= 1LL << (col % 64);
      }
    }

    int get(int row, int col) {
      return ((mat[row][col / 64] >> (col % 64)) & 1) == 1 ? 1 : 0;
    }

    // row2 ^= row1，bits 表示需要异或的位数，按 64 位一组整组异或
    void eor(int row1, int row2, int bits) {
      for (int k = 0; k <= bits / 64; k++) {
        mat[row2][k] ^= mat[row1][k];
      }
    }

二、need：消元过程里顺手记

第 i 列找主元，从第 i 行往后扫到第 n 行，第一个系数是 1 的行换上来当主元行。这一行来自第 j 条记录，把它记进 need，need 取所有主元来源行号的最大值。消元跑完，need 就是「确定所有 n 个变量，至少要用到前 need 条记录」。

这里有个细节：主元只在记录 1..n 里找，第 n+1 条往后的记录不参与消元。所以确定解的 need 最多是 n；如果前 n 条记录凑不满 n 个主元，再多记录也救不回来，直接判 Cannot Determine。

第 i 列扫完没有主元：直接 return。前面 i-1 列已经定了，这一列没有 1 说明变量 i 无法确定，除非这列本来就是多余列（i > n）。

// 位图版高斯消元：need 记下「用到的最晚那条测量记录」
    void gauss(int n) {
      need = 0;
      for (int i = 1; i <= n; i++) {
        for (int j = i; j <= n; j++) {
          if (get(j, i) == 1) {
            swap(i, j);
            need = max(need, j);
            break;
          }
        }
        // 第 i 列没有主元：方程组不能唯一确定，直接结束
        if (get(i, i) == 0) {
          return;
        }
        for (int j = 1; j <= n; j++) {
          if (i != j && get(j, i) == 1) {
            eor(i, j, n + 2);
          }
        }
      }
    }

三、判定与输出

消元结束后看前 n 行：对角线全 1，说明每个变量都有主元、方程组唯一解，输出 need，再把每行的常数列读出来：1 是外星虫，0 是地球虫。有一行对角线是 0，说明还有自由元，用所有记录也确定不了，打印 Cannot Determine。

外星虫的输出串是 ?y7M#，题面约定，不是乱码，直接照打。

// 读入 m 条测量记录，常数放在第 s + 1 列
    s = max(n, m);
    for (int i = 1; i <= m; i++) {
      string line;
      cin >> line;
      for (int j = 1; j <= n; j++) {
        set(i, j, line[j - 1] - '0');
      }
      cin >> b;
      set(i, s + 1, b);
    }
    gauss(s);

    // 前 n 行对角线全 1 才能确定每只虫的属性
    int sign = 1;
    for (int i = 1; i <= n; i++) {
      if (get(i, i) == 0) {
        sign = 0;
        break;
      }
    }
    if (sign == 0) {
      cout << "Cannot Determine" << endl;
    } else {
      cout << need << endl;
      for (int i = 1; i <= n; i++) {
        if (get(i, s + 1) == 1) {
          cout << "?y7M#" << endl;  // 外星虫
        } else {
          cout << "Earth" << endl;  // 地球虫
        }
      }
    }

四、复杂度

消元扫 s = max(n, m) 行、每列找主元扫 s 行、消元对 s 行做整组 long 异或（每组 (n+2)/64 个 long）。总操作 O(s² · n / 64)。s ≤ 2000 时约 108 次位运算，一秒内跑完。这是位图换来的常数优势。

五、总结

位图把「一行 n 个系数」压成 n/64 个 long，消元从逐格异或变成整组异或；need 在选主元时顺手取主元来源行号的最大值，消元结束它就是答案。判定逻辑和前面完全一样：前 n 行对角线全 1 才有唯一解。至此高斯消元专题的三种方程都见过了：加法、异或、同余，模板一样，区别只在「归一化」这一步怎么定义。
