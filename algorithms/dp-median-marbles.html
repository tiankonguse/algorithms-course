相邻必选与切段：两个极值

一个求合法子序列的最大上中位数，一个求切 k 段的分数极差。前者把「中位数」翻成 +1/−1 的累加和再二分答案，后者把「段价」拆成固定端加切口再排序。都是先换个角度看目标，再交给一个简单结构。

零、背景

「相邻必选」的约束长这样：选一个子序列，任意相邻两个原数组位置至少要选一个。它逼着任何空档长度不超过 1，于是「跳过」这个动作有严格限制，dp 就能顺下标做。

一、最大上中位数

长度 L 的序列，上中位数是第 ⌈L/2⌉ 个（从 1 数）。[1, 2, 3, 4] 的上中位数是 2；合法子序列里取 [2, 3, 4]，上中位数是 3，还能更大吗？不能。

二分答案 x，check 问：存不存在合法子序列，使 ≥ x 的个数过半？「过半」就是 (#≥x) − (#<x) > 0。于是把每个数换成 +1（≥ x）或 −1（< x），问题变成：存不存在合法子序列的累加和 > 0。

dp[i][0]：位置 i 选不选皆可时，i..n−1 能拿到的最大累加和；dp[i][1]：位置 i 必选。转移 dp[i][1] = h[i] + dp[i+1][0]（i 选了，i+1 可自由）；dp[i][0] = max(h[i] + dp[i+1][0], dp[i+1][1])（要么选 i，要么不选 i 但必须选 i+1）。check 返回 dp[0][0] > 0。

答案在排序后的数组里二分，一趟 check O(n)，总 O(n log n)。n = 1e5 实测 19.5ms。

中位数二分：check 逐步判定

二、平均值扩展

同一个约束下求最大平均值（AtCoder ABC236 E 第一问）：二分平均值 x，把每个数换成 arr[i] − x，check 存不存在合法子序列累加和 ≥ 0。和中位数的唯一差别是边界：平均 ≥ x 是累加和 ≥ 0，「过半」是 > 0，差一个等号。原因在长度：平均值的分子是 sum，中位数分子是 (2·(#≥x) − L)，过半是严格 > L/2。

三、珠子的背包

n 个珠子排成一排，切成 k 段，每段的价格 = 段首珠子 + 段尾珠子。问最大可能分数减最小可能分数。

观察分数结构：首段贡献 w[0]，末段贡献 w[n−1]，中间每个切口 (i, i+1) 恰好贡献一次 w[i] + w[i+1]（i 是前段尾，i+1 是后段首）。所以分数 = w[0] + w[n−1] + 选中的 k−1 个相邻对之和。

切 k 段 = 选 k−1 个切口。想最大，选 k−1 个最大的相邻对；想最小，选 k−1 个最小的。差值里的 w[0] + w[n−1] 抵消，只剩「最大 k−1 个和减最小 k−1 个和」。把相邻对数组排序，从两头各取 k−1 个。

切段：选切口，看最大最小分数

四、总结

两题的做法都是先把目标翻译掉：中位数翻译成符号累加和，段价翻译成固定端加切口。翻译完，一个交给二分 + dp，一个交给排序取极值。碰到求极值且数据不小的问题，先想目标能不能换成可判定或可排序的量，这一步往往把难度直接削掉一档。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100005;
    int help[MAXN];
    int dp[MAXN][2];

    // check(x)：存在合法子序列，使 >= x 的个数过半
    bool check(const vector<int>& arr, int x) {
        int n = arr.size();
        for (int i = 0; i < n; i++) {
            help[i] = arr[i] >= x ? 1 : -1;
        }
        // dp[i][0]：i 选不选皆可；dp[i][1]：i 必选，i..n-1 上的最大累加和
        for (int i = n - 1; i >= 0; i--) {
            dp[i][0] = max(help[i] + dp[i + 1][0], dp[i + 1][1]);
            dp[i][1] = help[i] + dp[i + 1][0];
        }
        return dp[0][0] > 0;
    }

    // 答案在排序后的值里二分
    int maxMedian(vector<int> arr) {
        vector<int> sorted = arr;
        sort(sorted.begin(), sorted.end());
        int l = 0, r = arr.size() - 1, ans = -1;
        while (l <= r) {
            int m = (l + r) / 2;
            if (check(arr, sorted[m])) {
                ans = sorted[m];
                l = m + 1;
            } else {
                r = m - 1;
            }
        }
        return ans;
    }
#include <bits/stdc++.h>
    using namespace std;

    // 分数 = w[0] + w[n-1] + 选中的 k-1 个相邻对之和
    // 每个切口 (i, i+1) 贡献 w[i] + w[i+1]，切哪 k-1 个自己定
    long long putMarbles(const vector<int>& w, int k) {
        int n = w.size();
        vector<long long> split;
        for (int i = 1; i < n; i++) {
            split.push_back((long long)w[i - 1] + w[i]);
        }
        sort(split.begin(), split.end());
        long long small = 0, big = 0;
        for (int i = 0, j = n - 2, p = 1; p < k; i++, j--, p++) {
            small += split[i];      // 最小分数：取 k-1 个最小的切口
            big += split[j];        // 最大分数：取 k-1 个最大的切口
        }
        return big - small;
    }
