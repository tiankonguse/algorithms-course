线性基：普通消元与最大异或和

一堆数字的非 0 异或和可能多到 2n 个，但「能凑出哪些异或和」这件事，只需要 O(位数) 个数字就能完整表达。这几个数字就是异或空间线性基。这一节讲普通消元怎么建基，再用它解最大异或和。

零、异或空间线性基

只讨论非负数。把一堆数字里任意个异或起来，去重后得到的所有非 0 异或和，就是这堆数字的异或空间。线性基是一堆「元素个数尽量少」的数字，它凑出的非 0 异或和，和原来那堆数字不多不少完全一样。

有两个结论支撑这个压缩，课上重点图解：

1) 一堆数字里任取 a、b，用 a^b 替换掉其中一个，异或空间不变。

2) 如果 a^b = 0（也就是 a = b），丢掉其中一个，异或空间不变。

第一个结论反着用也能成立：原来用 a、b 凑出的异或和，现在用 (a^b)、b 一样凑得出，a = (a^b)^b；反过来原来的组合也都能用新集合表达。第二个是第一个的直接推论：a = b 时 a^b = 0，丢掉一个不丢任何异或和，因为留下的那个和 0 异或还是它自己。

结论 2 有个容易漏的地方：丢掉重复数字影响的是「每种异或和出现了几次」，不影响「能不能得到」。能不能异或出 0 是另一回事：线性基凑不出 0，原数组照样可能凑得出（比如两个相同的数）。所以能否异或出 0 必须在建基时单独标记，这是本课的第三个结论。

一、普通消元：insert 建基

basis[i] 存「最高位是第 i 位」的基。插入一个数 num，从最高位往低位扫：num 第 i 位是 1 而 basis[i] 空，就存进去；basis[i] 已经有值，就 num ^= basis[i] 接着往下消。插入失败（消到 0）说明这个数在线性空间里，把 zero 标记成 true。

插完所有数，线性基就建好了。基的大小不超过位数（每个基的最高位互不相同），和数字个数无关。建基复杂度 O(n × 位数)，n 是数字个数，位数是最大数字的位数，这两者通常差一个数量级以上，这就是压缩的意义。

两个课上例子先看效果：

例1 [12, 9, 14, 11] 的基是 12 5 2，zero = true，原数组能异或出 0。

例2 [2, 5, 11, 6] 的基是 11 5 2 1，zero = false，非 0 异或和恰好是 1 到 15 全部 15 个。

二、代码：建基与 zero 标记

// 普通消元：往线性基里插入一个数
    // basis[i] 存最高位为 i 的基；插入失败说明能异或出 0，单独标记
    const int BIT = 50;

    long long basis[BIT + 1];

    bool insert(long long num) {
      for (int i = BIT; i >= 0; i--) {
        if (num >> i == 1) {
          if (basis[i] == 0) {
            basis[i] = num;
            return true;
          }
          num ^= basis[i];
        }
      }
      return false;
    }

insert 的循环条件「num >> i == 1」只在第 i 位是 1 时进分支；第 i 位是 0 直接跳过这一位，因为异或 basis[i] 只会动到比 i 低的位，对第 i 位没帮助。插入返回 true 表示线性基变大了，返回 false 表示 num 被消成 0，此时 zero 记 true。

// 把 n 个数全部插入，顺便记录能否异或出 0
    bool zero;

    void compute() {
      zero = false;
      for (int i = 1; i <= n; i++) {
        if (!insert(arr[i])) {
          zero = true;
        }
      }
    }

三、最大异或和（洛谷 P3812）

基建好之后，最大异或和是一个简单贪心：从高位到低位，ans = max(ans, ans ^ basis[i])。

为什么不用记路径：第 i 位能不能变 1，只由 basis[i] 决定，其他基的最高位都比 i 小，异或它们碰不到第 i 位。所以从高到低扫，能变 1 就变 1，低位怎么走都影响不了已经定下的高位。

// 最大异或和：得到线性基后从高位到低位贪心
    // 高位能变 1 就变 1，低位怎么走都不影响已经定下的高位
    long long computeMaximum() {
      for (int i = 1; i <= n; i++) {
        insert(arr[i]);
      }
      long long ans = 0;
      for (int i = BIT; i >= 0; i--) {
        ans = max(ans, ans ^ basis[i]);
      }
      return ans;
    }

n ≤ 500、arr[i] ≤ 250，建基 O(n × 50)，贪心 O(50)，总复杂度 O(n × 位数)，跟数字值域无关。

五、总结

线性基把异或空间压缩成 O(位数) 个数字，insert 从高到低逐位消，插不进的就是能异或出 0 的（单独标记 zero）。替换与舍弃两个结论保证压缩不丢信息。最大异或和 = 基上从高到低贪心，每步 max(ans, ans ^ basis[i])。普通消元得到的基能回答大小、异或和个数、有没有 0、最大异或和，但回答不了第 k 小异或和，那是高斯消元标准基的活，下一节讲。
