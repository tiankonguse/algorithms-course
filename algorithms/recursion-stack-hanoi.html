递归当工具：逆序栈、排序栈、汉诺塔

前面几题递归用来枚举，这一页递归当数据搬运工。题目把辅助容器全禁了，只准用系统栈：逆序栈把栈底捞出来，排序栈把最大值沉底，汉诺塔把移动轨迹摊平。

零、背景

这三题的共同约束：只能用栈的 push、pop、isEmpty 三个方法和递归函数，返回值最多单个整数，数组、vector、链表一律不许用。系统栈是唯一的辅助空间。

递归在这里扮演「先到底再回程」的搬运工：下去时一路取数，回来时一路放回。取数的方式决定了它拿回什么，放回的方式决定了数据怎么挪。逆序栈和排序栈都建立在同一个动作上：把栈里某个位置的值取出来，其余顺序不动。

一、递归逆序一个栈

目标是把栈整个倒过来。先解决一个子问题：取出栈底元素，上面的元素盖下来。这个动作叫 bottomOut。

bottomOut 递归地弹：弹出栈顶，如果栈空了，弹出来的就是栈底，直接返回；没空，先递归取下面的栈底，返回前把当前这个压回去。整个动作把栈底捞出来，沿途元素一个不少地落回原位。

#include <bits/stdc++.h>
    using namespace std;

    // 用递归函数逆序一个栈（不能用额外容器）
    // 栈底元素移除掉，上面的元素盖下来，返回移除掉的栈底元素
    int bottomOut(stack<int>& st) {
        int ans = st.top(); st.pop();
        if (st.empty()) return ans;
        int last = bottomOut(st);
        st.push(ans);
        return last;
    }

    void reverse(stack<int>& st) {
        if (st.empty()) return;
        int num = bottomOut(st);
        reverse(st);
        st.push(num);
    }

逆序就三步：bottomOut 取出栈底 num，递归逆序剩下的栈，把 num 压回栈顶。栈底元素最后压，正好落在新栈的顶部。

代价是每次 bottomOut 都要走完整个栈：弹到栈底再压回来。实测 n = 1000 时 pop 和 push 各约 50 万次（各 n(n+1)/2），合计约 100 万次，用时 6.7 毫秒。复杂度 O(n²)，多出来的 n 就是反复走完栈的那份。

二、递归排序一个栈

目标是从栈顶到栈底从小到大，约束照旧：返回值最多单个整数，不许用任何容器。不能像逆序那样一把梭，得把「遍历栈」拆成几个只返回单个整数的递归函数。

四个函数凑一套：deep 数栈的深度；max 从栈顶往下数 deep 层找最大值；times 数这个最大值出现了 k 次；down 把这 k 个最大值沉到底，其余元素顺序不变。前三个函数都是弹一遍、记结果、再压回，遍历完栈还是原来的栈。

#include <bits/stdc++.h>
    using namespace std;

    // 用递归函数排序栈：排完序后，从栈顶到栈底从小到大
    // 只能使用栈的 push、pop、isEmpty 三个方法和递归函数，
    // 除此之外不能使用任何容器，返回值最多为单个整数

    // 返回栈的深度，不改变栈的数据状况
    int deep(stack<int>& st) {
        if (st.empty()) return 0;
        int num = st.top(); st.pop();
        int d = deep(st) + 1;
        st.push(num);
        return d;
    }

    // 从栈顶开始往下数 deep 层，返回这 deep 层里的最大值
    int maxNum(stack<int>& st, int deep) {
        if (deep == 0) return INT_MIN;
        int num = st.top(); st.pop();
        int rest = maxNum(st, deep - 1);
        int m = max(num, rest);
        st.push(num);
        return m;
    }

    // 已知最大值是 m，返回它在栈顶往下 deep 层里出现了几次
    int times(stack<int>& st, int deep, int m) {
        if (deep == 0) return 0;
        int num = st.top(); st.pop();
        int rest = times(st, deep - 1, m);
        int t = rest + (num == m ? 1 : 0);
        st.push(num);
        return t;
    }

    // 把这 k 个最大值沉底，剩下元素的数据状况不变
    void down(stack<int>& st, int deep, int m, int k) {
        if (deep == 0) {
            for (int i = 0; i < k; i++) st.push(m);
        } else {
            int num = st.top(); st.pop();
            down(st, deep - 1, m, k);
            if (num != m) st.push(num);
        }
    }

    void sortStack(stack<int>& st) {
        int d = deep(st);
        while (d > 0) {
            int m = maxNum(st, d);
            int k = times(st, d, m);
            down(st, d, m, k);
            d -= k;
        }
    }

主循环每轮干一件事：当前未排序区（栈顶往下 deep 层）的最大值，全部沉到这一区底部。沉完这一轮，未排序区从底部缩进去 k 个位置，deep 减 k。轮数正好等于栈里不同值的个数。

实测一个顶到底为 [1,5,4,5,3,2,3,1,4,2] 的栈，5 轮排完（值 1、2、3、4、5 各一轮），弹压合计 220 次。随机 100 个元素、值域 20，20 轮、弹压约 6900 次；全相等的栈 1 轮就完。复杂度 O(n²)。

三、汉诺塔

n 层圆盘从「左」柱搬到「右」柱，一次只能动一个，大盘不能压小盘，打印最优移动轨迹。递归式子一句话：把上面 i−1 层从 from 挪到 other，第 i 层从 from 挪到 to，再把 i−1 层从 other 挪到 to。

#include <bits/stdc++.h>
    using namespace std;

    // 打印 n 层汉诺塔问题的最优移动轨迹
    // from 是起点柱，to 是终点柱，other 是第三根柱

    void f(int i, const string& from, const string& to, const string& other) {
        if (i == 1) {
            cout << "移动圆盘 1 从 " << from << " 到 " << to << "\n";
        } else {
            f(i - 1, from, other, to);
            cout << "移动圆盘 " << i << " 从 " << from << " 到 " << to << "\n";
            f(i - 1, other, to, from);
        }
    }

    void hanoi(int n) {
        if (n > 0) f(n, "左", "右", "中");
    }

这个式子为什么是最优：第 n 层大圆盘从 from 到 to 只动一次，动之前上面 n−1 层必须整体挪到 other（唯一的合法去向），动之后还得整体挪回 to。于是 T(n) = 2T(n−1) + 1，T(1) = 1，解出来 T(n) = 2ⁿ − 1。

步数与递归调用次数是同一个小数：调用总数恰好也等于 2ⁿ − 1。n = 3 是 7 步，n = 10 是 1023 步，n = 20 是 1048575 步。n 每加 1，步数翻倍再减一。

四、总结

逆序栈靠 bottomOut 取底加 reverse 递归，弹压次数约 n²，O(n²)。

排序栈把「遍历栈」拆成 deep、max、times、down 四个单返回值的递归函数，每轮把一种最大值沉底，轮数等于不同值个数，O(n²)。

汉诺塔是纯分治：T(n) = 2T(n−1) + 1，步数 2ⁿ − 1，n 每加一层就翻倍。

三题的共同点是递归栈当容器：系统栈既是调用载体，也是唯一辅助空间。后面做树、图的递归题，同样的「到底取数、回程放回」姿势会一直出现。
