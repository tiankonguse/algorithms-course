前缀余数与奇偶掩码：非数值的前缀信息

前缀信息不一定是前缀和本身。把每个前缀和模 p 的余数存下来，余数相同就能拼出能被 p 整除的段；把每个前缀的元音奇偶压成 5 位掩码，状态相同中间段所有元音都是偶数次。累积的东西换了，哈希表记位置的思想不变。

零、背景

前两讲的哈希表装的是前缀和：值本身、最早出现的位置、出现次数。这讲把「累积的东西」换成两种新的：模 p 的余数，和 5 个元音字母的奇偶状态。

共同点还是那句：段的信息等于两个前缀信息的差。余数相同 → 段和能被 p 整除；奇偶状态相同 → 段里每个元音都出现偶数次。

一、移除最短子数组，使剩余和能被 p 整除

整个数组的和模 p 等于 mod。移除一段 [l, r] 后剩余和能被 p 整除，等价于被移除的段和模 p 等于 mod，也就是两个前缀和模 p 的差等于 mod。

从左往右维护当前前缀余数 cur，要找的前缀余数是 (cur - mod + p) % p。哈希表里存余数出现的位置。

这题和前两题有一个关键差别：要移除的段越短越好，所以左端点越靠右越好，哈希表每次更新都覆盖，记的是每个余数最晚出现的位置。前两题求最长段，记最早；这里求最短段，记最晚。方向是反的。

两个边界：整体和已经能被 p 整除，返回 0，一个都不用移除；唯一可行方案是移除整个数组，返回 -1（题目不允许）。

二、每个元音包含偶数次的最长子串

元音只有 a、e、i、o、u 五个，用一个 5 位掩码记前缀里每个元音出现的奇偶：第 k 位是 1 表示这个元音出现了奇数次。遇到元音就异或对应位，遇到非元音不动。

两个位置的掩码相同，中间那段每个元音的出现次数就是偶数（偶数减偶数还是偶数，奇数减奇数也是偶数）。所以问题变成找相同掩码的最远距离，和上一讲「正负相等」一个套路：哈希表记最早出现，求最长。

掩码只有 32 种，用数组 map[32] 装最早出现位置就行，不用哈希表。map[0] = -1：空前缀的掩码是 0，最早出现在 -1。

三、最早还是最晚

同一个「哈希表记位置」的套路，更新策略由答案决定：

要求最长段，左端点越靠左越好，只在第一次出现时写入，记最早。

要求最短段，左端点越靠右越好，每次出现都覆盖，记最晚。

写反方向就全错：记成最早，移除段会偏长；记成最晚，最长子串会被截短。

四、复杂度与实测

时间 O(n)，空间 O(1)（掩码数组固定 32 个位置）或 O(p)（余数最多 p 种）。

实测（本机 g++ -O2）：整除题 n = 10^5 用时 90.9ms，暴力枚举移除段 n = 8×10^3 要 116.5ms，外推到 n = 10^5 约 18.2 秒。元音题 n = 10^6 用时 54.8ms，暴力枚举子串 n = 3×10^3 要 7.7ms，外推到 n = 10^6 约 860 秒，差四个数量级。

操作台：前缀余数与奇偶掩码，一个表两种记法

初始：map[0] = −1。

代码

#include <bits/stdc++.h>
    using namespace std;

    // 题6：移除最短子数组，使剩余元素的和能被 p 整除
    int minSubarray(vector<int>& nums, int p) {
        int mod = 0;
        for (int num : nums) {
            mod = (mod + num) % p;
        }
        if (mod == 0) {
            return 0;
        }
        // key : 前缀和 % p 的余数, value : 最晚出现的位置
        unordered_map<int, int> map;
        map[0] = -1;
        int ans = INT_MAX;
        for (int i = 0, cur = 0, find; i < (int)nums.size(); i++) {
            cur = (cur + nums[i]) % p;
            find = cur >= mod ? (cur - mod) : (cur + p - mod);
            if (map.count(find)) {
                ans = min(ans, i - map[find]);
            }
            map[cur] = i;                       // 覆盖：记最晚出现
        }
        return ans == (int)nums.size() ? -1 : ans;
    }

    // 题7：每个元音包含偶数次的最长子字符串
    int move(char cha) {
        switch (cha) {
        case 'a': return 0;
        case 'e': return 1;
        case 'i': return 2;
        case 'o': return 3;
        case 'u': return 4;
        default: return -1;
        }
    }
    int findTheLongestSubstring(string s) {
        vector<int> map(32, -2);        // map[状态] = 最早出现的位置
        map[0] = -1;
        int ans = 0;
        for (int i = 0, status = 0, m; i < (int)s.size(); i++) {
            m = move(s[i]);
            if (m != -1) {
                status ^= 1 << m;       // 元音改状态，非元音不动
            }
            if (map[status] != -2) {
                ans = max(ans, i - map[status]); // 相同状态，中间段元音全偶数次
            } else {
                map[status] = i;        // 只记最早出现
            }
        }
        return ans;
    }

总结

前缀信息不限于数值：模余数、奇偶掩码都能累积、都能相减。段信息等于前缀信息之差这个框架不变。

两个新细节：找整除段要记最晚（段越短越好），找最长元音段要记最早；掩码状态只有 32 种，数组就能装，不用哈希表。
