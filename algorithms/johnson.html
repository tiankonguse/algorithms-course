Johnson 全源最短路

图里有负边时，Floyd 是 O(n³)、每个点跑一次 Bellman-Ford 是 O(n²·m)。Johnson 的想法是先用一次 Bellman-Ford 把每条边的权改成非负值，之后每个点跑一次 Dijkstra，总时间 O(n·m·log n)。

零、背景

前面几节说的都是单源最短路：一个起点到所有点。这一节要的是全源最短路，任意两点 i、j 之间的距离都要。

没有负边的时候很简单，从每个点跑一次 Dijkstra，n 次下来是 O(n·m·log n)。有负边就麻烦了，Dijkstra 的贪心不再成立，只能每个点跑一次 Bellman-Ford，变成 O(n²·m)，或者干脆用 Floyd，O(n³)。

差距不小。n = 3000、m = 6000 时，Floyd 要做 2.7 × 10¹⁰ 次松弛，n 次 Dijkstra 只有 2 × 10⁸ 量级。挡在中间的只有一件事：负边。

一、问题

一共 n 个点 m 条有向边，边有边权，可能有负边、重边、自环。图里有负环就输出 −1；否则求任意两点的最短距离，不连通记 10⁹，自己到自己记 0。

二、朴素做法

能直接用的办法有两个。一是 Floyd，三重循环枚举跳板，O(n³)。二是每个点跑一次 Bellman-Ford，每次 O(n·m)，n 次就是 O(n²·m)。两个都不快。

想快就得用 Dijkstra，可它有负边。失效的过程是这样的：

问题出在 Dijkstra 的前提：弹出来的点的距离不再变小。这个前提靠的是「边权非负」，一旦有负边，后弹出的点还能把先弹出的点改小。

三、统一加个常数行不行

最直接的想法是给每条边加上同一个值，把负数抬成正的。这样做不行，因为路径经过的边数不一样，被抬高的总量也不一样。

具体来说，上面这条路只加一次，下面那条加两次。最短路从下面变成上面，答案错了。

因此要的不是「统一加」，而是「每条边加的量各不相同，但任意两条同源同终的路径加起来一样多」。这正是 Johnson 做的事。

四、最低势能 h

Johnson 先建一个虚拟的超级源点 s，从 s 向每个点连一条权值为 0 的边，然后从 s 跑一次 Bellman-Ford（实现上常用 SPFA），得到 h[i]。

因为 s 到谁都是 0，所以 h[i] 的含义是：从任意点出发，走任意一条路到 i，累计边权的最小值。这个值不会是正的（走空路径就是 0），负值越小说明「到 i 越便宜」。

这里有个关键性质。h 是最短路的距离，所以对任何一条边 u → v 都满足三角不等式：

h[v] ≤ h[u] + w

否则的话，走 u 再到 v 就能把 h[v] 变得更小，和「h[v] 已经是最小」矛盾。

顺带一提，跑 Bellman-Ford 的时候如果某个点被松弛了超过 n + 1 次，说明图里有负环，此时最短路没有意义，直接输出 −1 就行。这也是题目里负环判断的来历。

五、按势能改边权

把三角不等式移项，得到 w + h[u] − h[v] ≥ 0。于是把每条边的权改成：

w′ = w + h[u] − h[v]

六、为什么最短路没变

改权看着是把每条边都动了一遍，其实对一条完整的路径来说，中间那些 h 全都会抵消掉。

于是整个算法就是五步：

  1. 建超级源点 s，s 向每个点连一条权值为 0 的边。
  2. 从 s 跑一次 Bellman-Ford（SPFA），得到 h[i]，顺便判负环。
  3. 每条边 u → v 的权改成 w + h[u] − h[v]。
  4. 每个点跑一次 Dijkstra，得到改权后的距离 dist′(u, v)。
  5. 还原真实距离：dist(u, v) = dist′(u, v) − h[u] + h[v]。

八、代码

下面是模板题的完整实现。SPFA 负责求势能和判负环，之后 n 次 Dijkstra 用优先队列。

#include <bits/stdc++.h>
using namespace std;

using ll = long long;

const int MAXN = 3005;                  // 点 1..n，外加超级源点 0
const int MAXM = 12005;                 // m 条边 + 超级源点连出的 n 条边
const int INF  = 1000000000;

int n, m;
int head[MAXN], nxt[MAXM], to[MAXM], weight[MAXM], cntg;
int h[MAXN], dist[MAXN], updateCnt[MAXN];
bool enter[MAXN], vis[MAXN];

void addEdge(int u, int v, int w) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    weight[cntg] = w;
    head[u] = cntg;
}

// 返回 true 表示发现了负环
bool spfa(int s) {
    fill(h, h + n + 1, INF);
    fill(updateCnt, updateCnt + n + 1, 0);
    fill(enter, enter + n + 1, false);
    queue<int> q;
    h[s] = 0;
    updateCnt[s] = 1;
    enter[s] = true;
    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        enter[u] = false;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e], w = weight[e];
            if (h[v] > h[u] + w) {
                h[v] = h[u] + w;
                if (!enter[v]) {
                    if (++updateCnt[v] > n + 1) return true;   // 含超级源点共 n+1 个点
                    enter[v] = true;
                    q.push(v);
                }
            }
        }
    }
    return false;
}

void dijkstra(int s) {
    fill(dist, dist + n + 1, INF);
    fill(vis, vis + n + 1, false);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
    dist[s] = 0;
    heap.push({0, s});
    while (!heap.empty()) {
        auto [d, u] = heap.top();
        heap.pop();
        if (vis[u]) continue;
        vis[u] = true;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e], w = weight[e];
            if (!vis[v] && dist[v] > d + w) {
                dist[v] = d + w;
                heap.push({dist[v], v});
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 0, u, v, w; i < m; i++) {
        cin >> u >> v >> w;
        addEdge(u, v, w);
    }
    for (int i = 1; i <= n; i++) addEdge(0, i, 0);   // 超级源点

    if (spfa(0)) {
        cout << "-1\n";
        return 0;
    }

    for (int u = 1; u <= n; u++)                      // 改边权
        for (int e = head[u]; e; e = nxt[e])
            weight[e] += h[u] - h[to[e]];

    for (int i = 1; i <= n; i++) {
        dijkstra(i);
        ll ans = 0;
        for (int j = 1; j <= n; j++) {
            if (dist[j] == INF) ans += 1LL * j * INF;         // 不连通
            else ans += 1LL * j * (dist[j] - h[i] + h[j]);    // 还原
        }
        cout << ans << '\n';
    }
    return 0;
}

有两个细节。改边权那层循环只从 1 走到 n，超级源点连出的边不动，因为它们已经用不上了。还原时用 long long，n 到 3000 时一行的累加能到 10¹² 量级。

九、复杂度分析

操作时间复杂度
SPFA 求势能 h（含判负环）O(n·m) 最坏，实际远小于此
改 m 条边的权O(m)
每个点跑一次 Dijkstra（共 n 次）O(n·m·log n)
总时间O(n·m·log n)
Floyd（对照）O(n³)
每个点跑 Bellman-Ford（对照）O(n²·m)
额外空间O(n + m)

空间上有四份数组：邻接表 O(n + m)，势能 h O(n)，距离 dist O(n)，堆最多 O(m)。合起来是 O(n + m)。

用题目给的量级算一下：n = 3000、m = 6000 时，Floyd 是 2.7 × 10¹⁰ 次松弛，n 次 Bellman-Ford 是 5.4 × 10¹⁰，Johnson 只有 n · m · log n ≈ 2 × 10⁸，加上一次 SPFA，能过。

可以发现，Johnson 适合的是稀疏图。图一旦稠密到 m ≈ n²，n·m·log n 就比 n³ 还差，那时候直接用 Floyd 反而更省事。

十、最后

Johnson 的全部技巧就是那个「差」：给每条边加上 h[u] − h[v]。边权因此非负，路径长度却只多了一个只跟端点有关的常数，最短路原封不动。

这个「最低势能」的想法后面还会遇到，费用流里用它把负费用变成非负，是同一个套路。

它的适用边界也清楚：图里不能有负环。有负环时 Bellman-Ford 的松弛停不下来，最短路本身也没有定义。这类图上该问的是「有没有负环」，而不是「最短路是多少」。
