分组判定与可撤销并查集

上一节的撤销是 dfs 逼出来的。这一节反过来：我们自己决定撤销的时机，把要判定的东西按某个关键字分成一组，一组之内临时加边、判定、整组撤销。两道题都是这个形状。

零、一个通用的形状

有一批判定，每条判定只涉及少量元素，而且判定之间按某个关键字有序。做法是把每条判定拆成若干条「元素」，按关键字排序，然后顺着一个方向扫：

  • 关键字小于当前值的部分，是永久的，加进去就不撤了
  • 当前这一组的元素，临时加进去，判定，然后整组撤销

永久部分只需要一个指针一直往前推。临时部分就是可撤销并查集：加多少，撤多少，栈正好用完。

一、题目3：同在最小生成树里

n 个点 m 条无向带权边，图保证连通。q 条查询，每条给出 k 条边的编号，问这 k 条边能否同时出现在一棵最小生成树上。n、m、q 以及所有查询涉及的边的总量都不超过 5 × 10⁵。测试链接：CF891C。

二、判据：给查询边优先权

Kruskal 的过程是：按边权从小到大，能加就加。那么一组边 S 能同时出现在某棵最小生成树上，条件是，把 S 里的边在同权值的一批里优先加入时，每条都能加上而不成环。

理由是 Kruskal 在同权边之间的顺序本来就可以任意挑。既然可以任意挑，就把 S 里的边先挑，剩下的再补。补的时候如果 S 的某条边成环，说明它在任何 Kruskal 顺序里都会被跳过。

于是每条查询拆成 k 条 (u, v, w, 查询号)，按 (w, 查询号) 排序。权值小的组先处理，同一查询在同一权值下的边聚在一起。

四条点、五条边、三条查询

边 1-2(1)、2-3(2)、1-4(2)、3-4(3)、2-4(3)，编号 1 到 5。查询 1 问边 1、2；查询 2 问边 3、5；查询 3 问边 4。点「下一步」看每组的加边、判定和撤销。

永久合并（不再撤销） 本次临时加的边 还没轮到

三、代码

compute 里的 l、r 就是当前组的左右端点，ei 是永久区的指针。组里每加一条边就 unionCnt 加一，判定结束（不管是判完还是中途发现环）都撤销 unionCnt 次。

void compute() {
        int ei = 1, queryId, unionCnt;
        for (int l = 1, r = 1; l <= k; l = ++r) {
            while (r + 1 <= k && queries[l].w == queries[r + 1].w && queries[l].i == queries[r + 1].i) {
                r++;
            }
            for (; ei <= m && edge[ei].w < queries[l].w; ei++) {
                if (find(edge[ei].u) != find(edge[ei].v)) {
                    Union(edge[ei].u, edge[ei].v);
                }
            }
            queryId = queries[l].i;
            if (!ans[queryId]) {
                continue;
            }
            unionCnt = 0;
            for (int i = l; i <= r; i++) {
                if (find(queries[i].u) == find(queries[i].v)) {
                    ans[queryId] = false;
                    break;
                } else {
                    Union(queries[i].u, queries[i].v);
                    unionCnt++;
                }
            }
            for (int i = 1; i <= unionCnt; i++) {
                undo();
            }
        }
    }

这里有个细节：ans[queryId] 已经为 false 的查询会直接 continue，但 ei 指针照样往前推，永久区和查询的判定结果无关。

并查集部分就是上一节那三件套，find 不压缩、Union 小挂大、undo 弹栈。

int find(int i) {
        while (i != father[i]) {
            i = father[i];
        }
        return i;
    }

    void Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (siz[fx] < siz[fy]) {
            int tmp = fx;
            fx = fy;
            fy = tmp;
        }
        father[fy] = fx;
        siz[fx] += siz[fy];
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
    }

    void undo() {
        int fx = rollback[opsize][0];
        int fy = rollback[opsize--][1];
        father[fy] = fy;
        siz[fx] -= siz[fy];
    }

四、题目4：团建

n 个人各有一个组号，m 条边表示两人有矛盾，一共 k 个组（组可以没人）。两个组 a、b 一起去团建时，所有人可以重新打乱，要求分成最多两个集团、每人都在某个集团里、每个集团内部没有矛盾。这样的 (a, b) 叫合法组对，问有多少个。n、m、k ≤ 5 × 10⁵。测试链接：CF1444C。

「分成最多两个集团、集团内部无矛盾」就是这些人构成的矛盾图是二分图。所以问题是：哪两个组并在一起是二分图。

判断二分图用扩展域并查集：每个人拆成 i 和 i + n 两个点，一条矛盾边 (u, v) 就做两次合并，u 与 v + n、v 与 u + n。若某次加边前已经有 find(u) == find(v)，说明 u 和 v 被要求同色，可它们之间偏偏有矛盾边，奇环出现了，不是二分图。

先扫一遍所有边。组内边（两端同组）用来筛组：如果这个组自己的矛盾图不是二分图，它和谁都不可能合法，标记 conflict，同时把候选总数 k 减一。跨组边按 (小组号, 大组号) 存下来排序备用。

答案从 C(k, 2) 起算。之后处理跨组边：按 (uteam, vteam) 分成一组组，同一组对的全部边临时加进去，只要出现 find(u) == find(v) 就把答案减一，然后整组撤销。两组里有一个被标记过 conflict 就整组跳过。

void filter() {
        for (int i = 1; i <= 2 * n; i++) {
            father[i] = i;
            siz[i] = 1;
        }
        for (int i = 1, u, v; i <= m; i++) {
            u = edge[i][0];
            v = edge[i][1];
            if (team[u] < team[v]) {
                crossEdge[++cnt].u = u;
                crossEdge[cnt].uteam = team[u];
                crossEdge[cnt].v = v;
                crossEdge[cnt].vteam = team[v];
            } else if (team[u] > team[v]) {
                crossEdge[++cnt].u = v;
                crossEdge[cnt].uteam = team[v];
                crossEdge[cnt].v = u;
                crossEdge[cnt].vteam = team[u];
            } else {
                if (conflict[team[u]]) {
                    continue;
                }
                if (find(u) == find(v)) {
                    k--;
                    conflict[team[u]] = true;
                } else {
                	Union(u, v + n);
                	Union(v, u + n);
                }
            }
        }
    }
long long compute() {
        sort(crossEdge + 1, crossEdge + cnt + 1, CrossEdgeCmp);
        long long ans = (long long)k * (k - 1) / 2;
        int u, uteam, v, vteam, unionCnt;
        for (int l = 1, r = 1; l <= cnt; l = ++r) {
            uteam = crossEdge[l].uteam;
            vteam = crossEdge[l].vteam;
            while (r + 1 <= cnt && crossEdge[r + 1].uteam == uteam && crossEdge[r + 1].vteam == vteam) {
                r++;
            }
            if (conflict[uteam] || conflict[vteam]) {
                continue;
            }
            unionCnt = 0;
            for (int i = l; i <= r; i++) {
                u = crossEdge[i].u;
                v = crossEdge[i].v;
                if (find(u) == find(v)) {
                    ans--;
                    break;
                } else {
                	Union(u, v + n);
                	Union(v, u + n);
                    unionCnt += 2;
                }
            }
            for (int i = 1; i <= unionCnt; i++) {
                undo();
            }
        }
        return ans;
    }

k 这个变量有点绕：filter 里每发现一个不合法的组就 k--，于是 compute 起手的 C(k, 2) 已经把「含不合法组的组对」全减掉了。剩下要减的只有「两个组各自都行、合在一起不行」的那些。

复杂度分析

两道题的形状一样：排序一次，之后每条边（或每条查询拆出来的项）被加进并查集一次、撤销一次。

题目时间空间
CF891CO((m + K) log(m + K) + (m + K) log n)O(n + m + K)
CF1444CO((n + m) log m + m log n)O(n + m)
单次 UnionO(log n)栈上一条记录
单次 undoO(1)—

K 是所有查询涉及的边的总量，题面保证它和 m 同阶，所以整体是 O(m log m) 级别。CF1444C 的扩展域并查集把点数翻了一倍，father 和 siz 要开 2n，栈也要开到 2n。

最后

可撤销并查集在这两题里是「临时加边」的工具，撤销的时机由分组决定。再往后，线段树分治会把同样的撤销操作挂到一棵时间线段树上，一次 dfs 走完整棵树的加边与撤销，那才是它用得最多的地方。
