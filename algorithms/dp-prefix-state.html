前缀奇偶与按位状态

同一个前缀信息能回答两类问题：数子数组，和挑最长子序列。前者把前缀压成一个 0/1 奇偶，后者把「最后一个数是谁」压成「它含哪些位」。状态一小，转移也跟着简单。

零、背景

乘积的符号只由负号的个数决定，两个前缀的负号奇偶一比较，中间那段子数组的符号就出来了，这是「前缀奇偶」的用法。相邻两个数按位与不为 0，等价于共享任意一个二进制位，于是子序列的状态不记数、只记位，这是「按位状态」的用法。

一、问题：正负乘积

给一个不含 0 的数组，问乘积为正的子数组和乘积为负的子数组各多少个。子数组总数 O(n²)，不可能枚举。

记 cur 为前缀 [1..i] 里负号个数的奇偶。子数组 (j..i] 的乘积符号，等于 cur 异或前缀 j−1 的奇偶：异或得 0（奇偶相同）乘积为正，得 1（奇偶不同）乘积为负。

二、两个计数器

从左往右扫，cnt[0] 和 cnt[1] 记已经出现过的两种前缀奇偶的个数。对每个 i：当前奇偶 cur 之前出现过 cnt[cur] 次，每个都能配出一个正的子数组；cnt[cur ^ 1] 次配出负的。配完把当前奇偶记进去，一趟 O(n)。

[1, -2, 3, -4, 5] 扫完是正 7 个、负 8 个，总共 15 = 5×6/2 个子数组，一个不多一个不少。

n = 2e5 时子数组总数是 2e10，超过 int，计数用 long long。

正负乘积：前缀奇偶计数

「下一步」逐个处理元素。信息行给出当前前缀奇偶、两类前缀的个数，以及累计的正负子数组数。

// 正负乘积子数组：乘积符号只由负号的个数决定
    // cur 是前缀 [1..i] 里负号个数的奇偶，子数组 (j..i] 的符号 = cur 异或前缀 j-1 的奇偶
    // 异或为 0（奇偶相同）→ 正，异或为 1（奇偶不同）→ 负
    // cnt[0] / cnt[1] 统计之前出现过的两种前缀奇偶个数
    long long positive = 0, negative = 0;
    long long cnt[2] = {1, 0}; // 空前缀视为正，先算一个
    int cur = 0;
    for (int i = 1; i <= n; i++) {
        if (arr[i] < 0) {
            cur ^= 1;
        }
        positive += cnt[cur];     // 奇偶相同，乘积为正
        negative += cnt[cur ^ 1]; // 奇偶不同，乘积为负
        cnt[cur]++;
    }

三、问题：相邻与

求最长子序列，要求任意相邻两个数按位与不为 0。相邻合法 ⟺ 两个数共享至少一个二进制位，跟具体是哪位无关。

朴素状态是「最后一个数是谁」，转移 O(n)，总 O(n²)。换一种记法：pre[j] = 以「含第 j 位的数」结尾的合法子序列最长长度。新数 num 只要能接在「含第 j 位的数」后面，要求的就是 num 自己含第 j 位。

四、状态只记位

处理 num：cur = 1 起步（自己单独一个数也合法），对 num 的每个 set bit j 做 cur = max(cur, pre[j] + 1)；然后把 num 的 set bit 的 pre 全部更新成 max(pre[j], cur)。

一个数最多 31 位，每步 O(31)，总 O(31n)。[1..10] 答案是 7，[7,14,21,28,35] 答案是 4：这五个数都含 7 的位，排成一列全合法。

相邻与：pre 按位推进

演示里数字只显示低 8 位，代码里按 31 位算。「下一步」处理一个数，信息行给出 cur 怎么从 set bit 的 pre 推出来。

// 相邻与不为 0：相邻两个数只要共享任意一个二进制位即可
    // 不记「上一个数是谁」，记「上一个数含哪些位」：pre[j] 是
    // 「以含第 j 位的数结尾」的合法子序列最长长度
    int pre[32] = {0};
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        int cur = 1; // 单独一个数也合法
        for (int j = 0; j < 31; j++) {
            if (((arr[i] >> j) & 1) == 1) {
                cur = max(cur, pre[j] + 1);
            }
        }
        for (int j = 0; j < 31; j++) {
            if (((arr[i] >> j) & 1) == 1) {
                pre[j] = max(pre[j], cur);
            }
        }
        ans = max(ans, cur); // 全 0 的数组 pre 永远不更新，答案靠 cur 兜底成 1
    }
    return ans;

五、全 0 的边角

全是 0 时，0 没有任何 set bit，pre 数组从头到尾不更新。只看 pre 会答 0，但单独一个 0 就是长度 1 的合法子序列，正确答案是 1。答案边算边记 cur，最后取 max，就兜住了。实测 [0,0,0] 答案是 1。

复杂度分析

正负乘积：一趟扫描，时间 O(n)，空间 O(1)。相邻与：每个数固定看 31 位，时间 O(31n)，空间 O(32)。

做法时间空间
正负乘积：前缀奇偶计数O(n)O(1)
相邻与：按位状态O(31n)O(32)

总结

两个题都在压缩状态：正负乘积把前缀压成 0/1 奇偶，两个计数器直接数完所有子数组；相邻与把「上一个数」压成它含的位，pre[31] 一个数组装下全部状态。共同点是先找「性质只依赖哪一点信息」：符号只依赖负号个数的奇偶，接续只依赖共享的位。找到之后，状态就只留那一点。
