莫队 + 位图与根号分治

窗口里的东西可以是一张位图：重数用「一段连续的位置」表示，存在性用「一次移位加按位与」判断。剩下不好办的那一半交给根号分治。

零、背景

位图的用处是「一次操作顶几十个」：一个 unsigned long long 是一位 64 个开关，一次与运算相当于 64 次判断。莫队的窗口如果能用位图表示，增删和回答都能被压扁。

这一节两题，一题用位图数重数，一题用位图判存在性；第二题里除法的那部分位图不管用，改用根号分治离线处理。

一、掉进兔子洞

三个区间里同时出现的数，一个一个删掉，直到无法再删，剩下数字的个数叫剩余个数。比如 A = [1 2 2 3 3 3]、B = [1 2 2 3 3 3]、C = [1 1 2 3 3]：一起删掉一个 1、一个 2、两个 3，剩 A = [2 3]、B = [2 3]、C = [1]，剩余个数是 5。

给定一个长度为 n 的数组 arr，m 条查询，每条给 l1 r1 l2 r2 l3 r3 三个区间，打印剩余个数。

1 ≤ n、m ≤ 10⁵，1 ≤ arr[i] ≤ 10⁹。测试链接：P4688

二、朴素做法与换算

每删一轮，三个区间各少一个相同的值。设值 v 在三个区间里分别出现 a、b、c 次，它一共能被删 min(a, b, c) 轮，每轮消耗三个数。所以

剩余个数 = 三个区间长度之和 − 3 × Σv min(av, bv, cv)

朴素做法是每次查询数三遍、对每个值取 min，单次 O(区间长度)，总的 O(nm)。

难点在这个 Σ min。它要的是「三个区间共有的重数」，而位图擅长做交集，不擅长做重数。这里有个巧妙的处理：让重数变成一段连续的位置。

三、不去重的位图设计

先把值离散化。注意不是压成 1、2、3 这种紧凑编号，而是取它在排序数组里第一次出现的位置 r。这样值 v 的所有出现正好占住 [r, r + 出现次数 − 1] 这一段连续的位置，不同值占的段互不重叠。

于是窗口里值 v 出现 c 次，就把这一段的「前 c 个位置」点亮。三个区间各得到一张位图，按位与之后，每段里剩下的 1 的个数就是三个区间里这个值出现次数的最小值。

四、一次增删只动一位

加进来一个值 v，它的次数从 c 变成 c+1，位图上就是多点亮一个位置 r + c。删掉则是灭掉最后一个点亮的位置。都是 O(1)。

void add(int x) {          // x 是值的名次
    cnt[x]++;
    curSet[x + cnt[x] - 1] = 1;   // 这一段再点亮一格
}
void del(int x) {
    cnt[x]--;
    curSet[x + cnt[x]] = 0;       // 灭掉最后点亮的那一格
}

一条查询要三张位图，所以拆成三个子任务，共 3m 个，一起排序、一起滑。每到一个子任务，就把当前位图与到这张查询的位图上（第一次是赋值）。

还有个现实问题：每张位图 n 位，m 张就是 nm 位，10⁵ × 10⁵ 存不下。代码里分批做，每批处理三万条查询，处理完就输出、清空，位图数组只开三万张。

点「下一步」看这三个子任务怎么走。数组取 [1, 2, 2, 3, 3, 3]，三个区间是 [1,4]、[2,6]、[3,5]。

五、题目1 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 100001;
    const int MAXT = 30001;
    int n, m;
    int arr[MAXN];

    int sorted[MAXN];
    int bi[MAXN];

    int cnt[MAXN];
    bitset<MAXN> curSet;
    bool hasSet[MAXT];
    bitset<MAXN> bitSet[MAXT];

    Query query[MAXT * 3];

    int ans[MAXT];

    int kth(int num) {
        int left = 1, right = n, ret = -1;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] >= num) {
                ret = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return ret;
    }

    bool QueryCmp(const Query &a, const Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if (bi[a.l] & 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void add(int x) {
        cnt[x]++;
        curSet[x + cnt[x] - 1] = 1;
    }

    void del(int x) {
        cnt[x]--;
        curSet[x + cnt[x]] = 0;
    }

    void compute(int q) {
        int winl = 1, winr = 0;
        for (int i = 1; i <= q; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            if (!hasSet[id]) {
                hasSet[id] = true;
                bitSet[id] = curSet;
            } else {
                bitSet[id] &= curSet;
            }
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        prepare();
        for (int t = MAXT - 1; m > 0; m -= t) {
            int k = min(m, t);
            memset(cnt, 0, sizeof(int) * (n + 2));
            memset(hasSet, 0, sizeof(bool) * (k + 2));
            memset(ans, 0, sizeof(int) * (k + 2));
            curSet.reset();
            int cntq = 0, l, r;
            for (int i = 1; i <= k; i++) {
                for (int j = 1; j <= 3; j++) {
                    cin >> l >> r;
                    query[++cntq] = { l, r, i };
                    ans[i] += r - l + 1;
                }
            }
            sort(query + 1, query + cntq + 1, QueryCmp);
            compute(cntq);
            for (int i = 1; i <= k; i++) {
                ans[i] -= bitSet[i].count() * 3;
            }
            for (int i = 1; i <= k; i++) {
                cout << ans[i] << '\n';
            }
        }
        return 0;
    }

六、由乃的玉米田

给定一个长度为 n 的数组 arr，m 条查询，四种形式：打印 arr[l..r] 上能否选出两个数，差为 x；和为 x；积为 x；商为 x（且没有余数）。选出的两个数可以是同一个位置的数。能就打印 yuno，否则打印 yumi。

1 ≤ 所有数据 ≤ 10⁵。测试链接：P5355

七、四种判断怎么落到位图上

朴素做法是枚举区间里的两个数，O(长度²)。

窗口维护两张位图：bitSet1[v] = 1 表示值 v 出现过，bitSet2[MAXV − v] = 1 是同一份信息反着存。于是：

  • 差为 x：要找 u − w = x，也就是 w 和 w + x 都在。把 bitSet1 右移 x 位，位置 w 上放的就是原来 w + x 的位，两者按位与，非空就存在。
  • 和为 x：要找 u + w = x。bitSet2 里位置 MAXV − v 记着 v，把它右移 MAXV − x 位，位置 w 上放的就是 x − w 这个值的位，同样按位与。
  • 积为 x：枚举 x 的因子对 (f, x/f)，只要有一对两个数都在就行，代价 O(√x)。
  • 商为 x：要找 u / w = x，也就是 w 和 w·x 都在。枚举 w 从 1 到 MAXV/x，代价 O(MAXV/x)。

八、除法里 x 小的时候另走一条路

商为 x 的代价是 MAXV/x。x 大（≥ √MAXV）时代价不超过 √MAXV，可以接受；x 小的时候会退化成 O(MAXV)，一次查询就几十万次判断。

所以 x < √MAXV 的这类查询不进莫队，单独提出来按 x 分组处理。对每个小 x 扫一遍整个数组：pre[v] 记值 v 最后出现的位置，扫到位置 i 时，值是 v，那么能和它配对的数是 v·x（不超过 MAXV）或者 v/x（能整除时）。记 dp[i] 是「截止到 i，配成对时较小的那个位置最大能到多少」。

查询 [l, r] 只要看 dp[r] 是否 ≥ l：是就说明有一对，两个位置都落在 [l, r] 里。

每个小 x 扫一遍数组是 O(n)，x 不到 √MAXV ≈ 316 个，总共 O(n√MAXV)。

下面是 arr = [2, 4, 3, 6, 5]，五条查询依次是减 2、加 7、乘 12、除 2、减 5（最后一条的区间是 [3,5]）。

九、题目2 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, x, op, id;
    };

    const int MAXN = 100001;
    const int MAXV = 100000;
    const int MAXB = 401;
    int n, m, blen;
    int arr[MAXN];
    int bi[MAXN];

    Query query[MAXN];
    int cntq = 0;

    int headq[MAXB];
    int nextq[MAXN];
    int ql[MAXN];
    int qr[MAXN];
    int qid[MAXN];
    int cnts = 0;

    int cnt[MAXN];
    bitset<MAXN> bitSet1;
    bitset<MAXN> bitSet2;

    int pre[MAXN];
    int dp[MAXN];

    bool ans[MAXN];

    void addSpecial(int x, int l, int r, int id) {
        nextq[++cnts] = headq[x];
        headq[x] = cnts;
        ql[cnts] = l;
        qr[cnts] = r;
        qid[cnts] = id;
    }

    bool QueryCmp(const Query &a, const Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if (bi[a.l] & 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void add(int x) {
        cnt[x]++;
        if (cnt[x] == 1) {
            bitSet1[x] = 1;
            bitSet2[MAXV - x] = 1;
        }
    }

    void del(int x) {
        cnt[x]--;
        if (cnt[x] == 0) {
            bitSet1[x] = 0;
            bitSet2[MAXV - x] = 0;
        }
    }

    bool calc(int op, int x) {
        if (op == 1) {
            return (bitSet1 & (bitSet1 >> x)).any();
        } else if (op == 2) {
            return (bitSet1 & (bitSet2 >> (MAXV - x))).any();
        } else if (op == 3) {
            for (int f = 1; f * f <= x; f++) {
                if (x % f == 0 && bitSet1[f] && bitSet1[x / f]) {
                        return true;
                }
            }
            return false;
        } else {
            for (int i = 1; i * x <= MAXV; i++) {
                if (bitSet1[i] && bitSet1[i * x]) {
                    return true;
                }
            }
            return false;
        }
    }

    void compute() {
        int winl = 1, winr = 0;
        for (int i = 1; i <= cntq; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int jobx = query[i].x;
            int op = query[i].op;
            int id = query[i].id;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            ans[id] = calc(op, jobx);
        }
    }

    void special() {
        for (int x = 1; x < blen; x++) {
            if (headq[x] != 0) {
                memset(pre, 0, sizeof(int) * (MAXV + 1));
                memset(dp, 0, sizeof(int) * (n + 1));
                for (int i = 1; i <= n; i++) {
                    int v = arr[i];
                    pre[v] = i;
                    dp[i] = dp[i-1];
                    if (v * x <= MAXV) {
                        dp[i] = max(dp[i], pre[v * x]);
                    }
                    if (v % x == 0) {
                        dp[i] = max(dp[i], pre[v / x]);
                    }
                }
                for (int q = headq[x]; q > 0; q = nextq[q]) {
                    int l = ql[q];
                    int r = qr[q];
                    int id = qid[q];
                    ans[id] = (l <= dp[r]);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        blen = (int)sqrt(MAXV);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, op, l, r, x; i <= m; i++) {
            cin >> op >> l >> r >> x;
            if (op == 4 && x < blen) {
                addSpecial(x, l, r, i);
            } else {
                query[++cntq] = {l, r, x, op, i};
            }
        }
        sort(query + 1, query + cntq + 1, QueryCmp);
        compute();
        special();
        for (int i = 1; i <= m; i++) {
            cout << (ans[i] ? "yuno" : "yumi") << '\n';
        }
        return 0;
    }

十、复杂度分析

题目1：n 是数组长度，m 是查询数，一条查询拆成三个子任务。

操作时间复杂度
离散化O(n log n)
窗口增删一步O(1)（只动一位）
每个子任务与一次位图O(n / 64)
指针总移动（3m 个子任务）O((n + m)√n)
全部 m 次查询O((n + m)√n + mn / 64)

空间上分批做，每批三万张位图，每张 n 位，加上计数数组，O(30000 × n / 8 + n)。

题目2：n 是数组长度，m 是查询数，V 是值域（10⁵）。

操作时间复杂度
窗口增删一步O(1)
判断差 / 和O(V / 64)
判断积O(√x)
判断商（x ≥ √V，走莫队）O(V / x) ≤ O(√V)
判断商（x < √V，离线 dp）每个 x O(n)，共 O(n√V)

空间上是两张位图各 O(V)、计数数组 O(V)，加上小 x 的查询链表，O(V + m)。

十一、最后

两题都是把窗口的状态压成位图，区别在怎么用：一题用位图的「一段」表示重数，一题用位图的「移位」判断存在性。

位图解决不了的那部分（除法里 x 很小的情况）没有硬撑，而是单独提出来按根号分治离线处理。一道题里几种手段并存是常态，谁干得快就让谁干。

到这里，莫队这个专题的四节就过了一遍：普通莫队提供骨架，后面每一节都在回答同一个问题，窗口里到底该维护什么。
