树状数组优化建图：前缀范围连边一次只要 O(log v) 条

「袋中点权 1 到 p 的每个点，都向 x 连一条边权 w 的边」，这种前缀范围连边老实建是 O(n) 条。把树状数组的每个槽位变成一条按入袋时间增长的虚点链，一次范围操作只需要 O(log v) 条边，整张图的边数从平方级降到 O((n + m) log v)。

零、背景

优化建图处理的是「点到一片」的边：一条边的语义是连向某个范围里的所有点，而不是单个点。196 课的前缀优化建图用一条链解决「编号前缀」，点按编号排好，前缀 [1..p] 里的每个点通过链上中转互相到达，链是一次性摆好的。

这一课的问题麻烦在两点。范围落在点权上而不是编号上；点还是一个一个动态进袋的。值域上的前缀没法用一条链维护，点入袋的顺序和点权的大小没有任何关系，链摆好了新点就插不进去。

树状数组正好给出值域前缀的另一套分解：前缀 [1..p] 拆成 O(log v) 个槽位的并，每个槽位只管自己那一段值域。槽位内部再各自维护一条链，动态进袋就不再是问题。

一、问题

点的编号范围 1 到 n，点权范围 1 到 v。初始时袋子为空，没有任何边，要求实现四个方法：

方法语义
add(x, xv)编号 x、点权 xv 的点进入袋子；已入袋则忽略
rangeToX(p, x, w)袋中点权范围 1 到 p 的每个点，向点 x 连边权 w 的边
xToRange(x, p, w)点 x 向袋中点权范围 1 到 p 的每个点，连边权 w 的边
rangeToRange(p1, p2, w)袋中点权 1 到 p1 的每个点，向袋中点权 1 到 p2 的每个点，连边权 w 的边

建好图之后可以测任何图算法，课程代码里用 dijkstra 求最短路做对数器验证。所有语义边必须真的等价于「范围里每个点」，这是对数器检验的东西，也是后面 2-SAT 综合题敢用它的前提。

二、朴素做法

袋子用什么存都行，查询时老实扫一遍：rangeToX 把袋里点权不超过 p 的点各连一条边，O(|bag|) 条；rangeToRange 双重循环，O(|bag|²) 条。点数、操作数到 10⁵ 级别时边数直接上 10¹⁰，存不下。

可以发现瓶颈只在「范围里的每个点」这半句。把范围换成一两个中转虚点，让虚点顺着零权边把流量分发给范围里的点，边数就掉下来了。

三、前缀拆成 log 个槽

树状数组的经典性质：前缀 [1..p] 可以在 p 不断减去 lowbit 的过程中拆成一串槽位 i₁、i₂、…，每个槽位 i 覆盖值域段 [i − lowbit(i) + 1, i]。这些值域段互不重叠，并起来恰好是 [1..p]，段数不超过 log v。

于是「连向前缀里的每个点」变成「连向 log 个槽位」。剩下的问题是：槽位里装的是虚点还是实点？点动态进袋，槽位里放什么才能既收下新点、又让旧查询够得着？

四、槽位里挂一条版本链

每个槽位维护一条链，链上的节点是这个槽位收到的点，按入袋时间从老到新排列。方向是讲究的，出边和入边要两条方向相反的链：

out 链给「范围向 x 连边」用，链边方向是老节点指向新节点，点连向自己入袋那一刻的节点。这样任何一个历史点都能顺着链往前走，一直走到当前的链头。查询只需要从链头连一条边权 w 的边到 x，链头能被所有历史点到达，一条边就覆盖了整个前缀。

in 链给「x 向范围连边」用，方向整个反过来：新节点指向老节点，节点指向自己对应的点。x 连向链头，从链头顺着链往回走，就能到达这条链上出现过的每一个点。

add(x, xv) 的代价由此确定：覆盖 xv 的槽位恰有 O(log v) 个（xv 不断加 lowbit），每个槽位在链头新挂一个节点、连两条零权边。一个点入袋，总共造 O(log v) 个虚点、O(log v) 条边。

五、三个范围操作

rangeToX(p, x, w)：把 p 按 lowbit 拆成槽位，每个非空槽位的 out 链头向 x 连一条边权 w 的边。xToRange(x, p, w) 完全对称，用 in 链。两次循环都是 O(log v)。

rangeToRange(p1, p2, w) 是前两个的组合：造两个新虚点 X、Y，前缀 [1..p1] 的链头连向 X（0 权），X 向 Y 连 w，Y 再用 in 链连向前缀 [1..p2]。经过 X 的路径恰好表达了「p1 范围的每个点到 p2 范围的每个点，代价都是 w」。

有个细节值得注意：链上的边全是 0 权，边权 w 只出现在真正表达语义的那条边上。所以 dijkstra 在虚图上算出的最短路，和朴素建出的图完全一致，对数器里两个版本的 dijkstra 逐对比较，任何一条不一致都会报错。

七、代码

下面是建图部分的核心。链式前向星存边，cntt 给虚点编号，outTree、inTree 记录每个槽位的链头。对数器部分（暴力建图、双份 dijkstra、随机操作流）没有贴进来。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1001;
    const int MAXV = 1001;
    const int MAXT = 100001;
    const int MAXE = 100001;
    int n, v, cntt;

    bool inBag[MAXN];

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int weight[MAXE];
    int cntg;

    int outTree[MAXV];
    int inTree[MAXV];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int lowbit(int i) {
        return i & -i;
    }

    void addOut(int x, int xv) {
        while (xv <= v) {
            int preo = outTree[xv];
            int curo = ++cntt;
            if (preo > 0) {
                addEdge(preo, curo, 0);
            }
            addEdge(x, curo, 0);
            outTree[xv] = curo;
            xv += lowbit(xv);
        }
    }

    void addIn(int x, int xv) {
        while (xv <= v) {
            int prei = inTree[xv];
            int curi = ++cntt;
            if (prei > 0) {
                addEdge(curi, prei, 0);
            }
            addEdge(curi, x, 0);
            inTree[xv] = curi;
            xv += lowbit(xv);
        }
    }

    void add(int x, int xv) {
        if (!inBag[x]) {
            inBag[x] = true;
            addOut(x, xv);
            addIn(x, xv);
        }
    }

    void rangeToX(int p, int x, int w) {
        while (p > 0) {
            if (outTree[p] > 0) {
                addEdge(outTree[p], x, w);
            }
            p -= lowbit(p);
        }
    }

    void xToRange(int x, int p, int w) {
        while (p > 0) {
            if (inTree[p] > 0) {
                addEdge(x, inTree[p], w);
            }
            p -= lowbit(p);
        }
    }

    void rangeToRange(int p1, int p2, int w) {
        int x = ++cntt;
        int y = ++cntt;
        rangeToX(p1, x, 0);
        xToRange(y, p2, 0);
        addEdge(x, y, w);
    }

八、复杂度分析

操作时间复杂度新增规模
add(x, xv)O(log v)虚点 log v 个、边 O(log v) 条
rangeToX / xToRangeO(log v)边 O(log v) 条
rangeToRangeO(log v)虚点 2 个、边 O(log v) 条
建图总规模虚点 n·log v + 2m 个，边 (n + m)·log v 条
朴素建图（对照）rangeToRange 一条操作就 O(n²) 条边
dijkstra（虚图上）O((n + m)·log v · log(n log v))

时间上每个操作都贵在 lowbit 循环，最长 log v 步。整个交互过程是纯增量的：没有删除、没有重构，链只往头上加节点，所以均摊也不需要。

空间是链式前向星的常规开销：虚点数组、边数组都按 O((n + m) log v) 开，点权范围 v 只影响槽位下标的空间 O(v)。点数到 10⁵、值域到 10⁹ 时先离散化，槽位照样只有 O(n) 个量级。

九、最后

树状数组优化建图把「值域前缀连边」变成「log 个链头各出一条边」，代价是每个点多 log v 个虚点。链边全零权，语义边原样保留，任何图算法搬上来都不变形。

限制也很清楚：它只会切前缀 [1..p]。范围是任意区间 [l..r] 时，槽位分解就不够了，那要换成线段树按版本可持久化，是下一页的内容。范围进一步变成「两个权值都不超过我」的偏序关系时，数据结构也不够用了，得让 CDQ 分治上场。

这套结构在第四页还会再出现一次：P7477 的 2-SAT 蕴含边正好是「向左侧值排名前缀连边」，链按位置顺序增长，查询天然只看到过去，树状数组的版本链直接就是那道题的建边工厂。
