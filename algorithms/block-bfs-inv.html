分块好题（二）：磁力块与区间逆序对

分块不一定只用来维护数组。这一节里，一次分块给了 bfs 一个剪枝的抓手，另一次分块把区间逆序对拆成了散对散、散对整、整对整三类。

零、背景

上一节的两道题，分块都是直接维护序列信息：整块一步取，散块逐个算。

这一节的两道题不太一样。第一道是图上的搜索，分块的作用是让「整块能不能一步处理」变得可判断；第二道是静态统计，分块的作用是把一次查询拆成几类，每类各自预处理。

一、问题：磁力块

磁块有五个属性：位置 (x, y)、质量 m、磁力 p、吸引半径 range。

磁块 A 能把磁块 B 吸到 A 的位置，需要同时满足：A 与 B 的距离不大于 A 的吸引半径，并且 B 的质量不大于 A 的磁力。

你有一个初始磁块，给定它的位置、磁力、吸引半径（不给质量）。你永远停在初始磁块的位置，接下来给定 n 个磁块各自的五个属性。

吸过来的磁块可以随意使用，问最多能吸过来多少个。

1 ≤ n ≤ 3 * 10⁵，坐标在 ±10⁹，m、p、range 在 1 到 10⁹。

测试链接：洛谷 P10590、Codeforces 198E。

这里有个细节：被吸过来的磁块会被吸到你的位置上，而你的位置从头到尾没变，所以所有磁块到你的距离是一个固定值，开局算一次就够。

二、朴素做法

直接 bfs。队列里放已经到手的磁块，每次取出一个，扫一遍所有还没吸过来的磁块，能吸就入队。

while (!que.empty()) {
    cur = que.front(); que.pop();
    for (int j = 1; j <= n; j++)
        if (!vis[j] && dist[j] <= range[cur] && m[j] <= p[cur]) {
            vis[j] = true; que.push(j); ans++;
        }
}

每个磁块出队一次，每次扫 n 个，O(n²)。n 到 3 * 10⁵ 完全跑不动。

可以发现，扫全表很浪费。能不能吸由两个条件决定，一个是距离、一个是质量，只要把磁块排一排，很多判断就能成批做掉。

三、按质量排序，再分块

先把所有磁块按质量 m 从小到大排序，然后按这个顺序切成块，块长 √n。

这样切完之后，块的 m 区间是递增的：第 1 块的 m 最小，最后一块的 m 最大，而且块与块之间的 m 不交叉。

每个块内再按距离 dist 从小到大排序。记 maxm[b] 为第 b 块里最大的质量，也就是排序后块尾元素的 m。

两个排序各有各的用处：块间的 m 递增让「质量超了没有」可以整块判断，块内的 dist 递增让「距离够不够」可以顺着扫。

距离用平方和来算，吸引半径也平方，避免开根号出精度问题。

四、bfs 里的两条剪枝

取出队首磁块 cur，它有力 p[cur]、半径平方 range[cur]，然后按块号从小到大处理。

第一种情况：maxm[b] ≤ p[cur]，说明这一整块的质量都不超过当前磁力，质量这一关整块通过。

那就只需要看距离。块内按 dist 升序，从块首开始顺着取，dist ≤ range[cur] 的就吸走，一旦遇到一个 dist 超了，后面的只会更大，可以直接停。取走的用块首指针 bl[b] 往右推，整块被扫完就不会再回头。

第二种情况：maxm[b] > p[cur]，说明块里有质量超标的，只能暴力扫这一块，逐个判断距离和质量。

扫完这一块之后可以 break，不用再看后面的块。原因是块的 m 区间递增：既然第 b 块里最大的 m 都已经超过 p[cur]，那么 b 之后所有块里的所有磁块，m 都只会更大，一个也吸不动。

每个磁块出队时，整块通过的部分是均摊的（块首指针只右移），暴力扫最多发生一次，代价 O(块长)，另外还要挨个块看一眼，代价 O(块数)。

五、代码

初始磁块存在下标 0，质量设成 0，其余属性照常，这样它和普通磁块可以走同一套逻辑。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int x, y, m, p;
        long long range;
        long long dist;
    };

    bool cmp1(Node &a, Node &b) {
        return a.m < b.m;
    }

    bool cmp2(Node &a, Node &b) {
        return a.dist < b.dist;
    }

    const int MAXN = 300001;
    const int MAXB = 601;
    int n;
    Node arr[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];
    int maxm[MAXB];

    int que[MAXN];
    bool vis[MAXN];

    int bfs() {
        int ans = 0;
        vis[0] = true;
        int l = 1, r = 1;
        que[r++] = 0;
        while (l < r) {
            int cur = que[l++];
            for (int b = 1; b <= bnum; b++) {
                if (maxm[b] <= arr[cur].p) {
                    while (bl[b] <= br[b] && arr[bl[b]].dist <= arr[cur].range) {
                        int i = bl[b];
                        if (!vis[i]) {
                            vis[i] = true;
                            que[r++] = i;
                            ans++;
                        }
                        bl[b]++;
                    }
                } else {
                    for (int i = bl[b]; i <= br[b]; i++) {
                        if (arr[i].dist <= arr[cur].range && arr[i].m <= arr[cur].p && !vis[i]) {
                            vis[i] = true;
                            que[r++] = i;
                            ans++;
                        }
                    }
                    break;
                }
            }
        }
        return ans;
    }

    void prepare() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
        }
        sort(arr + 1, arr + n + 1, cmp1);
        for (int i = 1; i <= bnum; i++) {
            maxm[i] = arr[br[i]].m;
            sort(arr + bl[i], arr + br[i] + 1, cmp2);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int x, y, m, p, range;
        cin >> x >> y >> p >> range >> n;
        arr[0] = {x, y, 0, p, range, 0};
        for (int i = 1; i <= n; i++) {
            cin >> x >> y >> m >> p >> range;
            arr[i] = {x, y, m, p, range, 0};
        }
        long long xd, yd;
        for (int i = 0; i <= n; i++) {
            arr[i].range = arr[i].range * arr[i].range;
            xd = arr[0].x - arr[i].x;
            yd = arr[0].y - arr[i].y;
            arr[i].dist = xd * xd + yd * yd;
        }
        prepare();
        cout << bfs() << '\n';
        return 0;
    }

六、问题：区间逆序对

给定一个长度为 n 的排列，m 条操作，每条操作给 l、r，打印 arr[l..r] 上的逆序对数量。

1 ≤ n、m ≤ 10⁵，题目强制在线，测试链接：洛谷 P5046。

强制在线的意思是，每条操作的 l、r 是和上一次的答案异或之后才得到的，必须先回答上一条才能读下一条，莫队那种离线排序的做法用不上。

排列这个条件很好用：值域就是 1 到 n，且不重复，所以「区间里比 x 小的数有多少」可以做成值域上的前缀计数。

七、预处理四张表

按位置切成块，块长 √n 上下。然后把一次查询 [l, r] 会遇到的逆序对分成三类：散块内部、散块对整块、整块对整块。每类都预处理。

第一类，散块内部。pre[j] 是块内从块首到 j 的逆序对数，suf[j] 是块内从 j 到块尾的逆序对数。两个都用树状数组扫一遍块就能算出来。

第二类，散块对整块。cnt[b][v] 是前 b 个块里值 v 出现了多少次，这是值域上的前缀计数。于是「中间那些整块里比 arr[i] 小的数有多少」就是 cnt[rb-1][arr[i]] - cnt[lb][arr[i]]，一次查表。

第三类，整块对整块。dp[l][r] 是第 l 块到第 r 块的逆序对总数，用容斥递推：

dp[l][r] = dp[l + 1][r] + dp[l][r - 1] - dp[l + 1][r - 1] + f(l, r)

其中 f(l, r) 是第 l 块和第 r 块之间的逆序对数。两块内部都是有序副本，双指针扫一遍就是 O(块长)。

还需要一个通用的 f(x, xl, xr, y, yl, yr)，统计第 x 块下标在 [xl, xr] 内、第 y 块下标在 [yl, yr] 内的逆序对。它同时用于「左散块对右散块」和上面的 dp 递推。

合起来，一次查询是这么算的，lb、rb 是 l、r 所在的块号。

if (lb == rb) {                       // 落在同一块里
    if (l == bl[lb]) ans = pre[r];    // 正好从块首开始，直接用前缀
    else ans = pre[r] - pre[l - 1] - f(lb, bl[lb], l - 1, lb, l, r);
} else {
    ans = suf[l] + pre[r] + f(lb, l, br[lb], rb, bl[rb], r);
    for (int i = l; i <= br[lb]; i++)                   // 左散块对中间整块
        ans += cnt[rb - 1][arr[i]] - cnt[lb][arr[i]];
    for (int i = bl[rb]; i <= r; i++)                   // 中间整块对右散块
        ans += (br[rb - 1] - bl[lb + 1] + 1) - (cnt[rb - 1][arr[i]] - cnt[lb][arr[i]]);
    ans += dp[lb + 1][rb - 1];                              // 整块对整块
}

同块时有个细节：pre[r] - pre[l-1] 多算了块首到 l-1 这一段对 [l, r] 的贡献，要用 f 减掉。

跨块时左散块贡献的是「比它小的中间元素个数」，右散块贡献的是「比它大的中间元素个数」，后者用区间长度减去前者。

八、代码

代码里加了手写快读，块长取 (int)sqrt(n / 4)。

#include <bits/stdc++.h>

    using namespace std;

    char buf[1000000], *p1 = buf, *p2 = buf;

    inline char getChar() {
        return p1 == p2 && (p2 = (p1 = buf) + fread(buf, 1, 1000000, stdin), p1 == p2) ? EOF : *p1++;
    }

    inline int read() {
        int s = 0;
        char c = getChar();
        while (!isdigit(c)) {
            c = getChar();
        }
        while (isdigit(c)) {
            s = s * 10 + c - '0';
            c = getChar();
        }
        return s;
    }

    struct Node {
        int v, i;
    };

    bool NodeCmp(Node &a, Node &b) {
        return a.v != b.v ? a.v < b.v : a.i < b.i;
    }

    const int MAXN = 100001;
    const int MAXB = 701;
    int n, m;
    int arr[MAXN];
    Node sortv[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];

    int tree[MAXN];

    int pre[MAXN];
    int suf[MAXN];
    int cnt[MAXB][MAXN];
    long long dp[MAXB][MAXB];

    inline int lowbit(int i) {
        return i & -i;
    }

    inline void add(int i, int v) {
        while (i <= n) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    inline int sum(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    inline int f(int x, int xl, int xr, int y, int yl, int yr) {
        int ans = 0;
        for (int p1 = bl[x], p2 = bl[y] - 1, cnt = 0; p1 <= br[x]; p1++) {
            if (xl <= sortv[p1].i && sortv[p1].i <= xr) {
                while (p2 + 1 <= br[y] && sortv[p1].v > sortv[p2 + 1].v) {
                    p2++;
                    if (yl <= sortv[p2].i && sortv[p2].i <= yr) {
                        cnt++;
                    }
                }
                ans += cnt;
            }
        }
        return ans;
    }

    long long query(int l, int r) {
        long long ans = 0;
        int lb = bi[l], rb = bi[r];
        if (lb == rb) {
            if (l == bl[lb]) {
                ans = pre[r];
            } else {
                ans = pre[r] - pre[l - 1] - f(lb, bl[lb], l - 1, lb, l, r);
            }
        } else {
            ans = suf[l] + pre[r] + f(lb, l, br[lb], rb, bl[rb], r);
            for (int i = l; i <= br[lb]; i++) {
                ans += cnt[rb - 1][arr[i]] - cnt[lb][arr[i]];
            }
            for (int i = bl[rb]; i <= r; i++) {
                ans += br[rb - 1] - bl[lb + 1] + 1 - (cnt[rb - 1][arr[i]] - cnt[lb][arr[i]]);
            }
            ans += dp[lb + 1][rb - 1];
        }
        return ans;
    }

    void prepare() {
        blen = (int)sqrt(n / 4);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) bi[i] = (i - 1) / blen + 1;
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
        }
        for (int i = 1; i <= n; i++) {
            sortv[i].v = arr[i];
            sortv[i].i = i;
        }
        for (int i = 1; i <= bnum; i++) {
            sort(sortv + bl[i], sortv + br[i] + 1, NodeCmp);
        }
        for (int i = 1; i <= bnum; i++) {
            for (int j = bl[i]; j <= br[i]; j++) {
                cnt[i][arr[j]]++;
                if (j != bl[i]) {
                    pre[j] = pre[j - 1] + sum(n) - sum(arr[j]);
                }
                add(arr[j], 1);
            }
            for (int j = bl[i]; j <= br[i]; j++) {
                add(arr[j], -1);
            }
            for (int j = br[i]; j >= bl[i]; j--) {
                if (j != br[i]) {
                    suf[j] = suf[j + 1] + sum(arr[j]);
                }
                add(arr[j], 1);
            }
            for (int j = bl[i]; j <= br[i]; j++) {
                add(arr[j], -1);
            }
            int tmp = 0;
            for (int j = 1; j <= n; j++) {
                tmp += cnt[i][j];
                cnt[i][j] = tmp + cnt[i - 1][j];
            }
        }
        for (int l = bnum; l >= 1; l--) {
            dp[l][l] = pre[br[l]];
            for (int r = l + 1; r <= bnum; r++) {
                dp[l][r] = dp[l + 1][r] + dp[l][r - 1] - dp[l + 1][r - 1] + f(l, bl[l], br[l], r, bl[r], br[r]);
            }
        }
    }

    int main() {
        n = read();
        m = read();
        for (int i = 1; i <= n; i++) {
            arr[i] = read();
        }
        prepare();
        long long lastAns = 0;
        for (int i = 1, l, r; i <= m; i++) {
            l = read() ^ lastAns;
            r = read() ^ lastAns;
            lastAns = query(l, r);
            printf("%lld\n", lastAns);
        }
        return 0;
    }

九、复杂度分析

设 n 为序列长度，m 为操作条数，B 为块长，块数 n/B。

操作时间复杂度
磁力块：排序 + 分块O(n log n)
磁力块：bfs 总计O(n·n/B + n·B)，B = √n 时是 O(n√n)
逆序对：预处理 pre、sufO(n log n)
逆序对：预处理 cntO(n·n/B)
逆序对：预处理 dpO((n/B)² · B) = O(n²/B)
逆序对：单次查询O(B)，B = √n 时是 O(√n)

磁力块那一项，每个磁块出队时挨个块看一眼是 O(n/B)，暴力扫最多一块是 O(B)，两者各乘上出队次数 n；块首指针全程只右移，是均摊的。

逆序对的空间要留意：cnt 是块数乘值域，n/B 行、n 列，B = √n 时是 O(n√n) 个 int，这道题的数据范围下占了大部分内存。dp 是块数平方，O(n²/B²) = O(n)。

十、最后

磁力块那道题，分块提供的是「整块能不能一次性判断」这件事：质量这一关整块通过，距离这一关靠块内有序顺着扫。

区间逆序对这道题，分块提供的是分类：把一次查询切成散块和整块的组合，每种组合各自预处理，查询时只剩查表和 O(B) 的遍历。

再往后是树上分块，做法又不相同：树没有天然的连续下标，得先想办法造出一个来。
