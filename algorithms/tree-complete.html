完全二叉树：验证与节点计数

验证一棵树是不是完全二叉树，再在低于 O(n) 的时间里数出完全二叉树的节点个数。两题都靠完全二叉树「最后一层从右往左缺」这条性质。

零、背景

完全二叉树的定义：除了最后一层，每一层都是满的；最后一层的节点全部靠左。满二叉树是完全二叉树的特例，最后一层也满。

这个定义给两个抓手：层序扫一遍能验证，递归看左右子树高度能数节点。本节两题一前一后，正好把两个抓手都用上。

节点定义沿用前面的课，带构造器。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

一、验证完全二叉树（LeetCode 958）

层序 BFS 扫一遍，每遇到一个「左右不双全」的节点，把它之后的所有节点都必须是叶子。

记一个布尔 leaf：遇到缺孩子的节点，leaf 置真；之后只要还有节点带着孩子，就说明最后一层没有靠左排列，返回 false。

另外单独判一种情况：左孩子为空、右孩子不空，这棵树已经不可能靠左，直接返回 false。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 验证完全二叉树（LeetCode 958）
    // BFS 按层走。一旦遇到一个「左右不双全」的节点，之后所有节点都必须是叶子
    // （不能再有孩子），否则不是完全二叉树
    bool IsCompleteTree(TreeNode* h) {
        if (h == nullptr) {
            return true;
        }
        vector<TreeNode*> q;
        q.push_back(h);
        // 是否遇到过左右两个孩子不双全的节点
        bool leaf = false;
        for (int l = 0, r = 1; l < r;) {
            h = q[l++];
            // 情况一：左空右不空，直接不是
            // 情况二：已经进入叶子阶段，这个节点还有孩子，也不是
            if ((h->left == nullptr && h->right != nullptr) ||
                (leaf && (h->left != nullptr || h->right != nullptr))) {
                return false;
            }
            if (h->left != nullptr) {
                q.push_back(h->left);
                r++;
            }
            if (h->right != nullptr) {
                q.push_back(h->right);
                r++;
            }
            if (h->left == nullptr || h->right == nullptr) {
                leaf = true;
            }
        }
        return true;
    }

两处 false 别混：一个是「结构上右重左轻」当场判掉，一个是「见过缺口之后又见孩子」事后判掉。完整写法是 BFS 每出队一个节点就检查 leaf 是否已被置位。

时间 O(n)、空间 O(n)。

二、完全二叉树的节点数（LeetCode 222）

普通树数节点只能 O(n) 遍历。完全二叉树多了结构，可以走 O(log² n)：每次都砍掉一半的子树，只递归另一半。

记整棵树高 h（一直沿左走到底）。看根节点右子树的「最左节点」能扎到多深：

第一种情况，右子树最左节点扎到了最深层，深度 = h。这说明左子树是满的，高度 h-1，节点数 2h-1 − 1，直接算出来，只递归右子树。

第二种情况，右子树最左节点没到最深层，深度 = h-1。这说明右子树是满的，高度 h-2，节点数 2h-2 − 1，只递归左子树。

两种分支都是「一棵满子树直接算 + 另一棵递归」，每次递归树高减 1，而每层算满子树又花 O(树高) 数最左路径，总代价 O(log² n)。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 求完全二叉树的节点个数，时间复杂度低于 O(n)（LeetCode 222）
    // h 是整棵树的高度（从 1 开始数层）
    // 每走一步，看 cur 的右子树最左节点能不能扎到最深层：
    //   能 → cur 的左子树是满的，2^(h-level) 个节点直接算，只递归右子树
    //   不能 → cur 的右子树是满的（高度少一层），只递归左子树
    // 每层只走一条路，每步要 O(log n) 数最左深度，总 O(log² n)
    int CountNodes(TreeNode* head) {
        if (head == nullptr) {
            return 0;
        }
        return F(head, 1, MostLeft(head, 1));
    }

    // cur 当前在 level 层，h 是整棵树的高度
    // 返回 cur 这棵子树上的节点数
    int F(TreeNode* cur, int level, int h) {
        if (level == h) {
            return 1;   // 到了最后一层，只有 cur 自己
        }
        if (MostLeft(cur->right, level + 1) == h) {
            // 右子树的最左节点扎到了最深层 → 左子树是满二叉树，高度 h-level
            return (1 << (h - level)) + F(cur->right, level + 1, h);
        } else {
            // 右子树没扎到最深层 → 右子树是满二叉树，高度 h-level-1
            return (1 << (h - level - 1)) + F(cur->left, level + 1, h);
        }
    }

    // cur 在第 level 层，一直往左走，返回能扎到的最大层数
    int MostLeft(TreeNode* cur, int level) {
        while (cur != nullptr) {
            level++;
            cur = cur->left;
        }
        return level - 1;
    }

满二叉树节点数 2h − 1 是这题的地基，先记住它。这里的 h 是层数不是高度：MostLeft(head, 1) 从第 1 层开始沿左走，单节点树返回 1，节点数 2¹ − 1 = 1。习惯把高度从 0 数的人在这容易差 1，写 (1 << h) 之前先确认 h 是几层。

四、总结

验证题的核心是一个布尔：leaf 一旦置位，后面谁都别想带孩子。这是「最后一层靠左」的等价刻画。

计数题的核心是左右子树至少一棵满：用右子树最左节点的深度判断哪边满，满的那边 2层 − 1 直接算，另一边递归。

两题凑一起看，完全二叉树的两种性质正好各用一遍：层序顺序验证形状，子树高度计算规模。

下一节讲离散化：把稀疏的大值域压成稠密的小下标，树状数组和线段树都靠它把值域换成 O(n)。
