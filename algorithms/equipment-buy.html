装备购买：向量空间的线性基

属性向量可以乘任意实数系数组合，异或线性基那一套「位」的直觉在这里失效，但高斯消元的思想原样搬过来就能用。

零、问题

n 个物品，每个有 m 个属性值。一个物品是「不必要」的：如果给已选的物品分配一组系数，把属性值按系数相加能凑出它。a = {4, 6, 2}、b = {2, 8, 4}、c = {6, 19, 9}，因为 a × 0.5 + b × 2 = c，所以只要买了 a 和 b，c 就是不必要的。

要买尽量多的物品，且不出现不必要的物品，问最多买几件、最少花多少钱。属性 ≤ 1000、n、m ≤ 500。

一、向量空间的线性基

异或空间的系数只有 0 和 1，这里是任意实数。线性相关、线性无关、线性基这些概念照旧：一组物品线性无关，当且仅当没有任何一个能被其它物品的实数组合表示。「组合内不出现不必要物品」和「选出的属性向量线性无关」是同一件事。

建基的办法和异或空间一样是逐列消元，只是把异或换成实数减法：扫到第 j 个属性非 0，如果这一列还没有主元就占下，否则用已有的主元行把这一列的系数消成 0。消到末尾还非 0，说明这个向量不在前面的空间里，插入成功。

精度用容差判断：绝对值小于 1e-5 就当 0，属性是整数、n、m 才 500，double 足够。

二、贪心：价格升序，能插就买

目标是数量优先、花费次之。线性无关集合构成拟阵，任何两个最大独立集大小相同（都是向量空间维度 r），所以先保证数量：按价格升序逐个试插入，插入成功就买。

这个顺序同时保证花费最小：升序贪心等价于「在所有大小为 r 的独立集里挑价格和最小的那个」，标准拟阵贪心。

// 向量空间线性基：实数消元，插不进去说明线性相关
    bool insert(int i) {
      for (int j = 1; j <= m; j++) {
        if (fabs(mat[i][j]) >= sml) {
          if (basis[j] == 0) {
            basis[j] = i;
            return true;
          }
          double rate = mat[i][j] / mat[basis[j]][j];
          for (int k = j; k <= m; k++) {
            mat[i][k] -= rate * mat[basis[j]][k];
          }
        }
      }
      return false;
    }
// 装备购买：按价格升序逐个尝试，能插入就买
    int cnt = 0, cost = 0;
    sort(mat.begin() + 1, mat.end(), [&](const vector<double>& a, const vector<double>& b) {
      return a[m + 1] < b[m + 1];
    });
    for (int i = 1; i <= n; i++) {
      if (insert(i)) {
        cnt++;
        cost += (int)mat[i][m + 1];
      }
    }

排序 O(n log n)，插入每个物品扫 m 列、每列可能消 m 个数，总 O(n × m²)。n、m ≤ 500 直接跑。

四、总结

实数系数让「位」失效，但线性基的本质是向量空间：逐列找主元、消元、判定线性无关。装备购买题把「最多且最便宜」化成拟阵贪心，价格升序逐个试插入一次到位。实现上的坑是浮点容差：别拿 == 0 判断，属性再整也要留 1e-5 的余量。
