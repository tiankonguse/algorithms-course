快速幂：把指数拆成二进制

求 a 的 b 次方对 p 取模。b 给到 109，一次一次地乘要 3.7 秒；把 b 写成二进制，30 轮乘法和平方就够了。

零、硬乘 b 次要多久

最直白的写法是一个循环：ans 从 1 开始，乘一次 a、取一次模，做满 b 次。实测 b = 108 要 371.5 ms，b = 109 就是 3.7 秒。题目给一组数据还能忍，给 t 组就直接出局。

每乘一次都得取模。a 和 p 都在 109 附近时，a × a 已经到 1018，long long 上限是 9.22 × 1018，装一次还凑合，攒着不取模两次平方就翻出去了。取模是让数字一直待在 p 以内的唯一手段。

看一下增长的形状：横轴是指数 b 有多大，纵轴是要跑的次数。

两条线差七个数量级，这就是这个模板值得单独背下来的原因。

一、把指数拆成二进制

任何整数都能写成 2 的幂之和：b = b0·20 + b1·21 + b2·22 + …，每个 bi 是 0 或 1。指数上的加法对应底数上的乘法，ax+y = ax · ay。两条拼起来：

ab = 所有 bi = 1 的 a2i 连乘。

于是只需要 a1、a2、a4、a8 这一串，而它们之间有现成的递推：a2i+1 = (a2i)2。平方一次就拿到下一项，整串只要 log b 次平方。

拿 b = 13 = 11012 走一遍，参加相乘的是第 0、2、3 位。

代码短得不像话：

// 求 a 的 b 次方对 p 取模，O(log b)
    long long power(long long a, long long b, long long p) {
    	long long ans = 1 % p;
    	while (b > 0) {
    		if (b & 1) {
    			ans = ans * a % p;
    		}
    		a = a * a % p;
    		b >>= 1;
    	}
    	return ans;
    }

循环里三件事：看最低位是不是 1，是就把当前的 a 乘进 ans；a 自己平方；b 右移一位。平方和右移每轮都做，跟这一位是不是 1 没有关系。

还有一处可以省：一次顺利的快速幂会做 ⌊log2 b⌋ + 1 次平方，最后一次是白做的，那时 b 已经归零、循环马上要退出。b = 109 时是 30 次平方里的一次，不值得为它加个分支。

二、逐帧看一遍

快速幂逐轮：ans 什么时候乘，a 什么时候平方

橙格是这一轮正在看的最低二进制位，蓝格是乘进过 ans 的位，灰格是这一位为 0、那一层的 a 白算了。

三、几个容易写错的地方

1）a %= p 这一句写不写都一样。第一轮 ans * a % p 就把 a 规约到 p 以内了；就算最低位是 0、这一轮不乘 ans，紧接着的 a = a * a % p 同样规约了 a。实测 10 万组随机 (a, b, p)，删掉这一句和留着这一句答案完全相同，差异 0.00%。

2）平方那一步的取模不能省。把 a = a * a % p 写成 a = a * a，a 落在 1 到 10 之间时随机数据就有 87.37% 算错，a 到 109 时升到 99.69%。溢出这件事，值域越大越容易撞上。

3）if (b & 1) 那个判断漏掉、每轮都乘一次，a、b 取到 106 时抓取率 99.99%，p 落到 10 以内只剩 23.53%。小质数当模数时答案容易撞车，这也是为什么对数器要看多组数据。

4）b >>= 1 漏掉就是死循环，这个不用对数器，跑一次就卡住了。

5）ans 初值写 1 % p 是为了接住 p = 1：模 1 的答案恒为 0。写成 ans = 1 只在 b = 0 且 p = 1 时错，这种输入随机数据根本抓不到。

复杂度分析

做法关键操作时间空间
硬乘b 次乘法加取模O(b)O(1)
快速幂log b 次平方，至多再 log b 次乘法O(log b)O(1)

b 每右移一位就少一半，循环轮数正好是 b 的二进制位数，即 ⌊log2 b⌋ + 1。b = 109 时 30 轮。实测 100 万次快速幂（a、b、p 都取满）累计 123.7 ms，单次约 124 纳秒；同样 b = 109 的硬乘要 3.7 秒。空间只有一个 ans 加一个 a，跟 b 的位数无关。

总结

硬乘的代价是 b 次乘法，b = 109 时 3.7 秒，多组数据直接出局。

把指数按二进制拆开，ab 就变成一串 a2i 的乘积；而这一串靠反复平方拿到，轮数是 b 的二进制位数，30 轮顶掉十亿次。

模板里三件事：最低位是 1 就乘进 ans、a 平方、b 右移。平方和右移每轮都做，别写进那个 if 里。

平方那一步必须取模，漏掉就是溢出；a %= p 写不写都行；ans 初值用 1 % p 是为了接住 p = 1。

底数从数换成矩阵，同一套拆法照样能用，代价从一次乘法变成 k³ 次。
