跑路：倍增合并可达性

每秒可以移动 2^p 公里，p 每秒钟随便选。问 1 号点到 n 号点最少几秒。把「长度恰为 2^p 的路径」用倍增并起来，得到一张每条边都只花 1 秒的秒图，再跑最短路。

零、背景

n 个点 m 条有向边，每条边 1 公里。有一个空间跑路器，每秒可以直接移动 2^p 公里，p 在每秒开始时随便定。题目保证 1 到 n 一定能到达，问最少用几秒。n ≤ 50，m ≤ 10⁴，p ≤ 64。

直接模拟「每秒走到哪」不行：一秒能走的距离是 2^p，p 可以到 64，距离远超 2^63，状态存不下。要换一个角度看：一秒能走 2^p 公里，等价于「存在一条长度恰为 2^p 的路径」。

一、st[i][j][p]：长度恰为 2^p 的路径存在吗

st[i][j][p] 记 i 到 j 是否存在长度恰为 2^p 的路径。p = 0 时就是「i 到 j 有没有一条 1 公里的边」，直接读输入。

更长的怎么来？长度 2^p 的路径，可以拆成两段长度 2^(p−1) 的路径，中间过某个跳板 jump：st[i][j][p] = 存在 jump 使 st[i][jump][p−1] 且 st[jump][j][p−1]。三层循环枚举 jump、i、j，一次把整个 p 层算完。这就是 Floyd 式的倍增合并，和预处理里 Floyd 的写法一脉相承。

二、秒图 + 最短路

只要 st[i][j][p] 为真，从 i 到 j 就只花 1 秒，因为这一秒直接跳 2^p 公里。于是得到一张秒图：i 到 j 有一条权 1 的边，当且仅当存在某个 p 使 st[i][j][p] 为真。原边（2^0 = 1 公里）天然在这张图里。

秒图上从 1 到 n 的最短路就是答案。用 Floyd 求：先枚举跳板，再枚举每一组 (i, j)，dist[i][j] = min(dist[i][j], dist[i][jump] + dist[jump][j])。秒图上的每步都是一秒，最短路的边数就是秒数。

秒图逐步长出来：p 增大，一秒能跳更远

三、代码

倍增合并枚举顺序是次方 → 跳板 → (i, j)，保证 p 层完全由 p−1 层推出。合并时顺手把 dist_ 设成 1，最后跑一遍 Floyd：

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 61;
    const int MAXP = 64;           // 一秒最多跳 2^64 公里
    const int NA = INT_MAX;
    // st[i][j][p] : i 到 j 是否存在长度恰为 2^p 的路径
    bool st[MAXN][MAXN][MAXP + 1];
    // dist_[i][j] : i 到 j 的最少秒数
    int dist_[MAXN][MAXN];
    int n, m;

    int Compute() {
        // 倍增合并：长度 2^p 的路径 = 两段长度 2^(p-1) 的路径，中间过跳板 jump
        for (int p = 1; p <= MAXP; p++) {
            for (int jump = 1; jump <= n; jump++) {
                for (int i = 1; i <= n; i++) {
                    for (int j = 1; j <= n; j++) {
                        if (st[i][jump][p - 1] && st[jump][j][p - 1]) {
                            st[i][j][p] = true;
                            dist_[i][j] = 1;   // 跳 2^p 公里只花 1 秒
                        }
                    }
                }
            }
        }
        // 秒图建好：dist_ 里有值的边都是一秒。Floyd 求 1 到 n 的最少秒数
        for (int jump = 1; jump <= n; jump++) {
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= n; j++) {
                    if (dist_[i][jump] != NA && dist_[jump][j] != NA) {
                        dist_[i][j] = min(dist_[i][j], dist_[i][jump] + dist_[jump][j]);
                    }
                }
            }
        }
        return dist_[1][n];
    }

四、复杂度分析

倍增合并：p 有 65 层（0 到 64），每层枚举 jump、i、j 各 n 次，O(65 × n³)；Floyd O(n³)。n ≤ 50 时完全无压力。空间：st 是 n × n × 65 的布尔表，O(65 × n²)。

五、总结

要点：一秒跳 2^p 公里，别去枚举距离，改成记「长度恰为 2^p 的路径存不存在」；两段 2^(p−1) 拼一段 2^p，中间找个跳板，就是 Floyd 式倍增；合并完得到权全为 1 的秒图，剩下的交给最短路。看到「每次走 2 的幂」「步数上限很小、单步距离巨大」的题，先想能不能按次方分层合并。
