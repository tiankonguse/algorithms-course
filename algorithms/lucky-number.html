幸运数字：树上倍增与线性基

树上一条路径，路径上的点权随便选，异或和最大是多少。线性基本来只和集合有关，但路径是「深度 ≥ LCA 的点」这个集合，得给每个基记上它来自哪层，才能把树砍成两段。

零、问题

n 个点连成一棵树，每个点有数字，q 次查询：a 到 b 路径上的点，随意选择数字，求最大异或和。n ≤ 2 × 104、q ≤ 2 × 105、点权 ≤ 260。

路径是 x 到 LCA 再到 y 的一串点。直接想法：把路径上所有点的数字倒进一个线性基，求最大异或。但路径长 O(n)，q 次查询 O(nq) 不行。要预处理每个点「到根的线性基」，查询时把 x 段和 y 段拼起来。

一、带深度的线性基

每个点 u 维护 bases[u]：从根到 u 这条路径上所有点权组成空间的线性基。只存基还不够，查询时 x 段的基里可能有「深度比 LCA 浅」的点（不在路径上），要能用深度过滤。

于是每个基多记一个 level：它最早来自哪个深度的点。插入时如果新数更深，就把它和已有基交换：更深的数优先占位。这样 level[i] 永远是「能代表这个基位的最深来源」。

bases[u] 从父亲继承一份，再把 u 自己的数字插进去。对每个 u 这样做，全树一遍 DFS 就能建完，查询时 x、y 两段的基都现成。

二、查询：深度过滤 + 合并

lca = LCA(x, y)。x 侧基里 level ≥ deep[lca] 的基直接放进全局基（每个位一个，不冲突）；y 侧基里同样过滤后逐个插入（可能和 x 侧的基线性相关，要重新消）。合出来的全局基就是路径上点权的线性基，从高到低贪心取最大异或和。

// 带深度的线性基插入：更深的数优先占基位
    bool insertReplace(ll curv, int curl, ll* basis, int* level) {
      for (int i = BIT; i >= 0; i--) {
        if (curv >> i == 1) {
          if (basis[i] == 0) {
            basis[i] = curv;
            level[i] = curl;
            return true;
          }
          if (curl > level[i]) {
            swap(curv, basis[i]);
            swap(curl, level[i]);
          }
          curv ^= basis[i];
        }
      }
      return false;
    }
// 树上倍增：bases[u] 是根到 u 路径上点的线性基（每个基记深度）
    void dfs(int root) {
      stackSize = 0;
      push(root, 0, -1);
      while (stackSize > 0) {
        pop();
        if (e == -1) {
          deep[u] = deep[f] + 1;
          stjump[u][0] = f;
          for (int p = 1; p <= power; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
          }
          for (int i = 0; i <= BIT; i++) {
            bases[u][i] = bases[f][i];
            levels[u][i] = levels[f][i];
          }
          insertReplace(arr[u], deep[u], bases[u], levels[u]);
          e = head[u];
        } else {
          e = next[e];
        }
        if (e != 0) {
          push(u, f, e);
          if (to[e] != f) push(to[e], u, -1);
        }
      }
    }
// 查询：深度不小于 LCA 的基才有效，x 侧直接放、y 侧逐个插入
    ll query(int x, int y) {
      int lc = lca(x, y);
      memset(basis, 0, sizeof(basis));
      for (int i = BIT; i >= 0; i--) {
        ll num = bases[x][i];
        if (levels[x][i] >= deep[lc] && num != 0) basis[i] = num;
      }
      for (int i = BIT; i >= 0; i--) {
        ll num = bases[y][i];
        if (levels[y][i] >= deep[lc] && num != 0) {
          for (int j = i; j >= 0; j--) {
            if (num >> j == 1) {
              if (basis[j] == 0) { basis[j] = num; break; }
              num ^= basis[j];
            }
          }
        }
      }
      ll ans = 0;
      for (int i = BIT; i >= 0; i--) ans = max(ans, ans ^ basis[i]);
      return ans;
    }

预处理 O(n × 60²)（每个点复制 + 插入 60 位），查询 O(60²)（LCA O(60) + 合并 60 位）。树的 DFS 用迭代栈写，递归在 C++ 上会爆栈。

四、总结

幸运数字把线性基和树上倍增接起来：每个点存「到根的带深度线性基」，插入时深的数优先占位，查询按 LCA 深度过滤后合并两段。O(n × 60²) 预处理换 O(q × 60²) 查询，2 × 105 次查询直接跑。这个「带深度的基」是树上线性基题的标准零件，路径端点、子树、换根变体都在这上面改。
