高斯消元解加法方程组：判唯一解与严格三分

n 个变量、n 个方程，解不出来的时候要分清是「矛盾」还是「多解」，这两句话的区别藏在一列的主元上。本节讲高斯消元解加法方程组的两个模板：一个只回答「有没有唯一解」，一个把矛盾、多解、唯一解严格分开。

零、增广矩阵与主元

加法方程组长这样：

1·x1 + 2·x2 - 1·x3 = 9

2·x1 - 1·x2 + 2·x3 = 7

1·x1 - 2·x2 + 2·x3 = 0

把系数和常数拼在一起，就是增广矩阵：n 行，每行 n 个系数、第 n+1 列是常数。

高斯消元在两个动作里循环：

1）选主元。第 i 列选一个「绝对值最大的行」当基准行，换到第 i 行。绝对值大是为了数值稳定：后面要拿主元做除法，主元太小会把舍入误差放大。

2）消元。主元行除以主元，让主元变成 1；再用主元行消掉其他所有行的第 i 列，让这一列只剩主元行上有数。

还有一条判断句：double 有精度问题，0.0000001 这种数其实是 0。代码里用 sml = 1e-7 当阈值，绝对值小于它的数一律当 0 看。主元当 0 意味着这一列找不到基准，对应的变量是自由元，自由元一出现，方程组就回答不了唯一解。

一、模板一：只问有没有唯一解

第一题要求：有矛盾或无法确定唯一解就打印 No Solution，有唯一解就把每个变量保留两位小数打出来。

写法很直接：每一列选绝对值最大的行，换上来；主元接近 0，直接返回 0（没有唯一解，矛盾和多解在这里都算 No Solution）；否则归一化、全行消去。n 列处理完，每行最后一列就是对应变量的解。

#include <bits/stdc++.h>
    using namespace std;

    // 高斯消元模板一：只区分「有唯一解 / 没有」
    // sml 是 double 的精度阈值：绝对值小于它的数一律当作 0
    const double sml = 1e-7;
    double mat[102][102];  // mat[i][j]：第 i 个方程第 j 个未知数的系数，j = n+1 是常数
    int n;

    void swapRows(int a, int b) {
      for (int j = 1; j <= n + 1; j++) {
        swap(mat[a][j], mat[b][j]);
      }
    }

    // 返回 1 表示有唯一解，返回 0 表示矛盾或无法确定唯一解
    int gauss(int n) {
      for (int i = 1; i <= n; i++) {
        // 当前列绝对值最大的行当主元行，数值上最稳
        int max = i;
        for (int j = i + 1; j <= n; j++) {
          if (fabs(mat[j][i]) > fabs(mat[max][i])) {
            max = j;
          }
        }
        swapRows(i, max);
        // 主元接近 0：这一列找不到主元，方程组没有唯一解
        if (fabs(mat[i][i]) < sml) {
          return 0;
        }
        double tmp = mat[i][i];
        for (int j = i; j <= n + 1; j++) {
          mat[i][j] /= tmp;
        }
        // 用主元行消去其他所有行的当前列
        for (int j = 1; j <= n; j++) {
          if (i != j) {
            double rate = mat[j][i] / mat[i][i];
            for (int k = i; k <= n + 1; k++) {
              mat[j][k] -= mat[i][k] * rate;
            }
          }
        }
      }
      return 1;
    }

主元接近 0 时模板一直接返回，它不区分矛盾和多解。这叫「只问有没有」：没有唯一解就统一回答 No Solution，P3389 的判题标准正是这样。

二、模板二：矛盾、多解、唯一解严格三分

第二题要求更细：矛盾打印 -1，无法确定唯一解打印 0，唯一解打印每个变量。模板一在这个要求下不够用，它有三个地方必须改。

1）选主元时，跳过已经确定主元的行。模板一从第 i+1 行开始扫，模板二从第 1 行扫到第 n 行，但前面主元非 0 的行不参与竞争：j < i 且 mat[j][j] ≥ sml 的行直接 continue。

2）主元为 0 时不消。主元为 0 说明这一列是自由列，这行保留原样，留到最后判定。

3）消元结束后统一判定：主元为 0 且常数非 0 的行是矛盾（0 = 非 0 的数，不可能）；主元为 0 的行是多解（自由元）；全部主元非 0 才是唯一解。

#include <bits/stdc++.h>
    using namespace std;

    // 高斯消元模板二：严格区分矛盾、多解、唯一解
    // 主元为 0 的那一行不消，留到最后统一判定
    const double sml = 1e-7;
    double mat[102][102];
    int n;

    void swapRows(int a, int b) {
      for (int j = 1; j <= n + 1; j++) {
        swap(mat[a][j], mat[b][j]);
      }
    }

    void gauss(int n) {
      for (int i = 1; i <= n; i++) {
        int max = i;
        for (int j = 1; j <= n; j++) {
          // 前面已经确定主元的行，不再参与选主元
          if (j < i && fabs(mat[j][j]) >= sml) {
            continue;
          }
          if (fabs(mat[j][i]) > fabs(mat[max][i])) {
            max = j;
          }
        }
        swapRows(i, max);
        if (fabs(mat[i][i]) >= sml) {
          double tmp = mat[i][i];
          for (int j = i; j <= n + 1; j++) {
            mat[i][j] /= tmp;
          }
          for (int j = 1; j <= n; j++) {
            if (i != j) {
              double rate = mat[j][i] / mat[i][i];
              for (int k = i; k <= n + 1; k++) {
                mat[j][k] -= mat[i][k] * rate;
              }
            }
          }
        }
      }
    }
#include <bits/stdc++.h>
    using namespace std;

    // 消元结束后统一判定：
    // 主元为 0 的那一行，常数非 0 是矛盾，常数是 0 是多解
    const double sml = 1e-7;
    double mat[102][102];
    int n;

    int check() {
      int sign = 1;
      for (int i = 1; i <= n; i++) {
        if (fabs(mat[i][i]) < sml && fabs(mat[i][n + 1]) >= sml) {
          sign = -1;  // 矛盾
          break;
        }
        if (fabs(mat[i][i]) < sml) {
          sign = 0;   // 多解
        }
      }
      return sign;
      // sign = 1：唯一解，解就存在 mat[i][n + 1]
      // sign = 0：多解
      // sign = -1：矛盾
    }

判定的顺序有讲究：先看主元为 0 且常数非 0（矛盾，直接 -1），再看主元为 0（多解）。矛盾比多解优先，因为 0x = 5 这种行一旦出现，整个方程组无解，跟自由元几个无关。

三、冗余、不足与 0 系数行

方程个数和变量个数相等，不代表每行都有用。课上例子覆盖了几种边界，模板二都能接住：

表达式冗余：4 个方程、3 个变量，补一个全 0 行凑成 4×4。冗余的那行被消元后变成 0 = 0，主元为 0，判多解；如果冗余行的常数对不上（4x - 2y + 4z = 10 和 2x - y + 2z = 7 同比例但常数不等），消完后是 0 = 非 0，判矛盾。

表达式不足：2 个方程、3 个变量，补 0 行。少一个方程就少一个主元，判多解；两个方程本身打架（2x + 4y - 2z = 7 与 x + 2y - z = 5 成比例但常数不等）判矛盾。

0 系数行：0·x + 2·y = 3、0·x + 0·y = 0。第二行主元为 0、常数 0，判多解；y 有确定值 1.5，x 是自由元。

四、复杂度

三层循环各扫 n 行，模板一和模板二都是 O(n3)。n 是消元时的方程个数，表达式冗余时按补行后的个数算。

五、总结

这一节的两个模板差在三点：选主元时跳过不跳过已定主元的行、主元为 0 时消不消、判定时矛盾和多解分不分开。模板一回答「有没有唯一解」，模板二回答「是矛盾还是多解还是唯一解」。做高斯消元的题，先想清楚判题标准要哪一种，再决定用哪个模板。下一节（球形空间的中心点）和再下一节（错误称重）都复用这里的模板，区别只在方程怎么构造。
