划分链表

上一讲两个链表相加，结果里的节点全是 new 出来的。这一讲反过来：一个节点都不 new，把输入链上的节点原地重排，小于 x 的靠前，大于等于 x 的靠后，两段内部的顺序一个都不许动。

零、背景

链表题目在笔试、面试中的意义就是检验 coding 能力：思路一分钟讲完，代码能不能一遍写对才是分水岭。

这题还是快排里 partition 思路的链表版，但快排的 partition 靠交换，这题要求稳定。两条要求叠在一起：小于 x 的在前，大于等于 x 的在后，两段内部保持原始相对顺序。

一、问题

给一个链表的头节点 head 和一个特定值 x，把链表分隔，使得所有小于 x 的节点都出现在大于等于 x 的节点之前，并保留两个分区中每个节点的初始相对位置。原题是 86. 分隔链表。

样例：1→4→3→2→5→2，x = 3。小于 3 的有 1、2、2，大于等于的有 4、3、5。答案是 1→2→2→4→3→5。

注意两个 2：输入里第一个 2 在第二个 2 前面，结果里还是。4 和 3 也一样，4 在输入里靠前，结果里还是靠前。这就是「初始相对位置」。

二、先试试偷懒的写法：拷进数组

如果允许开数组，这题两分钟写完：扫一遍链表，值小于 x 的放进一个数组，其余放进另一个数组，再把两个数组接回一条链。代码短，样例过，答案对。

但它没练到链表。链表题要考的是原地调整：节点一个不 new，把输入链上的 next 指针重新指一遍。数组版多花了 O(n) 空间，恰好是这题想省的东西。

ListNode* partitionNaive(ListNode* head, int x) {
        vector<ListNode*> left, right;
        for (ListNode* p = head; p != nullptr; p = p->next) {
            if (p->val < x) left.push_back(p);
            else right.push_back(p);
        }
        for (int i = 0; i + 1 < (int)left.size(); i++) {
            left[i]->next = left[i + 1];
        }
        if (!left.empty()) {
            left.back()->next = right.empty() ? nullptr : right[0];
        }
        for (int i = 0; i + 1 < (int)right.size(); i++) {
            right[i]->next = right[i + 1];
        }
        if (!right.empty()) {
            right.back()->next = nullptr;
        }
        return left.empty() ? (right.empty() ? nullptr : right[0]) : left[0];
    }

这段代码正确，但把链表当数组用了。真正要练的是下面这种。

三、双区尾插

原地做法维护两套头尾指针：leftHead、leftTail 管小于 x 区，rightHead、rightTail 管大于等于 x 区。扫描原链，每遇到一个节点，先把 next 存下来，再断开 head->next，按值挂到对应区的尾部。

struct ListNode {
        int val;
        ListNode* next;
        ListNode(int v) : val(v), next(nullptr) {}
    };

    ListNode* partition(ListNode* head, int x) {
        ListNode* leftHead = nullptr;   // < x 的区域
        ListNode* leftTail = nullptr;
        ListNode* rightHead = nullptr;  // >= x 的区域
        ListNode* rightTail = nullptr;
        ListNode* next = nullptr;
        while (head != nullptr) {
            next = head->next;
            head->next = nullptr;
            if (head->val < x) {
                if (leftHead == nullptr) {
                    leftHead = head;
                } else {
                    leftTail->next = head;
                }
                leftTail = head;
            } else {
                if (rightHead == nullptr) {
                    rightHead = head;
                } else {
                    rightTail->next = head;
                }
                rightTail = head;
            }
            head = next;
        }
        if (leftHead == nullptr) {
            return rightHead;
        }
        leftTail->next = rightHead;
        return leftHead;
    }

为什么先存 next？确实，不存也行，只要你能保证后面的链不被弄丢。head->next 马上要被改写，改完就找不回原后继了，所以先拿一个变量接住。这和上一讲反转链表先存 next 是同一个动作。

挂的过程只有两种：区空，节点当区头；区不空，接在区尾后面。然后尾指针挪到新节点。四行 if 处理完一个节点，扫完整个链，最后把左区尾接到右区头。

四、稳定从哪来

尾插天然稳定。扫描顺序就是输入顺序，每个节点都挂在区尾，区内的先后就是扫描到的先后，不用额外记任何东西。

对比快排的 partition：两个指针相向交换，换着换着顺序就乱了，所以快排不稳定。这题全程只有尾插、没有交换，两段内部的相对顺序一条都不动。

五、三个边界

  • 左区空：所有节点都大于等于 x，直接返回 rightHead。
  • 右区空：leftTail->next = rightHead = nullptr，等于白接一下。
  • 空链表：循环不跑，leftHead 空，返回 rightHead（也是空）。

拼接那步 leftTail->next = rightHead 只会执行一次。成不了环：每个节点的 next 在挂入前都被断开过，最后只有区尾的 next 被重接。

六、复杂度分析

写法时间额外空间
拷进数组再重建O(n)O(n)，两个数组
双区尾插（原地）O(n)O(1)，四个指针

时间上没有优化空间，每个节点至少要被看一次。省下的在空间：不建新节点，结果链上的每个节点都是输入链上的原节点。

写完之后想验证「稳定」这条，把每个节点带上原始下标跑一遍对数器（005 那讲），随机数据刷几百组，重点看两件事：结果链长度没变，且两段内部的下标递增。下面这个演示可以当对照组，随机刷几轮，看两个相等的值顺序动不动。

七、最后

链表划分就一句话：扫描一遍，按值尾插到两个区的末尾，一个节点都不 new。稳定不是碰巧：尾插让区内的先后等于扫描的先后，两段内部顺序自然保住。

三个边界写代码时容易漏：左区空直接返回右区头，右区空时 leftTail->next 白接一下空指针，空链表直接返回空。拼接那步只会执行一次，成环的担忧不存在，每个节点的 next 在挂入前都被断开过。

原地写法的四个指针指向的都是输入链上的原节点，时间 O(n)、额外空间 O(1)；拷数组写法同样 O(n)，但要多开两个数组。下一讲队列和栈，容器里照样是「指针 + 下标」这一套。
