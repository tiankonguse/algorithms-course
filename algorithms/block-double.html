双层分块

分块再叠一层：位置分块之外，值域上也分一块。这一讲两道题，一道是「区间改值 + 区间第 k 小」，一道是「单点改值 + 区间里最大值不超过 v 的子数组计数」。两道题的共同点是查询要同时用到位置信息和值域信息，一层分块撑不住，得把值域也切开。

零、背景

分块的基本形态是：位置分块，整块打标记，零散部分暴力。这个形态只在「整块的信息能用一个标记概括」时成立，比如区间加、区间求和，标记是一个数。

换成「区间第 k 小」就不行了。整块打标记之后，你还是不知道这个块里有多少个数 ≤ mid，只能进到块内去数。于是值域上再分一层：值 1 到 V 按长度 B 切成 V/B 个值域块，每个序列块维护「落在每个值域块里各有多少个数」。查询时先在值域块的粒度上跳，一整块用计数直接扣掉 k，跳进目标块后再在块内逐个值扫过去。

外层管位置，内层管值，这就是双层分块。两层的块长可以不同，下面两道题的取法也不一样，一个取 300，一个取 512。

一、题目1：未来日记

给定一个长度为 n 的数组，m 条操作。操作 1 把 arr[l..r] 里所有值 x 变成值 y；操作 2 查询 arr[l..r] 里的第 k 小。n、m、值域都是 10⁵ 量级。测试链接：洛谷 P4119。

先看只做一层分块能到哪。每个块维护排序后的副本，改值时在块内二分定位再插入删除，代价 O(块长)；查询第 k 小二分答案，每次判定要统计 ≤ mid 的个数，对每个整块二分一次。n = 10⁵、块长 300 时，一次查询是 17 次二分 × 334 个块 × 块内二分 8 次，约 4.5 万次比较，乘 10⁵ 次查询远远超。

值域上分块之后，判定这一步被换成「值域块粒度扫 + 块内扫」，一次查询只要 V/B + B ≈ 634 次，两个 log 都去掉了。

二、双层结构怎么搭

序列块长 300，值域块长也取 300。因为 n 和值域同阶，代码里索性复用同一个 bi[]：bi[i] = (i-1)/300 + 1，位置 i 用它算序列块，值 x 用它算值域块。

每个序列块 b 内部再做一次值压缩。valset[b][v] 是值 v 在块 b 里的编号，0 表示块里没有这个值；setval[b][id] 反过来，是编号 id 对应的值；idxset[i] 是位置 i 上的值在自己块里的编号。有了这套编号，整块把 x 改名成 y 就只是改一次映射，不需要动任何位置。

两个统计数组都是前缀形式。sum1[b][vb] 是前 b 个序列块里，落在值域块 vb 的元素个数；sum2[b][v] 是前 b 个序列块里，值 v 的个数。做成前缀，是因为查询时中间那些整块要一次拿到统计，前缀相减就是 O(1)。

三、修改与查询

整块把 x 改成 y，分两种情况。块里没有 y 的时候只改映射：valset[b][y] 接过去，setval[b][编号] 改成 y，valset[b][x] 清零，再把 sum1、sum2 上 x 的计数挪给 y，一次 O(1)。

块里已经有 y 的时候，只能把块下放：arr[i] = setval[b][idxset[i]] 逐个位置还原出真值，再逐点把 x 改成 y，最后重建压缩，O(块长)。

这里有个细节：sum1 和 sum2 是前缀，改一个块会牵动它后面所有块。所以 update 开头从 bi[n] 倒着减掉前一项，把 bi[l] 之后的块还原成「当前块统计」；改完再从 bi[l] 正着加回前缀。

查询第 k 小时，两端零散块先下放、逐点数进 cnt1（值域块计数）和 cnt2（值计数）；中间整块靠 sum1、sum2 的前缀差补上。然后先在值域块粒度上累加 cnt1，第一次 ≥ k 的那个值域块就是答案所在块；再在这个块的 300 个值上扫 cnt2，第一个 ≥ k 的就是答案。

完整代码。快读那段是为了过这题的时间限制，中间 build、lazy、down、innerUpdate 四个函数是块内压缩的全部逻辑。

    
#include <bits/stdc++.h>

    using namespace std;

    char buf[1000000], *p1 = buf, *p2 = buf;

    inline char getChar() {
        return p1 == p2 && (p2 = (p1 = buf) + fread(buf, 1, 1000000, stdin), p1 == p2) ? EOF : *p1++;
    }

    inline int read() {
        int s = 0;
        char c = getChar();
        while (!isdigit(c)) {
            c = getChar();
        }
        while (isdigit(c)) {
            s = s * 10 + c - '0';
            c = getChar();
        }
        return s;
    }

    const int MAXN = 100001;
    const int MAXB = 401;
    int n, m;
    int arr[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];

    int idxset[MAXN];
    int valset[MAXB][MAXN];
    int setval[MAXB][MAXN];

    int sum1[MAXB][MAXB];
    int sum2[MAXB][MAXN];
    int cnt1[MAXB];
    int cnt2[MAXN];

    void build(int b) {
        for (int i = 1; i <= blen; i++) {
            valset[b][setval[b][i]] = 0;
        }
        for (int i = bl[b], s = 0; i <= br[b]; i++) {
            if (valset[b][arr[i]] == 0) {
                s++;
                valset[b][arr[i]] = s;
                setval[b][s] = arr[i];
            }
            idxset[i] = valset[b][arr[i]];
        }
    }

    void lazy(int b, int x, int y) {
        valset[b][y] = valset[b][x];
        setval[b][valset[b][x]] = y;
        valset[b][x] = 0;
    }

    void down(int b) {
        for (int i = bl[b]; i <= br[b]; i++) {
            arr[i] = setval[b][idxset[i]];
        }
    }

    void innerUpdate(int l, int r, int x, int y) {
        down(bi[l]);
        for (int i = l; i <= r; i++) {
            if (arr[i] == x) {
                sum1[bi[i]][bi[x]]--;
                sum1[bi[i]][bi[y]]++;
                sum2[bi[i]][x]--;
                sum2[bi[i]][y]++;
                arr[i] = y;
            }
        }
        build(bi[l]);
    }

    void update(int l, int r, int x, int y) {
        if (x == y || (sum2[bi[r]][x] - sum2[bi[l] - 1][x] == 0)) {
            return;
        }
        for (int b = bi[n]; b >= bi[l]; b--) {
            sum1[b][bi[x]] -= sum1[b - 1][bi[x]];
            sum1[b][bi[y]] -= sum1[b - 1][bi[y]];
            sum2[b][x] -= sum2[b - 1][x];
            sum2[b][y] -= sum2[b - 1][y];
        }
        if (bi[l] == bi[r]) {
            innerUpdate(l, r, x, y);
        } else {
            innerUpdate(l, br[bi[l]], x, y);
            innerUpdate(bl[bi[r]], r, x, y);
            for (int b = bi[l] + 1; b <= bi[r] - 1; b++) {
                if (sum2[b][x] != 0) {
                    if (sum2[b][y] != 0) {
                        innerUpdate(bl[b], br[b], x, y);
                    } else {
                        sum1[b][bi[y]] += sum2[b][x];
                        sum1[b][bi[x]] -= sum2[b][x];
                        sum2[b][y] += sum2[b][x];
                        sum2[b][x] = 0;
                        lazy(b, x, y);
                    }
                }
            }
        }
        for (int b = bi[l]; b <= bi[n]; b++) {
            sum1[b][bi[x]] += sum1[b - 1][bi[x]];
            sum1[b][bi[y]] += sum1[b - 1][bi[y]];
            sum2[b][x] += sum2[b - 1][x];
            sum2[b][y] += sum2[b - 1][y];
        }
    }

    void addCnt(int l, int r) {
        for (int i = l; i <= r; i++) {
            cnt1[bi[arr[i]]]++;
            cnt2[arr[i]]++;
        }
    }

    void clearCnt(int l, int r) {
        for (int i = l; i <= r; i++) {
            cnt1[bi[arr[i]]] = cnt2[arr[i]] = 0;
        }
    }

    int query(int l, int r, int k) {
        int ans = 0;
        bool inner = bi[l] == bi[r];
        if (inner) {
            down(bi[l]);
            addCnt(l, r);
        } else {
            down(bi[l]);
            down(bi[r]);
            addCnt(l, br[bi[l]]);
            addCnt(bl[bi[r]], r);
        }
        int sumCnt = 0;
        int vblock = 0;
        for (int b = 1; b <= bi[MAXN - 1]; b++) {
            int cnt = cnt1[b] + (inner ? 0 : sum1[bi[r] - 1][b] - sum1[bi[l]][b]);
            if (sumCnt + cnt >= k) {
                vblock = b;
                break;
            } else {
                sumCnt += cnt;
            }
        }
        for (int v = (vblock - 1) * blen + 1; v <= vblock * blen; v++) {
            int cnt = cnt2[v] + (inner ? 0 : sum2[bi[r] - 1][v] - sum2[bi[l]][v]);
            if (sumCnt + cnt >= k) {
                ans = v;
                break;
            } else {
                sumCnt += cnt;
            }
        }
        if (inner) {
            clearCnt(l, r);
        } else {
            clearCnt(l, br[bi[l]]);
            clearCnt(bl[bi[r]], r);
        }
        return ans;
    }

    void prepare() {
        blen = 300;
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i < MAXN; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
            build(i);
        }
        for (int i = 1; i <= bnum; i++) {
            for (int j = 1; j < MAXB; j++) {
                sum1[i][j] = sum1[i - 1][j];
            }
            for (int j = 1; j < MAXN; j++) {
                sum2[i][j] = sum2[i - 1][j];
            }
            for (int j = bl[i]; j <= br[i]; j++) {
                sum1[i][bi[arr[j]]]++;
                sum2[i][arr[j]]++;
            }
        }
    }

    int main() {
        n = read();
        m = read();
        for (int i = 1; i <= n; i++) {
            arr[i] = read();
        }
        prepare();
        for (int i = 1, op, l, r, x, y, k; i <= m; i++) {
            op = read();
            l = read();
            r = read();
            if (op == 1) {
                x = read();
                y = read();
                update(l, r, x, y);
            } else {
                k = read();
                printf("%d\n", query(l, r, k));
            }
        }
        return 0;
    }

整块（走前缀差） 零散（逐点数） 不在查询区间

四、题目2：魔法少女网站

给定一个长度为 n 的数组，m 条操作。操作 1 把 arr[x] 改成 v；操作 2 查询 arr[x..y] 里有多少连续子数组的最大值 ≤ v。n、m 都是 3×10⁵。测试链接：洛谷 P6578。

这题的分块方向反过来：不是「每个操作扫它涉及的块」，而是「每个块把所有操作扫一遍」。原因是区间查询的答案天然可以拆成「每个整块的贡献 + 两端零散」，而整块的贡献可以用一次「按值从小到大加数」同时算给所有查询。

块长取 512，也就是 1 << 9。取 2 的幂是为了后面基数排序分桶时用位运算切高低 9 位。

五、一个块里怎么算

对块 [l, r]，先把块内的位置按 arr 值升序排好，把落在这个块上的查询按 v 升序排好，两个都用两轮基数排序（低 9 位、高 9 位，桶大小 601）。然后双指针：v 递增，把值 ≤ v 的位置依次「加入」。

加入一个位置 idx 时，用双链表维护还没加入的位置。左边连续已加入的长度是 idx - lst[idx]，右边是 nxt[idx] - idx。所有新产生的、最大值 ≤ v 的子数组必须跨过 idx，左端点有左边那么多种选法，右端点有右边那么多种选法，乘起来就是新增数量 (idx - lst[idx]) * (nxt[idx] - idx)。算完把 idx 从链表摘掉。

六、答案怎么跨块拼起来

一个查询覆盖好几个整块，每块的贡献要拼成完整答案。对每个查询维护三个量：pre 是已累计部分的前缀连续长度，suf 是后缀连续长度，len 是已累计的总长度。合并一个新块时：

跨在两块交界处的子数组，左半边是前一块的后缀连续、右半边是当前块的前缀连续，数量是 suf * curPre，加上块内的 curAns 一起进答案。然后 pre 只有在前面整段都连续时才延长，suf 只有在当前块整段都连续时才接上之前的，判断依据都是拿 len 和 curLen 比。

块内被修改时要先把已收集的查询结算掉（calc），再改值，否则后面加数的顺序就乱了。查询只覆盖块的一部分时，不走批量，直接逐点把这个块内的那几个位置并进答案：位置可用就 merge(qi, 1, 1, 1, 1)，不可用就 merge(qi, 0, 0, 1, 0)。

    
#include <bits/stdc++.h>

    using namespace std;

    namespace fastio {
        static const int SZ = 1 << 20;
        char ibuf[SZ], *is = ibuf, *ie = ibuf;
        inline int gc() {
            if (is == ie) {
                size_t len = fread(ibuf, 1, SZ, stdin);
                if (len == 0) return -1;
                is = ibuf;
                ie = ibuf + len;
            }
            return *is++;
        }
        template <typename T>
        inline bool readInt(T& x) {
            int c = gc(); if (c == -1) return false;
            bool neg = false;
            while (c != '-' && (c < '0' || c > '9')) { c = gc(); if (c == -1) return false; }
            if (c == '-') { neg = true; c = gc(); }
            x = 0;
            while (c >= '0' && c <= '9') { x = x * 10 + (c & 15); c = gc(); }
            if (neg) x = -x;
            return true;
        }
        char obuf[SZ]; char* op = obuf;
        inline void flush() {
            fwrite(obuf, 1, op - obuf, stdout);
            op = obuf;
        }
        template <typename T>
        inline void writeInt(T x, char end = '\n') {
            if (op > obuf + SZ - 256) flush();
            if (x == 0) { *op++ = '0'; *op++ = end; return; }
            if (x < 0) { *op++ = '-'; x = -x; }
            char s[24]; int n = 0;
            while (x) { s[n++] = char('0' + x % 10); x /= 10; }
            while (n) *op++ = s[--n];
            *op++ = end;
        }
    }

    using fastio::readInt;
    using fastio::writeInt;
    using fastio::flush;

    const int MAXN = 300002;
    const int MAXB = 601;
    const int POW = 9;
    const int OFFSET = (1 << POW) - 1;
    int n, m;

    int arr[MAXN];
    int op[MAXN];
    int x[MAXN];
    int y[MAXN];
    int v[MAXN];

    int pos[MAXN];
    int qid[MAXN];
    int cntp;
    int cntq;

    int cntv[MAXB];
    int help[MAXN];

    int lst[MAXN];
    int nxt[MAXN];

    int pre[MAXN];
    int suf[MAXN];
    int len[MAXN];
    long long ans[MAXN];

    inline void radix(int* idx, int* val, int siz) {
        memset(cntv, 0, sizeof(int) * MAXB);
        for (int i = 1; i <= siz; i++) cntv[val[idx[i]] & OFFSET]++;
        for (int i = 1; i < MAXB; i++) cntv[i] += cntv[i - 1];
        for (int i = siz; i >= 1; i--) help[cntv[val[idx[i]] & OFFSET]--] = idx[i];
        memcpy(idx + 1, help + 1, siz * sizeof(int));
        memset(cntv, 0, sizeof(int) * MAXB);
        for (int i = 1; i <= siz; i++) cntv[val[idx[i]] >> POW]++;
        for (int i = 1; i < MAXB; i++) cntv[i] += cntv[i - 1];
        for (int i = siz; i >= 1; i--) help[cntv[val[idx[i]] >> POW]--] = idx[i];
        memcpy(idx + 1, help + 1, siz * sizeof(int));
    }

    inline void merge(int i, int curPre, int curSuf, int curLen, int curAns) {
        ans[i] += 1L * suf[i] * curPre + curAns;
        pre[i] = pre[i] + (pre[i] == len[i] ? curPre : 0);
        suf[i] = curSuf + (curSuf == curLen ? suf[i] : 0);
        len[i] += curLen;
    }

    void calc(int l, int r) {
        for (int i = l; i <= r; i++) {
            pos[++cntp] = i;
            lst[i] = i - 1;
            nxt[i] = i + 1;
        }
        radix(pos, arr, cntp);
        radix(qid, v, cntq);
        int curPre = 0, curSuf = 0, curLen = r - l + 1, curAns = 0;
        for (int i = 1, j = 1, idx; i <= cntq; i++) {
            while (j <= cntp && arr[pos[j]] <= v[qid[i]]) {
                idx = pos[j];
                if (lst[idx] == l - 1) {
                    curPre += nxt[idx] - idx;
                }
                if (nxt[idx] == r + 1) {
                    curSuf += idx - lst[idx];
                }
                curAns += 1L * (idx - lst[idx]) * (nxt[idx] - idx);
                lst[nxt[idx]] = lst[idx];
                nxt[lst[idx]] = nxt[idx];
                j++;
            }
            merge(qid[i], curPre, curSuf, curLen, curAns);
        }
        cntp = cntq = 0;
    }

    void compute(int l, int r) {
        for (int qi = 1; qi <= m; qi++) {
            if (op[qi] == 1) {
                if (l <= x[qi] && x[qi] <= r) {
                    calc(l, r);
                    arr[x[qi]] = v[qi];
                }
            } else {
                if (x[qi] <= l && r <= y[qi]) {
                    qid[++cntq] = qi;
                } else {
                    for (int i = max(x[qi], l); i <= min(y[qi], r); i++) {
                        if (arr[i] <= v[qi]) {
                            merge(qi, 1, 1, 1, 1);
                        } else {
                            merge(qi, 0, 0, 1, 0);
                        }
                    }
                }
            }
        }
        calc(l, r);
    }

    int main() {
        readInt(n);
        readInt(m);
        for (int i = 1; i <= n; i++) {
            readInt(arr[i]);
        }
        for (int i = 1; i <= m; i++) {
            readInt(op[i]);
            readInt(x[i]);
            if (op[i] == 1) {
                readInt(v[i]);
            } else {
                readInt(y[i]);
                readInt(v[i]);
            }
        }
        int blen = 1 << POW;
        int bnum = (n + blen - 1) / blen;
        for (int i = 1, l, r; i <= bnum; i++) {
            l = (i - 1) * blen + 1;
            r = min(i * blen, n);
            compute(l, r);
        }
        for (int i = 1; i <= m; i++) {
            if (op[i] == 2) {
                writeInt(ans[i]);
            }
        }
        flush();
        return 0;
    }

已加入（值 ≤ v） 本次刚加入 还没加入

七、复杂度分析

题目1 一次查询是 O(值域块数 + 块长 + 零散长度)，一次修改是 O(块数 + 触发下放的块数 × 块长)。下放看起来会退化，其实有势能兜着：一次 O(块长) 的下放必然让那个块里的值种类数减一，而种类数只能靠两端零散修改加回来，一次操作最多加两次。所以全部下放的总次数不超过 n + 2m。

题目2 是块数乘操作数的形态：每个块把所有 m 个操作扫一遍，另外每个查询最多在两个块里走零散，一共 O(m·n/B + m·B + n)。

操作时间复杂度空间复杂度
题目1 预处理（分块 + 值压缩 + 前缀）O(n · V/B)O(块数 × V)：sum1 是 bnum × 值域块数，sum2 与 valset 是 bnum × V，n、V 同阶时约几百 MB 量级，这是双层分块的主要代价

题目1 查询第 k 小O(V/B + B)
题目2 每个块（基数排序 + 双链表 + 扫操作）O(m + B)
题目2 全部O(m · n/B + m · B + n)

两道题的块长都是调出来的。题目1 要平衡「每次修改扫前缀的 n/B」和「下放总代价 (n+m)·B」，300 附近两项同量级；题目2 要平衡 m·n/B 与 m·B，理论最优是 √n ≈ 550，代码取 512 是为了让基数排序的两轮都正好切 9 位。

八、最后

双层分块做的事，是把「值域上的二分」换成「值域上的分块」，用一个 √V 换掉两个 log。代价是统计数组要开二维，空间比一层分块大一个量级。

下一节换分块套并查集：值域用并查集维护，块内的整块操作靠改并查集的父亲一次完成，连二维统计数组都可以省掉。

《完》
