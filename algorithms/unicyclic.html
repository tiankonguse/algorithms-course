基环树

树上的算法写顺手之后，多出一条边就卡住了。基环树刚好是多这一条边的连通图：n 个点、n 条边，结构固定成「一个环 + 环上挂树」。麻烦只有一处，环上两点之间不再只有一条路。这一节先把环找出来，再连做四道题。

零、背景

无向基环树就是「n 个点、n 条边、连通」的图。边数比树多一条，多出来的那一条必然把某个区间闭合成环。

所以形状是定死的：一个环，环上的每个点挂一棵树。环长记 k，树边就有 n − k 条。

有向的情形分两类。每个点的出度都是 1，边从外面一路指进环，叫内向树；每个点的入度都是 1，边从环一路指出去，叫外向树。两种也都是 n 点 n 边、也只有一个环。

处理套路跟着形状走：先用一次 dfs 把环上的点标记出来，再对环上每个点挂的那棵树（下称分树）单独建信息，最后在环上整合。树形 DP、树剖、单调队列这些工具在分树上照用不误。

环上的整合通常先做一步变形：把环断开成链，或者把环倍长成两圈。前者服务「删掉一条环边最优化」的问题，后者服务「环上任意两点配对」的问题，下一节的四道题都在用。

一、dfs 找环

找环有三条路。dfs 最常用，能一次拿到环上点的顺序、环上的边、环上边的权值。并查集只适用于无向图，边一条条加入，遇到两端已经连通的边就是闭环边，拿不到环上的全部点。拓扑排序把度数为 1 的点一层层消掉，剩下的点就是环上的点，也只能回答「谁在环上」。

这里只讲 dfs。两件事：给每个点一个 dfn 序号，dfn[u] 是第一次走到 u 时拿到的号；再记 from[u]，表示当前 dfs 路径上 u 是从哪个点进来的。

走到 u，枚举它的所有出边看邻点 v。v 没访问过，就记 from[v] = u 继续往下走。

v 已经访问过，比较 dfn：只有 dfn[u] < dfn[v] 才算数。满足这个条件说明 v 是在 u 之后被访问、又已经先回来的点，它只能是 u 子树里的点，而这条边不是走下来的那条，于是 u 到 v 的树路径加上这条边正好是一个环。

这时 u 是环上最浅的点，v 是环的另一头。沿着 from 从 v 一路退到 u，路过的点加上 u，就是环上的全部点。

要找环上的边和边权，把 from 拆成 fromNode 和 fromWeight 两个数组就行：往下走时顺手记下这条边的权值，收集环的时候一起收进数组，环上第 i 条边的权值就落在 val[i] 上。题目 5、6 都要用到这套信息。

有个细节容易踩：发现环之后不要直接 return 退出整个 dfs，要把当前连通块剩下的点也走完。基环树可以有多个连通块（题目 1、3、6 都是），dfn 全部标上号，外层才能靠 dfn[i] == 0 找到下一个连通块。

通用的找环骨架如下，四道题都在它上面补东西：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    int n;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;
    int from[MAXN];

    int cycle[MAXN];
    int cntc;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                from[v] = u;
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[++cntc] = u;
                for (int i = v; i != u; i = from[i]) {
                    cycle[++cntc] = i;
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v; i <= n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                dfs(i);
            }
        }
        cout << cntc << "\n";
        return 0;
    }

二、题目1：定向道路

n 个点、n 条无向边，图可能有多个连通块，保证每个连通块都是一棵基环树。给每条边定一个方向，要求得到的有向图里不能出现环，求方案数，对 1000000007 取余（CF711D）。

先看一个连通块。n 条边各自独立选方向，一共 2 的 n 次方种。

哪些定向会造出环？树边本身连环都组不成，把环缩成一个点之后剩下的是一片森林，森林里的边永远造不出有向环。所以有向环只可能整圈落在原环上：环上的 k 条边如果全部朝着同一个绕行方向，就是一个有向环。

环上全同向只有 2 种（顺时针、逆时针），此时剩下的 n − k 条树边随便定，都是坏方案，一共 2 · 2 的 (n−k) 次方，也就是 2 的 (n−k+1) 次方。

一个连通块的答案就是 2 的 n 次方减去 2 的 (n−k+1) 次方，多个连通块相乘。这里的 k 正是找环时收集到的环上点数，直接拿来用。

取模做减法要写成 (a - b + MOD) % MOD，不然会出现负数。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    const int MOD = 1000000007;
    int n, cntb;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int from[MAXN];
    int all[MAXN];
    int cycle[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    ll power(ll x, ll p) {
        ll ans = 1;
        while (p > 0) {
            if ((p & 1) == 1) {
                ans = (ans * x) % MOD;
            }
            x = (x * x) % MOD;
            p >>= 1;
        }
        return ans;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        all[cntb]++;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                from[v] = u;
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[cntb]++;
                for (int i = v; i != u; i = from[i]) {
                    cycle[cntb]++;
                }
            }
        }
    }

    ll compute() {
        ll ans = 1;
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                cntb++;
                dfs(i);
                ll a = power(2, all[cntb]);
                ll b = power(2, all[cntb] - cycle[cntb] + 1);
                ans = ans * ((a - b + MOD) % MOD) % MOD;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, x; i <= n; i++) {
            cin >> x;
            addEdge(i, x);
            addEdge(x, i);
        }
        ll ans = compute();
        cout << ans << "\n";
        return 0;
    }

三、题目2：简单路径数量

n 个点、n 条无向边，连通、没有重边和自环的基环树。简单路径是点不重复、边数至少 1 的路径。方向相反的两条算同一条，比如 (a, b, c) 和 (c, b, a) 只数一次。求简单路径总数（CF1454E）。

先回忆树上的结论：任意两点之间恰好一条简单路径，总数就是 C(n, 2)。

基环树多出来的只有一个来源：两点之间的路径要是能「绕环两侧各走一遍」，就有了第二条。什么样的点对会这样？

把环上的点标记出来，删掉环上的边，每个环上点 i 连着自己挂的那棵树，记这棵外向树的大小为 siz[i]，也就是 i 自己加上挂在它下面的所有点。因为环上的边都删了，各棵外向树两两不重叠，所有 siz[i] 加起来正好是 n。

两端点落在同一棵外向树里：路径只能在这棵树里走，唯一一条。落在两棵不同的外向树里：必须借道环，而环上有两个方向可选，于是有两条。

按这个分类直接数。对每个环上点 i，它的外向树内部的路径有 C(siz[i], 2) 条；一端在 siz[i] 里、另一端在树外的点对有 siz[i] · (n − siz[i]) 个，每个贡献两条路径，而它会被两端的树各数一次，合起来正好一次不多不少。

于是答案 = Σ [ C(siz[i], 2) + siz[i] · (n − siz[i]) ]，对每个环上点求和。统计 siz 时从环上点出发往下跑一次树形 dfs，碰到环上点就停，累加子树大小即可。

完整代码（多组数据，注意每组清空）：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    int t, n;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int from[MAXN];
    bool cycle[MAXN];

    ll siz[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                from[v] = u;
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[u] = true;
                for (int i = v; i != u; i = from[i]) {
                    cycle[i] = true;
                }
            }
        }
    }

    void dpOnTree(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !cycle[v]) {
                dpOnTree(v, u);
                siz[u] += siz[v];
            }
        }
    }

    ll compute() {
        dfs(1);
        ll ans = 0;
        for (int i = 1; i <= n; i++) {
            if (cycle[i]) {
                dpOnTree(i, 0);
                ans += siz[i] * (siz[i] - 1) / 2 + siz[i] * (n - siz[i]);
            }
        }
        return ans;
    }

    void prepare() {
        cntg = cntd = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = dfn[i] = 0;
            cycle[i] = false;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n;
            prepare();
            for (int i = 1, u, v; i <= n; i++) {
                cin >> u >> v;
                addEdge(u, v);
                addEdge(v, u);
            }
            ll ans = compute();
            cout << ans << "\n";
        }
        return 0;
    }

四、题目3：骑士

n 个点、n 条无向边，每个点有点权，图可能有多个连通块，保证每个连通块都是基环树。任意相邻两点不能同时选，求能选出的最大点权和（洛谷 P2607）。

树上的做法是入门 DP：dp[u][0] 表示不选 u 时子树的最优值，dp[u][1] 表示选 u。转移是不选 u 时孩子随便，dp[u][0] += max(dp[v][0], dp[v][1])；选了 u 时孩子必须不选，dp[u][1] += dp[v][0]。

基环树只多一条环上的边。找环时触发发现环的那条闭合边就顺手拿到，记作 (x, y)，把它的编号存进 skip。

原问题的最优解里，x 和 y 不可能同时被选，所以只有两种情况：x 不选，或者 y 不选。

把 skip 这条边在转移里跳过，整个连通块就变成一棵普通的树。以 x 为根跑一次树形 DP，dp[x][0] 正是「x 不选」时的最优值；以 y 为根再跑一次，dp[y][0] 就是「y 不选」时的最优值。两者取较大者，就是这一个连通块的答案。

多个连通块分别处理再累加。每个连通块都要重新找一次环，x、y、skip 三个量记得在进入新连通块前清零。

题目4 城市环路（洛谷 P1453）是同一道题：n 缩到 10 万，点权范围小，dp 用 int 就够；算完最大点权和之后再乘题目给的系数 k，输出保留一位小数。代码上只有三处不同，读入的下标加一、最后乘 k、用 double 打印。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 1000001;
    int n;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int x, y, skip;

    ll dp[MAXN][2];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                x = u;
                y = v;
                skip = (e + 1) >> 1;
            }
        }
    }

    void dpOnTree(int u, int fa) {
        dp[u][0] = 0;
        dp[u][1] = arr[u];
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa && (e + 1) >> 1 != skip) {
                dpOnTree(v, u);
                dp[u][0] += max(dp[v][0], dp[v][1]);
                dp[u][1] += dp[v][0];
            }
        }
    }

    ll compute() {
        ll ans = 0;
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                x = y = 0;
                dfs(i);
                dpOnTree(x, 0);
                ll cur = dp[x][0];
                dpOnTree(y, 0);
                cur = max(cur, dp[y][0]);
                ans += cur;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int x = 1, y; x <= n; x++) {
            cin >> arr[x];
            cin >> y;
            addEdge(x, y);
            addEdge(y, x);
        }
        ll ans = compute();
        cout << ans << "\n";
        return 0;
    }

五、复杂度分析

四道题共用同一个 dfs 骨架，环在发现的那一刻被整体收走，每个点进出各一次，每条边看两遍。

步骤时间复杂度空间复杂度
dfs 找环O(n)O(n)
题目1 定向道路O(n + c · log MOD)，c 是连通块数O(n)
题目2 简单路径数量O(n)O(n)
题目3 / 题目4 最大权独立集O(n)，每个连通块两次树形 DPO(n)

题目1 里唯一的额外开销是快速幂，每个连通块调用两次，模数固定成 10⁹+7，每次只要 30 步左右。

题目2 统计 siz 时从环上点往下走，每条树边只被走一次；题目3 的两次树形 DP 会让树边最多走四遍，仍是线性。空间是邻接表 2n 条边加几个 n 长的数组，n 到 2 × 10⁵ 完全够用。

六、最后

这一节的四道题骨架完全一样：dfn 定序、from 记路，最后那条满足 dfn[u] < dfn[v] 的非树边就是环的闭合边。变化的只是拿到环之后往里面填什么，数两个方向、数环上的弧、断一条边跑两次 DP。

还有一件事这一节一直绕过去了：环上的信息从来不是一遍扫下来的。树形 DP 靠「孩子算完再合并父亲」，环上没有这个天然的先后，两点之间永远有两条路。
