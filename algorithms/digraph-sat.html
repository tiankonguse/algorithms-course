范围蕴含边进 2-SAT：划分可重集与喵了个喵 II

2-SAT 的蕴含边一旦带上范围，「i 进集合 a，则左侧所有值不超过 v[i]−k 的位置都得进 b」，朴素建图就是平方级。两道洛谷题 P7477、P9139 把树状数组、主席树、CDQ 三种优化建图全部接进 2-SAT，同一条蕴含边有三种等价写法，Tarjan 缩点照常收尾。

零、背景

2-SAT 的框架：每个变量两个文字，蕴含边 u → v 表示「u 为真则 v 为真」，每条边都伴随它的逆否镜像；Tarjan 缩点后同一变量的两个文字不在同一个强连通分量里，就有解。这些是 196 课的内容。

麻烦出在约束的形状上。「i 左侧所有值不超过 v[i]−k 的位置都没进 a」这样一条规则，牵扯的是一片点而不是一个点。老实展开，一条规则就是 O(n) 条蕴含边，位置两两之间还会互相牵连，平方级挡不住。

前三页的结构在这一页变成「蕴含边工厂」：规则里的「一片点」换成数据结构上的少数几个节点，边数立刻掉到 O(n log n)。三种结构对同一道题给出三种实现，建出的图完全一样。

一、题目：划分可重集（P7477）

给定长度为 n 的数组 arr，从左到右把每个数划分进可重集 a 或 b，每个数至少进一个集合。arr[i] 能进集合 a 的条件：i 左侧任何 ≤ arr[i] − k 的数字都没进 a；能进集合 b 的条件：i 左侧任何 ≥ arr[i] + k 的数字都没进 b。另有 m 组关系 x y（保证 x < y），表示两个位置的数不能进同一个集合。

如果不存在合法划分输出 −1；存在则打印能划分成功的最小 k。n、m ≤ 2×10⁴，arr[i] ≤ 10⁹。

二、建模：条件变蕴含，二分找最小 k

变量是每个位置的选择：文字 i 表示「位置 i 进 a」，文字 i' 表示「进 b」。m 组关系是标准的 2-SAT 子句，x 和 y 不能同集，连四条对称边：x → y'、y → x'、x' → y、y' → x。

值条件按蕴含读。「i 进 a ⟹ 左侧所有值 ≤ v[i]−k 的 j 都进 b」，展开成两条边：i → j'（i 选 a 则那些 j 必须选 b），以及逆否形式 j → i'（j 选了 a 则 i 不能再选 a）。b 侧同理，范围换成值 ≥ v[i]+k，方向整个镜像。一条规则四个方向，每个方向都指向「一片点」。

k 有单调性：k 越大，两个值域门槛离 v[i] 越远，被牵连的 j 越少，约束越松。check(k) 的可行性随 k 单调不减，于是二分：l = 0，r = max(arr)，每次 check 建一张 2-SAT 图跑 Tarjan，最小可行 k 就是答案。

三、三种实现，同一张图

值先离散化：排序算出每个位置的排名 rak[i]。「值 ≤ v[i]−k」就是排名前缀 [1..small]，small 用二分数出来；「值 ≥ v[i]+k」把排名倒过来排，同样变成前缀。剩下的关键条件是「j 在 i 左侧」，三种实现的差别全在怎么处理这个时间维。

树状数组版最直接：按位置从 1 到 n 依次处理，每个位置先查询、后插入。查询发生时，链里恰好只有 j < i 的点，第一页讲过，链是按入袋时间增长的，查询天然只看过去。位置 i 的四个方向（连出去两条、被连进来两条）需要四棵树状数组：出链、入链各两棵。

主席树版按位置开版本：处理到 i 时先在版本 i−1 上查询，再把 i 的两个文字插入成版本 i。查询挂在历史版本上，等价于「只看到 i 左侧」。CDQ 版把位置当分治维：左半位置一定在右半位置左边，merge 时按值双指针建两条链，小值链管 a 侧蕴含、大值链管 b 侧蕴含。

下面是树状数组版的完整提交。small、big 两个二分把值门槛换算成排名个数，add 把位置 i 的两个文字插进四棵树，link 连出四个方向的蕴含边，check 建图跑 Tarjan，compute 外面套二分。主席树版和 CDQ 版只换 add 与 link 的实现，其余一字不改。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int v, i;
    };

    bool NodeCmp(Node a, Node b) {
        if (a.v != b.v) {
            return a.v < b.v;
        }
        return a.i < b.i;
    }

    const int MAXN = 20001;
    const int MAXM = 20001;
    const int MAXT = 1000001;
    const int MAXE = 2000001;
    int n, m, cntt;
    int v[MAXN];
    int x[MAXM];
    int y[MAXM];

    int rak[MAXN];
    Node arr[MAXN];

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int outTree1[MAXN];
    int inTree1[MAXN];
    int outTree2[MAXN];
    int inTree2[MAXN];

    int small(int num) {
        int l = 1, r = n, mid, ans = 0;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (arr[mid].v <= num) {
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }

    int big(int num) {
        int l = 1, r = n, mid, ans = n + 1;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (arr[mid].v >= num) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return n - ans + 1;
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int lowbit(int i) {
        return i & -i;
    }

    void addOut(int outTree[], int i, int x) {
        while (i <= n) {
            int preo = outTree[i];
            int curo = ++cntt;
            if (preo > 0) {
                addEdge(preo, curo);
            }
            addEdge(x, curo);
            outTree[i] = curo;
            i += lowbit(i);
        }
    }

    void addIn(int inTree[], int i, int x) {
        while (i <= n) {
            int prei = inTree[i];
            int curi = ++cntt;
            if (prei > 0) {
                addEdge(curi, prei);
            }
            addEdge(curi, x);
            inTree[i] = curi;
            i += lowbit(i);
        }
    }

    void rangeToX(int outTree[], int i, int x) {
        while (i > 0) {
            if (outTree[i] > 0) {
                addEdge(outTree[i], x);
            }
            i -= lowbit(i);
        }
    }

    void xToRange(int inTree[], int x, int i) {
        while (i > 0) {
            if (inTree[i] > 0) {
                addEdge(x, inTree[i]);
            }
            i -= lowbit(i);
        }
    }

    void add(int x, int otherx, int si, int bi) {
        addOut(outTree1, si, x);
        addIn(inTree1, si, otherx);
        addOut(outTree2, bi, otherx);
        addIn(inTree2, bi, x);
    }

    void link(int x, int otherx, int lowCnt, int highCnt) {
        xToRange(inTree1, x, lowCnt);
        rangeToX(outTree1, lowCnt, otherx);
        xToRange(inTree2, otherx, highCnt);
        rangeToX(outTree2, highCnt, x);
    }

    int other(int x) {
        return x <= n ? x + n : x - n;
    }

    void buildGraph(int k) {
        cntt = n << 1;
        for (int i = 1; i <= m; i++) {
            addEdge(x[i], other(y[i]));
            addEdge(y[i], other(x[i]));
            addEdge(other(x[i]), y[i]);
            addEdge(other(y[i]), x[i]);
        }
        for (int i = 1; i <= n; i++) {
            link(i, other(i), small(v[i] - k), big(v[i] + k));
            add(i, other(i), rak[i], n - rak[i] + 1);
        }
    }

    void clear() {
        for (int i = 1; i <= cntt; i++) {
            head[i] = dfn[i] = belong[i] = 0;
        }
        for (int i = 1; i <= n; i++) {
            inTree1[i] = outTree1[i] = inTree2[i] = outTree2[i] = 0;
        }
        cntt = cntg = cntd = top = sccCnt = 0;
    }

    bool check(int k) {
        buildGraph(k);
        for (int i = 1; i <= (n << 1); i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                check = false;
                break;
            }
        }
        clear();
        return check;
    }

    int compute() {
        for (int i = 1; i <= n; i++) {
            arr[i] = {v[i], i};
        }
        sort(arr + 1, arr + n + 1, NodeCmp);
        for (int i = 1; i <= n; i++) {
            rak[arr[i].i] = i;
        }
        int l = 0, r = arr[n].v, mid, ans = -1;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (check(mid)) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> v[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> x[i] >> y[i];
        }
        int ans = compute();
        cout << ans << "\n";
        return 0;
    }

四、题目：喵了个喵 II（P9139）

给定长度为 4n 的数组，1 到 n 每种数字恰好出现 4 次。从左到右把每个数字划分进序列 0 或序列 1，要求划分出的两条序列完全相等。能做到就输出 Yes 和每个位置的归属，否则输出 No。n ≤ 5×10⁴。

两条序列相等，每个值必然在每条序列里各占两格。方案可以化简：把每个值按位置记作 a < b < c < d，只需要保留两种摆法，0011（a、b 进序列 0，c、d 进序列 1）和 0101（a、c 进序列 0，b、d 进序列 1）。于是每个值就是一个布尔变量：真取 0011，假取 0101。

五、组：把摆法翻译成冲突边

连边不直接用「值 x 选 0011」，而是用四个组。组是一个位置对加一个文字，含义是「这个文字为真时，左端进序列 0、右端进序列 1」：值 x 造 (a, c, x)、(b, d, x)、(a, b, x')、(c, d, x') 四个组，前两个是 0011 摆法产生的错位对，后两个是 0101 摆法的。

两个组什么时候冲突？组 (l, r) 表示 l 进 0、r 进 1；另一个组 (l', r') 若整个嵌在它里面（l ≤ l' 且 r' ≤ r），两个文字不能同时为真：序列 0 里 l 的值排在 l' 前面，序列 1 里 r' 的值排在 r 前面，同一个值对在两条序列里顺序相反，序列不可能相等。同值自己的组嵌套连出来是自环，不构成约束，天然无害。

把所有组按右端点排序，依次处理。处理组 (l, r, x) 时，用树状数组按「位置倒序排名」查前缀：命中的恰好是已处理的（右端点不大于 r）且左端点不小于 l 的组，也就是嵌在里面的那些。命中的每个 t' 连两条边：x → t' 的否定，t' → x 的否定，对称性一条不落。查询完把 x 和 x' 都插进树状数组，给后面的组查。这套结构和第三页的 CDQ 一样有「按 r 排序 + 前缀查询」的味道，只不过这里排序直接做掉了偏序的一维。

判定和构造沿用 Tarjan：缩点后 belong[x] < belong[x+v] 时 x 取真，输出 0011 摆法；否则 x 取假，输出 0101。代码里同样备了树状数组、主席树、CDQ 三种实现，下面是树状数组版，建图核心在 buildGraph 的查询加插入四行。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int v, i;
    };

    bool NodeCmp(Node a, Node b) {
        if (a.v != b.v) {
            return a.v < b.v;
        }
        return a.i < b.i;
    }

    struct Group {
        int l, r, x;
    };

    bool GroupCmp(Group a, Group b) {
        return a.r < b.r;
    }

    const int MAXV = 50001;
    const int MAXN = 200001;
    const int MAXT = 5000001;
    const int MAXE = 20000001;
    int v, n, cntt;

    Node vi[MAXN];
    Group group[MAXN];
    int cntp;

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int outTree[MAXN];
    int inTree[MAXN];

    int ans[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int lowbit(int i) {
        return i & -i;
    }

    void addOut(int i, int x) {
        while (i <= n) {
            int preo = outTree[i];
            int curo = ++cntt;
            if (preo > 0) {
                addEdge(preo, curo);
            }
            addEdge(x, curo);
            outTree[i] = curo;
            i += lowbit(i);
        }
    }

    void addIn(int i, int x) {
        while (i <= n) {
            int prei = inTree[i];
            int curi = ++cntt;
            if (prei > 0) {
                addEdge(curi, prei);
            }
            addEdge(curi, x);
            inTree[i] = curi;
            i += lowbit(i);
        }
    }

    void rangeToX(int i, int x) {
        while (i > 0) {
            if (outTree[i] > 0) {
                addEdge(outTree[i], x);
            }
            i -= lowbit(i);
        }
    }

    void xToRange(int x, int i) {
        while (i > 0) {
            if (inTree[i] > 0) {
                addEdge(x, inTree[i]);
            }
            i -= lowbit(i);
        }
    }

    int other(int x) {
        return x <= v ? x + v : x - v;
    }

    void buildGraph() {
        sort(group + 1, group + cntp + 1, GroupCmp);
        cntt = v << 1;
        for (int i = 1; i <= cntp; i++) {
            int l = group[i].l;
            int p = n - l + 1;
            int x = group[i].x;
            xToRange(x, p);
            rangeToX(p, other(x));
            addIn(p, other(x));
            addOut(p, x);
        }
    }

    bool compute() {
        sort(vi + 1, vi + n + 1, NodeCmp);
        for (int i = 1; i <= n; i += 4) {
            int x = vi[i].v;
            int a = vi[i].i;
            int b = vi[i + 1].i;
            int c = vi[i + 2].i;
            int d = vi[i + 3].i;
            group[++cntp] = { a, c, x };
            group[++cntp] = { b, d, x };
            group[++cntp] = { a, b, x + v };
            group[++cntp] = { c, d, x + v };
        }
        buildGraph();
        for (int i = 1; i <= v << 1; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= v; i++) {
            if (belong[i] == belong[i + v]) {
                check = false;
                break;
            }
        }
        if (check) {
            for (int i = 1; i <= n; i += 4) {
                int x = vi[i].v;
                int a = vi[i].i;
                int b = vi[i + 1].i;
                int c = vi[i + 2].i;
                int d = vi[i + 3].i;
                if (belong[x] < belong[x + v]) {
                    ans[a] = 0;
                    ans[b] = 0;
                    ans[c] = 1;
                    ans[d] = 1;
                } else {
                    ans[a] = 0;
                    ans[b] = 1;
                    ans[c] = 0;
                    ans[d] = 1;
                }
            }
        }
        return check;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> v;
        n = v << 2;
        for (int i = 1; i <= n; i++) {
            cin >> vi[i].v;
            vi[i].i = i;
        }
        bool check = compute();
        if (check) {
            cout << "Yes" << "\n";
            for (int i = 1; i <= n; i++) {
                cout << ans[i];
            }
        } else {
            cout << "No" << "\n";
        }
        return 0;
    }

七、复杂度分析

项目划分可重集（P7477）喵了个喵 II（P9139）
离散化 / 排序O(n log n)O(n log n)
一次 check 建图O((n + m) log n) 条边O(n log n) 条边（组数 4n）
Tarjan 缩点O(n log n)O(n log n)
外层二分 O(log maxV) 次 check一次
总时间O((n + m) log n log maxV)O(n log n)
朴素建图（对照）一条值规则就 O(n) 条边，总计 O(n² + m)
额外空间O((n + m) log n)O(n log n)

P7477 的代价主要在二分：每次 check 都要重建整张图再缩点，log maxV 次叠加。P9139 没有二分，建一次图缩一次点就出答案；构造方案是缩点序顺带完成的，不额外付费。

空间上两题都是虚点、边、Tarjan 栈三块，按 O(n log n) 开；值域相关的数组（树状数组槽位、主席树版本数组）离散化后同样压到 n 的量级。主席树版和 CDQ 版的边数同阶，只是常数的差别。

八、最后

两道题合起来给这一讲收了尾：优化建图提供「点到一片」的边，2-SAT 提供判定和构造的框架，二分把最优值问题折成 feasibility。三种实现同图同解，说明树状数组、主席树、CDQ 处理范围和时间维的能力是等价的，选哪个，看范围是前缀还是区间、时间维要不要快照、代码想写多长。

往回看四页其实是一条线：把「连向一片」里的「一片」越换越抽象，前缀、区间、偏序矩形、嵌套的组，数据结构跟着换，图的语义从头到尾没变过。这也是优化建图能当通用件使的原因。
