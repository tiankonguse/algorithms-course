值域上取最值：平衡子序列与理想子序列

有一类子序列动态规划长成这个样子：dp[i] = nums[i] + max{dp[j]}，其中 j 要满足一个关于「值」的条件。条件是成对的，看着像要回头扫一遍前面所有位置。但只要把这个条件挪一挪，改写成「j 的某个量不超过 i 的同一个量」，max 就变成值域上的一段前缀最值，树状数组一次搞定。下面两道题都是这个套路，一个值域到 10 的 9 次方要离散化，一个值域只有 26。

零、背景

最长递增子序列那类题的转移，内层是「在所有能接在 i 前面的 j 里取最大值」。值域小的时候开个数组记 best[值] 就行，扫的时候顺便维护前缀最大值。值域一大，数组开不下，但仔细看会发现我们只问「不超过某个值的那一段里最大是多少」，这正是树状数组的前缀查询。于是数组换成树状数组，单次转移从 O(n) 变成 O(log n)。

判断能不能用，就看一件事：接上去的条件能不能写成单个量的大小比较。能写成，就有前缀最值；写不成，得换别的思路。

一、问题

题目一：平衡子序列的最大和。给定长度 n 的数组 nums。如果下标 i 和 j 都被选进子序列，且 i 在 j 左边，那么必须有 nums[j] - nums[i] >= j - i。任意两个被选中的下标都满足这个要求，子序列就是平衡的。返回所有平衡子序列里最大的累加和。数据范围 1 <= n <= 10^5，-10^9 <= nums[i] <= +10^9。

题目二：最长理想子序列。给定长度 n、只由小写字母组成的字符串 s，以及非负整数 k。子序列里任意相邻两个字符在字母表中的位次之差绝对值不超过 k，就叫理想子序列。返回最长理想子序列的长度。数据范围 1 <= n <= 10^5，0 <= k <= 25。

二、把平衡条件挪成单个量

题目一的条件写成 nums[j] - nums[i] >= j - i，四个量混在一起。把带 j 的挪到一边、带 i 的挪到另一边：

记 v[i] = nums[i] - i，条件就变成 v[j] >= v[i]。于是「平衡」等价于「选出的那些位置，v 值非降」。这一步是整道题的转折，它把两两之间的约束降级成相邻两个之间的约束：只要子序列里相邻两个满足 v 不降，传递性保证任意两个都满足。

于是转移式可以写出来了。设 dp[i] 为「以 i 结尾的平衡子序列的最大和」，那么能接在 i 前面的 j 满足 j < i 且 v[j] <= v[i]：

三、树状数组维护前缀最大值

转移的内层是「v 值不超过 v[i] 的那些 dp[j] 里取最大」。因为我们是按下标从小到大扫的，扫到 i 时树里装的正好是所有 j < i 的记录，下标那一维自动满足。

v[i] 能到正负 10 的 9 次方，还是要离散化：把所有 v 排个序去重，用名次当下标。树状数组的 add 换成取 max，sum 换成前缀取 max。

初始时树里每个位置都是「负无穷」。查询拿到负无穷说明前面没有能接的，那就不要前面，让 nums[i] 自己开一个子序列。更一般的判断是拿到负数就丢掉前面：既然要最大和，接一个负数的前缀只会更差。

int rankv(long long v) {
        int left = 1, right = m, mid;
        int ans = 0;
        while (left <= right) {
            mid = (left + right) / 2;
            if (sortv[mid] <= v) {
                ans = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans;
    }

long long maxBalancedSubsequenceSum(vector<long long>& nums) {
        build(nums);
        long long pre;
        for (int i = 0, k; i < n; i++) {
            k = rankv(nums[i] - i);
            pre = query(k);
            if (pre < 0) {
                update(k, nums[i]);
            } else {
                update(k, pre + nums[i]);
            }
        }
        return query(m);
    }

这里有个细节：nums[i] - i 里的 i 是 0 起的下标，离散化用的也是同一套下标。混用 1 起和 0 起会让整个数组整体偏移 1，因为是比较而不是相等，答案不变，但和别的代码对拍时容易看不出来。统一成一种写法省心。

四、最长理想子序列：值域只有 26

题目二的形状几乎一样。设 dp[c] 为「当前扫过的位置里，以字符 c 结尾的最长理想子序列长度」。扫到一个字符 v 时，能接在它前面的字符位次在 [v-k, v+k] 里，取这一段的最大值再加一：

字符集只有 26，其实直接把这个区间里的值挨个扫一遍也行，单次转移 26 次比较，总时间 O(26n)。用线段树是 O(n log 26)，两者在 n = 10 的 5 次方这个量级上差不出多少，线段树的意义在于它说明这条路能推广：字符集换成 10 的 5 次方个不同的值，同样的代码照样跑。

void up(int i) {
        segmax[i] = max(segmax[i << 1], segmax[i << 1 | 1]);
    }

    void update(int jobi, int jobv, int l, int r, int i) {
        if (l == r && jobi == l) {
            segmax[i] = jobv;
        } else {
            int m = (l + r) >> 1;
            if (jobi <= m) {
                update(jobi, jobv, l, m, i << 1);
            } else {
                update(jobi, jobv, m + 1, r, i << 1 | 1);
            }
            up(i);
        }
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            return segmax[i];
        }
        int m = (l + r) >> 1;
        int ans = 0;
        if (jobl <= m) {
            ans = max(ans, query(jobl, jobr, l, m, i << 1));
        }
        if (jobr > m) {
            ans = max(ans, query(jobl, jobr, m + 1, r, i << 1 | 1));
        }
        return ans;
    }
int longestIdealString(string s, int k) {
        memset(segmax, 0, sizeof(segmax));
        int v, p;
        int ans = 0;
        for (char cha : s) {
            v = cha - 'a' + 1;
            p = query(max(v - k, 1), min(v + k, 26), 1, 26, 1);
            ans = max(ans, p + 1);
            update(v, p + 1, 1, 26, 1);
        }
        return ans;
    }

单点更新不需要懒标记。更新的任务一定从根直插到某个叶子，路径上没有「整段一起变」这回事，up 一路把最大值推上去就够了。这也是线段树里最省事的一种用法：只查只改，没有区间修改。

复杂度分析

题目朴素转移优化后额外空间
平衡子序列的最大和O(n²)O(n log n)O(n)
最长理想子序列（挨个扫）O(n²)O(26n)O(26)
最长理想子序列（线段树）O(n²)O(n log 26)O(26)

平衡子序列这一题：离散化排序 O(n log n)，之后 n 次转移，每次一次 rank 二分 O(log n)、一次前缀查询 O(log n)、一次单点取 max O(log n)，合计 O(n log n)。空间是名次数组 n 个 int 加树状数组 n 个 long long，按题目上限 n = 10 的 5 次方算约 1.2 MB。注意 dp 值可能到 10 的 14 次方，必须用 long long，用 int 会在中间结果上溢出。

最长理想子序列这一题：字符集固定 26，线段树数组开 4 * 26 就够，额外空间 O(1) 级别。时间上每个字符一次 O(log 26) 的查询加一次 O(log 26) 的更新，log 26 大约是 4.7，和直接扫区间的 26 次比较处在同一量级。

总结

两道题的骨架是同一句：把配对的条件挪成单个量的大小比较，转移的内层就变成值域上的前缀最值（或者区间最值），交给树状数组或线段树。离散化负责把无界值域压成 1 到 m 的名次，按下标顺序扫保证「j < i」这一维自动成立。

几个实操上的点：树状数组取 max 时初始值要设成负无穷而不是 0，否则负数样例上「没有前驱」和「前驱和为 0」分不开；平衡子序列的 dp 值要用 long long；单点更新的线段树不需要懒标记。往后看到「能接上的条件是某某值不超过某某值」这种描述，就可以直接往这个套路上想。
