三种建图：邻接矩阵、邻接表、链式前向星

给 n 个点 m 条边，建图就是把「每条边 u→v 权 w」存下来。三种存法：邻接矩阵按点对存，邻接表按起点挂边，链式前向星用几个定长数组模拟邻接表。同一张有向带权图，n=2000、m=200000 实测：矩阵 4.71ms、邻接表 2.86ms、链式前向星 0.36ms。

零、背景

图题的第一步永远是建图。点的编号是 1 到 n，输入一般给 n、m 和 m 条边。三种方式都能把图存下来，区别在空间、速度和写法。

邻接矩阵：开一个 n×n 的表，g[i][j] 存 i→j 的边权。查任意两点之间有没有边是 O(1)，但空间是 O(n²)，n 上万就存不下。适合点的数量不多的图。

邻接表：每个点挂一个列表，列表里存邻居和边权。空间 O(n+m)，最常用的方式，比赛和笔试都够用。

链式前向星：邻接表的静态数组版，用 head、nxt、to、weight 四个数组模拟链表。比赛平台卡空间时用它，因为它不依赖容器、内存布局紧凑。注意无向图一条边要存两次，边的数组要开 2m。

一、同一张图的三种存法

用有向带权例 1：点 1..4，边 {1→3 权6, 4→3 权4, 2→4 权2, 1→2 权7, 2→3 权5, 3→1 权1}。

邻接表里边的顺序和输入顺序一致；链式前向星是头插，遍历时看到的是输入顺序的反序。看上面的例子，1 的邻居在表里是 (3,6)、(2,7)，链式前向星遍历出来是 (2,7)、(3,6)，正好反过来。

二、链式前向星的内存布局

链式前向星的核心是四个数组：head[i] 存点 i 的第一条边的编号，nxt[e] 存边 e 的下一条边的编号，to[e] 存边 e 指向的点，weight[e] 存边权。cnt 是边计数器，从 1 开始。

加边 addEdge(u, v, w) 做三件事：nxt[cnt] = head[u] 把新边接到旧头前面，to[cnt] = v、weight[cnt] = w，head[u] = cnt++ 让新边当新头。这就是头插，所以遍历顺序是反的。

遍历点 u 的所有出边，标准写法是 for (int ei = head[u]; ei > 0; ei = nxt[ei])，拿 to[ei] 是邻居、weight[ei] 是边权。这个 for 循环的写法要记牢，后面拓扑排序、最短路全是它。

边的数组大小：有向图 m 条边开 m+1，无向图一条边变两条，开 2m+1。开小了会越界写坏内存，这类 bug 编译器一句话都不说。

三、代码

三种方式一起写进一个结构：build(n) 清空重建，directGraph 建带权有向图，undirectGraph 建带权无向图（每条边双向加），addEdge 是链式前向星专用。

#include <bits/stdc++.h>
    using namespace std;
    // ================= 题 1：三种建图方式与遍历 =================
    namespace GraphBuild {
    const int MAXN = 11, MAXM = 21;
    int graph1[MAXN][MAXN];
    vector<vector<pair<int, int>>> graph2;
    int head[MAXN], nxt[MAXM], to[MAXM], weight[MAXM], cnt;

    void build(int n) {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++) graph1[i][j] = 0;
        graph2.clear();
        graph2.resize(n + 1);
        cnt = 1;
        fill(head, head + n + 1, 0);
    }

    // 链式前向星加边
    void addEdge(int u, int v, int w) {
        nxt[cnt] = head[u];
        to[cnt] = v;
        weight[cnt] = w;
        head[u] = cnt++;
    }

    // 有向带权图
    void directGraph(const vector<array<int, 3>>& edges) {
        for (auto& e : edges) graph1[e[0]][e[1]] = e[2];
        for (auto& e : edges) graph2[e[0]].push_back({e[1], e[2]});
        for (auto& e : edges) addEdge(e[0], e[1], e[2]);
    }

    // 无向带权图
    void undirectGraph(const vector<array<int, 3>>& edges) {
        for (auto& e : edges) { graph1[e[0]][e[1]] = e[2]; graph1[e[1]][e[0]] = e[2]; }
        for (auto& e : edges) {
            graph2[e[0]].push_back({e[1], e[2]});
            graph2[e[1]].push_back({e[0], e[2]});
        }
        for (auto& e : edges) { addEdge(e[0], e[1], e[2]); addEdge(e[1], e[0], e[2]); }
    }
    } // namespace GraphBuild

    // ================= 题 2：拓扑排序模版（邻接表动态建图，LC210） =================

总结

选哪种存法看两件事：点多不多、平台卡不卡空间。点少用矩阵，查边 O(1)；一般题用邻接表，写着最省心；比赛或静态空间优先用链式前向星，四个数组 + 一个 cnt，头插加边。

链式前向星的遍历顺序是输入的反序，如果题目对输出顺序敏感（比如拓扑排序要字典序），不能依赖加边顺序，要用下一页的小根堆那套。
