差分数组：区间加一次 O(1)

m 次操作，每次给区间 [l, r] 的所有数加同一个数，最后问每个位置的值。朴素做法每次把区间里的数挨个加一遍，差分数组改成只碰两个点，一遍前缀和收尾。

零、背景

给一个长度为 n 的数组做 m 次区间加：每次在 [l, r] 内每个数加 x，所有操作做完后问每个位置的最终值。n 和 m 都到 2×10⁵ 时，朴素做法枚举每个操作里的每个位置，总工作量 O(n·m)，约 4×10¹⁰ 次加法，跑不动。

这题只看最终结果，不在乎过程中间长什么样。差分数组就是为「批量改、最后查」准备的：把区间加拆成两个点加，做完所有操作后再用一遍前缀和把数组还原出来。

一、差分数组

记差分数组 D，定义 D[i] = A[i] - A[i-1]（A[0] 视作 0）。给区间 [l, r] 每个数加 x，只动两个位置：

D[l] += x，D[r+1] -= x。

为什么只动两个点：区间内部的相邻差不变（每个数都加了 x，差还是差）；A[l] 比 A[l-1] 多加了 x，所以 D[l] 跳 +x；A[r+1] 没加而 A[r] 加了，D[r+1] 跳 -x。所有操作做完后，A[i] = D[1] + D[2] + … + D[i]，一遍前缀和还原。

二、航班预订统计

LeetCode 1109：n 个航班，bookings[i] = [first, last, seats] 表示在 first 到 last 的每个航班上订了 seats 个座位，求每个航班的座位总数。这就是区间加：把 [first, last] 每个位置加 seats。

差分数组直接套：diff[first] += seats、diff[last+1] -= seats，所有预订处理完，一遍前缀和就是每个航班的答案。

三、朴素为什么慢

朴素做法每次遍历整个区间逐个加，总工作量是「操作数 × 平均段长」。差分数组每个操作只碰两个点，外加一遍 O(n) 前缀和。n=m=2×10⁵ 时，实测（本机 g++ -O2）：差分 0.68ms 跑完；暴力枚举 n=m=8×10³ 要 1.67ms，按 O(n·m) 外推到 2×10⁵ 约 1 秒，差了约 1500 倍。

四、复杂度与实测

时间 O(n+m)：m 次操作每次 O(1)，一遍前缀和 O(n)。空间 O(n)：差分数组和原数组同长。

代价是「不支持边操作、边查询」：差分数组里的值在还原之前不是真实值，想中途读某个位置得先做前缀和。边改边查是树状数组和线段树的活，后面课里见。

五、代码

航班预订统计的实现，整道题就一个函数：

// 题1：航班预订统计（LeetCode 1109）
    // bookings[i] = [first, last, seats]
    // 区间 [first, last] 每个位置 +seats → 差分两个点
    vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
        vector<int> diff(n + 2, 0);
        for (auto& book : bookings) {
            diff[book[0]] += book[2];       // 左端点 +seats
            diff[book[1] + 1] -= book[2];   // 右端点后一个位置 -seats
        }
        vector<int> ans(n);
        for (int i = 1, cur = 0; i <= n; i++) {
            cur += diff[i];                 // 一遍前缀和还原
            ans[i - 1] = cur;
        }
        return ans;
    }

总结

差分数组把区间加拆成两个点加：D[l] += x、D[r+1] -= x，全部操作做完后一遍前缀和还原。适合「批量改、最后查」的问题，O(n·m) 降到 O(n+m)。

这一讲加的是同一个数。下一讲区间里加的是等差数列，每项都不一样，差分数组要再差一次。
