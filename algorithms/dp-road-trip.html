开车旅行：最近次近与倍增

每个点右侧有第一近、第二近两个目标。a 开车永远去第二近，b 开车永远去第一近，两人轮流开。先 O(n log n) 预处理出每个点的最近和次近，再把「a、b 各开一次」当成一轮，用倍增表回答每一组查询。

零、背景

给一个长度为 n、无重复值的数组。对位置 i 的数字 x，只看右侧的数字，距离定义为差值绝对值，距离越小越近；距离一样时数值越小的越近。每个位置要第一近的位置与距离、第二近的位置与距离，分别记 to1/dist1、to2/dist2，不存在记 0。

a 和 b 同坐一辆车往右旅行，a 先开车，b 后开，此后每到达一个点就换人。a 在某点驾驶时车去该点右侧第二近的点，b 驾驶时去第一近的点。从 s 出发，开车总距离超过 x，或轮到某人时右侧无点可选，就停。问题 1：给定 x0，返回从哪个点出发 a 距离 / b 距离的比值最小，多个最小取 arr 值最大的点；问题 2：给定 s、x，返回 a、b 各开了多少。n、m ≤ 10⁵，x ≤ 10⁹。

问题 2 有 m 组查询，每组都从头模拟一轮一轮走会到 O(nm)。要先把「最近次近」预处理出来，再用倍增把「一轮一轮走」变成「2^p 轮一跳」。

一、最近次近：数组手搓双向链表

朴素做法是每个位置扫一遍右侧，O(n²)。有序表从右往左插入、查前驱后继也能做，但笔试、比赛里动态结构可能被卡空间。这里用手搓的双向链表，只用三个数组。

做法：按值从小到大排序，得到值序 rk。对每个位置建双向链表：last[i] 是值上比 arr[i] 小的最近位置，nxt[i] 是比它大的最近位置。然后按位置 1..n 依次处理：处理到 i 时，链表里剩下的全是位置 > i 的点，正好是 i 的右侧。i 的最近、次近一定在值上最接近的 4 个候选取里：前驱、前驱的前驱、后继、后继的后继。更新完把 i 从链表删掉。

为什么 4 个就够：最近、次近是右侧里距离最小的两个点，按值排它们必然贴着 i，顶多隔一层，前驱和后继是最近的两个候选，再往外一层的前驱的前驱、后继的后继补上次近的位置。

二、一轮开车 + 倍增表

最近次近到手后，开车规则是固定的：从 i 出发，a 先开去 to2[i]，b 再开去 to1[to2[i]]。把「a 开一次 + b 开一次」当成一轮：

stto[i][0] = to1[to2[i]]（一轮结束的位置）；stdist[i][0] = dist2[i] + dist1[to2[i]]（一轮总距离）；sta[i][0] = dist2[i]、stb[i][0] = dist1[to2[i]]（这一轮里 a、b 各开多少）。

然后倍增合并：从 i 出发开 2^p 轮，等于先开 2^(p−1) 轮到 stto[i][p−1]，再从那继续开 2^(p−1) 轮。距离、a 的累计、b 的累计都跟着拼：

三、查询：贪心跳 + 补最后一步

Travel(s, x)：p 从 20 往 0 试，如果 stto[s][p] 非 0（还有地方可去）且 x ≥ stdist[s][p]（油够开完 2^p 轮），就整段跳过去，扣油、累加 a、b。跳完后可能还剩最后一次 a 的开：a 先开，每轮收在 b 开完的位置，所以最后一格只可能是 a 开，检查 dist2[s] ≤ x 就补上。

问题 1 的 best(x0)：对每个起点 i（1..n−1）跑一次 Travel(i, x0)，算 a / b 比值，b = 0 时比值视作无穷大。取比值最小的起点，比值相同取 arr 值更大的。每个起点 O(log n)，总共 O(n log n)。

四、代码

先看最近次近的链表预处理。这里有个细节：单段距离最大到 2 × 10⁹，两段相加会超 int，所以下面的倍增累计数组用 long long：

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100005;
    int arr[MAXN];
    // to1/dist1 : 第一近的位置与距离，to2/dist2 : 第二近
    int to1[MAXN], dist1[MAXN], to2[MAXN], dist2[MAXN];
    int last[MAXN], nxt[MAXN];

    // 用 j 尝试更新 i 的第一近、第二近
    // 距离更小更近；距离一样时数值更小更近
    void Update(int i, int j) {
        if (j == 0) {
            return;
        }
        int d = abs(arr[i] - arr[j]);
        if (to1[i] == 0 || d < dist1[i] ||
            (d == dist1[i] && arr[j] < arr[to1[i]])) {
            to2[i] = to1[i];
            dist2[i] = dist1[i];
            to1[i] = j;
            dist1[i] = d;
        } else if (to2[i] == 0 || d < dist2[i] ||
                   (d == dist2[i] && arr[j] < arr[to2[i]])) {
            to2[i] = j;
            dist2[i] = d;
        }
    }

    // 从双向链表里摘掉 i
    void Delete(int i) {
        int l = last[i], r = nxt[i];
        if (l != 0) {
            nxt[l] = r;
        }
        if (r != 0) {
            last[r] = l;
        }
    }

    // 数组手搓双向链表：按值排序建链，再按位置从小到大处理并删除
    void Near() {
        vector<pair<int, int>> rk;   // (值, 位置)，按值排序
        for (int i = 1; i <= n; i++) {
            rk.push_back({arr[i], i});
        }
        sort(rk.begin(), rk.end());
        rk.insert(rk.begin(), {0, 0});
        rk.push_back({0, 0});
        for (int i = 1; i <= n; i++) {
            last[rk[i].second] = rk[i - 1].second;
            nxt[rk[i].second] = rk[i + 1].second;
        }
        // 处理到 i 时，链表里剩下的都是位置 > i 的点，即 i 右侧的点
        // 值上最接近的 4 个候选：前驱、前驱的前驱、后继、后继的后继
        for (int i = 1; i <= n; i++) {
            to1[i] = dist1[i] = to2[i] = dist2[i] = 0;
            Update(i, last[i]);
            Update(i, last[last[i]]);
            Update(i, nxt[i]);
            Update(i, nxt[nxt[i]]);
            Delete(i);
        }
    }

倍增表与查询：

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100005;
    const int MAXP = 20;
    int arr[MAXN];
    int to1[MAXN], dist1[MAXN], to2[MAXN], dist2[MAXN];
    // stto[i][p] : 从 i 出发，a/b 轮流开 2^p 轮后到达的点
    // sta/stb/stdist : 这段路程里 a 开、b 开、合计的距离
    // 单段距离可达 2*10^9，两段相加会超 int，累计数组用 long long
    int stto[MAXN][MAXP + 1];
    long long stdist[MAXN][MAXP + 1];
    long long sta[MAXN][MAXP + 1];
    long long stb[MAXN][MAXP + 1];
    int n;

    // 一轮 = a 开一次（去第二近）+ b 开一次（去第一近）
    void ST() {
        for (int i = 1; i <= n; i++) {
            stto[i][0] = to1[to2[i]];
            stdist[i][0] = (long long)dist2[i] + dist1[to2[i]];
            sta[i][0] = dist2[i];
            stb[i][0] = dist1[to2[i]];
        }
        for (int p = 1; p <= MAXP; p++) {
            for (int i = 1; i <= n; i++) {
                stto[i][p] = stto[stto[i][p - 1]][p - 1];
                if (stto[i][p] != 0) {
                    stdist[i][p] = stdist[i][p - 1] + stdist[stto[i][p - 1]][p - 1];
                    sta[i][p] = sta[i][p - 1] + sta[stto[i][p - 1]][p - 1];
                    stb[i][p] = stb[i][p - 1] + stb[stto[i][p - 1]][p - 1];
                }
            }
        }
    }

    long long A, B;   // 本次旅行 a、b 各开了多少

    // 从 s 出发，开车总距离不超过 x
    void Travel(int s, long long x) {
        A = 0;
        B = 0;
        for (int p = MAXP; p >= 0; p--) {
            if (stto[s][p] != 0 && x >= stdist[s][p]) {
                x -= stdist[s][p];
                A += sta[s][p];
                B += stb[s][p];
                s = stto[s][p];
            }
        }
        // 整轮跳完还剩一次 a 的开：a 先开，每轮停在 b 开完的位置
        if (dist2[s] <= x) {
            A += dist2[s];
        }
    }

五、复杂度分析

最近次近：排序 O(n log n)，每个位置看常数个候选，O(n)。倍增表 20 层每层 O(n)。单组查询从 p = 20 往 0 试，O(20)。问题 1 每个起点查一次 O(n log n)。空间 O(20n)。n、m = 10⁵ 时问题 2 的 m 组查询是 2 × 10⁶ 级别，稳过。

六、总结

要点：最近次近用按值排序的双向链表预处理，处理到 i 时链表里只剩右侧点，4 个候选覆盖最近次近；把「a 开 + b 开」打包成一轮，倍增表里同时记到达点、总距离、a 的累计、b 的累计；查询从大到小贪心跳整轮，最后只补 a 的一步。看到「交替按规则跳、大量查询」的题，先想能不能把两步打包成一轮再倍增。
