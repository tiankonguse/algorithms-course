统计重复个数：循环跳的倍增

s1 拼 a 次得到 x，s2 拼 b 次得到 y。问 y 再重复 m 次还能不能从 x 里作为子序列抠出来，返回最大的 m。答案只取决于 s1、s2 的长度，和 a、b 的值无关。

零、背景

如果 x 删掉一些字符能得到 y，就说 y 可以从 x 中获得，也就是 y 是 x 的子序列。现在 x = s1 拼接 a 次，y = s2 拼接 b 次，把 y 再拼接 m 次得到的串依然可能从 x 中获得，问最大的 m。

|s1|、|s2| ≤ 100，a、b ≤ 10⁶。直接构造 x = s1 × a 长度能到 10⁸，内存都放不下；就算放得下，m 的答案也不能靠逐次模拟，因为 a、b 太大。目标是做到时间复杂度与 a、b 的值无关。

一、next 表：循环找下一个字符要跨多远

匹配子序列时，s1 是可以循环的：走到末尾就绕回开头继续。next[i][c] 记从 s1 的 i 位置出发，循环扫描，第一次遇到字符 c 至少需要多长。

求法：right[c] 从后往前刷，记录 c 最近一次出现的位置。扫描到 i 时，right[c] 就是「i 之后最近的 c」或「下一轮的位置」，next[i][c] = right[c] − i + 1。s1 = "abc" 时，next[0]['b'] = 2（0→1 两步遇到 b），next[2]['a'] = 2（2→0 两步绕回 a）。

二、st 表：凑出 2^p 个 s2 要多长

st[i][0] 从 i 出发，把 s2 的字符挨个用 next 表接起来，得到一个 s2 需要的最短长度。s1 = "abc"、s2 = "ab"：从 0 出发，'a' 走 1 步到 1，'b' 走 1 步到 2，共 2；从 1 出发，'a' 要绕回 0 走 3 步到 1，'b' 走 1 步到 2，共 4。

更大的 p 用倍增：先凑出 2^(p−1) 个 s2，看落在哪个位置，再从那里继续凑 2^(p−1) 个。st[i][p] = st[i][p−1] + st[(st[i][p−1] + i) mod n][p−1]。

匹配一个 s2：从不同位置出发，逐字符走 next 表

三、贪心跳

表建好后，从 start = 0 出发，p 从 29 往下试：如果 st[start][p] + start ≤ n × a（x 的总长度），说明还能再塞进 2^p 个 s2，就跳：ans += 2^p，start += st[start][p]。大步长优先，最后 ans 就是能获得的 s2 个数。

答案要除以 b：y 本身是 s2 拼了 b 次，y 重复 m 次等于 s2 重复 b × m 次，所以 m = ans / b。除以 b 之前，ans 已经是尽量大的 s2 个数，b 整除即可。

这里有个细节：整个流程只用了 s1、s2 的长度 n 和 m2，a、b 只出现在最后一步的比较和除法里。所以复杂度 O(n × m2 + 30n)，和 a、b 的值无关。

四、代码

find 建 next 表 O(26n + m2)，st 表 O(n × m2)，倍增与贪心都是 O(30n) 级别：

#include <bits/stdc++.h>
    using namespace std;

    // next[i][c] : 从 s1 的 i 位置出发循环找字符 c，至少需要多长的 s1
    // right[c] 记录 c 最近一次出现的位置，从后往前刷
    bool Find(string& s1, int n, vector<vector<int>>& next_, string& s2) {
        vector<int> right(26, -1);
        for (int i = n - 1; i >= 0; i--) {
            right[s1[i] - 'a'] = i + n;
        }
        for (int i = n - 1; i >= 0; i--) {
            right[s1[i] - 'a'] = i;
            for (int j = 0; j < 26; j++) {
                next_[i][j] = (right[j] != -1) ? right[j] - i + 1 : -1;
            }
        }
        for (char c : s2) {
            if (next_[0][c - 'a'] == -1) {
                return false;   // 有字符在 s1 里根本不存在
            }
        }
        return true;
    }

    int GetMaxRepetitions(string str1, int a, string str2, int b) {
        string s1 = str1, s2 = str2;
        int n = s1.size();
        vector<vector<int>> next_(n, vector<int>(26));
        if (!Find(s1, n, next_, s2)) {
            return 0;
        }
        // st[i][p] : 从 i 位置出发，凑出 2^p 个 s2 至少需要多长的 s1
        vector<vector<long long>> st(n, vector<long long>(30));
        for (int i = 0; i < n; i++) {
            int cur = i;
            long long len = 0;
            for (char c : s2) {
                len += next_[cur][c - 'a'];
                cur = (cur + next_[cur][c - 'a']) % n;
            }
            st[i][0] = len;
        }
        // 倍增：先凑 2^(p-1) 个，落在新位置，再凑 2^(p-1) 个
        for (int p = 1; p <= 29; p++) {
            for (int i = 0; i < n; i++) {
                st[i][p] = st[i][p - 1] + st[(st[i][p - 1] + i) % n][p - 1];
            }
        }
        // 从 start = 0 贪心，先试大步长，x 里装得下就跳
        long long ans = 0, start = 0;
        for (int p = 29; p >= 0; p--) {
            if (st[start % n][p] + start <= (long long)n * a) {
                ans += 1LL << p;
                start += st[start % n][p];
            }
        }
        // ans 是 s2 的个数，y = s2 拼 b 次，所以能重复 ans / b 次
        return (int)(ans / b);
    }

五、复杂度分析

next 表 O(26n)，st[i][0] 每个起点扫一遍 s2 共 O(n × m2)，倍增 29 层 O(29n)，贪心 O(29)。总 O(n × m2 + 30n + 26n)，n、m2 ≤ 100，常数再大都无所谓。空间 O(26n + 30n)。时间与 a、b 完全无关，a、b = 10⁶ 和 a、b = 1 跑得一样快。

六、总结

要点：next 表让「循环找下一个字符」变成 O(1) 查询；st[i][p] 用倍增把「凑 2^p 个 s2」的长途跳拆成两段接力；查询从大到小贪心，塞得下就跳。看到「两个串各自重复若干次、问能抠出几个」的题，先想能不能只建和长度有关的表，把重复次数甩在查询阶段。
