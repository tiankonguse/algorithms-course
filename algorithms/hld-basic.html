重链剖分

重链剖分（Heavy Light Decomposition，HLD）给每个节点挑一个重儿子，重儿子之间连成重链。沿重链走 dfn 序号是连续的，于是任意两点间的路径被拆成 O(log n) 段连续区间，而子树本来就是一段。剩下的都交给线段树。

零、背景

线段树只会做一件事：数组上的区间操作。树没有数组那样的下标顺序，要用它，先得给节点排出一个顺序。

dfs 序能解决一半。一次 dfs 里，进入 u 到离开 u 之间的节点恰好是 u 的子树，所以子树就是一段连续区间，直接可用。

另一半解决不了：路径 u 到 v 上的点在 dfs 序里是散着的，中间夹着大量无关节点。重链剖分补的就是这一半，换一种遍历顺序（先走重儿子），让路径也能拆成少数几段连续区间。

一、两次 dfs 各填什么

dfs1 填 fa、dep、siz、son。son 是重儿子，也就是子树规模最大的那个儿子；几个儿子并列最大时任选一个，选哪个都不影响复杂度。

dfs2 填 top、dfn、seg。从根出发，先递归重儿子再递归剩下的儿子，每到一个节点发一个 dfn 号，同时记 seg[dfn] = 原节点编号。父节点和重儿子共用同一个 top，轻儿子自己当新链的链头。

可以发现重链只有顶端可能是轻儿子或者根，链中间的每一环都是父亲的重儿子。9 和 10 的 siz 都是 1，代码里取先遇到的那个（9）当重儿子，10 因此自开一条链。

dfs1 与 dfs2：

void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }
void dfs2(int u, int t) {
        top[u] = t;
        dfn[u] = ++cntd;
        seg[cntd] = u;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

二、两条性质

第一条：同一条重链上的节点 dfn 连续。dfs2 一进链就顺着重儿子走到底，中间不会插进别的节点。

第二条：同一棵子树的节点 dfn 连续，区间是 [dfn[u], dfn[u] + siz[u] − 1]。这条和普通 dfs 序一样，改遍历顺序不会破坏它。

有了这两条，子树操作是一次线段树区间操作，路径操作是若干次。段数取决于这条路径跨了几条重链。

三、路径怎么拆成区间

处理 x 到 y 时比较两个链头的深度：谁的链头更深，就处理谁那一条链上「链头到它自己」的整段，然后把它挪到链头的父亲。重复到两点落在同一条链上，最后补上两点之间那一段。

段数是 O(log n)。每处理完一条重链就要跨过一条轻边；u 是轻儿子时 u 的子树大小不超过父亲的一半，否则父亲的重儿子不会是别人。所以从任意点往根走，轻边不超过 log₂ n 条，一侧的段数不超过 log₂ n + 1，两侧合起来不超过 2 log₂ n + 1。

路径加与子树加、路径求和与子树求和：

void pathAdd(int x, int y, int v) {
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                add(dfn[top[y]], dfn[y], v, 1, n, 1);
                y = fa[top[y]];
            } else {
                add(dfn[top[x]], dfn[x], v, 1, n, 1);
                x = fa[top[x]];
            }
        }
        add(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]), v, 1, n, 1);
    }
void subtreeAdd(int x, int v) {
        add(dfn[x], dfn[x] + siz[x] - 1, v, 1, n, 1);
    }

    long long pathSum(int x, int y) {
        long long ans = 0;
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                ans = (ans + query(dfn[top[y]], dfn[y], 1, n, 1)) % MOD;
                y = fa[top[y]];
            } else {
                ans = (ans + query(dfn[top[x]], dfn[x], 1, n, 1)) % MOD;
                x = fa[top[x]];
            }
        }
        ans = (ans + query(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]), 1, n, 1)) % MOD;
        return ans;
    }

    long long subtreeSum(int x) {
        return query(dfn[x], dfn[x] + siz[x] - 1, 1, n, 1);
    }

四、题目1：重链剖分模版

洛谷 P3384。n 个节点、m 条操作，给定根 root 和模数 MOD。操作 1 是路径上加 v，操作 2 打印路径和，操作 3 是子树上加 v，操作 4 打印子树和，查询打印结果对 MOD 取模。n、m 不超过 10⁵。

四种操作正好各用一次上面的封装。线段树要支持区间加与区间求和，模板就是 lazy 标记那一套；注意所有加法都要取模，标记本身也要取模累加。

这里有个细节：线段树叶子上放的是 arr[seg[l]]，也就是按 dfn 顺序把点权摆进数组，不是 arr[l]。这一步漏了的话，所有查询都会错位。

复杂度分析

剖分是线性的，之后每一段区间操作都是一次线段树操作，代价由段数乘线段树单次的 O(log n) 决定。

操作时间说明
dfs1 + dfs2O(n)两个递归各把整棵树走一遍
建线段树O(n)按 dfn 顺序摆点权，自底向上合并
子树修改 / 查询O(log n)一次区间操作，区间是 [dfn[u], dfn[u]+siz[u]−1]
路径修改 / 查询O(log² n)不超过 2 log₂ n + 1 段，每段一次线段树操作
空间O(n)剖分数组 fa/dep/siz/son/top/dfn/seg 共 7n，线段树 4n

n = 10⁵ 时 2 log₂ n + 1 约 35 段，每段再乘线段树的 log₂ n，总规模在几千次基本操作，很宽裕。
