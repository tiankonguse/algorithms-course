笛卡尔树应用：把区间最值变成子树问题

笛卡尔树建树代码就十几行，难的是想明白「这道题的区间结构对应笛卡尔树的哪个部分」。这一课四道题覆盖四种翻译：插入序列的字典序最小拓扑序、最左端最大值位置的计数、直方图按矩形分块、消除收益按区间拆分。每一道都是建一棵笛卡尔树，剩下的交给树形 dp 或遍历。

零、背景

上一课的笛卡尔树：key 按下标组织成搜索树，value 按小根堆组织。有了它，「区间 [l, r] 的最小值在哪个位置」等于「找 l、r 的最近公共祖先」。这道题的区间结构被压缩进一棵树里。

四道题共用这个思路，但每个的「区间」含义不同。树的序里区间是「插入时间连续的一段」，序列计数里是「最左端最大值管辖的一段」，表格填数是「直方图里等高的一段」，砖块消除是「消除时还连着的一段」。看出这段结构对应笛卡尔树的哪个节点，题就解了一半。

一、树的序：字典序最小的插入序列

给定一个插入序列，它会在空搜索树里长出一棵 BST。反过来，给定一棵 BST 的最终形态，能长出它的插入序列很多：只要保证父节点比子节点先插入就行，这就是树的拓扑序。题目要字典序最小的那个。

两个观察。第一，x 是 y 的祖先，当且仅当 x 在插入序列里先于 y。所以合法序列恰好是所有拓扑序。第二，BST 有个关键性质：左子树里所有 key 都比根小，右子树里所有 key 都比根大。因此每步「从父已输出的节点里挑最小的」时，先序访问恰好每步都挑到可选的最小值：根固定后，左孩子一定比右孩子小，先走完左子树再走右子树。

结论：字典序最小的插入序列就是这棵树的先序遍历。怎么把「插入序列 → BST」反过来建树？读入时反转：arr[v] = i 表示数值 v 在第 i 次插入。于是 key = 数值（1..n），堆 = 插入时间（越早越小），建一棵小根堆笛卡尔树。树的先序遍历就是答案。

实现里先序用迭代栈写，避免递归爆栈（n 到 1e5，退化链会压爆递归）。

题3 完整实现（P1377 树的序）

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;

    int arr[MAXN];
    int left_[MAXN];
    int right_[MAXN];
    int stack_[MAXN];
    int n;

    void build() {
        for (int i = 1, top = 0, pos = 0; i <= n; i++) {
            pos = top;
            while (pos > 0 && arr[stack_[pos]] > arr[i]) {
                pos--;
            }
            if (pos > 0) {
                right_[stack_[pos]] = i;
            }
            if (pos < top) {
                left_[i] = stack_[pos + 1];
            }
            stack_[++pos] = i;
            top = pos;
        }
    }

    // 防止递归爆栈用迭代的方式实现先序遍历
    void pre() {
        int size = 1, i = 0, cur;
        while (size > 0) {
            cur = stack_[size--];
            arr[++i] = cur;
            if (right_[cur] != 0) {
                stack_[++size] = right_[cur];
            }
            if (left_[cur] != 0) {
                stack_[++size] = left_[cur];
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, v; i <= n; i++) {
            cin >> v;
            arr[v] = i;
        }
        build();
        pre();
        for (int i = 1; i <= n; i++) {
            if (i > 1) {
                cout << " ";
            }
            cout << arr[i];
        }
        cout << endl;
        return 0;
    }

二、序列计数：最左端最大值位置

定义最左端最大值位置：一段范围上取最大值，有多个相等时取最左的那个。给定数组 A，问有多少个等长数组 B（每个值在 [1, m]），使得任意子范围上 A 和 B 的最左端最大值位置相同。

先把 A 建成大根堆笛卡尔树。注意建树用严格小于才弹栈：相等的值不弹，先出现的留在上面。这样每个节点 u 恰好管辖一段区间，且 u 就是这段区间的最左端最大值位置（等值时最左的在上）。

B 要和 A 的划分一致，只要每个节点 u 满足：u 的管辖区间里，最左端最大值位置还是 u。等价于左子树所有值都小于 arr[u]（等于都不行，否则最左端会偏到左子树），右子树所有值小于等于 arr[u]。写成 dp 就是：

dp[u][j] = dp[u][j−1] + dp[左][j−1] × dp[右][j]

dp[u][j] 是 u 子树内所有节点值都不超过 j 的方案数。头节点取 j：左子树只能用 1..j−1，右子树用 1..j；前缀和 dp[u][j−1] 覆盖头节点取值 ≤ j−1 的情况。空子树 dp[0][j] = 1。

n、m 各自能到 2e5，但 n × m ≤ 1e6，所以 dp 表按当前这组 n、m 动态开，不提前开满。

题4 完整实现（CF1748E 序列计数）

#include <bits/stdc++.h>

    using namespace std;

    const int MOD = 1000000007;
    const int MAXN = 1000001;

    // 所有数字
    int arr[MAXN];

    // 笛卡尔树需要
    int left_[MAXN];
    int right_[MAXN];
    int stack_[MAXN];

    // tmp是动态规划的临时结果
    long long tmp[MAXN];

    int n, m;

    // 动态规划表，n * m <= 10^6，所以临时申请
    vector<vector<int>> dp;

    void build() {
        for (int i = 1, top = 0, pos; i <= n; i++) {
            pos = top;
            while (pos > 0 && arr[stack_[pos]] < arr[i]) {
                pos--;
            }
            if (pos > 0) {
                right_[stack_[pos]] = i;
            }
            if (pos < top) {
                left_[i] = stack_[pos + 1];
            }
            stack_[++pos] = i;
            top = pos;
        }
    }

    void dfs(int u) {
        if (u == 0) {
            return;
        }
        dfs(left_[u]);
        dfs(right_[u]);
        for (int j = 1; j <= m; j++) {
            tmp[j] = 1LL * dp[left_[u]][j - 1] * dp[right_[u]][j] % MOD;
        }
        for (int j = 1; j <= m; j++) {
            dp[u][j] = (dp[u][j - 1] + tmp[j]) % MOD;
        }
    }

    long long compute() {
        build();
        // 虽然n * m <= 10^6，但是n和m，单独都是2 * 10^5规模
        // 所以提前准备固定大小的表是不可能的，空间根本接受不了
        // 所以根据此时具体的n和m的大小，临时申请动态规划表，总大小不超过10^6
        dp.assign(n + 1, vector<int>(m + 1, 0));
        for (int j = 0; j <= m; j++) {
            // 没有节点时，不管要求节点值是什么，都默认有1种形态
            // 因为没有节点时，根本不影响任何决策
            dp[0][j] = 1;
        }
        dfs(stack_[1]);
        return dp[stack_[1]][m];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int cases;
        cin >> cases;
        for (int t = 1; t <= cases; t++) {
            cin >> n;
            cin >> m;
            for (int i = 1; i <= n; i++) {
                cin >> arr[i];
            }
            cout << compute() << endl;
        }
        return 0;
    }

三、表格填数：直方图切矩形

n 个直方图柱子紧挨着，第 i 列上方有 arr[i] 个格子。往这片区域放 k 个相同数字，任意两个不能在同一行或同一列。注意规则：同一行但中间被断开的两个格子不算冲突（不连通）。返回方法数。

三个基础结论先用起来。k×k 的矩形放 k 个不冲突：k!。n×m 的矩形放 k 个：先从 n 列里选 k 列、m 行里选 k 行、再把这 k 个数字排进去，C(n,k)·C(m,k)·k!。多边形区域要切成矩形才能用第二条。

用小根堆笛卡尔树切。节点 u 管一个矩形：列数是子树节点数 size[u]，高是 arr[u] − arr[fa]（u 的矩形是「比父节点多出来的那一段高度」）。整个直方图被切成一堆这样的矩形，矩形之间按树形嵌套。断开的行不冲突的规则恰好被这个切分消化：同一行不连通的格子属于不同子树区域，不会被同时选到冲突。

树上 dp：dp[u][i] 是 u 的矩形加子树区域放 i 个的方案数。子树先放 p 个（占 p 列），剩余 i−p 个放 u 自己的矩形：这个矩形 size[u]−p 列、arr[u]−arr[fa] 行，套第二个结论。转移：

dp[u][i] += C(size[u]−p, i−p) · C(arr[u]−arr[fa], i−p) · (i−p)! · dp[左][l]·dp[右][r]

p = l + r 是左右子树合计放的个数，先合并左右子树成一个多项式 tmp[p]，再和矩形区域组合。n、k ≤ 500，总复杂度 O(n·k²)。arr 能到 1e6，阶乘表和逆元表开到 1e6。

题5 完整实现（P6453 表格填数）

#include <bits/stdc++.h>

    using namespace std;

    const int MOD = 1000000007;
    const int MAXN = 501;
    const int MAXH = 1000000;

    // 所有数字
    int arr[MAXN];

    // 阶乘余数表
    int fac[MAXH + 1];

    // 阶乘逆元表
    int inv[MAXH + 1];

    // 笛卡尔树需要
    int left_[MAXN];
    int right_[MAXN];
    int stack_[MAXN];

    // dfs需要
    int size_[MAXN];

    // dp是动态规划表
    int dp[MAXN][MAXN];

    // tmp是动态规划的临时结果
    int tmp[MAXN];

    int n, k;

    int power(long long x, long long p) {
        long long ans = 1;
        while (p > 0) {
            if ((p & 1) == 1) {
                ans = ans * x % MOD;
            }
            x = x * x % MOD;
            p >>= 1;
        }
        return (int) ans;
    }

    int c(int n, int k) {
        return n < k ? 0 : (int) ((long long) fac[n] * inv[k] % MOD * inv[n - k] % MOD);
    }

    void build() {
        fac[0] = fac[1] = inv[0] = 1;
        for (int i = 2; i <= MAXH; i++) {
            fac[i] = (int) ((long long) fac[i - 1] * i % MOD);
        }
        inv[MAXH] = power(fac[MAXH], MOD - 2);
        for (int i = MAXH - 1; i >= 1; i--) {
            inv[i] = (int) ((long long) inv[i + 1] * (i + 1) % MOD);
        }
        for (int i = 1, top = 0, pos; i <= n; i++) {
            pos = top;
            while (pos > 0 && arr[stack_[pos]] > arr[i]) {
                pos--;
            }
            if (pos > 0) {
                right_[stack_[pos]] = i;
            }
            if (pos < top) {
                left_[i] = stack_[pos + 1];
            }
            stack_[++pos] = i;
            top = pos;
        }
    }

    void dfs(int u, int fa) {
        if (u == 0) {
            return;
        }
        dfs(left_[u], u);
        dfs(right_[u], u);
        size_[u] = size_[left_[u]] + size_[right_[u]] + 1;
        for (int i = 0; i <= k; i++) {
            tmp[i] = 0;
        }
        // 所有dfs过程都算上，这一部分的总复杂度O(n^2)
        for (int l = 0; l <= min(size_[left_[u]], k); l++) {
            for (int r = 0; r <= min(size_[right_[u]], k - l); r++) {
                tmp[l + r] = (tmp[l + r] + (long long) dp[left_[u]][l] * dp[right_[u]][r] % MOD) % MOD;
            }
        }
        // 所有dfs过程都算上，这一部分的总复杂度O(min(n的3次方, n * k平方))
        for (int i = 0; i <= min(size_[u], k); i++) {
            for (int p = 0; p <= i; p++) {
                dp[u][i] = (dp[u][i] + (long long) c(size_[u] - p, i - p) * c(arr[u] - arr[fa], i - p) % MOD
                            * fac[i - p] % MOD * tmp[p] % MOD) % MOD;
            }
        }
    }

    int compute() {
        build();
        dp[0][0] = 1;
        dfs(stack_[1], 0);
        return dp[stack_[1]][k];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        cin >> k;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        cout << compute() << endl;
        return 0;
    }

四、砖块消除：收益拆成每个位置的贡献

n 块砖排成一排，每次选一块消除，收益是它所在连续段（还没消除的砖）的重量和。一共有 n! 种消除顺序，问所有顺序的收益总和。

暴力枚举 n! 种顺序不可行，用期望线性性拆。总收益 = 每种顺序每步收益的和 = Σ_i arr[i] × (i 号砖被计入的总次数，跨所有顺序)。i 被计入一次，当且仅当某次消除发生在「包含 i 的连续段」里的某个位置。换到笛卡尔树的语言：把砖按重量建大根堆笛卡尔树，i 被计入的次数就是「消除过程中 i 的祖先被消到」的期望，算出来是调和级数。

直接给结论：i 号砖在所有顺序里被计入的期望次数是 H_i + H_{n−i+1} − 1，其中 H_k = 1 + 1/2 + … + 1/k。总收益 = n! × Σ_i (H_i + H_{n−i+1} − 1) · arr[i]。

演示：arr = [3, 5, 2, 4, 1]，每次消除当前段最重的砖

代码不用建笛卡尔树，公式直接算：连续数字逆元表造出 H 的模意义前缀和，一遍求和再乘 n!。这就是课件里「用笛卡尔树分析、用公式实现」的典型。

题6 完整实现（AT_agc028_b 砖块消除）

#include <bits/stdc++.h>

    using namespace std;

    const int MOD = 1000000007;
    const int MAXN = 100001;

    // 所有数字
    int arr[MAXN];

    // 连续数字逆元表
    int inv[MAXN];

    // sum[i] = (1/1 + 1/2 + 1/3 + ... + 1/i)，%MOD意义下的余数
    int sum_[MAXN];

    int n;

    void build() {
        inv[1] = 1;
        for (int i = 2; i <= n; i++) {
            inv[i] = (int) (MOD - (long long) inv[MOD % i] * (MOD / i) % MOD);
        }
        for (int i = 1; i <= n; i++) {
            sum_[i] = (sum_[i - 1] + inv[i]) % MOD;
        }
    }

    long long compute() {
        build();
        long long ans = 0;
        for (int i = 1; i <= n; i++) {
            ans = (ans + (long long) (sum_[i] + sum_[n - i + 1] - 1) * arr[i]) % MOD;
        }
        for (int i = 1; i <= n; i++) {
            ans = ans * i % MOD;
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        cout << compute() << endl;
        return 0;
    }

五、总结

四道题四棵树：树的序用「插入时间」当堆值建树，先序就是答案；序列计数用「值」当堆值建大根堆树，区间划分对齐最左端最大值，dp 只差一个「左严格小于」；表格填数用小根堆树把直方图切成矩形，矩形放数套组合数；砖块消除根本不建树，但期望次数是从笛卡尔树的祖先关系推出来的调和级数。

建树的代码每次都是那十几行单调栈。识别「区间结构 → 树节点」，再用树形 dp 或遍历收尾，是这个专题真正的练习点。
