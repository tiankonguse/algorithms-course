线性基：高斯消元标准基与第 k 小异或和

普通消元的基回答不了第 k 小异或和。拿 {7, 10, 4} 试：普通基是 10 7 3，第三小异或和按它算是 4、第四小是 10，全错。换成高斯消元得到的标准基 9 4 3，第三小 7、第四小 9，才对。差别在于标准基里每个基的最高位是唯一的。

零、普通基为什么错

把两个基展开成二进制看：

普通基 10 7 3：1010、0111、0011。7 和 3 都占着最低位，枚举组合时低位互相干扰，组合结果按数值排不成单调顺序，没法回答「第 k 小」。

高斯基 9 4 3：1001、0100、0011。每个基的最高位互不相同，而且这个位在别的基里是 0，低位随便组合时高位纹丝不动，组合结果天然按低位二进制单调。于是第 k 小的异或和 = 把 k 拆成二进制，选对应的基。

所以第 k 小必须用高斯消元的标准基。好在异或空间的高斯消元能简化：不需要维护主元和自由元的依赖关系（上一课同余方程组要维护，异或空间不用，因为主元列在其他行里直接异或消掉，依赖自然不存在）。

一、高斯消元建标准基

过程：len 从 1 开始。按位从高到低扫：在 arr[len..n] 里找第 i 位为 1 的行，换到第 len 行；如果 arr[len] 第 i 位是 1，就把其他行第 i 位全消掉，len++；否则这一列没有主元，继续下一列。

// 高斯消元：得到标准形式的异或空间线性基
    // 异或空间不需要维护主元与自由元的依赖关系，写法可以简化
    int len;

    void gauss() {
      len = 1;
      for (int i = BIT; i >= 0; i--) {
        // 从第 len 行开始找第 i 位为 1 的行，换到第 len 行
        for (int j = len; j <= n; j++) {
          if ((arr[j] & (1LL << i)) != 0) {
            swap(arr[j], arr[len]);
            break;
          }
        }
        if ((arr[len] & (1LL << i)) != 0) {
          // 把其他行第 i 位都消掉
          for (int j = 1; j <= n; j++) {
            if (j != len && (arr[j] & (1LL << i)) != 0) {
              arr[j] ^= arr[len];
            }
          }
          len++;
        }
      }
      len--;
      zero = len != n;
    }

结束时 len 减 1 才是线性基大小。zero = len != n：消元后主元行数比原数组个数少，说明有的数字被消成了 0，原数组能异或出 0。

二、第 k 小查询

len 个标准基，每个基最高位唯一，任意组合出来的 2len 个异或和两两不同。zero 为 true 时 0 也在集合里：k = 1 直接返回 0，其余 k 减 1 再查非 0 部分；k 超过集合大小返回 −1。

查询就是按 k 的二进制选基：k 的第 j 位是 1，就异或上第 len−j 个基。arr[len] 是最小的基，对应 k 的最低位，所以从最小基开始取。

// 第 k 小的异或和：k 的二进制位决定选哪些基
    // len 个基，每个基的最高位唯一，可组合出 2^len 个异或和
    long long queryKth(long long k) {
      if (zero && k == 1) {
        return 0;
      }
      if (zero) {
        k--;
      }
      if (k >= 1LL << len) {
        return -1;
      }
      long long ans = 0;
      // arr[len] 最小，对应 k 的最低位
      for (int i = len, j = 0; i >= 1; i--, j++) {
        if ((k & (1LL << j)) != 0) {
          ans ^= arr[i];
        }
      }
      return ans;
    }

例4 里 k = 3 = 0b011，选第 2、3 个基 4 ^ 3 = 7，正是第三小；k = 4 = 0b100，选第 1 个基 9，正是第四小。而普通基 10 7 3 在这里会给出 4 和 10 的错误答案。

四、总结

标准基的每个基最高位唯一，这是第 k 小异或和能按二进制组合的前提。高斯消元 O(n × 位数) 建基，每次查询 O(位数)。普通消元能答的问题（大小、个数、有没有 0、最大异或和）高斯消元全都能答，但反过来不行，所以一般题目用普通消元就够了，只有要第 k 小才上高斯消元。下一节给两个普通消元的应用：带权选最大线性无关组、异或空间计数。
