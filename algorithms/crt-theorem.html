中国剩余定理：逐项构造同余解

「三三数之剩二，五五数之剩三，七七数之剩二，问物几何？」一个数除以 3 余 2、除以 5 余 3、除以 7 余 2，答案是 23。这种「多个余数条件叠在一起」的问题，中国剩余定理给出了一行构造：把每个条件各自凑出一个专用项，加在一起再取模。

零、背景

n 个同余方程 x ≡ r1 (mod m1)、x ≡ r2 (mod m2)、……、x ≡ rn (mod mn)，模数两两互质，求满足全部方程的最小非负解 x。孙子算经那个问题就是 n=3、模数 3、5、7。这类问题不枚举：互质模数下解必然存在，而且有整齐的构造公式。

先给结论再解释。令 lcm = m1·m2·…·mn（互质时乘积就是最小公倍数）。对第 i 个方程，算 ai = lcm / mi，再求 ai 在模 mi 意义下的逆元 ai'（ai·ai' ≡ 1 mod mi），于是 ci = (ri · ai · ai') mod lcm。全部算完后 x = (c1 + c2 + … + cn) mod lcm 就是答案。关键性质是 ci 只对第 i 个模数「负责」：ci mod mi = ri，而对任何 j ≠ i 都有 ci mod mj = 0。

一、ci 为什么能「各管各的」

mi 两两互质时，lcm / mi 与 mi 互质，所以 ai = lcm / mi 在模 mi 下一定存在逆元。ci = (ri·ai·ai') mod lcm 这个式子，拆开看三部分：ri 是目标余数，ai·ai' ≡ 1 (mod mi) 保证这一项对第 i 个模数的贡献是 ri 而不是别的，最后的 mod lcm 把项的大小限制住。

看它对其他模数：ci 是 ai = lcm / mi 的整数倍，而 lcm / mi 是 mj（j ≠ i）的整数倍（因为 lcm 是所有模数的公倍数），所以 ci mod mj = 0。加总时每一项只在自己那个模数上留下余数，别的模数上全是 0，互不干扰。

用孙子算经验证：m = [3, 5, 7]，lcm = 105。a1 = 35，35 mod 3 = 2，逆元是 2，c1 = (2·35·2) mod 105 = 35；a2 = 21，21 mod 5 = 1，逆元 1，c2 = 63；a3 = 15，15 mod 7 = 1，逆元 1，c3 = 30。x = (35 + 63 + 30) mod 105 = 23。检查 23 mod 3 = 2、23 mod 5 = 3、23 mod 7 = 2，全对。

二、为什么必须两两互质

互质是两条保证的来源：一是 ai = lcm/mi 与 mi 互质，逆元存在；二是「ci 对别的模数贡献 0」成立，因为 lcm/mi 是别的模数的倍数。模数不互质时这两个性质都会破。比如 m1=2、m2=4、r1=0、r2=1：x ≡ 0 (mod 2) 说明 x 是偶数，x ≡ 1 (mod 4) 说明 x 是奇数，两个条件直接打架，没有解。不互质的情形要等扩展中国剩余定理（下一页的内容）用迭代合并来处理。

三、模板实现

exgcd 顺手把逆元求了：exgcd(ai, mi) 后 x 变量就是 ai 在模 mi 下的逆元（互质时 d = 1）。乘法全程用龟速乘，ri、ai、逆元三个数相乘会溢出 long long，每一步取模就安全了。

#include <bits/stdc++.h>
    using namespace std;
    typedef long long ll;
    ll d, x, y, px, py;
    void exgcd(ll a, ll b) {
      if (b == 0) {
        d = a;
        x = 1;
        y = 0;
      } else {
        exgcd(b, a % b);
        px = x;
        py = y;
        x = py;
        y = px - py * (a / b);
      }
    }
    ll multiply(ll a, ll b, ll mod) {
      a = (a % mod + mod) % mod;
      b = (b % mod + mod) % mod;
      ll ans = 0;
      while (b != 0) {
        if (b & 1) ans = (ans + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
      }
      return ans;
    }
    ll crt(int n, ll m[], ll r[]) {
      ll lcm = 1;
      for (int i = 1; i <= n; i++) lcm = lcm * m[i];
      ll ai, ci, ans = 0;
      for (int i = 1; i <= n; i++) {
        ai = lcm / m[i];
        exgcd(ai, m[i]);
        ci = multiply(r[i], multiply(ai, x, lcm), lcm);
        ans = (ans + ci) % lcm;
      }
      return ans;
    }
    int main() {
      int n;
      cin >> n;
      ll m[15], r[15];
      for (int i = 1; i <= n; i++) cin >> m[i] >> r[i];
      cout << crt(n, m, r) << endl;
      return 0;
    }

四、为什么用模 105 而不是模 15

ci 的累加和先 mod lcm 再输出。lcm 是 105，答案 23 正好小于 105；如果不取模，35 + 63 + 30 = 128 也是解（128 mod 3 = 2、mod 5 = 3、mod 7 = 2），但它不是最小非负解。通解是 x = 最小非负解 + k·lcm，取模一步把 k 归零。

总结

中国剩余定理把 n 个同余条件变成 n 个互不干扰的项：每个 ci 在自己的模数上留下 ri、在别的模数上留下 0，累加取模就是最小非负解。两个硬前提，模数两两互质、乘法防溢出，缺一个答案就是错的。模数不互质或余数可能为负的题目，见扩展中国剩余定理那页。
