二维树状数组：范围加与矩形查

二维差分把「矩形里每个数加 v」拆成四个角上的单点修改；把前缀和公式展开成四项，每项配一张树状数组表，范围加与矩形查就都是 O(log n · log m)。

零、背景

单点加的二维树状数组能应付改一个格子。题目再进一步：把一个子矩形里的每个数都加上 v，同时还要查任意子矩形的和。矩形加套矩形查，一维上靠差分加两张表解决，二维上把同样的两步各做一遍。

代价是树状数组从一张变四张。这一节把四张表是怎么冒出来的推一遍，这比背结论重要，推导里每一步都能对上一维的写法。

一、问题

n 行 m 列的矩阵 a，支持两种操作。

  • 修改：子矩形 (a, b) 到 (c, d) 里每个数加 v。
  • 查询：子矩阵 (a, b) 到 (c, d) 的累加和。

这是洛谷 P4514「上帝的题目」，树状数组在这一问里的标准练手题。n、m 都到 2048。

二、二维差分：矩形加变四点

一维上，[l, r] 整段加 v 在差分 d 上只动两个点。二维上定义差分 d[i][j] = a[i][j] + a[i−1][j−1] − a[i−1][j] − a[i][j−1]，a[i][j] 就是 d 的二维前缀和。给矩形 (a, b) 到 (c, d) 每个数加 v，在 d 上是四个角：

d[a][b] += v;      d[c + 1][d + 1] += v;
d[a][d + 1] -= v;  d[c + 1][b] -= v;

以 (2, 2) 到 (4, 5) 加 3 为例，四个角长这样。

这一步照搬二维差分的结论就行，出错点在「角要打到边界外一格」，c + 1、d + 1 这些下标别漏。

三、前缀和的四张表

查 (1, 1) 到 (x, y) 的和，把 a[i][j] 换成差分的前缀和，交换求和顺序，每个 d[p][q] 的权重是它被多少个 (i, j) 覆盖，即 (x − p + 1)·(y − q + 1)。展开：

S(x, y) = Σ d[p][q]·(x + 1 − p)·(y + 1 − q)
        = (x+1)(y+1)·Σ d − (y+1)·Σ p·d − (x+1)·Σ q·d + Σ p·q·d

四项各自都是 d 的某个加权和的前缀和，于是开四张树状数组表：

info1[i][j] = d[i][j]
info2[i][j] = i·d[i][j]
info3[i][j] = j·d[i][j]
info4[i][j] = i·j·d[i][j]

查 S(x, y) 时把四张表在 (x, y) 的前缀和各取一次，代入公式。注意公式里用的是 x 和 y 本身，不是 i 和 j，这一点跟一维的写法不同，也是最容易抄错的地方。

5000 组随机序列（矩阵长宽 1 到 7、每组 25 个操作）实测三种错法：

  • 只维护 info1，把前缀和当 (x+1)(y+1)·Σd：100% 被抓。四张表少一张公式就残。
  • 照搬一维的写法，四张表全用 (i − 1)：100% 被抓。一维是因为求和上限把公式化简出了 −1，二维展开后没有这一项。
  • 矩形加只打 (a, b) 与 (c + 1, d + 1) 两个角：97.12% 被抓。

三档都在九成七往上，随机数据对这一问不客气，写错基本当场现形。

四、代码与开销

四张表共用同一个 (i, j) 循环，add 里算好四个系数一次写完。

const int MAXN = 2050;
    int info1[MAXN][MAXN], info2[MAXN][MAXN], info3[MAXN][MAXN], info4[MAXN][MAXN];
    int n, m;

    int lowbit(int i) {
        return i & -i;
    }

    // 差分数组的 (x,y) 位置加 v，四张表一起动
    void add(int x, int y, int v) {
        int v1 = v;
        int v2 = x * v;
        int v3 = y * v;
        int v4 = x * y * v;
        for (int i = x; i <= n; i += lowbit(i))
            for (int j = y; j <= m; j += lowbit(j)) {
                info1[i][j] += v1;
                info2[i][j] += v2;
                info3[i][j] += v3;
                info4[i][j] += v4;
            }
    }

    // 原数组 (1,1) 到 (x,y) 这个矩形的累加和
    int sum(int x, int y) {
        int ans = 0;
        for (int i = x; i > 0; i -= lowbit(i))
            for (int j = y; j > 0; j -= lowbit(j))
                ans += (x + 1) * (y + 1) * info1[i][j]
                     - (y + 1) * info2[i][j]
                     - (x + 1) * info3[i][j]
                     + info4[i][j];
        return ans;
    }

    // 矩形 (a,b) 到 (c,d) 每个数增加 v：四个角打标记
    void rangeAdd(int a, int b, int c, int d, int v) {
        add(a, b, v);
        add(c + 1, d + 1, v);
        add(a, d + 1, -v);
        add(c + 1, b, -v);
    }

    // 矩形 (a,b) 到 (c,d) 的累加和
    int rangeSum(int a, int b, int c, int d) {
        return sum(c, d) - sum(a - 1, d) - sum(c, b - 1) + sum(a - 1, b - 1);
    }

开销主要在空间。n = m = 2048 时一张 int 表是 2050² × 4 字节，四张 64.1 MB；换成 long long 直接翻倍到 128.3 MB。P4514 的数据范围下 int 够用，自己出题不确定就老老实实 long long，换来的代价是空间翻倍。

时间上，1000 × 1000 的矩阵、10⁵ 次操作（矩形加与矩形查各半）实测 51.86 ms。每次操作是常数次 O(log n · log m) 的循环，矩形加打四个角、矩形查容斥四次前缀和，都是固定倍数。

五、复杂度分析

操作时间复杂度
矩形加（四个角）O(log n · log m)
矩形查（四次前缀和）O(log n · log m)
建树（n·m 个初始值逐个矩形加）O(n·m·log n·log m)

空间 O(n · m)，常数是 4。建树也可以先算出二维差分再 O(n·m) 一次成型，但写起来繁琐，题目里逐个矩形加通常够用。

用二维线段树（树套树）也能做这一问，空间和代码量都要上一个台阶，能被四张表解决的问题不值得。

六、总结

二维的范围加与矩形查，是「差分 + 树状数组」在二维上的完整形态：矩形加靠二维差分拆成四个角，前缀和公式展开出四项，四张表分别存 d、i·d、j·d、i·j·d。公式 S(x, y) = (x+1)(y+1)·S₁ − (y+1)·S₂ − (x+1)·S₃ + S₄ 里代的是查询点坐标。

写的时候盯住三处：四个角的正负号与外扩一格；公式里的系数用 x、y 而不是循环变量；空间预算先算一遍，2048 见方的 int 四张表 64.1 MB。

树状数组的常见形态到这里就齐了。什么时候它不够用、什么时候该换线段树，边界也都在这一节里量过了。
