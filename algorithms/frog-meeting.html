青蛙的约会：同余方程与格点计数

两只青蛙在环上同向跳，什么时候相遇？把「位置相同」翻译成同余方程 (m−n)·t ≡ x2−x1 (mod l)，就变成上一页的 ax + by = c。顺带解决一类更简单的问题：两格点连线上的整点个数，答案是 |Δx| 与 |Δy| 的 gcd 加 1。

零、背景

环上从 0 号位开始顺时针转圈。青蛙 A 在 x1 位、每秒跳 m 格，青蛙 B 在 x2 位、每秒跳 n 格，问最少几秒后两蛙到同一个位置，永远到不了就输出 Impossible。l 最大 3×10^9，m、n 最大 2×10^9，逐秒模拟是不可能的。

t 秒后 A 在 x1 + m·t（模 l），B 在 x2 + n·t（模 l）。相遇等价于 (x1 + m·t) ≡ (x2 + n·t) (mod l)，移项得到 (m−n)·t ≡ x2−x1 (mod l)。这就是要解的式子。

一、同余方程转成 ax + by = c

同余式 a·t ≡ c (mod l) 的意思是 a·t − c 是 l 的倍数，也就是存在整数 k 使 a·t + l·k = c。这不就是二元一次不定方程？未知数是 t 和 k，系数是 a 和 l。上页模板直接可用：c 是 gcd(a, l) 的倍数时有解，否则 Impossible。

系数处理有个细节。a = m−n 可能是负数，exgcd 的入参要非负。课程的做法：x1 < x2 时取 a = m−n、c = x2−x1，否则取 a = n−m、c = x1−x2；若 a 还是负的，两边同取反：a = −a、c = l − c（a·t ≡ c (mod l) 两边乘 −1，c 变成 −c，模 l 下等于 l−c）。这样保证 a ≥ 0 且 c ∈ [0, l)。

二、最小正 t

exgcd(a, l) 给出 a·t + l·k = gcd(a,l) 的特解，放大 c/gcd 后得到原方程特解 t0。t 的步长是 l/gcd(a,l)，把 t0 挪成 ≥ 1 的最小正整数，就是「至少多久才能相遇」。挪法与上一页的 x 完全一致：负数往上加步长、正数往下减步长。

演示：环上两蛙逐秒位置
long long x1, x2, m, n, l;

    int main() {
        scanf("%lld %lld %lld %lld %lld", &x1, &x2, &m, &n, &l);
        long long a, c;
        if (x1 < x2) {
            a = m - n;
            c = x2 - x1;
        } else {
            a = n - m;
            c = x1 - x2;
        }
        if (a < 0) {
            a = -a;
            c = l - c;
        }
        exgcd(a, l);
        if (c % d != 0) {
            printf("Impossible\n");

            } else {
                x0 -= (x0 - 1) / xd * xd;

        return 0;

三、格点连线上有几个格点

回到平面网格。A(x1,y1)、B(x2,y2) 是格点（横纵坐标都是整数），问线段 AB 上有几个格点（含端点）。答案：gcd(|x1−x2|, |y1−y2|) + 1。

为什么？沿线段从 A 往 B 走，横坐标每过一个单位，纵坐标按 Δy/Δx 的比例走。线路上「横纵都恰好是整数」的位置，只在 Δx、Δy 同时除以它们最大公约数的时候出现：把 (Δx, Δy) 约成 (Δx/g, Δy/g)，每一步的增量是 (1 的整数倍, 整数的整数倍) 里最小的非零整数格点步，能踩到的整点就是 起点 + 0、1、2、…、g 倍的 (Δx/g, Δy/g)，共 g+1 个。

long long gcd(long long a, long long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    int main() {
        int cases;
        scanf("%d", &cases);
        for (int t = 1; t <= cases; t++) {
            long long x1, y1, x2, y2;
            scanf("%lld %lld %lld %lld", &x1, &y1, &x2, &y2);
            long long ans = gcd(llabs(x1 - x2), llabs(y1 - y2)) + 1;
            printf("Case %d: %lld\n", t, ans);
        }
        return 0;
    }

总结

青蛙约会把环上相遇翻译成 a·t ≡ c (mod l)，再展开成 a·t + l·k = c 套不定方程模板，注意先把 a 调非负；最小正 t 用步长 l/gcd 一次挪到位。格点计数则是 gcd 的直接应用：|Δx| 与 |Δy| 的 gcd 决定线段上整点间距，答案 gcd+1。下一页的机器人在网格上画多边形，边界格点数就靠这个结论累加。
