火星词典：从单词排序学字母顺序

火星人的字典已经按他们的字母顺序排好，但顺序对我们未知。相邻两个单词第一次出现不同字母的位置，就暴露一条「谁在谁前面」的偏序关系。把偏序关系建成图跑拓扑排序，得到的就是字母顺序。矛盾的输入返回空字符串。

零、背景

LeetCode 269：words 里的单词都按新语言字母顺序排好了。拿相邻两个单词对比，比如 "wrt" 和 "wrf"，前面 "wr" 相同，第三个字符 t 和 f 不同，那么 t 必须排在 f 前面，因为 t 开头的单词排在前。

把所有相邻对扫一遍，得到一组「x 在 y 前」的约束。把这些约束当边建图，跑拓扑排序，出来的序列就是可行的字母顺序。

一、建边：相邻单词的第一个不同字符

逐位比较 cur 和 next：找到第一个不同的位置，就是一条偏序边 cur[j] → next[j]，后面不用再比。如果 cur 是 next 的前缀（cur 短），没有不同字符，这合法，比如 "ab" 在 "abc" 前面；反过来 next 是 cur 的前缀（next 短）就是矛盾，比如 "abc" 在 "ab" 前面，字典序里短前缀必须在前，输入不合法，返回 ""。

二、入度表与判环

入度表初始全 -1，扫 words 时把出现过的字母标记成 0。这样入度为 0 且 != -1 的字母就是「没有已知前驱」的字母，可以当拓扑起点；kinds 记录出现过的字母总数，最后 BFS 出队数不等于 kinds 就说明有环，返回 ""。

字母只有 26 个，图很小，跑得再快也快不到哪去。这题的重点全在建边正确：漏掉前缀矛盾检查是最高频的错法。含矛盾的输入下实测，漏检查的版本有 31.61% 的概率给出非空错误答案，而正确版返回 ""。

三、代码

#include <bits/stdc++.h>
    using namespace std;
    // ================= 题 4：火星词典（LC269） =================
    string AlienOrder(const vector<string>& words) {
        vector<int> indegree(26, -1);
        for (auto& w : words)
            for (char c : w) indegree[c - 'a'] = 0;
        vector<vector<int>> graph(26);
        for (int i = 0; i + 1 < (int)words.size(); i++) {
            const string& cur = words[i];
            const string& next = words[i + 1];
            int j = 0, len = min(cur.size(), next.size());
            for (; j < len; j++) {
                if (cur[j] != next[j]) {
                    graph[cur[j] - 'a'].push_back(next[j] - 'a');
                    indegree[next[j] - 'a']++;
                    break;
                }
            }
            if (j < (int)cur.size() && j == (int)next.size()) return "";
        }
        vector<int> queue(26);
        int l = 0, r = 0, kinds = 0;
        for (int i = 0; i < 26; i++) {
            if (indegree[i] != -1) kinds++;
            if (indegree[i] == 0) queue[r++] = i;
        }
        string ans;
        while (l < r) {
            int cur = queue[l++];
            ans.push_back((char)(cur + 'a'));
            for (int next : graph[cur])
                if (--indegree[next] == 0) queue[r++] = next;
        }
        return (int)ans.size() == kinds ? ans : "";
    }

四、演示：建边与拓扑排序

预设里的例子逐步建边，最后跑 Kahn。试试 ["abc","ab"] 这种前缀矛盾，看返回空字符串。

总结

火星词典 = 相邻单词对比建边 + 前缀矛盾检查 + 拓扑排序判环。偏序边只在第一个不同字符处产生，一次 break。

入度表用 -1 标记「没出现」是这类「字符集合不确定」题目的惯用手法：出现过的置 0，最后用 kinds 计数兜底判环。
