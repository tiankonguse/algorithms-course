01分数规划：背包与生成树

上一页的 check 是取 top-k 结余，因为选择没有约束。给选择加上重量下限、连通性这些约束，check 内部就要换工具：01背包和最小生成树。

零、问题

牛群才艺：n ≤ 250 头牛，每头有重量和才艺，选若干只让总重量不少于 w，最大化 才艺和 / 重量和，乘 1000 取整。w ≤ 1000，重量 ≤ 10^6。

最优比率生成树：n ≤ 1000 个村庄，坐标 (x, y) 决定两两之间的欧式距离，海拔 z 决定修路花费（海拔差绝对值）。连通所有村庄至少 n−1 条路，希望 总花费 / 总距离 尽量小，保留 3 位小数。修路条数少本身就是 n−1 条，于是问题精确化成「选一棵生成树，最小化 树上总花费 / 树上总距离」。

两题的 check 内部工具完全不同，一个 01背包、一个最小生成树，但「结余表达式 + 二分」的框架原样不动。

一、重量约束：01背包判定

固定 x，每头牛的结余 value_i = talent_i − x·weight_i。要在总重 ≥ w 的集合里最大化结余和，这是带重量下限的 01背包：dp[p] 记重量恰好 p 的最大结余和，重量一超过 w 就并进 dp[w]，相当于「≥ w」共用一个槽。

逆序滚动保证每头牛只用一次，p 从 w 往下扫，新重量 j = p + weight_i 超过 w 时直接更新 dp[w]：

bool check(double x) {
        for (int i = 1; i <= n; i++) {
            value[i] = (double)talent[i] - x * weight[i];
        }
        dp[0] = 0;
        for (int j = 1; j <= w; j++) dp[j] = NA;
        for (int i = 1; i <= n; i++) {
            for (int p = w; p >= 0; p--) {
                int j = p + weight[i];
                if (j >= w) {
                    dp[w] = max(dp[w], dp[p] + value[i]);
                } else {
                    dp[j] = max(dp[j], dp[p] + value[i]);
                }
            }
        }
        return dp[w] >= 0;
    }

无效解用 NA = −1e9 兜底（重量 0 之外的槽一开始全无效），dp[0] = 0 表示一头不选。dp[w] ≥ 0 就说明存在重量达标的选择让比值 ≥ x。二分上界取才艺和，输出直接截断：

int main() {
        scanf("%d%d", &n, &w);
        for (int i = 1; i <= n; i++) scanf("%d%d", &weight[i], &talent[i]);
        double l = 0, r = 0, ans = 0;
        for (int i = 1; i <= n; i++) r += talent[i];
        while (l < r && r - l >= sml) {
            double x = (l + r) / 2;
            if (check(x)) {
                ans = x;
                l = x + sml;
            } else {
                r = x - sml;
            }
        }
        printf("%d\n", (int)(ans * 1000));
    }

二、连通性约束：生成树判定

固定 x，把每条边的权改成 cost − x·dist。最小生成树权值和 ≤ 0 等价于存在一棵生成树让 (总花费) − x·(总距离) ≤ 0，即 总花费/总距离 ≤ x。这里的选择工具是 prim：每次解锁离已选点集「结余最近」的点，累加 n−1 条边。

double prim(double x) {
        for (int i = 1; i <= n; i++) {
            vis[i] = false;
            value[i] = cost[1][i] - x * dist[1][i];
        }
        vis[1] = true;
        double sum = 0;
        for (int i = 1; i <= n - 1; i++) {
            double minDist = 1e100;
            int next = 0;
            for (int j = 1; j <= n; j++) {
                if (!vis[j] && value[j] < minDist) {
                    minDist = value[j];
                    next = j;
                }
            }
            sum += minDist;
            vis[next] = true;
            for (int j = 1; j <= n; j++) {
                if (!vis[j] && value[j] > cost[next][j] - x * dist[next][j]) {
                    value[j] = cost[next][j] - x * dist[next][j];
                }
            }
        }
        return sum;
    }

注意二分方向反了：题目求最小比值，check 通过（MST 权值和 ≤ 0）说明当前 x 还能更小，往左二分；只有 check 失败才往右。上界取 100（海拔差上限），比任意真实比值都大：

int main() {
        while (scanf("%d", &n) == 1 && n != 0) {
            for (int i = 1; i <= n; i++) scanf("%d%d%d", &X[i], &Y[i], &Z[i]);
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= n; j++) {
                    if (i != j) {
                        dist[i][j] = sqrt((double)(X[i] - X[j]) * (X[i] - X[j]) +
                                          (double)(Y[i] - Y[j]) * (Y[i] - Y[j]));
                        cost[i][j] = abs(Z[i] - Z[j]);
                    }
                }
            }
            double l = 0, r = 100, ans = 0;
            while (l < r && r - l >= sml) {
                double x = (l + r) / 2;
                if (prim(x) <= 0) {
                    ans = x;
                    r = x - sml;
                } else {
                    l = x + sml;
                }
            }
            printf("%.3f\n", ans);
        }
    }

三、总结

背包题把「重量 ≥ w」压进 dp[w] 一个槽，生成树题用 prim 直接产出 n−1 条边的结余和，两题都只改 check 内部。还有一个要记牢的差异：求最大比值时 check 通过就往右，求最小比值时往左，方向写反答案会差一个量级。
