最大公约数、最小公倍数与同余原理

42 和 24 的最大公约数是 6，一行函数就求完。最小公倍数由 gcd 顺手得到。模运算里加减乘每步取模结果不变，除法要等逆元。

零、背景

最大公约数是「能同时整除两个数的最大整数」。42 和 24 的公因子有 1、2、3、6，最大的是 6。

这个数到处要用：约分、同余、扩展欧几里得、模逆元，底座都是它。课件原话是：不比赛的同学，哪怕目标是顶级公司应聘或考研，掌握这个只有一行的函数已经足够。

最小公倍数不用另写算法，gcd 除一下乘一下就出来。模运算里还有一套「同余原理」：结果要对某个数取模时，中间每一步取模，最终答案不变。这两样是后面几乎所有取模题的规范。

一、辗转相除法

过程就一句：gcd(a, b) = gcd(b, a % b)，b 为 0 时 a 就是答案。

42 和 24 走一遍：42 % 24 = 18，问题变成 gcd(24, 18)；24 % 18 = 6，变成 gcd(18, 6)；18 % 6 = 0，gcd(6, 0) = 6。三轮出结果。

暴力做法是从 min(a, b) 往下逐个试约数。a、b 到 1e18，暴力试不动；辗转相除每轮把数缩小一大截，几轮就停。

// 辗转相除法：gcd(a, b) = gcd(b, a % b)，b 为 0 时 a 就是答案
    long long gcd(long long a, long long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

二、为什么对

要证的是 gcd(a, b) = gcd(b, a % b)。设 a % b = r，那 a = bq + r。

先看一边：u 同时整除 a、b，即 a = su、b = tu。代入 r = a − bq，得 r = (s − tq)u，u 也整除 r。所以 a、b 的每个公因子都是 b、r 的公因子。

反过来：v 同时整除 b、r，即 b = xv、r = yv。a = bq + r = (xq + y)v，v 也整除 a。所以 b、r 的每个公因子都是 a、b 的公因子。

两边的公因子集合一样，最大公约数自然一样。b 为 0 时 a 就是答案，逐层回推成立。

这里有个细节：a < b 时第一轮 a % b = a，gcd(b, a) 和 gcd(a, b) 结果一样，所以函数不用先比大小。

三、迭代次数

实测 10 万对随机数：范围 1 到 1e18 时平均 35.5 轮，最大 54 轮。

最坏情况是斐波那契相邻项：gcd(F(k+1), F(k)) 恰好 k 轮。F(46)=1836311903、F(47)=2971215073，gcd 要走 46 轮。

迭代次数是 O(log max(a, b))，64 位整数最多 90 次左右。课件标的 O((log a)³) 是把每次除法的位代价也算进去的理论口径，实际取模次数就这么点。

四、最小公倍数

lcm(a, b) = a / gcd(a, b) * b。a/gcd 和 b/gcd 互质，互质的两数乘积就是最小公倍数。

顺序不能换。a、b 都大时 a*b 先溢出：a = b = 4e9，a*b = 1.6e19 超出 long long，实测得 -2446744073709551616；a/gcd*b = 4e9，正确。先除后乘，中间不经过 a*b 这个大数。

int 里更常见：1e9 × 1e9 溢出成 -1486618624。

// 最小公倍数：先除后乘，a * b 中间可能溢出
    long long lcm(long long a, long long b) {
        return a / gcd(a, b) * b;
    }

五、同余原理

结果要对 m 取模时，加法、乘法每一步算完直接取模，最后结果不变。

加法 (a + b) % m = (a%m + b%m) % m，乘法同理。减法注意 C++ 负数取模还是负的，写成 (a − b + m) % m，加一个 m 转非负。

乘法中间变量用 long：每项取模后最大 mod−1 ≈ 1e9，相乘约 1e18，int 装不下（1e9 × 1e9 在 int 里是 -1486618624），long long 装得下。

除法的同余要逆元，放后续课。

实测：((a+b)(c−d) + (a·c − b·d)) % mod 的逐步取模版与 __int128 精确参考对拍 10 万组（输入 1 到 1e9，mod=1e9+7），零不一致。

溢出反例：a = c = 3e9、b = d = 1。(a+b)(c−d) ≈ 9e18，a·c ≈ 9e18，两个一加 1.8e19 超 long long。直接算得 417656879，逐步取模得 880，880 才是对的。

// ((a + b) * (c - d) + (a * c - b * d)) % mod 的非负结果
    // 加减乘每一步算完直接取模；除法要逆元，后续课讲
    int sameMod(long long a, long long b, long long c, long long d, int mod) {
        int o1 = (int)(a % mod);                  // a
        int o2 = (int)(b % mod);                  // b
        int o3 = (int)(c % mod);                  // c
        int o4 = (int)(d % mod);                  // d
        int o5 = (o1 + o2) % mod;                 // a + b
        int o6 = (o3 - o4 + mod) % mod;           // c - d，加 mod 转非负
        int o7 = (int)((long long)o1 * o3 % mod); // a * c，long 兜住中间结果
        int o8 = (int)((long long)o2 * o4 % mod); // b * d
        int o9 = (int)((long long)o5 * o6 % mod); // (a + b) * (c - d)
        int o10 = (o7 - o8 + mod) % mod;          // a * c - b * d
        return (o9 + o10) % mod;
    }

复杂度分析

操作时间说明
gcd(a, b)O(log min(a, b)) 次取模最坏是斐波那契相邻项，64 位内最多约 90 轮；位运算口径 O((log a)³)
lcm(a, b)同 gcd一次 gcd，再一次除法一次乘法
逐步取模（加减乘）O(1)每步常数个模运算，中间值始终在 mod 内

空间：gcd 的递归栈 O(log min(a, b))，lcm 与逐步取模都是 O(1)。

总结

辗转相除：b 为 0 时返回 a，其余交给 gcd(b, a%b)。最坏是斐波那契对，64 位内最多 90 轮。

lcm 先除后乘，a/gcd 与 b/gcd 互质，中间不碰 a*b。

加减乘每步取模；减法加 m 转非负；乘法中间用 long long。

除法要逆元，后续课讲。gcd 是扩展欧几里得、裴蜀定理、模逆元的底座，下一课的神奇数字同时用上这里的取模、二分答案和容斥原理。
