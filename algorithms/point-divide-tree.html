点分树与动态点分治（一）：重构树、容斥与开点线段树

静态点分治每处理一个询问，都要把树按重心重新拆一遍。一旦题目带上修改，拆出来的统计没法留住，每次都要重来。点分树把这套拆法固化成一棵高度 O(log n) 的重构树，修改和查询都沿着它走很少几步就完成。这一页用震波把容斥逻辑图解清楚，再接两道同结构的题。

零、背景

静态点分治的结构是每次选重心、删掉、递归，共 O(log n) 层。它假设树是静态的：询问来了才拆，拆完统计，拆的过程本身不留任何东西。

带修改的题就麻烦了。点权一变，之前所有层的统计都过期，重新分治一次是 O(n log n)，m 次修改就是 O(nm log n)，n、m 都是 10⁵ 时远远超时。

解法是把分治过程本身留下来。点分治每次求出一棵子树的重心时，记录这个重心的上级重心是谁。把「重心 → 上级重心」这些边收集起来，正好是一棵重构出来的树，叫点分树。

它有三条性质。一是点分树上任意一个点的子树，对应原树的一个连通块。二是点分树上两点的 LCA，一定在原树这两点的简单路径上，因此 dist(x, y) = dist(x, c) + dist(y, c)，c 是那个 LCA。三是除此之外点分树和原树的联系很少，用的时候只能依赖前两条。因为每往下一层连通块至少减半，点分树的高度是 O(log n)。

点分树是怎么一步步长出来的

还是这棵 9 个点的树。点「下一步」看每一层分治：找到当前连通块的重心，删掉它，剩下的块继续。右边点分树的边跟着一条条出现。

当前层找到的重心 还没处理的点 已删除的点

一、题目1：震波

树上 n 个点、有点权，边权都是 1。m 条操作：操作 0 x y 打印从 x 出发距离不超过 y 的所有点的点权和；操作 1 x y 把 x 的点权改成 y。n、m 到 10⁵，点权到 10⁴。本题强制在线，x 和 y 都要用上次输出异或解出来。测试链接 P6329。

二、朴素做法

修改是 O(1) 的，直接改数组。查询从 x 跑一遍 bfs，把距离 ≤ y 的点权加起来，单次 O(n)。

两边乘起来是 O(nm)，10¹⁰ 量级，超时。强制在线还把「把询问攒起来离线批量处理」的路堵死了，必须单次操作就快。

树哈希、树剖这类按原树结构切分的做法，遇到「以任意点为圆心统计半径」的询问都得整树扫。要快，得换一棵树。

三、点分树上的容斥统计

先看一个观察。讨论 x 与其他点的、和距离有关的答案时，把其他点按「在点分树上来自 x 的哪个祖先重心」分类。x 的祖先重心只有 O(log n) 个，所以其他点最多被分成 O(log n) 类，每一类内部到 x 的距离有一个统一的表达式。

具体来说，设 fa 是 x 的某一级祖先重心。落在 fa 的连通块、但不在 x 往 fa 方向那一侧子块里的点 y，fa 一定在 x 到 y 的路径上，于是 dist(x, y) = dist(x, fa) + dist(y, fa)。统计「到 x 距离 ≤ k」就变成「到 fa 距离 ≤ k − dist(x, fa)」，一个只跟 fa 有关的桶就能回答。

于是给每个重心 c 准备一棵按距离下标的开点线段树 addTree[c]，把 c 所在连通块的每个点挂在自己的距离上。查询 x 时：自己这棵 addTree[x] 查 [0, k]；每级祖先 fa 查 addTree[fa] 的 [0, k − dist(x, fa)]。

这里有个细节：一个点的信息会被多个祖先重复统计。x 自己就在 addTree[x] 里，也在 addTree[4] 里，还在 addTree[2] 里。所以再给每条父子边配一棵 minusTree[u]，挂 u 的连通块、按到上级重心的距离。查询每级做加 addTree[fa] 减 minusTree[cur]，把低层已经算过的抵掉。

修改同理。点 x 的点权变动 v 时：addTree[x] 在距离 0 处加 v；沿祖先链每级 fa 在距离 dist(x, fa) 处加 v，同时给 minusTree[cur] 在同一位置加 v。修改和查询都是沿链走 O(log n) 级，每级一次线段树操作 O(log n)。

原树距离用 LCA 算，倍增或重链都行，单次 O(log n)。下面是完整代码，LCA 用的重链剖分。

震波查询模拟器：链上一级级加，也一级级减

点权等于点的编号。点「下一步」依次做四次半径递增的查询、一次点权修改、再两次别的起点的查询。左图里橙色点是这次统计到的点，右侧是链上每一级的加减明细。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXT = 10000001;
    int n, m;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int fa[MAXN];
    int dep[MAXN];
    int siz[MAXN];
    int son[MAXN];
    int top[MAXN];

    bool vis[MAXN];
    int centfa[MAXN];

    int addTree[MAXN];
    int minusTree[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int sum[MAXT];
    int cntt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int ei = head[u], v; ei; ei = nxt[ei]) {
            v = to[ei];
            if (v != f) {
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head[u], v; e; e = nxt[e]) {
            v = to[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    int getLca(int a, int b) {
        while (top[a] != top[b]) {
            if (dep[top[a]] <= dep[top[b]]) {
                b = fa[top[b]];
            } else {
                a = fa[top[a]];
            }
        }
        return dep[a] <= dep[b] ? a : b;
    }

    int getDist(int x, int y) {
        return dep[x] + dep[y] - (dep[getLca(x, y)] << 1);
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void centroidTree(int u, int fa) {
        centfa[u] = fa;
        vis[u] = true;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                centroidTree(getCentroid(v, u), u);
            }
        }
    }

    int add(int jobi, int jobv, int l, int r, int i) {
        if (i == 0) {
            i = ++cntt;
        }
        if (l == r) {
            sum[i] += jobv;
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[i] = add(jobi, jobv, l, mid, ls[i]);
            } else {
                rs[i] = add(jobi, jobv, mid + 1, r, rs[i]);
            }
            sum[i] = sum[ls[i]] + sum[rs[i]];
        }
        return i;
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return sum[i];
        }
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, ls[i]);
        }
        if (jobr > mid) {
            ans += query(jobl, jobr, mid + 1, r, rs[i]);
        }
        return ans;
    }

    void add(int x, int v) {
        addTree[x] = add(0, v, 0, n - 1, addTree[x]);
        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {
            int dist = getDist(x, fa);
            addTree[fa] = add(dist, v, 0, n - 1, addTree[fa]);
            minusTree[cur] = add(dist, v, 0, n - 1, minusTree[cur]);
        }
    }

    int query(int x, int k) {
        int ans = query(0, k, 0, n - 1, addTree[x]);
        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {
            int dist = getDist(x, fa);
            if (k - dist >= 0) {
                ans += query(0, k - dist, 0, n - 1, addTree[fa]);
                ans -= query(0, k - dist, 0, n - 1, minusTree[cur]);
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        dfs1(1, 0);
        dfs2(1, 1);
        centroidTree(getCentroid(1, 0), 0);
        for (int i = 1; i <= n; i++) {
            add(i, arr[i]);
        }
        int lastAns = 0;
        for (int i = 1, op, x, y; i <= m; i++) {
            cin >> op >> x >> y;
            x ^= lastAns;
            y ^= lastAns;
            if (op == 0) {
                lastAns = query(x, y);
                cout << lastAns << '\n';
            } else {
                add(x, y - arr[x]);
                arr[x] = y;
            }
        }
        return 0;
    }

四、题目2：烁烁的游戏

n 个点的树，初始点权全是 0，边权都是 1。m 条操作：M x k v 把从 x 出发距离不超过 k 的所有点的点权都加 v；Q x 打印 x 的点权。n、m 到 10⁵，v 在 ±10⁴。测试链接 P10603。

和震波正好是对偶的：那边是点修改、半径查询，这边是半径修改、点查询。点分树和两棵线段树的骨架原样保留，只是「往桶里写什么、从桶里读什么」对调了。

修改 M x k v 走到祖先重心 fa 时，剩余半径是 k − dist(x, fa)，把这个数当作位置往 addTree[fa] 里写；查询 Q x 时，门槛是 dist(x, fa)，从 fa 的桶里读 [dist(x, fa), n−1]，再减掉下级的同区间。

两边为什么恰好咬合：修改写在位置 k − dist(x, fa)，查询从位置 dist(y, fa) 开始读，位置 ≥ 门槛等价于 k − dist(x, fa) ≥ dist(y, fa)，移项就是 k ≥ dist(x, fa) + dist(y, fa)。fa 在 x 到 y 的路径上，右边正是 dist(x, y)。所以「读得到」恰好等价于「这次修改覆盖这个查询点」，不多不少。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXP = 18;
    const int MAXT = 20000001;
    int n, m;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dep[MAXN];
    int stjump[MAXN][MAXP];

    bool vis[MAXN];
    int siz[MAXN];
    int centfa[MAXN];

    int addTree[MAXN];
    int minusTree[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int sum[MAXT];
    int cntt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    }

    void getSize(int u, int fa) {

            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void centroidTree(int u, int fa) {
        centfa[u] = fa;
        vis[u] = true;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                centroidTree(getCentroid(v, u), u);
            }
        }
    }

    int add(int jobi, int jobv, int l, int r, int i) {
        if (i == 0) {
            i = ++cntt;
        }
        if (l == r) {
            sum[i] += jobv;
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[i] = add(jobi, jobv, l, mid, ls[i]);
            } else {
                rs[i] = add(jobi, jobv, mid + 1, r, rs[i]);
            }
            sum[i] = sum[ls[i]] + sum[rs[i]];
        }
        return i;
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return sum[i];
        }
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, ls[i]);
        }
        if (jobr > mid) {
            ans += query(jobl, jobr, mid + 1, r, rs[i]);
        }
        return ans;

        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {

                minusTree[cur] = add(k - dist, v, 0, n - 1, minusTree[cur]);

        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {

五、题目3：Atm的树

n 个点的带边权的树，边权 1 到 10。对每个节点 x，求从 x 出发到达其他点的距离中第 k 小的那个。x 到自己的距离 0 不参与评比，给定 k，输出 n 个答案。n 到 15000，k 到 5000。测试链接 P10604。

这是纯静态的题，没有修改。把震波的维护结构原样建出来：每个点的点权当作 1 插进所有相关的桶，query(x, limit) 就是「到 x 距离 ≤ limit 的点数」。

第 k 小距离没有直接的桶可查，但它关于 limit 单调，于是二分答案：找最小的 limit 使 query(x, limit) ≥ k + 1。加一是为了抵掉 x 自己：自己永远在桶的位置 0 处贡献一个名额，而题面规定距离 0 不参与评比，名额多算了一个。

二分的上界是所有边权之和 sumw。每个点独立二分，判定一次是链长 O(log n) 级、每级一次线段树查询，总量 O(n log n log² sumw)。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    const int MAXP = 18;
    const int MAXT = 1000001;
    int n, k, sumw;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    int dep[MAXN];
    int dist[MAXN];
    int stjump[MAXN][MAXP];

    bool vis[MAXN];
    int siz[MAXN];
    int centfa[MAXN];

    int addTree[MAXN];
    int minusTree[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int sum[MAXT];
    int cntt;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void dfs(int u, int fa, int dis) {
        dep[u] = dep[fa] + 1;
        dist[u] = dis;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa) {
                dfs(v, u, dis + w);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int getDist(int x, int y) {
        return dist[x] + dist[y] - (dist[getLca(x, y)] << 1);
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void centroidTree(int u, int fa) {
        centfa[u] = fa;
        vis[u] = true;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                centroidTree(getCentroid(v, u), u);
            }
        }
    }

    int add(int jobi, int jobv, int l, int r, int i) {
        if (i == 0) {
            i = ++cntt;
        }
        if (l == r) {
            sum[i] += jobv;
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[i] = add(jobi, jobv, l, mid, ls[i]);
            } else {
                rs[i] = add(jobi, jobv, mid + 1, r, rs[i]);
            }
            sum[i] = sum[ls[i]] + sum[rs[i]];
        }
        return i;
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return sum[i];
        }
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, ls[i]);
        }
        if (jobr > mid) {
            ans += query(jobl, jobr, mid + 1, r, rs[i]);
        }
        return ans;
    }

    void add(int x, int v) {
        addTree[x] = add(0, v, 0, sumw, addTree[x]);
        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {
            int dist = getDist(x, fa);
            addTree[fa] = add(dist, v, 0, sumw, addTree[fa]);
            minusTree[cur] = add(dist, v, 0, sumw, minusTree[cur]);
        }
    }

    int query(int x, int limit) {
        int ans = query(0, limit, 0, sumw, addTree[x]);
        for (int cur = x, fa = centfa[cur]; fa > 0; cur = fa, fa = centfa[cur]) {
            int dist = getDist(x, fa);
            if (limit - dist >= 0) {
                ans += query(0, limit - dist, 0, sumw, addTree[fa]);
                ans -= query(0, limit - dist, 0, sumw, minusTree[cur]);
            }
        }
        return ans;
    }

    int compute(int x) {
        int ans = 0;
        int l = 0, r = sumw, mid;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (query(x, mid) >= k) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        cin >> k;
        k = k + 1;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
            sumw += w;
        }
        dfs(1, 0, 0);
        centroidTree(getCentroid(1, 0), 0);
        for (int i = 1; i <= n; i++) {
            add(i, 1);
        }
        for (int i = 1; i <= n; i++) {
            cout << compute(i) << '\n';
        }
        return 0;

六、复杂度分析

三道题共用点分树骨架：建树时每层 getSize 的总代价和该层连通块同阶，加起来 O(n log n)。之后的差别全在链长和线段树的乘积上。

操作时间复杂度空间复杂度
建点分树（每层求重心、连父指针）O(n log n)O(n)
震波：单次修改 / 查询O(log² n)O(n log n)（开点线段树总节点数）
烁烁的游戏：单次修改 / 查询O(log² n)
Atm的树：单点二分（判定一次）O(log n · log sumw)（判定）/ O(log n · log² sumw)（整点二分）

震波的总复杂度 O((n + m) log² n)。开点线段树只给真实出现过的位置开节点，一次插入 O(log n) 个新节点，全部插入共 O(n log² n) 个节点，空间是 O(n log n) 量级；题目里 MAXT 开到 10⁷ 就是按这个上界准备的。Atm的树里 sumw 是边权总和，不超过 1.5×10⁵，log sumw 约 17，和 log n 同阶。

七、最后

点分树把「每次重来」的分治变成「一次建好、长期维护」的结构，代价是统计里必须带上容斥：每读一级祖先，就减掉一级下级。震波把这个逻辑走通之后，烁烁的游戏只是把读写对调，Atm的树再叠一层二分。
