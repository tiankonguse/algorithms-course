笛卡尔树、Treap树：随机优先级保住平衡

前面几课的有序表都在回答「插入删除时怎么维持平衡」。这一课换了个问法：给我一个已经定好的数组，能不能 O(n) 直接建成一棵「按下标是搜索树、按值是堆」的树。能。这棵树叫笛卡尔树，它把「区间最小值在哪」这种问题变成树上的祖先关系。Treap 是它的动态版：每个节点带一个随机优先级，靠旋转同时保住搜索树和堆两种结构，期望 O(log n)。

零、背景

AVL 树用旋转维持严格平衡，跳表用随机层数拆掉数据顺序的影响，替罪羊树失衡就重建。它们都是动态结构：边插入删除边修正。笛卡尔树不一样，它是静态的：给定数组，一次建树，结构完全由数组决定，没有插入删除。

那它有什么用？看它的定义就明白了。key 按下标组织成搜索二叉树（中序遍历恰好是 1..n），value 按小根堆组织（父节点的值 ≤ 子节点的值）。于是任意一段下标区间 [l, r]，区间最小值所在的位置，就是这段区间在树上对应子树的根。区间最值问题被翻译成了树上的问题。

Treap 就是把笛卡尔树动态化：插入的每个 (key, priority) 都是笛卡尔树的一个节点，priority 随机生成，key 当搜索树、priority 当堆。旋转只做左旋右旋两件事，实现比 AVL 简单，期望复杂度 O(log n)。算法竞赛里「有序表必带模板」一般是四个：替罪羊树、Treap、FHQ Treap、Splay。Treap 是旋转版，下下节课的 FHQ Treap 是拆分合并版，那才是 Treap 的重点。

一、笛卡尔树长什么样

给定数组 arr[1..n]，建出的树满足两条：下标是搜索树（i 的左子树里全是比 i 小的下标，右子树里全是比 i 大的），value 是小根堆（arr[父] ≤ arr[子]）。注意这是广义的堆：只要求子树的最小值一定在子树的头上，不要求子树是满的或者完全二叉树。

等值的 value 怎么处理？建树时用严格大于才弹栈，等于不弹。所以相等的值里，先出现的那个会在上面，后出现的挂到它的右侧。这保证「区间最左端最小值」跟树根一一对应，是下一课几道题要用到的细节。

堆性质怎么利用？查询「[l, r] 的最小值在哪个位置」：在树上找 l 和 r 的最近公共祖先。因为 l 和 r 的 LCA 是包含它们的最小子树的根，而这棵子树恰好对应下标区间 [l, r]，根就是区间最小值的位置。区间问题变成祖先查询，这就是笛卡尔树的核心价值。

二、O(n) 建树：单调栈

建树过程维护一个单调栈，栈底到栈顶的 value 严格递增（小根堆，大的被压在下面）。处理新节点 x 时四步：

1）按 x 的 value，把栈里 value 比 x 大的节点依次弹出。
2）最后弹出的那个节点 y，带着它整棵子树，成为 x 的左子树。
3）如果栈里还剩节点，栈顶 z 的右孩子变成 x。
4）x 入栈。

为什么这样建出来正好是笛卡尔树？弹出去的节点 value 都比 x 大，所以 x 是它们这段区间的更小值，x 当它们的父节点；x 又比剩下的栈顶 z 大，所以 x 挂在 z 的右侧。两个性质都保住了。

复杂度是 O(n)：每个节点最多入栈一次、出栈一次，总弹出次数 ≤ n。代码短得吓人，核心就一个 while 循环。n 到 1e7 也能跑，实测 1e7 个随机数建树只要 0.16 秒。

for (int i = 1; i <= n; i++) { while (top > 0 && arr[sta[top]] > arr[i]) top--; ... }

演示：arr = [3, 1, 4, 2, 5] 逐步建树（上方树，下方单调栈）

三、题1 完整实现（P5854 笛卡尔树模版）

洛谷 P5854 直接给 n 个值，要你输出验证用的两个异或值。数组开满 1e7，静态分配。提交时注意 i * (ls[i] + 1) 会溢出 int，先转 long long 再乘再异或。

#include <iostream>
    #include <vector>
    #include <stack>
    #include <cstdio>

    #define LL long long

    using namespace std;

    const int MAXN = 10000001;

    int arr[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int sta[MAXN];
    int n;

    void build() {
        int top = 0;
        for (int i = 1; i <= n; i++) {
            int pos = top;
            while (pos > 0 && arr[sta[pos]] > arr[i]) {
                pos--;
            }
            if (pos > 0) {
                rs[sta[pos]] = i;
            }
            if (pos < top) {
                ls[i] = sta[pos + 1];
            }
            sta[++pos] = i;
            top = pos;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        build();
        long long ans1 = 0, ans2 = 0;
        for (int i = 1; i <= n; i++) {
            ans1 ^= 1LL * i * (ls[i] + 1);
            ans2 ^= 1LL * i * (rs[i] + 1);
        }
        cout << ans1 << " " << ans2 << endl;
        return 0;
    }

四、Treap：给搜索树加随机优先级

Treap = Tree + Heap。每个节点存 (key, priority)：key 按搜索二叉树组织，priority 按堆组织。priority 是插入时随机生成的，谁大谁在上面（代码里是大根堆，priority 大的当父）。

插入一个 (key, priority)：先按 key 在搜索树上走到空位，把节点挂上去，然后检查这个新节点和它的父节点：如果新节点的 priority 比父大，就旋转把它顶上去，一路顶到 priority 不再违反堆性质为止。

删除分四种情况。无左无右：直接删。有左无右：左孩子接替。无左有右：右孩子接替。左右都有：priority 大的那个孩子旋转上来当父，被删节点转进它的子树里，递归删。这一步之所以能一直旋下去，是因为每次旋转都把目标节点往叶子方向推一层，最终落到叶子再删。

为什么随机 priority 能保平衡？这棵树本质上是「给每个 key 随机一个优先级建的笛卡尔树」。随机序列的笛卡尔树期望高度 O(log n)，跟跳表是同一个道理：结构不依赖数据顺序，依赖随机数。最坏情况理论上存在（随机数全排好序），但概率指数级小。

查询和前驱后继跟普通 BST 一样，顺着 key 走。这里有个 150 课也出现过的判定：删除 x 前先检查 getRank(x) != getRank(x + 1)。两个排名相等说明集合里根本没有 x，删了也是白删。

五、题2 完整实现（P3369 普通平衡树）

六操作全在：增加、删除、排名、第 k 小、前驱、后继。priority 用 rand() / RAND_MAX 生成 double，插入后自底向上检查旋转。词频用 key_count 数组，重复插入同一个 key 只加计数不建新节点。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;

    int cnt = 0;
    int head = 0;
    int key[MAXN];
    int key_count[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int siz[MAXN];
    double priority[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + key_count[i];
    }

    int leftRotate(int i) {
        int r = rs[i];
        rs[i] = ls[r];
        ls[r] = i;
        up(i);
        up(r);
        return r;
    }

    int rightRotate(int i) {
        int l = ls[i];
        ls[i] = rs[l];
        rs[l] = i;
        up(i);
        up(l);
        return l;
    }

    int add(int i, int num) {
        if (i == 0) {
            key[++cnt] = num;
            key_count[cnt] = siz[cnt] = 1;
            priority[cnt] = static_cast<double>(rand()) / RAND_MAX;
            return cnt;
        }
        if (key[i] == num) {
            key_count[i]++;
        } else if (key[i] > num) {
            ls[i] = add(ls[i], num);
        } else {
            rs[i] = add(rs[i], num);
        }
        up(i);
        if (ls[i] != 0 && priority[ls[i]] > priority[i]) {
            return rightRotate(i);
        }
        if (rs[i] != 0 && priority[rs[i]] > priority[i]) {
            return leftRotate(i);
        }
        return i;
    }

    void add(int num) {
        head = add(head, num);
    }

    int small(int i, int num) {
        if (i == 0) {
            return 0;
        }
        if (key[i] >= num) {
            return small(ls[i], num);
        } else {
            return siz[ls[i]] + key_count[i] + small(rs[i], num);
        }
    }

    int getRank(int num) {
        return small(head, num) + 1;
    }

    int index(int i, int x) {
        if (siz[ls[i]] >= x) {
            return index(ls[i], x);
        } else if (siz[ls[i]] + key_count[i] < x) {
            return index(rs[i], x - siz[ls[i]] - key_count[i]);
        }
        return key[i];
    }

    int index(int x) {
        return index(head, x);
    }

    int pre(int i, int num) {
        if (i == 0) {
            return INT_MIN;
        }
        if (key[i] >= num) {
            return pre(ls[i], num);
        } else {
            return max(key[i], pre(rs[i], num));
        }
    }

    int pre(int num) {
        return pre(head, num);
    }

    int post(int i, int num) {
        if (i == 0) {
            return INT_MAX;
        }
        if (key[i] <= num) {
            return post(rs[i], num);
        } else {
            return min(key[i], post(ls[i], num));
        }
    }

    int post(int num) {
        return post(head, num);
    }

    int remove(int i, int num) {
        if (key[i] < num) {
            rs[i] = remove(rs[i], num);
        } else if (key[i] > num) {
            ls[i] = remove(ls[i], num);
        } else {
            if (key_count[i] > 1) {
                key_count[i]--;
            } else {
                if (ls[i] == 0 && rs[i] == 0) {
                    return 0;
                } else if (ls[i] != 0 && rs[i] == 0) {
                    i = ls[i];
                } else if (ls[i] == 0 && rs[i] != 0) {
                    i = rs[i];
                } else {
                    if (priority[ls[i]] >= priority[rs[i]]) {
                        i = rightRotate(i);
                        rs[i] = remove(rs[i], num);
                    } else {
                        i = leftRotate(i);
                        ls[i] = remove(ls[i], num);
                    }
                }
            }
        }
        up(i);
        return i;
    }

    void remove(int num) {
        if (getRank(num) != getRank(num + 1)) {
            head = remove(head, num);
        }
    }

    void clear() {
        memset(key + 1, 0, cnt * sizeof(int));
        memset(key_count + 1, 0, cnt * sizeof(int));
        memset(ls + 1, 0, cnt * sizeof(int));
        memset(rs + 1, 0, cnt * sizeof(int));
        memset(siz + 1, 0, cnt * sizeof(int));
        memset(priority + 1, 0, cnt * sizeof(int));
        cnt = 0;
        head = 0;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        srand(time(0));
        int n;
        cin >> n;
        for (int i = 1, op, x; i <= n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        clear();
        return 0;
    }

六、总结

笛卡尔树是把数组 O(n) 建成「按下标搜索、按值堆」的树，区间最值位置就是子树的根，静态问题（区间划分、祖先关系、直方图分块）都变成树上问题。Treap 把同一个结构动态化：key 走搜索树，随机 priority 走堆，插入删除靠左旋右旋维持，期望 O(log n)。

下一课四道题全是笛卡尔树的应用：树的序、序列计数、表格填数、砖块消除。建树代码就上面那几行，题目的难点全在「把区间问题翻译成子树问题」这一步。
