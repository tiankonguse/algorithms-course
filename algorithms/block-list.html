块状链表：文本编辑器

块状数组解决的是区间统计，元素的位置从头到尾不动。要是题目要在中间插入一段、删掉一段，后面的元素就得整体搬家，数组就不合适了。块状链表把块和块用链表串起来：每块内部还是数组，插入删除只调整块之间的连接，后面内容的地址一个都不用挪。

零、背景

概念上，块状链表的每一块都是数组，块之间根据需求用单链表或双链表连接。实现上不动态 new 出链表节点，而是用 pool 数组做块编号的分配和回收，纯静态数组：编号从栈顶弹出就是分配，压回栈顶就是回收。

规模上保证「块内容量」和「块的数量」同等：块内容量取 2√n，任何块的内容大小不能超过这个容量。容量取 2√n 而不是 √n，是给分裂和合并留余量，不然后面 maintain 的时候没东西可合。

一、题目：文本编辑器

一开始文本为空，光标在文本开头。实现六种操作：Move k 把光标移到第 k 个字符之后；Insert n s 在光标处插入长度为 n 的字符串 s，光标不动；Delete n 删除光标后的 n 个字符；Get n 输出光标后的 n 个字符；Prev、Next 光标前后移动。插入总量不超过 2MB。测试链接：洛谷 P4008。

这题在 FHQ Treap 那讲里出现过，是同一道题。平衡树做它要把子树拆开再拼上，块状链表做它是把块切开再接上，思路同源，但块状链表好想得多。

读入上有个细节：代码读字符串时数的是「n 个 ASCII 在 32 到 126 之间的字符」，所以输入里 s 要另起一行，跟在 n 后面那个分隔空格会被当成第一个字符吃掉。

二、定位与分裂

find(pos) 从头块出发，沿 nxt 走，每过一块就把 pos 减掉那块的 siz，减不动了就停。结果是全局变量 bi（落在哪块）和 pi（块内偏移）。链长 O(√n)，定位一次 O(√n)。

split(curb, pos) 把块 curb 从偏移 pos 处切成两块：分配一个新块接在 curb 后面，把右半段 memcpy 过去，curb 的 siz 收缩成 pos。偏移正好等于块长时就不用切。

插入的完整流程是三步：find 定位、split 把插入点切到块边界、新内容按块内容量切成若干整块加一个余块依次挂进链。挂完调 maintain：从链头扫到尾，相邻两块的大小之和不超过容量就合并。合并也是 memcpy 加改指向，回收掉多出来的那个编号。

删除是对称的三步：find 定位后先 split，把删除起点切到块边界；然后沿链走，整块被删完的整个回收；最后一块没删完，在剩余长度处再 split 一次，把多余的尾巴留下。删完同样调 maintain 合并。

读取 Get 不做任何修改：find 定位后从光标所在块开始，逐块 memcpy 到输出缓冲，凑满 n 个字符为止。

三、实现细节

读入有一个专门处理的坑：Insert 的字符串在 n 的下一行，中间可能夹着回车符，字符串本身也可能跨行、包含空格。所以不能用 cin >> 读字符串，得 cin.get() 一个一个字符收，ASCII 码在 [32,126] 之外的直接丢弃，收满 n 个为止。

常数上限这样定：全文最大长度 MAXN 取 3×10⁶ 出头，块内容量 BLEN = 3001（约等于 2√MAXN），块数上限 BNUM 是 MAXN / BLEN 的两倍。每个块最满 3001 个字符，最坏情况下块数是容量的一半，两倍的余量够分裂挥霍。

还有一个容易忽略的边界：find 的循环条件是 pos > siz[curb]，等于时停在本块末尾，此时 split 会因为偏移等于块长而直接返回。空文本、光标在末尾这些情况都被这个条件自然覆盖掉。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 3000001;
    const int BLEN = 3001;
    const int BNUM = (MAXN / BLEN) << 1;

    char space[BNUM][BLEN];
    int pool[BNUM];
    int top = 0;

    int nxt[BNUM];
    int siz[BNUM];

    char str[MAXN];

    void prepare() {
        for (int i = 1, id = BNUM - 1; i < BNUM; i++, id--) {
            pool[i] = id;
        }
        top = BNUM - 1;
        siz[0] = 0;
        nxt[0] = -1;
    }

    int assign() {
        return pool[top--];
    }

    void recycle(int id) {
        pool[++top] = id;
    }

    int bi, pi;

    void find(int pos) {
        int curb = 0;
        while (curb != -1 && pos > siz[curb]) {
            pos -= siz[curb];
            curb = nxt[curb];
        }
        bi = curb;
        pi = pos;
    }

    void linkAndWrite(int curb, int nextb, char* src, int pos, int len) {
        nxt[nextb] = nxt[curb];
        nxt[curb] = nextb;
        memcpy(space[nextb], src + pos, len);
        siz[nextb] = len;
    }

    void merge(int curb, int nextb) {
        memcpy(space[curb] + siz[curb], space[nextb], siz[nextb]);
        siz[curb] += siz[nextb];
        nxt[curb] = nxt[nextb];
        recycle(nextb);
    }

    void split(int curb, int pos) {
        if (curb == -1 || pos == siz[curb]) return;
        int nextb = assign();
        linkAndWrite(curb, nextb, space[curb], pos, siz[curb] - pos);
        siz[curb] = pos;
    }

    void maintain() {
        for (int curb = 0, nextb; curb != -1; curb = nxt[curb]) {
            nextb = nxt[curb];
            while (nextb != -1 && siz[curb] + siz[nextb] <= BLEN) {
                merge(curb, nextb);
                nextb = nxt[curb];
            }
        }
    }

    void insert(int pos, int len) {
        find(pos);
        split(bi, pi);
        int curb = bi, newb, done = 0;
        while (done + BLEN <= len) {
            newb = assign();
            linkAndWrite(curb, newb, str, done, BLEN);
            done += BLEN;
            curb = newb;
        }
        if (len > done) {
            newb = assign();
            linkAndWrite(curb, newb, str, done, len - done);
        }
        maintain();
    }

    void erase(int pos, int len) {
        find(pos);
        split(bi, pi);
        int curb = bi;
        int nextb = nxt[curb];
        while (nextb != -1 && len > siz[nextb]) {
            len -= siz[nextb];
            recycle(nextb);
            nextb = nxt[nextb];
        }
        if (nextb != -1) {
            split(nextb, len);
            recycle(nextb);
            nxt[curb] = nxt[nextb];
        } else {
            nxt[curb] = -1;
        }
        maintain();
    }

    void get(int pos, int len) {
        find(pos);
        int curb = bi;
        pos = pi;
        int done = (len < siz[curb] - pos) ? len : (siz[curb] - pos);
        memcpy(str, space[curb] + pos, done);
        curb = nxt[curb];
        while (curb != -1 && done + siz[curb] <= len) {
            memcpy(str + done, space[curb], siz[curb]);
            done += siz[curb];
            curb = nxt[curb];
        }
        if (curb != -1 && done < len) {
            memcpy(str + done, space[curb], len - done);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        int pos = 0, len;
        char op[10];
        prepare();
        for (int i = 1; i <= n; i++) {
            cin >> op;
            if (op[0] == 'P') {
                pos--;
            } else if (op[0] == 'N') {
                pos++;
            } else if (op[0] == 'M') {
                cin >> pos;
            } else if (op[0] == 'I') {
                cin >> len;
                for (int j = 0; j < len; ) {
                    char ch = cin.get();
                    if (32 <= ch && ch <= 126) {
                        str[j++] = ch;
                    }
                }
                insert(pos, len);
            } else if (op[0] == 'D') {
                cin >> len;
                erase(pos, len);
            } else {
                cin >> len;
                get(pos, len);
                cout.write(str, len);
                cout.put('\n');
            }
        }
        return 0;
    }

五、复杂度分析

设全文长度 n，块内容量 B = 2√n。链长不超过 n / (B/2) 加上分裂的余量，仍是 O(√n) 规模。

操作时间复杂度空间复杂度
find 定位（沿链累减 siz）O(√n)O(n)：space 是 BNUM × BLEN 的字符矩阵，总量与两倍余量的 n 同阶；nxt、siz、pool 都是块数规模
split / merge（块内 memcpy 与改指向）O(√n)
Insert（定位 + 切块挂链 + maintain）O(√n + len)
Delete（定位 + 两端切 + 整块回收 + maintain）O(√n)
Get（定位 + 跨块拷贝）O(√n + n)，n 为读取长度

maintain 看似每次都扫全链 O(√n)，但插入删除本身就是 O(√n)，不改变量级。m 条操作总量 O(m·√n)，本题 2MB 的文本对应 √n 约 1400，跑起来很宽裕。

六、最后

块状链表的账算清楚了：定位 O(√n)、切块 O(√n)，换来的是插入删除不搬家。它绝对好想，链表怎么操作它就怎么操作；但未必好写，split、回收、maintain 里全是边界。区间增删、区间移动的题目，最优解大概率是平衡树，只是学习门槛往往更高。
