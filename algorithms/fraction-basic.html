01分数规划：结余与二分答案

n 个数据，每个带 (a, b)，选出 k 个让 a 的和 / b 的和尽量大。直觉是挑 a/b 最大的前 k 个，这条直觉是错的：和式会重新分配每个数据的权重。

零、问题

(5, 5)、(0, 1)、(2, 6) 三个数据选 2 个。按 a/b 排：1、0、0.333，贪心选 (5, 5) 和 (2, 6)，比值 7/11 ≈ 0.636。但选 (5, 5) 和 (0, 1) 是 5/6 ≈ 0.833，更大。a/b 大的数据放进整体里不划算：多给 5 的分子，分母跟着多 6，反而稀释了整体。

正式问题：n 个 (a_i, b_i)，a、b 都是非负整数，选恰好 k 个（输入给「舍弃 k 个」就等价于留 n-k 个），最大化 a 的和 / b 的和。b 的和为 0 无意义。n 上千，2^n 枚举没戏，好在题目只要求规定精度内正确，用二分逼近。

一、结余表达式

把「比值 ≥ x」翻译成加性判定：a 的和 / b 的和 ≥ x ⟺ (a 的和) − x·(b 的和) ≥ 0。给每个数据定义结余 m_i = a_i − x·b_i，选中的集合结余和就是 (a 的和) − x·(b 的和)。判定问题变成：固定 x，能不能选出 k 个数据，让结余和 ≥ 0。

结余和是可分离的：每个数据对总和的贡献就是自己的结余，所以最优选择直接取结余最大的 k 个。check(x) 三步：算结余、按结余排序、取前 k 个求和。

x 从 0 增大，结余和只降不升（每选一个数据斜率 −b_i ≤ 0）。存在唯一的 x* 让最优结余和为 0，它就是最大比值：x < x* 时 check 过，x > x* 时 check 不过。单调、可二分。

二、二分答案

上界取所有 a 的和（b ≥ 1 时比值不超过它），下界 0。每轮 x = (l + r) / 2 跑一次 check：check 为 true，说明这个 x 能达成，答案更新成 x，去右侧二分；check 为 false，去左侧。

每轮排序 O(n log n)，二分约 log V 轮，总 O(n log n log V)。sml 取 1e-6，比题面精度要求小两个数量级。

三、模板题

洛谷 P10505 与 POJ 2976 是同一道模板：n 个数据舍弃 k 个，留 n-k 个，最大化比值，乘 100 四舍五入。n ≤ 100、a、b ≤ 10^9。double 存 a、b 绰绰有余（10^9 在 double 精确整数范围内）。

check 的排序只认结余，a、b 本身不动：

bool check(double x) {
        for (int i = 1; i <= n; i++) {
            arr[i].m = arr[i].a - x * arr[i].b;
        }
        sort(arr.begin() + 1, arr.end(), [](const Node& u, const Node& v) {
            return u.m > v.m;
        });
        double sum = 0;
        for (int i = 1; i <= k; i++) sum += arr[i].m;
        return sum >= 0;
    }

输入给的是「舍弃数」，main 一进来 k = n − k 改成保留数，后面全按保留 k 个算。输出四舍五入用 (int)(100 * (ans + 0.005))，不是截断：

int main() {
        while (scanf("%d%d", &n, &k) == 2 && (n || k)) {
            arr.resize(n + 1);
            k = n - k;
            for (int i = 1; i <= n; i++) scanf("%lf", &arr[i].a);
            for (int i = 1; i <= n; i++) scanf("%lf", &arr[i].b);
            double l = 0, r = 0, ans = 0;
            for (int i = 1; i <= n; i++) r += arr[i].a;
            while (l < r && r - l >= sml) {
                double x = (l + r) / 2;
                if (check(x)) {
                    ans = x;
                    l = x + sml;
                } else {
                    r = x - sml;
                }
            }
            printf("%d\n", (int)(100 * (ans + 0.005)));
        }
    }
演示：结余排序 + 二分逼近

四、总结

01分数规划的骨架只有两块：把比值 ≥ x 改写成结余和 ≥ 0，然后对 x 二分。check 里「怎么选」因题而异，但结余表达式不变，二分方向看求最大还是最小。下面两页会看到同样的骨架接上背包、生成树、负环判定和树型dp，check 内部换成对应工具即可。
