莫队算法

查询全部拿到手、顺序随便排。先按 l 所在块分组、块内按 r 排序，再让两个指针接力滑动，总耗时压到 O((n+m)√n)。

零、背景

前面几节处理的都是边改边查，来一个操作就答一个。

还有一类题不一样：所有查询一次性给你，顺序随便你安排，最后把答案交上去就行。这类叫离线查询。

既然顺序自由，就可以先排序再回答。莫队是这条路上最典型的一个：它把查询重新排个序，让两个指针接力滑动，把总耗时从 O(nm) 压到 O((n+m)√n)。

一、问题

长度为 n 的数组 a，要回答 m 次查询。每次给区间 [l, r]，问这个区间里不同的数字有多少个。

例如 a = [1, 2, 1, 3, 2, 4, 1, 3]，查询 [0, 3] 里有 1、2、3 三种，答案是 3。

这些查询是离线的，可以全部拿到手再一起回答。

二、朴素做法

每个查询从 l 扫到 r，用计数数组 cnt 记每个数字出现几次，第一次出现时答案加一。

int query(int l, int r) {
    int cnt[MAXV] = {0}, ans = 0;
    for (int i = l; i <= r; i++) {
        if (cnt[a[i]] == 0) ans++;   // 第一次出现，答案加一
        cnt[a[i]]++;
    }
    return ans;
}

单次 O(n)，m 次就是 O(nm)。n 和 m 都到 10⁵ 时是 10¹⁰，跑不完。

浪费全在重复扫描上。看下面这 6 个查询的区间。

三、移动窗口

如果上一次查 [2, 5]，这一次查 [1, 6]，就没必要从头扫，只要把左端点从 2 挪到 1、右端点从 5 挪到 6。

于是维护一个当前窗口 [curL, curR]，以及这个窗口的计数和答案。回答新查询时逐步移动指针，每移一步更新答案。

移动一步只是增删一个元素，O(1)。

void add(int x) {                // 把 a[x] 加进窗口
    if (cnt[a[x]] == 0) ans++;   // 之前没有，现在有了
    cnt[a[x]]++;
}
void del(int x) {                // 把 a[x] 移出窗口
    cnt[a[x]]--;
    if (cnt[a[x]] == 0) ans--;   // 移走后一个不剩，答案减一
}

可以发现，这样算下来总时间只取决于指针一共走了多少步。查询顺序乱，指针来回横跳，步数还是 O(nm)；顺序排得好，步数就少。

四、给查询排序

排序规则借分块的思路：把左端点 l 按块分组，块大小约 √n。第一关键字是 l 所在的块号，第二关键字是同一块内按 r 从小到大。

int BS = sqrt(n);                // 块大小（约 √n）
bool cmp(Q a, Q b) {              // 查询的排序规则
    if (a.l / BS != b.l / BS)     // 先比较 l 所在的块
        return a.l / BS < b.l / BS;
    return a.r < b.r;             // 同一块内按 r 排
}
sort(q, q + m, cmp);

这么排的效果是：同一块内，l 只在块里摆动，最多 B 步；r 只增不减，一路向右。跨块时 r 会跳回左边一次，但块只有 n/B 个。

五、代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100005, MAXV = 1000005;
int a[N], cnt[MAXV], ans = 0;

struct Q {
    int l, r, id;       // id 记住这是第几个查询
} q[N];
int res[N];             // 每个查询的最终答案
int BS;

bool cmp(Q a, Q b) {    // 排序规则
    if (a.l / BS != b.l / BS) return a.l / BS < b.l / BS;
    return a.r < b.r;
}

void add(int x) {
    if (cnt[a[x]] == 0) ans++;
    cnt[a[x]]++;
}
void del(int x) {
    cnt[a[x]]--;
    if (cnt[a[x]] == 0) ans--;
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < m; i++) {
        cin >> q[i].l >> q[i].r;
        q[i].l--; q[i].r--;      // 转成 0 下标
        q[i].id = i;
    }
    BS = max(1, (int)sqrt(n));
    sort(q, q + m, cmp);

    int curL = 0, curR = -1;    // 初始空窗口
    for (int i = 0; i < m; i++) {
        int l = q[i].l, r = q[i].r;
        while (curL > l) add(--curL);
        while (curR < r) add(++curR);
        while (curL < l) del(curL++);
        while (curR > r) del(curR--);
        res[q[i].id] = ans;
    }
    for (int i = 0; i < m; i++) cout << res[i] << endl;
    return 0;
}

六、复杂度分析

设块大小为 B（约 √n），共 m 次查询，两个指针各自的移动量分开算。

左指针 curL：同一块内的查询，l 都落在这一块里，curL 每次最多移动 B 步，m 次查询合计 mB；跨块时最多从 n 跳回 0，块有 n/B 个，合计 n。加起来 O(mB + n)。

右指针 curR：同一块内 r 只增不减，最多走 n 步；块有 n/B 个，合计 n²/B。加起来 O(n²/B)。

取 B = √n，两项分别是 O(m√n) 和 O(n√n)，合起来就是 O((n + m)√n)。

操作时间复杂度
预处理 sortO(m log m)
移动一步（add / del）O(1)
左指针总移动O(m√n + n)
右指针总移动O(n√n)
全部 m 次查询O((n + m)√n)

空间上需要一个计数数组 cnt（大小是值域 V）和存查询的数组（大小 m），额外空间 O(V + m)。

对比朴素做法的 O(nm)：n 和 m 都是 10⁵ 时，nm 是 10¹⁰，(n+m)√n 约 6×10⁷，差了三个数量级。

这里有个常用的常数优化。块内按 r 升序排，跨块时右指针得从最右跳回最左，白走一趟。改成奇数块 r 升序、偶数块 r 降序，右指针跨块时就能顺着往回扫，省掉一半左右的移动。

七、最后

莫队能成立需要两个前提。一是查询离线，顺序能自己定；二是窗口能 O(1) 增删，也就是从一个区间挪到相邻区间时，答案可以增量维护。

不同数字个数、区间和、区间众数这些都满足。一旦查询中间夹着修改操作，指针就不只是在平面上滑动了，还多出一个时间维度，那个叫带修莫队，得再加一重分块。
