拓扑排序：Kahn 算法与两种建图

拓扑排序给有向无环图的点排个序，让每条边 u→v 都满足 u 排在 v 前面。Kahn 算法靠入度：入度为 0 的点没有前置，先出队；删掉它再找新的入度为 0 的点。如果最后有点删不掉，图里有环。

零、背景

课程表问题：0 号课要先修 1 号课，就用一条边 1→0 表示。学完全部课程的一个合法顺序，就是整张图的拓扑序。只有有向无环图才有拓扑序，有环意味着循环依赖，无解。

拓扑排序的顺序不只一种：多个入度为 0 的点同时可用时，先取谁都合法。这给了后面「字典序最小」做文章的空间，也给了出题人把环藏进来的空间。

一、Kahn 算法

四步：1）找所有入度为 0 的点入队；2）出队一个点，把它放进答案；3）删掉它，重点是删掉影响：它所有出边指向的点的入度减 1，减到 0 就入队；4）重复到队空。出队的顺序就是拓扑序。

判环：如果最后答案里点的数量小于 n，说明有环。环上的点互相牵制，谁也减不到入度 0，永远出不了队。

LC210 的例子是 4 门课，前置 [[1,0],[2,0],[3,1],[3,2]]，也就是 0→1、0→2、1→3、2→3。0 的入度是 0 先出，然后 1、2 的入度都变 0，出队顺序 0 1 2 3 或 0 2 1 3 都合法。图里若藏着 0→1 又 1→0 的环，就返回空数组。

二、模版代码：邻接表动态建图（LC210）

点的编号从 0 开始。graph[bi] 挂 ai 表示 bi→ai 这条边，入度表 indegree[ai] 加 1。队列开 n 长，出队顺序即答案；cnt 数出队点数，不等于 n 就返回空。

#include <bits/stdc++.h>
    using namespace std;
    // ================= 题 2：拓扑排序模版（邻接表动态建图，LC210） =================
    vector<int> FindOrder(int n, const vector<pair<int, int>>& pre) {
        vector<vector<int>> graph(n);
        vector<int> indegree(n, 0);
        for (auto& e : pre) {
            graph[e.second].push_back(e.first);
            indegree[e.first]++;
        }
        vector<int> queue(n);
        int l = 0, r = 0;
        for (int i = 0; i < n; i++)
            if (indegree[i] == 0) queue[r++] = i;
        int cnt = 0;
        while (l < r) {
            int cur = queue[l++];
            cnt++;
            for (int next : graph[cur])
                if (--indegree[next] == 0) queue[r++] = next;
        }
        return cnt == n ? queue : vector<int>();
    }

三、模版代码：链式前向星静态建图（牛客）

比赛版：点从 1 开始，链式前向星建图，队列和入度表都是定长数组。MAXN、MAXM 按题面数据范围开，这里开 200001 对应 n、m 不超过 2e5。有环输出 -1。

两种建图跑拓扑排序的差距很小：n=4e5、m≈6.4e5 的随机 DAG 实测，邻接表 6.23ms，链式前向星 6.54ms。差距不在拓扑排序本身，在内存布局。真正拉开差距的是空间：邻接表每挂一条边要一次堆分配，链式前向星全部写进定长数组。

#include <bits/stdc++.h>
    using namespace std;
    // ================= 题 2 变体：链式前向星静态建图（牛客模版） =================
    namespace TopoStatic {
    const int MAXN = 200001, MAXM = 200001;
    int head[MAXN], nxt[MAXM], to[MAXM], cnt;
    int indegree[MAXN], queueArr[MAXN];
    int l, r;

    void build(int n) {
        cnt = 1;
        fill(head, head + n + 1, 0);
        fill(indegree, indegree + n + 1, 0);
    }

    void addEdge(int f, int t) {
        nxt[cnt] = head[f];
        to[cnt] = t;
        head[f] = cnt++;
    }

    bool topoSort(int n, vector<int>& ans) {
        l = r = 0;
        for (int i = 1; i <= n; i++)
            if (indegree[i] == 0) queueArr[r++] = i;
        int cntNode = 0;
        while (l < r) {
            int cur = queueArr[l++];
            ans.push_back(cur);
            cntNode++;
            for (int ei = head[cur]; ei > 0; ei = nxt[ei]) {
                if (--indegree[to[ei]] == 0) queueArr[r++] = to[ei];
            }
        }
        return cntNode == n;
    }
    } // namespace TopoStatic

四、演示：Kahn 算法逐步执行

入度表跟着每一步更新，队列里装当前可用的点。试试有环的预设，看环上的点怎么都出不了队。

总结

Kahn 算法的骨架：入度表 + 队列 + 删影响，三件套缺一不可。判环用出队点数对比 n，这是拓扑排序最常见的用途之一。

队列换成小根堆，输出就是字典序最小的拓扑序，这就是下一页的事。再往后，火星词典、戳印序列这些题都是「先建模成图，再跑拓扑排序」。
