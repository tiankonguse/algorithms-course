后缀最大值加速：从上到下挖砖块

三角形砖墙，从上往下挖，挖一块要先把它的左上方和正上方两块挖掉。dp 转移枚举「上一列挖了几块」，这段枚举每次都要重新扫一遍已算好的行。预处理好每列的后缀最大值，枚举变成 O(1) 查表，还顺带把空间压成一个方阵。

零、背景

这一题和前三题的区别：预处理数组是「dp 表自身形态的复用」：每列的后缀最大值就是从 dp 行扫出来的，但每算一行就重新铺一遍，让转移里反复出现的 max 查询变成 O(1)。

一、问题

n 行三角形砖墙，第 j 行有 j 块砖（j 从 1 到 n），每块砖有一个分值（可能为负）。挖砖必须从上往下：挖第 i 行第 j 列（从右往左数）的砖，要求它正上方 grid[i][j-1] 和右上方 grid[i-1][j-1] 都已经挖掉。一共挖 m 块，返回能得到的最大分值。n ≤ 100，m ≤ 5000。

二、旋转存储

三、dp 与朴素枚举

第 i 列挖前 j 块（0 ≤ j ≤ i），收益 cur 是 grid[1..i][j] 的列内前缀和。上一列（i-1）挖了 x 块，那么第 i 列能挖 j 块的前提是 x ≥ j-1（右上方的支撑链），转移：

dp[j][k] = max(max(0, j-1) ≤ x ≤ k 的 dp[x][k-j]) + cur，其中 k 是总挖块数。

朴素对每个 (j, k) 枚举 x，O(n³) 起步。观察 max 查询的形态：k-j 固定时，x 的取值区间是 [max(0,j-1), k]，也就是「dp 行 0..k 上、列 k-j 的后缀最大值」。

四、后缀最大值预处理

每处理完一行 i，就铺一张 max[row][col] = dp 行 0..row 中、列 col 的后缀最大值。下一行转移时直接查：

// 预处理：max[row][col] 是 dp 的行 0..rowLimit 中、列 col 上的后缀最大值
    // 转移里"枚举上一列挖几块"的 O(i) 段被这张表压成 O(1)
    void prepare(int rowLimit) {
        for (int col = 0; col <= m; col++) {
            for (int row = rowLimit, suf = 0; row >= 0; row--) {
                suf = max(suf, dp[row][col]);
                max[row][col] = suf;
            }
        }
    }

主流程：

int compute() {
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            prepare(i - 1);              // 用前 i-1 行重新铺后缀最大值
            int cur = 0;                 // 第 i 列前 j 块的收益和
            for (int j = 0; j <= i; j++) {
                cur += grid[i][j];
                // 第 i 列挖前 j 块，至少要挖 j(j+1)/2 块（支撑链）
                for (int k = (j + 1) * j / 2; k <= m; k++) {
                    dp[j][k] = max[max(0, j - 1)][k - j] + cur;
                    ans = max(ans, dp[j][k]);
                }
            }
        }
        return ans;
    }

支撑链细节：第 i 列挖 j 块，右上方的第 i-1 列至少要挖 j-1 块，所以总块数 k 的起点是 j + (j-1) + ... + 1 = j(j+1)/2，这就是内层 k 从 (j+1)j/2 开始的原因。x 的上限取 k-j 而不是 m，因为右边各列还要分剩下的块数。

复杂度分析

朴素对每格枚举 x 是 O(n·m·n)；优化后每列铺表 O(m)，每格查表 O(1)，总 O(n·m) 铺表 + O(n·m) 填格 = O(n·m)。n = 100、m = 5000 时 5×10 的 5 次方，朴素最坏 5×10 的 7 次方。空间：dp 是 (n+1)×(m+1)，max 表同尺寸，O(n·m)。

总结

最后一题的三步：旋转存储让「右上支撑」变成列间依赖；看穿转移的 max 查询是「固定列的后缀最大值」；每列铺一次表，枚举 x 变查表。和炮兵阵地对比，那题预处理与 dp 无关的合法状态，这题预处理 dp 自身的后缀形态，但本质都是把反复枚举换成查数组。

这五题串起来就是预处理数组的两种用法：减少枚举（jump、行状态）和加速枚举（前缀/后缀和、前缀/后缀最值）。
