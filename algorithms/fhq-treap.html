FHQ Treap：split 与 merge 代替旋转

前面几课的有序表都在靠旋转维持平衡：AVL 转出四种违规分析，Treap 插入挂上再旋、删除分四情况。这一课换一种活法：整棵树不做任何旋转，只做两件事。split 把一棵树按值或排名劈成两半，merge 把两棵子树按优先级拼回去。所有操作都是这两个函数的排列组合，代码量比旋转版少一大截，还天然支持可持久化。算法竞赛「有序表必带模板」四件套里，FHQ Treap 是常被点名的一个。

零、背景

Treap 的平衡靠每个节点一个随机优先级：key 当搜索树、priority 当堆，期望 O(log n)。旋转版维护这两条性质要旋，插入删除各有分支；FHQ Treap 同一套随机优先级，但平衡性靠 split 和 merge 两个递归函数天然保持，写起来就剩「劈开、拼回」两个动作。

这一页讲普通有序表的两个版本：词频压缩版（重复值只存一个节点）和无词频版（FHQ 最常规的实现，每个值一个节点）。区间操作和可持久化在另外两页。

一、split：按值把树劈成两半

split 按 key 分裂：给定一棵搜索树和阈值 num，把 key ≤ num 的节点拧成一棵搜索树，key > num 的拧成另一棵。也可以按排名分裂：前 rank 个节点一棵，剩下的另一棵。区间操作那页用排名版，这一页全是按值。

代码里 split 的签名是 split(l, r, i, num)，三个参数里 l 和 r 不是普通变量，是「缺口链」：递归走到 key ≤ num 的分支时，把当前节点挂到 l 链的右侧（rs[l] = i），再往下劈它的右子树；走 key > num 的分支时，把节点挂到 r 链的左侧（ls[r] = i），再往下劈左子树。等 i 走到 0，两棵树的头分别出现在 rs[0]（≤ 部分）和 ls[0]（> 部分）。

递归路径上的每个节点在返回前都 up 一次重算 siz，所以劈完两棵树的 siz 都是对的。

二、merge：按优先级拼回一棵树

merge(l, r) 要求 l 整棵树的 key 都小于 r 整棵树的 key（按排名分裂时是 l 的排名全在 r 前面）。每一层比较两个头的优先级，priority 大的一方做当前的根，然后递归拼对方的子树：l 当头就拼 rs[l] 和 r，r 当头就拼 l 和 ls[r]。

因为 l 和 r 的 key 范围不相交，拼出来的树中序遍历正好是 l 的中序接 r 的中序，搜索树性质天然成立；优先级堆性质由每一层的取大保证。整个操作不做任何旋转，这是 FHQ 和旋转版 Treap 唯一的区别。

三、无词频版六操作

所有操作都是 split + merge 的组合。用临时槽 rs[0]、ls[0] 接收劈出的两棵树，用完立刻取走，下次 split 会重新覆盖。

1）增加 x：split(head, x - 1) 把 ≤ x - 1 的部分分出来，新建节点夹回去。
2）删除 x：两次 split 取出整棵 key == x 的子树 m，直接把 m 丢掉，把左右拼回。
3）查询排名：split(head, x - 1)，siz[rs[0]] + 1 就是比 x 小的个数加一。
4）查第 k 小、前驱、后继：直接在树上递归，不用 split。

这里有个细节。删除用的是 merge(merge(l, merge(ls[m], rs[m])), r)，如果删除的 x 根本不在树里，第二次 split 劈出来的 m 是 0，ls[m] 和 rs[m] 会读到临时槽 rs[0]（那里还存着 l），等于把 l 和自己合并了一次，变成自环，递归下去就是栈溢出。P3369 保证删除的数存在，线上不会触发；但写通用代码时要么先查存在性，要么删完把临时槽清掉。

四、题2 完整实现（P3369 无词频版）

无词频是 FHQ 最常规的设定：左子树的 key ≤ 根 ≤ 右子树。洛谷 P3369 数据规模 1e5、x ∈ [-1e7, 1e7]，静态数组开 1e5 就够。前驱后继不存在时分别返回整数最小值与最大值，和题面一致。

注意 add 里新节点入树用的是 merge(merge(rs[0], cnt), ls[0])，临时槽取走后立即使用；getRank 用完后把两半拼回，树保持原状。

#include <iostream>
    #include <cstdio>
    #include <cstdlib>
    #include <cstring>
    #include <algorithm>
    #include <climits>
    using namespace std;

    const int MAXN = 100001;
    int head = 0;
    int cnt = 0;
    int key[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int siz[MAXN];
    double priority[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + 1;
    }

    void split(int l, int r, int i, int num) {
        if (i == 0) {
            rs[l] = ls[r] = 0;
        } else {
            if (key[i] <= num) {
                rs[l] = i;
                split(i, r, rs[i], num);
            } else {
                ls[r] = i;
                split(l, i, ls[i], num);
            }
            up(i);
        }
    }

    int merge(int l, int r) {
        if (l == 0 || r == 0) {
            return l + r;
        }
        if (priority[l] >= priority[r]) {
            rs[l] = merge(rs[l], r);
            up(l);
            return l;
        } else {
            ls[r] = merge(l, ls[r]);
            up(r);
            return r;
        }
    }

    void add(int num) {
        split(0, 0, head, num);
        key[++cnt] = num;
        siz[cnt] = 1;
        priority[cnt] = (double)rand() / RAND_MAX;
        head = merge(merge(rs[0], cnt), ls[0]);
    }

    void remove(int num) {
        split(0, 0, head, num);
        int lm = rs[0];
        int r = ls[0];
        split(0, 0, lm, num - 1);
        int l = rs[0];
        int m = ls[0];
        head = merge(merge(l, merge(ls[m], rs[m])), r);
    }

    int getRank(int num) {
        split(0, 0, head, num - 1);
        int ans = siz[rs[0]] + 1;
        head = merge(rs[0], ls[0]);
        return ans;
    }

    int index(int i, int x) {
        if (siz[ls[i]] >= x) {
            return index(ls[i], x);
        } else if (siz[ls[i]] + 1 < x) {
            return index(rs[i], x - siz[ls[i]] - 1);
        } else {
            return key[i];
        }
    }

    int index(int x) {
        return index(head, x);
    }

    int pre(int i, int num) {
        if (i == 0) {
            return INT_MIN;
        }
        if (key[i] >= num) {
            return pre(ls[i], num);
        } else {
            return max(key[i], pre(rs[i], num));
        }
    }

    int pre(int num) {
        return pre(head, num);
    }

    int post(int i, int num) {
        if (i == 0) {
            return INT_MAX;
        }
        if (key[i] <= num) {
            return post(rs[i], num);
        } else {
            return min(key[i], post(ls[i], num));
        }
    }

    int post(int num) {
        return post(head, num);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        srand(time(0));
        int n;
        cin >> n;
        for (int i = 1, op, x; i <= n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        return 0;
    }

五、词频压缩版

P3369 允许重复加入同一个 x。无词频版每个 x 一个节点，重复多少次就建多少个节点；词频版给每个节点多存一个 count，重复值只建一个节点，siz 变成左子树大小 + 右子树大小 + count。插入时先 find，找到了 count 加一，找不到才 split 建新节点；删除时先 find，count 大于一就减一，等于一才做真正的 split 删除。这版删除在找到节点时才动树，不存在直接不操作，没有上一节那个自环问题。

词频版还有一个细节：删除时 count 等于一才 split，而 split 出来的是整棵 key == num 的子树，直接丢掉它（包括它的左右孩子），因为这个词频压缩下 key == num 只可能是这一个节点。up 里 siz 的合并公式换成带 count 的版本，排名查询就自动正确。

六、题1 完整实现（P3369 词频压缩版）

与题2 同题同数据范围，只是内部结构换成语频压缩。find 用搜索树性质直接找节点编号，changeCount 沿路更新 siz。

#include <iostream>
    #include <cstdio>
    #include <cstdlib>
    #include <cstring>
    #include <algorithm>
    #include <climits>
    using namespace std;

    const int MAXN = 100001;
    int head = 0;
    int cnt = 0;
    int key[MAXN];
    int key_count[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int siz[MAXN];
    double priority[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + key_count[i];
    }

    void split(int l, int r, int i, int num) {
        if (i == 0) {
            rs[l] = ls[r] = 0;
        } else {
            if (key[i] <= num) {
                rs[l] = i;
                split(i, r, rs[i], num);
            } else {
                ls[r] = i;
                split(l, i, ls[i], num);
            }
            up(i);
        }
    }

    int merge(int l, int r) {
        if (l == 0 || r == 0) {
            return l + r;
        }
        if (priority[l] >= priority[r]) {
            rs[l] = merge(rs[l], r);
            up(l);
            return l;
        } else {
            ls[r] = merge(l, ls[r]);
            up(r);
            return r;
        }
    }

    int find(int i, int num) {
        if (i == 0) {
            return 0;
        }
        if (key[i] == num) {
            return i;
        } else if (key[i] > num) {
            return find(ls[i], num);
        } else {
            return find(rs[i], num);
        }
    }

    void changeCount(int i, int num, int change) {
        if (key[i] == num) {
            key_count[i] += change;
        } else if (key[i] > num) {
            changeCount(ls[i], num, change);
        } else {
            changeCount(rs[i], num, change);
        }
        up(i);
    }

    void add(int num) {
        if (find(head, num) != 0) {
            changeCount(head, num, 1);
        } else {
            split(0, 0, head, num);
            key[++cnt] = num;
            key_count[cnt] = siz[cnt] = 1;
            priority[cnt] = (double)rand() / RAND_MAX;
            head = merge(merge(rs[0], cnt), ls[0]);
        }
    }

    void remove(int num) {
        int i = find(head, num);
        if (i != 0) {
            if (key_count[i] > 1) {
                changeCount(head, num, -1);
            } else {
                split(0, 0, head, num);
                int lm = rs[0];
                int r = ls[0];
                split(0, 0, lm, num - 1);
                int l = rs[0];
                head = merge(l, r);
            }
        }
    }

    int small(int i, int num) {
        if (i == 0) {
            return 0;
        }
        if (key[i] >= num) {
            return small(ls[i], num);
        } else {
            return siz[ls[i]] + key_count[i] + small(rs[i], num);
        }
    }

    int getRank(int num) {
        return small(head, num) + 1;
    }

    int index(int i, int x) {
        if (siz[ls[i]] >= x) {
            return index(ls[i], x);
        } else if (siz[ls[i]] + key_count[i] < x) {
            return index(rs[i], x - siz[ls[i]] - key_count[i]);
        }
        return key[i];
    }

    int index(int x) {
        return index(head, x);
    }

    int pre(int i, int num) {
        if (i == 0) {
            return INT_MIN;
        }
        if (key[i] >= num) {
            return pre(ls[i], num);
        } else {
            return max(key[i], pre(rs[i], num));
        }
    }

    int pre(int num) {
        return pre(head, num);
    }

    int post(int i, int num) {
        if (i == 0) {
            return INT_MAX;
        }
        if (key[i] <= num) {
            return post(rs[i], num);
        } else {
            return min(key[i], post(ls[i], num));
        }
    }

    int post(int num) {
        return post(head, num);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        srand(time(0));
        int n;
        cin >> n;
        for (int i = 1, op, x; i <= n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        return 0;
    }

七、数据加强：P6136 强制在线

题目链接页有 P6136：一开始给 n 个初始值，再给 m 个操作，每次输入的 x 要异或上一次查询的答案，最后把所有答案异或起来输出。代码就是无词频版加一个 main 的在线包装，数据量翻到 2e5，结构本身不用改。课上没有讲，留作自己验证。

八、总结

FHQ Treap 把平衡问题全部交给 split 和 merge：按值分裂适合有序表六操作，按排名分裂适合区间操作，两个函数都是纯递归、不碰旋转。词频压缩版用 count 换节点数，重复数据下省空间，删除只在 count 归零时动树；无词频版实现最直接，是理解 FHQ 的起点。下一课用它处理区间移动和范围翻转，再下一课加可持久化。
