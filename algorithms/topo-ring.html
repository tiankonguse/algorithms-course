基环树上的圆桌：拓扑删叶与环统计

每位员工都有一个喜欢的人，只有当被安排在喜欢的人旁边时才会参会，圆桌可以坐任意多人，求最多能坐多少人。favorite[i]=j 是一张每个点出度都为 1 的图，它的每个连通块是基环树：一个环，外挂几棵树。答案只跟环有关。

零、为什么每个连通块一定是基环树

favorite[i]=j 表示 i 指向 j，每个点恰好一条出边。n 个点 n 条边的有向图，每个弱连通分量里必然恰好有一个环，环上再挂树。这种结构叫基环树（也叫环套树）。

圆桌是环形排列：每个人至多两个邻座。环上的人两两相邻刚好满足；挂在环外的树上的点，只能顺着「谁喜欢谁」的链坐进圆桌，而且链的首尾必须接在环上的人旁边。

一、拓扑排序删掉所有树点

先做一遍拓扑排序：入度为 0 的点是树的叶子，没人喜欢它们，它们不可能是环上的人。出队时更新 deep[next] = max(deep[next], deep[cur] + 1)，然后把它删掉。deep[i] 的含义是「不包括 i 在内、能一路喜欢到 i 的最长链长」。

删完之后，剩下的所有点入度都大于 0，它们正好是全部的环。

二、两类环，两种算法

环长等于 2 和大于 2，答案的结构完全不同，分开处理：

环长大于 2：环上的人必须全部参会（少一个就有人旁边坐的不是喜欢的人），非环点一个都塞不进去。候选就是环长本身。

环长等于 2（a 喜欢 b、b 喜欢 a）：a 和 b 相邻坐，a 的另一侧可以接一条「喜欢 a 的最长链」，b 的另一侧接「喜欢 b 的最长链」。更妙的是，多个 2 环可以串在同一条大圆桌上（链尾接下一个 2 环的人），所以所有 2 环的贡献直接相加：2 + deep[a] + deep[b]。

答案取两者的最大值。

复杂度 O(n)。deep 的更新方向和拓扑删叶是同一遍循环，遍历完环直接统计，不用再建反向图。

#include <bits/stdc++.h>
    using namespace std;

    namespace Invitations {
    // 拓扑排序删掉所有不在环上的点，deep[i] 记录「不包括 i 的最长入链长度」；
    // 环长 2 的可带链（两条链 + 两个中心点，所有 2 环可以串起来），环长 > 2 只算环长。
    int maximumInvitations(const vector<int>& favorite) {
      int n = favorite.size();
      vector<int> indeg(n, 0);
      for (int i = 0; i < n; i++) indeg[favorite[i]]++;
      vector<int> que(n);
      int l = 0, r = 0;
      for (int i = 0; i < n; i++) {
        if (indeg[i] == 0) que[r++] = i;
      }
      vector<int> deep(n, 0);
      while (l < r) {
        int cur = que[l++];
        int next = favorite[cur];
        deep[next] = max(deep[next], deep[cur] + 1);
        if (--indeg[next] == 0) que[r++] = next;
      }
      int sumOfSmallRings = 0;
      int bigRings = 0;
      for (int i = 0; i < n; i++) {
        if (indeg[i] > 0) {
          int ringSize = 1;
          indeg[i] = 0;
          for (int j = favorite[i]; j != i; j = favorite[j]) {
            ringSize++;
            indeg[j] = 0;
          }
          if (ringSize == 2) {
            sumOfSmallRings += 2 + deep[i] + deep[favorite[i]];
          } else {
            bigRings = max(bigRings, ringSize);
          }
        }
      }
      return max(sumOfSmallRings, bigRings);
    }
    } // namespace Invitations

总结

函数图（每点出度 1）的题，先拓扑排序删叶，剩下的就是环。deep[i] 记录 i 的最长入链，2 环能带链且能累加，大环只能算环长。两类环分开统计，答案取 max。

删叶这一步用的还是拓扑排序：入度为 0 的点进队列，一路剥到只剩环。
