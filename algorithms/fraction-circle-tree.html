01分数规划：负环与树型dp

选择结构变成「图上找环」和「树上选闭包」时，check 内部换成判负环和树型dp，结余表达式与二分框架还是老样子。

零、问题

最小圈：n ≤ 3000、m ≤ 10000 的有向带权图，边权可负。环平均 = 环内边权和 / 边数，返回所有环里最小的平均值，保留 8 位小数。

最佳团体：k ≤ n ≤ 2500 的树，0 号是根且免费，每个非根节点有招募花费和战斗值。招一个节点必须连它所有祖先一起招，除根外恰好招 k 个，最大化 战斗和 / 花费和，保留 3 位小数。

「环」和「树上闭包」这两类选择，top-k 表达不了，check 内部换了判定工具，但读法一样：固定 x，结余和 ≥ 0 才通过。

一、环平均：减 x 判负环

固定 x，把每条边权减去 x。某个环的原平均 < x，等价于减 x 后这个环的权和 < 0。所以 check(x) 就是问：这张图有没有负环。最小圈的平均就是二分能到达的最小 x。

判负环用递归版 spfa：value[u] 记超级源点到 u 的最小累积边权，path[u] 记 u 是否在当前的递归路径上。边权能变小时才更新，更新完发现目标是递归路径上的点（回边成环），或者递归下去发现负环，就报告 true。

bool dfs(int u, double x) {
        if (u == 0) {
            for (int i = 1; i <= n; i++) {
                if (dfs(i, x)) return true;
            }
        } else {
            path[u] = true;
            for (int e = head[u]; e != 0; e = nxt[e]) {
                int v = to[e];
                double w = wgt[e] - x;
                if (value[v] > value[u] + w) {
                    value[v] = value[u] + w;
                    if (path[v] || dfs(v, x)) return true;
                }
            }
            path[u] = false;
        }
        return false;
    }

0 号点当超级源点，有通往所有点的边，从它开始逐个试。二分范围取 [−1e7, 1e7]，sml 1e-9：边权可负，左端不能从 0 开始。有负环说明最小平均还能更小，往左；没有负环才把 ans 更新成 x 往右。

二、树上闭包：dfn 序 + 树型dp

固定 x，节点结余 = 战斗值 − x·招募花费。要在树上选恰好 k 个点且闭包（选 v 必选父），最大化结余和。直接按树做 dp 要处理父子耦合，换成 dfn 序之后，树变成一段线性排列，子树是连续区间，背包直接在线上跑。

dfs 给每个节点编 dfn 号，同时记下子树大小 sz[i]：dfn 序里 i 的子树正好占 [i, i + sz[i] − 1]。

int dfs(int u) {
        int i = ++dfnCnt;
        dfn[u] = i;
        sz[i] = 1;
        for (int e = head[u]; e != 0; e = nxt[e]) {
            int v = to[e];
            sz[i] += dfs(v);
        }
        return sz[i];
    }

dp[i][j]：dfn 序 i 到 n 之间选 j 个点的最大结余。不选 i，整棵子树跳过，从 i + sz[i] 继续；选 i，结余 value[i] 加上从 i + 1 继续选 j − 1 个（i 的子树里其它点可再选，闭包已满足）：

bool check(double x) {
        for (int i = 0; i <= n; i++) {
            value[dfn[i]] = (double)strength[i] - x * cost[i];
        }
        for (int j = 1; j <= k; j++) dp[dfnCnt + 1][j] = NA;
        for (int i = dfnCnt; i >= 2; i--) {
            for (int j = 1; j <= k; j++) {
                dp[i][j] = max(dp[i + sz[i]][j], value[i] + dp[i + 1][j - 1]);
            }
        }
        return dp[2][k] >= 0;
    }

0 号节点 dfn 编号是 1，所以答案看 dp[2][k]。二分上界取 10000（战斗值上限），输出保留三位小数。

三、总结

负环判定接住「环平均」：减 x 之后有负环，说明平均还能压低，二分往左。树型dp 接住「树上闭包」：dfn 序把子树压成连续区间，不选就跳整棵子树。两题共享的骨架仍然是结余 + 二分，到这里 01分数规划的五种选择结构（top-k、背包、生成树、环、闭包）已经齐了。
