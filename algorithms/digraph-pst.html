主席树优化建图：任意区间连边降到 O(log v) 条边

树状数组只会切前缀 [1..p]，范围换成任意区间 [l..r] 就没了办法。线段树天然会拆区间，但袋子是动态的，点一个个进袋，静态树插不进去。按入袋顺序给线段树开版本，每次 add 只新建 O(log v) 个节点，任意区间的连边也就稳定在 O(log v) 条。

零、背景

前一页处理的是「前缀范围连边」：树状数组把前缀拆成 log 个槽位，槽位挂链，动态进袋没问题。可惜树状数组的分解只认前缀，lowbit 循环从 p 一路减到 0，拆出来的永远是 [1..p] 的若干段。

题目把范围改成了任意区间 [l..r]。会拆任意区间的结构是线段树：一个区间在树上分解成不超过 2·log v 个节点。经典的线段树优化建图就是这么做的，但那套做法默认点集是静态的，先把整棵树建好，再把点挂上去。

这一页的袋子是动态的。直接的想法是「线段树 + 版本」：每入袋一个点就开一个新版本，新版本只重造一条路径上的节点，其余部分共享旧版本。这正是主席树（可持久化线段树）的形态。

一、问题

接口和前一页几乎一样，只是前缀全部换成任意区间：

方法语义
add(x, xv)编号 x、点权 xv 的点进入袋子；已入袋则忽略
rangeToX(l, r, x, w)袋中点权范围 l 到 r 的每个点，向点 x 连边权 w 的边
xToRange(x, l, r, w)点 x 向袋中点权范围 l 到 r 的每个点，连边权 w 的边
rangeToRange(l1, r1, l2, r2, w)点权 l1 到 r1 的每个点，向点权 l2 到 r2 的每个点，连边权 w 的边

同样用 dijkstra 做对数器：优化版和暴力版在相同的随机操作流下建图，两份最短路必须逐对相等。

二、朴素做法

暴力还是扫袋子：rangeToX 找出点权落在 [l..r] 的点各连一条边，rangeToRange 是双重过滤。n、m 上 10⁵ 时边数 10¹⁰ 级，和前一页同一个死法。

先看静态版本怎么优化，再处理动态。这一步的方向感很重要：线段树要把「一片」压缩成「几个节点」，靠的是每个节点代表一段值域。

三、两棵方向相反的树

在值域 1 到 v 上建两棵线段树。出树（out 树）的边从儿子指向父亲，点 x 入袋时向自己值所在的叶子连一条边；查询 rangeToX(l, r, x, w) 把 [l..r] 分解成若干节点，每个节点向 x 连一条 w 边。点从叶子往上爬，爬到任何一个覆盖自己的分解节点，再花 w 到达 x。

入树（in 树）方向整个反过来：边从父亲指向儿子，叶子向点连边；xToRange 里 x 连向分解节点，顺着树往下流就到范围里的每个点。

四、动态袋子：按入袋顺序开版本

静态树的问题在「点什么时候挂上去」。如果先把树建死，再让点连向叶子，其实是可行的，这一页的查询永远看整个袋子，树的形态从没变过。真正需要版本的是另一件事：查询要区分时间。第四页的 P7477 里，位置 i 的连边只能看到 i 左侧已入袋的点，查询必须挂在版本 i−1 上，静态树给不了历史。

「线段树 + 版本」统一实现：每执行一次 add，版本号加一，出树、入树各开一个新根。新根到新叶的一条路径上逐层新建节点，路径之外的儿子指针直接抄旧版本。一个点入袋，出树、入树各新建 O(log v) 个节点。

还有一个不能省的细节：新节点要向同位置的旧节点连一条 0 权边（旧 → 新）。历史点的叶子连在旧节点上，它往上爬时会路过被替换过的位置；没有这条迁移边，老点就永远困在旧版本里，够不着新版本上的分解节点。

五、查询挂在版本上

rangeToX(l, r, x, w) 在出树的当前版本根上分解 [l..r]，命中的节点各向 x 连一条 w 边；xToRange 对称地用入树。分解走的是当前根，路径上自然混着各个版本出生的节点，共享的旧节点一样能用，这正是可持久化省下的部分。

rangeToRange(l1, r1, l2, r2, w) 和前一页一样造两个虚点 X、Y 桥接：出树分解连向 X，X 向 Y 连 w，Y 连向入树分解。

七、代码

出树用 buildOut 建空骨架，addOut 开新版本；入树方向相反。查询函数带区间参数的重载版本递归分解，外层包装挂在当前版本根上。对数器部分省略。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1001;
    const int MAXV = 1001;
    const int MAXT = 4000001;
    const int MAXE = 8000001;
    int n, v, cntt;

    bool inBag[MAXN];

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int weight[MAXE];
    int cntg;

    int rootOut[MAXN];
    int rootIn[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int curVersion;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int buildOut(int l, int r) {
        int rt = ++cntt;
        if (l < r) {
            int mid = (l + r) >> 1;
            ls[rt] = buildOut(l, mid);
            rs[rt] = buildOut(mid + 1, r);
            addEdge(ls[rt], rt, 0);
            addEdge(rs[rt], rt, 0);
        }
        return rt;
    }

    int buildIn(int l, int r) {
        int rt = ++cntt;
        if (l < r) {
            int mid = (l + r) >> 1;
            ls[rt] = buildIn(l, mid);
            rs[rt] = buildIn(mid + 1, r);
            addEdge(rt, ls[rt], 0);
            addEdge(rt, rs[rt], 0);
        }
        return rt;
    }

    int addOut(int jobx, int jobv, int l, int r, int i) {
        int rt = ++cntt;
        ls[rt] = ls[i];
        rs[rt] = rs[i];
        addEdge(i, rt, 0);
        if (l == r) {
            addEdge(jobx, rt, 0);
        } else {
            int mid = (l + r) >> 1;
            if (jobv <= mid) {
                ls[rt] = addOut(jobx, jobv, l, mid, ls[rt]);
                addEdge(ls[rt], rt, 0);
            } else {
                rs[rt] = addOut(jobx, jobv, mid + 1, r, rs[rt]);
                addEdge(rs[rt], rt, 0);
            }
        }
        return rt;
    }

    int addIn(int jobx, int jobv, int l, int r, int i) {
        int rt = ++cntt;
        ls[rt] = ls[i];
        rs[rt] = rs[i];
        addEdge(rt, i, 0);
        if (l == r) {
            addEdge(rt, jobx, 0);
        } else {
            int mid = (l + r) >> 1;
            if (jobv <= mid) {
                ls[rt] = addIn(jobx, jobv, l, mid, ls[rt]);
                addEdge(rt, ls[rt], 0);
            } else {
                rs[rt] = addIn(jobx, jobv, mid + 1, r, rs[rt]);
                addEdge(rt, rs[rt], 0);
            }
        }
        return rt;
    }

    void add(int x, int xv) {
        if (!inBag[x]) {
            inBag[x] = true;
            curVersion++;
            rootOut[curVersion] = addOut(x, xv, 1, v, rootOut[curVersion - 1]);
            rootIn[curVersion] = addIn(x, xv, 1, v, rootIn[curVersion - 1]);
        }
    }

    void rangeToX(int jobl, int jobr, int jobx, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobx, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                rangeToX(jobl, jobr, jobx, jobw, l, mid, ls[i]);
            }
            if (jobr > mid) {
                rangeToX(jobl, jobr, jobx, jobw, mid + 1, r, rs[i]);
            }
        }
    }

    void rangeToX(int l, int r, int x, int w) {
        rangeToX(l, r, x, w, 1, v, rootOut[curVersion]);
    }

    void xToRange(int jobx, int jobl, int jobr, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(jobx, i, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                xToRange(jobx, jobl, jobr, jobw, l, mid, ls[i]);
            }
            if (jobr > mid) {
                xToRange(jobx, jobl, jobr, jobw, mid + 1, r, rs[i]);
            }
        }
    }

    void xToRange(int x, int l, int r, int w) {
        xToRange(x, l, r, w, 1, v, rootIn[curVersion]);
    }

    void rangeToRange(int l1, int r1, int l2, int r2, int w) {
        int x = ++cntt;
        int y = ++cntt;
        rangeToX(l1, r1, x, 0);
        xToRange(y, l2, r2, 0);
        addEdge(x, y, w);
    }

八、复杂度分析

操作时间复杂度新增规模
建空骨架（出树 + 入树）O(v)节点 2·(2v − 1) 个
add(x, xv)O(log v)两棵树各 log v 个节点、O(log v) 条边
rangeToX / xToRangeO(log v)分解不超过 2·log v 个节点，边同阶
rangeToRangeO(log v)虚点 2 个、边 O(log v) 条
建图总规模节点 2v + n·log v + 2m，边 O((n + m)·log v)
查询任意历史版本O(log v)，版本数组随机访问

时间上每个操作都卡在线段树高度 log v 上，和树状数组版本一个量级，常数稍大，分解最多 2·log v 个节点，还要带上版本指针的拷贝。

空间比树状数组版本多一块：两棵骨架共 O(v)，加上 n 次入袋的 O(n log v) 新节点。值域大时同样先离散化，把 v 压到 n 的量级。

九、最后

主席树优化建图用版本换来了两样东西：任意区间的分解能力，以及「查询只看某个时刻」的历史能力。前者是线段树本身给的，后者才是可持久化的价值，第四页的 P7477 会把版本 i−1 精确地用在位置 i 的蕴含边上。

和前一页对比一下选型：范围永远是前缀、又关心时间的话，树状数组的链天然按时间增长，代码短得多；范围是任意区间才值得上主席树。两者处理的都是「值域上的范围」，如果约束变成「两个、三个权值同时不超过」，那已经不是范围问题，是偏序问题，下一页交给 CDQ 分治。
