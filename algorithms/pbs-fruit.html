接水果：路径包含与扫描线

盘子路径完全落在水果路径内部，这个「包含」关系在树上不好批量数，挪到 dfn 序上就变成平面上的矩形。矩形加扫描线，正好是整体二分喜欢的形状。

一、题目4：接水果

一共有 n 个点，给定 n − 1 条无向边，所有点连成一棵树。一共有 p 个盘子，每个盘子格式 a b c：盘子是点 a 到点 b 的路径，盘子权值为 c。一共有 q 个水果，每个水果格式 u v k：水果是点 u 到点 v 的路径，k 含义如下。如果一个盘子路径完全在一个水果路径的内部，那么该盘子可以接住该水果。那么对于每个水果，可能有很多盘子都可以将其接住，打印其中第 k 小的权值。1 ≤ n、p、q ≤ 4 × 10⁴，0 ≤ 盘子权值 ≤ 10⁹，内存可用空间 500MB。测试链接：P3242。

单个水果的做法是：把所有能接住它的盘子权值收起来排序取第 k 个。p、q 都是 4 × 10⁴，逐个做是 O(p·q) 级别，必须批量。

二、路径包含转成矩形

给每个点记 dfn，子树对应 dfn 上一段连续区间 [ldfn, rdfn]。水果的两个端点记成 X = min(dfn[u], dfn[v])、Y = max(dfn[u], dfn[v])，于是一个水果就是平面上的一个点 (X, Y)。盘子要问的是「哪些水果点落在我的区域里」，只要把区域写成若干个矩形就行。

盘子 (a, b) 先交换成 dfn[a] < dfn[b]，记 w = lca(a, b)，分两种形状。

形状一里那个 son 是 a 通向 b 的儿子，用倍增从 b 往上跳到 a 的下一层就能拿到。条件之所以是「一端在 b 的子树、另一端在 son 子树之外」，是因为水果路径要顺着 a 到 b 这条链走过来：它的一端必须落在链的末端 b 底下，另一端必须在别处，否则水果路径根本不会经过 a。

于是每个盘子变成一到两个矩形，每个矩形再拆成两条事件：在 x 起点处加 1，在 x 终点加一处减 1。水果变成一条查询事件，位置是 (X, Y)，带着它的 k。

三、扫描线与整体二分

把所有事件按 x 排序，x 相同时加在前、删在后、查询最后。顺着 x 从小往大扫，树状数组在 y 方向做区间加、单点查：扫到某个水果时，它在 y 位置查到的数，正好是所有矩形里覆盖这个点的个数。

外面套整体二分：只有权值不超过 mid 的盘子事件才真正打进树状数组，权值更大的那个盘子的加与删都跳过。于是水果在当前层查到的是「权值不超过 mid、又能接住我的盘子个数」，记成 satisfy。satisfy 不小于 k 就说明第 k 小不超过 mid，去左半；否则把 k 减去 satisfy 去右半。

这里有个细节：事件在整体二分里被划分成左右两堆之后，堆内仍然保持 x 的顺序，所以扫描线的因果关系不会乱。这也是为什么划分必须稳定。

void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        ldfn[u] = ++cntd;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if (to[e] != fa) {
                dfs(to[e], u);
            }
        }
        rdfn[u] = cntd;
    }

    int lca(int a, int b) {
        if (dep[a] < dep[b]) {
            int tmp = a;
            a = b;
            b = tmp;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int lcaSon(int a, int b) {
        if (dep[a] < dep[b]) {
            int tmp = a;
            a = b;
            b = tmp;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] > dep[b]) {
                a = stjump[a][p];
            }
        }
        return a;
    }

树状数组用的是「区间加、单点查」，两个端点各加一次。

int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= n) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    void add(int l, int r, int v) {
        add(l, v);
        add(r + 1, -v);
    }

    int query(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }
void compute(int el, int er, int vl, int vr) {
        if (el > er) {
            return;
        }
        if (vl == vr) {
            for (int i = el; i <= er; i++) {
                int id = eid[i];
                if (event[id].op == 3) {
                    ans[event[id].i] = vl;
                }
            }
        } else {
            int mid = (vl + vr) >> 1;
            int lsiz = 0, rsiz = 0;
            for (int i = el; i <= er; i++) {
                int id = eid[i];
                if (event[id].op == 1) {
                    if (event[id].v <= mid) {
                        add(event[id].yl, event[id].yr, 1);
                        lset[++lsiz] = id;
                    } else {
                        rset[++rsiz] = id;
                    }
                } else if (event[id].op == 2) {
                    if (event[id].v <= mid) {
                        add(event[id].yl, event[id].yr, -1);
                        lset[++lsiz] = id;
                    } else {
                        rset[++rsiz] = id;
                    }
                } else {
                    int satisfy = query(event[id].y);
                    if (satisfy >= event[id].k) {
                        lset[++lsiz] = id;
                    } else {
                        event[id].k -= satisfy;
                        rset[++rsiz] = id;
                    }
                }
            }
            for (int i = 1; i <= lsiz; i++) {
                eid[el + i - 1] = lset[i];
            }
            for (int i = 1; i <= rsiz; i++) {
                eid[el + lsiz + i - 1] = rset[i];
            }
            compute(el, el + lsiz - 1, vl, mid);
            compute(el + lsiz, er, mid + 1, vr);
        }
    }

四、复杂度分析

盘子拆出来的事件数是 O(p)，加上 q 个查询，排序一次 O((p + q) log(p + q))。整体二分在值域 0 到 10⁹ 上做，log V 约 30 层，每层每个事件一次 O(log n) 的树状数组操作。

操作时间复杂度空间复杂度
dfs 求 dfn、rdfn 与倍增表（只做一次）O(n log n)O(n + p + q)：前向星与倍增表 O(n log n)，事件数组按 8 · (n + p + q) 开，树状数组 O(n)，都在 500MB 之内
把一个盘子拆成事件O(log n)（一次 lca 与一次 lcaSon）
事件排序O((p + q) log(p + q))
分治一层（每个事件一次树操作）O((p + q) log n)
整体（共 log V 层，约 30 层）O((p + q) log n log V)

p、q 都是 4 × 10⁴ 时，事件总数不到 4 × 10⁵，乘上 30 层和 log n 大约是 2 × 10⁸ 次基本操作，事件结构体不大，可以通过。

五、最后

这题的关键一步是把「路径包含」翻译成 dfn 平面上的矩形。翻译完之后，判定结构又回到了树状数组，整体二分那一层几乎不用改。下一题反过来：判定结构不是树状数组，而是可撤销并查集。
