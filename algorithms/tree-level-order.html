二叉树的层序遍历：层序、锯齿、宽度与深度

前面三节把树从上到下、从左到右的三种深度优先序都走完了，递归和栈各来一遍。这一节换个方向：从上往下、一层一层扫。层序是队列的活，递归在这里帮不上忙。

零、背景

先序、中序、后序都是深度优先：沿着一条路走到头，再回头。层序是广度优先：先把同一层的节点全部处理完，再往下一层走。

广度优先需要「先来的人先走」。这正好是队列的语义：根先入队，处理完根，把它的两个孩子入队；处理完第一层，队列里恰好是第二层的全部节点。

本站从 013 课起就强调数组队列：vector 存节点，l 是队头下标、r 是队尾下标，出队只做 l++，入队只做 q[r++]=x。层序的四个题都用这个写法。

节点定义沿用前面的课，三个字段，没孩子写 nullptr。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

一、层序遍历（LeetCode 102）

题目要求按层返回：第 0 层一个列表、第 1 层一个列表，以此类推。

最容易想到的写法是普通 BFS 配一张哈希表，给每个节点记一个层号：入队时记 level+1，出队时按层号放进对应的列表。能过，但多一份哈希表的空间，还不如下面这个写法干净。

优化 BFS 的关键是「每次处理一层」：进入外层循环时，队列里恰好是同一层的节点，size = r - l 就是这一层的个数；内层循环只处理 size 个，一边出队收集、一边把它们的非空孩子入队。一轮结束，队列里正好是下一层。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 层序遍历：每次处理一层的优化 BFS
    // 队列里装的是「这一层的全部节点」，size = r - l 就是层大小
    vector<vector<int>> LevelOrder(TreeNode* root) {
        vector<vector<int>> ans;
        if (root == nullptr) {
            return ans;
        }
        vector<TreeNode*> q;
        q.push_back(root);
        for (int l = 0, r = 1; l < r;) {
            int size = r - l;
            vector<int> list;
            for (int i = 0; i < size; i++) {
                TreeNode* cur = q[l++];
                list.push_back(cur->val);
                if (cur->left != nullptr) {
                    q.push_back(cur->left);
                    r++;
                }
                if (cur->right != nullptr) {
                    q.push_back(cur->right);
                    r++;
                }
            }
            ans.push_back(list);
        }
        return ans;
    }

队列里同一时刻只有两层：正在处理的一层加已经入队的一层，所以数组开 n 的大小就够。时间 O(n)、空间 O(n)，每个节点进出队列各一次。

二、锯齿形层序遍历（LeetCode 103）

锯齿形就是奇数层反着收集：第 0 层从左往右、第 1 层从右往左、第 2 层从左往右。一层一换方向。

入队顺序不能变，变的是收集方向。用一个布尔 reverse 记当前层要不要反着读：false 时从 l 往 r-1 扫，true 时从 r-1 往 l 扫，扫够 size 个。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 锯齿形层序遍历：优化 BFS + 一层一换方向
    // reverse == false 时从左往右收集：l 到 r-1，步长 +1
    // reverse == true 时从右往左收集：r-1 到 l，步长 -1
    vector<vector<int>> ZigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> ans;
        if (root == nullptr) {
            return ans;
        }
        vector<TreeNode*> q;
        q.push_back(root);
        bool reverse = false;
        for (int l = 0, r = 1; l < r;) {
            int size = r - l;
            vector<int> list;
            if (!reverse) {
                for (int i = l, j = 0; j < size; i++, j++) {
                    list.push_back(q[i]->val);
                }
            } else {
                for (int i = r - 1, j = 0; j < size; i--, j++) {
                    list.push_back(q[i]->val);
                }
            }
            for (int i = 0; i < size; i++) {
                TreeNode* cur = q[l++];
                if (cur->left != nullptr) {
                    q.push_back(cur->left);
                    r++;
                }
                if (cur->right != nullptr) {
                    q.push_back(cur->right);
                    r++;
                }
            }
            ans.push_back(list);
            reverse = !reverse;
        }
        return ans;
    }

孩子入队永远先左后右。只有「读队列」的方向在变，「写队列」的顺序不变，下一层才能从左往右排好。

三、最大特殊宽度（LeetCode 662）

宽度的定义和「这一层有几个节点」不是一回事。题目把树看成完全二叉树：每一层从最左到最右的空位也算宽度。一条斜树每层只有一个节点，但宽度可以大得离谱。

做法是给每个节点编一个号：根是 1，左孩子 2*id，右孩子 2*id+1。这一层最右节点的编号减最左节点的编号加 1，就是这一层的宽度。

using ULL = unsigned long long;

    struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 二叉树的最大特殊宽度（LeetCode 662）
    // 把节点按完全二叉树编号：根是 1，左孩子 2*id，右孩子 2*id+1
    // 每层宽度 = 该层最大编号 - 最小编号 + 1，不存在的空位也算宽度
    // id 用 unsigned long long：节点多到 64 层时 int 会溢出（左移一位就翻倍）
    int WidthOfBinaryTree(TreeNode* root) {
        int ans = 1;
        vector<TreeNode*> nq;   // 节点队列
        vector<ULL> iq;         // 编号队列，与 nq 一一对应
        nq.push_back(root);
        iq.push_back(1ULL);
        for (int l = 0, r = 1; l < r;) {
            int size = r - l;
            ans = max(ans, (int)(iq[r - 1] - iq[l] + 1));
            for (int i = 0; i < size; i++) {
                TreeNode* node = nq[l];
                ULL id = iq[l++];
                if (node->left != nullptr) {
                    nq.push_back(node->left);
                    iq.push_back(id * 2ULL);
                    r++;
                }
                if (node->right != nullptr) {
                    nq.push_back(node->right);
                    iq.push_back(id * 2ULL + 1ULL);
                    r++;
                }
            }
        }
        return ans;
    }

编号必须用 unsigned long long。3000 层右偏链的最右节点编号是 22999，int 装不下，long long 也装不下。就算编号溢出回绕，同一层里「右减左」的差还是真实宽度：264 之后回绕成小数字，但相对差不变，实测 65 层深处的一对兄弟宽度仍算得 2。

四、最大深度与最小深度（LeetCode 104 / 111）

最大深度一行递归：空树是 0，否则左右子树取大再加 1。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 最大深度（LeetCode 104）：空树深度 0，否则左右取大再加 1
    int MaxDepth(TreeNode* root) {
        return root == nullptr ? 0 : max(MaxDepth(root->left), MaxDepth(root->right)) + 1;
    }

    // 最小深度（LeetCode 111）：
    // 空树 0，叶子 1。中间节点只看有孩子的那一侧。
    // 如果一侧为空，那一侧记 INF，不能记 0，否则根只有右孩子时最小深度会算成 1
    int MinDepth(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }
        if (root->left == nullptr && root->right == nullptr) {
            return 1;
        }
        int ldeep = INT_MAX;
        int rdeep = INT_MAX;
        if (root->left != nullptr) {
            ldeep = MinDepth(root->left);
        }
        if (root->right != nullptr) {
            rdeep = MinDepth(root->right);
        }
        return min(ldeep, rdeep) + 1;
    }

最小深度有个坑：不能照抄最大深度的 min。根只有右孩子、没有左孩子时，左子树深度按 0 算，min(0, 右) 会得出 1，答案是 2。

正确做法是把空子树记成 INT_MAX，只有非空的孩子参与比较：min(INF, 右子树) 得右子树深度再加 1，恰好是 2。叶子直接返回 1，这一句也不能省。

六、总结

层序四题共用一个骨架：数组队列 + 每次处理一层的 size 循环。

层序收集节点值，锯齿在收集时反着扫，宽度在收集时改用编号做差，深度则换成递归。队列怎么滚、size 怎么取，四个题一字不差。

最小深度提醒一句：空子树按 0 参与比较是这页最容易写错的地方，根只有一侧孩子时答案差 1。
