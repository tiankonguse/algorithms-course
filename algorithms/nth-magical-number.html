神奇数字：二分答案与容斥

能被 a 或 b 整除的正整数叫神奇数字。第 n 个神奇数字用二分答案找，个数用容斥数：m/a + m/b − m/lcm。n 到 1e9，答案对 1e9+7 取模。

零、背景

a = 2、b = 4 时，神奇数字是 2, 4, 6, 8, 10, …，第 5 个是 10。a = 4、b = 6 时，数列是 4, 6, 8, 12, 16, 18, 20, 24, …，第 5 个是 16。

n 到 1e9、a、b 到 4e4，答案可以到 4e13，所以最后对 1e9+7 取模。这道题把两个后面有专题的方法各用了一点点：二分答案、容斥原理，都用的很浅，之前没接触过也能懂。

一、直接枚举

最直白的做法：从 1 开始逐个检查 x % a == 0 || x % b == 0，数够 n 个停下。

要检查到第几个数？神奇数字的密度是 1/a + 1/b − 1/lcm(a,b)。a=4、b=6 时密度 1/3，第 n 个约 3n。实测 n=1e7 检查到 3e7，14.24ms。

n=1e9 就要检查 3e9 个数，约 1.4 秒。a、b 都大时更糟：a=b=40000，密度只有 1/40000，第 1e9 个神奇数字是 4e13，暴力枚举直接不可行。

慢在检查的个数跟答案成正比，答案可以到 4e13。

二、容斥：1 到 m 里有几个神奇数字

count(m) = m/a + m/b − m/lcm(a,b)。

1 到 m 里被 a 整除的 m/a 个，被 b 整除的 m/b 个。同时被两个整除的是公倍数，共 m/lcm 个，被加了两次，要减一次。

核对：m=24、a=4、b=6：24/4 + 24/6 − 24/12 = 6 + 4 − 2 = 8。数列 4, 6, 8, 12, 16, 18, 20, 24 正好 8 个。

lcm 就是上一页那个先除后乘的：lcm(a,b) = a/gcd(a,b) * b。

// 1 到 m 里能被 a 或 b 整除的数的个数：容斥
    // 被 a 整除的 + 被 b 整除的 - 被 a 和 b 同时整除的（公倍数）
    long long countLE(long long m, int a, int b) {
        return m / a + m / b - m / lcm(a, b);
    }

三、二分答案

count(m) 随 m 不减，要找的是「count(m) ≥ n 的最小 m」。标准的二分答案。

上界 r = n·min(a,b)：min(a,b) 的每个倍数都是神奇数字，所以第 n 个神奇数字一定 ≤ n·min(a,b)。

二分：l=0、r=n·min(a,b)，m=(l+r)/2。count(m) ≥ n 就记下答案、收紧右端，否则放大左端。

迭代次数就是区间长取 log2：n=1e9、a=2、b=4，r=2e9，31 次；a=b=40000，r=4e13，46 次。每次判定 O(1)。

这里有个细节：count(m) 里 m/a、m/b、m/lcm 都在 long long 范围（m ≤ 4e13），最后 ans % (1e9+7) 才转回 int。

// 第 n 个神奇数字，答案对 1e9 + 7 取模
    // 二分答案：神奇数字够 n 个的最小 m
    int nthMagicalNumber(int n, int a, int b) {
        long long l = 0, r = (long long)n * min(a, b), ans = 0;
        while (l <= r) {
            long long m = (l + r) / 2;
            if (countLE(m, a, b) >= n) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return (int)(ans % 1000000007);
    }

四、暴力与二分的差距

暴力检查的个数跟答案同数量级，答案可以到 4e13；二分把「检查 m 个」换成「判定 count(m) 约 40 次」，每次判定 O(1)。

复杂度分析

做法时间空间说明
直接枚举O(第 n 个神奇数字)O(1)答案 ≈ n/密度，最坏 4e13
二分答案 + 容斥O(log(n·min(a,b))) 次判定，每次 O(1)O(1)n=1e9 时 31 到 46 次判定

总结

神奇数字密度 1/a + 1/b − 1/lcm；count(m) = m/a + m/b − m/lcm，三除一减。

二分找「count(m) ≥ n 的最小 m」，上界 r = n·min(a,b)，答案对 1e9+7 取模。
