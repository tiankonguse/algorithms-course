块状数组：有序副本与整块标记

序列分块那一节里，块内存的是区间和，整块查询是一次加法。这一节开始分块专题，先看块状数组：给每个块配一份块内有序的副本，再给整块配一个加法标记，就能回答「区间里大于等于 v 的数有几个」，这恰好是线段树最不擅长、分块最顺手的一类查询。

零、背景

分块专题一共四讲：专题 1 是块状数组、块状链表，就是本节；专题 2 是分块的几道好题和树上分块；专题 3 是双层分块、分块结合并查集；专题 4 是根号分治。专题结束后会进入莫队。

分块的原理可以压缩成四句话。数据规模为 n 时，让划分出来的块内大小和块的数量几乎相同，都是 √n 规模；块内的信息暴力维护，整块的信息修改标签即可；处理区间修改或区间查询时，最多处理左散块、右散块、中间若干整块；块内遍历 O(√n)，块间遍历也是 O(√n)。

适用场景也明确。区间信息不可合并时，线段树这类结构难维护，分块往往容易，因为块内信息本来就是暴力维护的；数据量允许的情况下，分块优于暴力，又比高级结构好实现、好分析；分块维护信息容易，会衍生出很多变体，专题后面的课大量涉及。

也要说清分块的地位：正式比赛中很少出现以分块作为最优解的题目，它的优势是好想、好写、常数小。一道思维难度大的题，如果分块的做法已经很难，更优结构的做法只会更难。所以分块非必需，但收益高。

一、题目一：Give Away

给定长度为 n 的数组，m 条操作。操作 0 a b c 打印 arr[a..b] 上大于等于 c 的数字个数；操作 1 a b 把 arr[a] 改成 b。n ≤ 5×10⁵，m ≤ 10⁵，值在 1 到 10⁹。测试链接：洛谷 SP18185、SPOJ GIVEAWAY。

暴力查询一次 O(n)，总量 5×10¹⁰，超时。线段树也不好办：一个节点要回答「这段里 ≥ c 的有几个」，c 是查询临时给的，节点必须存下值的分布才答得出来，等于要写归并树或者树套树，门槛一下子上去了。

分块的解法是给每个块配一份有序副本 sortv。建块时把每块的元素拷进 sortv 排好序，块的答案就能二分：整块里 ≥ v 的个数，等于 sortv 中第一个 ≥ v 的位置到块尾的长度。散块部分没有副本可查，直接对 arr 暴力数。

单点修改也简单：改掉 arr[i] 之后，把这一块的 sortv 从 arr 重新拷一遍再排序。一块只有 √n 个数，代价 O(√n log√n)。

把流程过一遍。build 算出块长 blen = √n、块数 bnum，每个下标属于哪块记在 bi[i]，每块左右端点记在 bl、br。查询 query(l, r, v)：l、r 同块就整体暴力；否则左散块扫 [l, br[bi[l]]]，右散块扫 [bl[bi[r]], r]，中间每个整块调 getCnt 在 sortv 上二分。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXB = 1001;
    int n, m;
    int arr[MAXN];
    int sortv[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];

    void build() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
        }
        for (int i = 1; i <= n; i++) {
            sortv[i] = arr[i];
        }
        for (int i = 1; i <= bnum; i++) {
            sort(sortv + bl[i], sortv + br[i] + 1);
        }
    }

    int getCnt(int i, int v) {
        int l = bl[i], r = br[i], m, ans = 0;
        while (l <= r) {
            m = (l + r) >> 1;
            if (sortv[m] >= v) {
                ans += r - m + 1;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

    int query(int l, int r, int v) {
        int ans = 0;
        if (bi[l] == bi[r]) {
            for (int i = l; i <= r; i++) {
                if (arr[i] >= v) {
                    ans++;
                }
            }
        } else {
            for (int i = l; i <= br[bi[l]]; i++) {
                if (arr[i] >= v) {
                    ans++;
                }
            }
            for (int i = bl[bi[r]]; i <= r; i++) {
                if (arr[i] >= v) {
                    ans++;
                }
            }
            for (int i = bi[l] + 1; i <= bi[r] - 1; i++) {
                ans += getCnt(i, v);
            }
        }
        return ans;
    }

    void update(int i, int v) {
        int l = bl[bi[i]];
        int r = br[bi[i]];
        arr[i] = v;
        for (int j = l; j <= r; j++) {
            sortv[j] = arr[j];
        }
        sort(sortv + l, sortv + r + 1);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        build();
        cin >> m;
        int op, a, b, c;
        for (int i = 1; i <= m; i++) {
            cin >> op >> a >> b;
            if (op == 0) {
                cin >> c;
                cout << query(a, b, c) << '\n';
            } else {
                update(a, b);
            }
        }
        return 0;
    }

二、题目二：教主的魔法

给定长度为 n 的数组，m 条操作。操作 A l r v 打印 arr[l..r] 上大于等于 v 的数字个数；操作 M l r v 把 arr[l..r] 每个值都加 v。n ≤ 10⁶，m ≤ 3000，值在 1 到 10⁹。测试链接：洛谷 P2801。

与题目一的差别是多了一种修改：区间加。对整块来说，区间加是一个可以概括的量，挂标签就够了，每块加一个 lazy[b]，整块加 v 就是 lazy[b] += v，一个数都不用动。

这里有个细节：散块里的 arr[i] 存的是没加过 lazy 的存储值，真实值等于存储值加 lazy。所以散块加 v 时，先把 v 加到每个 arr[i] 上，再把这一块的 sortv 重构；整块查询二分前，先把 v 减掉 lazy[b] 再去和存储值比，两边是同一件事的两种写法。

修改 add(l, r, v) 与查询完全对称：l、r 同块就 innerAdd 暴力加；否则左右散块各做一次 innerAdd（加完顺带重排该块副本），中间整块 lazy[b] += v。m 只有 3000，就算每次都触发两块散块重构，总量也很小，靠的就是分块常数小。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1000001;
    const int MAXB = 1001;
    int n, m;
    int arr[MAXN];
    int sortv[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];

    int lazy[MAXB];

    void build() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
        }
        for (int i = 1; i <= n; i++) {
            sortv[i] = arr[i];
        }
        for (int i = 1; i <= bnum; i++) {
            sort(sortv + bl[i], sortv + br[i] + 1);
        }
    }

    int getCnt(int i, int v) {
        v -= lazy[i];
        int l = bl[i], r = br[i], m, ans = 0;
        while (l <= r) {
            m = (l + r) >> 1;
            if (sortv[m] >= v) {
                ans += r - m + 1;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

    int innerQuery(int l, int r, int v) {
        v -= lazy[bi[l]];
        int ans = 0;
        for (int i = l; i <= r; i++) {
            if (arr[i] >= v) {
                ans++;
            }
        }
        return ans;
    }

    int query(int l, int r, int v) {
        int ans = 0;
        if (bi[l] == bi[r]) {
            ans = innerQuery(l, r, v);
        } else {
            ans += innerQuery(l, br[bi[l]], v);
            ans += innerQuery(bl[bi[r]], r, v);
            for (int i = bi[l] + 1; i <= bi[r] - 1; i++) {
                ans += getCnt(i, v);
            }
        }
        return ans;
    }

    void innerAdd(int l, int r, int v) {
        for (int i = l; i <= r; i++) {
            arr[i] += v;
        }
        for (int i = bl[bi[l]]; i <= br[bi[l]]; i++) {
            sortv[i] = arr[i];
        }
        sort(sortv + bl[bi[l]], sortv + br[bi[l]] + 1);
    }

    void add(int l, int r, int v) {
        if (bi[l] == bi[r]) {
            innerAdd(l, r, v);
        } else {
            innerAdd(l, br[bi[l]], v);
            innerAdd(bl[bi[r]], r, v);
            for (int b = bi[l] + 1; b <= bi[r] - 1; b++) {
                lazy[b] += v;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        build();
        char op;
        int l, r, v;
        for (int i = 1; i <= m; i++) {
            cin >> op >> l >> r >> v;
            if (op == 'A') {
                cout << query(l, r, v) << '\n';
            } else {
                add(l, r, v);
            }
        }
        return 0;
    }

四、复杂度分析

设块长 B = √n，块数约 n/B。查询拆成三段：两端散块各扫 O(B)，中间最多 n/B 个整块，每块一次二分 O(log B)，合并起来 O(√n·log√n)。这也是两道题的总量：m 次操作就是 O(m·√n·log√n)。

操作时间复杂度空间复杂度
建块（拷贝并排序每块副本）O(n·log√n)O(n)：arr 与 sortv 各一份，lazy 每块一个，共 O(n + √n)
区间查询（散块暴力 + 整块二分）O(√n·log√n)
单点修改（题目一，重排所在块）O(√n·log√n)
区间加（题目二：散块重构 / 整块挂标记）O(√n·log√n) / O(1)
全部操作O(m·√n·log√n)

题目一 n = 5×10⁵、m = 10⁵，这个界相当极限，但分块常数小，可以通过。题目二 n 达到 10⁶、m 只有 3000，更是宽裕。

五、最后

块内有序副本是块状数组最常用的一招：它让「按值统计」这类查询在整块上有了二分的能力，而代价只是每个数多存一份。整块挂加法标记则是序列分块里 lazy 思想的直接延续，两招可以叠加。

不过有序副本能帮上忙的前提是「有序性对查询有用」。下一节的查询换成区间众数，它连两块的答案都合并不出来，有序副本彻底失效，得换成「块与块之间的预处理表」。
