双指针：快慢与同向

「双指针」是一类代码形状：两个变量各管各的位置，同时遍历一个序列。真正值钱的是每个形状背后「凭什么两个指针可以这样走」。快慢靠环结构，同向靠单调性。

零、背景

「双指针」这个说法很宽泛，课件按形状分了四类：同向双指针、快慢双指针、从两头往中间的双指针、其他。分类只是壳，拿来当公式背，题目换个壳就认不出来。

有的双指针纯粹是代码过程恰好用了两个指针，没有别的；有的双指针背后有单调性（贪心）的考虑，牵扯可能性的取舍，分析难度高一个档次。先有思考和优化，代码才变成双指针的形式。所以这一页重点放在「为什么能这样走」。

一、四种形态

同向双指针：两个指针一起往右走，一前一后，快的探路，慢的维护答案。快慢双指针：一个走一步，一个走两步，靠速度差找环。两头往中间：l 在头 r 在尾，往中间收，每一步排除一段不可能。其他：形状不规则的，比如用尾部当仓库、用 l/r 切区域。

这一页讲快慢与同向，下一页讲两头往中间，再下一页讲两种「其他」。

二、快慢双指针：寻找重复数（LeetCode 287）

n+1 个数，值都在 [1, n]，只有一个数重复，要求不修改数组、只用 O(1) 空间。

常见做法全被堵死：排序要改数组，计数数组要 O(n) 空间。注意值域 [1, n] 和位置数 n+1 的错位：位置比值的种类多一个，重复不可避免。

把数组当链表看：i 的 next 是 nums[i]。0 出发必进环，重复的数就是环的入口。快慢指针在这条虚拟链表上跑，就是 Floyd 判圈。

slow 每次走一步，fast 每次走两步。相遇后把 fast 拨回 0，两个都改成一步，再次相遇的位置就是环入口。

为什么第二次会相遇在入口：设环外长度 a，相遇时 slow 在环内走了 b，环长 c。slow 走了 a+b，fast 走了 a+b+kc，而 fast 的路程是 slow 的两倍，2(a+b) = a+b+kc，得 a+b = kc。第二阶段从起点走 a 步到入口；从相遇点继续走，因为 a = kc − b，走 a 步也正好回到入口。两个指针在入口碰头。

slow 和 fast 的初值都是下标，不是值：slow = nums[0]，fast = nums[nums[0]]，走的过程才取 nums[] 当跳板。写错初值最常见的表现是死循环或者碰头位置不对。

int findDuplicate(vector<int>& nums) {
        if (nums.size() < 2) {
            return -1;
        }
        int slow = nums[0];
        int fast = nums[nums[0]];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[nums[fast]];
        }
        fast = 0;
        while (slow != fast) {
            fast = nums[fast];
            slow = nums[slow];
        }
        return slow;
    }

实测：n=1e6、值 1..n 各一次加一个随机重复的长环数据，11.69ms。

三、同向双指针：供暖器（LeetCode 475）

房子在一条线上，供暖器也在同一条线上，所有供暖器半径一样，求覆盖全部房子的最小半径。半径最小，等价于每座房子到「离它最近的供暖器」的距离取最大。

朴素：每座房子对每个供暖器算距离，O(n×m)。排序后可以省：房子从左到右，供暖器也排序，离第 i 座房子最近的供暖器下标 j 只增不减。这就是同向双指针的单调性来源。

best(i, j) 判定当前 j 是不是最优：跟 j+1 比距离，当前更近就不动，否则 j++。跳到最后一个供暖器时已经是最优，不再前进。

bool best(vector<int>& houses, vector<int>& heaters, int i, int j) {
        return j == (int)heaters.size() - 1
            || abs(heaters[j] - houses[i]) < abs(heaters[j + 1] - houses[i]);
    }

    int findRadius(vector<int>& houses, vector<int>& heaters) {
        sort(houses.begin(), houses.end());
        sort(heaters.begin(), heaters.end());
        int ans = 0;
        for (int i = 0, j = 0; i < (int)houses.size(); i++) {
            while (!best(houses, heaters, i, j)) {
                j++;
            }
            ans = max(ans, abs(heaters[j] - houses[i]));
        }
        return ans;
    }

注意 best 里比较用的是绝对值。房子可以排在供暖器左边也可以排在右边，谁近谁负责，跟坐标正负无关。

实测：n=m=1e6，含两次排序共 91.81ms。

四、复杂度分析

题目时间复杂度额外空间
寻找重复数O(n)O(1)，不修改数组
供暖器O(n log n + m log m)，排序后扫描 O(n+m)O(1)

寻找重复数全程只扫数组，fast 走过的总步数 O(n)。供暖器两段排序占大头，排序后 j 不回退，扫描 O(n+m)。

总结

快慢指针借「数组当链表」的壳，把找重复数变成找环入口，慢快交替跑两遍；同向指针靠「最优位置单调」让 j 只进不退。两个套路都在回答同一件事：这个指针凭什么不回退。一个靠环结构，一个靠排序后的单调性。
