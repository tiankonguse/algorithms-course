线段树合并进阶：用合并加速树形 dp 的转移

上一讲讲的是线段树合并本身：两棵动态开点线段树怎么并成一棵，以及合并做统计的那类经典题。这一页换一个用法，把合并当成树形 dp 的「转移工具」，儿子算完的分布直接并到父亲身上，一次合并就把一整层的转移做完。

零、背景

树形 dp 的瓶颈通常在一个地方：父亲的状态要由所有儿子的状态「逐点合成」，状态下标一多就变成 O(n²)。

如果状态下标是权值、深度这类可以离散化的东西，就可以给每个点开一棵动态开点线段树，用下标当状态、用节点值当方案数。儿子合并到父亲时，线段树合并一次走过的节点数只跟「两棵树重叠的部分」有关，总代价是 O(n log n)。

这一页三个题都用这个思路，难点各不相同：题目1 合并时要顺带传递后缀最大值，题目2 要同时传递前缀信息和后缀信息，题目3 则是把「限制」翻译成一种向下传递的欠债。

一、题目1：领导集团问题

n 个点的树，1 号点是根，给每个点的点权。选一批点，要求任意两个被选的点 u、v，若 u 是 v 的祖先，则必须有点权 u ≤ v。打印最多能选几个点。n 到 2·10⁵，点权到 10⁹。测试链接 P4577。

先写最直接的 dp：设 f[u][w] 为 u 的子树里选点、且所有被选点权都 ≥ w 时最多能选几个。不选 u 就是各儿子的 f[v][w] 直接相加；选 u 的话，u 的权是 arr[u]，其它被选点必须都 ≥ arr[u]，于是贡献是 1 + Σ f[v][arr[u]]，只在 w ≤ arr[u] 时合法。

这个 dp 有 n 个点、n 种权值，逐位转移是 O(n²)，n 到 2·10⁵ 过不去。慢在「每个点都要把所有儿子的整条数组扫一遍」。

值域到 10⁹，先把点权离散化，式子不变。剩下的问题是把「每个儿子一份数组、父亲要逐位相加」这件事做快，这正是线段树合并的活。

给每个点开一棵动态开点线段树，下标是离散化后的权值。合并两棵树时，同一位置的值相加；遇到某棵树的子树为空，就把另一棵整棵接过来。这样每个点的所有儿子并完，复杂度只跟重叠节点数有关。

具体来说，处理点 u 时先在每个儿子 v 上查一次 query(arr[u], cntv)，把「子树 v 里所有权 ≥ arr[u] 的最多能选几个」拿回来，累加成 sum；所有儿子合并完之后，在 arr[u] 这一位打上 sum + 1，这就是「选 u」的方案。最后答案是根节点的整棵树上取最大值。

六点的树：一步步把儿子的树并到父亲身上

权值是 1:5、2:3、3:9、4:3、5:6、6:9，离散化后是 [3, 5, 6, 9]。点「下一步」按后序遍历处理每个点，右边是这个点最终的数组。数字取自课程代码的实际运行结果。

这里有个细节：数组里存的是「紧凑写法」，「选 u」这一档的 sum + 1 只写在 arr[u] 那一位，而不是铺满所有权 ≤ arr[u] 的位置。查询一律取后缀最大值，所以只要 arr[u] ≥ 查询的下界，这份贡献就一定被算进去；反过来，如果查询的下界比 arr[u] 还大，那本来就不该选 u，这一位也自然不会落进后缀里。

还有个细节更隐蔽：合并时，被并进来的那棵树贡献的是它的后缀最大值，而最初的那一棵贡献的是它自己存的值。两者一般相等，但当某一棵树的「选自己」那一档记在更靠右的位置、并且两棵树在同一位上都有节点时，会少算 1。实测 3000 组随机小样例（n 取 4 到 7、点权取 1 到 3）里只出现 1 次，例如 n=6、点权 [3,1,1,2,2,1]、父亲 [1,2,1,4,5] 这组，真实答案是 4（选 {2,3,4,5}），代码输出 3。写题时按课程代码提交是能过的，知道这个边界就好。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXT = MAXN * 20;
    int n;
    int arr[MAXN];
    int sorted[MAXN];
    int cntv;

    int head[MAXN];
    int nxt[MAXN];
    int to[MAXN];
    int cntg;

    int root[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int maxv[MAXT];
    int addLazy[MAXT];
    int cntt;

    int kth(int num) {
        int left = 1, right = cntv, ret = 0;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] <= num) {
                ret = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ret;
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void up(int i) {
        maxv[i] = max(maxv[ls[i]], maxv[rs[i]]);
    }

    void lazy(int i, int v) {
        if (i != 0) {
            maxv[i] += v;
            addLazy[i] += v;
        }
    }

    void down(int i) {
        if (addLazy[i] > 0) {
            lazy(ls[i], addLazy[i]);
            lazy(rs[i], addLazy[i]);
            addLazy[i] = 0;
        }
    }

    int update(int jobi, int jobv, int l, int r, int i) {
        int rt = i;
        if (rt == 0) {
            rt = ++cntt;
        }
        if (l == r) {
            maxv[rt] = max(maxv[rt], jobv);
        } else {
            down(rt);
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[rt] = update(jobi, jobv, l, mid, ls[rt]);
            } else {
                rs[rt] = update(jobi, jobv, mid + 1, r, rs[rt]);
            }
            up(rt);
        }
        return rt;
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return maxv[i];
        }
        down(i);
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans = max(ans, query(jobl, jobr, l, mid, ls[i]));
        }
        if (jobr > mid) {
            ans = max(ans, query(jobl, jobr, mid + 1, r, rs[i]));
        }
        return ans;
    }

    int merge(int l, int r, int t1, int t2, int max1, int max2) {
        if (t1 == 0 || t2 == 0) {
            if (t1 != 0) {
                lazy(t1, max2);
            }
            if (t2 != 0) {
                lazy(t2, max1);
            }
            return t1 + t2;
        }
        if (l == r) {
            maxv[t1] += max(maxv[t2], max2);
        } else {
            down(t1);
            down(t2);
            int mid = (l + r) >> 1;
            ls[t1] = merge(l, mid, ls[t1], ls[t2], max(max1, maxv[rs[t1]]), max(max2, maxv[rs[t2]]));
            rs[t1] = merge(mid + 1, r, rs[t1], rs[t2], max1, max2);
            up(t1);
        }
        return t1;
    }

    void dp(int u) {
        int sum = 0;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            dp(v);
            sum += query(arr[u], cntv, 1, cntv, root[v]);
            root[u] = merge(1, cntv, root[u], root[v], 0, 0);
        }
        root[u] = update(arr[u], sum + 1, 1, cntv, root[u]);
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            sorted[++cntv] = arr[i];
        }
        sort(sorted + 1, sorted + cntv + 1);
        int len = 1;
        for (int i = 2; i <= cntv; i++) {
            if (sorted[len] != sorted[i]) {
                sorted[++len] = sorted[i];
            }
        }
        cntv = len;
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 2, fa; i <= n; i++) {
            cin >> fa;
            addEdge(fa, i);
        }
        prepare();
        dp(1);
        cout << query(1, cntv, 1, cntv, root[1]) << '\n';
        return 0;
    }

二、题目2：根节点的取值

n 个点的树，1 号是根。叶子 x 的 arr[x] 是点权，所有叶子的点权互不相同；非叶最多两个孩子，此时 arr[x] 是概率：以 arr[x] 的概率取两个儿子点权的最大值，以 1 − arr[x] 的概率取最小值。概率用 [1, 9999] 表示 0.0001 ~ 0.9999。

设 1 号点的权值有 m 种可能，第 i 小的权值是 Vᵢ、取得概率是 Dᵢ，求 Σ i · Vᵢ · Dᵢ² 对 998244353 取模。n 到 3·10⁵，测试链接 P5298。

概率是分数，取模意义下用逆元转成整数：arr[x] 除以 10000 就是真实概率，乘 10000 的逆元即可，全程只做整数乘法。

每个点同样开一棵按下标（叶子的离散化权值）排开的动态开点线段树，存的是分布 D。合并两个孩子 a、b 时，新的分布是：

P(u = v) = P(a = v) · [ p · P(b < v) + (1 − p) · P(b > v) ] + P(b = v) · [ p · P(a < v) + (1 − p) · P(a > v) ]。

方括号里那两项，前一项是「b 落在 v 左边、靠取 max 拼出 v」，后一项是「b 落在 v 右边、靠取 min 拼出 v」。也就是说：进入左子树要带上右边那半的概率和乘 (1 − p)，进入右子树要带上左边那半的概率和乘 p。这就是合并时要同时传前缀信息和后缀信息的原因。

拖动两个概率，看根节点的分布和答案怎么变

五个点的树：1 号以 p₁ 取两个孩子的最大/最小，2 号以 p₂ 取 4 号和 5 号的最大/最小，3 号是权值为 9 的叶子，4 号是 3，5 号是 7。分布用小数显示，答案同时给出小数和对 998244353 取模的值。

0.5000
0.5000

最后一遍 dfs 把根那棵树的每个叶子取出来，得到 Dᵢ，再按 i 从 1 开始累加 i · Vᵢ · Dᵢ² 就是答案。注意 i 是「第几小」，下标从 1 开始，而线段树的下标从 1 开始正好对上。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    const int MAXT = MAXN * 40;
    const int MOD = 998244353;
    int n;

    int fa[MAXN];
    int arr[MAXN];
    int sorted[MAXN];
    int cntv;

    int sonCnt[MAXN];
    int son[MAXN][2];

    int root[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    long long sum[MAXT];
    long long mulLazy[MAXT];
    int cntt;

    long long D[MAXN];

    long long power(long long x, int p) {
        long long ans = 1;
        while (p) {
            if (p & 1) {
                ans = ans * x % MOD;
            }
            x = x * x % MOD;
            p >>= 1;
        }
        return ans;
    }

    int kth(int num) {
        int left = 1, right = cntv, ret = 0;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (sorted[mid] <= num) {
                ret = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ret;
    }

    void up(int i) {
        sum[i] = (sum[ls[i]] + sum[rs[i]]) % MOD;
    }

    void lazy(int i, long long v) {
        if (i) {
            sum[i] = sum[i] * v % MOD;
            mulLazy[i] = mulLazy[i] * v % MOD;
        }
    }

    void down(int i) {
        if (mulLazy[i] != 1) {
            lazy(ls[i], mulLazy[i]);
            lazy(rs[i], mulLazy[i]);
            mulLazy[i] = 1;
        }
    }

    int insert(int jobi, int l, int r, int i) {
        int rt = i;
        if (rt == 0) {
            rt = ++cntt;
            mulLazy[rt] = 1;
        }
        if (l == r) {
            sum[rt] = 1;
        } else {
            down(rt);
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
            up(rt);
        }
        return rt;
    }

    int merge(int l, int r, int t1, int t2, int p, long long sum1, long long sum2) {
        if (t1 == 0 || t2 == 0) {
            if (t1) {
                lazy(t1, sum2);
            }
            if (t2) {
                lazy(t2, sum1);
            }
            return t1 + t2;
        }
        if (l == r) {
            sum[t1] = (sum[t1] * sum2 % MOD + sum[t2] * sum1 % MOD) % MOD;
        } else {
            down(t1);
            down(t2);
            int mid = (l + r) >> 1;
            long long lsum1 = (sum1 + sum[rs[t1]] * (1 - p + MOD)) % MOD;
            long long lsum2 = (sum2 + sum[rs[t2]] * (1 - p + MOD)) % MOD;
            long long rsum1 = (sum1 + sum[ls[t1]] * p) % MOD;
            long long rsum2 = (sum2 + sum[ls[t2]] * p) % MOD;
            ls[t1] = merge(l, mid, ls[t1], ls[t2], p, lsum1, lsum2);
            rs[t1] = merge(mid + 1, r, rs[t1], rs[t2], p, rsum1, rsum2);
            up(t1);
        }
        return t1;
    }

    void dp(int u) {
        if (sonCnt[u] == 0) {
            root[u] = insert(arr[u], 1, cntv, root[u]);
        } else if (sonCnt[u] == 1) {
            dp(son[u][0]);
            root[u] = root[son[u][0]];
        } else {
            dp(son[u][0]);
            dp(son[u][1]);
            root[u] = merge(1, cntv, root[son[u][0]], root[son[u][1]], arr[u], 0, 0);
        }
    }

    void getd(int l, int r, int i) {
        if (i == 0) {
            return;
        }
        if (l == r) {
            D[l] = sum[i] % MOD;
        } else {
            down(i);
            int mid = (l + r) >> 1;
            getd(l, mid, ls[i]);
            getd(mid + 1, r, rs[i]);
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            if (fa[i] != 0) {
                son[fa[i]][sonCnt[fa[i]]++] = i;
            }
        }
        long long inv = power(10000, MOD - 2);
        for (int i = 1; i <= n; i++) {
            if (sonCnt[i] == 0) {
                sorted[++cntv] = arr[i];
            } else {
                arr[i] = (int)(inv * arr[i] % MOD);
            }
        }
        sort(sorted + 1, sorted + cntv + 1);
        int len = 1;
        for (int i = 2; i <= cntv; i++) {
            if (sorted[len] != sorted[i]) {
                sorted[++len] = sorted[i];
            }
        }
        cntv = len;
        for (int i = 1; i <= n; i++) {
            if (sonCnt[i] == 0) {
                arr[i] = kth(arr[i]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> fa[i];
        }
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        prepare();
        dp(1);
        getd(1, cntv, root[1]);
        long long ans = 0;
        for (int i = 1; i <= cntv; i++) {
            ans = (ans + (1LL * i * sorted[i]) % MOD * D[i] % MOD * D[i] % MOD) % MOD;
        }
        cout << ans << '\n';
        return 0;
    }

三、题目3：命运

n 个点的树，1 号是根，给 m 个点对 (x, y)，x 是 y 的祖先。树上每条边染成黑或白，要求每个点对的路径（x 到 y 那一段）上至少有一条黑边。打印染色方案数对 998244353 取模。n、m 到 5·10⁵，测试链接 P6773。

先化简限制。对固定的 y，若有两个点对 (x₁, y)、(x₂, y) 且 dep[x₁] < dep[x₂]，那么 x₂ 到 y 的路径是 x₁ 到 y 的路径的一部分，只要深的那条满足了，浅的自然满足。所以每个 y 只需要记最深的那一个 x，记 maxdep[y] = 所有以 y 结尾的点对里 dep[x] 的最大值。

再把限制翻译成「欠债」：设 black[y] 是根到 y 的路径上最靠下的那条黑边的下端深度。点对 (x, y) 要求路径上有黑边，等价于 black[y] > dep[x]。于是每个 y 头顶挂一笔欠债，「深度大于 maxdep[y] 的位置上还得有一条黑边」。

自底向上做 dp。每个点 u 一棵动态开点线段树，下标 a 存：u 子树里的边染完、且子树内能解决的限制都解决了，只剩一笔「深度 > a 的地方还得有黑边」的欠债，这时的方案数。初始 insert(maxdep[u]) 就是「一条边都还没染，欠债恰好是自己那条限制」。

合并孩子 v 时分两种：(u, v) 染黑，黑边的下端深度是 dep[v] = dep[u] + 1，比任何合法的 a 都大，所以 v 那笔欠债一笔勾销，方案数乘上 v 的总方案数 Total_v；(u, v) 染白，欠债往上传，u 原有的 a 和 v 的 aᵥ 取更严的那个，也就是下标取 max(a, aᵥ)。

写成式子就是 Sᵤ[a] · (Total_v + P_v(≤ a)) + Sᵥ[a] · Pᵤ(< a)：第一项里 Total_v 是染黑、P_v(≤ a) 是染白且不加重欠债；第二项是染白且由 v 那一笔把下标顶到 a。Total_v 用 query(0, dep[u]) 求，因为 a = dep[u] 表示「非把 (u, v) 染黑不可」，再大的欠债已经不可能满足了，不算在染黑的方案里。

六个点、三笔限制：欠债怎么自底向上合并

树是 1→2、1→3、2→4、2→5、3→6，点对是 (1,4)、(2,5)、(1,6)。点「下一步」按后序处理每个点，右边是它的欠债数组（下标 0 到 4，更深的位置恒为 0）。数字取自课程代码的实际运行结果。

答案是根节点的 0 号位：根头顶没有边，欠债必须已经清空。演示里那个例子手算也对得上，(2,5) 逼着 2 到 5 那条边必须是黑的，剩下 (1,2) 或 (2,4) 至少一条黑、(1,3) 或 (3,6) 至少一条黑，16 − 4 − 4 + 1 = 9 种。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXT = MAXN * 40;
    const int MOD = 998244353;
    int n, m;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int root[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    long long sum[MAXT];
    long long mulLazy[MAXT];
    int cntt;

    int dep[MAXN];
    int maxdep[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void up(int i) {
        sum[i] = (sum[ls[i]] + sum[rs[i]]) % MOD;
    }

    void lazy(int i, long long v) {
        if (i != 0) {
            sum[i] = sum[i] * v % MOD;
            mulLazy[i] = mulLazy[i] * v % MOD;
        }
    }

    void down(int i) {
        if (mulLazy[i] != 1) {
            lazy(ls[i], mulLazy[i]);
            lazy(rs[i], mulLazy[i]);
            mulLazy[i] = 1;
        }
    }

    int insert(int jobi, int l, int r, int i) {
        int rt = i;
        if (rt == 0) {
            rt = ++cntt;
            mulLazy[rt] = 1;
        }
        if (l == r) {
            sum[rt] = 1;
        } else {
            down(rt);
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
            up(rt);
        }
        return rt;
    }

    long long query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return sum[i] % MOD;
        }
        down(i);
        int mid = (l + r) >> 1;
        long long ans = 0;
        if (jobl <= mid) {
            ans = query(jobl, jobr, l, mid, ls[i]) % MOD;
        }
        if (jobr > mid) {
            ans = (ans + query(jobl, jobr, mid + 1, r, rs[i])) % MOD;
        }
        return ans;
    }

    int Merge(int l, int r, int t1, int t2, long long sum1, long long sum2) {
        if (t1 == 0 || t2 == 0) {
            if (t1 != 0) {
                lazy(t1, sum2);
            }
            if (t2 != 0) {
                lazy(t2, sum1);
            }
            return t1 + t2;
        }
        if (l == r) {
            sum[t1] = ((sum[t1] * (sum2 + sum[t2])) % MOD + (sum[t2] * sum1) % MOD) % MOD;
        } else {
            down(t1);
            down(t2);
            int mid = (l + r) >> 1;
            long long tmp1 = sum[ls[t1]];
            long long tmp2 = sum[ls[t2]];
            ls[t1] = Merge(l, mid, ls[t1], ls[t2], sum1, sum2);
            rs[t1] = Merge(mid + 1, r, rs[t1], rs[t2], sum1 + tmp1, sum2 + tmp2);
            up(t1);
        }
        return t1;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    void dp(int u, int fa) {
        root[u] = insert(maxdep[u], 0, n, root[u]);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dp(v, u);
                root[u] = Merge(0, n, root[u], root[v], 0, query(0, dep[u], 0, n, root[v]));
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        dfs(1, 0);
        cin >> m;
        for (int i = 1, x, y; i <= m; i++) {
            cin >> x >> y;
            if (dep[x] > maxdep[y]) {
                maxdep[y] = dep[x];
            }
        }
        dp(1, 0);
        long long ans = query(0, 0, 0, n, root[1]) % MOD;
        cout << ans << '\n';
        return 0;
    }

四、复杂度分析

三个题的骨架一样：离散化 O(n log n)，每个点一次插入 O(log n)，每次线段树合并的代价是两棵树重叠的节点数，一条边合并一次，总代价 O(n log n)。

操作时间复杂度空间复杂度
题目1：离散化 + 建树O(n log n)O(n)
题目1：每个点的插入 / 查询 / 合并O(log n) / O(log n) / 均摊 O(1)节点数 O(n log n)，MAXT 开 20n
题目2：概率转整数（一次快速幂）O(log MOD)—
题目2：合并 + 最后一遍取分布O(n log n) / O(n)节点数 O(n log n)，MAXT 开 40n
题目3：求深度 + 读点对O(n + m)O(n)
题目3：合并（含前缀和查询）O(n log n)节点数 O(n log n)，MAXT 开 40n

「均摊 O(1)」说的是合并的总代价：任意一次合并可能走很多节点，但每合并掉一个节点就少一个节点，所有合并加起来是 O(节点数) = O(n log n)，摊到 O(n) 次合并上就是常数级。

题目2 和题目3 的线段树要带乘法懒标记（题目1 是加法懒标记），因为合并时「整棵子树乘上一个数」是常态，不下传就会退化。

五、最后

这一页三个题，形式上都是「儿子的数组并到父亲」，差别全在合并时要顺带传什么：题目1 传后缀最大值，题目2 传前缀和与后缀和，题目3 传的是方案数之间的卷积。想清楚「合并时这一位需要知道对面哪些位的信息」，式子就出来了。
