球形空间的中心点：几何问题变成线性方程组

n 维空间里给 n+1 个点，它们在同一个球面上，球心怎么求？第一步不是解方程，而是把「到球心距离相等」翻译成 n 个线性方程。翻译完，上一节的模板直接接管。

零、把「距离相等」写成方程

设球心是 C，半径是 R。第 i 个点 Pi 在球面上，意思是

|Pi - C|2 = R2

对全部 n+1 个点都成立。未知数是 C 的 n 个坐标，加上 R，一共 n+1 个未知数，n+1 个方程。直接解它要面对 R2 这种非线性项，麻烦。

相邻两个方程相减，R2 正好消掉：

|Pi - C|2 - |Pi+1 - C|2 = 0

把平方展开、合并同类项，得到

2·(Pi - Pi+1)·C = |Pi|2 - |Pi+1|2

左边是 C 的 n 个坐标的线性组合，右边是已知常数。n+1 个点相邻作差，得到 n 个线性方程，n 个未知数，这就是标准的加法方程组。几何问题到此结束，剩下的是代数。

一、构造与求解

构造方程照上面公式一行行写：第 i 行的系数是 2·(Pi - Pi+1) 的每个坐标，常数累加 Pi 和 Pi+1 的坐标平方差。

#include <bits/stdc++.h>
    using namespace std;

    // 球心 C 到每个点 P_i 的距离都相等：
    // |P_i - C|^2 = R^2，对 i = 1..n+1 都成立
    // 相邻两个方程相减，R^2 被消掉，剩下 n 个线性方程：
    // 2 * (P_i - P_{i+1}) * C = |P_i|^2 - |P_{i+1}|^2
    const int MAXN = 12;
    double data[MAXN][MAXN];  // 第 i 个点的 n 个坐标
    double mat[MAXN][MAXN];
    int n;

    void build() {
      memset(mat, 0, sizeof(mat));
      for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
          mat[i][j] = 2 * (data[i][j] - data[i + 1][j]);
          mat[i][n + 1] += data[i][j] * data[i][j]
                           - data[i + 1][j] * data[i + 1][j];
        }
      }
    }

这里有个细节：右边用 += 累加，因为每个坐标的平方差都要加进常数里，不是只取最后一项。

构造完的方程组交给严格三分模板消元。共球面的 n+1 个点保证方程组有唯一解，消元后每一行最后一列就是球心的一个坐标，保留三位小数输出。

#include <bits/stdc++.h>
    using namespace std;

    // 构造好的 n 个方程用严格三分模板求解
    // 共球面的 n+1 个点保证方程组有唯一解，解就是球心
    const double sml = 1e-7;
    double mat[12][12];
    int n;

    void swapRows(int a, int b) {
      for (int j = 1; j <= n + 1; j++) {
        swap(mat[a][j], mat[b][j]);
      }
    }

    void gauss(int n) {
      for (int i = 1; i <= n; i++) {
        int max = i;
        for (int j = 1; j <= n; j++) {
          if (j < i && fabs(mat[j][j]) >= sml) {
            continue;
          }
          if (fabs(mat[j][i]) > fabs(mat[max][i])) {
            max = j;
          }
        }
        swapRows(i, max);
        if (fabs(mat[i][i]) >= sml) {
          double tmp = mat[i][i];
          for (int j = i; j <= n + 1; j++) {
            mat[i][j] /= tmp;
          }
          for (int j = 1; j <= n; j++) {
            if (i != j) {
              double rate = mat[j][i] / mat[i][i];
              for (int k = i; k <= n + 1; k++) {
                mat[j][k] -= mat[i][k] * rate;
              }
            }
          }
        }
      }
    }

    int main() {
      scanf("%d", &n);
      for (int i = 1; i <= n + 1; i++) {
        for (int j = 1; j <= n; j++) {
          scanf("%lf", &data[i][j]);
        }
      }
      build();
      gauss(n);
      for (int i = 1; i <= n; i++) {
        printf("%.3f ", mat[i][n + 1]);
      }
      printf("\n");
      return 0;
    }

为什么保证唯一解：n+1 个点在同一个球面上是题面给的，球心是客观存在的，作差得到的 n 个方程系数矩阵一定满秩。模板二的主元选择逻辑在这里照常工作，不需要额外处理自由元分支。

二、复杂度

构造方程 O(n2)，高斯消元 O(n3)。n ≤ 10，怎么跑都够。

演示：3 组二维点，逐条构造方程并解出球心

三、总结

球心问题的关键是构造：把「距离相等」相邻作差，R2 消掉，几何约束变成线性方程组。构造出来的方程系数可能带着小数，但不影响消元。这类题换一层皮就是「给若干等式求未知点」，套路都是先翻译成线性方程，再交给高斯消元模板。
