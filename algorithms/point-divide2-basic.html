静态点分治题集（一）：bfs、线段树与二分答案

上一节讲了静态点分治的原理、模版题和容斥题型。这一节换一批题：点分治负责把树按重心拆成一半一半，真正的功夫落在「每到一个重心，对当前子树跑什么统计」。这一页的三道题分别在重心下面接了 bfs、按颜色排序的线段树、和树上的一次二分。

零、背景

点分治的结构是固定的：每次选当前子树的重心当根，把它删掉，剩下的若干块每一块都不超过原来的一半，递归下去只有 O(log n) 层。

它真正值钱的地方在于：每来到一棵子树，都允许对当前子树做多次遍历、统计、合并。同一层里可以从重心出发跑一遍 bfs，也可以把子树排个序，甚至可以再套一层二分。只要这些额外操作的代价和当前子树的大小同阶，加起来就是 O(n log n)。

所以拿到题先想清楚两件事：一是一条路径什么时候会被统计到（要么经过当前重心，要么整体落在某个子树里递归处理），二是经过重心的那些路径，用什么手法把两半拼起来。

一、题目1：首都

n 个节点的树，每个节点有一种颜色，一共 k 种。要找一个连通区，使得连通区内出现过的每种颜色，在连通区外都不出现。这样的连通区可能有很多个，希望包含的颜色种类尽量少，输出「最少颜色数减一」。n、k 到 2×10⁵。

先把条件翻译一下。连通区合法，等价于它包含的每种颜色都在它里面完整出现，只要某种颜色在区内露过面，区外就不能再有同色的点。

于是从一个点出发，这个区就被唯一确定了，称作它的闭包：把起点的颜色记为已用，然后把这种颜色的所有点都拉进来；新拉进来的点如果带来新的颜色，再把新颜色的所有点也拉进来；如此往复。为了让区本身连通，走过的路径上的点也要算进来。

如果扩散过程中碰到了当前子树外面的点，说明这个闭包跨出了本层组件，不合法，直接记成一个无穷大。

剩下的交给点分治的一条基本事实：任何连通的点集，要么包含当前重心，要么整体落在重心的某一个子树里。前者用闭包直接算，后者递归。对每个重心求闭包的颜色数，取最小即可。

实现上拉两条链式前向星：一条存树的边，一条把「同一颜色的点」串成链表，方便 O(1) 找到一种颜色的全部点。计算闭包用 bfs，队列里既有新扩散进来的点，也有为了保持连通而补上的父亲。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int INF = 1000000001;
    int n, k;
    int color[MAXN];

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int cntg;

    int headc[MAXN];
    int nextc[MAXN];
    int toc[MAXN];
    int cntc;

    bool vis[MAXN];
    int siz[MAXN];

    int father[MAXN];
    int nodeRoot[MAXN];

    int que[MAXN];
    bool nodeVis[MAXN];
    bool colorVis[MAXN];

    void addEdge(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void addNode(int color, int node) {
        nextc[++cntc] = headc[color];
        toc[cntc] = node;
        headc[color] = cntc;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = headg[u]; e; e = nextg[e]) {
                int v = tog[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int rt) {
        father[u] = fa;
        nodeRoot[u] = rt;
        nodeVis[u] = false;
        colorVis[color[u]] = false;
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, rt);
            }
        }
    }

    int calc(int u) {
        dfs(u, 0, u);
        int l = 1, r = 0;
        que[++r] = u;
        nodeVis[u] = true;
        int ans = 0;
        while (l <= r) {
            int cur = que[l++];
            if (cur != u && !nodeVis[father[cur]]) {
                que[++r] = father[cur];
                nodeVis[father[cur]] = true;
            }
            if (!colorVis[color[cur]]) {
                colorVis[color[cur]] = true;
                ans++;
                for (int e = headc[color[cur]]; e; e = nextc[e]) {
                    int v = toc[e];
                    if (nodeRoot[v] != u) {
                        return INF;
                    }
                    if (!nodeVis[v]) {
                        que[++r] = v;
                        nodeVis[v] = true;
                    }
                }
            }
        }
        return ans;
    }

    int solve(int u) {
        vis[u] = true;
        int ans = calc(u);
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (!vis[v]) {
                ans = min(ans, solve(getCentroid(v, u)));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> k;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        for (int i = 1; i <= n; i++) {
            cin >> color[i];
            addNode(color[i], i);
        }
        int ans = solve(getCentroid(1, 0));
        cout << (ans - 1) << '\n';
        return 0;
    }

二、题目2：树的难题

n 个节点的树，每条边有一种颜色，一共 m 种，val[i] 是第 i 种颜色的权值，可能为负。一条简单路径按颜色分段，每种连续同色段只算一次 val，各段相加作为路径的权。求边数在 [limitl, limitr] 的所有路径里，最大的权是多少。n、m 到 2×10⁵。

路径的权是「分段去重」的，直接合并两半会出问题：从重心往两边各走一条边，如果这两条边同色，这段颜色在两半里被各算了一次，合起来应该只算一次。

处理办法是把重心 u 的儿子，按「u 到儿子那条边的颜色」排序。排序之后同色的儿子挨在一起，逐个颜色组处理。

维护两棵线段树，下标是路径的边数，值是该边数下的最大路径权。preTree 存已经处理完的、颜色小于当前颜色的那些子树；curTree 存当前颜色组里已经处理过的子树。

处理当前颜色 c 的某个子树时，两半分别和这两棵树配对：和 preTree 配对，两边第一条边颜色不同，直接查长度落在 [limitl-len, limitr-len] 的最大值加上本半；和 curTree 配对，两边第一条边同色，把多算的一次 val[c] 减掉。

一个颜色组处理完，把 curTree 的内容并进 preTree，清空 curTree，再进入下一种颜色。这样每个子树只被 dfs 一次、只插入一次线段树，复杂度才对。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int node, color;
    };

    bool EdgeCmp(Edge a, Edge b) {
        return a.color < b.color;
    }

    const int MAXN = 200001;
    const long long INF = 1LL << 60;
    int n, m, limitl, limitr;
    int val[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int color[MAXN << 1];
    int cntg;

    long long preTree[MAXN << 2];
    long long curTree[MAXN << 2];

    bool vis[MAXN];
    int siz[MAXN];

    Edge edgeArr[MAXN];
    int cnte;

    int edgeCnt[MAXN];
    long long pathSum[MAXN];

    int subtreeNode[MAXN];
    int cnts;
    int colorNode[MAXN];
    int cntc;

    void addEdge(int u, int v, int c) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        color[cntg] = c;
        head[u] = cntg;
    }

    void build(long long *tree, int l, int r, int i) {
        tree[i] = -INF;
        if (l < r) {
            int mid = (l + r) >> 1;
            build(tree, l, mid, i << 1);
            build(tree, mid + 1, r, i << 1 | 1);
        }
    }

    void clear(long long *tree, int l, int r, int i) {
        if (tree[i] == -INF) {
            return;
        }
        tree[i] = -INF;
        if (l < r) {
            int mid = (l + r) >> 1;
            clear(tree, l, mid, i << 1);
            clear(tree, mid + 1, r, i << 1 | 1);
        }
    }

    void update(long long *tree, int jobi, long long jobv, int l, int r, int i) {
        if (l == r) {
            tree[i] = max(tree[i], jobv);
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                update(tree, jobi, jobv, l, mid, i << 1);
            } else {
                update(tree, jobi, jobv, mid + 1, r, i << 1 | 1);
            }
            tree[i] = max(tree[i << 1], tree[i << 1 | 1]);
        }
    }

    long long query(long long *tree, int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            return tree[i];
        }
        int mid = (l + r) >> 1;
        long long ans = -INF;
        if (jobl <= mid) {
            ans = max(ans, query(tree, jobl, jobr, l, mid, i << 1));
        }
        if (jobr > mid) {
            ans = max(ans, query(tree, jobl, jobr, mid + 1, r, i << 1 | 1));
        }
        return ans;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int preColor, int edge, long long sum) {
        if (edge > limitr) {
            return;
        }
        edgeCnt[u] = edge;
        pathSum[u] = sum;
        subtreeNode[++cnts] = u;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int c = color[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, c, edge + 1, sum + (preColor == c ? 0 : val[c]));
            }
        }
    }

    long long calc(int u) {
        cnte = 0;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int c = color[e];
            if (!vis[v]) {
                edgeArr[++cnte] = {v, c};
            }
        }
        sort(edgeArr + 1, edgeArr + cnte + 1, EdgeCmp);
        update(preTree, 0, 0, 0, n, 1);
        long long ans = -INF;
        cntc = 0;
        for (int k = 1; k <= cnte; k++) {
            int v = edgeArr[k].node;
            int c = edgeArr[k].color;
            if (k > 1 && edgeArr[k - 1].color != c) {
                clear(curTree, 0, n, 1);
                for (int i = 1; i <= cntc; i++) {
                    int node = colorNode[i];
                    update(preTree, edgeCnt[node], pathSum[node], 0, n, 1);
                }
                cntc = 0;
            }
            cnts = 0;
            dfs(v, u, c, 1, val[c]);
            for (int i = 1; i <= cnts; i++) {
                int node = subtreeNode[i];
                int l = max(0, limitl - edgeCnt[node]);
                int r = limitr - edgeCnt[node];
                ans = max(ans, query(preTree, l, r, 0, n, 1) + pathSum[node]);
                ans = max(ans, query(curTree, l, r, 0, n, 1) + pathSum[node] - val[c]);
            }
            for (int i = 1; i <= cnts; i++) {
                int node = subtreeNode[i];
                colorNode[++cntc] = node;
                update(curTree, edgeCnt[node], pathSum[node], 0, n, 1);
            }
        }
        clear(preTree, 0, n, 1);
        clear(curTree, 0, n, 1);
        return ans;
    }

    long long solve(int u) {
        vis[u] = true;
        long long ans = calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans = max(ans, solve(getCentroid(v, u)));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> limitl >> limitr;
        for (int i = 1; i <= m; i++) {
            cin >> val[i];
        }
        for (int i = 1, u, v, c; i < n; i++) {
            cin >> u >> v >> c;
            addEdge(u, v, c);
            addEdge(v, u, c);
        }
        build(preTree, 0, n, 1);
        build(curTree, 0, n, 1);
        cout << solve(getCentroid(1, 0)) << '\n';
        return 0;
    }

三、题目3：快递员

n 个节点的树，每条边有正边权。给定 m 个点对 (a, b)，选择中心 x 之后，点对的距离定义为 a 到 x 的路径和加上 b 到 x 的路径和。要选一个 x，让所有点对距离的最大值尽量小，输出这个最小的最大值。n、m 到 10⁵。

固定 x 时，记 f(x) 为所有点对里最大的那个距离。看让 f(x) 取到最大值的点对 (a, b)。

如果 a、b 落在 x 的同一个儿子子树里，那么把中心往那棵子树里挪一步，a 到 x、b 到 x 这两段都要经过这条边的两端，两项一起变小，f 只会更小。也就是说，最优中心一定在那棵子树里。

如果最大的点对有多个，而且有的端点落在不同子树，或者 a、b 本身跨着 x，那么往任何一棵子树挪都会让另一组点对变大，x 已经是答案，停。

于是从当前子树的重心出发，判断「取到最大值的点对落在哪个子树」，就往那个子树的重心递归。每走一层子树规模至少减半，一共 O(log n) 层，可以看成树上的一次二分。

实现上，每层从重心 dfs 一遍，算出每个点到重心的距离；扫一遍 m 个点对求最大值，同时用 tree[] 记下每个点属于重心的哪个儿子子树（点自己或跨子树时记为 0）。最大值若只对应一个儿子子树就带着它往下走，否则收工。

中心点沿树移动时，最大点对距离怎么变

一条 5 个点的链，两个点对分别是 (1,2) 和 (4,5)。点「下一步」把中心从 1 挪到 5，看 f(x) 先降后升，最低的那个位置就是答案。点分治的做法是从重心出发、判断最大值落在哪半个子树，一次跳过去，而不用把每个点都试一遍。

当前中心 x 其他节点 f(x) 最小的位置

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;
    int a[MAXN];
    int b[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    int tree[MAXN];
    int dist[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int d, int t) {
        tree[u] = t;
        dist[u] = d;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u, d + weight[e], t);
            }
        }
    }

    int compute() {
        int ans = 1000000001;
        int u = getCentroid(1, 0);
        while (!vis[u]) {
            vis[u] = true;
            tree[u] = u;
            dist[u] = 0;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                int w = weight[e];
                dfs(v, u, w, v);
            }
            int maxDist = 0, son = 0;
            for (int i = 1; i <= m; i++) {
                int curDist = dist[a[i]] + dist[b[i]];
                int t1 = tree[a[i]];
                int t2 = tree[b[i]];
                if (maxDist < curDist) {
                    maxDist = curDist;
                    son = (t1 == t2) ? t1 : 0;
                } else if (maxDist == curDist && (t1 != t2 || t1 != son)) {
                    son = 0;
                }
            }
            ans = min(ans, maxDist);
            if (son == 0) {
                break;
            }
            u = getCentroid(son, u);
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
        }
        cout << compute() << '\n';
        return 0;
    }

四、复杂度分析

三道题的点分治骨架一样：找重心 O(size)，每层总代价和子树大小同阶，层数 O(log n)。差别只在重心处那步统计。

操作时间复杂度空间复杂度
题目1：闭包 bfs（每个点每层至多入队一次）O(n log n)O(n + m)（前向星、颜色链表、vis/siz）
题目2：子树排序 + 两棵线段树（下标边数）O(n log² n)
题目3：重心下探 + 每层 dfs 求距离、扫点对O(n log n + m log n)

题目2 多出来的一个 log 来自线段树：每层每个点做一次单点更新和一次区间查询。子树排序的总量是 O(n log n) 级别，不占大头。

题目3 每次下探只往一个子树走，dfs 求和扫点对的代价按当前子树大小算，逐层减半，合起来仍是 O((n+m) log n)。

五、最后

这三道题把「重心下面能干什么」摊开看了一眼：能扩散颜色、能排序后上数据结构、能再套一层二分。骨架一行没变，变的都是重心处那几十行。
