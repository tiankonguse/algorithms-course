子序列与组合：逐位决策的两兄弟

子序列和组合干的是同一件事：从一串东西里挑一部分出来。差别在子序列保顺序、组合只认值。两个题共用同一副骨架，带路径的递归：每走一步把选择记进 path，走到头把 path 收进答案。

零、背景

枚举题要返回一整个集合，递归的写法也就固定下来：每层做一次选择，选择记进 path，递归到底把 path 收进答案。这类递归叫带路径的递归，后面讲动态规划时还会碰到它的变体，只是路径被压缩进了状态。

先记住一个衡量标准：决策树的叶子数就是答案的量级。子序列每个字符两个分支，n 个字符 2^n 个叶子；组合按值分组，组数最多也是 n，最坏同样 2^n。两个题的 O(2^n · n) 就是这么来的。

一、字符串的全部子序列

子序列的定义：从原串按顺序挑字符，挑出来的拼一起，允许跳过中间的。空串也算。「ab」的子序列 4 个：ab、a、b、空串。n 个不同字符的子序列正好 2^n 个。

每个字符只有两种选择：要，或者不要。决策树画出来就是图 1 的样子。

实现上两个版本，区别只在 path 怎么记。f1 用 string，要就把字符尾插，递归回来再尾删；

#include <bits/stdc++.h>
    using namespace std;

    // 字符串的全部子序列（去重）
    // 测试链接 : https://www.nowcoder.com/practice/92e6247998294f2c933906fdedbc6e6a

    // 版本一：path 用 string，尾插尾删
    void f1(const string& s, int i, string& path, unordered_set<string>& set) {
        if (i == (int)s.length()) {
            set.insert(path);
        } else {
            path.push_back(s[i]);          // 把 s[i] 加到路径中去
            f1(s, i + 1, path, set);
            path.pop_back();               // 从路径中移除
            f1(s, i + 1, path, set);
        }
    }

f2 换 char 数组加一个 size：path[size] = s[i] 覆盖写，size 记当前长度，到底时只取前 size 个。string 的伸缩省掉了，代价是收答案时得把字符数组转回字符串。

#include <bits/stdc++.h>
    using namespace std;

    // 版本二：path 用字符数组 + size 记长度
    void f2(const string& s, int i, vector<char>& path, int size, unordered_set<string>& set) {
        if (i == (int)s.length()) {
            set.insert(string(path.begin(), path.begin() + size));
        } else {
            path[size] = s[i];             // 把 s[i] 放进 path[size]
            f2(s, i + 1, path, size + 1, set);
            f2(s, i + 1, path, size, set);
        }
    }

set 是去重开关。题目要求返回不重复的子序列，原串有重复字符时，不同选择路径可能走到同一个结果：字符串「aa」的「取、跳」和「跳、取」都是 a。set 插重了自然去重，代价是多走了一遍重复分支。

去重后的数量差得离谱。实测 15 个字符：全不同时 2^15 = 32768 个，全相同时只剩 16 个（空、a、aa、…、15 个 a）。递归调用次数与去不去重无关，恒为 2^(n+1) − 1：n=10 时 2047 次，n=15 时 65535 次。

复杂度 O(2^n · n)。叶子 2^n 个，每个叶子把 path 拼成字符串再插哈希表，路径最长 n，这 n 就是乘上去的部分。

二、数组的不重复组合

组合不看顺序，[1, 2] 和 [2, 1] 算同一个。题目再补一刀：数组本身可能含重复值，要返回不重复的组合。LeetCode 的子集 II 就是它。

[1, 2, 2] 的答案 6 个：[]、[2]、[2, 2]、[1]、[1, 2]、[1, 2, 2]。

直接套子序列的逐位决策会重复：两个 2 是不同的下标，选第一个还是选第二个都得到 [1, 2]，同一个组合出现两遍，还得靠 set 兜底。解法是先排序，把相等的值凑成一组，再按组决策：这一组的值要 0 个、要 1 个、要 2 个，直到全要。一个值只走一条链，重复从结构上消失。

代码里 j 先跳到下一组的开头，然后分两支：要 0 个，直接递归 j；要 1 个、2 个…用循环把本组的值逐个加进 path 再递归。循环变量复用 i，走完一组自动停在 j 上。

#include <bits/stdc++.h>
    using namespace std;

    // 数组的不重复组合（子集 II 去重版）
    // 测试链接 : https://leetcode.cn/problems/subsets-ii/

    void f(vector<int>& nums, int i, vector<int>& path, int size, vector<vector<int>>& ans) {
        if (i == (int)nums.size()) {
            ans.push_back(vector<int>(path.begin(), path.begin() + size));
        } else {
            // 下一组的第一个数的位置：跳过所有和 nums[i] 相等的数
            int j = i + 1;
            while (j < (int)nums.size() && nums[i] == nums[j]) j++;
            // 当前值 x，要 0 个
            f(nums, j, path, size, ans);
            // 当前值 x，要 1 个、2 个、3 个...都尝试
            for (; i < j; i++) {
                path[size++] = nums[i];
                f(nums, j, path, size, ans);
            }
        }
    }

    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());
        vector<int> path(nums.size());
        f(nums, 0, path, 0, ans);
        return ans;
    }

复杂度同样 O(2^n · n)：每个值各成一组的数组（没有重复）是树最大的时候，叶子 2^n，拷贝 path 的 O(n) 照旧。实测 [1, 1, 1, 1] 只有 5 个答案（空、1、11、111、1111），全组合本来有 16 个。

演示一：子序列逐帧

每个字符要或不要：左分支要，右分支不要，到底把 path 收进集合

演示二：组合逐帧

按值分组：一组决定要几个，组内只走一条链

三、总结

子序列和组合共享带路径的递归骨架：path 记选择，递归到底收答案，复杂度都由叶子数决定。

子序列按字符做二分决策，保顺序，去重交给哈希表；组合先排序再按值分组，不保顺序，去重发生在结构上。前者多花的遍历换来后者少用的 set。

这两题的决策是「取或不取」。下一节换一种决策：全排列不再问每个元素要不要，而是问每个位置放谁，叶子数从 2^n 跳到 n!。
