鞋带公式与 Pick 定理：格点多边形

机器人在网格上沿直线走一圈回到原点，围成一个多边形。要输出内部格点数、边上格点数、面积。边上格点用上一页的 gcd 结论逐段累加，面积用鞋带公式，内部格点由 Pick 定理从面积和边上格点反推。最后补一个硬币问题：互质面值 a、b 凑不出的最大钱数，答案只有一行 a·b − a − b。

零、背景

机器人从 (0,0) 出发，每次沿直线走到 (x+dx, y+dy)，共 n 步，路线不交叉、逆时针绕行、最终回到 (0,0)。问多边形内部几个格点、边上几个格点、面积多少。n ≤ 100，dx、dy ∈ [−100,100]，坐标不大但顶点数上百，逐点数格点不现实。

三件事各有现成工具：边上格点数由每段的 gcd 决定、面积由鞋带公式一次算完、内部格点数用 Pick 定理从两者反推。把工具拼起来就是完整解。

一、边上格点数：逐段累 gcd

一段从 (x,y) 到 (x+dx, y+dy) 的直线，边上格点数（含起点不含终点）是 gcd(|dx|, |dy|)。上一页已经证明：线段上整点间距由 (dx/g, dy/g) 决定，从起点出发能踩到 g 个新格点。多边形每条边都这样算，累加就是整个边界的格点数。

这里有个隐蔽点：累加时每条边都「含起点不含终点」，相邻边首尾相接，顶点只在它作为终点的那条边里被数一次，不会重复。

二、面积：鞋带公式

顶点按逆时针顺序排 (x0,y0), (x1,y1), …, (x{n−1},y{n−1})，面积 = |Σ (xi·y{i+1} − x{i+1}·yi)| / 2。几何意义：每一项 (xi, yi) 和 (x{i+1}, y{i+1}) 与原点构成的平行四边形有向面积，相邻两项相减正好消掉外部区域，剩下多边形本身。

题目的输入是增量 (dx,dy) 而不是顶点，但当前点 (x,y) 每步都在手边：第 i 步的交叉项 = x·(y+dy) − (x+dx)·y，逐步累加再除 2，就是鞋带公式的增量写法。逆时针绕行保证累加结果为正，不需要取绝对值。

三、内部格点：Pick 定理

Pick 定理：面积 A、边上格点数 B、内部格点数 I 满足 A = I + B/2 − 1。移项：I = A − B/2 + 1。面积和边上格点都已到手，内部格点数一行算完。

对格点多边形（顶点都是格点）这个关系恒成立，不管多边形多怪。注意 B 是偶数时才没有半格点，A 可能是半整数（如 .5），I 仍是整数，这正是定理的约束。

long long gcd(long long a, long long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    int main() {
        int cases;
        scanf("%d", &cases);
        for (int t = 1; t <= cases; t++) {
            int n;
            scanf("%d", &n);
            int edges = 0;
            double area = 0;
            for (int i = 1, x = 0, y = 0, dx, dy; i <= n; i++) {
                scanf("%d %d", &dx, &dy);
                edges += gcd(llabs((long long)dx), llabs((long long)dy));
                area += x * (y + dy) - (x + dx) * y;
                x += dx;
                y += dy;
            }
            area /= 2;
            int inners = (int)area - edges / 2 + 1;
            printf("Scenario #%d:\n", t);
            printf("%d %d %.1f\n\n", inners, edges, area);
        }
        return 0;
    }
演示：逐边累边上格点与鞋带项

四、无法组成的最大值

a、b 两种面值互质的硬币各有无限个，问凑不出的钱数里最大是多少。答案：a·b − a − b。以 3、5 为例：1、2、4、7 凑不出，最大的 7 = 3·5 − 3 − 5。

为什么卡在 a·b？裴蜀定理保证大于某阈值的数都能凑：a、b 互质时，任意整数 m ≥ (a−1)(b−1) 都能写成 ax + by（x、y ≥ 0）。恰好临界值下方那个点就是 ab−a−b：它凑不出（否则 ab−a−b = ax+by 会推出 a | b 或 b | a 的矛盾），而它之后的所有数都能凑。

int main() {
        long long a, b;
        scanf("%lld %lld", &a, &b);
        printf("%lld\n", a * b - a - b);
        return 0;
    }
演示：互质面值凑数与最大不可凑

总结

格点多边形三件套：边上格点逐边累 gcd(|dx|,|dy|)、面积用增量鞋带公式、内部格点用 Pick 定理 I = A − B/2 + 1 反推。它们各自独立，合起来正好覆盖 POJ1265 要的三个输出。硬币问题的最大不可凑 ab−a−b 是裴蜀定理的收官应用：互质保证阈值以上全可凑，临界点下方卡住。整页没有一处需要枚举。
