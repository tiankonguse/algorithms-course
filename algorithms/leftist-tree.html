左偏树：可并堆的 merge 与删除堆顶

堆结构用数组实现时，合并两个堆只能把小堆的元素逐个插进大堆，代价是 O(n log n)。左偏树是一棵用「右链长度」约束自身的二叉树，两个堆合并只要 O(log n)。

零、背景

能快速合并的堆结构不止左偏树一种：配对堆、斜堆、二项堆、斐波那契堆都能做到对数级合并。这一课只学左偏树，原因是下节课的可持久化版本要依赖它。其他可并堆结构没法方便地持久化。

左偏树表示的堆不是完全二叉树，而是广义的堆结构：父节点比子节点优先（小根堆里就是值更小），左右子树可以严重不对称。它的「平衡性」由 dist 值来维护，维护的不是树高，而是右链的长度。

一、dist 值：左偏的定义

每个节点的 dist 表示：离开这个节点后，至少经过几个节点能到达空。空节点的 dist 记作 dist[0] = -1，这样没有右儿子的节点，它的 dist 就等于 -1 + 1 = 0。

左偏树要求每个节点满足：左儿子 dist 不小于右儿子 dist。合并后一旦发现左儿子 dist 小于右儿子 dist，就交换左右子树。这个性质保证右链（一路走右儿子）的长度受 dist 限制，而合并恰好发生在右链上。

dist 沿右链单调递减，每走一步右儿子，dist 就少 1。

这个性质带来一个关键推论：dist 为 k 的子树至少包含 2k − 1 个节点。所以 n 个节点的左偏树，右链长度不超过 log(n+1)。合并沿着右链走，代价就是 O(log n)。

二、merge：合并总发生在右树上

合并两棵树 h1、h2，谁当头？小根堆取值较小的根（值相等取编号较小），另一个根递归合到它的右儿子上。这一步是左偏树的核心：递归永远发生在右树上，所以一趟合并最多走一条右链。

回溯到每一层都要检查：左儿子 dist 是否不小于右儿子 dist。不满足就交换左右子树，然后 dist[i] = dist[rs[i]] + 1。同时把新根登记进并查集：fa[ls[i]] = fa[rs[i]] = i，让并查集的代表节点始终是堆顶。

这里有个细节：小根堆相等值怎么处理？课程代码写的是 num[i] > num[j] || (num[i] == num[j] && i > j)，值相等时编号小的当头。这样 P3377 里「若有多个最小值，优先删除编号小的」就能保证删的是编号最小的那个堆顶。

三、并查集：找堆顶不走树结构

左偏树的平衡性只方便合并，树上依然可能出现很长的链。任何节点找堆顶的过程，不能依赖左偏树的结构，否则最坏情况还是 O(n)。

解法是给每个节点挂并查集：并查集最上方的代表节点 = 左偏树的头 = 堆顶。find(i) 一路压缩路径，摊还接近 O(1)。合并时新根的左、右儿子都指向它，代表节点自然被更新。

find 与树上父子是两个系统：树上的 left/right 是堆结构，并查集的 fa 是找头的捷径。merge 里更新 fa 的时机只有一个：新根确定之后。

四、删除堆顶：三步

删除堆顶节点 i，三步走：

1）i 的左右子树合并，形成新树；2）i 的 left、right、dist 信息清空；3）i 的 father 指向新树的头，这一步很重要：别的节点 find 到 i 时，能顺着 fa 一路压到新头。

课程代码里 pop 的前两行先把左右子树的 fa 复位成自己（fa[ls[i]] = ls[i]; fa[rs[i]] = rs[i]），这样 merge 时它们不会被误认成 i 的后代。然后 fa[i] = merge(ls[i], rs[i])，i 自己指向新头。

五、P3377 左偏树模板

题目给 n 个非负数字，每个单独成堆。操作 1 x y：x、y 所在堆合并，两个数字已在一个堆或某个已删除就不合并。操作 2 x：打印 x 所在堆的最小值并删掉它，x 已被删除打印 -1，多个最小值优先删编号小的。n、m ≤ 105。

删除用 num[i] = -1 标记（输入保证值非负，-1 不冲突）。查询时先看 num[x] 是否 -1，再看 find(x) 的堆顶值。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;
    int num[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int dist[MAXN];
    int fa[MAXN];

    void prepare() {
        dist[0] = -1;
        for(int i = 1; i <= n; i++) {
            ls[i] = rs[i] = dist[i] = 0;
            fa[i] = i;
        }
    }

    int find(int i) {
        fa[i] = fa[i] == i ? i : find(fa[i]);
        return fa[i];
    }

    int merge(int i, int j) {
        if (i == 0 || j == 0) {
            return i + j;
        }
        if (num[i] > num[j] || (num[i] == num[j] && i > j)) {
            swap(i, j);
        }
        rs[i] = merge(rs[i], j);
        if (dist[ls[i]] < dist[rs[i]]) {
            swap(ls[i], rs[i]);
        }
        dist[i] = dist[rs[i]] + 1;
        fa[ls[i]] = fa[rs[i]] = i;
        return i;
    }

    int pop(int i) {
        fa[ls[i]] = ls[i];
        fa[rs[i]] = rs[i];
        fa[i] = merge(ls[i], rs[i]);
        ls[i] = rs[i] = dist[i] = 0;
        return fa[i];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        prepare();
        for (int i = 1; i <= n; i++) {
            cin >> num[i];
        }
        for (int i = 1; i <= m; i++) {
            int op;
            cin >> op;
            if (op == 1) {
                int x, y;
                cin >> x >> y;
                if (num[x] != -1 && num[y] != -1) {
                    int l = find(x);
                    int r = find(y);
                    if (l != r) {
                        merge(l, r);
                    }
                }
            } else {
                int x;
                cin >> x;
                if (num[x] == -1) {
                    cout << -1 << "\n";
                } else {
                    int ans = find(x);
                    cout << num[ans] << "\n";
                    pop(ans);
                    num[ans] = -1;
                }
            }
        }
        return 0;
    }

题目的增强版 P2713 把数据量提到 106，操作变成字符 M x y / K x，K 找不到时打印 0。merge、pop 的逻辑一字不改，只换了输入格式和输出值。

六、merge 过程演示

两棵小左偏树合并

初始：A 树根 5（左 3，右 9），B 树根 8（左 2，右 7）。点「下一步」逐步合并。

蓝 = 原 A 树根，橙 = 左子树，绿 = 右子树，紫 = 原 B 树根

演示里合并的是两个 3 节点左偏树：A 树 5(3, 9)、B 树 8(2, 7)。5 和 8 比较后 5 当头，8 递归到 5 的右儿子 9；9 和 8 比较后 9 当头，8 挂到 9 的右儿子（空）。回溯时 9 的右儿子 dist 1 大于左儿子 dist 0，交换左右，最后 5 的右子树 dist 变 1，平衡。

总结

左偏树用 dist 约束右链长度：左儿子 dist 不小于右儿子，节点 dist 等于右儿子 dist 加 1，空节点 dist 记 -1。合并只发生在右链上，代价 O(log n)；找堆顶靠并查集压缩路径，不靠树结构；删除堆顶三步：左右合并、清空信息、fa 指向新头。这套结构是下节课可持久化左偏树的地基。
