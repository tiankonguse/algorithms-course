打表找规律：好串计数

用 r、e、d 三种字符拼长度 n 的串，恰好有 1 个长度 ≥2 的回文子串的串叫好串。n 到 1e9，暴力枚举 3^n 个串跑不动，但打出来的表是 6(n+1)。

零、背景

好串的定义有两半。第一半「有且仅有 1 个」：回文子串的计数恰好是 1。第二半「长度 ≥2」：单个字符不算回文，所以 n=1 时没有任何长度 ≥2 的子串，答案 0。

示例：n=2 时 rr、ee、dd 三个串各自只有一个回文子串（它自己），答案 3。n=3 时答案是 18。

输入是一个 int（n），输出是一个 int（数量），正是打表的适用形状。暴力枚举所有串在 n 小时完全可行，答案表一打出来，规律就藏不住了。

一、暴力枚举

枚举全部 3^n 个串。写一个三进制循环：code 从 0 到 3^n − 1，逐位取除以 3 的余数决定放 r、e、d。

对每个串数一遍回文子串：枚举所有 l < r 的子串区间，isPal 检查是否回文，计数超过 1 直接判坏提前退出。恰好 1 个的计入答案。

// 暴力：枚举全部 3^n 个串，统计恰好有 1 个回文子串的串数
    long long num1(int n) {
        long long total = 1;
        for (int i = 0; i < n; i++) total *= 3;
        long long cnt = 0;
        string s(n, 'r');
        for (long long code = 0; code < total; code++) {
            long long x = code;
            for (int i = 0; i < n; i++) {
                s[i] = "red"[x % 3];
                x /= 3;
            }
            int pal = 0;
            bool over = false;
            // 检查所有长度 >= 2 的子串区间
            for (int l = 0; l < n && !over; l++) {
                for (int r = l + 1; r < n; r++) {
                    if (isPal(s, l, r)) {
                        pal++;
                        if (pal > 1) {  // 已经不止 1 个，直接判坏
                            over = true;
                            break;
                        }
                    }
                }
            }
            if (pal == 1) cnt++;
        }
        return cnt;
    }

    // 判断 s[l..r] 是否回文
    bool isPal(const string& s, int l, int r) {
        while (l < r) {
            if (s[l] != s[r]) return false;
            l++;
            r--;
        }
        return true;
    }

规模是 3^n 个串，每个串检查 n(n−1)/2 个区间，每个区间 O(n)。实测：n=13 有 1594323 个串，109ms；n=16 有 43046721 个串，3.4 秒。每加 1，工作量翻 3 倍，n=20 就是 35 亿个串，n=1e9 想都别想。

二、打表

n=1 到 13 的答案打出来：

n=1、2、3 是特殊值：0、3、18。n≥4 起每加 1 答案加 6，正好 6(n+1)：30、36、42、48、54、60、66、72、78、84。

// 打表之后的最优解，n 到 1e9 也 O(1)
    long long num2(int n) {
        if (n == 1) return 0;
        if (n == 2) return 3;
        if (n == 3) return 18;
        return (6LL * (n + 1)) % 1000000007LL;
    }

n=1e9 时代公式：6 × (1e9 + 1) mod 1e9+7 = 999999971。暴力在 n=20 就放弃，公式在 n=1e9 还是一次乘法和一次取模。

三、好串长什么样

恰好 1 个回文子串，限制很硬：两个相同字符不能相邻，否则产生长度 2 的回文；不能隔一个位置，否则产生长度 3 的回文。唯一的回文只能来自其中一处，其余位置全部躲开。

n=3 的 18 个拆得开：12 个是「恰有一对相邻相同」（rre、err 这类），6 个是 aba 型（rer、ede 这类）。

n=4 的 30 个样例里两种形态都有：derr、edrr 靠尾部的 rr 撑起唯一回文，drer 靠中间的 e 撑起 r…r 的回文。n=5 答案 36，还是 6(n+1)。

结构分析能解释为什么线性，但打表课的重点在规律本身：表在那里，公式成立，直接写代码。真去数，就是两种形态各有几种位置。

总结

好串计数是打表课里最典型的题：输入输出都是简单类型，暴力只能撑到 n=13 左右，表一打出来就是等差 6(n+1)。

n=1、2、3 三个特殊值单独处理，n≥4 用 6(n+1) 对 1e9+7 取模。

「小范围暴力 + 大范围公式」的题，打表是唯一可靠的找规律手段。规律拿到后，复杂度从指数直接掉到 O(1)。
