莫队二次离线

普通莫队每挪动一个位置就要重算一次「这个位置带来的贡献」，当贡献无法 O(1) 维护时，总代价会变成「滑窗总距离 × 单次代价」。二次离线把窗口挪动产生的变化量拆成两份：一份能预先做成前缀和，当场就能算；另一份和窗口外的位置有关，先记成任务，等第二次离线时按扫描顺序一起算。两份都只花 O(n√n)。

零、背景

前置是序列分块和普通莫队；题目2 还要树状数组。本课讲第一种实现，对应题目1、题目2；下一页讲第二种实现，对应题目3、题目4，那一页的题目4 还要根号分治。

一、题目1：k1 二元组计数

给定一个长度为 n 的数组 arr 和非负整数 k。位置二元组 (i, j) 要满足 i ≠ j，且 arr[i] 异或 arr[j] 的二进制里有 k 个 1；i 和 j 换序算同一个。m 条查询，每条给出 l r，打印 arr[l..r] 上有多少这样的二元组。

1 ≤ n、m ≤ 10⁵，0 ≤ arr[i]、k < 16384，测试链接 P4887。

比如 arr = [1, 3, 5, 7]、k = 1，[1, 4] 上的答案是 4：1 和 3、1 和 5、3 和 7、5 和 7 这四对，异或值分别是 2、4、4、2，二进制里都只有 1 个 1。

二、普通莫队为什么卡住

窗口右端右移一位，新元素 arr[i] 带来的新二元组数，等于窗口里已有元素中「与 arr[i] 异或后有 k 个 1」的个数。值域是 0 到 2¹⁴−1，与 v 配对的值一共有 C(14, k) 个，k = 7 时是 3432 个。

于是每次挪动一位要枚举 3432 个值，莫队滑窗的总距离是 O(n√n)，n = 10⁵ 时约 3 × 10⁷ 次挪动，乘下来 10¹¹ 量级，完全不能接受。题目2 的区间逆序对也一样：挪动一位要查「已有元素里有多少比它大」，树状数组是 O(log n)，乘上滑窗距离还是太慢。

可以发现瓶颈在「每次挪动都要现算一次和整个窗口的配对」。窗口是连续变化的，相邻两次查询的窗口差别不大，但普通莫队只利用了「位置相邻」，没利用「配对这件事可以批量算」。

三、把变化量拆成两份

设当前窗口是 [winl, winr]，右端要右移到 jobr > winr，新增的位置是 winr+1 到 jobr。答案的变化由两部分构成：新增位置之间的配对，加上新增位置与老窗口 [winl, winr] 之间的配对。

预设 pre[i] 表示 arr[1..i] 上的配对总数，那么 pre[jobr] − pre[winr] 一次性给出了「涉及位置 > winr 且 ≤ jobr 的全部配对」，它比要的变化量多算了「新增位置与 [1, winl−1] 之间」的那部分。

因此右移这一步写成两笔：ans += pre[jobr] − pre[winr]，同时记一个任务 (x = winl−1, 区间 [winr+1, jobr], op = −1)，意思是将来减去 arr[1..x] 与 arr[winr+1..jobr] 之间的配对数。

左端移动对称。预设 suf[i] 表示 arr[i..n] 上的配对总数，winl 左移到 jobl 时新增的位置是 jobl 到 winl−1，ans += suf[jobl] − suf[winl]，并记任务 (x = winr+1, 区间 [jobl, winl−1], op = −1)，减去 arr[x..n] 与新增位置之间的配对。

反向移动（右端左移、左端右移）就是同一套公式取相反符号：pre / suf 的差分变成减号，任务的 op 变成 +1。四种情况合起来只有四行。

四、pre 与 suf 怎么预处理

两个数组都是一遍扫描，只装不删。以 pre 为例：维护一个值域计数 cnt，扫到位置 i 时，先读 cnt[arr[i]] 得到「已装进去的元素里与 arr[i] 配对的有几个」，累加进 pre[i]，再把所有与 arr[i] 配对的值 v 的 cnt[v] 加一。

题目1 里配对值最多 C(14, k) 个，所以这一遍是 O(n · C(14, k))；题目2 换成树状数组查「比它大的个数」，这一遍是 O(n log n)。两次扫描（pre、suf）各自一遍，比每次窗口挪动都现算一遍便宜得多。

五、第二次离线：任务挂在 x 上，扫一遍 x

任务是一个五元组 (x, l, r, op, id)：求 arr[1..x]（左任务）或 arr[x..n]（右任务）与 arr[l..r] 之间的配对数，乘上 op 加到第 id 条查询上。所有任务按 x 挂成链表，挂在 headl[x] 或 headr[x] 上。

左任务随 x 从 0 扫到 n，一边扫一边把 arr[x] 装进值域结构，扫到某个 x 就把它上面挂的任务全处理掉；右任务随 x 从 n+1 扫到 1，装的是 arr[x..n]。扫描过程中值域结构只增不减，这是能批量算的关键。

最后一步别忘了：ans 里存的是「从上一条查询到这条查询的变化量」，按莫队排好序的顺序做一遍前缀和，才是每条查询自己的答案。

六、整个过程走一遍

下面这个演示用 arr = [3, 1, 4, 1, 5, 9, 2, 6] 和五条查询，配对关系取「左边大右边小」的逆序对。前五步是第一次离线（莫队滑窗 + 生成任务），中间八步是第二次离线（扫 x 处理任务），最后一步做前缀和。点「下一步」跟着走。

七、题目1 的完整实现

pre、suf 两遍扫描，中间是莫队滑窗生成任务，最后两遍扫描处理任务。任务用链式前向星挂在 headl / headr 上，数组大小开 2m 就够。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 100002;
    const int MAXV = 1 << 14;
    int n, m, k;
    int arr[MAXN];
    int bi[MAXN];
    int kOneArr[MAXV];
    int cntk;

    Query query[MAXN];

    int headl[MAXN];
    int headr[MAXN];
    int nextq[MAXN << 1];
    int ql[MAXN << 1];
    int qr[MAXN << 1];
    int qop[MAXN << 1];
    int qid[MAXN << 1];
    int cntq;

    int cnt[MAXV];
    long long pre[MAXN];
    long long suf[MAXN];

    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r < b.r;
    }

    int lowbit(int x) {
        return x & -x;
    }

    int countOne(int num) {
        int ret = 0;
        while (num > 0) {
            ret++;
            num -= lowbit(num);
        }
        return ret;
    }

    void addLeftOffline(int x, int l, int r, int op, int id) {
        nextq[++cntq] = headl[x];
        headl[x] = cntq;
        ql[cntq] = l;
        qr[cntq] = r;
        qop[cntq] = op;
        qid[cntq] = id;
    }

    void addRightOffline(int x, int l, int r, int op, int id) {
        nextq[++cntq] = headr[x];
        headr[x] = cntq;
        ql[cntq] = l;
        qr[cntq] = r;
        qop[cntq] = op;
        qid[cntq] = id;
    }

    void prepare() {
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        sort(query + 1, query + m + 1, QueryCmp);
        for (int v = 0; v < MAXV; v++) {
            if (countOne(v) == k) {
                kOneArr[++cntk] = v;
            }
        }
    }

    void compute() {
        for (int i = 1; i <= n; i++) {
            pre[i] = pre[i - 1] + cnt[arr[i]];
            for (int j = 1; j <= cntk; j++) {
                cnt[arr[i] ^ kOneArr[j]]++;
            }
        }
        memset(cnt, 0, sizeof(cnt));
        for (int i = n; i >= 1; i--) {
            suf[i] = suf[i + 1] + cnt[arr[i]];
            for (int j = 1; j <= cntk; j++) {
                cnt[arr[i] ^ kOneArr[j]]++;
            }
        }
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            if (winr < jobr) {
                addLeftOffline(winl - 1, winr + 1, jobr, -1, id);
                ans[id] += pre[jobr] - pre[winr];
            }
            if (winr > jobr) {
                addLeftOffline(winl - 1, jobr + 1, winr, 1, id);
                ans[id] -= pre[winr] - pre[jobr];
            }
            winr = jobr;
            if (winl > jobl) {
                addRightOffline(winr + 1, jobl, winl - 1, -1, id);
                ans[id] += suf[jobl] - suf[winl];
            }
            if (winl < jobl) {
                addRightOffline(winr + 1, winl, jobl - 1, 1, id);
                ans[id] -= suf[winl] - suf[jobl];
            }
            winl = jobl;
        }
        memset(cnt, 0, sizeof(cnt));
        for (int x = 0; x <= n; x++) {
            if (x >= 1) {
                for (int j = 1; j <= cntk; j++) {
                    cnt[arr[x] ^ kOneArr[j]]++;
                }
            }
            for (int q = headl[x]; q > 0; q = nextq[q]) {
                int l = ql[q], r = qr[q], op = qop[q], id = qid[q];
                for (int j = l; j <= r; j++) {
                    ans[id] += 1LL * op * cnt[arr[j]];
                }
            }
        }
        memset(cnt, 0, sizeof(cnt));
        for (int x = n + 1; x >= 1; x--) {
            if (x <= n) {
                for (int j = 1; j <= cntk; j++) {
                    cnt[arr[x] ^ kOneArr[j]]++;
                }
            }
            for (int q = headr[x]; q > 0; q = nextq[q]) {
                int l = ql[q], r = qr[q], op = qop[q], id = qid[q];
                for (int j = l; j <= r; j++) {
                    ans[id] += 1LL * op * cnt[arr[j]];
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> k;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 2; i <= m; i++) {
            ans[query[i].id] += ans[query[i - 1].id];
        }
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

这里有个细节：k = 0 时 C(14, 0) = 1，配对值只有自己，pre[i] 统计的就是「和 arr[i] 相等的元素个数」；k = 7 时配对值有 3432 个，两遍扫描各要 3.4 × 10⁸ 次加法，这也是本题卡常的原因，代码里把配对值先收进 kOneArr 就是为了这段循环尽量紧凑。

八、题目2：区间逆序对

给定一个长度为 n 的数组，i < j 且 arr[i] > arr[j] 的 (i, j) 叫逆序对。m 条查询，每条给出 l r，打印 arr[l..r] 上的逆序对数量。1 ≤ n、m ≤ 10⁵，0 ≤ arr[i] ≤ 10⁹，测试链接 P5047。

骨架和题目1 完全一样，差别只有两处。一是配对关系有方向：pre[i] 加的是「已装元素里比 arr[i] 大的个数」，suf[i] 加的是「已装元素里比 arr[i] 小的个数」。二是值域到 10⁹，先离散化，第二次离线里查「已装元素中大于 v 的个数」如果每次用树状数组是 O(log n)，乘上任务枚举量 O(n√n) 会到 10⁸ 量级，改成值域分块：装一个元素 O(√V)，查一次 O(1)。

具体来说，装一个值 v 时，比 v 小的整块（块号小于 v 所在块）的 blockCnt 各加一，块内比 v 小的位置 numCnt 各加一；查询「已装元素里大于 x 的个数」时取 blockCnt[bi[x]] + numCnt[x]，一次加法就出来。块长取 √V，两边都是 O(√V) 和 O(1)。

离散化和分块的初始化：

void prepare() {
        for (int i = 1; i <= n; i++) {
            sorted[i] = arr[i];
        }
        sort(sorted + 1, sorted + n + 1);
        cntv = 1;
        for (int i = 2; i <= n; i++) {
            if (sorted[cntv] != sorted[i]) {
                sorted[++cntv] = sorted[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i] = kth(arr[i]);
        }
        int blen = (int)sqrt(n);
        int bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, cntv);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

值域分块的三个函数，左任务用 addLeftCnt（查「大于 x 的个数」），右任务用 addRightCnt（查「小于 x 的个数」）：

void addLeftCnt(int val) {
        for (int b = 1; b <= bi[val] - 1; b++) {
            blockCnt[b]++;
        }
        for (int i = bl[bi[val]]; i < val; i++) {
            numCnt[i]++;
        }
    }

    void addRightCnt(int val) {
        for (int b = bi[val] + 1; b <= bi[cntv]; b++) {
            blockCnt[b]++;
        }
        for (int i = val + 1; i <= br[bi[val]]; i++) {
            numCnt[i]++;
        }
    }

    long long getCnt(int val) {
        return blockCnt[bi[val]] + numCnt[val];
    }

compute 与题目1 同形，只把装值、查值换成上面三个函数：

void compute() {
        for (int i = 1; i <= n; i++) {
            pre[i] = pre[i - 1] + sum(cntv) - sum(arr[i]);
            add(arr[i], 1);
        }
        memset(tree + 1, 0, cntv * sizeof(int));
        for (int i = n; i >= 1; i--) {
            suf[i] = suf[i + 1] + sum(arr[i] - 1);
            add(arr[i], 1);
        }
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            if (winr < jobr) {
                addLeftOffline(winl - 1, winr + 1, jobr, -1, id);
                ans[id] += pre[jobr] - pre[winr];
            }
            if (winr > jobr) {
                addLeftOffline(winl - 1, jobr + 1, winr, 1, id);
                ans[id] -= pre[winr] - pre[jobr];
            }
            winr = jobr;
            if (winl > jobl) {
                addRightOffline(winr + 1, jobl, winl - 1, -1, id);
                ans[id] += suf[jobl] - suf[winl];
            }
            if (winl < jobl) {
                addRightOffline(winr + 1, winl, jobl - 1, 1, id);
                ans[id] -= suf[winl] - suf[jobl];
            }
            winl = jobl;
        }
        for (int x = 0; x <= n; x++) {
            if (x >= 1) {
                addLeftCnt(arr[x]);
            }
            for (int q = headl[x]; q > 0; q = nextq[q]) {
                int l = ql[q], r = qr[q], op = qop[q], id = qid[q];
                long long ret = 0;
                for (int j = l; j <= r; j++) {
                    ret += getCnt(arr[j]);
                }
                ans[id] += ret * op;
            }
        }
        memset(blockCnt, 0, sizeof(blockCnt));
        memset(numCnt, 0, sizeof(numCnt));
        for (int x = n + 1; x >= 1; x--) {
            if (x <= n) {
                addRightCnt(arr[x]);
            }
            for (int q = headr[x]; q > 0; q = nextq[q]) {
                int l = ql[q], r = qr[q], op = qop[q], id = qid[q];
                long long ret = 0;
                for (int j = l; j <= r; j++) {
                    ret += getCnt(arr[j]);
                }
                ans[id] += ret * op;
            }
        }
    }

九、复杂度分析

设块长为 √n，滑窗总距离 O((n + m)√n)，任务区间长度之和同样是这个量级。

环节题目1（k1 二元组）题目2（区间逆序对）
pre、suf 两遍扫描O(n · C(14, k))O(n log n)
莫队排序 + 滑窗生成任务O(m log m + (n + m)√n)O(m log m + (n + m)√n)
第二次离线：装元素O(n · C(14, k))O(n√n)
第二次离线：枚举任务区间O((n + m)√n)O((n + m)√n)
单次查询贡献O(1)O(1)
总计O((n + m)√n + n · C(14, k))O((n + m)√n)
空间O(n + m + 2¹⁴)O(n + m)

空间主要是四个数组：pre、suf 各 O(n)，任务链表 O(m)，值域计数 O(V)。任务用链式前向星存，每条查询最多生成两个任务，开 2m 个槽位。

十、最后

二次离线的核心就一句：把「和整个窗口的配对」从每次挪动里拆出来，攒成任务批量算。不做二次离线时题目1 是 O((n + m)√n · C(14, k))、题目2 是 O((n + m)√n · log n)；拆出来之后配对变成全程只做几遍扫描，滑窗部分只剩 O(1) 的加减。

代价是维护两份信息：pre、suf 各 O(n)，加一条任务链表 O(m)。下一页换第二种实现，只保留一份 pre，代码更少，代价是贡献的定义要重新设计。
