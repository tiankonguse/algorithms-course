优先队列

只关心「当前最小的那个数是谁」，用一棵完全二叉树存下所有数，插入和删除最小值都只要 O(log n)。

零、背景

前面几个结构都在对付区间：分块和树状数组管区间和，线段树连区间修改也能管。这一节换一类问题。

不关心区间，只关心一堆数里「当前最小的那个是谁」，而且这堆数还在不断加进来、删出去。

一、问题

有 n 堆果子，每堆重量不同。每次挑出最轻的两堆合并成一堆，花费是这两堆重量之和，新的一堆放回去，直到只剩一堆。问最小总花费是多少。

比如 5 堆，重量是 1、2、3、4、5。合 1 和 2 得 3，花 3；合 3 和 3 得 6，花 6；合 4 和 5 得 9，花 9；最后合 6 和 9 得 15，花 15。总花费 3 + 6 + 9 + 15 = 33。

把问题抽象一下，就是反复做三件事：

  • push：加入一个新数；
  • top：看一眼当前最小的数；
  • pop：删掉当前最小的数。

三种操作交替进行，一共 n 次上下。要算的是这 n 次的总耗时。

二、朴素做法

先看用普通数组随便放。push 放末尾，O(1)；top 和 pop 都得从头扫到尾找最小值，O(n)。

再换一种，始终保持数组有序。top 是 O(1)，最小值就在开头；pop 删掉开头后要把后面的元素整体前移，push 要先找位置再整体后移，两步都是 O(n)。

可以发现，两种写法各占一头，总有一个操作是 O(n)，n 次操作合起来是 O(n²)。每次操作前先排一遍序更贵，一次就要 O(n log n)。

其实并不需要整个数组有序，只要随时知道谁最小就够了。维护全部顺序是多余的开销。

三、只保证堆顶最小

优先队列就是这样一种结构：只暴露 push、top、pop 三个操作，不保证整体有序，只保证第 1 个位置永远最小。

实现它的经典结构是二叉堆，它满足两条要求：

  1. 结构性：是一棵完全二叉树，除最后一层外都是满的，最后一层从左往右紧挨着排。
  2. 堆性质：每个节点都 ≤ 它的两个孩子。

由堆性质可以直接推出，从根往下走任意一条路径，值都不会变小，所以最小值一定在根上。

第一条要求看着有点多余，换成普通二叉树为什么不行？看下面两张编号。

四、用数组存这棵完全二叉树

完全二叉树按从上到下、从左到右编号，编号是连续的，中间没有空洞，可以直接放进数组。

下面统一从下标 1 开始存，下标 0 空着不用，于是父子关系就是几句算术：

  • 下标 i 的父亲：i / 2（整除）；
  • 下标 i 的左孩子：2 × i；
  • 下标 i 的右孩子：2 × i + 1。

把鼠标移到节点上，看看它的父亲和孩子分别在哪个下标。

五、插入：新数往上浮

要插入一个新数，先把它放到数组末尾。这样完全二叉树的形状不会被破坏，只是堆性质可能不成立了，新数可能比它的父亲还小。

然后做上浮：不断拿它和父亲比较，比父亲小就交换，直到父亲更小或者到了堆顶。

下面往堆里插入 4，上浮只走了两层。

void push(int v) {
    heap[++sz] = v;              // 先放到末尾
    int i = sz;
    while (i > 1) {                  // 还没到堆顶
        int p = i / 2;               // 父亲的下标
        if (heap[p] <= heap[i]) break;  // 父亲更小，堆性质已经满足
        swap(heap[p], heap[i]);
        i = p;                       // 继续往上比
    }
}

n 个节点的完全二叉树高度是 ⌊log₂ n⌋，上浮最多走这么多层，所以插入是 O(log n)。

六、弹出最小值：堆顶往下沉

弹出时不能直接删掉堆顶，那样堆里就出现两个根，形状也乱了。做法是三步：

  1. 先把堆顶 heap[1] 取走，它就是最小值；
  2. 把最后一个元素搬到堆顶，这样形状仍然是一棵完全二叉树；
  3. 再做下沉：不断和两个孩子中较小的那个比较，比它大就交换，直到满足堆性质或者落到叶子。

第 3 步必须选较小的那个孩子。要是随便找个大孩子交换，它当上父亲以后仍然违反堆性质。

void pop() {
    heap[1] = heap[sz--];            // 最后一个元素搬到堆顶，长度减 1
    int i = 1;
    while (i * 2 <= sz) {              // 还有孩子
        int c = i * 2;                   // 左孩子
        if (c + 1 <= sz && heap[c+1] < heap[c]) c++;  // 右孩子更小就选右孩子
        if (heap[i] <= heap[c]) break;  // 已经比两个孩子都小
        swap(heap[i], heap[c]);
        i = c;                       // 继续往下比
    }
}

七、建堆：一次性把 n 个数摆好

如果一开始手里就有 n 个数，逐个 push 是 O(n log n)。更快的办法是先把所有数原样放进数组，再从最后一个非叶节点 n / 2 开始，倒着对每个位置做一次下沉。

为什么从 n / 2 开始？下标大于 n / 2 的节点都是叶子，没有孩子，天然满足堆性质，不用管。倒着做的好处是：处理某个节点时，它的左右子树已经是堆了，一次下沉就能让整棵子树变成堆。

单次下沉最贵是 O(log n)，但越靠底层的节点越多、下沉距离却越短：倒数第二层最多 n/4 个、最多下沉 1 层，倒数第三层最多 n/8 个、最多下沉 2 层。总代价是 n/4 × 1 + n/8 × 2 + n/16 × 3 + …，这个级数收敛，加起来小于 n，所以建堆是 O(n)。

void build(int a[], int n) {
    sz = n;
    for (int i = 1; i <= n; i++) heap[i] = a[i];  // 原样放进数组
    for (int i = n / 2; i >= 1; i--)                // 从最后一个非叶节点倒着下沉
        sinkDown(i);
}

八、代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100;
int heap[N];   // heap[1] 是堆顶（最小值），下标 0 空着不用
int sz = 0;    // 当前元素个数

// 上浮：把第 i 个位置的数往上交换到合适位置
void siftUp(int i) {
    while (i > 1) {
        int p = i / 2;
        if (heap[p] <= heap[i]) break;
        swap(heap[p], heap[i]);
        i = p;
    }
}

// 下沉：把第 i 个位置的数往下交换到合适位置
void sinkDown(int i) {
    while (i * 2 <= sz) {
        int c = i * 2;                                   // 左孩子
        if (c + 1 <= sz && heap[c+1] < heap[c]) c++;      // 取更小的孩子
        if (heap[i] <= heap[c]) break;
        swap(heap[i], heap[c]);
        i = c;
    }
}

// 插入一个数
void push(int v) {
    heap[++sz] = v;
    siftUp(sz);
}

// 看一眼最小值
int top() { return heap[1]; }

// 删除最小值
void pop() {
    heap[1] = heap[sz--];
    sinkDown(1);
}

// 用数组 a[1..n] 建堆
void build(int a[], int n) {
    sz = n;
    for (int i = 1; i <= n; i++) heap[i] = a[i];
    for (int i = n / 2; i >= 1; i--) sinkDown(i);
}

int main() {
    int a[] = {0, 5, 3, 8, 1, 9, 2, 7};  // a[0] 不用，实际是 7 个数
    build(a, 7);
    while (sz > 0) {                  // 不断取最小，得到升序输出
        cout << top() << " ";
        pop();
    }
    return 0;
}
// 输出：1 2 3 5 7 8 9

做题时可以直接用 STL，它内部就是二叉堆。

#include <queue>
priority_queue<int> q;                              // 默认大顶堆，top() 是最大值
priority_queue<int, vector<int>, greater<int>> q;   // 小顶堆，top() 是最小值

q.push(x);   // 插入，O(log n)
q.top();     // 取堆顶，O(1)
q.pop();     // 删除堆顶，O(log n)
q.size();    // 元素个数

九、复杂度分析

堆是一棵完全二叉树，n 个节点的高度是 ⌊log₂ n⌋，上浮和下沉都只沿一条从根到叶的路径走，最多走这么多层。

操作时间复杂度说明
建堆 buildO(n)自底向上逐个下沉，越靠底层节点越多但下沉越短
插入 pushO(log n)末尾放数后上浮，最多走树高
取最小值 topO(1)堆顶就是 heap[1]
删除最小值 popO(log n)末尾元素搬到堆顶后下沉
取走全部 n 个（堆排序）O(n log n)n 次 pop，每次 O(log n)

空间上只用一个数组 heap 存 n 个元素，加一个记录长度的变量，所有操作都是原地交换，额外空间 O(1)，算上数据本身是 O(n)。

回到开头的果子问题：n 次操作，朴素做法总耗时 O(n²)；用优先队列每次 O(log n)，总耗时 O(n log n)。

十、最后

堆换了个思路：不求整体有序，只守住「父 ≤ 子」这一条，于是插入和弹出都只要走一条从根到叶的路径，代价从 O(n) 降到 O(log n)。

代价是它只能给你最小值。想查第 k 小、想按值查找某个元素在不在，堆都做不了，那还是得回到有序结构上去。

另外 STL 的 priority_queue 默认是大顶堆，比较符号要反着写。要小顶堆就得多写两个模板参数，写错的话现象是「取出来的数越来越小」，一眼能看出来。
