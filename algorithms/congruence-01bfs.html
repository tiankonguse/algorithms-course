同余最短路：01bfs 与构造

上一页的图边权是任意正数，用 dijkstra。有的题边权只有 0 和 1，01bfs 的 O(V+E) 比 dijkstra 的 O(E log V) 快一截。最小数位和这道题，把「数位」翻译成「乘 10 免费、加 1 花 1」的图，答案就是 01bfs 第一次撞到余数 0 的代价。

零、01bfs：边权只有 0 和 1 的最短路

边权只有 0 和 1 时，把堆换成双端队列：松弛 0 权边得到的点塞队首，1 权边得到的点塞队尾。出队的点距离一定定了：队首永远比队尾小，0 权不会产生更小的「后来者」。这是 dijkstra 的特例，但省了 log，跑成 O(V+E)。

实现就一个 deque：pop_front 取点，0 权 push_front、1 权 push_back。一个点只出队一次（出过就标记），代价非负保证正确。

一、题3 最小数位和：把数位画成图

求 k 的正整数倍里，十进制数位和最小的那一个的数位和。k ≤ 10^5，直接枚举倍数不可能，答案对应的数可以大得离谱（k=19 时答案是 1000000001）。

构造一张图：点是余数 0..k−1，从数字 1 出发（余数 1、数位和 1）。两种走法：末尾补一个 0，数位和不变，边权 0；末尾这一位加 1，数位和加 1，边权 1。走出来的任何数都是合法的十进制数，代价就是它的数位和；反过来任何一个 k 的倍数都能逐位构造出来。所以第一次走到余数 0 时的代价，就是最小数位和。

这一步的巧妙在「加 1」花 1 的语义：它加的是当前最低位，不是整个数字加 1。数位和确实跟着 +1，不会出现 19→20 这种进位把数位和打下来的情况，因为加 1 永远发生在最低位之后新生成的那一位上。

用 01bfs：0 权（补 0）放队首、1 权（加 1）放队尾。首次到 0 就是答案。k ≤ 10^5，图 10^5 个点、2×10^5 条边，01bfs 线性过。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXK = 100001;

    int k;
    bool visitArr[MAXK];

    int bfs() {
    	deque<pair<int, int>> dq;
    	dq.push_back({1, 1});
    	while (!dq.empty()) {
    		auto cur = dq.front();
    		dq.pop_front();
    		int mod = cur.first, cost = cur.second;
    		if (!visitArr[mod]) {
    			visitArr[mod] = true;
    			if (mod == 0) {
    				return cost;
    			}
    			dq.push_front({(mod * 10) % k, cost});
    			dq.push_back({(mod + 1) % k, cost + 1});
    		}
    	}
    	return -1;
    }

    int main() {
    	cin >> k;
    	cout << bfs() << endl;
    	return 0;
    }

实测（对拍）：3000 组随机 k ∈ [2,30]，课程 01bfs 输出与「按数位和从 1 递增的 DP 判定是否存在 k 倍数」完全一致；k=19 的答案是 2（1000000001，枚举前 20 万倍根本看不到）。

二、题4 墨墨的等式：区间里数个数

n 种正数、每种任意个，统计 [l, r] 里能拼出的数有多少个。模取第一个非零数 x，每个 vi 连边 j → (j+vi) mod x 权 vi，dijkstra 跑出 dist[r] = 余 r 的最小可拼值。

计数用前缀相减：count(R) = 余数 r 的 (R−dist[r])/x+1 之和（dist[r] ≤ R 才贡献）。答案 = count(r) − count(l−1)。读入时 l 直接减 1，代码里 count 写两遍，一次套 r、一次套 l。

数值范围 ≤ 5×10^5 的模做图，l、r 到 10^12 不影响：图只按余数开，计数是纯算术。n ≤ 12，图 x 个点、n 组边，dijkstra 一次跑完。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 5000001;

    int n, x;
    long long l, r;

    int head[MAXN], nxt[MAXM], to[MAXM], cnt;
    long long weight[MAXM];
    long long distanceArr[MAXN];
    bool visitedArr[MAXN];

    void prepare() {
    	cnt = 1;
    	fill(head, head + x, 0);
    	fill(distanceArr, distanceArr + x, LLONG_MAX);
    	fill(visitedArr, visitedArr + x, false);
    }

    void addEdge(int u, int v, long long w) {
    	nxt[cnt] = head[u];
    	to[cnt] = v;
    	weight[cnt] = w;
    	head[u] = cnt++;
    }

    void dijkstra() {
    	priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> heap;
    	heap.push({0, 0});
    	distanceArr[0] = 0;
    	while (!heap.empty()) {
    		auto cur = heap.top();
    		heap.pop();
    		int u = cur.second;
    		long long w = cur.first;
    		if (visitedArr[u]) {
    			continue;
    		}
    		visitedArr[u] = true;
    		for (int ei = head[u], v; ei > 0; ei = nxt[ei]) {
    			v = to[ei];
    			if (!visitedArr[v] && distanceArr[v] > w + weight[ei]) {
    				distanceArr[v] = w + weight[ei];
    				heap.push({distanceArr[v], v});
    			}
    		}
    	}
    }

    long long compute() {
    	dijkstra();
    	long long ans = 0;
    	for (int i = 0; i < x; i++) {
    		if (r >= distanceArr[i]) {
    			ans += (r - distanceArr[i]) / x + 1;
    		}
    		if (l >= distanceArr[i]) {
    			ans -= (l - distanceArr[i]) / x + 1;
    		}
    	}
    	return ans;
    }

    int main() {
    	cin >> n >> l >> r;
    	l = l - 1;
    	x = 0;
    	for (int i = 1, vi; i <= n; i++) {
    		cin >> vi;
    		if (vi != 0) {
    			if (x == 0) {
    				x = vi;
    				prepare();
    			} else {
    				for (int j = 0; j < x; j++) {
    					addEdge(j, (j + vi) % x, vi);
    				}
    			}
    		}
    	}
    	cout << compute() << endl;
    	return 0;
    }

实测（对拍）：3000 组随机小用例（v 含 0，l、r ≤ 100），课程 dijkstra 版输出与「完全背包打表数 [l, r] 可拼个数」完全一致。v 全是 0 时图为空，答案 0：代码里 x 一直是 0，dijkstra 跑了个空图。

演示 · 墨墨的等式：dist 定下来，两个截断一减就是答案

总结

01bfs 是 dijkstra 在边权只有 0/1 时的线性特例：0 权塞队首、1 权塞队尾，出队即定值。

最小数位和把数位构造画成余数图：补 0 免费、最低位加 1 花 1，首次到余数 0 的代价就是答案；墨墨的等式直接在同余图上 dijkstra，用 count(r)−count(l−1) 数区间。

两道题都是「构造图 → 跑最短路 → 数答案」。下一种做法连图都不建：按 gcd 拆子环、每个子环转两圈，O(n·x) 跑完同余最短路。
