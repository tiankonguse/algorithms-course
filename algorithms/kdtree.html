K-D 树

点铺在平面上，一维的套路就都用不上了。K-D 树的办法是按某个维度找中位点把点集切成两半，左右各自再换一个维度切下去，每个节点额外记下整棵子树的包围盒。查询时拿包围盒做一次粗略估计，估计都拼不过当前答案，整棵子树就不用看了。

零、背景

前面那些结构基本都只管一维：树状数组管前缀和，线段树管区间，平衡树管大小顺序。换成平面上的点，问「离这个点最近的点有多远」「矩形里有多少个点」「点权加起来是多少」，一维的做法全都套不上。

K-D 树是给二维以及更高维准备的二叉搜索树。K 是维度数，竞赛里 K 常常是 2 或 3，二维最常见，这一节也主要在二维上讲。更高维的写法只是在维数下标上循环，没有本质区别。

前半段讲静态部分：点一次性给全，之后只查询。后半段讲点会一路插进来的动态写法，两种实现都给出，再配上几道形状各异的题目。

一、问题

平面最近点对。一共 n 个点，每个点给定坐标 (x, y)，输出距离最近的两个点之间的距离，保留四位小数。2 ≤ n ≤ 2 × 10⁵，0 ≤ x、y ≤ 10⁹。

下面一直用这 8 个点当例子：

编号12345678
坐标 (x, y)(2, 3)(5, 8)(9, 1)(4, 2)(7, 9)(1, 6)(8, 4)(3, 7)

手算几个距离就能找到答案：6 号到 8 号是 √5，1 号到 4 号也是 √5，2 号到 5 号还是 √5。再没有更近的了，答案就是 √5，约 2.2361。

二、朴素做法

两两算一遍，取最小，O(n²)。n = 2 × 10⁵ 时要比 2 × 10¹⁰ 次，肯定超时。

换个问法：对每个点求「除它自己之外最近的点」，一共 n 次查询，答案取最小。问题就落到「一次最近邻查询要多久」上。K-D 树把这一次查询压到平均 O(log n)，整个问题就跟着变成 O(n log n)。

三、交替选维度，把点切成一棵树

先按 x 找中位点，让它当根；x 比它小的进左子树，其余的进右子树。左右两侧各自按 y 找中位点当根，再下一层又回到 x。每一层换一个维度，这就是名字里那个 K。

「找中位点」这一步直接交给 nth_element：nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension}) 一次调用就把第 mid 小的那个放到 arr[mid]，摊还 O(n)。没有现成函数的环境里用随机选择算法手写，期望也是 O(n)。

也可以每个节点都算一下两维各自的方差，取方差大的那一维来切。空间分裂更接近方块，剪枝更狠，但每建一层都要把所有点扫两遍，实际很少用。

建一层的代价和这一层的点数成正比，递归深度 log n，整体 O(n log n)。

上面那 8 个点切完之后，根是 4 号 (4, 2)；左子树根是 6 号 (1, 6)，它的两个儿子是 1 号与 8 号；右子树根是 7 号 (8, 4)，左边挂着 3 号，右边挂着 2 号，2 号下面还有一个 5 号。

四、节点上记什么

除了自己的坐标和左右儿子，每个节点还要记 xmin、xmax、ymin、ymax，也就是能把整棵子树框起来的那个矩形，通常叫包围盒。查询时能不能剪枝，全看它。

还要不要别的，取决于题目问什么：数个数就存 siz，求点权和就存 sum，问最近/最远则只要包围盒就够了。

0 号节点代表空树，它的初值必须设成 xmin[0] = ymin[0] = +INF、xmax[0] = ymax[0] = -INF，否则 min 和 max 会把 0 掺和进来，包围盒算错。这一步在建树和第一次插入之前做，很容易漏。

五、粗略估计

有了包围盒，就能回答一个问题：查询点到这棵子树里「任何一个点」的距离，最少可能是多少。答案就是把查询点到这个矩形的距离算出来。查询点已经被套在矩形里，这个距离就是 0。

这个值是「子树里所有点到查询点距离」的下界，也是后面所有剪枝唯一的依据。

写成代码只有几行。横向的间隙先在 xmin、xmax 之间比一次，纵向同理，最后两个间隙各自平方加起来。

六、用估计剪枝

查询从根往下走，每到一个节点做三件事。

  1. 算查询点到当前节点的真实距离，更新答案 ans。
  2. 对左右两个儿子各算一次估计值 gl、gr。
  3. 只有估计值严格小于 ans 时才递归进去，并且先走估计值更小的那边。

第 3 条的两个细节都有讲究。先走小的那一边，是为了尽早把 ans 压小，ans 越小后面的剪枝越狠；用严格小于而非小于等于，是因为等于表示这棵子树里最好的情况也只能和当前答案打平，不会让答案变得更好，那就没有必要进去。

单次查询最差是 O(n)，也就是一路走进每个节点。但估计值只有在查询点离盒子很近时才可能小，实际通常走不了几层就停住。

八、平面最近点对

回到第一道题。答案初始化为 dist(1, 2)，然后对每个点跑一次第六节那套查询，全局取最小。有两个地方要留意。

一是查询里要跳过自己，也就是if (qi != i) 才更新答案，否则自己到自己的距离 0 会把答案直接钉死。二是答案为 0 时可以直接跳出循环，点重合了就不会有更近的。

不过这题 K-D 树不是正解。单次查询最差 O(n)，刻意构造的数据能让每个盒子的估计值都刚好卡在答案上、一棵子树也剪不掉，复杂度正确的做法是分治，计算几何专题会讲。

九、矩形查询为什么是 O(√n)

换一类问题：查矩形里有多少个点、点权之和是多少。这类查询不依赖答案好不好修剪，它有确定的上界。

走到节点时仍然是三种情况，按顺序判断：包围盒和查询矩形没交集，返回 0；包围盒被查询矩形整个包住，直接返回节点上存好的 sum 或 siz；否则看当前节点自己是否落在矩形里，再往两个儿子递归。

代价出在第三种情况上，也就是那些被查询矩形的边界「横穿」的区域。下面数一数这样的区域有多少。

把推导写完整。一个装着 n 个点的方块，往下走一组（先按 x 切、再按 y 切）之后变成 4 个方块，每个装 n / 4 个点。一条竖直的边界只会落进其中一列，也就是 2 个小方块。于是格子数满足递归式 T(n) = 2 · T(n/4) + O(1)，用 Master 公式算出来 T(n) = O(n^(log₄ 2)) = O(√n)。

换个写法也行：设最深的一组编号为 h，那时候有 4ʰ 个方块、每条边界穿过 2ʰ 个。方块里的点降到一个时停止拆分，也就是 4ʰ = n，于是 2ʰ = √n。各层加起来是 1 + 2 + 4 + ⋯ + 2ʰ，一个等比数列，被最后一项卡住，总共 O(√n)。

推广到 K 维，每 K 层算一组，一组之后区域数变成 2ᴷ 份，单次正交范围查询是 O(n^(1 − 1/K))。

十、点会插进来

建好的树不会永远够用。点一路插进来，树会往一侧长偏，包围盒跟着变大，框住的空白越来越多，剪枝渐渐失效。所以要维持它的形状。

有人会问能不能像普通平衡树那样转一圈。不行：平衡树能旋转，是因为所有节点共用同一个排序标准，转完之后中序还是有序的。K-D 树每层换维度，排序标准不统一，旋转会把节点挪到别的深度上，它原本承担的那个维度的划分关系就没了。替罪羊树不靠旋转，失衡就把整棵子树收集起来重建一次，正好合适。

于是有两种维持办法。

替罪羊树的方式是最推荐的那一版。始终只维护一棵树，只有一个根，查询只在一棵树上剪枝，效果稳定，也容易往下扩展出删除操作和树套树。代价是实现稍复杂，而且平衡因子允许左右存在一定比例的不平衡，理论上不严格保证矩形查询的 O(√n)，但一般够用。

二进制分组的方式另有一套思路：把总的点数按二进制拆成若干组，每组节点数是 2 的幂，每组单独一棵静态 K-D 树。新来的点自成一个大小为 1 的组，然后像二进制进位一样不断把相邻组合并。单次插入摊还 O(log² n)。

二进制分组的优点是每组都用静态建树一次成型，实现简单，适合「一棵动态 K-D 树、只有插入」的场景。缺点也清楚：一棵树被拆成好几棵，查询要挨个访问，剪枝不能跨组，常数比替罪羊树差；要做删除、要做树套树就很难受了。此外还有根号重构的路子，复杂度更高，这里不再展开。

十一、替罪羊树方式的插入与重建

插入的形状和普通二叉搜索树一样：拿新节点从根往下比，按当前层的维度决定往左还是往右，走到空位就挂上去，回溯时逐个 maintain。

回溯的每一步都检查一下当前节点是否失衡，判据是 ALPHA * siz[i] >= max(siz[ls[i]], siz[rs[i]])，ALPHA 一般取 0.7。失衡就记下这棵子树的根 top、它的父亲 topFather、它挂在父亲的哪一侧 topSide，以及它这一层该用哪个维度 topDimension。

这个记录是覆盖式的，而回溯是从叶子往根走的，所以最后留下的是最高的那个失衡节点。重建它，就能一次性把这一整条路径上的失衡都解决掉。

重建本身很简单：对 top 做一次 dfs 把节点收集进临时数组，用静态建树那套流程重出一棵子树，再按 topFather 和 topSide 接回去。topFather 为 0 说明重建的是整棵树，直接换根。

重建的代价是「子树节点数 × log」，比普通替罪羊树的重构多一个 log，摊到一次插入上是 O(log² n)。

十二、半平面也是区域

范围不一定非得是与坐标轴平行的矩形。巧克力王国这道题给的是 a · x + b · y < c，一条斜线把平面劈成两半。

思路完全一样，只要能回答「这棵子树里 a · x + b · y 最小可能是多少、最大可能是多少」。做法是分别算四个分量：minv = min(a·xmin, a·xmax) + min(b·ymin, b·ymax)，maxv = max(a·xmin, a·xmax) + max(b·ymin, b·ymax)。minv ≥ c 说明这一整棵都不可能满足，返回 0；maxv < c 说明全都满足，直接返回存好的 sum。

a、b 可能为负，这时候 min(a·xmin, a·xmax) 对应的不再是 xmin 那个角。所以必须用 min/max 把四种组合都算一遍，不能图省事固定取左下角。

十三、三维偏序

n 个对象，每个有 a、b、c 三个属性。f(i) 是满足 aⱼ ≤ aᵢ 且 bⱼ ≤ bᵢ 且 cⱼ ≤ cᵢ 且 j ≠ i 的 j 的个数，最后统计 f(i) = d 的 i 有多少个。

先把所有对象按 a 从小到大排一遍。排完之后，位置靠前的对象它的 a 一定不大于靠后的，于是 a 这一维可以不管了，剩下 b、c 两维正是 K-D 树熟悉的东西。

a 相等的那几个要当成一组处理：先把整组都插进 K-D 树，然后再逐个查询。如果插一个查一个，组内的对象之间就互相漏掉了。查询返回的是 ≤ 的个数，里面包含对象自己，减 1 才是 f(i)。

十四、换个度量：曼哈顿距离

前面的例子都用欧氏距离。天使玩偶这道题规定的距离是 |x₁ − x₂| + |y₁ − y₂|，其余都一样：动态加点，查最近。

要改的只有两处。真实距离改成两个差的绝对值之和，估计函数也要跟着改成同一度量的下界：横向间隙就是 |qx − xmin| 与 |qx − xmax| 里较大的那个，纵向同理，两个加起来。

十五、代码

下面是静态 K-D 树配上最近点对那道题的完整实现。建树有两份，build1 是交替选维度，build2 是按方差选维度，主函数里用 build1。

#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const int MAXN = 200001;
const ll INF = 1LL << 60;
int n;

ll x[MAXN];
ll y[MAXN];
int arr[MAXN];

int root;
int ls[MAXN];
int rs[MAXN];
ll xmin[MAXN];
ll xmax[MAXN];
ll ymin[MAXN];
ll ymax[MAXN];

ll ans;

int compareNode(int i, int j, int dimension) {
    ll v1 = dimension == 0 ? x[i] : y[i];
    ll v2 = dimension == 0 ? x[j] : y[j];
    return v1 == v2 ? 0 : v1 < v2 ? -1 : 1;
}

struct Cmp {
    int dimension;

    bool operator()(int a, int b) const {
        return compareNode(a, b, dimension) < 0;
    }
};

void maintain(int i) {
    xmin[i] = min(x[i], min(xmin[ls[i]], xmin[rs[i]]));
    xmax[i] = max(x[i], max(xmax[ls[i]], xmax[rs[i]]));
    ymin[i] = min(y[i], min(ymin[ls[i]], ymin[rs[i]]));
    ymax[i] = max(y[i], max(ymax[ls[i]], ymax[rs[i]]));
}

int build1(int l, int r, int dimension) {
    if (l > r) {
        return 0;
    }
    int mid = (l + r) >> 1;
    nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension});
    int rt = arr[mid];
    ls[rt] = build1(l, mid - 1, dimension ^ 1);
    rs[rt] = build1(mid + 1, r, dimension ^ 1);
    maintain(rt);
    return rt;
}

double variance(int l, int r, int dimension) {
    double siz = r - l + 1, sum = 0, avg = 0, dif = 0;
    for (int i = l; i <= r; i++) {
        sum += dimension == 0 ? x[arr[i]] : y[arr[i]];
    }
    avg = sum / siz;
    sum = 0;
    for (int i = l; i <= r; i++) {
        dif = (dimension == 0 ? x[arr[i]] : y[arr[i]]) - avg;
        sum += dif * dif;
    }
    return sum / siz;
}

int build2(int l, int r) {
    if (l > r) {
        return 0;
    }
    int mid = (l + r) >> 1;
    int dimension = variance(l, r, 0) >= variance(l, r, 1) ? 0 : 1;
    nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension});
    int rt = arr[mid];
    ls[rt] = build2(l, mid - 1);
    rs[rt] = build2(mid + 1, r);
    maintain(rt);
    return rt;
}

ll dist(int qi, int i) {
    ll dx = x[qi] - x[i];
    ll dy = y[qi] - y[i];
    return dx * dx + dy * dy;
}

ll guess(int qi, int i) {
    if (i == 0) {
        return INF;
    }
    ll qx = x[qi];
    ll qy = y[qi];
    ll dx = qx < xmin[i] ? (xmin[i] - qx) : (qx > xmax[i] ? (qx - xmax[i]) : 0);
    ll dy = qy < ymin[i] ? (ymin[i] - qy) : (qy > ymax[i] ? (qy - ymax[i]) : 0);
    return dx * dx + dy * dy;
}

void updateAns(int qi, int i) {
    if (i == 0) {
        return;
    }
    if (qi != i) {
        ans = min(ans, dist(qi, i));
    }
    ll gl = guess(qi, ls[i]);
    ll gr = guess(qi, rs[i]);
    if (gl < gr) {
        if (gl < ans) {
            updateAns(qi, ls[i]);
        }
        if (gr < ans) {
            updateAns(qi, rs[i]);
        }
    } else {
        if (gr < ans) {
            updateAns(qi, rs[i]);
        }
        if (gl < ans) {
            updateAns(qi, ls[i]);
        }
    }
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%lld%lld", &x[i], &y[i]);
        arr[i] = i;
    }
    xmin[0] = ymin[0] = INF;
    xmax[0] = ymax[0] = -INF;
    root = build1(1, n, 0);
    // root = build2(1, n);
    ans = dist(1, 2);
    for (int i = 1; i <= n; i++) {
        updateAns(i, root);
        if (ans == 0) {
            break;
        }
    }
    printf("%.4f\n", sqrt((double) ans));
    return 0;
}

巧克力王国那题的结构完全一样，只是把「无交集 / 被包住」的两个判断换成了对 a · x + b · y 的极值比较。

#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const int MAXN = 50001;
const ll INF = 1LL << 60;
int n, m;

ll x[MAXN];
ll y[MAXN];
ll v[MAXN];
int arr[MAXN];

int root;
int ls[MAXN];
int rs[MAXN];

ll sum[MAXN];
ll xmin[MAXN];
ll xmax[MAXN];
ll ymin[MAXN];
ll ymax[MAXN];

int compareNode(int i, int j, int dimension) {
    ll v1 = dimension == 0 ? x[i] : y[i];
    ll v2 = dimension == 0 ? x[j] : y[j];
    return v1 == v2 ? 0 : v1 < v2 ? -1 : 1;
}

struct Cmp {
    int dimension;

    bool operator()(int a, int b) const {
        return compareNode(a, b, dimension) < 0;
    }
};

void maintain(int i) {
    sum[i] = v[i] + sum[ls[i]] + sum[rs[i]];
    xmin[i] = min(x[i], min(xmin[ls[i]], xmin[rs[i]]));
    xmax[i] = max(x[i], max(xmax[ls[i]], xmax[rs[i]]));
    ymin[i] = min(y[i], min(ymin[ls[i]], ymin[rs[i]]));
    ymax[i] = max(y[i], max(ymax[ls[i]], ymax[rs[i]]));
}

int build(int l, int r, int dimension) {
    if (l > r) {
        return 0;
    }
    int mid = (l + r) >> 1;
    nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension});
    int rt = arr[mid];
    ls[rt] = build(l, mid - 1, dimension ^ 1);
    rs[rt] = build(mid + 1, r, dimension ^ 1);
    maintain(rt);
    return rt;
}

ll query(ll a, ll b, ll c, int i) {
    if (i == 0) {
        return 0;
    }
    ll ax1 = xmin[i] * a;
    ll ax2 = xmax[i] * a;
    ll by1 = ymin[i] * b;
    ll by2 = ymax[i] * b;
    ll minv = min(ax1, ax2) + min(by1, by2);
    ll maxv = max(ax1, ax2) + max(by1, by2);
    if (minv >= c) {
        return 0;
    }
    if (maxv < c) {
        return sum[i];
    }
    ll ans = 0;
    if (a * x[i] + b * y[i] < c) {
        ans += v[i];
    }
    ans += query(a, b, c, ls[i]);
    ans += query(a, b, c, rs[i]);
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> x[i] >> y[i] >> v[i];
        arr[i] = i;
    }
    xmin[0] = ymin[0] = INF;
    xmax[0] = ymax[0] = -INF;
    root = build(1, n, 0);
    ll a, b, c;
    for (int i = 1; i <= m; i++) {
        cin >> a >> b >> c;
        cout << query(a, b, c, root) << "\n";
    }
    return 0;
}

下面是动态版本，用的是替罪羊树的方式，对应强制在线的那道矩形求和。插入沿路径走，回溯检查失衡，插完重建一次。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 200001;
const int INF = 1 << 30;
int n;

int x[MAXN];
int y[MAXN];
int v[MAXN];

int cntkdt;
int root;
int ls[MAXN];
int rs[MAXN];

int siz[MAXN];
int sum[MAXN];
int xmin[MAXN];
int xmax[MAXN];
int ymin[MAXN];
int ymax[MAXN];

double ALPHA = 0.7;
int top;
int topFather;
int topSide;
int topDimension;

int arr[MAXN];
int treeSiz;

int init(int qx, int qy, int qv) {
    cntkdt++;
    x[cntkdt] = qx;
    y[cntkdt] = qy;
    v[cntkdt] = qv;
    ls[cntkdt] = rs[cntkdt] = 0;
    siz[cntkdt] = 1;
    sum[cntkdt] = qv;
    xmin[cntkdt] = xmax[cntkdt] = qx;
    ymin[cntkdt] = ymax[cntkdt] = qy;
    return cntkdt;
}

void maintain(int i) {
    siz[i] = 1 + siz[ls[i]] + siz[rs[i]];
    sum[i] = v[i] + sum[ls[i]] + sum[rs[i]];
    xmin[i] = min(x[i], min(xmin[ls[i]], xmin[rs[i]]));
    xmax[i] = max(x[i], max(xmax[ls[i]], xmax[rs[i]]));
    ymin[i] = min(y[i], min(ymin[ls[i]], ymin[rs[i]]));
    ymax[i] = max(y[i], max(ymax[ls[i]], ymax[rs[i]]));
}

int compareNode(int i, int j, int dimension) {
    int v1 = dimension == 0 ? x[i] : y[i];
    int v2 = dimension == 0 ? x[j] : y[j];
    return v1 == v2 ? 0 : v1 < v2 ? -1 : 1;
}

struct Cmp {
    int dimension;

    bool operator()(int a, int b) const {
        return compareNode(a, b, dimension) < 0;
    }
};

int build(int l, int r, int dimension) {
    if (l > r) {
        return 0;
    }
    int mid = (l + r) >> 1;
    nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension});
    int rt = arr[mid];
    ls[rt] = build(l, mid - 1, dimension ^ 1);
    rs[rt] = build(mid + 1, r, dimension ^ 1);
    maintain(rt);
    return rt;
}

bool balance(int i) {
    return ALPHA * siz[i] >= max(siz[ls[i]], siz[rs[i]]);
}

void dfs(int i) {
    if (i != 0) {
        arr[++treeSiz] = i;
        dfs(ls[i]);
        dfs(rs[i]);
    }
}

void rebuild() {
    if (top != 0) {
        treeSiz = 0;
        dfs(top);
        int newRoot = build(1, treeSiz, topDimension);
        if (topFather == 0) {
            root = newRoot;
        } else if (topSide == 1) {
            ls[topFather] = newRoot;
        } else {
            rs[topFather] = newRoot;
        }
    }
}

int add(int insertNode, int u, int fa, int side, int dimension) {
    if (u == 0) {
        return insertNode;
    }
    if (compareNode(insertNode, u, dimension) <= 0) {
        ls[u] = add(insertNode, ls[u], u, 1, dimension ^ 1);
    } else {
        rs[u] = add(insertNode, rs[u], u, 2, dimension ^ 1);
    }
    maintain(u);
    if (!balance(u)) {
        top = u;
        topFather = fa;
        topSide = side;
        topDimension = dimension;
    }
    return u;
}

void add(int qx, int qy, int qv) {
    top = topFather = topSide = topDimension = 0;
    int insertNode = init(qx, qy, qv);
    root = add(insertNode, root, 0, 0, 0);
    rebuild();
}

int query(int x1, int y1, int x2, int y2, int i) {
    if (i == 0) {
        return 0;
    }
    if (xmax[i] < x1 || x2 < xmin[i] || ymax[i] < y1 || y2 < ymin[i]) {
        return 0;
    }
    if (x1 <= xmin[i] && xmax[i] <= x2 && y1 <= ymin[i] && ymax[i] <= y2) {
        return sum[i];
    }
    int ans = 0;
    if (x1 <= x[i] && x[i] <= x2 && y1 <= y[i] && y[i] <= y2) {
        ans += v[i];
    }
    ans += query(x1, y1, x2, y2, ls[i]);
    ans += query(x1, y1, x2, y2, rs[i]);
    return ans;
}

int query(int x1, int y1, int x2, int y2) {
    return query(x1, y1, x2, y2, root);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    xmin[0] = ymin[0] = INF;
    xmax[0] = ymax[0] = -INF;
    int op, a, b, c, d, lastAns;
    cin >> op;
    lastAns = 0;
    while (op != 3) {
        cin >> a >> b >> c;
        a ^= lastAns;
        b ^= lastAns;
        c ^= lastAns;
        if (op == 1) {
            add(a, b, c);
        } else {
            cin >> d;
            d ^= lastAns;
            lastAns = query(a, b, c, d);
            cout << lastAns << "\n";
        }
        cin >> op;
    }
    return 0;
}

换成二进制分组只需要改增删两处：add 的时候把前面的组合掉重出，query 的时候挨棵访问。

void add(int qx, int qy, int qv) {
    cntkdt++;
    x[cntkdt] = qx;
    y[cntkdt] = qy;
    v[cntkdt] = qv;
    arr[cntkdt] = cntkdt;
    int p = 0;
    while (root[p] != 0) {
        root[p++] = 0;
    }
    root[p] = build(cntkdt - (1 << p) + 1, cntkdt, 0);
}

int query(int x1, int y1, int x2, int y2, int i) {
    if (i == 0) {
        return 0;
    }
    if (xmax[i] < x1 || x2 < xmin[i] || ymax[i] < y1 || y2 < ymin[i]) {
        return 0;
    }
    if (x1 <= xmin[i] && xmax[i] <= x2 && y1 <= ymin[i] && ymax[i] <= y2) {
        return sum[i];
    }
    int ans = 0;
    if (x1 <= x[i] && x[i] <= x2 && y1 <= y[i] && y[i] <= y2) {
        ans += v[i];
    }
    ans += query(x1, y1, x2, y2, ls[i]);
    ans += query(x1, y1, x2, y2, rs[i]);
    return ans;
}

int query(int x1, int y1, int x2, int y2) {
    int ans = 0;
    for (int p = 0; p < MAXP; p++) {
        ans += query(x1, y1, x2, y2, root[p]);
    }
    return ans;
}

最后是 K 维加上懒更新的核心几段。区域整体被包住时不往下下发，只在节点上打一个标记；往下走之前必须先 down 一次。

void lazy(int i, ll v) {
    if (i != 0) {
        val[i] += v;
        sum[i] += v * siz[i];
        addTag[i] += v;
    }
}

void down(int i) {
    if (addTag[i] != 0) {
        lazy(ls[i], addTag[i]);
        lazy(rs[i], addTag[i]);
        addTag[i] = 0;
    }
}

bool outside(int i) {
    for (int d = 0; d < k; d++) {
        if (maxv[i][d] < qx[d] || qy[d] < minv[i][d]) {
            return true;
        }
    }
    return false;
}

bool covered(int i) {
    for (int d = 0; d < k; d++) {
        if (qx[d] > minv[i][d] || qy[d] < maxv[i][d]) {
            return false;
        }
    }
    return true;
}

bool pointIn(int i) {
    for (int d = 0; d < k; d++) {
        if (qx[d] > pos[i][d] || qy[d] < pos[i][d]) {
            return false;
        }
    }
    return true;
}

void addValue(int i) {
    if (i == 0) {
        return;
    }
    if (outside(i)) {
        return;
    }
    if (covered(i)) {
        lazy(i, qv);
        return;
    }
    if (pointIn(i)) {
        val[i] += qv;
    }
    down(i);
    addValue(ls[i]);
    addValue(rs[i]);
    maintain(i);
}

ll querySum(int i) {
    if (i == 0) {
        return 0;
    }
    if (outside(i)) {
        return 0;
    }
    if (covered(i)) {
        return sum[i];
    }
    ll ans = 0;
    if (pointIn(i)) {
        ans += val[i];
    }
    down(i);
    ans += querySum(ls[i]);
    ans += querySum(rs[i]);
    return ans;
}

十六、复杂度分析

操作时间复杂度
静态建树（交替选维度）O(n log n)
静态建树（按方差选维度）O(n log² n)
单次最近 / 第 k 远查询O(log n) 平均，O(n) 最差
二维矩形范围查询（严格均衡）O(√n)
K 维正交范围查询O(n^(1 − 1/K))
替罪羊树方式单次插入O(log² n) 摊还
替罪羊树方式单次重构O(k log k)，k 是子树大小
二进制分组单次插入O(log² n) 摊还
二进制分组单次查询O(√n)
朴素做法（两两枚举对照）O(n²)
静态 K-D 树额外空间O(n)

最近查询那一行要稍微说一句。O(log n) 说的是数据分布正常时的表现，它依赖剪枝；对手可以针对某个查询点构造一批框得很扁的节点，让估计值全都绕不过答案，那时就是 O(n)。所以这一条不能当复杂度保证来用。

矩形查询那一行是有保证的，前提是树本身足够均衡，也就是每层都严格按中位点切开。二进制分组每组都用静态方式一次建成，这个前提天然成立；替罪羊树方式允许左右存在一定比例的不平衡，严格说这个上界不成立，实际很少出问题。

空间上，静态 K-D 树只有 n 个节点，每个节点存自己的坐标、左右儿子、四个包围盒边界，外加一个聚合值，十个左右的 int，n = 2 × 10⁵ 时不到十兆。动态版本也是 n 个节点，重建是复用原节点而不是新建，不会增长。

十七、容易写错的地方

  • 0 号节点的初值必须设成 xmin[0] = ymin[0] = +INF、xmax[0] = ymax[0] = -INF，而且要在建树或第一次插入之前做。忘了设，maintain 里的 min、max 会把 0 掺进来，包围盒算错，剪枝跟着全线失准。
  • 估计函数和真实距离必须是同一个度量。曼哈顿距离的题目不能直接沿用欧氏版本那套 dx² + dy²，看起来只差一个平方，猜出来的数根本不是下界，答案会偏大。
  • 剪枝的方向要看需求。求最近用 guess < ans 才继续；求第 k 远要反过来，堆满之后只在 guess >= heap.top().dist 时才敢进去。方向搞反，不是答案错就是退化成遍历整棵树。
  • 最近点对里 updateAns 记得跳过自己。查询 i 号点的时候一定会走到节点 i 本身，不跳过它，它到自己的距离 0 会立刻把答案钉死。
  • 重建前要把懒标记下发。dfs 收集节点的那个地方必须先 down(i)，否则收上来的 val 是还没下发下去的旧值，重建出来的树从一开始就是错的。
  • 替罪羊树的 top 系列变量在每次插入开头要清零。它们是覆盖式赋值，如果插入路径上没有节点失衡，上一次留下的值会把一棵好端端的子树重建掉。
  • 三维偏序里同一组 a 必须「先全插再全查」。一个个插查交替，组内之间会互相漏掉；查询的结果还要减 1，去掉自己。
  • 坐标到 10⁹ 时，欧氏距离的平方会到 10¹⁸ 量级，要用 long long。写 int 会在读入阶段就溢出。

十八、最后

K-D 树做的事情说穿了就两步：把空间一刀一刀切成盒，让每个节点报告自己那个盒的范围；查询时先估一个下界，估都估不过当前答案就整棵跳过。

它的强项和弱项是一回事。数据分布好、空间特征明显，一次剪枝能砍掉一大片，跑得比很多「复杂度正确」的做法还快；反过来，对手能设计出让你每一片都得进去看的结构，这时候它就是骗分技巧而不是正解。做题时先看清时限和题面有没有强调复杂度。

再往后，它的用法还有两个方向。给每个区域配一个虚点，可以把「一条边连向一片区域内的所有点」压成 O(m√n) 条边；把维度拆开，外层挂树状数组管第一维、每个下标背后一棵 K-D 树管剩下两维，就是树套树。这两件事分别在K-D 树优化建图和树套树里讲。
