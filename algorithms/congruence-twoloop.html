同余最短路：背包转两圈

前两页的最短路都建了图。这页把图拆了：按 gcd 把余数分成几个子环，每个子环转两圈，O(n·x) 预处理完同余最短路，查询 O(1)。体积 10^5、查询 10^12 的背包题靠它过。不建图，直接转圈松弛价值补偿。

零、子环与两圈：不建图的松弛

目标还是算 dist[r]（余 r 的最小可拼值 / 最优价值），但换个实现。观察转移 j → (j+v) mod x：所有边跳的余数差都是 v 的倍数，而 gcd(v, x) = d 时，(j+v) mod x 只会在 j 所在的那个模 d 子环里转。所以整个图被拆成 d 个互不相通的子环，每个子环是 x/d 个点首尾相接的环。

在一个环上做松弛，转一圈不够：松弛沿环的单向传播，起点 j 自己的更新发生在第一圈的末尾，它影响不到环里排在它前面的点。转两圈，环首尾的传播才补上。这就是「两次转圈法」名字的由来：每个子环从 j 出发，沿 +v 走，走满两圈。

复杂度：对每个物品 i，gcd(v[i], x) 个子环、每环 x/gcd 个点走两圈，一圈 O(n·x) 总松弛，空间只一个 dist 数组。比 dijkstra 的 O(E log V) 省掉 log，还省了建图。

一、题5 背包：价值补偿怎么转

题面：n 种物品（体积 v[i]、价值 c[i]，每种无限），m 条查询 jobv ∈ [10^11, 10^12]，问恰好凑满 jobv 的最大价值和，凑不满输出 -1。jobv 大到 10^12，普通完全背包的二维 DP 想都别想。

先挑一个「基准物品」：性价比（c/v）最高的那个，记体积 x、价值 y。把体积的余数图转圈，但 dp[r] 存的不是「最小体积」，是补偿：总体积先用基准物品铺满，替换掉若干基准物品、加入其他物品后，剩余体积（对 x 取模）为 r 时的最大价值净变化。

转移一行看明白：加入物品 i（体积 v[i]、价值 c[i]），新剩余 = (cur+v[i]) mod x；因为总体积不变，多占的 (cur+v[i])/x 个体积要从基准物品里扣掉，每个基准物品价值 y，所以净补偿 = dp[cur] − ((cur+v[i])/x)·y + c[i]，取 max。dp[0] = 0，其余初始为负无穷。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100001;

    long long inf = LLONG_MIN;
    int v[MAXN], c[MAXN];
    long long dp[MAXN];
    int n, m, x, y;

    int gcd(int a, int b) {
    	return b == 0 ? a : gcd(b, a % b);
    }

    void compute() {
    	fill(dp, dp + x, inf);
    	dp[0] = 0;
    	for (int i = 1; i <= n; i++) {
    		if (v[i] != x) {
    			int d = gcd(v[i], x);
    			for (int j = 0; j < d; j++) {
    				for (int cur = j, next, circle = 0; circle < 2; circle += cur == j ? 1 : 0) {
    					next = (cur + v[i]) % x;
    					if (dp[cur] != inf) {
    						dp[next] = max(dp[next], dp[cur] - (long long)((cur + v[i]) / x) * y + c[i]);
    					}
    					cur = next;
    				}
    			}
    		}
    	}
    }

    int main() {
    	cin >> n >> m;
    	double best = 0, ratio;
    	for (int i = 1; i <= n; i++) {
    		cin >> v[i] >> c[i];
    		ratio = (double)c[i] / v[i];
    		if (ratio > best) {
    			best = ratio;
    			x = v[i];
    			y = c[i];
    		}
    	}
    	compute();
    	long long jobv;
    	for (int i = 1; i <= m; i++) {
    		cin >> jobv;
    		int mod = (int)(jobv % x);
    		if (dp[mod] == inf) {
    			cout << "-1" << endl;
    		} else {
    			cout << jobv / x * y + dp[mod] << endl;
    		}
    	}
    	return 0;
    }

查询 O(1)：jobv 的余数 r = jobv mod x；dp[r] 是负无穷说明凑不出，输出 -1；否则答案 = (jobv/x)·y + dp[r]：基准铺满的价值加上补偿。

实测（对拍）：3000 组随机小用例（n ≤ 6，v ∈ [2,10]，c ∈ [1,8]，jobv ≤ 60），转圈输出与「完全背包打表求恰体积最大价值」完全一致。有个细节：基准必须是性价比最高的物品，不是体积最小的。补偿定义要求「先用基准铺满」是最优起点，便宜又占地方的基准会让补偿算成负的没意义。

总结

两次转圈法是同余最短路的第三种实现：不建图，按 gcd(v[i], x) 拆子环，每个子环单向走两圈松弛。两圈的原因很具体：环上松弛沿单向传播，起点在第一圈末尾才更新，第二圈补上首尾。

背包题把它用到极致：性价比最高的物品当基准，dp[r] 存「替换基准后的价值补偿」，查询拆成 (jobv/x)·y + dp[jobv mod x]。三种实现（dijkstra 任意边权、01bfs 0/1 边权、转两圈不建图）挑着用，同余最短路这一页就齐了。
