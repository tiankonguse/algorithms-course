线段树优化建图

有一类最短路题，要加的边不是一个点连一个点，而是一个点连一整段区间，或者两段区间互相连。一条条地连会到 O(n²) 条边，撑不住。办法是先让「区间」在图上有个代表节点，把批量连边压到 O(log n) 条。

零、背景

最短路、连通性、拓扑排序这些算法，前提都是先把图建出来。通常边是题目直接给的，一条条加就行。

但有一类题，边是「批量」的：从一个点连向一段下标区间，一段区间连向一个点，甚至一段区间连向另一段区间。

n 到 10⁵ 时，一次批量操作就涉及 O(n) 甚至 O(n²) 条边，总边数直接爆掉。优化的方向只有一个：不让每个点各自连边，而是给「一段区间」一个自己的节点，连到区间就等于连到那个节点。

一、问题

下面三种批量连边，后面几乎所有题都是它们的变体。设点都在数轴上排成一排，用下标 1 到 n 标识。

具体来说，第一种是点连区间：点 x 到区间 [l, r] 里的每个点，各加一条边权 w 的边。

第二种是区间连点：区间 [l, r] 里的每个点，各向点 x 连一条边权 w 的边。

第三种是区间连区间：区间 [a, b] 里的每个点，都向区间 [c, d] 里的每个点连一条边，常带同一个边权 w。

再往后还有更一般的形式：把「区间」换成树上一段连续路径，或者一个点向上的一段范围。结构换了，思路是一样的，留到后面一页。

二、朴素做法

直接照题意加边。点连区间就循环区间里的每个点加一条边，区间连点同理，区间连区间就是两层循环，长度相乘条边。

单次点连区间 O(n)，单次区间连区间 O(n²)。n 和 q 都到 10⁵ 时，最坏情况是 10¹⁰ 条边，内存开不下，时间更不用谈。

而且就算边数勉强开下，跑一次 Dijkstra 也要 O(m log n)，m 大了照样超时。所以必须从建边这一步减量，不能指望后面的算法救场。

三、线段树优化建图：出树与入树

把下标 1 到 n 建成一棵线段树，每个节点对应一段区间。区间连边就落在这棵树的节点上。

需要两棵树，方向相反。可以发现，一棵树只能负责一个方向的「收」或「散」，所以要两棵。

第一棵叫出树：孩子指向父亲，边权 0。真实点是叶子，信息顺着 0 边往上走，能汇到某个区间节点上。它负责把一段区间「收」成一个点，用于区间连点。

第二棵叫入树：父亲指向孩子，边权 0。从某个区间节点出发，顺着 0 边往下走，能到达区间里每个叶子。它负责把一个点「散」到一段区间，用于点连区间。

两棵树的叶子是同一批真实点，编号共用；只有内部节点是新增的辅助点，一共 O(n) 个。

四、一次连边的写法

点 x 连区间 [l, r]：在入树上把 [l, r] 拆成不超过 2 log n 个节点，x 各连一条边权 w 的边过去。顺着入树的 0 边往下，就覆盖了整段区间。

区间 [l, r] 连点 x：在出树上拆成同样多的节点，每个节点连一条边权 w 的边到 x。

区间连区间：新建两个辅助点 u、v。出树上 [a, b] 拆出的节点连到 u，u 连 v 带边权 w，v 连到入树上 [c, d] 拆出的节点。这样一段区间先被收到 u，跨一步到 v，再散到另一段。

拆分用的是线段树区间递归：当前节点整段落在询问区间里，就加一条边直接返回；否则往左右孩子递归。写法固定，一次操作加 O(log n) 条边。

点连区间：入树怎么把边数压下来

点 1 要连向区间 [3,6]，边权 5。点「下一步」，看它怎么在入树上拆成两个节点、只连两条边。

拆出的入树节点 新加的边 树内 0 边

把上面四个函数拼起来，就是优化建图的模版。建两棵树，再按操作类型调对应的连边函数。

int ls[MAXT];
    int rs[MAXT];
    int rootOut;
    int rootIn;
    int cntt;
    int cntg;
    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int weight[MAXE];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int buildOut(int l, int r) {
        int rt;
        if (l == r) {
            rt = l;
        } else {
            rt = ++cntt;
            int mid = (l + r) >> 1;
            ls[rt] = buildOut(l, mid);
            rs[rt] = buildOut(mid + 1, r);
            addEdge(ls[rt], rt, 0);
            addEdge(rs[rt], rt, 0);
        }
        return rt;
    }

    int buildIn(int l, int r) {
        int rt;
        if (l == r) {
            rt = l;
        } else {
            rt = ++cntt;
            int mid = (l + r) >> 1;
            ls[rt] = buildIn(l, mid);
            rs[rt] = buildIn(mid + 1, r);
            addEdge(rt, ls[rt], 0);
            addEdge(rt, rs[rt], 0);
        }
        return rt;
    }

    void xToRange(int jobx, int jobl, int jobr, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(jobx, i, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                xToRange(jobx, jobl, jobr, jobw, l, mid, ls[i]);
            }
            if (jobr > mid) {
                xToRange(jobx, jobl, jobr, jobw, mid + 1, r, rs[i]);
            }
        }
    }

    void rangeToX(int jobl, int jobr, int jobx, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {

五、题目1：遗产

n 个点，给定起点 s，q 次操作。操作一是单点 x 到单点 y 连边权 w 的有向边；操作二是点 x 到区间 [l, r] 每个点连边权 w 的边；操作三是区间 [l, r] 每个点到点 x 连边权 w 的边。求 s 到每个点的最短距离，不连通输出 -1。

n、q 都到 10⁵，边权 w 到 10⁹。

三种操作正好对应前面三种连边，直接套模版。操作一就是普通的单点连边，操作二走 xToRange，操作三走 rangeToX。

这里有个细节：线段树的叶子编号就是原来的点 1 到 n，所以辅助点的编号都大于 n。最后只需要输出 1 到 n 的 dist，辅助点算出来的距离不用管。图是有向带权图，跑一遍 Dijkstra 即可。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXT = MAXN * 10;
    const int MAXE = MAXN * 30;
    const ll INF = 1LL << 60;
    int n, q, s;

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int weight[MAXE];
    int cntg;

    int ls[MAXT];
    int rs[MAXT];
    int rootOut, rootIn;
    int cntt;

    ll dist[MAXT];
    bool vis[MAXT];

    struct Node {
        int u;
        ll d;

        bool operator < (const Node &other) const {
            return d > other.d;
        }
    };

    priority_queue<Node> heap;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int buildOut(int l, int r) {
        int rt;
        if (l == r) {
            rt = l;
        } else {
            rt = ++cntt;
            int mid = (l + r) >> 1;
            ls[rt] = buildOut(l, mid);
            rs[rt] = buildOut(mid + 1, r);
            addEdge(ls[rt], rt, 0);
            addEdge(rs[rt], rt, 0);
        }
        return rt;
    }

    int buildIn(int l, int r) {
        int rt;
        if (l == r) {
            rt = l;
        } else {
            rt = ++cntt;
            int mid = (l + r) >> 1;
            ls[rt] = buildIn(l, mid);
            rs[rt] = buildIn(mid + 1, r);
            addEdge(rt, ls[rt], 0);
            addEdge(rt, rs[rt], 0);
        }
        return rt;
    }

    void xToRange(int jobx, int jobl, int jobr, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(jobx, i, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                xToRange(jobx, jobl, jobr, jobw, l, mid, ls[i]);
            }
            if (jobr > mid) {
                xToRange(jobx, jobl, jobr, jobw, mid + 1, r, rs[i]);
            }
        }
    }

    void rangeToX(int jobl, int jobr, int jobx, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobx, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                rangeToX(jobl, jobr, jobx, jobw, l, mid, ls[i]);
            }
            if (jobr > mid) {
                rangeToX(jobl, jobr, jobx, jobw, mid + 1, r, rs[i]);
            }
        }
    }

    void dijkstra() {
        for (int i = 1; i <= cntt; i++) {
            dist[i] = INF;
        }
        dist[s] = 0;
        heap.push({s, 0});
        while (!heap.empty()) {
            Node cur = heap.top();
            heap.pop();
            int u = cur.u;
            ll d = cur.d;
            if (!vis[u]) {
                vis[u] = true;
                for (int e = head[u]; e > 0; e = nxt[e]) {
                    int v = to[e];
                    int w = weight[e];
                    if (!vis[v] && dist[v] > d + w) {
                        dist[v] = d + w;
                        heap.push({v, dist[v]});
                    }
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> q >> s;
        cntt = n;
        rootOut = buildOut(1, n);
        rootIn = buildIn(1, n);
        for (int i = 1, op, x, y, l, r, w; i <= q; i++) {
            cin >> op;
            if (op == 1) {
                cin >> x >> y >> w;
                addEdge(x, y, w);
            } else if (op == 2) {
                cin >> x >> l >> r >> w;
                xToRange(x, l, r, w, 1, n, rootIn);
            } else {
                cin >> x >> l >> r >> w;
                rangeToX(l, r, x, w, 1, n, rootOut);
            }
        }
        dijkstra();
        for (int i = 1; i <= n; i++) {
            cout << (dist[i] == INF ? -1 : dist[i]) << " ";
        }
        return 0;
    }

六、前后缀优化建图

线段树能处理二维的区间，但不是所有批量连边都适合它。有时候约束是一条链上的单侧关系：某个点要连向它前面所有点，或者后面所有点都连向某个点。

这时给每个位置再开两个点。前缀点 pre[i] 代表下标 1 到 i，后缀点 suf[i] 代表 i 到 n。

连法是 pre[i] 连 pre[i-1] 和 i，suf[i] 连 suf[i+1] 和 i，方向按题目需要翻转。这样「i 连向所有 j < i」只需要连到 pre[i-1]，「所有 j > i 连向 i」只从 suf[i+1] 连过来，每条约束 O(1) 条边，整条链 O(n) 个辅助点。

前后缀的辅助点数和线段树同阶，但常数小得多，能用的场景也更窄，只适合单侧的前缀或后缀。它最常见的舞台是 2-SAT，把 O(n²) 的约束压到 O(n)，下一批页面会讲。树状数组、主席树、CDQ 版优化建图的思路见 树状数组优化建图、主席树优化建图、CDQ 优化建图。

七、复杂度分析

线段树优化建图的代价，是把点数从 n 加到 O(n)，换来边数从 O(n²) 降到 O(log n) 每次。

步骤时间复杂度空间复杂度
建出树 + 入树O(n)O(n) 个辅助点
单点连区间 / 区间连单点O(log n) 条边O(n + m)
区间连区间O(log n) 条边 + 2 个辅助点
Dijkstra（建图之后）O(m log n)O(n + m)

点数从 n 变成 O(n)，边数 m 从朴素的 O(n²) 降到 O((n + q) log n)。n = q = 10⁵ 时，边数大约是 3 × 10⁶ 量级，和朴素的 10¹⁰ 差了好几个数量级。

空间上，出树和入树各 O(n) 个节点，两棵树的叶节点复用编号，所以总点数在 4n 附近。链式前向星按操作次数乘 log n 开边数组即可。

八、最后

优化建图的本质，是用一层结构替掉一次枚举。线段树替的是下标区间，前后缀替的是单侧前缀，树剖替的是树上一段路径，倍增替的是向上的一段范围。
