线段树分治 + 线性基：异或最短路、八纵八横

图上的边加加减减，维护「x 到 y 的所有路径中，沿途边权异或起来的最小值（或最大值）」。这件事单独用带权并查集做不出来（它只能给一条路径的值），加上线性基收集所有环之后就完整了。边有生效区间，于是再套一层线段树分治。

零、背景

前置有三块：线性基的基础以及它的题目4；带权并查集；可撤销并查集。线段树分治的原理，上一节（同组前一页）讲过时间轴线段树加背包。

这一页的两道题都是同一个组合套路：带权并查集给出一条参考路径的异或值，线性基里装着所有环的异或值，两者拼起来就能自由调整。区别在于题 4 的边随时可能被删，所以要连并查集一起回滚；题 5 的初始边永不删除，只有后加的边在区间里生效，因此初始部分用经典带权并查集就够了。

一、两个零件怎么拼

先看不带修改时的样子。带权并查集里 eor[u] 记 u 到代表元的路径异或和，路径压缩时要同步压缩权值。加入一条 x 到 y、权值 w 的边时：

如果 x 和 y 已经在同一个集合里，这条边一定产生一个环。环的异或值是 getEor(x) ^ getEor(y) ^ w，前两项把各自到根的路径异或值拼出来，第三项是这条新边本身。把环扔进线性基。

如果不在同一集合，按大小把其中一个集合挂到另一个下面，并把新代表的 eor 值设成上面算出来的那个 w'。这一步不产生环。

查询的时候，getEor(x) ^ getEor(y) 是某一条 x 到 y 路径的异或值，而任意两条 x 到 y 的路径之差都是一个环的组合，所以答案就是这个值在线性基张成的空间里能取到的极值。

二、题目4 异或最短路

一共有 n 个点、m 条边，每条边有边权。接下来 q 个操作：操作 1 x y d 加入一条 x 到 y、权值 d 的边；操作 2 x y 删除这条边；操作 3 x y 询问，x 到 y 的路上随便走，沿途边权异或起来，最小值是多少。保证 x < y，且任意操作后图连通、无重边、无自环。数据范围 1 ≤ n、m、q ≤ 2 · 10⁵（测试链接：https://www.luogu.com.cn/problem/CF938G）。

所有边权不超过 2^30，所以线性基开到 bit 29 就够。把这棵线段树建在时间戳 0 到 q 上：初始的 m 条边时间戳为 0，之后每个加入/删除操作都有它自己的时间戳。

2.1 同一个端点的多次出现要切成区间

处理方式是：把每条「边的一次出现」看成一个事件 (x, y, t, w)，按 (x, y) 排序、同一组里再按 t 排序。注意 x、y 在说法上保证 x < y，删除操作只给出端点，所以删除操作本身不带权值，它的时间戳只表示「这一次生效结束」。

于是同一组事件里，第 1 个和第 2 个之间是该边的第 1 段生效期，第 3 个和第 4 个之间是第 2 段，以此类推；如果最后一个事件落单（只有出现没有删除），它的生效期一直延到 q。这里有个细节：这条边两次出现的权值完全可以不同，所以每段生效期要带上自己那次出现的权值。

代码里把这个分组 + 配对的过程写在 prepare 中，event 数组先填 m 条初始边（时间戳 0）再填每个非查询操作（时间戳是它的操作序号），排序之后每两个一组拆出线段：

    
void prepare() {
        for (int i = 1; i <= n; i++) {
            father[i] = i;
            siz[i] = 1;
        }
        sort(event + 1, event + eventCnt + 1, EventCmp);
        int x, y, start, end, d;
        for (int l = 1, r = 1; l <= eventCnt; l = ++r) {
            x = event[l].x;
            y = event[l].y;
            while (r + 1 <= eventCnt && event[r + 1].x == x && event[r + 1].y == y) {
                r++;
            }
            for (int i = l; i <= r; i += 2) {
                start = event[i].t;
                end = (i + 1 <= r) ? (event[i + 1].t - 1) : q;
                d = event[i].w;
                add(start, end, x, y, d, 0, q, 1);
            }
        }
    }

2.2 可撤销的带权并查集

不路径压缩（压缩了就不好撤销），所以 find 是循环往上走，getEor 把沿途的 eor 全部异或起来。合并只按大小挂，同时往 rollback 栈里记 (fu, fv)，撤销时把 fv 重新指向自己、fu 的大小减回去。

返回 true 表示这次 Union 真的合并了两个集合（需要回滚），false 表示这条边产生了一个环（只往线性基里插东西，不用回滚）。dfs 里数一数 true 的次数就知道要 undo 几步。

    
int find(int i) {
        while (i != father[i]) {
            i = father[i];
        }
        return i;
    }

    int getEor(int i) {
        int res = 0;
        while (i != father[i]) {
            res ^= eor[i];
            i = father[i];
        }
        return res;
    }

    bool Union(int u, int v, int w) {
        int fu = find(u);
        int fv = find(v);
        w = getEor(u) ^ getEor(v) ^ w;
        if (fu == fv) {
            insert(w);
            return false;
        }
        if (siz[fu] < siz[fv]) {
            int tmp = fu;
            fu = fv;
            fv = tmp;
        }
        father[fv] = fu;
        siz[fu] += siz[fv];
        eor[fv] = w;
        rollback[++opsize][0] = fu;
        rollback[opsize][1] = fv;
        return true;
    }

    void undo() {
        int fu = rollback[opsize][0];
        int fv = rollback[opsize--][1];
        father[fv] = fv;
        eor[fv] = 0;
        siz[fu] -= siz[fv];
    }

2.3 可撤销的线性基

和先前提到的思想一模一样：线性基难做的是撤销，而「一个点位被几个不同元素先后插入」这个问题可以转成，按插入顺序把这些元素排成一个队列，撤销时把队尾弹出。这里的实现用 inspos 记录每次插入落在哪个 bit 上，basiz 是插入计数，cancel(oldsiz) 把 basiz 退回到 oldsiz，并把对应位置清零。

需要注意的是，这种「记录每个插入的最小时间点」的写法比撤销到「插入前的整份拷贝」省空间：只需要一个 bit 位的下表 + 一个计数。

    
void insert(int num) {
        for (int i = BIT; i >= 0; i--) {
            if (num >> i == 1) {
                if (basis[i] == 0) {
                    basis[i] = num;
                    inspos[basiz++] = i;
                    return;
                }
                num ^= basis[i];
            }
        }
    }

    int minEor(int num) {
        for (int i = BIT; i >= 0; i--) {
            num = min(num, num ^ basis[i]);
        }
        return num;
    }

    void cancel(int oldsiz) {
        while (basiz > oldsiz) {
            basis[inspos[--basiz]] = 0;
        }
    }

2.4 分治主体

dfs 到节点时，把挂在这个节点上的所有边依次处理：能合并就合并并记下次数，成环就把环的异或值插进线性基；叶子上是查询就用 getEor 拼出参考路径，再交给线性基贪心：

    
void dfs(int l, int r, int i) {
        int oldsiz = basiz;
        int unionCnt = 0;
        for (int e = head[i]; e; e = nxt[e]) {
            if (Union(tox[e], toy[e], tow[e])) {
                unionCnt++;
            }
        }
        if (l == r) {
            if (op[l] == 3) {
                ans[l] = minEor(getEor(x[l]) ^ getEor(y[l]));
            }
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        cancel(oldsiz);
        for (int k = 1; k <= unionCnt; k++) {
            undo();
        }
    }

注意回滚顺序：先 cancel(oldsiz) 清掉本节点插进线性基的环，再按 unionCnt 次 undo 退回并查集。二者没有先后依赖，不过按「后插入的先清」的习惯写成这样更直观。

异或最短路：一次 dfs 中的并入、成环、回答与撤销

总代价：平均一条边产生 O(log q) 次插入，每次插入是一次 find + getEor（不路径压缩，最坏 O(log n)）加一次线性基插入 O(30)，摊下来 O((n + m + q) · log q · log n)，实际跑得很轻。

三、题目5 八纵八横

一共有 n 个点、m 条边，每条边的边权用一个 01 字符串表示，初始就保证图连通。初始的 m 条边永不删除。接下来 q 个操作：Add x y z 加入 x 到 y、边权为 z 的边（第 k 条添加操作时该边编号为 k）；Cancel k 删除编号为 k 的边；Change k z 把编号为 k 的边的边权改成 z。每次操作后要打印：从 1 号点出发最后回到 1 号点，边随便走，沿途所有边权异或起来的最大值。数据范围 1 ≤ n、m ≤ 500，0 ≤ q ≤ 1000，边权字符串长度 ≤ 1000（测试链接：https://www.luogu.com.cn/problem/P3733）。

和题 4 的差别有两点：一是初始边永不消失，它属于「全局都存在」的部分；二是边权不是整数而是最多 1000 位的 01 串。前者让初始部分可以完全不进线段树；后者让线性基的每一位都得用 bitset<1000> 表示。

具体做法：初始边用经典带权并查集合进去，不做任何回滚，因为这些边在所有时刻都存在，dfs 一路上它们的影响一直有效。后面每条 Add / Change 出来的边才切成区间挂到时间树：Add 时记 last[k] = 当前操作序号 i；Cancel k 时把旧权值的区间 [last[k], i-1] 挂上并把 last[k] 置 0；Change k z 时同样先挂旧权值的 [last[k], i-1]，然后把当前权值改成 z、last[k] 改成 i。最后还没被 Cancel 或 Change 的边，补上 [last[k], q]。

    
    ans[0] = maxEor();
        string op;
        int k;
        for (int i = 1; i <= q; i++) {
            cin >> op;
            if (op == "Add") {
                ++edgeCnt;
                cin >> x[edgeCnt] >> y[edgeCnt] >> w[edgeCnt];
                last[edgeCnt] = i;
            } else if (op == "Cancel") {
                cin >> k;
                add(last[k], i - 1, x[k], y[k], w[k], 1, q, 1);
                last[k] = 0;
            } else {
                cin >> k;
                add(last[k], i - 1, x[k], y[k], w[k], 1, q, 1);
                cin >> w[k];
                last[k] = i;
            }
        }
        for (int i = 1; i <= edgeCnt; i++) {
            if (last[i] != 0) {
                add(last[i], q, x[i], y[i], w[i], 1, q, 1);
            }
        }
        if (q > 0) {
            dfs(1, q, 1);
        }

线性基与并查集都换成 bitset 版本：插入、求最大值、撤销的规则和整数版一字不差，只是每个「元素」从 int 变成 bitset<1000>。经典带权并查集可以放心做路径压缩（初始边不用回滚），getEor 里先 find 一次拿到最新的 eor。

    
void insert(bs& num) {
        for (int i = BIT; i >= 0; i--) {
            if (num[i] == 1) {
                if (basis[i][i] == 0) {
                    basis[i] = num;
                    inspos[basiz++] = i;
                    return;
                }
                num ^= basis[i];
            }
        }
    }

    bs maxEor() {
        bs ret;
        for (int i = BIT; i >= 0; i--) {
            if (ret[i] == 0 && basis[i][i] == 1) {
                ret ^= basis[i];
            }
        }
        return ret;
    }

    void cancel(int oldsiz) {
        while (basiz > oldsiz) {
            basis[inspos[--basiz]].reset();
        }
    }

    int find(int i) {
        if (i != father[i]) {
            int tmp = father[i];
            father[i] = find(tmp);
            eor[i] ^= eor[tmp];
        }
        return father[i];
    }

    bs getEor(int i) {
        find(i);
        return eor[i];
    }

    void Union(int u, int v, bs& w) {
        int fu = find(u);
        int fv = find(v);
        bs weight = getEor(u) ^ getEor(v) ^ w;
        if (fu == fv) {
            insert(weight);
        } else {
            father[fv] = fu;
            eor[fv] = weight;
        }
    }

分治主体与题 4 几乎一致，区别是每次只挂 Union 而没有回滚动作（本节点上的操作在回溯时只需要清线性基）：

    
void dfs(int l, int r, int i) {
        int oldsiz = basiz;
        for (int e = head[i]; e; e = nxt[e]) {
            Union(tox[e], toy[e], tow[e]);
        }
        if (l == r) {
            ans[l] = maxEor();
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        cancel(oldsiz);
    }

输出一共有 q + 1 行：第 0 行是只有初始边时的答案（ans[0] 在 main 里建完初始并查集就直接算好），之后每一行是对应操作结束后的答案。二进制输出要去掉前导零，全零时打印一个 0。

这里有个细节：Union 之前先 find 两次拿代表元，即使已经在同一集合里也要把环的 weight 算出来插进线性基。这与题 4 的 insert(w) 是同一个动作；区别只在题 4 的 Union 返回 true / false 来告诉 dfs 要不要记一笔 undo，而题 5 的时间树节点上不需要并查集回滚，dfs 里也就少了一步。

五、最后

这道题的框架是三件东西拼起来：带权并查集给出路径异或，线性基收集环的信息，线段树分治处理边的生效区间。三件工具各自独立，接口只碰两次：加边时插入线性基，查询时先路径异或再和线性基取极值。

两题相比：题 4 规模大但权值只有 30 位，瓶颈在线段树的节点个数；题 5 规模小但权值有 1000 位，瓶颈在 bitset 线性基的插入。同一套框架，换的是挂在每个节点上的那件「工具」。
