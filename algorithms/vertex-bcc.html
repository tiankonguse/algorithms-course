点双连通分量

割点切出来的块会在割点上重叠，这是它和边双最大的不同。把每个「删掉任何一个点都不散架」的极大子图找出来，就是点双连通分量。这一节给 Tarjan 加一个栈，一次 dfs 把所有点双弹出来，然后连做五道题。

零、背景

上一节求割点用的 dfn、low、扎口袋，这一节原样保留，新东西只有一个栈。

先说定义。无向图里两个点 u 和 v，随便删掉除它们之外的任何一个点，u 和 v 依然连通，就说 u 和 v 是点双连通的。一个极大的点双连通子图，叫一个点双连通分量（V-BCC）。

「极大」指的是不能再往里加点。点和点可以同属多个点双，通过割点；但每条边恰好属于一个点双。这条性质后面反复用到。

一、定义与性质

割点把图分割出的每一块，配上块边界上的割点，就是一个个点双。反过来，每个割点会在它相邻的每个点双里各出现一次。

有一条边的情况值得单独记：割边的两个端点删掉谁都照样连通（只剩两个点，无别的点可删），所以每条割边的两个端点自己构成一个点双。

因为割点会被复制进多个点双，所有点双的规模总和不再是 n。一条链就是最坏情况：n 个点的链有 n − 1 个点双 {i, i+1}，总规模 2(n − 1)，接近 2n。存点双的数组要按 2n 开。

二、朴素做法

照定义来：枚举每个点 w，删掉，跑一遍 dfs 看哪些点对被分开，再按「没被任何 w 分开」把点对归成点双。一次 O(n + m)，n 个点 O(n·(n + m))，n 到 5 × 10⁵ 时完全不可行。

顺着想一步「先求割点、删掉所有割点、剩下的连通块配上相邻割点」，这条路走不通：一个点双里可能有多个割点，全删掉会把点双切碎。比如四方环 a-b-c-d，a 和 c 都是割点，删掉后 b 和 d 各自成块，但真正的点双是 {a,b,c,d} 整体。

Tarjan 的栈版本一遍 dfs 全部收完，也不用担心切错。

三、Tarjan 求点双连通分量

规则在求割点的基础上加两条。第一，来到节点 u，设好 dfn[u] 和 low[u] 之后，u 进栈。第二，树边 (u, v) 返回时发现 low[v] ≥ dfn[u]，u 扎起口袋：从栈顶不断弹点，直到把 v 弹出来为止，弹出的点加上 u 自己（不弹），构成一个新的点双。

为什么弹到 v 为止：栈里比 v 早进栈的点属于别的口袋，不该被这次带走；v 之上恰好是这棵子树里还没被收走的点。u 不弹出，因为它还要给别的口袋当袋口，割点本来就要在相邻的每个点双里各出现一次，留在栈里正是让它被下一个口袋再收一遍。

回边照旧 low[u] = min(low[u], dfn[v])。根当袋口不需要特判，每个树儿子各自检查、各自弹各自的。

孤立点要单独处理：没有边的点自成一个点双（题目4 的要求），在主循环里看见 head 为 0 的点直接发一个分量。

判定写 low[v] ≥ dfn[u] 还是 low[v] == dfn[u] 是等价的：反着走的树边把 low[v] 压到了 dfn[u]，low[v] 不会比它大。

Tarjan 求点双走一遍

还是上一节那张图。这次多了一个栈：点第一次被访问时进栈，扎口袋的时候从栈顶往下弹，弹出一个点双。点「下一步」看栈怎么进、怎么弹。

当前 dfs 所在的点 已访问 还没走到 袋口（不弹出）

四、题目4：点双连通分量模版

给定一张无向图，n 个点、m 条边，建图时忽略自环。打印点双连通分量的个数，打印每个点双的大小和节点编号，打印顺序随意。每个孤立点分配一个点双。1 ≤ n ≤ 5 × 10⁵，1 ≤ m ≤ 2 × 10⁶。（洛谷 P8435）

m 到 2 × 10⁶，前向星和点双数组都要开够。输出用的点双内容存在一维数组 vbccArr 里，另配 vbccSiz 和每个分量在 vbccArr 里的左右端点，比 vector 快一截。

注意主循环里对孤立点的处理：dfn 为 0 且 head 为 0 的点，直接生成一个只含自己的分量，不进 tarjan。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 2000001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int vbccSiz[MAXN];
    int vbccArr[MAXN << 1];
    int vbccl[MAXN];
    int vbccr[MAXN];
    int idx;
    int vbccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    vbccCnt++;
                    vbccSiz[vbccCnt] = 1;
                    vbccArr[++idx] = u;
                    vbccl[vbccCnt] = idx;
                    int pop;
                    do {
                        pop = sta[top--];
                        vbccSiz[vbccCnt]++;
                        vbccArr[++idx] = pop;
                    } while (pop != v);
                    vbccr[vbccCnt] = idx;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            if (u != v) {
                addEdge(u, v);
                addEdge(v, u);
            }
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                if (head[i] == 0) {
                    vbccCnt++;
                    vbccSiz[vbccCnt] = 1;
                    vbccArr[++idx] = i;
                    vbccl[vbccCnt] = vbccr[vbccCnt] = idx;
                } else {
                    tarjan(i);
                }
            }
        }
        cout << vbccCnt << "\n";
        for (int i = 1; i <= vbccCnt; i++) {
            cout << vbccSiz[i] << "\n";
            for (int j = vbccl[i]; j <= vbccr[i]; j++) {
                cout << vbccArr[j] << " ";
            }
            cout << "\n";
        }
        return 0;
    }

五、题目5：点双连通分量模版（字典序）

给定一张无向图，n 个点、m 条边。忽略所有孤立点，打印点双连通分量的个数，打印每个点双内部的节点编号：分量内编号从小到大，分量之间按序列字典序小的先打印。1 ≤ n ≤ 5 × 10⁴，1 ≤ m ≤ 3 × 10⁵。（洛谷 B3610）

求法和题目4 完全一样，差别全在输出：每个分量内部排一次序，分量之间再按字典序排一次。分量用 vector 存，比较函数按位置逐个比，前缀相同短的在前。

孤立点直接不跑 tarjan，自然就被忽略了。这道题的判定写的是 low[v] == dfn[u]，和 ≥ 等价，理由在上一节说过。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    const int MAXM = 300001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    vector<vector<int>> vbccArr;

    bool VbccCmp(const vector<int> &o1, const vector<int> &o2) {
        int size = min(o1.size(), o2.size());
        for (int i = 0; i < size; i++) {
            if (o1[i] != o2[i]) {
                return o1[i] < o2[i];
            }
        }
        return o1.size() < o2.size();
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] == dfn[u]) {
                    vector<int> list;
                    list.push_back(u);
                    int pop;
                    do {
                        pop = sta[top--];
                        list.push_back(pop);
                    } while (pop != v);
                    vbccArr.push_back(list);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0 && head[i] > 0) {
                tarjan(i);
            }
        }
        cout << vbccArr.size() << "\n";
        for (int i = 0; i < vbccArr.size(); i++) {
            sort(vbccArr[i].begin(), vbccArr[i].end());
        }
        sort(vbccArr.begin(), vbccArr.end(), VbccCmp);
        for (int i = 0; i < vbccArr.size(); i++) {
            for (int node : vbccArr[i]) {
                cout << node << " ";
            }
            cout << "\n";
        }
        return 0;
    }

六、题目6：夺回据点

一共 n 个据点、m 条双向道路，所有据点连通在一起。每个据点给定点权 cost，代表夺取这个据点的花费。当夺取某个据点之后，再夺取相邻的据点，认为没有花费。可以按任意顺序夺取所有据点，但过程中必须保证还没夺取的据点都在同一个连通区里，不被已夺取的据点隔开。打印最小的总花费。1 ≤ n、m ≤ 10⁵。（LeetCode LCP「夺回据点」）

先把约束翻译清楚。割点不能随便先夺：割点被夺走，它两侧还没夺的点就被隔开了。准确地说，割点必须在它某一侧的点全部夺完之后才能夺。于是夺取顺序只能沿着点双树从外往里剥。

叶子点双（恰含一个割点）必须从内部付一次钱。想不付钱进入它，就得先夺它的割点；而那个割点能被夺的时候，它别的方向必须已经空了，所以那次免费进入只可能留给最后。也就是说，每个叶子点双都要付「内部最小花费」这笔钱，只有最后收尾的那一个可以白拿，白拿的机会当然留给最贵的那笔。

非叶点双有两个以上的割点，从一个割点免费进来、从另一个免费出去，全程不付钱。整图只有一个点双时没有割点，付全图最小点权就够了。

所以答案 = 各叶子点双内部最小花费之和 − 其中最大的一次；整图一个点双时 = 全图最小点权。

实现上把求割点和求点双写在一个 tarjan 里，最后扫一遍所有点双：数一数每个点双里有几个割点，恰一个的就是叶子，找非割点的最小花费。代码是 LeetCode 提交版，交 Solution 类，头文件按平台惯例省略。

class Solution {
    public:
        static const int MAXN = 100001;
        static const int MAXM = 100001;
        int n, m;

        int head[MAXN];
        int nxt[MAXM << 1];
        int to[MAXM << 1];
        int cntg;

        int dfn[MAXN];
        int low[MAXN];
        int cntd;

        int sta[MAXN];
        int top;

        bool cutVertex[MAXN];
        vector<vector<int>> vbccArr;

        void prepare() {
            cntg = cntd = top = 0;
            for (int i = 1; i <= n; i++) {
                head[i] = dfn[i] = low[i] = 0;
                cutVertex[i] = false;
            }
            vbccArr.clear();
        }

        void addEdge(int u, int v) {
            nxt[++cntg] = head[u];
            to[cntg] = v;
            head[u] = cntg;
        }

        void tarjan(int u, bool root) {
            dfn[u] = low[u] = ++cntd;
            sta[++top] = u;
            int son = 0;
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                if (dfn[v] == 0) {
                    son++;
                    tarjan(v, false);
                    low[u] = min(low[u], low[v]);
                    if (low[v] >= dfn[u]) {
                        if (!root || son >= 2) {
                            cutVertex[u] = true;
                        }
                        vector<int> list;
                        list.push_back(u);
                        int pop;
                        do {
                            pop = sta[top--];
                            list.push_back(pop);
                        } while (pop != v);
                        vbccArr.push_back(list);
                    }
                } else {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }

        long long minimumCost(vector<int>& cost, vector<vector<int>>& roads) {
            n = cost.size();
            m = roads.size();
            prepare();
            for (int i = 0; i < m; i++) {
                int u = roads[i][0] + 1;
                int v = roads[i][1] + 1;
                addEdge(u, v);
                addEdge(v, u);
            }
            tarjan(1, true);
            long long ans = 0;
            if (vbccArr.size() == 1) {
                ans = LLONG_MAX;
                for (int i = 0; i < n; i++) {
                    ans = min(ans, (long long)cost[i]);
                }
            } else {
                int maxVal = INT_MIN;
                for (auto &vbcc : vbccArr) {
                    int cut = 0;
                    int val = INT_MAX;
                    for (int cur : vbcc) {
                        if (cutVertex[cur]) {
                            cut++;
                        } else {
                            val = min(val, cost[cur - 1]);
                        }
                    }
                    if (cut == 1) {
                        ans += val;
                        maxVal = max(maxVal, val);
                    }
                }
                ans -= maxVal;
            }
            return ans;
        }
    };

七、题目7：矿场搭建

一共 n 个地点，至少 2 个，每个地点都有人，m 条双向道路连通所有地点。地震会发生在任何一个地点：地震地点的道路和救援点都会失效，其他地点的人都要能走到某个救援点。救援点可以设在任何地点，求至少需要几个救援点，以及设立方案的总数（方案是无序集合）。多组数据，读到 m = 0 结束。1 ≤ n, m ≤ 1000。（洛谷 P3225）

按点双分类讨论。

整图没有割点（只有一个点双）：地震点本身就是救援点也没了，所以至少设 2 个；任意两个地点都行，方案数 C(n, 2)。点数至少 2，两个点被一条边连着也算一个点双，结论同样成立。

恰含一个割点的点双（叶子点双）：割点地震时，这个点双和外界断开，救援点必须设在它的非割点里，1 个就够（删掉任何一个点，点双内部依然连通）；位置有 siz − 1 种，siz 是点双含割点的总规模。

含两个以上割点的点双：不用设。地震发生在任何一个点，剩下的人都能从另一个割点走出去，到达别的点双里的救援点。

所以 ans1 = 叶子点双的个数（或整图一个点双时取 2），ans2 = 各叶子点双 (siz − 1) 的乘积（或 C(n, 2)）。

输入以边为单位（先给 m 再给 m 条边），节点编号不连续，n 用出现过的最大编号。求割点和点双合在一个 tarjan 里，和题目6 同一副骨架。完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 1001;
    const int MAXM = 1001;
    int t, n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    bool cutVertex[MAXN];
    int vbccSiz[MAXN];
    int vbccArr[MAXN << 1];
    int vbccl[MAXN];
    int vbccr[MAXN];
    int idx;
    int vbccCnt;

    ll ans1, ans2;

    void prepare() {
        cntg = cntd = top = idx = vbccCnt = 0;
        for (int i = 1; i < MAXN; i++) {
            head[i] = dfn[i] = low[i] = 0;
            cutVertex[i] = false;
        }
        n = 0;
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, bool root) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        int son = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                son++;
                tarjan(v, false);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    if (!root || son >= 2) {
                        cutVertex[u] = true;
                    }
                    vbccCnt++;
                    vbccSiz[vbccCnt] = 1;
                    vbccArr[++idx] = u;
                    vbccl[vbccCnt] = idx;
                    int pop;
                    do {
                        pop = sta[top--];
                        vbccSiz[vbccCnt]++;
                        vbccArr[++idx] = pop;
                    } while (pop != v);
                    vbccr[vbccCnt] = idx;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void compute() {
        if (vbccCnt == 1) {
            ans1 = 2;
            ans2 = 1ll * n * (n - 1) / 2;
        } else {
            ans1 = 0;
            ans2 = 1;
            for (int i = 1; i <= vbccCnt; i++) {
                int siz = vbccSiz[i], cut = 0;
                for (int j = vbccl[i]; j <= vbccr[i]; j++) {
                    if (cutVertex[vbccArr[j]]) {
                        cut++;
                    }
                }
                if (cut == 1) {
                    ans1 += 1;
                    ans2 = ans2 * (siz - 1);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        t = 0;
        cin >> m;
        while (m != 0) {
            prepare();
            for (int i = 1, u, v; i <= m; i++) {
                cin >> u >> v;
                n = max(n, u);
                n = max(n, v);
                addEdge(u, v);
                addEdge(v, u);
            }
            tarjan(1, true);
            compute();
            cout << "Case " << (++t) << ": " << ans1 << " " << ans2 << "\n";
            cin >> m;
        }
        return 0;
    }

八、题目8：圆桌骑士

一共 n 个骑士，m 条厌恶关系，每条代表两个骑士互相讨厌。任选骑士开圆桌会议，厌恶关系的骑士不能相邻，圆桌人数必须是大于 1 的奇数，防止赞同票和反对票一样多。有的骑士不管怎么安排都无法参会，打印这个数量。1 ≤ n ≤ 10³，1 ≤ m ≤ 10⁶。（SPOJ SP2878 / 洛谷 P2878 同源题）

先把「能参会」翻译清楚。圆桌是一个环排列，相邻的骑士两两不讨厌。把「不讨厌」连成边，一张合法的圆桌就是图上一个长度为奇数的环，骑士能参会 ⟺ 他处在某个奇环上。

任何一条环上的任意两点，沿环的两侧有两条不相交的路，所以整个环落在同一个点双里。结论一：奇环不会跨过割点，跨割点的两个骑士无法同席。

结论二：一个点双里只要有奇环，点双里的每个骑士都坐在某个奇环上。证明不展开，说法是沿着奇环和点双内的路径拼接把每个点绕进去。于是判定变成：对每个点双检查它是不是二分图，二分图没有奇环，染色遇到同色相邻就说明有奇环。

建图有个反转：m 条是厌恶关系，要连的是补图（不讨厌才连边）。n 只有 1000，讨厌关系记成布尔矩阵，补图建边 O(n²)。补图里的孤立点（讨厌所有人）自成一个点双，没有奇环，自然判为不能参会。

统计时注意：割点可能属于多个点双，只要其中一个有奇环，它就能参会，标记用或运算累加。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1001;
    const int MAXM = 1000001;
    int n, m;
    bool hate[MAXN][MAXN];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int vbccArr[MAXN << 1];
    int vbccl[MAXN];
    int vbccr[MAXN];
    int idx;
    int vbccCnt;

    bool curVbcc[MAXN];
    int color[MAXN];
    bool ok[MAXN];

    void prepare() {
        cntg = cntd = top = idx = vbccCnt = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = dfn[i] = low[i] = 0;
            ok[i] = false;
            for (int j = 1; j <= n; j++) {
                hate[i][j] = false;
            }
        }
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    vbccCnt++;
                    vbccArr[++idx] = u;
                    vbccl[vbccCnt] = idx;
                    int pop;
                    do {
                        pop = sta[top--];
                        vbccArr[++idx] = pop;
                    } while (pop != v);
                    vbccr[vbccCnt] = idx;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    bool oddLoop(int u, int c) {
        color[u] = c;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (curVbcc[v]) {
                if (color[v] == c) {
                    return true;
                }
                if (color[v] == 0 && oddLoop(v, c == 1 ? 2 : 1)) {
                    return true;
                }
            }
        }
        return false;
    }

    int compute() {
        for (int i = 1; i <= vbccCnt; i++) {
            for (int j = vbccl[i]; j <= vbccr[i]; j++) {
                curVbcc[vbccArr[j]] = true;
                color[vbccArr[j]] = 0;
            }
            bool check = oddLoop(vbccArr[vbccl[i]], 1);
            for (int j = vbccl[i]; j <= vbccr[i]; j++) {
                curVbcc[vbccArr[j]] = false;
                ok[vbccArr[j]] = ok[vbccArr[j]] | check;
            }
        }
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (!ok[i]) {
                ans++;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        while (n != 0 || m != 0) {
            prepare();
            for (int i = 1, u, v; i <= m; i++) {
                cin >> u >> v;
                hate[u][v] = true;
                hate[v][u] = true;
            }
            for (int u = 1; u <= n; u++) {
                for (int v = u + 1; v <= n; v++) {
                    if (!hate[u][v]) {
                        addEdge(u, v);
                        addEdge(v, u);
                    }
                }
            }
            for (int i = 1; i <= n; i++) {
                if (dfn[i] == 0) {
                    tarjan(i);
                }
            }
            int ans = compute();
            cout << ans << "\n";
            cin >> n >> m;
        }
        return 0;
    }

九、复杂度分析

求点双和求割点同一个 dfs，O(n + m)。所有点双的总规模不超过 2n，遍历点双的额外开销也是 O(n + m)。

题目6 夺回据点O(n + m)O(n + m)

题目8 的补图建边是 n ≤ 1000 下的 O(n²)，约 10⁶；每个点双的染色只走点双内部的边，所有点双加起来还是 O(n + m′)。

题目6、7 在点双上各扫一遍统计割点个数，总和受 2n 约束，不改变量级。

十、最后

五道题的分工很清楚：两道模版练弹栈的手感，三道经典题都在「点双树」上数叶子，夺回据点数叶子的最小花费，矿场搭建数叶子的救援点，圆桌骑士借点双数奇环。

点双沿着割点重叠，直接缩点会丢信息。把每个割点拆成多份、每个点双压成一个方点，就得到圆方树，这是下一节课的主角（圆方树原理与模版）；LCT 维护图结构那一页里它已经出场过一次。
