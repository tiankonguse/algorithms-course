柱状图最大矩形与最大矩形

柱状图里找能框出的最大矩形，每根柱子「当高」算一次宽度，弹出时结算。同一招再走一步，01 矩阵里的最大矩形就是逐行累加高度后反复跑柱状图。

零、背景

n 根柱子，每根宽 1、高 height[i]，要找出能勾勒出的最大矩形面积。面积 = 高 × 宽，矩形必须完全落在柱状图里，不能跨到比它矮的柱子上。

naive 的写法是枚举每根柱子当高，向左右扩展到第一根比它矮的柱子为止，数宽度。最坏 O(n²)（升序柱，每根都要扩到底），n = 10⁵ 就卡死。

一、每根柱子当高

以 height[cur] 为高的最大矩形，左右边界正好是「第一个更小」的位置：left 和 right 之外有更矮的柱子，矩形跨不过去。所以宽度 = right - left - 1，中间全是 ≥ height[cur] 的柱子。

这不就是上一页左右更小的模版。单调栈弹出 cur 时结算 height[cur] × (i - left - 1)，清算阶段 right 换成 n。取最大值就是答案。

拿 [2,1,5,6,2,3] 走一遍，答案 10：位置 0 的高 2，弹出时 left=-1、right=1，面积 2×1=2；位置 3 的高 6，left=2、right=4，面积 6×1=6；位置 2 的高 5，弹出时 left=1、right=4，面积 5×2=10，这就是最终答案；清算阶段位置 5 高 3 算 3×1=3、位置 4 高 2 算 2×(6-1-1)=8、位置 1 高 1 算 1×6=6，都没超过 10。

#include <bits/stdc++.h>
    using namespace std;

    // 每根柱子作为高，宽 = 右边界 - 左边界 - 1
    int largestRectangleArea(vector<int>& height) {
        int n = height.size();
        int ans = 0;
        vector<int> stk;
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && height[stk.back()] >= height[i]) {
                int cur = stk.back();
                stk.pop_back();
                int left = stk.empty() ? -1 : stk.back();
                ans = max(ans, height[cur] * (i - left - 1));
            }
            stk.push_back(i);
        }
        while (!stk.empty()) {              // 清算：右边界 = n
            int cur = stk.back();
            stk.pop_back();
            int left = stk.empty() ? -1 : stk.back();
            ans = max(ans, height[cur] * (n - left - 1));
        }
        return ans;
    }

二、01 矩阵的最大矩形

矩阵里只含 1 的最大矩形，逐行变成柱状图：height[j] 从第 0 行累计到当前行，遇到 0 就清零、遇到 1 就加 1。第 i 行的 height[j] 就是「以 (i, j) 为底边、向上连续 1 的高度」。

每行累加完 height，跑一遍柱状图最大矩形，取所有行的最大值。LC 的样例矩阵四行 height 分别是 [1,0,1,0,0]、[2,0,2,1,1]、[3,1,3,2,2]、[4,0,0,3,0]，直方图面积 1、3、6、4，答案是 6，来自第三行高 2 宽 3 那块。

#include <bits/stdc++.h>
    using namespace std;

    // 01 矩阵：逐行累计 height[j]，每行跑一遍直方图最大矩形
    int largestRectangleArea(vector<int>& height, int m) {
        int ans = 0;
        vector<int> stk;
        for (int i = 0; i < m; i++) {
            while (!stk.empty() && height[stk.back()] >= height[i]) {
                int cur = stk.back();
                stk.pop_back();
                int left = stk.empty() ? -1 : stk.back();
                ans = max(ans, height[cur] * (i - left - 1));
            }
            stk.push_back(i);
        }
        while (!stk.empty()) {
            int cur = stk.back();
            stk.pop_back();
            int left = stk.empty() ? -1 : stk.back();
            ans = max(ans, height[cur] * (m - left - 1));
        }
        return ans;
    }

    int maximalRectangle(vector<vector<char>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<int> height(m, 0);
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                height[j] = grid[i][j] == '0' ? 0 : height[j] + 1;
            }
            ans = max(ans, largestRectangleArea(height, m));
        }
        return ans;
    }

三、复杂度分析

题目时间复杂度额外空间
柱状图中最大的矩形O(n)O(n)
最大矩形（01 矩阵）O(n×m)O(m)

矩阵那题 n 行每行跑一遍 O(m) 的直方图，总 O(n×m)。height 数组只存当前行，m 个元素。

四、总结

柱状图最大矩形是单调栈的经典结算场景：每根柱作为高，左右第一个更小夹出的宽度就是它能框的最大宽，弹出时一次算清。最大矩形再往前一步，逐行累计高度把二维问题压成一维。

单调栈-上到此收尾：左右边界、贡献法、直方图三套用法全是同一个「弹出即结算」动作。下节课继续单调栈的其他用法。
