莫队 + 值域分块与光速幂

窗口维护好了，答案还要再问一层：一次查询要在值域的一段区间上统计。这一节两题分别用值域分块和次数桶把这一层压到 O(√V)。

零、背景

前面几题，窗口一到位置答案就出来了。这一节的两题不一样，窗口到位之后还得再算一次：题目问的不是整个窗口，而是窗口里落在某个数值范围的部分。

莫队负责把窗口挪到位，剩下那一层用根号手段解决。两题的解法不同，思路是同一个：把值域切成块，整块一次给出，零头暴力。

一、作业

给定一个长度为 n 的数组 arr，m 条查询，每条给 l r a b，打印两个答案：arr[l..r] 上数值在 [a, b] 的数字个数，以及数值在 [a, b] 的数字种数。

1 ≤ 所有数据 ≤ 10⁵。测试链接：P4396

二、朴素做法

窗口维护 numCnt[x]（值 x 出现了几次）是容易的，增删都是 O(1)。难的是回答：要给 [a, b] 上的「个数」和「种数」，最直接是从 a 扫到 b，单次 O(V)，V = 10⁵，m 次就是 10¹⁰。

把值域切成块，块长取 √V。每个块记两个数：blockCnt 是这一块里窗口内元素的总个数，blockKind 是这一块里出现过的不同值的个数。

于是查询 [a, b] 分三段：两端所在的块是零头，暴力扫块内的那几个值；中间的整块直接用 blockCnt 和 blockKind 一次加上。单次 O(√V)。

三、块的两个数怎么维护

加一个值 x：numCnt[x] 加一，所在块的 blockCnt 加一；只有当 numCnt[x] 从 0 变成 1 时，这个值才「新出现」，这时 blockKind 才加一。删是反过来。

void add(int x) {
    numCnt[x]++;
    blockCnt[bi[x]]++;
    if (numCnt[x] == 1) blockKind[bi[x]]++;   // 这个值第一次出现
}
void del(int x) {
    numCnt[x]--;
    blockCnt[bi[x]]--;
    if (numCnt[x] == 0) blockKind[bi[x]]--;   // 这个值一个不剩了
}

注意值域的块长跟莫队的块长是两回事：值域块长按 √V 算（本题 V = 10⁵，约 316），莫队的块长按 √n 算。别混着用。

点「下一步」，看窗口滑动以及每次查询的三段统计。数组取 [1, 3, 2, 3, 1, 4]，值域 1..9，块长 3。

四、题目1 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, a, b, id;
    };

    const int MAXN = 100001;
    const int MAXV = 100000;
    const int MAXB = 401;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];

    int numCnt[MAXN];
    int blockCnt[MAXB];
    int blockKind[MAXB];

    int ans1[MAXN];
    int ans2[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if (bi[a.l] & 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void add(int x) {
        numCnt[x]++;
        blockCnt[bi[x]]++;
        if (numCnt[x] == 1) {
            blockKind[bi[x]]++;
        }
    }

    void del(int x) {
        numCnt[x]--;
        blockCnt[bi[x]]--;
        if (numCnt[x] == 0) {
            blockKind[bi[x]]--;
        }
    }

    void setAns(int a, int b, int id) {
        if (bi[a] == bi[b]) {
            for (int i = a; i <= b; i++) {
                if (numCnt[i] > 0) {
                    ans1[id] += numCnt[i];
                    ans2[id]++;
                }
            }
        } else {
            for (int i = a; i <= br[bi[a]]; i++) {
                if (numCnt[i] > 0) {
                    ans1[id] += numCnt[i];
                    ans2[id]++;
                }
            }
            for (int i = bl[bi[b]]; i <= b; i++) {
                if (numCnt[i] > 0) {
                    ans1[id] += numCnt[i];
                    ans2[id]++;
                }
            }
            for (int i = bi[a] + 1; i <= bi[b] - 1; i++) {
                ans1[id] += blockCnt[i];
                ans2[id] += blockKind[i];
            }
        }
    }

    void compute() {
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int joba = query[i].a;
            int jobb = query[i].b;
            int id = query[i].id;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            setAns(joba, jobb, id);
        }
    }

    void prepare() {
        int blen = (int)sqrt(MAXV);
        int bnum = (MAXV + blen - 1) / blen;
        for (int i = 1; i <= MAXV; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, MAXV);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r >> query[i].a >> query[i].b;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans1[i] << ' ' << ans2[i] << '\n';
        }
        return 0;
    }

五、盼君勿忘

一个序列里每种数字只保留一个，得到的累加和叫去重累加和。给定一个长度为 n 的数组 arr，m 条查询，每条给 l r p：把 arr[l..r] 上每个子序列的去重累加和都加起来，打印结果对 p 取模。

1 ≤ n、m、arr[i] ≤ 10⁵，1 ≤ p ≤ 10⁹。测试链接：P5072

六、朴素做法与逐个值的贡献

子序列有 2^len 个，逐个枚举再去重求和，一次查询就是 O(len × 2^len)，完全不可行。

换个方向，看单个值 v 贡献了多少。设 v 在区间里出现 t 次，区间长度是 len。所有子序列里，不含 v 的只能从其余 len − t 个位置里选，有 2^(len−t) 个；其余的都含 v，共 2^len − 2^(len−t) 个。含 v 的每个贡献一个 v（去重之后只算一次）。

所以 v 的贡献是 v × (2^len − 2^(len−t))，答案就是所有值的贡献之和。

七、次数桶与光速幂

出现次数相同的若干个值可以合并：记 sum[t] 是所有「出现 t 次」的值的和，答案就是 Σt (2^len − 2^(len−t)) × sum[t]。

增删的时候，一个值 v 的次数从 t 变成 t+1，就是 sum[t] 减掉 v、sum[t+1] 加上 v，O(1)。

剩下的问题是遍历哪些 t。t 从 1 到 len 全扫一遍是 O(len)，太慢。实际非零的 sum[t] 没那么多，用链表只串起 sum[t] ≠ 0 的那些 t：某个 t 的 sum 变成 0 就从链表里摘掉，从 0 变成非 0 就插回表头。

还有 2 的幂。每次查询的 p 和 len 都可能不同，不能预处理。代码里用光速幂：把指数按 √len 分块，smlPower[i] = 2^i，bigPower[i] = 2^(i×块长)，于是 2^k = bigPower[k / 块长] × smlPower[k % 块长]。每次查询花 O(√len) 打表，之后每次取幂是 O(1)。

下面是 arr = [1, 2, 1, 3, 2]，两条查询 [1,4] p=100 和 [2,5] p=50。

八、题目2 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, p, id;
    };

    const int MAXN = 100001;
    const int MAXB = 401;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];
    int bi[MAXN];

    int head;
    int lst[MAXN];
    int nxt[MAXN];

    int cnt[MAXN];
    long long sum[MAXN];

    long long smlPower[MAXB];
    long long bigPower[MAXB];

    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if (bi[a.l] & 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void addNode(int x) {
        lst[head] = x;
        nxt[x] = head;
        head = x;
    }

    void delNode(int x) {
        if (x == head) {
            head = nxt[head];
            lst[head] = 0;
            nxt[x] = 0;
        } else {
            nxt[lst[x]] = nxt[x];
            lst[nxt[x]] = lst[x];
            lst[x] = 0;
            nxt[x] = 0;
        }
    }

    void add(int num) {
        if (cnt[num] > 0) {
            sum[cnt[num]] -= num;
        }
        if (cnt[num] > 0 && sum[cnt[num]] == 0) {
            delNode(cnt[num]);
        }
        cnt[num]++;
        if (cnt[num] > 0 && sum[cnt[num]] == 0) {
            addNode(cnt[num]);
        }
        if (cnt[num] > 0) {
            sum[cnt[num]] += num;
        }
    }

    void del(int num) {
        if (cnt[num] > 0) {
            sum[cnt[num]] -= num;
        }
        if (cnt[num] > 0 && sum[cnt[num]] == 0) {
            delNode(cnt[num]);
        }
        cnt[num]--;
        if (cnt[num] > 0 && sum[cnt[num]] == 0) {
            addNode(cnt[num]);
        }
        if (cnt[num] > 0) {
            sum[cnt[num]] += num;
        }
    }

    void setAns(int len, int p, int id) {
        int blockLen = (int)sqrt(len);
        int blockNum = (len + blockLen - 1) / blockLen;
        smlPower[0] = 1;
        for (int i = 1; i <= blockLen; i++) {
            smlPower[i] = (smlPower[i - 1] << 1) % p;
        }
        bigPower[0] = 1;
        for (int i = 1; i <= blockNum; i++) {
            bigPower[i] = (bigPower[i - 1] * smlPower[blockLen]) % p;
        }
        long long res = 0, p1, p2, tmp;
        p1 = bigPower[len / blockLen] * smlPower[len % blockLen] % p;
        for (int t = head; t > 0; t = nxt[t]) {
            p2 = bigPower[(len - t) / blockLen] * smlPower[(len - t) % blockLen] % p;
            tmp = (p1 - p2) * sum[t] % p;
            res = ((res + tmp) % p + p) % p;
        }
        ans[id] = res;
    }

    void compute() {
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int jobp = query[i].p;
            int id = query[i].id;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            setAns(jobr - jobl + 1, jobp, id);
        }
    }

    void prepare() {
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r >> query[i].p;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

九、复杂度分析

题目1：n 是数组长度，m 是查询数，V 是值域大小（10⁵）。

操作时间复杂度
窗口增删一步（add / del）O(1)
回答一次查询（两段零头 + 整块）O(√V)
指针总移动O((n + m)√n)
全部 m 次查询O((n + m)√n + m√V)

空间上是 numCnt（值域 V）、块的两个数组（√V 个块）和查询数组，O(V + m)。

题目2：n 是数组长度，m 是查询数，一次查询的 len 记作 L。

操作时间复杂度
窗口增删一步O(1)
光速幂打表（每次查询）O(√L)
遍历链表算答案O(桶数) ≤ O(L)
指针总移动O((n + m)√n)
全部 m 次查询O((n + m)√n + m√n)

链表跳过 sum = 0 的桶，实际遍历的桶数远小于 L，这是这题能过的关键常数优化。空间上是 cnt、sum 各 O(n)，O(n)。

十、最后

两题都是莫队把窗口挪到位之后，再靠根号手段结算答案。区别在结算的对象：一个在值域上分块，一个把次数做成桶。

判断该用哪种，看答案问的是「值域的一段」还是「出现次数」。前者把值域切块，后者按次数归并，这两种转换在这一类题里反复出现。

下一节的两题把窗口里的东西换成位图，增删变成一次位运算，查询也靠位运算一次判完。
