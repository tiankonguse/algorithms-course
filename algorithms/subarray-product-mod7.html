乘积最大子数组与余数那一维

最大子数组累加和只要一个量：以 i 结尾的最大累加和。把加法换成乘法，负数会把最小的那个翻成最大的，一个量就不够用了。再换成「挑一些数加起来能被 7 整除」，光记最大值也不够，得把余数一起记进状态。两道题看着不挨着，做的事是同一件：状态里多带一个量。

零、乘积最大子数组：最小值和最大值一起走

拿 [-2, 3, -4] 走一遍，问题立刻出来。只记「以 i 结尾的最大乘积」：i = 0 是 −2，i = 1 取 max(3, −2 × 3) = 3，i = 2 取 max(−4, 3 × (−4)) = −4，三个位置的最大值一路是 3。

正确答案是 24。−2 × 3 = −6 是这一段里最小的乘积，正好被下一个 −4 翻成了 24。只看最大值的写法把 −6 丢掉了，后面就翻不回来。

所以每个位置记两个数：以 i 结尾的最大乘积 mx 和最小乘积 mn。nums[i] 是负数时，乘积最大的候选来自 mn * nums[i]；是正数时来自 mx * nums[i]；是 0 时两个都归零。三个候选一起取 min 和 max，就是代码里那两行。

curmin 和 curmax 要用同一轮旧的 mn、mx 算，不能先更新 mn 再算 curmax。这个坑和「滚动数组覆盖前先存下来」是同一类，写顺手了就中招。

#include <bits/stdc++.h>
    using namespace std;

    // 乘积最大子数组
    // nums 里可能有正数、负数、0，返回非空连续子数组的最大乘积
    // 中间结果可能超出 int，所以全程用 double
    double maxProduct(const vector<int>& nums) {
        double ans = nums[0], mn = nums[0], mx = nums[0], curmin, curmax;
        for (int i = 1; i < (int)nums.size(); i++) {
            // 以 i 结尾的子数组，要么只取 nums[i]，要么接在 i-1 结尾的子数组后面
            // 接的时候必须同时看最大和最小：负数会把最小的那个翻成最大
            curmin = min((double)nums[i], min(mn * nums[i], mx * nums[i]));
            curmax = max((double)nums[i], max(mn * nums[i], mx * nums[i]));
            mn = curmin;
            mx = curmax;
            ans = max(ans, mx);
        }
        return ans;
    }

全程用 double 也是有原因的：中间结果会超出 int。[-1000, -1000, -1000, 2, 2] 的正确答案是 4000000，int 版算出来是 294967296（本机实测），差在第 4 步要算 −2 × 10⁹ × 2 = −4 × 10⁹，已经装不进 int 了。答案本身只有四百万，int 完全装得下，坏的只是中间那一步。

演示：逐位推进 mn / mx / ans

随机数组上各跑 2 万组对拍，两个错版的抓取率：只维护最大值 43.7%，全程 int 45.5%。对数器抓这两种错都很轻松，随便跑几百组就能撞上。

一、被 7 整除：把余数记进状态

第二题换个方向。给定一个非负数组，随便挑数字组成子序列（不要求连续），要求挑出来的累加和是 7 的倍数，问这个累加和最大是多少。

累加和能有多大没有上界，塞不进状态里。能塞进去的是它除以 7 的余数，只有 7 种取值。

定义 dp[i][j]：在 nums[0..i-1] 上随便选，能做到「累加和 % 7 == j」时，最大的那个累加和是多少；做不到就记 −1。答案在 dp[n][0]。

转移时两个数要选或不选。不选 nums[i−1] 直接继承 dp[i-1][j]；选它，记 cur = nums[i-1] % 7，那前 i−1 个数得先做出余数 need 满足 (need + cur) % 7 == j，也就是 need = cur <= j ? j - cur : j - cur + 7。need 这个减法是全题唯一的机关。

#include <bits/stdc++.h>
    using namespace std;

    // 子序列累加和必须被 7 整除的最大累加和
    // nums 非负，可以任意选数字组成子序列，要求子序列累加和 % 7 == 0，返回最大累加和
    int maxSumDiv7(const vector<int>& nums) {
        int n = (int)nums.size();
        // dp[i][j] : nums[0..i-1] 上随意选，能做到子序列累加和 % 7 == j 时，最大累加和
        // dp[i][j] == -1 表示做不到
        vector<vector<int>> dp(n + 1, vector<int>(7, 0));
        dp[0][0] = 0;
        for (int j = 1; j < 7; j++) {
            dp[0][j] = -1;
        }
        for (int i = 1, x, cur, need; i <= n; i++) {
            x = nums[i - 1];
            cur = nums[i - 1] % 7;
            for (int j = 0; j < 7; j++) {
                // 不选 nums[i-1]
                dp[i][j] = dp[i - 1][j];
                // 选 nums[i-1]：前 i-1 个数要先做出余数 need，加上 cur 之后才是 j
                need = cur <= j ? (j - cur) : (j - cur + 7);
                if (dp[i - 1][need] != -1) {
                    dp[i][j] = max(dp[i][j], dp[i - 1][need] + x);
                }
            }
        }
        return dp[n][0];
    }

    // 空间压缩：填第 i 行只用到第 i-1 行
    int maxSumDiv7Roll(const vector<int>& nums) {
        int n = (int)nums.size();
        vector<int> pre(7, -1), cur(7, -1);
        pre[0] = 0;
        for (int i = 1, x, c, need; i <= n; i++) {
            x = nums[i - 1];
            c = nums[i - 1] % 7;
            for (int j = 0; j < 7; j++) {
                cur[j] = pre[j];
                need = c <= j ? (j - c) : (j - c + 7);
                if (pre[need] != -1) {
                    cur[j] = max(cur[j], pre[need] + x);
                }
            }
            pre = cur;
        }
        return pre[0];
    }

哨兵必须是 −1，不能图省事用 0。dp 里存的是最大累加和，0 是个合法值：什么都不选，余数 0、累加和 0。拿 0 当「做不到」会把空集和真答案混在一起，实测 86% 的随机样本会算错；need 的减法写反成 (cur - j + 7) % 7，错 75%。

空间上第 i 行只读第 i−1 行，留两行就够。n = 100 万时二维表 26.7 MB、42.37 毫秒，滚动版 0.05 KB、7.87 毫秒，快 5.4 倍。

演示：逐格填 dp 表

7 这个数是题目定的常数，写成 O(7n) 和 O(n) 是一回事。真要较真，模数换成 m 就是 O(n·m)。

二、复杂度分析

问题时间额外空间
乘积最大子数组O(n)O(1)
被 7 整除的最大子序列和（二维表）O(7n)O(7n)
被 7 整除的最大子序列和（滚动）O(7n)O(7)

空间说明：乘积那题只留 ans、mn、mx 三个变量，写 O(1)；被 7 整除那题二维表是 (n + 1) × 7 个 int，n = 100 万时 26.7 MB，滚动之后只剩两行 56 字节。实测耗时：乘积版 n = 1000 万 22.18 毫秒；被 7 整除的二维表 n = 100 万 42.37 毫秒，滚动版 7.87 毫秒。暴力参考分别是枚举全部子数组 O(n²)（n = 20000 时 152.55 毫秒、2.0 亿个子数组）与枚举全部子序列 O(2ⁿ)（n = 24 时 39.58 毫秒、1677 万个子集）。

三、总结

两题都是「一个量不够」：乘法里负数会把最小值翻成最大值，所以 mn 和 mx 必须成对推进，且要用同一轮的旧值；被 7 整除那题把除不尽的余数当成第二维状态，值域只有 7 格，代价几乎白送。

写这两类题时值得先问一句：状态里记的东西够不够把后面的决策定下来。不够就补一个量，补的如果是余数、正负性、奇偶这种小集合，复杂度基本不变。
