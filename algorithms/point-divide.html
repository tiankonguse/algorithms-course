静态点分治

树上路径统计的主力分治。每次删掉一个重心点，统计跨过它的所有路径，子树递归。这一页讲树的重心、点分治的框架，再做三道模版题：聪聪可可、距离为 k 的点对、权值和为 k 的最少边数。容斥的写法放下一页。

零、背景

树上路径统计是这一批课的主线：指标挂在一条完整的路径上，而每条路径都要照顾到。点分治是这类题的第一选择，也叫重心分解（Centroid Decomposition）：每次在当前连通区里挑一个重心点当「树头」，统计跨过它的路径，然后把它删掉，剩下的每棵子树各自递归。

前置知识两块：树的重心，以及普通的树上 dfs。要留意的是重心处必须按顺序处理多棵子树，否则复杂度会炸，这件事这里正面解决。

一、问题

给一棵 n 个点的带边权的树，指标挂在「一条完整路径」上：路径权值和能被 3 整除的点对有多少、距离恰好为 k 的点对是否存在、权值和等于 k 的路径最少几条边。n 从 10⁴ 到 10⁵。

可以发现这些问题的公共点：答案要数的是所有点对，而每个点对的指标又依赖整条路径。只看局部、想把子树信息拼起来的做法都使不上劲。

二、朴素做法

枚举所有点对，逐对求路径指标。从每个点出发 dfs 一遍可以拿到它到所有点的距离，共 O(n²)；n = 10⁵ 时是 10¹⁰ 级别，不可行。

换根 DP 处理过直径那类「两端信息可拼接」的指标，但计数、存在性这类指标，两棵子树的信息没法在换根时合并，需要另一条路。

分治的出路：让每条路径恰好在「跨过某个被删的点」时被统计一次。要做到不重不漏，只要每条路径被统计的时机唯一，它第一次被分开的那一刻。

三、树的重心

假设当前树有 n 个点。选点 x 当树头时，如果 x 的每棵子树大小都不超过 n/2，x 就是树的重心。一棵树的重心有 1 个或 2 个。

找重心的过程分两步。先 dfs 一遍求出每个点的子树大小和总数 n；然后从出发点往下游走：发现某个儿子 v 的子树大小超过 n/2，就走进 v 重复考察；走不动了，当前点就是重心。

下面这棵 9 个点的树，从 8 出发：8 的大子树有 8 个点，走进 4；4 的大子树 7 个点，走进 2；2 的大子树 6 个点，走进 1；1 的两棵子树各 4 个点，都不超过 4，停。重心是 1。

为什么非要是重心：删掉重心后每棵子树都不超过 n/2，下一层的规模至少减半，分治层数 O(log n)。换成随便一个点，菊花图上每次只消掉 1 个点，层数退化成 O(n)。

四、点分治的框架

框架由四个函数组成。

getCentroid(u, fa)：找到当前连通区的重心，也就是上面的两步走法。

dfs(u, fa, ...)：在当前连通区里收集信息，通常是每个点到某个起点的距离，可能带上边数、最大边权这类伴生指标。

calc(u)：利用收集的信息，求解和重心 u 有关的答案。

solve(u)：对连通区做点分治。标记 vis[u] = true 表示 u 当过重心、从此退出；统计 calc(u)；然后对 u 的每个还没退出的邻居所在子树，重新找重心递归下去。

理解的核心有两条。第一，树上选哪个点当头都不影响答案的求解，所以每层随便挑一个对分治最有利的头，重心。第二，答案只有两种来源：跨过头点的路径，在头点处统计最方便；头点某棵子树内部的路径，留给递归。

具体来说，跨过重心 u 的路径分三类：两端点在 u 的不同子树里；一端就是 u 自己。这两类在本层统计。两端点在同一棵子树里的路径不经过 u，本层不碰，全部留给递归。

这里有个细节。每来到一棵新的连通区，节点数量信息必须重新计算，递归传进来的规模是上一层的旧账，直接用会找错重心，网上大部分写法都栽在这里。所以 getCentroid 每次都先 getSize 重算一遍。

五、题目1：聪聪可可

n 个点组成一棵树，边有边权。点对 (u, v) 的简单路径权值和能被 3 整除则称合法，(x, x) 的路径权值和算 0，(x, y) 与 (y, x) 是不同的点对。打印合法点对数量 / 总数量（n²）的最简分数。1 ≤ n、边权 ≤ 2×10⁴。

样例：5 个点的菊花图，边权 1、2、3、4，答案是 11/25。

路径和只需要按模 3 分类。dfs 收集子树里每个点到重心的距离，cur[0..2] 记三个桶的计数。

关键还是防止同一棵子树配对。calc 按子树逐棵处理：先用之前所有子树的累计桶 all 和当前桶 cur 配对，两段路径和是 3 的倍数只有 0+0、1+2、2+1 三种组合，配完再把 cur 并进 all。跨过重心的路径和是 (a + b) mod 3，两端各取一段正好拼起来。

和重心自己的配对是 cur[0] × 2（距离模 3 为 0 的点，正反两个方向）。calc 里 ans 的初值 1，是重心自己的 (x, x) 这一对；每个点最终都会当一次重心，这些 1 加起来正好是 n 个自身点对。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    int n;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    int cur[3];
    int all[3];

    int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dis) {
        cur[dis % 3]++;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + weight[e]);
            }
        }
    }

    int calc(int u) {
        int ans = 1;
        all[0] = all[1] = all[2] = 0;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (!vis[v]) {
                cur[0] = cur[1] = cur[2] = 0;
                dfs(v, u, w);
                ans += all[0] * cur[0] * 2 + all[1] * cur[2] * 2 + all[2] * cur[1] * 2 + cur[0] * 2;
                all[0] += cur[0];
                all[1] += cur[1];
                all[2] += cur[2];
            }
        }
        return ans;
    }

    int solve(int u) {
        int ans = 0;
        vis[u] = true;
        ans += calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans += solve(getCentroid(v, u));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        int centroid = getCentroid(1, 0);
        int a = solve(centroid);
        int b = n * n;
        int c = gcd(a, b);
        a /= c;
        b /= c;
        cout << a << "/" << b << '\n';
        return 0;
    }

六、题目2：距离为 k 的点对

n 个点组成一棵树，边有边权。m 条查询，每条给数字 k，打印树上距离恰好为 k 的点对是否存在。1 ≤ n ≤ 10⁴，1 ≤ 边权 ≤ 10⁴，1 ≤ m ≤ 100，1 ≤ k ≤ 10⁷。

每次查询都跑一遍重心分解也能出答案，但常数大；正确的姿势是离线：把 m 条查询全部读进来，重心分解全过程只做一次。

exist 数组标记「到重心距离为 d 的点是否出现过」，exist[0] 恒为 true，让重心自己参与配对。dfs 收集子树内距离时顺手剪枝：距离超过所有查询的最大值 maxk 就不用往下走了。

防同一棵子树配对的办法和题 1 同源：当前子树的每个距离 dis，去查 query[i] - dis 是否在 exist 里；这一整棵子树查完，才把它的距离并进 exist。m 条查询的答案在这一轮全部顺带判完。

收尾时只把出现过的距离清回 false，不做整个数组的 memset，10⁷ 大小的数组反复清零会把时间全吃掉。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 101;
    const int MAXV = 10000001;
    int n, m;

    int query[MAXM];
    int maxk;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    int cur[MAXN];
    int cntc;
    int all[MAXN];
    int cnta;
    bool exist[MAXV];

    bool ans[MAXM];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dis) {
        if (dis > maxk) {
            return;
        }
        cur[++cntc] = dis;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + weight[e]);
            }
        }
    }

    void calc(int u) {
        cnta = 0;
        exist[0] = true;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                cntc = 0;
                dfs(v, u, weight[e]);
                for (int i = 1; i <= m; i++) {
                    for (int j = 1; !ans[i] && j <= cntc; j++) {
                        if (query[i] - cur[j] >= 0) {
                            ans[i] |= exist[query[i] - cur[j]];
                        }
                    }
                }
                for (int i = 1; i <= cntc; i++) {
                    all[++cnta] = cur[i];
                    exist[cur[i]] = true;
                }
            }
        }
        for (int i = 1; i <= cnta; i++) {
            exist[all[i]] = false;
        }
    }

    void solve(int u) {
        vis[u] = true;
        calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                solve(getCentroid(v, u));
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i];
            maxk = max(maxk, query[i]);
        }
        solve(getCentroid(1, 0));
        for (int i = 1; i <= m; i++) {
            if (ans[i]) {
                cout << "AYE" << '\n';
            } else {
                cout << "NAY" << '\n';
            }
        }
        return 0;
    }

七、题目3：权值和为 k 的最少边数

n 个点组成一棵树，边有边权。找路径权值和等于 k 的简单路径，打印最少边数，不存在打印 -1。点的编号从 0 开始。1 ≤ n ≤ 2×10⁵，0 ≤ 边权、k ≤ 10⁶。

dp[dis] 记「已处理的那些子树里，到重心距离为 dis 的最少边数」，dp[0] = 0。当前子树的每个点 (dis, edge) 拿 ans = min(ans, dp[k - dis] + edge) 来配对；整棵子树配完，才用它的 edge 更新 dp[dis]。和前两题一样，先配对后并入。

样例：4 个点 0-1-2-3 连成链，边权 1、2、3，k = 3。0 到 2 的路径和是 3 要 2 条边，而 2 到 3 这条边本身权值就是 3，答案是 1。

收尾同样只恢复出现过的 dp 值。读入时点编号整体 +1 转成 1 开始。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int dis, edge;
    };

    const int MAXN = 200001;
    const int MAXK = 1000001;
    const int INF = 1000000001;
    int n, k;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    Node cur[MAXN];
    int cntc;

    int allDis[MAXN];
    int cnta;

    int dp[MAXK];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dis, int edge) {
        if (dis > k) {
            return;
        }
        cur[++cntc] = { dis, edge };
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + weight[e], edge + 1);
            }
        }
    }

    int calc(int u) {
        int ans = INF;
        cnta = 0;
        dp[0] = 0;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                cntc = 0;
                dfs(v, u, weight[e], 1);
                for (int i = 1; i <= cntc; i++) {
                    ans = min(ans, dp[k - cur[i].dis] + cur[i].edge);
                }
                for (int i = 1; i <= cntc; i++) {
                    allDis[++cnta] = cur[i].dis;
                    dp[cur[i].dis] = min(dp[cur[i].dis], cur[i].edge);
                }
            }
        }
        for (int i = 1; i <= cnta; i++) {
            dp[allDis[i]] = INF;
        }
        return ans;
    }

    int solve(int u) {
        vis[u] = true;
        int ans = calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans = min(ans, solve(getCentroid(v, u)));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> k;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            u++;
            v++;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        fill(dp, dp + MAXK, INF);
        int ans = solve(getCentroid(1, 0));
        if (ans == INF) {
            ans = -1;
        }
        cout << ans << '\n';
        return 0;
    }

八、复杂度分析

重心保证每层连通区规模至少减半，分治共 O(log n) 层；每层内找重心和收集信息都是线性。

操作时间复杂度空间复杂度
找重心（每层合计）O(n)O(n + maxk)（题 1、题 2 只需 O(n)，题 3 的 dp 数组按 k 的上界开）
收集距离信息（每层合计）O(n)
题 1 配对（桶大小 3）O(n) / 层
题 2 逐查询判定（每层）O(m·n)
题 1 / 题 3 总计、题 2 总计O(n log n)、O(m·n·log n)

题 2 的 m ≤ 100、n ≤ 10⁴，O(m·n·log n) 约 1.3×10⁷；离线做一遍分解，比每个查询在线跑一遍省一个 m 倍的常数。

九、最后

三个模版题共用一副骨架：找重心、收集距离、按子树先配对后并入、递归。变化的只是「配对」那一步用什么数据结构。

下一页换成容斥的写法：先统计整个连通区的答案，再减去每棵子树内部多算的部分，配对就能放开手做，还能顺手接上双指针和树状数组。
