树上分块（一）：重链序列分块与随机撒点

序列分块能用，是因为下标连续。树上没有这个前提，所以树上分块的第一步永远是「想办法造出连续下标」，或者「干脆不造，用别的东西代替块」。

零、背景

前面几道题，分块切的都是数组：下标连续，[l, r] 天然能分成「左散块 + 中间整块 + 右散块」。

树上的路径没有这种结构，两个端点之间的点既不连续、也不成块。所以要先解决「树的哪个维度是可以切的」。

这一节给两种做法：一种是重链剖分之后对 dfn 序号分块，另一种是随机撒关键点。两种都用在下面这道题上。

一、问题：树上分块模版题

一棵 n 个节点的树，每个节点有点权。m 条操作，每条操作给 k 个点对，每个点对 (x, y) 在树上有一条路径，k 个点对就是 k 条路径。

每条操作打印两个答案：k 条路径上不同点权的数量，以及这些点权集合里没出现的最小非负数（mex）。

1 ≤ n、点对总数 ≤ 10⁵，点权 ≤ 30000。题目强制在线，测试链接：洛谷 P3603。

强制在线的意思是每条操作的 x、y 要和上一次的答案异或才能得到，必须回答完上一条才能读下一条。

二、朴素做法

每条操作开一个 set，把 k 条路径上的点权全塞进去，最后输出 set.size() 和从 0 开始第一个没出现的数。

代价是路径总长度。题目只保证点对总数是 10⁵，单条操作里可以只给一个点对、且这个点对横跨整棵树，一次就是 O(n)，m 次下来是 O(n²)。

可以发现瓶颈在「逐个把点权加进集合」。只要能把路径上的点整段整段地并进去，就能快下来。

点权 ≤ 30000 这个范围提示了做法：用一个 30001 位的位图表示「哪些点权出现过」，不同点权数就是位图里 1 的个数，mex 就是从低位开始第一个 0。合并两条路径的信息，就是一次位图或。

三、重链剖分给出连续下标

重链剖分之后，每个节点拿到一个 dfn 序号，并且有两条性质：一棵子树内的 dfn 是连续的一段，同一条重链上的 dfn 也是连续的一段。

第二条性质是关键。树上任意一条路径，按重链剖分的标准跳法拆开，会变成 O(log n) 段，每一段都是「某条重链上的一段」，也就是 dfn 上连续的一段。

这样问题就变了：原来是「把树上一条路径的点并进位图」，现在是「把 dfn 数组上若干个区间并进位图」。

四、dfn 序列分块 + 位图

对 dfn 数组分块，块长取 √(20n) 左右。每个块维护一个位图 bitSet[b]，表示这个块里出现过哪些点权，预处理时把块内每个点的点权置进去。

一次区间查询 [l, r] 就完全是序列分块的套路了：两端不完整的块逐个点置位 ans[val[i]] = 1，中间完整的块直接 ans |= bitSet[b]。

于是单点信息（散块）和整块信息走的是两条不同的路：散块靠 val 数组一个一个来，整块靠预处理好的位图一次并进去。

五、代码：重链序列分块

两遍 dfs 做重链剖分，第二遍 dfs 顺便把 val[dfn] 填好。之后就是标准的 dfn 分块。

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXB = 401;
    const int MAXV = 30001;
    int n, m, f, k;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int fa[MAXN];
    int dep[MAXN];
    int siz[MAXN];
    int son[MAXN];
    int top[MAXN];
    int dfn[MAXN];
    int val[MAXN];
    int cntd;

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];
    bitset<MAXV> bitSet[MAXB];

    bitset<MAXV> ans;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != f) {
                siz[u] += siz[v];
                if (!son[u] || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        dfn[u] = ++cntd;
        val[cntd] = arr[u];
        if (!son[u]) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head[u], v; e; e = nxt[e]) {
            v = to[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    void query(int l, int r) {
        if (bi[l] == bi[r]) {
            for (int i = l; i <= r; i++) {
                ans[val[i]] = 1;
            }
        } else {
            for (int i = l; i <= br[bi[l]]; i++) {
                ans[val[i]] = 1;
            }
            for (int i = bl[bi[r]]; i <= r; i++) {
                ans[val[i]] = 1;
            }
            for (int i = bi[l] + 1; i <= bi[r] - 1; i++) {
                ans |= bitSet[i];
            }
        }
    }

    void updateAns(int x, int y) {
        while (top[x] != top[y]) {
            if (dep[top[x]] < dep[top[y]]) {
                swap(x, y);
            }
            query(dfn[top[x]], dfn[x]);
            x = fa[top[x]];
        }
        query(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]));
    }

    void prepare() {
        dfs1(1, 0);
        dfs2(1, 1);
        blen = (int)sqrt(n * 20);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
            for (int j = bl[i]; j <= br[i]; j++) {
                bitSet[i][val[j]] = 1;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> f;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        prepare();
        for (int i = 1, lastAns = 0; i <= m; i++) {
            ans.reset(); 
            cin >> k;
            for (int j = 1, x, y; j <= k; j++) {
                cin >> x >> y;
                if (f) {
                    x ^= lastAns;
                    y ^= lastAns;
                }
                updateAns(x, y);
            }
            int ans1 = ans.count();
            int ans2 = MAXV;
            for (int i = 0; i < MAXV; i++) {
                if (ans[i] == 0) {
                    ans2 = i;
                    break;
                }
            }
            cout << ans1 << ' ' << ans2 << '\n';
            lastAns = ans1 + ans2;
        }
        return 0;
    }

updateAns 里的 while 就是重链剖分跳 lca 的那套：谁的 top 深就先把谁这条链处理掉，最后两条链合到一起，再处理剩下的同一条链上的一段。

注意这里的 dfn 分块没有维护修改，只维护查询，因为题目里点权从头到尾不变。

六、另一种思路：随机撒点

重链剖分那套需要两遍 dfs、还要维护重儿子。换一个更省事的办法：在树上随机选大约 √n 个节点当关键点，剩下的是非关键点。

随机撒点之后有两条期望性质：一个非关键点往上走到最近的关键点，期望距离是 O(√n)；两个相邻关键点之间，期望距离也是 O(√n)。

这两条性质正好对应分块里的散块和整块。非关键点到最近关键点之间，就是散块，暴力走；两个相邻关键点之间，就是整块，得能一步拿到。

具体实现是给每个关键点 b 维护两个东西：up[b]，从这个关键点往上遇到的下一个关键点；downSet[b]，从这个关键点往上直到下一个关键点之前，这一段上所有点的点权位图。

七、一次查询的三段

先求 lca，然后从 x 往上一路处理到 lca，y 同理，最后把 lca 自己的点权也置进去。单边的过程分三步。

第一步：x 不是关键点、也还没到 lca，就一路往上走，边走边置位，直到踩到一个关键点或者走到 lca 为止。这一段是散块，代价是期望 O(√n)。

第二步：x 现在是关键点，只要它上面那个关键点 up[x] 还比 lca 深，就整段跳：ans |= downSet[kthMark[x]]，然后 x = up[x]。一次跳一整段，一次位图或。

第三步：整段跳不动了，说明剩下的距离不到一个整段，从 x 暴力走到 lca 就行。

整段跳的次数是 O(√n) 级别，每次一个位图或；两段散块各是 O(√n) 个点。整体是 O(√n) 乘上位图的字数，常数比重链那版大不少。

八、代码：随机撒点

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXB = 401;
    const int MAXV = 30001;
    const int MAXP = 17;
    int n, m, f, k;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dep[MAXN];
    int stjump[MAXN][MAXP];

    int markNum;
    bool vis[MAXN];
    int markNode[MAXN];
    int kthMark[MAXN];
    int up[MAXN];
    bitset<MAXV> downSet[MAXB];

    bitset<MAXV> ans;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            if (to[e] != fa) {
                dfs(to[e], u);
            }
        }
    }

    int lca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    void query(int x, int xylca) {
        while (kthMark[x] == 0 && x != xylca) {
            ans[arr[x]] = 1;
            x = stjump[x][0];
        }
        while (up[x] && dep[up[x]] > dep[xylca]) {
            ans |= downSet[kthMark[x]];
            x = up[x];
        }
        while (x != xylca) {
            ans[arr[x]] = 1;
            x = stjump[x][0];
        }
    }

    void updateAns(int x, int y) {
        int xylca = lca(x, y);
        query(x, xylca);
        query(y, xylca);
        ans[arr[xylca]] = 1;
    }

    void prepare() {
        dfs(1, 0);
        int len = (int)sqrt(n * 10);
        markNum = (n + len - 1) / len;
        for (int b = 1, pick; b <= markNum; b++) {
            do {
                pick = rand() % n + 1;
            } while (vis[pick]);
            vis[pick] = true;
            markNode[b] = pick;
            kthMark[pick] = b;
        }
        for (int b = 1, cur; b <= markNum; b++) {
            downSet[b][arr[markNode[b]]] = 1;
            cur = stjump[markNode[b]][0];
            while (cur != 0) {
                if (kthMark[cur] > 0) {
                    up[markNode[b]] = cur;
                    break;
                } else {
                    downSet[b][arr[cur]] = 1;
                    cur = stjump[cur][0];
                }
            }
        }	
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        srand(time(0));
        cin >> n >> m >> f;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        prepare();
        for (int i = 1, lastAns = 0; i <= m; i++) {
            ans.reset();
            cin >> k;
            for (int j = 1, x, y; j <= k; j++) {
                cin >> x >> y;
                if (f) {
                    x ^= lastAns;
                    y ^= lastAns;
                }
                updateAns(x, y);
            }
            int ans1 = ans.count();
            int ans2 = MAXV;
            for (int i = 0; i < MAXV; i++) {
                if (ans[i] == 0) {
                    ans2 = i;
                    break;
                }
            }
            cout << ans1 << ' ' << ans2 << '\n';
            lastAns = ans1 + ans2;
        }
        return 0;
    }

prepare 里随机挑 markNum 个不重复的节点当关键点，然后对每个关键点往上走到下一个关键点，路上把点权并进 downSet，顺便记下 up。

这里的 downSet 是「关键点自己 + 它上面到下一个关键点之前」的点权集合，是按照 fa 方向往上走的，名字里的 down 只是沿用课程代码的叫法。

九、复杂度分析

设 n 为节点数，B 为 dfn 分块的块长，V = 30001 为点权范围，位图一次或是 V / 64 个字。

操作时间复杂度
重链剖分（两遍 dfs）O(n)
dfn 分块预处理每个块的位图O(n)
重链版：一条路径拆段O(log n) 段
重链版：一段 dfn 区间查询O(B + (n/B)·V/64)
重链版：单次操作O(k·log n·(B + (n/B)·V/64))，B = √(20n) 时约 O(k·log n·√n)
随机撒点：预处理O(n)
随机撒点：单次查询一条路径O(√n + √n·V/64)，期望
mex 的扫描O(V)，每条操作一次

空间上，重链版要 bnum = n/B 个位图，每个 V 位，B = √(20n) 时是 O((n/B)·V) 位；随机撒点版要 markNum ≈ √n 个位图，量级更小。

重链版的块长取 √(20n) 而不是 √n，是因为块间操作（位图或）的常数比块内操作（逐个置位）大得多，把块长放大一点，块数就少一点。这就是前面说的调块长卡常。

十、最后

重链序列分块的路子是：先造出连续下标（dfn），再回到熟悉的序列分块。随机撒点的路子是：不造下标，直接靠撒点把树切成散段和整段。

两种做法都能过这道题，前者确定性好写，后者更短但常数大。再往后还有节点个数分块，那是另一种切法，用在下一节的两道题上。
