2-SAT 的优化建图

上一节把 2-SAT 的判定和前缀优化建图讲完了。这一节看它在真题里怎么用：约束一旦变成「一组里至多一个」或者「某个取值和一段位置上的取值互斥」，两两连边就是 O(k²)，得换成前后缀链、线段树、前缀树把边数压下来。三道题，两次二分，三种压缩结构。

零、背景

回顾一句。2-SAT 把每个变量的两种取值各建一个点，一个子句 (a ∨ b) 拆成两条蕴含边 ¬a → b 与 ¬b → a。整张图跑一遍 tarjan 求强连通分量，某个变量的两个点落在同一个分量里就无解，否则按分量编号就能拼出一组赋值。细节在前一节 2-SAT 与前缀优化建图。

蕴含边天然成对出现。图上有一条 p → q，就一定还有一条 ¬q → ¬p，因为 ¬p ∨ q 和 ¬¬q ∨ ¬p 是同一个子句。这条性质是一种优化手法的前提：只连一半的边，另一半由对称性补上；反过来也表示建图时不能只连单方向。

这一节三道题的约束都不是两个固定变量之间的蕴含，而是「一组里至多一个」和「某个取值要和一段位置上的取值互斥」。这类约束朴素长这样：组里有 k 个候选，任意两个都不能同时为真，于是两两连边，一组 k(k−1) 条，组一大就爆。三种压缩结构分别管三种「一组」的形状：前后缀链管一列候选，线段树管一段位置区间，前缀树管一条前缀链。

一、题目1：黑手党

n 个点、m 条无向边，每条边给两个端点 x、y，一个颜色 c，一个破坏时间 t。要选出一些边摧毁，剩下的留作幸存。摧毁是并行进行的，所以耗时等于被摧毁边里 t 的最大值。

两条限制：任意两条摧毁边在图中不能相邻；任意两条同色的幸存边在图中也不能相邻。求可行方案里最小的摧毁耗时。

外层套二分答案。固定一个上限 limit，破坏时间超过 limit 的边就不能被摧毁，只能幸存，于是问题变成存在性判定，正好交给 2-SAT。

变量取每条边，真表示摧毁，假表示幸存。「t > limit 的边必须幸存」就是强行规定这个变量为假，连一条 i → ¬i，也就是代码里的 addEdge(i, i + m)。

剩下两条限制都能读成「一组里至多一个为真」。

第一条，摧毁边不能相邻。对每个点，挂在它身上的边里至多一条被摧毁。把每条边的两个端点各摊开一次，按端点分组，组内对「摧毁」这个字面量要求至多一个为真。

第二条，同色幸存边不能相邻。对每个点，挂在它身上且同色的边里至多一条幸存。按「端点、颜色」分组，组内对「幸存」这个字面量，也就是摧毁字面量的反面 other(eid)，要求至多一个为真。

「一组里至多一个为真」怎么建才不爆边。设一组的候选字面量是 g₁ 到 g_k，朴素做法是任取 i ≠ j 连一条 g_i → ¬g_j，共 k(k−1) 条。m 到 5×10⁴ 时，一个点上挂满边，这一组的边长就是 2.5×10⁹ 条，直接爆。

前后缀链把它压到线性，结构和 前缀优化建图里那套是同一个思路，只是这里要「至多一个」，所以前缀和后缀两条链都得建。前缀链的节点 P_i 表示「g₁ 到 g_i 全部为假」，三条边把含义钉死：P_i → ¬g_i 说明 P_i 成立则 g_i 为假；P_i → P_{i−1} 把「全假」往左传；关键是 g_i → P_{i−1}，只要 g_i 为真，它前面的候选就一个都不能真。后缀链的 S_i 表示「g_i 到 g_k 全部为假」，完全对称，g_i → S_{i+1} 压住后面。

两条链一合，g_i 为真时它前面全假、后面也全假，正是至多一个。一组 k 个候选，代价是 2k 个辅助点加 6k−4 条边。

二分答案就套在这上面：每次 check 按 limit 重建一遍图，tarjan 判一次矛盾；有解就把上限往小里收，最后得到最小的可行上限。

「一组里至多一个为真」的前后缀优化建图

候选字面量 g 前缀链 P / 后缀链 S 否定字面量 ¬g

完整代码。groupLink 就是前后缀优化建图，两次分组分别处理两条限制：

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int eid, nid, color;
    };

    bool NodeCmp(Node a, Node b) {
        if (a.nid != b.nid) {
            return a.nid < b.nid;
        }
        return a.color < b.color;
    }

    const int MAXM = 50001;
    const int MAXT = 500001;
    const int MAXE = 1000001;
    int n, m, k, maxt, cntt;

    Node arr[MAXM << 1];
    int destroyTime[MAXM];

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int cntg;

    int group[MAXM];
    int gsiz;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int ansTime;
    int ansSize;
    int ansArr[MAXM];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int other(int i) {
        return i <= m ? i + m : i - m;
    }

    void groupLink() {
        if (gsiz > 1) {
            cntt++;
            addEdge(cntt, other(group[1]));
            for (int i = 2; i <= gsiz; i++) {
                cntt++;
                addEdge(cntt, other(group[i]));
                addEdge(group[i], cntt - 1);
                addEdge(cntt, cntt - 1);
            }
            cntt++;
            addEdge(cntt, other(group[gsiz]));
            for (int i = gsiz - 1; i >= 1; i--) {
                cntt++;
                addEdge(cntt, other(group[i]));
                addEdge(group[i], cntt - 1);
                addEdge(cntt, cntt - 1);
            }
        }
    }

    void buildGraph(int limit) {
        cntt = m << 1;
        for (int i = 1; i <= m; i++) {
            if (destroyTime[i] > limit) {
                addEdge(i, i + m);
            }
        }
        for (int l = 1, r = 1; l <= k; l = ++r) {
            int curx = arr[l].nid;
            while (r + 1 <= k && curx == arr[r + 1].nid) {
                r++;
            }
            gsiz = 0;
            for (int i = l; i <= r; i++) {
                group[++gsiz] = arr[i].eid;
            }
            groupLink();
        }
        for (int l = 1, r = 1; l <= k; l = ++r) {
            int curx = arr[l].nid;
            int curc = arr[l].color;
            while (r + 1 <= k && curx == arr[r + 1].nid && curc == arr[r + 1].color) {
                r++;
            }
            gsiz = 0;
            for (int i = l; i <= r; i++) {
                group[++gsiz] = other(arr[i].eid);
            }
            groupLink();
        }
    }

    void clear() {
        for (int i = 1; i <= cntt; i++) {
            head[i] = dfn[i] = belong[i] = 0;
        }
        cntt = cntg = cntd = top = sccCnt = 0;
    }

    bool getAns(int limit) {
        buildGraph(limit);
        for (int i = 1; i <= (m << 1); i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= m; i++) {
            if (belong[i] == belong[i + m]) {
                check = false;
                break;
            }
        }
        if (check) {
            ansTime = ansSize = 0;
            for (int i = 1; i <= m; i++) {
                if (belong[i] < belong[i + m]) {
                    ansTime = max(ansTime, destroyTime[i]);
                    ansArr[++ansSize] = i;
                }
            }
        }
        clear();
        return check;
    }

    bool compute() {
        sort(arr + 1, arr + k + 1, NodeCmp);
        int l = 1, r = maxt, mid;
        bool hasAns = false;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (getAns(mid)) {
                hasAns = true;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return hasAns;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        maxt = 0;
        for (int i = 1, x, y, c, t; i <= m; i++) {
            cin >> x >> y >> c >> t;
            arr[++k].eid = i;
            arr[k].nid = x;
            arr[k].color = c;
            arr[++k].eid = i;
            arr[k].nid = y;
            arr[k].color = c;
            destroyTime[i] = t;
            maxt = max(maxt, t);
        }
        bool check = compute();
        if (check) {
            cout << "Yes" << "\n";
            cout << ansTime << " " << ansSize << "\n";
            for (int i = 1; i <= ansSize; i++) {
                cout << ansArr[i] << " ";
            }
        } else {
            cout << "No" << "\n";
        }
        return 0;
    }

二、题目2：旗帜

n 面旗子，第 i 面有 a[i]、b[i] 两个可选位置，每面旗子挑一个放下。两面旗子之间的最小距离 d 越大越好看，求所有可能 d 里的最大值。

还是二分。固定 d 之后，「距离小于 d 的两面旗子不能同时出现」是一条硬约束，判定交给 2-SAT。

变量取每面旗子，真表示放 a[i]，假表示放 b[i]。所有候选位置一共 2n 个，编号 i 与 i+n 是同一面旗子的两个选择。约束说的是：候选位置 u 和候选位置 v 来自不同旗子、并且距离小于 d，那么 u 和 v 不能同时被选，连一条 u → ¬v。

朴素做法对每个候选扫一遍和它距离小于 d 的所有候选，一条条连。一个候选平均要连 O(n) 条，总共 O(n²)，n 到 10⁴ 已经是 10⁸ 量级，再乘上二分就没法看。

注意到「和 u 冲突的候选」在按位置排好序之后是一段连续区间。把 2n 个候选位置按坐标排序，在这条序列上建线段树，每个树节点代表一段区间，树边从父节点指向两个儿子，于是「落到某个节点」就等价于「落到这个节点管的所有位置」。这套结构就是 线段树优化建图里那副，搬过来用。候选 u 连向覆盖它冲突区间的若干个树节点，每次只要 O(log n) 条边，总数从 O(n²) 降到 O(n log n)。

叶子挂的不是别的，正是「这个候选没有被选中」的否定字面量，这样区间节点往下推，推出来的就是「这些候选全部不能选」。

这里有个细节。冲突区间要挖掉候选自己，代码里把它拆成 [l, i−1] 和 [i+1, r] 两段再连。如果不挖，就会出现 u → ¬u 这种自指边，等于强行规定 u 必须为假，把本来可以选的位置给禁掉了。除非确实想表达「这个取值不能用」，否则建图时要避开会推出 x → ¬x 的假设。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int pos, xid;
    };

    bool NodeCmp(Node a, Node b) {
        if (a.pos != b.pos) {
            return a.pos < b.pos;
        }
        return a.xid < b.xid;
    }

    const int MAXN = 10001;
    const int MAXT = 100001;
    const int MAXE = 1000001;
    int n, k;
    int a[MAXN];
    int b[MAXN];

    Node arr[MAXN << 1];

    int ls[MAXT];
    int rs[MAXT];
    int root;
    int cntt;

    int head[MAXT];
    int nxt[MAXE];
    int to[MAXE];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int kth(int num) {
        int l = 1, r = k, mid, ans = k + 1;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (arr[mid].pos >= num) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int other(int i) {
        return i <= n ? i + n : i - n;
    }

    int build(int l, int r) {
        int rt;
        if (l == r) {
            rt = other(arr[l].xid);
        } else {
            rt = ++cntt;
            int mid = (l + r) >> 1;
            ls[rt] = build(l, mid);
            rs[rt] = build(mid + 1, r);
            addEdge(rt, ls[rt]);
            addEdge(rt, rs[rt]);
        }
        return rt;
    }

    void xToRange(int xid, int jobl, int jobr, int l, int r, int i) {
        if (jobl > jobr) {
            return;
        }
        if (jobl <= l && r <= jobr) {
            addEdge(xid, i);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                xToRange(xid, jobl, jobr, l, mid, ls[i]);
            }
            if (jobr > mid) {
                xToRange(xid, jobl, jobr, mid + 1, r, rs[i]);
            }
        }
    }

    void buildGraph(int d) {
        cntt = k;
        root = build(1, k);
        for (int i = 1; i <= k; i++) {
            int pos = arr[i].pos;
            int l = kth(pos - d + 1);
            int r = kth(pos + d) - 1;
            int x = arr[i].xid;
            xToRange(x, l, i - 1, 1, k, root);
            xToRange(x, i + 1, r, 1, k, root);
        }
    }

    void clear() {
        for (int i = 1; i <= cntt; i++) {
            head[i] = dfn[i] = belong[i] = 0;
        }
        cntt = cntg = cntd = top = sccCnt = 0;
    }

    bool check(int d) {
        buildGraph(d);
        for (int i = 1; i <= (n << 1); i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                check = false;
                break;
            }
        }
        clear();
        return check;
    }

    int compute() {
        for (int i = 1; i <= n; i++) {
            arr[i].pos = a[i];
            arr[i].xid = i;
            arr[i + n].pos = b[i];
            arr[i + n].xid = i + n;
        }
        k = n << 1;
        sort(arr + 1, arr + k + 1, NodeCmp);
        int l = 0, r = arr[k].pos, d, ans = 0;
        while (l <= r) {
            d = (l + r) >> 1;
            if (check(d)) {
                ans = d;
                l = d + 1;
            } else {
                r = d - 1;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> a[i] >> b[i];
        }
        int ans = compute();
        cout << ans << "\n";
        return 0;
    }

三、题目3：编码

n 个只含 0、1、? 的字符串，每个串最多一个问号。问号要定成 0 或 1，要求确定之后没有任何一个串是另一个串的前缀。

变量取每个串的问号，真表示定成 0，假表示定成 1；本来就没有问号的串，取值被锁死。约束是「两个串不能一个是另一个的前缀」，翻译过去就是这两个串的取值不能同时被选，一条互斥边。

朴素地枚举每一对串比较前缀关系，是 O(n²) 次比较，字符总数到 5×10⁵ 也过不去。把所有候选串塞进一棵前缀树，前缀关系就变成了树上的祖先—后代关系。

于是约束分三种，全在树上处理。第一种，一个候选串 x 和「根到它父亲这条链上所有候选串」互斥，那些是 x 的真前缀。第二种，x 和「它所在节点的子树里所有候选串」互斥，那些串把 x 当成了真前缀。第三种，终点落在同一个节点的候选串其实是同一个字符串，彼此也互斥。

前两种靠树上两条链压。每个树节点配一个 up 节点和一个 down 节点：up 顺着父指针往上垒，表示「这条到根的路径上有候选串被选中」；down 顺着子树往下垒，表示「这棵子树里有候选串被选中」。候选 x 只要连到 up、down 上，就能一次性把「所有和它前缀互斥的串」排除掉，边数是 O(串长) 而不是 O(串数)。

第三种还是前后缀优化建图，和题目1 的 groupLink 是同一段代码：把同一个节点上的候选串排成一列，组内至多一个被选。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXP = 1000002;
    const int MAXT = 5000001;
    const int MAXE = 10000001;
    int n, cntt;

    string arr[MAXN << 1];

    int headg[MAXT];
    int nextg[MAXE];
    int tog[MAXE];
    int cntg;

    int tree[MAXP][2];
    int fa[MAXP];
    int up[MAXP];
    int down[MAXP];
    int cntp;

    int headx[MAXP];
    int nextx[MAXP];
    int tox[MAXP];
    int cntx;

    int group[MAXN];
    int gsiz;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    void addEdge(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = headg[u]; e > 0; e = nextg[e]) {
            int v = tog[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int other(int x) {
        return x <= n ? x + n : x - n;
    }

    void addGroup(int u, int x) {
        nextx[++cntx] = headx[u];
        tox[cntx] = x;
        headx[u] = cntx;
    }

    void insert(int x) {
        string str = arr[x];
        int cur = 1;
        for (int si = 0; si < (int)str.length(); si++) {
            int path = str[si] == '0' ? 0 : 1;
            if (tree[cur][path] == 0) {
                tree[cur][path] = ++cntp;
                fa[cntp] = cur;
                up[cntp] = ++cntt;
                down[cntp] = ++cntt;
                addEdge(up[cntp], up[cur]);
                addEdge(down[cur], down[cntp]);
            }
            cur = tree[cur][path];
        }
        addEdge(x, up[fa[cur]]);
        addEdge(up[cur], other(x));
        addEdge(x, down[cur]);
        addEdge(down[fa[cur]], other(x));
        addGroup(cur, x);
    }

    void groupLink() {
        if (gsiz > 1) {
            cntt++;
            addEdge(cntt, other(group[1]));
            for (int i = 2; i <= gsiz; i++) {
                cntt++;
                addEdge(cntt, other(group[i]));
                addEdge(group[i], cntt - 1);
                addEdge(cntt, cntt - 1);
            }
            cntt++;
            addEdge(cntt, other(group[gsiz]));
            for (int i = gsiz - 1; i >= 1; i--) {
                cntt++;
                addEdge(cntt, other(group[i]));
                addEdge(group[i], cntt - 1);
                addEdge(cntt, cntt - 1);
            }
        }
    }

    void buildGraph() {
        cntt = n << 1;
        cntp = 1;
        up[1] = ++cntt;
        down[1] = ++cntt;
        for (int x = 1; x <= (n << 1); x++) {
            insert(x);
        }
        for (int u = 1; u <= cntp; u++) {
            gsiz = 0;
            for (int e = headx[u]; e > 0; e = nextx[e]) {
                group[++gsiz] = tox[e];
            }
            groupLink();
        }
    }

    void addString(int i, string s) {
        int mark = -1;
        for (int si = 0; si < (int)s.length(); si++) {
            if (s[si] == '?') {
                mark = si;
                break;
            }
        }
        if (mark == -1) {
            if (s[0] == '0') {
                addEdge(i + n, i);
            } else {
                addEdge(i, i + n);
            }
            mark = 0;
        }
        s[mark] = '0';
        arr[i] = s;
        s[mark] = '1';
        arr[i + n] = s;
    }

四、复杂度分析

三道题的建图规模都从「候选数的平方」降到了「候选数的线性或者对数」。

步骤时间复杂度空间复杂度
题目1 一次 check（前后缀建图 + tarjan）O(m)O(m)
题目1 整体（二分 O(log maxT) 次）O(m log maxT)
题目2 一次 check（线段树建图 + tarjan）O(n log n)O(n log n)
题目2 整体（二分 O(log maxP) 次）O(n log n log maxP)
题目3 建图 + tarjan（L 为字符总数）O(L)O(L)

边数的对比更直观。题目1 的一组候选，朴素是 k(k−1) 条，前后缀链是 6k−4 条，前者平方级、后者线性，两组分组都跑一遍，总量从最坏 O(m²) 掉到 O(m)。题目2 里每个候选要连的是一段区间，朴素 O(n) 条，线段树拆成 O(log n) 个节点，总量从 O(n²) 掉到 O(n log n)。题目3 的候选串总共 L 个字符，前缀树上每个候选只连常数条边，总量 O(L)。

tarjan 的复杂度是点数加边数的线性，所以三题的判定步骤都跟着建图规模走。空间同样是线性的，题目2 的线段树把点数和边数都乘了一个 log n。

五、最后

三道题的骨架完全一样：二分答案或者直接判定，把约束翻成「一组里至多一个」，按组的形状选一种压缩结构，tarjan 收尾。前后缀链对应一列候选，线段树对应一段位置区间，前缀树对应一条前缀链。

建图的手法记住之后，剩下的都是翻译。黑手党要把两条限制分别按端点和按「端点、颜色」分组，旗帜要看出冲突候选排好序之后是连续区间，编码要把前缀关系认到树上的祖先关系上。翻译对了，图自然就是线性的。
