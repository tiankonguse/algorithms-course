扩展欧几里得：从裴蜀定理到逆元

裴蜀定理说 ax+by=gcd(a,b) 有解，但没说怎么找。扩展欧几里得在算 gcd 的递归里顺手把特解带出来，一行不多一行不少。它是求逆元的通用底座：费马小定理要求模是质数，exgcd 只要求互质。

零、背景

上一页用 220、170 手工倒推出了 10 = 7·220 + (−9)·170。每次手工倒推太累，扩展欧几里得就是把「顺着辗转相除倒推」写成通用代码：递归到 (d, 0) 再一层层回退，每层用下一层的特解拼出自己的特解。

一、扩展欧几里得

递归 exgcd(a, b)：b=0 时 gcd=a，特解 x=1、y=0（a·1 + 0·0 = a 成立）。否则先递归 exgcd(b, a%b)，拿到下一层的特解 (x′, y′)，满足 b·x′ + (a%b)·y′ = d。

设 a = b·q + r，其中 q = a/b、r = a%b。把 r = a − b·q 代进下一层的等式：

b·x′ + (a − b·q)·y′ = d → a·y′ + b·(x′ − q·y′) = d。

于是当前层的特解 x = y′、y = x′ − q·y′。递归下行时记不住旧值没关系，回溯时从下一层直接算。

long long d, x, y, px, py;

    void exgcd(long long a, long long b) {
      if (b == 0) {
        d = a;
        x = 1;
        y = 0;
      } else {
        exgcd(b, a % b);
        px = x;
        py = y;
        x = py;
        y = px - py * (a / b);
      }
    }

px、py 是回溯时暂存的下一层 x、y：先 exgcd(b, a%b) 把全局 x、y 覆盖成下一层的值，备份到 px、py，再按公式改写成当前层的值。入参 a、b 必须非负，负数的 gcd 语义会乱。

递归深度 O(log min(a,b))，每层一次取模。理论 O(log)，实际取模代价高一些，但仍是几十层的量级，a、b 到 2e9 也毫秒级。

二、均匀生成器（POJ 1597）

seed(1)=0，seed(i+1)=(seed(i)+step) % mod。step=3、mod=5：0、3、1、4、2，五个数全覆盖，判 Good Choice。step=2、mod=4：0、2、0、2…，只有一半，判 Bad Choice。

序列走的都是 step 的累加：seed 集合是 { k·step mod mod }。设 g=gcd(step,mod)，k·step 一定是 g 的倍数，模 mod 后依然落在 g 的倍数上；反过来裴蜀定理保证 g 的每个倍数都能被 k·step 凑出来（模意义下同理）。所以可达集合大小 = mod/g。覆盖全部 ⟺ mod/g = mod ⟺ g = 1。判 gcd(step,mod)==1 一行收工。

int gcd(int a, int b) {
      return b == 0 ? a : gcd(b, a % b);
    }

    int main() {
      int step, mod;
      while (scanf("%d %d", &step, &mod) != EOF) {
        printf("%10d%10d    ", step, mod);
        if (gcd(step, mod) == 1) {
          printf("Good Choice\n");
        } else {
          printf("Bad Choice\n");
        }
      }
      return 0;
    }

三、同余方程（洛谷 P1082）

求 ax ≡ 1 (mod b) 的最小正整数解，题目保证 a、b 互质。翻译成不定方程：ax − 1 = b·y → ax + (−y)·b = 1。a、b 互质时 gcd=1，exgcd(a, b) 解出特解 x 和某个 y（它其实是 −y，但没人关心 y）。

特解可能是负数。所有解形如 x + k·b（模 b 意义下），调成最小正整数就是 (x % b + b) % b。

long long d, x, y, px, py;

    void exgcd(long long a, long long b) {
      if (b == 0) {
        d = a;
        x = 1;
        y = 0;
      } else {
        exgcd(b, a % b);
        px = x;
        py = y;
        x = py;
        y = px - py * (a / b);
      }
    }

    int main() {
      long long a, b;
      scanf("%lld %lld", &a, &b);
      exgcd(a, b);
      printf("%lld\n", (x % b + b) % b);
      return 0;
    }

费马小定理求逆元要求模是质数，这里 b 不一定是质数，所以必须走 exgcd。a、b ≤ 2e9，px − py·(a/b) 可能到 1e18 量级，必须 long long。

复杂度分析

题目时间复杂度空间复杂度
均匀生成器（POJ1597）O(log min(step,mod))O(1)
同余方程（P1082）O(log min(a,b))O(log min(a,b)) 递归栈

两题各一次 gcd / exgcd，b 到 2e9 时递归几十层，栈空间可以忽略。

总结

扩展欧几里得在回溯时用下一层的特解拼当前层：x = y′、y = x′ − q·y′，入参保证非负。均匀生成器把「能不能覆盖全部」化成 gcd(step,mod)==1；同余方程 ax ≡ 1 化成一元不定方程 ax + by = 1，exgcd 求逆元不要求模为质数，答案记得 (x%b+b)%b 调正。
