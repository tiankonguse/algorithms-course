虚树的六个题目

建树只是前置动作，难的是虚树上那一遍 dp 怎么写。这一页把六个题逐个做完：前三道是模版题，能看出「边权取什么」和「头节点要不要补」；后三道是经典题，分别要求双向边、子树大小修正，以及干脆不建树、只用虚树的性质。

零、背景

上一页给出了虚树的两种建树方式和它的复杂度：点数是 O(k)，每条边代表原树上的一段路径，路径上没有别的虚树点。这一页沿用那份代码骨架，六个题共用同一套 dfs + getLca。

六个题分两组。前三道（王国和城市、大工程、消耗战）里，虚树只是一个「把 O(n) 压成 O(k)」的支架，dp 本身很短。后三道（世界树、病毒传播、寻宝游戏）里，答案还牵扯虚树之外的原树信息，要靠子树大小、Dijkstra 或者 dfn 环来补。

下面统一用这一棵 13 个点的树做例子：1 连 2、3、4；2 连 5、6；5 连 7、8；6 连 9；3 连 10、11；4 连 12、13。dfs 按编号从小到大走，dfn 依次是 1、2、5、7、8、6、9、3、10、11、4、12、13。

一、题目1：王国和城市（CF613D）

一棵 n 个点的树，q 条查询。每条查询给出 k 个互不相同的点，称作重要点。你可以攻占若干个非重要点，被攻占的点无法通行；要让重要点两两之间不再连通，打印最少攻占几个非重要点，做不到就打印 -1。1 ≤ n、q ≤ 10⁵，所有查询给出的点的总数 ≤ 10⁵。测试链接：https://www.luogu.com.cn/problem/CF613D。

先判无解：如果某个重要点的父亲也是重要点，这两个点直接相邻，中间没有可以攻占的点，一定无解。代码里用倍增表的第 0 层扫一遍就能判出来。

有解时建虚树，然后跑一遍树型 dp。cost[u] 是 u 的虚树子树里已经付出的攻占数，siz[u] 是处理完 u 的子树之后还有几条「活着的、需要继续往上连通」的关键点分支。

合并完所有儿子之后分两种情形。u 自己是重要点：子树里每条分支都必须在进入 u 之前被掐断，于是 cost[u] += siz[u]，然后 u 自己变成一条分支，siz[u] = 1。u 不是重要点且 siz[u] > 1：有两条以上的分支要穿过 u，只能把 u 自己攻占掉，于是 cost[u]++、siz[u] = 0。其余情形不动。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXP = 20;
    int n, q, k;

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int cntg;

    int headv[MAXN];
    int nextv[MAXN];
    int tov[MAXN];
    int cntv;

    int dep[MAXN];
    int dfn[MAXN];
    int stjump[MAXN][MAXP];
    int cntd;

    int arr[MAXN];
    bool isKey[MAXN];

    int tmp[MAXN << 1];
    int stk[MAXN];

    int siz[MAXN];
    int cost[MAXN];

    bool cmp(int x, int y) {
        return dfn[x] < dfn[y];
    }

    void addEdgeG(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void addEdgeV(int u, int v) {
        nextv[++cntv] = headv[u];
        tov[cntv] = v;
        headv[u] = cntv;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        dfn[u] = ++cntd;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = headg[u]; e; e = nextg[e]) {
            if (tog[e] != fa) {
                dfs(tog[e], u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) a = stjump[a][p];
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int buildVirtualTree1() {
        sort(arr + 1, arr + k + 1, cmp);
        int len = 0;
        for (int i = 1; i < k; i++) {
            tmp[++len] = arr[i];
            tmp[++len] = getLca(arr[i], arr[i + 1]);
        }
        tmp[++len] = arr[k];
        sort(tmp + 1, tmp + len + 1, cmp);
        int unique = 1;
        for (int i = 2; i <= len; i++) {
            if (tmp[unique] != tmp[i]) {
                tmp[++unique] = tmp[i];
            }
        }
        cntv = 0;
        for (int i = 1; i <= unique; i++) {
            headv[tmp[i]] = 0;
        }
        for (int i = 1; i < unique; i++) {
            addEdgeV(getLca(tmp[i], tmp[i + 1]), tmp[i + 1]);
        }
        return tmp[1];
    }

    int buildVirtualTree2() {
        sort(arr + 1, arr + k + 1, cmp);
        cntv = 0;
        headv[arr[1]] = 0;
        int top = 0;
        stk[++top] = arr[1];
        for (int i = 2; i <= k; i++) {
            int x = arr[i];
            int y = stk[top];
            int lca = getLca(x, y);
            while (top > 1 && dfn[stk[top - 1]] >= dfn[lca]) {
                addEdgeV(stk[top - 1], stk[top]);
                top--;
            }
            if (lca != stk[top]) {
                headv[lca] = 0;
                addEdgeV(lca, stk[top]);
                stk[top] = lca;
            }
            headv[x] = 0;
            stk[++top] = x;
        }
        while (top > 1) {
            addEdgeV(stk[top - 1], stk[top]);
            top--;
        }
        return stk[1];
    }

    void dp(int u) {
        cost[u] = siz[u] = 0;
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            dp(v);
            cost[u] += cost[v];
            siz[u] += siz[v];
        }
        if (isKey[u]) {
            cost[u] += siz[u];
            siz[u] = 1;
        } else if (siz[u] > 1) {
            cost[u]++;
            siz[u] = 0;
        }
    }

    int compute() {
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = true;
        }
        bool check = true;
        for (int i = 1; i <= k; i++) {
            if (isKey[stjump[arr[i]][0]]) {
                check = false;
                break;
            }
        }
        int ans = -1;
        if (check) {
            int tree = buildVirtualTree1();
            dp(tree);
            ans = cost[tree];
        }
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = false;
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdgeG(u, v);
            addEdgeG(v, u);
        }
        dfs(1, 0);
        cin >> q;
        for (int t = 1; t <= q; t++) {
            cin >> k;
            for (int i = 1; i <= k; i++) {
                cin >> arr[i];
            }
            cout << compute() << '\n';
        }
        return 0;
    }

二、题目2：大工程（P4103）

一棵 n 个点的树。在 a、b 之间建立新通道的代价是两点在树上的距离。q 条查询，每条给出 k 个点，这 k 个点两两之间都会建立新通道，打印代价之和、代价的最小值、代价的最大值。1 ≤ n ≤ 10⁶，1 ≤ q ≤ 5 × 10⁴，所有查询给出的点的总数 ≤ 2n。测试链接：https://www.luogu.com.cn/problem/P4103。

虚树的边权取深度差。dp 时每个点维护四个量：siz[u] 是子树里关键点的个数，sum[u] 是这些点到 u 的距离之和，near[u] / far[u] 是子树里离 u 最近 / 最远的关键点距离。合并一个儿子 v 时，设 len = dep[v] − dep[u]：新产生的 k 对通道里，跨过 u 到 v 这一段的有 siz[u] × siz[v] 对。

代价和那一项可以拆开看：v 侧每个点要走「自己到 v 的距离 + len」，u 侧每个点要走「自己到 u 的距离」，于是新增的总长是 (sum[u] + siz[u] × len) × siz[v] + sum[v] × siz[u]。最小值和最大值更简单：穿过这条边的最近一对是 near[u] + near[v] + len，最远一对是 far[u] + far[v] + len。

大工程的 dp，一条边一条边合并

关键点是 {7, 9, 10, 12}，虚树 1→{2,10,12}、2→{7,9}。点「下一步」，看每合并一条虚边，siz、sum 和三个答案怎么变。

    void dp(int u) {
        siz[u] = isKey[u] ? 1 : 0;
        sum[u] = 0;
        if (isKey[u]) {
            near[u] = far[u] = 0;
        } else {
            near[u] = INF;
            far[u] = -INF;
        }
        for (int e = headv[u]; e; e = nextv[e]) {
            dp(tov[e]);
        }
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            long long len = (long long)dep[v] - dep[u];
            costSum += (sum[u] + 1LL * siz[u] * len) * siz[v] + sum[v] * siz[u];
            siz[u] += siz[v];
            sum[u] += sum[v] + len * siz[v];
            costMin = min(costMin, near[u] + near[v] + len);
            costMax = max(costMax, far[u] + far[v] + len);
            near[u] = min(near[u], near[v] + len);
            far[u] = max(far[u], far[v] + len);
        }
    }

    void compute() {
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = true;
        }
        int tree = buildVirtualTree1();
        costSum = 0;
        costMin = INF;
        costMax = -INF;
        dp(tree);
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = false;
        }
    }

    }

三、题目3：消耗战（P2495）

一棵 n 个点的树，每条边有边权。q 条查询，每条给出 k 个关键节点，且一定不包含 1 号节点。你可以随意切断边，代价就是边权；要让所有关键节点都无法到达 1 号节点，打印最小总代价。1 ≤ n、q ≤ 5 × 10⁵，所有查询给出的点的总数 ≤ 5 × 10⁵。测试链接：https://www.luogu.com.cn/problem/P2495。

这一题必须把 1 号点额外塞进虚树。虚树的头是 dfn 最小的那个点，未必是原树的头；而答案要求所有关键点都到不了 1，dp 必须真的从 1 号点开始算。做法是在塞 LCA 之前先塞一个 1 进去，后面排序去重时它自然落在第一位。

边权也不再是深度差，而是原树路径上的最小边权。因为「切断 u 到 v 这条路径」的最小代价就是路径上最便宜的那条边。倍增表多维护一个 mindist[u][p]（u 往上 2ᵖ 条边里的最小边权），getDist 在往上跳的时候顺手取 min。

dp 只有一行转移：对每个儿子 v，如果 v 是关键点，子树里全是关键点、只能切断 u 到 v 这一段，代价就是边权 w；否则在「切断 u 到 v 这一段」和「在 v 的子树里继续切」之间取小。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXP = 20;
    int n, q, k;

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int weightg[MAXN << 1];
    int cntg;

    int headv[MAXN];
    int nextv[MAXN];
    int tov[MAXN];
    int weightv[MAXN];
    int cntv;

    int dep[MAXN];
    int dfn[MAXN];
    int stjump[MAXN][MAXP];
    int mindist[MAXN][MAXP];
    int cntd;

    int arr[MAXN];
    bool isKey[MAXN];
    int tmp[MAXN << 1];
    int stk[MAXN];

    long long cost[MAXN];

    bool cmp(int x, int y) {
        return dfn[x] < dfn[y];
    }

    void addEdgeG(int u, int v, int w) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        weightg[cntg] = w;
        headg[u] = cntg;
    }

    void addEdgeV(int u, int v, int w) {
        nextv[++cntv] = headv[u];
        tov[cntv] = v;
        weightv[cntv] = w;
        headv[u] = cntv;
    }

    void dfs(int u, int fa, int w) {
        dep[u] = dep[fa] + 1;
        dfn[u] = ++cntd;
        stjump[u][0] = fa;
        mindist[u][0] = w;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
            mindist[u][p] = min(mindist[u][p - 1], mindist[stjump[u][p - 1]][p - 1]);
        }
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa) dfs(v, u, weightg[e]);
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int getDist(int u, int v) {
        int dist = 100000001;
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[v][p]] >= dep[u]) {
                dist = min(dist, mindist[v][p]);
                v = stjump[v][p];
            }
        }
        return dist;
    }

    int buildVirtualTree1() {
        sort(arr + 1, arr + k + 1, cmp);
        int len = 0;
        tmp[++len] = 1;
        for (int i = 1; i < k; i++) {
            tmp[++len] = arr[i];
            tmp[++len] = getLca(arr[i], arr[i + 1]);
        }
        tmp[++len] = arr[k];
        sort(tmp + 1, tmp + len + 1, cmp);
        int unique = 1;
        for (int i = 2; i <= len; i++) {
            if (tmp[unique] != tmp[i]) {
                tmp[++unique] = tmp[i];
            }
        }
        cntv = 0;
        for (int i = 1; i <= unique; i++) {
            headv[tmp[i]] = 0;
        }
        for (int i = 1; i < unique; i++) {
            int lca = getLca(tmp[i], tmp[i + 1]);
            addEdgeV(lca, tmp[i + 1], getDist(lca, tmp[i + 1]));
        }
        return tmp[1];
    }

    int buildVirtualTree2() {
        sort(arr + 1, arr + k + 1, cmp);
        cntv = 0;
        headv[1] = 0;
        int top = 0;
        stk[++top] = 1;
        for (int i = 1; i <= k; i++) {
            int x = arr[i];
            int y = stk[top];
            int lca = getLca(x, y);
            while (top > 1 && dfn[stk[top - 1]] >= dfn[lca]) {
                addEdgeV(stk[top - 1], stk[top], getDist(stk[top - 1], stk[top]));
                top--;
            }
            if (lca != stk[top]) {
                headv[lca] = 0;
                addEdgeV(lca, stk[top], getDist(lca, stk[top]));
                stk[top] = lca;
            }
            headv[x] = 0;
            stk[++top] = x;
        }
        while (top > 1) {
            addEdgeV(stk[top - 1], stk[top], getDist(stk[top - 1], stk[top]));
            top--;
        }
        return stk[1];
    }

    void dp(int u) {
        for (int e = headv[u]; e; e = nextv[e]) {
            dp(tov[e]);
        }
        cost[u] = 0;
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            int w = weightv[e];
            if (isKey[v]) {
                cost[u] += w;
            } else {
                cost[u] += min(cost[v], (long long)w);
            }
        }
    }

    long long compute() {
        for (int i = 1; i <= k; i++) {

        int tree = buildVirtualTree1();
        dp(tree);

            isKey[arr[i]] = false;
        }
        return cost[tree];
    }

四、题目4：世界树（P3233）

一棵 n 个点的树。q 条查询，每条给出 k 个管理点；树上每个点都找最近的管理点来管理自己，距离相同时选编号最小的管理点；打印每个管理点管理了多少个点。1 ≤ n、q ≤ 3 × 10⁵，所有查询给出的管理点总数 ≤ 3 × 10⁵。测试链接：https://www.luogu.com.cn/problem/P3233。

同样要把 1 号点补进虚树，理由和上一题一样：统计要从整棵树的头开始。这一题分三遍 dfs。

第一遍自底向上：dist[u]、manager[u] 取子树里最近的，遇到管理点就把自己置成距离 0、管理者是自己。第二遍自顶向下：用父亲的结果去更新儿子，把「从上方绕过来更近」的情况补上。两遍之后虚树上每个点的归属都定了。

第三遍才是难点。虚树上一条边 u → v 在原树上是一整段路径，路径中间那些点不在虚树里，它们的归属不能直接继承 u 或 v。做法是在这条路径上二分一个分界点 x：x 及其子树归 manager[v]，x 以上归 manager[u]。统计时先假设 u 的整棵原树子树都归 manager[u]，再把「x 的整棵子树」那部分挪给 manager[v]，最后扣掉 v 的整棵子树，递归下去。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    const int MAXP = 20;
    int n, q, k;

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int cntg;

    int headv[MAXN];
    int nextv[MAXN];
    int tov[MAXN];
    int cntv;

    int dep[MAXN];
    int siz[MAXN];
    int dfn[MAXN];
    int stjump[MAXN][MAXP];
    int cntd;

    int order[MAXN];
    int arr[MAXN];
    bool isKey[MAXN];
    int tmp[MAXN << 1];

    int manager[MAXN];
    int dist[MAXN];
    int ans[MAXN];

    bool cmp(int x, int y) {
        return dfn[x] < dfn[y];
    }

    void addEdgeG(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void addEdgeV(int u, int v) {
        nextv[++cntv] = headv[u];
        tov[cntv] = v;
        headv[u] = cntv;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        siz[u] = 1;
        dfn[u] = ++cntd;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa) {
                dfs(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int buildVirtualTree() {
        sort(arr + 1, arr + k + 1, cmp);
        int len = 0;
        tmp[++len] = 1;
        for (int i = 1; i < k; i++) {
            tmp[++len] = arr[i];
            tmp[++len] = getLca(arr[i], arr[i + 1]);
        }
        tmp[++len] = arr[k];
        sort(tmp + 1, tmp + len + 1, cmp);
        int unique = 1;
        for (int i = 2; i <= len; i++) {
            if (tmp[unique] != tmp[i]) {
                tmp[++unique] = tmp[i];
            }
        }
        cntv = 0;
        for (int i = 1; i <= unique; i++) {
            headv[tmp[i]] = 0;
        }
        for (int i = 1; i < unique; i++) {
            addEdgeV(getLca(tmp[i], tmp[i + 1]), tmp[i + 1]);
        }
        return tmp[1];
    }

    void dp1(int u) {
        dist[u] = 1000000001;
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            dp1(v);
            int w = dep[v] - dep[u];
            if (dist[v] + w < dist[u] || (dist[v] + w == dist[u] && manager[v] < manager[u])) {
                dist[u] = dist[v] + w;
                manager[u] = manager[v];
            }
        }
        if (isKey[u]) {
            dist[u] = 0;
            manager[u] = u;
        }
    }

    void dp2(int u) {
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            int w = dep[v] - dep[u];
            if (dist[u] + w < dist[v] || (dist[u] + w == dist[v] && manager[u] < manager[v])) {
                dist[v] = dist[u] + w;
                manager[v] = manager[u];
            }
            dp2(v);
        }
    }

    void amend(int u, int v) {
        if (manager[u] == manager[v]) {
            return;
        }
        int x = v;
        for (int p = MAXP - 1; p >= 0; p--) {
            int jump = stjump[x][p];
            if (dep[u] < dep[jump]) {
                int tou = dep[jump] - dep[u] + dist[u];
                int tov = dep[v] - dep[jump] + dist[v];
                if (tov < tou || (tov == tou && manager[v] < manager[u])) {
                    x = jump;
                }
            }
        }
        int delta = siz[x] - siz[v];
        ans[manager[u]] -= delta;
        ans[manager[v]] += delta;
    }

    void dp3(int u) {
        ans[manager[u]] += siz[u];
        for (int e = headv[u]; e; e = nextv[e]) {
            int v = tov[e];
            amend(u, v);
            ans[manager[u]] -= siz[v];
            dp3(v);
        }
    }

    void compute() {
        for (int i = 1; i <= k; i++) {
            arr[i] = order[i];
        }
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = true;
            ans[arr[i]] = 0;
        }
        int tree = buildVirtualTree();
        dp1(tree);
        dp2(tree);
        dp3(tree);
        for (int i = 1; i <= k; i++) {
            isKey[arr[i]] = false;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdgeG(u, v);
            addEdgeG(v, u);
        }
        dfs(1, 0);
        cin >> q;
        for (int t = 1; t <= q; t++) {
            cin >> k;
            for (int i = 1; i <= k; i++) {
                cin >> order[i];
            }
            compute();
            for (int i = 1; i <= k; i++) {
                cout << ans[order[i]] << ' ';
            }
            cout << '\n';
        }
        return 0;
    }

五、题目5：树上病毒传播（CF1320E）

一棵 n 个城市的树，q 条查询。每条查询先给 k 种病毒：第 i 种病毒的初次感染城市是 start[i]、传播速度是 speed[i]；再给 m 个关键城市，打印每个关键城市最终被第几号病毒感染。

传播规则按轮次进行：每一轮病毒 1 先传播，然后病毒 2，直到病毒 k，下一轮又从病毒 1 开始。如果第 i 种病毒已经感染了城市 x，当自己传播时想感染 y，需要满足两个条件：x 到 y 的路径边数 ≤ speed[i]，且这条路径上除 x 之外所有城市都未被感染。城市一旦被感染就永久保持。1 ≤ n、q、所有查询的病毒总数、所有查询的关键城市总数 ≤ 2 × 10⁵。测试链接：https://www.luogu.com.cn/problem/CF1320E。

这一题的虚树要连双向边，因为感染是从各个源头向外扩散，方向不固定。关键点是 k 个病毒起点加上 m 个查询城市，一起塞进虚树。

建完之后在虚树上跑多源 Dijkstra。每个状态记三个量：当前城市、从源头走过的真实距离 udist、以及到达时间 vtime = ⌈udist / speed⌉。堆的排序是时间小的先出，时间相同则病毒编号小的先出。

这里有个细节：一轮里每种病毒各自扩散一次，一次可以推进 speed[i] 条边，所以「第几轮到达」就等于 ⌈距离 / speed[i]⌉；而同一轮里病毒编号小的先动手，于是并列时编号小的胜出。把这两条写进堆的排序规则，逐轮模拟和 Dijkstra 的结果就完全一致了。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int id, dist, time, virus;
        bool operator<(const Node &other) const {
            if (time != other.time) {
                return time > other.time;
            }
            return virus > other.virus;
        }
    };

    const int MAXN = 200001;
    const int MAXP = 20;
    int n, q, k, m;

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int cntg;

    int headv[MAXN];
    int nextv[MAXN << 1];
    int tov[MAXN << 1];
    int cntv;

    int dep[MAXN];
    int dfn[MAXN];
    int stjump[MAXN][MAXP];
    int cntd;

    int start[MAXN];
    int speed[MAXN];
    int query[MAXN];

    int arr[MAXN << 1];
    int tmp[MAXN << 2];
    int len;

    priority_queue<Node> heap;
    bool vis[MAXN];
    int minTime[MAXN];
    int findVirus[MAXN];

    bool cmp(int x, int y) {
        return dfn[x] < dfn[y];
    }

    void addEdgeG(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void addEdgeV(int u, int v) {
        nextv[++cntv] = headv[u];
        tov[cntv] = v;
        headv[u] = cntv;
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        dfn[u] = ++cntd;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = headg[u]; e; e = nextg[e]) {
            if (tog[e] != fa) {
                dfs(tog[e], u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int buildVirtualTree() {
        int tot = 0;
        for (int i = 1; i <= k; i++) {
            arr[++tot] = start[i];
        }
        for (int i = 1; i <= m; i++) {
            arr[++tot] = query[i];
        }
        sort(arr + 1, arr + tot + 1, cmp);
        len = 0;
        for (int i = 1; i < tot; i++) {
            tmp[++len] = arr[i];
            tmp[++len] = getLca(arr[i], arr[i + 1]);
        }
        tmp[++len] = arr[tot];
        sort(tmp + 1, tmp + len + 1, cmp);
        int unique = 1;
        for (int i = 2; i <= len; i++) {
            if (tmp[unique] != tmp[i]) {
                tmp[++unique] = tmp[i];
            }
        }
        cntv = 0;
        for (int i = 1; i <= unique; i++) {
            headv[tmp[i]] = 0;
        }
        for (int i = 1; i < unique; i++) {
            int lca = getLca(tmp[i], tmp[i + 1]);
            addEdgeV(lca, tmp[i + 1]);
            addEdgeV(tmp[i + 1], lca);
        }
        len = unique;
        return tmp[1];
    }

    void dijkstra() {
        for (int i = 1; i <= len; i++) {
            int u = tmp[i];
            minTime[u] = n + 1;
            findVirus[u] = k + 1;
            vis[u] = false;
        }
        for (int i = 1; i <= k; i++) {
            int s = start[i];
            minTime[s] = 0;
            findVirus[s] = i;
            heap.push(Node{s, 0, 0, i});
        }
        while (!heap.empty()) {
            Node cur = heap.top();
            heap.pop();
            int u = cur.id;
            int udist = cur.dist;
            int uvirus = cur.virus;
            if (!vis[u]) {
                vis[u] = true;
                for (int e = headv[u]; e; e = nextv[e]) {
                    int v = tov[e];
                    if (!vis[v]) {
                        int vdist = udist + abs(dep[u] - dep[v]);
                        int vtime = (vdist + speed[uvirus] - 1) / speed[uvirus];
                        if (vtime < minTime[v] || (vtime == minTime[v] && uvirus < findVirus[v])) {
                            minTime[v] = vtime;
                            findVirus[v] = uvirus;
                            heap.push(Node{v, vdist, vtime, uvirus});
                        }
                    }
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdgeG(u, v);
            addEdgeG(v, u);
        }
        dfs(1, 0);
        cin >> q;
        for (int t = 1; t <= q; t++) {
            cin >> k >> m;
            for (int i = 1, s, v; i <= k; i++) {
                cin >> start[i] >> speed[i];
            }
            for (int i = 1; i <= m; i++) {
                cin >> query[i];
            }
            buildVirtualTree();
            dijkstra();
            for (int i = 1; i <= m; i++) {
                cout << findVirus[query[i]] << ' ';
            }
            cout << '\n';
        }
        return 0;
    }

六、题目6：寻宝游戏（P3320）

一棵 n 个点的树，边有边权。每个点有两种类型：刷宝的点和不刷宝的点，开始时全是不刷宝的点。接下来 m 条操作，第 i 条是「x 号点的类型翻转」。每次操作后，你可以瞬移到任意点作为出发点、无代价，然后走路拿完所有刷宝点的宝物并回到出发点，打印最小的行走总路程。1 ≤ n、m ≤ 10⁵。测试链接：https://www.luogu.com.cn/problem/P3320。

先看清答案的形状。k 个刷宝点的最小连通子树，边权和记为 W；从任意点出发、走完这些点再回到出发点，最短路程就是 2W，每条边都要来回各走一次。而 2W 又等于：把这 k 个点按 dfn 序排成一个环，环上相邻两点距离之和。

这就是虚树在这里的角色：虚树是最小连通子树的压缩树，上面那条环正好是压缩树的欧拉回路。于是维护一个按 dfn 排序的 set，翻转点 x 时只有它在环上的前驱 low 和后继 high 受影响，增量是 delta = d(x, low) + d(x, high) − d(low, high)。插入就加 delta，删除就减 delta。

这里有个细节：这一题的代码并没有真的把虚树建出来，用到的只是上面那条性质。集合里只有一个点时答案是 0，代码里 size ≤ 1 直接返回 0，不会去取前驱后继。

翻转一个点，答案怎么变

操作序列是 7、9、10、12、7（最后一次是把 7 翻回去）。点「下一步」，看每次翻转取到哪一对前驱后继、delta 是多少、答案怎么累加。

本次翻转的点 x 前驱 low / 后继 high 环上其它点 
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXP = 20;
    int n, m;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    int dep[MAXN];
    long long dist[MAXN];
    int dfn[MAXN];
    int seg[MAXN];
    int stjump[MAXN][MAXP];
    int cntd;

    int arr[MAXN];
    bool treasure[MAXN];
    std::set<int> st;
    std::set<int>::iterator it;

    long long ans[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void dfs(int u, int fa, int w) {
        dep[u] = dep[fa] + 1;
        dfn[u] = ++cntd;
        seg[cntd] = u;
        dist[u] = dist[fa] + w;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dfs(v, u, weight[e]);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    long long getDist(int x, int y) {
        return dist[x] + dist[y] - 2LL * dist[getLca(x, y)];
    }

    void compute() {
        long long curAns = 0;
        for (int i = 1; i <= m; i++) {
            int nodeId = arr[i];
            int dfnId = dfn[nodeId];
            if (!treasure[nodeId]) {
                treasure[nodeId] = true;
                st.insert(dfnId);
            } else {
                treasure[nodeId] = false;
                st.erase(dfnId);
            }
            if (st.size() <= 1) {
                curAns = 0;
            } else {
                int low = seg[(it = st.lower_bound(dfnId)) == st.begin() ? *--st.end() : *--it];
                int high = seg[(it = st.upper_bound(dfnId)) == st.end() ? *st.begin() : *it];
                long long delta = getDist(nodeId, low) + getDist(nodeId, high) - getDist(low, high);
                if (treasure[nodeId]) {
                    curAns += delta;
                } else {
                    curAns -= delta;
                }
            }
            ans[i] = curAns;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        dfs(1, 0, 0);
        for (int i = 1; i <= m; i++) {
            cin >> arr[i];
        }
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

七、复杂度分析

六个题共用同一套预处理：一次 dfs 拿 dep、dfn 和倍增表，O(n log n)。之后每条查询只在虚树上做 O(k) 的事。表里 k 是本次查询的关键点数，K 是所有查询的 k 之和。

题目单次查询时间额外空间虚树的特殊之处
题1 王国和城市O(k log k + k log n)O(k)不需要边权，只需父子关系
题2 大工程O(k log k + k log n)O(k)边权取深度差，n 可到 10⁶
题3 消耗战O(k log k + k log n)O(k)补进 1 号点，边权取路径最小边权
题4 世界树O(k log k + k log n)O(k)补进 1 号点，统计时用原树子树大小修正
题5 病毒传播O(k log k + k log n + k log k)O(k)连双向边，再跑一遍 Dijkstra
题6 寻宝游戏单次操作 O(log n)O(n)不建树，只维护 dfn 序的 set
全部 q 条查询O(K log K + K log n)O(K)预处理另计 O(n log n)

题 5 多出来的一项来自堆：每条虚边最多进堆一次，堆里有 O(k) 个元素，所以是 O(k log k)。题 6 不用建树，代价只在 set 的插入删除和一次 LCA 上，与虚树的 O(k) 框架无关。

六个题里真正随 n 增长的只有预处理那一步。所有查询的关键点总数 K 有上界，这正是虚树能把复杂度里的 n 换掉的前提。

八、最后

回头看这六个题，虚树本身没变，变的是三处开关：边权取什么（深度差、路径最小边权、还是不要边权）、头节点要不要补原树的头、要不要连双向边。题目要什么信息，就开哪个开关。

题 6 是最特别的一个：它把「虚树 = 最小连通子树的压缩树」这条性质单独拿出来用，连树都不建，只维护 dfn 环。能看出虚树有时候是一棵树，有时候只是一个结论。

下一讲换静态点分治，树上分治的第一条路线：这回按重心把树切开，统计跨过重心的路径，和虚树「只留关键点」的思路正好互补。

《完》
