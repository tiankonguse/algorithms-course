高斯消元解异或方程组：选数凑完全平方

n 个正整数里选至少一个相乘，要乘出完全平方数，有几种选法？这个问题的方程长得很吓人（n ≤ 300，每个数能到 10^18），可它每行方程只有一个系数 1，剩下的全是异或。这一节讲异或方程组的高斯消元模板，以及主元和自由元怎么把答案数出来。

零、加法模板换成异或，三个动作变两个

133 课的高斯消元模板做三件事：选主元、归一化、消元。异或方程组里，所有运算都在 0 和 1 之间进行，归一化可以直接删掉：1 的逆元还是 1，主元行根本不用除。

选主元也变了：加法版挑「绝对值最大的行」保数值稳定，异或版只需要找「这一列是 1 的行」。0 和 1 没有精度问题，随便挑一个非 0 的都行。

消元用异或：主元行的整行和别的行按位异或，把那一列的 1 消成 0。异或的逆运算还是异或，消完的行不会被污染。

下面是模板本体。注意它和加法版的唯一区别：swap 之后不除、消元用 ^=。

// 高斯消元解决异或方程组模板（行最简形）
    void gauss(int n) {
      for (int i = 1; i <= n; i++) {
        // 找第 i 列有 1 的行，换到第 i 行
        for (int j = 1; j <= n; j++) {
          if (j < i && mat[j][j] == 1) {
            continue;
          }
          if (mat[j][i] == 1) {
            swap(i, j);
            break;
          }
        }
        // 第 i 列有主元，把所有行的第 i 位消成 0
        if (mat[i][i] == 1) {
          for (int j = 1; j <= n; j++) {
            if (i != j && mat[j][i] == 1) {
              for (int k = i; k <= n + 1; k++) {
                mat[j][k] ^= mat[i][k];
              }
            }
          }
        }
      }
    }

一、完全平方数：每个质因子的指数都是偶数

选几个数相乘得完全平方数，等价于：每个质因子在乘积里的总指数是偶数。每个数要么选（指数加上）要么不选（指数不变），于是每个质数得到一个方程：参与选中的那些数的指数之和 mod 2 必须等于 0。

数据范围在这里帮了大忙：每个数的质因子一定不超过 2000。2000 以内的质数一共 303 个，所以方程最多 303 行，而变量是数的个数 n ≤ 300，行数比列数还多，矩阵是「竖着的」。

建矩阵的活很简单：每个数分解质因子，某个质数出现奇数次，这一格记 1，偶数次记 0（正好是异或的语义）。

// 埃氏筛收集 2000 以内的质数，一共 303 个
    void prepare() {
      for (int i = 2; i * i <= 2000; i++) {
        if (!vis[i]) {
          for (int j = i * i; j <= 2000; j += i) {
            vis[j] = true;
          }
        }
      }
      for (int i = 2; i <= 2000; i++) {
        if (!vis[i]) {
          prime[++cnt] = i;
        }
      }
    }

    // 每个数分解质因子：指数是奇数就记 1
    for (int i = 1; i <= n; i++) {
      long long cur = arr[i];
      for (int j = 1; j <= cnt && cur != 0; j++) {
        while (cur % prime[j] == 0) {
          mat[j][i] ^= 1;
          cur /= prime[j];
        }
      }
    }

常数列全部是 0：每个方程都要求「指数和是偶数」，右边没有别的数。这个矩阵直接喂给模板。

二、主元有多少，自由元就有多少，答案 = 2^自由元 - 1

消元结束后数主元：对角线是 1 的行就是主元行。设主元数量是 main，自由元数量就是 n - main。

自由元之间互不影响，每个自由元都可以独立决定选或不选，所以选法一共 2^(n-main) 种。但注意：所有自由元都不选的时候，每个质数方程左边全是 0，恒成立。这对应「一个数都不选」的空集。题目要求至少选一个数，把空集减掉：

// 消元后统计主元数量，自由元 = n - main
    gauss(cnt);
    int mainCnt = 0;
    for (int i = 1; i <= cnt; i++) {
      if (mat[i][i] == 1) {
        mainCnt++;
      }
    }
    // 每个自由元独立决定选或不选，共 2^(n-main) 种
    // 全部自由元都不选 = 空集，题目要求至少选一个，减去 1
    int ans = (pow2[n - mainCnt] - 1 + MOD) % MOD;

为什么空集对应「全部自由元不选」？看主元：自由元一旦确定，主元的选法就被方程钉死了。全部自由元不选，主元也只能全不选，于是所有变量都不选，就是空集。反过来，只要有一个自由元选了，对应的主元跟着动，选出来的乘积就是完全平方数。

三、一个看起来多余的细节：行数比列数多

方程行数是质数个数 303，变量列数是 n ≤ 300。模板里 gauss(cnt) 的循环按行数扫，第 n+1 列往后的列全是 0，消元扫过它们不会产生主元，也不会影响前面的结果。真正的主元只会出现在 ≤ n 列里，所以 main 的计数照常有效。

还有个边界要接住：有的数分解完质因子后还剩大于 1 的余数？不会。数据保证质因子不超过 2000，分解循环把 2000 以内所有质数试完，余数必然是 1。

四、复杂度

异或消元三层循环：找主元扫一行、消元对整行异或。行数 cnt ≈ 303，列数 n + 1 ≤ 301，总操作 O(cnt² · n) ≈ 3×107 量级，一秒以内跑完。位运算快的版本在 134 课的第三题（外星千足虫）里再讲。

五、总结

异或方程组的高斯消元比加法版省一步归一化，消元动作是整行异或。完全平方数题把它和质因子分解接上：每个质数一个方程、每个数一个变量，答案由自由元数量决定，2^(n-main)-1 里那个 -1 是空集。下一节的「全变 1 最少操作」复用同一个模板，但自由元不再是数方案，而是要枚举出最省操作的那一组。
