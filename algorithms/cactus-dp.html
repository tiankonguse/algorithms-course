仙人掌 DP

树上的 DP 写顺手之后，图上出现环就卡住了。仙人掌是「允许长环的树」：每条边要么是割边，要么只属于一个简单环。这个限制刚好松到，环可以被一圈一圈剥出来，DP 照着树的骨架往下走，遇到环就单独处理。这一节先把遍历和找环的骨架搭好，然后连做五道题。

零、背景

仙人掌图（cactus graph）是无向连通图的一个子类：每条边要么是割边，要么最多出现在一个简单环里。普通的树是仙人掌的特例。

几个后面反复用到的结论。

一个节点可以是多个环的环顶，也就是多个环在这一点「打结」。反过来，一个节点如果不是环顶，最多参与一个环。

一个简单环是一个点双连通分量，不是边双连通分量，环上任何两个点都双连通，但环上的边删掉任何一条，环就散成链了。割边之间则是纯粹的树。

因此生成「环上节点的信息」时，经常刻意不包含环顶。因为环顶可能同时是别的环的环顶，它身上的信息一旦和环混在一起，下一个环就没法干净地叠加。

一、仙人掌的遍历和找环

整套做法的地基是 Tarjan 求割边算法的一个改版。DFS 过程中维护 dfn（时间戳）、low（能回溯到的最早祖先）和一个栈，访问到的点进栈。

链式前向星存边，边从编号 2 开始成对出现，e ^ 1 就是 e 的反向边。用「边的编号」而不是「父节点」判回头路，重边也能处理。

每个点遍历它的所有边，除了来的那条反向边，剩下三种情况：

第一种，v 没访问过，递归下去。回来之后看 low[v] 和 dfn[u] 的关系，又分三支，这是整个流程的分岔口。

low[v] < dfn[u]：v 那边的口袋扎到了 u 的祖先身上，u 只负责把 low 传播上去，栈不动。

low[v] > dfn[u]：v 的口袋完全没扎住 u，边 (u, v) 是割边，v 的子树在栈里只占 v 自己，把它弹掉。

low[v] == dfn[u]：v 的口袋正好扎在 u 身上，栈里从 v 往上直到 v 的这段，连同 u，正好是一个环。弹栈到 v，环就拿到了。

第二种，v 已经访问过且 dfn[v] < dfn[u]，这是一条回边。用 dfn[v] 更新 low，同时把这条边的权值记给 v，环的「闭合边」的信息要挂在环上最深的祖先，也就是 v 那一头。

第三种，dfn[v] > dfn[u]，是「弃边」：对面是自己的后代，那条边在对面已经被当作回边处理过了，这里什么都不做。

树的边也一样走这个流程：树边的权值记给子节点（from 信息），环上每条边依次设置归属，环的末尾边分给环顶。

二、题目1：仙人掌删边方案数

给 n 个点、m 条路径，每条路径的相邻两点之间都有边，合成一张无向图。如果图不是仙人掌，输出 0；如果是，可以删掉一些边，删完剩下的图还得连通，这样的删法叫有效方案，一条不删也算。求有效方案数，答案很大要高精度。

先把「删完仍连通」翻译一下。割边删掉图就断成两半，所以割边一条都不能删。环上的边删掉一条，环散成链，图照样连通。

反过来，同一个环里能删几条？删两条，环断成两截，图就分成两半，不连通。所以每个环要么一条不删，要么恰好删一条。

不同的环之间互不影响，因为它们没有公共边。于是答案是所有环的贡献的乘积：一个环长 k 条边，贡献 k + 1 种（k 种删一条，1 种不删）。

判定「不是仙人掌」也很省事：一个点是两个环的环顶，等价于有边同时落在两个环里。遍历时统计每个点触发「环回边」的次数，超过一次就不是仙人掌。注意这个次数要连回边一起数，环顶认出环可能是在子树回溯时（low == dfn），也可能是自己摸到回边。

答案是大数乘积，高精度用字符串模拟乘一个 int：从低位乘到高位，处理进位，最后把进位翻转到前面接上。答案可能非常大，位数要留足。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    const int MAXM = 1000001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int edgeCnt[MAXN];
    int cntc;

    int cycleCnt[MAXN];

    string ans;

    void multiply(int x) {
        int carry = 0;
        for (int i = ans.size() - 1; i >= 0; i--) {
            int cur = (ans[i] - '0') * x + carry;
            ans[i] = cur % 10 + '0';
            carry = cur / 10;
        }
        string pre = "";
        while (carry > 0) {
            pre += carry % 10 + '0';
            carry /= 10;
        }
        reverse(pre.begin(), pre.end());
        ans = pre + ans;
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                    cycleCnt[u]++;
                } else if (low[v] > dfn[u]) {
                    top--;
                } else {
                    cntc++;
                    edgeCnt[cntc] = 1;
                    int pop;
                    do {
                        pop = sta[top--];
                        edgeCnt[cntc]++;
                    } while (pop != v);
                }
            } else if (dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
                cycleCnt[u]++;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntg = 1;
        for (int i = 1, k, x, y; i <= m; i++) {
            cin >> k >> x;
            for (int j = 2; j <= k; j++) {
                cin >> y;
                addEdge(x, y);
                addEdge(y, x);
                x = y;
            }
        }
        tarjan(1, 0);
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0 || cycleCnt[i] >= 2) {
                check = false;
                break;
            }
        }
        if (check) {
            ans = "1";
            for (int i = 1; i <= cntc; i++) {
                multiply(edgeCnt[i] + 1);
            }
            cout << ans << "\n";
        } else {
            cout << 0 << "\n";
        }
        return 0;
    }

三、题目2：仙人掌加边方案数

给一张无向连通图，没有自环重边。可以往里加一些新的边，加完之后还是仙人掌的加法叫有效方案，一条不加也算，但不允许加出自环或二元环。求方案数，对 998244353 取余，多组数据。

先跑一遍上面的 Tarjan：图本身不是仙人掌就直接输出 0。是仙人掌，才轮到「往哪加」的问题。

加一条边，会在图上多出一个环，这个环由新边和原图上的一条路径组成。要保住仙人掌性质，路径只能走割边，踩到老环的边上，那条边就同时属于两个环了。

再想路径之间怎么互不干扰。多条新边对应多条割边路径，它们不能共享割边（共享的割边就属于两个新环）；一个点上，穿过它的路径在这一点进出各占一个方向，所以一个点上「被占用的方向」之间两两不同。

于是每个点独立地做一个决定：把它的若干条割边方向，两两配对（配成一对 = 一条路径在这里拐弯）或者落单（不拐弯）。i 个方向配成若干对加落单的方案数记作 f[i]，它满足 f[i] = f[i-1] + (i-1) · f[i-2]：第 i 个方向要么落单，剩 i-1 个随便配；要么和前面 i-1 个里挑一个配成一对，剩 i-2 个随便配。f[0] = f[1] = 1。

不同点上的配对怎么拼成完整的路径？一条割边 (u, v)，u 把方向 (u→v) 配了对，说明有条路径走到 v；v 那头如果也配了 (v→u)，路径自动接续穿过 v。两头都落单，这条边就没被任何路径用上。

路径最短是多长？一条路径至少占两条割边，加上新边，环至少三条边。所以二元环根本造不出来，不用额外排除。而「全落单」就是一条不加，也自然被数进去了。

环顶也照这个规则数：环上的两条边不算方向，一个点哪怕是好几个环的环顶，方向还是只有割边那几条。配对发生在「进了环又出环」的路径上时，中间经过的环节点同样按割边方向配对，语义一致。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 500001;
    const int MAXM = 1000001;
    const int MOD = 998244353;
    int t, n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    bool cycleEdge[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int fromEdge[MAXN];
    int cycleCnt[MAXN];

    bool vis[MAXN];
    ll f[MAXN];
    ll dp[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        cycleEdge[cntg] = false;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                fromEdge[v] = e;
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                    cycleCnt[u]++;
                } else if (low[v] > dfn[u]) {
                    top--;
                } else {
                    int pop;
                    int edge = fromEdge[u];
                    cycleEdge[edge] = cycleEdge[edge ^ 1] = true;
                    do {
                        pop = sta[top--];
                        edge = fromEdge[pop];
                        cycleEdge[edge] = cycleEdge[edge ^ 1] = true;
                    } while (pop != v);
                }
            } else if (dfn[v] < dfn[u]) {
                fromEdge[v] = e;
                low[u] = min(low[u], dfn[v]);
                cycleCnt[u]++;
            }
        }
    }

    void dpOnTree(int u, int fa) {
        vis[u] = true;
        ll ans = 1;
        int direction = fa == 0 ? 0 : 1;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !cycleEdge[e]) {
                dpOnTree(v, u);
                ans = ans * dp[v] % MOD;
                direction++;
            }
        }
        dp[u] = ans * f[direction] % MOD;
    }

    void prepare() {
        f[0] = f[1] = 1;
        f[2] = 2;
        for (int i = 3; i <= n; i++) {
            f[i] = (f[i - 1] + f[i - 2] * (i - 1)) % MOD;
        }
        for (int i = 1; i <= n; i++) {
            head[i] = dfn[i] = low[i] = fromEdge[i] = cycleCnt[i] = 0;
            vis[i] = false;
            dp[i] = 0;
        }
        cntg = 1;
        cntd = top = 0;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n >> m;
            prepare();
            for (int i = 1, u, v; i <= m; i++) {
                cin >> u >> v;
                addEdge(u, v);
                addEdge(v, u);
            }
            tarjan(1, 0);
            bool check = true;
            for (int i = 1; i <= n; i++) {
                if (cycleCnt[i] >= 2) {
                    check = false;
                    break;
                }
            }
            if (check) {
                ll ans = 1;
                for (int i = 1; i <= n; i++) {
                    if (!vis[i]) {
                        dpOnTree(i, 0);
                        ans = ans * dp[i] % MOD;
                    }
                }
                cout << ans << "\n";
            } else {
                cout << 0 << "\n";
            }
        }
        return 0;
    }

四、题目3：仙人掌最长路线

n 个点 m 条边的无向连通仙人掌，路线可以从任何城市开始，但必须在 1 号点结束；可以重复经过同一个点，不能重复经过同一条边。求最长路线的边数。

路线反过来读，就是「从 1 号点出发、不重复走边、随便停在哪」的最长路线。所以只要求 g[1]：g[u] 定义为从 u 出发、在 u 的子仙人掌内、不重边地走，最长能走多少条边。

沿着割边走是普通的树形 DP。麻烦在环上，一个环进入之后怎么走最划算。观察一个事实：在环上，从环顶 u 进去、可以把整个环完整走一圈回到 u；也可以走到环上某一点 x，钻进 x 挂的子仙人掌里不再回来。

所以给每个点两个值：f[u] 是「从 u 出发最后回到 u」的最长边数，g[u] 是「从 u 出发随便停」的最长边数。f[u] 里环的贡献是整圈：环长加上每个环节点子树的 f；g[u] 在 f[u] 的基础上，换成「半圈钻进某个子树的 g」，取最划算的那个。

环是从栈里弹出来的，弹出顺序天然是「从深到浅」，环长和前缀都顺着累加。半圈枚举每个环节点 x：走「靠近环顶那一边」到 x 再进子树，或者绕远那一边到 x，两边各扫一遍取 max。f、g 的差值作为这个环对 g[u] 的增量 delta，和其他割边子树的增量放在一起取最大。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 20001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int cycle[MAXN];
    int f[MAXN];
    int g[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    int dpOnCycle(int u, int v) {
        int siz = 0;
        int pop;
        do {
            pop = sta[top--];
            cycle[++siz] = pop;
        } while (pop != v);
        int best = 0;
        int sum = 1;
        for (int i = 1; i <= siz; i++) {
            best = max(best, sum + g[cycle[i]]);
            sum += f[cycle[i]] + 1;
        }
        f[u] += sum;
        int otherSide = sum;
        for (int i = 1; i <= siz; i++) {
            otherSide -= f[cycle[i]] + 1;
            best = max(best, otherSide + g[cycle[i]]);
        }
        return best - sum;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        int delta = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    top--;
                    delta = max(delta, g[v] + 1);
                } else {
                    delta = max(delta, dpOnCycle(u, v));
                }
            } else if (dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
        g[u] = f[u] + delta;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntg = 1;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        tarjan(1, 0);
        cout << g[1] << "\n";
        return 0;
    }

五、题目4：仙人掌最大独立集

仙人掌上选一些点，任意相邻两点不能同时选，最大化点权之和。两个版本：给点权（P4410），或者点权全是 1（P10779）。

树上独立集是入门 DP：dp[u][0] 表示 u 不选、dp[u][1] 表示 u 选。割边部分照搬：u 不选时孩子随便，u 选时孩子必须不选。

环上的处理是断环成链。环顶 u 和栈里最深那个环节点 w 在环上相邻（环是 u - v - … - w - u）。弹栈拿到的环序列从浅到深，链的两端正好是 u 和 w。

dp[u][0] 时 u 不选，w 不受 u 的限制：在链上做一次普通 DP，w 可选可不选，最后把结果累到 dp[u][0]。

dp[u][1] 时 u 选了，w 必须不选。做法是第二次 DP，把链尾 w 的「选」状态强制成负无穷，只剩「w 不选」的转移。两次 DP 的初值只差在 pre1 是 -INF 还是 dp[w][1]。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 200001;
    const int INF = 1000000000;
    int n, m;
    int arr[MAXN];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int cycle[MAXN];
    int dp[MAXN][2];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dpOnCycle(int u, int v) {
        int siz = 0;
        int pop;
        do {
            pop = sta[top--];
            cycle[++siz] = pop;
        } while (pop != v);
        int pre0 = dp[cycle[1]][0], pre1 = dp[cycle[1]][1];
        int cur0, cur1;
        for (int i = 2; i <= siz; i++) {
            int x = cycle[i];
            cur0 = max(pre0, pre1) + dp[x][0];
            cur1 = pre0 + dp[x][1];
            pre0 = cur0;
            pre1 = cur1;
        }
        dp[u][0] += max(pre0, pre1);
        pre0 = dp[cycle[1]][0];
        pre1 = -INF;
        for (int i = 2; i <= siz; i++) {
            int x = cycle[i];
            cur0 = max(pre0, pre1) + dp[x][0];
            cur1 = pre0 + dp[x][1];
            pre0 = cur0;
            pre1 = cur1;
        }
        dp[u][1] += pre0;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        dp[u][0] = 0;
        dp[u][1] = arr[u];
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    dp[u][0] += max(dp[v][0], dp[v][1]);
                    dp[u][1] += dp[v][0];
                    top--;
                } else {
                    dpOnCycle(u, v);
                }
            } else if (dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntg = 1;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }

        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }

        tarjan(1, 0);
        cout << max(dp[1][0], dp[1][1]) << "\n";
        return 0;
    }

六、题目5：仙人掌直径

点 x 到点 y 的距离是最短路径的边数，直径是任意两点距离的最大值。输入给的是若干条路径，路径相邻两点之间都有边，保证是仙人掌。

距离要求「最短」，所以环上两点走的是环上两段中较短的一段。树形 DP 求直径的套路是维护 dist[u]（u 向下最远），经过 u 拼接两条。仙人掌上有两处不同。

第一处，环顶 u 的 dist 更新：从环上某个环节点 x 回到 u，走环的两边取短的一边，min(i-1, siz-(i-1))，i 是 x 在环弹出顺序里的位置。

第二处，环内部两点的最短距离要限「不超过环长的一半」。把环上各点的 dist 复制成两倍长度的数组，滑窗维护 arr[i] + i 的最大值，窗口限制 (i - que[l]) * 2 <= siz，单调队列里 arr[j] - j 递减，拼出 dist[i] + i + dist[j] - j。这就是「环上任意两点、走短边」的最大拼接。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    const int MAXM = 1000001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int dist[MAXN];
    int arr[MAXN << 1];
    int que[MAXN << 1];
    int diameter;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dpOnCycle(int u, int v) {
        int siz = 0;
        arr[++siz] = dist[u];
        int pop;
        do {
            pop = sta[top--];
            arr[++siz] = dist[pop];
        } while (pop != v);
        for (int i = 1; i <= siz; i++) {
            arr[i + siz] = arr[i];
        }
        int l = 1, r = 0;
        que[++r] = 1;
        for (int i = 2; i <= siz << 1; i++) {
            while (l <= r && (i - que[l]) * 2 > siz) {
                l++;
            }
            diameter = max(diameter, arr[i] + i + arr[que[l]] - que[l]);
            while (l <= r && arr[que[r]] - que[r] <= arr[i] - i) {
                r--;
            }
            que[++r] = i;
        }
        for (int i = 2; i <= siz; i++) {
            dist[u] = max(dist[u], arr[i] + min(i - 1, siz - (i - 1)));
        }
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                if (low[v] < dfn[u]) {
                    low[u] = min(low[u], low[v]);
                } else if (low[v] > dfn[u]) {
                    top--;
                    diameter = max(diameter, dist[u] + dist[v] + 1);
                    dist[u] = max(dist[u], dist[v] + 1);
                } else {
                    dpOnCycle(u, v);
                }
            } else if (dfn[v] < dfn[u]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntg = 1;
        for (int i = 1, k, x, y; i <= m; i++) {
            cin >> k >> x;
            for (int j = 2; j <= k; j++) {
                cin >> y;
                addEdge(x, y);
                addEdge(y, x);
                x = y;
            }
        }
        tarjan(1, 0);
        cout << diameter << "\n";
        return 0;
    }

七、复杂度分析

五道题共用同一个遍历骨架，一遍 DFS 每条边走两次，环在弹栈时被整体取走，每个点进出栈各一次。

题目时间复杂度空间复杂度
题目1 删边方案数O(n + m + 答案位数 × 环数)O(n + m)
题目2 加边方案数O(n + m) 每组O(n + m)
题目3 最长路线O(n + m)O(n)
题目4 最大独立集O(n + m)（环上两次线性 DP）O(n)
题目5 直径O(n + m)（环上单调队列均摊）O(n)

环上那几步看着嵌套，其实每个环节点最多被弹出一次、进单调队列一次，加起来还是线性。题目1 的高精度乘法是唯一超线性的部分，乘的次数是环数，每次乘法扫一遍当前位数。

空间都是邻接表加几个数组，n、m 到 10⁶ 也扛得住。

八、最后

这五道题的骨架完全一样：改版 Tarjan 挂着一个栈，栈里的段就是环，割边在树边的位置。变化的只是环被弹出来那一刻往里填什么，数乘积、配方向、断链 DP、单调队列，填的东西不同，骨架一行不改。

环顶的「一个点多个环」性质是所有细节的来源：环上信息不含环顶、配对只数割边方向、独立集第二次 DP 强制最深点不选，都是为了把环顶从环里摘干净，让树的部分和环的部分互不污染。

下一节把这些题搬到圆方树上做，环不再现场处理，而是先压缩成一个方点，很多推导会反过来变成「树上怎么走」的问题。
