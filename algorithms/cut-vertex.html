割点

无向图里有些点是「要害」：把它连同相连的边一起拿掉，图就散架了。这样的点叫割点。这一节用 dfn 和 low 两个数组，一次 dfs 把所有割点找出来，然后连做三道题。

零、背景

这一节站在两讲的基础上：强连通分量给出了 dfn、low 的骨架，割边和边双连通分量把这副骨架搬到了无向图上。现在还是同一副骨架，只是「口袋」从边换成了点。

先把两个数组说清楚。dfn[u] 是第一次走到 u 时发的时间戳，先来先得、绝不重复。low[u] 是 u 和它的子树沿着树边往下、再顺着回边往回摸，能摸到的最小时间戳。

无向图的 dfs 里，边分三类。树边是往下走的新边；回边指向已经访问过、时间戳更小的点；剩下的都算弃边，比如反着扫回来的树边重复、指向时间戳更大的点，它们对 low 没有影响。

这里有个细节：这套代码不记父亲。反着走的树边（u 回看父亲 v）也会被当成回边处理，把 low[u] 和 dfn[v] 取一次 min。看起来像作弊，其实无害，判定的门槛恰好是 dfn[u]，等号照样成立，下一节会专门说这件事。

一、割点的定义

删掉某个点以及与它相连的所有边，如果无向图的连通区数量增加了，这个点就叫割点。图本身不保证连通，删点之前就有若干个连通块，比较的是删前删后的块数。

和割边对照着看：割边拿掉一条边，割点拿掉一个点和它身上的所有边。一个点可以既是割点又是割边的端点，两个概念互相不蕴含。

二、朴素做法

最直接的办法是照定义来：枚举每个点，删掉，跑一遍 dfs 数连通块，和原来的数量比。一次 O(n + m)，n 个点就是 O(n·(n + m))。

n 到 2 × 10⁴、m 到 10⁵ 时，这个数是 4 × 10⁹ 量级，必然超时。

可以发现，删一个点会不会散架，只取决于它周围「口袋」的结构。而这个结构，dfs 的时候顺手就能看见，这就是 Tarjan 的切入点。

三、Tarjan 求割点

dfs 沿树边往下走，每条树边 (u, v)（u 在上、v 在下）返回的时候，检查 low[v] 和 dfn[u]。

如果 low[v] ≥ dfn[u]，说明 v 的子树里所有回边最高只够到 u 自己，一条都翻不出去。删掉 u，这棵子树就和上方断开。这个动作叫扎口袋，u 是袋口。

于是有两条判定。u 不是根：只要扎起一次口袋，u 就是割点。u 是根：根的上方没有点，口袋扎得再多也不会散架，只有树儿子数 ≥ 2，删掉根才能把两棵子树分开，根的判定只看树儿子数，不看 low。

遇到回边时 low[u] = min(low[u], dfn[v])，必须用 dfn[v]，不能用 low[v]。回边贡献的是这条边一头连着的那个祖先，dfn[v] 正是它的时间戳；low[v] 是 v 那边整棵子树的摸高，把别人的子树情况借过来，口袋就会扎错位置。

还有一个等价的写法。因为反着走的树边把 low[v] 压到了 dfn[u]，low[v] 永远不会超过 dfn[u]，所以判定写 low[v] ≥ dfn[u] 和写 low[v] == dfn[u] 结果相同。两种写法站内都会出现。

Tarjan 求割点走一遍

8 个点、9 条边，两个三角形靠一条边串起来。点「下一步」，看 dfn、low 怎么走，口袋在哪里一个个扎起来，割点怎么现形。

当前 dfs 所在的点 已访问 还没走到 已认出的割点

求割点的骨架如下，三道题都在它上面改：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    const int MAXM = 100001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    bool cutVertex[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, bool root) {
        dfn[u] = low[u] = ++cntd;
        int son = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                son++;
                tarjan(v, false);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    if (!root || son >= 2) {
                        cutVertex[u] = true;
                    }
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i, true);
            }
        }
        int cutCnt = 0;
        for (int i = 1; i <= n; i++) {
            if (cutVertex[i]) {
                cutCnt++;
            }
        }
        cout << cutCnt << "\n";
        for (int i = 1; i <= n; i++) {
            if (cutVertex[i]) {
                cout << i << " ";
            }
        }
        cout << "\n";
        return 0;
    }

四、题目1：割点模版

给定一张无向图，n 个点、m 条边，不保证连通。打印图中割点的数量，然后从小到大打印所有割点的编号。1 ≤ n ≤ 2 × 10⁴，1 ≤ m ≤ 10⁵。（洛谷 P3388）

就是上面的模版。外层对每个 dfn 为 0 的点跑一次 tarjan，起点当根。

有两处细节。无向边要正反各存一条，前向星数组开 2m。cutVertex 是布尔数组，一个点扎多次口袋也只记一次，不用去重。

五、题目2：电力

给定一张无向图，n 个点、m 条边，不保证连通，点的编号 0 到 n−1。只能删除一个点的话，连通块最多能有多少。多组数据，读到 0 0 结束。1 ≤ n ≤ 10⁴，1 ≤ m ≤ 2 × 10⁴。（POJ 2117 / LOJ 10103）

先数出初始的连通块数 block。删掉一个点 u 之后，u 所在的那块会裂开，其余块不动。

裂成几块，Tarjan 已经给出答案。u 是所在块的根：每棵子树各自成块，裂成 son 块。u 不是根：每个口袋里的子树各自成块，再加上 u 上方那块，裂成 cut + 1 块，cut 是 u 扎口袋的次数。

所以删 u 之后的总块数 = block − 1 + (u 是根 ? son : cut + 1)，对所有的 u 取最大值就是答案。根的口袋数恰好等于 son − 1，两条式子其实是同一件事的两种数法。

编号 0 到 n−1 读进来统一加一。cut 在这里数的是次数，不是标记。完整代码：

#include <iostream>
    #include <algorithm>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 20001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int block, ans;

    void prepare() {
        cntg = cntd = block = ans = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = dfn[i] = low[i] = 0;
        }
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, bool root) {
        dfn[u] = low[u] = ++cntd;
        int son = 0, cut = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                son++;
                tarjan(v, false);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u] && !root) {
                    cut++;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (root) {
            ans = max(ans, son);
        } else {
            ans = max(ans, cut + 1);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        cin >> n >> m;
        while (n != 0 || m != 0) {
            prepare();
            for (int i = 1, u, v; i <= m; i++) {
                cin >> u >> v;
                u++;
                v++;
                addEdge(u, v);
                addEdge(v, u);
            }
            for (int i = 1; i <= n; i++) {
                if (dfn[i] == 0) {
                    block++;
                    tarjan(i, true);
                }
            }
            cout << (block + (ans - 1)) << "\n";
            cin >> n >> m;
        }
        return 0;
    }

六、题目3：嗅探器

给定一张 n 个点、m 条边的无向图，所有节点属于同一个连通区。再给定点 a 和点 b，如果删掉某个别的点能让 a 和 b 不再连通，这个点叫关键点。打印编号最小的关键点，不存在打印 No solution。1 ≤ n ≤ 2 × 10⁵，1 ≤ m ≤ 5 × 10⁵。（洛谷 P5058）

从 a 出发跑一遍 dfs，a 就成了整棵 dfs 树的根，b 一定在树里。这样一来，某个点 u 是关键点，当且仅当 u 在 a 到 b 的树路径上，并且 u 扎起的某个口袋把 b 装了进去。

翻译成判定：u 有一个树儿子 v，满足 low[v] ≥ dfn[u]（u 扎口袋），并且 b 在 v 的子树里（删掉 u 后 b 被隔开）。加上 u 不是 a 也不是 b 这两个排除条件。

「b 在 v 的子树里」用的判据是 dfn[b] ≥ dfn[v]。这里有个细节：检查发生在 v 的子树刚返回的那一刻，此时还没访问到的点 dfn 都是 0；已经访问过、dfn 又不小于 dfn[v] 的点，只能落在 v 的子树里，不会误判到后面才走的分支。

整图连通，从 a 跑一次 tarjan 就够。完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXM = 500001;
    int n, a, b;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    bool isKey[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u] && u != a && u != b && dfn[b] >= dfn[v]) {
                    isKey[u] = true;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        int u, v;
        cin >> u >> v;
        while (u != 0 || v != 0) {
            addEdge(u, v);
            addEdge(v, u);
            cin >> u >> v;
        }
        cin >> a >> b;
        tarjan(a);
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (isKey[i]) {
                ans = i;
                break;
            }
        }
        if (ans == 0) {
            cout << "No solution" << "\n";
        } else {
            cout << ans << "\n";
        }
        return 0;
    }

七、复杂度分析

三道题共用一个 dfs 骨架：每个点进出各一次，每条边的两个方向各扫一次，判定都是常数时间。

步骤时间复杂度空间复杂度
求割点（题目1）O(n + m)O(n + m)
电力（题目2）O(n + m) 每组数据O(n + m)
嗅探器（题目3）O(n + m)，只跑一次 dfsO(n + m)

空间是链式前向星 2m 条边，加上 dfn、low、cutVertex 几个 n 长的数组。电力是多组数据，每组开头把这几个数组清一遍，清空本身也是 O(n + m)。

题目2 的答案整合只在每个点 dfs 返回时做一次 max，题目3 在判定里多加了三个布尔条件，都没有引入新的量级。

八、最后

三道题同一副骨架：模版题认标记，电力数口袋裂块，嗅探器给口袋加了一个「b 在不在里面」的条件。改动都发生在 low[v] ≥ dfn[u] 那一行附近。

有一件事这一节一直绕着走：割点切出来的块，会在割点上重叠。割边切边双，边双互不相交，直接缩点就行；点双不行，一个割点同时属于两边的块。下一节把口袋真正地弹出来，正面处理这个问题。
