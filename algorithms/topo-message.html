拓扑排序推送消息：食物链计数与最安静

拓扑排序不只是输出一个合法顺序。出队的点可以把信息推给下游：有多少条路径走到这里，上游谁最安静。这类题能成立的唯一前提是，u 出队的那一刻，所有能到 u 的点都已经处理完，所以 u 推下去的信息是完整的。

零、为什么消息能「推」下去

Kahn 算法里，一个点入队的前提是入度减到 0，也就是它的所有前驱都出过队了。反过来讲：u 出队时，指向 u 的每条边都已经结算过。所以任何「从上游聚合出来的信息」推到 u 就是最终值，再往下推不会错。

这套思路就是树形 dp 的雏形，只不过把树换成了 DAG。信息的聚合方式按题目变：食物链计数是加法累加，喧闹和富有是最值覆盖。两个都在这页。

一、最大食物链计数（P4017）

题面给一个有向无环图，边 a→b 代表 a 在食物链中被 b 捕食，也就是 b 吃 a。问从最初级动物（不捕食任何生物的入度为 0 的点）到最顶级捕食者（不被捕食的出度为 0 的点）一共有几条食物链，答案模 80112002。

方向别记反：箭头指向捕食者。生产者入度为 0，因为它不吃别人；顶级消费者出度为 0，因为没谁吃它。官方样例 5 个点 7 条边答案 5，下面这张图是它的推送过程。

lines[i] 记「到 i 的食物链条数」。入度为 0 的点 lines 置 1，出队时把 lines[u] 加到每个下游 v 上。u 没有出边时，说明它是顶级消费者，lines[u] 直接累进答案。

注意答案很大，每次加法都要取模。中间值不取模会溢出，取早了也只是多花一点时间，不影响正确性。

复杂度 O(n+m)，链式前向星存图，四个数组加一个 cnt，头插加边。

#include <bits/stdc++.h>
    using namespace std;

    namespace FoodLines {
    const int MAXN = 5001, MAXM = 500001, MOD = 80112002;
    int head[MAXN], nxt[MAXM], to[MAXM], cnt;
    int indeg[MAXN], lines[MAXN], que[MAXN];

    void build(int n) {
      cnt = 1;
      for (int i = 1; i <= n; i++) head[i] = indeg[i] = lines[i] = 0;
    }
    void addEdge(int u, int v) {
      nxt[cnt] = head[u];
      to[cnt] = v;
      head[u] = cnt++;
    }
    // 入度为 0 的初级动物 lines = 1；出队时把线路数推给下游；
    // 没有出边的点（最顶级捕食者）把 lines 累进答案。
    int ways(int n) {
      int l = 0, r = 0;
      for (int i = 1; i <= n; i++) {
        if (indeg[i] == 0) {
          que[r++] = i;
          lines[i] = 1;
        }
      }
      int ans = 0;
      while (l < r) {
        int u = que[l++];
        if (head[u] == 0) {
          ans = (ans + lines[u]) % MOD;
        } else {
          for (int ei = head[u]; ei > 0; ei = nxt[ei]) {
            int v = to[ei];
            lines[v] = (lines[v] + lines[u]) % MOD;
            if (--indeg[v] == 0) que[r++] = v;
          }
        }
      }
      return ans;
    }
    } // namespace FoodLines

二、喧闹和富有（LC851）

richer[i] = [a, b] 表示 a 比 b 有钱。answer[x] 要求在「钱不少于 x」的所有人里，挑安静值 quiet 最小的人。钱不少于 x 的人包括 x 自己，再加上所有比 x 有钱的人。

直接做法是每个人反向跑一遍图找所有比自己有钱的，O(n²) 起步。推送消息的做法：a 比 b 有钱，建边 a→b，拓扑序里 a 先出队，a 的答案已经包含了「比 a 有钱的所有人 + a」，拿它去跟 b 的当前答案比安静值，谁安静覆盖谁。b 的入度归零时，所有比 b 有钱的人都已经推过它了。

ans[i] 初始化为 i 自己，这一步不能省，否则没人推过的点答案会是空的。官方样例 8 个人，答案是 5 5 2 5 4 5 6 7：0、1、3、5 的答案都收敛到 5，因为 5 是它们共同的「更富且更安静」的前辈。

复杂度同样是 O(n+m)。它和上一题的区别只在聚合方式：计数是加法，选人是比较后覆盖。

#include <bits/stdc++.h>
    using namespace std;

    namespace LoudRich {
    vector<int> loudAndRich(int n, const vector<vector<int>>& richer, const vector<int>& quiet) {
      vector<vector<int>> graph(n);
      vector<int> indeg(n, 0);
      for (auto& r : richer) {
        graph[r[0]].push_back(r[1]);
        indeg[r[1]]++;
      }
      vector<int> que(n);
      int l = 0, r = 0;
      for (int i = 0; i < n; i++) {
        if (indeg[i] == 0) que[r++] = i;
      }
      vector<int> ans(n);
      for (int i = 0; i < n; i++) ans[i] = i;
      while (l < r) {
        int cur = que[l++];
        for (int next : graph[cur]) {
          if (quiet[ans[cur]] < quiet[ans[next]]) ans[next] = ans[cur];
          if (--indeg[next] == 0) que[r++] = next;
        }
      }
      return ans;
    }
    } // namespace LoudRich

总结

拓扑排序推送消息的三步：入度 0 的点给初始值，出队时把聚合信息推给所有下游，信息按题意取加法或最值。前提永远是「u 出队时前驱都结算完」，这句话是这类题正确性的全部依据。
