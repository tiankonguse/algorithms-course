圆方树的路径查询与动态维护

这一页是圆方树的「重装备」篇：四道题全部把圆方树当成一棵普通的树来操作，树链剖分判必经、线段树查链上最小值、虚树公式数分隔点、平衡树动态维护关键点集合。图上的查询和修改，经过圆方树这一层翻译，全变成了树上的标准操作。

零、背景

前两页的查询都靠倍增 LCA，这一页的题目数据更大、操作更多，得换更重的工具。树链剖分把树切成若干条重链，任何一条路径拆成 O(log n) 段链上的连续区间；配合线段树，区间查询和单点修改都是对数级。站内 LCT 那几页已经用过它，这里照用。

判定「点 c 是否在 a 到 b 的路径上」是这一页反复出现的原语。树剖的写法：a、b 链顶不同时，把链顶深的那个往上跳；跳之前检查 c 是否落在当前链段上，c 的链顶与 a 相同且 c 不深于 a。最后 a、b 同链，判 dep 区间即可。这个判定对圆点方点一视同仁。

另一件工具是虚树：一次查询只涉及少数关键点时，把关键点和它们两两的 LCA 抽出来建成一棵小树，规模是 O(k) 的。题9、题10 用的是虚树的计数结论，不需要真的把虚树建出来。

一、题目7：警察

给定 n 个点 m 条边的无向连通图，无重边。q 次查询有两种：给 a、b、c、d（已知 c、d 之间有边），删掉这条边，问 a、b 是否连通；给 a、b、c，删掉点 c，问 a、b 是否连通。n 到 10⁵，m 到 5×10⁵，q 到 3×10⁵。

删点 c 的查询是老结论：c 在 a 到 b 的树路径上就不连通。删边的查询分两种情况：这条边不是割边，图删掉它纹丝不动，连通；这条边是割边，删它等价于删掉它撑起的那个方点，割边两点一方点，方点就是这条边在圆方树上的化身。于是查询变成：方点 f 是否在 a 到 b 的路径上。

建树时顺手做记录：Tarjan 里 low[v] > dfn[u] 成立说明树边 (u, v) 是割边，此刻新建的方点编号存进 map<pair<int,int>, int>，键是 (u, v) 排序后的点对。注意 Tarjan 要带「成对边」判定，反向边不能用来更新 low。

这题的空间卡得很紧，树上倍增的表开不下，树链剖分只要 fa、dep、siz、son、top 几个数组，刚好能过。两种查询最后都归到同一个 mustPass 判定，单次 O(log n)。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 500001;
    int n, m, q, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int cnts;

    map<pair<int, int>, int> cutMap;

    int fa[MAXN << 1];
    int dep[MAXN << 1];
    int siz[MAXN << 1];
    int son[MAXN << 1];
    int top[MAXN << 1];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void addCut(int x, int y, int cut) {
        int a = min(x, y);
        int b = max(x, y);
        cutMap[{a, b}] = cut;
    }

    int getCut(int x, int y) {
        int a = min(x, y);
        int b = max(x, y);
        auto ans = cutMap.find({a, b});
        return ans == cutMap.end() ? 0 : ans -> second;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++cnts] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    if (low[v] > dfn[u]) {
                        addCut(u, v, cntn);
                    }
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[cnts--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head2[u], v; e > 0; e = next2[e]) {
            v = to2[e];
            if (v != f) {
                dfs1(v, u);
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head2[u], v; e > 0; e = next2[e]) {
            v = to2[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    bool mustPass(int a, int b, int c) {
        while (top[a] != top[b]) {
            if (dep[top[a]] < dep[top[b]]) {
                swap(a, b);
            }
            if (top[c] == top[a] && dep[c] <= dep[a]) {
                return true;
            }
            a = fa[top[a]];
        }
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        return top[a] == top[c] && dep[b] <= dep[c] && dep[c] <= dep[a];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntn = n;
        cnt1 = 1;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1, 0);
        dfs1(1, 0);
        dfs2(1, 1);
        cin >> q;
        for (int i = 1, op, a, b, c, d; i <= q; i++) {
            cin >> op;
            if (op == 1) {
                cin >> a >> b >> c >> d;
                int cut = getCut(c, d);
                if (cut == 0) {
                    cout << "yes\n";
                } else {
                    cout << (mustPass(a, b, cut) ? "no" : "yes") << "\n";
                }
            } else {
                cin >> a >> b >> c;
                cout << (mustPass(a, b, c) ? "no" : "yes") << "\n";
            }
        }
        return 0;
    }

二、题目8：游客

n 个城市 m 条双向道路，全连通，每个城市有商品报价。两种操作：C x y 把城市 x 的报价改成 y；A x y 从 x 走到 y，路线自选但不能重复经过城市，打印沿途能遇到的最低报价。n、m、q 到 10⁵。

「不重复城市」保证走的是简单路径，对应圆方树路径；进入一个方点，就获得了在它的点双内随意换路线的权利。路径经过方点 f 时，f 的任何邻居圆点都可以成为入出口，所以 f 能「遇到」的报价就是它邻居圆点报价的最小值。圆点的报价就是自己的。查询 = 树路径上点的权值最小值，方点权 = 邻居圆点权最小值。

修改是麻烦的地方。圆点 x 改报价，所有包含 x 的方点的最小值都可能变。x 是割点时它挂在好几个方点上，逐个改是错的姿势，正确的姿势是让每个方点的有序表只收集孩子圆点的权，父圆点不进表。这样 x 出现在且仅出现在它父方点的表里，修改 x 只需要动一个方点。代价是查询时如果 LCA 是方点，它的父圆点不在路径区间里，要额外查一次。

具体实现：dfs1 建树剖时顺手给方点建有序表（map 套 map，值带计数）；dfs2 按 nid 给线段树的初值，圆点放自己的报价，方点放表里的最小值。操作 C x y：先改父方点的表（删旧值、加新值、取最小值更新线段树），再改 x 自己的线段树位置。操作 A x y：跳链做区间最小，最后若较浅端点是方点，答案再和它父圆点的报价取 min。根节点没有父方点，判一下边界。

带修改的路径最小报价

三角形 {1,2,3}、割边 3-4、三角形 {4,5,6}。报价 5 3 8 7 2 6。两次修改、三次查询，看方点的表怎么动、LCA 是方点时怎么补查。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 100001;
    const int INF = 1000000001;
    int n, m, q, cntn;
    int arr[MAXN];

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int cnts;

    int fa[MAXN << 1];
    int dep[MAXN << 1];
    int siz[MAXN << 1];
    int son[MAXN << 1];
    int top[MAXN << 1];
    int nid[MAXN << 1];
    int cnti;

    unordered_map<int, map<int, int>> maps;
    int val[MAXN << 1];
    int minv[MAXN << 3];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void addNum(int u, int num) {
        if (!maps.count(u)) {
            maps.emplace(u, map<int, int>());
        }
        auto &mp = maps[u];
        auto it = mp.find(num);
        if (it == mp.end()) {
            mp.emplace(num, 1);
        } else {
            it->second++;
        }
    }

    void delNum(int u, int num) {
        auto &mp = maps[u];
        int cnt = mp[num];
        if (cnt == 1) {
            mp.erase(num);
        } else {
            mp[num] = cnt - 1;
        }
    }

    int getMin(int u) {
        return maps[u].begin()->first;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++cnts] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[cnts--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs1(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != f) {
                dfs1(v, u);
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
                if (u > n) {
                    addNum(u, arr[v]);
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        nid[u] = ++cnti;
        val[nid[u]] = u <= n ? arr[u] : getMin(u);
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head2[u], v; e > 0; e = next2[e]) {
            v = to2[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    void up(int i) {
        minv[i] = min(minv[i << 1], minv[i << 1 | 1]);
    }

    void build(int l, int r, int i) {
        if (l == r) {
            minv[i] = val[l];
        } else {
            int mid = (l + r) / 2;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            up(i);
        }
    }

    void update(int jobi, int jobv, int l, int r, int i) {
        if (l == r) {
            minv[i] = jobv;
        } else {
            int mid = (l + r) / 2;
            if (jobi <= mid) {
                update(jobi, jobv, l, mid, i << 1);
            } else {
                update(jobi, jobv, mid + 1, r, i << 1 | 1);
            }
            up(i);
        }
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            return minv[i];
        }
        int mid = (l + r) / 2;
        int ans = INF;
        if (jobl <= mid) {
            ans = min(ans, query(jobl, jobr, l, mid, i << 1));
        }
        if (jobr > mid) {
            ans = min(ans, query(jobl, jobr, mid + 1, r, i << 1 | 1));
        }
        return ans;
    }

    int pathMin(int x, int y) {
        int ans = INF;
        while (top[x] != top[y]) {
            if (dep[top[x]] < dep[top[y]]) {
            	swap(x, y);
            }
            ans = min(ans, query(nid[top[x]], nid[x], 1, cnti, 1));
            x = fa[top[x]];
        }
        if (dep[x] < dep[y]) {
            swap(x, y);
        }
        ans = min(ans, query(nid[y], nid[x], 1, cnti, 1));
        if (y > n) {
            ans = min(ans, arr[fa[y]]);
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        cntn = n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1);
        dfs1(1, 0);
        dfs2(1, 1);
        build(1, cnti, 1);
        for (int i = 1; i <= q; i++) {
            char op;
            int x, y;
            cin >> op >> x >> y;
            if (op == 'C') {
                int father = fa[x];
                if (father > 0) {
                    delNum(father, arr[x]);
                    addNum(father, y);
                    update(nid[father], getMin(father), 1, cnti, 1);
                }
                arr[x] = y;
                update(nid[x], y, 1, cnti, 1);
            } else {
                cout << pathMin(x, y) << "\n";
            }
        }
        return 0;
    }

三、题目9：战略游戏

给定 n 个点 m 条边的无向连通图，可能有重边。q 次查询，每次给 s 个关键点，你只能删掉一个关键点之外的点，删完只要关键点中存在两点不连通就算成功。对每次查询打印可选择的点数。n 到 10⁵，m 到 2×10⁵，所有查询的 s 之和到 2×10⁵。

一个点可选，当且仅当它落在某两个关键点的树路径上。所有关键点两两路径并起来的圆点集合，正是关键点在圆方树上的虚树里的全部圆点。所以答案 = 虚树圆点数 − s：虚树圆点 = 关键点本身 + 路径上的其他圆点，前者不许删，后者个个都会分隔某对关键点；不在虚树上的点删了无关痛痒。

数虚树圆点不用建虚树。给每条树边 e 记 w(e) = 1 当且仅当下端点是圆点。虚树里除根以外的每个点都恰好是某条虚树边的下端，所以 Σw(e) = 虚树圆点数 −（虚树根是圆点 ? 1 : 0）。

把 dep 换成「到根路径上的圆点个数」记作 dist，两点间的 dist[a] + dist[b] - 2 * dist[lca] 恰好等于路径上 w(e) 之和：路径上除 LCA 外每个点都是某条路径边的下端。再把关键点按 dfn 排序、首尾相接成环，相邻两点的路径每条虚树边恰好覆盖两次，于是相邻 getDist 之和 = 2·Σw(e)。

合起来：虚树圆点数 = 相邻 getDist 之和 / 2 + extra，extra 是 1 当且仅当首尾两点的 LCA，也就是虚树根，是圆点。答案再减 s。

排序按 dfn（dfs 序）而不是编号，相邻对包括首尾闭合的那一对。单次查询的开销是排序加 s 次 LCA。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 200001;
    const int MAXP = 20;
    int t, n, m, q, s, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int dist[MAXN << 1];
    int dep[MAXN << 1];
    int stjump[MAXN << 1][MAXP];
    int nid[MAXN << 1];
    int cnti;

    int arr[MAXN];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs(int u, int fa) {
        nid[u] = ++cnti;
        dist[u] = dist[fa] + (u <= n ? 1 : 0);
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int getDist(int x, int y) {
        return dist[x] + dist[y] - 2 * dist[getLca(x, y)];
    }

    int compute() {
        sort(arr + 1, arr + s + 1, [](int x, int y) {return nid[x] < nid[y];});
        int sumDist = 0;
        for (int i = 1; i < s; i++) {
            sumDist += getDist(arr[i], arr[i + 1]);
        }
        sumDist += getDist(arr[1], arr[s]);
        int extra = getLca(arr[1], arr[s]) <= n ? 1 : 0;
        return sumDist / 2 + extra - s;
    }

    void prepare() {
        cnt1 = cnt2 = cntd = top = cnti = 0;
        for (int i = 1; i <= n; i++) {
            head1[i] = head2[i] = dfn[i] = 0;
            head2[i + n] = 0;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n >> m;
            cntn = n;
            prepare();
            for (int i = 1, u, v; i <= m; i++) {
                cin >> u >> v;
                addEdge1(u, v);
                addEdge1(v, u);
            }
            tarjan(1);
            dfs(1, 0);
            cin >> q;
            for (int i = 1; i <= q; i++) {
                cin >> s;
                for (int j = 1; j <= s; j++) {
                    cin >> arr[j];
                }
                cout << compute() << "\n";
            }
        }
        return 0;
    }

四、题目10：国土规划

给定 n 个点 m 条边的无向连通图，可能有重边无自环。初始时所有点状态为 0。q 次操作，每次翻转某个点 x 的状态，然后打印「无所谓点」的数量：状态为 0、且删除它之后所有状态为 1 的点依然连通的点。2 ≤ n ≤ 10⁵，m、q 到 2×10⁵。

状态为 1 的点是动态的关键点集合，题目9 的结论直接复用：会破坏 1 点连通性的点 = 虚树圆点集合减去 1 点本身，无所谓点数 = n − 虚树圆点数 = n −（sumDist/2 + extra）。

sumDist 不能每次重算，要增量维护。把当前 1 点按 dfn 存进有序集合；翻转点 u 时，找 u 在环序里的前驱 low 和后继 high（越界则环绕），u 的加入或 removal 改变的距离恰好是 dist(u,low) + dist(u,high) - dist(low,high)，环上相邻三点的路径，加上 u 多出两条边段，减去原来的一条。加入 u 时 sumDist 加上这个量，删除时减去。extra 每次用集合首尾（dfn 最小和最大的点）的 LCA 现算。

边界情况：集合为空时删谁都无所谓，答案 n；集合只有一个点时虚树圆点数是 1，答案 n − 1。集合用 set<int> 按 dfn 存，前驱后继 O(log n)，配倍增 LCA，单次操作对数级。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 200001;
    const int MAXP = 20;
    int n, m, q, cntn;
    bool arr[MAXN];

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int dist[MAXN << 1];
    int dep[MAXN << 1];
    int stjump[MAXN << 1][MAXP];
    int nid[MAXN << 1];
    int seg[MAXN << 1];
    int cnti;

    set<int> st;
    set<int>::iterator it;
    int sumDist;

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs(int u, int fa) {
        nid[u] = ++cnti;
        seg[cnti] = u;
        dist[u] = dist[fa] + (u <= n ? 1 : 0);
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int a, int b) {
        if (dep[a] < dep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int getDist(int x, int y) {
        return dist[x] + dist[y] - 2 * dist[getLca(x, y)];
    }

    int compute(int u) {
        int id = nid[u];
        if (!arr[u]) {
            arr[u] = true;
            st.insert(id);
        } else {
            arr[u] = false;
            st.erase(id);
        }
        if (st.size() <= 1) {
            sumDist = 0;
        } else {
            int low = seg[(it = st.lower_bound(id)) == st.begin() ? *--st.end() : *--it];
            int high = seg[(it = st.upper_bound(id)) == st.end() ? *st.begin() : *it];
            int delta = getDist(u, low) + getDist(u, high) - getDist(low, high);
            if (arr[u]) {
                sumDist += delta;
            } else {
                sumDist -= delta;
            }
        }
        if (st.empty()) {
            return 0;
        }
        int extra = getLca(seg[*st.begin()], seg[*st.rbegin()]) <= n ? 1 : 0;
        return sumDist / 2 + extra;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        cntn = n;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1);
        dfs(1, 0);
        for (int i = 1, x; i <= q; i++) {
            cin >> x;
            int ans = n - compute(x);
            cout << ans << "\n";
        }
        return 0;
    }

五、复杂度分析

四道题的预处理都包含建圆方树；查询和修改的开销由各自的数据结构决定。

操作时间复杂度空间复杂度
题目7 建树（含割边 map）O(n + m log m)O(n + m)（树剖五件套，无倍增表）
题目7 一次查询O(log n)O((n + m) log n)（倍增表）或线段树四倍
题目8 一次修改 / 查询O(log n) / O(log² n)
题目9 一次查询（s 个关键点）O(s log s + s log n)
题目10 一次操作O(log n)set 与倍增表同上

题目7 的 map 只存割边，条数不超过 n − 1，log 因子很小，主要是省空间的考虑。题目8 的方点表总大小等于圆方树的边数，每个权值进出表各一次，均摊 O(log)。题目9 的排序只在查询内做，Σs 与 m 同级。题目10 的 extra 和 Δ 都只调常数次 LCA。

六、最后

四道题放在一起看，圆方树的角色很清楚：它不直接解题，而是把图翻译成树，让树链剖分、线段树、虚树、平衡树这些现成工具全部进场。题目7 把割边变成了可删的方点，题目8 把点双的绕行权变成了可维护的最小值，题目9、10 把「分隔关键点」变成了虚树圆点的计数。

值得记住的两个手筋：方点的表只装孩子、修改就只需要动一个方点，代价是查询时补一次父圆点；dep 换成「到根圆点数」之后，两点距离自动变成路径上圆点的计数，配合相邻覆盖两次的性质，虚树圆点数一个除法就出来。

圆方树到这里告一段落。往后遇到图上问必经、问绕行、问点双结构的题，先想想把它建出来。
