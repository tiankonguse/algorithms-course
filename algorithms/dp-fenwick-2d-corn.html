二维树状数组：方伯伯的玉米田

给一段区间整体 +1，重复最多 k 次，问做完后最长不下降子序列能到多长。这个「区间 +1」和 LIS 看着没关系，但把它翻译成「每个玉米可以独立拔高 0 到 k 次」，转移的内层就变成在（高度，修改次数）这个二维平面上取前缀最大值，二维树状数组正好接得住。

零、背景

最长不下降子序列的转移，内层是「在所有能接在我前面的位置里取最大值」。玉米田这道题多了一个操作维度：每个玉米可以拔高若干次。状态多一维，转移的内层就从一维前缀最大值变成二维前缀最大值。

一、问题

给长度 n 的数组 arr，每次选一个区间 [l, r] 全部 +1，最多做 k 次。做完之后，最长不下降子序列的长度是多少。数据范围 1 <= n <= 10^4，1 <= arr[i] <= 5000，2 <= k <= 500。

二、把区间 +1 拆成独立拔高

先想清楚操作到底能造成什么结果。一次 [l, r] +1 把 l 到 r 之间的每个玉米都抬一次，k 次操作之后，每个玉米被抬的总次数就是覆盖它的区间个数。反过来，给每个玉米任意指定一个 0 到 k 的拔高次数，也都能用单点区间拼出来。所以「每个玉米独立拔高」在能力上和「区间 +1」等价，问题变成：每个玉米选一个拔高次数，使选出的子序列不下降，且总拔高次数不超 k。

但选进 LIS 的玉米之间有个方向约束。设左边玉米在 p、拔高 q 次，右边玉米在 i、拔高 j 次。给右边玉米拔高的区间可以从 i 自己开始往右伸，不碰左边的玉米，所以「右边抬得比左边多」随时能做到。反过来，给左边玉米拔高的区间只要右端点够到 i，就会连 i 一起抬起来，做不到「左边抬得多、右边抬得少」。于是最优方案可以整理成：被选中的玉米，拔高次数从左到右不减，即 q <= j。这一条是整道题能往下做的关键。

三、状态与转移

设 dp[i][j] 为「以 i 号玉米结尾、i 被拔高 j 次时，最长不下降子序列的长度」。前一个被选中的玉米 p 要满足三条：p < i、q <= j、最终高度 arr[p] + q <= arr[i] + j。于是

枚举 p 和 q 是 O(n²k²)，n 到 10 的 4 次方扛不住。内层查询长这样：已经扫过的玉米里，「最终高度不超过 arr[i] + j、拔高次数不超过 j」的记录中 dp 最大是多少。这是一个二维前缀最大值。

四、二维树状数组

把两维都开成树状数组：一维是最终高度，一维是拔高次数。查询 query2d(H, j+1) 返回「高度不超过 H、次数不超过 j」的前缀最大值，更新 update2d(H, j+1, dp) 往右上传播。arr[i] 上限 5000，拔高最多 k 次，最终高度最多 5000 + k，两维都能直接开数组，不用离散化。

树状数组的 add 换成取 max，前缀和换成前缀取 max，再套一层循环就是二维版。初始全是 0，dp 值至少是 1，不需要负无穷。

五、j 必须从大到小枚举

同一个玉米的 k+1 条记录会在同一次内层循环里全部写进树。如果 j 从小到大：先写 (arr[i]+0, 1)，轮到 j=1 时查询 (arr[i]+1, 2)，查到的前缀里包含自己刚写的那条 (arr[i]+0, 1)，于是这个玉米被当成「它前面的玉米」接了一次，长度凭空多算一段。j 从大到小：先写高度大的 (arr[i]+k, k+1)，再查询高度小的 (arr[i]+k-1, k)，高度这一维不满足，自己污染不到自己。代码里只有这一处顺序不能换。

六、实现

二维树状数组的模板，两维都是取 max：

const int MAXH = 5500;
    const int MAXK = 501;
    int tree2d[MAXH + 1][MAXK + 1];

    void update2d(int x, int y, int v) {
        for (int i = x; i <= MAXH; i += i & -i) {
            for (int j = y; j <= k + 1; j += j & -j) {
                tree2d[i][j] = max(tree2d[i][j], v);
            }
        }
    }

    int query2d(int x, int y) {
        int ans = 0;
        for (int i = x; i > 0; i -= i & -i) {
            for (int j = y; j > 0; j -= j & -j) {
                ans = max(ans, tree2d[i][j]);
            }
        }
        return ans;
    }

主循环。注意第二层 j 从 k 到 0，以及树状数组里次数下标统一 j+1（因为 j 从 0 开始，而树状数组下标从 1 开始）：

int compute() {
        int v, dp;
        for (int i = 1; i <= n; i++) {
            for (int j = k; j >= 0; j--) {
                v = arr[i] + j;
                dp = query2d(v, j + 1) + 1;
                update2d(v, j + 1, dp);
            }
        }
        return query2d(MAXH, k + 1);
    }

七、演示：填表过程

逐步扫每个玉米，每个玉米再按 j 从 k 到 0 枚举。高亮的格子是当前要填的 dp[i][j]，它由「高度不超过 arr[i]+j、次数不超过 j」的已填记录取 max 加一得到。同一列从上往下看，能直观看到「次数小的格子先填、后填的查不到自己」的顺序效果。

复杂度分析

外层 i 循环 n 次，内层 j 循环 k+1 次，每次一个查询一个更新，各 O(log(5000+k) · log(k+1))。总时间 O(n · k · log²)，n = 10 的 4 次方、k = 500 时约 5 × 10 的 8 次方次位运算，洛谷数据能过。

空间是 tree2d[5501][501] 一个二维 int 数组，约 5500 × 500 × 4 字节，约 11 MB。

总结

这道题做三件事：把「区间 +1」翻译成「每个玉米独立拔高」；用「拔高次数从左到右不减」收掉操作的顺序约束；把转移内层的二维前缀最大值交给二维树状数组。实操上唯一不能换的顺序是内层 j 从大到小，防止同一个玉米自己的记录互相污染。

往后看到「操作次数」和「值域」同时卡状态的题，可以试试把两维都扔进树状数组；一维放不下就离散化，离散化见同一讲的达标子数组题。
