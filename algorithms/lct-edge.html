LCT 维护边权

LCT 的辅助 splay 汇总的是点权，边权没地方放。这一节的五道题都站在同一个转换上：给每条边也发一个编号，把它当成一个点拉进 LCT，边权就变成了点权。转换之后剩下的活，就是在这套骨架上换目标，有的换成路径上的最大边，有的换成生成树，有的还要跟时间打交道。

零、背景

LCT 维护的一直是挂在点上的信息：子树大小、点权最大、路径的和。这些东西都属于某个具体的点 x，往上汇总时看 sum[x] 就够了。

边不一样。原图里 a 和 b 之间那条边，既不该算进 a，也不该算进 b。可它偏偏又有自己的权值，还要参与路径上的比较和累加。

换个问法就没这个问题了：既然点能挂信息，那把边也变成一个点呢？

一、边转点

编号规则只有两条：

  1. 原图的点 1 到 n，在 LCT 里编号不变。
  2. 原图的第 i 条边，在 LCT 里编号 n + i。

原图上 a 和 b 之间有一条边 i，转换后在 LCT 里连两条：a 到 n + i，n + i 到 b。

转换之后，LCT 里的一个点有两种身份，靠编号区分：

  • x <= n，是原图的点，它没有边权，up 里给它一个永远赢不了的哨兵值。
  • x > n，是边节点，它的点权就是第 x - n 条边的权值。

于是「一条路径上的边权」就变成了「一条路径上的点权」，只看方框那些点。路径和、路径最大、路径最小，全回到了熟悉的位置：split(x, y) 之后整条路径躺在一棵 splay 里，根上汇总的就是答案。

有个细节要留意。哨兵值的取法和边权范围有关：边权非负时，点节点取 0 就够了；边权可以为负或者可以为 0，就得取 -INF。否则点节点会莫名其妙地赢过所有边。

另外，路径上真正有意义的量是「边节点的最值」，而这条链上点节点和边节点是交替出现的。写 up 的时候，只要保证点节点永远不赢，最后留在根上的就一定是一条边。

二、模板要改的三处

标准 LCT 骨架一行都不用动，只改三个地方。

第一处是 up。下面维护的是「路径上最大边」，数组里存的是边的编号，不是权值：

void up(int x) {
        maxEdge[x] = x <= n ? 0 : x - n;
        if (arr[maxEdge[ls[x]]].w > arr[maxEdge[x]].w) {
            maxEdge[x] = maxEdge[ls[x]];
        }
        if (arr[maxEdge[rs[x]]].w > arr[maxEdge[x]].w) {
            maxEdge[x] = maxEdge[rs[x]];
        }
    }

arr[0] 是全局零值。点节点先取到自己对应的那条边（是点就取 0），再和左右两个儿子比一比。之所以存编号，是因为换边的时候要拿它去找两个端点，只有权值是找不到人的。

想把最大换成最小，把两个 > 反过来就行。

第二处是 link。原图的点之间不再直接连边，边节点是中间人：

link(arr[i].x, n + i);
    link(arr[i].y, n + i);

第三处是 cut。删一条边时要断两条：

cut(arr[pre].x, n + pre);
    cut(arr[pre].y, n + pre);

代码里给这几个动作套个 addEdge、cutEdge 的名字会更清楚，实现本身没有新东西。

三、加边成环，换掉一条

后面五道题里，有四道都会反复用同一个动作：往当前的生成森林里加一条边，如果成环，就把环上某条边换掉。

判断成环很容易。makeroot(x) 之后看 findroot(y) 是不是 x：是，说明两点本来就连通，这条边一加进去就成环。

成环之后换谁，看题目要什么。这里有三种，别混：

  • 要维护最小生成树，就换掉环上最大的那条边（新边更小才值得换）。
  • 要维护最大生成树，就换掉环上最小的那条边。
  • 题目2 要维护「当前窗口里最小的边」，换的也是环上最小边，但它维护的不是最小生成树，下面单独说。

换的时候顺序是固定的：先用 split 把路径拆出来，在根上读出那条边的编号，再 cut 掉它的两个端点，最后 link 新边。下面这个演示就走一遍这个过程。

加边、成环、换边

四条边按 C、A、D、B、E 的顺序加进来，每条边的权值标在旁边。点「下一步」一步步走，注意第 4 步换掉了哪条边。

已经在生成树里 当前处理的边 还没加进来或被换掉

四、题目1：水管局长

n 个点、m 条无向边，给定每条边的两个端点和边权。接下来有 q 条操作，两种类型：

  • 1 x y：打印点 x 到点 y 的所有路径中，最大边权的最小值。
  • 2 x y：删除点 x 和点 y 之间的直接边，这条边一定存在。

题目保证任何时刻图都连通，无重边无自环。n 到 10³，m、q 到 10⁵。

删除不好做。LCT 会 link、会 cut，但「一条边没了之后，剩下的图长什么样」这种全局信息它答不上来。

先把问题的答案看清楚。所谓「所有路径中最大边权的最小值」，就是最小瓶颈路。而最小瓶颈路有一条老结论：它一定可以在最小生成树上取到。两个方向各说一句就够了，最小生成树的割性质保证任何一条跨割的路径都不会比树上的更优；反过来树上的那条路径本身就是一个合法候选。

所以整道题真正要维护的东西只有一个：当前的最小生成树。图随时连通，答案只跟这棵树有关。

剩下的就是处理删除。倒过来看：把所有删除操作收集起来，先建出「删除全部执行完之后」的那张图的生成树；然后从最后一次操作往前扫，删除变成了加边，而查询的答案在倒序里读出来，正序输出就行。

倒序加边这件事和前面那个演示里的还不一样：加进来的顺序是操作给的，不按权值排。所以这里必须加一句判断，新边比环上最大边更小，才值得换；比它大就别动。

还有一处实现上的选择。题面里删除是按端点 (x, y) 给的，而 LCT 里用的边编号是自己排出来的。代码先把边按权值排序，用排序后的下标当编号，再开一个 map 把端点对映回编号。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int x, y, w;
    };

    bool EdgeCmp(Edge a, Edge b) {
        return a.w < b.w;
    }

    const int MAXN = 200001;
    int n, m, q;
    Edge arr[MAXN];

    int qop[MAXN];
    int qx[MAXN];
    int qy[MAXN];

    int father[MAXN];

    bool deleted[MAXN];
    map<pair<int, int>, int> edgeMap;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int maxEdge[MAXN];
    int ans[MAXN];

    int find(int x) {
        if (x != father[x]) {
            father[x] = find(father[x]);
        }
        return father[x];
    }

    void up(int x) {
        maxEdge[x] = x <= n ? 0 : x - n;
        if (arr[maxEdge[ls[x]]].w > arr[maxEdge[x]].w) {
            maxEdge[x] = maxEdge[ls[x]];
        }
        if (arr[maxEdge[rs[x]]].w > arr[maxEdge[x]].w) {
            maxEdge[x] = maxEdge[rs[x]];
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    pair<int, int> key(int x, int y) {
        int a = min(x, y);
        int b = max(x, y);
        return {a, b};
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            father[i] = i;
        }
        sort(arr + 1, arr + m + 1, EdgeCmp);
        for (int i = 1; i <= m; i++) {
            edgeMap[key(arr[i].x, arr[i].y)] = i;
        }
        for (int i = 1; i <= q; i++) {
            if (qop[i] == 2) {
                deleted[edgeMap[key(qx[i], qy[i])]] = true;
            }
        }
        int edgeCnt = 0;
        for (int i = 1; i <= m && edgeCnt != n - 1; i++) {
            if (!deleted[i]) {
                int x = arr[i].x, y = arr[i].y, fx = find(x), fy = find(y);
                if (fx != fy) {
                    father[fx] = fy;
                    link(x, n + i);
                    link(y, n + i);
                    edgeCnt++;
                }
            }
        }
    }

    void addEdge(int e) {
        split(arr[e].x, arr[e].y);
        int maxe = maxEdge[arr[e].y];
        if (arr[e].w < arr[maxe].w) {
            cut(arr[maxe].x, n + maxe);
            cut(arr[maxe].y, n + maxe);
            link(arr[e].x, n + e);
            link(arr[e].y, n + e);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        for (int i = 1; i <= m; i++) {
            cin >> arr[i].x >> arr[i].y >> arr[i].w;
        }
        for (int i = 1; i <= q; i++) {
            cin >> qop[i] >> qx[i] >> qy[i];
        }
        prepare();
        for (int i = q; i >= 1; i--) {
            if (qop[i] == 1) {
                split(qx[i], qy[i]);
                ans[i] = arr[maxEdge[qy[i]]].w;
            } else {
                addEdge(edgeMap[key(qx[i], qy[i])]);
            }
        }
        for (int i = 1; i <= q; i++) {
            if (qop[i] == 1) {
                cout << ans[i] << "\n";
            }
        }
        return 0;
    }

五、题目2：最小差值生成树

n 个点、m 条无向边，图连通，可能有自环。选一棵生成树，希望树里最大边权减最小边权的值尽量小，输出这个差值。n 到 5×10⁴，m 到 2×10⁵。

把所有边按权值升序排好，一条条往 LCT 里加。加的时候分两种：两点不连通就直接连上；已经连通就 split 出来，把环上最小的那条边换掉。

makeroot(x);
    if (findroot(y) != x) {
        link(x, n + i);
        link(y, n + i);
    } else {
        split(x, y);
        int pre = minEdge[y];
        cut(arr[pre].x, n + pre);
        cut(arr[pre].y, n + pre);
        link(x, n + i);
        link(y, n + i);
    }

注意这里是无条件换。因为边是按权值升序进来的，新边一定不比树里任何一条边小，换掉最小的那条，等于让这棵树尽可能「大」。

为什么是让树尽量大？把这套操作从头到尾连起来看：每加一条边就挤掉当前最小的，和「把所有边从大到小做一遍 Kruskal」留下的东西是一回事。也就是说，处理完第 i 条边之后，LCT 里存的正是前 i 条边的最大生成树。

最小生成树用不上，但它的极差正好是我们需要的量。维护一个数组 removed 记哪条边被挤掉了，再拿一个指针 first 从前往后扫，它停在「还没有被挤掉的最小边」上。这棵树的最大边就是刚加进来的第 i 条边，所以

答案候选 = arr[i].w - arr[first].w

只要 LCT 里的边数凑够 n - 1（也就是成了一棵生成树），就用这个式子更新一次答案。

为什么枚举这些候选就够了，说一句最有说服力的：设最优的那棵树里最大的边是第 k 条，权为 M。处理到第 k 条时，LCT 里那棵树的边权都不超过 M。假如它的最小边比最优树的最小边还小，那它本身就是一棵更好的树，跟「最优」矛盾；否则它的极差不超过最优值。而它又实实在在是一棵生成树，极差不可能比最优更小。两边一夹就相等了。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int x, y, w;
    };

    bool EdgeCmp(Edge a, Edge b) {
        return a.w < b.w;
    }

    const int MAXN = 300001;
    int n, m;
    Edge arr[MAXN];

    bool removed[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int minEdge[MAXN];

    void up(int x) {
        int cur = x <= n ? 0 : x - n;
        int l = minEdge[ls[x]];
        int r = minEdge[rs[x]];
        if (cur == 0 || (l != 0 && l < cur)) {
            cur = l;
        }
        if (cur == 0 || (r != 0 && r < cur)) {
            cur = r;
        }
        minEdge[x] = cur;
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    int compute() {
        sort(arr + 1, arr + m + 1, EdgeCmp);
        int edgeCnt = 0;
        int first = 1;
        int ans = INT_MAX;
        for (int i = 1; i <= m; i++) {
            int x = arr[i].x;
            int y = arr[i].y;
            if (x == y) {
                removed[i] = true;
            } else {
                makeroot(x);
                if (findroot(y) != x) {
                    link(x, n + i);
                    link(y, n + i);
                    edgeCnt++;
                } else {
                    split(x, y);
                    int pre = minEdge[y];
                    cut(arr[pre].x, n + pre);
                    cut(arr[pre].y, n + pre);
                    link(x, n + i);
                    link(y, n + i);
                    removed[pre] = true;
                }
            }
            while (removed[first]) {
                first++;
            }
            if (edgeCnt == n - 1) {
                ans = min(ans, arr[i].w - arr[first].w);
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> arr[i].x >> arr[i].y >> arr[i].w;
        }
        cout << compute() << "\n";
        return 0;
    }

六、题目3：魔法森林

n 个点 m 条边，每条边有 a、b 两种权值，可能有重边和自环。定义一条路径的代价为「路径上最大的 a 加上路径上最大的 b」。求 1 号点到 n 号点路径代价的最小值，不连通输出 -1。n 到 5×10⁴，m 到 10⁵。

最大值的和不好一起压。那就固定一个、放开另一个。

把边按 a 升序排好，一条条加进来。假设最优路径上最大的 a 出现在第 i 条边，那么在处理到第 i 条边时，「a 不超过 arr[i].a」的那些边全都在手里了。在这个边集里，我们只关心一件事：1 到 n 的路径上最大 b 能有多小。这又是一条最小瓶颈路，它落在「按 b 做出来的最小生成树」上。

于是 LCT 的结构按 b 维护：加边成环时，把环上 b 最大的那条边换掉，前提是当前边的 b 更小。同时 up 里要记两份信息，路径上 a 最大的边、路径上 b 最大的边。

makeroot(x);
    if (findroot(y) != x) {
        link(x, n + i);
        link(y, n + i);
    } else {
        split(x, y);
        int pre = maxbEdge[y];
        if (arr[i].b < arr[pre].b) {
            cut(arr[pre].x, n + pre);
            cut(arr[pre].y, n + pre);
            link(x, n + i);
            link(y, n + i);
        }
    }

每加完一条边，如果 1 和 n 连通，就读一次 1 到 n 的路径：arr[maxaEdge[n]].a + arr[maxbEdge[n]].b 就是一个候选答案。

这里 maxaEdge 不能省。第 i 条边不一定落在 1 到 n 的路径上，如果偷懒直接写 arr[i].a，算出来的和会比真实值偏大。老老实实从路径上读，答案会更紧。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int x, y, a, b;
    };

    bool EdgeCmp(Edge e1, Edge e2) {
        return e1.a < e2.a;
    }

    const int MAXN = 200001;
    const int INF = 1000000001;
    int n, m;
    Edge arr[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int maxaEdge[MAXN];
    int maxbEdge[MAXN];

    void up(int x) {
        maxaEdge[x] = x <= n ? 0 : x - n;
        if (arr[maxaEdge[ls[x]]].a > arr[maxaEdge[x]].a) {
            maxaEdge[x] = maxaEdge[ls[x]];
        }
        if (arr[maxaEdge[rs[x]]].a > arr[maxaEdge[x]].a) {
            maxaEdge[x] = maxaEdge[rs[x]];
        }
        maxbEdge[x] = x <= n ? 0 : x - n;
        if (arr[maxbEdge[ls[x]]].b > arr[maxbEdge[x]].b) {
            maxbEdge[x] = maxbEdge[ls[x]];
        }
        if (arr[maxbEdge[rs[x]]].b > arr[maxbEdge[x]].b) {
            maxbEdge[x] = maxbEdge[rs[x]];
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    int compute() {
        sort(arr + 1, arr + m + 1, EdgeCmp);
        int ans = INF;
        for (int i = 1; i <= m; i++) {
            int x = arr[i].x;
            int y = arr[i].y;
            if (x != y) {
                makeroot(x);
                if (findroot(y) != x) {
                    link(x, n + i);
                    link(y, n + i);
                } else {
                    split(x, y);
                    int pre = maxbEdge[y];
                    if (arr[i].b < arr[pre].b) {
                        cut(arr[pre].x, n + pre);
                        cut(arr[pre].y, n + pre);
                        link(x, n + i);
                        link(y, n + i);
                    }
                }
            }
            makeroot(1);
            if (findroot(n) == 1) {
                split(1, n);
                ans = min(ans, arr[maxaEdge[n]].a + arr[maxbEdge[n]].b);
            }
        }
        return ans == INF ? -1 : ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> arr[i].x >> arr[i].y >> arr[i].a >> arr[i].b;
        }
        int ans = compute();
        cout << ans << "\n";
        return 0;
    }

七、题目4：温暖会指引我们前行

n 个地点，道路是无向边，每条道路有温度和长度两种权值。初始没有任何道路，之后出现的道路温度互不相同。

对于 x 到 y 的每一条路径，把路径上的道路按温度升序排列，得到这条路径的温度序列。温度序列字典序最大的那条路径叫最佳路径，因为温度互不相同，最佳路径唯一。

三条操作：find e x y t l 建一条编号 e、端点 x y、温度 t、长度 l 的边；move x y 打印 x 到 y 最佳路径的长度总和，不连通输出 -1；change e l 把编号 e 的道路长度改成 l。

先要把「字典序最大」翻译成一句能操作的话。

结论是：最佳路径就是最大生成树上 x 到 y 的那条路径。理由可以从阈值往后推。把所有温度不小于 v 的边单独拿出来组成一张子图，最大生成树有个性质，它被限制在这张子图上时，连通块划分和子图本身一模一样。这个性质是「温度从大到小做 Kruskal」的直接产物：扫到 v 以上的那些边时，并查集里的划分就是子图的连通块，而最大生成树里所有不小于 v 的边正好就是被选中的那些。

把这条性质套到路径上：如果存在一条 x 到 y 的路径，边全都小于 v，那就说明 x 和 y 在子图里不连通，于是在 T 上它们也不连通，T 上 x→y 的路径也必然有一条边小于 v。

于是逐位比较就出来了。两条路径的温度序列从第一个位置开始比，也就是先比「路径上最小的温度」。最大生成树上的路径，在每个阈值 v 下面，「小于 v 的边数」都不会更多，所以它第一个跟别人不一样的位置，一定更大。

转换完成之后，LCT 要做的事就两种：维护一棵按温度的最大生成树（加边成环就换掉环上温度最小的边，前提是当前边温度更大）；以及维护路径上长度的和。

这里有个容易踩的坑：点节点也会被算进「温度最小」的比较里。代码给这些点设了温度正无穷，它们永远不会被换掉。

int sum[MAXN];
    int mintEdge[MAXN];

    void up(int x) {
        int e = x <= n ? 0 : x - n;
        sum[x] = sum[ls[x]] + sum[rs[x]] + el[e];
        mintEdge[x] = e;
        if (et[mintEdge[ls[x]]] < et[mintEdge[x]]) {
            mintEdge[x] = mintEdge[ls[x]];
        }
        if (et[mintEdge[rs[x]]] < et[mintEdge[x]]) {
            mintEdge[x] = mintEdge[rs[x]];
        }
    }

长度和的处理要小心 change。改的是一条边的长度，也就是某个边节点的点权。做法是把那个点 splay 上来，改完 up 一次：

void change(int e, int l) {
        splay(n + e);
        el[e] = l;
        up(n + e);
    }

splay(n + e) 之后，这个点在它那棵辅助树里没有祖先了，改完只需要往上汇总它自己。

八、题目5：严格次小生成树

n 个点 m 条无向边，边有边权，可能有自环。严格次小生成树的边权和必须严格大于最小生成树的边权和，题目保证它存在，求这个和。n 到 10⁵，m 到 3×10⁵，边权到 10⁹。

先用 Kruskal 求出最小生成树，权和记作 sum。

然后是关键观察：任何一棵生成树，都可以看成「把某一条非树边加进去，环上换掉一条边」得到的。而想让权和比 sum 大得尽量少，就该对每条非树边算一次最小的增量。

设非树边权为 w，它加进去形成的环里，树边的最大权是 v₁、严格次大权是 v₂。分三种情况：

  • w > v₁：换掉最大边，增量是 w - v₁。
  • w < v₁：换掉最大边反而让权和变小了，这棵树比最小生成树还小，不可能是次小。跳过。
  • w == v₁：换掉 v₁ 之后权和没变，不满足「严格大于」。这时只能退一步换 v₂，增量是 w - v₂。

最后答案是 sum 加上所有情况里最小的那个增量。所以 up 要同时维护最大值和严格次大值。

合并两份信息时不能想当然。左右儿子的当前最大和严格次大是先合成一个，再把自己（如果是边节点）插进去：

void up(int x) {
        int l = ls[x], lmax1 = max1[l], lmax2 = max2[l];
        int r = rs[x], rmax1 = max1[r], rmax2 = max2[r];
        if (lmax1 > rmax1) {
            max1[x] = lmax1;
            max2[x] = max(rmax1, lmax2);
        } else if (rmax1 > lmax1) {
            max1[x] = rmax1;
            max2[x] = max(lmax1, rmax2);
        } else {
            max1[x] = lmax1;
            max2[x] = max(lmax2, rmax2);
        }
        int v = x <= n ? -INF : arr[x - n].w;
        if (v > max1[x]) {
            max2[x] = max1[x];
            max1[x] = v;
        } else if (v < max1[x] && v > max2[x]) {
            max2[x] = v;
        }
    }

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    struct Edge {
        int x, y, w;
    };

    bool EdgeCmp(Edge a, Edge b) {
        return a.w < b.w;
    }

    const int MAXN = 400001;
    const int MAXM = 300001;
    const int INF = 1000000001;
    int n, m;

    Edge arr[MAXM];
    int father[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int max1[MAXN];
    int max2[MAXN];

    int find(int x) {
        if (x != father[x]) {
            father[x] = find(father[x]);
        }
        return father[x];
    }

    void up(int x) {
        int l = ls[x], lmax1 = max1[l], lmax2 = max2[l];
        int r = rs[x], rmax1 = max1[r], rmax2 = max2[r];
        if (lmax1 > rmax1) {
            max1[x] = lmax1;
            max2[x] = max(rmax1, lmax2);
        } else if (rmax1 > lmax1) {
            max1[x] = rmax1;
            max2[x] = max(lmax1, rmax2);
        } else {
            max1[x] = lmax1;
            max2[x] = max(lmax2, rmax2);
        }
        int v = x <= n ? -INF : arr[x - n].w;
        if (v > max1[x]) {
            max2[x] = max1[x];
            max1[x] = v;
        } else if (v < max1[x] && v > max2[x]) {
            max2[x] = v;
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        fa[x] = y;
    }

    ll compute() {
        sort(arr + 1, arr + m + 1, EdgeCmp);
        ll sum = 0;
        int minAdd = INF;
        for (int i = 1; i <= m; i++) {
            int x = arr[i].x;
            int y = arr[i].y;
            int w = arr[i].w;
            if (x != y) {
                int fx = find(x);
                int fy = find(y);
                if (fx != fy) {
                    father[fx] = fy;
                    max1[n + i] = w;
                    max2[n + i] = -INF;
                    link(x, n + i);
                    link(y, n + i);
                    sum += w;
                } else {
                    split(x, y);
                    int v1 = max1[y];
                    int v2 = max2[y];
                    if (w > v1) {
                        minAdd = min(minAdd, w - v1);
                    } else if (w == v1 && v2 != -INF) {
                        minAdd = min(minAdd, w - v2);
                    }
                }
            }
        }
        return sum + minAdd;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> arr[i].x >> arr[i].y >> arr[i].w;
        }
        for (int i = 1; i <= n; i++) {
            father[i] = i;
        }
        for (int i = 0; i <= n; i++) {
            max1[i] = max2[i] = -INF;
        }
        cout << compute() << "\n";
        return 0;
    }

九、复杂度分析

设 n 为点数，m 为边数，q 为操作数。LCT 里一共有 n + m 个点，makeroot、access、splay、link、cut、findroot、split 都是均摊 O(log(n + m))。边转点之后，加一条边是两次 link 或两次 cut，常数翻倍但仍是对数级。

步骤时间复杂度
up（汇总一个点）O(1)
access / link / cut / findrootO(log(n + m)) 均摊
题目1：Kruskal 预处理O(m log m)
题目1：单次操作（倒序扫一遍）O(log(n + m))
题目2 / 题目3：排序加 m 次加边O(m log m + m log(n + m))
题目4：每条操作一次加边或一次查询O(log(n + m))
题目5：Kruskal 加每条非树边一次 splitO(m log m + m log(n + m))

空间上，LCT 的每个数组都开到 n + m：fa、ls、rs、rev、sta，再加一两个汇总数组。题目1 多一个 map 存端点对到编号的映射，整体 O(n + m)。

十、最后

边转点这个转换本身只有三行代码，难的是想清楚「这条路径上我要什么」。

五道题的目标各不相同：求最小瓶颈路、求极差最小的生成树、两权值相加、字典序最大、严格次小。但它们脚下踩的是同一块地砖，把边变成点，让 splay 去汇总；剩下的全是在「成环之后换掉哪一条」上做文章。

下一节把时间轴也搬进来：一条边不再永远存在，而是只在某一段区间里存在。那时候就不只是 LCT 一个结构的事了。
