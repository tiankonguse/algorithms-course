最好的部署：任意顺序压成相邻状态

n 台机器排成一排，部署顺序自己定，每台的收益只看它被部署那一刻左右邻居里已经部署了几台。区间 dp 从最后一步想清楚切分，线性 dp 把「谁先谁后」压成相邻两台之间的相对顺序。

零、背景

给 n 台机器，每次挑一台部署，顺序任意。部署 i 号机器时，如果左右邻居里已部署 0 台，收益 a[i]；1 台，收益 b[i]；2 台，收益 c[i]。求总收益最大。部署顺序影响每台的收益，因为先部署的机器周围往往是空的，后部署的机器周围已经满了。

n = 4 的一组数据：a = [5,3,2,4]，b = [6,8,9,7]，c = [9,12,11,10]。部署顺序 1 → 4 → 3 → 2：1 号先部署，两边没人，收益 5；4 号部署时邻居 3 号还没部署，收益 4；3 号部署时右边 4 号已在，收益 9；2 号最后部署，左右 1、3 号都在，收益 12。合计 5 + 4 + 9 + 12 = 30。

一、区间 dp：想最后一步

f(l, r) 表示部署 l..r 的所有机器、且 l−1 与 r+1 一定没部署时的最大收益。最后一台部署的是谁，是唯一要决定的事：

最后部署 l：l 的右邻居 l+1..r 已全部署，左边 l−1 没部署，收益 b[l]，再接 f(l+1, r)。最后部署 r：对称，b[r] + f(l, r−1)。最后部署中间的 i：左右两个区间都已部署完，收益 c[i]，再接 f(l, i−1) + f(i+1, r)。只剩一台时 l = r，两边都没部署，收益 a[l]。

状态 O(n²)，每个状态枚举中间点 O(n)，总 O(n³)。n = 500 实测 152ms，n 上到 1e5 就完全没法跑。

二、线性 dp：把顺序压成相邻状态

一台机器的收益只被 i−1、i+1 这两台影响，隔着远的机器完全不相干。于是对相邻的 i 和 i+1，只有「i 先部署」或「i+1 先部署」两种相对顺序。dp[i][0/1] 表示 i 号机器的前一台（i−1）没部署 / 已部署时，部署完 i..n 的最大收益：

dp[i][0]：i−1 没部署。若 i 先部署，此刻左右都没部署，收益 a[i]，轮到 i+1 时它的前一台 i 已部署，接 dp[i+1][1]；若 i+1 先部署，i+1 部署时前一台 i 还没部署，接 dp[i+1][0]，最后 i 部署时右边已部署 1 台，收益 b[i]。

dp[i][1]：i−1 已部署。i 先部署收益 b[i]，接 dp[i+1][1]；i+1 先部署收益 c[i]，接 dp[i+1][0]。答案 dp[1][0]。O(n)，n = 1e5 实测 8ms。

部署顺序回放：逐步部署看收益

三、复杂度对比

同一份数据：区间 dp 枚举最后一步，O(n³)，n = 500 要 152ms，n = 1000 直接到 1.2 秒量级；线性 dp 只留相邻相对顺序，O(n)，n = 1e5 只要 8ms。区间 dp 的正确性没得挑，代价是状态里多了一整个区间。线性 dp 靠的是抓住收益只依赖邻居这个性质。

区间版先验证正确性，线性版跑大数据：

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100005;
    long long a[MAXN], b[MAXN], c[MAXN];
    long long dp[MAXN][2];
    int n;

    // 区间 dp：部署 l..r 的机器，且 l-1、r+1 一定没部署
    // 想最后一步部署谁：边界机器最后部署时，相邻只有 1 台已部署
    long long f(int l, int r) {
        if (l == r) {
            return a[l];            // 只剩一台，两边都没部署，收益 a[l]
        }
        long long ans = f(l + 1, r) + b[l];     // 最后部署 l：右边已部署，收益 b[l]
        ans = max(ans, f(l, r - 1) + b[r]);     // 最后部署 r
        for (int i = l + 1; i < r; i++) {
            // 最后部署中间的 i：左右两边区间都已部署，收益 c[i]
            ans = max(ans, f(l, i - 1) + f(i + 1, r) + c[i]);
        }
        return ans;
    }
#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 100005;
    long long a[MAXN], b[MAXN], c[MAXN];
    long long dp[MAXN][2];
    int n;

    // 线性 dp：dp[i][0/1] 表示 i 号机器的前一台（i-1）没/已部署
    // 转移只看 i 与 i+1 谁先部署：先部署的按部署时刻收益，后部署的交给 dp
    long long best() {
        dp[n][0] = a[n];            // n 号左边没机器，相当于前一台没部署
        dp[n][1] = b[n];            // 但 n 号右边没机器，相邻至多 1 台
        for (int i = n - 1; i >= 1; i--) {
            // i-1 没部署：i 先部署收益 a[i]（右边 0 台）或 i+1 先部署收益 b[i]
            dp[i][0] = max(a[i] + dp[i + 1][1], b[i] + dp[i + 1][0]);
            // i-1 已部署：i 先部署收益 b[i] 或 i+1 先部署收益 c[i]
            dp[i][1] = max(b[i] + dp[i + 1][1], c[i] + dp[i + 1][0]);
        }
        return dp[1][0];
    }

四、总结

收益只由相邻机器决定时，任意顺序的决策可以压成「相邻两台谁先部署」。区间 dp 适合先验证正确性，线性 dp 才是能跑大数据的那版。看到「顺序任意、收益只和局部有关」的题，先问自己：状态能不能只留一台机器和它前一台的关系。
