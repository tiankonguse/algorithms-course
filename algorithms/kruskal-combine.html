重构树接上最短路和 ST 表

子树里可以挂的不只是个数。挂上「到 1 号点的最短路」，能回答归程；给每个原始点记一个 dfn，再用 ST 表查区间最值，能回答「一段编号什么时候连通」。

零、题目4：归程

一共有 n 个点、m 条无向边，原图连通，每条边有长度 l 和海拔 a。一共有 q 条查询，格式如下：查询 x y，起初走过海拔 > y 的边免费，可视为开车，但是车不能走海拔 ≤ y 的边；你可以在任意节点下车，车不能再用；下车后经过每条边的长度（包括海拔 > y 的边）都算入步行长度。你想从点 x 到 1 号点，打印最小步行长度。1 ≤ n ≤ 2 × 10⁵，1 ≤ m、q ≤ 4 × 10⁵，强制在线。测试链接：P4768。

拆开看：水位 y 一旦给定，能开车到达的范围就定下来了，也就是「只走海拔 > y 的边」的那个连通块。在这个块里任选一个点下车，剩下的步行长度是它到 1 号点的最短路。所以要的是这个连通块里 dist 到 1 的最小值。

两件事各做一次。先对原图跑一遍 dijkstra，求出每个点到 1 号点的最短路 dist；再按海拔降序建重构树，让每个节点记下自己子树里所有叶子的 dist 最小值 mindist。

二、题目5：加边直到连通

图里有 n 个点、m 条无向边，点的编号 1~n，边的编号 1~m，所有点都连通。一共有 q 条查询，格式如下：查询 l r，至少要加完编号前多少的边，才能使得 [l, r] 中的所有点连通。1 ≤ n ≤ 10⁵，1 ≤ m、q ≤ 2 × 10⁵。测试链接：CF1706E。

把边的编号当边权升序建树。要让 [l, r] 里所有点连通，需要的最小编号就是这些点在树上 LCA 的 nodeKey。

一堆点的 LCA 怎么算？有个常用结论：一堆点的 LCA 等于其中 dfn 最小的那个点和 dfn 最大的那个点的 LCA。所以只要能快速查出 [l, r] 里 dfn 的最小值和最大值。

这里的 dfn 是重构树上所有节点（不只是叶子）的 dfs 序，但 ST 表只对原始点建：stmin[i][0] = stmax[i][0] = dfn[i]，i 从 1 到 n。查询 [l, r] 时在这个数组上做区间最值，得到的两个 dfn 再用 seg 数组还原成节点编号。

三、代码

题目4 的 dfs 和 query。dfs 里先递归再取 min，和上一节 leafsiz 的写法是同一个模子。

void dfs(int u, int fa) {
        stjump[u][0] = fa;
        for(int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[ stjump[u][p - 1] ][p - 1];
        }
        for(int e = headk[u]; e > 0; e = nextk[e]) {
            dfs(tok[e], u);
        }
        if(u <= n) {
            mindist[u] = dist[u];
        } else {
            mindist[u] = INF;
        }
        for(int e = headk[u]; e > 0; e = nextk[e]) {
            mindist[u] = min(mindist[u], mindist[tok[e]]);
        }
    }

    int query(int node, int line) {
        for(int p = MAXP - 1; p >= 0; p--) {
            if(stjump[node][p] > 0 && nodeKey[stjump[node][p]] > line) {
                node = stjump[node][p];
            }
        }
        return mindist[node];
    }

题目5 的 ST 表只对原始点建，长度是 n，不是 2n。查询完把 dfn 还原成节点编号再求 LCA。

void buildst() {
    	lg2[0] = -1;
        for (int i = 1; i <= n; i++) {
        	lg2[i] = lg2[i >> 1] + 1;
            stmax[i][0] = dfn[i];
            stmin[i][0] = dfn[i];
        }
        for (int p = 1; p <= lg2[n]; p++) {
            for (int i = 1; i + (1 << p) - 1 <= n; i++) {
                stmax[i][p] = max(stmax[i][p - 1], stmax[i + (1 << (p - 1))][p - 1]);
                stmin[i][p] = min(stmin[i][p - 1], stmin[i + (1 << (p - 1))][p - 1]);
            }
        }
    }

    int dfnmin(int l, int r) {
        int p = lg2[r - l + 1];
        int ans = min(stmin[l][p], stmin[r - (1 << p) + 1][p]);
        return ans;
    }

    int dfnmax(int l, int r) {
        int p = lg2[r - l + 1];
        int ans = max(stmax[l][p], stmax[r - (1 << p) + 1][p]);
        return ans;
    }
int query(int l, int r) {
        int x = seg[dfnmin(l, r)];
        int y = seg[dfnmax(l, r)];
        return nodeKey[lca(x, y)];
    }

复杂度分析

步骤时间说明
dijkstra（题目4）O(m log m)只在原图上跑一次，与查询无关
边排序 + 建树O(m log m)题目4 按海拔降序，题目5 按编号升序
dfs 建表O(n log n)题目4 顺带算 mindist，题目5 顺带记 dfn 与 seg
题目5 建 ST 表O(n log n)对 n 个原始点的 dfn 建最大、最小两张表
单次查询O(log n)题目4 一次上跳；题目5 两次 O(1) 区间最值加一次 LCA
空间O(n log n)倍增表 (2n) × 20，题目5 再加两张 n × 20 的 ST 表

题目4 是强制在线的，但重构树本身不要求离线，这一点和后面的题目6 正相反。

最后

题目5 用 ST 表在 dfn 序上查区间最值，本质上是在叶子序列上做区间查询。下一节换个更重的：在叶子的 dfn 序上建线段树和主席树，回答「连通块里点权的最大值」和「第 k 大点权」。
