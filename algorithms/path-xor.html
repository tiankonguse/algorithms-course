路径最大异或和：图与线性基

无向图里 1 到 n 可以绕路，绕出来的每条路都能拆成「一条树路径 + 若干环」。于是问题变成：DFS 树把所有环的异或收进线性基，再把树路径和环空间凑最大异或和。

零、问题

n 个点 m 条边的无向图，每条边有权，从 1 走到 n，路径上边的异或和最大是多少。路径可以重复走边。n ≤ 5 × 104、m ≤ 105、边权 ≤ 1018。

重复走一条边两次异或成 0，等价于没走。所以一条任意路径 = 一条简单路径 + 若干环的组合（环的异或随便加）。剩下两件事：找一条简单路径当基准，把图里所有环的异或空间建出来。

一、DFS 树收集环

对图做一次 DFS，走出来的树边构成生成树，记 path[u] 为根到 u 的树路径异或。每条非树边 (u, v) 都对应一个基本环：树路径 u..v 加上这条边，异或是 path[u] ^ w ^ path[v]。图里任何环都能表示成基本环的异或组合，所以把每个基本环插进线性基，就是整个图的环空间。

DFS 迭代写：访问到已 visited 的点，那条边就是非树边，环入基；访问到新点，就是树边，继续往下走。父边直接跳过。

二、答案：树路径 ^ 环空间

1 到 n 的树路径是 path[n]，答案 = path[n] 异或环空间里的某个数，取最大。线性基查询从高到低贪心即可。

// DFS 树：path[u] 是根到 u 的树路径异或，遇到已访问点就收集环
    void dfs(int root) {
      stackSize = 0;
      push(root, 0, -1, 0);
      while (stackSize > 0) {
        pop();
        if (e == -1) {
          path[u] = p;
          visited[u] = true;
          e = head[u];
        } else {
          e = next[e];
        }
        if (e != 0) {
          push(u, f, e, p);
          int v = to[e];
          ll xr = p ^ weight[e];
          if (visited[v]) insert(xr ^ path[v]);   // 非树边形成环，环异或入基
          else push(v, u, -1, xr);
        }
      }
    }
// 答案 = path[n] ^ 环空间，从高到低贪心取最大
    ll query(ll init) {
      for (int i = BIT; i >= 0; i--) {
        init = max(init, init ^ basis[i]);
      }
      return init;
    }

DFS O(n + m)，每个基本环插入 O(60)，查询 O(60)。严格说这题属于基环树 dp 的范畴，但不系统学基环树也能直接用这个思路做。

四、总结

路径最大异或和 = 树路径 + 环空间：DFS 树给出基准 path[n]，非树边逐个把基本环插进线性基，最后贪心取最大。图里所有环都能由基本环异或出来，这是整个解法成立的关键。重复走边不改变异或结果，所以绕路只增加环的选择，不会弄丢答案。
