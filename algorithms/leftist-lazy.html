左偏树的懒更新：城池攻占与棘手操作

左偏树的合并、弹出都只动根附近的节点，懒更新因此可以只打在堆顶：整棵树要更新，就在头节点记一个 mul / add 标记，等 merge、pop 真正碰到子树节点时再下发。与线段树的懒更新是同一套「能懒则懒」的机制。

零、懒更新挂在头节点

线段树的懒更新依赖下标区间：整段更新只改区间节点上的标记，查询或下推时才真正作用到叶子。左偏树没有下标区间，树的形态又随合并不断变化，标记打在哪里？答案是最简单的位置：堆顶。

小根堆里，根节点是整棵树的最小值。想让整棵树每个节点都加 v，就在根上记 add += v；想让整棵树都乘 m，就在根上记 mul *= m。任何时刻，某个节点的真实值 = 节点存的值经过它到根路径上所有标记作用后的结果。合并、弹出要比较两个节点的值，或者要移动子树时，才把堆顶的标记下发给左右儿子，保证比较和移动发生在真实值上。

乘法标记有一个容易写错的细节：堆顶挂着 mul = m, add = a 时，真实值 = 存的值 × m + a。下发给儿子时，儿子的 add 要变成 add × m + a，而不是简单的 add + a，因为加法标记整体也要跟着乘法放大。上面城池攻占代码里的 down 函数就是照这个式子写的。

一、城池攻占（P3261）

n 个城市组成一棵树，1 号是根。每个城市有防御值，还有一条奖励规则：奖励类型 0 表示攻克后攻击力加一个值，类型 1 表示攻克后攻击力乘一个值。m 个骑士各带初始攻击力，从自己的起点城市开始向上攻城：攻击力 ≥ 城市防御，城破，拿到奖励继续攻上级；攻击力 < 防御，骑士当场牺牲。每个骑士独立行动。要输出每个城市牺牲了几个骑士、每个骑士攻占了几座城。

数据范围是 3×105，奖励还会让攻击力不断增长，所以骑士的攻击力得用 long long 存。

解法把每个城市看成一棵骑士堆，按攻击力排小根堆。城市编号满足上级编号小于自身编号，于是从 n 号城市倒着处理到 1 号：处理城市 i 时，从下级城市合并上来的骑士已经全在 i 的堆里了。这一步做三件事：

（1）把堆里攻击力小于防御的骑士全部弹出，每弹一个，城市 i 的牺牲计数加一，骑士的牺牲城市记成 i。弹出用上一课的 pop：左右儿子合并，头节点清空。

（2）剩余骑士整堆打上城市 i 的奖励懒标记：类型 0 是加、类型 1 是乘，都只改堆顶的 mul / add。

（3）整堆合并进上级城市 belong[i] 的堆。

最后统计：每个骑士攻占的城市数 = 起点深度 deep[first] 减去牺牲城市深度 deep[die]。骑士一路攻到根没牺牲时 die 记 0、deep[0] 记 0，攻占数正好是起点深度。

核心代码只有 merge、pop 和两个懒更新函数，down 负责下发、upgrade 负责在堆顶打标记：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    int n, m;
    long long defend[MAXN];
    int belong[MAXN];
    int type[MAXN];       
    long long gain[MAXN];
    long long attack[MAXN];
    int first[MAXN];
    int deep[MAXN];
    int top[MAXN];
    int sacrifice[MAXN];
    int die[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int dist[MAXN];
    long long mul[MAXN];
    long long add[MAXN];

    void prepare() {
        dist[0] = -1;
        for (int i = 1; i <= m; i++) {
            ls[i] = rs[i] = dist[i] = 0;
            mul[i] = 1;
            add[i] = 0;
        }
        for (int i = 1; i <= n; i++) {
            sacrifice[i] = top[i] = 0;
        }
    }

    void upgrade(int i, int t, long long v) {
        if (t == 0) {
            attack[i] += v;
            add[i] += v;
        } else {
            attack[i] *= v;
            mul[i] *= v;
            add[i] *= v;
        }
    }

    void down(int i) {
        if (mul[i] != 1 || add[i] != 0) {
            int l = ls[i];
            int r = rs[i];
            if (l != 0) {
                attack[l] = attack[l] * mul[i] + add[i];
                mul[l] = mul[l] * mul[i];
                add[l] = add[l] * mul[i] + add[i];
            }
            if (r != 0) {
                attack[r] = attack[r] * mul[i] + add[i];
                mul[r] = mul[r] * mul[i];
                add[r] = add[r] * mul[i] + add[i];
            }
            mul[i] = 1;
            add[i] = 0;
        }
    }

    int merge(int i, int j) {
        if (i == 0 || j == 0) {
            return i + j;
        }
        if (attack[i] > attack[j]) {
            swap(i, j);
        }
        down(i);
        rs[i] = merge(rs[i], j);
        if (dist[ls[i]] < dist[rs[i]]) {
            swap(ls[i], rs[i]);
        }
        dist[i] = dist[rs[i]] + 1;
        return i;
    }

    int pop(int i) {
        down(i);
        int ans = merge(ls[i], rs[i]);
        ls[i] = rs[i] = dist[i] = 0;
        return ans;
    }

    void compute() {
        deep[1] = 1;
        for (int i = 2; i <= n; i++) {
            deep[i] = deep[belong[i]] + 1;
        }
        for (int i = 1; i <= m; i++) {
            if (top[first[i]] == 0) {
                top[first[i]] = i;
            } else {
                top[first[i]] = merge(top[first[i]], i);
            }
        }
        for (int i = n; i >= 1; i--) {
            while (top[i] != 0 && attack[top[i]] < defend[i]) {
                die[top[i]] = i;
                sacrifice[i]++;
                top[i] = pop(top[i]);
            }
            if (top[i] != 0) {
                upgrade(top[i], type[i], gain[i]);
                if (top[belong[i]] == 0) {
                    top[belong[i]] = top[i];
                } else {
                    top[belong[i]] = merge(top[belong[i]], top[i]);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        prepare();
        for (int i = 1; i <= n; i++) {
            cin >> defend[i];
        }
        for (int i = 2; i <= n; i++) {
            cin >> belong[i] >> type[i] >> gain[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> attack[i] >> first[i];
        }
        compute();
        for (int i = 1; i <= n; i++) {
            cout << sacrifice[i] << "\n";
        }
        for (int i = 1; i <= m; i++) {
            cout << deep[first[i]] - deep[die[i]] << endl;
        }
        return 0;
    }

merge 比较的是骑士的攻击力，也就是真实值。所以合并前先 down(i) 把堆顶的标记下发，保证 attack[i] 与 attack[j] 可比。弹出时同样先 down 再合并左右。

二、棘手的操作（P3273）

n 个节点各自独立成集合，实现 7 种操作：U 合并两个集合、A1 单点加、A2 集合加、A3 全体加、F1 查单点、F2 查集合最大值、F3 查全局最大值。操作共 m 次，n、m 都是 3×105。

每个集合用一棵大根堆维护，堆顶就是集合最大值。三个查询都能 O(1) 回答，麻烦的是三种加法怎么打标记：

（1）A2 集合加：只改堆顶的 add[h]，整棵堆共享。

（2）A3 全局加：单独记一个 addAll 偏移量，三个查询输出时统一加上，不下发到任何节点。

（3）A1 单点加：单点没法用集合标记，做法是把节点从堆里摘出来（remove），此刻把集合的 add 落进它的 num，加完 v 后独立成堆再合并回去。

F3 需要一个全局视角：代码里用 multiset heads 维护所有堆顶的真实值，A2、A1、U 改变堆顶时从 heads 里删掉旧的、插入新的，F3 直接取 heads.rbegin() 加 addAll。

U 合并两个集合时，课程代码做了启发式：比较两个集合的大小 siz，把小的集合整体 down 成绝对权值再 merge 进大的集合，大的集合的 add 标记直接继承。这样避免把两边都展开，摊还代价低。注意合并前先把两个堆顶从 heads 里删掉，合并完再插入新的堆顶。

这套代码的核心是 remove：删掉堆里任意节点后，还要从它的父节点向上重算 dist、必要时交换左右，并更新并查集指向。上一课的 leftist-delete 页已经完整讲过 remove，这里直接复用。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    int n, m;
    int num[MAXN];
    int up[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int dist[MAXN];
    int fa[MAXN];
    int siz[MAXN]; 
    int add[MAXN];
    int sta[MAXN];
    multiset<int> heads;
    int addAll = 0;

    void minusHead(int h) {
        if (h != 0) {
            heads.erase(heads.find(num[h] + add[h]));
        }
    }

    void addHead(int h) {
        if (h != 0) {
            heads.insert(num[h] + add[h]);
        }
    }

    void prepare() {
        dist[0] = -1;
        heads.clear();
        for (int i = 1; i <= n; i++) {
            up[i] = ls[i] = rs[i] = dist[i] = 0;
            fa[i] = i;
            siz[i] = 1;
            add[i] = 0;
            addHead(i);
        }
        addAll = 0;
    }

    int find(int i) {
        fa[i] = fa[i] == i ? i : find(fa[i]);
        return fa[i];
    }

    int merge(int i, int j) {
        if (i == 0 || j == 0) return i + j;
        if (num[i] < num[j]) {
            swap(i, j);
        }
        rs[i] = merge(rs[i], j);
        up[rs[i]] = i;
        if (dist[ls[i]] < dist[rs[i]]) {
            swap(ls[i], rs[i]);
        }
        dist[i] = dist[rs[i]] + 1;
        fa[ls[i]] = i;
        fa[rs[i]] = i;
        return i;
    }

    int remove(int i) {
        int h = find(i);
        fa[ls[i]] = ls[i];
        fa[rs[i]] = rs[i];
        int s = merge(ls[i], rs[i]);
        int f = up[i];
        fa[i] = s;
        up[s] = f;
        if (h != i) {
            fa[s] = h;
            if (ls[f] == i) {
                ls[f] = s;
            } else {
                rs[f] = s;
            }
            for (int d = dist[s]; dist[f] > d + 1; f = up[f], d++) {
                dist[f] = d + 1;
                if (dist[ls[f]] < dist[rs[f]]) {
                    swap(ls[f], rs[f]);
                }
            }
        }
        up[i] = ls[i] = rs[i] = dist[i] = 0;
        return fa[s];
    }

    void down(int i, int v) {
        if (i != 0) {
            add[i] = 0;
            int size = 0;
            sta[++size] = i;
            while (size > 0) {
                i = sta[size--];
                num[i] += v;
                if (rs[i] != 0) sta[++size] = rs[i];
                if (ls[i] != 0) sta[++size] = ls[i];
            }
        }
    }

    void u(int i, int j) {
        int l = find(i);
        int r = find(j);
        if (l == r) return;
        int lsize = siz[l];
        minusHead(l);
        int rsize = siz[r];
        minusHead(r);
        int addTag;
        if (lsize <= rsize) {
            down(l, add[l] - add[r]);
            addTag = add[r];
        } else {
            down(r, add[r] - add[l]);
            addTag = add[l];
        }
        int h = merge(l, r);
        siz[h] = lsize + rsize;
        add[h] = addTag;
        addHead(h);
    }

    void a1(int i, int v) {
        int h = find(i);
        minusHead(h);
        int l = remove(i);
        if (l != 0) {
            siz[l] = siz[h] - 1;
            add[l] = add[h];
            addHead(l);
        }
        num[i] = num[i] + add[h] + v;
        fa[i] = i;
        siz[i] = 1;
        add[i] = 0;
        addHead(i);
        u(l, i);
    }

    void a2(int i, int v) {
        int h = find(i);
        minusHead(h);
        add[h] += v;
        addHead(h);
    }

    void a3(int v) {
        addAll += v;
    }

    int f1(int i) {
        return num[i] + add[find(i)] + addAll;
    }

    int f2(int i) {
        int h = find(i);
        return num[h] + add[h] + addAll;
    }

    int f3() {
        return (*heads.rbegin()) + addAll;
    }

    int main(){
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) cin >> num[i];
        prepare();
        cin >> m;
        for (int i = 1; i <= m; i++) {
            string op; 
            cin >> op;
            if (op == "F3") {
                cout << f3() << "\n";
            } else {
                int x; cin >> x;
                if (op == "U") {
                    int y; cin >> y;
                    u(x, y);
                } else if (op == "A1") {
                    int y; cin >> y;
                    a1(x, y);
                } else if (op == "A2") {
                    int y; cin >> y;
                    a2(x, y);
                } else if (op == "A3") {
                    a3(x);
                } else if (op == "F1") {
                    cout << f1(x) << "\n";
                } else {
                    cout << f2(x) << "\n";
                }
            }
        }
        return 0;
    }

课程注释里点了一句：集合级的懒更新其实已经属于「启发式合并」的范畴，后面的课会专门讲。左偏树在这里只是提供了一个 O(log n) 的合并工具。

三、城池攻占演示

骑士爬城：防御、奖励与牺牲

城市树 1 ← 2 ← 3，防御 4 / 3 / 5。骑士 A 攻击 4 起点城 3，骑士 B 攻击 6 起点城 3。点「下一步」逐城处理。

蓝 = 城市根，橙 = 防御，绿 = 骑士，红 = 牺牲骑士

三座城市组成一条链：城 3 防御 5、奖励加 2（攻破后攻击 +2）；城 2 防御 3、奖励乘 2；城 1 防御 4、没有奖励。骑士 A 攻击 4、B 攻击 6，都从城 3 出发。逆序处理：城 3 先弹掉攻击不足的 A（4 < 5），B 攻破城 3 拿 +2 变成 8；城 2 防御 3，B 攻破拿 ×2 变成 16；城 1 防御 4，B 攻破。最终 A 牺牲在城 3，B 攻占 3 座城。

总结

左偏树做懒更新，标记只挂在堆顶：整树加改 add、整树乘改 mul，merge、pop 碰到子树时才下发。乘法下发时 add 要跟着乘，这是最容易被写错的地方。城池攻占用城市逆序处理，把每座城的骑士堆合并到上级，奖励打一次标记整堆生效；棘手操作把集合加打在堆顶、全局加打成偏移量，堆顶集合用 multiset 维护，F3 才能 O(1) 取全局最大。下节课的可持久化左偏树会换一套玩法：合并不再改老节点，而是沿途拷贝。
