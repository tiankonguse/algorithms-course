P哥的桶：线段树与线性基

桶里装任意个数字，单点塞数字、区间查最大异或和。线段树每个节点存一个线性基，插入沿路径更新，查询把覆盖区间的基合并起来。

零、问题

n 个桶排成一排，每个桶能装任意多个数字。两个操作：操作 1 k v 把 v 放进 k 号桶；操作 2 l r 从 l..r 号桶随意拿数字，返回能得到的最大异或和。n、m ≤ 5 × 104，v ≤ 231 - 1。

线段树套线性基：每个范围节点维护该范围内所有桶数字的线性基。插入把数字沿路径写进每个覆盖节点；查询把区间拆成 O(log n) 个完整节点，把它们的线性基合并进一个全局基，再求最大异或和。

一、为什么能合并

线性基满足合并性质：两个集合的异或空间的并，等于把两个线性基互相插入得到的线性基。区间 [l, r] 的异或空间 = 各覆盖节点桶数字的异或空间的并，逐基插入即可。每个节点的基大小是位数 O(30)，节点合并一次 O(30²)。

二、实现

插入沿用普通消元：从最高位往下，这一位没基就占下，有基就异或掉。查询先清空全局基，merge 把覆盖节点的基逐个插进去，最后从高到低贪心取最大。

// 异或空间线性基：普通消元插入，插入失败说明在空间里
    const int BIT = 30;
    bool insert(int* basis, int num) {
      for (int i = BIT; i >= 0; i--) {
        if (num >> i == 1) {
          if (basis[i] == 0) {
            basis[i] = num;
            return true;
          }
          num ^= basis[i];
        }
      }
      return false;
    }
// P哥的桶：线段树每个范围维护一个线性基
    void add(int jobi, int jobv, int l, int r, int i) {
      insert(treeBasis[i], jobv);       // 沿路径每个节点都插入
      if (l < r) {
        int mid = (l + r) >> 1;
        if (jobi <= mid) add(jobi, jobv, l, mid, i << 1);
        else add(jobi, jobv, mid + 1, r, i << 1 | 1);
      }
    }
    void merge(int jobl, int jobr, int l, int r, int i) {
      if (jobl <= l && r <= jobr) {
        for (int j = BIT; j >= 0; j--)
          if (treeBasis[i][j] != 0) insert(basis, treeBasis[i][j]);
      } else {
        int mid = (l + r) >> 1;
        if (jobl <= mid) merge(jobl, jobr, l, mid, i << 1);
        if (jobr > mid) merge(jobl, jobr, mid + 1, r, i << 1 | 1);
      }
    }
    int query(int jobl, int jobr, int m) {
      memset(basis, 0, sizeof(basis));
      merge(jobl, jobr, 1, m, 1);       // 收集覆盖区间的线性基
      int ans = 0;
      for (int j = BIT; j >= 0; j--) ans = max(ans, ans ^ basis[j]);
      return ans;
    }

插入 O(log n × 30)，查询 O(log n × 30²)，n、m 到 5 × 104 没压力。

四、总结

线段树套线性基的关键是「线性基可合并」：两两插入不丢信息。插入沿路径写节点，查询合并覆盖节点，各 O(log n) 段。这类「区间异或查询 + 单点修改」的结构题，线性基 + 线段树是标准解法；区间修改版本要换别的结构，但合并思路一样。
