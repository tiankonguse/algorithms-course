dfn 序：把子树框成一段区间

深度优先遍历走过的顺序，给每个节点编号，就是 dfn 序。它顺手做成了一件事：把任意一棵子树，变成 dfn 上的一段连续区间。子树里的节点关系，从此可以拿区间来算。

零、子树变成一段区间

按深度优先的顺序遍历整棵树，每第一次走到一个节点就给它编个号，1、2、3……编出来的序列就是 dfn 序。

dfs 有一个性质：走进一个节点 x 之后，必须把 x 的整棵子树走完，才会离开 x。所以 x 子树里的所有节点，dfn 序号是连在一起的一段。

具体来说，如果 x 的 dfn 序号是 d，子树里有 sz 个节点，那这棵子树就占 dfn 的区间 [d, d + sz - 1]。

这条性质有两个直接用途。一是判断节点之间的关系：y 在不在 x 的子树里，就是看 dfn[y] 落不落在 [dfn[x], dfn[x] + sz[x] - 1] 这段区间里。二是跨子树的讨论：把子树摆到数组上，很多区间上的技巧就能用了。

打 dfn 序号的同时，顺手把每棵子树的大小也算出来。子树大小靠后序拿到：进 x 时先记 1，每个儿子走完再把自己那部分加进来。

int dfn[MAXN];   // 下标是节点值，存 dfn 序号
    int deep[MAXN];  // 下标是 dfn 序号，存根到它的边数
    int sz[MAXN];    // 下标是 dfn 序号，存子树大小
    int dfnCnt;

    // 走到 x 节点，从根到这里经过了 k 条边
    void f(TreeNode* x, int k) {
        int i = ++dfnCnt;
        dfn[x->val] = i;
        deep[i] = k;
        sz[i] = 1;
        if (x->left) {
            f(x->left, k + 1);
            sz[i] += sz[dfn[x->left->val]];
        }
        if (x->right) {
            f(x->right, k + 1);
            sz[i] += sz[dfn[x->right->val]];
        }
    }

一、移除子树后的二叉树高度

给一棵二叉树，n 个节点的值互不相同，都在 1 到 n 之间。给 m 个查询，第 i 个查询要移除以 queries[i] 的值作为根的那棵子树，返回移除之后树的高度。每次查询互相独立，做完一次树会还原。题面保证查询的值不是根节点的值。

朴素做法是按查询来：每次真的把子树删掉，再从根跑一遍求高度。m 次查询就是 O(m·n)。

树高是「从根到某个节点的最长简单路径上的边数」，也就是所有节点里最深的那个的深度。

删掉一棵子树之后，剩下的节点是 dfn 上去掉一段区间：[dfn[q], dfn[q] + sz[dfn[q]] - 1]。根还在，剩下的每个节点都还从根出发有路径，所以新的高度就是剩下节点里最大的深度。

于是把深度按 dfn 排成一列，预处理两个数组：maxl[i] 是前缀最大深度，maxr[i] 是后缀最大深度。对一个查询 q，答案就是 max(maxl[d-1], maxr[d + sz[d]])，其中 d = dfn[q]。左边看被挖区间之前的点，右边看之后那些点。

这里有两个容易踩的地方，都能用数字说明。只挖掉节点自己、忘了它的整棵子树也是一段区间，实测 53.73% 出错；只保留前缀最大、忘了区间右边还有节点，52.85% 出错。

int maxl[MAXN], maxr[MAXN];

    vector<int> treeQueries(TreeNode* root, vector<int>& queries) {
        dfnCnt = 0;
        f(root, 0);
        for (int i = 1; i <= dfnCnt; i++) maxl[i] = max(maxl[i - 1], deep[i]);
        maxr[dfnCnt + 1] = 0;
        for (int i = dfnCnt; i >= 1; i--) maxr[i] = max(maxr[i + 1], deep[i]);
        vector<int> ans;
        for (int q : queries) {
            int d = dfn[q];
            // 子树 q 占区间 [d, d + sz[d] - 1]，挖掉之后看两边的最高点
            int leftMax = maxl[d - 1];
            int rightMax = maxr[d + sz[d]];
            ans.push_back(max(leftMax, rightMax));
        }
        return ans;
    }

二、从树中删除边的最小分数

给一棵树和每个节点的值。删掉两条不同的边，树会裂成三个连通块。每块的分数是块内所有节点值的异或和，一种删法的分数是「最大异或和减最小异或和」。求所有删法里最小的分数。

删掉一条边，等于砍掉某个节点向父亲的那棵子树。要让每块的异或和好算，先给树打 dfn、算子树异或和 xr（dfn 下标），这样整棵树的异或和就是 xr[1]。

两条被砍的边，各自对应一棵子树。按 dfn 把小的那棵叫 pre、大的叫 pos。因为子树是 dfn 上的区间，这两个区间只可能是两种关系：

  1. 包含：pos 整棵落在 pre 里面，即 pos < pre + sz[pre]。这时三块分别是 pos 这棵、pre 去掉 pos、以及 pre 外面的全部。
  2. 不相交：两个区间各走各的。三块分别是 pos 这棵、pre 这棵、以及剩下的全部。

每块的异或和都用 xr 拼出来，判断落在哪种情形，就看 pos 和 pre + sz[pre] 谁大。枚举两条边 O(n²) 对，每对 O(1) 算完，数据范围下正好够用。

不加区间包含判断，一律按「不相交」算，实测 35.29% 出错。这一处恰恰是整题的分水岭。

int dfn[MAXN];   // 下标是原始编号，存 dfn 序号
    int xr[MAXN];    // 下标是 dfn 序号，存子树异或和
    int sz[MAXN];    // 下标是 dfn 序号，存子树大小
    int dfnCnt;

    void f(vector<int>& nums, vector<vector<int>>& g, int u) {
        int i = ++dfnCnt;
        dfn[u] = i;
        xr[i] = nums[u];
        sz[i] = 1;
        for (int v : g[u]) {
            if (dfn[v] == 0) {            // dfn 还没打过，v 就是儿子
                f(nums, g, v);
                xr[i] ^= xr[dfn[v]];
                sz[i] += sz[dfn[v]];
            }
        }
    }

打 dfn 的这一步，用 dfn 是否为零来判断「这个邻居访问过没有」，就不用再传父亲了。

int minimumScore(vector<int>& nums, vector<pair<int, int>>& edges) {
        int n = nums.size();
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e.first].push_back(e.second);
            g[e.second].push_back(e.first);
        }
        dfnCnt = 0;
        f(nums, g, 0);
        int m = edges.size(), ans = INT_MAX;
        for (int i = 0; i < m; i++) {
            int a = max(dfn[edges[i].first], dfn[edges[i].second]);
            for (int j = i + 1; j < m; j++) {
                int b = max(dfn[edges[j].first], dfn[edges[j].second]);
                int pre = min(a, b), pos = max(a, b);
                int s1 = xr[pos], s2, s3;
                if (pos < pre + sz[pre]) {    // pos 整棵都在 pre 里面
                    s2 = xr[pre] ^ xr[pos];
                    s3 = xr[1] ^ xr[pre];
                } else {                       // 两棵子树互不包含
                    s2 = xr[pre];
                    s3 = xr[1] ^ s1 ^ s2;
                }
                ans = min(ans, max(max(s1, s2), s3) - min(min(s1, s2), s3));
            }
        }
        return ans;
    }

复杂度分析

题目时间空间
移除子树后的二叉树高度O(n + m)O(n)
从树中删除边的最小分数O(n²)O(n)

高度那题，打 dfn 和前缀后缀最大都是一趟 O(n)，每个查询 O(1)，合起来 O(n + m)；空间开的是 dfn、深度、子树大小和前后缀最大，都是 O(n)。

最小分数那题，枚举两条边一共 O(n²) 对，每对常数次异或和比较，时间 O(n²)；存 dfn、子树异或和、子树大小的数组是 O(n)。节点数到 1000 时，n² 是 10⁶ 量级，跑起来没有压力。

打 dfn 的递归深度同样是实测过的边界。最小分数那版每层只带两个引用参数，链上能撑到 172788 层；如果数据可能出现很深的链，改成显式栈更稳。

总结

dfn 序给每个节点一个编号，让 dfs 顺序在数组上摊开。子树从树上的一块，变成数组上的一段：[dfn[x], dfn[x] + sz[x] - 1]。

「y 在不在 x 的子树里」于是变成一次区间判断，这是 dfn 最常用的用法。

区间上的老技巧都能搬过来。移除子树的高度用前缀、后缀最大值避开被挖走的那段；删两条边的最小分数靠区间包含关系，把三块异或和一次拼出来。

用 dfn 的时候，子树大小必须和序号一起算好。忘了子树是一段区间、只把它当单个节点处理，是最常见的错。

dfn 还不止用来判关系。把「选哪些节点」也摆到 dfn 上，树上背包能有一个比朴素做法快得多的解。
