全排列：交换回溯与同层去重

排列不回答「挑哪些」，回答「按什么顺序放」。n 个元素排进 n 个位置，叶子数从 2ⁿ 跳到 n!。做法也不是逐位取或不取，而是直接在数组上交换，换完再换回来。

零、背景

子序列和组合是选子集，全排列是排顺序。决策树的形状跟着变了：子序列每个位置两个分支，排列的第 i 层有 n − i + 1 个分支。第 0 层挑谁来占第 0 位，第 1 层从剩下的里挑谁来占第 1 位，一路排完。

量级差距先摆出来：n = 10 时，子序列 2^10 = 1024 个，排列 10! = 3628800 个，差了三千多倍。所以排列题的数据规模总是很小，n 超过 12 就得换思路。

一、没有重复项的全排列

做法一句话：位置 i 从 i 到 n−1 里挑一个元素放到 i 位，然后递归排 i+1 位以后。挑的过程直接在原数组上交换完成。

交换法的关键在换完要换回来。递归进入下一层前，把 nums[i] 和 nums[j] 交换；递归返回后，再把它们交换回去，数组恢复成进入前的样子。这一步漏了，上一层的选择会被下一层改掉，回溯树就串了味。

#include <bits/stdc++.h>
    using namespace std;

    // 没有重复项数字的全排列
    // 测试链接 : https://leetcode.cn/problems/permutations/

    void f(vector<int>& nums, int i, vector<vector<int>>& ans) {
        if (i == (int)nums.size()) {
            ans.push_back(nums);
        } else {
            for (int j = i; j < (int)nums.size(); j++) {
                swap(nums[i], nums[j]);
                f(nums, i + 1, ans);
                swap(nums[i], nums[j]);   // 恢复现场，特别重要
            }
        }
    }

    vector<vector<int>> permute(vector<int>& nums) {
        vector<vector<int>> ans;
        f(nums, 0, ans);
        return ans;
    }

为什么新开一个 path 数组不行？可以，但每层得拷贝。交换法连拷贝都省了：叶子时数组本身就是当前排列，直接收。

递归调用的次数比叶子多。实测 n = 8：叶子 40320 个（8!），递归调用 109601 次，等于 sum_{i=0..8} P(8, i)。第 i 层有 n! / (n−i)! 个节点，每一层都在往上叠。n = 3 时叶子 6 个、调用 16 次，树画在图 1 里。

复杂度 O(n! · n)：叶子 n! 个，每个叶子把数组拷进答案 O(n)。

二、有重复项的去重全排列

数组可能有重复值，要输出不重复的排列。[1, 1, 2] 的答案 3 个：[1, 1, 2]、[1, 2, 1]、[2, 1, 1]。直接套上一节的交换法会得到 6 个，两个 1 被当成两个元素。

去重的做法叫同层去重：第 i 位的值只尝试一次。循环到 j 时，如果 nums[j] 的值已经在这一层放过，跳过。用集合 used 记「值有没有来过 i 位置」。

#include <bits/stdc++.h>
    using namespace std;

    // 有重复项数组的去重全排列
    // 测试链接 : https://leetcode.cn/problems/permutations-ii/

    void f(vector<int>& nums, int i, vector<vector<int>>& ans) {
        if (i == (int)nums.size()) {
            ans.push_back(nums);
        } else {
            unordered_set<int> used;
            for (int j = i; j < (int)nums.size(); j++) {
                // nums[j] 没有来过 i 位置，才去尝试
                if (used.find(nums[j]) == used.end()) {
                    used.insert(nums[j]);
                    swap(nums[i], nums[j]);
                    f(nums, i + 1, ans);
                    swap(nums[i], nums[j]);
                }
            }
        }
    }

    vector<vector<int>> permuteUnique(vector<int>& nums) {
        vector<vector<int>> ans;
        f(nums, 0, ans);
        return ans;
    }

为什么同层去重就够？重复排列的唯一来源是同一个值在同一位置重复出现。第 0 位放第一个 1 和放第二个 1，得到的排列集合完全一样；把第二个 1 的整棵子树剪掉，一个不漏。不同层的重复是合法的：第 0 位放 1、第 1 位也放 1，这是排列的一部分，不是重复。

省了多少实测看得到：[1, 1, 1, 2, 2] 无剪枝要先生成 5! = 120 个再滤，同层去重直接输出 10 个（= 5! / 3! / 2!），递归调用 34 次。

复杂度 O(n! · n)，与无重复同阶，剪枝只去掉重复分支。

三、总结

全排列用交换回溯：换到位置、递归、换回，叶子 n! 个，调用 sum P(n, i) 次，复杂度 O(n! · n)。

去重发生在同层：第 i 位同值只放一次，集合 used 记下放过的值。它剪掉的是「同一个值在同一位置」的重复分支，不同层重复属于合法排列。

这三题（子序列、组合、排列）把带路径的递归和回溯的姿势都过了一遍。下一节换一种用法：递归不再枚举，而是当数据搬运工，用系统栈逆序栈、排序栈，最后是汉诺塔。
