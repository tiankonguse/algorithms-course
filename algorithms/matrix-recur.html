多阶递推：关系矩阵怎么填

泰波那契是把斐波那契往后推一阶，t(i) = t(i-1) + t(i-2) + t(i-3)。多米诺托米诺更麻烦，题面只说要拿 2×1 的条和 L 形铺满 2×n，递推式根本没给，得先暴力把表打出来。两个题最后都落到同一个模板：状态装最近 k 项，矩阵第 0 列写系数。

零、泰波那契：三项一起推

t(0) = 0、t(1) = 1、t(2) = 1，之后 t(i) = t(i-1) + t(i-2) + t(i-3)。想让状态前进一格，向量里就得放下最近三项：(t(n), t(n-1), t(n-2))。

关系矩阵的填法照着二阶抄。第 0 列写递推式的三个系数 (1, 1, 1)；第 1 列写成 (1, 0, 0)，含义是新状态的第二个分量取旧状态的第一个分量；第 2 列写成 (0, 1, 0)，把第二个分量挪到第三个。

起点是 v(2) = (t(2), t(1), t(0)) = (1, 1, 0)，幂次 n-2。

// 泰波那契：t(i) = t(i-1) + t(i-2) + t(i-3)，t(0) = 0、t(1) = 1、t(2) = 1
    long long tribonacci(long long n) {
    	if (n == 0) {
    		return 0;
    	}
    	if (n == 1) {
    		return 1;
    	}
    	if (n == 2) {
    		return 1;
    	}
    	Mat start(1, 3);			// 状态 (t(2), t(1), t(0))
    	start.a[0][0] = 1; start.a[0][1] = 1; start.a[0][2] = 0;
    	Mat base(3, 3);
    	base.a[0][0] = 1; base.a[0][1] = 1; base.a[0][2] = 0;   // 第 0 列是递推式的系数
    	base.a[1][0] = 1; base.a[1][1] = 0; base.a[1][2] = 1;   // 第 1、2 列把状态往后挪一格
    	base.a[2][0] = 1; base.a[2][1] = 0; base.a[2][2] = 0;
    	Mat ans = multiply(start, matrixPower(base, n - 2));
    	return ans.a[0][0];
    }

一、多米诺托米诺：递推式自己找

题面是两种瓷砖铺满 2×n：2×1 的多米诺可以竖放或横放，L 形的托米诺可以转四个方向，问铺满的方法数，答案对 109+7 取模。

卡在一个地方：L 形会把某一列铺掉一格、留出缺口，光用「铺满 2×m 的方法数」这一个量描述不了中间状态。所以要加一个缺角状态：h = 1 表示 2×n 的区域缺了一角（缺左上或缺右下都可以，两种朝向对称，数量一样）。

按最左边那一列怎么铺分类：

  1. 竖着放一块多米诺，右边剩 2×(n-1)，方案数是 f(n-1, 0)；
  2. 横着叠两块多米诺，右边剩 2×(n-2)，方案数是 f(n-2, 0)；
  3. 放一个 L 形，它必定在下一列留出缺口，而补这个缺口的位置有上下两种，方案数是 2 × f(n-2, 1)。

缺角状态自己的递推更短：缺口要么被一块横的多米诺盖掉一角、把缺口挪到更右边，要么直接由另一个 L 形补上，于是 f(n, 1) = f(n-1, 1) + f(n-1, 0)。

这两个式子写出来就是暴力，代价是指数级，n 只能跑到十几，但打表够用了。

// 打表用：h = 0 求铺满 2*n 的方法数，h = 1 求缺了一个角的 2*n
    long long brute(int n, int h) {
    	if (n == 0) {
    		return h == 0 ? 1 : 0;
    	}
    	if (n == 1) {
    		return 1;
    	}
    	if (h == 1) {
    		return brute(n - 1, 0) + brute(n - 1, 1);
    	}
    	return brute(n - 1, 0) + brute(n - 2, 0) + 2 * brute(n - 2, 1);
    }

    // 把前 9 项打出来看规律：1 2 5 11 24 53 117 258 569
    for (int i = 1; i <= 9; i++) {
    	cout << brute(i, 0) << " ";
    }
    cout << endl;

打出来的前 9 项：1、2、5、11、24、53、117、258、569。

指数增长有多快，量一下就知道：暴力算 f(15) 要 0.139 ms，f(20) 4.18 ms，f(25) 71.38 ms，f(30) 1355 ms。每多一阶大约乘 1.77，n 到 109 想都不用想。

规律长这样：g(n) = 2 × g(n-1) + g(n-3)，中间跳过了 g(n-2)。第 0 列的三个系数就是 (2, 0, 1)。

// 打表得到 g(1) = 1、g(2) = 2、g(3) = 5，之后满足 g(n) = 2 * g(n-1) + g(n-3)
    long long numTilings(long long n) {
    	if (n == 1) {
    		return 1;
    	}
    	if (n == 2) {
    		return 2;
    	}
    	if (n == 3) {
    		return 5;
    	}
    	Mat start(1, 3);			// 状态 (g(3), g(2), g(1))
    	start.a[0][0] = 5; start.a[0][1] = 2; start.a[0][2] = 1;
    	Mat base(3, 3);
    	base.a[0][0] = 2; base.a[0][1] = 1; base.a[0][2] = 0;   // 第 0 列是系数 2、0、1
    	base.a[1][0] = 0; base.a[1][1] = 0; base.a[1][2] = 1;
    	base.a[2][0] = 1; base.a[2][1] = 0; base.a[2][2] = 0;
    	Mat ans = multiply(start, matrixPower(base, n - 3));
    	return ans.a[0][0];
    }

题目要的 numTilings(n) 就是 g(n)，起点 (g(3), g(2), g(1)) = (5, 2, 1)，幂次 n-3。这一步一步都对得上：g(4) = 2 × 5 + 1 = 11，g(5) = 2 × 11 + 2 = 24。

二、逐格看一遍

三组递推式，同一个模板

橙格是递推式的系数（第 0 列），蓝格是把状态后移的 1。点下一步推一格，下面两行分别是推出来的数和题面/暴力给出的数。

复杂度分析

做法关键操作时间空间
暴力枚举按最左边一列怎么铺分类递归约 O(1.77n)O(n)
矩阵快速幂log n 次 k 阶矩阵相乘，每次 k3 次乘加O(k3 · log n)O(k2)

3 阶时 k3 = 27，log2 109 ≈ 30，合起来约 800 次乘加。实测泰波那契第 109 项单次 0.0017 ms（跑 100 万次累计 1682.8 ms），多米诺单次 0.0016 ms。暴力那边 f(30) 就要 1355 ms，f(109) 是个没法写出来的数。打表只用来定系数，跑完 n ≤ 9 就收工，那点指数代价忽略不计。

总结

k 阶固定系数递推的状态是最近 k 项排成的行向量，矩阵是 k 阶方阵：第 0 列写 k 个系数，第 1 到 k-1 列各放一个 1，把状态整体往后挪一格。

起点是递推式给出的那 k 个初始项，幂次是 n 减去起点最后一项的下标。写之前先把这三样对一遍，幂次差一位答案就全错。

递推式不摆在题面上时，先写一个按「最左边怎么铺」分类的暴力，把前十几项打出来，再从表里凑系数。多米诺托米诺的表凑出来是 g(n) = 2g(n-1) + g(n-3)，中间那项系数是 0。

暴力的用处就到这里。它跑 n ≤ 20 只要几毫秒，n = 30 已经 1.3 秒，指数增长不会陪你走远。
