线段树的分裂：按值域切开与区间染色

上一页一直在做合并：把两棵动态开点线段树并成一棵。这一页做反方向的操作，把一棵树按值域切成两棵，切下来的那棵整体搬走当新结构用。分裂本身只有 O(log n)，但要跟合并、空间池配合才好用。

零、背景

合并解决的是「儿子往父亲汇总」，分裂解决的是「按区间把一份数据整体摘出来」。两者共用同一套骨架：动态开点线段树，节点按需申请，用完还回池子。

这一页两个题。题目4 是分裂的模版题，五个操作把分裂、合并、单点加、区间查、第 k 小全过一遍；题目5 把「每种值一棵线段树」和分裂合在一起，做出「区间内把 x 全改成 y」这种看起来很重的操作。

一、题目4：线段树分裂

数字范围 1 到 n，先给出每种数字的个数，建成编号为 1 的可重集合，以后新集合的编号自增。m 条操作，五种类型：

  • 操作 0 x y z：x 号集合里取出 [y, z] 范围上的所有数字，生成新集合
  • 操作 1 x y：x 号与 y 号合并，以后 y 号不再使用
  • 操作 2 x y z：x 号里加入 y 个数字 z
  • 操作 3 x y z：查询 x 号里 [y, z] 上的数字个数
  • 操作 4 x y：查询 x 号里第 y 小的数字，不存在打印 −1

所有数据到 2·10⁵，测试链接 P5494。

集合用一棵按值域开的动态开点线段树表示，节点存该区间的数字个数。难点只有操作 0，其余四个都是线段树的常规操作。

写法上有个小技巧：分裂要返回两棵树的根，C++ 里不方便返回 pair，就用全局变量 tree1、tree2 承接。递归时先往下切，子树切完把结果挂回当前节点的左右儿子，再 up 一下。

合并那头比上一页的合并简单得多：两棵树的对应节点把计数相加，其中一棵整棵还回池子（del）。节点来自静态数组，用一个栈当空间池，newNode 弹一个、del 压回去。

七个操作跑一遍：分裂出 2 号、再分裂出 3 号、最后合并回 1 号

初始集合 1 里数字 1 到 5 分别有 1、2、3、4、5 个。点「下一步」逐条执行操作，格子里的数是该数字在集合里的个数。输出取自课程代码的实际运行结果。

这里有个细节：第 k 小那个函数没有判断 k 是否超过总数。它会一路往右走到最右边那个存在的叶子并返回它，只有当这条路径上有节点缺失时才返回 −1。于是「集合里最大值恰好是值域上界 n」时，查一个不存在的 k 会返回 n 而不是 −1。实测：n = 3、集合只有三个 3、查第 5 小，代码输出 3（应该是 −1）；换成集合 {1:2, 2:1}、查第 5 小，输出 −1 是对的。

另一个细节在空间上：题目给的数据范围到 2·10⁵，但课程的池子只开 MAXN × 10 = 2·10⁶ 个节点。建树就用掉 4·10⁵，之后每次分裂新建约 18 个、只有合并才回收，所以全是分裂的极端数据下池子会提前见底。真要卡满范围，把 MAXT 开到 MAXN × 20 更稳。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXT = MAXN * 10;
    int n, m;

    int root[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    long long sum[MAXT];
    int version;

    int pool[MAXT];
    int top;

    void prepare() {
        top = 0;
        for (int i = 1; i < MAXT; i++) {
            pool[++top] = i;
        }
    }

    int newNode() {
        return pool[top--];
    }

    void del(int i) {
        pool[++top] = i;
        ls[i] = 0;
        rs[i] = 0;
        sum[i] = 0;
    }

    void up(int i) {
        sum[i] = (sum[ls[i]] + sum[rs[i]]);
    }

    int add(int jobi, int jobv, int l, int r, int i) {
        int rt = i;
        if (rt == 0) {
            rt = newNode();
        }
        if (l == r) {
            sum[rt] += jobv;
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[rt] = add(jobi, jobv, l, mid, ls[rt]);
            } else {
                rs[rt] = add(jobi, jobv, mid + 1, r, rs[rt]);
            }
            up(rt);
        }
        return rt;
    }

    long long query(int jobl, int jobr, int l, int r, int i) {
        if (i == 0) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return sum[i];
        }
        int mid = (l + r) >> 1;
        long long ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, ls[i]);
        }
        if (jobr > mid) {
            ans += query(jobl, jobr, mid + 1, r, rs[i]);
        }
        return ans;
    }

    int kth(long long jobk, int l, int r, int i) {
        if (i == 0) {
            return -1;
        }
        if (l == r) {
            return l;
        }
        int mid = (l + r) >> 1;
        if (sum[ls[i]] >= jobk) {
            return kth(jobk, l, mid, ls[i]);
        } else {
            return kth(jobk - sum[ls[i]], mid + 1, r, rs[i]);
        }
    }

    int merge(int l, int r, int t1, int t2) {
        if (t1 == 0 || t2 == 0) {
            return t1 + t2;
        }
        if (l == r) {
            sum[t1] += sum[t2];
        } else {
            int mid = (l + r) >> 1;
            ls[t1] = merge(l, mid, ls[t1], ls[t2]);
            rs[t1] = merge(mid + 1, r, rs[t1], rs[t2]);
            up(t1);
        }
        del(t2);
        return t1;
    }

    int tree1, tree2;

    void split(int jobl, int jobr, int l, int r, int t1) {
        if (t1 == 0) {
            tree1 = t1;
            tree2 = 0;
            return;
        }
        if (jobl <= l && r <= jobr) {
            tree1 = 0;
            tree2 = t1;
            return;
        }
        int t2 = newNode();
        int mid = (l + r) >> 1;
        if (jobl <= mid) {
            split(jobl, jobr, l, mid, ls[t1]);
            ls[t1] = tree1;
            ls[t2] = tree2;
        }
        if (jobr > mid) {
            split(jobl, jobr, mid + 1, r, rs[t1]);
            rs[t1] = tree1;
            rs[t2] = tree2;
        }
        up(t1);
        up(t2);
        tree1 = t1;
        tree2 = t2;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        prepare();
        cin >> n >> m;
        version = 1;
        for (int i = 1, x; i <= n; i++) {
            cin >> x;
            root[version] = add(i, x, 1, n, root[1]);
        }
        for (int i = 1, op, x, y, z; i <= m; i++) {
            cin >> op;
            if (op == 0) {
                cin >> x >> y >> z;
                split(y, z, 1, n, root[x]);
                root[x] = tree1;
                root[++version] = tree2;
            } else if (op == 1) {
                cin >> x >> y;
                root[x] = merge(1, n, root[x], root[y]);
            } else if (op == 2) {
                cin >> x >> y >> z;
                root[x] = add(z, y, 1, n, root[x]);
            } else if (op == 3) {
                cin >> x >> y >> z;
                cout << query(y, z, 1, n, root[x]) << '\n';
            } else {
                cin >> x >> y;
                cout << kth(y, 1, n, root[x]) << '\n';
            }
        }
        return 0;
    }

二、题目5：值全改的操作

长度为 n 的数组 arr，q 条操作，每条是 l r x y：把 arr[l..r] 里所有等于 x 的数改成 y。所有操作做完后从左到右打印 arr。n、q 到 2·10⁵，arr[i]、x、y 都在 1 到 100，测试链接 CF911G。

值域只有 100，这是全部线索。给每个值开一棵动态开点线段树，下标是数组位置，root[v] 存「值 v 出现在哪些位置上」。于是「把区间 [l, r] 里的 x 改成 y」就变成两步：从 root[x] 里分裂出 [l, r] 这一段，再把切下来的那棵合并进 root[y]。

这里的树不需要存计数，存一个 bool status 就够：这个区间里有没有该值的位置。合并时用按位或，最后一次 dfs 时 status 为假的整棵子树直接跳过。

顺序也无所谓，因为每条操作只是把位置从一个值的集合搬到另一个值的集合，搬完的结果和逐条模拟完全一样。最后按值从小到大染色，同一个位置只会在一棵树上，所以填回去是确定的。

八个位置、三条操作：值是怎么一批一批搬走的

初始 arr = [2, 1, 2, 1, 3, 3, 1, 2]。点「下一步」执行下一条操作，橙色框是要改的区间，格子里的数是当前的值。最后一行是课程代码实际打印的结果。

这里也有个细节：池子的开销比题目4 小很多。值域只有 100，同一棵树的上层节点是共用的，实测 n = 2·10⁵ 时建树只用了约 1.57·10⁶ 个节点，平均每个位置 7.9 个；再把 q 拉满到 2·10⁵ 跑一遍，峰值仍然是这个数，最后还剩 1.57·10⁶ 个空闲。原因是每条分裂后面紧跟一次合并，切下来的节点大半当场还回池子，不像题目4 那样只增不减。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXT = MAXN * 10;
    const int MAXV = 100;
    int n, q;
    int arr[MAXN];

    int root[MAXV + 1];
    int ls[MAXT];
    int rs[MAXT];
    bool status[MAXT];

    int pool[MAXT];
    int top;

    void prepare() {
        top = 0;
        for (int i = 1; i < MAXT; i++) {
            pool[++top] = i;
        }
    }

    int newNode() {
        return pool[top--];
    }

    void del(int i) {
        pool[++top] = i;
        ls[i] = 0;
        rs[i] = 0;
        status[i] = false;
    }

    void up(int i) {
        status[i] = status[ls[i]] | status[rs[i]];
    }

    int insert(int jobi, int l, int r, int i) {
        int rt = i;
        if (rt == 0) {
            rt = newNode();
        }
        if (l == r) {
            status[rt] = true;
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
            up(rt);
        }
        return rt;
    }

    int merge(int l, int r, int t1, int t2) {
        if (t1 == 0 || t2 == 0) {
            return t1 + t2;
        }
        if (l == r) {
            status[t1] |= status[t2];
        } else {
            int mid = (l + r) >> 1;
            ls[t1] = merge(l, mid, ls[t1], ls[t2]);
            rs[t1] = merge(mid + 1, r, rs[t1], rs[t2]);
            up(t1);
        }
        del(t2);
        return t1;
    }

    int tree1, tree2;

    void split(int jobl, int jobr, int l, int r, int t1) {
        if (t1 == 0) {
            tree1 = t1;
            tree2 = 0;
            return;
        }
        if (jobl <= l && r <= jobr) {
            tree1 = 0;
            tree2 = t1;
            return;
        }
        int t2 = newNode();
        int mid = (l + r) >> 1;
        if (jobl <= mid) {
            split(jobl, jobr, l, mid, ls[t1]);
            ls[t1] = tree1;
            ls[t2] = tree2;
        }
        if (jobr > mid) {
            split(jobl, jobr, mid + 1, r, rs[t1]);
            rs[t1] = tree1;
            rs[t2] = tree2;
        }
        up(t1);
        up(t2);
        tree1 = t1;
        tree2 = t2;
    }

    void dfs(int val, int l, int r, int i) {
        if (i == 0 || !status[i]) {
            return;
        }
        if (l == r) {
            arr[l] = val;
        } else {
            int mid = (l + r) >> 1;
            dfs(val, l, mid, ls[i]);
            dfs(val, mid + 1, r, rs[i]);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        prepare();
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= n; i++) {
            root[arr[i]] = insert(i, 1, n, root[arr[i]]);
        }
        cin >> q;
        for (int i = 1, l, r, x, y; i <= q; i++) {
            cin >> l >> r >> x >> y;
            split(l, r, 1, n, root[x]);
            root[x] = tree1;
            root[y] = merge(1, n, root[y], tree2);
        }
        for (int v = 1; v <= MAXV; v++) {
            dfs(v, 1, n, root[v]);
        }
        for (int i = 1; i <= n; i++) {
            cout << arr[i] << ' ';
        }
        return 0;
    }

三、复杂度分析

两个题的骨架相同：动态开点线段树加空间池。分裂是 O(log n) 个新节点，合并的代价是两棵树重叠的节点数，其余操作都是线段树的常规 O(log n)。

操作时间复杂度空间复杂度
题目4：建集合（n 次插入）O(n log n)O(n log n)，n = 2·10⁵ 时约 4·10⁵
题目4：分裂（新建节点数）O(log n)每次新开 O(log n) 个
题目4：合并O(重叠节点数)，均摊 O(1)被吃掉的那棵整棵回收
题目4：加数字 / 查个数 / 第 k 小O(log n)—
题目5：建 100 棵树（n 次插入）O(n log n)O(n log n)，实测 n = 2·10⁵ 时约 1.57·10⁶，也是峰值
题目5：每条操作（分裂 + 合并）O(log n)节点在合并时还回池子
题目5：最后一遍染色O(状态为真的节点数)O(n)

题目4 的空间是个真约束：分裂只增不减，池子必须按「建树 + 全部分裂」的最坏情况开。题目5 因为每条分裂后面紧跟一次合并，池子可以开得紧一些。两个题的 MAXT 都写成了 MAXN × 10，题目5 够用，题目4 在极端数据下不够。

四、最后

分裂给合并补上了反方向：合并是「把儿子的信息汇总到父亲」，分裂是「按区间把一份信息整体摘出来另作他用」。两件事合在一起，可重集合就能做区间切分、区间合并这类看起来要平衡树才能做的事，而代价始终只有 O(log n)。

题目5 那种「按值建树、按位置分裂」的思路还能套到别的题上：只要修改是「把某个值的一段位置整体改成另一个值」，就可以把值当成桶、把位置当成下标。
