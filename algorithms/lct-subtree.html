LCT 维护子树信息

LCT 天然擅长的是路径：makeroot、access、splay 一套下来，一条链就完整地躺在一棵辅助树里。子树不一样，它横跨好多条链，成员还会因为别人的 access 随时变动。这一节看怎么给「虚子树」单独记一笔账，把连通区大小、子树最大点权这类信息挂上去；以及信息做不了减法时，每个点还得额外配什么。

零、背景

LCT 里每个节点最多认一个实儿子。实边首尾相接，把整棵树切成若干条互不相交的实链。

一个节点只把它的实儿子记在辅助树的左右儿子里；虚儿子不占任何位置，由那个儿子单方面把 fa 指向父亲，父亲这边什么都不知道。

每条实链单独用一棵 splay 维护，splay 里按节点在原树中的深度排序：浅的在左，深的在右。下图左边是原树上实边和虚边的划分，右边是对应的四棵辅助树。

splay 转来转去，改的是树的形状，不改「哪些点在同一条链上、链上谁深谁浅」。处理路径信息时这也是常规操作：makeroot(x)、access(y)、splay(y) 之后，x 到 y 的整条路径正好完整落在 y 的辅助树里。

子树就没这个待遇了。

一、问题

先从一道题说起。大融合：n 个点，初始互不连通，q 次操作。

  • A x y：x 和 y 之间加一条边，保证之前两点不连通。
  • Q x y：打印 x、y 这条边的负载，保证这条边存在。

负载的定义是这条边两侧端点各自所在连通区的大小之积。n、q 都到 10⁵。

要回答一次 Q，就得知道「这条边被临时拆掉之后，两边各有多少个点」。森林的形态一直在变，加边这件事情 LCT 很拿手，难的是挂在上面的那个「大小」。

二、朴素做法

每次 Q，把这条边临时删掉，从 x 出发 dfs 数一遍、从 y 出发再数一遍，乘起来，然后把边加回去。一次 O(n)，q 次下来 O(nq)。

换个思路：真正需要持续跟进的其实就一件事，「某个点这一侧有多大」。只要树变形的时候这个数跟着变，Q 就能压到 O(log n)。

三、vir 和 sum

拿一个点 x 来看，它在 LCT 里的全部贡献分成四块：自己在辅助树里的左儿子、右儿子、全部的虚子树，以及它自己。

左儿子右儿子顺着 splay 就能查到，虚子树没有任何地方存着，所以单独开一个数组，这里叫它 vir。

void up(int x) {
    sum[x] = sum[ls[x]] + sum[rs[x]] + vir[x] + 1;
}

这里有个细节值得先说清楚：sum[x] 并不等于「x 在原树里的子树大小」。如果 x 的辅助树里还挂着它上方的节点，这些也会被算进去。

想拿 x 的子树答案，先 access(x); splay(x);。这一趟做完 rs[x] 一定是 0，x 的所有儿子都在 vir 里了，答案就是 vir[x] 加上 x 自己的贡献。

四、access 时的实虚转换

access 是把某个点到树的根这条路径变成实边的一趟旅行。每路过一个节点 x，就发生一次实虚互换，vir 必须同步改账。

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        vir[x] += sum[rs[x]];
        vir[x] -= sum[y];
        rs[x] = y;
        up(x);
    }
}

具体来说就两件事。x 原来的右子树是它实方向上更深的那一段，这一趟要把它变成虚的，vir[x] += sum[rs[x]]；y 是上一趟处理过的下层节点，它本来是 x 的虚儿子，现在要接到实方向上，vir[x] -= sum[y]。

实虚转换的账本

左边是原树，右边是每条实链对应的辅助树。节点框里第二行是 vir 和 sum。点「下一步」一步步走，也可以直接点左边的某个点，对它做一次 access。

实边（两个端点在同一棵辅助树里） 虚边（只有下端那个点记着父亲）

五、link 也要记账

加边的时候，x 整棵树是挂到 y 下面当虚儿子的。

void link(int x, int y) {
    makeroot(x);
    if (findroot(y) != x) {
        access(y);
        splay(y);
        fa[x] = y;
        vir[y] += sum[x];
        up(y);
    }
}

makeroot(x) 之后 x 那棵树以 x 为根，fa[x] = y 就是把整棵挂过去，所以 vir[y] += sum[x]。

cut 反倒不用动 vir：被断开的那条边本来是实的，摘掉之后两侧各自还是完整的两棵树，up 一遍就够了。

六、题目1：大融合

回到最开始那道题。有了 sum，一次 Q 就是三步：先把这条边断开，两侧各问一次，再连回去。

long query(int x, int y) {
    cut(x, y);
    makeroot(x);
    int sizx = sum[x];
    makeroot(y);
    int sizy = sum[y];
    link(x, y);
    return 1LL * sizx * sizy;
}

cut(x, y) 之后是两个连通区。makeroot(x) 让 x 这一侧以 x 为根，此时 x 没有上方节点了，它的辅助树加虚子树就是整个连通区，读 sum[x] 即可。y 那一侧同理。

整套代码就是这样：标准的 LCT 骨架，只在 up、access、link 三个地方多了 vir 那几笔。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100001;
int n, q;

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];
bool rev[MAXN];
int sta[MAXN];

int vir[MAXN];
int sum[MAXN];

void up(int x) {
    sum[x] = sum[ls[x]] + sum[rs[x]] + vir[x] + 1;
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void reverse(int x) {
    if (x != 0) {
        swap(ls[x], rs[x]);
        rev[x] = !rev[x];
    }
}

void down(int x) {
    if (rev[x]) {
        reverse(ls[x]);
        reverse(rs[x]);
        rev[x] = false;
    }
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    int siz = 0;
    sta[++siz] = x;
    for (int y = x; !isroot(y); y = fa[y]) {
        sta[++siz] = fa[y];
    }
    while (siz != 0) {
        down(sta[siz--]);
    }
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        vir[x] += sum[rs[x]];
        vir[x] -= sum[y];
        rs[x] = y;
        up(x);
    }
}

void makeroot(int x) {
    access(x);
    splay(x);
    reverse(x);
}

int findroot(int x) {
    access(x);
    splay(x);
    down(x);
    while (ls[x] != 0) {
        x = ls[x];
        down(x);
    }
    splay(x);
    return x;
}

void split(int x, int y) {
    makeroot(x);
    access(y);
    splay(y);
}

void link(int x, int y) {
    makeroot(x);
    if (findroot(y) != x) {
        access(y);
        splay(y);
        fa[x] = y;
        vir[y] += sum[x];
        up(y);
    }
}

void cut(int x, int y) {
    makeroot(x);
    if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
        fa[y] = rs[x] = 0;
        up(x);
    }
}

long query(int x, int y) {
    cut(x, y);
    makeroot(x);
    int sizx = sum[x];
    makeroot(y);
    int sizy = sum[y];
    link(x, y);
    return 1LL * sizx * sizy;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> q;
    for (int i = 1; i <= n; i++) {
        sum[i] = 1;
    }
    for (int i = 1; i <= q; i++) {
        char op;
        int x, y;
        cin >> op >> x >> y;
        if (op == 'A') {
            link(x, y);
        } else {
            cout << query(x, y) << "\n";
        }
    }
    return 0;
}

七、题目2：QTREE6

接下来这道题换了个方向：树的形态完全固定，会变的是每个节点的颜色。要求回答节点 x 所在的同色连通块有多大。

先把每个点拆成两个状态点：黑色状态的编号是 x，白色状态的编号是 x + n。两套森林共用同一套 LCT 数组，彼此之间没有任何边。

状态点的「有效」与否由它自己的贡献值 val 决定：有效就是 1，无效就是 0。初始全是黑色，于是黑森林里连好了原树的所有边，白森林里全是孤立点。

接下来是这里最关键的一个设计：原树以 1 号点为根固定下来，每个状态点记着自己那个固定不动的父亲 parent[x]。翻转 x 的颜色时，只断一条边、连一条边，老颜色那边把 parent 边删掉，新颜色那边把对应的 parent 边连上。

这条设计省下的是工作量。如果按另一种想法，翻转时把 x 和所有同色邻居重连一遍，菊花图上中间那个点一次翻转就要动 O(n) 条边。

查询的写法顺着这个图就出来了。找到 x 当前那个状态点在它所在森林里的根 ys：

int query(int x) {
    int xs = val[x] == 1 ? x : x + n;
    int ys = findroot(xs);
    return val[ys] == 1 ? sum[ys] : sum[rs[ys]];
}

ys 是这片森林最顶上的那个点。它要是有效，整棵树都同色，答案就是 sum[ys]；它要是无效，findroot 最后一步把 ys 旋到了辅助树的根，它右边挂着的正是 ys 下面那一整摊，答案就是 sum[rs[ys]]。

注意这只 LCT 没有 makeroot 也没有 reverse：树以 1 号点为根这件事是固定的，边的方向永远是「儿子连向父亲」，所以整套操作都不需要翻转。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 200001;
int n, q;

int head[MAXN];
int nxt[MAXN];
int to[MAXN];
int cntg;

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];

int parent[MAXN];
int val[MAXN];
int vir[MAXN];
int sum[MAXN];

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

void up(int x) {
    sum[x] = sum[ls[x]] + sum[rs[x]] + vir[x] + val[x];
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
    up(x);
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        vir[x] += sum[rs[x]];
        vir[x] -= sum[y];
        rs[x] = y;
        up(x);
    }
}

int findroot(int x) {
    access(x);
    splay(x);
    while (ls[x] != 0) {
        x = ls[x];
    }
    splay(x);
    return x;
}

void link(int x, int f) {
    if (f == 0) {
        return;
    }
    access(f);
    splay(f);
    splay(x);
    fa[x] = f;
    vir[f] += sum[x];
    up(f);
}

void cut(int x, int f) {
    access(x);
    splay(x);
    if (f != 0) {
        int left = ls[x];
        fa[left] = 0;
        ls[x] = 0;
        up(x);
    }
}

int query(int x) {
    int xs = val[x] == 1 ? x : x + n;
    int ys = findroot(xs);
    return val[ys] == 1 ? sum[ys] : sum[rs[ys]];
}

void reverseColor(int x) {
    int pre = val[x] == 1 ? x : x + n;
    int cur = pre <= n ? pre + n : pre - n;
    cut(pre, parent[pre]);
    val[pre] = 0;
    val[cur] = 1;
    link(cur, parent[cur]);
}

void dfs(int u, int f) {
    if (f != 0) {
        parent[u] = f;
        parent[u + n] = f + n;
    }
    val[u] = sum[u] = 1;
    for (int e = head[u]; e != 0; e = nxt[e]) {
        int v = to[e];
        if (v != f) {
            dfs(v, u);
            link(v, u);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1, u, v; i < n; i++) {
        cin >> u >> v;
        addEdge(u, v);
        addEdge(v, u);
    }
    dfs(1, 0);
    cin >> q;
    for (int i = 1, op, x; i <= q; i++) {
        cin >> op >> x;
        if (op == 0) {
            cout << query(x) << "\n";
        } else {
            reverseColor(x);
        }
    }
    return 0;
}

八、题目3：QTREE7

把上一题的「连通块大小」换成「连通块里的最大点权」，再加一个改点权的操作。

麻烦在于大小可以加加减减，最大值不行。一个虚子树要退场，和是把减掉那部分减掉即可，最大值减完之后你并不知道剩下的还有没有一样大的。

常见的办法是给每个点挂一张有序表：表里存的是它每个虚子树当前的答案，出现几次存几次。

access 那两笔记账也就跟着改了写法：

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        if (rs[x] != 0) vir[x].insert(maxv[rs[x]]);
        if (y != 0) vir[x].erase(vir[x].find(maxv[y]));
        rs[x] = y;
        up(x);
    }
}

link 的时候同样要在父亲的表中插入一份 maxv[x]。初始时黑色状态点的 val 是它的点权，白色状态点的 val 是 -INF；改点权就是把当前有效那个状态点 access、splay 之后改 val 再 up。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 200001;
const int INF = 1000000001;
int n, q;

int color[MAXN];
int weight[MAXN];

int head[MAXN];
int nxt[MAXN];
int to[MAXN];
int cntg;

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];

int parent[MAXN];
int val[MAXN];
multiset<int> vir[MAXN];
int maxv[MAXN];

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

int getmax(int x) {
    if (vir[x].empty()) {
        return -INF;
    }
    return *vir[x].rbegin();
}

void up(int x) {
    maxv[x] = max(val[x], max(getmax(x), max(maxv[ls[x]], maxv[rs[x]])));
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
    up(x);
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        if (rs[x] != 0) {
            vir[x].insert(maxv[rs[x]]);
        }
        if (y != 0) {
            vir[x].erase(vir[x].find(maxv[y]));
        }
        rs[x] = y;
        up(x);
    }
}

int findroot(int x) {
    access(x);
    splay(x);
    while (ls[x] != 0) {
        x = ls[x];
    }
    splay(x);
    return x;
}

void link(int x, int f) {
    if (f == 0) {
        return;
    }
    access(f);
    splay(f);
    splay(x);
    fa[x] = f;
    vir[f].insert(maxv[x]);
    up(f);
}

void cut(int x, int f) {
    access(x);
    splay(x);
    if (f != 0) {
        int left = ls[x];
        fa[left] = 0;
        ls[x] = 0;
        up(x);
    }
}

int query(int x) {
    int xs = val[x] != -INF ? x : x + n;
    int ys = findroot(xs);
    return val[ys] != -INF ? maxv[ys] : maxv[rs[ys]];
}

void reverseColor(int x) {
    int pre = val[x] != -INF ? x : x + n;
    int cur = pre <= n ? pre + n : pre - n;
    cut(pre, parent[pre]);
    val[cur] = val[pre];
    val[pre] = -INF;
    link(cur, parent[cur]);
}

void updateValue(int x, int w) {
    int cur = val[x] != -INF ? x : x + n;
    access(cur);
    splay(cur);
    val[cur] = w;
    up(cur);
}

void dfs(int u, int f) {
    if (f != 0) {
        parent[u] = f;
        parent[u + n] = f + n;
    }
    for (int e = head[u]; e != 0; e = nxt[e]) {
        int v = to[e];
        if (v != f) {
            dfs(v, u);
            int cur = color[v] == 0 ? v : v + n;
            link(cur, parent[cur]);
        }
    }
}

void prepare() {
    maxv[0] = -INF;
    for (int i = 1; i <= n; i++) {
        if (color[i] == 0) {
            val[i] = maxv[i] = weight[i];
            val[i + n] = maxv[i + n] = -INF;
        } else {
            val[i] = maxv[i] = -INF;
            val[i + n] = maxv[i + n] = weight[i];
        }
    }
    dfs(1, 0);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1, u, v; i < n; i++) {
        cin >> u >> v;
        addEdge(u, v);
        addEdge(v, u);
    }
    for (int i = 1; i <= n; i++) {
        cin >> color[i];
    }
    for (int i = 1; i <= n; i++) {
        cin >> weight[i];
    }
    prepare();
    cin >> q;
    for (int i = 1, op, x, w; i <= q; i++) {
        cin >> op >> x;
        if (op == 0) {
            cout << query(x) << "\n";
        } else if (op == 1) {
            reverseColor(x);
        } else {
            cin >> w;
            updateValue(x, w);
        }
    }
    return 0;
}

九、题目4：QTREE5

再往前一步。树固定，节点黑白，操作是翻转颜色和「打印 x 到最近白色节点的距离」。

一条实链上要维护两个值：lm[x] 是这条链最浅的那个点出发到最近白点的距离，rm[x] 是最深的那个点出发的距离。虚子树那边依旧是每人一张有序表，存的是每个虚儿子自己的 lm；表里的最小值加 1，就是从 x 一头扎进这片虚子树之后的距离。

于是 lm[x] 就是三个候选值里取最小。

查询的时候 access(x); splay(x);，此时 x 就是这条链最深的点，答案直接读 rm[x]。翻转颜色也只是这三行：

void reverseColor(int x) {
    access(x);
    splay(x);
    color[x] ^= 1;
    up(x);
}

建图的时候，dfs 一遍，把每个孩子的 lm 塞进父亲的表里，此时所有边都是虚的。题目初始全是黑色，所以 lm、rm 一律初始化成 INF。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100001;
const int INF = 1000000001;
int n, q;

int head[MAXN];
int nxt[MAXN << 1];
int to[MAXN << 1];
int cntg;

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];

int color[MAXN];
int siz[MAXN];
int lm[MAXN];
int rm[MAXN];

multiset<int> vir[MAXN];

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

int getmin(int x) {
    if (vir[x].empty()) {
        return INF;
    }
    return *vir[x].begin();
}

void up(int x) {
    siz[x] = siz[ls[x]] + siz[rs[x]] + 1;
    int l1 = lm[ls[x]];
    int l2 = siz[ls[x]] + (color[x] == 1 ? 0 : getmin(x) + 1);
    int l3 = siz[ls[x]] + 1 + lm[rs[x]];
    lm[x] = min(l1, min(l2, l3));
    int r1 = rm[rs[x]];
    int r2 = siz[rs[x]] + (color[x] == 1 ? 0 : getmin(x) + 1);
    int r3 = siz[rs[x]] + 1 + rm[ls[x]];
    rm[x] = min(r1, min(r2, r3));
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
    up(x);
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        if (rs[x] != 0) {
            vir[x].insert(lm[rs[x]]);
        }
        if (y != 0) {
            vir[x].erase(vir[x].find(lm[y]));
        }
        rs[x] = y;
        up(x);
    }
}

void reverseColor(int x) {
    access(x);
    splay(x);
    color[x] ^= 1;
    up(x);
}

int query(int x) {
    access(x);
    splay(x);
    return rm[x] == INF ? -1 : rm[x];
}

void dfs(int u, int f) {
    fa[u] = f;
    siz[u] = 1;
    lm[u] = rm[u] = INF;
    for (int e = head[u]; e != 0; e = nxt[e]) {
        int v = to[e];
        if (v != f) {
            dfs(v, u);
            vir[u].insert(lm[v]);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    lm[0] = rm[0] = INF;
    for (int i = 1, u, v; i < n; i++) {
        cin >> u >> v;
        addEdge(u, v);
        addEdge(v, u);
    }
    dfs(1, 0);
    cin >> q;
    for (int i = 1, op, x; i <= q; i++) {
        cin >> op >> x;
        if (op == 0) {
            reverseColor(x);
        } else {
            cout << query(x) << "\n";
        }
    }
    return 0;
}

十、总结与注意点

能这么维护的子树信息，本质上是可减的：节点数、点权和、异或和。虚子树进出只要加一项减一项。

汇总一个状态点的时候，永远是三块加自己：x 自身 + x 的所有虚子树 + x 在辅助树里的左右儿子。access 引起的实虚转换，必须同步地在这三块之间搬数据。

不可减的信息，比如最大值、最小值，常见做法就是每个点再配一张有序表或者一棵平衡树。

剩下的几条是踩坑换来的经验：

  1. LCT 天生不擅长子树信息，尤其是信息不可减的时候，或者动态树上还要做子树懒更新。
  2. 这些情况往往还得额外配数据结构，实现难度会明显上一个台阶。
  3. 如果发现越写越复杂，多半应该退回来想想有没有难度更低的做法。
  4. 动态树配上复杂的路径或子树信息、子树懒更新，这类问题更适合用 top tree。
  5. 这一类题比赛里出现频率不高。

十一、复杂度分析

设 n 为点数，q 为操作次数。

LCT 的 makeroot、access、splay、link、cut、findroot、split 都是均摊 O(log n)。vir 记账只是在这些操作的常量步里多几次加减。

操作时间复杂度
up（汇总一个点）O(1)
access / link / cut / findrootO(log n) 均摊
题目1（大融合）单次 QO(log n)
题目2（QTREE6）单次操作O(log n)
题目3、4，带有序表每轮 access 要在表里增删一次，O(log² n)

空间上，题目1 是几个长度 O(n) 的数组，O(n)。题目2 到 4 每个点拆成两个状态点，数组开到 2n，仍然是 O(n)。题目3、4 每个点一张有序表，所有表加起来存的是虚子树的条目，总数 O(n)，只是常数比单纯数组大不少。

十二、最后

LCT 维护子树信息，说穿了就是一句话：实的部分交给 splay，虚的部分自己记账。

麻烦都集中在「access 会把谁实谁虚换一遍」这件事上。记账的公式从来没变过，变的是记的东西：题目1 记的是点数可以做加减，题目3 记的是最大值就只能用有序表代替减法。

下一节把同样的骨架搬到图结构上，边变成点、点双变成方点，LCT 就不再是维护一棵树，而是在维护一张图的连通结构。
