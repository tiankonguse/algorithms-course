两张预处理表：等差数列求和与初始化

还是「小规模预处理、大规模暴力」，但这两道题的表不能一步算出来。等差数列求和要把后缀和叠两层才能得到项的编号，初始化要把懒标记记成模 x 意义下的前缀和后缀，再套一层数组分块来回答区间和。

零、背景

上一节的两张表都是一步算出来的：余数类的和、从每个位置出发的步数，扫一遍数组就填完了。这一节的两道题不一样，表里存的东西要经过一次变形。

变形的方向其实有迹可循。查询要的是「带系数的和」，表就得先把系数叠进去；查询要的是「区间和」，表就得存成能做区间和的形状，也就是前缀或者后缀。

一、题目3：等差数列求和

一共有 t 组测试，每组测试遵循同样的设定。给定一个长度为 n 的数组 arr，接下来有 q 条查询，查询格式如下。

查询 s d k：arr[s] 作为第 1 项、arr[s + 1d] 作为第 2 项、arr[s + 2d] 作为第 3 项，以此类推，每项的值乘项的编号，一共 k 项都累加起来，打印累加和。1 ≤ n ≤ 10⁵，1 ≤ q ≤ 2 × 10⁵。测试链接：CF1921F。

参数是步长 d。暴力是从 s 开始跳 k 次，代价 O(k)，而 k 不超过 n/d，所以 d 大于 B 的时候暴力就够了，代价小于 n/B。d 不超过 B 的时候要能 O(1) 出答案。

第一步先把「同余类上的后缀和」算出来。记 f[d][i] 为从 i 开始、每次加 d、一直到超过 n 的所有值之和，递推是 f[d][i] = arr[i] + f[d][i + d]，i 从 n 倒着推到 1。

f 里没有项的编号。再叠一层：记 g[d][i] = f[d][i] + g[d][i + d]。展开看，g[d][i] 里 arr[i] 出现 1 次、arr[i + d] 出现 2 次、arr[i + 2d] 出现 3 次，恰好就是题目要的「值乘编号」。

g 是「一直加到超过 n」的结果，题目只要前 k 项，多出来的尾部要减掉。尾部从第 k + 1 项开始，起点是 s + d·k。这一段的每个值在 g 里的系数是 1、2、3，在题目里的系数应该是 k + 1、k + 2，差一个常数 k，所以要减的是 g[d][s + d·k] 加上 f[d][s + d·k] 乘 k。

这里有个细节：s + d·k 超过 n 的时候不用减，因为 g[d][s] 本身就是到数组末尾为止的，没有多出来的项。代码里用 if (s + d * k <= n) 判断。

    
void prepare() {
        blen = (int)sqrt(n);
        for (int d = 1; d <= blen; d++) {
            for (int i = n; i >= 1; i--) {
                f[d][i] = arr[i] + (i + d > n ? 0 : f[d][i + d]);
            }
        }
        for (int d = 1; d <= blen; d++) {
            for (int i = n; i >= 1; i--) {
                g[d][i] = f[d][i] + (i + d > n ? 0 : g[d][i + d]);
            }
        }
    }
    
long long query(int s, int d, int k) {
        long long ans = 0;
        if (d <= blen) {
            ans = g[d][s];
            if (s + d * k <= n) {
                ans -= g[d][s + d * k] + f[d][s + d * k] * k;
            }
        } else {
            for (int i = 1; i <= k; i++) {
                ans += 1LL * arr[s + (i - 1) * d] * i;
            }
        }
        return ans;
    }

预处理是 d 从 1 到 B，每个 d 倒着扫两遍数组，代价 O(n·B)。两张表都是 long，B 行各 n 列，开表的时候按常数上限开、只填前 B 行。

二、题目4：初始化

给定一个长度为 n 的数组 arr，接下来有 m 条操作，操作格式如下。

  • 操作 1 x y z：从 arr[y] 开始，下标每次 +x，所有相应位置的数都 +z，题目保证 y ≤ x。
  • 操作 2 x y：打印 arr[x..y] 的累加和，答案对 1000000007 取余。

1 ≤ n、m ≤ 2 × 10⁵。测试链接：洛谷 P5309。

参数是步长 x，和上一节题目 1 是同一个形状，但这里问的是区间和而不是整个同余类，所以表要换一种记法。

先看清一次操作到底影响哪些位置。y 不超过 x，所以起点 y 落在一个模 x 的余数类里，而这个余数类在 1 到 x 之间只有一个代表，就是 y 自己。也就是说，位置 p 会被这次操作加到，当且仅当 ((p − 1) mod x) + 1 等于 y。

x 大于 B 的操作不去预处理，直接跳着改 arr，代价 O(n/x)。为了能快速求区间和，顺手把 arr 做一次数组分块：块长 B，块和记在 sum 里，改一个点就更新它所在块的块和。

x 不超过 B 的操作不能跳着改，那样一次就是 O(n/x) 了，得留成懒标记。标记要能回答区间和，所以记成两个前缀性质的数组。

pre[x][i] 是所有起点不超过 i 的操作的 z 之和，suf[x][i] 是所有起点不小于 i 的操作的 z 之和。一次 add(x, y, z) 就是给 pre[x][y..x] 和 suf[x][1..y] 各加一遍 z，代价 O(x)。

查询区间 [l, r] 时，把区间在模 x 的意义上切成三段。位置 l 所在的轮是 (l − 1) / x + 1，位置 r 所在的轮是 (r − 1) / x + 1，中间的轮数是两者之差减一。同一轮里，被影响的位置编号从 a = ((l − 1) mod x) + 1 到 b = ((r − 1) mod x) + 1，贡献是 pre[x][b] − pre[x][a − 1]。跨轮的时候，首段是编号 a 到 x，用 suf[x][a]；中间每一整轮都是全部起点，贡献 pre[x][x]；尾段是编号 1 到 b，贡献 pre[x][b]。

    
void add(int x, int y, long long z) {
        if (x <= blen) {
            for (int i = y; i <= x; i++) {
                pre[x][i] += z;
            }
            for (int i = y; i >= 1; i--) {
                suf[x][i] += z;
            }
        } else {
            for (int i = y; i <= n; i += x) {
                arr[i] += z;
                sum[bi[i]] += z;
            }
        }
    }
    
long long querySum(int l, int r) {
        int lb = bi[l], rb = bi[r];
        long long ans = 0;
        if (lb == rb) {
            for (int i = l; i <= r; i++) {
                ans += arr[i];
            }
        } else {
            for (int i = l; i <= br[lb]; i++) {
                ans += arr[i];
            }
            for (int i = bl[rb]; i <= r; i++) {
                ans += arr[i];
            }
            for (int b = lb + 1; b <= rb - 1; b++) {
                ans += sum[b];
            }
        }
        return ans;
    }

    long long query(int l, int r) {
        long long ans = querySum(l, r);
        for (int x = 1, lth, rth, num; x <= blen; x++) {
            lth = (l - 1) / x + 1;
            rth = (r - 1) / x + 1;
            num = rth - lth - 1;
            if (lth == rth) {
                ans = ans + pre[x][(r - 1) % x + 1] - pre[x][(l - 1) % x];
            } else {
                ans = ans + suf[x][(l - 1) % x + 1] + pre[x][x] % MOD * num + pre[x][(r - 1) % x + 1];
            }
        }
        return ans % MOD;
    }

查询里 pre[x][x] % MOD * num 只在这一项取模，其余项累加到最后统一取模。n 和 m 都在 2 × 10⁵ 量级，每次加的 z 在 long 范围内累加不会溢出，这样写能省掉几次取模。

三、复杂度分析

两道题的预处理都是 O(n·B)，查询都按 x 与 B 的大小分两条路。题目 4 多一层数组分块，块长也取 B。

操作时间复杂度空间复杂度
题目3 预处理 f、g（d ≤ B，各倒扫 n 个位置）O(n·B) = O(n√n)O(n·B)：两张 long 表，各 B 行 n 列
题目3 查询 s d k（d ≤ B 取表 / d > B 跳 k 次）O(1) / O(k) ≤ O(√n)
题目4 预处理（分块、块和）O(n)O(n + B²)：pre 与 suf 各 B² 个格子，arr 与块和 O(n)
题目4 修改 1 x y z（x ≤ B 改标记 / x > B 跳着改）O(x) ≤ O(B) / O(n/x) ≤ O(√n)
题目4 查询 2 x y（分块求区间和）O(B + n/B) = O(√n)
题目4 查询 2 x y（再叠 x = 1..B 的懒标记）O(B) = O(√n)

题目 3 有多组测试，每组都要重新填表，总代价按各组 n 之和算。题目 4 单次查询是 O(√n) 而不是 O(1)，因为分块求和和枚举 B 个步长这两件事都省不掉。

四、最后

这两道题的表都不是直接扫一遍能填出来的。带系数的和要叠两层后缀和，区间和要把懒标记记成模 x 意义下的前缀和后缀，再按轮切成三段。
