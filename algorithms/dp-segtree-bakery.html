线段树区间加：划分 k 段的最大得分

把数组切成最多 k 段，每段得分的内部不同数字个数。分段的 DP 长成 dp[t][i] = max{dp[t-1][p] + cost(p+1, i)}，麻烦全在 cost：它随 i 移动而变，每个新扫到的数字会让一段连续的 p 的得分同时 +1。这种「一个候选区间整体加、全局取 max」正好是线段树加懒标记的主场。

零、背景

分段 DP 是经典结构：dp[t][i] 表示前 i 个数分 t 段的最优值，转移枚举最后一段从哪里开始。朴素做法枚举 p 是 O(n²) 一次转移，k 轮下来 O(k n²)。这一题 cost 是「区间内不同数字个数」，它有很好的增量性质：i 往右走一步，只有一段连续候选的 cost 会变。利用这个性质，枚举 p 的 O(n) 可以整段用线段树扛下来。

一、问题

给长度 n 的数组，最多分成 k 段不重合的子数组，每段得分是内部不同数字的个数，返回最大总分。数据范围 1 <= n <= 35000，1 <= k <= 50，1 <= arr[i] <= n。

二、状态与朴素转移

设 dp[t][i] 为「前 i 个数分 t 段的最大得分」，最后一段是 (p+1..i)，那么

cost(p+1, i) 是这段里不同数字的个数。p 的合法范围是 [t-1, i-1]（前面至少要分 t-1 段）。对每个 t 跑一遍，每遍内层是「对所有 p 求 dp[t-1][p] + cost(p+1, i) 的最大值」。

三、cost 的增量维护

关键在于观察 i 前进时 cost 怎么变。扫到位置 i，数字 arr[i] 上一次出现的位置记为 pre。对候选 p：

  • 如果 p >= pre，那么 (p+1..i) 里 arr[i] 是第一次出现（上一次出现位置 pre 在区间外），cost 比 (p+1..i-1) 多 1；
  • 如果 p < pre，arr[i] 在区间里已经出现过，cost 不变。

所以每扫到 i，只需要把候选 p in [pre, i-1] 这一段的「当前值」整体 +1。上一轮 i-1 结束时，线段树叶子 p 里存的是 dp[t-1][p] + cost(p+1, i-1)；加完这一刀，就变成了 dp[t-1][p] + cost(p+1, i)。

四、线段树扛住枚举

对每一层 t：先把线段树 build 成 dp[t-1][0..n]，然后把 pre 数组清空（每个数字在上一层的 last 位置从 0 重新算）。之后 i 从 1 到 n：

  • add(pre[arr[i]], i-1, +1)：给这段候选整体加 1 的 cost；
  • 如果 i >= t，dp[i] = query(0, i-1)：所有能接的 p 里取最大值；
  • pre[arr[i]] = i：更新出现位置。

线段树的范围是 0 ~ n，不是 1 ~ n。因为 p = 0 是合法候选（最后一段从 1 开始，前面 0 个数分 0 段，dp[t-1][0] = 0），它也得参与查询。

五、实现

线段树维护最大值，带区间加懒标记，是标准模板：

void up(int i) {
        segmax[i] = max(segmax[i << 1], segmax[i << 1 | 1]);
    }

    void down(int i) {
        if (lazyadd[i] != 0) {
            lazy(i << 1, lazyadd[i]);
            lazy(i << 1 | 1, lazyadd[i]);
            lazyadd[i] = 0;
        }
    }

    void lazy(int i, int v) {
        segmax[i] += v;
        lazyadd[i] += v;
    }

    void build(int l, int r, int i) {
        if (l == r) {
            segmax[i] = dp[l];
        } else {
            int mid = (l + r) >> 1;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            up(i);
        }
        lazyadd[i] = 0;
    }

    void add(int jobl, int jobr, int jobv, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            lazy(i, jobv);
        } else {
            down(i);
            int mid = (l + r) >> 1;
            if (jobl <= mid) add(jobl, jobr, jobv, l, mid, i << 1);
            if (jobr > mid) add(jobl, jobr, jobv, mid + 1, r, i << 1 | 1);
            up(i);
        }
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) return segmax[i];
        down(i);
        int mid = (l + r) >> 1;
        int ans = INT_MIN;
        if (jobl <= mid) ans = max(ans, query(jobl, jobr, l, mid, i << 1));
        if (jobr > mid) ans = max(ans, query(jobl, jobr, mid + 1, r, i << 1 | 1));
        return ans;
    }

主流程。注意 build 每层都跑一次，把上一层的 dp 铺进树里；pre 每层也重置：

int compute() {
        memset(dp, 0, sizeof(dp));
        for (int t = 1; t <= k; t++) {
            build(0, n, 1);
            memset(pre, 0, sizeof(pre));
            for (int i = 1; i <= n; i++) {
                add(pre[arr[i]], i - 1, 1, 0, n, 1);
                if (i >= t) {
                    dp[i] = query(0, i - 1, 0, n, 1);
                }
                pre[arr[i]] = i;
            }
        }
        return dp[n];
    }

复杂度分析

外层 t 循环 k 次，内层 i 循环 n 次，每次一次区间加（O(log n)）加一次查询（O(log n)）。总时间 O(k n log n)，k = 50、n = 35000 时约 50 × 35000 × 15 次操作，稳过。空间是线段树两个 n×4 数组，O(n)。

对比朴素 O(k n²)：数据范围内 k n² 到 6 × 10 的 10 次方量级，慢两个数量级以上。

总结

这一题的套路是「分段 DP 的 cost 有增量性质」：每个新数字只影响一段连续候选，于是枚举最后一段起点的 O(n) 被线段树区间加 + 前缀查询替代。三个注意点：线段树范围要含 0 号候选；pre 每层重置；i >= t 才允许更新 dp（前面至少要分 t-1 段）。

下一题基站选址会用同一棵线段树，只是把 max 换成 min、把「区间加 1」换成「区间加赔偿」，骨架完全一样。
