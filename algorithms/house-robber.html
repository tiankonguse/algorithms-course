不能选相邻元素的最大累加和

从数组里挑一些数加起来，要求任何两个被选中的数在原数组里都不相邻。它和最大子数组正好相反：子数组必须连续，这里必须「跳着选」。同一道题在环形数组上、再把「钱数最大」换成「能力值最小」又长出两道题，三道题共用一张 dp 表。

零、线性版本：对每间房做一次决定

把数组当成一排房子，走到第 i 间时只有两种选择。偷它，那么第 i − 1 间必须空着，前面的最优解是 dp[i − 2]；不偷它，最优解就是 dp[i − 1]。转移只有这两条：

dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])

答案就是 dp[n − 1]：定义里 dp[i] 管的是 nums[0..i] 这一整段的自由选择，不用再扫一遍取最大。

#include <bits/stdc++.h>
    using namespace std;

    int rob1(const vector<int>& nums) {
        int n = (int)nums.size();
        if (n == 1) return nums[0];
        if (n == 2) return max(nums[0], nums[1]);
        // dp[i]：nums[0..i] 上随意选，但不能选相邻数字，能得到的最大累加和
        vector<int> dp(n);
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        for (int i = 2; i < n; i++) {
            dp[i] = max(dp[i - 1], max(nums[i], dp[i - 2] + nums[i]));
        }
        return dp[n - 1];
    }

    // 空间压缩：只留 dp[i-2] 和 dp[i-1]
    int rob2(const vector<int>& nums) {
        int n = (int)nums.size();
        if (n == 1) return nums[0];
        if (n == 2) return max(nums[0], nums[1]);
        int prepre = nums[0];
        int pre = max(nums[0], nums[1]);
        for (int i = 2, cur; i < n; i++) {
            cur = max(pre, max(nums[i], prepre + nums[i]));
            prepre = pre;
            pre = cur;
        }
        return pre;
    }

演示：线性 dp 逐帧填表

代码里 transfer 写成了 max(nums[i], dp[i - 2] + nums[i])，比常见写法多包了一层 max。数据非负时这个分支没有作用（dp[i − 2] 反正 ≥ 0）；它真正的用途是允许数组里有负数：那时候「不选前面任何一间、只偷第 i 间」可能是最优的。LeetCode 的数据全非负，两种写法都对。

一、环形版本：按「偷不偷第一间」拆成两半

首尾相连之后，第 0 间和第 n − 1 间不能同时偷。这恰好把问题劈成两个互斥的线性问题：

偷第 0 间：第 1 间和第 n − 1 间必须空着，中间剩下 nums[2..n-2] 随便选，加上 nums[0]；不偷第 0 间：nums[1..n-1] 变成普通的线性问题。两个答案取大的那个。

// nums[l..r] 范围上，没有环形的概念，返回不能选相邻数字时的最大累加和
    int best(const vector<int>& nums, int l, int r) {
        if (l > r) return 0;
        if (l == r) return nums[l];
        if (l + 1 == r) return max(nums[l], nums[r]);
        int prepre = nums[l];
        int pre = max(nums[l], nums[l + 1]);
        for (int i = l + 2, cur; i <= r; i++) {
            cur = max(pre, nums[i] + max(0, prepre));
            prepre = pre;
            pre = cur;
        }
        return pre;
    }

    int rob(const vector<int>& nums) {
        int n = (int)nums.size();
        if (n == 1) return nums[0];
        // 偷第一间：只能再偷 2..n-2；不偷第一间：1..n-1 随便选
        return max(best(nums, 1, n - 1), nums[0] + best(nums, 2, n - 2));
    }

best 里的转移写的是 nums[i] + max(0, prepre)：那个 max(0, ·) 对应「前面一段整体都不偷」。环形拆分后，两个子问题都允许答案是 0（一间都不偷），这一点和线性版不同。

两处都容易写漏。只算「不偷第 0 间」的一半，实测 37.76% 的随机样本答案偏小；偷了第 0 间却把右边界照抄成 n − 1（忘了第 n − 1 间已经和第 0 间相邻），也是 37.48%。

演示：环形拆成两个线性问题

二、打家劫舍 IV：把「钱最多」换成「能力最小」

题面反过来问：至少偷 k 间（还是不能相邻），单间金额不能超过「窃取能力」，问能力最小是多少。钱数最大化变成了能力值最小化，dp 里那张表帮不上直接的忙。

关键观察是单调性：能力值越大，「金额不超过它」的房子越多，能偷的间数只增不减。于是「能力值为 x 时能否偷够 k 间」是一个随 x 单调的判断，答案可以二分。二分的范围就是数组里的最小值到最大值，值域 10⁹ 也只要 30 轮。

每轮的检查问题又回到这张 dp 表，只是值从「钱数」换成了「间数」：

dp[i] = max(dp[i - 1], (nums[i] <= ability ? 1 : 0) + dp[i - 2])

这个「最多能偷多少间」还有更短的定义：贪心。从左往右扫，碰到金额不超过 ability 的房子就偷，然后直接跳过下一间。它和 dp 的答案在 5000 组随机样本上零差异：一段连续可偷的房子长度为 len 时，最多能偷 ⌈len / 2⌉ 间，贪心恰好做到这一点。

// 能力值为 ability 时，最多能偷多少间（房间数量，不是钱数）
    int mostRob(const vector<int>& nums, int n, int ability) {
        if (n == 1) return nums[0] <= ability ? 1 : 0;
        if (n == 2) return (nums[0] <= ability || nums[1] <= ability) ? 1 : 0;
        vector<int> dp(n);
        dp[0] = nums[0] <= ability ? 1 : 0;
        dp[1] = (nums[0] <= ability || nums[1] <= ability) ? 1 : 0;
        for (int i = 2; i < n; i++) {
            dp[i] = max(dp[i - 1], (nums[i] <= ability ? 1 : 0) + dp[i - 2]);
        }
        return dp[n - 1];
    }

    // 贪心：能偷就偷，偷完下一间直接跳过去
    int mostRobGreedy(const vector<int>& nums, int n, int ability) {
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] <= ability) {
                ans++;
                i++;
            }
        }
        return ans;
    }

    int minCapability(const vector<int>& nums, int k) {
        int n = (int)nums.size(), l = nums[0], r = nums[0];
        for (int i = 1; i < n; i++) {
            l = min(l, nums[i]);
            r = max(r, nums[i]);
        }
        int m, ans = 0;
        while (l <= r) {
            m = l + (r - l) / 2;
            if (mostRob(nums, n, m) >= k) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

演示：二分窃取能力

两个易错点都实测过：贪心偷完忘了跳过下一间（把「不能相邻」丢掉），随机一档能力值上就有 58.23% 的样本现形；二分里把 >= k 写成 > k，86.67% 的样本答案偏大。

三、复杂度分析

问题时间额外空间
线性打家劫舍O(n)O(1)（滚动变量）
环形打家劫舍O(n)O(1)
打家劫舍 IV（二分 + 贪心）O(n log V)O(1)

空间说明：三题都只留常数个变量。打家劫舍 IV 的 log V 是二分轮数，V 是值域宽度，值域 10⁹ 时 30 轮；n = 100000、k = n / 3 的实测总耗时 0.86 毫秒，其中一次贪心检查约 0.12 毫秒。

四、总结

三道题是一张 dp 表的三次变体。线性版的转移是「偷或不偷」两条分支；环形版把首尾冲突翻译成「第 0 间偷不偷」的互斥两半，两半都是线性问题；打家劫舍 IV 把目标从最大钱数换成最小能力值，靠「能力越大越容易偷够」的单调性转成二分，每轮检查用同一张表或者一段贪心。

遇到「选不选、相邻限制」这类约束，先想想状态里要不要记「上一间偷没偷」；如果限制还能用两个前驱状态表达，就保持 O(1) 个变量。再往后的变形会要求记录连续偷了多少间，那时候 dp 就要多开一维了。
