Kruskal 重构树

Kruskal 求最小生成树时，那些「合并了两个连通块」的边，本身就构成一棵树。把它显式建出来，很多「边权受限」的图上问题就变成了树上问题。

零、把并查集的合并过程画下来

Kruskal 的过程是熟悉的：边按边权从小到大排序，一条条考虑，两个端点不在同一个集合就选它，否则丢掉。常规实现里，选中一条边之后只做一件事，在并查集里 union。

这里多做一件事：新建一个节点，让它的权等于这条边的边权，再把两个集合的代表节点挂成它的左右儿子，最后让这个新点当新集合的代表。

于是原始图的每个点都是叶子，每次成功的合并长出一个内部节点。整个过程结束时有几个连通块，就得到几棵重构树。连通图是一棵，节点数 2n - 1。

一、题目1：星际导航

图里有 n 个点、m 条无向边，每条边给定边权，图里可能有若干个连通的部分。一共有 q 条查询，每条查询格式如下：查询 x y，点 x 和点 y 希望连通起来，其中的最大边权希望尽量小，打印这个值；如果怎样都无法连通，打印 "impossible"。1 ≤ n ≤ 10⁵，1 ≤ m ≤ 3 × 10⁵，1 ≤ q ≤ 10⁵。测试链接：P2245。

这是「最小瓶颈路」的标准问法：不要求路径总长最短，只要求路径上最粗的那条边尽量细。下面这张图会贯穿本节所有例子。

三、为什么 LCA 就是答案

Kruskal 造出来的最小生成树同时也是最小瓶颈树：任意两点在生成树上的路径，最大边权不超过原图任何一条 x-y 路径的最大边权。这点由 Kruskal 的贪心顺序直接保证。

更具体一点。在重构树里看 x 和 y，它们的 LCA 恰好是「Kruskal 过程中 x 和 y 第一次落进同一个集合」时新建的那个节点。这个时刻用的那条边，既是让二者连通的第一条边，也是所有连通方案里最大边权最小的那条。

于是题目1 的答案就是 nodeKey[lca(x, y)]。两点根本不在一个连通块时，重构树是森林，用并查集的 find 判断一下，不同就打印 impossible。

这里有个细节：建完树之后 father 数组还能继续用。每棵重构树的根就是该连通块并查集的顶，find 会一路走到根上，两个点同一个连通块当且仅当 find 值相同。

四、代码

建树这一段就是 Kruskal 加三行：新点编号、记边权、连两条边。

void kruskalRebuild() {
        for (int i = 1; i <= n; i++) {
            father[i] = i;
        }
        sort(edge + 1, edge + m + 1, cmp);
        cntu = n;
        for (int i = 1; i <= m; i++) {
            int fx = find(edge[i].u);
            int fy = find(edge[i].v);
            if (fx != fy) {
                father[fx] = father[fy] = ++cntu;
                father[cntu] = cntu;
                nodeKey[cntu] = edge[i].w;
                addEdge(cntu, fx);
                addEdge(cntu, fy);
            }
        }
    }

建完之后每棵树各自 dfs 一遍，填深度和倍增表。注意森林要枚举所有 i == father[i] 的根。

void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            dfs(to[e], u);
        }
    }

查询用的 LCA 是标准写法，没有任何改动。

int lca(int a, int b) {
        if (dep[a] < dep[b]) {
            int tmp = a;
            a = b;
            b = tmp;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

复杂度分析

重构树节点数不超过 2n，所有数组按 2n 开。排序是大头，建树几乎是线性的。

步骤时间说明
边排序O(m log m)按边权升序，整节课的瓶颈都在这里
Kruskal 建树O(m α(n))每条边两次 find，成功时再建一个点连两条边
dfs 建倍增表O(n log n)最多 2n 个节点，每个填 MAXP = 20 层
单次查询O(log n)两次 find 加一次 LCA
总体O(m log m + (n + q) log n)n = 10⁵、m = 3 × 10⁵ 时轻松通过
空间O(n log n)stjump 是 (2n) × 20 的 int 数组

dfs 是递归写的，n = 10⁵ 时链状重构树的递归深度会到 10⁵ 量级，提交时留意栈空间。
