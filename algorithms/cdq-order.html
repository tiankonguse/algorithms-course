CDQ 分治与三维偏序

归并分治统计的是「左区间跨右区间」的贡献。CDQ 分治在这套框架上再配一个树状数组，就能多处理一整个维度的约束。本页先讲总论，再用三维偏序和动态逆序对两道题把框架落地。

零、背景

归并分治在前面出现过多次：归并排序、逆序对、达标子数组都靠它。做法都是在排序的过程中完成统计：当前区间二分成左右两半，问题的答案 = 左半内部产生的答案 + 右半内部产生的答案 + 左半跨到右半的答案。

前两项交给递归，关键永远是第三项。左右两半各自有序，这个便利性能把跨区间的统计加速到线性。

CDQ 分治就是归并分治，再把「跨区间统计」这一步交给高级数据结构（树状数组、线段树）。如果数据结构单次调用是 O(log n)，那么整体满足 T(n) = 2·T(n/2) + O(n·log n)，解出来是 O(n·log²n)。

既然整体已经是 n·log²n 这个量级，每层内部直接用排序替代归并也不影响复杂度。归并需要的辅助空间省掉了，代码也更好写，代价只是常数时间。

一、题目1：三维偏序

一共有 n 个对象，每个对象有 a、b、c 三个属性，属性值范围都是 [1, k]。f(i) 表示满足 aⱼ ≤ aᵢ 且 bⱼ ≤ bᵢ 且 cⱼ ≤ cᵢ 且 j ≠ i 的 j 的数量。ans(d) 表示 f(i) == d 的 i 的数量，要求打印所有的 ans[d]，d 的范围是 [0, n)。1 ≤ n ≤ 10⁵，1 ≤ k ≤ 2×10⁵。测试链接：洛谷 P3810。

朴素做法是每个 i 枚举所有 j，三个条件逐个判断，O(n²)。n 到 10⁵，这个代价是 10¹⁰ 量级，超时。

可以发现约束恰好是三维，而 CDQ 分治擅长的就是「一维排序、一维分治、一维数据结构」。具体分工：先按 (a, b, c) 字典序排序，a 这一维就定下了大顺序；CDQ 在数组上二分，跨半统计时 aⱼ ≤ aᵢ 由字典序自动保证；merge 里两半各自按 b 有序，用双指针推进；c 这一维交给树状数组做前缀计数。

merge 的具体形状：p2 从左往右扫右半，p1 不断把 b 不超过 arr[p2].b 的左半元素 add(c, 1) 进树状数组，然后 f[arr[p2].i] += query(arr[p2].c)，也就是问「左半里 b、c 都不超过我的有几个」。统计完把 add 过的元素全部减回去，再把 [l, r] 整段按 b 排序，交给上一层。

这里有个细节：a、b、c 全相等的对象组不能漏算。排序后这样的组是连续段，设组内区间 [l, r]，prepare 阶段给每个 i 预置 f = r − i，即排在它后面的相等对象个数。排在它前面的相等对象由分治负责：任意两个位置不同的元素，一定在某一层被分进左右两半，左边的 j 会带着 b、c 都满足 ≤ 的条件被算给右边的 i。一边预置、一边分治，相等组不重不漏。

三维偏序：顶层 merge(1, 4, 8) 的双指针与树状数组

树状数组里的 c 词频：
左半（按 b 排序）
右半（按 b 排序）

8 个对象按 (a, b, c) 排序后对半分，演示里能看到右半每个对象在本层拿到的贡献依次是 1、0、1、2。更深的层还会继续补贡献，比如 idx7 在下一层已经先拿到过 1，本层又拿到 1，最终 f = 2。全部统计完 ans[f[i]]++，打印 ans[0..n−1]。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int i, a, b, c;
    };

    bool CmpAbc(Node x, Node y) {
        if (x.a != y.a) {
            return x.a < y.a;
        }
        if (x.b != y.b) {
            return x.b < y.b;
        }
        return x.c < y.c;
    }

    bool CmpB(Node x, Node y) {
        return x.b < y.b;
    }

    const int MAXN = 100001;
    const int MAXK = 200001;
    int n, k;

    Node arr[MAXN];
    int tree[MAXK];
    int f[MAXN];
    int ans[MAXN];

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= k) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int query(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    void merge(int l, int m, int r) {
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].b <= arr[p2].b) {
                p1++;
                add(arr[p1].c, 1);
            }
            f[arr[p2].i] += query(arr[p2].c);
        }
        for (int i = l; i <= p1; i++) {
            add(arr[i].c, -1);
        }
        sort(arr + l, arr + r + 1, CmpB);
    }

    void cdq(int l, int r) {
        if (l == r) {
            return;
        }
        int mid = (l + r) / 2;
        cdq(l, mid);
        cdq(mid + 1, r);
        merge(l, mid, r);
    }

    void prepare() {
        sort(arr + 1, arr + n + 1, CmpAbc);
        for (int l = 1, r = 1; l <= n; l = ++r) {
            while (r + 1 <= n && arr[l].a == arr[r + 1].a && arr[l].b == arr[r + 1].b && arr[l].c == arr[r + 1].c) {
                r++;
            }
            for (int i = l; i <= r; i++) {
                f[arr[i].i] = r - i;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> k;
        for (int i = 1; i <= n; i++) {
            arr[i].i = i;
            cin >> arr[i].a >> arr[i].b >> arr[i].c;
        }
        prepare();
        cdq(1, n);
        for (int i = 1; i <= n; i++) {
            ans[f[i]]++;
        }
        for (int i = 0; i < n; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

二、题目2：动态逆序对

给定一个长度为 n 的排列，1 到 n 每个数字都出现一次。前面的数大于后面的数就组成一个逆序对。再给定一个长度为 m 的数组，表示依次删除的数字。要求每次删除数字前打印排列中逆序对的总数，共 m 条。1 ≤ n ≤ 10⁵，1 ≤ m ≤ 5×10⁴。测试链接：洛谷 P3157。

删除只会减少逆序对。每次删除前后的差值，就是与被删数还组成逆序对的、活着的数的个数：位置在它左边且值比它大的，加上位置在它右边且值比它小的。于是答案可以写成「初始逆序对数 + 每一步增量的前缀和」。

把整个过程事件化：n 个原始事件（影响 +1，带原始下标）加上 m 个删除事件（影响 −1，带删除时刻 q），全部放进一个数组。事件在数组里的先后就是时序，这正好当 CDQ 的大顺序；merge 里按下标排序，双指针配合树状数组按值统计。

跨区间的统计要跑两遍双指针。从左往右扫：对右半事件 p2，把左半里下标更小的元素 add 进树状数组，ans[q] += d × (query(n) − query(v))，统计左侧值大的对。从右往左扫：把左半里下标更大的元素 add 进去，ans[q] += d × query(v − 1)，统计左侧值小的对。两遍合起来恰好覆盖「j 在左、e 在右」的所有逆序搭档。

动态逆序对：每次删除前统计（排列 4 2 3 1，依次删 4、1、2）

演示里的三条输出是 5、2、0。删除 4 时消失的对是 (4,2)、(4,3)、(4,1) 共 3 个，删除 1 时消失的是 (2,1)、(3,1) 共 2 个，删除 2 时已经没有对消失。前缀和的口径和代码完全一致。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int v, i, d, q;
    };

    bool NodeCmp(Node x, Node y) {
        return x.i < y.i;
    }

    const int MAXN = 100001;
    const int MAXM = 50001;
    int n, m;

    int num[MAXN];
    int pos[MAXN];
    int del[MAXM];

    Node arr[MAXN + MAXM];
    int cnt = 0;

    int tree[MAXN];

    long long ans[MAXM];

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= n) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int query(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    void merge(int l, int m, int r) {
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].i < arr[p2].i) {
                p1++;
                add(arr[p1].v, arr[p1].d);
            }
            ans[arr[p2].q] += arr[p2].d * (query(n) - query(arr[p2].v));
        }
        for (int i = l; i <= p1; i++) {
            add(arr[i].v, -arr[i].d);
        }
        for (p1 = m + 1, p2 = r; p2 > m; p2--) {
            while (p1 - 1 >= l && arr[p1 - 1].i > arr[p2].i) {
                p1--;
                add(arr[p1].v, arr[p1].d);
            }
            ans[arr[p2].q] += arr[p2].d * query(arr[p2].v - 1);
        }
        for (int i = m; i >= p1; i--) {
            add(arr[i].v, -arr[i].d);
        }
        sort(arr + l, arr + r + 1, NodeCmp);
    }

    void cdq(int l, int r) {
        if (l == r) {
            return;
        }
        int mid = (l + r) / 2;
        cdq(l, mid);
        cdq(mid + 1, r);
        merge(l, mid, r);
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            arr[++cnt].v = num[i];
            arr[cnt].i = i;
            arr[cnt].d = 1;
            arr[cnt].q = 0;
        }
        for (int i = 1; i <= m; i++) {
            arr[++cnt].v = del[i];
            arr[cnt].i = pos[del[i]];
            arr[cnt].d = -1;
            arr[cnt].q = i;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> num[i];
            pos[num[i]] = i;
        }
        for (int i = 1; i <= m; i++) {
            cin >> del[i];
        }
        prepare();
        cdq(1, cnt);
        for (int i = 1; i < m; i++) {
            ans[i] += ans[i - 1];
        }
        for (int i = 0; i < m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

三、复杂度分析

两道题的框架一样，代价都由「层数 × 每层代价」决定。每层的排序或双指针是线性的，树状数组的每次 add、query 是一个 log，所以每层是 O(E·log 值域)，一共 O(log E) 层。

题目事件规模时间复杂度空间复杂度
三维偏序n 个对象O(n·log n·log k)O(n + k)
动态逆序对E = n + m 个事件O((n+m)·log(n+m)·log n)O(n + m)

n = 10⁵ 时三维偏序约 10⁵ × 17 × 18 ≈ 3×10⁷ 次基本操作。动态逆序对的答案最多约 n²/2 = 5×10⁹，超过 int，所以 ans 用 long long。

空间上两题都是静态数组：对象或事件一份、树状数组一份，没有递归栈以外的动态分配。
