全变 1 的最少操作次数：主元依赖自由元

n 个点排成一张无向图，每个点初始是 0。操作任意一个点，它自己和所有邻居的状态一起翻转。目标：所有点变 1。能达成目标的方案可能不止一种，要打印操作次数最少的那一种。n ≤ 35，答案是「最少几次」，不是「有几种」。这一节把上一节的异或模板用起来，并补上模板没有的部分：主元依赖自由元时，怎么枚举出最优解。

零、每个点一个方程：被翻转奇数次

设 xi = 1 表示操作了点 i。点 i 最后是 1，等价于它被翻了奇数次：自己（xi）加上所有邻居（Σ xj），异或起来等于 1。

xi ^ Σj∈邻居(i) xj = 1

于是矩阵的第 i 行：第 i 列是 1（操作自己翻自己）、每条边 (u, v) 让 mat[u][v] 和 mat[v][u] 都是 1（操作对方翻自己）、常数列全是 1（目标全变 1）。

建矩阵的代码没有悬念：

// 每个点：操作自己翻转自己，目标全变成 1
    for (int i = 1; i <= n; i++) {
      mat[i][i] = 1;
      mat[i][n + 1] = 1;
    }
    // 边：操作 u 会翻转 v，操作 v 也会翻转 u
    for (int i = 1, u, v; i <= m; i++) {
      cin >> u >> v;
      mat[u][v] = 1;
      mat[v][u] = 1;
    }

一、消元之后分两种情况

拿上一节的模板消元。对角线全 1 是唯一解：常数里 1 的个数就是要操作的次数，直接数出来。

对角线出现 0 就是多解：有些点是自由元，选它和不选它都满足方程。这时候不能只数常数了，得枚举自由元的每种取值，算每种方案的操作次数，取最小。

二、主元依赖自由元，所以从后往前决策

消元完成后，第 i 行的非零系数只可能出现在编号比 i 大的列：编号更小的主元列已经被消成 0 了。这意味着：决策顺序要倒着来，从第 n 行往回走到第 1 行。

走到自由元（mat[i][i] == 0）：它不影响任何已决策的变量，选 0 选 1 都试一遍。

走到主元（mat[i][i] == 1）：影响它的自由元编号都比 i 大，已经全部决定。主元的值由方程反推：

cur = mat[i][n+1] ^ (所有 j > i 且 mat[i][j] == 1 的 op[j])

dfs 的完整实现：

// 从第 n 行往第 1 行决策，num 是已经确定的操作次数
    void dfs(int i, int num) {
      if (num >= ans) {
        return;
      }
      if (i == 0) {
        ans = num;
        return;
      }
      if (mat[i][i] == 0) {
        // 自由元：不影响主元，选或不选都可以
        op[i] = 0;
        dfs(i - 1, num);
        op[i] = 1;
        dfs(i - 1, num + 1);
      } else {
        // 主元：值由已经决定的自由元确定
        int cur = mat[i][n + 1];
        for (int j = i + 1; j <= n; j++) {
          if (mat[i][j] == 1) {
            cur ^= op[j];
          }
        }
        dfs(i - 1, num + cur);
      }
    }

三、剪枝：num 已经超过当前答案就停

dfs 每递归一层就多决定一个变量，num 是已经确定的操作次数。num 一旦不小于当前已知的最优 ans，这条分支再往下走只会更差，直接剪掉。ans 的初值设成 n（全操作一遍），多解分支里第一个完整方案就把它压下来。

唯一解分支不用 dfs，直接数常数里的 1；只有出现自由元才走 dfs，自由元数量决定了枚举规模。

四、复杂度

消元 O(n³)，dfs 枚举 2^自由元 种取值。n ≤ 35 时自由元通常不多，剪枝后实际跑得更快；如果自由元真的接近 35，任何枚举都会炸，只能靠题目数据保证有解且自由元可控。

演示：消元 + 倒序决策，找最少操作次数

五、总结

这题的方程构造是模板的直接应用，真正的新东西在消元之后：自由元出现时，主元的值依赖编号更大的自由元，所以必须倒序决策：自由元先枚举，主元由方程反推，全程带着剪枝。上一节数自由元个数出答案，这一节枚举自由元找最优，两道题合起来正好把「主元和自由元」这个关系用完整。下一节（外星千足虫）把行压进位图，顺手处理 n = 1000 的规模。
