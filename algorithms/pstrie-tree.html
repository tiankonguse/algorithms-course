树上的两种版本：字符串树与路径子树异或

上一页的版本是按下标排的，每插进去一个数就多一个版本。把树拿来，版本的「顺序」就有了别的排法：顺着父亲排，或者顺着 dfn 排。这一页两道题各用一种，中间夹着同一个老问题，trie 的差查询一次只能消两个版本。

零、子节点的树从父亲的树加工得到

树上做一次 dfs，进入 u 时拿父亲那棵树当底子，把边 (fa, u) 上的字符串插进去，得到的就是 root[u]。它代表的集合是「根到 u 这条路径上的所有边」。多叉 trie 的复制方式和 01Trie 完全一样，只是每个节点的儿子从 2 个变成 26 个。

clone 是把 26 个儿子和 pass 整块拷过去；insert 在这里多做了件事：pass[rt]++ 和沿途 pass[cur]++，这样某个节点的 pass 就是「路径上有多少条边经过了它」。

一、题目2：字符串树

n 个点 n-1 条边，边权是字符串。m 条查询 u v s：u 到 v 的路径上有多少条边的字符串以 s 为前缀。n、m 到 10⁵，字符串长度不超过 10，字符只有 a 到 z。题目链接 P6088。

朴素做法是每条查询都沿路径走一遍，路径长度可以到 n，一乘 m 就到 10¹⁰。

换个看法：root[w] 里存的是根到 w 的所有边，所以 query(s, root[w]) 直接给出「根到 w 的路径上有几条边以 s 为前缀」。记它为 f(w)。u 到 v 的路径等于根到 u 加根到 v，再减掉两倍的根到 lca。

Trie 里的走法是逐字符：i = tree[i][path]，走到中途发现 i == 0，说明这条路上从来没出现过这个前缀，直接返回 0。

    
int query(const string &str, int i) {
        for (int j = 0; j < (int)str.size(); j++) {
            int path = num(str[j]);
            i = tree[i][path];
            if (!i) return 0;
        }
        return pass[i];
    }

    void dfs(int u, int fa, const string &path) {
        root[u] = insert(path, root[fa]);
        deep[u] = deep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            if (to[e] != fa) {
                dfs(to[e], u, weight[e]);
            }
        }
    }

int clone(int i) {
        int rt = ++cntt;
        for (int c = 1; c <= 26; c++) {
            tree[rt][c] = tree[i][c];
        }
        pass[rt] = pass[i];
        return rt;
    }

    int insert(const string &str, int i) {
        int rt = clone(i);
        pass[rt]++;
        int pre = rt;
        for (int j = 0; j < (int)str.size(); j++) {
            int path = num(str[j]);
            i = tree[i][path];
            int cur = clone(i);
            pass[cur]++;
            tree[pre][path] = cur;
            pre = cur;
        }
        return rt;
    }
    
int compute(int u, int v, const string &s) {
        return query(s, root[u]) + query(s, root[v]) - 2 * query(s, root[lca(u, v)]);
    }

二、题目3：路径和子树的异或

一棵树，1 号点是根，每个点有点权。m 条操作：1 x y 在以 x 为根的子树里任选一个值，希望异或 y 之后最大；2 x y z 在 x 到 y 的路径上任选一个值，希望异或 z 之后最大。n、m 到 10⁵，值小于 2³⁰。题目链接 P4592。

两问要的集合形状不一样，得做两套版本：root1 顺着 dfn 序排，root2 顺着父亲排。dfs 一次就把两套都加工出来。

    
void dfs2(int u, int fa) {
        root1[dfn[u]] = insert(arr[u], root1[dfn[u] - 1]);
        root2[u] = insert(arr[u], root2[fa]);
        for (int ei = head[u]; ei > 0; ei = nxt[ei]) {
            if (to[ei] != fa) {
                dfs2(to[ei], u);
            }
        }
    }

子树这一问很直接：dfn 把子树压成连续区间 [dfn[x], dfn[x] + siz[x] - 1]，两端版本一减就是整个子树的点权集合。

路径这一问麻烦一点。集合应该是「root2[x] 加 root2[y]，减 root2[lca]，再减 root2[fa(lca)]」，但 trie 的差查询一次只能吃两个版本，三个以上的线性组合它做不了。于是拆成两段：(fa(lca) 到 x) 和 (fa(lca) 到 y)，各查一次，取大的那个。fa(lca) 用 stjump[lca][0] 一步拿到。

复杂度分析

题2 的字符串长度记作 L（不超过 10），题3 的二进制位记作 BIT = 29。

项目时间空间
题2 一次加工（插入一条边）O(L)O(L) 个节点
题2 一次 queryO(L)—
题2 单次 LCAO(log n)O(n log n)
题2 建树 + m 条查询O((n + m) · (L + log n))O(n · L · 26)
题3 一次 dfsO(n · BIT)O(n · BIT · 2)
题3 单次子树查询O(BIT)同上
题3 单次路径查询O(log n + 2 · BIT)同上

题2 的节点数是 Σ(边字符串长度) 加一个根节点，n 到 10⁵、长度不超过 10 时上界是 10⁶ 多一点，代码开 MAXT = 1000001；每个节点开 tree[][27]，下标 0 空着、1 到 26 对应 a 到 z。题3 要两套版本，每套 n · (BIT + 2) 个节点，MAXT = MAXN * 62 就是这么来的。
