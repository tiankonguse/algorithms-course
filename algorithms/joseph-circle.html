约瑟夫环：从模拟到 O(n) 递推

n 个人围成环，从 1 号开始报数，报到 k 的删掉，下一个人重新从 1 报。n、k 到 10^6 时链表模拟是 O(nk)，得用一条递推把幸存者从环里「拔」出来：ans = (ans + k − 1) % c + 1。每轮报数还不一样的加强版，把这条公式倒着用一遍就行。

零、经典递推

设 f(c) 是「c 个人的环」里最后幸存者的编号（从 1 数）。f(1) = 1。现在想从 f(c−1) 推出 f(c)：

f(c) = (f(c−1) + k − 1) % c + 1

直觉是这样：c 个人的环报数报到 k 删掉那个人后，剩下 c−1 个人，从被删者的下一个开始重新从 1 报。把这 c−1 个人按「新报数起点」重新编号成 1..c−1，它们的相对关系跟一个全新的 c−1 人环完全一样。所以 c−1 人环的幸存者编号 f(c−1)，映射回 c 人环的旧编号就是 f(c−1)+k−1（从删掉位置的下一个开始数），再对 c 取模加 1 修正到 1 开头。

这条公式从 c=2 一直算到 c=n，O(n) 完成，只用一个 int。它不记中间删了谁，只关心「最后活下来的人在当前环里是几号」，每一步把上一轮的编号平移回这一轮。

一、约瑟夫环实现

题目链接：P8671 约瑟夫环，n、k ≤ 10^6。从 c=2 循环到 n，每一步只做一次取模。

#include <bits/stdc++.h>
    using namespace std;

    int compute(int n, int k) {
    	int ans = 1;
    	for (int c = 2; c <= n; c++) {
    		ans = (ans + k - 1) % c + 1;
    	}
    	return ans;
    }

    int main() {
    	ios::sync_with_stdio(false);
    	cin.tie(nullptr);
    	int n, k;
    	cin >> n >> k;
    	cout << compute(n, k) << endl;
    	return 0;
    }

二、每轮报数不同的加强版

现在游戏有 n−1 轮，第 i 轮报数到 arr[i] 才删人。把经典公式里的固定 k 换成每轮的 arr[i] 就行，但方向要想清楚：

ans = (ans + arr[i] − 1) % c + 1，i 从 n−1 倒着走到 1，c 从 2 正着走到 n

为什么倒着用：正向第 1 轮删完剩 n−1 人，最后一轮（第 n−1 轮）删完剩 1 人。幸存者在「剩 1 人」的环里编号必然是 1。回推一步：剩 2 人时（刚做完倒数第二轮删除），幸存者在 2 人环里是几号？用第 n−1 轮的报数 arr[n−1] 代入公式。所以循环里 i 从 n−1 递减到 1（每轮的报数），c 从 2 递增到 n（环大小）。

顺带一提，经典版其实也是这个加强版的特殊情形：每轮 k 都一样，公式完全一致。加强版不能用链表模拟（O(n·max arr) 扛不住），O(n) 递推是唯一出路。

三、加强版实现

这是真实大厂笔试原题，没有公开测试链接，用对数器验证：暴力链表模拟和 O(n) 递推对拍。代码里只留正式方法，循环变量 c 和 i 一增一减，同时控制环大小和轮数。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 1000001;

    int n;
    int arr[MAXN];

    int compute() {
    	if (n == 1) {
    		return 1;
    	}
    	int ans = 1;
    	for (int c = 2, i = n - 1; c <= n; c++, i--) {
    		ans = (ans + arr[i] - 1) % c + 1;
    	}
    	return ans;
    }

    int main() {
    	ios::sync_with_stdio(false);
    	cin.tie(nullptr);
    	cin >> n;
    	for (int i = 1; i < n; i++) {
    		cin >> arr[i];
    	}
    	cout << compute() << endl;
    	return 0;
    }

总结

约瑟夫环的 O(n) 递推 ans = (ans + k − 1) % c + 1，本质是把「c−1 人环的幸存者编号」沿删除位置平移回 c 人环。它不需要维护环结构，代价是只回答「最后谁活着」，回答不了「第几个被删」。每轮报数不同的加强版把固定 k 换成 arr[i]，并且倒着回推：幸存者从 1 人环的编号 1 出发，用最后一轮的报数推回 2 人环，一路推到 n 人环。经典版是加强版的特例，两条公式同源。
