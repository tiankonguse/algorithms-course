de Bruijn 序列与构造序列

这一页三道题不给素材，要自己造一个最短的串，让它的连续子串把所有可能的密码都包含一遍。答案叫 de Bruijn 序列，生成办法就是把所有密码建成一张图，然后走一条欧拉回路。

零、背景

以破解保险箱为例：密码有 n 位，每位是 0 到 k-1，一共 k 的 n 次方种。要造一个串，它的每个长度为 n 的连续子串，恰好把所有密码各出现一次。串越短越好。

把密码变成图的边是整个做法的核心。节点是长度 n-1 的串，也就是状态；从状态 u 补一个数字 d，滑出新的状态 v，这条边就代表密码「u 拼 d」。节点共 k 的 n-1 次方个，每个点恰好 k 条出边、k 条入边，边数正好是 k 的 n 次方。

每个点入度等于出度，所以欧拉回路一定存在。一条回路把每条边走一次，就等于每个密码被覆盖一次。回路从起点出发前先写下起点的 n-1 个字符，此后每走一条边追加一个字符，总长 (n-1) + k 的 n 次方，这也是理论下界。

代码里节点不用存字符串，编号就是那个 k 进制数。从编号 u 补数字 d，新编号是 (u * k + d) % m，其中 m 是 k 的 n-1 次方。状态转移一行搞定，整张图是隐式的，连边表都不用建。

起点取全 0 状态，字典序最小自然满足：每步从数字小的边开始走。答案的写法是先补 n-1 个 0，再把 path 数组倒序接上。

一、题目6：破解保险箱

密码有 n 位，每位是 0 到 k-1，共 k 的 n 次方种可能。构造一个串，连续子串包含所有可能的密码，先保证最短，再保证字典序尽量小。n 到 4，k 到 10。测试链接：LeetCode 753 Cracking the Safe。

递归版 euler1 直接照模版写。n 和 k 都很小，最多 10000 条边，递归深度安全。实测 crackSafe(2, 2) 得到 00110，长度 5，四个滑窗 00、01、11、10 各出现一次。

LeetCode 版的完整代码，提交的是 Solution 类。

class Solution {
    public:
        static const int MAXN = 5001;
        int n, k, m;
        int cur[MAXN];
        int path[MAXN];
        int cntp;

        int sta[MAXN][2];
        int u, e;
        int stacksize;

        void push(int u, int e) {
            sta[stacksize][0] = u;
            sta[stacksize][1] = e;
            stacksize++;
        }

        void pop() {
            stacksize--;
            u = sta[stacksize][0];
            e = sta[stacksize][1];
        }

        void prepare(int len, int num) {
            n = len;
            k = num;
            m = 1;
            for (int i = 1; i <= n - 1; i++) {
                m *= k;
            }
            for (int i = 0; i < m; i++) {
                cur[i] = 0;
            }
            cntp = 0;
        }

        void euler1(int u, int e) {
            while (cur[u] < k) {
                int ne = cur[u]++;
                euler1((u * k + ne) % m, ne);
            }
            path[++cntp] = e;
        }

        void euler2(int node, int edge) {
            stacksize = 0;
            push(node, edge);
            while (stacksize > 0) {
                pop();
                if (cur[u] < k) {
                    int ne = cur[u]++;
                    push(u, e);
                    push((u * k + ne) % m, ne);
                } else {
                    path[++cntp] = e;
                }
            }
        }

        string crackSafe(int n, int k) {
            prepare(n, k);
            euler1(0, -1);
            string ans;
            ans.reserve((n - 1) + (cntp - 1));
            for (int i = 1; i <= n - 1; i++) {
                ans.push_back('0');
            }
            for (int i = cntp - 1; i >= 1; i--) {
                ans.push_back(char('0' + path[i]));
            }
            return ans;
        }
    };

二、题目7：所有可能的密码串

n 位密码，每位 0 到 9，共 10 的 n 次方种，构造最短且字典序最小的串。n 到 6。测试链接：POJ 1780。

和题目6是同一个题，k 固定成 10。但 n 等于 6 时节点数是 10 的 5 次方、边数 10 的 6 次方，递归深度最坏跟着边数走，会爆栈。所以这里用迭代版 euler2：手写一个栈，存（当前点，走哪条边出去）二元组。

迭代版的逻辑和递归版一一对应。弹出一个点时，如果它还有剩余出边，就把点和这条边重新压回去，再压入走过去的新点；没有出边了才写进 path。这样每个点被压多次也没关系，写进 path 的时机仍然是「出边走光」。

实测 n 等于 1 输出 0123456789；n 等于 2 输出 101 位，10 的 2 次方加 1，滑窗验证 100 个密码各一次。

#include <cstdio>

    const int MAXN = 1000002;
    int n, k, m;

    int cur[MAXN];
    int path[MAXN];
    int cntp;

    int sta[MAXN][2];
    int u, e;
    int stacksize;

    void push(int u, int e) {
        sta[stacksize][0] = u;
        sta[stacksize][1] = e;
        stacksize++;
    }

    void pop() {
        stacksize--;
        u = sta[stacksize][0];
        e = sta[stacksize][1];
    }

    void prepare(int len, int num) {
        n = len;
        k = num;
        m = 1;
        for (int i = 1; i <= n - 1; i++) {
            m *= k;
        }
        for (int i = 0; i < m; i++) {
            cur[i] = 0;
        }
        cntp = 0;
    }

    void euler(int node, int edge) {
        stacksize = 0;
        push(node, edge);
        while (stacksize > 0) {
            pop();
            if (cur[u] < k) {
                int ne = cur[u]++;
                push(u, e);
                push((u * k + ne) % m, ne);
            } else {
                path[++cntp] = e;
            }
        }
    }

    int main() {
        int len;
        int num = 10;
        scanf("%d", &len);
        while (len != 0) {
            prepare(len, num);
            euler(0, -1);
            for (int i = 1; i <= n - 1; i++) {
                putchar('0');
            }
            for (int i = cntp - 1; i >= 1; i--) {
                putchar((char)('0' + path[i]));
            }
            putchar('\n');
            scanf("%d", &len);
        }
        return 0;
    }

三、题目8：太鼓达人

所有长度为 n 的二进制状态共 2 的 n 次方个。构造一个可以循环使用的串，连续子串包含所有二进制状态。先求最小长度，再给字典序最小的方案。比如 n 等于 3 时，最小长度 8，方案 00010111，其中末尾两个状态靠循环使用补出来。n 到 11。测试链接：Luogu P10950、LOJ 10110。

循环使用是和前两题唯一的区别。线性串里结尾要补 n-1 个字符凑出最后几个窗口；循环串首尾相接，这 n-1 个字符直接省掉，长度从 k 的 n 次方加 n 减一，降到 k 的 n 次方。

生成的串天然是前缀 n 个 0、后缀 n-1 个 0 的形状，输出时去掉后缀的 n-1 个 0 就行。代码按 k 进制推广实现，二进制只是 k 等于 2 的特例。实测 n 等于 3 输出「8 00010111」。

完整代码。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 3001;
    int n, k, m;

    int cur[MAXN];
    int path[MAXN];
    int cntp;

    void prepare(int len, int num) {
        n = len;
        k = num;
        m = 1;
        for (int i = 1; i <= n - 1; i++) {
            m *= k;
        }
        for (int i = 0; i < m; i++) {
            cur[i] = 0;
        }
        cntp = 0;
    }

    void euler(int u, int e) {
        while (cur[u] < k) {
            int ne = cur[u]++;
            euler((u * k + ne) % m, ne);
        }
        path[++cntp] = e;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int len;
        cin >> len;
        int num = 2;
        prepare(len, num);
        euler(0, -1);
        cout << (m * k) << " ";
        for (int i = 1; i <= n - 1; i++) {
            cout << "0";
        }
        for (int i = cntp - 1; i >= n; i--) {
            cout << path[i];
        }
        cout << "\n";
        return 0;
    }

四、复杂度分析

生成阶段每条边走一次，线性；答案长度就是边数加 n 减一。

操作时间复杂度空间复杂度
隐式建图（状态编号 O(1) 转移）O(1)O(kn-1)（cur 数组、path 数组、手写栈）
Hierholzer 生成（递归或迭代）O(kn)
拼答案输出O(kn)

题目7 的 n 等于 6 时边数 10 的 6 次方，递归爆栈换迭代就是这个量级逼出来的。题目8 的 n 到 11，2 的 11 次方只有 2048 条边，怎么写都够。

五、最后

构造序列题的钥匙只有一把：密码变边、状态变点。欧拉回路的存在性由「每点入度出度都是 k」白送，剩下的是把递归写稳、把答案拼对。
