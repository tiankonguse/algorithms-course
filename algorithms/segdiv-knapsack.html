线段树分治 + 背包类 dp

线段树分治处理的对象是「一段一段生效」的东西：商品在时刻 L 出现、时刻 R 后被删除，装备从队头或队尾进出，操作覆盖某个位置。把这段生效的时间（或位置）拆成 O(log) 个线段树节点，然后用一次 dfs 把「加入—回答—撤销」串起来。本页三道题里，每个节点要维护的都是一类背包 dp。

零、背景

前置是 01 背包和线段树分治的原理。原理那一节只给出过一句话的形态：把时间轴 1 到 q 建成线段树，一条只在 [l, r] 内存在的边（商品、装备、操作），挂到能完整覆盖 [l, r] 的若干个节点上，任何一个区间都会被拆成不超过 O(log q) 个节点。

dfs 到某个叶子的时候，根到这条路径上所有节点挂着的元素，正好就是该时刻集合里的全部元素。这一点成立之后，「加入」在节点上进行一次，「回答」在叶子上进行一次，「撤销」在回溯时按反序执行一次，整套流程就跑完了。

本页三道题分别给每种背包配一张图：题 1 是标准的 01 背包（容量 k 很小），题 2 是「模 p 余数」意义下的背包（下标在 0 到 p-1 的环上），题 3 干脆把线段树建在位置轴上，节点里做的是 bitset 子集和。后面一节讲线性基版本，再后面一节讲可持久化 01Trie 版本。

一、时间轴线段树上挂着什么

一开始所有集合为空，每个元素只在一个连续的时间段里存在。扫描一遍全部操作就能算出每个元素的 [from, to]，之后把这个区间挂到时间轴线段树上。

下面这张图里，时间轴是 1 到 8，三件商品的生效区间分别是 [1, 8]、[3, 6]、[5, 8]。拆完之后商品 A 只挂在根节点上，商品 B 挂在 [3, 4] 和 [5, 6] 上，商品 C 挂在 [5, 6] 和 [7, 8] 上。

撤销有两条路。一条是对每个元素做逆运算（这才是可撤销并查集那条线的思路），另一条是进入节点之前把整个 dp 数组备份进 backup[dep]，离开时原样拷回来。本页三道题走的都是第二条：dp 数组的规模很小（k ≤ 10³、p ≤ 500、bitset 只有几百个机器字），每层拷一次的钱可以忽略。

二、题目1 博物馆劫案

给定 n 件商品，每件有价值 v 和重量 w，1 到 n 号商品一开始就在集合 s 里。接下来 q 个操作：操作 1 x y 往 s 里加入一件价值 x、重量 y 的商品，编号自增；操作 2 x 删除编号 x 的商品；操作 3 查询当前的 f(s)。

集合的价值定义分两层：a(s, m) 是在 s 里挑若干件、总重量不超过 m 时能获得的最大价值；给了正数 k、BAS、MOD 之后，f(s) = Σ(m = 1 到 k) a(s, m) · BAS 的 m-1 次方 % MOD。数据范围 1 ≤ n ≤ 5 · 10³，1 ≤ q ≤ 3 · 10⁴，k 和每件商品重量 ≤ 10³（测试链接：https://www.luogu.com.cn/problem/CF601E）。

朴素做法是每次查询重新跑一遍 01 背包：O(当时集合大小 · k)，查询最多 3 · 10⁴ 次，直接到 10¹¹ 这个量级。真正浪费的地方在于相邻两次查询之间集合只变了很少的元素，而背包是完全重算的。

把商品看成「一段时间内的存在」之后，事情就顺了。也是发现有增量和撤销两条路径之后，结合线段树分治框架就能很容易想到解法。

2.1 拿到每件商品的生效区间

初始的 n 件商品生效区间是 [1, q]。第 i 个操作如果是操作 1，新商品编号 ++n，它的起点是 i，终点先置成 q；如果是操作 2 x，就把 x 号商品的终点改成 i - 1。最后扫一遍，from ≤ to 的商品才有资格进线段树。

    
void prepare() {
        for (int i = 1; i <= n; i++) {
            from[i] = 1;
            to[i] = q;
        }
        for (int i = 1; i <= q; i++) {
            if (op[i] == 1) {
                n++;
                v[n] = x[i];
                w[n] = y[i];
                from[n] = i;
                to[n] = q;
            } else if (op[i] == 2) {
                to[x[i]] = i - 1;
            }
        }
        for (int i = 1; i <= n; i++) {
            if (from[i] <= to[i]) {
                add(from[i], to[i], v[i], w[i], 1, q, 1);
            }
        }
    }

这里的 add 就是普通的区间拆分，jobl、jobr 是商品生效的时间段，jobv、jobw 是它的价值和重量，命中节点时用链表挂上去。

    
void clone(long long* a, long long* b) {
        for (int i = 0; i <= k; i++) {
            a[i] = b[i];
        }
    }

    void addEdge(int i, int v, int w) {
        nxt[++cnt] = head[i];
        tov[cnt] = v;
        tow[cnt] = w;
        head[i] = cnt;
    }

    void add(int jobl, int jobr, int jobv, int jobw, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobv, jobw);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobv, jobw, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobv, jobw, mid + 1, r, i << 1 | 1);
            }
        }
    }

2.2 dfs 里的背包与回滚

进入节点先把 dp 拷进 backup[dep]，然后倒着做 01 背包（每个节点一次），叶子处如果是查询就按定义把 Σ dp[m] · BAS^(m-1) 算出来，最后把 backup[dep] 拷回 dp。

dp[j] 存的是「总重量不超过 j 时的最大价值」，初始全为 0（数组本身就是 0），所以不需要额外的负无穷处理，最后直接取 dp[m] 就是 a(s, m)。

这里有个细节：backup 的下标是 dep（深度），不是节点编号。同一层的两个兄弟节点用的是同一个 backup[dep]，但它们不会同时使用这条路径之外的东西，dfs 的递归序保证了安全。

    
void dfs(int l, int r, int i, int dep) {
        clone(backup[dep], dp);
        for (int e = head[i]; e > 0; e = nxt[e]) {
            int v = tov[e];
            int w = tow[e];
            for (int j = k; j >= w; j--) {
                dp[j] = max(dp[j], dp[j - w] + v);
            }
        }
        if (l == r) {
            if (op[l] == 3) {
                long long ret = 0;
                long long base = 1;
                for (int j = 1; j <= k; j++) {
                    ret = (ret + dp[j] * base) % MOD;
                    base = (base * BAS) % MOD;
                }
                ans[l] = ret;
            }
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1, dep + 1);
            dfs(mid + 1, r, i << 1 | 1, dep + 1);
        }
        clone(dp, backup[dep]);
    }

叶子回答

整个过程里每个商品被加入了 O(log q) 次，每次加入是 O(k) 的倒序背包，于是总时间 O((n + 新增商品数) · k · log q)，空间被 backup 数组主导，是 O(k · log q)。

三、题目2 贪玩蓝月

每件装备有特征值 w 和战斗力 v，放装备的背包是一个双端队列，只有队列里的装备是可选的。给定数值 p，接下来 m 个操作：IF x y 从前端加入一件装备，IG x y 从后端加入，DF 删掉队首，DG 删掉队尾，QU x y 询问，挑选若干装备，特征值累加和 % p 必须落在 [x, y] 内，求最大战斗力，无方案打印 -1。数据范围 1 ≤ m ≤ 5 · 10⁴，1 ≤ p ≤ 500（测试链接：https://loj.ac/p/6515）。

方便之处是：背包（双端队列）的操作全部形态固定，而且每件装备的入队时刻和出队时刻是可以直接读出来的，于是它同样是一条「生长—消失」的线段。

enqueue 和 pop_front / pop_back 是可以直接读出来的。具体来说，读到 IF 或 IG 时把 (特征值 % p、战斗力、当前操作序号) 从相应的一端推进，读到 DF 或 DG 时把队首/队尾的装备弹出来，它的生效区间就是 [入队时刻, 当前操作序号 - 1]，最后队列里剩下的装备补上 [入队时刻, m]。

    
void prepare() {
        array<int,3> equip;
        for (int i = 1; i <= m; i++) {
            if (op[i] == 1) {
                knapsack.push_front({x[i] % p, y[i], i});
            } else if (op[i] == 2) {
                knapsack.push_back({x[i] % p, y[i], i});
            } else if (op[i] == 3) {
                equip = knapsack.front();
                add(equip[2], i - 1, equip[0], equip[1], 1, m, 1);
                knapsack.pop_front();
            } else if (op[i] == 4) {
                equip = knapsack.back();
                add(equip[2], i - 1, equip[0], equip[1], 1, m, 1);
                knapsack.pop_back();
            }
        }
        while (!knapsack.empty()) {
            equip = knapsack.front();
            add(equip[2], m, equip[0], equip[1], 1, m, 1);
            knapsack.pop_front();
        }
        for (int i = 0; i < p; i++) {
            dp[i] = -1;
        }
        dp[0] = 0;
    }

每个节点上的 dp[j] 表示「挑若干件装备，特征值累加和 % p 恰好等于 j 时的最大战斗力」，不可达是 -1，初始只有 dp[0] = 0。注意转移：

dp[(j + w) % p] = max(dp[(j + w) % p], pre[j] + v);

这里的 pre 是加入这件装备之前的 dp 快照，必须先用 clone(pre, dp) 存下来再用。原因是 % p 之后下标成了一个环，j 和 (j + w) % p 会互相落在对方后面，就地更新的话同一件装备会被反复使用，答案就错了。这一点和题 1 的倒序 01 背包是同一个诉求的两种写法：倒序是为了不让同一件被用两次，这里环上没法倒序，只能换快照。

    
void add(int jobl, int jobr, int jobw, int jobv, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobw, jobv);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobw, jobv, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobw, jobv, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void dfs(int l, int r, int i, int dep) {
        clone(backup[dep], dp);
        for (int e = head[i], w, v; e > 0; e = nxt[e]) {
            w = tow[e];
            v = tov[e];
            clone(pre, dp);
            for (int j = 0; j < p; j++) {
                if (pre[j] != -1) {
                    dp[(j + w) % p] = max(dp[(j + w) % p], pre[j] + v);
                }
            }
        }
        if (l == r) {
            if (op[l] == 5) {
                long long ret = -1;
                for (int j = x[l]; j <= y[l]; j++) {
                    ret = max(ret, dp[j]);
                }
                ans[l] = ret;
            }
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1, dep + 1);
            dfs(mid + 1, r, i << 1 | 1, dep + 1);
        }
        clone(dp, backup[dep]);
    }

查询是在叶子上做的：op[l] == 5（也就是 QU）时把 dp[x] 到 dp[y] 的最大值取出来，全为 -1 就输出 -1。总代价是 O(m · p · log m)，p ≤ 500 时完全能接受。

四、题目3 打印所有合法数

一个长度为 n 的序列，一开始所有值都是 0。一共有 q 条操作，每条操作是 l r k：把序列 [l..r] 上每个数字加 k。你可以随意选一些操作来执行，但每条操作只能执行一次。如果你能让序列的最大值正好等于 v，那么 v 就算一个合法数。要打印 1 到 n 范围内有多少合法数，并从小到大打印它们。数据范围 k ≤ n、q ≤ 10⁴（测试链接：https://www.luogu.com.cn/problem/CF981E）。

先给后会用到的观察：所有加法都不涉及负数，所以在同一条操作的选择下，某个位置的值 = 所有覆盖它、且被选中的操作的 k 之和。

考虑一个合法数 v 是怎么来的。假设你选出一批覆盖同一个位置 i 的操作子集 T，它们让位置 i 的值变成 v。取被执行的集合 S = T，那么位置 i 的值正好是 v = Σ(k, 覆盖 i 的操作)。对于任意其他位置 j，它只被 T 中一部分操作覆盖（每个操作都覆盖 i，但不一定覆盖 j），于是位置 j 的值 ≤ v。这就是说：任何一个位置的任意子集和，都能当作最大值。反过来显然成立，所以「合法数」正好等于「某个位置上所有覆盖操作的子集和」。

于是问题变成：对每个位置，求覆盖它的操作的全部子集和。这刚好能用线段树来表达：这里不再把线段树建在时间上，而是建在位置 1 到 n 上；一条操作 [l, r] 挂到能覆盖它那些位置的 O(log n) 个节点上；dfs 沿根到某个叶子的路径走下来时，遇到的操作正好是所有覆盖该位置的操作。

集合和中拿「累加可能出现的最大值」这件事，用 bitset 做：dp 的第 x 位是 1 表示 x 能被凑出来，加入一条权值为 k 的操作就是 dp |= dp << k。这一条语句同时表达了「选它」和「不选它」两种可能。

dfs 的写法和前两题完全一致：进节点备份 bitset（这里的 backup 照样按深度开），往下 dfs 到叶子就把 dp 并进全局答案 ans。注意 ans 也是 bitset，最后从小到大扫它的每一位即可。

    
void addEdge(int i, int v) {
        nxt[++cnt] = head[i];
        to[cnt] = v;
        head[i] = cnt;
    }

    void add(int jobl, int jobr, int jobv, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobv);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobv, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobv, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void dfs(int l, int r, int i, int dep) {
        backup[dep] = dp;
        for (int e = head[i]; e > 0; e = nxt[e]) {
            dp |= dp << to[e];
        }
        if (l == r) {
            ans |= dp;
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1, dep + 1);
            dfs(mid + 1, r, i << 1 | 1, dep + 1);
        }
        dp = backup[dep];
    }

复杂度算很直接：每条操作挂在 O(log n) 个节点上，每个节点一次 bitset 移位与或运算是 O(n / 64)，于是总时间 O(q · log n · n / 64)，n、q 都是 10⁴ 量级时非常轻松。

六、最后

套路是固定的：先扫出每个元素的生效区间，拆成 O(log q) 个节点挂上，再一次 dfs 把「加入、回答、撤销」串起来。这一页的三道题 dp 各不相同（01 背包、模 p 背包、bitset 可达性），回滚全是整块拷贝。

共同点就一条：dp 数组很小，备份成本低、撤销成本高，整块拷贝最划算。下一节换到的线性基也不构成例外，只是撤销变成从插入栈里退掉最后几个基向量。
