LCT 维护边双缩点

一条无向边加进来，如果两端已经连通，图里就多出一个环，环上的点从此属于同一个边双连通分量，再也不会分开。LCT 只认树，但每次成环时把整条环上的路径并进并查集的一个代表点，图就永远是一棵「缩过点的树」。这一节的三道题，联盟的大小、边双的点权和、必经边的条数，都改成在这棵树上查询；带删除的那道，先时光倒流。

零、背景

边双连通分量的定义可以换成不含桥的说法：一个点集内部任意两点之间都存在两条没有公共边的路径。等价地，环上的所有点在同一个边双里。

静态图的边双用 tarjan 一次 DFS 就缩完了。这里是动态的：边一条条加进来，边双只会发生一件事，两个或多个旧的合并成一个，永远不会裂开。合并只会发生在「加的边两端已连通」的时刻，环恰好是当前树上那条路径加新边。逐条边处理、每次只在路径上动手，这就是 LCT 的主场。

缩点用什么记？并查集。每个边双选一个代表点，分量里所有点的 father 指过去。它不做什么复杂的事，只负责回答「这个点现在属于谁」。

一、加边成环时发生了什么

三道题的加边完全一样，写成一个 link。先把两端换成代表点 x = find(x)、y = find(y)：

  • 已经是同一个代表点：什么都不用做。
  • findroot 不同，也就是还不连通：makeroot(x) 之后 fa[x] = y，两棵树接成一棵。
  • 同一棵树但不在一个分量里：新边让 x 到 y 的树上路径加这条边成环，整条路径合并成一个边双。

第三种是关键。makeroot(x) 把 x 转成树根，接着 findroot(y) 里的 access(y) 把 y 到 x 的路径拉成实链，splay 完成后辅助树的根在 x。此时 rs[x] 是 splay 里中序在 x 深侧的那部分，恰好是环上路径里除 x 外的所有点。condense 就是对这棵右子树递归三行：father[·] = x，把代表的计数累加到 x 身上，然后 rs[x] = 0 把它们从实链上摘下来。

摘下来的点为什么不用再管？它们在 splay 里的 fa 指针还指向旧结构，但之后所有操作进门先 find，access 循环里那句 fa[x] = find(fa[x]) 会随手把沿途旧指针换成代表点。退役点自己永远不会再被单独访问。

代价也不用担心。condense 是整棵右子树递归，单次最坏和链长同阶，但每个点一生只被 condense 一次，之后只以代表点的身份出现，摊到全程是 O(n)。

二、题目1：星球联盟

n 个点、m 条无向边先给好，然后依次加入 p 条无向边。「联盟」的定义是两点之间存在两条没有公共边的路径，也就是在同一个边双里。每次加边后判断：x 和 y 不属于同一联盟打印 No，属于就打印联盟里的节点数。n、m、p 到 2×10⁵。

骨架就是上面的 link，每个代表点记一个 nodeCnt，初始为 1，condense 时把右子树各点的计数累加到 x 身上。加边后的三种结果对应三种输出：不连通，link 完返回 No；成环，condense 完返回 nodeCnt[x]；本来就在同一联盟，直接返回 nodeCnt[x]。

题目给的前 m 条边用同一个 link 处理，答案不用打印。整道题没有额外的结构，nodeCnt 是并查集上唯一多出来的信息。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    int n, m, p;

    int father[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int nodeCnt[MAXN];

    int find(int x) {
        if (x != father[x]) {
            father[x] = find(father[x]);
        }
        return father[x];
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        x = find(x);
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            fa[x] = find(fa[x]);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void condense(int x, int root) {
        if (x != 0) {
            father[x] = root;
            nodeCnt[root] += nodeCnt[x];
            condense(ls[x], root);
            condense(rs[x], root);
        }
    }

    int link(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) {
            return nodeCnt[x];
        }
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
            return -1;
        } else {
            condense(rs[x], x);
            rs[x] = 0;
            return nodeCnt[x];
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> p;
        for (int i = 1; i <= n; i++) {
            father[i] = i;
            nodeCnt[i] = 1;
        }
        for (int i = 1, x, y; i <= m; i++) {
            cin >> x >> y;
            link(x, y);
        }
        for (int i = 1, x, y; i <= p; i++) {
            cin >> x >> y;
            int ans = link(x, y);
            if (ans == -1) {
                cout << "No\n";
            } else {
                cout << ans << "\n";
            }
        }
        return 0;
    }

三、题目2：长跑

n 个点，每个点有点权，初始没有边。m 条操作：

  • 1 x y：x 和 y 之间加无向边。
  • 2 x y：把点 x 的点权改成 y。
  • 3 x y：给每条边指定方向后，希望从 x 走到 y 的过程中拿到最多的点权和，重复经过某点只算一次；不连通打印 −1。方向只影响本次操作。

n 到 1.5×10⁵，m 到 5n。

先想操作 3。指定方向后从 x 到 y，能拿到哪些点？边双内部：任意两点有两条不公共边的路径，走一条去、另一条绕回来，整块的点全都能收进口袋，和方向怎么指定无关。边双之间：缩点后的图是一棵树，路径唯一，只有路径上的块能经过。所以答案就是 x 到 y 的树上路径经过的所有边双的点权和，和不连通时的 −1。

维护三层数值：sum[x] 是代表点 x 的整个边双点权和，condense 时累加，改点权时改它；sumOfSum[x] 是辅助 splay 子树的 sum 之和，也就是整条实链上各边双的权值总和，交给 up。查询时 split(x, y)，答案就是 sumOfSum[y]。

改点权的操作 2 有个小坑：改的是原图的点 x，但 sum 挂在代表点上，所以先 find(x)。改完还要让上方的汇总值刷新：makeroot(x) 把代表点转到根，sum 加上差值，再 up 一次让 sumOfSum 跟上。

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    int n, m;

    int father[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    ll arr[MAXN];
    ll sum[MAXN];
    ll sumOfSum[MAXN];

    int find(int x) {
        if (x != father[x]) {
            father[x] = find(father[x]);
        }
        return father[x];
    }

    void up(int x) {
        sumOfSum[x] = sumOfSum[ls[x]] + sumOfSum[rs[x]] + sum[x];
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        x = find(x);
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
            fa[x] = find(fa[x]);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void condense(int x, int root) {
        if (x != 0) {
            father[x] = root;
            sum[root] += sum[x];
            condense(ls[x], root);
            condense(rs[x], root);
        }
    }

    void link(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) {
            return;
        }
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        } else {
            condense(rs[x], x);
            rs[x] = 0;
            up(x);
        }
    }

    void update(int x, int y) {
        ll delta = y - arr[x];
        arr[x] = y;
        x = find(x);
        makeroot(x);
        sum[x] += delta;
        up(x);
    }

    ll query(int x, int y) {
        x = find(x);
        y = find(y);
        if (findroot(x) != findroot(y)) {
            return -1;
        }
        split(x, y);
        return sumOfSum[y];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            father[i] = i;
            cin >> arr[i];
            sum[i] = arr[i];
            sumOfSum[i] = arr[i];
        }
        for (int i = 1, op, x, y; i <= m; i++) {
            cin >> op >> x >> y;
            if (op == 1) {
                link(x, y);
            } else if (op == 2) {
                update(x, y);
            } else {
                cout << query(x, y) << "\n";
            }
        }
        return 0;
    }

四、题目3：航线规划

n 个点、m 条无向边，任何时刻图连通、无重边。q 条操作：

  • 0 x y：删除 x 和 y 之间的直接边。
  • 1 x y：查询 x 到 y 之间有多少条必经边。

n 到 3×10⁴，m 到 10⁵，q 到 4×10⁴。必经边就是桥：删掉它两端就不连通的边。

删边不好做，倒过来做。把所有操作先扫一遍，凡是会被删掉的边都标出来；把剩下的边先 link 好成树，此时每个点自成边双。然后从最后一个操作倒着走：原操作是删边，倒放就是加边，加边可能触发缩点；原操作是查询，倒放时图恰好是「正序那个时刻」的图，答案当场算出来，存进数组，最后正序输出。

查询算什么。缩点后的图是树，x 到 y 的必经边就是树上路径横跨的桥。路径上相邻两个边双之间恰好一条桥，所以必经边数等于路径上的边双数减一。给辅助 splay 维护 ebcc[x]：子树里代表点的个数，up 一行搞定。split(x, y) 之后答案是 ebcc[y] - 1；find 完两端相同就是同一个边双，答案 0。

删边用 map 按端点对找到边的编号：先加进边表时把 (小端点, 大端点) 存进 map，操作 0 查这个 pair 拿到编号，标记删除。输入以 −1 结尾。

时光倒流：删边变加边，环变成块

左边是两个三角形 1-2-3、4-5-6 用桥 D 相连的图。正序操作：查 2 到 5、删 1-3、查 2 到 6、删 4-5、查 2 到 6。下面从右往左倒放：先把 C、E 拿掉建好树，再一步步把删掉的边加回来，查询的答案在倒放里读出来。

还在图里的边 本次倒放加回的边 查询高亮的路径

                    queryAns[j--] = ebcc[y] - 1;
                }
            }
        }
        for (int i = 1; i <= queryCnt; i++) {

        }
        return 0;

五、复杂度分析

设 n 为点数，m 为边数，q 为操作数。三个题的 link 是同一个：

操作时间复杂度
加边（不连通，直接连）O(log n) 均摊
加边（成环，condense）O(log n) 均摊
condense 的总量（全程）O(n)，每点只缩一次
findO(α(n)) 均摊

六、最后

这一页的骨架比看上去还小：LCT 负责找环、缩环，并查集负责记住「谁在哪个块里」，两层结构各干一件事。

星球联盟数块里的点，长跑算块上的权和，航线规划数路径跨过的块减一。三道题的 link 一字不差，变的只是挂在代表点身上的那个数值。
