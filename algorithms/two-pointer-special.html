双指针：分区与归位

还有一类双指针用指针当边界把数组切成几块区域，一边扫一边搬运。按奇偶排序用尾部当仓库，缺失的第一个正数用 l/r 切出归位区和垃圾区。

零、背景

前面两页的双指针都在「走」：同向一起走、快慢差速走、两头往中间走。这一页的两个题，指针的意义是「边界」：一块区域已处理完、一块区域待处理、一块区域是垃圾，两个指针一夹，中间就是工作区。

先看一个分拣题，再看一个区域题。

一、按奇偶排序数组 II（LeetCode 922）

数组一半是奇数一半是偶数，要求偶数待在偶数下标、奇数待在奇数下标。注意这里不用排序，只要每个位置奇偶对，怎么排列都行。

odd 指向下一个要填奇数的位置（从 1 开始，每次 +2），even 指向下一个要填偶数的位置（从 0 开始，每次 +2）。数组尾部 nums[n−1] 当待分拣的仓库：每次看仓库里那个数，奇数 swap 到 odd 坑、odd += 2，偶数 swap 到 even 坑、even += 2。坑里的数被换到尾部，继续当仓库。

循环条件是 odd < n && even < n：只要还有坑没填满就继续。为什么不会把已经填好的坑再换乱：odd、even 只往前进，换到尾部的是坑里原来那个数，它还没被处理过。

vector<int> sortArrayByParityII(vector<int>& nums) {
        int n = nums.size();
        for (int odd = 1, even = 0; odd < n && even < n;) {
            if ((nums[n - 1] & 1) == 1) {
                swap(nums[odd], nums[n - 1]);
                odd += 2;
            } else {
                swap(nums[even], nums[n - 1]);
                even += 2;
            }
        }
        return nums;
    }

实测：n=2e6 随机数组 11.67ms。

二、缺失的第一个正数（LeetCode 41）

找没出现的最小正整数，要求 O(n) 时间、O(1) 空间。排序是 O(n log n)，计数数组要 O(n) 空间，都不合格。可行的思路是把每个正数放到它该在的位置：数字 x 应该待在 x−1 号位置，然后从头找第一个「位置和数字对不上」的下标。

l 的左边是归位区：i 位置放着 i+1。r 的右边是垃圾区。中间 [l, r) 是待检查区。循环里永远盯着 arr[l] 看：

三种情况：arr[l] == l+1，正好归位，l++ 扩大归位区。arr[l] 是垃圾，swap 到垃圾区、r−−。否则把它交换到该去的位置 swap(arr[l], arr[arr[l]−1])，新换来的数继续看。

垃圾的判据三个，漏一个都会错：arr[l] ≤ l，说明 1 到 l 已经收集全，这个数太小装不下；arr[l] > r，超过「最好情况」的容量；arr[arr[l]−1] == arr[l]，目标位置已经有同样的值，留一个就够，重复的丢掉。

int firstMissingPositive(vector<int>& arr) {
        int l = 0;
        int r = arr.size();
        while (l < r) {
            if (arr[l] == l + 1) {
                l++;
            } else if (arr[l] <= l || arr[l] > r || arr[arr[l] - 1] == arr[l]) {
                swap(arr[l], arr[--r]);
            } else {
                swap(arr[l], arr[arr[l] - 1]);
            }
        }
        return l + 1;
    }

结束时 l 是第一个没归位的位置，答案 l+1。实测：n=1e6 混合正负 2.73ms。

三、复杂度分析

题目时间复杂度额外空间
按奇偶排序数组 IIO(n)O(1)
缺失的第一个正数O(n)，每步至少推进 l 或 r 一格O(1)

两个题每轮循环都至少让一个指针前进，总步数 O(n)。交换操作 O(1)。

总结

这两个题指针的功能是「切区域」：按奇偶排序把尾部当仓库、两个坑指针分拣；缺失的第一个正数用 l/r 切出归位区和垃圾区，数要么归位、要么进垃圾区、要么换到该去的位置。共同点是想清楚「谁已处理、谁待处理、谁是垃圾」三块区域的边界，指针只是边界的标记。

双指针四类至此齐了：同向靠单调性、快慢靠环结构、两头靠排除、分区靠边界。做题时先问一句：这个题的两个指针，凭什么这样动？
