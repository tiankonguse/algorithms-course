跳表：静态数组实现有序表

AVL 树靠旋转保证平衡，跳表换一条路：让骰子决定每个节点占几层，期望层数 O(log n)，查询从顶层开始一层层往下跳。随机化把「数据顺序决定结构」这层耦合拆掉了。就算输入是严格升序，跳表结构也不退化。

零、背景

有序表要支持六种操作，单次 O(log n)：增加 x（重复加入算词频）、删除 x（多个只删一个）、查询 x 的排名（比 x 小的个数 + 1）、查询排名第 k 的数、前驱、后继。

上一讲的 AVL 树用左右子树高度差 ≤ 1 把树压平，查询从根往下走。跳表不用树：它是一摞有序链表，底层装着全部元素，上面每层按概率稀疏化。查找一个数，从最上层开始，能跳就跳，跳不过去就降一层，到底层时已经离目标很近了。

为什么值得这么做？二叉搜索树最怕一种输入：按有序顺序插入，树直接退化成链表，O(log n) 变 O(n)。跳表把「结构长什么样」的决定权从数据手里拿过来，交给随机层数。数据再刁钻，结构分布依然稳定。代价是期望意义上的 O(log n)，不是最坏保证。

一、跳表长什么样

每个节点除了值，还有一个随机层数。层数 1 的节点只在最底层出现；层数 L 的节点在下面 L 层都出现。最底层是一条完整的有序链表，越往上节点越少。

上图是插入 2, 5, 8, 11, 14, 17 后的一个可能形态：17 层数 4（每层都在），2 层数 1（只占底层）。层数怎么来？抛硬币，小于 0.5 就加一层，直到抛到大的或撞上限 MAXL：

int randomLevel() {
    int ans = 1;
    while ((rand() / double(RAND_MAX)) < 0.5) {
        ans++;
    }
    return min(ans, MAXL);
}

期望层数是 2（P(层 ≥ k) = 0.5^(k-1)），第 k 层期望放 n / 2^(k-1) 个节点。这就是复杂度分析的起点。

二、静态数组怎么装

竞赛里不用指针结构，跳表照旧开静态数组。节点从 1 号开始用，0 表示空指针（没有节点）：

const int MAXL = 20;      // 层数上限
const int MAXN = 100001;  // 最大操作数，节点数不会超过它

int cnt;                 // 已用的节点个数
int key[MAXN];           // 节点的值
int key_count[MAXN];    // 词频：这个值出现过几次
int level[MAXN];        // 每个节点的层数
int next_node[MAXN][MAXL + 1];  // next_node[i][h]：i 在第 h 层的后继节点编号
int len[MAXN][MAXL + 1];         // len[i][h]：i 到 next_node[i][h] 这条边跨过多少个元素

1 号节点是哨兵：值 INT_MIN、层数 MAXL，所有查询和修改从它出发。build() 建好哨兵，clear() 把用过的空间清零再把 cnt 归 0。跑多组数据时跳表支持反复重建。

next_node[i][h] 是二维数组，[MAXN][MAXL+1] 最坏 10 万 × 21 个 int，约 8 MB，完全装得下。跳表的「指针」就是数组下标，找后继是查表，不是解引用。

三、len 数组：一条边跨过几个元素

排名和按排名取值都要知道「跳过去多少元素」，所以每条边额外记一个长度。语义要分两层看：

  • 最底层：len[i][1] 是 next_node[i][1] 那个节点的词频。底层的边通向一个具体元素，跨过个数就是它的词频。
  • 更高层：len[i][h] 是这一跳覆盖的区间里，底层元素的总个数（词频都算）。上图的第二层链，哨兵到 2 跨过底层两个「2」，len = 2；2 到 7 跨过 [5, 7, 7] 三个元素，len = 3。

查询 x 排名时把沿途的 len 累加，得到比 x 小的元素个数，加 1 就是排名。这就是 getRank 的原料。

四、查询：从顶层往下跳

find(i, h, num) 在 i 的第 h 层找 num：当前层的后继值小于 num 就一直往右走，走不动就降一层继续，到底层时精确匹配。核心循环只有一句：

int find(int i, int h, int num) {
    while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
        i = next_node[i][h];
    }
    if (h == 1) {
        if (next_node[i][h] != 0 && key[next_node[i][h]] == num) {
            return next_node[i][h];
        } else {
            return 0;
        }
    }
    return find(i, h - 1, num);
}

查 11：第 3 层（这层只有 5 和 11）从哨兵跳到 5，5 的下一个就是 11，走不动；降第 2 层从 5 出发，5 先跳到 8（8 < 11），8 的下一跳是 11，又走不动；降到底层，底层 8 的后继正好是 11，命中。每层只做常数次比较，从第 20 层降到第 1 层总共 O(log n) 步。

其他三个查询同套路：

  • small(i, h, num)：和 find 一样往右走，但沿途把 len 累进 rightCnt，返回比 num 小的个数。getRank(num) = small(1, MAXL, num) + 1。
  • index(x)：查排名第 x 的数。维护已累计个数 c，当 c + len[i][h] < x 就跳这条边（把整个区间都算进 c），否则降层，底层返回所在节点的 key。
  • pre(num)：前驱。到底层时停下的位置如果就是哨兵（i == 1），说明没有前驱，返回 INT_MIN；否则 key[i] 就是比 num 小的最大数。
  • post(num)：后继。底层停在的位置如果后继为空返回 INT_MAX；有个细节：如果 key[next_node[i][1]] == num（num 自己就在下一格），要再往后走一步才是真正比 num 大的数。课程代码专门处理了这一格。

五、增加与删除

增加分两路：

  • find 找到 num 已存在：addCount 从顶层到底层逐层把路径上的 len 加 1，并给底层那个节点的 key_count 加 1。词频 +1，结构不动。
  • 找不到：新开节点 cnt + 1，randomLevel 定层数，addNode 逐层把它链进每层链表，同时维护 len。这里有个关键账：addNode(i, h, j) 返回 rightCnt（第 h 层跳过的元素数），递归往下一层插入后拿回 downCnt，于是新边 j 的 len[j][h] 和旧边被拆成两段的 len[i][h] 都能算出来，不需要重扫底层。完整代码在文末。

删除对称：词频大于 1 时 removeCount 沿路径把 len 减 1、底层词频减 1；词频只剩 1 时 removeNode 逐层把 j 从链表摘掉（h > level[j] 的层本来就该没有 j，只减 len），底层拼接两段，len 用 len[i][h] += len[j][h] - 1 合回来。

跳表的删除比 AVL 省心一大截：AVL 删节点可能要旋转好几处恢复平衡，跳表删除就是纯链表摘除，没有「删完重新平衡」这一步。这是随机结构的一大红利。

六、复杂度

每层期望节点数减半：第 1 层 n 个、第 2 层 n/2、第 3 层 n/4……层数超过 log2 n 的概率极小。一次查询从顶层下降，每层往右走常数步，期望步数 O(log n)。

演示·随机层数：抛硬币决定每个节点占几层

上图把「随机化」摊开看：每个节点层数由一轮抛硬币决定（小于 0.5 就加一层）。全部插完后，第 1 层有全部节点，第 2 层只有约一半，第 3 层约四分之一。增删改查都在这摞链上走，期望 O(log n)。最坏情况（连续抛出一堆大）概率指数级小，实际不用管。

大厂笔试、算法竞赛要用有序表时，跳表、AVL、替罪羊、Treap、FHQ Treap、Splay 会一种就够用；跳表实现最直白，静态数组版总共 200 多行。

题1 完整实现

下面是洛谷 P3369「普通平衡树」的完整解法。测试时把类名改成 Main。静态数组跳表，含增加、删除、排名、按排名取数、前驱、后继六种操作。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXL = 20;
    const int MAXN = 100001;

    int cnt;
    int key[MAXN];
    int key_count[MAXN];
    int level[MAXN];
    int next_node[MAXN][MAXL + 1];
    int len[MAXN][MAXL + 1];

    void build() {
        cnt = 1;
        key[cnt] = INT_MIN;
        level[cnt] = MAXL;
    }

    void clear() {
        memset(key + 1, 0, cnt * sizeof(int));
        memset(key_count + 1, 0, cnt * sizeof(int));
        memset(level + 1, 0, cnt * sizeof(int));
        for (int i = 1; i <= cnt; i++) {
            memset(next_node[i], 0, (MAXL + 1) * sizeof(int));
            memset(len[i], 0, (MAXL + 1) * sizeof(int));
        }
        cnt = 0;
    }

    int randomLevel() {
        int ans = 1;
        while ((rand() / double(RAND_MAX)) < 0.5) {
            ans++;
        }
        return min(ans, MAXL);
    }

    int find(int i, int h, int num) {
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            i = next_node[i][h];
        }
        if (h == 1) {
            if (next_node[i][h] != 0 && key[next_node[i][h]] == num) {
                return next_node[i][h];
            } else {
                return 0;
            }
        }
        return find(i, h - 1, num);
    }

    void addCount(int i, int h, int num) {
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            i = next_node[i][h];
        }
        if (h == 1) {
            key_count[next_node[i][h]]++;
        } else {
            addCount(i, h - 1, num);
        }
        len[i][h]++;
    }

    int addNode(int i, int h, int j) {
        int rightCnt = 0;
        while (next_node[i][h] != 0 && key[next_node[i][h]] < key[j]) {
            rightCnt += len[i][h];
            i = next_node[i][h];
        }
        if (h == 1) {
            next_node[j][h] = next_node[i][h];
            next_node[i][h] = j;
            len[j][h] = key_count[next_node[j][h]];
            len[i][h] = key_count[next_node[i][h]];
            return rightCnt;
        } else {
            int downCnt = addNode(i, h - 1, j);
            if (h > level[j]) {
                len[i][h]++;
            } else {
                next_node[j][h] = next_node[i][h];
                next_node[i][h] = j;
                len[j][h] = len[i][h] + 1 - downCnt - key_count[j];
                len[i][h] = downCnt + key_count[j];
            }
            return rightCnt + downCnt;
        }
    }

    void add(int num) {
        if (find(1, MAXL, num) != 0) {
            addCount(1, MAXL, num);
        } else {
            key[++cnt] = num;
            key_count[cnt] = 1;
            level[cnt] = randomLevel();
            addNode(1, MAXL, cnt);
        }
    }

    void removeCount(int i, int h, int num) {
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            i = next_node[i][h];
        }
        if (h == 1) {
            key_count[next_node[i][h]]--;
        } else {
            removeCount(i, h - 1, num);
        }
        len[i][h]--;
    }

    void removeNode(int i, int h, int j) {
        if (h < 1) {
            return;
        }
        while (next_node[i][h] != 0 && key[next_node[i][h]] < key[j]) {
            i = next_node[i][h];
        }
        if (h > level[j]) {
            len[i][h]--;
        } else {
            next_node[i][h] = next_node[j][h];
            len[i][h] += len[j][h] - 1;
        }
        removeNode(i, h - 1, j);
    }

    void remove(int num) {
        int j = find(1, MAXL, num);
        if (j != 0) {
            if (key_count[j] > 1) {
                removeCount(1, MAXL, num);
            } else {
                removeNode(1, MAXL, j);
            }
        }
    }

    int small(int i, int h, int num) {
        int rightCnt = 0;
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            rightCnt += len[i][h];
            i = next_node[i][h];
        }
        if (h == 1) {
            return rightCnt;
        } else {
            return rightCnt + small(i, h - 1, num);
        }
    }

    int getRank(int num) {
        return small(1, MAXL, num) + 1;
    }

    int index(int i, int h, int x) {
        int c = 0;
        while (next_node[i][h] != 0 && c + len[i][h] < x) {
            c += len[i][h];
            i = next_node[i][h];
        }
        if (h == 1) {
            return key[next_node[i][h]];
        } else {
            return index(i, h - 1, x - c);
        }
    }

    int index(int x) {
        return index(1, MAXL, x);
    }

    int pre(int i, int h, int num) {
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            i = next_node[i][h];
        }
        if (h == 1) {
            return i == 1 ? INT_MIN : key[i];
        } else {
            return pre(i, h - 1, num);
        }
    }

    int pre(int num) {
        return pre(1, MAXL, num);
    }

    int post(int i, int h, int num) {
        while (next_node[i][h] != 0 && key[next_node[i][h]] < num) {
            i = next_node[i][h];
        }
        if (h == 1) {
            if (next_node[i][h] == 0) {
                return INT_MAX;
            }
            if (key[next_node[i][h]] > num) {
                return key[next_node[i][h]];
            }
            i = next_node[i][h];
            if (next_node[i][h] == 0) {
                return INT_MAX;
            } else {
                return key[next_node[i][h]];
            }
        } else {
            return post(i, h - 1, num);
        }
    }

    int post(int num) {
        return post(1, MAXL, num);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        srand(time(0));
        build();
        int n;
        cin >> n;
        for (int i = 1, op, x; i <= n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        clear();
        return 0;
    }

总结

1）跳表 = 多层有序链表，底层全量、上层稀疏，节点层数由抛硬币决定；2）next_node[i][h] 存第 h 层后继，len[i][h] 存这条边跨过的元素个数（底层是词频）；3）find / small / index / pre / post 都是「上层大步走、走不动降层」一个套路；4）增加删除都是链表操作，词频单独记，删除没有平衡修复这一步；5）期望 O(log n)：第 k 层期望 n / 2^(k-1) 个节点，随机化把最坏输入挡在门外。下一讲替罪羊树是「不旋转、整棵重建」的另一种平衡思路。
