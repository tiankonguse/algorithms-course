洗牌：位置乘 2，逆元还原牌面

n 张牌每次按「右堆第 i 张在前、左堆第 i 张在后」重新排列，问洗 m 次后第 l 张是什么牌面。n、m 都给到 1e10，模拟一次都嫌多。看穿洗牌是「位置乘 2」之后，问题变成一次逆元计算。

零、背景

n=6，初始 1 2 3 4 5 6。洗一次：左堆 1 2 3、右堆 4 5 6，右堆第 i 张在前左堆第 i 张在后，得到 4 1 5 2 6 3。再洗一次 2 4 6 1 3 5，第三次回到 1 2 3 4 5 6。

问的是洗 m 次后第 l 张是谁。m 到 1e10，逐次洗牌不可能。把洗牌看成位置变化：每张牌洗一次去了哪个位置？规律很干净，新位置是旧位置的 2 倍。

一、洗牌是位置乘 2

原位置 p，洗一次后去 2p mod (n+1)。验证 n=6：原位置 1 的牌去位置 2，2 去 4，3 去 6，4 去 1（8 mod 7），5 去 3（10 mod 7），6 去 5（12 mod 7）。和上面的排列一一对上。

为什么：位置 p ≤ n/2 在左堆，交叉后新位置是第 2p 位；位置 p > n/2 在右堆，设 p = n/2 + i，新位置是第 2i−1 位，即 2p − n − 1 = 2p − (n+1)。两段统一成 2p mod (n+1)。

洗 m 次就是位置连续乘 m 次 2：初始在第 x 位的牌，洗 m 次后在第 x·2^m mod (n+1) 位。题目给的是「第 l 张牌的牌面」：设牌面为 x，它在洗 m 次后落到位置 l，所以 x·2^m ≡ l (mod n+1)。

n 是偶数，n+1 是奇数，2^m 与 n+1 一定互质，逆元存在：x = l·(2^m)^{-1} mod (n+1)。求逆元用上一页的扩展欧几里得，这里不要求模是质数。

二、大数：龟速乘与快速幂

2^m 是天文数字，只能模意义下算。但 n+1 到 1e10+1，模意义下做乘法 a·b 时 a、b 都是 1e10 量级，乘积 1e20 超 long long 上限 9.2e18，直接乘溢出。解法是龟速乘：把 b 拆成二进制，边加倍边取模，每次只加两个 < 2^31 的数，绝不溢出。

long long multiply(long long a, long long b, long long mod) {
      a = (a % mod + mod) % mod;
      b = (b % mod + mod) % mod;
      long long ans = 0;
      while (b != 0) {
        if ((b & 1) != 0) {
          ans = (ans + a) % mod;
        }
        a = (a + a) % mod;
        b >>= 1;
      }
      return ans;
    }

龟速乘把一次乘法拆成 O(log b) 次加法取模。求 2^m 用快速幂，里面的乘法全部换成龟速乘：

long long power(long long a, long long b, long long mod) {
      long long ans = 1;
      while (b > 0) {
        if ((b & 1) == 1) {
          ans = multiply(ans, a, mod);
        }
        a = multiply(a, a, mod);
        b >>= 1;
      }
      return ans;
    }

三、exgcd 求逆元，答案一次乘出

compute(n, m, l)：mod = n+1，先算 pow2 = power(2, m, mod)，再 exgcd(pow2, mod) 得到特解 x，满足 x·pow2 + y·mod = 1，也就是 x 是 pow2 在模 mod 下的逆元。(x % mod + mod) % mod 调成正数。最后 multiply(x0, l, mod) 就是牌面。

long long compute(long long n, long long m, long long l) {
      long long mod = n + 1;
      exgcd(power(2, m, mod), mod);
      long long x0 = (x % mod + mod) % mod;
      return multiply(x0, l, mod);
    }

n=6、m=1、l=3：mod=7，2^1=2，exgcd(2,7) 得 x=−3，逆元 x0=(−3+7)=4（2·4=8≡1 mod 7）。答案 3·4 mod 7 = 5，洗一次后第 3 张是 5，与排列 4 1 5 2 6 3 一致。

复杂度分析

项目时间复杂度空间复杂度
洗牌（P2054）O(log m · log M)O(log M) 递归栈

快速幂 O(log m) 轮，每轮龟速乘 O(log M)，M = n+1 ≤ 1e10+1 只有 34 位；exgcd 也是 O(log M)。总操作几十次大数加法取模。

总结

洗牌的本质是位置乘 2 mod (n+1)，洗 m 次是乘 2^m，逆元把「位置推牌面」翻回来。n 到 1e10 时乘法溢出，龟速乘按二进制拆乘数、快速幂按二进制拆指数，两者配合把 O(m) 洗牌压成 O(log m · log M)。
