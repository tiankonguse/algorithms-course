二项式定理与杨辉三角

(a+b)^n 展开成 n+1 项，第 k 项的系数是 C(n,k)。这个定理背下来容易，证明起来也不难：数学归纳法六步，每一步都只是初等代数。当 a=b=1，系数排出来就是杨辉三角，也是组合数的打表来源。

零、二项式定理

二项式定理说的是：

(a+b)n = Σk=0..n C(n,k)·an−k·bk

其中 C(n,k) = n! / (k!·(n−k)!)。n=2 时展开 (a+b)² = a² + 2ab + b²，系数 1、2、1 正是 C(2,0)、C(2,1)、C(2,2)。这个定理对所有非负整数 n 成立，证明用数学归纳法：

关键在第 4、5 步。第 4 步把 b 那半边的和式做换元 k' = k+1，让两项的 a、b 指数对齐；第 5 步合并时冒出来的 C(m,k)+C(m,k−1) 正好等于 C(m+1,k)（帕斯卡恒等式），于是系数表自己递推出来了。证明里唯一用到的组合数性质就是这个恒等式。

一、a=b=1：杨辉三角与组合恒等式

把 a=1、b=1 代进去，(1+1)ⁿ = 2ⁿ = Σ C(n,k)。展开的前几行系数排出来就是杨辉三角，也叫帕斯卡三角：

三角的加法规则 C(i,j) = C(i−1,j) + C(i−1,j−1) 就是上面证明第 5 步的帕斯卡恒等式。它直接给出一条 O(n²) 建表、O(1) 查询组合数的路：把 C(i,j) 全填进一张 n×n 的表，要哪个查哪个。n 小时打表最省事，n 大了换阶乘余数表那套（下一页讲）。

演示 · 打表：C(i,j) = C(i−1,j) + C(i−1,j−1) 逐格填

二、题1 杨辉三角（P5732）

给定 n ≤ 20，打印杨辉三角前 n 行。直接用上面的打表：每行首尾先填 1，中间按组合恒等式递推。n=20 时中间最大的 C(19,9)=92378，int 装得下，用 long long 更稳。

#include <bits/stdc++.h>
    using namespace std;

    // 打印杨辉三角前 n 行，n <= 20
    int main() {
      int n;
      cin >> n;
      long long tri[20][20] = {};
      // 每行首尾是 1
      for (int i = 0; i < n; i++) {
        tri[i][0] = tri[i][i] = 1;
      }
      // 组合恒等式 C(i,j) = C(i-1,j) + C(i-1,j-1)
      for (int i = 1; i < n; i++) {
        for (int j = 1; j < i; j++) {
          tri[i][j] = tri[i - 1][j] + tri[i - 1][j - 1];
        }
      }
      for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
          cout << tri[i][j] << " ";
        }
        cout << "\n";
      }
    }

两层循环 O(n²)，n ≤ 20 完全没压力。这道题是打表路线的起点：表建好之后，任意 C(i,j) 都是 O(1)。

总结

二项式定理 (a+b)ⁿ = Σ C(n,k)·an−k·bk 用数学归纳法证明：基例 n=1，假设 n=m，展开 (a+b)^(m+1)，换元对齐指数，再用帕斯卡恒等式 C(m,k)+C(m,k−1)=C(m+1,k) 合并，六步收工。证明里唯一的新东西就是这个恒等式，它同时就是杨辉三角的加法规则，也是打表求组合数的依据。下一页把 n 放大到 10⁵ 量级，打表 O(n²) 扛不住时，换阶乘余数表和阶乘逆元表。
