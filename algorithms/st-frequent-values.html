区间里出现次数最多的数

数组已经排好序，反复问「这一段里出现次数最多的那个数，出现了几次」。如果数组无序，这题没什么好办法；有序这个条件一加，相同值必然连成一段，问题就变成查「最长的一段有多长」了。

零、问题

给定长度 n 的有序数组，m 次询问 [l, r]，每次要这段里出现次数最多的值的出现次数。数组全程不改。n 到 10⁵，询问次数远大于 n。

每次扫一遍区间是最直接的答案：从头数到尾，记下当前这段连续相同的值有多长，取最大。一次 O(区间长度)，问一百万次就没法看了。实测 n 等于 10⁵ 时，一次随机查询平均 11 微秒。

一、游程编码：把相同的值压成一段

数组有序，所以相同的值一定挨着。扫一遍，把每一段连续相同的值记下左端点和右端点，顺便给每个位置打上它属于第几段的标签。这一步 O(n)，做完之后数组被压成了「若干段 + 每段的长度」。

第一个位置要特判，否则它会跟一个不存在的「前一段」比较。常见做法是给 arr[0] 填一个数据里不会出现的哨兵值，这样第一次比较必然不相等，第一段自然开出来。题目值域是 −10⁵ 到 10⁵ 时，填 −23333333 这种数就够。

const int MAXN = 100001;
    const int LIMIT = 17;
    int arr[MAXN], log2[MAXN];
    // bucket[i] : i 位置落在第几段；leftB / rightB : 每一段的左右端点
    int bucket[MAXN], leftB[MAXN], rightB[MAXN];
    int stmax[MAXN][LIMIT];
    int cnt;

    // 游程编码：相同值连成一段，段长进 ST 表
    void build(int n) {
        arr[0] = -23333333;           // 哨兵，保证第 1 个位置一定开出一段
        cnt = 0;
        for (int i = 1; i <= n; i++) {
            if (arr[i - 1] != arr[i]) {
                rightB[cnt] = i - 1;
                leftB[++cnt] = i;
            }
            bucket[i] = cnt;
        }
        rightB[cnt] = n;
        log2[0] = -1;
        for (int i = 1; i <= cnt; i++) {
            log2[i] = log2[i >> 1] + 1;
            stmax[i][0] = rightB[i] - leftB[i] + 1;
        }
        for (int p = 1; p <= log2[cnt]; p++) {
            for (int i = 1; i + (1 << p) - 1 <= cnt; i++) {
                stmax[i][p] = max(stmax[i][p - 1], stmax[i + (1 << (p - 1))][p - 1]);
            }
        }
    }

点「下一步」逐个位置扫过去，橙色是当前位置，颜色交替标出不同的段，下方一栏是该位置属于第几段。可以换五组数据，试试全相同和全不同两种极端。

段长直接当成第 0 层填进 ST 表，表按段数 cnt 开行：n 等于 10⁵、随机数据下游程数 4865 时，表是 4865 行 × 13 列，6.3 万个 int，0.24 MB。值重复得越多，段越少，表越小。

二、查询：拆成三段

询问 [l, r] 落在哪两段里，一眼就能查出来：看 bucket[l] 和 bucket[r]。三种情况。

两段是同一段，说明整个询问泡在一个游程内部，答案就是长度 r - l + 1，没有别的可说。

两段相邻，答案是左边那段被切剩多少、右边那段被切剩多少，取大的那个。中间没有完整段，不涉及 ST 表。

中间还夹着完整的段，就要在「左边残留、右边残留、中间整段的最大值」三者里取最大。中间那段用 ST 表 O(1) 查出最长的一段有多长。

// 三段拼：左边一截、右边一截、中间整段查 ST
    int query(int l, int r) {
        int lb = bucket[l], rb = bucket[r];
        if (lb == rb) {                       // 整个询问落在一段里
            return r - l + 1;
        }
        int a = rightB[lb] - l + 1;           // 左边那一段被切剩多少
        int b = r - leftB[rb] + 1;            // 右边那一段被切剩多少
        int c = 0;
        if (lb + 1 < rb) {                    // 中间还夹着完整段
            int from = lb + 1, to = rb - 1;
            int p = log2[to - from + 1];
            c = max(stmax[from][p], stmax[to - (1 << p) + 1][p]);
        }
        return max(max(a, b), c);
    }

边界那两个式子要盯准。左边残留是 rightB[lb] - l + 1（从左端点所在段的右端往回数），右边残留是 r - leftB[rb] + 1。中间整段的下标是 lb + 1 到 rb - 1，只有 lb + 1 < rb 时才存在，这个判断省不得。

点「下一步」看一次查询怎么拆：先定两端落在第几段，再算左边残留、右边残留、中间整段，最后三者取最大。可以换五组询问，包含同段与相邻段两种退化情况。

把「截端点」这三行拿掉、直接拿 bucket[l] 到 bucket[r] 去查 ST 表，是最常见的错法。实测 9 万次随机查询，82.96% 会算错，错在把询问之外的元素也算进了某一段的长度。

三、为什么中间那段能 O(1)

中间是若干个完整的游程，要的是它们的长度最大值。这正是可重复贡献问题：取最大值时，两段有重叠也不影响结果。于是照那套 ST 表模板办：第 0 层是段长，第 p 层由两个第 p−1 层取最大，查询拿两个长度 2 的 p 次方的区间盖住询问。

到这里能看出这道题的形状：有序带来的游程编码负责把「众数」翻译成「最长的一段」，ST 表负责在 O(1) 里回答「这一段区间里最长的一段多长」。两件事各管一段，拼起来就是答案。

五、总结

这道题的关键一步在预处理：数组有序，相同值连成游程，把每一段的左右端点和长度记下来，「出现次数最多的数出现几次」就变成了「这一段里最长的一段有多长」。段长进 ST 表，查询 O(1)。

查询要分成三种情况处理：询问落在同一段里、跨相邻两段、跨三段以上。中间夹着的完整段查 ST 表，两端被切开的残留单独算，三者取最大。省掉端点处理的写法会让 82.96% 的查询算错。

哨兵那一行别忘：arr[0] 要填一个数据里不会出现的值，否则第一段开不出来，bucket[1] 会落错段。
