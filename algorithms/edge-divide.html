边分治

树上路径统计的另一种分治。点分治每次围绕一个重心点讨论跨过它的路径，边分治每次围绕一条重心边讨论跨过它的路径。这一页讲重心边怎么找、为什么要三度化重构，然后做两道题：BZOJ2870 最长道路tree 和 CF833D 红黑蛛网。分治过程里那条二叉的递归结构，下一页会把它做成边分树。

零、背景

点分治是这类题的主力：每次删掉一个重心点，统计跨过它的所有路径。它的前置是点分治上下和点分树三讲，这里不展开，只对照着讲差异。

边分治换个删法：每次删掉一条重心边，统计跨过这条边的所有路径。解决问题的类型几乎相同，都是路径、点对统计。

代价是要先做一次三度化重构，所以边分治更冷门。好处是每次只面对两个连通区：点分治在重心点处要按顺序处理多棵子树，防止复杂度爆炸；边分治没有这个问题，因为就两份信息，直接拼。

一、问题

给一棵 n 个点的树，问所有路径、所有点对的某种统计量。题目规模到 5×10⁴ 甚至 10⁵，逐对枚举行不通。

分治的想法是：切一条边，跨过这条边的路径在这一刻统计最方便，两侧各自收集信息，拼起来就是完整路径。之后两侧各自递归。

于是关键变成：怎么切，才能让每一层切完两侧都别太大。

二、朴素做法

枚举所有点对，逐条算路径上的指标。n = 5×10⁴ 时约 1.25×10⁹ 对，n = 10⁵ 时更多，都会超时。

分治的出路在于：不枚举点对，而是让每条路径恰好在「跨过某条被删的边」时被统计一次。要做到不重不漏，只需要每条路径统计一次的时机唯一，它第一次被分开的那一刻。

三、重心边

定义和重心点对称：一条边把树切成两个连通区，让较大一侧的规模尽可能小，这样的边叫重心边。

树上任何点的度数不超过 3 时，性质很好。重心边的一个端点就是树的重心点；重心点通向最大子树的那条边就是重心边，并列时随便挑一条。切完之后较大一侧不超过 2n/3，每层至少消掉三分之一，分治层数 O(log n)。

普通树不一定有这么好的边。最坏的是菊花图：中心挂着一片叶子，切任何一条边都是 1 | n-1，较大侧几乎不缩小，层数退化成 O(n)。

四、三度化重构

先把树重建成「任何点度数不超过 3」的形态。做法是对儿子多的点 u：第一个儿子直连 u，后面的儿子通过虚点 p1、p2……串成链挂上去。重建后点数至多翻倍。

虚点和虚边的设置按题目来。题 1 里虚点复制 u 的点权、虚边权 0：链经过 u 时最小值不变，链上点数（距离 + 1）也不虚增。题 2 里虚边权 1、颜色不设：乘积和红黑计数都不受影响。

边的编号沿用链式前向星那套：从 2 开始，正反两条边编号相邻。边 e 的反向边是 e ^ 1，这条无向边的组号是 e >> 1。vis[组号] 标记已经当过重心边的边，找重心边时直接跳过。

找重心边分两步。先 getSize 算出当前连通区的规模，然后从任意点出发：只要某个邻居一侧超过总数的一半，就走进去。走不动时停在重心点，取它通向最大子树的那条边。

五、递归的样子

整个流程在一棵 7 个点的树上走一遍。每一步先点亮当前连通区，选出重心边（橙色），两侧染成不同颜色，然后两侧各自递归，直到全部变成单点。

六、题目1：最长道路tree

n 个点组成一棵树，每个点有点权。任何一条链的指标 = 链上节点数 × 链上节点的最小点权，打印最大指标。1 ≤ n ≤ 5×10⁴。

样例：3 个点，权值 5 3 5，边 1-2、1-3，答案是 min(5, 5) × 2 = 10。

三度化时虚点复制点权、虚边权 0。于是重心边两侧收集的信息只有两样：到边的距离、路径上的最小点权。一条跨边链的节点数 = 两侧距离和 + 1，最小值 = 两侧 minv 的较小者。

把两侧各排成按 minv 升序的数组，然后双指针。固定左侧第 i 个点作为整条链最小值所在的点，右侧所有 minv 不小于它的点里，取到边距离最大的那个拼起来。左侧从大到小扫，满足条件的右侧点是排序后的后缀，指针只会单向前进。

这里有个细节。u 和它的虚点权值相同、中间虚边权 0，这一对配出来的「链」节点数是 1，指标正好是 arr[u]。也就是说单点会混进答案，只要这个点有虚点。课程代码保留了这一行为，常见的题解写法也是这样。

完整代码如下。

    
#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    struct Node {
        int edge, minv;
    };

    bool NodeCmp(Node x, Node y) {
        return x.minv < y.minv;
    }

    const int MAXN = 100001;
    int n, cntn;
    int arr[MAXN];

    int head1[MAXN];
    int next1[MAXN << 1];
    int to1[MAXN << 1];
    int weight1[MAXN << 1];
    int cnt1;

    int head2[MAXN];
    int next2[MAXN << 1];
    int to2[MAXN << 1];
    int weight2[MAXN << 1];
    int cnt2;

    bool vis[MAXN];
    int siz[MAXN];

    Node larr[MAXN];
    int cntl;

    Node rarr[MAXN];
    int cntr;

    ll ans;

    void addEdge1(int u, int v, int w) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        weight1[cnt1] = w;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v, int w) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        weight2[cnt2] = w;
        head2[u] = cnt2;
    }

    void rebuild(int u, int fa) {
        int last = 0;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            int w = weight1[e];
            if (v != fa) {
                if (last == 0) {
                    last = u;
                    addEdge2(u, v, w);
                    addEdge2(v, u, w);
                } else {
                    int add = ++cntn;
                    arr[add] = arr[u];
                    addEdge2(last, add, 0);
                    addEdge2(add, last, 0);
                    addEdge2(add, v, w);
                    addEdge2(v, add, w);
                    last = add;
                }
                rebuild(v, u);
            }
        }
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroidEdge(int u, int fa) {
        getSize(u, fa);
        int total = siz[u];
        int half = total >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head2[u]; e > 0; e = next2[e]) {
                int v = to2[e];
                if (v != fa && !vis[e >> 1] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        int best = 0, edge = 0;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            if (!vis[e >> 1]) {
                int v = to2[e];
                int sub = (v == fa ? (total - siz[u]) : siz[v]);
                if (sub > best) {
                    best = sub;
                    edge = e;
                }
            }
        }
        return edge;
    }

    void dfs(int u, int fa, int edge, int minv, int op) {
        if (op == 0) {
            larr[++cntl] = { edge, minv };
        } else {
            rarr[++cntr] = { edge, minv };
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                dfs(v, u, edge + weight2[e], min(minv, arr[v]), op);
            }
        }
    }

    void calc(int edge) {
        cntl = cntr = 0;
        int v1 = to2[edge];
        int v2 = to2[edge ^ 1];
        dfs(v1, 0, 0, arr[v1], 0);
        dfs(v2, 0, weight2[edge], arr[v2], 1);
        sort(larr + 1, larr + cntl + 1, NodeCmp);
        sort(rarr + 1, rarr + cntr + 1, NodeCmp);
        ll maxEdge = 0;
        for (int i = cntl, j = cntr; i >= 1; i--) {
            while (j >= 1 && rarr[j].minv >= larr[i].minv) {
                maxEdge = max(maxEdge, 1LL * rarr[j].edge);
                j--;
            }
            if (j < cntr) {
                ans = max(ans, 1LL * larr[i].minv * (maxEdge + larr[i].edge + 1));
            }
        }
        maxEdge = 0;
        for (int i = cntr, j = cntl; i >= 1; i--) {
            while (j >= 1 && larr[j].minv >= rarr[i].minv) {
                maxEdge = max(maxEdge, 1LL * larr[j].edge);
                j--;
            }
            if (j < cntl) {
                ans = max(ans, 1LL * rarr[i].minv * (maxEdge + rarr[i].edge + 1));
            }
        }
    }

    void solve(int u) {
        int edge = getCentroidEdge(u, 0);
        if (edge > 0) {
            vis[edge >> 1] = true;
            calc(edge);
            solve(to2[edge]);
            solve(to2[edge ^ 1]);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge1(u, v, 1);
            addEdge1(v, u, 1);
        }
        cntn = n;
        cnt2 = 1;
        rebuild(1, 0);
        solve(1);
        cout << ans << '\n';
        return 0;
    }

七、题目2：红黑蛛网

n 个点组成一棵树，每条边有重量 w 和颜色 c（红或黑）。点对 (x, y) 的路径上红边数 r、黑边数 b，路径合法当且仅当 2 × min(r, b) ≥ max(r, b)。合法路径的收益 = 路径所有边的重量乘积，(x, y) 与 (y, x) 只算一次，输出所有合法路径收益的总乘积对 10⁹+7 取余，不存在合法路径输出 1。2 ≤ n ≤ 10⁵。

直接的做法是容斥：答案 = 所有点对的路径乘积 × 非法点对路径乘积的逆元。

所有点对的那份不用边分治。每条边 e 恰好被 siz × (n - siz) 个点对跨过（两侧各取一点），所以全部路径的总乘积 = 每条边 w 的 siz×(n-siz) 次方连乘。一次 dfs 就算完。

非法点对的那份用边分治。对每条重心边，左侧收集每个点的 (r, b, 乘积)，右侧同。一个点对非法只有两种可能：红太少，2(r₁+r₂) < b₁+b₂；或者黑太少，2(b₁+b₂) < r₁+r₂。两个条件不可能同时成立，否则 r、b 同时为 0，而路径至少有一条带颜色的边。

把左侧改写成 key = 2r - b，按 key 排序，乘积做前缀积。右侧每个点二分找出所有满足 2r₁ - b₁ < b₂ - 2r₂ 的左侧点，个数和乘积连乘一次拿到。黑太多的那侧对称地再做一遍。每个非法点对恰好在其分离边上被统计一次。

虚边的设置：权 1（乘积不变）、颜色不设（计数不变）。虚点不参与统计，收集信息时只记 u ≤ n 的点。

完整代码如下。

    
#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    struct Node {
        int key;
        ll path;
    };

    bool NodeCmp(Node x, Node y) {
        return x.key < y.key;
    }

    const int MAXN = 200001;
    const int MOD = 1000000007;
    int n, cntn;

    int head1[MAXN];
    int next1[MAXN << 1];
    int to1[MAXN << 1];
    int weight1[MAXN << 1];
    int color1[MAXN << 1];
    int cnt1;

    int head2[MAXN];
    int next2[MAXN << 1];
    int to2[MAXN << 1];
    int weight2[MAXN << 1];
    int color2[MAXN << 1];
    int cnt2;

    bool vis[MAXN];
    int siz[MAXN];

    Node redArr[MAXN];
    Node blackArr[MAXN];
    int cnta;

    ll ans1, ans2;

    ll power(ll x, ll p) {
        ll ans = 1;
        x %= MOD;
        while (p != 0) {
            if (p & 1) {
                ans = ans * x % MOD;
            }
            p >>= 1;
            x = x * x % MOD;
        }
        return ans;
    }

    void addEdge1(int u, int v, int w, int c) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        weight1[cnt1] = w;
        color1[cnt1] = c;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v, int w, int c) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        weight2[cnt2] = w;
        color2[cnt2] = c;
        head2[u] = cnt2;
    }

    void rebuild(int u, int fa) {
        int last = 0;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            int w = weight1[e];
            int c = color1[e];
            if (v != fa) {
                if (last == 0) {
                    last = u;
                    addEdge2(u, v, w, c);
                    addEdge2(v, u, w, c);
                } else {
                    int add = ++cntn;
                    addEdge2(last, add, 1, -1);
                    addEdge2(add, last, 1, -1);
                    addEdge2(add, v, w, c);
                    addEdge2(v, add, w, c);
                    last = add;
                }
                rebuild(v, u);
            }
        }
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroidEdge(int u, int fa) {
        getSize(u, fa);
        int total = siz[u];
        int half = total >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head2[u]; e > 0; e = next2[e]) {
                int v = to2[e];
                if (v != fa && !vis[e >> 1] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        int best = 0, edge = 0;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            if (!vis[e >> 1]) {
                int v = to2[e];
                int sub = (v == fa ? (total - siz[u]) : siz[v]);
                if (sub > best) {
                    best = sub;
                    edge = e;
                }
            }
        }
        return edge;
    }

    int lessThan(Node arr[], int len, int num) {
        int l = 1, r = len, mid, ans = 0;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (arr[mid].key < num) {
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }

    void dfsLeft(int u, int fa, int red, int black, ll path) {
        if (u <= n) {
            redArr[++cnta] = { 2 * red - black, path };
            blackArr[cnta] = { 2 * black - red, path };
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                int nextRed = red + (color2[e] == 0 ? 1 : 0);
                int nextBlack = black + (color2[e] == 1 ? 1 : 0);
                dfsLeft(v, u, nextRed, nextBlack, path * weight2[e] % MOD);
            }
        }
    }

    void dfsRight(int u, int fa, int red, int black, ll path) {
        if (u <= n) {
            int r = lessThan(redArr, cnta, black - 2 * red);
            int b = lessThan(blackArr, cnta, red - 2 * black);
            if (r > 0) {
                ans2 = ans2 * power(path, r) % MOD * redArr[r].path % MOD;
            }
            if (b > 0) {
                ans2 = ans2 * power(path, b) % MOD * blackArr[b].path % MOD;
            }
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                int nextRed = red + (color2[e] == 0 ? 1 : 0);
                int nextBlack = black + (color2[e] == 1 ? 1 : 0);
                dfsRight(v, u, nextRed, nextBlack, path * weight2[e] % MOD);
            }
        }
    }

    void calc(int edge) {
        cnta = 0;
        int v1 = to2[edge];
        dfsLeft(v1, 0, 0, 0, 1);
        sort(redArr + 1, redArr + cnta + 1, NodeCmp);
        sort(blackArr + 1, blackArr + cnta + 1, NodeCmp);
        for (int i = 2; i <= cnta; i++) {
            redArr[i].path = redArr[i - 1].path * redArr[i].path % MOD;
            blackArr[i].path = blackArr[i - 1].path * blackArr[i].path % MOD;
        }
        int v2 = to2[edge ^ 1];
        int red = (color2[edge] == 0 ? 1 : 0);
        int black = (color2[edge] == 1 ? 1 : 0);
        dfsRight(v2, 0, red, black, weight2[edge] % MOD);
    }

    void getAns2(int u) {
        int edge = getCentroidEdge(u, 0);
        if (edge > 0) {
            vis[edge >> 1] = true;
            calc(edge);
            getAns2(to2[edge]);
            getAns2(to2[edge ^ 1]);
        }
    }

    void getAns1(int u, int fa) {
        siz[u] = 1;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (v != fa) {
                getAns1(v, u);
                siz[u] += siz[v];
                ans1 = ans1 * power(weight1[e], 1LL * siz[v] * (n - siz[v])) % MOD;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v, w, c; i < n; i++) {
            cin >> u >> v >> w >> c;
            addEdge1(u, v, w, c);
            addEdge1(v, u, w, c);
        }
        cntn = n;
        cnt2 = 1;
        ans1 = ans2 = 1;
        getAns1(1, 0);
        rebuild(1, 0);
        getAns2(1);
        ll ans = ans1 * power(ans2, MOD - 2) % MOD;
        cout << ans << '\n';
        return 0;
    }

八、复杂度分析

三度化把点数翻到至多 2n，之后每个连通区的处理是线性的，排序是每层的主导。

操作时间复杂度空间复杂度
三度化重构O(n)O(n)（重建树至多 2n 点、4n 条有向边，信息数组同阶）
找重心边（每个连通区）O(区大小)
收集两侧信息（每层合计）O(n)
排序（每层）O(n log n)
总计（O(log n) 层）O(n log² n)

题 1 的双指针和题 2 的二分都在排序之后，每层 O(n log n) 封顶。数组按 2n 开，邻接表按 4n 条有向边开。

九、最后

边分治和点分治处理同一类问题，差别在切的东西：切点要多棵子树按顺序拼，切边只有两份信息直接合。冷门的原因只是多了一次三度化。

下一节把每层的重心边记下来，做成每个点集自己的二叉信息树，也就是边分树：它能像线段树一样可持久化、能合并。
