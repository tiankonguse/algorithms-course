一维动态规划的四种形状：丑数、括号、环绕串、子序列计数

过了从递归到 dp 那一关，剩下的题不必每次都从递归重新推。这一页四个题各自代表一种常见的一维形状：三条候选序列归并、以 i 结尾往左接、以字符结尾取最大延伸、以字符结尾计数并去重。

零、先把「以谁结尾」问出来

一维动态规划最难的一步是把 dp[i] 的含义定下来。定含义有个固定的问法：这个位置必须被算进去吗？如果答案是必须，那 dp[i] 就是「必须以 i 结尾」的答案，转移时也只看能和 i 接上的那些位置。

下面四题都是这么定的，差别在「接上的方式」和「存的是长度还是个数」。

一、丑数 II：三条候选序列归并

丑数就是质因数只有 2、3、5 的正整数，默认第一个是 1。前几项是 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 15……注意 7、11、13 都不在里面。

一个丑数乘 2、乘 3、乘 5 还是丑数。所以准备三条序列：已算出的丑数各自乘 2、乘 3、乘 5，每条序列自己递增。要找下一个丑数，就是三条序列的队头取最小。

三条序列不用真的开数组存。用 i2、i3、i5 三个下标指着「乘完之后还没进 dp 的最早那个丑数」，每轮拿 dp[i2]×2、dp[i3]×3、dp[i5]×5 比一下。

#include <bits/stdc++.h>
    using namespace std;

    // 三条候选序列归并：i2/i3/i5 分别指向「乘 2/3/5 之后还没进 dp」的最早位置
    int nthUglyNumber(int n) {
        vector<int> dp(n + 1, 0);
        dp[1] = 1;
        for (int i = 2, i2 = 1, i3 = 1, i5 = 1, a, b, c, cur; i <= n; i++) {
            a = dp[i2] * 2;
            b = dp[i3] * 3;
            c = dp[i5] * 5;
            cur = min(min(a, b), c);
            // 三个 if 都要走，相等说明同一数值从多条序列来，指针都得往前挪
            if (cur == a) i2++;
            if (cur == b) i3++;
            if (cur == c) i5++;
            dp[i] = cur;
        }
        return dp[n];
    }

实测填前 15 项的过程（括号里是填完这一项后的三个指针）：2, 3, 4, 5, 6, 8, 9, 10, 12, 15, 16, 18, 20, 24。n = 1690 时答案是 2123366400，耗时 0.006ms。

那三个 if 一个都不能写成 else if。6 既能由 3×2 来，也能由 2×3 来，只挪一个指针的话下一次还会算出 6，dp 里就出现重复。实测（2 万组随机 n，对照组是逐个整数试除的暴力）：写成 else if 之后 94.94% 的样本答案不对，错版填出的前 15 项里明摆着有 6, 6、10, 10、12, 12, 12。

二、最长有效括号：以 i 结尾往左接

dp[i] 定成「子串必须以 i 位置的字符结尾，往左整体有效的最大长度」。以左括号结尾的子串不可能是有效的，所以只有 s[i] == ')' 时才要算。

i 左边紧挨着的那一整段已经有效了，长度是 dp[i-1]，先跳过去。跳过去之后的那个位置 p = i − dp[i−1] − 1，如果 s[p] 是左括号，它就能和 i 配上：

配上了之后，还要把 p 左边紧邻的那一段接上来，长度是 dp[p−1]。这三段加起来才是 dp[i]。

#include <bits/stdc++.h>
    using namespace std;

    // dp[i] : 必须以 i 位置字符结尾，往左整体有效的最大长度
    int longestValidParentheses(string& str) {
        int n = str.size();
        vector<int> dp(n, 0);
        int ans = 0;
        for (int i = 1, p; i < n; i++) {
            if (str[i] == ')') {
                // 先跳过 i 左边已经有效的那一整段，p 就是要和 i 配对的那个位置
                p = i - dp[i - 1] - 1;
                //  ?         )
                //  p         i
                if (p >= 0 && str[p] == '(') {
                    dp[i] = dp[i - 1] + 2 + (p - 1 >= 0 ? dp[p - 1] : 0);
                }
            }
            ans = max(ans, dp[i]);
        }
        return ans;
    }

实测（2 万组随机括号串，对照组是枚举所有子串并检查）：忘了接 dp[p−1] 那一段，38.77% 的样本答案偏小。"()(())" 正解 6，漏掉那一段只剩 4，因为 "()" 和 "(())" 中间断开了。

几个样例的 dp 数组："()(())" 是 0 2 0 0 2 6，答案 6；"(()" 是 0 2 0，答案 2；")()())" 答案 4。长度 10⁶ 的随机括号串跑一遍 3.22ms。

三、环绕字符串：以字符结尾的最大延伸

base 是把 a 到 z 无限首尾相接的字符串：…zabcdefghijklmnopqrstuvwxyzabcd…。一个子串在 base 里出现过，等价于它沿着字母表连续（z 后面可以接 a）。问 s 里有多少个不同的非空子串满足这个条件。

同一个结尾字符，短的必然被长的包含：以 b 结尾的最长延伸是 3，那 b、ab、zab 三个就都算，贡献 3 个。所以只要对每个字符记「以它结尾的最长延伸」，最后把 26 个值加起来。

扫一遍 s，用 len 记当前这一段连续的长度：能和前一个字符接上就 len++，接不上就 len = 1。然后 dp[当前字符] = max(dp[当前字符], len)。

#include <bits/stdc++.h>
    using namespace std;

    // dp[ch] : s 里「必须以字符 ch 结尾」的子串，最长能延伸多少
    int findSubstringInWraproundString(string& str) {
        int n = str.size();
        vector<int> s(n);
        for (int i = 0; i < n; i++) s[i] = str[i] - 'a';
        vector<int> dp(26, 0);
        dp[s[0]] = 1;
        for (int i = 1, cur, pre, len = 1; i < n; i++) {
            cur = s[i];
            pre = s[i - 1];
            // 沿 base 走一步：z 后面接 a，或者字母表里的下一个
            if ((pre == 25 && cur == 0) || pre + 1 == cur) {
                len++;
            } else {
                len = 1;
            }
            dp[cur] = max(dp[cur], len);
        }
        int ans = 0;
        for (int i = 0; i < 26; i++) ans += dp[i];
        return ans;
    }

max 不能省。s = "zab" 里 a 只出现一次，dp[a] = 2（za）；要是 s = "abcabcd"，a 在第 4 位又出现一次，那次的 len 是 1，直接赋值会把 3 覆盖成 1。实测（2 万组随机串，对照组是把所有子串塞进集合）：直接赋值不取 max，23.98% 的样本答案偏小。

实测样例："a" 得 1，"cac" 得 2，"zab" 得 6（z:1、a:2、b:3），"abcd" 得 10（1+2+3+4），"abcabcd" 还是 10。长度 10⁶ 的随机串 0.72ms。

四、不同的子序列 II：以字符结尾计数

这题要数 s 有多少个不同的非空子序列。"不同" 两个字是全部难点：s = "aaa" 的子序列里有三个 a，但只能算一个。

还是按结尾字符分类。cnt[ch] 记「目前以 ch 结尾的不同子序列个数」，all 记「含空串在内目前一共有多少个」。读到字符 x 时，把 x 接在所有已有子序列后面，理论上新增 all 个；但其中以 x 结尾的那些（cnt[x] 个）之前已经数过了，得减掉。

newAdd = all − cnt[x]，然后 cnt[x] += newAdd、all += newAdd。答案就是 all − 1（减掉空串）。

#include <bits/stdc++.h>
    using namespace std;

    const int MOD = 1000000007;

    // cnt[ch] : 目前以 ch 结尾的不同子序列个数；all : 含空串的总数
    int distinctSubseqII(string& s) {
        vector<int> cnt(26, 0);
        int all = 1, newAdd;
        for (char x : s) {
            // 新增 = 全部接上 x，减去已经在 cnt[x] 里数过的那些
            newAdd = (all - cnt[x - 'a'] + MOD) % MOD;
            cnt[x - 'a'] = (cnt[x - 'a'] + newAdd) % MOD;
            all = (all + newAdd) % MOD;
        }
        return (all - 1 + MOD) % MOD;
    }

实测（2 万组随机串，对照组是把所有子集组成的串塞进集合）：newAdd 直接用 all、不减 cnt[x]，90.42% 的样本答案偏大。"aaa" 正解 3，错版算出 7。

几个样例："abc" 得 7，"aba" 得 6，"aaa" 得 3，"abab" 得 11。长度 10⁶ 的随机串 6.94ms。

五、复杂度分析

题目时间复杂度额外空间实测
丑数 IIO(n)O(n)n = 1690 用 0.006ms，答案 2123366400
最长有效括号O(n)O(n)长度 10⁶ 用 3.22ms
环绕字符串中唯一的子字符串O(n)O(1)，只有 26 个格子长度 10⁶ 用 0.72ms

四个都是 O(n)，因为每个位置只做常数次比较或算术。空间上，丑数要把整张 dp 留着（第 n 项依赖第 n−1 项的指针位置），括号那题只依赖左边可以滚成 O(1)，后两题本来就只有 26 个格子。

六、总结

定 dp[i] 含义时问一句「这个位置必须算进去吗」，能挡掉一半的设计错误。四题的 dp 含义都是「必须以某位置/某字符结尾」，转移也只看能接上的那一两处。

四个坑各自对应一处实测：丑数的三个指针要各自独立地挪（else if 错 94.94%），括号要接上 p 左边那一段（漏了错 38.77%），环绕串的 dp 取 max 不赋值（直接赋值错 23.98%），子序列的新增量要减掉 cnt[x]（不减错 90.42%）。

这四题都不需要从递归起步，直接按「以谁结尾」就能推出转移。再往后的二维 dp、区间 dp 也是同一个问法，只是 dp 的下标从一个变成两个。
