分块结合并查集

上一页的双层分块要开一块二维的统计数组，空间上不太划算。这一节换个办法：值域上不再分块，而是用并查集维护「值域的映射」。整块操作把一整段值整体挪位置时，只要让这段值的父亲一起指过去，一次改完，计数数组是一维的。

零、背景

分块的老套路是：整块打标记，零散部分暴力。标记能省事的前提是「整块的修改可以概括成一个量」，区间加是一个数，区间赋值是一个值。

有些操作概括不成一个量，但它在值域上有形状。比如「所有大于 x 的数减去 x」，落到值域上就是把一段区间整体左移。这种「整段移动」用并查集最合适：让被移动的那段值的父亲指向新位置，一个值都不用真的去改。

一、题目：五彩斑斓的世界

给定一个长度为 n 的数组，m 条操作。操作 1 把 arr[l..r] 里所有大于 x 的数减去 x；操作 2 查询 arr[l..r] 里 x 出现的次数。n ≤ 10⁶，m ≤ 5×10⁵，值和 x 都在 0 到 10⁵。测试链接：洛谷 P4117。

这题的两个操作都是值域相关的：改的是「大于 x 的那一段」，查的是「值恰好等于 x 的有几个」。单点改不了，只能整段挪，正好是并查集的用武之地。

二、整体骨架

序列按 √n 分块，然后沿用上一页题 2 那个方向：每个块把所有 m 条操作扫一遍。每到一个块就重建一次统计，cntv[v] 是块内存储值 v 的个数，maxv 是块内最大的存储值，lazy 归零，值域并查集 fa[v] = v 全部重新指向自己。

块内的一条操作如果整块覆盖，走并查集的 O(1) 或 O(段长) 路径；只覆盖一部分，就把块下放、逐点改，代价 O(块长)。

三、lazy 与存储值

数组里存的是「存储值」，真实值 = 存储值 − lazy。整体减 x 这件事，只要 lazy 加 x，块内一个数都不用动。反过来，查真实值 x 的个数，就是查存储值 x + lazy 的计数。

四、整块修改：往哪边挪

整块做「大于 x 的减去 x」时，真实值域被 x 切成两半。真实值 ≤ x 的那半不动，> x 的那半要左移 x。挪哪半都行，代价是那半的长度，所以选短的那半挪。

挪「小的那半」时，动的是真实值 1 到 x 这一段：它们的真实值不变，但存储值要跟着 lazy 一起加 x，于是 cntv[v + x] += cntv[v]、fa[v] = v + x，然后 lazy 加 x。挪「大的那半」时反过来：cntv[v - x] += cntv[v]、fa[v] = v - x，lazy 不动。

这里有个细节为什么能摊还：一次整块修改花掉 O(挪动长度)，而真实最大值（maxv - lazy）正好下降这么多。值域只有 V 这么大，一个块内所有整块修改的挪动总量就是 O(V)，不会退化成 O(m·V)。

五、下放与查询

零散操作要拿到真值，得先把块下放：arr[i] = find(arr[i]) 沿并查集的父亲链走到根，得到当前存储值，再减 lazy 就是真实值。下放之后这个块的统计就靠 cntv 逐点维护。

整块查询是 O(1) 的：ans += cntv[jobx + lazy]。整块修改前先看一眼 jobx >= maxv - lazy，说明块里没有数大于 x，直接跳过。

x = 0 的查询单独处理。0 不会大于任何非负的 x，也就永远不会被减，所以 0 的个数从头到尾不变，预处理一个前缀和就够了。

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1000001;
    const int MAXM = 500001;
    const int MAXV = 100002;
    int n, m;
    int blen, bnum;

    int arr[MAXN];
    int op[MAXM];
    int ql[MAXM];
    int qr[MAXM];
    int qx[MAXM];

    int maxv, lazy;
    int fa[MAXV];
    int pre0[MAXN];
    int cntv[MAXV];

    int ans[MAXM];

    int find(int x) {
        if (x != fa[x]) {
            fa[x] = find(fa[x]);
        }
        return fa[x];
    }

    void change(int x, int y) {
        fa[x] = y;
    }

    void down(int l, int r) {
        for (int i = l; i <= r; i++) {
            arr[i] = find(arr[i]);
        }
    }

    void update(int qi, int l, int r) {
        int jobl = ql[qi], jobr = qr[qi], jobx = qx[qi];
        if (jobx >= maxv - lazy || jobl > r || jobr < l) {
            return;
        }
        if (jobl <= l && r <= jobr) {
            if ((jobx << 1) <= maxv - lazy) {
                for (int v = lazy + 1; v <= lazy + jobx; v++) {
                    cntv[v + jobx] += cntv[v];
                    cntv[v] = 0;
                    change(v, v + jobx);
                }
                lazy += jobx;
            } else {
                for (int v = lazy + jobx + 1; v <= maxv; v++) {
                    cntv[v - jobx] += cntv[v];
                    cntv[v] = 0;
                    change(v, v - jobx);
                }
                for (int v = maxv; v >= 0; v--) {
                    if (cntv[v] != 0) {
                        maxv = v;
                        break;
                    }
                }
            }
        } else {
            down(l, r);
            for (int i = max(l, jobl); i <= min(r, jobr); i++) {
                if (arr[i] - lazy > jobx) {
                    cntv[arr[i]]--;
                    arr[i] -= jobx;
                    cntv[arr[i]]++;
                }
            }
            for (int v = maxv; v >= 0; v--) {
                if (cntv[v] != 0) {
                    maxv = v;
                    break;
                }
            }
        }
    }

    void query(int qi, int l, int r) {
        int jobl = ql[qi], jobr = qr[qi], jobx = qx[qi];
        if (jobx == 0 || jobx > maxv - lazy || jobl > r || jobr < l) {
            return;
        }
        if (jobl <= l && r <= jobr) {
            ans[qi] += cntv[jobx + lazy];
        } else {
            down(l, r);
            for (int i = max(l, jobl); i <= min(r, jobr); i++) {
                if (arr[i] - lazy == jobx) {
                    ans[qi]++;
                }
            }
        }
    }

    void compute(int l, int r) {
        memset(cntv, 0, sizeof(int) * MAXV);
        maxv = lazy = 0;
        for (int i = l; i <= r; i++) {
            maxv = max(maxv, arr[i]);
            cntv[arr[i]]++;
        }
        for (int v = 0; v <= maxv; v++) {
            fa[v] = v;
        }
        for (int i = 1; i <= m; i++) {
            if (op[i] == 1) {
                update(i, l, r);
            } else {
                query(i, l, r);
            }
        }
    }

    void prepare() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            pre0[i] = pre0[i - 1] + (arr[i] == 0 ? 1 : 0);
        }
        for (int i = 1; i <= m; i++) {
            if (op[i] == 2 && qx[i] == 0) {
                ans[i] = pre0[qr[i]] - pre0[ql[i] - 1];
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> op[i] >> ql[i] >> qr[i] >> qx[i];
        }
        prepare();
        for (int i = 1, l, r; i <= bnum; i++) {
            l = (i - 1) * blen + 1;
            r = min(i * blen, n);
            compute(l, r);
        }
        for (int i = 1; i <= m; i++) {
            if (op[i] == 2) {
                cout << ans[i] << '\n';
            }
        }
        return 0;
    }

六、复杂度分析

设序列块长 B、值域大小 V。每个块要重建统计 O(V + B)，再把 m 条操作扫一遍：整块操作摊还 O(V)，零散操作 O(B)。块数是 n/B。

操作时间复杂度空间复杂度
进入一个块（重建 cntv 与 fa）O(V + B)O(n + m + V)：arr 与操作各开一份，cntv 和 fa 都只开 V 个，比双层分块的二维数组省一个量级
整块修改（摊还到所有操作）O(V)
整块查询O(1)
零散修改或查询O(B)
全部（n/B 个块）O((n/B) · (m + V) + m · B)

块长取 √n 时，前后两项是 m·√n 与 n/B·V = √n·V，n = 10⁶、V = 10⁵ 时都在 10⁸ 量级。这题 n 比 m 大，把块长往上调一点会更划算，代码里直接取 √n。

七、最后

分块套并查集的关键就一句话：整块操作在值域上是「整段移动」，而整段移动可以用改父亲代替改每一个数。代价从 O(段长) 变成 O(1) 次指向，剩下的扫描靠势能摊还。
