AVL 树：静态数组实现有序表

有序表是一个抽象类：key 按序组织，支持增删改查和排名、第 k 小、前驱后继，全部 O(log n)。AVL 树是把它落地的第一站，也是理解后面跳表、替罪羊树、Treap 的起点。这一页把一个完整可用的 AVL 有序表拆开讲：静态数组怎么存、左旋右旋怎么转、四种违规怎么判、删除双子节点怎么替换。

零、有序表

「有序表」的抽象层只有一句话：key 按序组织，支持和序有关的查询。具体到操作：增加一个 key（重复加入算多个词频）、删除一个 key（只删一个）、查 key 的排名（比它小的个数 + 1）、查排名第几的 key、查前驱（小于 x 的最大数）、查后继（大于 x 的最小数）。不管底层是什么结构，这些操作都要 O(log n)。

竞赛里实现有序表，代码用静态数组写：数组下标当指针，节点编号是 1..cnt 的整数，0 表示空。为什么不用 new？笔试和算法竞赛环境里，动态结构的分配和回收不可控，可能超时；工程上为了防止内存泄漏才用动态结构。静态数组的代价是预先估好 MAXN，本题操作次数 1e5、值域 −1e7..1e7，MAXN 开到 1e5 + 1 够用。

一、平衡性

AVL 的平衡定义：任意节点，左子树高度和右子树高度相差不超过 1。高度存在 height 数组里，空子树高度按 0 算。

除了 height，每个节点还要维护这些信息：key 本身、key_count（这个词频，重复加入累加）、siz（整个子树里所有词频之和，排名靠它）、ls 和 rs（左右孩子下标）。为什么多维护 siz 而不是只维护节点数？重复值算多个，排名是按词频算的。

树高被压住是 O(log n) 的来源。满足这个平衡条件的树，高度不超过 1.44 log2(n+2)，于是单次操作最多走这么多层。

二、左旋与右旋

旋转是 AVL 的原子操作。左旋 leftRotate(i)：i 的右孩子 r 升为根，r 的左子树改挂到 i 的右边，i 变成 r 的左孩子。右旋对称。

旋转后要 up(i)、up(r)，重新算这两个节点的 height 和 siz。这里有个值得停一下的观察：旋转不改变中序遍历的次序。BST 里节点本来就按 key 排序，旋转只改父子关系，不改变「谁在谁的左边」。正是这一点让排名、第 k 小、前驱后继在任意次旋转之后依然正确，有序表才能放心用旋转维持平衡。

三、四种违规

新增或删除节点后，从被影响的位置往上，每个祖先都可能失衡。失衡只有四种形态，按「哪边高、哪个孙子高」分类：

LL：左子树高，且左子树的左子树也高，右旋一次。LR：左子树高，但高的是左子树的右子树，先左旋左子树再右旋。RR 和 RL 对称。maintain(i) 里判定 LL 还是 LR，靠一句 height[ls[ls[i]]] >= height[rs[ls[i]]]：左孙更高或持平按 LL 处理，否则按 LR。这个「持平按 LL」的写法不是巧合，它同时兜住了删除后 LL 和 LR 一起出现的情况（详见删除那一节）。

四、增加节点

add(i, num) 递归走：节点为空就新开一个节点；key 相等就 key_count++；num 小走左、大走右。回溯时先 up(i) 再 maintain(i)，从底往上每一层都可能旋转。

每一层调整是 O(1)，总代价就是树高 O(log n)。真实发生的旋转次数极少，复杂度主要就是走过树高的路程，不是真的每次都转到。

五、删除节点

remove(i, num) 递归定位。key_count 大于 1 直接减一，不动结构。减到 1 时按孩子情况处理：

没有孩子，返回 0，节点消失。只有左孩子或只有右孩子，孩子顶替。两个孩子都有，这是重点：找右子树的最左节点 mostLeft（中序后继），用 removeMostLeft 把它从右子树摘下来，再让 mostLeft 顶替被删节点，左右孩子接过来。替换之后整棵树还是 BST。

外层 remove(num) 先查 getRank(num) != getRank(num + 1) 确认 num 存在。getRank(num + 1) 统计的是小于 num+1 的个数，等于小于等于 num 的个数再加 1，两个排名不同就说明 num 在树里。

注意点：删除后可能 LL 和 LR 同时出现，maintain 里按 LL 调整；可能 RR 和 RL 同时出现，按 RR 调整。代码里写的就是这个顺序，不需要额外分支。

六、六种操作

getRank(x)：比 x 小的个数 + 1。key[i] >= x 走左子树，否则累加左子树大小加词频，继续走右子树。

index(x)：第 x 小的数。siz[左] >= x 走左；siz[左] + key_count[i] < x 走右并把 x 减掉前面；否则落在当前节点，返回 key[i]。

pre(x)：小于 x 的最大数，没有返回 INT_MIN。post(x)：大于 x 的最小数，没有返回 INT_MAX。两个都是递归里取 max/min 的写法。

七、题目1：完整实现

洛谷 P3369。六种操作全实现，主函数按 op 分发，代码就是上面的拼装：

#include <iostream>
    #include <algorithm>
    #include <climits>
    #include <cstring>

    using namespace std;

    const int MAXN = 100001;

    int cnt = 0;
    int head = 0;
    int key[MAXN];
    int height[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int key_count[MAXN];
    int siz[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + key_count[i];
        height[i] = max(height[ls[i]], height[rs[i]]) + 1;
    }

    int leftRotate(int i) {
        int r = rs[i];
        rs[i] = ls[r];
        ls[r] = i;
        up(i);
        up(r);
        return r;
    }

    int rightRotate(int i) {
        int l = ls[i];
        ls[i] = rs[l];
        rs[l] = i;
        up(i);
        up(l);
        return l;
    }

    int maintain(int i) {
        int lh = height[ls[i]];
        int rh = height[rs[i]];
        if (lh - rh > 1) {
            if (height[ls[ls[i]]] >= height[rs[ls[i]]]) {
                i = rightRotate(i);
            } else {
                ls[i] = leftRotate(ls[i]);
                i = rightRotate(i);
            }
        } else if (rh - lh > 1) {
            if (height[rs[rs[i]]] >= height[ls[rs[i]]]) {
                i = leftRotate(i);
            } else {
                rs[i] = rightRotate(rs[i]);
                i = leftRotate(i);
            }
        }
        return i;
    }

    int add(int i, int num) {
        if (i == 0) {
            key[++cnt] = num;
            key_count[cnt] = siz[cnt] = height[cnt] = 1;
            return cnt;
        }
        if (key[i] == num) {
            key_count[i]++;
        } else if (key[i] > num) {
            ls[i] = add(ls[i], num);
        } else {
            rs[i] = add(rs[i], num);
        }
        up(i);
        return maintain(i);
    }

    void add(int num) {
        head = add(head, num);
    }

    int getRank(int i, int num) {
        if (i == 0) {
            return 0;
        }
        if (key[i] >= num) {
            return getRank(ls[i], num);
        } else {
            return siz[ls[i]] + key_count[i] + getRank(rs[i], num);
        }
    }

    int getRank(int num) {
        return getRank(head, num) + 1;
    }

    int removeMostLeft(int i, int mostLeft) {
        if (i == mostLeft) {
            return rs[i];
        } else {
            ls[i] = removeMostLeft(ls[i], mostLeft);
            up(i);
            return maintain(i);
        }
    }

    int remove(int i, int num) {
        if (key[i] < num) {
            rs[i] = remove(rs[i], num);
        } else if (key[i] > num) {
            ls[i] = remove(ls[i], num);
        } else {
            if (key_count[i] > 1) {
                key_count[i]--;
            } else {
                if (ls[i] == 0 && rs[i] == 0) {
                    return 0;
                } else if (ls[i] != 0 && rs[i] == 0) {
                    i = ls[i];
                } else if (ls[i] == 0 && rs[i] != 0) {
                    i = rs[i];
                } else {
                    int mostLeft = rs[i];
                    while (ls[mostLeft] != 0) {
                        mostLeft = ls[mostLeft];
                    }
                    rs[i] = removeMostLeft(rs[i], mostLeft);
                    ls[mostLeft] = ls[i];
                    rs[mostLeft] = rs[i];
                    i = mostLeft;
                }
            }
        }
        up(i);
        return maintain(i);
    }

    void remove(int num) {
        if (getRank(num) != getRank(num + 1)) {
            head = remove(head, num);
        }
    }

    int index(int i, int x) {
        if (siz[ls[i]] >= x) {
            return index(ls[i], x);
        } else if (siz[ls[i]] + key_count[i] < x) {
            return index(rs[i], x - siz[ls[i]] - key_count[i]);
        }
        return key[i];
    }

    int index(int x) {
        return index(head, x);
    }

    int pre(int i, int num) {
        if (i == 0) {
            return INT_MIN;
        }
        if (key[i] >= num) {
            return pre(ls[i], num);
        } else {
            return max(key[i], pre(rs[i], num));
        }
    }

    int pre(int num) {
        return pre(head, num);
    }

    int post(int i, int num) {
        if (i == 0) {
            return INT_MAX;
        }
        if (key[i] <= num) {
            return post(rs[i], num);
        } else {
            return min(key[i], post(ls[i], num));
        }
    }

    int post(int num) {
        return post(head, num);
    }

    void clear() {
        memset(key + 1, 0, cnt * sizeof(int));
        memset(height + 1, 0, cnt * sizeof(int));
        memset(ls + 1, 0, cnt * sizeof(int));
        memset(rs + 1, 0, cnt * sizeof(int));
        memset(key_count + 1, 0, cnt * sizeof(int));
        memset(siz + 1, 0, cnt * sizeof(int));
        cnt = 0;
        head = 0;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        for (int i = 1, op, x; i <= n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        clear();
        return 0;
    }

洛谷 P6136 是同一套结构的数据加强版：操作还是这六种，只是输入变成强制在线，每次读到的 x 先异或上一次查询的答案，最后输出所有查询答案的异或。核心逻辑和本页代码完全一样，只是 main 里多两行异或。

总结

AVL 树是平衡搜索树的起点：静态数组存节点，height 管平衡，siz 管排名；左旋右旋是原子操作，不改变中序次序，所以排名类查询旋转后依然正确；失衡只有 LL、LR、RL、RR 四种，maintain 按一句高度比较选旋转；删除双子节点用右子树最左节点顶替，替换后仍是 BST。后面跳表、替罪羊树、Treap 都是同一套「有序表」抽象，换各自的平衡方式。
