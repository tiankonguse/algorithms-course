点的度都是奇数的最小瓶颈

判定结构从树状数组换成可撤销并查集之后，整体二分的形状也得跟着变：这题要同时在时间和权值两个维度上分治，而且递归的先后顺序不能随便换。

一、题目5：点的度都是奇数的最小瓶颈

一共有 n 个点，初始没有边，依次加入 m 条无向边，每条边有边权。每次加入后，询问是否存在一个边集，满足每个点连接的边的数量都是奇数。如果存在，希望边集的最大边权尽可能小，如果不存在打印 −1。2 ≤ n ≤ 10⁵，1 ≤ m ≤ 3 × 10⁵，1 ≤ 边权 ≤ 10⁹。测试链接：CF603E、CF603E。

「最小瓶颈」问的是：在能达成目标的边集里，最大边权最小能是多少。等价于找一个阈值 W，只用权值不超过 W 的边就能达成目标，取最小的那个 W。

二、判定标准

先看一个图在什么条件下能选出让每个点度数为奇数的边集。答案是：每个连通块的点数都是偶数。

必要性简单：一个连通块里所有点的度数加起来等于边数的两倍，是偶数。如果每个点的度数都是奇数，那奇数的个数必须是偶数，也就是连通块里的点数是偶数。

充分性靠构造：连通块里取一棵生成树，从叶子往根看，每个点如果已经连出去的边数是偶数，就把它连父亲的那条边选上，否则不选。这样除根以外每个点的度数都是奇数；而整块的点数是偶数，所以根的度数也必然是奇数。

并查集里不用存全部信息，只要存每个块的大小是奇是偶。合并两个块时，只有两个都是奇数块才会让 oddnum 减少 2，其余情况奇偶性不变。撤销的时候原样加回来。

三、单调性与分治的形状

「全偶」这个性质有个好用的特点：它只会被加边改善，不会被加边破坏。因为块与块合并时，两个偶数块合起来还是偶数块；既然当前没有奇数块，就不会出现「偶数加奇数」这种变坏的情况。

于是判定关于阈值 W 单调：某个 W 成立，更大的 W 一定成立。答案 ans[i] 关于时间 i 单调不增：边越来越多，能做到的事只会更多。

分治要同时处理两个维度。compute(el, er, vl, vr) 里 el..er 是时间区间，vl..vr 是权值排名的区间。取 mid 之后，从 el 开始按时间往后加边，只加那些权值排名不超过 mid 的边，一直加到 oddnum 第一次变成 0，记这个位置为 split。后面所有时间的答案都不超过 mid，前面的都大于 mid。

这里有个细节：递归的先后顺序不能换。右半要的是「时间小于 el、排名不超过 mid」的边，正好是当前状态再补上中间那一批；左半要的是「时间小于 split、排名小于 vl」的边。代码先递归右半、撤销、再补边递归左半，就是为了少做一次大规模的撤销。

int find(int i) {
        while (i != father[i]) {
            i = father[i];
        }
        return i;
    }

    bool Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (fx == fy) {
            return false;
        }
        if ((siz[fx] & 1) == 1 && (siz[fy] & 1) == 1) {
            oddnum -= 2;
        }
        if (siz[fx] < siz[fy]) {
            int tmp = fx;
            fx = fy;
            fy = tmp;
        }
        father[fy] = fx;
        siz[fx] += siz[fy];
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
        return true;
    }

    void undo() {
        int fx = rollback[opsize][0];
        int fy = rollback[opsize--][1];
        father[fy] = fy;
        siz[fx] -= siz[fy];
        if ((siz[fx] & 1) == 1 && (siz[fy] & 1) == 1) {
            oddnum += 2;
        }
    }

并查集不能路径压缩，否则撤销的时候不知道改了谁。按大小合并，栈里记下每次合并的父子，撤销时反向操作。

void compute(int el, int er, int vl, int vr) {
        if (el > er) {
            return;
        }
        if (vl == vr) {
            for (int i = el; i <= er; i++) {
                ans[i] = vl;
            }
        } else {
            int mid = (vl + vr) >> 1;
            int unionCnt1 = 0;
            for (int i = vl; i <= mid; i++) {
                if (wsort[i].tim < el) {
                    if (Union(wsort[i].x, wsort[i].y)) {
                        unionCnt1++;
                    }
                }
            }
            int unionCnt2 = 0;
            int split = er + 1;
            for (int i = el; i <= er; i++) {
                if (edge[i].rak <= mid) {
                    if (Union(edge[i].x, edge[i].y)) {
                        unionCnt2++;
                    }
                }
                if (oddnum == 0) {
                    split = i;
                    break;
                }
            }
            for (int i = 1; i <= unionCnt2; i++) {
                undo();
            }
            compute(el, split - 1, mid + 1, vr);
            for (int i = 1; i <= unionCnt1; i++) {
                undo();
            }
            int unionCnt3 = 0;
            for (int i = el; i <= split - 1; i++) {
                if (edge[i].rak < vl) {
                    if (Union(edge[i].x, edge[i].y)) {
                        unionCnt3++;
                    }
                }
            }
            compute(split, er, vl, mid);
            for (int i = 1; i <= unionCnt3; i++) {
                undo();
            }
        }
    }

prepare 里按权值排序，把每条边的排名 rak 算出来，同时也记下按排名排好的数组 wsort，供「补边」时按排名区间扫描。

void prepare() {
        oddnum = n;
        for (int i = 1; i <= n; i++) {
            father[i] = i;
            siz[i] = 1;
        }
        for (int i = 1; i <= m; i++) {
            wsort[i].x = edge[i].x;
            wsort[i].y = edge[i].y;
            wsort[i].w = edge[i].w;
            wsort[i].tim = edge[i].tim;
        }
        sort(wsort + 1, wsort + m + 1, EdgeCmp);
        for (int i = 1; i <= m; i++) {
            wsort[i].rak = i;
            edge[wsort[i].tim].rak = i;
        }
    }

四、复杂度分析

排序一次 O(m log m)。分治每一层里，三个循环扫过的区间在各节点之间互不重叠，加起来是 O(m) 次并查集操作，一共 log m 层。

操作时间复杂度空间复杂度
按权值排序并算排名（只做一次）O(m log m)O(n + m)：边数组两份各 O(m)（edge 与 wsort），并查集的 father、siz 各 O(n)，回滚栈 O(m)
一次 Union / undo（不路径压缩，按大小合并）O(log n)
分治一层（三个循环的区间互不重叠）O(m log n)
整体（共 log m 层）O(m log m log n)
每个点的答案O(1) 取 wsort[ans].w

m = 3 × 10⁵ 时，log m 大约是 19，log n 大约是 17，并查集操作常数很小，可以通过。

五、最后

这题的分治是「按时间找切点、按权值缩值域」，和前面几题按询问划分的样子很不一样，但不变式是同一个：进节点时结构里已经有该有的东西，出节点时原样撤销。下一节看一个长得很像整体二分、其实不是的做法。
