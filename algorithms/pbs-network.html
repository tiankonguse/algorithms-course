网络：树上差分加整体二分

判定用的结构从树状数组换成树上点差分，整体二分的骨架不用动。这题还有一个绕的地方：问的是「无关请求里的最大值」，判定要反过来想，看有没有「大于 mid 且无关」的请求存在。

一、题目3：网络

一共有 n 个服务器，给定 n − 1 条边，所有服务器连成一棵树。某两个服务器之间的路径上可能接受一条请求，路径上的所有服务器都需要保存该请求的重要度。一共有 m 条操作，每条操作是如下 3 种类型中的一种，操作依次发生，第 i 条操作发生的时间为 i。

操作 0 x y v：x 号服务器到 y 号服务器的路径上，增加了一个重要度为 v 的请求。操作 1 t：当初时间为 t 的操作一定是增加请求的操作，现在这个请求结束了。操作 2 x：当前时间下，和 x 号服务器无关的所有请求中，打印最大的重要度；如果当前时间下没有任何请求，或者所有请求都和 x 号服务器有关，打印 −1。2 ≤ n ≤ 10⁵，1 ≤ m ≤ 2 × 10⁵，1 ≤ 重要度 ≤ 10⁹。测试链接：P3250。

「和 x 有关」的意思是这条请求的路径经过 x。所以操作 2 问的是：所有还活着的请求里，那些路径不经过 x 的，重要度最大是多少。

二、判定反过来写

整体二分要求每个询问能回答一个「答案是不是不超过 mid」的问题。这里直接判「最大值是多少」不方便，改成判反面：只看重要度大于 mid 的那些请求，问它们里面有没有一条与 x 无关。

如果一条都没有，说明所有大于 mid 的请求都经过 x，那「无关请求的最大值」不可能超过 mid，答案去左半。只要存在一条，说明无关请求里已经有一个大于 mid 的，答案一定大于 mid，去右半。于是判定被换成了计数：数一数有多少条大于 mid 的请求，再数一数其中有多少条经过 x，两者相等就是「全都经过 x」。

这里有个细节：cover 不可能大于 request，所以相等与小于就是全部情况。值域从 0 开始，答案是 0 时表示连一条无关请求都没有，打印 −1。

三、路径加与点查询

要在树上批量做「一条路径上的点加 1」，再单点查「这个点被加了几次」。树上点差分配 dfn 序就能一次搞定：路径 u 到 v，lca 记成 w，在 dfn[u] 上加 1、dfn[v] 上加 1、dfn[w] 上减 1、dfn[fa[w]] 上减 1。查一个点 x 被几条路径覆盖，就是求 x 子树对应 dfn 区间的和。

为什么这样是对的：把点 x 的子树和理解为「从 x 往下漏下来的量」。路径 3 到 4 在两端各放一个 +1，在 lca 处放 −1 抵消掉重复计数的那段，再在 lca 的父亲处放 −1 阻止它继续往上漏。于是只有路径上的点，子树里恰好只剩一个 +1。

四、结束操作怎么处理

操作 1 只给了一个时间 t，它要撤销的是时间 t 那条加入操作。读入时不好直接改，因为不知道 t 的 x、y、v 读到没有，其实一定读到了，t 小于当前时间。所以可以在全部读完之后统一处理：扫一遍，遇到操作 1 就把 x 当成下标，去把时间 t 那条操作的 x、y、v 抄过来。抄完之后操作 1 和操作 0 拥有完全相同的 x、y、v，分治时只是一个取 +1、一个取 −1。

void dfs(int u, int f) {
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        dfn[u] = ++cntd;
        stjump[u][0] = f;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e != 0; e = nxt[e]) {
            if (to[e] != f) {
                dfs(to[e], u);
            }
        }
        for (int e = head[u]; e != 0; e = nxt[e]) {
            if (to[e] != f) {
                siz[u] += siz[to[e]];
            }
        }
    }

    int lca(int a, int b) {
        if (dep[a] < dep[b]) {
            int tmp = a;
            a = b;
            b = tmp;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[a][p]] >= dep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= n) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int query(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    void pathAdd(int x, int y, int v) {
        int xylca = lca(x, y);
        int lcafa = fa[xylca];
        add(dfn[x], v);
        add(dfn[y], v);
        add(dfn[xylca], -v);
        if (lcafa != 0) {
            add(dfn[lcafa], -v);
        }
    }

    int pointQuery(int x) {
        return query(dfn[x] + siz[x] - 1) - query(dfn[x] - 1);
    }

主过程里，重要度大于 mid 的请求才打到树上。加请求的操作取 +1，撤销请求的操作取 −1，用一个 request 变量跟着数。扫完记得原样撤销，把树状数组恢复成进入本节点时的样子。

void compute(int el, int er, int vl, int vr) {
        if (el > er) {
            return;
        }
        if (vl == vr) {
            for (int i = el; i <= er; i++) {
                int id = eid[i];
                if (op[id] == 2) {
                    ans[y[id]] = vl;
                }
            }
        } else {
            int mid = (vl + vr) / 2;
            int lsiz = 0, rsiz = 0, request = 0;
            for (int i = el; i <= er; i++) {
                int id = eid[i];
                if (op[id] == 0) {
                    if (v[id] <= mid) {
                        lset[++lsiz] = id;
                    } else {
                        pathAdd(x[id], y[id], 1);
                        request++;
                        rset[++rsiz] = id;
                    }
                } else if (op[id] == 1) {
                    if (v[id] <= mid) {
                        lset[++lsiz] = id;
                    } else {
                        pathAdd(x[id], y[id], -1);
                        request--;
                        rset[++rsiz] = id;
                    }
                } else {
                    if (pointQuery(x[id]) == request) {
                        lset[++lsiz] = id;
                    } else {
                        rset[++rsiz] = id;
                    }
                }
            }
            for (int i = 1; i <= lsiz; i++) {
                eid[el + i - 1] = lset[i];
            }
            for (int i = 1; i <= rsiz; i++) {
                eid[el + lsiz + i - 1] = rset[i];
            }
            for (int i = 1; i <= rsiz; i++) {
                int id = rset[i];
                if (op[id] == 0 && v[id] > mid) {
                    pathAdd(x[id], y[id], -1);
                }
                if (op[id] == 1 && v[id] > mid) {
                    pathAdd(x[id], y[id], 1);
                }
            }
            compute(el, el + lsiz - 1, vl, mid);
            compute(el + lsiz, er, mid + 1, vr);
        }
    }

void prepare() {

        }
        for (int i = 1; i <= m; i++) {

五、复杂度分析

值域 V 是 10⁹ 量级。分治每层每个操作最多一次路径加（四次树状数组单点加）或一次点查询，都是 O(log n)，一共 log V 层。

操作时间复杂度空间复杂度
dfs 求 dfn、siz 与倍增表（只做一次）O(n log n)O(n + m)：前向星 O(n)，倍增表 O(n log n) 约 2 × 10⁶ 个 int，操作数组 O(m)，树状数组 O(n)
一次 lca（倍增跳）O(log n)
一次路径加 / 点查询（树状数组）O(log n)
分治一层（m 个操作各一次树操作）O(m log n)
整体（共 log V 层，约 30 层）O((n log n + m log n) log V)

m = 2 × 10⁵、log V = 30 时大约是 10⁸ 量级，树状数组常数小，配合 O(2) 的优化可以通过。

六、最后

这题的两处转折值得记：一是判定改成数「有没有」，把求最大值换成比两个数；二是路径加用点差分塞进 dfn 序，让判定结构仍然是树状数组。下一节的判定还要再加一层，路径与路径的包含关系要先转成平面上的矩形。
