值域区间里有数吗：美味与宝石

前两页的 trie 负责回答「集合里有没有一个数能和 x 异或出某一位的 1」。这一页两道题要做的事情多一层：可选集合有了额外限制，一个数要先满足某种范围，才轮到异或登场。限制的形状不同，工具也跟着换。

一、题目4：美味

给定数组 arr，m 条查询 b x l r：从 arr[l..r] 里选一个数 a，希望 b ^ (a + x) 最大，打印这个值。n、m 到 2 × 10⁵，值小于 10⁵。题目链接 P3293。

朴素做法是枚举 l 到 r 的每个数算一遍，一次 O(n)，m 一乘就是 4 × 10¹⁰。

换个角度。把 a + x 记成 v，要最大化的是 b ^ v，那就从高位到低位一位一位地把 v 定下来。已经定好的高位记作 best，看第 i 位时：

b 的这一位是 1，我们希望 v 的这一位是 0，v 落在 [best, best + 2^i - 1]；b 的这一位是 0，我们希望 v 的这一位是 1，v 落在 [best + 2^i, best + 2^(i+1) - 1]。而 v = a + x，把区间整体减 x，就是 a 应该落在的值域区间。

于是问题变成了：arr[l..r] 里有没有数落在某个值域区间 [L, R]。这是可持久化权值线段树的本职：root[i] 插入 arr[1..i]，两个版本一减得到区间内的计数。

    
int query(int jobl, int jobr, int l, int r, int u, int v) {
        if (jobr < l || jobl > r) {
            return 0;
        }
        if (jobl <= l && r <= jobr) {
            return siz[v] - siz[u];
        }
        int mid = (l + r) / 2;
        int ans = 0;
        if (jobl <= mid) {
            ans += query(jobl, jobr, l, mid, ls[u], ls[v]);
        }
        if (jobr > mid) {
            ans += query(jobl, jobr, mid + 1, r, rs[u], rs[v]);
        }
        return ans;
    }

外面套一层逐位试探，就是整个 compute。

    
int compute(int b, int x, int l, int r) {
        int best = 0;
        for (int i = BIT; i >= 0; i--) {
            if (((b >> i) & 1) == 1) {
                if (query(best - x, best + (1 << i) - 1 - x, 0, s, root[l - 1], root[r]) == 0) {
                    best += 1 << i;
                }
            } else {
                if (query(best + (1 << i) - x, best + (1 << (i + 1)) - 1 - x, 0, s, root[l - 1], root[r]) != 0) {
                    best += 1 << i;
                }
            }
        }
        return best ^ b;
    }

注意 best 的初值是 0，它表示 v 的高位前缀，最后返回 best ^ b。另外 x 被减掉之后区间可能整体跑到值域外面，query 开头的越界判断会直接返回 0，不用额外裁剪。

二、题目5：生成能量密度最大的宝石

长度为 n 的数组 arr，没有重复数字。随便选一个长度至少是 2 的子数组，它必有次大值；次大值与「子数组里除它之外任选一个数字」的异或最大值，叫做这个子数组的能量密度。求最大的能量密度。n 到 5 × 10⁴，值到 10⁹。题目链接 P4098。

枚举子数组是 O(n²)，每个还要找出次大值、再 scan 一遍，到 10¹⁴ 去了。

换个枚举对象：枚举谁是次大值。设当前是位置 i，值是 w。要让 w 当次大值，子数组里只能有一个比 w 大的数，它就是最大值。记位置 i 左边第一个比 w 大的是 L1、第二个是 L2，右边第一个是 R1、第二个是 R2。

最大值取 L1 时，另一个位置可以落在 [L2+1, R1-1]，再往外就会捎进来第三个比 w 大的数，w 就掉到第三大去了。最大值取 R1 时同理，范围是 [L1, R2-1]。所以每个 i 只查两次。

怎么找这四个位置。把下标按值从小到大排序，依次从双向链表里摘掉。轮到自己时，链表里剩下的都是值比自己大的位置，左右邻居就是 L1 和 R1，再往外一格是 L2 和 R2。

版本按下标排：root[i] 是原始数组里位置 1 到 i 的前缀版本。这里有个容易绕错的点，链表里摘掉的位置只是不再参与「找 L1、R1」，查询区间里的数一个都不少，[L2+1, R1-1] 里比 w 小的那些数照样可以拿来配对。

    
void prepare() {
        last[0] = 0;
        nxt[0] = 1;
        last[n + 1] = n;
        nxt[n + 1] = n + 1;
        for (int i = 1; i <= n; i++) {
            root[i] = insert(arr[i].second, root[i - 1]);
            last[i] = i - 1;
            nxt[i] = i + 1;
        }
        sort(arr.begin() + 1, arr.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
            return a.second < b.second;
        });
    }
    
int compute() {
        int ans = 0;
        for (int i = 1, index, value, l1, l2, r1, r2; i <= n; i++) {
            index = arr[i].first;
            value = arr[i].second;
            l1 = last[index];
            l2 = last[l1];
            r1 = nxt[index];
            r2 = nxt[r1];
            if (l1 != 0) {
                ans = max(ans, query(value, root[l2], root[r1 - 1]));
            }
            if (r1 != n + 1) {
                ans = max(ans, query(value, root[l1], root[r2 - 1]));
            }
            nxt[l1] = r1;
            last[r1] = l1;
        }
        return ans;
    }
arr = [3, 1, 4, 2, 5]，按值从小到大摘五步

橙色是当前的 i，蓝色两个候选区间取最大异或。

候选区间 [L2+1, R1-1] 候选区间 [L1, R2-1] 已经从链表里摘掉

复杂度分析

s 是值的上界，题4 里 BIT = 18（值小于 10⁵ 需要 17 位，加一是保险）。题5 的 BIT = 30，因为值到 10⁹。

项目时间空间
题4 建 n 个版本O(n log s)O(n log s)
题4 一次值域计数O(log s)—
题4 一次查询（BIT + 1 次计数）O(BIT · log s)同上
题5 排序O(n log n)O(n)
题5 建 n 个版本O(n · BIT)O(n · BIT)
题5 枚举 n 个位置O(n · BIT)同上

题4 的线段树是「先 build 一棵空树再往上插入」，根节点一式两份下去，节点数约 2·s + n·log s，代码开 MAXT = 4000001。题5 的 MAXN 只有 50002，所以 MAXT 开 MAXN * 32 就够了。

最后

这两道题的套路是一句话：把「一步登天的最大值」拆成「一位一位地把答案定下来」，每一位落地都要有人回答「这一支有没有数」。谁回答取决于限制长什么样，限制在值域就用权值线段树，限制在位置区间就用 trie 的版本差。
