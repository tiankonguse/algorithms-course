二元一次不定方程：通解与最小正解

ax + by = c 什么时候有整数解？有解时有多少组、x 的最小正值怎么求？答案全挂在 gcd 上：c 是 gcd(a,b) 的倍数就有解，有解就有无穷多组，全部解能用 exgcd 的一组特解加两个固定步长列出来。

零、背景

形如 ax + by = c（a、b、c 是整数，a、b 不全为 0）的方程叫二元一次不定方程，也叫丢番图方程。上节课已经有一个结论：ax + by = c 有整数解，当且仅当 c 是 d = gcd(a,b) 的整数倍。这页把它变成能直接算的工具：解有几组、每组怎么表示、题目要的最小正 x、y 怎么取出来。

以 2x + 3y = 13 为例。gcd(2,3)=1，1 整除 13，方程有解。凑一下：x=2、y=3 是一组，x=5、y=1 也是一组。解不是孤立的，x 每加 3、y 相应减 2，就得到下一组。这个「每加/减多少」的节奏，正是通解公式的来源。

一、通解：一组特解 + 两个固定步长

先看 d = gcd(a,b) 的情形。上节课的扩展欧几里得算法给出 ax + by = d 的一组特解 (x0, y0)。把它变成通解：x = x0 + (b/d)·n，y = y0 − (a/d)·n，n 取任意整数。代入验证：a·(x0 + (b/d)n) + b·(y0 − (a/d)n) = ax0 + by0 + (ab/d − ab/d)·n = d。n 每变 1，x 动 b/d、y 反向动 a/d，步长由 d 决定。

回到 ax + by = c。c = d·k（k = c/d），把特解整体放大 k 倍：x0' = x0·k，y0' = y0·k 是原方程的一组特解，通解照抄步长：x = x0' + (b/d)·n，y = y0' − (a/d)·n。

a、b 互质时 d = 1，步长就是 b 和 −a，解点像楼梯一样整齐地铺满整条线。

解永远沿同一方向排：x 增、y 减（b/d 和 a/d 都非负，符号相反）。所以「正整数解有多少组」不需要枚举，看 y 能取几个正值就知道。

二、最小正 x：把特解挪进区间

题目要 x 的最小正整数值。x 以 b/d 为步长铺在数轴上，任意整数解都能通过加减步长挪到 (0, b/d] 区间里，那个位置就是最小正 x。对应地 y 跟着反向挪。挪法是整除法直接算，不用循环：x 偏小时往上加、x 已经为正时往下减，一步到位。

挪完 x 再看 y。y 也是正数，说明存在正整数解；y 不是正数，说明整条解链上 y 都是负的（y 随 x 增大单调减小），此时没有正整数解，但要输出 x 的最小正值和 y 的最小正值。

三、模板实现

全局变量版 exgcd 先求 (d, x0, y0)，再在主流程里放大、挪 x、判 y。三个分支对应三种输出：无解、无正整数解、有正整数解。

long long d, x, y, px, py;

    void exgcd(long long a, long long b) {
        if (b == 0) {
            d = a;
            x = 1;
            y = 0;
        } else {
            exgcd(b, a % b);
            px = x;
            py = y;
            x = py;
            y = px - py * (a / b);
        }
    }
int main() {
        int cases;
        scanf("%d", &cases);
        for (int t = 1; t <= cases; t++) {
            long long a, b, c;
            scanf("%lld %lld %lld", &a, &b, &c);
            exgcd(a, b);
            if (c % d != 0) {
                printf("-1\n");
            } else {
                x *= c / d;
                y *= c / d;
                long long xd = b / d;
                long long yd = a / d;
                if (x < 0) {
                    long long times = (xd - x) / xd;
                    x += xd * times;
                    y -= yd * times;
                } else {
                    long long times = (x - 1) / xd;
                    x -= xd * times;
                    y += yd * times;
                }
                if (y <= 0) {
                    printf("%lld ", x);
                    printf("%lld\n", y + yd * ((yd - y) / yd));
                } else {
                    printf("%lld ", (y - 1) / yd + 1);
                    printf("%lld ", x);
                    printf("%lld ", y - (y - 1) / yd * yd);
                    printf("%lld ", x + (y - 1) / yd * xd);
                    printf("%lld\n", y);
                }
            }
        }
        return 0;
    }

四、正整数解的数量与最值

x 挪到最小正后，x 每加一个 b/d，y 就减一个 a/d。y 从当前值往下数，还能减 (y−1)/a·d 次才到 1，所以正整数解的数量是 (y−1)/a·d + 1。这数量同时也是「x 还能往右挪几步」，x 的最大正值 = 最小正 x + 步数·(b/d)。y 的最小正值 = y − 步数·(a/d)，y 的最大正值就是当前 y。

四种值一页算完：数量、x 的最小/最大正值、y 的最小/最大正值，全是整除法，没有一处要枚举。

总结

ax + by = c 的求解分三步：c 不被 gcd(a,b) 整除 → 无解；exgcd 出特解后放大 c/d；把 x 挪进 (0, b/d]，由 y 的正负判定正整数解是否存在。通解公式 x = x0' + (b/d)n、y = y0' − (a/d)n 同时给出数量与最值，不需要枚举。下一页的青蛙约会，就是把这个模板套到同余方程上。
