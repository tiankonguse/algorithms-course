分块结合可撤销并查集

前面分块的对象都是数组的位置。这一节换个对象：分的是「操作序列」和「边序列」。两道题都是图论题，共同骨架是，块里不变的那部分先排好序、按查询的关键字单调加进并查集；块里会变的那部分，对每个查询临时加进去、查完立刻撤销。

零、背景

可撤销并查集和普通的并查集只差一点：不做路径压缩，只按大小合并，每次合并把 (fx, fy, siz[fx]) 压进一个栈。要撤销时从栈顶一路弹回去，把 fa[fy] = fy、siz[fx] 还原，就回到合并前的样子。记下当时的栈深 opsize，就能一次撤销到那个时刻。

路径压缩会破坏树形，所以撤销版本不能压缩，find 是 O(log n) 而不是 α(n)。这一点会写进后面的块长里。

一、题目1：桥梁

n 个点的无向图，m 条边，边权同时也是限重：车重不超过限重才能过。q 条操作，操作 1 把某条边的限重改掉，操作 2 问从某点出发、车重为 car 能到达几个不同的点。n ≤ 5×10⁴，m、q ≤ 10⁵。测试链接：洛谷 P5443。

一次查询要做的事是：把所有限重 ≥ car 的边加进并查集，看点所在的集合有多大。带修改就没法一次性加完，这是时间分块的典型场景。

二、时间分块

把 q 条操作按顺序切成块，块长取 sqrt(q · log₂n)。对每个块，块内的边分成两类：会被本块修改的边（change 标记），和本块内始终不变的边。

不变的边可以放心地按限重降序加进并查集，加进去就不撤；会变的边对每个查询单独判断当时的权值，临时加、查完撤销。

三、块内怎么跑

块内的查询按车重从大到小排序。指针 j 只往前走，把 w[edge[j]] >= car 的不变边依次合并进去，所有查询加起来只扫一遍边表。

轮到某个查询时，先记下 opsize，再把本块里那些修改边按「这条查询发生前最后一次修改」的权值算一遍：≥ car 就临时合并。答案取 siz[find(nid)]，然后撤销到刚才记下的 opsize。

这里有个细节：块内的修改边最多块长条，所以每个查询的临时合并是 O(块长) 次，这是块长不能取太大的原因之一；反过来块长太小，块数就多，每块要扫一遍 m 条边，这是块长不能太小的原因。

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    const int MAXM = 100001;
    const int MAXQ = 100001;
    int n, m, q;
    int blen, bnum;

    int u[MAXM];
    int v[MAXM];
    int w[MAXM];

    int op[MAXQ];
    int eid[MAXQ];
    int tow[MAXQ];
    int nid[MAXQ];
    int car[MAXQ];

    int edge[MAXM];
    bool change[MAXM];
    int curw[MAXM];

    int operate[MAXQ];
    int query[MAXQ];
    int update[MAXQ];

    int fa[MAXN];
    int siz[MAXN];
    int rollback[MAXM][2];
    int opsize = 0;

    int arr1[MAXM];
    int arr2[MAXM];

    int ans[MAXQ];

    void build() {
        for (int i = 1; i <= n; i++) {
            fa[i] = i;
            siz[i] = 1;
        }
    }

    int find(int x) {
        while (x != fa[x]) {
            x = fa[x];
        }
        return x;
    }

    void Union(int x, int y) {
        int fx = find(x), fy = find(y);
        if (fx == fy) {
            return;
        }
        if (siz[fx] < siz[fy]) {
            swap(fx, fy);
        }
        fa[fy] = fx;
        siz[fx] += siz[fy];
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
    }

    void undo() {
        for (int fx, fy; opsize > 0; opsize--) {
            fx = rollback[opsize][0];
            fy = rollback[opsize][1];
            fa[fy] = fy;
            siz[fx] -= siz[fy];
        }
    }

    void merge() {
        int siz1 = 0, siz2 = 0;
        for (int i = 1; i <= m; i++) {
            if (change[edge[i]]) {
                arr1[++siz1] = edge[i];
            } else {
                arr2[++siz2] = edge[i];
            }
        }
        sort(arr1 + 1, arr1 + siz1 + 1, [&](int x, int y) { return w[x] > w[y]; });
        int i = 0, p1 = 1, p2 = 1;
        while (p1 <= siz1 && p2 <= siz2) {
            edge[++i] = w[arr1[p1]] >= w[arr2[p2]] ? arr1[p1++] : arr2[p2++];
        }
        while (p1 <= siz1) {
            edge[++i] = arr1[p1++];
        }
        while (p2 <= siz2) {
            edge[++i] = arr2[p2++];
        }
    }

    void compute(int l, int r) {
        build();
        memset(change + 1, 0, m * sizeof(bool));
        int cntu = 0, cntq = 0;
        for (int i = l; i <= r; i++) {
            if (op[operate[i]] == 1) {
                change[eid[operate[i]]] = true;
                update[++cntu] = operate[i];
            } else {
                query[++cntq] = operate[i];
            }
        }
        sort(query + 1, query + cntq + 1, [&](int x, int y) { return car[x] > car[y]; });
        for (int i = 1, j = 1; i <= cntq; i++) {
            while (j <= m && w[edge[j]] >= car[query[i]]) {
                if (!change[edge[j]]) {
                    Union(u[edge[j]], v[edge[j]]);
                }
                j++;
            }
            opsize = 0;
            for (int k = 1; k <= cntu; k++) {
                curw[eid[update[k]]] = w[eid[update[k]]];
            }
            for (int k = 1; k <= cntu && update[k] < query[i]; k++) {
                curw[eid[update[k]]] = tow[update[k]];
            }
            for (int k = 1; k <= cntu; k++) {
                if (curw[eid[update[k]]] >= car[query[i]]) {
                    Union(u[eid[update[k]]], v[eid[update[k]]]);
                }
            }
            ans[query[i]] = siz[find(nid[query[i]])];
            undo();
        }
        for (int i = 1; i <= cntu; i++) {
            w[eid[update[i]]] = tow[update[i]];
        }
        merge();
    }

    void prepare() {
        blen = max(1, (int)sqrt(q * log2(n)));
        bnum = (q + blen - 1) / blen;
        sort(edge + 1, edge + m + 1, [&](int x, int y) { return w[x] > w[y]; });
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> u[i] >> v[i] >> w[i];
            edge[i] = i;
        }
        cin >> q;
        for (int i = 1; i <= q; i++) {
            cin >> op[i];
            if (op[i] == 1) {
                cin >> eid[i] >> tow[i];
            } else {
                cin >> nid[i] >> car[i];
            }
            operate[i] = i;
        }
        prepare();
        for (int i = 1, l, r; i <= bnum; i++) {
            l = (i - 1) * blen + 1;
            r = min(i * blen, q);
            compute(l, r);
        }
        for (int i = 1; i <= q; i++) {
            if (op[i] == 2) {
                cout << ans[i] << '\n';
            }
        }
        return 0;
    }
一个块内的两次查询

四个点三条边：1-2 限重 5、2-3 限重 3、3-4 限重 7。块内操作是先查（车重 4），再把边 2 改成 6，再查（车重 6）。点「下一步」看哪些边常驻、哪些临时加、撤销撤到哪。

常驻在并查集里的边 本次临时加的边 还没加 / 加不进

四、题目2：最小公倍数

n 个点的无向图，边权形如 2ᵃ · 3ᵇ。q 次查询，每次问：从 u 出发能不能走到 v，且路径上所有边权的最小公倍数恰好是 2ᵃ · 3ᵇ。n、q ≤ 5×10⁴，m ≤ 10⁵。测试链接：洛谷 P3247。

最小公倍数在每个质因子上取指数最大值，所以问题等价于：存在一条 u 到 v 的路径，路径上每条边都满足 aᵢ ≤ a 且 bᵢ ≤ b，并且至少有一条边取到 a、至少有一条边取到 b。

第二条是关键。它要求路径上必须有一条边，其 aᵢ 恰好等于 a。把边按 a 排序之后，这样的边落在哪个块里是唯一确定的，这是这题能分块的原因。

归属条件写成 ea[edge[l]] <= qa && (r+1 > m || qa < ea[edge[r+1]])。这个条件同时保证两件事：前缀 edge[1..l-1] 里所有边的 a 都不超过 qa；a 大于 qa 的边既不在前缀里、也不在块内，天然被排除。

于是并查集里的边就是「aᵢ ≤ qa 且 bᵢ ≤ qb」的全部边：前缀的那部分按 b 升序排序后双指针加入（查询也按 b 升序排过），块内的那部分逐个判断后临时加入，查完撤销。

判定的时候除了 find(u) == find(v)，还要看集合上的 maxa == qa 且 maxb == qb。这两个最大值是并查集根上额外维护的，合并时取两边最大值再和当前边的指数取 max，撤销时一并还原。

为什么最大可以取在整个连通块上，而不是某一条具体的路径上：路径允许重复走边，一条走法可以在连通块里绕一圈把需要的边都走一遍，所以两个最大值能同时在一条路径上达成。

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    const int MAXM = 100001;
    const int MAXQ = 50001;
    int n, m, q;
    int blen, bnum;

    int eu[MAXM];
    int ev[MAXM];
    int ea[MAXM];
    int eb[MAXM];

    int qu[MAXQ];
    int qv[MAXQ];
    int qa[MAXQ];
    int qb[MAXQ];

    int edge[MAXM];
    int query[MAXQ];

    int cur[MAXQ];
    int cursiz;

    int fa[MAXN];
    int siz[MAXN];
    int maxa[MAXN];
    int maxb[MAXN];
    int rollback[MAXN][5];
    int opsize = 0;

    bool ans[MAXQ];

    void build() {
        for (int i = 1; i <= n; i++) {
            fa[i] = i;
            siz[i] = 1;
            maxa[i] = -1;
            maxb[i] = -1;
        }
    }

    int find(int x) {
        while (x != fa[x]) {
            x = fa[x];
        }
        return x;
    }

    void Union(int x, int y, int a, int b) {
        int fx = find(x), fy = find(y);
        if (siz[fx] < siz[fy]) {
            swap(fx, fy);
        }
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
        rollback[opsize][2] = siz[fx];
        rollback[opsize][3] = maxa[fx];
        rollback[opsize][4] = maxb[fx];
        if (fx != fy) {
            fa[fy] = fx;
            siz[fx] += siz[fy];
        }
        maxa[fx] = max(max(maxa[fx], maxa[fy]), a);
        maxb[fx] = max(max(maxb[fx], maxb[fy]), b);
    }

    void undo() {
        for (int fx, fy; opsize > 0; opsize--) {
            fx = rollback[opsize][0];
            fy = rollback[opsize][1];
            fa[fy] = fy;
            siz[fx] = rollback[opsize][2];
            maxa[fx] = rollback[opsize][3];
            maxb[fx] = rollback[opsize][4];
        }
    }

    bool check(int x, int y, int a, int b) {
        int fx = find(x), fy = find(y);
        return fx == fy && maxa[fx] == a && maxb[fx] == b;
    }

    void compute(int l, int r) {
        cursiz = 0;
        for (int i = 1; i <= q; i++) {
            if (ea[edge[l]] <= qa[query[i]] && (r + 1 > m || qa[query[i]] < ea[edge[r + 1]])) {
                cur[++cursiz] = query[i];
            }
        }
        if (cursiz > 0) {
            build();
            sort(edge + 1, edge + l, [&](int x, int y) { return eb[x] < eb[y]; });
            for (int i = 1, j = 1; i <= cursiz; i++) {
                while (j < l && eb[edge[j]] <= qb[cur[i]]) {
                    Union(eu[edge[j]], ev[edge[j]], ea[edge[j]], eb[edge[j]]);
                    j++;
                }
                opsize = 0;
                for (int k = l; k <= r; k++) {
                    if (ea[edge[k]] <= qa[cur[i]] && eb[edge[k]] <= qb[cur[i]]) {
                	      Union(eu[edge[k]], ev[edge[k]], ea[edge[k]], eb[edge[k]]);
                    }
                }
                ans[cur[i]] = check(qu[cur[i]], qv[cur[i]], qa[cur[i]], qb[cur[i]]);
                undo();
            }
        }
    }

    void prepare() {
        blen = max(1, (int)sqrt(m * log2(n)));
        bnum = (m + blen - 1) / blen;
        sort(edge + 1, edge + m + 1, [&](int x, int y) { return ea[x] < ea[y]; });
        sort(query + 1, query + q + 1, [&](int x, int y) { return qb[x] < qb[y]; });
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> eu[i] >> ev[i] >> ea[i] >> eb[i];
            edge[i] = i;
        }
        cin >> q;
        for (int i = 1; i <= q; i++) {
            cin >> qu[i] >> qv[i] >> qa[i] >> qb[i];
            query[i] = i;
        }
        prepare();
        for (int i = 1, l, r; i <= bnum; i++) {
            l = (i - 1) * blen + 1;
            r = min(i * blen, m);
            compute(l, r);
        }
        for (int i = 1; i <= q; i++) {
            cout << (ans[i] ? "Yes" : "No") << '\n';
        }
        return 0;
    }

五、复杂度分析

桥梁：设块长 B、块数 q/B。每块的代价是「扫一遍边表 O(m)」+「排序查询 O(B log B)」+「每个查询处理块内改边 O(B²)」，出块时再归并一次 O(m)。

最小公倍数：每块的代价是「给前缀排序 O(m log m)」+「每个查询处理块内边 O(B)」，全部查询只归属一个块，所以块内处理总共 O(q·B)。

操作时间复杂度空间复杂度
桥梁：进一个块（分边 + 归并 + 排序查询）O(m + B log B)O(n + m + q)：边与操作各存一份，并查集的 fa / siz 开 n 个，回滚栈开块长量级；最小公倍数那题回滚栈每条记录五项，开 n 个
桥梁：块内查询（双指针加边 + 临时改边）O(m + B²)
桥梁：全部O((q/B) · m + q · B)
最小公倍数：进一个块（前缀按 b 排序）O(m log m)
最小公倍数：全部O((m/B) · m log m + q · B)

桥梁那题平衡 m·q/B 与 q·B，理论最优是 B = √m；代码取 sqrt(q · log₂n) 偏大一些，因为撤销版并查集的 find 是 O(log n)，块内那 B 条临时边的常数比排序的常数重。最小公倍数那题取 sqrt(m · log₂n)，同理。

六、最后

两块题的骨架是一样的：把「会变的东西」限制在一个块里，块外那部分就能预先排序、单调地加进并查集；块内那部分对每个查询临时加、查完撤销。时间分块切的是操作序列，边分块切的是排好序的边表，切什么取决于「什么在变」。
