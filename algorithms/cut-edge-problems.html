割边与边双的应用

上一页把求割边和边双缩点两个模版讲完了。这一页看四道题怎么用它们：一条边两侧各有多少个服务点、无桥时怎么给无向边定向、加边之后桥数怎么跟着变、最少补几条边能让整张图没有桥。缩点这段代码四道题一字不改，变的只有缩点之后那几行。

零、背景

四道题都建立在同一个事实上：桥两侧的点集被这条桥唯一地分开，删掉桥，两边就再也走不通。所以「断开某条边会发生什么」这个问题，只需要看这条边两侧各有什么。

边双内部没有桥，一块里的点可以互相绕过去，缩点之后进一步只剩一棵树。树上一删边就分成两棵子树，这个结构比原图干净得多，四道题的收尾都在树上完成。

一、题目3：关键网络线路

连通无向图，k 个点提供 A 服务，l 个点提供 B 服务，k、l 都是正数。一个点可以两种服务都有、都不有、或者只有一种。服务顺着边传播，但要求每个点都能同时拿到 A 和 B。如果删掉某条边后，有节点拿不到两种服务中的至少一种，这条边叫关键边，求关键边的数量和端点。

一条边是不是关键，要看它是不是桥。不是桥的边删了不影响连通，服务照样传得到，永远不关键。所以只需在割边的判定处额外看一下这条桥两侧的服务分布。

设桥是 u-v，v 是下面那侧，子树 v 记 acnt[v] 个 A 服务点、bcnt[v] 个 B 服务点。删掉 u-v 后，子树 v 和外界的服务被隔开，于是有两种情况会出问题。

一是子树 v 里缺 A 或缺 B，里面的点拿不齐两种服务；二是子树 v 里凑齐了全部 A（acnt[v] == k）或全部 B（bcnt[v] == l），外面的点失去了唯一的来源。两种情况用子树和一次判断即可，跟 tarjan 的回溯同步完成。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 1000001;
    int n, m, k, l;
    int acnt[MAXN];
    int bcnt[MAXN];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int ans1[MAXN];
    int ans2[MAXN];
    int cnta;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
                if (low[v] > dfn[u]) {
                    if (acnt[v] == 0 || acnt[v] == k || bcnt[v] == 0 || bcnt[v] == l) {
                        cnta++;
                        ans1[cnta] = v;
                        ans2[cnta] = u;
                    }
                }
                acnt[u] += acnt[v];
                bcnt[u] += bcnt[v];
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m >> k >> l;
        for (int i = 1, x; i <= k; i++) {
            cin >> x;
            acnt[x] = 1;
        }
        for (int i = 1, x; i <= l; i++) {
            cin >> x;
            bcnt[x] = 1;
        }
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        tarjan(1, 0);
        cout << cnta << "\n";
        for (int i = 1; i <= cnta; i++) {
            cout << ans1[i] << " " << ans2[i] << "\n";
        }
        return 0;
    }

二、题目4：贝尔敦道路

连通无向图，给每条边指定一个方向变成有向边，要求任意两点互相可达。无解输出 0，有解输出每条边的方向。

先看桥。桥的两个端点之间只有这一条路，定向之后必然只有单向，两点不可能互相可达，所以只要有一处桥就无解。

没有桥时一定有解，这是定向问题的经典结论：一个连通图能定向成强连通图，当且仅当它没有桥。构造方法就藏在 dfs 树里。

树边从父指向子，回边从后代指向祖先（也就是 dfn 大的点指向 dfn 小的点）。这样每个点都能沿树边一路向下走到后代，也能沿一条回边跳回某个祖先，环环相扣，整张图就强连通了。

代码里这两件事挤在一条判断上：遍历到边 u-v 时，若 dfn[v] == 0（树边，v 在后）或 dfn[v] < dfn[u]（回边，后代指向祖先），就把方向记成 u→v。同时用 check 记录是否遇到过桥，遇到就无解。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 300001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    bool check;
    int ans1[MAXM];
    int ans2[MAXM];
    int cnta;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0 || dfn[v] < dfn[u]) {
                cnta++;
                ans1[cnta] = u;
                ans2[cnta] = v;
            }
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
                if (low[v] > dfn[u]) {
                    check = false;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        check = true;
        tarjan(1, 0);
        if (!check) {
            cout << 0 << "\n";
        } else {
            for (int i = 1; i <= m; i++) {
                cout << ans1[i] << " " << ans2[i] << "\n";
            }
        }
        return 0;
    }

三、题目6：网络

连通无向图，q 次操作，每次在 x、y 之间新增一条边，打印此时图中桥的数量。

先一遍 tarjan 把原图缩点成一棵树，每条树边对应原来的一条桥。每次加一条边 x-y，等价于在树上 x 到 y 的路径上补了一条边，路径上的每条树边都落进了一个新环，从此不再是桥。

于是每加入一条边，就把树上这条路径上的边全部「合并」掉。用并查集维护：每个点存它往上走第一个还带着桥的祖先，加边时从较深的一端不断往上并，直到两端并到一起。并查集带路径压缩，整个过程的均摊代价很低。

设当前还有 ebccCnt 个连通块，缩点树就有 ebccCnt - 1 条边，也就是当前桥的数量。每合并一次就让 ebccCnt 减一，所以每次输出 ebccCnt - 1 即可。

加边之后，桥是怎么一条条消失的

缩点后的树，每条树边原本都是桥。点「下一步」加一条边，看树上路径被圈起来、路径上的桥用并查集合并掉，桥的数量随之下降。

本次加入的边 已合并（不再是桥） 仍是桥

完整代码：

#include <iostream>
    #include <algorithm>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 200001;
    int t, n, m, q;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int ebccCnt;

    int up[MAXN];
    int dep[MAXN];
    int fa[MAXN];

    void prepare() {
        cntg = 1;
        cntd = top = ebccCnt = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = dfn[i] = low[i] = 0;
        }
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    void dfs(int u, int f) {
        dep[u] = dep[f] + 1;
        up[u] = f;
        fa[u] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != f) {
                dfs(v, u);
            }
        }
    }

    int find(int i) {
        if (i != fa[i]) {
            fa[i] = find(fa[i]);
        }
        return fa[i];
    }

    void Union(int x, int y) {
        x = find(x);
        y = find(y);
        if (x != y) {
            if (dep[x] < dep[y]) {
                fa[y] = x;
            } else {
                fa[x] = y;
            }
        }
    }

    void link(int x, int y) {
        x = find(belong[x]);
        y = find(belong[y]);
        while (x != y) {
            if (dep[x] >= dep[y]) {
                Union(x, up[x]);
                x = find(x);
            } else {
                Union(y, up[y]);
                y = find(y);
            }
            ebccCnt--;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        t = 0;
        cin >> n >> m;
        while (n != 0 || m != 0) {
            prepare();
            for (int i = 1; i <= m; i++) {
                cin >> a[i] >> b[i];
                addEdge(a[i], b[i]);
                addEdge(b[i], a[i]);
            }
            tarjan(1, 0);
            condense();
            dfs(1, 0);
            cout << "Case " << (++t) << ":\n";
            cin >> q;
            for (int i = 1, x, y; i <= q; i++) {
                cin >> x >> y;
                link(x, y);
                cout << ebccCnt - 1 << "\n";
            }
            cout << "\n";
            cin >> n >> m;
        }
        return 0;
    }

四、题目7：冗余路径

连通无向图，问至少添加几条边，能让整张图变成一个边双连通分量。

还是先缩点。目标「整张图没有桥」等价于「缩点树上的每条边都消失」。第一次 tarjan 之后，问题变成：给一棵树加最少的边，让它每条边都落在某个环上。

树上的桥要成环，得靠叶子对儿牵线。数一遍度数为 1 的叶子数 leaf，每加一条边可以连接两个叶子，让它们之间路径上的所有桥一起成环。所以最少要加 (leaf + 1) / 2 条边：把叶子两两配对连接即可。

实现上只要在缩点后重新数一遍每个边双的度数，度数为 1 的个数就是 leaf。不用真的建出树，直接扫原图的每条边，两端点属于不同边双就给各自度数加一。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 5001;
    const int MAXM = 10001;
    int n, m;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int ebccCnt;

    int degree[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    int getLeaf() {
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                degree[ebcc1]++;
                degree[ebcc2]++;
            }
        }
        int ans = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            if (degree[i] == 1) {
                ans++;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
            addEdge(b[i], a[i]);
        }
        tarjan(1, 0);
        int leafCnt = getLeaf();
        cout << (leafCnt + 1) / 2 << "\n";
        return 0;
    }

五、复杂度分析

四道题都先跑一遍 tarjan，后面要么一遍线性扫描，要么并查集均摊。

操作时间复杂度空间复杂度
题目3：tarjan + 子树服务计数O(n + m)O(n + m)（前向星 2m 条有向边 + dfn / low / 栈 / 并查集）
题目4：tarjan 顺手定向O(n + m)
题目6：缩点 + dfs 预处理；每次加边并查集合并O(n + m) / 均摊 O(α(n))
题目7：缩点 + 扫边数叶子O(n + m)

题目6 的并查集带路径压缩、按深度合并，每条桥一生只会被合并一次，q 次操作合起来仍是接近线性的。题目3、题目4、题目7 都只多扫一遍边表，没有额外对数因子。

六、最后

四道题放到一起看，套路只有一条：先问「删掉这条边会怎样」，答案一定落在桥两侧的点集上；再把图缩点成树，把「边」的问题换成「树上路径 / 子树」的问题。

割边和边双这一支到这里收尾，下一讲在缩点后的树上做更细的活：先看一条路径最多能跨过多少座桥，也就是树的直径。
