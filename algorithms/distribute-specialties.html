分特产：隔板法当钦定，形式四抠恰好

m 种特产、第 j 种有 arr[j] 个，分给 n 个同学，要求每个同学至少拿到一个特产。同一种特产之间不区分。直接数「每人至少一个」麻烦，先数「钦定 i 个同学空手」就只剩隔板法，最后形式四反演把空手数抠回 0。

零、隔板法

a 个相同的物品分给 b 个人，允许有人空手，等价于 a 个物品排成一列、插 b−1 块板：C(a+b−1, b−1)。要求每人至少 1 个，先每人发 1 个，剩下 a−b 个再随便分：C(a−b+b−1, b−1) = C(a−1, b−1)。

图上 5 个球分给 3 个人（允许空手）：4 个空隙里选 2 个插板，C(6,2)=15 种（含空手）；每人至少 1 个：先拿掉 3 个球只剩 2 个，C(4,2)=6 种。

分特产时每种特产独立：第 j 种特产 arr[j] 个分给某 b 个人（可空），C(arr[j]+b−1, b−1) 种；要求每人至少一个特产是「跨种类的整体要求」，不是每种特产都分到每个人。

一、钦定 i 个同学空手

钦定哪 i 个同学空手：C(n,i)。剩下 n−i 个同学每种特产随便分（可空），第 j 种 C(arr[j]+n−i−1, n−i−1)。乘积：

g(i) = C(n,i) · Πj=1..m C(arr[j]+n−i−1, n−i−1)

g(i) 是「钦定至少 i 个同学空手」的方案数。题目要「恰好 0 个空手」，形式四反演（n=0）：

答案 = Σi=0..n (−1)^i · g(i)

图上 n=3 个同学、2 种特产（arr = [2, 1]）。钦定 i=1 个同学空手：3 种选法，剩下 2 人分 2 个特产 A（C(2+2−1,1)=3 种）和 1 个特产 B（C(1+2−1,1)=2 种），g(1)=3·3·2=18。反演 Σ(−1)^i g(i) 把「钦定」里的重复计数抵消，剩下恰好 0 个空手。

g(n)（钦定全部 n 个同学空手）在代码里直接置 0：m≥1 时每种特产至少 1 个，不存在能分出去的同学，全空手方案数为 0。

二、代码

隔板的行号最大到 arr[j]+n−1，n、arr[j] 都不超过 1000，所以组合表建到 2n 行就够。反演求和从 i=0 到 n 一项一项带符号累加。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 1001;
    const int MAXK = MAXN * 2;
    const int MOD = 1000000007;

    int arr[MAXN];
    long long c[MAXK][MAXK];
    long long g[MAXN];
    int n, k, m;

    int main() {
        cin >> n;
        k = n * 2;
        cin >> m;
        for (int i = 1; i <= m; i++) cin >> arr[i];
        for (int i = 0; i <= k; i++) {
            c[i][0] = 1;
            for (int j = 1; j <= i; j++) c[i][j] = (c[i - 1][j] + c[i - 1][j - 1]) % MOD;
        }
        // g[i] = 钦定 i 个同学空手，其余 n-i 个同学任意分
        // 每种特产 arr[j] 个分给 n-i 个人（可空）：隔板法 C(arr[j]+n-i-1, n-i-1)
        for (int i = 0; i < n; i++) {
            g[i] = c[n][i];
            for (int j = 1; j <= m; j++) g[i] = g[i] * c[arr[j] + n - i - 1][n - i - 1] % MOD;
        }
        g[n] = 0;
        // 形式四反演 n=0：恰好 0 个空手 = Σ (-1)^i * g[i]
        long long ans = 0;
        for (int i = 0; i <= n; i++) {
            if ((i & 1) == 0) ans = (ans + g[i]) % MOD;
            else ans = (ans + g[i] * (MOD - 1)) % MOD;
        }
        cout << ans << endl;
        return 0;
    }

演示 · g(i) 反演 vs 暴力枚举：n 个同学每人至少一个特产

总结

分特产的关键是把「每人至少一个」换成「钦定 i 个空手」：C(n,i) 选人，剩下 n−i 人每种特产隔板法 C(arr[j]+n−i−1, n−i−1)，乘起来就是 g(i)。形式四反演 n=0 直接 Σ(−1)^i g(i)。组合数表建到 2n 行覆盖隔板行号，g(n) 置 0 对应全空手方案数为 0。复杂度 O(n² + nm)。下一页糖果药片也是形式四，但 g 的「钦定」来自配对 dp，不再是隔板。
