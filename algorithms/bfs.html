BFS 广度优先搜索

从起点出发一层一层向外扩散：先走完所有距离为 1 的点，再走距离为 2 的点。于是第一次到达终点时走过的步数，就是最短步数。

零、背景

前面几节处理的都是数组和字符串。换到图上，最基础的一个问题是：从 A 到 B 最少要走几步。

只要每次移动的代价都一样，比如网格里走一格就算一步，广度优先搜索就能在线性时间里给出答案。它的名字来自访问顺序：先访问离起点近的，再访问远的。

一、问题

下面是一个 6 行 8 列的网格。S 是起点，T 是终点，# 是墙壁。每次只能向上、下、左、右走一格，不能穿墙。问从 S 到 T 最少要走几步。

二、先试试 DFS

最自然的想法是沿一个方向一直走下去，走不通了再退回来换方向，把所有能走的路都试一遍，取最小的步数。

int ans = INF;
bool vis[N][N];

void dfs(int r, int c, int d) {      // 当前在 (r,c)，已走 d 步
    if (r < 0 || r >= n || c < 0 || c >= m) return;
    if (g[r][c] == '#' || vis[r][c]) return;
    if (g[r][c] == 'T') { ans = min(ans, d); return; }
    vis[r][c] = true;                      // 踩上这个格子
    dfs(r + 1, c, d + 1);                  // 下
    dfs(r - 1, c, d + 1);                  // 上
    dfs(r, c + 1, d + 1);                  // 右
    dfs(r, c - 1, d + 1);                  // 左
    vis[r][c] = false;                     // 退回，别的路还能走
}

最后那行还原不能省，省了别的路就走不过来。可一旦还原，就得把所有可能的路都试一遍，最坏是 O(4^V)，网格稍微大一点就跑不完。

要是把还原去掉，每个格子只走一次，速度降到 O(V)，但答案不再对：第一次撞到 T 的那条路未必最短，而 T 已经标成走过，后面更短的路再也走不到了。

看下面这个小图，圆圈里的数字是 DFS 的访问顺序。

可以发现，问题不在遍历得全不全，而在顺序。DFS 的顺序是走得深，我们要的是离得近。

三、一层一层向外扩散

换个顺序：先把离 S 最近的一圈全部走完，再走下一圈。那么第一次碰到 T 时，步数自然就是最少的。

还是上面那张图，这回圆圈里的数字是到 S 的距离。

怎么保证一圈一圈地走？用队列。起点入队，距离记 0；之后反复从队首取出一个点，把它的所有还没访问过的邻居加到队尾，距离记成当前点的距离加 1；队列空了就结束。

队列是先进先出的。先被放进来的点距离小、会先被处理，它产生的邻居只能排在队尾，所以整个队列里的点始终按距离从小到大排着。

void bfs(int sr, int sc) {              // 从 (sr,sc) 出发
    memset(dist, -1, sizeof(dist));      // -1 表示还没访问过
    queue<pair<int, int>> q;
    dist[sr][sc] = 0;
    q.push({sr, sc});

    int dr[4] = {1, -1, 0, 0};             // 下 上 右 左
    int dc[4] = {0, 0, 1, -1};

    while (!q.empty()) {
        int r = q.front().first, c = q.front().second;
        q.pop();
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;  // 出界
            if (g[nr][nc] == '#') continue;                            // 墙
            if (dist[nr][nc] != -1) continue;                        // 已访问
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});                            // 排到队尾
        }
    }
}

最后那句跳过判断是 BFS 的关键。每个点只在第一次被走到时入队，越早入队距离越短，之后再遇到它就一定不划算，直接跳过。

四、为什么第一次到达就是最短

理由有两条，一起看才成立。一是队列单调：队列里各点的距离只可能是 d 或 d+1，绝不会乱序，因为距离小的点先入队、先被扩展，它产生的邻居只能排在队尾。二是距离正确：一个点第一次被走到，是从某个距离为 d 的点扩展来的，而所有距离小于 d 的点都已经扩展完了，它们都没能到达这个点，说明不存在更短的路。

下面是这张图从起点开始的前几步，左边是出队的点，右边是当时的队列。

于是第一次给 T 赋上距离时，它就是全局最短。这也是 BFS 最主要的用途：求边权全为 1 的图上的最短路。

五、完整代码

开头那道迷宫题的完整写法。

#include <bits/stdc++.h>
using namespace std;

const int N = 1005;
char g[N][N];
int dista[N][N];
int n, m, sr, sc, tr, tc;
int dr[4] = {1, -1, 0, 0};
int dc[4] = {0, 0, 1, -1};

int bfs() {
    memset(dista, -1, sizeof(dista));
    queue<pair<int, int>> q;
    dista[sr][sc] = 0;
    q.push({sr, sc});

    while (!q.empty()) {
        int r = q.front().first, c = q.front().second;
        q.pop();
        if (r == tr && c == tc) return dista[r][c];   // 第一次出队即最短
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
            if (g[nr][nc] == '#') continue;
            if (dista[nr][nc] != -1) continue;
            dista[nr][nc] = dista[r][c] + 1;
            q.push({nr, nc});
        }
    }
    return -1;                              // 走不到终点
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> g[i][j];
            if (g[i][j] == 'S') { sr = i; sc = j; }
            if (g[i][j] == 'T') { tr = i; tc = j; }
        }
    }
    cout << bfs() << endl;
    return 0;
}

六、通用图上的写法

把网格换成邻接表，同一套写法可以跑在任意无权图上。

vector<int> adj[N];        // adj[u] 存 u 的所有邻居
int distv[N];               // 到起点的最短距离，-1 表示未访问

void bfs(int s) {
    fill(distv, distv + N, -1);
    queue<int> q;
    distv[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {         // 遍历 u 的每个邻居
            if (distv[v] != -1) continue;
            distv[v] = distv[u] + 1;
            q.push(v);
        }
    }
}

七、复杂度分析

设图有 V 个点、E 条边，用邻接表存储。每个点恰好入队一次、出队一次，出队时把它的所有邻居扫一遍，所有点的邻居数之和是 2E（无向图每条边被数两次）。

操作时间复杂度
入队 / 出队一次O(1)
扩展一个点（扫它的所有邻居）O(deg(v))
全部 V 个点各扩展一次O(V + E)
网格图（n 行 m 列）O(n·m)

空间上需要 dist 数组 O(V)、队列最多同时存放 O(V) 个点、邻接表 O(V + E)，合计额外空间 O(V + E)，网格图上是 O(n·m)。

对比第二节那个 DFS：还原 vis 的版本要枚举所有路径，是指数级的 O(4^V)；不还原的版本是 O(V)，但答案不对。BFS 用 O(V + E) 拿到正确的最短路。

八、最后

BFS 的骨架就三件事：一个队列、一个 dist 数组、每个点只入队一次。它换来的是「按距离从小到大」的访问顺序，最短路是这个顺序的直接副产品。

边界也清楚：所有边的代价必须相同。一旦边有了权重，出队顺序就不再等于距离顺序，这套论证也就不成立了，那时候要换成 Dijkstra。
