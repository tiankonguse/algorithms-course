莫队 + 前缀差分

两道题的答案都不是「窗口里有什么」，而是「窗口里的元素两两配成多少对」。把区间拆成两个前缀之差，莫队维护的对象就从元素换成前缀状态。

零、背景

上一节把左指针的移动也离线掉，省下的是扫描。这一节回到窗口本身，问的是另一件事：窗口里到底该维护什么。

莫队只要求两件事：查询能离线、窗口能 O(1) 增删。至于窗口里维护的是什么，没有限制。

有一类题不一样：单个元素自己说不出答案，答案藏在元素的配对关系里。这类题常用前缀差分处理，把区间上的量写成两个前缀的差，于是窗口从原数组挪到前缀数组上，增删的还是单个元素。

下面两题一个字符串、一个数组，做法不同，思路是同一个。

一、美好的每一天

给定一个长度为 n 的字符串 str，只含小写字母。一个子串重排之后能成为回文串，就叫达标子串。m 条查询，每条给 l r，打印 str[l..r] 上有多少个达标子串。

1 ≤ n、m ≤ 6×10⁴。测试链接：P3604

二、朴素做法

枚举 str[l..r] 的每个子串，数一遍各字符的奇偶，统计至多一个奇数的有多少个。子串 O(n²) 个，每个还要数一遍，单次查询就到 O(n²) 或 O(26n²)，m 次完全跑不动。

换个角度看这个条件。重排之后能成为回文串，等价于「至多一个字符出现奇数次」。

用 26 位二进制记一个集合里各字符的奇偶：第 i 位是 1 表示第 i 个字符出现了奇数次。记 pref[i] 是 str[1..i] 的这个状态，pref[0] = 0。

那么子串 str[l..r] 的奇偶状态就是 pref[r] ^ pref[l-1]。它达标，当且仅当这个异或值里至多有一个 1 位，也就是两个前缀状态相等、或者只差一个字符。

于是查询 [l, r] 换了个说法：在状态数组 pref[0..n] 的区间 [l-1, r] 里，有多少对下标 (i, j)、i < j，满足 pref[i] 与 pref[j] 相等或只差一位。

三、窗口挪到状态数组上

问题变成了「状态数组的区间 [l-1, r] 上有多少达标对」，这正是莫队能处理的形式：窗口在 pref 数组上滑动，每次只增删一个状态。

加入状态 s 时，它和窗口里已有的每个状态都要配一次。达标的只有两类：和它相等的，以及和它差一位的（26 种）。所以新增的对数是 cnt[s] 加上 26 个 cnt[s ^ (1<<i)]。

void add(int s) {
    curAns += cnt[s];                        // 和已有状态相等的
    for (int i = 0; i < 26; i++) {
        curAns += cnt[s ^ (1 << i)];        // 和已有状态只差一位的
    }
    cnt[s]++;
}
void del(int s) {
    cnt[s]--;
    curAns -= cnt[s];
    for (int i = 0; i < 26; i++) {
        curAns -= cnt[s ^ (1 << i)];
    }
}

删除是加入的逆过程，注意先减 cnt 再算贡献，顺序反了会把自己也算进配对里。

剩下的是下标对齐。状态的编号比字符多一个，代码里把 pref 整体后移一位，让 pref[i] 落在下标 i+1 上；查询的右端点跟着加一，l 不动。写进代码就是 prepare 里那几行。

点「下一步」，看窗口在状态数组上怎么走。字符串取 abacbcac，四条查询依次是 [1,3]、[2,5]、[1,8]、[4,7]。

演示　美好的每一天：窗口在 9 个前缀状态上滑动（块大小 3）

四、题目1 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 60002;
    const int MAXV = 1 << 26;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];

    int bi[MAXN];
    int cnt[MAXV];
    long long curAns = 0;
    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if (bi[a.l] & 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void add(int s) {
        curAns += cnt[s];
        cnt[s]++;
        for (int i = 0; i < 26; i++) {
            curAns += cnt[s ^ (1 << i)];
        }
    }

    void del(int s) {
        cnt[s]--;
        curAns -= cnt[s];
        for (int i = 0; i < 26; i++) {
            curAns -= cnt[s ^ (1 << i)];
        }
    }

    void compute() {
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            ans[id] = curAns;
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            arr[i] ^= arr[i - 1];
        }
        for (int i = n; i >= 0; i--) {
            arr[i + 1] = arr[i];
        }
        n++;
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= m; i++) {
            query[i].r++;
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        char c;
        for (int i = 1; i <= n; i++) {
            cin >> c;
            arr[i] = 1 << (c - 'a');
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

五、简单的询问

给定一个长度为 n 的数组 arr，下标从 1 到 n。get(l, r, x) 表示 arr[l..r] 上 x 出现了几次。q 条查询，每条给 l1 r1 l2 r2，打印 Σx get(l1, r1, x) × get(l2, r2, x)。

1 ≤ n、q ≤ 5×10⁴，1 ≤ arr[i] ≤ n。测试链接：P5268

朴素做法是把两个区间各数一遍再对乘，单次 O(n)。

这里的量也藏在配对里：答案是两个区间的「计数向量」做内积。把 get 写成前缀之差，get(l, r, x) = P(r, x) − P(l-1, x)，两个差相乘展开成四项。

于是每条查询拆成四个子任务，每个子任务问的是「arr[1..a] 和 arr[1..b] 两个前缀的计数向量内积是多少」，带符号累加。

六、莫队的状态换成两个前缀长度

子任务的参数不是区间 (l, r)，而是两个前缀的长度 (siz1, siz2)。莫队照样能跑：维护 cnt1、cnt2 两个计数数组，以及 curAns = Σx cnt1[x] × cnt2[x]。

把 siz1 加一，就是往第一个前缀里添一个数 v，内积只增加 cnt2[v]；siz2 加一同理，只增加 cnt1[v]。删的时候先减再算，方向相反。

while (win1 < job1) {          // 第一个前缀变长
    win1++;
    cnt1[arr[win1]]++;
    curAns += cnt2[arr[win1]];
}
while (win1 > job1) {          // 第一个前缀变短
    cnt1[arr[win1]]--;
    curAns -= cnt2[arr[win1]];
    win1--;
}

排序规则不变，第一关键字换成 siz1 所在块。这里还有个小动作：如果 siz1 > siz2 就交换，让所有子任务的 siz1 都不超过 siz2，指针的摆动范围小一半。

下面是 arr = [1, 2, 1, 3, 2] 的三条查询，拆成 12 个子任务后按块排序依次处理。

演示　简单的询问：两个前缀指针交替移动
前缀 1：arr[1..siz1] 前缀 2：arr[1..siz2]

七、题目2 代码

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int siz1, siz2, op, id;
    };

    const int MAXN = 50001;
    int n, q, cntq;
    int arr[MAXN];
    Query query[MAXN << 2];
    int bi[MAXN];

    int cnt1[MAXN];
    int cnt2[MAXN];
    long long curAns = 0;
    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.siz1] != bi[b.siz1]) {
            return bi[a.siz1] < bi[b.siz1];
        }
        if (bi[a.siz1] & 1) {
            return a.siz2 < b.siz2;
        } else {
            return a.siz2 > b.siz2;
        }
    }

    void addQuery(int siz1, int siz2, int op, int id) {
        query[++cntq].siz1 = siz1;
        query[cntq].siz2 = siz2;
        query[cntq].op = op;
        query[cntq].id = id;
    }

    void compute() {
        int win1 = 0, win2 = 0;
        for (int i = 1; i <= cntq; i++) {
            int job1 = query[i].siz1;
            int job2 = query[i].siz2;
            int op = query[i].op;
            int id = query[i].id;
            while (win1 < job1) {
                win1++;
                cnt1[arr[win1]]++;
                curAns += cnt2[arr[win1]];
            }
            while (win1 > job1) {
                cnt1[arr[win1]]--;
                curAns -= cnt2[arr[win1]];
                win1--;
            }
            while (win2 < job2) {
                win2++;
                cnt2[arr[win2]]++;
                curAns += cnt1[arr[win2]];
            }
            while (win2 > job2) {
                cnt2[arr[win2]]--;
                curAns -= cnt1[arr[win2]];
                win2--;
            }
            ans[id] += curAns * op;
        }
    }

    void prepare() {
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= cntq; i++) {
            if (query[i].siz1 > query[i].siz2) {
                swap(query[i].siz1, query[i].siz2);
            }
        }
        sort(query + 1, query + cntq + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        cin >> q;
        for (int i = 1, l1, r1, l2, r2; i <= q; i++) {
            cin >> l1 >> r1 >> l2 >> r2;
            addQuery(r1, r2, 1, i);
            addQuery(r1, l2 - 1, -1, i);
            addQuery(l1 - 1, r2, -1, i);
            addQuery(l1 - 1, l2 - 1, 1, i);
        }
        prepare();
        compute();
        for (int i = 1; i <= q; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

八、复杂度分析

两题的骨架都是莫队，区别只在一次增删的代价。

题目1：状态数组长 n+1，窗口增删一次要扫 26 个字母，O(26) 视作常数。

操作时间复杂度
预处理前缀状态O(26n)
查询排序O(m log m)
窗口增删一步（add / del）O(26)
指针总移动O((n + m)√n)
全部 m 次查询O(26(n + m)√n)

空间上要开一个大小 2²⁶ 的计数数组，因为状态就是 26 位二进制，这是这题最占地方的部分，约 2²⁶ × 4 字节；查询数组 O(m)。

题目2：一次查询拆成四个子任务，子任务数变成 4q，窗口增删是 O(1)。

操作时间复杂度
每条查询拆子任务O(1)，共 4q 个
子任务排序O(q log q)
窗口增删一步O(1)
指针总移动O((n + q)√n)
全部 q 次查询O((n + q)√n)

空间上是两个计数数组 cnt1、cnt2（值域 n）和 4q 个子任务，O(n + q)。

九、最后

两题做的事同一件：把「区间内的配对关系」翻译成「两个前缀之差」，然后让莫队在前缀数组上滑。

题目2 走得更远一点，它的窗口状态干脆不是区间而是两个前缀长度，说明莫队的窗口只是一个二维点，横纵两轴放什么由题目决定。

下一题换个方向：区间上的信息不再是数，而是字符串，得先把串压成一个整数才能放进计数数组。
