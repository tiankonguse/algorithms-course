树上分块（二）：王室联邦与区间父变小

上一节的两种树上分块都要先造下标或者先撒点。这一节的两道题换了个切法：一个按节点个数凑够就切，一个压根没碰树的结构，只是把 fa 数组当成序列来分块。

零、背景

树上分块的方式不止一种，常见的还有节点个数分块、节点深度分块、顶簇分块等。

这一节给两道题：王室联邦用节点个数分块，区间父变小用序列分块去维护 fa 数组，顺带用了一点树上的跳跃。

一、问题：王室联邦

一共有 n 个城市，编号 1 到 n，n - 1 条边连成一棵树。给定数值 b，请把树划分成若干个省，要求如下。

每个省至少有 b 个城市、最多有 3 * b 个城市；每个省必须有一个省会，省会可以在省内也可以在省外，一个城市可以是多个省的省会；一个省里，任何城市到达省会的路径上，除了省会之外的其他城市，必须都在省内。

输出一种有效划分即可：先打印省的个数 k，再打印 n 个数字表示每个城市属于哪个省，最后打印 k 个数字表示每个省会的城市编号。

1 ≤ n、b ≤ 10³，测试链接：洛谷 P2325。

二、dfs 带一个栈，攒够就成省

做法是一次 dfs，外加一个全局栈。栈里放的是「还没决定归属的城市」。

进入节点 u 时，先记下当前栈的大小 x。然后依次 dfs u 的每个儿子，每回来一个儿子就检查一次：如果栈里比 x 多出来的部分 ≥ b，就立刻成立一个新省，省会设成 u，把栈顶一直弹回到 x，弹出来的城市全部划给这个省。

所有儿子处理完之后，才把 u 自己压进栈。u 不参与刚才的判断，这一步很关键。

演示　栈的攒与弹

10 个城市，b = 3。左边是树，中间是栈，右边是已经成立的省。

在栈里，还没定归属 已经划进某个省

三、为什么这样划分是合法的

先看省的大小。判断条件是 siz - x ≥ b，所以成省时至少 b 个，下限没问题。

上限分成两部分。每次成省都会把栈弹回到 x，所以 siz - x 恰好是「上次成省（或者 u 这次开始）以来攒下的量」，而它在上一次检查时一定还不到 b。新加进来的这一份是某个儿子子树内部最后剩下的残留，也不到 b，因为子树里每攒够 b 就已经成过省了。两者加起来不到 2b。

dfs 全部结束之后，栈里剩下的部分按代码全都划给最后一个省。这部分也不到 b，否则根节点的最后一个儿子回来时就该成省了。所以最后一个省最多不到 3b。

再看省会。成省的时候省会设成 u，而 u 是在所有儿子都处理完之后才压栈的，此刻它还没进栈，所以 u 不属于这个新省。省会落在省外，题目是允许的。

最后是路径那条要求。被弹出的点是「某些儿子子树里剩下的部分」，而子树里成过省的部分早就弹掉了，剩下的是包含子树根在内的一整块。省内任意城市 w 往上走到 u，中间经过的点都在同一次弹出的集合里，所以整条路径除省会 u 之外都在省内。

四、代码

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1001;
    int n, b;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int capital[MAXN];
    int belong[MAXN];
    int cntb;

    int sta[MAXN];
    int siz;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u, int f) {
        int x = siz;
        for (int e = head[u], v; e; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs(v, u);
                if (siz - x >= b) {
                    capital[++cntb] = u;
                    while (siz != x) {
                        belong[sta[siz--]] = cntb;
                    }
                }
            }
        }
        sta[++siz] = u;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> b;
        for (int i = 1, u, v; i < n; i++) {
            cin >> u >> v;
            addEdge(u, v);
            addEdge(v, u);
        }
        dfs(1, 0);
        if (cntb == 0) {
            capital[++cntb] = 1;
        }
        while (siz > 0) {
            belong[sta[siz--]] = cntb;
        }
        cout << cntb << '\n';
        for (int i = 1; i <= n; i++) {
            cout << belong[i] << ' ';
        }
        cout << '\n';
        for (int i = 1; i <= cntb; i++) {
            cout << capital[i] << ' ';
        }
        cout << '\n';
        return 0;
    }

dfs 结束之后还有一个保护：如果一个省都没成立过（n < b 时会这样），就补一个省，省会设成 1，再把栈里剩下的全划给它。

整段代码没有预处理、没有块数组，栈就是全部的舞台，一次 dfs O(n)。

五、问题：区间父变小

一棵大小为 n 的树，节点 1 是树头，给定 fa[2..n] 表示每个点的父亲，对每个 i > 1 都有 fa[i] < i。

m 条操作：操作 1 x y z，把 [x..y] 范围上每个点 i 的 fa[i] 改成 max(1, fa[i] - z)；操作 2 x y，查询点 x 和点 y 的最近公共祖先。

2 ≤ n、m ≤ 10⁵，测试链接：Codeforces 1491H。

这棵树的形状一直在变，但有一条性质没变：fa[i] < i 永远成立，因为 fa 只会变小。所有祖先链都是编号严格递减的，这一条是后面所有跳跃的依据。

六、out 数组：一次跳出块

把编号 1 到 n 当成序列分块，块长 √n。光有 fa 只能一步一步往上爬，一次查询 O(n)，所以再维护一个 out 数组。

out[i] 的含义是：从 i 沿 fa 往上走，第一个跳出 i 所在块的祖先。计算方式是递推：如果 fa[i] 已经小于块首，那 out[i] = fa[i]；否则 out[i] = out[fa[i]]，继续往上找。因为 fa[i] < i，按编号从小到大算，out[fa[i]] 一定已经算好了。

整块被整体减的时候，块内所有点的 fa 一起变小，out 也会跟着变，所以要么重建、要么想办法让它还能用。

七、查询：两层跳

lca 的过程写成两个 while。第一个 while 处理「还没到同一块」的情况，第二个 while 处理「已经在同一块，但还没汇合」的情况。

第一个 while 的条件是 bi[x] != bi[y] 或者 jumpOut(x) != jumpOut(y)。只要不满足就继续跳：块号不同就跳块号大的那个，块号相同就两个一起跳。跳的时候用的是 jumpOut，一次至少跨过一个整块。

第二个 while 用的是 jumpFa，一次只走一步 fa。进了同一块之后，两点之间的距离最多一个块长，所以最多块长次就汇合。

这里有个细节：第二个 while 里比较的是编号大小，谁编号大谁往上走。因为 fa[i] < i 恒成立，编号大的一定不是编号小的那个的祖先，这样走不会跳过最近公共祖先。

八、整块消减与重建的剪枝

修改区间 [l, r] 时，两端不完整的块逐个改 fa，然后重建这两个块。重建做两件事：把累积的 lazy 落到 fa 上、lazy 归零，再按新的 fa 重算一遍 out。

中间完整的块只打标记：lazy[b] += v，minusCnt[b]++。但是 out 依赖 fa 的具体值，光打标记 out 就过期了，所以代码规定 minusCnt[b] 不超过块长时，顺便把这块重建一次。

超过块长之后就不再重建了，只累加 lazy。这样做是安全的：整块被消减的次数达到块长之后，块内每个点的 fa 都已经被减掉了至少块长那么多，而 fa[i] ≤ i - 1 ≤ 块尾 - 1，减掉块长之后一定小于块首。此时所有点一步就跳出块，out[i] 就等于 fa[i]，jumpOut 和 jumpFa 变成同一个东西，自然也不会跳错。

而且 fa 只会变小，一旦所有点的 fa 都小于块首，之后就一直小于块首，这个状态不会被破坏。之后即使这块再被零散修改，重建时 out 依然等于 fa。

九、代码

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXB = 501;
    int n, m;

    int fa[MAXN];
    int out[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];
    int br[MAXB];
    int lazy[MAXB];
    int minusCnt[MAXB];

    void innerUpdate(int b) {
        for (int i = bl[b]; i <= br[b]; i++) {
            fa[i] = max(1, fa[i] - lazy[b]);
        }
        lazy[b] = 0;
        for (int i = bl[b]; i <= br[b]; i++) {
            if (fa[i] < bl[b]) {
                out[i] = fa[i];
            } else {
                out[i] = out[fa[i]];
            }
        }
    }

    void update(int l, int r, int v) {
        if (bi[l] == bi[r]) {
            for (int i = l; i <= r; i++) {
                fa[i] = max(1, fa[i] - v);
            }
            innerUpdate(bi[l]);
        } else {
            for (int i = l; i <= br[bi[l]]; i++) {
                fa[i] = max(1, fa[i] - v);
            }
            innerUpdate(bi[l]);
            for (int i = bl[bi[r]]; i <= r; i++) {
                fa[i] = max(1, fa[i] - v);
            }
            innerUpdate(bi[r]);
            for (int b = bi[l] + 1; b <= bi[r] - 1; b++) {
                lazy[b] = min(n, lazy[b] + v);
                if (++minusCnt[b] <= blen) {
                    innerUpdate(b);
                }
            }
        }
    }

    int jumpFa(int i) {
        return max(1, fa[i] - lazy[bi[i]]);
    }

    int jumpOut(int i) { 
        return max(1, out[i] - lazy[bi[i]]);
    }

    int lca(int x, int y) {
        while (bi[x] != bi[y] || jumpOut(x) != jumpOut(y)) {
            if (bi[x] != bi[y]) {
                if (bi[x] < bi[y]) {
                    swap(x, y);
                }
                x = jumpOut(x);
            } else {
                x = jumpOut(x);
                y = jumpOut(y);
            }
        }
        while (x != y) {
            if (x < y) {
                swap(x, y);
            }
            x = jumpFa(x);
        }
        return x;
    }

    void prepare() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, n);
            innerUpdate(i);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 2; i <= n; i++) {
            cin >> fa[i];
        }
        prepare();
        for (int i = 1, op, x, y, z; i <= m; i++) {
            cin >> op >> x >> y;
            if (op == 1) {
                cin >> z;
                update(x, y, z);
            } else {
                cout << lca(x, y) << '\n';
            }
        }
        return 0;
    }

jumpFa 和 jumpOut 都要减去当前块的 lazy，因为 fa 和 out 存的都是「还没扣掉 lazy 的旧值」，真正要用的值是扣完之后的结果。

注意 lazy[b] 被 min(n, ...) 夹住了，扣得再多也不会减成负数，配合 max(1, ...) 保证编号始终合法。

十、复杂度分析

设 n 为节点数，m 为操作条数，B 为块长，块数 n/B。

操作时间复杂度
王室联邦：一次 dfsO(n)
区间父变小：预处理O(n)
修改：两端散块重建O(B)
修改：中间整块打标记O(n/B)
整块重建的均摊总代价O(n·B)（每块最多重建 B 次，每次 O(B)）
查询：第一层跨块O(n/B)
查询：第二层块内O(B)
单次修改 / 查询（B = √n）O(√n)

空间上只需要 fa、out 两个数组加上每块的 lazy 和 minusCnt，一共 O(n)。

王室联邦那道题的空间也是 O(n)，栈和答案数组各一份。

十一、最后

王室联邦的分块思路是「按个数凑」：不需要下标连续，攒够 b 个就切一刀，栈天然保证了切出来的部分连通。

区间父变小则是反过来用：树没有连续下标，那就用编号当下标，fa 数组本身就是一个序列，序列分块直接就能上。out 数组是这道题的关键，它把「一步一步爬」变成「一次跨一个块」。

分块的几种切法到这里就齐了。分块的价值在于好想好写，树上分块能解的题，往往树链剖分、虚树、线段树合并这些做法复杂度更优，遇到不好理解的分块解法时，投入精力之前值得先权衡一下。
