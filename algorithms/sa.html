后缀数组

把一个字符串的所有后缀按字典序排好，就得到后缀数组。有了它，找子串、数出现次数、找最长重复子串，都变成在有序表上找区间。

零、背景

前面几节处理的都是数组上的区间问题。换成字符串，问法就变成找子串、数出现次数、找重复段。

这类问题有一个共同的入口。所谓后缀，就是从某个位置开始一直切到结尾的那一段；而任何一个子串，都恰好是某个后缀的开头一段。

一、问题

给一个字符串 s，长度 n。常见的问题大致有三类：

  • 模式串 p 在 s 里有没有出现；
  • p 出现了几次；
  • s 里出现至少两次的最长子串是哪个。

以 s = "banana" 为例，它一共有 6 个后缀，从位置 1 到 6 分别是 banana、anana、nana、ana、na、a。

子串 "ana" 在 s 里出现了两次，起点是位置 2 和位置 4。位置 2 的后缀是 "anana"，位置 4 的后缀是 "ana"，而 "ana" 正好是这两个后缀的开头三个字符。

后缀一共 n 个。如果能把它们按字典序排好，上面那三个问题就都换了副样子。排好之后记两个数组：sa[i] 是排第 i 名的后缀从哪个位置开始，rk[i] 是从位置 i 开始的后缀排第几。两者互为反函数，sa[rk[i]] = i。

字典序比较从第一个字符开始，第一个不同的字符决定大小；短串是长串的前缀时短串更小，所以 "a" 排在 "ana" 前面，"ana" 又排在 "anana" 前面。

二、朴素做法

最直接的想法是把 n 个后缀一个一个切出来，交给 sort。

vector<string> suf;
for (int i = 0; i < n; i++) suf.push_back(s.substr(i));  // 共 n 个后缀
sort(suf.begin(), suf.end());

这样很慢，慢在两处。一处是单次比较贵：两个后缀最坏要逐字符比 n 次。另一处是比较次数多：sort 大约要做 n log n 次比较。

两者相乘是 O(n² log n)。n 到 10⁵ 就跑不完了。

可以发现，比较贵是因为每次都比了整个后缀。要是能先比短一点，再慢慢加长，单次比较就能便宜下来。

三、倍增

倍增的做法是别一次比完。先只比前 1 个字符，再比前 2 个、前 4 个、前 8 个，每轮把比较长度翻倍。

好处在下一轮。比较两个后缀的前 2w 个字符，可以拆成前后两半：前 w 个，和接下来的 w 个。而这两半各自的排名上一轮已经算出来了，就是上一轮的 rk。

所以这一轮要比的不再是字符串，而是两个整数对 (rk[i], rk[i+w])，一次比较 O(1)。

轮数是 O(log n)，长度每轮翻倍，log n 轮之后就盖过整个串长。下面是 "banana" 三轮的排名，颜色相同表示本轮排名相同。

只要还有并列，说明长度不够，得继续翻倍；等到 n 个排名互不相同，就已经完全分开了。拖动滑条，看同一轮里哪些后缀还没分开。

四、每轮怎么排序

每轮要按双关键字 (rk[i], rk[i+w]) 排序。关键字是 0 到 n 之间的整数，值域很小，用计数排序就能 O(n) 排完，不必用 O(n log n) 的 sort。

双关键字的做法是两趟稳定排序：先按第二关键字排，再在它的基础上稳定地按第一关键字排。

第二关键字那一趟还能省掉。上一轮的 sa 已经按「前 w 个字符」排好，那么 sa[i] - w 这个序列本身就是按第二关键字有序的，扫一遍就能得到 id。

这里有个细节：起点 i 大于 n - w 的后缀，后半段已经没有字符，第二关键字取 0，最小，天然排在最前。

// 一轮倍增的核心（w 为本轮比较长度的一半）
int p = 0;
for (int i = n; i > n - w; i--) id[++p] = i;              // 第二关键字为 0，最小
for (int i = 1; i <= n; i++)
    if (sa[i] > w) id[++p] = sa[i] - w;      // 其余按第二关键字有序

memset(cnt, 0, sizeof(cnt));
for (int i = 1; i <= n; i++) cnt[px[i] = rk[id[i]]]++;  // 按第一关键字计数
for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
for (int i = n; i >= 1; i--) sa[cnt[px[i]]--] = id[i];  // 稳定回填

两趟都是 O(n)，每轮 O(n)，一共 O(log n) 轮。

五、height 数组

光有 sa 还不够用，很多问题要知道「排在一起的两个后缀，开头有多长是相同的」。height[i] 记的就是排第 i 名的后缀与排第 i-1 名的后缀的最长公共前缀长度。

在 "banana" 里，排第 3 的是 "anana"，排第 2 的是 "ana"，公共前缀是 "ana"，所以 height[3] = 3。

如果每对相邻后缀都从头比一遍，最坏又是 O(n²)。这里有个性质可以让它线性求出来：height[rk[i]] ≥ height[rk[i-1]] - 1。

意思是比较的起点从 i-1 挪到 i，公共前缀最多少 1。所以求 height[rk[i]] 时，可以从上一个值减 1 开始往后伸，不必回到 0。

每步伸出去的量累计不超过 2n，总时间是 O(n)。拖动滑条，看每一对相邻后缀的公共前缀有多长。

int k = 0;
for (int i = 1; i <= n; i++) {
    if (rk[i] == 1) { k = 0; continue; }   // 排第一，没有前一名
    if (k) k--;                           // 从上一个值减 1 开始
    int j = sa[rk[i] - 1];                // 排在前一名的后缀
    while (i + k <= n && j + k <= n && s[i + k] == s[j + k]) k++;
    height[rk[i]] = k;
}

六、能做什么

后缀排好序之后，以 p 为前缀的那些后缀在 sa 里一定是连续的一段。这句话是下面三件事的共同依据。

找 p 有没有出现，就在 sa 上二分，每次拿 p 和中间那个后缀的前缀比，一次比较 O(|p|)，共 O(|p| log n)。

数 p 出现几次，用两次二分定出这一段的左右端点，区间长度就是次数。

找最长重复子串更简单。出现至少两次的子串，一定藏在某两个相邻后缀的公共前缀里，所以答案就是 height 的最大值。上图的例子里最大值是 3，对应 "ana"。

七、代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
char s[N];
int n, m;                             // n 串长，m 当前不同排名的个数
int sa[N], rk[N], oldrk[N << 1], id[N], px[N], cnt[N];
int height[N];

// 比较两个后缀的「前 2w 个字符」是否相同（用上一轮的排名）
bool cmp(int x, int y, int w) {
    return oldrk[x] == oldrk[y] && oldrk[x + w] == oldrk[y + w];
}

int main() {
    scanf("%s", s + 1);                    // 从 1 开始存
    n = strlen(s + 1);
    m = 128;                            // 第一轮按字符的 ASCII 值排

    for (int i = 1; i <= n; i++) cnt[rk[i] = s[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;

    for (int w = 1; w < n; w <<= 1) {         // 倍增：长度每轮翻倍
        int p = 0;
        for (int i = n; i > n - w; i--) id[++p] = i;    // 第二关键字为 0
        for (int i = 1; i <= n; i++)
            if (sa[i] > w) id[++p] = sa[i] - w;   // 其余按第二关键字有序

        memset(cnt, 0, sizeof(cnt));
        for (int i = 1; i <= n; i++) cnt[px[i] = rk[id[i]]]++;
        for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; i--) sa[cnt[px[i]]--] = id[i];

        memcpy(oldrk, rk, sizeof(rk));      // 重算 rk
        p = 0;
        for (int i = 1; i <= n; i++)
            rk[sa[i]] = cmp(sa[i], sa[i - 1], w) ? p : ++p;
        m = p;
        if (m == n) break;                 // 排名互不相同，已经排好
    }

    int k = 0;                             // 求 height
    for (int i = 1; i <= n; i++) {
        if (rk[i] == 1) { k = 0; continue; }
        if (k) k--;
        int j = sa[rk[i] - 1];
        while (i + k <= n && j + k <= n && s[i + k] == s[j + k]) k++;
        height[rk[i]] = k;
    }

    for (int i = 1; i <= n; i++) cout << sa[i] << " ";
    return 0;
}

八、复杂度分析

构造走的是倍增加计数排序：一共 O(log n) 轮，每轮两趟计数排序是 O(n)。height 靠「最多少 1」的性质线性求出。

操作时间复杂度
构造 sa（倍增 + 计数排序）O(n log n)
构造 sa（每轮改用 sort）O(n log² n)
求 heightO(n)
单次模式匹配（二分）O(m log n)
数出现次数（两次二分）O(m log n)
最长重复子串（扫 height）O(n)

表里 m 是模式串长度。空间上需要 sa、rk、oldrk、id、px、cnt、height 这几个数组，其中 oldrk 要给 rk[i+w] 的越界留余量，开到 2n。整体额外空间 O(n)，常数略大。

对比朴素做法的 O(n² log n)：n 到 10⁵ 时后者是 10¹⁰ 量级，前者约 1.7×10⁶。

九、最后

后缀数组做的事可以概括成两件：把所有后缀排好序，再求出相邻后缀的公共前缀。排好序之后，子串问题就变成有序表上找区间的问题，找模式串是二分定位，数出现次数是找一段连续区间，最长重复子串是 height 的最大值。

代价是 O(n log n) 的构造和一份不算短的代码。只做一次模式匹配的话，KMP 更省事；要反复查、还要数出现次数，才轮到后缀数组上场。
