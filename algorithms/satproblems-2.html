2-SAT 的建模与判定

上一页把约束压成线性条数的边之后，判定还是跑一遍 tarjan。这一页换两个角度：题目本身不是布尔变量，得先把取值翻译过来；区间合法性有单调性，干脆不把图建出来，用并查集判定加一倍增表直接数答案。

零、背景

上一页的骨架是「建图加 tarjan 判矛盾」。这一页两道题的共同点是约束本身不直接给出 2-SAT 变量，或者根本不需要把图建出来。

题目4 里一个地点有三种可选的赛车，三不是二，得想办法把它掰成布尔。题目5 的每条限制是双向蕴含，正好等价于并查集的一次合并；区间是不是合法只看合并过程有没有出现冲突，于是可以只用并查集判定，再用整体二分和倍增表把每个询问的答案算出来。原理部分见 2-SAT 与前缀优化建图，优化建图三种结构见 2-SAT 的优化建图。

一、题目4：游戏

n 个地点，地面有 x、a、b、c 四种类型；赛车有 A、B、C 三辆。a 类地面不能跑 A，b 类不能跑 B，c 类不能跑 C，x 类没有限制。另外给 m 条限制，格式是 pos1 car1 pos2 car2，含义是：如果 pos1 用 car1，那么 pos2 必须用 car2。求任意一组安排，无解输出 −1。x 类地面的个数 d 不超过 8。

先看不带 x 的地面。a 类地面能跑的车是 B、C 两辆，b 类是 A、C，c 类是 A、B，都正好两辆。两辆就是一个布尔变量：变量真表示选第一辆，假表示选第二辆。2-SAT 的变量有了。

麻烦在 x 类地面，它能跑三辆，三个取值没法直接成一个布尔变量。注意到 d ≤ 8，可以枚举：对每个 x 类地点，强行规定它不许跑 A 或者不许跑 B，于是它只剩两辆可选，回到布尔。2^d ≤ 256 种情况，每种建一次图跑一次 tarjan。

枚举禁 A 和禁 B 两种就够了吗，够了。任何一组方案里，某个 x 地点用的车只可能是 A、B、C 之一。它用 A，就对应禁 B 的那次枚举，那一次允许 A、C；它用 B，对应禁 A 的那次，允许 B、C；它用 C，两次枚举都允许。所以任何一组合法方案，总能在某一次枚举里被完整地表达出来。

限制怎么连边。设限制是「pos1 用 car1 则 pos2 用 car2」。先看前提：如果 car1 在 pos1 的地面上是被禁的车，这个前提永远不会成立，限制自动满足，直接跳过。

否则把 car1 定位到 pos1 的两个布尔之一，记作字面量 id1。再看结论：如果 car2 在 pos2 的地面上被禁，那么「pos1 用 car1」这件事本身就不允许发生，连一条 id1 → ¬id1，把它逼成假。否则把 car2 记成 id2，连 id1 → id2，同时补上逆否边 ¬id2 → ¬id1。

判定照旧：同一个地点的两个字面量落在同一个强连通分量里就无解，否则按分量编号给每个地点挑第一辆或第二辆。一次枚举找不到方案就试下一种，全都失败才输出 −1。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    int n, d, m;

    char ban[128];
    char first[128];
    char second[128];

    char groundType[MAXN];
    int pos1[MAXN];
    char car1[MAXN];
    int pos2[MAXN];
    char car2[MAXN];

    int posx[MAXN];

    int head[MAXN];
    int nxt[MAXN];
    int to[MAXN];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    char ans[MAXN];

    void prepare() {
        ban['a'] = 'A';
        ban['b'] = 'B';
        ban['c'] = 'C';
        first['a'] = 'B';
        first['b'] = 'A';
        first['c'] = 'A';
        second['a'] = 'C';
        second['b'] = 'C';
        second['c'] = 'B';
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int other(int i) {
        return i <= n ? i + n : i - n;
    }

    void buildGraph(int stax) {
        for (int bit = 0, idx = 1; bit < d; bit++, idx++) {
            if (((stax >> bit) & 1) == 1) {
                groundType[posx[idx]] = 'a';
            } else {
                groundType[posx[idx]] = 'b';
            }
        }
        for (int i = 1; i <= m; i++) {
            int p1 = pos1[i];
            char g1 = groundType[p1];
            char c1 = car1[i];
            if (ban[g1] == c1) {
                continue;
            }
            int id1 = c1 == first[g1] ? p1 : p1 + n;
            int p2 = pos2[i];
            char g2 = groundType[p2];
            char c2 = car2[i];
            if (ban[g2] == c2) {
                addEdge(id1, other(id1));
            } else {
                int id2 = c2 == first[g2] ? p2 : p2 + n;
                addEdge(id1, id2);
                addEdge(other(id2), other(id1));
            }
        }
    }

    void clear() {
        for (int i = 1; i <= n << 1; i++) {
            head[i] = dfn[i] = belong[i] = 0;
        }
        cntg = cntd = top = sccCnt = 0;
    }

    bool compute() {
        for (int i = 1, sizx = 0; i <= n; i++) {
            if (groundType[i] == 'x') {
                posx[++sizx] = i;
            }
        }
        for (int stax = 0; stax < 1 << d; stax++) {
            buildGraph(stax);
            for (int i = 1; i <= n << 1; i++) {
                if (dfn[i] == 0) {
                    tarjan(i);
                }
            }
            bool check = true;
            for (int i = 1; i <= n; i++) {
                if (belong[i] == belong[i + n]) {
                    check = false;
                    break;
                }
            }
            if (check) {
                for (int i = 1; i <= n; i++) {
                    char ground = groundType[i];
                    if (belong[i] < belong[i + n]) {
                        ans[i] = first[ground];
                    } else {
                        ans[i] = second[ground];
                    }
                }
                return true;
            }
            clear();
        }
        return false;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        prepare();
        cin >> n >> d;
        for (int i = 1; i <= n; i++) {
            cin >> groundType[i];
        }
        cin >> m;
        for (int i = 1; i <= m; i++) {
            cin >> pos1[i] >> car1[i] >> pos2[i] >> car2[i];
        }
        bool check = compute();
        if (check) {
            for (int i = 1; i <= n; i++) {
                cout << ans[i];
            }
        } else {
            cout << -1 << "\n";
        }
        return 0;
    }

二、题目5：布尔

n 个变量取值 0 或 1，m 条限制，第 i 条形如 u x v y：如果 u 的取值是 x，那么 v 的取值是 y；同时如果 v 的取值是 y，那么 u 的取值是 x。两个方向同时成立，合起来是一个双向蕴含。

限制编号 1 到 m，一个区间 [a, b] 合法，指区间内的限制同时成立时存在赋值方案。q 次询问 [l, r]，问把 [l, r] 最少切成多少段连续区间，每段都合法；做不到输出 −1。

先把限制看成一个等式。记字面量 L 为「u 取 x」，M 为「v 取 y」，限制说的就是 L 与 M 的取值必须相同，同时 ¬L 与 ¬M 的取值也必须相同。这正是 2-SAT 里「两个字面量绑在一起」的形态，可以用并查集维护：把 L 和 M 合并，把 ¬L 和 ¬M 也合并。过程中只要出现某个字面量和它的反面落在同一集合里，这一段就矛盾。

并查集要能撤销。区间合法性问的是「一条条加限制，加到哪一条第一次冲突」，这个位置要对很多起点并行地做，退回去时得把合并原样弹掉。所以并查集不写路径压缩，find 老老实实沿父指针往上走，合并按大小记栈，undo 把栈弹回去。

天生矛盾的限制要单独标记。如果一条限制里 u 等于 v 且 x 不等于 y，它等价于要求「u 取 x」和「u 取 ¬x」，单条就矛盾，任何包含它的区间都无解。用一个前缀和 error[] 记下这类限制的位置，询问时先看一眼区间里有没有，有就直接输出 −1。

接下来求 first[i]：从位置 i 开始往右加限制，第一次出现冲突的位置。区间 [i, first[i]−1] 就是以 i 开头的最长合法区间。

first 有单调性。从 i 开始比从 i−1 开始少了一条限制 i−1 的约束，冲突只会来得更晚或者一样晚，所以 first[i] 不小于 first[i−1]。可以对所有 i 一起二分答案：整体二分把位置分成答案落在左半和右半的两批，左半需要的限制是右半的子集，于是增量地往并查集里加边，用完了再撤销。一趟下来只需 O(m log m) 级别的合并。

有了 first，询问还要数最少几段。这是经典的区间覆盖：从 l 出发，每次尽量往右跳。倍增表把「跳 2^p 段」预处理出来，st[i][0] 就是 first[i]，表示跳一段之后落到哪；st[i][p] 等于 st[st[i][p−1]][p−1]，表示跳 2^p 段。查询时从高位往低位贪心，只要 st[l][p] 不超过 r 就跳过去，并把答案加上 2^p，最后再补上收尾的一段。

倍增表数最少的合法段数

first[1..10] = 4, 4, 6, 7, 10, 10, 11, 11, 11, 11，询问 [1, 10]。点「下一步」，看贪心从高位到低位怎么跳，最后落在三段上。

已确定覆盖的位置 当前跳到的起点 l 还没覆盖

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXM = 600001;
    const int MAXQ = 1000001;
    const int MAXP = 20;
    int n, m, q;

    int error[MAXM];

    int u[MAXM];
    int v[MAXM];

    int fa[MAXN];
    int siz[MAXN];
    int rollback[MAXN][2];
    int opsize;

    int first[MAXM];

    int st[MAXM + 1][MAXP];

    int find(int i) {
        while (i != fa[i]) {
            i = fa[i];
        }
        return i;
    }

    void Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (fx != fy) {
            if (siz[fx] < siz[fy]) {
                swap(fx, fy);
            }
            fa[fy] = fx;
            siz[fx] += siz[fy];
            rollback[++opsize][0] = fx;
            rollback[opsize][1] = fy;
        }
    }

    void undo(int oldsiz) {
        while (opsize > oldsiz) {
            int fx = rollback[opsize][0];
            int fy = rollback[opsize--][1];
            fa[fy] = fy;
            siz[fx] -= siz[fy];
        }
    }

    int other(int x) {
        return x <= n ? x + n : x - n;
    }

    bool conflict(int x) {
        return find(x) == find(other(x));
    }

    void compute(int ql, int qr, int vl, int vr) {
        if (ql > qr) {
            return;
        }
        if (vl == vr) {
            for (int i = ql; i <= qr; i++) {
                first[i] = vl;
            }
            return;
        }
        int mid = (vl + vr) >> 1;
        int backup1 = opsize;
        bool bad = false;
        for (int i = max(qr + 1, vl); i <= mid; i++) {
            Union(u[i], v[i]);
            Union(other(u[i]), other(v[i]));
            if (conflict(u[i])) {
                bad = true;
                break;
            }
        }
        if (bad) {
            undo(backup1);
            compute(ql, qr, vl, mid);
        } else {
            int backup2 = opsize;
            int split = min(qr, mid);
            for (; split >= ql; split--) {
                Union(u[split], v[split]);
                Union(other(u[split]), other(v[split]));
                if (conflict(u[split])) {
                    break;
                }
            }
            undo(backup2);
            compute(split + 1, qr, mid + 1, vr);
            undo(backup1);
            for (int i = split + 1; i <= qr && i < vl; i++) {
                Union(u[i], v[i]);
                Union(other(u[i]), other(v[i]));
            }
            compute(ql, split, vl, mid);
        }
    }

    void buildst() {
        opsize = 0;
        for (int i = 1; i <= (n << 1); i++) {
            fa[i] = i;
            siz[i] = 1;
        }
        compute(1, m, 1, m + 1);
        for (int p = 0; p < MAXP; p++) {
            st[m + 1][p] = m + 1;
        }
        for (int i = m; i >= 1; i--) {
            st[i][0] = first[i];
            for (int p = 1; p < MAXP; p++) {
                st[i][p] = st[st[i][p - 1]][p - 1];
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        for (int i = 1, x, y; i <= m; i++) {
            cin >> u[i] >> x >> v[i] >> y;
            error[i] = u[i] == v[i] && x != y ? 1 : 0;
            u[i] = x == 0 ? u[i] : (u[i] + n);
            v[i] = y == 0 ? v[i] : (v[i] + n);
        }
        buildst();
        for (int i = 1; i <= m; i++) {
            error[i] += error[i - 1];
        }
        for (int i = 1, l, r; i <= q; i++) {
            cin >> l >> r;
            if (error[r] - error[l - 1] > 0) {
                cout << -1 << "\n";
            } else {
                int ans = 0;
                for (int p = MAXP - 1; p >= 0; p--) {
                    if (st[l][p] <= r) {
                        l = st[l][p];
                        ans += 1 << p;
                    }
                }
                ans++;
                cout << ans << "\n";
            }
        }
        return 0;
    }

三、复杂度分析

题目4 的开销全在枚举次数上；题目5 的判定不做建图，复杂度落在并查集的合并次数和倍增表的规模上。

步骤时间复杂度空间复杂度
题目4 一次枚举（建图 + tarjan）O(n + m)O(n + m)
题目4 整体（枚举 2^d 种，d ≤ 8）O(2^d (n + m))
题目5 整体二分求 first[]O(m log m) 次合并O(n + m log m)
题目5 建倍增表O(m log m)
题目5 单次询问O(log m)

题目4 的枚举上限由 d 决定，d 只有 8，2^d 最多 256，乘上 O(n + m) 的建图和 tarjan 是能接受的量级。每一次枚举都重新建一遍图，图上的点数只有 2n，边数由 m 条限制给出，最多两条。

题目5 的合并次数来自整体二分的每一层：每一层里每条限制最多被加入和撤销各一次。可撤销并查集不压缩路径，find 的代价是树高，按大小合并保证树高是 O(log n)，所以单次合并带一个很小的对数因子。倍增表按 log m 层预处理，每层 m 个位置，空间也是 O(m log m)。单次询问从高位往低位跳，总共 log m 次比较。

四、最后

这两道题的看点都不在建图本身。题目4 是把「三选一」拆成「先禁掉一个，再二选一」，枚举把三值问题搬回 2-SAT；题目5 是发现双向蕴含正好是并查集的一次合并，于是判定退化成一个非常轻的操作，能撤销、能大批量并行做。

上一页的三道题靠优化建图把边数压下来，这两道题一个靠枚举控制规模、一个干脆绕开建图，思路不同但落点一样：让一个本来不可做的规模变回可做的。
