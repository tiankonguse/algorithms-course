点分治的容斥题型

点分治的第二种统计姿势。上一页靠「按子树先配对后并入」防重复，这一页换成容斥：calc 把整个连通区的点全部收集、放开手统计，再把每棵子树内部多算的部分减掉。四道题：距离 ≤ k 的点对数量、相近点对、所有合法路径的魔力和、消息传递。

零、背景

上一页的三道模版题里，calc 都要按重心 u 的子树逐棵处理：当前子树先和已处理子树的累计信息配对，配完才并入。这个「增量」写法的好处是常数小，坏处是配对的逻辑被拆得比较碎。

容斥是另一种等价姿势：先把整个连通区当成一整份统计，再对每棵子树把「不该在本层算的」减掉。写起来更直，而且配对发生在完整的数组上，排序、双指针、树状数组这些工具都能直接接上。

一、问题

还是树上点对统计，但指标比模版题更进一步：距离和边数两个维度同时限制（相近点对）、路径上最大边权求和（魔魔力）、查询挂在点上带着参数走（消息传递）。n 到 10⁵。

共同点：每个点对的指标依赖完整路径，但只要能写成「到重心的两段信息拼在一起判定」，容斥的框架就套得上去。

二、朴素做法（直接配对错在哪）

最省事的 calc 长这样：dfs 收集整个连通区里每个点到重心 u 的距离（u 自己距离 0），全部放进一个数组，然后在这个数组上两两统计。

错在同一棵子树里的点对也被统计了。x、y 同在子树 a 里，它们的路径根本不经过 u；calc(u) 拿 dist(x) + dist(y) 判了一遍，递归进子树 a 时还会再判一遍。而且 dist(x) + dist(y) 是绕经 u 的长度，比真实路径只会更长，用它判「距离 ≤ k」，合法的照样合法，于是这一对被数了两遍。

三、容斥

修正的办法是减回去。solve 里对重心 u 先 ans += calc(u, 0)，整份统计；再对 u 的每棵子树 v，ans -= calc(v, w)，w 是边 u–v 的权。

calc(v, w) 的 dfs 从 v 出发但带着初始距离 w，也就是说收集到的仍然是「到 u 的距离」。这样同一棵子树内部的点对，在加的那份和减的那份里判定条件一字不差，加一次减一次，恰好抵消，净贡献为 0，完全留给递归处理。

剩下有净贡献的只有两种：两端在不同子树的点对，以及一端是 u 自己的点对（calc(u, 0) 里 u 以距离 0 参与，减去的子树份里没有 u）。这正是「跨过重心」的完整定义。

可以发现上一页的「先配对后并入」就是这份容斥的增量版：逐棵子树只算跨子树的配对，等价于先全算再减。两种写法结果相同，这一页的题都用容斥版，因为配对发生在完整数组上，排序之后双指针、树状数组才使得上劲。

先看最典型的一题，配对用双指针。

双指针统计距离和 ≤ k 的点对

数组是当前连通区所有点到重心的距离（升序，0 是重心自己），k = 10。点「下一步」看指针怎么移动。

四、题目1：距离 ≤ k 的点对数量

n 个点组成一棵树，边有边权。求两点距离 ≤ k 的点对数量，(x, x) 不算点对，(x, y) 与 (y, x) 算同一个。1 ≤ n ≤ 4×10⁴，0 ≤ 边权 ≤ 10³，0 ≤ k ≤ 2×10⁴。

calc 把连通区所有点到重心的距离收进数组（含重心的 0），升序排序。双指针 l 在头、r 在尾：如果 dis[l] + dis[r] ≤ k，那么 l 到 l+1..r 之间任何一个点都能和 l 配，一次数出 r - l 对，l 右移；否则 r 太大，连最小的 l 都配不上，r 左移。l 追上 r 时结束。

自身配不上：每个点在数组里只出现一次，l = r 时 r - l = 0。容斥的部分照旧：ans += calc(u, 0)，每棵子树 ans -= calc(v, w)。

样例：5 个点，边 1-2(4)、1-3(4)、2-4(3)、2-5(1)，k = 7，答案是 7。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 50001;
    int n, k;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    int disArr[MAXN];
    int cnta;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dis) {
        if (dis > k) {
            return;
        }
        disArr[++cnta] = dis;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + weight[e]);
            }
        }
    }

    long long calc(int u, int dis) {
        cnta = 0;
        dfs(u, 0, dis);
        long long ans = 0;
        sort(disArr + 1, disArr + cnta + 1);
        for (int l = 1, r = cnta; l <= r; ) {
            if (disArr[l] + disArr[r] <= k) {
                ans += r - l;
                l++;
            } else {
                r--;
            }
        }
        return ans;
    }

    long long solve(int u) {
        vis[u] = true;
        long long ans = calc(u, 0);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans -= calc(v, weight[e]);
                ans += solve(getCentroid(v, u));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        cin >> k;
        cout << solve(getCentroid(1, 0)) << '\n';
        return 0;
    }

五、题目2：相近点对

n 个点组成一棵树，1 号点是树头，从 2 号起每个点给父节点编号和边权。求同时满足路径权值和 ≤ limitw、路径边数 ≤ limitl 的点对数量，(x, x) 不算，(x, y) 与 (y, x) 同一个。1 ≤ limitl ≤ n ≤ 10⁵，0 ≤ limitw ≤ 10⁹，0 ≤ 边权 ≤ 10⁴。

限制变成了两个维度。到重心的信息相应升级成二元组 (dis, edge)：距离和边数。

按 dis 排序后，dis 这一维交给双指针：l 从头出发，只要 dis[l] + dis[r] > limitw 就把 r 减进来（从树状数组里移除）；满足时处理 l，先把自己从树状数组移除，再查剩下点里 edge ≤ limitl - edge[l] 的个数。

edge 这一维交给树状数组：下标是边数，插一棵、查一次前缀和。两个维度一个靠指针收缩、一个靠前缀计数，互不干扰。

容的部分和题 1 完全一样：calc(u, 0, 0) 加整份，calc(v, w, 1) 减子树份，初始边数 1 对应「从 u 出发已经走过一条边」。样例：3 个点链 1-2(3)、2-3(4)，limitl = 2、limitw = 5，合法点对是 (1,2)、(2,3) 两个，答案是 2。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int dis, edge;
    };

    bool NodeCmp(Node a, Node b) {
        return a.dis < b.dis;
    }

    const int MAXN = 100002;
    int n, limitl, limitw;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    Node arr[MAXN];
    int cnta;

    int tree[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        i++;
        while (i <= limitl + 1) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int sum(int i) {
        i++;
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dis, int edge) {
        if (dis > limitw || edge > limitl) {
            return;
        }
        arr[++cnta] = { dis, edge };
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + weight[e], edge + 1);
            }
        }
    }

    long long calc(int u, int dis, int edge) {
        cnta = 0;
        dfs(u, 0, dis, edge);
        sort(arr + 1, arr + cnta + 1, NodeCmp);
        for (int i = 1; i <= cnta; i++) {
            add(arr[i].edge, 1);
        }
        long long ans = 0;
        for (int l = 1, r = cnta; l <= r; ) {
            if (arr[l].dis + arr[r].dis <= limitw) {
                add(arr[l].edge, -1);
                ans += sum(limitl - arr[l].edge);
                l++;
            } else {
                add(arr[r].edge, -1);
                r--;
            }
        }
        return ans;
    }

    long long solve(int u) {
        vis[u] = true;
        long long ans = calc(u, 0, 0);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans -= calc(v, weight[e], 1);
                ans += solve(getCentroid(v, u));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> limitl >> limitw;
        for (int i = 2, fa, w; i <= n; i++) {
            cin >> fa >> w;
            addEdge(i, fa, w);
            addEdge(fa, i, w);
        }
        cout << solve(getCentroid(1, 0)) << '\n';
        return 0;
    }

六、题目3：所有合法路径的魔力和

n 个点组成一棵树，边有边权。路径边数在 [l, r] 内则合法，一条路径的魔力值是路径上所有边权的最大值，求所有合法路径的魔力值之和，(x, y) 与 (y, x) 是不同的点对。1 ≤ n、边权 ≤ 10⁵。

收集的二元组换成 (maxv, edge)：到重心路径上的最大边权和边数。按 maxv 升序排序，逐个点先查后加：处理第 i 个点时，树状数组里是前 i-1 个点（maxv 都不超过它），查询边数落在 [l - edge[i], r - edge[i]] 的个数，乘上 maxv[i] 累加。排序保证了配出来的路径最大值恰好取 maxv[i]。

这里有个细节。calc(u, 0, 0) 把 u 自己以 (0, 0) 收进数组，配对区间是 [l - 0, r - 0]；题目保证 l ≥ 1，所以 u 只会和边数至少为 1 的点配，不会和自己配。最后输出时乘 2，把无序对翻成有序对。

样例：3 个点链 1-2(1)、2-3(2)，l = 2、r = 3。只有 (1,3) 这一对边数为 2 落在区间里，魔力值 2，有序化后答案是 4。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int maxv, edge;
    };

    bool NodeCmp(Node a, Node b) {
        return a.maxv < b.maxv;
    }

    const int MAXN = 100002;
    int n, l, r;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    Node arr[MAXN];
    int cnta;

    int tree[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        i++;
        while (i <= r + 1) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int sum(int i) {
        i++;
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int maxv, int edge) {
        if (edge > r) {
            return;
        }
        arr[++cnta] = { maxv, edge };
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, max(maxv, weight[e]), edge + 1);
            }
        }
    }

    long long calc(int u, int maxv, int edge) {
        cnta = 0;
        dfs(u, 0, maxv, edge);
        sort(arr + 1, arr + cnta + 1, NodeCmp);
        long long ans = 0;
        for (int i = 1; i <= cnta; i++) {
            ans += 1LL * arr[i].maxv * (sum(r - arr[i].edge) - sum(l - arr[i].edge - 1));
            add(arr[i].edge, 1);
        }
        for (int i = 1; i <= cnta; i++) {
            add(arr[i].edge, -1);
        }
        return ans;
    }

    long long solve(int u) {
        vis[u] = true;
        long long ans = calc(u, 0, 0);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans -= calc(v, weight[e], 1);
                ans += solve(getCentroid(v, u));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> l >> r;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        long long ans = solve(getCentroid(1, 0));
        cout << (ans << 1) << '\n';
        return 0;
    }

七、题目4：消息传递

n 个点组成一棵树，边权全是 1。m 条查询 x k：打印有多少点与 x 的距离恰好为 k。1 ≤ n、m ≤ 10⁵，0 ≤ k < n。

查询带着参数，不方便在配对时逐个扫。做法是把查询挂到点上：链表 addQuery(x, k, id)，dfs 经过 x 时把查询展开成一条记录 need = k - depth(x)，depth 是 x 到本次 dfs 起点的边数。

nodeCnt[d] 统计本次 dfs 里边数为 d 的点有几个。查询记录集中起来，统一用 ans[id] += nodeCnt[need] × effect 结算：加整份时 effect = +1，减子树份时 effect = -1，起算深度分别是 0 和 1。

距离为 0 的查询会把 x 自己数进去，这和题目「与 x 的距离恰好为 0」的语义一致。dfs 结束只清 nodeCnt[0..maxEdge]，不清整个数组，多组数据下才跑得动。

样例：链 1-2-3-4-5，查询 (1, 2) 的答案是 1（只有点 3），查询 (3, 4) 的答案是 0。

完整代码如下。

#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int need, qid;
    };

    const int MAXN = 100001;
    int t, n, m;

    int headg[MAXN];
    int nextg[MAXN << 1];
    int tog[MAXN << 1];
    int cntg;

    int headq[MAXN];
    int nextq[MAXN];
    int dis[MAXN];
    int qid[MAXN];
    int cntq;

    bool vis[MAXN];
    int siz[MAXN];

    int nodeCnt[MAXN];
    int maxEdge;

    Node arr[MAXN];
    int cnta;

    int ans[MAXN];

    void addEdge(int u, int v) {
        nextg[++cntg] = headg[u];
        tog[cntg] = v;
        headg[u] = cntg;
    }

    void addQuery(int u, int k, int id) {
        nextq[++cntq] = headq[u];
        dis[cntq] = k;
        qid[cntq] = id;
        headq[u] = cntq;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = headg[u]; e; e = nextg[e]) {
                int v = tog[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int edge) {
        nodeCnt[edge]++;
        maxEdge = max(maxEdge, edge);
        for (int e = headq[u]; e; e = nextq[e]) {
            if (dis[e] >= edge) {
                arr[++cnta] = { dis[e] - edge, qid[e] };
            }
        }
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, edge + 1);
            }
        }
    }

    void calc(int u, int edge, int effect) {
        cnta = 0;
        maxEdge = 0;
        dfs(u, 0, edge);
        for (int i = 1; i <= cnta; i++) {
            ans[arr[i].qid] += nodeCnt[arr[i].need] * effect;
        }
        for (int v = 0; v <= maxEdge; v++) {
            nodeCnt[v] = 0;
        }
    }

    void solve(int u) {
        vis[u] = true;
        calc(u, 0, 1);
        for (int e = headg[u]; e; e = nextg[e]) {
            int v = tog[e];
            if (!vis[v]) {
                calc(v, 1, -1);
                solve(getCentroid(v, u));
            }
        }
    }

    void prepare() {
        cntg = 0;
        cntq = 0;
        for (int i = 1; i <= n; i++) {
            headg[i] = 0;
            headq[i] = 0;
            vis[i] = false;
        }
        for (int i = 1; i <= m; i++) {
            ans[i] = 0;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n >> m;
            prepare();
            for (int i = 1, u, v; i < n; i++) {
                cin >> u >> v;
                addEdge(u, v);
                addEdge(v, u);
            }
            for (int i = 1, x, k; i <= m; i++) {
                cin >> x >> k;
                addQuery(x, k, i);
            }
            solve(getCentroid(1, 0));
            for (int i = 1; i <= m; i++) {
                cout << ans[i] << '\n';
            }
        }
        return 0;
    }

八、复杂度分析

容斥不改变分治的结构，层数还是 O(log n)；配对从增量换成「完整数组 + 数据结构」，每层的代价由排序或树状数组主导。

操作时间复杂度空间复杂度
找重心 + 收集信息（每层合计）O(n)O(n + m)（点对数组、树状数组按 n 开，查询记录按 m 开）
题 1 排序 + 双指针（每层）O(n log n)
题 2、题 3 排序 + 树状数组（每层）O(n log n)
题 4 查询展开（每层）O(n + m)
四题总计O(n log² n)、题 4 为 O((n+m) log n)

题 4 每层最多把每条查询展开两次（整份一次、所在子树份一次），查询的总量乘上 log n 层就是答案的规模，10⁵ 的 n、m 也扛得住。

九、最后

容斥版点分治的骨架比模版版更整齐：calc 收集整份、配对交给数据结构、减掉子树份。维度多了就加树状数组，查询多了就挂链表，配对的口径始终是「到重心的两段信息」。

下一讲还有静态点分治的更多题目；再往后，把每层的重心记下来组织成新树，就是点分树和动态点分治的地盘。
