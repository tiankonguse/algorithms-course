树上的可持久化：路径第 k 小与厉害关系

序列上的版本差是「前缀 r 减前缀 l-1」，树上没有「前缀」，但树的两种遍历给了两个天然顺序：根路径（从根往下）和 dfn 序（子树连续）。顺着这两种顺序建版本，树上问题就落回可持久化线段树。

一、根路径版本：路径上的第 k 小

题目要求：树上每个点有权值，查询 u 到 v 的路径上第 k 小的点权。n、m ≤ 1e5，强制在线。

先离散化值域。每个点存一个版本：root[u] 是「根到 u 的路径上各值出现几次」的值域树。建法就是 DFS：进到 u 时从 root[父亲] 复制一条路径，把 arr[u] 的计数 +1。

路径 u→v 上的频数怎么从这些版本里拿出来？树上差分的标准公式：

频数(u→v) = root[u] + root[v] - root[lca] - root[父(lca)]

为什么对：root[u] + root[v] 把根到 u、根到 v 的两条链叠在一起，公共部分（根到 lca）被算了两次；减去 root[lca] 一次、再减去 root[父(lca)] 一次，正好把「根到父(lca)」全部抵消，剩下恰好是 lca 到 u 和 lca 到 v 两条链，也就是 u 到 v 的路径。四个版本从根一起下钻，每层的 siz 都按这个公式算，就能定位第 k 小。

DFS 里顺手把树上倍增的表也建了，LCA 用它回答。注意强制在线的细节：真实 u = 给定 u 异或 lastAns，v 和 k 不动，别把三个参数都异或了。

路径上的第 k 小（P2633）

int insert(int jobi, int l, int r, int i) {
        int rt = ++cntt;
        ls[rt] = ls[i];
        rs[rt] = rs[i];
        siz[rt] = siz[i] + 1;
        if (l < r) {
            int mid = (l + r) / 2;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
        }
        return rt;
    }

    int query(int jobk, int l, int r, int u, int v, int lca, int lcafa) {
        if (l == r) {
            return l;
        }
        int lsiz = siz[ls[u]] + siz[ls[v]] - siz[ls[lca]] - siz[ls[lcafa]];
        int mid = (l + r) / 2;
        if (lsiz >= jobk) {
            return query(jobk, l, mid, ls[u], ls[v], ls[lca], ls[lcafa]);
        } else {
            return query(jobk - lsiz, mid + 1, r, rs[u], rs[v], rs[lca], rs[lcafa]);
        }
    }

    void dfs(int u, int f) {
        root[u] = insert(kth(arr[u]), 1, s, root[f]);
        deep[u] = deep[f] + 1;
        stjump[u][0] = f;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int ei = head[u]; ei > 0; ei = nxt[ei]) {
            if (to[ei] != f) {
                dfs(to[ei], u);
            }
        }
    }

    int lca(int a, int b) {
        if (deep[a] < deep[b]) {
            swap(a, b);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (deep[stjump[a][p]] >= deep[b]) {
                a = stjump[a][p];
            }
        }
        if (a == b) {
            return a;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[a][p] != stjump[b][p]) {
                a = stjump[a][p];
                b = stjump[b][p];
            }
        }
        return stjump[a][0];
    }

    int kth(int u, int v, int k) {
        int lcaNode = lca(u, v);
        int i = query(k, 1, s, root[u], root[v], root[lcaNode], root[stjump[lcaNode][0]]);
        return sorted[i];
    }

二、dfn 前缀版本：更为厉害

题目要求：数三元组 (a, b, c)，a、b 都比 c 厉害（都是 c 的祖先），且 a、b 是邻居（路径边数 ≤ k）。n、m ≤ 3e5。

先看 b 相对 a 在哪，分两类：

1）b 是 a 的祖先。此时 c 在 a 的子树里。b 的可选范围是 a 的祖先中距离 ≤ k 的，数量 min(k, dep[a]-1)；c 的数量是 siz[a]-1。贡献 (siz[a]-1) × min(k, dep[a]-1)。

2）b 在 a 的子树里（距离 ≤ k，即深度 ≤ dep[a]+k）。此时 c 在 b 的子树里，贡献 siz[b]-1，对所有这样的 b 累加。

第二类需要一个「子树内按深度求和」的结构：dfs 生成 dep、siz、dfn，子树 a 对应 dfn 区间 [dfn[a], dfn[a]+siz[a]-1]。按 dfn 顺序建版本：每个点 u 在深度 dep[u] 处累加 siz[u]-1。查询子树 a 里深度 [dep[a]+1, dep[a]+k] 的总和，就是两个版本一减。

        ans += query(dep[a] + 1, dep[a] + k, 1, depth, root[dfn[a] - 1], root[dfn[a] + siz[a] - 1]);

四、总结

树上可持久化的两招：根路径版本用「父传子」的方式建，回答路径问题靠树上差分；dfn 前缀版本利用子树区间连续，回答子树内按深度/权值的聚合。序列上「版本差 = 区间信息」的直觉，在树上分别对应「路径 = 四版本组合」和「子树 = 两版本相减」。前置的树上倍增、dfn 遍历都是老工具，新东西只有版本怎么排。
