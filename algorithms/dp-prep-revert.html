前缀和加速枚举：还原数组的方法数

丢失了部分数字的数组要还原，每个位置的值都不超过左右邻居的较大者。从右往左填，状态里要记住「刚填的数字」和「它和更前一个的大小关系」。填一个位置的合法取值是三段连续的区间，朴素做法一段一段枚举，预处理数组把三段区间分别改成后缀和与前缀和，枚举从 O(m) 变 O(1)。

零、背景

「加速枚举」和上一题的「减少枚举」不同：这里枚举的数字段没有少，只是把重复求的区间和提前算好。值域只有 ≤ 200，m 很小，但 n 有 10 的 4 次方，每层少一个 O(m) 的枚举，总共省掉 O(n·m) 到 O(n·m²) 的差距。

一、问题

原本长度 n 的数组，下标从 1 开始，每个位置是不超过 200 的正数，且满足 arr[i] <= max(arr[i-1], arr[i+1])，边界 arr[1] <= arr[2]、arr[n] <= arr[n-1]。部分数字丢失（记 0），问还原成不违规数组有多少种方法，答案对 998244353 取模。n 到 10 的 4 次方。

二、从右往左的状态设计

决定位置 i 的值时，右边邻居 arr[i+1] 已经确定，但 arr[i-1] 还没定，约束 arr[i] <= max(arr[i-1], arr[i+1]) 没法当场判定。换个角度：决定位置 i 时能判定的是「位置 i+1 的约束」，它右边的 arr[i+2] 也定了。所以状态要带上右侧两个值的信息：

memo[v][s]：上一个位置（i+1）填的是 v；s 表示它和更前一个位置（i+2）的关系：s = 0 表示 v 严格大于它，s = 1 表示 v 小于等于它。决定位置 i 填 cur 时，检查「位置 i+1 的约束」：v <= max(cur, arr[i+2])。

  • cur > v：位置 i+1 约束自动满足（max 至少是 cur > v）。新关系 s' = 0（cur 严格大于 v）。
  • cur = v：约束满足（max ≥ v）。新关系 s' = 1。
  • cur < v：只有 s = 1（v ≤ arr[i+2]）时才满足，因为 max = arr[i+2] ≥ v。新关系 s' = 1。

三、朴素枚举

位置 i 未定时，对每个 (v, s) 枚举 cur 分三段累加：

dp[v][s] = sum(cur=v+1..m 的 memo[cur][0]) + memo[v][1] + (s==1 时 sum(cur=1..v-1 的 memo[cur][1]))。注意 cur = v 那一段独立出来，因为它的新关系是 s' = 1。

四、前缀/后缀和预处理

三段里两段是连续区间的求和：memo[cur][0] 的后缀和、memo[cur][1] 的前缀和。每层开始前 O(m) 重建，转移里 O(1) 查表：

// 预处理：suf0 是 memo[*][0] 的后缀和，pre1 是 memo[*][1] 的前缀和
    // memo[v][s]：上一个数字是 v；s=0 表示它严格大于更前一个，s=1 表示小于等于
    void prepare() {
        suf0[m] = memo[m][0];
        for (int v = m - 1; v >= 0; v--) {
            suf0[v] = (suf0[v + 1] + memo[v][0]) % MOD;
        }
        pre1[1] = memo[1][1];
        for (int v = 2; v <= m; v++) {
            pre1[v] = (pre1[v - 1] + memo[v][1]) % MOD;
        }
    }

主流程（滚动数组 memo/dp，每层互换）：

int compute() {
        for (int v = 0; v <= m; v++) {   // 第 0 个数字的边界
            memo[v][0] = 0;
            memo[v][1] = 1;
        }
        for (int i = 1; i <= n; i++) {
            prepare();                   // 每一层重建一次前缀/后缀和
            for (int v = 0; v <= m; v++) {
                for (int s = 0; s <= 1; s++) {
                    int ans = 0;
                    if (arr[i] != 0) {   // 位置 i 的数字已经确定
                        if (arr[i] >= v || s == 1) {
                            ans = memo[arr[i]][arr[i] > v ? 0 : 1];
                        }
                    } else {             // 位置 i 需要填，三段枚举合并成查表
                        if (v + 1 <= m) ans = (ans + suf0[v + 1]) % MOD;
                        if (v != 0)      ans = (ans + memo[v][1]) % MOD;
                        if (s == 1)      ans = (ans + pre1[v - 1]) % MOD;
                    }
                    dp[v][s] = ans;
                }
            }
            swap(memo, dp);
        }
        return memo[0][1];
    }

复杂度分析

朴素是每层对每个 (v, s) 枚举 cur，O(n·m²)；优化后每层 O(m) 建前缀/后缀和，再加 O(m) 填表，总 O(n·m)。n = 10 的 4 次方、m = 200 时，n·m = 2×10 的 6 次方，n·m² = 4×10 的 8 次方，差两个数量级。

空间：memo/dp 都是 (m+1)×2，加 suf0/pre1 各 m+1，O(m)。

总结

这一题最绕的是状态语义：从右往左填，s 表示「刚填的值 v 和更前一个的关系」，它决定了 cur < v 那段能不能走。三个枚举段里两段是区间和，预处理后缀和与前缀和后 O(1) 查表。和炮兵阵地对照：那题预筛状态集合，这题预存区间和，都是「转移里反复算的东西先算好」。
