静态点分治题集（二）：背包、中位数与字符串哈希

接着上一页的题集。这四道题的差距都在重心处那步统计：一道是树上依赖背包，一道是二分答案配单调队列，一道是单调栈把点对数压下来再上线段树，还有一道是字符串哈希。点分治骨架还是原样，难点全在「怎么把两半拼起来」。

零、背景

上一页的题，重心下面接的是 bfs、排序和一次下探。这一页把统计手法换成更重的东西，但出发点不变：一条路径要么经过当前重心，要么整体落在某个子树里递归处理。

真正需要设计的是经过重心的路径怎么算。四道题分别给出了四种拼法：按 dfn 序做依赖背包、按长度区间滑单调队列、把有用的点对先筛出来、按长度对 m 取模分组配对。

一、题目4：树上购物

n 个商店连成一棵树，第 i 个商店只卖第 i 种物品，物品有价值 v[i]、单价 c[i]、数量 d[i]。买过东西的商店，在树上必须连通。手里有 m 元，求能获得的最大价值总和。n ≤ 500，m ≤ 4000，d[i] ≤ 2000。

先翻译条件。「买过的商店连通」，等价于被选中的商店构成一棵连通子树，而且每个被选中的商店至少买一件，只要你从它这儿买了东西，它就进了这个集合。

点分治负责枚举经过重心的连通块，剩下的递归。重心处要解决的是：在当前这棵子树里选一个连通块，预算内价值最大。

把子树按 dfs 序排成一列，子树在序列里是连续的一段。记 dp[i][j] 为「从序列第 i 个点开始往后选，预算 j」的最大价值，从后往前推。处理第 i 个点 cur 时有三个来源。

一是买 cur 至少一件，那么它的子树可以接上来，从 dp[i+1][j-c[cur]] 转到 dp[i][j]，价值加 v[cur]。二是剩下的 d[cur]-1 件不强制，用多重背包的二进制分组再做一遍。三是不买 cur，它的整棵子树都不能碰，直接接到 dp[endDfn[cur]+1]。

这三条合起来，恰好保证「取了一个点，它的祖先就都被取过」，选出来的必定是连通块。答案就是 dp[1][m]。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 501;
    const int MAXM = 4001;
    int t, n, m;

    int v[MAXN];
    int c[MAXN];
    int d[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    int nodeArr[MAXN];
    int endDfn[MAXN];
    int cntd;

    int val[MAXN];
    int cost[MAXN];
    int dp[MAXN + 1][MAXM];

    void prepare() {
        cntg = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = 0;
            vis[i] = false;
        }
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa) {
        nodeArr[++cntd] = u;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u);
            }
        }
        endDfn[u] = cntd;
    }

    int calc(int u) {
        cntd = 0;
        dfs(u, 0);
        for (int i = cntd; i > 0; i--) {
            int cur = nodeArr[i];
            int cnt = d[cur] - 1;
            int num = 0;
            for (int k = 1; k <= cnt; k <<= 1) {
                val[++num] = v[cur] * k;
                cost[num] = c[cur] * k;
                cnt -= k;
            }
            if (cnt > 0) {
                val[++num] = v[cur] * cnt;
                cost[num] = c[cur] * cnt;
            }
            for (int j = m; j >= c[cur]; j--) {
                dp[i][j] = dp[i + 1][j - c[cur]] + v[cur];
            }
            for (int k = 1; k <= num; k++) {
                for (int j = m; j >= cost[k]; j--) {
                    dp[i][j] = max(dp[i][j], dp[i][j - cost[k]] + val[k]);
                }
            }
            for (int j = 0; j <= m; j++) {
                dp[i][j] = max(dp[i][j], dp[endDfn[cur] + 1][j]);
            }
        }
        int ans = dp[1][m];
        for (int i = 1; i <= cntd; i++) {
            for (int j = 0; j <= m; j++) {
                dp[i][j] = 0;
            }
        }
        return ans;
    }

    int solve(int u) {
        vis[u] = true;
        int ans = calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                ans = max(ans, solve(getCentroid(v, u)));
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int k = 1; k <= t; k++) {
            cin >> n >> m;
            for (int i = 1; i <= n; i++) {
                cin >> v[i];
            }
            for (int i = 1; i <= n; i++) {
                cin >> c[i];
            }
            for (int i = 1; i <= n; i++) {
                cin >> d[i];
            }
            prepare();
            for (int i = 1, u, v; i < n; i++) {
                cin >> u >> v;
                addEdge(u, v);
                addEdge(v, u);
            }
            cout << solve(getCentroid(1, 0)) << '\n';
        }
        return 0;
    }

二、题目5：最大中位数路径

n 个节点的树，边权在 0 到 10⁹。一条路径的权取这条路径上边权的中位数：把这条路径的 k 个边权从小到大排，取下标 ⌊k/2⌋ 的那个（下标从 0 数起），也就是第 ⌊k/2⌋+1 小，k 是偶数时就是中间两个里较大的那个。求边数在 [limitl, limitr] 的所有路径里权最大的那条，输出它两个端点。n ≤ 10⁵。

「最大中位数」是二分答案的典型信号。判定「是否存在长度落在 [limitl, limitr] 的路径，其中位数至少是 X」时，把每条边按 w ≥ X 记 +1、否则记 −1，就变成问有没有一条合法长度的路径，边权和 ≥ 0。

两者等价：和 ≥ 0 说明至少有 ⌈k/2⌉ 条边的边权不小于 X，而「第 ⌊k/2⌋+1 小的边权 ≥ X」也正好等价于这一点。

边权先离散化成排名，二分在排名上做，判定就只需要那份 ±1。判定的统计仍然放在点分治里：从重心出发，枚举每一棵子树，维护 preVal[L] 表示已经处理过的子树里、长度为 L 的半路径的最大和。

当前半路径长度为 i 时，要和 preVal 在下标区间 [limitl-i, limitr-i] 上取最大值。i 每加一，这个区间整体左移一格，正是滑动窗口，用单调队列维护即可。判定成功就顺手把取到最大值的节点记下来，用于最后输出方案。

这里有个细节：子树的处理顺序不能乱来。如果按输入顺序枚举，preVal 的长度可能远超当前子树规模，枚举 i 时窗口会拉得很长，复杂度就废了。做法是按子树高度（或大小）从小到大排序，处理到当前子树时前面所有子树的高度都不超过它，总代价才和当前子树大小同阶。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Input {
        int u, v, w;
    };

    bool InputCmp(Input a, Input b) {
        return a.w < b.w;
    }

    struct Edge {
        int eid, size;
    };

    bool EdgeCmp(Edge a, Edge b) {
        return a.size < b.size;
    }

    const int MAXN = 100001;
    const int INF = 1000000001;
    int n, limitl, limitr, cntw;

    Input arr[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    Edge edgeArr[MAXN];
    int cnte;

    int preVal[MAXN];
    int preNode[MAXN];
    int preLen;

    int curVal[MAXN];
    int curNode[MAXN];
    int curLen;

    int que[MAXN];

    int ans, ansu, ansv;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int edge, int sum, int limit) {
        curLen = max(curLen, edge);
        if (sum > curVal[edge]) {
            curVal[edge] = sum;
            curNode[edge] = u;
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, edge + 1, sum + (w >= limit ? 1 : -1), limit);
            }
        }
    }

    bool check(int u, int limit) {
        preVal[0] = 0;
        preNode[0] = u;
        preLen = 0;
        for (int k = 1; k <= cnte; k++) {
            int v = to[edgeArr[k].eid];
            int w = weight[edgeArr[k].eid];
            for (int i = 1; i <= siz[v]; i++) {
                curVal[i] = -INF;
            }
            curLen = 0;
            dfs(v, u, 1, w >= limit ? 1 : -1, limit);
            int ql = 1, qr = 0;
            for (int i = min(preLen, limitr); i >= limitl; i--) {
                while (ql <= qr && preVal[que[qr]] <= preVal[i]) {
                    qr--;
                }
                que[++qr] = i;
            }
            int down = limitr, up = limitl;
            for (int i = 1; i <= curLen; i++) {
                up--;
                if (up >= 0 && up <= preLen) {
                    while (ql <= qr && preVal[que[qr]] <= preVal[up]) {
                        qr--;
                    }
                    que[++qr] = up;
                }
                if (ql <= qr && que[ql] == down) {
                    ql++;
                }
                down--;
                if (ql <= qr && preVal[que[ql]] + curVal[i] >= 0) {
                    if (limit > ans) {
                        ans = limit;
                        ansu = curNode[i];
                        ansv = preNode[que[ql]];
                    }
                    return true;
                }
            }
            for (int i = 1; i <= curLen; i++) {
                if (i > preLen || curVal[i] > preVal[i]) {
                    preVal[i] = curVal[i];
                    preNode[i] = curNode[i];
                }
            }
            preLen = max(preLen, curLen);
        }
        return false;
    }

    void calc(int u) {
        getSize(u, 0);
        cnte = 0;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                edgeArr[++cnte] = { e, siz[v] };
            }
        }
        sort(edgeArr + 1, edgeArr + cnte + 1, EdgeCmp);
        int l = 1, r = cntw, mid;
        while (l <= r) {
            mid = (l + r) >> 1;
            if (check(u, mid)) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
            if (r <= ans) break;
        }
    }

    void solve(int u) {
        vis[u] = true;
        calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                solve(getCentroid(v, u));
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> limitl >> limitr;
        for (int i = 1; i < n; i++) {
            cin >> arr[i].u >> arr[i].v >> arr[i].w;
        }
        sort(arr + 1, arr + n, InputCmp);
        cntw = 0;
        for (int i = 1; i < n; i++) {
            if (i == 1 || arr[i - 1].w != arr[i].w) {
                cntw++;
            }
            addEdge(arr[i].u, arr[i].v, cntw);
            addEdge(arr[i].v, arr[i].u, cntw);
        }
        solve(getCentroid(1, 0));
        cout << ansu << " " << ansv << '\n';
        return 0;
    }

三、题目6：支配点对距离

n 个节点的树，每边有权，dist(i, j) 是两点间边权和。对一个编号区间 [x, y]，在 x ≤ a < b ≤ y 的所有点对里，距离最小的那个叫这个区间的支配点对，它的距离就是区间的支配点对距离；如果 x == y，规定为 −1。m 次询问，每次给 x、y，求支配点对距离。n ≤ 2×10⁵，m ≤ 10⁶。

朴素做法是先把所有点对的距离都算出来，每次查询在区间里扫一遍，点对数是 O(n²)，查询每次又是 O(n²)，两边都撑不住。

第一个观察：真正有用的点对只有 O(n log n) 个。在点分治的每一层，把当前组件里的点按编号排序，用一个 dist 单调递减的栈从左往右扫一遍：新点比栈顶点更近时，栈顶点和新点构成一个候选点对，同时把栈顶点弹掉。再从右往左扫一遍。这样每个点至多被弹出一次，留下的候选点对总数就是 O(n log n)。

为什么够：一个区间里最近的那对点，一定是某一层里被这条规则保留下来的对（要么直接就是栈相邻时配出来的，要么被它们之间更近的点对盖住，而那对也在候选里）。

第二个观察：查询可以离线。把候选点对按较大的那个端点 b 排序，查询按 y 排序。扫描时把 b ≤ 当前 y 的点对拿来更新线段树：用它的距离去更新位置 a 上的最小值。查询 [x, y] 就变成线段树上 [x, y] 的最小值。x == y 单独回答 −1。

于是所有点对的距离计算交给点分治，区间查询交给线段树，两边各司其职。

一个一个区间问下去，支配点对是谁

一条 5 个点的链，边权依次是 5、2、1、6。点「下一步」换一个查询区间，看橙色那一对被挑出来，它的距离就是这次查询的答案。x 等于 y 时不存在点对，答案是 −1。

支配点对 落在区间内的点

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int x, y, id;
    };

    struct Pair {
        int a, b;
        long long dist;
    };

    bool QueryCmp(Query q1, Query q2) {
        return q1.y < q2.y;
    }

    bool PairCmp(Pair p1, Pair p2) {
        return p1.b < p2.b;
    }

    const int MAXN = 200001;
    const int MAXM = 1000001;
    const int MAXP = 10000001;
    const long long INF = 1LL << 60;
    int n, m;
    Query queryArr[MAXM];

    Pair pairArr[MAXP];
    int cntp;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    bool vis[MAXN];
    int siz[MAXN];

    long long dist[MAXN];
    int nodeArr[MAXN];
    int cnta;

    int sta[MAXN];
    int top;

    long long minTree[MAXN << 2];
    long long ans[MAXM];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, long long dis) {
        dist[u] = dis;
        nodeArr[++cnta] = u;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dis + w);
            }
        }
    }

    void stackAdd(int cur) {
        while (top > 0 && dist[sta[top]] >= dist[cur]) {
            pairArr[++cntp] = { min(sta[top], cur), max(sta[top], cur), dist[sta[top]] + dist[cur] };
            top--;
        }
        sta[++top] = cur;
    }

    void calc(int u) {
        cnta = 0;
        dfs(u, 0, 0);
        sort(nodeArr + 1, nodeArr + cnta + 1);
        top = 0;
        for (int i = 1; i <= cnta; i++) {
            stackAdd(nodeArr[i]);
        }
        top = 0;
        for (int i = cnta; i >= 1; i--) {
            stackAdd(nodeArr[i]);
        }
    }

    void solve(int u) {
        vis[u] = true;
        calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                solve(getCentroid(v, u));
            }
        }
    }

    void up(int i) {
        minTree[i] = min(minTree[i << 1], minTree[i << 1 | 1]);
    }

    void build(int l, int r, int i) {
        if (l == r) {
            minTree[i] = INF;
        } else {
            int mid = (l + r) >> 1;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            up(i);
        }
    }

    void update(int jobi, long long jobv, int l, int r, int i) {
        if (l == r) {
            minTree[i] = min(minTree[i], jobv);
        } else {
            int mid = (l + r) >> 1;
            if (jobi <= mid) {
                update(jobi, jobv, l, mid, i << 1);
            } else {
                update(jobi, jobv, mid + 1, r, i << 1 | 1);
            }
            up(i);
        }
    }

    long long query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            return minTree[i];
        }
        long long ans = INF;
        int mid = (l + r) >> 1;
        if (jobl <= mid) {
            ans = min(ans, query(jobl, jobr, l, mid, i << 1));
        }
        if (jobr > mid) {
            ans = min(ans, query(jobl, jobr, mid + 1, r, i << 1 | 1));
        }
        return ans;
    }

    void compute() {
        solve(getCentroid(1, 0));
        sort(queryArr + 1, queryArr + m + 1, QueryCmp);
        sort(pairArr + 1, pairArr + cntp + 1, PairCmp);
        build(1, n, 1);
        for (int i = 1, j = 1; i <= m; i++) {
            for (; j <= cntp && pairArr[j].b <= queryArr[i].y; j++) {
                update(pairArr[j].a, pairArr[j].dist, 1, n, 1);
            }
            if (queryArr[i].x == queryArr[i].y) {
                ans[queryArr[i].id] = -1;
            } else {
                ans[queryArr[i].id] = query(queryArr[i].x, queryArr[i].y, 1, n, 1);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        cin >> m;
        for (int i = 1; i <= m; i++) {
            cin >> queryArr[i].x >> queryArr[i].y;
            queryArr[i].id = i;
        }
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

四、题目7：模式字符串

n 个节点的树，每个节点上一个大写字母。给定长度 m 的字符串 s（也只有大写字母），m ≤ n。对于点对 (u, v)，把路径上节点的字母依次拼起来，如果恰好是 s 重复若干正数次，就算合法。求合法的点对数，注意 (u, v) 和 (v, u) 算两次，(u, v) 里 u 和 v 不同。

路径拼出来的串长度必须是 m 的倍数。把 s 无限接下去，从任意位置出发都能读到 s 的某个循环。

用字符串哈希把「这一半对不对得上」变成一次相等判断。预处理两个数组：pre[L] 是 s 无限重复串前 L 个字符的哈希，suf[L] 是把 s 反转后无限重复串前 L 个字符的哈希。

点分治时，从重心 u 往下走，走到深度 dep 的节点就算出从 u 到它的哈希。这个哈希等于 pre[dep]，说明这一半从重心这端起正好是 s 的一段循环前缀；等于 suf[dep]，说明它是某段循环后缀的反向。

两半要拼成 s 的整数倍，等价于两半接起来的总长度是 m 的倍数。总长度是两半各自的长度加起来再减去 1（重心那个点被两半都算了一次）。所以按「长度对 m 取模」把半路径分组，用已经处理过的子树里对应组的个数，直接累加。

重心自己算作长度 1 的一条半路径，初始化进两组里；这样「一个端点是重心」的路径也能被统计到。每换一棵子树，先把当前子树里前缀、后缀的计数拿去和已处理子树配对，再把当前子树的计数并进去，避免同一棵子树内部配对产生重复。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const long long BASE = 499;
    int t, n, m;

    char val[MAXN];
    char str[MAXN];
    int a[MAXN];
    int b[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    long long pre[MAXN];
    long long suf[MAXN];

    bool vis[MAXN];
    int siz[MAXN];

    int deep[MAXN];
    long long curp[MAXN];
    long long curs[MAXN];
    long long allp[MAXN];
    long long alls[MAXN];

    long long ans;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroid(int u, int fa) {
        getSize(u, fa);
        int half = siz[u] >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (v != fa && !vis[v] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        return u;
    }

    void dfs(int u, int fa, int dep, long long hash) {
        deep[u] = dep;
        hash = hash * BASE + (val[u] - 'A' + 1);
        if (hash == pre[dep]) {
            curp[(dep - 1) % m + 1]++;
            ans += alls[m - (dep - 1) % m];
        }
        if (hash == suf[dep]) {
            curs[(dep - 1) % m + 1]++;
            ans += allp[m - (dep - 1) % m];
        }
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (v != fa && !vis[v]) {
                dfs(v, u, dep + 1, hash);
                deep[u] = max(deep[u], deep[v]);
            }
        }
    }

    void calc(int u) {
        int maxDep = 0;
        allp[1] = alls[1] = 1;
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                dfs(v, u, 2, 1LL * (val[u] - 'A' + 1));
                int curDep = min(deep[v], m);
                for (int i = 1; i <= curDep; i++) {
                    allp[i] += curp[i];
                    alls[i] += curs[i];
                    curp[i] = curs[i] = 0;
                }
                maxDep = max(maxDep, curDep);
            }
        }
        for (int i = 1; i <= maxDep; i++) {
            allp[i] = alls[i] = 0;
        }
    }

    void solve(int u) {
        vis[u] = true;
        calc(u);
        for (int e = head[u]; e; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                solve(getCentroid(v, u));
            }
        }
    }

    void prepare() {
        cntg = 0;
        ans = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = 0;
            vis[i] = false;
        }
        for (int i = 1; i < n; i++) {
            addEdge(a[i], b[i]);
            addEdge(b[i], a[i]);
        }
        long long tmp = 1;
        for (int i = 1; i <= n; i++) {
            pre[i] = pre[i - 1] + tmp * (str[(i - 1) % m + 1] - 'A' + 1);
            suf[i] = suf[i - 1] + tmp * (str[m - (i - 1) % m] - 'A' + 1);
            tmp = tmp * BASE;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int k = 1; k <= t; k++) {
            cin >> n >> m;
            for (int i = 1; i <= n; i++) {
                cin >> val[i];
            }
            for (int i = 1; i < n; i++) {
                cin >> a[i] >> b[i];
            }
            for (int i = 1; i <= m; i++) {
                cin >> str[i];
            }
            prepare();
            solve(getCentroid(1, 0));
            cout << ans << '\n';
        }
        return 0;
    }

五、复杂度分析

四道题的点分治骨架依旧是 O(n log n) 层工作量。多出来的对数因子来自各自的统计手法。

操作时间复杂度空间复杂度
题目4：树上依赖背包（每层对子树按预算 m 转移）O(n m log n log d)O(n m)（dp 表按预算开一维）
题目5：二分答案（排名上）× 每层 O(size) 判定O(n log n log W)O(n)
题目6：候选点对 O(n log n) + 离线线段树O(n log² n + m log n)O(n log n + m)
题目7：每层一遍哈希与按模分组统计O(n log n)O(n)

题目4 里 d 是单店数量上限，二进制的 log 只在这一维上；n、m 都不大，所以能过。题目5 里 W 是不同边权的种数，二分在排名上做，判定每层一遍扫描。题目6 的候选点对由每层的单调栈产生，共 O(n log n) 个，线段树承担查询那一侧的 log。

六、最后

四道题连着上一页的三道，说的其实是同一件事：点分治把树按重心拆成 O(log n) 层，每一层给足了对当前子树做统计的自由度。剩下的就是把统计本身写对，背包的连通约束、滑动窗口的边界、候选点对的筛法和哈希的分组。
