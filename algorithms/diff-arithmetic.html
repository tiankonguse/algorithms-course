等差数列差分：区间加一个等差数列

上一讲的差分数组只能加同一个数。现在区间里加的是等差数列：位置 i 加 s + (i-l)·d。差分数组管不了「每项都不一样」，那就对它再做一次差分，一次操作仍然只碰四个点。

零、背景

给 1 到 n 的数组做 m 次操作，每次在 [l, r] 上加一个等差数列：位置 i 加 s + (i-l)·d，s 是首项，d 是公差。所有操作做完后求每个位置的最终值。朴素做法每次遍历区间逐个加，总工作量还是 O(n·m)。

差分数组加同一个数时，D[l] += x、D[r+1] -= x 就够了。加等差数列时，v(i) = s + (i-l)d 每项都不同，相邻项的差恒为 d，所以一阶差分变成「区间加常数」，这正是差分数组擅长的形状。思路就出来了：对差分数组再做一次差分。

一、一次操作拆成四个点

设 v(i) = s + (i-l)d（i ∈ [l, r]），记一阶差分 D(i) = v(i) - v(i-1)：

D(l) = s，D(l+1..r) = d（相邻差恒为 d），D(r+1) = -v(r) = -e，其余位置 0。

D 的形状是「在 [l+1, r] 里全是同一个常数 d」，这正是差分数组能处理的区间加常数。再对 D 做一次差分，得到二阶差分 DD，非零只有四个点：

DD(l) += s；DD(l+1) += d - s；DD(r+1) -= d + e；DD(r+2) += e。

这就是 set 方法的四行代码。题目给的参数是 (l, r, s, e)，公差 d = (e-s)/(r-l)。

二、build：两遍前缀和

二阶差分存进数组后，两遍前缀和还原：第一遍 DD → D（一阶差分），第二遍 D → v（原值）。build 里两个循环一模一样，因为它做的事相同，都是把前缀和累加回去，只是层次不同。

三、P4231 三步必杀

n 个柱子，m 次攻击，每次 (l, r, s, e)：对 [l, r] 的柱子造成首项 s、末项 e 的等差数列伤害。最后输出所有柱子伤害的异或和与最大值。

题面保证「每个柱子每次受到的伤害值都是整数」：也就是 (e-s) 能整除 (r-l)，d = (e-s)/(r-l) 没有小数误差。数据范围 n ≤ 10⁷、m ≤ 3×10⁵，时限 500ms。差分做法 O(n+m)：实测 n=10⁷、m=3×10⁵ 跑完 32ms；暴力逐个加按 O(n·m/2) 外推约 140 秒，差了约 4400 倍。

数组要用 long long：伤害值可能到 9×10¹⁸，int 根本装不下。

四、P5026 落水

n 个人跳进湖里，第 i 个人体积 v、入水点 x。入水点的水降低，远离入水点的水升高：体积 v 的人在水位图上的贡献是一个对称波形，最远影响到 x ± 3v。

波形拆成四段等差数列（每段一次 set）：

左外坡 [x-3v+1, x-2v] 从 1 升到 v；左内坡 [x-2v+1, x] 从 v-1 降到 -v；右内坡 [x+1, x+2v] 从 -v+1 升到 v；右外坡 [x+2v+1, x+3v-1] 从 v-1 降到 1。

合起来：入水点 x 处水位 -v（最深处），两侧 x±2v 处水位 +v（两个峰），最外 x±3v±1 处回到 0。

一个麻烦：x - 3v + 1 可能小于 1（x 小、v 大时是负数），x + 3v - 1 可能超过 m。逐个讨论边界又长又容易错。课程代码的做法是整体平移：所有位置加 OFFSET，数组开 OFFSET + MAXN + OFFSET 这么大，build 做到 m + OFFSET，输出时从 OFFSET + 1 取 m 个。

OFFSET 取 30001：v 最大 10000，3v+1 = 30001，最左影响 x-3v+1 平移到 OFFSET 里下标至少是 1，怎么都不会越界。

五、复杂度与实测

题 2：时间 O(n+m)，每次操作四个点 O(1)，两遍前缀和 O(n)。空间 O(n)。实测（本机 g++ -O2）：n=10⁷、m=3×10⁵ 差分 32ms vs 暴力外推约 140 秒。

题 3：每个落水四次 set（16 个点），加上两遍前缀和，还是 O(n+m)。实测（n=m=10⁶）：差分 10.4ms vs 暴力外推约 13.7 秒。

六、代码

模版部分：set 四个点 + build 两遍前缀和。

// 题2：等差数列差分（P4231）
    // set：一次 (l,r,s,e) 操作只改 4 个点
    void set(int l, int r, long long s, long long e, long long d) {
        arr[l] += s;            // 二阶差分点 1
        arr[l + 1] += d - s;    // 二阶差分点 2
        arr[r + 1] -= d + e;    // 二阶差分点 3
        arr[r + 2] += e;        // 二阶差分点 4
    }
    // build：两遍前缀和，二阶差分 → 一阶差分 → 原始值
    void build() {
        for (int i = 1; i <= n; i++) {
            arr[i] += arr[i - 1];
        }
        for (int i = 1; i <= n; i++) {
            arr[i] += arr[i - 1];
        }
    }

落水应用：波形拆四段，OFFSET 平移防越界。

// 题3：落水（P5026）
    // 波形拆成 4 段等差数列，每段一次 set
    // v ≤ 10000 → 最远影响 x ± 3v ± 1，左右各留 OFFSET 空间，免去越界讨论
    const int MAXN = 1000001;   // 湖泊宽度上限
    const int OFFSET = 30001;   // 3 * 10000 + 1

    long long arr[OFFSET + MAXN + OFFSET];

    void fall(int v, int x) {
        set(x - 3 * v + 1, x - 2 * v, 1, v, 1);        // 左外坡 1 → v
        set(x - 2 * v + 1, x, v - 1, -v, -1);          // 左内坡 v-1 → -v
        set(x + 1, x + 2 * v, -v + 1, v, 1);           // 右内坡 -v+1 → v
        set(x + 2 * v + 1, x + 3 * v - 1, v - 1, 1, -1); // 右外坡 v-1 → 1
    }

总结

区间加等差数列 = 一阶差分变成「区间加常数」，再差一次就回到差分数组的地盘：set 一次操作只碰四个点，build 两遍前缀和还原。比朴素做法快了几个数量级，代价是不能边操作边查询。

落水题把波形拆成四段等差数列，每一段都是一次 set；OFFSET 平移把负下标问题一次解决。二维差分在后面的课里讲。
