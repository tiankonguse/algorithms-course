并查集应用：集合数即答案

并查集在 union 成功时把集合数减一，这个 sets 变量很多题的答案就是它。情侣牵手错位几次、相似字符串分成几组，都在问「还剩几个集合」。

零、背景

上一页的模版只回答「同集合吗」「合并了吗」。应用题的套路是：把题目的实体映射成并查集的元素，把「有关系」变成 union，最后答案落在 sets 或者由 sets 推出来。

这一页两题都是这个形状：情侣牵手是「座位相邻连边」，相似字符串是「两两相似连边」，答案都跟集合数挂钩。

一、情侣牵手：错位环要 size-1 次交换

2n 个座位坐 n 对情侣，编号 (0,1)、(2,3) 依次类推。每个座位 i 上坐的人 row[i]，它属于第 row[i]/2 对。两个相邻座位坐着的两个人各属于一对，这个座位对就把这两「对」绑到了一起。

把每对情侣当节点，每个座位对 (row[i], row[i+1]) 连一条边，连通块里的节点形成了一个错位环。一个环有 size 对，环内交换 size-1 次就能全部归位，所以总交换次数 = Σ(size-1) = 对总数 - 集合数。

并查集只管合并和减 sets：初始 sets = n，每 union 成功一次减一，答案 = n - sets。LC 例 [0,2,1,3]：座位 0-1 坐着 0、2（第 0 对、第 1 对），座位 2-3 坐着 1、3（第 0 对、第 1 对），两个集合并成一个，sets 从 2 变 1，答案 2-1 = 1。

#include <bits/stdc++.h>
    using namespace std;

    // 情侣牵手：坐错位置时相邻两座连一条边，答案 = 对数 - 集合数
    int minSwapsCouples(vector<int>& row) {
        int n = row.size();
        int k = n / 2;                    // k 对情侣
        vector<int> father(k);
        for (int i = 0; i < k; i++) father[i] = i;
        int sets = k;

        function<int(int)> find = [&](int i) -> int {
            if (i != father[i]) father[i] = find(father[i]);
            return father[i];
        };
        auto unionSet = [&](int x, int y) {
            int fx = find(x), fy = find(y);
            if (fx != fy) {
                father[fx] = fy;
                sets--;
            }
        };

        for (int i = 0; i < n; i += 2) {  // 每个座位对里的两人按「情侣对号」合并
            unionSet(Math.floor(row[i] / 2), Math.floor(row[i + 1] / 2));
        }
        return k - sets;
    }

二、相似字符串组：两两判相似再合并

字符串 X 和 Y 相似，指交换 X 中两个位置的字母就能得到 Y（两字符相同位置的视为自相似）。所有字符串互为异位词，所以只要数两个串有几个位置不同：0 个（本身相等）或 2 个（交换一次可达）都相似，其余不相似。

对每对字符串判一次相似，相似就 union。n ≤ 300、串长 ≤ 300，两两比较 O(n²×m) 足够。LC 例 ["tars","rats","arts","star"]：tars 和 rats 差 2 位相似，tars 和 arts 也相似，三个串并成一组，star 单独一组，sets = 2。

#include <bits/stdc++.h>
    using namespace std;

    // 相似字符串组：两两判相似（交换两个位置能相等，或本身就相等），相似则合并
    int numSimilarGroups(vector<string>& strs) {
        int n = strs.size();
        int m = strs[0].size();
        vector<int> father(n);
        for (int i = 0; i < n; i++) father[i] = i;
        int sets = n;

        function<int(int)> find = [&](int i) -> int {
            if (i != father[i]) father[i] = find(father[i]);
            return father[i];
        };
        auto unionSet = [&](int x, int y) {
            int fx = find(x), fy = find(y);
            if (fx != fy) {
                father[fx] = fy;
                sets--;
            }
        };

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (find(i) != find(j)) {
                    int diff = 0;
                    for (int k = 0; k < m && diff < 3; k++) {
                        if (strs[i][k] != strs[j][k]) diff++;
                    }
                    if (diff == 0 || diff == 2) {   // 差 0 或差 2 都相似
                        unionSet(i, j);
                    }
                }
            }
        }
        return sets;
    }

三、复杂度分析

题目时间复杂度额外空间
情侣牵手O(n)O(n)
相似字符串组O(n²×m)O(n)

情侣牵手 n 是座位数，合并 n/2 次，每次均摊 O(α)。相似字符串组主体在 O(n²) 次判相似，每次 O(m) 比较，并查集是配角。

四、总结

应用题的套路固定：实体映射成元素，关系映射成 union，答案落在 sets 上。情侣牵手要理解「一个错位环要 size-1 次交换」，相似字符串要写对「差 0 或差 2 才相似」的判定。

sets 还能带上更多信息：下节课会讲给每个集合打标签、数集合数量的小扩展。先记结论，这两个模版直接背下来用。
