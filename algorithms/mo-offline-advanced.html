莫队二次离线（二）：贡献重定义与三次离线

上一页的写法要维护 pre 和 suf 两份前缀信息、两条任务链表，因为左端移动和右端移动的方向不同。第二种实现只剩一份 pre 和一条链表：左端移动也去查同一份 pre，多出来的那部分正好被任务抵消。代价是「一个位置装进集合时的贡献」要重新定义，题目3 把它拆成两份，题目4 的两个方向干脆不对称，得再补一次离线。

零、背景

题目3 需要树状数组，题目4 需要根号分治。这一页的两道题都用第二种实现，代码比上一页短一截，但第一次读会绕一些。

一、题目3：区间 Abbi 值

给定一个长度为 n 的数组。如果 arr[l..r] 包含数字 v，并且 v 在这个区间里是第 k 小，那么这个数字的 Abbi 值就是 v × k；区间 Abbi 值是区间内所有数字的 Abbi 值之和。m 条查询，每条给出 l r，打印 arr[l..r] 的 Abbi 值。

1 ≤ n、m ≤ 5 × 10⁵，1 ≤ arr[i] ≤ 10⁵，测试链接 P5501。

比如 [1, 2, 2, 3] 的 Abbi 值 = 1 × 1 + 2 × 2 + 2 × 2 + 3 × 4 = 21。这里 k 是「区间里严格小于它的元素个数 + 1」，两个 2 拿到的是同一个 k = 2，3 的 k = 4。

二、把贡献拆成两块

设一个集合里已经有若干数字，现在把值 v 装进去。Abbi 值的变化是两块：新数字自己那份 v × (比它小的个数 + 1)，以及所有比 v 大的数字各自多了一个比它们小的元素、k 加一，于是每一份都加上它自己的值。

写成式子就是：增量 = (比 v 小的个数) × v + (比 v 大的值之和) + v。最后那个 v 是每个位置自己的基础项，跟集合里有什么无关，把它挪到最后统一用区间和补上，中间只算前两块。

于是 pre[i] 的含义变成：把 arr[i] 装进 arr[1..i−1] 时，除自己的 arr[i] 之外的增量，再做前缀和。扫一遍用两个树状数组就能算：一个记值出现次数，一个记值的总和。

三、第二种实现：左端也查同一份 pre

右端移动和上一页完全一样：右移时 ans += pre[jobr] − pre[winr]，任务挂在 x = winl−1；左移时符号反过来。

左端移动改用 pre 处理。设左端从 winl 左移到 jobl < winl，新增的位置是 jobl 到 winl−1，记作 B 段。先减掉 pre[winl−1] − pre[jobl−1]，也就是「把 B 装进 arr[1..jobl−1] 的增量」；再记一个任务挂在 x = winr 上，区间是 [jobl, winl−1]，op = +1，求的是「把 B 装进 arr[1..winr] 的增量」。

B 自己内部的配对在两笔里都算了，减一次加一次正好抵消；arr[1..jobl−1] 那部分也是一减一加抵消；最后只剩 B 与 [winl, winr] 的配对，正是要的变化量。

反向的左端右移同理，符号对调。四种移动合起来仍是四行，只是第二条链表和 suf 都不需要了。

四、值域分块：lessCnt 与 moreSum

第二次离线要查「集合里比 v 小的个数」和「集合里比 v 大的值之和」。用树状数组是 O(log V)，乘上任务枚举量 O(n√n) 会偏慢，换值域分块：装一个值改 O(√V)，查一次 O(1)。

具体来说，装进值 v 时：比 v 大的整块的 blockLessCnt 各加一，块内比 v 大的位置 numLessCnt 各加一；比 v 小的整块的 blockMoreSum 各加 v，块内比 v 小的位置 numMoreSum 各加 v。注意块长取的是 √V（V = 10⁵），和莫队的块长 √n 不是一回事。

六、题目3 的代码

两个分块数组和它们的维护函数：

void addVal(int val) {
        for (int b = bi[val] + 1; b <= bi[MAXV]; b++) {
            blockLessCnt[b]++;
        }
        for (int i = val + 1; i <= br[bi[val]]; i++) {
            numLessCnt[i]++;
        }
        for (int b = 1; b <= bi[val] - 1; b++) {
            blockMoreSum[b] += val;
        }
        for (int i = bl[bi[val]]; i < val; i++) {
            numMoreSum[i] += val;
        }
    }

    int lessCnt(int x) {
        return blockLessCnt[bi[x]] + numLessCnt[x];
    }

    long long moreSum(int x) {
        return blockMoreSum[bi[x]] + numMoreSum[x];
    }

pre 的构造、莫队滑窗、第二次离线的扫描，全在 compute 里：

void compute() {
        for (int i = 1; i <= n; i++) {
            pre[i] = pre[i - 1] + sum(treeCnt, arr[i] - 1) * arr[i] + sum(treeSum, MAXV) - sum(treeSum, arr[i]);
            add(treeCnt, arr[i], 1);
            add(treeSum, arr[i], arr[i]);
        }
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            if (winr < jobr) {
                addOffline(winl - 1, winr + 1, jobr, -1, id);
                ans[id] += pre[jobr] - pre[winr];
            }
            if (winr > jobr) {
                addOffline(winl - 1, jobr + 1, winr, 1, id);
                ans[id] -= pre[winr] - pre[jobr];
            }
            winr = jobr;
            if (winl > jobl) {
                addOffline(winr, jobl, winl - 1, 1, id);
                ans[id] -= pre[winl - 1] - pre[jobl - 1];
            }
            if (winl < jobl) {
                addOffline(winr, winl, jobl - 1, -1, id);
                ans[id] += pre[jobl - 1] - pre[winl - 1];
            }
            winl = jobl;
        }
        long long tmp;
        for (int x = 0; x <= n; x++) {
            if (x >= 1) {
                addVal(arr[x]);
            }
            for (int q = headq[x]; q > 0; q = nextq[q]) {
                int l = ql[q], r = qr[q], op = qop[q], id = qid[q];
                for (int j = l; j <= r; j++) {
                    tmp = 1LL * lessCnt(arr[j]) * arr[j] + moreSum(arr[j]);
                    if (op == 1) {
                        ans[id] += tmp;
                    } else {
                        ans[id] -= tmp;
                    }
                }
            }
        }
    }

prepare 只做前缀和与值域分块的初始化：

void prepare() {
        for (int i = 1; i <= n; i++) {
            preSum[i] = preSum[i - 1] + arr[i];
        }
        int blen = (int)sqrt(MAXV);
        int bnum = (MAXV + blen - 1) / blen;
        for (int i = 1; i <= MAXV; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
            br[i] = min(i * blen, MAXV);
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

七、题目4：区间倍数二元组

给定一个长度为 n 的数组。如果 arr[i] 是 arr[j] 的倍数（≥ 1 倍），那么 (i, j) 就是一个倍数二元组。i ≠ j 时 (i, j) 和 (j, i) 算两个不同的二元组，i = j 时只算一个。m 条查询，每条给出 l r，打印 arr[l..r] 上有多少倍数二元组。

1 ≤ n、m、arr[i] ≤ 5 × 10⁵，测试链接 P5398。

比如 [2, 4, 2, 6] 有 10 个：i ≠ j 的有 (1,3)、(2,1)、(2,3)、(3,1)、(4,1)、(4,3) 这 6 个，加上 4 个 i = j 的，一共 10 个。

八、因子量与倍数量

和前几题不同，这里的配对关系不对称：arr[j] 整除 arr[i] 才算数。把位置 i 装进已有集合时，增量要分两个方向数。

一是「已装的里面有多少是 arr[i] 的因子」，也就是已装元素整除 arr[i] 的个数，用一个数组 xcnt[v] 记「v 是多少个已装元素的因子」，直接读 xcnt[arr[i]]；二是「已装的里面有多少是 arr[i] 的倍数」，这个方向要枚举 arr[i] 的所有因子 d，读 vcnt[d]（已装元素里值等于 d 的个数）。

pre 的构造就是这两笔相加：pre[i] = pre[i−1] + xcnt[arr[i]] + Σ_{d | arr[i]} vcnt[d]。因子用试除法枚举，每个数 O(√V)。

九、根号分治：大值枚举倍数，小值再走一次离线

第一次离线（莫队滑窗）照旧生成任务，任务求的是「arr[1..x] 与 arr[l..r] 之间的二元组个数」。第二次离线扫 x 时，如果还是按上面两个方向算，第二个方向要枚举 arr[j] 的所有因子，乘上任务枚举量太慢。

换个角度：第二个方向也可以写成「已装元素 v 整除 arr[j]」，于是按 v 的大小分两类。v 大（> 100）时它作为因子的倍数很少，装元素时直接枚举它的倍数 v、2v、3v …… 把对应的 xcnt 加一，总代价 O(maxV / v)，v 越大越便宜；v 小（≤ 100）时倍数很多，不能这么干，改成第三次离线统一处理。

这里有个细节：第三次离线的贡献写成 vcnt[x] × (xcnt[r] − xcnt[l−1])，和前面「枚举区间里每个位置」的写法不一样。因为小值 v 的因子量只跟「区间里能被 v 整除的位置有多少」有关，可以一次算完，不必逐个位置查。

十、自己跟自己的那一对

i = j 时只算一个二元组，而中间的计算里，位置 j 装进集合时两个方向都会把自己算进去，一共两次。左端左移、右移时新增的每一段都要扣掉 2 × 段长，这就是代码里 +2 × (winl − jobl) 那一项的来历。右端移动不涉及这个问题，因为任务区间和集合没有交集。

最后主函数里还有一笔：ans += r − l + 1，把区间里每个位置的 i = j 那一对加回来。

void addFactors(int num) {
        if (headf[num] == 0) {
            for (int f = 1; f * f <= num; f++) {
                if (num % f == 0) {
                    nextf[++cntf] = headf[num];
                    fac[cntf] = f;
                    headf[num] = cntf;
                }
            }
        }

void compute() {
        for (int i = 1; i <= n; i++) {
            int num = arr[i];
            pre[i] = pre[i - 1];
            pre[i] += xcnt[num];
            for (int e = headf[num], f, other; e > 0; e = nextf[e]) {
                f = fac[e];
                other = num / f;
                xcnt[f]++;
                pre[i] += vcnt[f];
                if (other != f) {
                    xcnt[other]++;
                    pre[i] += vcnt[other];
                }
            }
            vcnt[num]++;
        }
        int winl = 1, winr = 0;
        for (int i = 1; i <= m; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            int id = query[i].id;
            if (winr < jobr) {
                addOffline(winl - 1, winr + 1, jobr, -1, id);
                ans[id] += pre[jobr] - pre[winr];
            }
            if (winr > jobr) {
                addOffline(winl - 1, jobr + 1, winr, 1, id);
                ans[id] -= pre[winr] - pre[jobr];
            }
            winr = jobr;
            if (winl > jobl) {
                addOffline(winr, jobl, winl - 1, 1, id);
                ans[id] -= pre[winl - 1] - pre[jobl - 1] + 2 * (winl - jobl);
            }
            if (winl < jobl) {
                addOffline(winr, winl, jobl - 1, -1, id);
                ans[id] += pre[jobl - 1] - pre[winl - 1] + 2 * (jobl - winl);
            }
            winl = jobl;
        }

十二、复杂度分析

设 V = max(arr)，LIMIT = 100，莫队块长 √n，值域块长 √V。

题目4 里「大值枚举倍数」那一笔的总代价是 Σ_{arr[i] > LIMIT} V / arr[i]，每个数不超过 V / LIMIT，乘上 n 看似很大，但实际按值域分摊后是 O(n√V) 量级，值大于 √V 的数最多 √V 个贡献，值小于 √V 的数每个贡献 O(√V)。

十三、最后

能离线就先离线：滑窗每次挪动都要做的配对，攒成任务批量算，代价从「每次挪动一遍」变成「全程几遍扫描」。题目3 的 Abbi 值、题目4 的倍数二元组都走这条路，题目4 的「大值枚举倍数」也在第一次离线时压进了任务。

两种实现的差别到这里就清楚了：第一种保留 pre、suf 两条链，思路直观，代价是多一遍扫描和一条链表；第二种只剩一份 pre，代价是贡献要重新定义，遇到题目4 这种不对称的配对还要再补一次离线。这一讲的四道题之外，下一讲是莫队的综合应用。
