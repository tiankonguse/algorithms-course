长链剖分优化树上动态规划

有一类树形 dp 的状态第二维是「到 u 的距离」。这种表的形状跟子树高度绑在一起，而长链剖分恰好把高度方向摊成了一维连续空间，长儿子直接继承，轻儿子暴力合并，总代价 O(n)。

零、背景

上一节用长链剖分做的是结构查询：链上 dfn 连续、跨链条数少。这一节用它做动态规划，吃的是同一条性质，只是把「连续」用在了 dp 表上。

先看什么时候能用得上。假设 dp[u][i] 表示「u 的子树里，与 u 有关、且第二维是 i 的某种量」，i 的取值范围由子树高度决定，并且转移形如 dp[u][i] 依赖 dp[儿子][i − 1]。这类表就能压进长链。

一、表怎么摊开

dfs2 先递归长儿子，所以一条长链上的点，dfn 是连续的一段。把 dp[u][i] 存进 dp[dfn[u] + i]，链上每个点的表就首尾相接地排进同一个一维数组：u 的第 i 格，正好是长儿子的第 i − 1 格。

于是长儿子的信息不用搬，父节点直接读自己的格子就行。轻儿子的表在别处，只能老老实实枚举合并。

为什么总代价是 O(n)。每条长链只在它的链头处被完整遍历一次，链上其他点都是白捡继承。所有链长加起来是 n，所以合并的总次数也是 O(n)。

二、题目6：Dominant Indices

n 个点的树，1 号点是根。定义 d(u, x) 为「以 u 为根的子树里，到 u 距离恰好为 x 的节点个数」。对每个 u，找最小的 x 使 d(u, x) 最大，打印这个 x。1 ≤ n ≤ 10⁶。测试链接：CF1009F、洛谷 CF1009F。

dp[u][i] = d(u, i)，第二维正是到 u 的距离，转移是 dp[u][i] += dp[轻儿子][i − 1]。长儿子的那一份已经躺在自己的格子里了。

答案 ansx[u] 的初值取 ansx[长儿子] + 1：长儿子子树里的最优距离，到 u 这里要整体加一层。合并轻儿子时再逐个距离比较，值更大就更新，值相等取更小的 x。

这里有个细节：最后有一段 if (getdp(u, ansx[u]) == 1) ansx[u] = 0。当最大值就是 1 时，d(u, 0) 也等于 1（u 自己），0 比任何正数都小，直接回到 0。

void dfs1(int u, int fa) {
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa) {
                if (son[u] == 0 || len[son[u]] < len[v]) {
                    son[u] = v;
                }
            }
        }
        len[u] = len[son[u]] + 1;
    }

    void dfs2(int u, int fa) {
        dfn[u] = ++cntd;
        setdp(u, 0, 1);
        ansx[u] = 0;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], u);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa && v != son[u]) {
                dfs2(v, u);
            }
        }
        ansx[u] = ansx[son[u]] + 1;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa && v != son[u]) {
                for (int i = 1; i <= len[v]; i++) {
                    setdp(u, i, getdp(u, i) + getdp(v, i - 1));
                    if (getdp(u, i) > getdp(u, ansx[u]) || (getdp(u, i) == getdp(u, ansx[u]) && i < ansx[u])) {
                        ansx[u] = i;
                    }
                }
            }
        }
        if (getdp(u, ansx[u]) == 1) {
            ansx[u] = 0;
        }
    }

三、题目7：火热旅馆

n 个点的树。三个点构成一个点组 (a, b, c)，打乱顺序算同一个。问树上有多少个点组内部两两距离相等。1 ≤ n ≤ 10⁵，答案在 long 范围内。测试链接：P5904。

两两相等表示存在一个中心 o，三点到 o 的距离都是 d，且三点分属 o 的三个不同分支，两个点在同一分支时，它们的 lca 会掉到 o 下面，两点距离就小于 2d 了。

于是要两张表。f[u][i] 是子树 u 里到 u 距离为 i 的点数，和题6 一样。g[u][i] 记的是「还差一个点」的点对：u 的子树里有多少个点对 (a, b)，满足 lca(a, b) = o、dist(o, a) = dist(o, b) = d，且 d − dist(u, o) = i。

这个 i 的定义看着绕，它的作用是把「点对所在的深度」和「当前参照点」对齐。参照点从 u 挪到它长儿子时，lca 到儿子的距离比到 u 少 1，所以 i 要加 1，索引方向正好和 f 相反。

空间安排就在 dfs2 里：fid[u] 顺序递增，gid[u] 由长儿子反推，叶子处把 gid 锚到 fid[链头] × 2，两张表互不重叠。

void dfs1(int u, int f) {
        fa[u] = f;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                if (son[u] == 0 || len[son[u]] < len[v]) {
                    son[u] = v;
                }
            }
        }
        len[u] = len[son[u]] + 1;
    }

    void dfs2(int u, int top) {
        fid[u] = cntd++;
        if (son[u] == 0) {
            gid[u] = fid[top] * 2;
            return;
        }
        dfs2(son[u], top);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != son[u] && v != fa[u]) {
                dfs2(v, v);
            }
        }
        gid[u] = gid[son[u]] + 1;
    }

合并一个轻儿子 v 时，答案从两个方向产生：v 里的点去补 u 这边已经配好的点对，v 里已经配好的点对由 u 这边的点去补。之后把 v 的贡献并进 u 的两张表。

void dfs3(int u) {
        setf(u, 0, 1);
        if (son[u] == 0) {
            return;
        }
        dfs3(son[u]);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != son[u] && v != fa[u]) {
                dfs3(v);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != son[u] && v != fa[u]) {
                for (int i = 0; i <= len[v]; i++) {
                    if (i < len[u] && i - 1 >= 0) {
                        ans += getg(u, i) * getf(v, i - 1);
                    }
                    if (i > 0 && i + 1 < len[v]) {
                        ans += getf(u, i) * getg(v, i + 1);
                    }
                }
                for (int i = 0; i <= len[v]; i++) {
                    if (i + 1 < len[v]) {
                        setg(u, i, getg(u, i) + getg(v, i + 1));
                    }
                    if (i - 1 >= 0) {
                        setg(u, i, getg(u, i) + getf(u, i) * getf(v, i - 1));
                    }
                }
                for (int i = 0; i <= len[v]; i++) {
                    if (i - 1 >= 0) {
                        setf(u, i, getf(u, i) + getf(v, i - 1));
                    }
                }
            }
        }
        ans += getg(u, 0);
    }

最后一句 ans += getg(u, 0) 是「u 自己当第三个点」的情况：i = 0 表示 d = dist(u, o)，也就是点对的两条臂和 u 到中心的距离相等，u 正好补上第三条臂。

复杂度分析

两个题的时间都是 O(n)，因为每条长链只在链头处被完整扫一遍，所有链长之和是 n。题6 的 n 到 10⁶，O(n) 是必须的。

操作时间说明
dfs1（算 len、选长儿子）O(n)每个点扫一遍邻接表
dfs2（分 fid / gid）O(n)每个点访问一次
题6 合并全部轻儿子O(n)轻儿子 v 只贡献 len[v] 次循环，链长总和为 n
题7 合并全部轻儿子O(n)同上，每个 v 三轮各 len[v] 次
题6 空间O(n)dp 数组只有 n 格
题7 空间O(n)f 开 n 格，g 开 2n 格

对照一下暴力做法：给每个点开满 O(n) 的表，空间 O(n²)，时间也是 O(n²)。长链剖分把「每个点一份表」变成「每条链一份表」，两边同时降到 O(n)。

最后

判断一个树形 dp 能不能上长链剖分，就看三点：第二维是不是跟子树高度同阶、转移是不是只跨一层、合并是不是逐格相加。三条都满足，就可以把表摊进长链。
