分割方法数：拆成组合数

把数组 A 拆成 B、C 两份，A[i] = B[i] + C[i]，B 从左到右不能降、C 从左到右不能升，问有多少种拆法。n 能到 10⁷，枚举不可能。答案藏在一个组合数里：先看约束怎么翻译成差分，再看自由量怎么数。

零、约束翻译成差分

B 非降，等价于差分 d[i] = B[i] − B[i−1] ≥ 0（d[1] = B[1]）。C 非升这条约束也作用在 B 的差分上：

C[i] ≥ C[i+1] ⇔ A[i] − B[i] ≥ A[i+1] − B[i+1] ⇔ B[i+1] − B[i] ≥ A[i+1] − A[i]

A 上升时右边是负数，差分 ≥ 0 自动满足；A 下降时，差分必须垫高 A 的下降量。所以每个位置都有一个「必填的差分下界」，先把这些必填量从预算里扣掉，剩下的自由量再分配。

预算从哪来？B 和 C 都 ≥ 1，所以 B[i] ∈ [1, A[i]−1]，B 的总增长空间是 A[1]−1 再减去所有必填的下降量。扣完剩下的自由量 k，要分给 n 个位置（B[1] 一个、差分 n−1 个），每个 ≥ 0。非负整数解个数就是星星棒：C(k+n−1, n)。

二、题4 分割的方法数（课上版）

实现：k 从 A[1]−1 起步，每遇到一次下降 arr[i−1] > arr[i] 就减去差值；k 归零或为负说明必填量超预算，答案 0。剩下的直接 C(k+n−1, n)。注意 k 可能被减到 0，循环里加 k > 0 的短路。

#include <bits/stdc++.h>
    using namespace std;

    const int MOD = 1000000007;

    // 乘法快速幂
    long long power(long long x, long long p) {
      long long ans = 1;
      while (p > 0) {
        if (p & 1) ans = ans * x % MOD;
        x = x * x % MOD;
        p >>= 1;
      }
      return ans;
    }

    // C(n, k) % MOD
    long long comb(int n, int k) {
      long long fac = 1, inv1 = 1, inv2 = 1;
      for (int i = 1; i <= n; i++) {
        fac = fac * i % MOD;
        if (i == k) inv1 = power(fac, MOD - 2);
        if (i == n - k) inv2 = power(fac, MOD - 2);
      }
      return fac * inv1 % MOD * inv2 % MOD;
    }

    int main() {
      int n;
      cin >> n;
      vector<int> arr(n);
      for (int i = 0; i < n; i++) cin >> arr[i];
      // 课上题意：B[i], C[i] >= 1，单个数 v 的分裂方式有 v-1 种
      int k = arr[0] - 1;
      // 每遇到一次下降，差分必须垫高 arr[i-1]-arr[i]，从总量里扣
      for (int i = 1; i < n && k > 0; i++) {
        if (arr[i - 1] > arr[i]) k -= arr[i - 1] - arr[i];
      }
      if (k <= 0) {
        cout << 0 << "\n";
        return 0;
      }
      // 自由量分给 n 个位置，方案数 = C(k + n - 1, n)
      cout << comb(k + n - 1, n) << "\n";
    }

这道题原本是真实大厂笔试题，用对数器验证：暴力 ways1 逐层枚举 B[i]、C[i] 的所有合法取值，随机小数组对拍 2 万组，与上面的公式完全一致。转化的重点不在组合数本身，在「把两个单调约束叠到 A 的差分上，算出必填量」这一步。

三、LeetCode 版的唯一差别

测试链接上的题意允许 B[i]、C[i] ≥ 0：单个数 v 的分裂方式从课上版的 v−1 种变成 v+1 种（(0,v)、(1,v−1)、…、(v,0)）。反映在代码里，k 的初始值从 arr[0]−1 改成 arr[0]+1，其余一行不变。

#include <bits/stdc++.h>
    using namespace std;

    const int MOD = 1000000007;

    long long power(long long x, long long p) {
      long long ans = 1;
      while (p > 0) {
        if (p & 1) ans = ans * x % MOD;
        x = x * x % MOD;
        p >>= 1;
      }
      return ans;
    }

    long long comb(int n, int k) {
      long long fac = 1, inv1 = 1, inv2 = 1;
      for (int i = 1; i <= n; i++) {
        fac = fac * i % MOD;
        if (i == k) inv1 = power(fac, MOD - 2);
        if (i == n - k) inv2 = power(fac, MOD - 2);
      }
      return fac * inv1 % MOD * inv2 % MOD;
    }

    int main() {
      int n;
      cin >> n;
      vector<int> arr(n);
      for (int i = 0; i < n; i++) cin >> arr[i];
      // 测试链接题意：B[i], C[i] >= 0，单个数 v 的分裂方式有 v+1 种
      // 与课上版唯一的区别就是下面这一行的 +1
      int k = arr[0] + 1;
      for (int i = 1; i < n && k > 0; i++) {
        if (arr[i - 1] > arr[i]) k -= arr[i - 1] - arr[i];
      }
      if (k <= 0) {
        cout << 0 << "\n";
        return 0;
      }
      cout << comb(k + n - 1, n) << "\n";
    }

两版对拍都过：课上版对暴力 ways1（B、C ≥ 1）3000 组全一致，LC 版对暴力 ways0（B、C ≥ 0）也 3000 组全一致。差异就一个字，改的时候别顺手改到别的。

总结

分割方法数的核心转化：C 非升 ⇔ B 的差分必须盖住 A 的下降量，于是「A[1]−1 的预算 − 总下降量 = 自由量 k」，方案数 = C(k+n−1, n)，O(n) 读一遍数组就能算。两种题意的差别只在 k 的 ±1。这类「约束翻译成差分、自由量数组合数」的思路值得记住：凡是要数单调数组对的数量，先看能不能把约束压到差分上。
