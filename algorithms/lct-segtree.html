线段树分治 + LCT

上一节的边一进来就不走了。这一节的边会走：某条道路只在第 l 天到第 r 天存在，或者某条边的权值从某一天起换成了另一个数。按天重新算一遍太慢，于是换一个角度，不是按天维护结构，而是把结构维护成「时间上的一段段」，在里面走一遍 DFS，出来顺手回退。

零、背景

前面五道题里，边的存在与否、权值是多少，从头到尾都是固定的。LCT 只要跟着加边、删边就能维持住最小生成树。

有些题目不是这样：一条边只在某段时间里存在，出了这段时间就没了；或者一条边的权值在第 3 天是 7，第 4 天变成 2。

这类「区间上生效」的东西，LCT 自己没有表达能力。它的结构里只有点、边、父子关系，没有时间。

所以得在外面再套一层，专门管时间。这层是线段树分治。

一、问题

先看一道具体的。n 个点，n-1 条无向道路把所有点连成一棵树，这些道路从头到尾都在。另外有 m 条变化的道路，每条只在第 l 天到第 r 天存在，道路有权值代表费用。

每天从 1 号点出发，游览所有点。同一天里，一条道路第一次经过时收一次费，之后再经过免费。要求游览结束后剩余钱数大于 0，求每天出发时至少要带多少钱，也就是当天的总费用加 1。

n 到 5×10⁴，m 到 10⁵，天数固定为 32766，输出也是 32766 行。

先把「游览所有点要花多少钱」翻译成图论语言。从 1 号出发走遍所有点，走过的道路必须把所有点连起来，所以至少是一棵生成树的规模。反过来，随便取一棵生成树，从 1 号点沿着树走：进每棵子树之前收一次费，出来之后这条边就免费了，所以每条树边恰好被收费一次，总费用正好是这棵生成树的边权和。

于是当天的费用就是当天这张图的最小生成树边权和。题目变成：每天求一次当前图的最小生成树，再加 1。

二、朴素做法

最直接的想法是按天模拟。第 d 天，把固定道路和所有覆盖第 d 天的变化道路收集起来，跑一遍 Kruskal 求最小生成树边权和，输出加 1。

复杂度是 O(D · m log m)。D 是 3×10⁴，m 是 10⁵，乘起来是十亿量级，过不去。

但相邻两天之间变的东西其实很少。第 d 天和第 d+1 天，差别只在于「今天结束的那些边」和「明天开始的那些边」。如果能让这两天的计算共用大部分结果，就有戏了。

问题是，LCT 只支持删除一条具体的边，不支持「回到两天前的那个状态」。我们需要的是批量撤销，不是单点删除。

三、线段树分治

换个角度想：与其按天去维护结构，不如按「时间区间」去维护结构。

把时间轴 1 到 D 建成一棵线段树。一条只在 [l, r] 存在的边，把它挂到线段树上能完整覆盖 [l, r] 的那些节点上。任何一个区间都会被拆成不超过 O(log D) 个节点。

挂好之后，从根开始 DFS 这棵线段树。上面的节点代表的时间段包含下面的，所以走一条从根到叶子的路径时，路径上每个节点挂的边加起来，正好就是「这一天存在的所有边」。

走到叶子，把答案记下来。要走兄弟子树之前，得先把这一路加进来的边全都退回去。

一句话概括这套做法：不求一次算对，而是把「按天算」改成「按时间区间算」，让每条边只被处理 O(log D) 次。

四、撤销怎么撤销

这里不需要「删掉指定的某条边」这种能力，只需要「把刚才做过的事反过来做一遍」。

开一个栈，每次 LCT 的结构被改动，就把这次改动记一条：

int rollbackEdge[MAXN << 1];
    int rollbackType[MAXN << 1];
    int opsize;

记录里带一个类型。类型 1 表示「加了一条边」，撤销时要把这条边 cut 掉；类型 2 表示「换边时被挤掉了一条边」，撤销时要把那条边 link 回来。

void backup(int edge, int type) {
        rollbackEdge[++opsize] = edge;
        rollbackType[opsize] = type;
    }

    void undo() {
        int e = rollbackEdge[opsize];
        int t = rollbackType[opsize--];
        if (t == 1) {
            cut(ex[e], n + e);
            cut(ey[e], n + e);
            mstSum -= ew[e];
        } else {
            link(ex[e], n + e);
            link(ey[e], n + e);
            mstSum += ew[e];
        }
    }

顺序必须是后进先出。上面这段加边逻辑里，换边的时候先记「挤掉了 pre」，再记「加进来了 e」，那么撤销时先碰到的就是 e，正好把它删掉，然后再把 pre 接回去。顺序反了就成了一条不存在的边，LCT 会算错。

还有一点可以放心：splay 的那些旋转不改变任何连通关系，转来转去只是把辅助树的形状换了。撤销的时候完全不用管它们，只要把 link 和 cut 反过来做，森林就回到了进入节点之前的样子。

DFS 的骨架非常统一：

void dfs(int l, int r, int i) {
        int tmp = opsize;
        for (int k = head[i]; k != 0; k = nxt[k]) {
            addEdge(to[k]);
        }
        if (l == r) {
            ans[l] = mstSum;
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        while (opsize > tmp) {
            undo();
        }
    }

进节点前记一下栈的大小 tmp，出节点后一路 undo 到栈里只剩 tmp 条记录。为什么要一路退回去？因为进入这个节点之前，栈里可能已经有祖先节点留下的记录了，那些不属于本次改动，不该动。

五、题目6：变化的道路

回到上面那道题。固定道路的区间是 [1, D]，变化道路的区间是 [l, r]，按前面第三节的办法挂上去就行。

加边的逻辑和题目1 是同一套：先 makeroot、findroot 判断连通性，不连通就接上，连通就 split 出路径，看环上最大边是不是比新边大，大才换。加边顺序是 DFS 决定的，不按权值排，所以这个「比它大才换」的判断不能省。

另外两个小地方：mstSum 的初值设成 1，省得每次输出再加；dfs 走到叶子时直接 ans[l] = mstSum，因为固定道路本身就是一棵树，图随时连通，不存在无解的情况。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    const int MAXD = 32767;
    const int MAXT = 4000001;
    int n, m;

    int ex[MAXN];
    int ey[MAXN];
    int ew[MAXN];
    int cnte;

    int head[MAXD << 2];
    int nxt[MAXT];
    int to[MAXT];
    int cntg;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int maxEdge[MAXN];

    int rollbackEdge[MAXN << 1];
    int rollbackType[MAXN << 1];
    int opsize;

    ll mstSum = 1;
    ll ans[MAXD];

    void rangeAddEdge(int i, int e) {
        nxt[++cntg] = head[i];
        to[cntg] = e;
        head[i] = cntg;
    }

    void add(int jobl, int jobr, int jobe, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            rangeAddEdge(i, jobe);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobe, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobe, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void up(int x) {
        maxEdge[x] = x <= n ? 0 : x - n;
        if (ew[maxEdge[ls[x]]] > ew[maxEdge[x]]) {
            maxEdge[x] = maxEdge[ls[x]];
        }
        if (ew[maxEdge[rs[x]]] > ew[maxEdge[x]]) {
            maxEdge[x] = maxEdge[rs[x]];
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    void backup(int edge, int type) {
        rollbackEdge[++opsize] = edge;
        rollbackType[opsize] = type;
    }

    void addEdge(int e) {
        int x = ex[e];
        int y = ey[e];
        makeroot(x);
        if (findroot(y) != x) {
            link(x, n + e);
            link(y, n + e);
            backup(e, 1);
            mstSum += ew[e];
        } else {
            split(x, y);
            int pre = maxEdge[y];
            if (ew[pre] > ew[e]) {
                cut(ex[pre], n + pre);
                cut(ey[pre], n + pre);
                backup(pre, 2);
                mstSum -= ew[pre];
                link(x, n + e);
                link(y, n + e);
                backup(e, 1);
                mstSum += ew[e];
            }
        }
    }

    void undo() {
        int e = rollbackEdge[opsize];
        int t = rollbackType[opsize--];
        if (t == 1) {
            cut(ex[e], n + e);
            cut(ey[e], n + e);
            mstSum -= ew[e];
        } else {
            link(ex[e], n + e);
            link(ey[e], n + e);
            mstSum += ew[e];
        }
    }

    void dfs(int l, int r, int i) {
        int tmp = opsize;
        for (int k = head[i]; k != 0; k = nxt[k]) {
            addEdge(to[k]);
        }
        if (l == r) {
            ans[l] = mstSum;
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        while (opsize > tmp) {
            undo();
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        int day = MAXD - 1;
        for (int i = 1; i < n; i++) {
            cin >> ex[++cnte];
            cin >> ey[cnte];
            cin >> ew[cnte];
            add(1, day, cnte, 1, day, 1);
        }
        cin >> m;
        for (int i = 1, l, r; i <= m; i++) {
            cin >> ex[++cnte];
            cin >> ey[cnte];
            cin >> ew[cnte];
            cin >> l;
            cin >> r;
            add(l, r, cnte, 1, day, 1);
        }
        dfs(1, day, 1);
        for (int i = 1; i <= day; i++) {
            cout << ans[i] << "\n";
        }
        return 0;
    }

六、题目7：城市建设

n 个点 m 条无向边，边有边权，编号 1 到 m，图保证连通。接下来 q 次修改，每次给出 e w，把第 e 条边的边权改成 w。每次修改之后，输出当前图的最小生成树边权和。

题目里没有「边存在一段时间」这种说法，只有「权值被改」。但这两件事可以缝合到一起。

把一条边的每个权值看成一条独立的边。第 e 条边的初始权值是 w₀，在第 t₁ 次修改后变成 w₁，在第 t₂ 次修改后变成 w₂……那么：

  • 权值 w₀ 对应的那条边，存在于 [1, t₁ − 1]。
  • 权值 w₁ 对应的那条边，存在于 [t₁, t₂ − 1]。
  • 依此类推。

于是每次修改都追加一条「新边」，端点和被改的那条边一样，权值是新的值，区间从这次修改开始。老版本在同一个时刻结束。图里边的条数不超过 m + q，而每条边都有了自己的区间，问题就回到了题目6。

代码里这段区间是倒着扫出来的。先用 endTime[e] 表示「e 这个权值下一次被改掉的时刻」，初值是 q + 1；然后从 q 往前扫，遇到第 i 次修改改的是 e，就把新版本挂在 [i, endTime[e] − 1] 上，再把 endTime[e] 改成 i。倒着扫的原因很直接：先碰到的总是后面那次修改，它给出的正是这个版本的结束时刻。

扫完之后，endTime[e] 停在这条边第一次被改的时刻，如果它大于 1，说明原始权值在 [1, endTime[e] − 1] 这段里有效，也要挂上去。

叶子 i 记的是「第 i 次修改之后」的答案，因为区间起点是 i，第 i 天当然包含在内。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    const int MAXQ = 50001;
    const int MAXT = 4000001;
    int n, m, q;

    int ex[MAXN];
    int ey[MAXN];
    int ew[MAXN];
    int cnte;

    int changeEdge[MAXQ];
    int endTime[MAXN];

    int head[MAXQ << 2];
    int nxt[MAXT];
    int to[MAXT];
    int cntg;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    bool rev[MAXN];
    int sta[MAXN];

    int maxEdge[MAXN];

    int rollbackEdge[MAXN << 1];
    int rollbackType[MAXN << 1];
    int opsize;

    ll mstSum;
    ll ans[MAXQ];

    void rangeAddEdge(int i, int e) {
        nxt[++cntg] = head[i];
        to[cntg] = e;
        head[i] = cntg;
    }

    void add(int jobl, int jobr, int jobe, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            rangeAddEdge(i, jobe);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobe, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobe, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void up(int x) {
        maxEdge[x] = x <= n ? 0 : x - n;
        if (ew[maxEdge[ls[x]]] > ew[maxEdge[x]]) {
            maxEdge[x] = maxEdge[ls[x]];
        }
        if (ew[maxEdge[rs[x]]] > ew[maxEdge[x]]) {
            maxEdge[x] = maxEdge[rs[x]];
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    void backup(int edge, int type) {
        rollbackEdge[++opsize] = edge;
        rollbackType[opsize] = type;
    }

    void addEdge(int e) {
        int x = ex[e];
        int y = ey[e];
        makeroot(x);
        if (findroot(y) != x) {
            link(x, n + e);
            link(y, n + e);
            backup(e, 1);
            mstSum += ew[e];
        } else {
            split(x, y);
            int pre = maxEdge[y];
            if (ew[pre] > ew[e]) {
                cut(ex[pre], n + pre);
                cut(ey[pre], n + pre);
                backup(pre, 2);
                mstSum -= ew[pre];
                link(x, n + e);
                link(y, n + e);
                backup(e, 1);
                mstSum += ew[e];
            }
        }
    }

    void undo() {
        int e = rollbackEdge[opsize];
        int t = rollbackType[opsize--];
        if (t == 1) {
            cut(ex[e], n + e);
            cut(ey[e], n + e);
            mstSum -= ew[e];
        } else {
            link(ex[e], n + e);
            link(ey[e], n + e);
            mstSum += ew[e];
        }
    }

    void dfs(int l, int r, int i) {
        int tmp = opsize;
        for (int k = head[i]; k != 0; k = nxt[k]) {
            addEdge(to[k]);
        }
        if (l == r) {
            ans[l] = mstSum;
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        while (opsize > tmp) {
            undo();
        }
    }

    void prepare() {
        for (int i = 1; i <= m; i++) {
            endTime[i] = q + 1;
        }
        for (int i = q; i >= 1; i--) {
            int e = changeEdge[i];
            add(i, endTime[e] - 1, m + i, 1, q, 1);
            endTime[e] = i;
        }
        for (int i = 1; i <= m; i++) {
            if (endTime[i] > 1) {
                add(1, endTime[i] - 1, i, 1, q, 1);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> q;
        cnte = m;
        for (int i = 1; i <= m; i++) {
            cin >> ex[i] >> ey[i] >> ew[i];
        }
        for (int i = 1, e, w; i <= q; i++) {
            cin >> e >> w;
            changeEdge[i] = e;
            ex[++cnte] = ex[e];
            ey[cnte] = ey[e];
            ew[cnte] = w;
        }
        prepare();
        dfs(1, q, 1);
        for (int i = 1; i <= q; i++) {
            cout << ans[i] << "\n";
        }
        return 0;
    }

七、复杂度分析

设边数是 M（题目7 里 M = m + q），天数是 D，LCT 里的点数是 n + M。

每条边被拆到 O(log D) 个线段树节点上，所以线段树上挂着的边条目总数是 O(M log D)。DFS 会访问到每一个节点，在节点上对每条挂着的边做一次 LCT 加边。

步骤时间复杂度
把一条边挂到线段树上O(log D)
所有边挂完（线段树上的条目总数）O(M log D)
一次 LCT 加边（含可能的换边）O(log(n + M)) 均摊
总时间O(M log D log(n + M))
一次撤销O(log(n + M)) 均摊

题目6 里 M 到 10⁵，D 到 3.3×10⁴，log D 约 15，LCT 那边的 log 约 19，乘起来大概 3×10⁷ 次基本操作，能过。

空间上，线段树每个节点挂一条链表，存的是「这个节点上有哪些边」，总条目 O(M log D)。撤销栈要跟着记下所有改动，每次加边最多产生两条记录，所以栈也是 O(M log D) 条。实现里把这两个数组都开成了 400 万。

八、最后

线段树分治解决的不是某一类具体的图论问题，而是一类很通用的困境：某个东西只在一段时间内有效，而维护它的数据结构不支持删除。

办法就是绕开删除，把「按时间点维护」换成「按时间区间维护」，让结构沿着 DFS 一路只增不减，退回去的时候再用栈把改动原路撤回。

这套骨架和 LCT 之间几乎不耦合：只要那个数据结构支持撤销，换成并查集、换成别的都行。题目7 的坑也在这里，同一道题用 LCT 和用并查集，代码结构几乎一样，区别只在换边的时候 LCT 能比较环上的边，并查集做不到。
