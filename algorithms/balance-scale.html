天平：把关系收紧成区间

每个砝码只有 1、2、3 克三种可能，两两比较给出关系矩阵。这道题不建图跑最短路，而是记录每两个砝码「差值」的最大、最小可能值，再用 Floyd 把区间收紧，最后统计三种答案一定成立的对数。

零、差值的上下界

记 dmin[i][j]、dmax[i][j] 为 xi − xj 在所有满足矩阵的重量赋值下的最小、最大可能值。初始化直接读矩阵：

s[i][j] 是 '=' → 差恒 0；'+'（i 比 j 重）→ 差 ∈ [1,2]（重量只有 1..3，重的那个至少多 1 克、至多多 2 克）；'-' → [−2,−1]；'?' → 未知，先放开成 [−2,2]；自己对自己差 0。

一、Floyd 收紧

区间可以组合：xi − xj = (xi − xk) + (xk − xj)，所以 xi − xj 的下界至少是「xi − xk 下界 + xk − xj 下界」的和。于是：

dmin[i][j] = max(dmin[i][j], dmin[i][k] + dmin[k][j])，dmax[i][j] = min(dmax[i][j], dmax[i][k] + dmax[k][j])。

这跟最短路 Floyd 是同一个三重循环，只是 dmin 取「更大的下界」（路径给的下界更紧）、dmax 取「更小的上界」。桥 k 放最外层，道理一样：先把每个 k 能收紧的都收掉，下一轮在这个基础上继续。

#include <bits/stdc++.h>
    using namespace std;
    typedef long long ll;
    const int MAXN = 55;
    int dmin[MAXN][MAXN], dmax[MAXN][MAXN];
    char s[MAXN][MAXN];
    int n, a, b;
    int ans1, ans2, ans3;

    void compute() {
      for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
          if (s[i][j] == '=') {
            dmin[i][j] = 0; dmax[i][j] = 0;
          } else if (s[i][j] == '+') {
            dmin[i][j] = 1; dmax[i][j] = 2;
          } else if (s[i][j] == '-') {
            dmin[i][j] = -2; dmax[i][j] = -1;
          } else {
            dmin[i][j] = -2; dmax[i][j] = 2;
          }
        }
      }
      for (int i = 1; i <= n; i++) {
        dmin[i][i] = 0; dmax[i][i] = 0;
      }
      for (int bridge = 1; bridge <= n; bridge++) {
        for (int i = 1; i <= n; i++) {
          for (int j = 1; j <= n; j++) {
            dmin[i][j] = max(dmin[i][j], dmin[i][bridge] + dmin[bridge][j]);
            dmax[i][j] = min(dmax[i][j], dmax[i][bridge] + dmax[bridge][j]);
          }
        }
      }
      ans1 = ans2 = ans3 = 0;
      for (int i = 1; i <= n; i++) {
        for (int j = 1; j < i; j++) {
          if (i != a && i != b && j != a && j != b) {
            if (dmin[a][i] > dmax[j][b] || dmin[a][j] > dmax[i][b]) ans1++;
            if (dmax[a][i] < dmin[j][b] || dmax[a][j] < dmin[i][b]) ans3++;
            if (dmin[a][i] == dmax[a][i] && dmin[j][b] == dmax[j][b] && dmin[a][i] == dmin[j][b]) ans2++;
            else if (dmin[b][i] == dmax[b][i] && dmin[j][a] == dmax[j][a] && dmin[b][i] == dmin[j][a]) ans2++;
          }
        }
      }
    }

    int main() {
      scanf("%d%d%d", &n, &a, &b);
      for (int i = 1; i <= n; i++) {
        scanf("%s", s[i] + 1);
      }
      compute();
      printf("%d %d %d\n", ans1, ans2, ans3);
      return 0;
    }

二、统计三种答案

题目把 a、b 放左边，另选两个砝码放右边。左边重是 xa + xb > xi + xj 恒成立。这个条件可以转写成两组独立的差分比较：

xa + xb > xi + xj 等价于 xa − xi > xj − xb。左边的最小可能值用 dmin[a][i]，右边 xj − xb 的最大可能值用 dmax[j][b]：dmin[a][i] > dmax[j][b] 成立，就说明任何赋值下左边都重。

另一组转写 xa − xj > xi − xb，对应 dmin[a][j] > dmax[i][b]。两条判据都是同一个不等式的不同写法，任一条成立即左重。

右重对称：dmax[a][i] < dmin[j][b] 或 dmax[a][j] < dmin[i][b]。

等重的要求更严格：两边的差都必须唯一确定，而且确定值相等：dmin[a][i]==dmax[a][i] 且 dmin[j][b]==dmax[j][b] 且 dmin[a][i]==dmin[j][b]；另一组对称写法查 dmin[b][i]==dmax[b][i] && dmin[j][a]==dmax[j][a] && dmin[b][i]==dmin[j][a]。

xa + xb 与 xi + xj 的差可以写成 (xa − xi) − (xj − xb)：两侧都唯一确定且相等，差就恒 0。b 侧写法只是把组合换了个方向。

对拍时先按「a、i 一边，b、j 一边」理解题意，3000 组全 MISMATCH。题目是 a、b 都在左边、另选两个放右边，比较的是 xa + xb 对 xi + xj。改对口径后全过。

演示 · Floyd 收紧：每个桥 k 一轮，区间怎么越收越紧

总结

差值区间初始化：'=' 是 [0,0]、'+' 是 [1,2]、'-' 是 [−2,−1]、'?' 先放开成 [−2,2]，自己对自己差 0。

Floyd 三重循环收紧：dmin 取路径下界和的 max、dmax 取 min，桥放最外层；一轮把能收紧的都收掉，下一轮在收紧结果上继续。

左重判 dmin[a][i] > dmax[j][b] 或 dmin[a][j] > dmax[i][b]；右重对称；等重要两侧差值都唯一确定且相等。

题面是 a、b 都放左边、另选两个放右边，比较的是 xa + xb 与 xi + xj，别按「a+i 对 b+j」想。
