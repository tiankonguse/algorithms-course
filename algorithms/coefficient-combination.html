组合数与计算系数

n 到 2000 打表还能忍，n 到 10⁵ 还按 O(n²) 建表就爆了。换一条路：阶乘余数表 + 阶乘逆元表，O(n) 建表、O(1) 查询，还能按模算。计算系数用这套表，组合数问题的查询也靠它铺底。

零、阶乘余数表与阶乘逆元表

要算 C(n,k) % MOD，先把两个表建出来：

  • fac[i] = i! % MOD，正序递推：fac[i] = i·fac[i−1] % MOD。注意 0! = 1，fac[0] 要初始化为 1，漏了 k=0 这类查询直接错。
  • inv[i] = (i!)⁻¹ % MOD，逆序递推：inv[MAX] = (fac[MAX])^(MOD−2)（费马小定理），然后 inv[i] = (i+1)·inv[i+1] % MOD。这个递推的推导：1/(i!) = (i+1)·1/((i+1)!)。

然后 C(n,k) = fac[n]·inv[k]·inv[n−k] % MOD，一次乘法查询。前提是 MOD 是素数（费马小定理才成立），这里两个题的模数 10007 和 10⁹+7 都是。

一、题2 计算系数（P1313）

求 (ax+by)^k 展开后 xⁿ·yᵐ 这一项的系数，n+m=k，答案对 10007 取模。二项式定理直接给：这一项是 C(k,n)·(ax)ⁿ·(by)ᵐ，系数 = C(k,n)·aⁿ·bᵐ。aⁿ、bᵐ 用乘法快速幂（k ≤ 1000，指数很小，但写法照旧），组合数查上面两张表。

#include <bits/stdc++.h>
    using namespace std;

    const int MOD = 10007;
    const int MAXK = 1001;

    long long fac[MAXK + 1];  // fac[i] = i! % MOD
    long long inv[MAXK + 1];  // inv[i] = (i!)^{-1} % MOD

    // 乘法快速幂：x^p % MOD
    long long power(long long x, int p) {
      long long ans = 1;
      while (p > 0) {
        if (p & 1) ans = ans * x % MOD;
        x = x * x % MOD;
        p >>= 1;
      }
      return ans;
    }

    void build() {
      // 0! = 1
      fac[0] = 1;
      fac[1] = 1;
      for (int i = 2; i <= MAXK; i++) {
        fac[i] = (long long)i * fac[i - 1] % MOD;
      }
      // 逆元逆序递推：inv[i] = (i+1) * inv[i+1]
      inv[MAXK] = power(fac[MAXK], MOD - 2);
      for (int i = MAXK - 1; i >= 0; i--) {
        inv[i] = (long long)(i + 1) * inv[i + 1] % MOD;
      }
    }

    long long c(int n, int k) {
      return fac[n] * inv[k] % MOD * inv[n - k] % MOD;
    }

    // (ax + by)^k 展开后 x^n * y^m 这一项的系数
    int main() {
      build();
      int a, b, k, n, m;
      cin >> a >> b >> k >> n >> m;
      // 系数 = C(k, n) * a^n * b^m
      cout << power(a, n) * power(b, m) % MOD * c(k, k - n) % MOD << "\n";
    }

fac 表建到 MAXK=1001，因为 k ≤ 1000、n+m=k，C 的参数不会超出。这个题把「幂 + 组合数」拼在一起，两样都是 O(log k) 和 O(1)。

二、题3 组合数问题（P2822）

数合法对：0 ≤ i ≤ n、0 ≤ j ≤ min(i,m) 里，C(i,j) 是 k 的整数倍的有多少。t ≤ 10⁴ 组查询、k 全程固定，n、m ≤ 2000。每组查询现算 O(n·m) 会超时，预处理走两步：

第一步，模 k 建 C 表：加法与取模可交换，c[i][j] = (c[i−1][j] + c[i−1][j−1]) % k，表里的 0 就是合法对。第二步，二维前缀和：sum[i][j] = 合法格数在矩形 [0..i]×[0..j] 的和，查一次 O(1)。

演示 · 二维前缀和：合法格（C(i,j) 是 k 的倍数）逐格累计

#include <bits/stdc++.h>
    using namespace std;

    const int MAXV = 2000;
    const int MAXN = 2002;

    int c[MAXN][MAXN];   // c[i][j] = C(i,j) % k
    int f[MAXN][MAXN];   // f[i][j] = 1 当且仅当 C(i,j) 是 k 的整数倍
    int sum[MAXN][MAXN]; // 二维前缀和

    int main() {
      int t, k;
      cin >> t >> k;
      // 模 k 建组合数表：加法与取模可交换
      for (int i = 0; i <= MAXV; i++) {
        c[i][0] = 1;
        for (int j = 1; j <= i; j++) {
          c[i][j] = (c[i - 1][j] + c[i - 1][j - 1]) % k;
        }
      }
      for (int i = 1; i <= MAXV; i++) {
        for (int j = 1; j <= i; j++) {
          f[i][j] = c[i][j] % k == 0 ? 1 : 0;
        }
      }
      // 二维前缀和：矩形 (i,j) 内合法格数
      for (int i = 2; i <= MAXV; i++) {
        for (int j = 1; j <= i; j++) {
          sum[i][j] = sum[i][j - 1] + sum[i - 1][j] - sum[i - 1][j - 1] + f[i][j];
        }
        sum[i][i + 1] = sum[i][i]; // m 可能比 n 大，查到这行末尾
      }
      while (t--) {
        int n, m;
        cin >> n >> m;
        // 0 <= i <= n, 0 <= j <= min(i, m)
        cout << (m > n ? sum[n][n] : sum[n][m]) << "\n";
      }
    }

查询时注意 m 可能比 n 大：j 的上界是 min(i,m)，m ≥ n 时整张 n×n 三角都算，输出 sum[n][n]。代码里 sum[i][i+1] = sum[i][i] 就是为了让查询下标 m=n+1 这类情况不越界。

总结

组合数两条路：小规模打表（上一页的杨辉三角，O(n²) 建 O(1) 查），大规模用阶乘余数表 + 阶乘逆元表（O(n) 建 O(1) 查，要求模是素数）。计算系数题 = 快速幂 × 组合数；组合数问题题 = 模 k 建表 + 二维前缀和把 O(n·m) 查询压到 O(1)。两张表这套模板后面还会反复用：凡是出现「C(n,k) % MOD 大量查询」的题，先想它。
