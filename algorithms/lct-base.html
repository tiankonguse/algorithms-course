LCT 原理与模版

Link-Cut Tree 要在一条随时加边删边的森林上做路径查询。它的骨架只有六个操作，代码不到一百行。难点全在理解「实链怎么组织成一棵 splay」以及「一个点的父亲为什么可能不认它」。这一节先把原理讲透，再用模版把三道最直接的题走一遍。

零、背景

有一片森林，边上会发生两件事：中间加一条边，或者删一条边。整个过程图始终是森林，不能出环。要做的事有四种：判断两点是否连通、查一条路径上的信息、求动态 LCA、维护动态生成树。

这类问题叫动态树问题。它和普通树形问题的区别在于结构会变，一次 link 或 cut 之后，原来的父子关系可能整条链都换了。用重链剖分或倍增预处理过的东西，一旦树变了就全部作废。

LCT 是解决动态树最经典的结构，由 Sleator 和 Tarjan 提出。它把树上的边分成实边和虚边，实边连成链，每条链挂在一棵 splay 上。所有操作都靠调整这两类边来完成。

它是在线的：link、cut、查询交错的顺序也能直接处理。别的手段里，线段树分治是离线的，Euler Tour Tree、Top Tree、全局平衡二叉树也能处理一部分动态树问题，只是普及度不如 LCT。

一、实链剖分

先给边分两类。

一个点如果有儿子，可以指定其中一个儿子和它之间的边为实边，其余和它相连的边都是虚边。一个点最多认一个实边儿子，所以实边连起来是一段一段的路径，叫实链。

每条实链上挂一棵 splay。这棵 splay 的中序遍历，恰好是实链上的点按「在原树里从浅到深」的顺序排出来的结果。

也就是说，一棵辅助 splay 的中序序列，就是原树上一段从上到下的路径。想把一段路径拎出来，只要让它变成一条实链。

二、认父不认子

辅助 splay 的根还留着一个 fa 指针，指向实链顶点的父亲，也就是虚边另一头的那个点。这个指针必须留着，否则 access 往上爬会断线。

麻烦在于这个 fa 是单向的：它指向的那个父亲，并不把 splay 的根当成自己的儿子。所以 ls[fa[x]] 和 rs[fa[x]] 里都找不到 x。

判断一个点是不是它所在 splay 的根，就看它的父亲认不认它当儿子：

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

父亲两个儿子都不是它，说明它上面那条边是虚边，它就是所在 splay 的根。后面所有「往上走」的判断都建立在这一句上：splay 停在根，access 从根跳虚边去上一层。

三、六个操作

模版只有六个动作。前四个负责把路径拎出来，后两个负责改结构。

access(x) 把从整棵树根到 x 的路径变成一条实链，路上原来的实边全部断开成虚边。它是所有操作的地基。

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        rs[x] = y;
        up(x);
    }
}

从 x 出发，一层层往上爬。每次把当前点 splay 到它辅助树的根，再把它的右儿子换成上一轮处理的那个点。y 从 0 起步，所以第一轮会把 x 原来的实儿子断掉；之后每接一次，就有一小段路径从虚变实。

下面这个演示把 access(6) 的过程逐步展开。虚线是虚边，蓝色实线是实边。

access(6)：把根到 6 的路径接成一条实链

点「下一步」看每一轮 splay 之后哪条边从虚变实。橙色点是当前正在处理的点。

实边（同一条实链） 当前处理的点 虚边

makeroot(x) 把 x 变成整棵原树的根。

void makeroot(int x) {
    access(x);
    splay(x);
    reverse(x);
}

access(x) 之后，根到 x 已经在一条实链上，x 是这条链最深的点。这时把整条链翻转，x 就成了最浅的点，也就是新的树根。

翻转靠一个 rev 懒标记：对一个点打上标记，等价于交换它的左右儿子并递归下去。因为 splay 的中序遍历就是链的深度序，交换左右儿子正好把顺序倒过来。

findroot(x) 找到 x 所在的整棵原树的根。

int findroot(int x) {
    access(x);
    splay(x);
    while (ls[x] != 0) {
        x = ls[x];
    }
    splay(x);
    return x;
}

access(x) 之后，根到 x 都在同一棵 splay 里，根就是中序最靠前的点。一路往左儿子走到底，就是整棵树的根。代码里还夹了几次 down 下传翻转标记，否则左右儿子可能是反的。

两点是否连通，就是 findroot(x) == findroot(y)。

split(x, y) 把 x 到 y 的路径拎出来，整条路径落在一棵 splay 里，根是 y。

void split(int x, int y) {
    makeroot(x);
    access(y);
    splay(y);
}

先把 x 换成根，此时 x 到 y 就是从根往下的一条路径，access(y) 把它接成实链，最后 splay(y) 把 y 顶到这棵 splay 的根上。于是答案直接挂在 y 这个点的汇总值上。

剩下两个改结构的动作很薄。

void link(int x, int y) {
    makeroot(x);
    if (findroot(y) != x) {
        fa[x] = y;
    }
}

void cut(int x, int y) {
    makeroot(x);
    if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
        fa[y] = rs[x] = 0;
        up(x);
    }
}

link 先让 x 成为根，只要 y 不和它连通，把 x 的 fa 指向 y 就接上了。这是一条虚边，x 是它自己那棵 splay 的根，正好符合「认父不认子」。

cut 判断得细一点：先 makeroot(x)，如果 y 的根确实是 x，说明它们连通；再要求 fa[y] == x、ls[y] == 0、rs[x] == y，这三条说明 x 和 y 之间正好是一条直接边，中间没夹别的点。都满足才断开。

四、完整模版

把上面六个动作拼起来，再加上 rotate、splay 和汇总函数 up，就是一份能直接用的 LCT。这道题维护路径异或和，所以 up 里做的是异或。

有一点和普通 splay 不同：splay 在转之前要先把 x 到根的翻转标记从上到下推一遍，否则左右儿子的交换会错位。模版里用一个栈 sta 把路径上的点压起来，再倒着 down。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;
    int arr[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];

    bool rev[MAXN];
    int sta[MAXN];

    int xorsum[MAXN];

    void up(int x) {
        xorsum[x] = xorsum[ls[x]] ^ xorsum[rs[x]] ^ arr[x];
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
            xorsum[i] = arr[i];
        }
        for (int i = 1, op, x, y; i <= m; i++) {
            cin >> op >> x >> y;
            if (op == 0) {
                split(x, y);
                cout << xorsum[y] << "\n";
            } else if (op == 1) {
                link(x, y);
            } else if (op == 2) {
                cut(x, y);
            } else {
                splay(x);
                arr[x] = y;
                up(x);
            }
        }
        return 0;
    }

五、题目1：模版题

n 个点，每个点有点权。m 条操作：0 x y 查 x 到 y 路径上点权的异或和（保证连通），1 x y 加一条直接边（已连通就忽略），2 x y 删一条直接边（不存在就忽略），3 x y 把 x 的点权改成 y。

n 到 10⁵，m 到 3×10⁵。

这是上面那段代码本身，只是把 up 里的汇总换成异或。查询走 split(x, y) 后读 xorsum[y]；改点权时先把 x splay 到根，改完 up 一次就够，splay 之后它没有祖先，往上的汇总只需要翻它自己。

六、题目2：动态树 LCA

n 个点，初始时每个点各自是一棵单点有根树。m 条操作：link x y 让 x 成为 y 的儿子（保证 x 是所在树的根，且和 y 不连通），cut x 删掉 x 和它父亲的直接边（保证 x 不是根），lca x y 查 x 和 y 的最低公共祖先（保证同树）。

n、m 到 10⁵。

因为已经规定了谁是儿子，link 不需要 makeroot，把 x 的 fa 直接指向 y 就行；cut 更省，access(x) 之后 x 和父亲的边一定在 x 的左链上，断开即可。

关键在 lca。有一个很轻的写法：先 access(x)，再 access(y)。第二次 access 一路往上爬，最后停留的那个点，就是 x 和 y 的 LCA。

道理不难看。第一次 access(x) 之后，根到 x 成了实链。第二次 access(y) 往上爬时，会一直在实链上走到根到 y 的分岔口为止，那个分岔点正是两点的最低公共祖先。代码里让 access 返回它最后 splay 的那个点，正好就是答案。

注意 x 等于 y 时要单独返回，否则两次 access 会互相干扰。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
    }

    void splay(int x) {
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    int access(int x) {
        int ans = 0;
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            ans = x;
        }
        return ans;
    }

    void makeson(int x, int y) {
        access(x);
        splay(x);
        fa[x] = y;
    }

    void cutfa(int x) {
        access(x);
        splay(x);
        fa[ls[x]] = 0;
        ls[x] = 0;
    }

    int lca(int x, int y) {
        if (x == y) {
            return x;
        }
        access(x);
        return access(y);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, x, y; i <= m; i++) {
            string op;
            cin >> op;
            if (op == "link") {
                cin >> x >> y;
                makeson(x, y);
            } else if (op == "cut") {
                cin >> x;
                cutfa(x);
            } else {
                cin >> x >> y;
                cout << lca(x, y) << "\n";
            }
        }
        return 0;
    }

七、题目3：洞穴勘测

n 个点，初始没有边，任意时刻图都是森林。m 条操作：Connect x y 加一条直接边（保证原来不存在），Destroy x y 删一条直接边（保证原来存在），Query x y 查两点是否连通，打印 Yes 或 No。

n 到 10⁴，m 到 2×10⁵。

这题只用得上模版里的两个动作：Connect 就是 link，Destroy 就是 cut，Query 就是比两次 findroot。连 up 都不用写，因为没有任何信息需要往上汇总。

它也算是模版里 cut 那串判断的样板：直接边不存在时不能乱切，所以 cut 里那四条检查一条都不能省。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    int n, m;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int sta[MAXN];
    bool rev[MAXN];

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, x, y; i <= m; i++) {
            string op;
            cin >> op >> x >> y;
            if (op == "Connect") {
                link(x, y);
            } else if (op == "Destroy") {
                cut(x, y);
            } else {
                if (findroot(x) == findroot(y)) {
                    cout << "Yes" << "\n";
                } else {
                    cout << "No" << "\n";
                }
            }
        }
        return 0;
    }

八、复杂度分析

splay 的均摊分析在 Splay 树那一讲，LCT 沿用它。每个操作单次均摊 O(log n)，常数比普通线段树大不少。

为什么常数大还能保证总代价：每次操作都先 access 把实链串好，某一次 access 可能走很远、代价很高，但它顺手把这些点调整成了便于以后访问的 splay 形态；老实链因为新实链断开时，各段仍然是 splay 的组织，性能优势留着。付出和补偿一抵消，均摊就是对数。

操作时间复杂度
up（汇总一个点）O(1)
rotate / splayO(log n) 均摊
access / makeroot / findroot / split / link / cutO(log n) 均摊
题目1 / 题目2 / 题目3：单次操作O(log n) 均摊
题目1 / 题目2 / 题目3：总时间O(m log n)

空间上，LCT 只需要几个大小 n 的数组：fa、ls、rs、rev，再加一个 sta 辅助栈和题目各自要汇总的数组，整体 O(n)。

九、最后

原理部分到这里就够用了。模版里真正需要记住的只有一句：辅助 splay 的中序是路径，access 是唯一把虚边改成实边的动作。

六个操作可以拆成两半记：access、makeroot、findroot、split 负责把路径拎出来，link、cut 负责改结构。最难理解的是「认父不认子」：辅助 splay 的根保留 fa 指针指回实链顶点的父亲，access 往上爬就靠它。三道理题的差别只在 up 汇总什么，骨架一字不改。
