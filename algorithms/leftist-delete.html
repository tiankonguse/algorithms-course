左偏树删除任意编号节点：断罪者与可并堆

删除堆顶只要把左右子树合并，但 P4971 断罪者要删的是任意编号的错事，它不一定是堆顶，可能埋在树中间。删一个中间节点，树上父节点的连接要接上，dist 链要从下往上重算。

零、背景

左偏树删堆顶的三步操作，前提是「要删的节点恰好是根」。断罪者里的操作是「第 a 件错事的罪恶值变成 0」，a 是任意编号，它在树里的位置可能是叶子、可能是中间节点、也可能是堆顶。

课程为此引入一套新信息：up 数组记树上真实的父节点，它和并查集的 father 是两回事。father 是找堆顶的捷径，up 是树结构本身。删除任意节点时两套信息都要维护正确。

一、删除任意节点的五步

假设要删节点 i，整棵树的头是 h（find(i) 的结果）：

1）建立 up 数组：树上真实父节点信息，up ≠ 并查集的路径信息 father。

2）节点 i 的左右树合并，形成的树记作 s。

3）假设 i 的树上父节点是 f，去掉 i 之后，节点 f 和树 s 直接连在一起。

4）从 s 节点往上，更新节点的 dist 值；如果发现左儿子 dist 小于右儿子 dist，就交换左右树。这是核心：保证左偏树的性质，修改节点总数是 O(log n)。

5）保证每个节点的 up、left、right、dist、father 信息更新正确。

第 4 步的循环写成 for (int d = dist[s]; dist[f] > d + 1; f = up[f], d++)：f 从 s 的父节点开始，只要 f 的 dist 比「s 子树的新 dist 加 1」还大，就把它压到 d + 1，必要时交换 f 的左右儿子，然后顺着 up 向上。因为左偏树右链短，这一趟最多走 O(log n) 个节点。

注意一个边界：如果 i 恰好是堆顶（h == i），就不存在 f，第 3、4 步跳过，行为退化成「删除堆顶」。所以删任意节点的代码天然兼容删堆顶。

二、P4971 断罪者

一个人有 n 件错事（每件一个罪恶值），m 次领悟。领悟 2 a：第 a 件错事的罪恶值变成 0；领悟 3 a b：a 所在集合中最大罪恶值的错事减 b，减成负数就当 0，并列取编号较小的；领悟 4 a b：两个集合合并。一个集合的罪恶值只取最大那件，一个人的罪恶值等于所有集合罪恶值累加。

课程实现是大根堆：merge 比较条件反过来，值大的当头（并列编号小）。「罪恶值变 0」和「最大罪恶值减 b」都走同一个 reduce：把目标节点从堆里 remove 出来，改值，再 merge 回去。删除任意编号节点的能力在这里是刚需。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 2000001;
    int t, w, n, m;
    long long k;
    long long num[MAXN];
    int up[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int dist[MAXN];
    int fa[MAXN];

    void prepare() {
        dist[0] = -1;
        for (int i = 1; i <= n; i++) {
            up[i] = ls[i] = rs[i] = dist[i] = 0;
            fa[i] = i;
        }
    }

    int find(int i) {
        return fa[i] == i ? i : (fa[i] = find(fa[i]));
    }

    int merge(int i, int j) {
        if (i == 0 || j == 0) {
            return i + j;
        }
        if (num[i] < num[j] || (num[i] == num[j] && i > j)) {
            swap(i, j);
        }
        rs[i] = merge(rs[i], j);
        up[rs[i]] = i;
        if (dist[ls[i]] < dist[rs[i]]) {
            swap(ls[i], rs[i]);
        }
        dist[i] = dist[rs[i]] + 1;
        fa[ls[i]] = fa[rs[i]] = i;
        return i;
    }

    int remove(int i) {
        int h = find(i);
        fa[ls[i]] = ls[i];
        fa[rs[i]] = rs[i];
        int s = merge(ls[i], rs[i]);
        int f = up[i];
        fa[i] = s;
        up[s] = f;
        if (h != i) {
            fa[s] = h;
            if (ls[f] == i) {
                ls[f] = s;
            } else {
                rs[f] = s;
            }
            for (int d = dist[s]; dist[f] > d + 1; f = up[f], d++) {
                dist[f] = d + 1;
                if (dist[ls[f]] < dist[rs[f]]) {
                    swap(ls[f], rs[f]);
                }
            }
        }
        up[i] = ls[i] = rs[i] = dist[i] = 0;
        return fa[s];
    }

    void reduce(int i, long long v) {
        int h = remove(i);
        num[i] = max(num[i] - v, 0LL);
        fa[h] = fa[i] = merge(h, i);
    }

    long long compute() {
        long long ans = 0;
        long long mx = 0;
        for (int i = 1; i <= n; i++) {
            if (fa[i] == i) {
                ans += num[i];
                if (num[i] > mx) mx = num[i];
            }
        }
        if (w == 2) {
            ans -= mx;
        } else if (w == 3) {
            ans += mx;
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(NULL);
        cin >> t >> w >> k;
        for(int i = 1; i <= t; i++) {
            cin >> n >> m;
            prepare();
            for (int j = 1; j <= n; j++) {
                cin >> num[j];
            }
            for (int j = 1, op, a, b; j <= m; j++) {
                cin >> op >> a;
                if (op == 2) {
                    reduce(a, num[a]);
                } else if (op == 3) {
                    cin >> b;
                    reduce(find(a), b);
                } else {
                    cin >> b;
                    int l = find(a);
                    int r = find(b);
                    if (l != r) {
                        merge(l, r);
                    }
                }
            }
            long long ans = compute();
            if (ans == 0) {
                cout << "Gensokyo " << ans << endl;
            } else if (ans > k) {
                cout << "Hell " << ans << endl;
            } else {
                cout << "Heaven " << ans << endl;
            }
        }
        return 0;
    }

compute 里数 fa[i] == i 的节点，也就是每个集合的堆顶，把堆顶罪恶值累加，顺便记下全局最大。最后按死亡方式 w 调整：w 等于 2 减去最大集合罪恶值，w 等于 3 加上最大集合罪恶值。

三、P11266 可并堆2

FollowUp 题把「一个堆」扩展成「很多堆」：root[x] 表示第 x 个集合的堆顶。操作 0 x y：集合 x 中删除元素 y；操作 1 x：查询集合 x 的最小值；操作 2 x y：集合 y 合并到集合 x（之后不再以 y 做集合编号）；操作 3 x y z：集合 x 中元素 y 的权值改为 z，只可能变小。

这套操作的难点在 op0 和 op3：删除的 y 是任意编号，改值的 z 只变小。小根堆里改小一个值，最坏情况下它可能一路升级成堆顶，但课程代码直接 remove(y) 再 merge 回去，一次完成，不需要像二叉堆那样向上冒泡。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1000001;
    int n, m;

    int num[MAXN];
    int up[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int dist[MAXN];
    int father[MAXN];

    int root[MAXN];

    void prepare() {
        dist[0] = -1;
        for (int i = 1; i <= n; i++) {
            up[i] = ls[i] = rs[i] = dist[i] = 0;
            father[i] = i;
            root[i] = i;
        }
    }

    int find(int i) {
        father[i] = father[i] == i ? i : find(father[i]);
        return father[i];
    }

    int merge(int i, int j) {
        if (i == 0 || j == 0) {
            return i + j;
        }
        if (num[i] > num[j] || (num[i] == num[j] && i > j)) {
            swap(i, j);
        }
        rs[i] = merge(rs[i], j);
        up[rs[i]] = i;
        if (dist[ls[i]] < dist[rs[i]]) {
            swap(ls[i], rs[i]);
        }
        dist[i] = dist[rs[i]] + 1;
        father[ls[i]] = father[rs[i]] = i;
        return i;
    }

    int remove(int i) {
        int h = find(i);
        father[ls[i]] = ls[i];
        father[rs[i]] = rs[i];
        int s = merge(ls[i], rs[i]);
        int f = up[i];
        father[i] = s;
        up[s] = f;
        if (h != i) {
            father[s] = h;
            if (ls[f] == i) {
                ls[f] = s;
            } else {
                rs[f] = s;
            }
            for (int d = dist[s]; dist[f] > d + 1; f = up[f], d++) {
                dist[f] = d + 1;
                if (dist[ls[f]] < dist[rs[f]]) {
                    swap(ls[f], rs[f]);
                }
            }
        }
        up[i] = ls[i] = rs[i] = dist[i] = 0;
        return father[s];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        prepare();
        for (int i = 1; i <= n; i++) {
            cin >> num[i];
        }
        for (int i = 1, op, x, y, z; i <= m; i++) {
            cin >> op;
            if (op == 0) {
                cin >> x >> y;
                root[x] = remove(y);
                if (root[x] != 0) {
                    father[root[x]] = root[x];
                    up[root[x]] = 0;
                }
            } else if (op == 1) {
                cin >> x;
                cout << num[root[x]] << "\n";
            } else if (op == 2) {
                cin >> x >> y;
                root[x] = merge(root[x], root[y]);
                if (root[x] != 0) {
                    father[root[x]] = root[x];
                    up[root[x]] = 0;
                }
            } else {
                cin >> x >> y >> z;
                int h = remove(y);
                num[y] = z;
                father[y] = y;
                root[x] = merge(h, y);
                if (root[x] != 0) {
                    father[root[x]] = root[x];
                    up[root[x]] = 0;
                }
            }
        }
        return 0;
    }

op3 里 num[y] = z 只可能变小，所以改完 merge 回去的 y 在堆里优先级只会更高，不会更低。如果允许变大，还得另想办法把 y 向下调。题目刻意规避了这个分支。

四、删除任意节点演示

删除埋在树中间的节点

初始左偏树：根 5，左子树 3(1,4)，右子树 8(7)。点「下一步」删除节点 8。

蓝 = 根，橙 = 左子树，绿 = 右子树，红 = 被删节点，紫 = 合并后的 s

演示选的是删右子树的根 8：8 的左右子树（左 7）合并成 s = 7，5 的右儿子从 8 换成 7，5 的 dist 从 1 变 0（右儿子没了）。如果删的是更深的节点，dist 重算的链会更长，逻辑一模一样。

总结

删除任意编号节点需要第二套父指针 up 来记录真实树结构，并查集 father 只负责找头。五步里最关键的是第 4 步：从 s 向上按「左儿子 dist ≥ 右儿子 dist」逐层重算并交换，修改节点总数 O(log n)。断罪者靠它实现任意错事的清零与减半，可并堆2靠它实现任意元素的删除与改值。这套「提出 → 改值 → 放回」的套路，下节课的可持久化左偏树还要继续用。
