线段树分治：原理与模版

删边不好做，就把每条边「哪些时刻存在」拍成若干区间，挂到一棵以时间为下标的线段树上，再带着可撤销并查集把整棵树走一遍。进区间做什么，出区间就撤销什么，叶子上回答查询。

零、背景

并查集擅长加边，不擅长删边。删掉一条边再查连通性，普通的并查集立刻失效，能扛住删边的结构（LCT、线段树合并）都偏重。

但很多题并不强制在线。操作序列事先全部给定，每条边什么时候出现、什么时候消失都能提前算出来。这时可以换一个问法：不问「删掉这条边会怎样」，而问「在每个时间点上，图长什么样」。

把时间当成下标建一棵线段树，每条边只在自己的时间段里生效。线段树把任意区间拆成 log 段，每段挂一个任务；然后遍历整棵树，进区间执行任务，出区间撤销。这就是线段树分治。

它需要的搭档只有一个：可撤销并查集，也就是不路径压缩、按大小合并、用栈记录每次合并的那个。

一、把时间拍成线段树

设操作总数为 m，时间就是 1 到 m。每条修改操作都有一个有效时间段 [l, r]，用线段树的区间覆盖把它拆成 O(log m) 个节点，任务（这条边）挂在这些节点上。

任务总数因此是 O(m log m)：每条修改被拆成 log m 份，每份都是独立的任务。同一条边会以好几份任务的形式出现在不同的节点上，互相不知道对方的存在。

二、进区间做事，出区间撤销

遍历到某个节点时，把它身上的任务逐个执行：并查集里能并就并，记下并了几次。往下递归之前，结构里已经有「这个区间里始终存在」的全部边；递归回来，把刚才并的次数逐个 undo，恢复原状。

叶子是单个时间点。到这里，并查集里恰好是「这个时刻所有存在的边」合并出来的连通情况，查询直接在并查集上做。

能这么做的前提是 undo 严格按后进先出：进节点并了什么、出节点就撤什么，顺序不能乱。可撤销并查集天生满足这一点。

把整棵线段树走一遍

三、题目1：动态图连通性

n 个点，m 条操作。操作 0 x y：x 和 y 之间现在没有边，加一条；操作 1 x y：x 和 y 之间现在有边，删掉；操作 2 x y：查询 x 和 y 是否连通。1 ≤ n ≤ 5000，1 ≤ m ≤ 5 × 10⁵，不强制在线。测试链接：LOJ 121。

这就是线段树分治的模版题，唯一的活儿是把操作序列整理成边的时间段。

对每一对点 (x, y) 记一个 last：上次「操作 0」发生的时刻。再次遇到涉及这对点的「操作 1」时，这条边的有效时间段就是 [last, i-1]，把它挂上线段树，然后把 last 清掉。全部操作读完，还留着 last 的边从头活到尾，统一挂 [last, m]。

注意这对点的操作要成对出现：题目保证加边时没边、删边时有边，所以按 (x, y) 有序对去重后，last 的记录是准确的。n ≤ 5000，last 直接开成二维数组。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 5001;
    const int MAXM = 500001;
    const int MAXT = 5000001;

    int n, m;

    int op[MAXM];
    int u[MAXM];
    int v[MAXM];

    int last[MAXN][MAXN];

    int father[MAXN];
    int siz[MAXN];
    int rollback[MAXN][2];
    int opsize = 0;

    int head[MAXM << 2];
    int nxt[MAXT];
    int tox[MAXT];
    int toy[MAXT];
    int cnt = 0;

    bool ans[MAXM];

    void addEdge(int i, int x, int y) {
        nxt[++cnt] = head[i];
        tox[cnt] = x;
        toy[cnt] = y;
        head[i] = cnt;
    }

    int find(int i) {
        while (i != father[i]) {
            i = father[i];
        }
        return i;
    }

    void Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (siz[fx] < siz[fy]) {
            int tmp = fx;
            fx = fy;
            fy = tmp;
        }
        father[fy] = fx;
        siz[fx] += siz[fy];
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
    }

    void undo() {
        int fx = rollback[opsize][0];
        int fy = rollback[opsize--][1];
        father[fy] = fy;
        siz[fx] -= siz[fy];
    }

    void add(int jobl, int jobr, int jobx, int joby, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobx, joby);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobx, joby, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobx, joby, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void dfs(int l, int r, int i) {
        int unionCnt = 0;
        for (int ei = head[i], x, y, fx, fy; ei > 0; ei = nxt[ei]) {
            x = tox[ei];
            y = toy[ei];
            fx = find(x);
            fy = find(y);
            if (fx != fy) {
                Union(fx, fy);
                unionCnt++;
            }
        }
        if (l == r) {
            if (op[l] == 2) {
                ans[l] = find(u[l]) == find(v[l]);
            }
        } else {
            int mid = (l + r) >> 1;
            dfs(l, mid, i << 1);
            dfs(mid + 1, r, i << 1 | 1);
        }
        for (int j = 1; j <= unionCnt; j++) {
            undo();
        }
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            father[i] = i;
            siz[i] = 1;
        }
        for (int i = 1, t, x, y; i <= m; i++) {
            t = op[i];
            x = u[i];
            y = v[i];
            if (t == 0) {
                last[x][y] = i;
            } else if (t == 1) {
                add(last[x][y], i - 1, x, y, 1, m, 1);
                last[x][y] = 0;
            }
        }
        for (int x = 1; x <= n; x++) {
            for (int y = x + 1; y <= n; y++) {
                if (last[x][y] != 0) {
                    add(last[x][y], m, x, y, 1, m, 1);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, t, x, y; i <= m; i++) {
            cin >> t >> x >> y;
            op[i] = t;
            u[i] = min(x, y);
            v[i] = max(x, y);
        }
        prepare();
        dfs(1, m, 1);
        for (int i = 1; i <= m; i++) {
            if (op[i] == 2) {
                if (ans[i]) {
                    cout << "Y" << "\n";
                } else {
                    cout << "N" << "\n";
                }
            }
        }
        return 0;
    }

四、题目2：判断二分图

n 个点，时刻 0 到 k，m 条操作。每条操作给出 x y l r：x 和 y 之间连一条边，l 时刻出现，r 时刻消失。依次输出 1 时刻以内、2 时刻以内、…、k 时刻以内，图是不是二分图。这里「i 时刻以内」指时间段 0 ~ i-1。1 ≤ n、k ≤ 10⁵，1 ≤ m ≤ 2 × 10⁵，数据保证 l < r。测试链接：P5787。

先把时间换算过来：边存在于时刻 l 到 r-1，而答案 i 覆盖时刻 0 到 i-1，所以这条边影响的是 i ∈ [l+1, r] 的那些答案。挂任务时区间就写 [l+1, r]。

判定二分图用扩充域并查集：每个点拆成 x 和 x+n 两个，边 (x, y) 进来就 Union(x, y+n) 和 Union(y, x+n)，含义是「x 和 y 不在同一侧」。哪天发现 find(x) == find(y)，说明 x 和 y 被迫同侧，图里出现了奇环。

这里有个可剪枝的细节：某个节点的任务自己就冲突了，那么它覆盖的每个时刻都冲突（节点任务只是叶子边集的子集），整段叶子直接标 No，不必再往下走。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXT = 3000001;
    int n, m, k;

    int father[MAXN << 1];
    int siz[MAXN << 1];
    int rollback[MAXN << 1][2];
    int opsize = 0;

    int head[MAXN << 2];
    int nxt[MAXT];
    int tox[MAXT];
    int toy[MAXT];
    int cnt = 0;

    bool ans[MAXN];

    void addEdge(int i, int x, int y) {
        nxt[++cnt] = head[i];
        tox[cnt] = x;
        toy[cnt] = y;
        head[i] = cnt;
    }

    int find(int i) {
        while (i != father[i]) {
            i = father[i];
        }
        return i;
    }

    void Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (siz[fx] < siz[fy]) {
            int tmp = fx;
            fx = fy;
            fy = tmp;
        }
        father[fy] = fx;
        siz[fx] += siz[fy];
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
    }

    void undo() {
        int fx = rollback[opsize][0];
        int fy = rollback[opsize--][1];
        father[fy] = fy;
        siz[fx] -= siz[fy];
    }

    void add(int jobl, int jobr, int jobx, int joby, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            addEdge(i, jobx, joby);
        } else {
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobx, joby, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobx, joby, mid + 1, r, i << 1 | 1);
            }
        }
    }

    void dfs(int l, int r, int i) {
        bool check = true;
        int unionCnt = 0;
        for (int ei = head[i]; ei > 0; ei = nxt[ei]) {
            int x = tox[ei], y = toy[ei], fx = find(x), fy = find(y);
            if (fx == fy) {
                check = false;
                break;
            } else {
                Union(x, y + n);
                Union(y, x + n);
                unionCnt += 2;
            }
        }
        if (check) {
            if (l == r) {
                ans[l] = true;
            } else {
                int mid = (l + r) >> 1;
                dfs(l, mid, i << 1);
                dfs(mid + 1, r, i << 1 | 1);
            }
        } else {
            for (int k = l; k <= r; k++) {
                ans[k] = false;
            }
        }
        for (int k = 1; k <= unionCnt; k++) {
            undo();
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> k;
        for (int i = 1; i <= n * 2; i++) {
            father[i] = i;
            siz[i] = 1;
        }
        for (int i = 1, x, y, l, r; i <= m; i++) {
            cin >> x >> y >> l >> r;
            add(l + 1, r, x, y, 1, k, 1);
        }
        dfs(1, k, 1);
        for (int i = 1; i <= k; i++) {
            if (ans[i]) {
                cout << "Yes" << "\n";
            } else {
                cout << "No" << "\n";
            }
        }
        return 0;
    }

五、复杂度分析

挂任务：每条修改拆成 O(log m) 个区间，共 O(m log m) 份任务。遍历：每份任务在它所在的节点执行一次并查集合并，叶子上每次查询 O(log n)，undo 总次数等于合并总次数。

操作时间复杂度空间复杂度
把一条修改挂上线段树O(log m)O(m log m)：任务总数 O(m log m)，链式前向星存任务；并查集 father、siz、回滚栈共 O(n)
一次 Union / undo（按大小合并，无路径压缩）O(log n)
叶子上一次查询O(log n)
整体（题目 1 与题目 2 同型）O(m log m log n)

题目 1 还有一个 O(n²) 的 last 二维数组，n ≤ 5000 时约 10⁷ 个 int，能开下；如果 n 更大，得换成哈希表或对操作排序后整理。

六、最后

这套结构的通用配方就三样：一根轴、一堆「在某段轴值上生效」的任务、一个能撤销的数据结构。轴是时间是本页的选择，下一页把它换成答案轴和颜色轴，同一个骨架立刻能做 mex 生成树和路径颜色统计。
