Bellman-Ford 与 SPFA：负权单源最短路

边权出现负数之后，Dijkstra 那句「弹出即定死」就不再成立，得换成一轮一轮扫边的松弛法。Bellman-Ford 每轮把所有边看一遍，最多 n-1 轮收敛；SPFA 只把上一轮被改动过的点放回队列，多数图上快得多。

零、松弛操作

一条从 P 到 S、权为 W 的边。如果 distance[P] + W 比当前的 distance[S] 还小，就用它把 distance[S] 改小。这一步叫这条边对 S 做了一次松弛。

一轮的意思是：把图里所有边都试着松弛一次。Bellman-Ford 就是不停地重复这个动作，直到某一轮一条边也没能松弛成功，说明所有距离都定下来了。

一、为什么最多 n-1 轮

一次成功的松弛，会让「到该点的最短路走了几条边」这个数至少加 1。从源点出发的最短路最多经过 n 个点，也就是 n-1 条边，所以 n-1 轮之内一定收敛。

实测（本机 clang -O2，链状图 1 到 2 到 … 到 n，每条边权 1）：n = 100 需要 99 轮，n = 1000 需要 999 轮，n = 5000 需要 4999 轮，正好是 n-1。每轮都要把 m 条边看一遍，最坏情况就是 O(n·m)。

收敛了就能提前退出：某一轮一条边都没松弛成功，后面的轮次全是白扫。

演示 · 逐轮松弛：一轮推进多少，什么时候该停

二、判负环：第 n 轮还能松弛

如果从源点能走到一个负环，绕着环转一圈距离还会变小，松弛永远不会停。所以跑满 n 轮之后再看一眼：第 n 轮还有边能松弛成功，就说明源点能到达负环。

要留意判断的范围：整张图里可能有负环，但源点走不到它，那就不算。想判整张图有没有负环，得加一个虚拟源点连到所有点上，再从虚拟源点跑一遍。

三、LC787：最多中转 k 次

题意是 n 个城市、一批单向航班，求 src 到 dst 最多中转 k 次的最便宜价格。把轮数定死在 k+1 轮就行：第 i 轮结束后 cur[v] 表示「最多坐 i 段航班」的最便宜价格，跑完 k+1 轮就是最多 k 次中转。

关键在于每一轮的松弛要基于上一轮的 cur，结果写进 next。直接在 cur 上改的话，同一轮里刚算出来的价格会被再拿去做中转，等于中转次数不限，答案偏小。

实测（40000 组随机小图，用「枚举所有不超过 k+1 条边的路径」做暴力参考）：复制版 0 处不符；原地版 1413 处偏小，占 3.53%。

#include <bits/stdc++.h>
    using namespace std;

    // Bellman-Ford 的思路，但只跑 k + 1 轮：第 i 轮结束表示「最多坐 i 段航班」
    // 返回 src 到 dst 最多中转 k 次的最便宜价格
    int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
        vector<int> cur(n, INT_MAX);
        cur[src] = 0;
        for (int i = 0; i <= k; i++) {
            // 这一轮的松弛全部基于上一轮的 cur，结果写进 next
            vector<int> next = cur;
            for (vector<int>& edge : flights) {
                if (cur[edge[0]] != INT_MAX) {
                    next[edge[1]] = min(next[edge[1]], cur[edge[0]] + edge[2]);
                }
            }
            cur = next;
        }
        return cur[dst] == INT_MAX ? -1 : cur[dst];
    }

两个样例：例一 n = 4、flights 是 [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]、src = 0、dst = 3、k = 1，答案是 700。例二 n = 3、flights 是 [[0,1,100],[1,2,100],[0,2,500]]、k = 1 得 200，把 k 改成 0 就得 500。

代价是 O(k·m)。n = 2000、m = 4998 时，k = 100 用 0.22ms，k = 1000 用 2.20ms，k = 5000 用 10.97ms，k = 10000 用 21.94ms，和 k+1 乘 m 成正比。

四、SPFA：只把动过的点放回队列

朴素 Bellman-Ford 每轮扫所有边，可实际上绝大多数点这一轮根本没变。没变的点，它的出边不可能引起新的松弛，扫了也是白扫。

SPFA 用一个队列装「上一轮距离变小了的点」，每轮只考察这些点的出边。同一个点已经在队列里就不重复放，用一个 enter 标记拦住。

复杂度并没有变好，最坏还是 O(n·m)，链那种最短路要一路传到底的图它也就快在常数上；稀疏随机图上优势才明显。所以有不带负权的边时优先用 Dijkstra，非得用 SPFA 就把数据规模看清楚。

判负环也靠它：一个点入队次数超过 n-1 次，说明它在环上转圈。洛谷 P3385 就是这套揉在一起的模版。

#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 2001;
    // 边权非负时题目给的是一条无向边，要占两个数组位置，所以开到 2m
    const int MAXM = 12001;

    int head[MAXN], nextEdge[MAXM], to[MAXM], weight[MAXM], cnt;
    int dis[MAXN];
    int updateCnt[MAXN];   // 每个点被松弛的次数
    int queue1[MAXN * MAXN];// 一个点最多入队 n 次，队列开 n * n 足够
    int l, r;
    bool enter[MAXN];

    void build(int n) {
        cnt = 1;
        l = r = 0;
        for (int i = 1; i <= n; i++) {
            head[i] = 0;
            enter[i] = false;
            dis[i] = INT_MAX;
            updateCnt[i] = 0;
        }
    }

    void addEdge(int u, int v, int w) {
        nextEdge[cnt] = head[u];
        to[cnt] = v;
        weight[cnt] = w;
        head[u] = cnt++;
    }

    // 从 1 号点出发能不能走到负环
    bool spfa(int n) {
        dis[1] = 0;
        updateCnt[1]++;
        queue1[r++] = 1;
        enter[1] = true;
        while (l < r) {
            int u = queue1[l++];
            enter[u] = false;
            for (int ei = head[u]; ei > 0; ei = nextEdge[ei]) {
                int v = to[ei], w = weight[ei];
                if (dis[u] + w < dis[v]) {
                    dis[v] = dis[u] + w;
                    if (!enter[v]) {
                        // 松弛次数超过 n - 1 次，说明它在负环上转圈
                        if (++updateCnt[v] > n - 1) {
                            return true;
                        }
                        queue1[r++] = v;
                        enter[v] = true;
                    }
                }
            }
        }
        return false;
    }

演示 · SPFA 的队列：只有动过的点才回到队尾

读入有个细节：w 不小于 0 的边是双向的，题目给 u 到 v 一条非负边，等于 v 到 u 也有一条同权的；w 小于 0 的边才是单向。所以边数组要按 2m 开，不然 m = 6000 的时候会写越界。

样例两组数据分别输出 NO、YES。第一组的环 1 到 2 到 3 到 1 权值是 2 + 1 - 3 = 0，不是负环；第二组的环是 3 + 4 - 8 = -1，是负环。

总结

松弛是共同的那一步：distance[P] + W 比 distance[S] 小就更新。Bellman-Ford 一轮扫全部边，最多 n-1 轮，代价 O(n·m)，第 n 轮还能松弛就说明源点能走到负环。

LC787 那类限定中转次数的题，把轮数定在 k+1 轮，而且每轮的松弛必须基于上一轮的快照，否则中转次数会失控。

SPFA 把没动过的点跳过，实测在链、随机稀疏图、网格上比朴素版少看几十到上千倍的边，判负环也是同一套结构。代价是最坏情况仍然退化成 O(n·m)，边权非负时没有理由不用 Dijkstra。
