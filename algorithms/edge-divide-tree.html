边分树

边分治的递归结构是二叉的：每层删一条重心边，连通区一分为二。把每个点在这棵递归树上的位置记下来，就得到一棵信息树，它长得像线段树，于是能做线段树那两件事：可持久化、合并。这一页讲清楚这棵树是什么，然后做 CF757G 可持久化边分树。

零、背景

上一节的边分治是一次性的：每层统计完就扔掉，下一题重新来。分治的结构本身其实很值钱。

点分治也有对应的结构，就是点分树。但点分树的每个节点可能挂多棵子树，不是二叉的，所以做不了线段树式的操作。

边分树不一样。每层恰好两个分支，所有点的信息树长在同一个骨架上，这个骨架就是线段树的形状。

一、问题

树上 n 个点，n-1 条带权边。给定长度为 n 的排列 arr。q 条操作：操作 1 x y z，输出 arr[x..y] 中每个节点到 z 的距离之和；操作 2 x，交换 arr[x] 和 arr[x+1] 的值。本题强制在线。1 ≤ n、q ≤ 2×10⁵。

「前缀 + 相邻交换 + 在线查询」这个组合，就是可持久化线段树做区间第 k 小的形状。区别只在信息是树上的距离，所以要有一棵能可持久化的树上信息结构。

二、朴素做法

每个询问从 z 出发 dfs 一遍，把 arr[x..y] 每个点的距离加起来，单次 O(n)，总共 O(nq)，4×10¹⁰ 级别，超时。

瓶颈在于距离没有被预处理成可拼接的量。边分治恰好提供了一种拆法：两点间的距离，按它们第一次被分开的那条重心边，拆成两侧两段。

三、边分树的原理

先把全局的骨架看清楚。边分治每一层删一条重心边，递归两侧：于是一条重心边是一个节点，它的两个孩子是两侧各自的重心边。整棵树的所有重心边组成一棵全局二叉树。

每个点从初始连通区出发，每层待在重心边的某一侧，直到自己单独成区。它走过的这条路径，就是它的信息树：路径上每个节点记录两样东西，这个点在这一层的哪一侧、离这条边多远。

信息树的用法是逐节点聚合。一个点集的信息树，就是把集合里所有点的路径放到同一副骨架上，每个节点做取舍：求和、计数、取最大，按题目需要。合并两个点集，就是把两棵信息树在骨架的每个节点上对齐相加。

最有用的性质在这个时候出现：两棵信息树合并到某个节点时，一棵在左侧、另一棵在右侧，这样的组合恰好枚举了跨过这条重心边的所有点对。分治保证每对点只在它们的分离边上被枚举一次，不重不漏。

合并的写法和线段树一样省：新建节点、继承旧指针、只在有变化的一侧递归。旧版本原样保留，这就是可持久化。

四、可持久化：前缀与差分

回到题目。先跑一遍边分治，把骨架和每个点的信息树建出来：每个实点 u 第一次遇到时开 root[u] 当链头，之后每下一层，在链尾挂一个左孩子或右孩子，写上到这一侧的距离。up[u] 是链尾游标。

然后做前缀。pre[i] = pre[i-1] 和 root[arr[i]] 合并的结果，代表点集 {arr[1..i]} 的信息树。合并沿链新建节点，每次 O(log n)，信息树的深度就是分治层数。

查询用差分。pre[y] 和 pre[x-1] 在骨架的每个节点上相减，就得到 {arr[x..y]} 的信息。距离在每一层拆开算：z 的信息树给出它在每一层的走向和距离；z 走向左的那层，点集里在右侧的点到 z 的距离 = 自己的右侧距离 + z 的左侧距离，逐点相加正好是「右侧距离和 + z 左距离 × 右侧个数」；z 走向右的层对称。

操作 2 有个讨巧的地方：交换 arr[x] 和 arr[x+1] 不改变前 x+1 个元素组成的集合，所以 pre[x+1] 往后全部不用动，只有 pre[x] = pre[x-1] ⊕ root[arr[x]] 要按交换后的值重建一次。

强制在线的处理是标准的：读进来的参数异或 lastAns 解码，输出后 lastAns 只保留低 30 位。

完整代码如下。

    
#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 400001;
    const int MAXT = MAXN * 30;
    int n, q, cntn;

    int head1[MAXN];
    int next1[MAXN << 1];
    int to1[MAXN << 1];
    int weight1[MAXN << 1];
    int cnt1;

    int head2[MAXN];
    int next2[MAXN << 1];
    int to2[MAXN << 1];
    int weight2[MAXN << 1];
    int cnt2;

    bool vis[MAXN];
    int siz[MAXN];

    int up[MAXN];
    int root[MAXN];
    int ls[MAXT];
    int rs[MAXT];
    int lcnt[MAXT];
    int rcnt[MAXT];
    ll lsum[MAXT];
    ll rsum[MAXT];
    int cntt;

    int arr[MAXN];
    int pre[MAXN];

    void addEdge1(int u, int v, int w) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        weight1[cnt1] = w;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v, int w) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        weight2[cnt2] = w;
        head2[u] = cnt2;
    }

    void rebuild(int u, int fa) {
        int last = 0;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            int w = weight1[e];
            if (v != fa) {
                if (last == 0) {
                    last = u;
                    addEdge2(u, v, w);
                    addEdge2(v, u, w);
                } else {
                    int add = ++cntn;
                    addEdge2(last, add, 0);
                    addEdge2(add, last, 0);
                    addEdge2(add, v, w);
                    addEdge2(v, add, w);
                    last = add;
                }
                rebuild(v, u);
            }
        }
    }

    void getSize(int u, int fa) {
        siz[u] = 1;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                getSize(v, u);
                siz[u] += siz[v];
            }
        }
    }

    int getCentroidEdge(int u, int fa) {
        getSize(u, fa);
        int total = siz[u];
        int half = total >> 1;
        bool find = false;
        while (!find) {
            find = true;
            for (int e = head2[u]; e > 0; e = next2[e]) {
                int v = to2[e];
                if (v != fa && !vis[e >> 1] && siz[v] > half) {
                    fa = u;
                    u = v;
                    find = false;
                    break;
                }
            }
        }
        int best = 0, edge = 0;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            if (!vis[e >> 1]) {
                int v = to2[e];
                int sub = (v == fa ? (total - siz[u]) : siz[v]);
                if (sub > best) {
                    best = sub;
                    edge = e;
                }
            }
        }
        return edge;
    }

    void dfs(int u, int fa, ll dist, int op) {
        if (u <= n) {
            if (up[u] == 0) {
                up[u] = ++cntt;
                root[u] = cntt;
            }
            int cur = up[u];
            int nxt = ++cntt;
            if (op == 0) {
                ls[cur] = nxt;
                lsum[cur] = dist;
                lcnt[cur] = 1;
            } else {
                rs[cur] = nxt;
                rsum[cur] = dist;
                rcnt[cur] = 1;
            }
            up[u] = nxt;
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa && !vis[e >> 1]) {
                dfs(v, u, dist + weight2[e], op);
            }
        }
    }

    void solve(int u) {
        int edge = getCentroidEdge(u, 0);
        if (edge > 0) {
            vis[edge >> 1] = true;
            int v1 = to2[edge];
            int v2 = to2[edge ^ 1];
            dfs(v1, 0, 0, 0);
            dfs(v2, 0, weight2[edge], 1);
            solve(v1);
            solve(v2);
        }
    }

    int add(int p, int i) {
        if (p == 0 || i == 0) {
            return p + i;
        }
        int rt = ++cntt;
        ls[rt] = ls[p];
        rs[rt] = rs[p];
        lcnt[rt] = lcnt[p] + lcnt[i];
        rcnt[rt] = rcnt[p] + rcnt[i];
        lsum[rt] = lsum[p] + lsum[i];
        rsum[rt] = rsum[p] + rsum[i];
        if (ls[i] > 0) {
            ls[rt] = add(ls[rt], ls[i]);
        } else {
            rs[rt] = add(rs[rt], rs[i]);
        }
        return rt;
    }

    ll query(int p1, int p2, int i) {
        if (ls[i] == 0 && rs[i] == 0) {
            return 0;
        } else if (ls[i] > 0) {
            return query(ls[p1], ls[p2], ls[i]) + rsum[p2] - rsum[p1] + lsum[i] * (rcnt[p2] - rcnt[p1]);
        } else {
            return query(rs[p1], rs[p2], rs[i]) + lsum[p2] - lsum[p1] + rsum[i] * (lcnt[p2] - lcnt[p1]);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> q;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1, u, v, w; i < n; i++) {
            cin >> u >> v >> w;
            addEdge1(u, v, w);
            addEdge1(v, u, w);
        }
        cntn = n;
        cnt2 = 1;
        rebuild(1, 0);
        solve(1);
        for (int i = 1; i <= n; i++) {
            pre[i] = add(pre[i - 1], root[arr[i]]);
        }
        ll mask = (1LL << 30) - 1;
        ll lastAns = 0;
        ll a, b, c;
        int op, x, y, z, tmp;
        for (int i = 1; i <= q; i++) {
            cin >> op;
            if (op == 1) {
                cin >> a >> b >> c;
                a ^= lastAns;
                b ^= lastAns;
                c ^= lastAns;
                x = (int)a;
                y = (int)b;
                z = (int)c;
                lastAns = query(pre[x - 1], pre[y], root[z]);
                cout << lastAns << '\n';
                lastAns &= mask;
            } else {
                cin >> a;
                a ^= lastAns;
                x = (int)a;
                tmp = arr[x];
                arr[x] = arr[x + 1];
                arr[x + 1] = tmp;
                pre[x] = add(pre[x - 1], root[arr[x]]);
            }
        }
        return 0;
    }

五、复杂度分析

信息树的深度等于分治层数，建树和每次合并的代价都由这个深度决定。

操作时间复杂度空间复杂度
三度化与边分治建骨架O(n log n)O(n log n)（信息树节点，MAXT 开到 30n）
建每个点的信息树（合计）O(n log n)
前缀 pre[i]（每次合并一条链）O(log n) 每次，共 O(n log n)
查询（沿 root[z] 的链差分）O(log n) 每次
操作 2（重建一个 pre[x]）O(log n) 每次

n、q 都是 2×10⁵ 时总量在 4×10⁶ 个节点级别，数组按 30n 开够用。

六、最后

边分树 = 边分治的骨架 + 每个点集在这副骨架上的信息。二叉同构是全部优势的来源：可持久化靠新建节点保留版本，合并靠逐节点对齐相加，跨重心边的点对在合并时自然被枚举。

下一节看合并的两次实战：两棵树上的距离拼一拼（暴力写挂），三棵树各自出力（通道）。那两题是边分树真正发力的地方。
