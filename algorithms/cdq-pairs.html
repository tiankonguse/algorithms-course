CDQ 分治统计点对

一堆对象两两配对，每对带一个约束和一个贡献。CDQ 分治的做法是把答案切成三部分，只攻「跨过中点」的那部分。这一节两道题：第一道跨区间用双指针就够，第二道还要再加一棵树状数组。

零、背景

统计类的问题大多长这样：n 个对象，每个对象有几个属性，要求所有满足某组约束的对象对的贡献之和。

归并分治在这类问题上的套路是固定的。当前区间二分成左右两半，答案 = 左半内部的答案 + 右半内部的答案 + 左半跨到右半的答案。前两项交给递归，关键永远是第三项。

CDQ 分治就是这套归并分治，再加一个数据结构来算跨区间的贡献。数据结构单次调用 O(log n) 时，整体是 T(n) = 2 * T(n/2) + O(n * log n)，解出来 O(n * log²n)。

本节课的两道题里，第一道的跨区间统计只用双指针扫一遍，是 O(n)，整体 O(n log n)；第二道要树状数组，整体 O(n log²n)。

一、问题：奶牛音量和

一共有 n 只奶牛，每只奶牛给定听力 v、坐标 x。

任何一对奶牛产生的音量 = max(vi, vj) * 两只奶牛的距离。

一共有 n * (n - 1) / 2 对奶牛，打印音量总和。

1 ≤ n、v、x ≤ 5 * 10⁴。

测试链接：洛谷 P5094。

二、朴素做法

枚举每一对，直接算。

for (int i = 1; i <= n; i++) {
    for (int j = i + 1; j <= n; j++) {
        ans += max(v[i], v[j]) * abs(x[i] - x[j]);
    }
}

n 取 5 * 10⁴ 时是 1.25 * 10⁹ 对，肯定超时。慢在每对都要单独判一次 max。

三、先把 max 定下来

把奶牛按听力 v 从小到大排序。排序之后，对任意 i < j 都有 vᵢ ≤ vⱼ，于是 max(vᵢ, vⱼ) 恒等于 vⱼ。

可以发现，max 这一项不再依赖具体的 i，只和 j 有关。答案就变成下面这个形式。

ans = Σ(j) vⱼ * Σ(i < j) |xᵢ - xⱼ|

剩下的问题只有一个：对每个 j，快速求出它和前面所有 i 的距离之和。

这里有个细节：v 相等的两只牛，max 取谁都一样，所以排序时相等的元素谁前谁后不影响结果。

四、跨中点的贡献

分治的架子照旧，cdq(l, r) 分成左右两半，答案由三部分相加。

return cdq(l, m) + cdq(m + 1, r) + merge(l, m, r);

merge 算的是「左半的牛」配「右半的牛」的贡献。因为大顺序是按 v 排的，左半的 v 都不超过右半的 v，所以配出来的一对，max 一定是右半那只牛的 v。

于是 merge 里对每个右半的牛 j，要算它和左半所有牛的距离之和。左半在归并的过程中已经按 x 排好序了，把 x 小于 xⱼ 的划一段、x 不小于 xⱼ 的划一段，两段的距离和可以各用一个前缀和表示。

前面一段：Σ (xⱼ - xᵢ) = 个数 * xⱼ - 左边x之和
后面一段：Σ (xᵢ - xⱼ) = 右边x之和 - 个数 * xⱼ

代码里用 lsum 记已经划到左边的 x 之和，rsum 记还没划过去的 x 之和。指针每往右挪一个，就把这个 x 从 rsum 挪到 lsum。

扫完右半之后，照常做一次归并，把整个区间按 x 排好序交上去。右半的牛是按原顺序（也就是 v 的顺序）逐个扫的，不要求有序。

五、代码：奶牛音量和

    
#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int v, x;
    };

    bool NodeCmp(Node a, Node b) {
        return a.v < b.v;
    }

    const int MAXN = 50001;
    int n;
    Node arr[MAXN];
    Node tmp[MAXN];

    long long merge(int l, int m, int r) {
        int p1, p2;
        long long rsum = 0, lsum = 0, ans = 0;
        for (p1 = l; p1 <= m; p1++) {
            rsum += arr[p1].x;
        }
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].x < arr[p2].x) {
                p1++;
                rsum -= arr[p1].x;
                lsum += arr[p1].x;
            }
            ans += (1LL * (p1 - l + 1) * arr[p2].x - lsum + rsum - 1LL * (m - p1) * arr[p2].x) * arr[p2].v;
        }
        p1 = l;
        p2 = m + 1;
        int i = l;
        while (p1 <= m && p2 <= r) {
            tmp[i++] = arr[p1].x <= arr[p2].x ? arr[p1++] : arr[p2++];
        }
        while (p1 <= m) {
            tmp[i++] = arr[p1++];
        }
        while (p2 <= r) {
            tmp[i++] = arr[p2++];
        }
        for (i = l; i <= r; i++) {
            arr[i] = tmp[i];
        }
        return ans;
    }

    long long cdq(int l, int r) {
        if (l == r) {
            return 0;
        }
        int mid = (l + r) / 2;
        return cdq(l, mid) + cdq(mid + 1, r) + merge(l, mid, r);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i].v >> arr[i].x;
        }
        sort(arr + 1, arr + n + 1, NodeCmp);
        cout << cdq(1, n) << '\n';
        return 0;
    }
演示 ①　六只奶牛的七次跨区间统计

样例：6 只牛 (v, x) = (3,1) (1,5) (2,3) (5,2) (4,6) (6,4)，按 v 排序后是 (1,5) (2,3) (3,1) (4,6) (5,2) (6,4)，答案是 157。

x < xⱼ，距离 = xⱼ - xᵢ x ≥ xⱼ，距离 = xᵢ - xⱼ

六、问题：机器人聊天对

一共有 n 个机器人，给定一个整数 k，每个机器人给定位置 x、视野 y、智商 q。

第 i 个机器人可以看见的范围是 [xᵢ - yᵢ, xᵢ + yᵢ]。

如果两个机器人相互之间可以看见，并且智商差距不大于 k，那么它们会开始聊天。打印有多少对机器人可以聊天。

1 ≤ n ≤ 10⁵，0 ≤ k ≤ 20，0 ≤ x、y、q ≤ 10⁹。

测试链接：洛谷 CF1045G。

七、互相看见：按视野从大到小排

朴素做法还是枚举一对，判三个条件：距离不超过两个视野、智商差不超过 k。O(n²)，n = 10⁵ 时不行。

「相互看见」这个说法比第一道题麻烦一点：距离要同时不超过 yᵢ 和 yⱼ。

把所有机器人按视野 y 从大到小排序。排完之后，分治时左半的 y 都不小于右半的 y。对左半的 i 和右半的 j，只要 |xᵢ - xⱼ| ≤ yⱼ 成立，由 yᵢ ≥ yⱼ 就知道另一个方向也成立。

因此统计的时候只用右半那个机器人的视野区间去数左半的点就够了，不用再回头判一次。

八、智商差：滑动窗口加树状数组

智商这一维的处理和第一道题不同，它不是「不超过某个值」，而是「差的绝对值不超过 k」，是个区间约束。

merge 的时候把左右两半各自按 q 从小到大排序。对右半的机器人 j，合法的左半机器人是 q 落在 [qⱼ - k, qⱼ + k] 里的那些。

两边都有序，这个区间可以用两个指针维护：winr 一直往右吃到 q > qⱼ + k 为止，winl 一直往右吐掉 q < qⱼ - k 的。进窗口的机器人把它的 x 加进树状数组，出窗口的减掉。

坐标 x 最大到 10⁹，先离散化。所有 x 排序去重之后，第 j 个机器人的视野 [xⱼ - yⱼ, xⱼ + yⱼ] 用二分换成格子区间 [lⱼ, rⱼ]：l 是第一个不小于 xⱼ - yⱼ 的格子，r 是第一个大于 xⱼ + yⱼ 的格子再减一。

这一步做完，查询就是树状数组的区间求和。

这里有个细节：窗口里的机器人是逐个加入树状数组的，查询用前缀和相减。清空的时候要按加过的格子逐个减回去，不能直接 memset，否则一次清空就是 O(n)，整体会退化成 O(n²)。

九、代码：机器人聊天对

    
#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int x, y, q, l, r;
    };

    bool CmpY(Node a, Node b) {
        return a.y > b.y;
    }

    bool CmpQ(Node a, Node b) {
        return a.q < b.q;
    }

    const int MAXN = 100001;
    int n, k, s;

    Node arr[MAXN];
    int x[MAXN];
    int tree[MAXN];

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= s) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int sum(int i) {
        int ret = 0;
        while (i > 0) {
            ret += tree[i];
            i -= lowbit(i);
        }
        return ret;
    }

    int query(int l, int r) {
        return sum(r) - sum(l - 1);
    }

    long long merge(int l, int m, int r) {
        int winl = l, winr = l - 1;
        long long ans = 0;
        for (int i = m + 1; i <= r; i++) {
            while (winl <= m && arr[winl].q < arr[i].q - k) {
                add(arr[winl].x, -1);
                winl++;
            }
            while (winr + 1 <= m && arr[winr + 1].q <= arr[i].q + k) {
                winr++;
                add(arr[winr].x, 1);
            }
            ans += query(arr[i].l, arr[i].r);
        }
        for (int i = winl; i <= winr; i++) {
            add(arr[i].x, -1);
        }
        sort(arr + l, arr + r + 1, CmpQ);
        return ans;
    }

    long long cdq(int l, int r) {
        if (l == r) {
            return 0;
        }
        int mid = (l + r) / 2;
        return cdq(l, mid) + cdq(mid + 1, r) + merge(l, mid, r);
    }

    int lower(int num) {
        int l = 1, r = s, m, ans = 1;
        while (l <= r) {
            m = (l + r) / 2;
            if (x[m] >= num) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

    int upper(int num) {
        int l = 1, r = s, m, ans = s + 1;
        while (l <= r) {
            m = (l + r) / 2;
            if (x[m] > num) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            x[i] = arr[i].x;
        }
        sort(x + 1, x + n + 1);
        s = 1;
        for (int i = 2; i <= n; i++) {
            if (x[s] != x[i]) {
                x[++s] = x[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            arr[i].l = lower(arr[i].x - arr[i].y);
            arr[i].r = upper(arr[i].x + arr[i].y) - 1;
            arr[i].x = lower(arr[i].x);
        }
        sort(arr + 1, arr + n + 1, CmpY);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> k;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i].x >> arr[i].y >> arr[i].q;
        }
        prepare();
        cout << cdq(1, n) << '\n';
        return 0;
    }
演示 ②　顶层那次 merge：窗口滑三格，命中两个

样例：6 个机器人 (x, y, q) = (2,3,5) (5,2,8) (8,4,3) (1,1,7) (6,5,6) (9,2,9)，k = 2，答案是 2。按 y 从大到小排完之后，左半是 #5、#3、#1，右半是 #2、#6、#4。

窗口内（智商差合法） 视野区间内且命中 浅框是当前机器人的视野格子区间

十、复杂度分析

设 n 为对象个数。两道题的差别只在 merge 这一步的代价。

操作时间复杂度
题 1 排序O(n log n)
题 1 每层 merge 合计O(n)
题 1 总计O(n log n)
题 2 离散化（排序去重 + n 次二分）O(n log n)
题 2 每层 merge 合计O(n log n)（每个元素两次树状数组操作）
题 2 总计O(n log² n)

题 2 的每层里，每个机器人恰好进窗口一次、出窗口一次，一次树状数组操作 O(log n)，所以每层是 O(n log n)，log n 层就是 O(n log²n)。

空间上，题 1 多了辅助数组 tmp，是 O(n)；题 2 多了树状数组和离散化用的坐标数组，也是 O(n)。

十一、最后

两道题用的都是同一个架子：先按某一维排好大顺序，分治时只统计跨过中点的那些对，剩下的维度交给排序后的双指针或者树状数组。

下一部分还是这个架子，只是统计的对象从「一对点」换成了「dp 的一次转移」。
