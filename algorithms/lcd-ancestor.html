长链剖分的原理与应用

重链剖分按子树大小挑重儿子，长链剖分按子树高度挑长儿子。换一个挑选标准，树的切法就完全不同，得到的是另一种性质：一条长链上的所有点，在 dfn 上连续。

零、背景

重链剖分解决的是「路径拆成 O(log n) 段」。它是靠重儿子的子树大小 ≥ 轻儿子两倍来保证的：每跨一条链，子树至少折半。

长链剖分没有这个保证。它换来的是另一件事：长儿子优先走，一条长链上的点在 dfn 上连成一整段，段长恰好等于链长。这一节的两个题都吃这个性质。

一、怎么剖

每个点在所有儿子里，挑子树高度最大的那个当长儿子，其余是轻儿子。高度相同的随便挑一个，不影响性质。dfs1 里只改一行比较标准：把 siz 换成 len。

len[u] 的定义是「从 u 往下沿长儿子能走多少个点」，所以 len[u] = len[son[u]] + 1，叶子为 1。这个量要在儿子都算完之后才能定，所以它在 dfs1 的末尾。

这里有个细节：点 2 的子树是 {2, 4, 5, 6}，点 3 的子树是 {3, 7, 8}。前者点多，重链剖分自然选它；后者层深，长链剖分反过来选它。两个标准互不蕴含，所以两种剖分不能互相替代。

二、两条性质

性质一：从任意点往根走，跨过的长链条数是 O(√n)。每跨一次说明上一条链不是最长的，链的长度严格递增，而总点数是 n，所以条数被 √n 卡住。这条性质保证了「按链跳」的次数不会太多。

性质二：给每条链的链头开一个长度等于链长的信息表，所有链的表加起来是 O(n)。这是长链剖分优化动态规划的基础，下一节用它。

还有一条最直接的性质：一条长链上的点，dfn 是连续的，且段长 = 链长。因为 dfs2 先递归长儿子，中途不会插入别的子树。

三、题目4：树上 k 级祖先

n 个点编号 1 到 n，给出每个点的父亲（arr[i] = 0 表示 i 是根）。m 条查询 x k，打印 x 往上走 k 步到达的点。要求预处理 O(n log n)、单次查询 O(1)。题目强制在线，入参由上次答案异或随机数得到。1 ≤ n ≤ 5 × 10⁵，1 ≤ m ≤ 5 × 10⁶。测试链接：P5903。

倍增表能做到 O(log n) 查询，卡在 m = 5 × 10⁶ 上。要做到 O(1)，得把「剩下的零头」也一次算出来。

办法是两步。先用倍增跳掉 k 的最高位 2^h，剩下的 r = k − 2^h 严格小于 2^h。这时有个关键结论：跳完之后的落点，它所在的长链长度至少是 2^h。理由也简单，落点往上 2^h 步都在同一条链上，否则它所在链的长儿子方向就断了。

既然落点所在链长 ≥ 2^h，那链头往下和往上的 2^h 个位置都被预处理过，r 这个零头一定落在里面。所以给每个链头预处理两张表：up 存链头往上 0 到 len − 1 步的祖先，down 存链头往下 0 到 len − 1 步的长儿子方向节点。

void dfs1(int u, int f) {
        stjump[u][0] = f;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        dep[u] = dep[f] + 1;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                if (son[u] == 0 || len[son[u]] < len[v]) {
                    son[u] = v;
                }
            }
        }
        len[u] = len[son[u]] + 1;
    }

    void prepare() {
        dfs1(root, 0);
        dfs2(root, root);
        high[0] = -1;
        for (int i = 1; i <= n; i++) {
            high[i] = high[i / 2] + 1;
        }
        for (int u = 1; u <= n; u++) {
            if (top[u] == u) {
                for (int i = 0, a = u, b = u; i < len[u]; i++, a = stjump[a][0], b = son[b]) {
                    setUp(u, i, a);
                    setDown(u, i, b);
                }
            }
        }
    }

查询时先把 k 减掉 2^h，再减掉「落点到它链头的距离」。减完为正，说明答案在链头上方，查 up；减完为负，说明答案在链头下方，查 down。两种情况都是 O(1)。

int query(int x, int k) {
        if (k == 0) {
            return x;
        }
        if (k == (1 << high[k])) {
            return stjump[x][high[k]];
        }
        x = stjump[x][high[k]];
        k -= (1 << high[k]);
        k -= dep[x] - dep[top[x]];
        x = top[x];
        return (k >= 0) ? getUp(x, k) : getDown(x, -k);
    }

四、题目5：攻略

n 个点的树，每个点有点权，规定 1 号点是头。一条路径必须从 1 号点出发，走到某个叶节点停止，路径上点权之和叫这条路径的收益。可以随意选出 k 条路径，所有经过的点取并集，并集里点权之和叫这 k 条路径的收益。打印最大收益。1 ≤ n、k ≤ 2 × 10⁵，点权都是正数。测试链接：P10641。

把「儿子的子树里最大收益」当作挑选标准，做一次长链剖分的泛化：每个点认 money 最大的儿子当长儿子。money[u] = money[长儿子] + 点权[u]，也就是从 u 往下沿长儿子走到底能拿到的收益。

为什么取前 k 大就合法。要点是点权为正，于是 money[父链头] 严格大于任何轻儿子为头的链的 money。一条链被选中，它父链一定也被选中，前 k 大的集合天然是「从根连下来」的形状。

反过来，任何一组 k 条路径，都能拆成 k 条完整的链：路径取并集，等价于在剖分后的链集合里挑若干条，且必须满足父子闭合。取前 k 大正好是满足闭合条件里和最大的一组。

void dfs1(int u, int f) {
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
            }
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                if (son[u] == 0 || money[son[u]] < money[v]) {
                    son[u] = v;
                }
            }
        }
        fa[u] = f;
        money[u] = money[son[u]] + arr[u];
    }

    void dfs2(int u, int t) {
        top[u] = t;
        if (son[u] == 0) {
            return;
        }
        dfs2(son[u], t);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != fa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }
long long compute() {
        int len = 0;
        for (int i = 1; i <= n; i++) {
            if (top[i] == i) {
                sorted[++len] = money[i];
            }
        }
        sort(sorted + 1, sorted + len + 1);
        long long ans = 0;
        for (int i = 1, j = len; i <= k; i++, j--) {
            ans += sorted[j];
        }
        return ans;
    }

复杂度分析

题4 的预处理分两块：倍增表 O(n log n)，链头的 up / down 表总计 O(n)。题5 只有两个 dfs 加一次排序。

操作时间说明
dfs1 + dfs2 长链剖分O(n)两个递归各遍历整棵树一遍
倍增表 stjumpO(n log n)n 个点各填 20 层
链头 up / down 表O(n)所有链长之和恰好是 n
单次 k 级祖先查询O(1)一次倍增取值 + 一次 up 或 down 取值
题5 两个 dfsO(n)每个点扫一遍邻接表
题5 排序O(n log n)链头最多 n 个
空间O(n log n)题4 的 stjump 占 n × 20，其余是 O(n)

题4 的 n = 5 × 10⁵、m = 5 × 10⁶，O(1) 查询是硬要求。二分答案或者再套一层 log 都会超时。

最后

这一节用的是长链剖分的「结构性」性质：链上 dfn 连续、跨链条数少。下一节换一个用法，把动态规划表沿着长链摊开，让整棵树的 dp 总代价降到 O(n)。
