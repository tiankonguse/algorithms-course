Splay 树

不追求平衡，把访问过的节点提到根，摊还下来还是 O(log n)。

零、背景

AVL 树靠「每个节点左右子树高度差不超过 1」保证查询 O(log n)，代价是每次插入、删除都要一路检查平衡因子，必要时旋转，平衡信息还得维护对。Splay 树换了一条路：树不时刻平衡，但每次操作都把被访问的那个节点旋转到根。

这个设计的底气是局部性：刚访问过的节点，很快还会被访问。把 x 提上来的过程同时把 x 的祖先们往下压，整条访问路径被「压扁」。单次操作可以很慢（比如提根一条 5 万长的链），但 n 次操作的总代价只有 O(n log n)，摊到每次还是 O(log n)。

这一课把提根的三种旋转讲清楚，再用两题落地：普通平衡树（P3369）和强制在线版（P6136）。

一、提根的三态

把节点 x 提上去，一路只有三种旋转组合。设 x 的父亲是 y，祖父是 z（没有祖父就省略）。

1）zig：升一步。y 已经是目标位置（根或要挂到的节点），x 直接转到 y 的位置。x 是 y 的左子时右旋，是右子时左旋。

2）zig-zig：一字型，先转父亲。x 和 y 同侧（x 是 y 的左子、y 也是 z 的左子；或都是右子）。先旋转 y 到 z 的位置，再旋转 x。顺序不能反。

3）zig-zag：之字型，自己转两次。x 和 y 异侧（x 是 y 的左子、y 是 z 的右子，或反过来）。x 连续转两次，第一次转完 x 到了 y 的位置，第二次到 z 的位置。

为什么一字型要先转父亲？因为连续转自己两次，会把一字链拧成之字，树高减半的效果就没了。先转 y 再转 x，x 的路径深度约减半，这才是摊还 O(log n) 的几何来源。

二、势能分析

证明 Splay 的总代价，用的是势能法。定义每个节点的权 w(x) = log(以 x 为根的子树大小)，整棵树的势能等于所有 w(x) 的和。

关键在于 zig-zig 这一步的势能变化。设旋转前 x 的子树大小为 s，旋转后为 s′，可以推出 势能变化量不超过 3 乘 (w′(x) − w(x))。于是旋转的摊还代价 = 1 + 势能变化 ≤ 3 乘 (w′(x) − w(x)) 加 1。

一次 splay 过程中，x 一路提根，w(x) 单调上升，这些项累加时中间项互相抵消，最后只剩首尾：总摊还代价 ≤ 3 乘 (w(根) − w(x初)) 加 1 = O(log n)。所有操作（查询、插入、删除）都伴随一次 splay，所以 n 次操作的总代价 O(n log n)。

势能法的好处是它不要求树时刻平衡。初始树哪怕是一条 5 万深的链，也不影响摊还结论。这也是 Splay 敢用在 LCT 上的原因：树的形态随便变，只要每个操作末尾提根，总代价就有保证。

三、P3369 普通平衡树：无词频的静态数组实现

洛谷 P3369 要求维护一个集合：插入、删除、按值查排名、按排名查值、查前驱、查后继。这里用静态数组 + 下标当指针实现，没有词频数组（重复值直接开新节点，左≤头≤右，等于的头放左边子树）。

先看「提根」和「旋转」这两个地基。splay(i, goal) 把节点 i 一路转到 goal 的孩子位置，goal 是 0 就转到根。lr(i) 返回 i 是左子还是右子，rotate 按儿子方向重组父子关系。

然后六个操作逐个来。插入 add 在 BST 里找到位置挂叶子，然后 splay 到根。getRank 数小于 x 的个数再加 1，返回前把找到的节点提根。index 按排名找节点再提根。

前驱后继用「记忆化」：变量 last 记录上一次提根的节点，pre(x) 先看 last 是否小于 x 且最大，是就直接返回，否则从根开始找。这样每个查询都伴随一次 splay，摊还代价有保证。

删除是这里最绕的。先 getRank(x) 和 getRank(x+1)，两个排名不等说明 x 存在。三种情况：只有头一个节点；x 是唯一的根（没有左子树）；一般情况：把 x 的右子树整个嫁接到前驱的右孩子上。P3369 保证删除的数一定存在。

这里有个细节：前驱、后继不存在时返回 INT_MIN 和 INT_MAX。这两个值只是给调用方一个「没有」的信号，不参与排序比较。

#include <iostream>
    #include <vector>
    #include <algorithm>
    #include <climits>

    using namespace std;

    const int MAXN = 100001;

    int head = 0;
    int cnt = 0;
    int key[MAXN];
    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int siz[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + 1;
    }

    int lr(int i) {
        return rs[fa[i]] == i ? 1 : 0;
    }

    void rotate(int i) {
        int f = fa[i], g = fa[f], soni = lr(i), sonf = lr(f);
        if (soni == 1) {
            rs[f] = ls[i];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[i] = f;
        } else {
            ls[f] = rs[i];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[i] = f;
        }
        if (g != 0) {
            if (sonf == 1) {
                rs[g] = i;
            } else {
                ls[g] = i;
            }
        }
        fa[f] = i;
        fa[i] = g;
        up(f);
        up(i);
    }

    void splay(int i, int goal) {
        int f = fa[i], g = fa[f];
        while (f != goal) {
            if (g != goal) {
                if (lr(i) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(i);
                }
            }
            rotate(i);
            f = fa[i];
            g = fa[f];
        }
        if (goal == 0) {
            head = i;
        }
    }

    int find(int rank) {
        int i = head;
        while (i != 0) {
            if (siz[ls[i]] + 1 == rank) {
                return i;
            } else if (siz[ls[i]] >= rank) {
                i = ls[i];
            } else {
                rank -= siz[ls[i]] + 1;
                i = rs[i];
            }
        }
        return 0;
    }

    void add(int num) {
        key[++cnt] = num;
        siz[cnt] = 1;
        if (head == 0) {
            head = cnt;
        } else {
            int f = 0, i = head, son = 0;
            while (i != 0) {
                f = i;
                if (key[i] <= num) {
                    son = 1;
                    i = rs[i];
                } else {
                    son = 0;
                    i = ls[i];
                }
            }
            if (son == 1) {
                rs[f] = cnt;
            } else {
                ls[f] = cnt;
            }
            fa[cnt] = f;
            splay(cnt, 0);
        }
    }

    int getRank(int num) {
        int i = head, last = head;
        int ans = 0;
        while (i != 0) {
            last = i;
            if (key[i] >= num) {
                i = ls[i];
            } else {
                ans += siz[ls[i]] + 1;
                i = rs[i];
            }
        }
        splay(last, 0);
        return ans + 1;
    }

    int index(int x) {
        int i = find(x);
        splay(i, 0);
        return key[i];
    }

    int pre(int num) {
        int i = head, last = head;
        int ans = INT_MIN;
        while (i != 0) {
            last = i;
            if (key[i] >= num) {
                i = ls[i];
            } else {
                ans = max(ans, key[i]);
                i = rs[i];
            }
        }
        splay(last, 0);
        return ans;
    }

    int post(int num) {
        int i = head, last = head;
        int ans = INT_MAX;
        while (i != 0) {
            last = i;
            if (key[i] <= num) {
                i = rs[i];
            } else {
                ans = min(ans, key[i]);
                i = ls[i];
            }
        }
        splay(last, 0);
        return ans;
    }

    void remove(int num) {
        int kth = getRank(num);
        if (kth != getRank(num + 1)) {
            int i = find(kth);
            splay(i, 0);
            if (ls[i] == 0) {
                head = rs[i];
            } else if (rs[i] == 0) {
                head = ls[i];
            } else {
                int j = find(kth + 1);
                splay(j, i);
                ls[j] = ls[i];
                fa[ls[j]] = j;
                up(j);
                head = j;
            }
            if (head != 0) {
                fa[head] = 0;
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        for (int i = 0, op, x; i < n; i++) {
            cin >> op >> x;
            if (op == 1) {
                add(x);
            } else if (op == 2) {
                remove(x);
            } else if (op == 3) {
                cout << getRank(x) << endl;
            } else if (op == 4) {
                cout << index(x) << endl;
            } else if (op == 5) {
                cout << pre(x) << endl;
            } else {
                cout << post(x) << endl;
            }
        }
        return 0;
    }

四、P6136 强制在线：结果参与下一次解码

P6136 和 P3369 的操作一模一样，唯一的区别是强制在线：每次读入的 x 要先异或上一次的输出 lastAns 才是真正的操作数，每次查询的输出也要异或进最终的答案。

数据结构部分一个字都不用改，变的只是 main 里的编码和解码。lastAns 初始 0，每次操作 x ^= lastAns，每次查询输出 ans 后 lastAns = ans，最后所有查询的答案逐位异或就是题目要求的输出。

总结

这一课就三件事：

1）提根只有三态：zig 升一步、zig-zig 一字型先转父亲、zig-zag 之字型自己转两次。顺序错了，链压扁的效果就没了。

2）势能 = 所有节点 log(子树大小) 之和，单次 splay 摊还 O(log n)，n 次操作总 O(n log n)。树不平衡也没关系，这正是它敢用在 LCT 上的底气。

3）P3369 与 P6136 代码几乎相同，后者只多了 main 里的异或解码。前驱后继不存在返回 INT_MIN/INT_MAX，删除用两个排名判存在。
