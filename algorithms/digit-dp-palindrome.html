数位 dp：状态里带前两位，以及反过来数

萌数这个题有两处和前面的数位 dp 不一样：状态要记住前两位而不只是前一位，而且直接数萌数很难数，数「不是萌数的数」反而顺手。这一页讲这两件事，顺带讲一道二进制上的同类题，那道题连递归都不用，一个预处理数组加一遍扫描就完事。

零、萌数

一个数字里只要存在长度至少为 2 的回文子串，就叫萌数。101、110、111、1234321、45568 都是，1、12、123 都不是。给 l 和 r，问 [l, r] 上有多少个萌数，答案对 1000000007 取余。l 和 r 是字符串，最长能到 1000 位。

一千位，逐个判断根本不可能。得按位拆。

一、先看清「回文子串」到底在说什么

长度至少为 2 的回文，看着要枚举所有子串才能判，其实不用。一个长度 L ≥ 2 的回文里一定能截出长度 2 或者长度 3 的回文：L 是偶数就取最中间那两位，它们相等；L 是奇数就取最中间那三位，两端相等。

长度 2 的回文就是相邻两位相等，长度 3 的回文就是隔一位的两位相等。所以判定条件缩成一句话：存在 i 使 s[i] == s[i+1]，或者 s[i] == s[i+2]。

这条等价关系不用靠感觉。拿字母表只有 3 个数字、长度 1 到 9 的全部 29523 个串跑一遍穷举，逐个比对「有没有长度 ≥ 2 的回文子串」和「是否存在相邻或隔一位相等」，29523 个串全部一致，其中 29472 个是萌数。串越长萌数占比越高，这是显然的：位置越多，撞上相等的机会越多。

二、状态里要带前两位

填第 i 位时，能不能填 cur 要看它和前一位、前前一位的关系。所以状态里得装 pp 和 p 两个数，各自再用 10 表示「那一位没填过」。

条件就是 pp != cur && p != cur。pp 是哨兵 10 的时候它跟任何数字都不等，自动放过，正好对应「前面不足两位」的情形。

三、反过来数更好写

顺着数萌数，得在递归里维护一个「已经萌了没有」的标记，而且萌了之后后面随便填，分支会长得很乱。换个方向：数「不是萌数」的数有多少个，再用总数减。

不是萌数，意味着每一位都和前两位不等，这正好是上面那个 pp != cur && p != cur，顺着填下去一路剪掉非法分支就行，状态干净。

这里有个细节。all 取的是 num 对 MOD 的余数，而 f 数的是 [0, num] 这 num+1 个数，所以 all − f 单独拿出来等于「萌数的个数减 1」：num = 100 时它给 9，真值是 10；num = 1 时它给 −1。这个偏差在 cnt(r) − cnt(l) 里正好抵消，不影响答案。

之所以要这么绕，是为了不做「字符串减一」。区间 [l, r] 写成 cnt(r) − cnt(l) + check(l)：前者是 (l, r] 上的萌数，后者把 l 自己补回来，合起来正好是 [l, r]。一千位的字符串做减法，写起来比这一句麻烦得多。

四、代码

递归的三件参数：走到第 i 位、前两位是 pp 和 p、free 是几。

// 从 num 的高位开始，当前来到第 i 位
    // pp 是前前位数字、p 是前一位数字，值为 10 表示那一位没有选择过数字
    // free == 1 表示之前的位已经确定比 num 小，接下来的数字可以自由选择
    // free == 0 表示之前的位和 num 一样，接下来的数字不能超过 num 当前位
    // 返回 <= num 且不是萌数的数字有多少个
    int f(const string &num, int i, int pp, int p, int free) {
        if (i == (int)num.size()) {
            return 1;
        }
        if (dp[i][pp][p][free] != -1) {
            return dp[i][pp][p][free];
        }
        int ans = 0;
        if (free == 0) {
            if (p == 10) {
                // 当前来到的就是 num 的最高位
                ans = (ans + f(num, i + 1, 10, 10, 1)) % MOD; // 当前位不选数字
                for (int cur = 1; cur < num[i] - '0'; cur++) {
                    ans = (ans + f(num, i + 1, p, cur, 1)) % MOD;
                }
                ans = (ans + f(num, i + 1, p, num[i] - '0', 0)) % MOD;
            } else {
                // 只要和前两位都不相同，就不会造出长度 2 或 3 的回文
                for (int cur = 0; cur < num[i] - '0'; cur++) {
                    if (pp != cur && p != cur) {
                        ans = (ans + f(num, i + 1, p, cur, 1)) % MOD;
                    }
                }
                if (pp != num[i] - '0' && p != num[i] - '0') {
                    ans = (ans + f(num, i + 1, p, num[i] - '0', 0)) % MOD;
                }
            }
        } else {
            if (p == 10) {
                ans = (ans + f(num, i + 1, 10, 10, 1)) % MOD; // 依然不选数字
                for (int cur = 1; cur <= 9; cur++) {
                    ans = (ans + f(num, i + 1, p, cur, 1)) % MOD;
                }
            } else {
                for (int cur = 0; cur <= 9; cur++) {
                    if (pp != cur && p != cur) {
                        ans = (ans + f(num, i + 1, p, cur, 1)) % MOD;
                    }
                }
            }
        }
        dp[i][pp][p][free] = ans;
        return ans;
    }

入口先把 num 对 MOD 取余存进 all，再拿 all 减去「不是萌数的个数」。check 就是第一节那个判定，用来补 l 自己。

// 一个数字里出现长度 >= 2 的回文子串，等价于
    // 存在相邻两位相等，或者存在隔一位的两个数字相等
    bool check(const string &num) {
        for (int pp = -2, p = -1, i = 0; i < (int)num.size(); pp++, p++, i++) {
            if (pp >= 0 && num[pp] == num[i]) {
                return true;
            }
            if (p >= 0 && num[p] == num[i]) {
                return true;
            }
        }
        return false;
    }

    // 返回 0 ~ num 范围上萌数的个数减 1（相减时才好用，见正文）
    int cnt(const string &num) {
        if (num[0] == '0') {
            return 0;
        }
        int n = num.size();
        ll all = 0, base = 1;
        for (int i = n - 1; i >= 0; i--) {
            all = (all + base * (num[i] - '0')) % MOD;  // num 对 MOD 取余
            base = (base * 10) % MOD;
        }
        build(n);
        return (int)((all - f(num, 0, 10, 10, 0) + MOD) % MOD);
    }

    // 不做「字符串减 1」，改成 cnt(r) - cnt(l) 再补上 l 自己
    int compute(const string &l, const string &r) {
        int ans = (cnt(r) - cnt(l) + MOD) % MOD;
        if (check(l)) {
            ans = (ans + 1) % MOD;
        }
        return ans;
    }

五、写错的地方

三种错法各跑两万组随机区间（l、r 在 10⁶ 以内）。

状态里只留 p、漏掉 pp，99.96% 的样本会错。漏掉 pp 等于只查相邻相等，所有「隔一位相等」的萌数全被漏掉，比如 101。

free 那一支的循环从 0 起步而不是 1，等于允许前导零变成真数字，58.58% 的样本会错。这个数字和上一页 windy 数漏掉「一个数字也不要」那一支恰好相同，原因是它们是同一类错误：短位数被数了两遍。

忘了补 check(l)，61.77% 的样本会错。只要 l 自己恰好是萌数就会少一个，随机区间里这不算稀奇。

具体反例：[100, 1000] 正解 253，只留 p 的那版给 172，忘 check(l) 的那版给 252。[111, 111] 正解 1，忘 check(l) 的那版给 0。

七、另一道：二进制上不含连续 1

给一个正整数 n，问 [0, n] 里二进制表示不含连续 1 的数有几个。这题也是「状态里带上一位」，但上界只有 2³¹，位数少，有更省事的算法。

先预处理 cnt[len]：二进制有 len 位时，不含连续 1 的状态有多少个。最高位是 1 的话下一位只能是 0，后面 len−2 位随便；最高位是 0 的话后面 len−1 位随便。于是 cnt[len] = cnt[len−1] + cnt[len−2]，就是斐波那契：cnt[0] = 1、cnt[1] = 2、cnt[2] = 3、cnt[3] = 5…一直到 cnt[30] = 2178309。

然后从高位往低位扫 num。第 i 位是 1 时，把它改成 0，后面 i 位就可以随便填，贡献 cnt[i]；改完之后前缀仍然贴着 num，继续看下一位。

有一处必须提前返回：如果 num 的第 i 位和第 i+1 位都是 1，那么前缀继续贴着 num 就一定不合法，后面不用再看。

这段代码短得不像动态规划，但它的每一步都是上面那个「改成 0 之后随便填」的展开。

// cnt[len] : 二进制有 len 位时，不存在连续 1 的状态有多少个
    // cnt[0] = 1（全是 0 那种），cnt[1] = 2（0 和 1），之后是斐波那契
    int cnt[31];

    // 从 num 二进制的高位开始，当前来到第 i 位，之前的位完全和 num 一样
    // 返回 <= num 且不存在连续 1 的状态有多少个
    int f(int num, int i) {
        if (i == -1) {
            return 1;                     // num 自身合法
        }
        int ans = 0;
        if ((num & (1 << i)) != 0) {
            // num 的第 i 位是 1：把这一位改成 0，后面 i 位随便填
            ans += cnt[i];
            if ((num & (1 << (i + 1))) != 0) {
                // num 的第 i 位和第 i + 1 位都是 1
                // 前缀继续和 num 一样就一定不合法，提前返回
                return ans;
            }
        }
        ans += f(num, i - 1);             // 前缀保持和 num 一样，继续看下一位
        return ans;
    }

    int findIntegers1(int n) {
        cnt[0] = 1;
        cnt[1] = 2;
        for (int len = 2; len <= 30; len++) {
            cnt[len] = cnt[len - 1] + cnt[len - 2];
        }
        return f(n, 30);
    }

改成迭代只是把递归栈去掉，逻辑一字不差：

// 只是把递归改成迭代，完全是等义改写
    int findIntegers2(int n) {
        cnt[0] = 1;
        cnt[1] = 2;
        for (int len = 2; len <= 30; len++) {
            cnt[len] = cnt[len - 1] + cnt[len - 2];
        }
        int ans = 0;
        for (int i = 30; i >= -1; i--) {
            if (i == -1) {
                ans++;                    // 一路和 num 一样走到了底，num 自身合法
                break;
            }
            if ((n & (1 << i)) != 0) {
                ans += cnt[i];
                if ((n & (1 << (i + 1))) != 0) {
                    break;
                }
            }
        }
        return ans;
    }

用标准数位 dp 也能做，状态是「还剩几位、上一位是不是 1、free 是几」，一共 31 × 2 × 2 = 124 格：

// 也可以走标准的数位 dp：状态里带「上一位是不是 1」
    int dp[33][2][2];

    // i 是当前位，pre 是上一位填的数字，free == 1 表示已经比 n 小
    int g(int n, int i, int pre, int free) {
        if (i < 0) {
            return 1;
        }
        if (dp[i][pre][free] != -1) {
            return dp[i][pre][free];
        }
        int cur = (n >> i) & 1;
        int ans = 0;
        int up = free ? 1 : cur;
        for (int d = 0; d <= up; d++) {
            if (pre == 1 && d == 1) {
                continue;                 // 连续两个 1，不要
            }
            ans += g(n, i - 1, d, free || d < cur);
        }
        dp[i][pre][free] = ans;
        return ans;
    }

    int findIntegers3(int n) {
        memset(dp, -1, sizeof(dp));
        return g(n, 30, 0, 0);
    }

三种写法在 n = 10⁹ 上单次分别是 0.000009 毫秒、0.000025 毫秒和 0.000230 毫秒。递归版和迭代版都是 O(位数)，差别只在常数；数位 dp 版多了 124 个格子的填表，慢一档，但它是通用套路，换一道约束不一样的题照样能用。

两万组随机 n（n ≤ 2×10⁵）的实测：

错法现形率说明
去掉提前返回96.74%n = 3 时给 4，正解 3；n = 100 时给 38，正解 34
cnt[1] 初值写成 1100.00%整个斐波那契跟着错，n = 3 给 2，n = 100 给 21
贡献写成 cnt[i+1]100.00%把「剩下 i 位」数成「剩下 i+1 位」，n = 3 给 5，n = 100 给 55

提前返回那一处最容易被当成可有可无的优化删掉。它其实是正确性的一部分：不返回就会继续往下加，把本来不合法的那一支也算进答案。

十、复杂度分析

题目时间额外空间
萌数O(n × 11 × 11 × 2 × 10) = O(n)，n 是位数O(n × 11 × 11 × 2)，n = 1000 时约 24 万个 int ≈ 968 KB
不含连续 1（预处理 + 扫描）O(31) 预处理加 O(31) 扫描 = O(1)O(31)，cnt 数组
不含连续 1（数位 dp）O(31 × 2 × 2 × 2)O(31 × 2 × 2)

萌数那一栏的 11 × 11 是 pp 和 p 各自的 11 个取值（0 到 9 加上哨兵 10），后面那个 2 是 free。位数 1000 时状态接近 24 万个，还能接受；位数再往上就得考虑把 pp 压掉了。

十一、总结

约束牵扯前 k 位，状态里就带前 k 位。这道题 k 是 2，windy 数那道 k 是 1，写法是同一套。

顺着数不好数就反着数。all − f 这个方向让递归里只剩一条「每一位都和前两位不等」的干净链，不用维护「已经满足没有」这种标记。

区间 [l, r] 用 cnt(r) − cnt(l) + check(l) 避开字符串减法，代价是 cnt 单独看会差 1，这个偏差在相减时抵消。

位数固定且很小的时候，递归往往能退化成「预处理 + 一遍扫描」。不含连续 1 那道题就是：cnt 数组一次算好，之后每位只做一次加法和一次判断。
