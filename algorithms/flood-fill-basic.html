洪水填充：一次感染一整片

一个递归函数从某个格子出发，把和它连成一片的格子全部改成另一个值。看着是到处乱窜的暴力过程，代价却和把网格扫一遍同阶：每格只被真正处理一次。

零、背景

网格题里最常做的事是「找到和某个格子连通的整片，然后统一处理」。数岛屿、判区域、染色、扩散，全都是这一件事。

做法只有一句：走到一个格子上，先看看它合不合规矩（有没有越界、是不是要找的那种格子），不合就返回；合规就把它改成另一个值，然后朝四个方向分别调用自己。

关键在于改的那个值不撤销。常见的递归过程里，路径信息进栈出栈要成对恢复，因为还要回头枚举别的分支；这里不需要回头，改完就是改完了，同一片永远只会被处理一次。

一、感染函数的形状

四行就能写完：判越界与不合格、改标记、四个方向各自递归。方向顺序怎么写都行，上下左右只是一种习惯。

「改成另一个值」这一步同时干了三件事：标记已处理、避免重复进入、给后面的扫描留证据。所以主循环扫到没被改过的格子时，可以直接断定发现了一片新区域。

// 从 (i,j) 出发，把连着的 '1' 全部改成 '2'
    void dfs(vector<string>& board, int n, int m, int i, int j) {
        if (i < 0 || i == n || j < 0 || j == m || board[i][j] != '1') {
            return;
        }
        board[i][j] = '2';
        dfs(board, n, m, i - 1, j);
        dfs(board, n, m, i + 1, j);
        dfs(board, n, m, i, j - 1);
        dfs(board, n, m, i, j + 1);
    }

二、岛屿数量：数一共启动了几次

网格里 '1' 是陆地、'0' 是水，上下左右相连的 '1' 算同一座岛。主循环把每个格子看一眼，遇到 '1' 就把计数加一，再从这里感染一整片；遇到 '0' 或者已经被改成 '2' 的，直接跳过。

计数加一的时机就是「发现新岛」的时机，因为能被主循环碰到的 '1'，一定是还没被任何一次感染碰过的。

// 主循环扫一遍，碰到没被改过的 '1' 就说明发现了一座新岛
    int numIslands(vector<string>& board) {
        int n = board.size();
        int m = board[0].size();
        int islands = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (board[i][j] == '1') {
                    islands++;
                    dfs(board, n, m, i, j);
                }
            }
        }
        return islands;
    }

三、为什么是线性的

每个格子会招来几次调用？它被四个邻居各叫一次（方向是死写的四个，不管邻居在不在网格里），再加上自己被真正进入的那一次。一个格子摊到五次调用以内，调用次数和格子数同阶。

实测很贴这个数：200×200 全是 '1' 的网格（4 万格），感染函数一共被调用 160001 次，正好是 4×40000+1，每格摊 4.00 次。随机网格更省，密度 0.3 时每格 1.32 次、密度 0.5 时 2.06 次、密度 0.7 时 2.80 次。

300×300、密度 0.45 的随机网格上，三种数法都给出 8127 座岛，耗时分别是：感染递归 1.49ms、并查集 2.83ms、BFS 队列 3.68ms。感染版最快，因为它既不用开队列也不用维护 father 数组，标记直接写在原网格上。

演示：主循环扫格子，扫到 '1' 就感染一整片

四、递归深度等于连通块大小

感染函数没有尾递归优化可指望，栈一层压一层，深度等于这一片有多长。全是陆地的网格最坏：200×200 全 '1' 实测最深 40001 层，就是格子总数。

本机 macOS 默认栈 8176 KB，这个写法的每帧约 113 字节，于是七万多层就到顶了。实测：272×272 全 '1'（73984 格）能跑完，274×274（75076 格）段错误。所以大网格要么换队列版，要么确认数据里没有巨大的连通块。

随机网格的压力小得多，200×200 上实测最大深度：密度 0.4 时 41 层、0.5 时 88 层、0.6 时 1246 层。真会出事的是整片连在一起的构造数据。

// 递归深度等于连通块大小，换成队列就没有这个上限
    int numIslandsBfs(vector<string>& board) {
        int n = board.size(), m = board[0].size(), islands = 0;
        int dr[4] = {1, -1, 0, 0}, dc[4] = {0, 0, 1, -1};
        queue<pair<int, int>> q;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (board[i][j] != '1') continue;
                islands++;
                board[i][j] = '2';
                q.push({i, j});
                while (!q.empty()) {
                    auto [x, y] = q.front();
                    q.pop();
                    for (int d = 0; d < 4; d++) {
                        int nx = x + dr[d], ny = y + dc[d];
                        if (nx < 0 || nx == n || ny < 0 || ny == m) continue;
                        if (board[nx][ny] != '1') continue;
                        board[nx][ny] = '2';
                        q.push({nx, ny});
                    }
                }
            }
        }
        return islands;
    }

五、被围绕的区域：从边界往里感染

棋盘上 'O' 是被 'X' 包围的区域候选，问哪些 'O' 被完全围住（上下左右走不到边界），把它们填成 'X'。

顺着题意做，是对每块 'O' 都查一次「能不能走到边界」。查一次的代价是整片区域的大小，于是总代价是每片区域大小的平方和，网格一大立刻爆炸。

反过来想就通了：走不到边界的 'O' 才是要改的，那先把走得到边界的都标记出来，剩下没被标记的就是答案。边界只有最外一圈，从这一圈上的每个 'O' 出发感染，把这些格子临时改成 'F'；最后扫一遍，还是 'O' 的填成 'X'，是 'F' 的还原成 'O'。

实测（随机棋盘，密度 0.6）：n=40 时顺向 11.99ms、反向 0.06ms；n=200 时顺向 2126.76ms、反向 0.44ms，差约 4800 倍。全是 'O' 的棋盘更极端，n=60 时顺向 97.54ms、反向 0.06ms。

// 从边界上的 'O' 出发感染成 'F'，剩下的 'O' 全是被围住的
    void dfs(vector<string>& board, int n, int m, int i, int j) {
        if (i < 0 || i == n || j < 0 || j == m || board[i][j] != 'O') {
            return;
        }
        board[i][j] = 'F';
        dfs(board, n, m, i + 1, j);
        dfs(board, n, m, i - 1, j);
        dfs(board, n, m, i, j + 1);
        dfs(board, n, m, i, j - 1);
    }

    void solve(vector<string>& board) {
        int n = board.size();
        int m = board[0].size();
        for (int j = 0; j < m; j++) {
            if (board[0][j] == 'O') dfs(board, n, m, 0, j);
            if (board[n - 1][j] == 'O') dfs(board, n, m, n - 1, j);
        }
        for (int i = 1; i < n - 1; i++) {
            if (board[i][0] == 'O') dfs(board, n, m, i, 0);
            if (board[i][m - 1] == 'O') dfs(board, n, m, i, m - 1);
        }
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X';
                else if (board[i][j] == 'F') board[i][j] = 'O';
            }
        }
    }

演示：先从边界感染成 F，剩下的 O 全是被围住的

六、复杂度分析

指标值
时间复杂度O(n×m)，网格 n 行 m 列
额外空间O(n×m)（递归栈，最坏等于连通块大小；队列版是 O(n×m) 的队列）
标记写在原网格上不额外开 visited 数组，代价是原数据被改掉

时间这一项不含系数里的方向数：每格摊到 4 次调用加 1 次进入，常数是 5。递归版的额外空间严格说是 O(最大连通块大小)，全陆地网格下等于格子数。

七、总结

感染函数四行：判越界与不合格、改标记、四个方向递归。标记不撤销是整套做法的支点，它让「主循环扫到未改过的格子」等价于「发现一片新区域」。

用的时候记两件事。一是递归深度等于连通块大小，整片连在一起的网格会打穿栈，七万层上下就是本机上限，这时候换队列版。二是别顺着题意硬查，先问一句「剩下的才是答案吗」，能反过来就反过来：被围绕的区域从边界感染，比逐块判定快三个数量级。

把标记换成编号、把一次感染换成多次感染，这套动作还能往上叠出更难的用法。
