传递闭包

有向图里 i 能不能走到 j，走几条边都行。用 Floyd 的方式枚举每个点当跳板，再把每一行压成一个 bitset，一次或运算就合并一整行，复杂度从 O(n³) 降到 O(n³ / 64)。

零、背景

有些关系是有方向、又能传递的。a 比 b 强，b 比 c 强，那 a 就比 c 强；i 有一条边到 k，k 有一条边到 j，那 i 就能走到 j。

把这种关系建成有向图之后，要回答的问题就是：任意两点 i、j 之间，有没有一条长度至少为 1 的有向路径。所有答案放在一起是一张 n × n 的 0/1 矩阵，叫传递闭包，也叫可达矩阵。

它的用处比听起来大。「能不能比出高下」「还缺几条关系」「名次能不能定下来」，最后都落到这张矩阵上。

一、问题

给定一张有向图的邻接矩阵 a：a[i][j] = 1 表示有一条 i 到 j 的边，0 表示没有。求传递闭包矩阵 b：b[i][j] = 1 当且仅当 i 经过至少一条边能到 j。

二、朴素做法

最直接的办法是从每个点做一次 DFS 或者 BFS，把能到的点全标上。n 个点各做一遍，复杂度是 O(n·(n + m))。

稠密图里 m ≈ n²，这就是 O(n³)。n = 2000 时是 8 × 10⁹，跑不动。稀疏图能快些，但 m 一大照样退回 O(n³)。

换个思路：不去「搜」，而是像 Floyd 那样枚举跳板。

三、枚举跳板

Floyd 求最短路时，外层枚举的 bridge 是「只允许路径经过编号 ≤ bridge 的点」的意思。求可达性时可以照搬：如果 i 已经能到 bridge，而 bridge 能到 j，那么 i 就能到 j。

写成三重循环是这样：

for (int bridge = 1; bridge <= n; bridge++)
    for (int i = 1; i <= n; i++)
        if (dp[i][bridge])
            for (int j = 1; j <= n; j++)
                dp[i][j] |= dp[bridge][j];

复杂度 O(n³)，和朴素做法一个量级。真正省时间的是下面这一步。

四、一行压成一个 bitset

矩阵里存的只是 0 和 1，一个 bit 就够，没必要用一个 int 甚至一个 bool。把第 i 行的 n 个关系压成一个 bitset，最内层那个「逐列或」的循环就消失了，两个 bitset 做一次 |=，机器上一口气处理 64 个 bit。

于是三重循环变成两重，最里面那句只剩一个 |=：

void floyd() {
    for (int bridge = 1; bridge <= n; bridge++)
        for (int i = 1; i <= n; i++)
            if (dp[i][bridge])
                dp[i] |= dp[bridge];
}

省下来的倍数就是字长。n = 2000 时，原本 8 × 10⁹ 次「列」操作，现在只有 1.25 × 10⁸ 次位运算。

六、代码

下面是模板题的完整实现，一共十几行。

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;

int n;
bitset<MAXN> dp[MAXN];               // dp[i][j] = 1：i 能到 j

void floyd() {
    for (int bridge = 1; bridge <= n; bridge++)
        for (int i = 1; i <= n; i++)
            if (dp[i][bridge])          // i 能到 bridge
                dp[i] |= dp[bridge];   // 就把 bridge 能到的全接过来
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1, s; j <= n; j++) {
            cin >> s;
            dp[i][j] = s;
        }
    floyd();
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (dp[i][j] ? "1 " : "0 ");
        cout << '\n';
    }
    return 0;
}

这里有个容易漏掉的点：dp[i][bridge] 这个判断不能省。省掉的话，i 到不了 bridge 也会被或上bridge 那一行，凭空多出很多可达关系。

七、复杂度分析

操作时间复杂度
每个点 DFS / BFS（朴素）O(n·(n + m))，稠密图 O(n³)
Floyd 三重循环O(n³)
bitset 版 FloydO(n³ / 64)（n² 次或运算，每次 n / 64 个字）
读入邻接矩阵O(n²)
总时间O(n³ / 64)
额外空间O(n² / 8) 字节

空间上，n 行 bitset 一共 n² 个 bit，也就是 n² / 8 个字节。n = 2000 时是 5 × 10⁵ 字节，不到半兆，很宽松。

时间复杂度里那个 64 是机器字长。bitset<MAXN> 的 |= 会把整行拆成 ⌈n / 64⌉ 个 64 位字，一个字一次算完，所以是 n³ / 64 而不是 n³。

这也说明它的边界：n 到几千没问题，再大下去 n² / 8 的空间先撑不住。那种规模得换成按连通分量缩点，或者别的可达性结构。

八、换个问法

闭包求出来之后，大部分题目要的不是矩阵本身，而是从矩阵里数出点什么。下面几个都是同一个骨架，只改最后一步。

连通数

问有多少个有序点对 (i, j) 满足 i 能到 j，并且每个点都能到自己。做法是把对角线先置成 1，求完闭包后数一数每行有几个 1。

for (int i = 1; i <= n; i++) dp[i][i] = true;   // 自己到自己也算
floyd();
int ans = 0;
for (int i = 1; i <= n; i++) ans += dp[i].count();

确定能力

n 头奶牛能力各不相同，给出 m 条「a 强于 b」的关系，关系可传递。问有几头牛的名次能确定下来。一头牛的名次能确定，等价于它和其余 n − 1 头牛的高下都已明确。

for (int i = 0, a, b; i < m; i++) { cin >> a >> b; dp[a][b] = true; }
floyd();
for (int i = 1; i <= n; i++)
    for (int j = i + 1; j <= n; j++)
        if (dp[i][j] || dp[j][i]) { cnt[i]++; cnt[j]++; }  // 这一对能比出来
int ans = 0;
for (int i = 1; i <= n; i++)
    if (cnt[i] == n - 1) ans++;                        // 和所有牛都比过

需要关系

还是那些强弱关系，问至少还要补充几条关系，才能把完整排名定下来。 unknow 的那一对就需要问一次，数一数两个方向都不可达的点对有多少。

floyd();
int need = 0;
for (int i = 1; i <= n; i++)
    for (int j = i + 1; j <= n; j++)
        if (!dp[i][j] && !dp[j][i]) need++;            // 这一对还没法比

有向图与查询

定义一条路径的代价是路径上所有点编号的最大值，q 次询问 s 到 t 的最小代价。做法是边跑 Floyd 边回答：当跳板枚举到 bridge 时，只允许经过编号 ≤ bridge 的点，s 到 t 第一次连通的那个 bridge，加上 s、t 自己的编号，就是答案。

void floyd() {
    for (int i = 1; i <= q; i++) ans[i] = -1;
    for (int bridge = 1; bridge <= n; bridge++) {
        for (int i = 1; i <= n; i++)
            if (dp[i][bridge]) dp[i] |= dp[bridge];
        for (int i = 1; i <= q; i++)                 // 刚好在这一轮连通
            if (ans[i] == -1 && dp[s[i]][t[i]])
                ans[i] = max(bridge, max(s[i], t[i]));
    }
}

排序

逐条加入「A < B」这样的关系，每加一条就判断一次：有没有矛盾、排名是不是已经唯一。判断还是看闭包，对角线上出现 1 说明有环，也就是矛盾；存在一对两个方向都不可达，说明还没定下来。

// 0：还没确定　1：已确定　2：有矛盾
int check() {
    for (int i = 1; i <= n; i++)
        if (dp[i][i]) return 2;                 // 自己能到自己，成环了
    for (int i = 1; i <= n; i++)
        for (int j = i + 1; j <= n; j++)
            if (!dp[i][j] && !dp[j][i]) return 0;  // 有一对还没比出来
    return 1;
}

确定之后输出升序序列：对每个元素数一数有多少个元素比它小，这个个数就是它排第几，直接放到对应位置。

九、最后

传递闭包本身很简单，就是 Floyd 去掉「取最小」那一步，只留下「有没有」。真正让它在 n = 2000 这种规模上能用起来的，是 bitset 把最内层循环换成了一次位运算。

用的时候记住两件事：一是 if (dp[i][bridge]) 那个判断别漏；二是题目说「自己能到自己」时要先把对角线置 1，说「走至少一条边」时则不要置，两者差一个环的判断。
