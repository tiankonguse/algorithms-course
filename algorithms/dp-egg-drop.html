扔鸡蛋：把楼层换进值域

k 个鸡蛋、n 层楼，最坏情况下最少扔几次能确定临界层。直觉的 dp(k, n) 是 O(kn²)。把「楼层」从输入挪进值域、把「次数」当状态，问题变成「j 次最多能测几层」，一趟就出答案。

零、背景

一个鸡蛋碎了就没了，两个鸡蛋就能用「先粗后细」的策略省次数。经典的二分答案 dp(k, n) = 1 + min_x max(dp(k−1, x−1), dp(k, n−x))：在 x 层扔一次，碎了就去下面 x−1 层用 k−1 个蛋，没碎去上面 n−x 层用 k 个蛋，取最坏情况再最小化。状态 k×n、转移枚举 x，O(kn²)，n = 1e4 就上亿了。

题目数据能到 n = 1e9（LeetCode 887），这条路完全走不通。

一、换状态：次数当维度，楼层当值

定义 dp[i][j]：i 个鸡蛋、最多扔 j 次，能确定多少层楼（无论临界层在哪一层都能测出）。递推：扔一次在中间某层，碎了，下面 dp[i−1][j−1] 层用 i−1 个蛋、j−1 次测；没碎，上面 dp[i][j−1] 层用 i 个蛋、j−1 次测；这一层本身也确定了。

dp[i][j] = dp[i−1][j−1] + dp[i][j−1] + 1。次数 j 从 1 往上试，dp[k][j] ≥ n 时 j 就是答案。

k = 2 时 dp[2][j] = j(j+1)/2：1、3、6、10、15…… j = 14 时 105 ≥ 100，所以 2 个鸡蛋 100 层要 14 次，而 1 个鸡蛋要 100 次。鸡蛋足够多时接近二分，dp[k][j] = 2^j − 1：100 个蛋 1e4 层只需要 14 次，因为 2^14 − 1 = 16383。

二、空间压缩

递推里 dp[i][j] 只用到了 j−1 的两行：dp[i−1][j−1] 和 dp[i][j−1]。外层循环 j，内层循环 i，一维数组滚动就够。k = 2、n = 1e9 时，j 最多跑到 44721 就够，一次循环都没白费。

j 次最多测多少层：选鸡蛋数，看增长

三、总结

直觉 dp 把「次数」当答案、「楼层」当下标，于是要枚举扔的位置。换状态后次数成为维度、楼层成为值，枚举消失了，代价是答案要顺着 j 一点点试。这个「答案换值域」的套路，在数据范围给到 1e9 这类题上比二分答案更直接：二分答案还要保证判定单调，这里连判定的步骤都省了。

滚动数组版：

#include <bits/stdc++.h>
    using namespace std;

    // dp[i]：i 个鸡蛋、已扔 j 次时，最多能确定多少层
    // 递推：dp[i][j] = dp[i-1][j-1] + dp[i][j-1] + 1，j 是外层循环
    int superEggDrop(int k, int n) {
        if (k == 1) {
            return n;               // 一个鸡蛋只能一层一层试
        }
        vector<int> dp(k + 1, 0);
        for (int j = 1; j <= n; j++) {
            int pre = 0;            // 上一轮 dp[i-1][j-1] 的值
            for (int i = 1; i <= k; i++) {
                int tmp = dp[i];
                dp[i] = dp[i] + pre + 1;    // 不碎测 dp[i][j-1]，碎了测 dp[i-1][j-1]
                pre = tmp;
                if (dp[i] >= n) {
                    return j;       // 第 j 次已经能覆盖 n 层
                }
            }
        }
        return -1;
    }
