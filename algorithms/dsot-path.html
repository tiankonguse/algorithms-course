路径上的统计

前面三节问的都是子树。这一节问路径：一条路径能不能重排成回文、路径上第 k 小的权值是多少。第一道还是树上启发式合并，第二道只借用了「小集合往大集合里倒」这个想法。

一、题目6：最长重排回文路径

一共有 n 个节点，编号 1 到 n，给定 n − 1 条边，所有节点连成一棵树，1 号节点为树头。每条边上都有一个字符，字符范围 a 到 v，一共 22 种。节点 a 到节点 b 的路径，如果所有边的字符收集起来能重新排列成回文串，该路径就是重排回文路径。打印 1 到 n 每个节点为头的子树中，最长重排回文路径的长度。1 ≤ n ≤ 5 × 10⁵。测试链接：CF741D。

第一步是把判定转化成异或。一串字符能重排成回文，当且仅当出现奇数次的字符最多一个。22 种字符各占一个二进制位，把每个字符记成 1 << (c − 'a')，一条路径上所有字符的异或和，就把「哪些字符出现了奇数次」记了下来。所以判定条件变成：路径异或和是 0，或者恰好只有一个二进制位是 1。

第二步是把路径异或和变成两个前缀的异或。定义 eor[u] 是根到 u 的路径上所有字符的异或。那么 a 到 b 的路径异或和就是 eor[a] ^ eor[b]，因为根到 LCA 那一段被异或了两次，正好抵消。dfs1 一遍就能把所有 eor 算出来。

void dfs1(int u, int d, int x) {
        siz[u] = 1;
        dep[u] = d;
        eor[u] = x;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            dfs1(to[e], d + 1, x ^ (1 << weight[e]));
        }
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            siz[u] += siz[v];
            if (son[u] == 0 || siz[son[u]] < siz[v]) {
                son[u] = v;
            }
        }
    }

第三步是统计。维护一个数组 maxdep[x]：当前已经贡献的节点里，eor 值等于 x 的那些节点的最大深度。有了它，一个节点 v 和「已贡献部分」里能配成回文的最长路径就是

长度 = maxdep[eor[v]] + dep[v] − 2 × dep[u]，或者把 eor[v] 翻转某一位之后再查一次，一共 23 种取值。

这里 u 是 LCA。减去 2 × dep[u] 是因为两条前缀在 LCA 之上重复算了两次。maxdep 里存的是深度，深度越大路径越长，所以取 max 是对的。

处理轻儿子的时候有个顺序问题：这个轻儿子的答案要先用「已经贡献的部分」算出来，才能把它自己贡献进去。否则会出现自己和自己配对，算出一条长度为 0 的假路径。所以代码里先 answerFromLight(v, u) 再 effect(v)。

void answerFromLight(int light, int u) {
        if (maxdep[eor[light]] != 0) {
            ans[u] = max(ans[u], maxdep[eor[light]] + dep[light] - dep[u] * 2);
        }
        for (int i = 0; i < MAXV; i++) {
            if (maxdep[eor[light] ^ (1 << i)] != 0) {
                ans[u] = max(ans[u], maxdep[eor[light] ^ (1 << i)] + dep[light] - dep[u] * 2);
            }
        }
        for (int e = head[light]; e > 0; e = nxt[e]) {
            answerFromLight(to[e], u);
        }
    }

dfs2 骨架不变，第 5 步换成四类答案取最大：儿子们已经算好的答案、当前节点和重儿子树上任意一点、当前轻儿子树上任意一点和已贡献部分。

void dfs2(int u, int keep) {
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != son[u]) {
                dfs2(v, 0);
            }
        }
        if (son[u] != 0) {
            dfs2(son[u], 1);
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            ans[u] = max(ans[u], ans[to[e]]);
        }
        if (maxdep[eor[u]] != 0) {
            ans[u] = max(ans[u], maxdep[eor[u]] - dep[u]);
        }
        for (int i = 0; i < MAXV; i++) {
            if (maxdep[eor[u] ^ (1 << i)] != 0) {
                ans[u] = max(ans[u], maxdep[eor[u] ^ (1 << i)] - dep[u]);
            }
        }
        maxdep[eor[u]] = max(maxdep[eor[u]], dep[u]);
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (v != son[u]) {
                answerFromLight(v, u);
                effect(v);
            }
        }
        if (keep == 0) {
            cancel(u);
        }
    }

cancel 只能是整体清零，理由和上一节一样：maxdep 记的是最大值，撤不回去。另外 maxdep 的下标范围是 1 << 22，也就是 419 万个 int，约 16 MB，这在 5 × 10⁵ 的数据范围下是可以接受的。

二、题目7：森林

一共有 n 个节点，编号 1 到 n，初始时给定 m 条边，所有节点可能组成森林结构。每个节点都给定非负的点权，一共有 t 条操作。操作 Q x y k：点 x 到点 y 路径上所有的权值中，打印第 k 小的权值是多少，题目保证 x 和 y 联通并且路径上至少有 k 个点。操作 L x y：点 x 和点 y 之间连接一条边，题目保证操作后所有节点仍然是森林。题目要求强制在线，请不要使用离线算法。1 ≤ n、m、t ≤ 8 × 10⁴，点权 ≤ 10⁹。测试链接：P3302。

树上路径第 k 小是可持久化线段树的经典用法，见可持久化线段树那一讲的题目 4。给每个节点 u 建一个版本 root[u]，存的是「根到 u 这条路径上所有点权的计数」。那么 x 到 y 路径上的点权计数就是四个版本相加减：root[x] + root[y] − root[lca] − root[fa[lca]]。

int insert(int jobi, int l, int r, int i) {
        int rt = ++cntt;
        ls[rt] = ls[i];
        rs[rt] = rs[i];
        siz[rt] = siz[i] + 1;
        if (l < r) {
            int mid = (l + r) / 2;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
        }
        return rt;
    }

有了这四个版本的组合，在线段树上二分就是第 k 小：看左儿子的计数够不够 k，够就往左走，不够就往右走并减去左儿子的计数。

int query(int jobk, int l, int r, int u, int v, int lca_, int lcafa) {
        if (l == r) {
            return l;
        }
        int lsize = siz[ls[u]] + siz[ls[v]] - siz[ls[lca_]] - siz[ls[lcafa]];
        int mid = (l + r) / 2;
        if (lsize >= jobk) {
            return query(jobk, l, mid, ls[u], ls[v], ls[lca_], ls[lcafa]);
        } else {
            return query(jobk - lsize, mid + 1, r, rs[u], rs[v], rs[lca_], rs[lcafa]);
        }
    }

查询时先求 LCA。求 LCA 用的倍增表在 dfs 里顺手填，dep 也在这里算。

int queryKth(int x, int y, int k) {
        int xylca = lca(x, y);
        int lcafa = stjump[xylca][0];
        int i = query(k, 1, diff, root[x], root[y], root[xylca], root[lcafa]);
        return sorted[i];
    }

加边是这一节唯一和「合并」沾边的地方。两棵树要连成一棵，直接把一整棵树重新 dfs 一遍代价是 O(树大小 × log n)。关键的选择是重新 dfs 哪一棵：永远挑小的那棵。这就是开头那个「小集合往大集合里倒」，一个节点每被重新 dfs 一次，它所在的树至少变大一倍，所以每个节点最多被重算 O(log n) 次。

void connect(int x, int y) {
        addEdge(x, y);
        addEdge(y, x);
        int fx = treeHead[x];
        int fy = treeHead[y];
        if (setSiz[fx] >= setSiz[fy]) {
            dfs(y, x, fx);
        } else {
            dfs(x, y, fy);
        }
    }

重新 dfs 的时候，root 版本要接着新父亲往下建，dep 和 stjump 全部重算，treeHead 和 setSiz 也一起更新。

void dfs(int u, int fa, int treeh) {
        root[u] = insert(arr[u], 1, diff, root[fa]);
        dep[u] = dep[fa] + 1;
        treeHead[u] = treeh;
        setSiz[treeh]++;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[ stjump[u][p - 1] ][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if (to[e] != fa) {
                dfs(to[e], u, treeh);
            }
        }
    }

强制在线这一条决定了不能用离线算法。输入里 x、y、k 都是加密过的：真实值 = 读入值 ^ lastAns，lastAns 是上一次查询的答案，初始为 0。加边操作不改 lastAns。

复杂度分析

环节题目6 重排回文题目7 森林第 k 小
预处理dfs1 求 eor、siz、son，O(n)离散化 O(n log n)，初始建树 O(n log n)
dfs2 全部调用O(n log n × 23)不适用
单次查询不需要查询LCA O(log n) + 线段树二分 O(log n)
单次加边不适用O(小树大小 × log n)
加边累计不适用O(n log²n)
空间O(n + 2²²)O(n log n)（主席树 + 倍增表）

题目 6 的 23 是常数：翻转 0 位到 21 位一共 22 种，加上不翻转本身，每次查询 23 次查表。题目 7 的加边累计是 O(n log²n)：每个节点被重算 O(log n) 次，每次重算要在线段树上插入一个点，代价 O(log n)。

最后

四节下来，变化的一直是「信息统计」这四个字：颜色计数、深度桶、异或值的最大深度、可持久化线段树。不变的只有那个六步的 dfs2，和「小集合往大集合里倒」这一个观察。碰到新的子树统计题，先想清楚统计什么、怎么在 O(1) 里加一个点和撤一个点，剩下的往骨架里填就行。
