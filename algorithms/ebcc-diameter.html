边双缩点与树的直径

割边和边双连通分量缩点的模版上一节已经给过了。这一节看缩完点之后能做什么：先把「边双内部什么边都能走到」这条性质讲透，再把「一条路径最多经过多少座桥」变成树上最长路，最后在桥的破坏费用上加一层二分，把直径重新套回答案里。三道题的缩点都是同一段代码，变化的只有缩点之后那几行。

零、背景

边双连通分量是「拆掉任意一条边都还连通」的极大点集。换个说法：分量里任意两点之间都有两条没有公共边的路径。等价地，一条边是桥，当且仅当它不属于任何环；而环上的所有点必然落在同一个边双里。

把每个边双缩成一个点，桥就变成连接这些新点的边。桥一定不在环上，所以缩点之后不会再有环；原图连通时，缩点结果正好是一棵树。

于是「图上的行走问题」常常可以换成「树上的路径问题」。这是这一类题的全部价值所在：图上的环会带来无穷多种走法，缩掉之后只剩下一棵结构简单的树。

一、缩点：从图到树

缩点的模版就是一遍 tarjan 求边双。dfs 时记 dfn 和 low，用栈把当前边双的点攒着，回溯到 dfn[u] == low[u] 时弹栈成一块。

这里有个细节：判断父边要靠边的编号，(e ^ 1) == preEdge，而不是靠父节点。用节点判父边会把重边当成回边，重边本是两条边、能成环，误判之后整块边双就碎掉了。

缩完点，再把原图的每条边接到两端所属的边双上，就得到一棵树。桥的两端一定属于不同的边双，桥也因此成了树边。

二、题目1：追寻文物

无向连通图，每条边除了端点还有一个属性：这条边上有没有商品。给定起点 s 和终点 t，路径怎么走随意，但每条边只能经过一次；问从 s 到 t 的路上能不能碰到商品。

「点可以重复、边不能重复」的路径叫 trail。判断的依据是一条关于边双的结论：在一个边双内部，任意两点 u、v 和任意一条边 e，总存在一条从 u 到 v、并且恰好经过 e 的 trail。

直觉是耳分解。边双可以被拆成一串「耳」，每条边都属于某个环；从 u 出发，沿环绕到 e 的那一侧，穿过 e 再从另一侧绕向 v，因为每一步都还有另一条边兜底，所以总能绕开已经走过的边。

于是做法很直接：把图缩点。s、t 所在的树路径上的每一条树边（也就是桥），只要它有商品就算数；路径上每个边双内部，只要里面有一条带商品的边，也算数。三类信息按或运算合起来，为真打印 YES。

看代码里的 val 数组：某个边双内部的边上有商品时，把 val[边双] 记成 1。dfs 从 s 走到 t，一路把 val[u] 和经过的树边权都或进来，最后看这一路的累加值。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    const int MAXM = 300001;
    int n, m, s, t;
    int a[MAXM];
    int b[MAXM];
    int c[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int weight[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int val[MAXN];
    int ebccCnt;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            int w = c[i];
            if (ebcc1 == ebcc2) {
                if (w == 1) {
                    val[ebcc1] = 1;
                }
            } else {
                addEdge(ebcc1, ebcc2, w);
                addEdge(ebcc2, ebcc1, w);
            }
        }
    }

    bool check(int u, int fa, bool ok) {
        ok |= val[u] > 0;
        if (u == t) {
            return ok;
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa) {
                if (check(v, u, ok || w > 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i] >> c[i];
            addEdge(a[i], b[i], 0);
            addEdge(b[i], a[i], 0);
        }
        tarjan(1, 0);
        condense();
        cin >> s >> t;
        s = belong[s];
        t = belong[t];
        if (check(s, 0, false)) {
            cout << "YES\n";
        } else {
            cout << "NO\n";
        }
        return 0;
    }

三、题目2：最多的桥

无向连通图，边走一次就不能再走。找一条能经过最多桥的路径，打印桥的条数。

缩点之后，桥就是树边。一条路径在缩点树上就是一条简单路径，经过的桥数就是这条路径的边数。要最大化边数，取树的直径即可。

要注意的是，题面只要求「边走一次不能重复」，并没有限制路径本身必须简单。但在树上一个来回会把同一条树边用两次，边就重复了；而边双内部可以任意绕，不影响桥的计数。所以能取到的最多桥数，正是缩点树的直径。

实现是树形 dp：dist[u] 记「从 u 向下、到某个后代的最长桥链」，合并孩子时用两条最长的拼一下更新 diameter。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 300001;
    const int MAXM = 300001;
    int n, m;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int ebccCnt;

    int dist[MAXN];
    int diameter;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2);
                addEdge(ebcc2, ebcc1);
            }
        }
    }

    void dpOnTree(int u, int fa) {
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dpOnTree(v, u);
                diameter = max(diameter, dist[u] + dist[v] + 1);
                dist[u] = max(dist[u], dist[v] + 1);
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
            addEdge(b[i], a[i]);
        }
        tarjan(1, 0);
        condense();
        dpOnTree(1, 0);
        cout << diameter << "\n";
        return 0;
    }

四、题目3：越狱老虎桥

无向连通图，每条边有破坏费用。敌人可以在任意两点之间新增一条不可破坏的边；之后你要只破坏一条边，让图分成两个连通块。敌人的新边端点未知，要按最坏情况准备，问至少准备多少钱；做不到打印 -1。

先缩点。敌人新增一条边 (x, y)，在缩点树上等价于给 x 到 y 的这条树路径加了一条「保护罩」：路径上的桥，即使破坏也不再能断开图。所以能拿来断图的那条边，必须落在路径之外。

最坏情况是敌人把路径选得尽量长，保护掉尽量多的桥。一条路径最多能覆盖的桥数，就是缩点树的直径。于是「能否只用费用不超过 limit 的桥完成任务」的判定是：把费用不超过 limit 的桥看成权 1、其余看成权 0，算出带权直径；只要带权直径小于「权 1 的桥的总数」，就一定有一条权 1 的桥在路径之外。

直径是单调的，桥的总数也是固定的，于是可以二分 limit。注意全是桥、且所有桥正好排在一条直径上时判定永远不成立，答案就是 -1。

从原图走到直径与二分

一个带环、带桥的小图。点「下一步」，看 tarjan 怎么把边双染出来、桥怎么变成树边、直径取哪一条，最后二分判定怎么落在这棵树上。

当前关注的边 / 路径 桥 边双内部（非桥）

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 1000001;
    int n, m, maxv;
    int a[MAXM];
    int b[MAXM];
    int c[MAXM];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int weight[MAXM << 1];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int ebccCnt;

    int dist[MAXN];
    int diameter;
    int edgeCnt;

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void tarjan(int u, int preEdge) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if ((e ^ 1) == preEdge) {
                continue;
            }
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v, e);
                low[u] = min(low[u], low[v]);
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {
            ebccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = ebccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= ebccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int ebcc1 = belong[a[i]];
            int ebcc2 = belong[b[i]];
            int w = c[i];
            if (ebcc1 != ebcc2) {
                addEdge(ebcc1, ebcc2, w);
                addEdge(ebcc2, ebcc1, w);
            }
        }
    }

    void dpOnTree(int u, int fa, int limit) {
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (v != fa) {
                dpOnTree(v, u, limit);
                int w = weight[e] <= limit ? 1 : 0;
                edgeCnt += w;
                diameter = max(diameter, dist[u] + dist[v] + w);
                dist[u] = max(dist[u], dist[v] + w);
            }
        }
    }

    bool check(int limit) {
        for (int i = 1; i <= ebccCnt; i++) {
        	dist[i] = 0;
        }
        diameter = edgeCnt = 0;
        dpOnTree(1, 0, limit);
        return diameter < edgeCnt;
    }

    int compute() {
        int l = 1, r = maxv, mid, ans = -1;
        while (l <= r) {
            mid = (l + r) / 2;
            if (check(mid)) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cntg = 1;
        cin >> n >> m;
        maxv = 0;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i] >> c[i];
            addEdge(a[i], b[i], 0);
            addEdge(b[i], a[i], 0);
            maxv = max(maxv, c[i]);
        }
        tarjan(1, 0);
        condense();
        cout << compute() << "\n";
        return 0;
    }

五、复杂度分析

三道题的缩点都是同一遍 tarjan，线性开销。题目2 的树形 dp、题目3 的一次判定也都是线性的，主要区别在题目3 套了一层二分。

操作时间复杂度空间复杂度
tarjan 求边双 + 缩点O(n + m)O(n + m)
题目1 从 s 走到 t 的分量标记O(n)
题目2 树形 dp 求直径O(n)
题目3 一次判定 / 总复杂度O(n) / O(n log V)

这里 n 指缩点树上的点数，不超过原图点数；V 是边权的最大值，题目3 的二分次数是 log V。邻接表开了两倍边数，栈和 dfn、low 都是点数级别。

六、最后

三道题共用一段缩点模版，剩下的都是树上功夫：或运算标记、树形直径、二分判定。边双缩点本身不难，难的是想清楚缩点之后图上的性质对应到树上是哪句话。

下一节继续往下走，缩点之后要配上 LCA、树上差分和树形 dp，题的规模也上一个台阶。
