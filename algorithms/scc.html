强连通分量与缩点

有向图比无向图难的地方，就在「可达」是单向的。一族点如果彼此都能走到，它们就是一个强连通分量；把每个分量揉成一个点，整张图的环就全没了，剩下一个 DAG。这一节先讲清楚 Tarjan 怎么找分量，再讲缩点之后那些出度入度的基础题。

零、背景

无向图的连通性很直白，能走过去就是连通。有向图不一样，u 能到 v、v 不一定能到 u。于是「互相可达」这个关系才是好用的那一半。

一个强连通分量，简称 SCC，是极大的一族点：族里任意两点 u、v，u 能到 v，v 也能到 u。极大是指再往里加任何一个点，这个性质就破坏了。

单个点也算 SCC，只要它不和其他点互相可达。所以任何有向图都能被拆成若干个 SCC，每个点恰好属于一个。

一、什么是强连通分量

看下面这张图。1、2、3 两两之间绕着圈走，彼此都能到达，是一个 SCC；4、5 也绕着一个圈，是另一个 SCC。3 到 4 有一条边，但 4 回不到 3，所以它们不在同一个分量里。

把每个 SCC 揉成一个点，原来分量内部那些边就消失了。剩下的边只连接不同的分量，而跨分量的边不可能绕回来，否则两个分量就会合成一个。所以缩点后的图没有环。

缩点之后的好处很实在：DAG 上没有环，很多在图上有环时没法定义的东西，一下就清楚了。谁必须先做、谁需要先被满足，全看边指的方向。

要保证答案不变，缩点时必须把同一个分量里所有点看成一个整体。分量内部的点权求和、取最小值、计数，都要在这时候一次性算出来。

二、Tarjan：dfn、low 与栈

求 SCC 的主流办法是 Tarjan。它在一次 dfs 的过程中，用两个数组加一个栈就把所有分量分出来。

dfn[u] 是 u 被访问的时间戳，dfs 到 u 时递增分配。它同时也是 u 在 dfs 树里的深度顺序。

low[u] 的定义要背准：在 u 的子树里，从 u 出发、最多往上走一条回边，能到达的、dfs 树里最靠上的那个点的 dfn 值。换句更直白的话，low[u] 是 u 这棵子树「能倒着爬回多高」。

遍历时还要准备一个栈。每个点第一次被访问就进栈，只有当一个点确定了所属的分量，才会被弹出栈。

dfs 中遇到的边分三种。指向没访问过的点的，是树边，先递归下去；指向栈内点的，是回边，说明绕回了祖先；指向已经出栈的点的，是弃边，说明去的是别的分量，什么都不用做。

看这张图。dfs 的顺序是 1 → 2 → 3 → 4 → 5。3 有一条回边指向 1，所以 3 的子树能爬回 1，low[3] = dfn[1] = 1；2 也跟着变 low[2] = 1。5 有一条回边指向 4，low[5] = dfn[4] = 4，回溯后 low[4] = 4。

代码里对应三句话。遇到树边，先递归再 low[u] = min(low[u], low[v])；遇到回边，low[u] = min(low[u], dfn[v])；遇到弃边，跳过。

三、扎口袋：什么时候弹栈

dfs 完 u 的所有出边之后，比较 dfn[u] 和 low[u]。两者相等，说明 u 的子树里没有任何一条回边能爬到 u 的上面去，u 就是这个分量的「根」，于是把栈顶一路弹到 u 为止，这批点构成一个分量。

不等就说明 u 上面还有祖先在兼容它，这时候不能弹，把 low 继续往回传。

这个过程很像扎口袋：dfs 一路向下，把点按顺序塞进栈；能爬回去的分量要等到爬不动的那个根出现，口袋才在根这里扎紧，一次性倒出来。

回边那一步有个流传很广的疑问：到底写 low[u] = min(low[u], dfn[v])，还是 low[u] = min(low[u], low[v])？两种写法的运行结果都对。推荐第一种，因为它忠实于 low 的定义，low 记的是爬回某个祖先的 dfn；用 low[v] 会把「爬回祖先」和「爬回某个更深的后代」混在一起，让 low 的含义变模糊。

还有两个细节。访问每个点之前要先判 dfn 是否为 0，没访问过才从这里起一次 dfs，因为图不一定连通。另外，回边只对「还在栈里」的点生效，所以判断条件里要写 belong[v] == 0，把已经出栈的弃边挡掉。

Tarjan 在这个图上跑一遍

点「下一步」，按 dfs 顺序走：看每个点的 dfn、low 怎么定，栈怎么进，最后在哪两个地方扎口袋。

四、缩点

有了 belong 数组，缩点就是一件笨活：把每个分量看成一个新点，原来是 1 到 sccCnt 的编号，直接拿来用。原图里每条边 u → v，如果 belong[u] 和 belong[v] 不同，就在缩点图上连一条 belong[u] → belong[v] 的边。

连完之后缩点图一定没有环。如果它还有环，环上那些分量之间彼此可达，早就该被合并成一个分量了，矛盾。

接下来多数题的套路都一样：先 tarjan 求分量，把每个分量的信息（点权之和、最小值、计数）算出来，再扫一遍原边统计缩点图上的入度和出度。

五、题目1：强连通分量模版题1

n 个点 m 条边的有向图，要求打印分量个数；然后按 1 号点、2 号点……的顺序，打印每个点所在的分量，同一个分量只打印一次，每行内节点编号从小到大。

「同一个分量只打印一次」这句话，等于让我们输出分量的节点集合，而且按分量里最小点在原序列中的位置排序。做法是 tarjan 弹栈时把点依次记进一个数组，同时记下每个分量的左右下标；输出时按节点编号 1 到 n 扫一遍，遇到新分量就把它那一段排序后打印。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 100001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccArr[MAXN];
    int sccl[MAXN];
    int sccr[MAXN];
    int idx;
    int sccCnt;

    bool sccPrint[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            sccl[sccCnt] = idx + 1;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccArr[++idx] = pop;
            } while (pop != u);
            sccr[sccCnt] = idx;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        cout << sccCnt << "\n";
        for (int i = 1; i <= sccCnt; i++) {
            sort(sccArr + sccl[i], sccArr + sccr[i] + 1);
        }
        for (int i = 1; i <= n; i++) {
            int scc = belong[i];
            if (!sccPrint[scc]) {
                sccPrint[scc] = true;
                for (int j = sccl[scc]; j <= sccr[scc]; j++) {
                    cout << sccArr[j] << " ";
                }
                cout << "\n";
            }
        }
        return 0;
    }

六、题目2：强连通分量模版题2

同样求所有分量，只是输出换成了「先打印分量大小，再打印分量的点」，点的顺序任意。

因为顺序不再有要求，就不必维护 sccArr 那套左右下标，弹栈时直接把 size 累加、点排在第几段里顺手记下即可。代码比题 1 短一截，是更常见的模版形态。

七、题目3：强连通分量模版题3

n 个点 m 条边，边带类型：t 为 1 是 a 到 b 的单向边，t 为 2 是双向边。求最大的分量，先打印大小，再按编号从小到大打印节点；若有多个同样大的分量，取字典序最小的那个。

双向边就是正反两条有向边，建图时照着连即可，其余照旧。找最大分量靠一遍 sccSiz。字典序最小的处理有个小技巧：按节点编号从小到大扫，第一个落在最大分量里的点，它所在的分量就是字典序最小的，因为比较字典序看的正是最小节点。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 5001;
    const int MAXM = 100001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccSiz[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccSiz[sccCnt]++;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, a, b, t; i <= m; i++) {
            cin >> a >> b >> t;
            if (t == 1) {
                addEdge(a, b);
            } else {
                addEdge(a, b);
                addEdge(b, a);
            }
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        int largest = 0;
        for (int i = 1; i <= sccCnt; i++) {
            largest = max(largest, sccSiz[i]);
        }
        cout << largest << "\n";
        for (int i = 1; i <= n; i++) {
            if (sccSiz[belong[i]] == largest) {
                int scc = belong[i];
                for (int j = i; j <= n; j++) {
                    if (belong[j] == scc) {
                        cout << j << " ";
                    }
                }
                break;
            }
        }
        cout << "\n";
        return 0;
    }

八、复杂度分析

三道题都是纯模版，一遍 tarjan 加一遍收尾扫描，没有额外的数据结构。

操作时间复杂度空间复杂度
tarjan 求所有强连通分量O(n + m)O(n + m)（链式前向星 + dfn/low/栈/belong 各一个数组）
题目1 打印（含每段排序）O(n log n) 最坏
题目2 / 题目3 收尾扫描O(n + m)

tarjan 里每个点进栈出栈各一次，每条边只看一次，所以主体是线性的。题目1 要给每个分量的节点排序，最坏是 O(n log n)，注意题目保证 n 到 10⁴ 所以排序不吃紧。递归深度最坏是 n 层，n 到 10⁴ 时栈空间够用；如果 n 更大，就得把 dfs 改成迭代版。

九、最后

这一节的核心只有一件事：Tarjan 用一次 dfs 求出所有分量，靠的是 dfn 记时间、low 记能爬回多高、栈记还没归属的点。dfn 等于 low 的地方就是分量的根。

真正的题目不会只让你数分量，而是缩点之后在 DAG 上做题。下一节把出度入度、点权、拓扑这几类基础题逐个过一遍，看缩点之后每道题到底在看哪个量。
