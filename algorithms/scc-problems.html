缩点基础应用

上一节把 Tarjan 和缩点讲完，这一节看它能解什么题。七道题分成三堆：数出度入度的、在分量上取点权的、以及缩点之后再做一次判定的。真正要背的不是代码，而是「题目里问的那句话，对应到缩点图上是哪个量」。

零、背景

缩点之后得到一张没有环的图。DAG 上有些东西天生就好用：谁没有入边，谁只能被别人指着；谁没有出边，谁走不到别处。

再加上每个分量本身是一个整体，分量内部的点权可以预先合并成一个值。这两件事合起来，就能覆盖这一节所有的题。

先把三种套路各自叫个名字。数度数的题，答案往往就是「入度为 0 的分量有几个」或者「出度为 0 的分量有几个」。点权的题，是把分量内的点权合成一个最小值。判定的题，是在缩点图上再跑一遍拓扑或者再做一次可达性判断。

一、数出度：受欢迎的牛

n 只牛两两之间有喜欢关系，喜欢是有向可传递的，每只牛都算喜欢自己。如果一头牛被所有牛喜欢，它就是明星，问明星有几头。

「被所有牛喜欢」翻译成图的语言，就是从任意一头牛出发都能走到它。缩点之后，这个问题变成：有没有哪个分量，所有分量都能到达它。

在 DAG 上，能到达所有分量的，只可能是出度为 0 的分量。反过来，如果出度为 0 的分量只有一个，那它就是所有分量的汇，所有点都能走到它。所以判据很简单：出度为 0 的分量恰好一个，答案是它的大小；有零个或两个以上，答案是 0。

实现上，扫一遍原图的每条边，如果两端 belong 不同，就给 belong[u] 的出度加一。然后数出度为 0 的分量个数，顺便记下那个分量的 size。

为什么只看跨分量的边？因为分量内部的边缩点之后就不存在了；它们不产生出度。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 50001;
    int n, m;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccSiz[MAXN];
    int sccCnt;

    int outdegree[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                sccSiz[sccCnt]++;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 != scc2) {
                outdegree[scc1]++;
            }
        }
        int num = 0, siz = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (outdegree[i] == 0) {
                num++;
                siz = sccSiz[i];
            }
            if (num > 1) {
                siz = 0;
                break;
            }
        }
        cout << siz << "\n";
        return 0;
    }

二、数入度：消息扩散

n 个城市 m 条单向道路，每条路可以把消息顺着方向传下去。至少要在几个城市发布消息，才能让所有城市都收到。

一个分量内部互相可达，只要有一个城市收到消息，整个分量都收到了。所以问题落在缩点图上：从哪些分量出发，能覆盖所有分量。

入度为 0 的分量，没有任何别的分量能给它传消息，只能自己发一次。而每一个入度不为 0 的分量，都能从某个入度为 0 的分量顺着边走过来。所以答案就是入度为 0 的分量个数。

实现和上一题对称，扫原边统计的是入度。

三、数入度出度：校园网络

n 个节点 m 条有向边，问两件事。第一，至少在哪几个节点投放消息，才能让所有节点收到，这题的答案是入度为 0 的分量个数，和消息扩散一样。第二，至少加几条边，才能让任意两个节点之间都能互相传递消息，也就是让整张图强连通。

第二问要动脑。缩点之后，图是 DAG。要让 DAG 强连通，必须把每个源（入度为 0）和每个汇（出度为 0）都接上。

设入度为 0 的分量有 in0 个，出度为 0 的有 out0 个。把汇连到源，一条边就能同时补掉一个汇和一个源，所以答案是 max(in0, out0)。如果缩点后只剩一个分量，图本来就强连通，答案是 0。

第一问在这种情形下仍要输出 1，因为至少得有人发出第一条消息。

这题输入格式特殊：先读 n，然后每个点读一行，行内以 0 结尾。建图时边数 m 是边读边累加的。

四、缩点点权：间谍网络

n 个间谍里只有 p 个可以贿赂，各自有价格，其余价格当成无穷大。控制关系是单向可传递的：贿赂一个间谍，他和所有他能控制的人都归你。如果控制不了所有人，输出 NO 和无法控制的人里最小编号；否则输出 YES 和最少花费。

先看能不能控制所有人。能贿赂的间谍是起点，从他们出发 dfs 一遍，如果有点没被访问到，那这些点就是控制不了的，输出其中最小编号即可。

能控制所有人时，缩点。一个分量只要里面有一个间谍被贿赂，整个分量就到手了；取分量内最便宜的那个价格当这个分量的代价。

哪些分量非买不可？入度为 0 的那些。因为没有别的分量能控制它，只能从它内部买一个。入度不为 0 的分量，一定有个前驱能控制它。所以答案是所有入度为 0 的分量的代价之和。

实现时用 cost 数组给不可贿赂的点标上「无穷大」，只从能贿赂的点起 tarjan。这样跑完后 belong 为 0 的点，就是控制不到的，最小的那个编号就是答案的后半段。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 3001;
    const int MAXM = 8001;
    const int INF = 1000000001;
    int n, p, m;

    int cost[MAXN];
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int minVal[MAXN];
    int sccCnt;

    int indegree[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            minVal[sccCnt] = INF;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                minVal[sccCnt] = min(minVal[sccCnt], cost[pop]);
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> p;
        for (int i = 1; i <= n; i++) {
            cost[i] = INF;
        }
        for (int i = 1, u, c; i <= p; i++) {
            cin >> u >> c;
            cost[u] = c;
        }
        cin >> m;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge(a[i], b[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (cost[i] != INF && dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == 0) {
                check = false;
                ans = i;
                break;
            }
        }
        if (!check) {
            cout << "NO" << "\n";
            cout << ans << "\n";
        } else {
            for (int i = 1; i <= m; i++) {
                int scc1 = belong[a[i]];
                int scc2 = belong[b[i]];
                if (scc1 != scc2) {
                    indegree[scc2]++;
                }
            }
            for (int i = 1; i <= sccCnt; i++) {
                if (indegree[i] == 0) {
                    ans += minVal[i];
                }
            }
            cout << "YES" << "\n";
            cout << ans << "\n";
        }
        return 0;
    }

五、缩点点权：检查站

n 个点 m 条边的有向图，每个点有点权。要放若干个检查站，让所有点都被控制。控制只在一个分量内部生效：分量里选了某个点，整个分量都被控制。要求最小点权和，以及方案数对 1000000007 取模。

「控制只在一个分量内部生效」是关键。分量之间不互相帮忙，所以每一个分量都要放一个检查站。

同一个分量里，选权值最小的点最划算。如果有多个点并列最小，选哪个都对，方案数就多几种。所以答案是所有分量的最小点权之和，方案数是每个分量里最小点权点数的乘积。

实现上，tarjan 弹栈时顺手更新分量内的最小点权和它的出现次数，收尾时把 minVal 加起来、把 minCnt 乘起来即可。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    const int MAXM = 300001;
    const int MOD = 1000000007;
    int n, m;
    int val[MAXN];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int minVal[MAXN];
    int minCnt[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            minVal[sccCnt] = 1000000001;
            minCnt[sccCnt] = 0;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
                if (minVal[sccCnt] > val[pop]) {
                    minVal[sccCnt] = val[pop];
                    minCnt[sccCnt] = 1;
                } else if (minVal[sccCnt] == val[pop]) {
                    minCnt[sccCnt]++;
                }
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> val[i];
        }
        cin >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, v);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        long long ans1 = 0, ans2 = 1;
        for (int i = 1; i <= sccCnt; i++) {
            ans1 += minVal[i];
            ans2 = (ans2 * minCnt[i]) % MOD;
        }
        cout << ans1 << " " << ans2 << "\n";
        return 0;
    }

六、判定：任意两点都有路

给定有向图，问是否任意两点都有路，这里的「有路」指至少一个方向能到。

缩点之后，问题变成：缩点图能不能被串成一条链。因为只有链上任意两点都是先后关系，才满足至少一个方向可达。

判定的办法是拓扑排序。每次取入度为 0 的点，如果某一刻可选的点超过一个，说明出现了两个互不可达的分支，答案是 No。整个过程中队列里始终只有一个点，就是 Yes。

这个条件等价于缩点图的拓扑序唯一。唯一拓扑序本身就说明没有并列可选的分支。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 1001;
    const int MAXM = 6001;
    int t, n, m;
    int a[MAXM];
    int b[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    int indegree[MAXN];
    int que[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    void condense() {
        cntg = 0;
        for (int i = 1; i <= sccCnt; i++) {
            head[i] = 0;
        }
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]];
            int scc2 = belong[b[i]];
            if (scc1 != scc2) {
                indegree[scc2]++;
                addEdge(scc1, scc2);
            }
        }
    }

    bool topo() {
        int l = 1, r = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (indegree[i] == 0) {
                que[++r] = i;
            }
        }
        while (l <= r) {
            int siz = r - l + 1;
            if (siz > 1) {
                return false;
            }
            int u = que[l++];
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                if (--indegree[v] == 0) {
                    que[++r] = v;
                }
            }
        }
        return true;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n >> m;
            cntg = cntd = sccCnt = 0;
            top = 0;
            for (int i = 1; i <= n; i++) {
                head[i] = dfn[i] = belong[i] = indegree[i] = 0;
            }
            for (int i = 1; i <= m; i++) {
                cin >> a[i] >> b[i];
                addEdge(a[i], b[i]);
            }
            for (int i = 1; i <= n; i++) {
                if (dfn[i] == 0) {
                    tarjan(i);
                }
            }
            condense();
            bool ans = topo();
            cout << (ans ? "Yes" : "No") << "\n";
        }
        return 0;
    }

七、巧妙建图：稳定婚姻

n 对夫妻，每对给出女名男名；还有 m 对暧昧关系，也给出女名男名，名字都在已知的人里。如果一对夫妻之间的婚姻破裂，涉事的男女能通过一系列私奔重新搭配，这对夫妻就是不稳定的，输出 Unsafe，否则 Safe。

把这件事画成有向图：婚姻关系连一条从女方到男方的边，暧昧关系连一条从男方到女方的边。为什么这么连？从一段婚姻出发，走到男方；男方可以顺着暧昧边走到别的女方；那个女方又顺着婚姻边走到她的丈夫。一条这样的路径，就是一串连锁的私奔。

于是一对夫妻不稳定，等价于这对夫妻的两个点互相可达，也就是落在同一个强连通分量里。因为那样就能绕一圈回到起点，把所有涉事的人都卷进来重新搭配。

实现时用哈希表把名字映射成编号，每对夫妻占两个编号。建完图跑一遍 tarjan，检查每一对夫妻的两个点 belong 是否相同。

完整代码：

    
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 10001;
    const int MAXM = 30001;
    int n, m;

    int a[MAXN];
    int b[MAXN];
    int cntn;
    unordered_map<string, int> nameId;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        string girl, boy;
        for (int i = 1; i <= n; i++) {
            cin >> girl >> boy;
            a[i] = ++cntn;
            b[i] = ++cntn;
            nameId[girl] = a[i];
            nameId[boy] = b[i];
            addEdge(a[i], b[i]);
        }
        cin >> m;
        for (int i = 1; i <= m; i++) {
            cin >> girl >> boy;
            addEdge(nameId[boy], nameId[girl]);
        }
        for (int i = 1; i <= cntn; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        for (int i = 1; i <= n; i++) {
            if (belong[a[i]] == belong[b[i]]) {
                cout << "Unsafe" << "\n";
            } else {
                cout << "Safe" << "\n";
            }
        }
        return 0;
    }

八、复杂度分析

七道题都是「一遍 tarjan 缩点 + 一遍线性收尾」，除了稳定婚姻要多一次哈希映射，其余没有额外的对数或根号。

操作时间复杂度空间复杂度
tarjan 求强连通分量 + 缩点O(n + m)O(n + m)（链式前向星 + dfn/low/栈/belong/度数各一个数组；稳定婚姻多一张哈希表）
题目4 / 5 / 6 统计入度出度O(n + m)
题目7 / 8 缩点点权合并O(n + m)
题目9 缩点图上拓扑排序O(n + m)
题目10 建图（unordered_map 映射名字）O((n + m)) 期望

度数统计都只扫一遍原边，每条边最多让一个分量的入度或出度加一，所以和 n、m 同阶。稳定婚姻的哈希表最坏单次是 O(n)，用 unordered_map 时期望 O(1)，整体期望线性。递归深度最坏是 n 层，题目里的 n 到 10⁵ 时需要留意系统栈，必要时把 dfs 改成迭代版。

九、最后

这一节七道题，回头看只有三种动作：数缩点图上的入度出度、把分量内的点权合成一个值、在缩点图上再跑一次拓扑或可达性判定。题目怎么包装，落到图上都是这三种之一。

缩点本身只是把环压平。下一讲把这个工具接上拓扑排序、动态规划、最短路、树上背包和差分约束，让它去解更难的题。
