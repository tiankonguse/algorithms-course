加限制的 LCS：把答案当状态

n ≤ 1e6、m ≤ 1e3 的最长公共子序列，经典 O(nm) 要开 1e9 格，跑不动。把「s2 前缀匹配出多长的公共子序列」当成状态，状态数只跟 m 有关，复杂度就压到 O(26n + m²)。

零、背景

经典 LCS 的 dp[i][j] 是「s1 前 i 个、s2 前 j 个的最长公共子序列长度」，状态 n×m，每个 O(1)，总 O(nm)。n = 1e5、m = 1e3 时已经实测 529ms，n 放大到 1e6 就是 5.3 秒量级，必然超时。

数据不对称：n 巨大、m 只有 1e3。理想复杂度要挂在 m 上，n×m 的乘法项得整个消失。

一、换状态：把长度当值

定义 f(i, j)：用 s2 的前 i 个字符，凑出一个长度为 j 的公共子序列，s1 至少需要多长的前缀。凑不出来记 NA。

两个下标 i、j 都不超过 m，状态一共 m² 个。答案是最大的 j，使 f(m, j) ≠ NA。跟经典表比，这里把「长度」从答案挪进了状态，把「s1 用掉多少」从下标挪成了值。

二、next 表：从位置跳到位置

转移里需要「在 s1 的某个位置之后，字符 c 第一次出现在哪」。预处理好 nxt[i][c]：s1 中第一个位置大于 i 的字符 c 的位置，找不到是 NA。从右往左扫一遍就能填，O(26n)。

s1 = abcde 时 nxt[0][a] = 1、nxt[0][c] = 3、nxt[1][c] = 3、nxt[3][e] = 5，位置都是 1-based。

三、转移：用或不用 s2[i−1]

f(i, j) 的两条路：不用 s2 的第 i 个字符，f(i−1, j)；用它，先看 f(i−1, j−1) = pre 需要多长的 s1 前缀，再在 pre 之后找 s2[i−1] 第一次出现的位置，即 nxt[pre][s2[i−1]]。

f(i, j) = min(f(i−1, j), nxt[f(i−1, j−1)][s2[i−1]])。边界：j = 0 时返回 0，i < j 时不可能，返回 NA。每格 O(1)，总 O(m²)。

s1 = abcde、s2 = ace 时：f(2, 2) = 3（s2 前缀 ac 凑出长度 2 的子序列，s1 前缀 3 就够：a 在 1、c 在 3）；f(3, 3) = 5（再加 e 在 5）。答案 3。

f(i, j) 表：s2 = ace，逐格填

四、复杂度与局限

build 一次 O(26n)，之后每个状态 O(1)，总 O(26n + m²)。空间上 nxt 是 (n+1)×26，memo 是 m×m。这招成立的条件是 m 真的小：状态数 m² 若 m 也到 1e5，一样爆。它是「把复杂度从 n×m 挪到 m²」的典型，前提是 n 大、m 小。

经典版和优化版：

#include <bits/stdc++.h>
    using namespace std;

    // 经典 LCS：O(n * m)，n、m 都大时跑不动
    int lcs1(const string& s1, const string& s2) {
        int n = s1.size(), m = s2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (s1[i - 1] == s2[j - 1]) {
                    dp[i][j] = 1 + dp[i - 1][j - 1];
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m];
    }
#include <bits/stdc++.h>
    using namespace std;

    const int MAXN = 1000005;
    const int MAXM = 1005;

    // 优化版：O(26 * n + m * m)
    // nxt[i][c]：s1 中第一个位置大于 i 的字符 c 的位置，找不到为 NA
    int nxt[MAXN][26];
    int last[26];
    int memo[MAXM][MAXM];           // f(i, j) 的记忆化表
    const int NA = INT_MAX / 4;

    void build(const string& s1) {
        for (int j = 0; j < 26; j++) {
            last[j] = NA;
        }
        int n = s1.size();
        for (int i = n; i >= 0; i--) {
            for (int j = 0; j < 26; j++) {
                nxt[i][j] = last[j];        // i 之后第一个 j，来自右边已扫到的
            }
            if (i > 0) {
                last[s1[i - 1] - 'a'] = i; // 1-based 位置
            }
        }
    }

    // s2 的前缀（长度 i）想和 s1 形成长度 j 的公共子序列
    // 返回至少需要多长的 s1 前缀，做不到返回 NA
    int f(int i, int j, const string& s2) {
        if (i < j) {
            return NA;
        }
        if (j == 0) {
            return 0;
        }
        if (memo[i][j] != -1) {
            return memo[i][j];
        }
        int ans = f(i - 1, j, s2);              // 不匹配 s2 的第 i 个字符
        int pre = f(i - 1, j - 1, s2);          // 先匹配前 j-1 个
        if (pre != NA) {
            int cha = s2[i - 1] - 'a';
            ans = min(ans, nxt[pre][cha]);      // 在 pre 之后找 s2[i-1]
        }
        return memo[i][j] = ans;
    }
