双单调队列：窗口里的最大和最小

约束长成「窗口内 max − min ≤ limit」或「max − min ≥ d」时，窗口同时要最大值和最小值。开两个单调队列：一个队头是最大，一个队头是最小，互不干扰。这一页的两道题共用同一副双队列骨架，一求最长一求最短。

零、背景

上一页的队列只维护最大值。约束一旦变成「任意两数差 ≤ limit」，光有最大值不够：窗口的最小值也得出窗口就作废。开两个队列，maxDeque 队内大→小（队头最大），minDeque 队内小→大（队头最小），入队弹出、过期检查的规则一模一样，只是比较方向反过来。

一、题 2：绝对差不超过限制的最长连续子数组（LeetCode 1438）

窗口 [l, r)，r 永远是下一个还没进窗口的位置。ok(limit, number) 先算 number 进来后的 max 和 min：max 取「maxDeque 队头的值」和 number 的较大者，min 同理取较小者，差 ≤ limit 就放行。

外层循环 l 从 0 到 n−1：能进就进（while r < n 且 ok 就 push(r++)），窗口 [l, r) 就是 l 开头能延伸到的最远处，ans 取 r − l，然后 pop(l)。

为什么 l 只进不退：l 右移窗口变小，max − min 只减不增，已经满足 ≤ limit 的窗口不会因为变小而不满足。所以对每个 l 直接扩到极限就是最优。

两个错法：ok() 里 max 取了 maxDeque 的队尾（队尾是最小值），随机数据只有 6.61% 算错，多数时候队尾恰好等于队头或 number 兜底，这个错非常隐蔽；忘掉 pop(l)，过期的最大或最小还在队列里当队头，60.64% 算错。

实测 n=1e6、limit=5000 的随机数组 5.3ms。暴力的朴素做法（枚举子数组扫 max/min）是 O(n³)，n=1000 就要 8ms。

二、题 3：接取落水的最小花盆（洛谷 P2698）

水滴坐标 (x, y)，y 是高度，下落速度每秒 1 单位，所以从 y 落到 x 轴要 y 秒。花盆接住的第一滴和最后一滴之间的时间差就是窗口里 y 的最大值减最小值。题目要求时间差 ≥ D，等价于窗口内 max(y) − min(y) ≥ d。

先把水滴按 x 排序，窗口就是排序后的一段连续区间，宽度是两端 x 之差。双队列照旧维护 y 的 max 和 min。

题 2 和题 3 的骨架几乎一样，只有两处不同：ok() 的判断方向反了（题 2 是 ≤ limit 才放行，题 3 是 ≥ d 才达标），求的窗口一个是「最长」一个是「最短」，所以题 2 扩到不满足为止、题 3 扩到满足为止。

三个错法，随机数据下的抓取率：ok() 的方向写反（≥ d 写成 ≤ d）99.95%；忘掉 pop 94.83%；更新宽度时用 drops[r] 而不是 drops[r−1]（r 是还没进窗口的下一个）94.83%。

无解返回 −1（单滴水或者所有水滴高度差都够不到 d）。实测 n=1e6 随机坐标 58ms，含一次排序。

三、代码

题 2：

struct DoubleQueue {
        vector<int> maxDeque, minDeque;   // 都存下标
        int maxh, maxt, minh, mint;
        vector<int>* arr;

        // number 进来后 max - min 是否仍 <= limit
        bool ok(int limit, int number) {
            int maxv = maxh < maxt ? max((*arr)[maxDeque[maxh]], number) : number;
            int minv = minh < mint ? min((*arr)[minDeque[minh]], number) : number;
            return maxv - minv <= limit;
        }
        void push(int r) {
            while (maxh < maxt && (*arr)[maxDeque[maxt - 1]] <= (*arr)[r]) maxt--;
            maxDeque[maxt++] = r;
            while (minh < mint && (*arr)[minDeque[mint - 1]] >= (*arr)[r]) mint--;
            minDeque[mint++] = r;
        }
        void pop(int l) {
            if (maxh < maxt && maxDeque[maxh] == l) maxh++;
            if (minh < mint && minDeque[minh] == l) minh++;
        }
    };

    int LongestSubarray(vector<int>& nums, int limit) {
        int n = (int)nums.size();
        DoubleQueue dq(n);
        dq.arr = &nums;
        int ans = 0;
        for (int l = 0, r = 0; l < n; l++) {
            while (r < n && dq.ok(limit, nums[r])) dq.push(r++);
            ans = max(ans, r - l);
            dq.pop(l);
        }
        return ans;
    }

题 3：

struct DoubleQueueY {
        vector<int> maxDeque, minDeque;
        int maxh, maxt, minh, mint;
        vector<pair<int, int>>* arr;   // (x, 高度)

        bool okD(int d) {
            int maxv = maxh < maxt ? (*arr)[maxDeque[maxh]].second : 0;
            int minv = minh < mint ? (*arr)[minDeque[minh]].second : 0;
            return maxv - minv >= d;
        }
        void push(int r) {
            while (maxh < maxt && (*arr)[maxDeque[maxt - 1]].second <= (*arr)[r].second) maxt--;
            maxDeque[maxt++] = r;
            while (minh < mint && (*arr)[minDeque[mint - 1]].second >= (*arr)[r].second) mint--;
            minDeque[mint++] = r;
        }
        void pop(int l) {
            if (maxh < maxt && maxDeque[maxh] == l) maxh++;
            if (minh < mint && minDeque[minh] == l) minh++;
        }
    };

    int SmallestFlowerPot(vector<pair<int, int>>& drops, int d) {
        int n = (int)drops.size();
        sort(drops.begin(), drops.end());
        DoubleQueueY dq(n);
        dq.arr = &drops;
        int ans = INT_MAX;
        for (int l = 0, r = 0; l < n; l++) {
            while (!dq.okD(d) && r < n) dq.push(r++);
            if (dq.okD(d)) {
                ans = min(ans, drops[r - 1].first - drops[l].first);
            }
            dq.pop(l);
        }
        return ans == INT_MAX ? -1 : ans;
    }

总结

双单调队列 = 单队列重复两次，一次大→小一次小→大。题 2 和题 3 验证了两个使用方向：约束 ≤ limit 求最长时扩到不满足，约束 ≥ d 求最短时扩到满足。骨架、入队、过期检查全一样，只有 ok() 的方向和答案的取法不同。

单调队列还能跟动态规划结合（窗口内最值做转移），那是【扩展】课程的内容。下一讲单调队列-下会介绍它的其他用法。
