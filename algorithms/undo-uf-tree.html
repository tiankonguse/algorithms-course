可撤销并查集与树上回溯

不要任意版本，只要能退回上一步，那就用不着可持久化数组了。合并时把改动压进一个栈，撤销时弹出来还原。这一节用它做树上路径的增量维护。

零、从可持久化退一步

上一节的结构能回答「第 x 号版本长什么样」，代价是每次修改都要造 O(log n) 个节点。很多场合不需要这么强：操作序列是深度优先的，撤销的一定是最后一次改动。

这时只要一个栈。合并时把「谁挂到了谁下面」记进 rollback，撤销时取出这条记录，把 father 和 siz 改回去。撤销是 O(1)，也不用建线段树。

前提是仍然不做路径压缩。压缩会在一次 find 里改多个 father，栈里就得记多条记录，而且记录的数量不可控。保留小挂大，一次合并只动两个位置，栈里只压一条。

一、题目2：Ball Collector

有一棵 n 个点的树，第 i 个点上放着编号为 Aᵢ 和 Bᵢ 的两个小球。对每个 v = 2 到 n，各自独立地问：从 1 号点沿最短路走到 v，路径上每个点取走一个球，取到的编号最多能有几种。1 ≤ Aᵢ、Bᵢ ≤ n ≤ 2 × 10⁵。测试链接：AT_abc302_h、ABC302 Ex。

二、固定一条路径时怎么算

把球编号看成图的点，路径上第 i 个点给出一条边 (Aᵢ, Bᵢ)。每个树点只能取一个球，也就是每条边只能选一个端点。问题变成：这个图里最多能选出多少个不同的点。

于是答案是每个连通块 min(点数, 边数) 的总和。块是树时边数 = 点数 − 1，块里有环时边数 ≥ 点数。

三、路径是嵌套的，加边删边天然成栈

把 1 号点当根做深度优先遍历。进入点 u 时把边 (Aᵤ, Bᵤ) 加进并查集，此时并查集里正好是根到 u 这条路径上的全部边，ans[u] 直接读出来。回溯时把这条边删掉。

删的一定是最后加的那条，这正是栈的顺序。所以并查集只要支持「撤销上一次合并」，也就是可撤销并查集。

四、维护什么，怎么撤销

并查集里除了 father 和 siz，多存一个 edgeCnt：每个集合头记下这个块里有多少条边。合并两个块时，边数是两边之和再加 1（新加的这条）。

答案 ball 也是增量维护的。进入点 u 时，若两个球已经在同一块，先看 edgeCnt 是否小于 siz，是就 ball 加 1，然后 edgeCnt 加 1；若在两个块里，只要有一个块满足 edgeCnt < siz 就 ball 加 1，然后合并。可以发现 ball 始终等于所有块 min(点数, 边数) 的和。

撤销要分两种。做过 Union 的，弹栈还原 father、siz、edgeCnt；没做 Union（两个球同块）的，只是 edgeCnt 加了 1，手动减回去。ball 加过的也要减回去。代码里用两个 bool 记住这次到底干了什么。

int find(int i) {
    	while(i != father[i]) {
    		i = father[i];
    	}
    	return i;
    }

    void Union(int x, int y) {
        int fx = find(x);
        int fy = find(y);
        if (siz[fx] < siz[fy]) {
            int tmp = fx;
            fx = fy;
            fy = tmp;
        }
        father[fy] = fx;
        siz[fx] += siz[fy];
        edgeCnt[fx] += edgeCnt[fy] + 1;
        rollback[++opsize][0] = fx;
        rollback[opsize][1] = fy;
    }

    void undo() {
        int fx = rollback[opsize][0];
        int fy = rollback[opsize--][1];
        father[fy] = fy;
        siz[fx] -= siz[fy];
        edgeCnt[fx] -= edgeCnt[fy] + 1;
    }

Union 把小的挂到大的下面，栈里只记 (fx, fy) 这一对：撤销时 father[fy] = fy、siz[fx] 减回去、edgeCnt[fx] 减回去。注意 fy 在撤销前已经被改过，siz[fy] 和 edgeCnt[fy] 却没被动过，所以还原是干净的。

void dfs(int u, int fa) {
        int fx = find(arr[u][0]);
        int fy = find(arr[u][1]);
        bool added = false;
        bool unioned = false;
        if (fx == fy) {
            if (edgeCnt[fx] < siz[fx]) {
                ball++;
                added = true;
            }
            edgeCnt[fx]++;
        } else {
            if (edgeCnt[fx] < siz[fx]|| edgeCnt[fy] < siz[fy]) {
                ball++;
                added = true;
            }
            Union(fx, fy);
            unioned = true;
        }
        ans[u] = ball;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            if (to[e] != fa) {
                dfs(to[e], u);
            }
        }
        if (added) {
            ball--;
        }
        if (unioned) {
            undo();
        } else {
            edgeCnt[fx]--;
        }
    }

复杂度分析

每个树点进入一次、回溯一次。一次 find 沿链跳 O(log n) 层，加上一次合并或一次撤销的常数操作。

操作时间说明
findO(log n)不压缩，只靠小挂大，树高 ≤ log₂ n
UnionO(log n)两次 find 加常数次改值，压一条记录
undoO(1)弹一条记录，改回 father、siz、edgeCnt
总体O(n log n)n 个点各进出一次
空间O(n)father、siz、edgeCnt 各 n 个，栈最多 n 条

代码里的 rollback 栈开的是 int[MAXN][2]，因为每个点最多贡献一次合并，栈深不超过 n。这里没有递归爆栈问题之外的额外开销，n = 2 × 10⁵ 时递归深度也是 O(n)，实际提交要注意栈空间。

最后

这里的撤销是被动的：dfs 的回溯顺序决定了撤销顺序。下一节看另一种用法，按权值把边分好组，一组之内临时加边、判定、再整组撤销，撤销的时机由我们自己安排。
