裴蜀定理：最小正组合就是 gcd

给定 a、b，所有 ax+by（x、y 取任意整数）能凑出的最小正数是多少？答案不是 min(a,b)，也不是 |a−b|，而是 gcd(a,b)，而且能凑出的数恰好是 gcd 的所有倍数。

零、背景

a=6、b=10 时试几个组合：6·2+10·0=12、6·(−3)+10·2=2、6·1+10·1=16。能凑出的最小正数是 2，能凑出的数全是偶数。2 正好是 gcd(6,10)，偶数正好是 2 的倍数，这条规律就是裴蜀定理。

直觉上「最小正组合」像是要枚举 x、y，实际上它被 gcd 一个数钉死，这是「线性组合能取到什么值」这类问题的总开关。

一、裴蜀定理

a、b 不全为 0 时，存在整数 x、y，使得 ax + by = gcd(a,b)。反过来，ax+by 能取到的值都是 gcd(a,b) 的整数倍。两句话合起来：线性组合能凑出的集合 = gcd 的所有倍数，最小正整数就是 gcd 本身。

两个直接推论。a、b 互质当且仅当存在 x、y 使 ax+by=1；ax+by=c 有解当且仅当 c 是 gcd(a,b) 的倍数。

两项的结论可以推广到 n 项：a1·x1 + a2·x2 + … + an·xn 能凑出的最小正整数，等于 gcd(a1, a2, …, an)。修塔、洗牌、同余方程，后面几页的题都挂在这条定理上。

二、证明：顺着辗转相除倒推

gcd 用辗转相除法算：gcd(a,b) = gcd(b, a%b)。证明裴蜀定理，就是证明每一层的 gcd 都能写成当前两个数的线性组合。递归到底层 (d, 0)，gcd = d，而 d = d·1 + 0·0，显然成立；回退时把上一层的表示代进来，就能拼出这一层的表示。

以 220、170 为例。辗转相除：220 = 1·170+50，170 = 3·50+20，50 = 2·20+10，20 = 2·10+0，gcd = 10。倒推：10 = 50−2·20 = 50−2·(170−3·50) = 7·50−2·170 = 7·(220−170)−2·170 = 7·220−9·170。于是 10 = 7·220 + (−9)·170，x=7、y=−9。

回退那一步的拼法是有固定公式的，下一节「扩展欧几里得」把它写成通用代码。这里先记住：证明就是顺着辗转相除倒着走一遍。

三、模板题（洛谷 P4549）

n 个整数 a1..an，找一组整数 x1..xn，让 a1·x1 + a2·x2 + … + an·xn 是最小正整数，返回这个最小值。n ≤ 20、ai ≤ 1e5。裴蜀定理的 n 项版：答案就是 gcd(|a1|, …, |an|)，逐个累 gcd 即可。

ai 可能是负数，先取绝对值再 gcd。gcd 的结果一定是正数，不会出现「最小正整数是 0」的疑问。

int gcd(int a, int b) {
      return b == 0 ? a : gcd(b, a % b);
    }

    int main() {
      int n;
      scanf("%d", &n);
      int ans = 0;
      for (int i = 1; i <= n; i++) {
        int v;
        scanf("%d", &v);
        ans = gcd(abs(v), ans);
      }
      printf("%d\n", ans);
      return 0;
    }
演示：逐个累 gcd 逼近最小正组合

四、修理宝塔（HDU 5512）

n 座塔编号 1 到 n，a 号和 b 号已经修好。Yuwgna 先手、Iaka 后手轮流修，每步挑两座已修塔 j、k，修 j+k 号或 j−k 号（范围 1..n），谁先修完全部谁赢。判先手赢还是后手赢。2 ≤ n ≤ 2·10^4。

关键观察：能修到的塔号集合，被 gcd(a,b) 一个数钉死。a、b 都是 g=gcd(a,b) 的倍数，j±k 也是 g 的倍数，所以可达塔都是 g 的倍数；反过来，裴蜀定理保证任意 g 的倍数都能用 a、b 的线性组合凑出（组合过程里出现的中间塔也在集合里）。于是可达塔恰好是 g 的 1 倍、2 倍、…、直到不超过 n，一共 n/g 座。

a、b 两座已修，剩余 n/g−2 步。每步必须修一座，塔的集合不会因选择而变化，先手赢当且仅当剩余步数是奇数，也就是 n/g 是奇数。

int gcd(int a, int b) {
      return b == 0 ? a : gcd(b, a % b);
    }

    int main() {
      int cases;
      scanf("%d", &cases);
      for (int t = 1; t <= cases; t++) {
        int n, a, b;
        scanf("%d %d %d", &n, &a, &b);
        printf("Case #%d: ", t);
        if (((n / gcd(a, b)) & 1) == 1) {
          printf("Yuwgna\n");
        } else {
          printf("Iaka\n");
        }
      }
      return 0;
    }

n=10、a=4、b=6 时 g=2，可达 2、4、6、8、10 共 5 座，5 是奇数，先手赢。就算先手第一步只修了 2，后手也只剩 8、10 两座，步数固定，结局不变。

复杂度分析

总结

裴蜀定理把「线性组合能凑出什么数」钉死成 gcd 的倍数，最小正组合就是 gcd；n 项版直接累 gcd。证明顺着辗转相除倒推，回退公式正是扩展欧几里得的骨架。修塔题把「可达塔 = g 的倍数」数清楚后，博弈变成数奇偶，一行判据收工。
