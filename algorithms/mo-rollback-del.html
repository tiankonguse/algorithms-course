只删回滚莫队

删掉容易、加回去难的答案，反过来做：窗口从整段 [1, n] 出发只往里缩，每个任务临时缩到位、记下答案，再靠备份把答案和窗口一起还原。

零、背景

上一节的只增回滚莫队对付的是「加容易、删难」。这一类正好反过来。

典型例子是区间 mex：一段范围里没出现过的最小自然数。删掉一个数字时，如果它的出现次数变成 0，mex 有可能变小，取个 min 就行；把数字加回来时，mex 有可能变大，变大到多少得重新往后查一遍。

一、问题

长度为 n 的数组 arr，一共 m 条查询 l r，打印 arr[l..r] 内没有出现过的最小自然数，0 也算自然数。0 <= n、m、arr[i] <= 2 * 10^5。测试链接：P4137。

这题的最优解是主席树，前面讲主席树时已经给过。这里拿它当只删回滚莫队的入门题，因为它把「加回去难」这件事暴露得最清楚。

二、朴素做法

每条查询开一个标记数组，扫一遍 l..r 把出现过的数字打上标记，再从 0 开始找第一个没被打标记的位置。

int force(int l, int r) {
    for (int i = l; i <= r; i++) vis[arr[i]] = true;
    int ret = 0;
    while (vis[ret]) ret++;
    for (int i = l; i <= r; i++) vis[arr[i]] = false;
    return ret;
}

一次 O(r - l + 1)，m 条最坏 O(nm)。n、m 都是 2 * 10^5 时是 4 * 10^10，跑不动。

三、只让窗口删数字

窗口要是只删不减，就得从最大的窗口开始：初始 winl = 1，winr = n，cnt 记下所有数字的出现次数，mex 也算好。

排序的规则跟着反过来。查询还是按 l 所在块分组，但块内按 r 从大到小排，这样同一个组里 winr 只往左走。

设 l 所在块的左边界是 bl。来到某一组，先让 winl 走到 bl（一直在删），此时的答案记为 beforeJob。

组内每个任务还是四步。

第一步，让 winr 走到 jobr，一路删，答案跟着更新。第二步，把答案存成 backup。第三步，让 winl 走到 jobl，继续删，答案更新完就是这个任务的答案，记下来。第四步，让 winl 退回 bl，这一步在加数字，但不碰答案，答案直接赋回 backup。

一组做完后，让 winr 回到 n，同样只更新 cnt 不更新答案，答案赋回 beforeJob。

和只增那版对照着看：那边是右指针只往右、左指针临时左扩；这边是右指针只往左、左指针临时右扩。备份的位置也一样，都在「临时那一半开始之前」。

五、题目1 的代码

del 里只有一句：出现次数减到 0 时，mex 取 min。add 里只有一句 cnt++，答案全靠 backup 和 beforeJob 还原。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 200001;
    const int MAXB = 501;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXB];

    int cnt[MAXN];
    int mex;
    int ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return b.r < a.r;
    }

    void del(int num) {
        if (--cnt[num] == 0) {
            mex = min(mex, num);
        }
    }

    void add(int num) {
        cnt[num]++;
    }

    void compute() {
        for (int i = 1; i <= n; i++) {
            cnt[arr[i]]++;
        }
        mex = 0;
        while (cnt[mex] != 0) {
            mex++;
        }
        int winl = 1, winr = n;
        for (int block = 1, qi = 1; block <= bnum && qi <= m; block++) {
            while (winl < bl[block]) {
                del(arr[winl++]);
            }
            int beforeJob = mex;
            for (; qi <= m && bi[query[qi].l] == block; qi++) {
                int jobl = query[qi].l;
                int jobr = query[qi].r;
                int id = query[qi].id;
                while (winr > jobr) {
                    del(arr[winr--]);
                }
                int backup = mex;
                while (winl < jobl) {
                    del(arr[winl++]);
                }
                ans[id] = mex;
                mex = backup;
                while (winl > bl[block]) {
                    add(arr[--winl]);
                }
            }
            while (winr < n) {
                add(arr[++winr]);
            }
            mex = beforeJob;
        }
    }

    void prepare() {
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
        }
        sort(query + 1, query + m + 1, QueryCmp);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

六、秃子酋长

长度为 n 的数组 arr，1 到 n 这些数字各出现一次。一共 m 条查询 l r：把 arr[l..r] 里的数按值排序，求排序后相邻两个数在原序列中位置的差的绝对值之和。1 <= n、m <= 5 * 10^5。测试链接：P8078。

这题的答案本身两边都好维护：加一个数字，在有序表里找到前后邻居，把三条距离换成两条；删一个数字同理。真正麻烦的是有序表。数组上做插入删除是 O(n) 的，平衡树又重。

把「按值排序」看成一条双向链表就能绕开：数字就是节点，lst 记前驱、nxt 记后继，删除一个节点只要改两根指针，O(1)。

加回来同样只要两行：nxt[lst[num]] = num 和 lst[nxt[num]] = num。前提是这个节点的前驱和后继此刻还相邻，也就是加回来的顺序必须正好是删的顺序反过来。只删回滚莫队恰好提供这个性质：删的时候是某个方向一路删，回滚的时候就按相反方向一路加回去。

初始时把 1 到 n 全部串好，两端各放一个哨兵 0 和 n + 1，sum 先算成整条链的距离和，之后每个任务只做删除和回滚。

#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 500001;
    int n, m;
    int arr[MAXN];
    Query query[MAXN];
    int pos[MAXN];

    int blen, bnum;
    int bi[MAXN];
    int bl[MAXN];

    int lst[MAXN + 1];
    int nxt[MAXN + 1];
    long long sum;
    long long ans[MAXN];

    bool QueryCmp(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r > b.r;
    }

    inline void del(int num) {
        int less = lst[num], more = nxt[num];
        if (less != 0) {
            sum -= abs(pos[num] - pos[less]);
        }
        if (more != n + 1) {
            sum -= abs(pos[more] - pos[num]);
        }
        if (less != 0 && more != n + 1) {
            sum += abs(pos[more] - pos[less]);
        }
        nxt[less] = more;
        lst[more] = less;
    }

    inline void add(int num) {
        nxt[lst[num]] = num;
        lst[nxt[num]] = num;
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            pos[arr[i]] = i;
        }
        blen = (int)sqrt(n);
        bnum = (n + blen - 1) / blen;
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        for (int i = 1; i <= bnum; i++) {
            bl[i] = (i - 1) * blen + 1;
        }
        sort(query + 1, query + 1 + m, QueryCmp);
    }

    void compute() {
        for (int v = 1; v <= n; v++) {
            lst[v] = v - 1;
            nxt[v] = v + 1;
        }
        nxt[0] = 1;
        lst[n + 1] = n;
        for (int v = 2; v <= n; v++) {
            sum += abs(pos[v] - pos[v - 1]);
        }
        int winl = 1, winr = n;
        for (int block = 1, qi = 1; block <= bnum && qi <= m; block++) {
            while (winl < bl[block]) {
                del(arr[winl++]);
            }
            long long beforeJob = sum;
            for (; qi <= m && bi[query[qi].l] == block; qi++) {
                int jobl = query[qi].l;
                int jobr = query[qi].r;
                int id = query[qi].id;
                while (winr > jobr) {
                    del(arr[winr--]);
                }
                long long backup = sum;
                while (winl < jobl) {
                    del(arr[winl++]);
                }
                ans[id] = sum;
                sum = backup;
                while (winl > bl[block]) {
                    add(arr[--winl]);
                }
            }
            while (winr < n) {
                add(arr[++winr]);
            }
            sum = beforeJob;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> query[i].l >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= m; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

七、复杂度分析

环节复杂度说明
初始化窗口O(n)统计全部数字的出现次数，扫一遍算出初始答案
查询排序O(m log m)按 l 的块号、再按 r 从大到小
每组的右指针O(n)组内 jobr 不上升，winr 从 n 走到 bl 附近，组末再回到 n
全部组的右指针O(n√n)共约 √n 组
每个任务的左指针O(√n)winl 只在块内移动，且每次都退回 bl
总时间O((n + m)√n)与只增回滚莫队同量级
额外空间O(n + m)计数数组 cnt 和查询数组

两类回滚莫队的代价完全一样，选哪个只看 add 和 del 里哪一个是写不出来的那个。

八、最后

判断方法可以固定成一句话：写出 add 和 del，哪个需要「重新扫一遍别的东西」才能更新答案，就把哪个踢出窗口，剩下的交给备份。

莫队这套排序加窗口的办法不止能用在数组上。下一节的树上莫队，把树上的路径也变成一段区间。
