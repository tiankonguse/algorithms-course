AC 自动机配数位 dp

数出不大于 n 的正整数里，十进制表示不含给定数字串的那些。判断「含不含」交给 AC 自动机，位数上限交给数位 dp，两件事接起来只需要一个布尔标记——难的是这个标记得在建机时就推到位。

零、题目

一个正整数 x 是幸运数字，当且仅当它的十进制表示里不包含集合 s 中任意一个元素作为子串。s = {22, 333, 0233} 时，233 是幸运数字，2333 不是（含 333），20233 不是（含 0233），3223 不是（含 22）。给定 n 与 s，数出不超过 n 的幸运数字个数，对 109+7 取模。

两个细节先记住。n 可能长到 1300 位，只能当字符串读，不能读成数字。s 里的元素可以带前导零，"0233" 这种串在数字的表示里只能出现在中间，比如 10233 含它、233 不含。

题目天然分成两半：一段数字串读进去有没有命中任何一个目标串，是 AC 自动机的事；「不超过 n」这个上界，是数位 dp 的事。两边各写各的，中间靠状态对接。

一、命中判定压成一个布尔

走文章时站在节点 j 上，j 自己的标记只说明「有一个目标串在这个节点结束」。这段数字有没有命中，要看整条 fail 链上有没有标记。逐次沿链找的写法，代价取决于链有多长。

换个位置做这件事：建 fail 的时候，每个节点处理完就执行 alert[u] |= alert[fail[u]]。层序遍历保证父亲先于孩子被处理，所以轮到 u 时，alert[fail[u]] 已经是它整条 fail 链的或。推完之后，u 上的标记就是「站到这里算不算命中」的完整答案，判定退化成读一个布尔。

拿 s = {34, 123456} 看。前缀树里 "1234" 是一条中间路径，它自己不是任何目标串的结尾；但它的 fail 指向 "34"，前移之后 "1234" 的标记变成真。读到 "1234" 这一段时，里面藏着的 "34" 当场就被发现。

代价可以忽略：建机时每个节点多做一次或运算。实测 1300 位、1865 个节点的数据上，建 fail 加前移一共 0.021 毫秒。

两种写错的方式都要防。一是不前移、判定时只看本节点，会漏报命中，随机数据（n ≤ 999、模式 1~3 个、字母表 0~3）里 4.17% 的组答案不同；把字母表缩到 {0,1}、模式之间更容易互为后缀，抓取率涨到 19.37%。二是把前移写成覆盖 alert[u] = alert[fail[u]]，本该保留的标记被抹掉，两种数据形状下的抓取率是 93.73% 与 99.27%。

标记沿 fail 边前移

每点一步处理一个节点，看它从父亲那里继承到了什么。切到「不前移」，只有目标串的结尾才有标记。

二、数位 dp 的状态

四个参数：(i, j, free, has)。

i 是从最高位数的第几位；j 是 AC 自动机上「已经填进去的这一段」最后落在哪个节点，一位都没填时落在根；free 说明这一位能不能随便选，free = 0 表示前面每一位都贴着 n 的前缀走、这一位的上限就是 n 的这一位，free = 1 表示前面已经选过更小的数字、后面 0 到 9 随便；has 说明前面有没有选过数字，用来挡前导零。

has 的存在是因为数字不能以 0 开头，而 dp 从最高位往低位填，前面几位完全可能一直空着。has = 0 的时候不能把 0 当成数字的一部分，只能继续空着，或者从 1 开始选。走到末尾时返回 has，空串不算一个正整数，所以 0 不会被数进去。

转移按 has 与 free 分成四支，每支枚举这一位选什么，落到 tree[j][pick]：

1）has = 0 且 free = 0：继续空着；或者从 1 到 n[i]−1 选一个，选完 free 变 1；或者选 n[i]，free 保持 0。

2）has = 0 且 free = 1：继续空着；或者从 1 到 9 选一个。

3）has = 1 且 free = 0：从 0 到 n[i]−1 选一个，free 变 1；或者选 n[i]。

4）has = 1 且 free = 1：0 到 9 随便选。

每一支进门先看 alert：命中就直接返回 0，整棵子树不必再展开。

三、代码

插入数字串，结尾节点打上警报：

// 目标串插进 10 叉前缀树，结尾节点打上警报
    void insert(const string& w) {
        int u = 0;
        for (int j = 0; j < (int)w.size(); j++) {
            int c = w[j] - '0';
            if (tree[u][c] == 0) {
                tree[u][c] = ++cnt;
            }
            u = tree[u][c];
        }
        alert[u] = true;
    }

建 fail 的循环里多一句或运算，标记就推完了：

// 建 fail 的同时把命中标记往前推：每个孩子一次或上父亲的标记
    void setFail() {
        int l = 0, r = 0;
        for (int i = 0; i <= 9; i++) {
            if (tree[0][i] > 0) {
                box[r++] = tree[0][i];
            }
        }
        while (l < r) {
            int u = box[l++];
            for (int i = 0; i <= 9; i++) {
                if (tree[u][i] == 0) {
                    tree[u][i] = tree[fail[u]][i];
                } else {
                    fail[tree[u][i]] = tree[fail[u]][i];
                    box[r++] = tree[u][i];
                }
            }
            alert[u] |= alert[fail[u]];
        }
    }

四个分支全写出来，便于逐支对照：

// i 走到第几位，j 是 AC 自动机上的节点，free 是这一位能不能随便选，has 是前面有没有选过数字
    int f(int i, int j, int free, int has) {
        if (alert[j]) {
            return 0;
        }
        if (i == n) {
            return has;
        }
        if (dp[i][j][free][has] != -1) {
            return dp[i][j][free][has];
        }
        int ans = 0;
        int cur = num[i] - '0';
        if (has == 0) {
            if (free == 0) {
                ans = (ans + f(i + 1, 0, 1, 0)) % MOD;
                for (int pick = 1; pick < cur; pick++) {
                    ans = (ans + f(i + 1, tree[j][pick], 1, 1)) % MOD;
                }
                ans = (ans + f(i + 1, tree[j][cur], 0, 1)) % MOD;
            } else {
                ans = (ans + f(i + 1, 0, 1, 0)) % MOD;
                for (int pick = 1; pick <= 9; pick++) {
                    ans = (ans + f(i + 1, tree[j][pick], 1, 1)) % MOD;
                }
            }
        } else {
            if (free == 0) {
                for (int pick = 0; pick < cur; pick++) {
                    ans = (ans + f(i + 1, tree[j][pick], 1, 1)) % MOD;
                }
                ans = (ans + f(i + 1, tree[j][cur], 0, 1)) % MOD;
            } else {
                for (int pick = 0; pick <= 9; pick++) {
                    ans = (ans + f(i + 1, tree[j][pick], 1, 1)) % MOD;
                }
            }
        }
        dp[i][j][free][has] = ans;
        return ans;
    }

合并版把 limit 与两个新值算出来后一次递归，意思完全相同：

// 合并版：limit 决定这一位最多能选到几，has 与 free 的新值用三元表达式一次算完
    int f2(int i, int u, int free, int has) {
        if (alert[u]) {
            return 0;
        }
        if (i == n) {
            return has;
        }
        if (dp[i][u][free][has] != -1) {
            return dp[i][u][free][has];
        }
        int limit = free == 0 ? num[i] - '0' : 9;
        int ans = 0;
        for (int pick = 0; pick <= limit; pick++) {
            ans = (ans + f2(i + 1, has == 0 && pick == 0 ? 0 : tree[u][pick],
                            free == 0 && pick == limit ? 0 : 1,
                            has == 0 && pick == 0 ? 0 : 1)) % MOD;
        }
        dp[i][u][free][has] = ans;
        return ans;
    }

沿着 n 的前缀逐位走

每点一步走一位，看这一位能选什么、每个候选落到哪个节点、哪些被标记挡下。答案由完整的记忆化搜索给出。

两组实测答案，可以用来对拍：n = 300、s = {22, 333, 0233} 得 288；n = 10233、s = {0233} 得 10232，也就是只有 10233 自己不合格。

四、复杂度分析

做法关键操作时间空间
建机（前缀树 + fail + 标记前移）每个节点扫 10 条边、一次或运算O(10 × 总字符数)O(10 × 节点数)
记忆化搜索每个状态枚举这一位的 10 个选择O(n × 节点数 × 2 × 2 × 10)O(n × 节点数 × 2 × 2)
命中判定沿 fail 链找每次判定多走一遍链上面每一项再乘最长串长O(1) 额外

状态的四个维度里，n 是位数、节点数是所有目标串总字符数的上界，两个 2 分别是 free 与 has。实测 n = 1300 位、100 个长度 20 的目标串（总字符 2000，建出 1865 个节点），建机 0.021 毫秒，记忆化搜索 69.606 毫秒，答案 450153324。表按题目的上限开成 1305 × 2005 × 2 × 2 个 int，约 39.9 MB，所以模板里 MAXS 只开到 2001 就够了。判定那一行如果换成沿链找，同一份数据要多 40599553 次探测、80.387 毫秒，链越长差距越大。

总结

命中判定能压成一个布尔，前提是在建 fail 时把标记按层推下去，alert[u] |= alert[fail[u]]。推完之后走文章只用读一个标记，判定 O(1)；写成覆盖会抹掉自己的标记，两种数据形状下 93% 以上会给出不同答案。

数位 dp 的状态是 (i, j, free, has)：j 是 AC 自动机上的节点，free 管「这一位能不能随便选」，has 管「前导零算不算数字」。四支分支的差别只在枚举范围和两个标记怎么变。

两件事各自线性，合起来是 O(n × 节点数 × 4 × 10) 的时间与 O(n × 节点数 × 4) 的空间，n = 1300 位时 39.9 MB 的表、69.606 毫秒跑完。

到这里 AC 自动机的三处绕圈都换掉了：建机时用直通边，统计时用 fail 反图，实时判定用标记前移。剩下的用法都是这三样的组合。
