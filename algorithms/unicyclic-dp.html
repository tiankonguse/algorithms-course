基环树环上 DP

找环只是开头，麻烦都在后面：环上没有「孩子先算、父亲后算」的天然次序，两点之间永远有两条路。补救的办法是把环变成链。这一节四道题，从删边最优、环上配对，一路走到带修改的最短路和字典序贪心。

零、把环变成链

上一节的 dfs 骨架把环上的点收进 arr，把环上每条边的权值收进 val，环的形状和顺序都有了。往下怎么算，取决于问题要什么，但变形只有两种手法。

手法一，断开一条边。要「删掉环上一条边」的问题直接枚举断在哪：断开之后环成链，链可以随便用前缀和、前后缀最值。

手法二，倍长。把环复制一份接在后面，长度翻倍，环上任意两点都能在这两倍的数组里表达。适合「环上任意两点配对」的问题，再配一个「不超过一整圈」的窗口。

两种手法里反复出现同一个指标：height[i] − sum[i]。height 是环节点往下最远能伸多深，sum 是环上到它的前缀和。两点 i、j 的跨环路径长度是 height[i] + height[j] + (sum[i] − sum[j])，整理成 (height[i] + sum[i]) + (height[j] − sum[j])，一半只跟 i 有关，一半只跟 j 有关，就能分开维护。

一、题目1：树直径最小化

n 个点、n 条无向边、连通、带边权的基环树。可以删掉环上任何一条边，让图变成树，希望这棵树的直径尽量小。第一问直接输出最小的直径（CF835F 王国道路）；第二问等价于输出它除以 2，保留一位小数（洛谷 P1399 快餐店）。n 到 2 × 10⁵，边权到 10⁹。

先把答案拆成两块。删掉一条环边后，树的直径要么完全落在某棵分树内部，要么跨过环。

分树内部这一块跟删哪条边无关。对每个环上点跑一遍「树上求直径」的 dfs，维护 dist（往下最深）和全局的 diameter，取最大记作 ans1。

跨环这一块才跟断点有关。删掉位置 p 的边后，环变成链，链上两个环节点 a、b 之间的路径长度是 height[a] + height[b] 加上链上距离，而链上距离带着前缀和。要跨过链，路径一定一头在断点左侧、一头在右侧。

于是对每个断点 p，从前往后扫一遍，记 preMax（左段里 height 加前缀和的最大）和 preDiameter（左段内部的最大路径）；再从后往前扫一遍，记 sufMax 和 sufDiameter。删位置 p 的候选答案是三者取 max：preMax[p] + sufMax[p + 1]（跨断点）、preDiameter[p]（左段内部）、sufDiameter[p + 1]（右段内部）。把 p 从 1 到 环长减一 都试一遍，再加上 preDiameter[环长] 覆盖「删最后一条边」的情形，取最小。

这里有个细节：右段的点到链相接处的距离，要「沿环往后走到最后一个环节点，再走那条闭合边」，所以后缀扫描里的前缀和带着闭合边的权值，方向和前缀扫描相反。

最终答案就是 max(ans1, 上面枚举出的最小值)。两问共用这份代码，只在输出时不同。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 200001;
    int n;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int fromNode[MAXN];
    int fromWeight[MAXN];
    bool cycle[MAXN];
    int arr[MAXN];
    int val[MAXN];
    int cnta;

    ll dist[MAXN];
    ll diameter;

    ll height[MAXN];

    ll preMax[MAXN];
    ll preDiameter[MAXN];

    ll sufMax[MAXN];
    ll sufDiameter[MAXN];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                fromNode[v] = u;
                fromWeight[v] = weight[e];
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[u] = true;
                arr[++cnta] = u;
                val[cnta] = weight[e];
                for (int i = v; i != u; i = fromNode[i]) {
                    cycle[i] = true;
                    arr[++cnta] = i;
                    val[cnta] = fromWeight[i];
                }
            }
        }
    }

    void dpOnTree(int u, int fa) {
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa && !cycle[v]) {
                dpOnTree(v, u);
                diameter = max(diameter, dist[u] + dist[v] + w);
                dist[u] = max(dist[u], dist[v] + w);
            }
        }
    }

    ll dpOnCycle() {
        ll best = 0;
        ll sum = 0;
        for (int i = 1; i <= cnta; i++) {
            preMax[i] = max(preMax[i - 1], height[i] + sum);
            preDiameter[i] = max(preDiameter[i - 1], sum + height[i] + best);
            best = max(best, height[i] - sum);
            sum += val[i];
        }
        sufMax[cnta] = height[cnta] + val[cnta];
        sufDiameter[cnta] = height[cnta];
        best = height[cnta] - val[cnta];
        sum = val[cnta] + val[cnta - 1];
        for (int i = cnta - 1; i >= 1; i--) {
            sufMax[i] = max(sufMax[i + 1], height[i] + sum);
            sufDiameter[i] = max(sufDiameter[i + 1], sum + height[i] + best);
            best = max(best, height[i] - sum);
            sum += val[i - 1];
        }
        ll ans = LLONG_MAX;
        for (int i = 1; i < cnta; i++) {
            ans = min(ans, max(preMax[i] + sufMax[i + 1], max(preDiameter[i], sufDiameter[i + 1])));
        }
        ans = min(ans, preDiameter[cnta]);
        return ans;
    }

    ll compute() {
        dfs(1);
        ll ans1 = 0;
        for (int i = 1; i <= cnta; i++) {
            diameter = 0;
            dpOnTree(arr[i], 0);
            ans1 = max(ans1, diameter);
            height[i] = dist[arr[i]];
        }
        ll ans2 = dpOnCycle();
        return max(ans1, ans2);
    }

    int main() {
        scanf("%d", &n);
        for (int i = 1, u, v, w; i <= n; i++) {
            scanf("%d%d%d", &u, &v, &w);
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        ll ans = compute();

        // 王国道路，CF835F，使用如下打印
        printf("%lld\n", ans);

        // 快餐店，洛谷P1399，使用如下打印
        // printf("%.1f\n", (double)ans / 2.0);

        return 0;
    }

二、题目2：岛屿

n 个点、n 条无向边、带边权，图可能有多个连通块，保证每个连通块都是基环树。对每个连通块，求点不重复的路径能拿到的最大边权和，也就是基环树的直径，全部加起来输出。n 到 10⁶（洛谷 P4381）。

还是那两块。分树内部跑树上直径，取最大记 ans1；跨环的记 ans2，两者的较大者就是这个连通块的直径。

ans2 是「环上任意两点配对」：max(height[i] + height[j] + sum[i] − sum[j])。这次不断边，因为不删任何东西，两个方向都能走，但路径不能绕超过一整圈，否则会重复经过点。

把环倍长。i 从左往右扫，j 在它后面不超过一整圈的位置里选，用单调队列维护 height[j] − sum[j] 的最大值：队头太旧（跟 i 差出一圈以上）就弹出，新元素入队前把不如它的从队尾弹掉。每个点进出队列各一次。

多个连通块就靠 dfn 找下一个没访问过的点，每个连通块算完把直径累加。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 1000001;
    int n;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int weight[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int fromNode[MAXN];
    int fromWeight[MAXN];
    bool cycle[MAXN];
    int arr[MAXN];
    int val[MAXN];
    int cnta;

    ll dist[MAXN];
    ll diameter;

    ll sum[MAXN << 1];
    ll height[MAXN << 1];
    int que[MAXN << 1];

    void addEdge(int u, int v, int w) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        weight[cntg] = w;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                fromNode[v] = u;
                fromWeight[v] = weight[e];
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[u] = true;
                arr[++cnta] = u;
                val[cnta] = weight[e];
                for (int i = v; i != u; i = fromNode[i]) {
                    cycle[i] = true;
                    arr[++cnta] = i;
                    val[cnta] = fromWeight[i];
                }
            }
        }
    }

    void dpOnTree(int u, int fa) {
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            int w = weight[e];
            if (v != fa && !cycle[v]) {
                dpOnTree(v, u);
                diameter = max(diameter, dist[u] + dist[v] + w);
                dist[u] = max(dist[u], dist[v] + w);
            }
        }
    }

    ll compute(int root) {
        cnta = 0;
        dfs(root);
        sum[1] = 0;
        for (int i = 2, j = 1; j <= cnta; i++, j++) {
            sum[i] = val[j];
        }
        for (int i = cnta + 2; i <= cnta * 2; i++) {
            sum[i] = sum[i - cnta];
        }
        for (int i = 1; i <= cnta * 2; i++) {
            sum[i] += sum[i - 1];
        }
        ll ans1 = 0;
        for (int i = 1; i <= cnta; i++) {
            diameter = 0;
            dpOnTree(arr[i], 0);
            ans1 = max(ans1, diameter);
            height[i] = dist[arr[i]];
            height[i + cnta] = height[i];
        }
        ll ans2 = 0;
        int ql = 1, qr = 0;
        for (int i = 1; i <= cnta * 2; i++) {
            while (ql <= qr && que[ql] <= i - cnta) {
                ql++;
            }
            if (ql <= qr) {
                ans2 = max(ans2, height[i] + height[que[ql]] + sum[i] - sum[que[ql]]);
            }
            while (ql <= qr && height[que[qr]] - sum[que[qr]] <= height[i] - sum[i]) {
                qr--;
            }
            que[++qr] = i;
        }
        return max(ans1, ans2);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int u = 1, v, w; u <= n; u++) {
            cin >> v >> w;
            addEdge(u, v, w);
            addEdge(v, u, w);
        }
        ll ans = 0;
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                ans += compute(i);
            }
        }
        cout << ans << "\n";
        return 0;
    }

三、题目3：最短距离

n 个点、n 条无向边、带边权的连通基环树，m 个操作：操作 1 x y 把第 x 条边的边权改成 y；操作 2 x y 查询点 x 和点 y 之间的最短距离。n 到 10⁵ + 6，边权到 5000（洛谷 P4949）。

先把工具备齐。建议先看懂树链剖分，以及「边权转点权」：每条边的权值挂到它更深的那个端点上，改边权就是单点改，问树上两点的距离就是边权转点权后的路径区间和。本题只有单点改和区间求和，树状数组就够了，不用线段树。

树上那一套怎么搬到基环树？把环找出来，环上的边先抽走，剩下的每个环上点带着自己的分树，都是普通的树。对每棵分树做树剖，每个点记 belong，表示它属于哪个环点的分树；环上的边按环的顺序排成单独一段，跟分树一起放进同一个树状数组，各占一段下标。

查询分两种。x、y 在同一棵分树里：belong 相同，树剖直接算，路径不会碰环。在不同分树：先各自走到所属的环点，这段用树剖算；环上两段弧用前缀和相减得到，取短的那段；三段加起来就是答案。

修改也简单：先算出这条边的权值挂在哪个下标（分树内部的边挂在更深端点的 dfn 上，环上的边挂在自己那段里），树状数组加上差值。

另一种更巧的做法：标记环上一条边把它忽略，整张图按一棵树做树剖；查询时比较「不走标记边」和「走标记边绕环另一半」两个值，取小。实现更短，这里展开的是上面好想的那种。

完整代码（树剖 + 树状数组，逻辑照「好想的解法」）：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100007;
    int n, m;
    int u[MAXN];
    int v[MAXN];
    int w[MAXN];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;
    int from[MAXN];
    bool cycle[MAXN];
    int arr[MAXN];
    int cnta;

    int cycleEdgeTo[MAXN];
    int cycleId[MAXN];
    int belong[MAXN];

    int fa[MAXN];
    int dep[MAXN];
    int siz[MAXN];
    int son[MAXN];
    int top[MAXN];

    int tree[MAXN << 1];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs1(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                from[v] = u;
                cycleEdgeTo[(e + 1) >> 1] = v;
                dfs1(v);
            } else if (dfn[u] < dfn[v]) {
                cycleEdgeTo[(e + 1) >> 1] = u;
                cycle[u] = true;
                arr[++cnta] = u;
                for (int i = v; i != u; i = from[i]) {
                    cycle[i] = true;
                    arr[++cnta] = i;
                }
            }
        }
    }

    void dfs2(int u, int f, int h) {
        belong[u] = h;
        fa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e > 0; e = nxt[e]) {
            v = to[e];
            if (!cycle[v] && v != f) {
                dfs2(v, u, h);
                siz[u] += siz[v];
                if (son[u] == 0 || siz[son[u]] < siz[v]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs3(int u, int t) {
        top[u] = t;
        dfn[u] = ++cntd;
        if (son[u] != 0) {
            dfs3(son[u], t);
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (!cycle[v] && v != fa[u] && v != son[u]) {
                dfs3(v, v);
            }
        }
    }

    int lowbit(int i) {
        return i & -i;
    }

    void add(int i, int v) {
        while (i <= cntd) {
            tree[i] += v;
            i += lowbit(i);
        }
    }

    int query(int i) {
        int ans = 0;
        while (i >= 1) {
            ans += tree[i];
            i -= lowbit(i);
        }
        return ans;
    }

    int sum(int l, int r) {
        if (l > r) {
            return 0;
        }
        return query(r) - query(l - 1);
    }

    int edgeToNode(int i) {
        if (cycle[u[i]] && cycle[v[i]]) {
            return cycleId[cycleEdgeTo[i]];
        } else {
            return max(dfn[u[i]], dfn[v[i]]);
        }
    }

    void prepare() {
        dfs1(1);
        cntd = 0;
        for (int i = 1; i <= cnta; i++) {
            dfs2(arr[i], 0, arr[i]);
            dfs3(arr[i], arr[i]);
        }
        for (int i = 1; i <= cnta; i++) {
            cycleId[arr[i]] = ++cntd;
        }
        for (int i = 1; i <= n; i++) {
            add(edgeToNode(i), w[i]);
        }
    }

    void setEdge(int edge, int val) {
        add(edgeToNode(edge), val - w[edge]);
        w[edge] = val;
    }

    int jump(int x, int y) {
        int ans = 0;
        while (top[x] != top[y]) {
            if (dep[top[x]] < dep[top[y]]) {
                ans += sum(dfn[top[y]], dfn[y]);
                y = fa[top[y]];
            } else {
                ans += sum(dfn[top[x]], dfn[x]);
                x = fa[top[x]];
            }
        }
        if (dfn[x] < dfn[y]) {
            ans += sum(dfn[x] + 1, dfn[y]);
        } else {
            ans += sum(dfn[y] + 1, dfn[x]);
        }
        return ans;
    }

    int getDistance(int x, int y) {
        if (belong[x] == belong[y]) {
            return jump(x, y);
        } else {
            int a = min(cycleId[belong[x]], cycleId[belong[y]]);
            int b = max(cycleId[belong[x]], cycleId[belong[y]]);
            int p1 = sum(a, b - 1);
            int p2 = sum(n + 1, cntd) - p1;
            return jump(x, belong[x]) + jump(y, belong[y]) + min(p1, p2);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> u[i] >> v[i] >> w[i];
            addEdge(u[i], v[i]);
            addEdge(v[i], u[i]);
        }
        prepare();
        for (int i = 1, op, x, y; i <= m; i++) {
            cin >> op >> x >> y;
            if (op == 1) {
                setEdge(x, y);
            } else {
                cout << getDistance(x, y) << "\n";
            }
        }
        return 0;
    }

四、题目4：旅行

n 个点、m 条无向边，m 是 n − 1（普通树）或者 n（基环树）。从 1 号点开始 dfs，按访问顺序把每个点记下来，得到一个序列。普通树的答案，是所有遍历顺序里字典序最小的那个序列；基环树可以先删掉环上任何一条边变成普通树，在所有删法里取字典序最小的结果。n 到 5 × 10⁵（洛谷 P5022 普通版、P5049 加强版）。

普通树很好办。dfs 序列里，先走的子树整体排在前面，所以把每个点的儿子按编号升序排好，每次走编号最小的没访问过的邻居，得到的就是字典序最小。

基环树的暴力是枚举删哪条环边，每删一次做一遍上面的贪心，n 到 5000 能过。加强版要一遍 dfs 里做完，关键在于：站在环上时，真正的选择只有一个。

具体来说，走到环上的点 u（来路是环上的一侧），没访问过的邻居里编号最大的是环另一侧的 end（邻接表按编号升序排，最后扫到的就是它）。这时候有两条路：继续沿环走向 end，或者回头。回头表示这一步所在的边等价于被删掉，之后图成了树，照普通贪心走完就行。

判据是拿 end 和 back 比，back 是从上一层传下来的「回退之后接下来会走到的点」。end 比 back 大，就回头：把回溯标志 turn 置真，当前这趟不再走 end，end 那个点以后从环的另一侧绕过来再访问。

实现上有两个细节。邻接表按「起点升序、终点降序」排序后头插建边，遍历顺序正好是编号升序。找到环之后才允许做这个判断，不在环上的点照普通贪心走。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int u, v;
    };

    bool EdgeCmp(Edge a, Edge b) {
        if (a.u != b.u) {
            return a.u < b.u;
        }
        return a.v > b.v;
    }

    const int MAXN = 500001;
    int n, m;

    Edge arr[MAXN << 1];

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int dfn[MAXN];
    int cntd;

    int from[MAXN];
    bool cycle[MAXN];

    bool turn;
    bool vis[MAXN];
    int ans[MAXN];
    int cnta;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs(int u) {
        dfn[u] = ++cntd;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                from[v] = u;
                dfs(v);
            } else if (dfn[u] < dfn[v]) {
                cycle[u] = true;
                for (int i = v; i != u; i = from[i]) {
                    cycle[i] = true;
                }
            }
        }
    }

    void path(int u, int back) {
        vis[u] = true;
        ans[++cnta] = u;
        if (!cycle[u] || turn) {
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                if (!vis[v]) {
                    path(v, n + 1);
                }
            }
            return;
        }
        int end = 0;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                end = v;
            }
        }
        turn = cycle[end] && end > back;
        if (turn) {
            for (int e = head[u]; e > 0; e = nxt[e]) {
                int v = to[e];
                if (!vis[v] && v != end) {
                    path(v, n + 1);
                }
            }
            return;
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (!vis[v]) {
                if (!cycle[v]) {
                    path(v, n + 1);
                } else {
                    int next = back;
                    for (int ne = nxt[e]; ne > 0; ne = nxt[ne]) {
                        int nv = to[ne];
                        if (!vis[nv]) {
                            next = nv;
                            break;
                        }
                    }
                    path(v, next);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            arr[i] = {u, v};
            arr[i + m] = {v, u};
        }
        sort(arr + 1, arr + m * 2 + 1, EdgeCmp);
        for (int i = 1; i <= m * 2; i++) {
            addEdge(arr[i].u, arr[i].v);
        }
        dfs(1);
        path(1, n + 1);
        for (int i = 1; i <= n; i++) {
            cout << ans[i] << " ";
        }
        return 0;
    }

五、复杂度分析

四道题都建立在上一次的 dfs 找环之上，找环本身线性。环上部分各有各的账。

题目时间复杂度空间复杂度
题目1 树直径最小化O(n)，前后缀各扫一遍O(n)
题目2 岛屿直径O(n)，单调队列均摊O(n)
题目3 最短距离预备 O(n log n)；改 O(log n)；查 O(log² n)O(n)
题目4 旅行O(n log n)，瓶颈在边排序O(n)

题目1 看着是两层枚举，其实前缀、后缀、汇总各是线性的一遍。题目2 的窗口里每个环节点最多进出队列一次，倍长之后也只是常数翻倍。题目3 的查询是树剖跳链乘上树状数组求和，10⁵ 的规模绰绰有余；题目4 排序完只剩一遍 dfs。

空间都是邻接表加几个线性数组。题目2 的 n 到 10⁶，环相关的数组开两倍。

六、最后

两节连起来看，基环树的题面五花八门，骨架只有一条：dfs 把环拎出来，分树各自建信息，环上把信息并起来。

环上并信息靠「变链」。要删边最优就枚举断点，前后缀各扫一遍；要环上配对就倍长加滑窗；要带修改的距离就树剖加树状数组，环单独占一段下标；要字典序就把决定压成一次比较。指标始终是 height 加减前缀和，它把「点到环的距离」和「环上走了多远」并成一个数。

树上的工具到这里几乎都能搬上环了。搬不动的部分，多半是因为环上两点有两条路，凡是碰到这一步，就把环断开或者倍长，回到链上再想。
