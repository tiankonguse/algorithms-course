岛屿数量：二维网格的并查集

0/1 网格里数连通块，并查集把每个 '1' 当成元素，相邻的 '1' 合并，最后剩几个集合就有几座岛。要点是把二维坐标压成一维下标。

零、背景

网格里 '1' 是陆地、'0' 是水，上下左右相邻的 '1' 属于同一座岛，数总共有几座岛。直觉做法是 DFS/BFS 洪水填充，每碰到一个没访问过的 '1' 就把它能到的所有陆地标记掉、计数加一。

并查集是另一种等价思路：先让每个 '1' 单独成集，再把相邻的 '1' 合并，合并的次数越少、剩下的集合数就是岛屿数。它和洪水填充的区别在于顺序：洪水填充从某个 '1' 出发扩散，并查集扫一遍网格把邻接关系全部连上。

一、二维压成一维

并查集只有一维的 father 数组，二维网格要压平：位置 (a, b) 的编号 = a × cols + b。查 father 时用这个编号，union 时先把两个坐标都转成编号。

这个映射的唯一要求是「一个格子一个编号」，行优先顺序足够。注意越界：只有左边 (a, b-1) 和上边 (a-1, b) 两个方向需要检查，右和下会在后面的格子被反向检查到，一遍扫描就够。

二、先成集，再合并

两遍扫描：第一遍给所有 '1' 建集（father 指向自己、sets++）；第二遍扫每个 '1'，看左边和上边，如果是 '1' 就 union。union 成功一次 sets 减一。

LC 的样例一（4×5 网格）只有一块连通的陆地，sets 从 8 一路合并到 1；样例二有两块分离的陆地，答案 3。注意合并方向只扫左上，别漏：两个左右相邻的 '1' 在左边那个被扫到时就和右边连上了，右边扫到时已经同根，不会重复减。

#include <bits/stdc++.h>
    using namespace std;

    // 岛屿数量：'1' 各自成集，左/上的相邻 '1' 合并，集合数就是岛屿数
    int numIslands(vector<vector<char>>& board) {
        int n = board.size(), m = board[0].size();
        vector<int> father(n * m, -1);
        int sets = 0;
        auto idx = [&](int a, int b) { return a * m + b; };  // 二维压成一维

        for (int a = 0; a < n; a++) {         // 先给所有 '1' 单独成集
            for (int b = 0; b < m; b++) {
                if (board[a][b] == '1') {
                    father[idx(a, b)] = idx(a, b);
                    sets++;
                }
            }
        }

        function<int(int)> find = [&](int i) -> int {
            if (i != father[i]) father[i] = find(father[i]);
            return father[i];
        };
        auto unionSet = [&](int x, int y) {
            int fx = find(x), fy = find(y);
            if (fx != fy) {
                father[fx] = fy;
                sets--;
            }
        };

        for (int i = 0; i < n; i++) {         // 再合并左、上两个方向的相邻陆地
            for (int j = 0; j < m; j++) {
                if (board[i][j] == '1') {
                    if (j > 0 && board[i][j - 1] == '1') unionSet(idx(i, j), idx(i, j - 1));
                    if (i > 0 && board[i - 1][j] == '1') unionSet(idx(i, j), idx(i - 1, j));
                }
            }
        }
        return sets;
    }

演示 · 岛屿逐帧：每个 '1' 检查左、上邻居并合并

三、复杂度分析

指标值
时间复杂度O(n×m×α)，网格 n×m
额外空间O(n×m)（father 数组）

每个格子被访问常数次，每次 union/find 均摊 O(α)。father 数组大小是网格格子数，n×m 上限 10⁵ 时没压力。

四、总结

二维并查集 = 坐标压一维 + 两遍扫描（建集、合并）。和洪水填充相比，它把「连通」变成了「合并」，往后网格类的并查集题（包括带权、动态加岛）都从这里长出来。

洪水填充是另一条等价路线，两招都值得会。并查集-上到这里收尾：模版、集合数应用、二维映射，三页覆盖。
