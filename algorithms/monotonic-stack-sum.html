子数组最小值之和：贡献法

把所有子数组的最小值加起来，直接枚举不现实。把问题翻过来：数每个位置「作为最小值」覆盖了多少个子数组，一个 O(n) 的乘法就出来了。

零、背景

arr 有 n 个元素，求所有子数组 min 的和。子数组一共 n(n+1)/2 个，n = 3×10⁴ 时约 4.5×10⁸ 个，每个都求一次最小值，怎么都过不去。

换个角度：与其统计每个子数组的最小值，不如统计每个位置「在多少个子数组里是最小值」。arr[i] 贡献的次数乘上 arr[i]，全加起来就是答案。这个统计叫贡献法。

一、贡献法：一个位置覆盖多少个子数组

位置 cur 作为最小值的子数组，左端只能取 (left, cur] 这些位置，右端只能取 [cur, right)，其中 left 是左边最近且更小的位置、right 是右边最近且更小的位置。左右独立，次数就是 (cur - left) × (right - cur)。

为什么必须用「更小」当边界：子数组只要跨过 left（把更小的值包进来），最小值就不是 arr[cur] 了；跨过 right 同理。所以 cur 的势力范围就是两个更小值夹出来的那段。

拿 [3, 1, 2, 4] 对一遍：位置 0 的值 3，左右更小分别是 -1 和 1，覆盖 (0-(-1))×(1-0) = 1 个子数组 [3]；位置 1 的值 1，左右更小是 -1 和 4（不存在），覆盖 2×3 = 6 个子数组；位置 2 的值 2，覆盖 (2-1)×(4-2) = 2 个；位置 3 的值 4，覆盖 1 个。总和 1×3 + 6×1 + 2×2 + 1×4 = 17。

二、相等的值：谁都不许吞谁

有相等的值时要小心：left 和 right 都要求严格更小，可相等的两个位置会互相挡。处理办法是弹栈条件用 >=，相等的旧位置被新位置顶出去，旧位置的 right 就止于相等处。

看 [71, 55, 82, 55]，答案 593。两个 55 分头干活：位置 1 的 55 弹出时 right = 3（那里是位置 3 的 55，相等），覆盖 (1-(-1))×(3-1) = 4 个子数组，贡献 220；位置 3 的 55 清算时 right = 4，覆盖 4 个子数组，也贡献 220。相等的值各管各的区间，不重不漏。真要把相等也吞进来，答案会算重。

三、单调栈结算

左右更小的位置正好是上一页那套单调栈。遍历阶段弹出时结算 (cur - left) × (i - cur) × arr[cur]，清算阶段 right 换成 n。代码里只有这几行是核心，剩下的都是读入输出。

#include <bits/stdc++.h>
    using namespace std;

    const int MOD = 1000000007;

    int sumSubarrayMins(vector<int>& arr) {
        long long ans = 0;
        int n = arr.size();
        vector<int> stk;
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && arr[stk.back()] >= arr[i]) {
                int cur = stk.back();
                stk.pop_back();
                int left = stk.empty() ? -1 : stk.back();
                // cur 作为最小值，覆盖 (cur-left) × (i-cur) 个子数组
                ans = (ans + (long long)(cur - left) * (i - cur) * arr[cur]) % MOD;
            }
            stk.push_back(i);
        }
        while (!stk.empty()) {              // 清算：右边没有更小的，right = n
            int cur = stk.back();
            stk.pop_back();
            int left = stk.empty() ? -1 : stk.back();
            ans = (ans + (long long)(cur - left) * (n - cur) * arr[cur]) % MOD;
        }
        return (int)ans;
    }

四、取模

答案可能很大，要模 10⁹ + 7。累加用 long long 兜住乘法：最坏 (cur-left) 和 (i-cur) 都接近 n = 3×10⁴，乘积接近 10⁹，再乘 arr[cur] 接近 10⁹，中间量会到 10¹⁸，int 装不下。每步加完立即取模，别攒到最后。

五、复杂度分析

指标值
时间复杂度O(n)
额外空间O(n)（栈）

每个位置入栈一次、出栈最多一次，弹栈总次数 ≤ n，两趟 while 加起来就是 O(n)。取模是常数时间，不影响量级。

六、总结

子数组最小值之和的关键是贡献法：每个位置作为最小值的子数组数 = (cur - left) × (right - cur)，左右边界用严格更小的位置定，弹栈用 >= 让相等的值各管一段。

这套「弹出即结算左右边界」还能直接算柱状图里的最大矩形，下一个页面见。
