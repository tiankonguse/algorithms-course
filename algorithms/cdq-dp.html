CDQ 分治优化 dp

dp 的转移如果只从左边来、并且「谁能转移给谁」能用一个偏序判出来，就可以把转移整批交给分治。这一节两道题：一道是模版，另一道还要顺带统计方案数。

零、背景

能用 CDQ 分治优化的 dp，一般都有三个特征。

一是历史依赖性，算 dp[i] 时只依赖下标更小的历史状态。

二是转移的偏序性，两个对象之间能不能转移，由若干属性的比较决定。

三是可批量维护性，左边的状态能塞进一个数据结构里，一次更新右边的若干个 dp。

做法是把递归的顺序换一下。原来是「左、右、中」，现在变成「左、中、右」。

cdq(l, mid);          // 1，先把左半的 dp 全部算成最终值
merge(l, mid, r);    // 2，用左半的 dp 整批更新右半
cdq(mid + 1, r);     // 3，再递归算右半

第二步是整个过程的关键，它要快。左右两半各自按某个标准排好序之后，一般用双指针加树状数组做到 O(n log n)。

这里有个细节：如果 merge 里为了方便统计而重新排序，一定要用辅助数组，不能动原数组的下标次序。dp 必须保持从左到右计算，次序乱了答案就错了。

一、问题：序列

给定一个长度为 n 的数组 arr，一共有 m 条操作，格式为 x v，表示 x 位置的数变成 v。

你可以选择不执行任何操作，或者只选择一个操作来执行，然后 arr 不再变动。

请在 arr 中选出一组下标序列，不管你做出什么选择，下标序列所代表的数字都是不下降的。打印序列能达到的最大长度。

1 ≤ 所有数字 ≤ 10⁵。

测试链接：洛谷 P4093。

二、朴素做法

设 dp[j] 是选了 j 作为最后一个下标时的最大长度。转移时枚举前一个下标 i < j，判断这一对能不能相邻。

判断本身要先预处理。每个位置 x 记两个值：lv[x] 是 x 位置可能取到的最小值，rv[x] 是可能取到的最大值，初值都是原值，每条操作都拿来更新一次 min 和 max。

lv[idx] = min(lv[idx], val);
rv[idx] = max(rv[idx], val);

有了 lv 和 rv，一对下标 i < j 能不能相邻就变成两个不等式。

操作作用在 i 上时，i 最大会变成 rv[i]，j 保持原值，要求 rv[i] ≤ arr[j]。操作作用在 j 上时，j 最小会变成 lv[j]，i 保持原值，要求 arr[i] ≤ lv[j]。操作作用在别处或者不执行时，要求 arr[i] ≤ arr[j]，这一条被前两条包住了。

于是转移条件是：i < j 且 arr[i] ≤ lv[j] 且 rv[i] ≤ arr[j]。朴素枚举是 O(n²)。

三、分治里批量转移

下标这一维交给分治：cdq(l, r) 先递归算完左半，再用左半整批更新右半，最后递归右半。

merge 里做的事是这样：左半按 arr（原值）从小到大排，右半按 lv 从小到大排。双指针把 arr[i] ≤ lv[j] 的左半元素逐个加进树状数组，加的位置是 rv[i]，值是 dp[i]。

这时候树状数组里存的是「所有满足第一个不等式的左半元素」，按 rv 组织。右半的 j 要的是 rv[i] ≤ arr[j] 里最大的 dp[i]，正好是一次前缀最大值查询，查到 arr[j] 为止。

dp[j] = max(dp[j], query(arr[j]) + 1);

树状数组按下标值开，取 max 而不是求和，清空的时候要把加过的格子逐个还原成 0。

代码里树状数组的上界直接用了 n。本题所有数字不超过 10⁵，n 也是这个量级，够用；换成别的数据范围时记得按真实值域开。

四、代码：序列

    
#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int i, v, lv, rv;
    };

    bool CmpV(Node a, Node b) {
        return a.v < b.v;
    }

    bool CmpLv(Node a, Node b) {
        return a.lv < b.lv;
    }

    const int MAXN = 100001;
    int n, m;
    int v[MAXN];
    int lv[MAXN];
    int rv[MAXN];

    Node arr[MAXN];
    int tree[MAXN];
    int dp[MAXN];

    int lowbit(int i) {
        return i & -i;
    }

    void more(int i, int num) {
        while (i <= n) {
            tree[i] = max(tree[i], num);
            i += lowbit(i);
        }
    }

    int query(int i) {
        int ret = 0;
        while (i > 0) {
            ret = max(ret, tree[i]);
            i -= lowbit(i);
        }
        return ret;
    }

    void clear(int i) {
        while (i <= n) {
            tree[i] = 0;
            i += lowbit(i);
        }
    }

    void merge(int l, int m, int r) {
        for (int i = l; i <= r; i++) {
            arr[i].i = i;
            arr[i].v = v[i];
            arr[i].lv = lv[i];
            arr[i].rv = rv[i];
        }
        sort(arr + l, arr + m + 1, CmpV);
        sort(arr + m + 1, arr + r + 1, CmpLv);
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].v <= arr[p2].lv) {
                p1++;
                more(arr[p1].rv, dp[arr[p1].i]);
            }
            dp[arr[p2].i] = max(dp[arr[p2].i], query(arr[p2].v) + 1);
        }
        for (int i = l; i <= p1; i++) {
            clear(arr[i].rv);
        }
    }

    void cdq(int l, int r) {
        if (l == r) {
            return;
        }
        int mid = (l + r) / 2;
        cdq(l, mid);
        merge(l, mid, r);
        cdq(mid + 1, r);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> v[i];
            lv[i] = v[i];
            rv[i] = v[i];
        }
        for (int i = 1, idx, val; i <= m; i++) {
            cin >> idx >> val;
            lv[idx] = min(lv[idx], val);
            rv[idx] = max(rv[idx], val);
        }
        for (int i = 1; i <= n; i++) {
            dp[i] = 1;
        }
        cdq(1, n);
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            ans = max(ans, dp[i]);
        }
        cout << ans << '\n';
        return 0;
    }

五、问题：拦截导弹

一共有 n 个导弹，编号 1 ~ n，表示导弹从早到晚依次到达，每个导弹给定高度 h、速度 v。

你有导弹拦截系统，第 1 次可以拦截任意参数的导弹，但是之后拦截的导弹，高度和速度都不能比前一次拦截的导弹大。

你的目的是尽可能多的拦截导弹，如果有多个最优方案，会随机选一个执行。打印最多能拦截几个导弹，并且打印每个导弹被拦截的概率。

1 ≤ n ≤ 5 * 10⁴，1 ≤ h、v ≤ 10⁹。

测试链接：洛谷 P2487。

六、两遍 dp 拼概率

拦截的序列要求 h 和 v 都不上升，就是最长不上升子序列。长度好算，概率要数方案。

第一遍从左到右，len1[i] 是以 i 结尾的最长长度，cnt1[i] 是达到它的方案数。第二遍从右到左，len2[i] 是以 i 开头的最长长度，cnt2[i] 同理。

第二遍不用另写一套，把 h、v 数组整个反过来，条件就从「不上升」变成「不下降」，再跑一遍同样的 CDQ 就行，跑完把 len2、cnt2 也反转回来。

设最长长度是 len，总方案数是所有 len1[i] == len 的 cnt1[i] 之和。导弹 i 落在某个最优方案里，当且仅当 len1[i] + len2[i] - 1 == len。

它对应的方案数是 cnt1[i] * cnt2[i]，i 在两边各算了一次，长度加了两次所以要减一。于是概率就是下面这个式子。

概率(i) = cnt1[i] * cnt2[i] / 总方案数

剩下的细节是树状数组。它要维护前缀最大值，还要同时维护这个最大值出现了几次：更新时遇到更大的值就替换并重置次数，遇到相等的值就把次数累加。

条件是不上升，下标要反过来用。v 离散化之后取 s - v + 1，原来「v 更小」就变成「下标更大」，前缀查询查到的就是所有 v 不小于当前 v 的状态。

方案数可能非常大，代码里用 double 存，概率按浮点输出。

七、代码：拦截导弹

    
#include <bits/stdc++.h>

    using namespace std;

    struct Node {
        int i, h, v;
    };

    bool Cmp1(Node a, Node b) {
        return a.h > b.h;
    }

    bool Cmp2(Node a, Node b) {
        return a.h < b.h;
    }

    const int MAXN = 50001;
    int n, s;
    int h[MAXN];
    int v[MAXN];
    int sortv[MAXN];

    Node arr[MAXN];

    int treeVal[MAXN];
    double treeCnt[MAXN];

    int len1[MAXN];
    double cnt1[MAXN];

    int len2[MAXN];
    double cnt2[MAXN];

    int lowbit(int i) {
        return i & -i;
    }

    void more(int i, int val, double cnt) {
        while (i <= s) {
            if (val > treeVal[i]) {
                treeVal[i] = val;
                treeCnt[i] = cnt;
            } else if (val == treeVal[i]) {
                treeCnt[i] += cnt;
            }
            i += lowbit(i);
        }
    }

    int queryVal;
    double queryCnt;

    void query(int i) {
        queryVal = 0;
        queryCnt = 0;
        while (i > 0) {
            if (treeVal[i] > queryVal) {
                queryVal = treeVal[i];
                queryCnt = treeCnt[i];
            } else if (treeVal[i] == queryVal) {
                queryCnt += treeCnt[i];
            }
            i -= lowbit(i);
        }
    }

    void clear(int i) {
        while (i <= s) {
            treeVal[i] = 0;
            treeCnt[i] = 0;
            i += lowbit(i);
        }
    }

    void merge1(int l, int m, int r) {
        for (int i = l; i <= r; i++) {
            arr[i].i = i;
            arr[i].h = h[i];
            arr[i].v = v[i];
        }
        sort(arr + l, arr + m + 1, Cmp1);
        sort(arr + m + 1, arr + r + 1, Cmp1);
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].h >= arr[p2].h) {
                p1++;
                more(s - arr[p1].v + 1, len1[arr[p1].i], cnt1[arr[p1].i]);
            }
            query(s - arr[p2].v + 1);
            if (queryVal + 1 > len1[arr[p2].i]) {
                len1[arr[p2].i] = queryVal + 1;
                cnt1[arr[p2].i] = queryCnt;
            } else if (queryVal + 1 == len1[arr[p2].i]) {
                cnt1[arr[p2].i] += queryCnt;
            }
        }
        for (int i = l; i <= p1; i++) {
            clear(s - arr[i].v + 1);
        }
    }

    void cdq1(int l, int r) {
        if (l == r) {
            return;
        }
        int m = (l + r) / 2;
        cdq1(l, m);
        merge1(l, m, r);
        cdq1(m + 1, r);
    }

    void merge2(int l, int m, int r) {
        for (int i = l; i <= r; i++) {
            arr[i].i = i;
            arr[i].h = h[i];
            arr[i].v = v[i];
        }
        sort(arr + l, arr + m + 1, Cmp2);
        sort(arr + m + 1, arr + r + 1, Cmp2);
        int p1, p2;
        for (p1 = l - 1, p2 = m + 1; p2 <= r; p2++) {
            while (p1 + 1 <= m && arr[p1 + 1].h <= arr[p2].h) {
                p1++;
                more(arr[p1].v, len2[arr[p1].i], cnt2[arr[p1].i]);
            }
            query(arr[p2].v);
            if (queryVal + 1 > len2[arr[p2].i]) {
                len2[arr[p2].i] = queryVal + 1;
                cnt2[arr[p2].i] = queryCnt;
            } else if (queryVal + 1 == len2[arr[p2].i]) {
                cnt2[arr[p2].i] += queryCnt;
            }
        }
        for (int i = l; i <= p1; i++) {
            clear(arr[i].v);
        }
    }

    void cdq2(int l, int r) {
        if (l == r) {
            return;
        }
        int m = (l + r) / 2;
        cdq2(l, m);
        merge2(l, m, r);
        cdq2(m + 1, r);
    }

    int lower(int num) {
        int l = 1, r = s, ans = 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (sortv[mid] >= num) {
                ans = mid;
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return ans;
    }

    void prepare() {
        for (int i = 1; i <= n; i++) {
            sortv[i] = v[i];
        }
        sort(sortv + 1, sortv + n + 1);
        s = 1;
        for (int i = 2; i <= n; i++) {
            if (sortv[s] != sortv[i]) {
                sortv[++s] = sortv[i];
            }
        }
        for (int i = 1; i <= n; i++) {
            v[i] = lower(v[i]);
        }
        for (int i = 1; i <= n; i++) {
            len1[i] = len2[i] = 1;
            cnt1[i] = cnt2[i] = 1.0;
        }
    }

    void compute() {
        cdq1(1, n);
        for (int l = 1, r = n; l < r; l++, r--) {
            swap(h[l], h[r]);
            swap(v[l], v[r]);
        }
        cdq2(1, n);
        for (int l = 1, r = n; l < r; l++, r--) {
            swap(len2[l], len2[r]);
            swap(cnt2[l], cnt2[r]);
        }
    }

    int main() {
        scanf("%d", &n);
        for (int i = 1; i <= n; i++) {
            scanf("%d%d", &h[i], &v[i]);
        }
        prepare();
        compute();
        int len = 0;
        double cnt = 0.0;
        for (int i = 1; i <= n; i++) {
            len = max(len, len1[i]);
        }
        for (int i = 1; i <= n; i++) {
            if (len1[i] == len) {
                cnt += cnt1[i];
            }
        }
        printf("%d\n", len);
        for (int i = 1; i <= n; i++) {
            if (len1[i] + len2[i] - 1 < len) {
                printf("0 ");
            } else {
                printf("%.5f ", cnt1[i] * cnt2[i] / cnt);
            }
        }
        printf("\n");
        return 0;
    }

八、复杂度分析

设 n 为序列长度，m 为操作数（第一道）。

操作时间复杂度
题 1 预处理 lv、rvO(n + m)
题 1 每层 merge 合计O(n log n)（排序 O(n log n) 加双指针与树状数组）
题 1 总计O(n log² n)
题 2 离散化O(n log n)
题 2 每遍 CDQO(n log² n)
题 2 总计O(n log² n)（两遍是常数倍）

题 1 每层里的排序是 O(len log len)，一层加起来 O(n log n)，乘上 log n 层是 O(n log²n)。题 2 同理，跑两遍只差一个常数。

空间上，题 1 多了 arr、树状数组和 dp，是 O(n)；题 2 多了两遍的 len、cnt，也是 O(n)。

九、最后

这两道题的 merge 都只处理了一个维度的偏序，靠双指针加树状数组收工。约束再多一维的时候，双指针就不够用了，得再往里套一层分治。
