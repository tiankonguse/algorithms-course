2-SAT

一个变量只有两种取值，一条限制只牵扯两个变量，这类判定问题叫 2-SAT。它的解法格外统一：把每个取值假设当成点，把每条限制拆成两条有向边，建出的图里跑一遍强连通分量，可满足性就定了。这一节把点集怎么摆、边怎么连、解怎么取讲清楚，再配两道模版题。

零、背景

判定问题里，每个变量只能取 0 或 1，另外给定一堆限制。每条限制形如「x 取某个值，或者 y 取某个值」，这种只牵扯两个变量的限制叫作子句。

要判断的是：能不能给每个变量定一个值，让所有子句都成立。

如果一条子句里可以有任意多个变量，那就是通用的 SAT 问题，是 NP 完全的，没有多项式做法。子句里变量个数压到两个，问题就从 NP 完全掉回了线性可解，这一步的落差很大。

2-SAT 之所以简单，是因为每条子句都能化成两条单向的蕴含关系，而蕴含关系可以叠在一张图上，叠加之后一遍强连通分量就把整体矛盾筛干净了。

一、问题

n 个变量，取值 0 或 1。对每个变量 x，把两种可能写成互斥的一对假设：x 与 ¬x。任何一组解里，这两个假设恰好一个成立。

一条子句「x 或 y」，只排除一种情况：x 和 y 同时为假。想清楚它排除了什么，后面转成边就顺手了。

拿两个具体子句感受一下：x == 1 或 y == 1，以及 x == 1 或 y == 0。它们同时成立时，x 必须取 1 吗？

二、朴素做法

最直接的想法是把 2ⁿ 种取值全枚举一遍，每种取值逐条检查子句。n 小的时候能跑，n 一上去就彻底没戏。

也可以换个角度：把每条子句展开成它允许的取值组合，再想办法同时满足所有组合。但子句之间会互相牵制，不把整体枚举一遍就说不清，最后还是绕回 2ⁿ。

这两条路都堵在同一个地方：判定的代价随变量个数指数增长。下面这张对照表就是这个意思。

三、建图：一条子句拆成两条蕴含边

子句 (x ∨ y) 说的是「x、y 至少一个为真」。把这句话换个说法：x 若为假，y 就必须为真；y 若为假，x 就必须为真。

现在把每个取值假设当成一个点，把「若 u 成立，则 v 一定成立」当成一条有向边 u → v。上面那两句就是两条边：¬x → y 和 ¬y → x。

一条子句固定变成两条边。回到四种取值看，只有 (x=0, y=0) 不满足子句，而这两条边正好把「走向违反」的两条路堵死。

四、对称性

建图时有个容易被忽略的细节：边不能只加一条，得成对加。

图上每个点 u 都有一个对立点 ¬u。只要 u → v 在图上，那么 ¬v → ¬u 也必须在图上。

原因在于「u 能推出 v」和「v 不成立就能推出 u 不成立」是同一件事，后者正是前者的逆否命题。一句话成立，它的逆否命题必然成立，两者同真同假。

子句拆边时，这两条边天然就成对出现：¬x → y 的对称边是 ¬y → x，而它正是同一条子句的另外半句。所以只要照「一条子句 → 两条边」的规矩走，对称性自动满足；一旦手写出边，漏掉一条对称边，后面的判定就会给出错误的答案。

五、跑强连通分量，判定与取解

图建好有 2n 个点、2m 条边。跑一遍 Tarjan 或 Kosaraju，求出所有强连通分量。

判定很直接：如果某个变量的两个假设 x 和 ¬x 落在同一个强连通分量里，说明 x 能推出 ¬x、¬x 也能推出 x，互相矛盾，无解。所有变量都不出现这种情况，就有解。

取一组解要绕一下。把每个分量缩成一个点，得到一张 DAG，沿着有向边的方向有一个拓扑序。对每个变量，选拓扑序更靠后的那个假设作为它的取值。

为什么这样取一定自洽？反证一下。假设按规则选了 x=1，可图上有条边把 x=1 推到了 y=0，而按规则 y 该取 1，两者打架。y 该取 1 表示 ¬y 的分量在 y 的分量之前；x=1 推 y=0 表示 x=1 的分量能到 y=0 的分量。再补上对称边 ¬y → ¬x，¬y 的分量又能到 ¬x 的分量。把这些前后关系串起来会绕成一个环，x=1、¬x、y=1、¬y 全挤进同一个分量，和「x 与 ¬x 不同分量」的前提矛盾。所以这种打架不会发生。

Tarjan 的分量编号从汇侧往源侧递增，编号越小越靠后。所以代码里只要比较两个假设的分量编号，取更小的那个即可。

六、模版题

n 个变量，编号 1 到 n，取值 0 或 1。m 条限制，每条给出四个数 x1 v1 x2 v2，含义是「编号 x1 的变量取 v1，或者编号 x2 的变量取 v2」。

给出一组满足所有限制的取值；做不到就输出 IMPOSSIBLE。

点集约定：编号 i 表示变量 i 取 1，编号 i+n 表示变量 i 取 0。一条子句按 v1、v2 的取值分四种情况，每种情况照「子句 → 两条边」拆开。

拿 v1=v2=1 举例，子句是 (x1=1 ∨ x2=1)。x1 若不为 1，x2 就必须为 1，得边 x1+n → x2；对称地有边 x2+n → x1。其余三种情况同理。代码里四个分支各写两行 addEdge，正好对应上面这套拆法。

判定就是检查 belong 数组：只要某个变量 i 和 i+n 同分量就无解。输出时比较 belong[i] 和 belong[i+n]，取编号更小的那个假设。

从子句到解：一步步看着图长出来

两个变量 x、y，配四个假设点。点「下一步」，逐条加入子句、画出蕴含边，最后缩点、判定、取解，再看添一条子句怎么把问题变成无解。

模版题完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 2000001;
    int n, m;

    int head[MAXN];
    int nxt[MAXN];
    int to[MAXN];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, x1, v1, x2, v2; i <= m; i++) {
            cin >> x1 >> v1 >> x2 >> v2;
            if (v1 == 1 && v2 == 1) {
                addEdge(x1 + n, x2);
                addEdge(x2 + n, x1);
            } else if (v1 == 0 && v2 == 1) {
                addEdge(x1, x2);
                addEdge(x2 + n, x1 + n);
            } else if (v1 == 1 && v2 == 0) {
                addEdge(x2, x1);
                addEdge(x1 + n, x2 + n);
            } else {
                addEdge(x1, x2 + n);
                addEdge(x2, x1 + n);
            }
        }
        for (int i = 1; i <= n << 1; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                check = false;
                break;
            }
        }
        if (check) {
            cout << "POSSIBLE" << "\n";
            for (int i = 1; i <= n; i++) {
                if (belong[i] < belong[i + n]) {
                    cout << "1 ";
                } else {
                    cout << "0 ";
                }
            }
        } else {
            cout << "IMPOSSIBLE" << "\n";
        }
        return 0;
    }

七、第二道模版：和平委员会

n 个团体，每个团体两个代表，编号分别是 2i−1 和 2i。m 条讨厌关系 x y：代表 x 和代表 y 不能同时入选。每个团体恰好选一个代表，要求选出的代表之间没有讨厌关系。

变量是「代表 i 是否入选」。每个团体的两个代表正好互为反面：编号 x 与编号 other(x) 就是同一变量的一对假设，编号方式不再需要额外错开 n 位，省掉一层偏移。

讨厌关系 x、y 说的是「不能同时入选」，也就是子句 ¬x ∨ ¬y。拆成两条边：x → ¬y 与 y → ¬x。代码里 other 函数返回同团的另一个代表，两行 addEdge 就够了。

取解依旧比较分量编号：每个团体挑编号更小的那个假设对应的代表。判定同样是看 2i−1 与 2i 是否同分量。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    const int MAXM = 50001;
    int n, m;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int other(int x) {
        return (x & 1) == 0 ? (x - 1) : (x + 1);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge(u, other(v));
            addEdge(v, other(u));
        }
        for (int i = 1; i <= n << 1; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        bool check = true;
        for (int i = 1, a, b; i <= n; i++) {
            a = i << 1;
            b = a - 1;
            if (belong[a] == belong[b]) {
                check = false;
            }
        }
        if (check) {
            for (int i = 1, a, b; i <= n; i++) {
                a = i << 1;
                b = a - 1;
                if (belong[a] < belong[b]) {
                    cout << a << "\n";
                } else {
                    cout << b << "\n";
                }
            }
        } else {
            cout << "NIE" << "\n";
        }
        return 0;
    }

八、复杂度分析

n 个变量对应 2n 个点，m 条子句对应 2m 条边。建图、求强连通分量、判定取解都是线性的。

步骤时间复杂度空间复杂度
建图（每条子句两条边）O(n + m)O(n + m)
Tarjan 求强连通分量O(n + m)O(n + m)（递归栈 O(n)）
判定与输出一组解O(n)O(n)

点数固定是 2n，边数固定是 2m，两者都是输入的线性倍。模版题的 n、m 到 10⁶，点边规模在千万级以内，几个一维数组就能装下。

Tarjan 用递归写最省事，深度是点数级别，n 到 10⁶ 时要留意递归栈，必要时改成迭代版。空间里占大头的是边表 head、nxt、to 和 tarjan 的 dfn、low、sta、belong，都是与点、边同阶的数组。

九、最后

2-SAT 的全部招式就是这几步：一对点表示一个变量的两种假设，一条子句两条边，跑一遍强连通分量，看对立点是否同分量，最后取拓扑序靠后的那个假设。

真正要练的是把题目里的条件翻译成子句。「二选一」「不能同时」「至少一个」这几种说法都有固定的写法，见得多了一眼就能翻。

这套做法还有一处不够顺的地方：当一条子句里出现「某一段前缀（或区间）里的所有点都要连边」时，逐个连边会退化成平方级别。把这段压成常数条边的前缀技巧在前缀优化建图；三道「条件怎么翻译成子句」的经典题（宇航员、约束条件、同谋者）在2-SAT 的巧妙建图里；更复杂的建图手法在2-SAT 与优化建图的更多题目里接着讲。
