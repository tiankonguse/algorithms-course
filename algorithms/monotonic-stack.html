单调栈：两侧最近更小与每日温度

每个位置都想找左右两侧「最近且比它小」的位置，暴力是 O(n²)。单调栈用「每个位置入栈一次、最多出栈一次」把总代价压成 O(n)，还顺手解决重复值怎么算的细节。

零、背景

n 个数的数组，每个位置 i 问两件事：左边离 i 最近且值比 arr[i] 小的位置在哪，右边离 i 最近且值比 arr[i] 小的位置在哪。没有就记 -1。

直接做法是每个位置向两边扫。最坏情况（升序数组，每个位置左边全是更小的）O(n²)，n = 10⁶ 时是 10¹² 次比较，跑不完。问题在于每个位置的信息被反复重扫，没有复用。

单调栈的观察：位置 i 能成为谁的「右边最近更小」？它左边那些比它大的、还在等答案的位置。反过来，位置 i 的「左边最近更小」一定在它入栈前已经就位。把这两个关系维护好，一趟就能结清。

一、单调栈过程

栈底到栈顶严格递增。新位置 i 来，先把栈顶中值 ≥ arr[i] 的全部弹出，再入栈。被弹出的 cur 结算：左边更小 = 弹出后的新栈顶（栈单调递增，栈里剩的值都 < arr[cur]），右边更小 = 当前 i（就是它把 cur 顶出去的）。

均摊 O(n) 的根据很简单：每个位置只入栈一次，出栈也最多一次，整个过程的弹出次数 ≤ n。别被「while 弹出」吓到。每个位置出栈最多一次，所有弹出加起来 ≤ n，摊到 n 次入栈里就是 O(1)。

栈里剩下没弹出的位置，右边没有更小的，清算时右答案记 -1。左边答案从入栈那一刻就确定了，不需要修正；右边答案要修正，原因就是重复值。

二、重复值：弹出条件与修正阶段

弹出条件写成 arr[栈顶] >= arr[i]，相等的旧位置会被新位置顶出去。拿 [1, 2, 2, 1] 看：位置 2 的值也是 2，位置 1 弹出时「右边最近更小」被记成位置 2，可题目要严格小于，2 不小于 2。

修正阶段从右往左跑一遍：如果某位置的右侧答案位置上的值和自己相等，就把右侧答案改成那个位置的右侧答案，一步跳到真正更小的位置。从右往左保证跳的时候，目标位置的右侧答案已经修正完。

这里有个细节：相等值让「哪个位置作为答案」的归属变了，但每个位置的答案本身还是唯一确定的。栈用 >= 还是 > 弹出，取决于题目要不要严格。这一页的模版题是严格小于，所以 >= 弹出 + 修正。

三、模版题：左右两侧最近更小的位置

输入 n 和数组，输出每个位置左右两侧最近且值更小的下标，没有的写 -1。牛客的单调栈模版题，三阶段写全：遍历结算、清算、修正。

#include <bits/stdc++.h>
    using namespace std;

    // 每个位置左右两侧最近且严格更小的位置，-1 表示不存在
    vector<pair<int, int>> leftRightLess(vector<int>& arr) {
        int n = arr.size();
        vector<int> stk;
        vector<pair<int, int>> ans(n, {-1, -1});
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && arr[stk.back()] >= arr[i]) {
                int cur = stk.back();
                stk.pop_back();
                ans[cur].first = stk.empty() ? -1 : stk.back();   // 左：弹后栈顶
                ans[cur].second = i;                              // 右：当前 i
            }
            stk.push_back(i);
        }
        while (!stk.empty()) {                                    // 清算：右边没有更小
            int cur = stk.back();
            stk.pop_back();
            ans[cur].first = stk.empty() ? -1 : stk.back();
            ans[cur].second = -1;
        }
        for (int i = n - 2; i >= 0; i--) {                        // 修正：跳过相等的右侧邻居
            if (ans[i].second != -1 && arr[ans[i].second] == arr[i]) {
                ans[i].second = ans[ans[i].second].second;
            }
        }
        return ans;
    }

复杂度 O(n)：三趟循环各 O(n)，修正那趟从右往左也是 O(n)。空间 O(n) 是栈和答案数组。

四、每日温度

每日温度问的是「右边最近且更大的位置距离」，找更大的，单调栈反过来：栈底到栈顶递减，新温度大于栈顶时弹出，弹出时结算 i - cur。

等值处理也反过来：弹出条件用 arr[栈顶] < arr[i]，相等的温度不会把旧位置顶出去，因为题目要严格更大。拿 [73,74,75,71,69,72,76,73] 走一遍，答案是 1 1 4 2 1 1 0 0：75 那天等 4 天到 76，71 等 2 天到 72，最后两个位置之后没有更高温度记 0。

演示 1 · 单调栈逐帧：新位置把栈顶中 ≥ 自己的全弹出并结算左右更小

演示 2 · 每日温度逐帧：新温度更大时弹出并记距离

#include <bits/stdc++.h>
    using namespace std;

    // 右侧最近且更大的位置距离，没有记 0
    vector<int> dailyTemperatures(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, 0);
        vector<int> stk;                    // 底到顶递减，等值不弹
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && nums[stk.back()] < nums[i]) {
                int cur = stk.back();
                stk.pop_back();
                ans[cur] = i - cur;
            }
            stk.push_back(i);
        }
        return ans;
    }

复杂度 O(n)，n 是温度天数。每日温度 n 上限 10⁵，单调栈一趟跑完，比每个位置向后找更大（最坏 O(n²)）快得多。

六、总结

单调栈把「每个位置左右两侧最近的边界」一次结清：底到顶单调，弹出即结算，左边是弹后栈顶、右边是当前元素。重复值是唯一的坑，弹出条件用 >= 还是 > 决定要不要修正阶段。

左右更小和左右更大只是单调方向换一下。下一页用同一套栈算子数组最小值之和，每个位置作为最小值覆盖的子数组数，正好是左右边界夹出来的矩形。
