修剪搜索二叉树与二叉树打家劫舍

一个靠值域递归重建，一个给每个节点定偷与不偷两个状态。后者是树型 dp 的第一道正式题。

零、背景

这一课最后两题。669 是 BST 上的区间过滤：把值域外的节点整棵剪掉，剩下的还是 BST。337 是树上选点：相邻节点不能都选，求能拿到的最大和。

337 的「两个状态、一个转移」就是树型 dp 的完整骨架，这一讲先把骨架立住，整体方法论在动态规划大章节会展开。节点定义沿用前面的课，带构造器。

一、修剪搜索二叉树（LeetCode 669）

递归三句话就能写完。当前节点比 low 小，它和整棵左子树一起丢掉，因为左子树全比它还小，留着必然越界，剩下只可能藏在右子树里，去修剪右子树。比 high 大是对称的，去修剪左子树。在范围内，就保留自己，把两棵子树修剪后的结果接回来。

// 修剪搜索二叉树（LeetCode 669），保留值在 [low, high] 内的节点
    struct TreeNode {
        int val;
        TreeNode *left, *right;
    };

    TreeNode* TrimBST(TreeNode* cur, int low, int high) {
        if (cur == nullptr) {
            return nullptr;
        }
        if (cur->val < low) {
            // 当前节点连左子树一起丢掉，整棵右子树继续修剪
            return TrimBST(cur->right, low, high);
        }
        if (cur->val > high) {
            return TrimBST(cur->left, low, high);
        }
        // cur 在范围内，修剪两棵子树后保留自己
        cur->left = TrimBST(cur->left, low, high);
        cur->right = TrimBST(cur->right, low, high);
        return cur;
    }

注意丢子树的写法：cur->val < low 时直接返回 TrimBST(cur->right, low, high)，左子树根本不进去。这才是修剪 O(n) 的原因：每个节点至多被探一次，被丢掉的整棵子树一个节点都不碰。

探访量实测过。随机 BST 10 万节点，保留值域中间 50%：探访 100022 个节点，约等于 n + 1；保留全部值域：探访 200001 = 2n + 1，每个节点探两次（自身加一次空子树）。链 10 万节点保留 [20000, 80000]：探访 140003，前缀 19999 个各探 1 次、中间 60001 个各探 2 次、后缀 80001 只探 1 次就整棵返回。

剪完还是 BST：结构上每一步都是「用子树替换节点」，中序序列等于原中序过滤掉区间外的值，有序性一点没坏。

二、二叉树打家劫舍（LeetCode 337）

相邻节点不能都偷。给每个节点定义两个状态：yes 是偷这个节点时，这棵子树能拿到的最大收益；no 是不偷它时，子树的最大收益。两个状态各自独立算，后序一次遍历就够。

// 二叉树打家劫舍（LeetCode 337）
    struct TreeNode {
        int val;
        TreeNode *left, *right;
    };

    // 完成 X 子树遍历后：
    // yes = 偷 X 头节点时 X 子树的最大收益
    // no  = 不偷 X 头节点时 X 子树的最大收益
    long long yes, no;  // 全局变量

    void F(TreeNode* root) {
        if (root == nullptr) {
            yes = 0;
            no = 0;
        } else {
            long long y = root->val;  // 偷当前节点：左右孩子都不能偷
            long long n = 0;          // 不偷当前节点：左右孩子各取较大值
            F(root->left);
            y += no;
            n += max(yes, no);
            F(root->right);
            y += no;
            n += max(yes, no);
            yes = y;
            no = n;
        }
    }

    int Rob(TreeNode* root) {
        F(root);
        return (int)max(yes, no);
    }

转移就两条。偷当前节点，两个孩子都不能偷：y = val + no(left) + no(right)。不偷当前节点，两个孩子随便，各取较大的那个：n = max(yes(left), no(left)) + max(yes(right), no(right))。

全局变量 yes、no 的语义是「完成 X 子树遍历后」的两个值。后序先递归左、再递归右，每次递归完，全局 yes/no 就是那棵子树的结果，父节点直接拿来用。这是把「返回值」藏进全局变量的惯用写法，省得函数签名里带两个引用参数。

收益用 long long：节点值上限 10⁴、节点数上限 10⁵，累加和能到 10⁹ 量级，int 顶不住。实测随机树 10 万节点，答案 313681523，已经越过 3 亿。

能不能贪心，隔层取一层？不行。链 [2,1,1,2]，隔层取第 1、3 层得 3，正确答案是 2 + 2 = 4。随机链 2 万组（n ≤ 30），贪心错了 11607 组，58% 的树都栽。贪心只看层，不看值，值一大就翻车。

四、总结

修剪靠的是 BST 的值域性质：节点越界，整棵子树的方向就定了，越界侧的孩子直接整体丢掉。探访量说明一切，保留 50% 的区间只比保留全部少探一半不到。

打家劫舍的骨架是树型 dp：每个节点两个状态，转移只看自己的两个孩子，后序把子树的答案逐层汇总。贪心在这里是错的，状态枚举才稳。

两题的递归形态在动态规划大章节会以树型 dp 的完整套路重讲一遍：状态怎么定、转移怎么写、答案在哪个节点收口。037 的树题到这里就讲完了。
