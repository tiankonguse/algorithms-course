达标子数组的个数：归并分治与树状数组

子数组的累加和落在 [lower, upper] 里就算达标。前缀和把它改写成「两个前缀和之差落在一个区间」，问题立刻变成数点对。n 到 10 的 5 次方，两两枚举是 5 × 10 的 9 次方次比较，得换办法。两种做法都能做到 O(n log n)：归并分治常数更小，树状数组配离散化更好懂。

零、背景

前缀和是处理子数组统计的常备工具。令 s[i] 为前 i 个数的和，那么子数组 (l..r) 的和就是 s[r] - s[l-1]。这一句把「一段连续区间」压成「两个点」，后面所有推导都在这两个点上做。

麻烦在于前缀和本身没有范围。nums[i] 可以是任意整数，n 是 10 的 5 次方，s[i] 能跑到正负 10 的 14 次方量级，既不能当下标，也不能指望它单调。所以两种做法都要先解决「值域无界」这件事：一个用排序把它变有序，一个用离散化把它压成名次。

一、问题

给定长度 n 的数组 nums 和两个整数 lower、upper。子数组达标的条件是累加和在 [lower, upper] 范围上，返回达标子数组的个数。

数据范围：1 <= n <= 10^5，nums[i] 可能是任意整数，-10^5 <= lower <= upper <= +10^5。注意 lower 可以是负数，nums[i] 也可以是负数，答案最大是 n*(n+1)/2，会超过 int，统计变量要用 long long。

二、前缀和改写成数点对

记 s[i] = nums[0] + ... + nums[i]，另外补一个 s[-1] = 0。子数组 (l..r) 达标就是：

把不等式挪一挪，条件是 s[r] - upper <= s[l-1] <= s[r] - lower。也就是说，扫到位置 r 时，只要知道前面已经出现过的前缀和里有多少个落在 [s[r]-upper, s[r]-lower] 这一段值域上，就把这个数加到答案里。

「前面出现过的值里，有多少个落在某段值域上」这句话，正是树状数组的模板问题。剩下的问题是值域太大，以及值可能是负数。

三、归并分治

先看不依赖离散化的做法。把前缀和数组 s[0..n-1] 拿去分治，f(l, r) 返回「下标对 (a, b) 都落在 [l, r] 里、a < b、且 s[b] - s[a] 达标」的个数。

左右两半各自的答案递归算。跨中点的那些对，左端点在左半、右端点在右半，下标大小关系天然满足，于是只剩值域条件。左半和右半在归并之后都是有序的，对每个右半的元素 s[i]，左半里满足条件的是一段连续区间，用两个指针框出来就行。

这里有个细节值得盯一下：窗口 [wl, wr) 是左闭右开，wr 用的是 <= 而 wl 用的是 <，正好对应值域区间的两个端点一个是闭的一个也是闭的。写成两个 < 或者两个 <=，边界上的样例就会差一个。

int countRangeSum(int n, int lower, int upper) {
        sumv[0] = nums[0];
        for (int i = 1; i < n; i++) {
            sumv[i] = sumv[i - 1] + nums[i];
        }
        lowv = lower;
        upv = upper;
        return f(0, n - 1);
    }
const int MAXN = 100001;
    long long sumv[MAXN], helpv[MAXN];
    int lowv, upv;

    int mergeCnt(int l, int m, int r) {
        int ans = 0;
        int wl = l, wr = l;
        long long mx, mn;
        for (int i = m + 1; i <= r; i++) {
            mx = sumv[i] - lowv;
            mn = sumv[i] - upv;
            while (wr <= m && sumv[wr] <= mx) wr++;
            while (wl <= m && sumv[wl] < mn) wl++;
            ans += wr - wl;
        }
        int p1 = l, p2 = m + 1, i = l;
        while (p1 <= m && p2 <= r) {
            helpv[i++] = sumv[p1] <= sumv[p2] ? sumv[p1++] : sumv[p2++];
        }
        while (p1 <= m) helpv[i++] = sumv[p1++];
        while (p2 <= r) helpv[i++] = sumv[p2++];
        for (i = l; i <= r; i++) sumv[i] = helpv[i];
        return ans;
    }

    int f(int l, int r) {
        if (l == r) {
            return lowv <= sumv[l] && sumv[l] <= upv ? 1 : 0;
        }
        int m = (l + r) / 2;
        return f(l, m) + f(m + 1, r) + mergeCnt(l, m, r);
    }

递归深度是 log n，每层合并是 O(n)，总时间 O(n log n)。额外空间只有一个 help 数组，O(n)。

四、树状数组加离散化

换个角度：值域大这件事，其实只用到「相对大小」。我们从来不问「前缀和等于多少」，只问「有多少个前缀和不超过某个值」。那么把所有会出现的前缀和排个序、去重，用名次代替原值就够了。

rank(v) 的定义是「sorted 里小于等于 v 的最大名次」，找不到就返回 0。有了它，「不超过 v 的个数」就是树状数组的前缀和 presum(rank(v))。

int rankv(long long v) {
        int left = 1, right = m, mid;
        int ans = 0;
        while (left <= right) {
            mid = (left + right) / 2;
            if (sorted[mid] <= v) {
                ans = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans;
    }
void add(int i, int c) {

    int presum(int i) {
        int ans = 0;
        while (i > 0) {
            ans += tree[i];
            i -= i & -i;
        }
        return ans;
    }

主流程：扫每个位置，先算出当前前缀和 s，用它去查「已经出现过的前缀和里有多少个落在 [s-upper, s-lower]」，再把 s 自己插进树状数组。

int countRangeSum(vector<long long>& nums, int lower, int upper) {
        build(nums);
        long long s = 0;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            s += nums[i];
            ans += presum(rankv(s - lower)) - presum(rankv(s - upper - 1));
            if (lower <= s && s <= upper) {
                ans++;
            }
            add(rankv(s), 1);
        }
        return ans;
    }

这里有个细节：离散化的集合是 s[0..n-1] 这 n 个前缀和，s[-1] = 0 那个空前缀并不在里面。所以「子数组从 0 开始」这种情况查不到，得单独补一句判断累加。漏掉这一句，全是正数的样例会少算一截。

还有一处容易写错：查询用的是 rank(s - upper - 1) 而不是 rank(s - upper) 再减一。因为 s - upper - 1 这个值本身不在集合里，rank 会把它向下取到最接近的那一档，减一的操作交给二分自己完成，比手算稳妥。

复杂度分析

两种做法的规模都是 n。

做法时间额外空间
枚举两端点O(n²)O(n)
归并分治O(n log n)O(n)
树状数组 + 离散化O(n log n)O(n)

归并分治：递归式 T(n) = 2T(n/2) + O(n)，展开得 O(n log n)。额外空间只有 help 数组与 sum 数组，都是 n 个 long long，按题目上限 n = 10 的 5 次方算，合计约 1.6 MB。

树状数组：离散化排序 O(n log n)，之后每个位置做两次 rank（各 O(log n)）、两次 presum、一次 add，合计 O(n log n)。空间是排序数组 n 个 long long 加树状数组 n 个 int，约 1.2 MB。

常数上归并分治更好：它的内层是指针移动，没有二分和位运算。树状数组的理解成本低一些，代码里那些模板函数可以直接搬。

总结

这道题的关键一步是前缀和改写：子数组的统计问题变成值域上的计数问题，前缀和的值域无界由离散化解决，有序性由归并过程自带。两种做法其实是同一件事的两种落地：归并分治在排序的过程中顺手统计，树状数组先排序再用名次统计。

几个容易写错的地方：s[-1] = 0 要单独判断、值域区间的两个端点一个用 < 一个用 <=、统计变量开 long long。这些在 n 很小的样例上不一定暴露，交上去才会挂。往后的「按值域统计」类题目，思路都是这个路子：先问清楚要查什么量，再看这个量能不能用树状数组或者线段树维护。
