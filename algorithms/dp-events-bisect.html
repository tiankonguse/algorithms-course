参加会议 II：二分定位前驱

n 个会议，最多参加 k 个，时间不能重叠，求最大收益。按结束时间排序后，「选当前会议」要接的上一场是结束时间最靠右的不冲突会议，这个位置可以二分，把每行转移里的枚举省掉。

零、背景

给 n 个会议，每个有开始时间、结束时间、收益三个值。参加一个会议必须完整参加完，同一时间只能参加一场。结束时间是包含在会议里的：一个会议的结束时间等于另一个会议的开始时间，两场就撞了。最多参加 k 个，问能拿到的收益最大和。

限制是 n × k ≤ 10⁶，开始和结束时间最大到 10⁹。时间范围太大，不能拿时间点当状态；n 和 k 都不小，每行转移要是还枚举前面的所有会议，O(n²k) 直接超。

一、按结束时间排序，dp[i][j] 记前缀

把会议按结束时间从小到大排序。dp[i][j] 表示 0..i 号会议里最多选 j 个能拿到的最大收益。对第 i 个会议，两条路：

不选它，收益 dp[i−1][j]；选它，那它必须是当前选的最后一场，前面的会议都要在它开始之前结束，也就是说要接「结束时间 < events[i] 开始时间」的最右那场 pre 号会议，收益 dp[pre][j−1] + events[i] 的收益。

两个候选取大，dp[i][j] = max(dp[i−1][j], dp[pre][j−1] + w[i])。边界 pre = −1 表示前面没有不冲突的会议，这时选它自己就是收益 w[i]。

二、pre 为什么能二分

「结束时间 < s」是一个前缀性质：按结束时间排序后，满足条件的会议一定聚在数组前段。所以 find(events, i−1, s) 在 0..i−1 上二分，找最后一个结束时间 < s 的位置，O(log n) 一次。

这里有个细节：比较是严格小于。会议结束时间等于另一个会议的开始时间时两场不能都参加，所以 events[mid][1] < s 才放行，等于不行。

dp 表逐步填：看每行 pre 和两条转移

三、代码

排序用结束时间，dp 行内循环 j 从 1 到 k，pre 每行只算一次，整题 O(n log n + nk)：

#include <bits/stdc++.h>
    using namespace std;

    // events[i][0] : 开始时间, events[i][1] : 结束时间, events[i][2] : 收益
    // 在 0..i 范围（已按结束时间排序）里，找结束时间 < s 的最右会议，没有返回 -1
    int Find(vector<vector<int>>& events, int i, int s) {
        int l = 0, r = i, mid, ans = -1;
        while (l <= r) {
            mid = (l + r) / 2;
            if (events[mid][1] < s) {
                ans = mid;
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return ans;
    }

    int MaxValue(vector<vector<int>>& events, int k) {
        int n = events.size();
        sort(events.begin(), events.end(),
             [](auto& a, auto& b) { return a[1] < b[1]; });
        // dp[i][j] : 0..i 范围上最多选 j 个会议召开，最大收益
        vector<vector<int>> dp(n, vector<int>(k + 1, 0));
        for (int j = 1; j <= k; j++) {
            dp[0][j] = events[0][2];
        }
        for (int i = 1; i < n; i++) {
            // 结束时间严格小于 events[i] 开始时间的最后一个会议，才能和 i 同时参加
            int pre = Find(events, i - 1, events[i][0]);
            for (int j = 1; j <= k; j++) {
                // 不选 i 号会议，或者选它：前面接 dp[pre][j-1]，加上 i 的收益
                dp[i][j] = max(dp[i - 1][j],
                               (pre == -1 ? 0 : dp[pre][j - 1]) + events[i][2]);
            }
        }
        return dp[n - 1][k];
    }

四、复杂度分析

排序 O(n log n)，每行一次二分 O(log n)，再加 k 个转移，总 O(n log n + nk)，n × k ≤ 10⁶ 时轻松过。空间 O(nk) 的 dp 表。

五、总结

要点：会议按结束时间排序后，「能接在前面」是一个前缀，二分一次拿到 pre；dp 里 j 这一维管最多选几个，收益全正所以「最多」和「正好」自然对齐；比较用严格小于，等于算冲突。看到「时间不重叠、带权选 k 个」的题，先想能不能按某一维排序把枚举压成二分。
