贪心：排完序再两两配对

一道题要把 nums 改成 target 的样子，一次操作只能把 2 从一个下标搬到另一个下标；另一道题要挑两个人组队，让两人较弱的那一面尽量高。两道题的答案都在一次排序之后的配对里。

零、两道题各自要什么

第一题给两个等长的正整数数组 nums 和 target。一次操作挑两个不同的下标 i、j，让 nums[i] 加 2、nums[j] 减 2。两个数组「相似」指每个值出现的次数都一样。求把 nums 变成与 target 相似的最少操作次数，数据保证一定变得了。

第二题有 n 个员工，每人有推理能力 a 和阅读能力 b。选两个人 i、j 去比赛，推理算 (ai + aj) / 2，阅读算 (bi + bj) / 2，表现取两者中较小的那个。要让表现尽量高，问最高是多少。

第一题的样例：nums = [8,12,6]、target = [2,14,10]。两次操作就够了，先把 6 减 2、8 加 2，再把 4 减 2、12 加 2，得到 [2,10,14]。

两道题的做法完全一样：把两边都排好序，然后按位置配对。区别只在「按什么排」。

一、使数组相似：奇偶分开，各自排序

先看一次操作动了什么。i 加 2、j 减 2，两个下标一个变多一个变少，但每个数的奇偶永远不变。所以 nums 里的奇数只能变成 target 里的奇数，偶数只能变成偶数。

这就是第一处拆分：把 nums 分成奇数段和偶数段，target 也照做，两边的奇数凑一堆、偶数凑一堆。段内怎么排？从小到大排，然后一一对应。

为什么从小到大的顺序配最省？拿两对来看。设 nums 这边有两个数 x1 ≤ x2，target 那边有两个数 y1 ≤ y2。配成 (x1,y1) 和 (x2,y2) 时总距离是 |x1 − y1| + |x2 − y2|；换成交叉的 (x1,y2) 和 (x2,y1)，总距离只会变大。

道理是两条线段要么一个套住另一个，要么互不相交，同序配对时两段距离加起来正好是「较长的那个区间」；改成交叉，两个点各要跑远一点。

配好之后答案就定下来了。设第 i 对的两个数相差 di。一次操作把 2 从一个下标搬到另一个下标，相当于同时把一对的正差和负差各消掉 2，也就是让 Σ|di| 少 4。所以要消掉这 8 的绝对值总和，需要 8 ÷ 4 = 2 次。

写成公式就是 Σ|nums[i] − target[i]| ÷ 4，配对用的是排序后同奇偶段内的同位置元素。

// 使数组相似的最少操作次数：每次挑两个不同下标，一个加 2、一个减 2
    // 每个数的奇偶永远不会变，所以奇数和奇数配、偶数和偶数配
    // 两条链各自排序后一一对应，每次操作能让差值总和减 4，答案就是差值总和除以 4
    int splitOddEven(vector<int>& arr, int n) {
        int oddSize = 0;
        for (int i = 0; i < n; i++) {
            if ((arr[i] & 1) == 1) swap(arr[i], arr[oddSize++]);
        }
        return oddSize;
    }

    long long makeSimilar(vector<int> nums, vector<int> target) {
        int n = nums.size();
        int oddSize = splitOddEven(nums, n);
        splitOddEven(target, n);
        sort(nums.begin(), nums.begin() + oddSize);
        sort(nums.begin() + oddSize, nums.end());
        sort(target.begin(), target.begin() + oddSize);
        sort(target.begin() + oddSize, target.end());
        long long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += abs((long long)nums[i] - target[i]);
        }
        return ans / 4;
    }

这里有个大小上的提醒。n 有 105、值到 109 时，差值总和能到 1014 量级。实测一组 n = 105 的数据，答案是 38267592234，32 位整数已经装不下了，得用 64 位。

二、知识竞赛：按 |a − b| 排序之后找前缀最大

第二题两人配对，推理和阅读哪个更弱？给每个人记 d = a − b，那么两人配对时 X − Y = (di + dj) / 2，谁强谁弱就看两个人的 d 加起来是正是负。

把所有人按 |d| 从小到大排序，让排序靠后的那个人当配对的「第二人」，他的 |d| 不小于前面任何人。假设他的推理是短板，也就是 ai ≤ bi，那么 di ≤ 0，而前面任何人的 |dj| ≤ |di|，于是

di + dj ≤ −|di| + |dj| ≤ 0

也就是阅读那一侧不会比推理那一侧差，两人的表现就是推理的平均值 (ai + aj) / 2。要让这个数最大，第二个人的 a 已经定了，去前面挑 a 最大的那个就行。

对称地，如果他的阅读是短板（ai > bi），就去前面挑 b 最大的那个。整趟只需要两个变量：已扫过的人里最大的 a、最大的 b。复杂度就是一次排序。

样例 {(1,5), (4,4), (7,3), (2,6), (9,1)} 按 |d| 排完是 (4,4) (1,5) (7,3) (2,6) (9,1)，最后一行的答案是 9，也就是表现 9 ÷ 2 = 4.5。程序里 ans 存的是「两倍的表现」，输出时再除以 2。

// 知识竞赛：每人有推理 a 和阅读 b，选两人让 min((ai+aj)/2, (bi+bj)/2) 最大
    // 按 |a - b| 升序排序，靠后的那个人当第二个；他的短板在哪一侧，就配那一侧的前缀最大值
    int quiz(vector<pair<int, int>> p) {
        sort(p.begin(), p.end(), [](const pair<int, int>& x, const pair<int, int>& y) {
            return abs(x.first - x.second) < abs(y.first - y.second);
        });
        int maxA = p[0].first;
        int maxB = p[0].second;
        int ans = 0;
        for (int i = 1; i < (int)p.size(); i++) {
            if (p[i].first <= p[i].second) {
                ans = max(ans, maxA + p[i].first);
            } else {
                ans = max(ans, maxB + p[i].second);
            }
            maxA = max(maxA, p[i].first);
            maxB = max(maxB, p[i].second);
        }
        return ans;
    }

题目关键操作时间空间

时间都花在排序上，扫描本身是 O(n)。实测（n = 106）使数组相似 86.0ms，n = 105 时 7.2ms；知识竞赛 n = 2×105 用 8.6ms。

总结

使数组相似那题分两步定配对：奇偶是操作不变量，所以按奇偶分堆；每堆内部按大小排序后同位置配对，依据是「交叉配对的总距离只会更大」。答案就是差值总和除以 4，因为一次操作恰好让差值总和减 4。数组值和 n 都大的时候记得用 64 位。

知识竞赛那题先给每个人算 d = a − b，按 |d| 排序，再让靠后的人当配对的第二人。这一步把「谁强谁弱」固定住了，于是瓶颈落在哪一侧就确定了，另一边只要前缀最大。两题都说明同一件事：配对题先想办法把顺序定下来，配对就变成按位置取数。
