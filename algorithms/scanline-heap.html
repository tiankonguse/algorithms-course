扫描线：堆与延迟删除

边界从小到大扫过去，每个边界造成的影响先进堆；过期的元素不急着删，等它浮到堆顶再说。包含每个查询的最小区间和天际线，一道题一套流程。

零、背景

扫描线只是一种流程的设计。坐标轴上散布着很多边界：区间的左右端点、矩形的上下边、大楼的左右沿。把它们收集起来排序，从小到大扫过去，每到一个边界就把这个边界造成的影响维护好，扫的过程中顺便统计答案。

边界造成的影响有简单有复杂。影响只是「一个数进集合、一个数出集合、问集合里的极值」，用堆就够；影响是「一整段区间被覆盖或取消覆盖」，要问覆盖总长度，那就得线段树上场。本门讲前一类，后一类放在扫描线与线段树那一门。

一、包含每个查询的最小区间

题意：给 n 个区间 intervals[i] = [l, r] 和 m 个查询 queries[i] = q。对每个查询，答案是所有包含 q 的区间中最短的那个的长度，没有区间包含 q 就答 -1。n 和 m 各自到 10⁵，坐标在 1 到 10⁷ 之间。

一个一个查询枚举所有区间，是 O(nm)，一千万次运算看着不多，两边都取 10⁵ 就是 10¹⁰，超时。慢在每次查询都把全部区间重看一遍，而这些区间对相邻查询的答案往往有贡献。

二、排序之后，问题变了样子

把查询按位置升序排，区间按左端点升序排。扫到查询 q 的时候，所有左端点不超过 q 的区间都可以进集合了；左端点比 q 大的区间先不用管，后面的查询会用到它们。

此时要回答的是：集合里覆盖 q 的最短区间。覆盖 q 就是右端点不小于 q。于是集合要支持三件事：插入一个区间、删掉右端点小于 q 的区间、查最短。插入和查最短堆都行，删除不行，堆只能高效删堆顶。

三、延迟删除：过期也不删，等它到堆顶

办法是堆里放（长度，右端点）两个数，按长度小根。每次查询先看堆顶：它的右端点小于 q，说明这个区间已经盖不住 q 了，删掉，再看下一个；直到堆顶的右端点不小于 q，或者堆空了。这时候的堆顶就是答案。

埋在堆里、同样过期但更长的区间怎么办？不管。它们当不上答案：比堆顶长的区间，只要堆顶没过期就轮不到它们；等堆顶和比堆顶短的那些都被删光，它们自己浮到堆顶，那时候再删也一样。每个区间入堆一次、出堆一次，删除的总次数不会超过 n。

拿 q 等于 7 那一步细看。进场之后堆里是（长 2 端 6）、（长 4 端 4）、（长 6 端 8）、（长 8 端 9）。堆顶（长 2 端 6）最短，但它的右端 6 小于 7，盖不住，删；下一个（长 4 端 4）也盖不住，删；第三个（长 6 端 8）右端 8 不小于 7，它就是答案 6。两个被删的区间从头到尾没有被「翻出来」过，是它们自己浮到堆顶的。

这里有个细节：延迟删除靠的是「堆顶是极值」这一条。换成查第 k 小的结构，堆顶过期不说明别的元素也过期，这套流程就不成立。

四、天际线：同一套流程搬到 x 轴

题意：n 栋楼，第 i 栋是 [l, r, h]，从 x 轴上从左往右看过去，输出轮廓的所有拐点，每个拐点是（横坐标，高度）。两栋楼挨着时中间不输出点，高度不变就不输出。

流程几乎一样：楼按左端点排序，扫描线从左往右；左端点不超过当前位置的楼入堆，堆按高度大根；右端点小于当前位置的楼，浮到堆顶就删；当前高度就是堆顶的高度。高度和上一个位置不一样，就记一个拐点。

坐标要先离散化，x 能到 10⁹。收集每栋楼的 l、r 减 1、r 三个值，排序去重。为什么带上 r 减 1：楼在 [l, r) 上有效，最后一个受影响的离散坐标是 r 减 1，到 r 就该过期；而 r 本身要收集，是为了输出终点那个落回 0 的拐点。

四栋楼扫下来，堆里发生的事可以一句一句数：x 到 1，A 进场，高度 3，输出（1, 3）；x 到 2，B 进场，堆顶变成 4，输出（2, 4）；x 到 5、6、7，A 和 C 先后过期，堆顶一直是 B 的 4，没有新拐点；x 到 8，B 过期，堆空，高度落 0，输出（8, 0）；x 到 9，D 进场，输出（9, 5）；x 到 11，D 过期，输出（11, 0）。

#include <bits/stdc++.h>
    using namespace std;

    vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
        int n = intervals.size(), m = queries.size();
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[0] < b[0];
        });
        vector<vector<int>> ques(m, vector<int>(2));
        for (int i = 0; i < m; i++) {
            ques[i][0] = queries[i];
            ques[i][1] = i;
        }
        sort(ques.begin(), ques.end());
        // 0 : 长度 1 : 影响到的位置
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
        vector<int> ans(m);
        for (int i = 0, j = 0; i < m; i++) {
            for (; j < n && intervals[j][0] <= ques[i][0]; j++) {
                heap.push({intervals[j][1] - intervals[j][0] + 1, intervals[j][1]});
            }
            while (!heap.empty() && heap.top().second < ques[i][0]) {
                heap.pop();
            }
            ans[ques[i][1]] = heap.empty() ? -1 : heap.top().first;
        }
        return ans;
    }

    vector<pair<int, int>> getSkyline(vector<vector<int>>& arr) {
        int n = arr.size();
        // 1) 收集左边界、右边界-1、右边界 2) 排序去重
        vector<int> xs;
        for (int i = 0; i < n; i++) {
            xs.push_back(arr[i][0]);
            xs.push_back(arr[i][1] - 1);
            xs.push_back(arr[i][1]);
        }
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        int m = xs.size();
        // 3) 左边界和右边界，修改成排名值
        for (int i = 0; i < n; i++) {
            arr[i][0] = lower_bound(xs.begin(), xs.end(), arr[i][0]) - xs.begin() + 1;
            // 大楼影响到的右边界，减少1
            arr[i][1] = lower_bound(xs.begin(), xs.end(), arr[i][1] - 1) - xs.begin() + 1;
        }
        // 4) 大楼根据左边界排序
        sort(arr.begin(), arr.end());
        // 0 : 高度 1 : 影响到的位置
        priority_queue<pair<int, int>> heap;
        vector<int> height(m + 1, 0);
        for (int i = 1, j = 0; i <= m; i++) {
            for (; j < n && arr[j][0] <= i; j++) {
                heap.push({arr[j][2], arr[j][1]});
            }
            while (!heap.empty() && heap.top().second < i) {
                heap.pop();
            }
            if (!heap.empty()) {
                height[i] = heap.top().first;
            }
        }
        vector<pair<int, int>> ans;
        for (int i = 1, pre = 0; i <= m; i++) {
            if (pre != height[i]) {
                ans.push_back({xs[i - 1], height[i]});
            }
            pre = height[i];
        }
        return ans;
    }

点「下一步」逐个离散坐标扫过去，看每步哪些楼进场、哪些过期被弹出、堆顶高度怎么变、拐点在哪输出。可以切换三组楼。

五、复杂度分析

项最小区间天际线
排序O(n log n + m log m)O(n log n)
扫描过程O((n + m) log n)O(n log n)
全程O((n + m) log n)O(n log n)
空间O(n + m)O(n)

两道题都是一个元素进堆一次、出堆一次，每次堆操作 O(log n)。天际线的堆最多同时装下全部 n 栋楼，空间就是 O(n)；最小区间要额外存查询的原始下标，空间 O(n + m)。

实测 n 和 m 各 10⁵、坐标 10⁹：最小区间 0.058 秒，天际线 0.076 秒（本机 clang -O2）。

六、总结

扫描线加堆的两道题共享一个骨架：边界排序，逐个进场，堆顶过期就删，堆顶即答案。延迟删除把「从堆中间删元素」这个堆不支持的操作换成了「多删几次堆顶」，代价不变。

天际线比最小区间多做的事只有一件：坐标离散化，且右边界要减 1 再收进离散数组。

最后

一是延迟删除的正确性压在「堆顶是极值」上，维护别的序（第 k 小、中位数）不能照抄。

二是天际线收集坐标时漏掉 r 减 1，楼会多占一个坐标，轮廓上多出一截平台。

三是同一个 x 上有多条边界时，处理顺序在天际线无所谓（取最大高度），在矩形周长并里会直接算错，那是下一门的内容。
