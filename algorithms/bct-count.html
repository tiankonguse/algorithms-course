圆方树上的计数

圆方树建好之后，「删一个点会破坏多少点对」「三元组路径有多少种」「哪些边删了不碍事」这类统计题，全都变成树上的活儿。这一页三道题：两道树形 DP 数点对和三元组，一道树上差分数边。它们共享同一个记账工具，子树里的圆点个数 siz。

零、背景

上一页建的是广义圆方树：割边两点一边也算点双，圆点的邻居全是方点。这页继续用它，并且给每个树节点记一个 siz：子树里的圆点个数。方点自己的 siz 不算它本身，只在 dfs 回溯时把孩子圆点的 siz 累上来。

有了 siz，「一个方向上有多少个原图点」就是 O(1) 的事。计数题的通用姿势是：枚举割点或点双的一侧，另一侧用总数减出来。题目5 的图可能有多个连通区，总数 total 按连通块分开统计，做法不变。

还有一个后面反复用的事实：每条原图边恰好属于一个点双。边双、割边都有自己的归属，挂在圆方树上就是「较深那端的父方点」，题目6 会用到。

一、题目4：城市阻断

给定 n 个点 m 条边的无向连通图。对每个点 i，删掉与 i 相连的所有边，i 本身保留并参与点对统计，问有多少有序点对 (x, y) 互不连通。n 到 10⁵，m 到 5×10⁵。

删掉 i 的所有邻边，等于在圆方树上把圆点 i 摘下来。树散成几份，每一份的圆点集就是原图里的一块：i 的每个邻方点 v 带走下方一块，大小正是 siz[v]；父方向带走一块，大小 n − siz[i]；i 自己单独一块，大小 1。同一块内的点在删边后仍然连通，不同块之间全部断开。

有序不连通对数就是每一块算一遍「块内点数 × 块外点数」再求和：每个有序对 (x, y) 恰好被 x 所在的块计一次。

实现是一次 dfs：回溯到圆点 u 时，每个孩子方点 v 贡献 siz[v] * (n - siz[v] - 1)；所有孩子处理完后补上父块与自身 (n - siz[u]) * (siz[u] - 1) 和 2 * (n - 1)。三段加起来与「逐块 |A|·(n−|A|)」完全等价，只是把 i 自己那份摊进了各个式子里。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXM = 500001;
    int n, m, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int siz[MAXN << 1];
    ll ans[MAXN];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dpOnTree(int u, int fa) {
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dpOnTree(v, u);
                if (u <= n) {
                    ans[u] += 1LL * siz[v] * (n - siz[v] - 1);
                }
                siz[u] += siz[v];
            }
        }
        siz[u] += u <= n ? 1 : 0;
        if (u <= n) {
            ans[u] += 1LL * (n - siz[u]) * (siz[u] - 1);
            ans[u] += 2LL * (n - 1);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntn = n;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1);
        dpOnTree(1, 0);
        for (int i = 1; i <= n; i++) {
            cout << ans[i] << "\n";
        }
        return 0;
    }

二、题目5：铁人两项

给定 n 个点 m 条边的无向图，可能有多个连通区。数三元组 (a, b, c)：三点互不相同，且存在一条从 a 出发、经过 b、最终到 c 的路径，沿途节点不重复。n 到 10⁵，m 到 2×10⁵。

固定 a 和 c，合法的 b 是哪些点？a 到 c 的不重复路径对应圆方树路径，路径上的点都能被「顺路经过」：圆点是被必经的点，本身就能当 b；方点代表一整个点双，路径只占用它的两个方向（进和出），点双里其余的成员都能绕进去当 b 再绕出来。

于是固定 a、c 后，b 的个数 = 路径上圆点的贡献 1，加上路径上方点 f 的贡献 deg(f) − 2，其中 deg(f) 是方点的邻居数，也就是点双的大小。a、c 自身要从总数里扣掉。

直接枚举 a、c 是平方的。换个方向：枚举 b 和「b 被经过的方向」，一次树形 DP 全部数完。圆点 u 当 b：a 在孩子 v 的子树里、c 在外面，贡献 siz[v] * (total - siz[v] - 1)；a 在 u 子树内但不等于 u、c 在外面，贡献 (siz[u] - 1) * (total - siz[u])。方点 u 当「b 所在的点双」：a 从孩子 v 方向进来、c 从父方向出去，b 是剩下 deg(u) − 2 个邻居圆点之一，贡献 siz[v] * (deg[u] - 2) * (total - siz[v])，根方向对称再补一份。

多个连通区各跑一遍 Tarjan 和 DP，total 重置后再累计答案。割边方点 deg = 2，贡献 deg − 2 = 0，正好对应「割边上没有第三个点可以当 b」。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MAXM = 200001;
    int n, m, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int deg[MAXN << 1];
    int siz[MAXN << 1];
    int total;
    ll ans;

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        total++;
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    deg[cntn]++;
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                        deg[cntn]++;
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dpOnTree(int u, int fa) {
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dpOnTree(v, u);
                if (u <= n) {
                    ans += 1LL * siz[v] * (total - siz[v] - 1);
                } else {
                    ans += 1LL * siz[v] * (deg[u] - 2) * (total - siz[v]);
                }
                siz[u] += siz[v];
            }
        }
        siz[u] += u <= n ? 1 : 0;
        if (u <= n) {
            ans += 1LL * (siz[u] - 1) * (total - siz[u]);
        } else {
            ans += 1LL * siz[u] * (deg[u] - 2) * (total - siz[u]);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntn = n;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                total = 0;
                tarjan(i);
                dpOnTree(i, 0);
            }
        }
        cout << ans << "\n";
        return 0;
    }

三、题目6：边的查询

给定 n 个点 m 条边的无向连通图，q 次查询，每次给 x 和 y：所有从 x 到 y 的简单路径上出现过的边里，有多少条边在单独移除后 x 和 y 仍然互相可达。n、m、q 到 2×10⁵。

x 到 y 的简单路径在圆方树上走的是 x 到 y 的树路径；路径每进入一个方点 f，就获得了在 f 的点双内随意绕行的能力。所以「出现过的边」恰好是：路径上每个方点对应的点双内的全部边，一个不多一个不少。

哪些能删？点双内的边数至少是 2 时，删掉任何一条，点双内的点仍然互相连通，否则这条边就是割边，而割边自己撑起一个两点一方点，不会出现在多边的点双里。反过来，方点只有一条边（割边方点）时，这条边删了 x、y 必断。

于是答案 = 路径上「边数至少为 2 的方点」的边数之和。做法分三步：每条原图边挂到它所属的方点上；只有一条边的方点清零；查询时把路径上各点的计数加起来。挂边的位置不用找：一条边的两端必属于同一点双，在树上看，挂到较深那端的父方点就行。

计数挂好之后做一遍自顶向下的前缀和：edgeCnt[u] += edgeCnt[父]。查询 x、y 时答案是 edgeCnt[x] + edgeCnt[y] - edgeCnt[lca] - edgeCnt[lca 的父]，两条根链相加、扣掉 LCA 和 LCA 父亲的根链，剩下的恰好是 x 到 y 路径上每个点的计数各一次，圆点的计数恒为 0，求和的就是路径上的方点。

边的归属与路径求和

还是那八个点的图。先看每条边挂到哪个方点、割边方点怎么清零，再查两组点对。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXM = 200001;
    const int MAXP = 20;
    int n, m, q, cntn;
    int a[MAXM];
    int b[MAXM];

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int dep[MAXN << 1];
    int stjump[MAXN << 1][MAXP];
    int edgeCnt[MAXN << 1];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int x, int y) {
        if (dep[x] < dep[y]) {
            swap(x, y);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[x][p]] >= dep[y]) {
                x = stjump[x][p];
            }
        }
        if (x == y) {
            return x;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[x][p] != stjump[y][p]) {
                x = stjump[x][p];
                y = stjump[y][p];
            }
        }
        return stjump[x][0];
    }

    void dfsCnt(int u, int fa) {
        edgeCnt[u] += edgeCnt[fa];
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dfsCnt(v, u);
            }
        }
    }

    void buildEdgeCnt() {
        for (int i = 1; i <= m; i++) {
            int fa = stjump[a[i]][0];
            int fb = stjump[b[i]][0];
            if (fa == fb || stjump[fa][0] == b[i]) {
                edgeCnt[fa]++;
            } else {
                edgeCnt[fb]++;
            }
        }
        for (int i = n + 1; i <= cntn; i++) {
            if (edgeCnt[i] == 1) {
                edgeCnt[i] = 0;
            }
        }
        dfsCnt(1, 0);
    }

    int query(int x, int y) {
        int xylca = getLca(x, y);
        int lcafa = stjump[xylca][0];
        return edgeCnt[x] + edgeCnt[y] - edgeCnt[xylca] - edgeCnt[lcafa];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntn = n;
        for (int i = 1; i <= m; i++) {
            cin >> a[i] >> b[i];
            addEdge1(a[i], b[i]);
            addEdge1(b[i], a[i]);
        }
        tarjan(1);
        dfs(1, 0);
        buildEdgeCnt();
        cin >> q;
        for (int i = 1, x, y; i <= q; i++) {
            cin >> x >> y;
            cout << query(x, y) << "\n";
        }
        return 0;
    }

四、复杂度分析

三道题的预处理都是一两遍 dfs，题目6 的查询侧要一个倍增 LCA。

操作时间复杂度空间复杂度
建圆方树O(n + m)O(n + m)
题目4、5 树形 DPO(n + m)O(n + m)，答案数组 64 位
题目6 建边归属 + 前缀和O(n + m)O((n + m) log n)（倍增表）
题目6 一次查询O(log n)

题目4 的答案最大接近 n²，要用 long long；题目5 的贡献式三个因子相乘，同样 64 位。题目6 挂边时按输入顺序遍历 m 条边，每条 O(1) 定位方点，没有排序也没有额外数据结构。

五、最后

这一页的三个统计对象不同，骨架是一样的：把「删掉谁、经过谁、绕过谁」翻译成圆方树上的一侧，另一侧用 siz 或 total 减出来。方点的 deg 顺便承担了「点双大小」的角色，铁人两项里 deg − 2 这个因子就是它。

题目6 还给出一个更 general 的技巧：把边权挂到点上、前缀和配 LCA 差分，路径点权和一次查询解决。下一页把这个技巧配合树链剖分与线段树，做带修改的路径查询。
