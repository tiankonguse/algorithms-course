高斯消元解同余方程组：工具工厂

工厂有 n 种工具，每种制作天数固定但数据丢了，只有工人的工作记录：某天开始、某天结束、中间加工了哪些工具。靠这些记录把天数推断出来，还要判断记录是不是互相矛盾、天数能不能唯一确定。这是同余方程组完整模板的应用：判定矛盾、多解、唯一解三种情况。

零、题意：从周几到周几，做了哪几件工具

一共有 n 种工具（编号 1~n），m 条记录。一条记录的格式：

4 WED SUN 13 18 1 13

意思是：一个工人一共加工 4 件工具，从某个星期三开始，到某个星期天结束，加工的依次是 13 号、18 号、1 号、13 号。工作期间不休息，每件工具串行加工，做完一件才开始下一件。每种工具制作天数固定，3 到 9 天，但数据丢失了。

要求：记录矛盾 → Inconsistent data.；无法确定 → Multiple solutions.；能确定 → 打印所有工具的天数。n、m ≤ 300。

一、每条记录变成一行方程

设 xt 是工具 t 的制作天数。一条记录给出：Σ（工具出现次数 × 天数）≡ 周日数 (mod 7)。系数就是该工具在这条记录里出现了几次，常数是 (结束日 − 开始日 + 1) mod 7，周日用 MON=0 … SUN=6 编号。

样例里「4 WED SUN 13 18 1 13」：工具 13 出现 2 次、18 出现 1 次、1 出现 1 次，常数 = SUN(6) − WED(2) + 1 = 5。这一行是 2x13 + x18 + x1 ≡ 5 (mod 7)。

方程个数 m 可能比工具数 n 少。模板统一把矩阵扩成 s = max(n, m) 行，不足的补全 0 行。下面是记录读入和建矩阵：

// 题目2：把每条记录变成一行方程
    // 记录"4 WED SUN 13 18 1 13"：共 4 件，周三做到周日
    // 工具出现次数为系数，总天数为常数（mod 7）
    void prepare() {
      for (int i = 1; i <= s; i++) {
        for (int j = 1; j <= s + 1; j++) {
          mat[i][j] = 0;
        }
      }
      for (int i = 1; i <= m; i++) {
        int k = readInt();  // 本记录加工了几件工具
        string st = readString();
        string et = readString();
        for (int j = 1; j <= k; j++) {
          int tool = readInt();
          mat[i][tool] = (mat[i][tool] + 1) % MOD;
        }
        // 周日数：(结束日 - 开始日 + 1) mod 7
        mat[i][s + 1] = ((day(et) - day(st) + 1) % MOD + MOD) % MOD;
      }
    }

二、消元后的三种判定

消元直接用上一节的完整模板（保留主元与自由元关系）。消完之后扫对角线：

某行主元系数是 0 但常数不是 0 → 这一行是 0 = 非 0，矛盾；前 n 行里有行没有主元 → 自由元存在，多解；否则唯一解，直接读常数。

// 题目2：判定矛盾、多解、唯一解
    gauss(s);
    int sign = 1;
    for (int i = 1; i <= s; i++) {
      // 系数全 0 但常数非 0：矛盾
      if (mat[i][i] == 0 && mat[i][s + 1] != 0) {
        sign = -1;
        break;
      }
      // 前 n 行里有行没有主元：多解
      if (i <= n && mat[i][i] == 0) {
        sign = 0;
      }
    }
    if (sign == -1) {
      cout << "Inconsistent data." << endl;
    } else if (sign == 0) {
      cout << "Multiple solutions." << endl;
    } else {
      // 制作天数在 3 到 9 之间，小于 3 时加 7 恢复
      for (int i = 1; i <= n; i++) {
        if (mat[i][s + 1] < 3) {
          mat[i][s + 1] += 7;
        }
      }
      for (int i = 1; i <= n; i++) {
        cout << mat[i][s + 1] << (i == n ? "\n" : " ");
      }
    }

唯一解时有个收尾：消元结果是 mod 7 的值（0~6），而题目说制作天数在 3 到 9 之间。0~6 里唯一可能是 3~6 或 7（即 0），所以小于 3 就加 7，7 对应 0。上页样例的输出就是 8 3：8 ≡ 1，3 ≡ 3。

同一套模板跑三个记录集：官方样例（唯一解）、两条相同记录（多解）、样例加一条冲突记录（矛盾）。看消元后主元怎么分布，判定怎么落到三种输出。

四、总结

工具工厂题把「记录」翻译成模 7 的线性方程：出现次数是系数、周日差是常数，补到 s = max(n, m) 行。完整模板消元后按对角线判定：0 系数配非 0 常数是矛盾，前 n 行缺主元是多解，否则唯一解，最后小于 3 的值加 7 恢复成 3~9 的天数。同余方程组这一节到此闭环：加法、异或、同余三种方程，模板的核心差异只在归一化（除、异或、乘逆元）和消元动作（减、异或、gcd 缩放）。
