线段树维护最小值：基站选址

一排村庄，选最多 k 个位置建基站，没被覆盖到的村庄要赔钱。状态定为「最右的基站建在 i」，转移要枚举上一个基站 p 并算中间村庄的赔偿。赔偿是「随着最右基站右移而不断暴露」的量，正好用线段树维护最小值加区间加一次扛下：叶子 p 存「dp[t-1][p] + 已暴露赔偿」，扫到 i 先查前缀最小值，再给会失服务的候选区间加赔偿。

零、背景

覆盖类 DP 的常规做法是把「最后一个被选对象的位置」放进状态，然后枚举上一个。这题的数据是村庄在一条线上，基站装在村庄位置上，覆盖范围是一个以村庄为中心的区间。真正难算的是「没覆盖到的村庄要赔」这笔动态的账：最右基站每往右挪一步，就可能有几个村庄从「被服务」变成「失服务」，赔偿要重新算。

一、问题

n 个村庄排成一排，dist[i] 是 i 号到 1 号的距离（有序无重复），fix[i] 是在 i 号建基站的费用，range[i] 是 i 号村庄的接收范围（基站到它的距离不超过这个数就得到服务），warranty[i] 是它没被任何基站服务时的赔偿。最多选 k 个村庄建基站，返回总花费最小值。数据范围 1 <= n <= 20000，1 <= k <= 100。

二、预处理：覆盖区间与预警列表

对每个村庄 j，能被哪些基站服务？基站装在村庄位置 p 上，条件是 dist[p] >= dist[j] - range[j] 且 dist[p] <= dist[j] + range[j]。dist 有序，二分两次就能得到服务它的基站位置区间 [left[j], right[j]]：

预警列表是关键装置。对村庄 j，记下 right[j]：当最右基站的位置从 right[j] 挪到 right[j]+1 时，j 就从「被服务」变成「失服务」。把所有这种村庄挂在 right[j] 这个位置下（链式前向星存邻接表），扫到位置 i 时一次拿到「刚越过右边界」的全部村庄。

三、状态与转移

设 dp[t][i] 为「最多建 t 个基站、最右一个建在 i 号、1..i 号村庄的最少花费」。转移枚举上一个基站 p（p < i）：

其中 penalty(p+1..i-1) 是这段村庄里、p 和 i 都覆盖不到的村庄的赔偿和。先看 t=1：只有一个基站建在 i，前面村庄 j < i 只要 right[j] < i 就失服务（left[j] <= i 对 j < i 恒成立），赔偿可以随 i 递增累计。

四、线段树维护最小值

t >= 2 时，内层是「对所有 p 求 dp[t-1][p] + penalty(p+1..i-1) 的最小值」。把每个 p 当作线段树的一个叶子，叶子值 = dp[t-1][p] + 已经暴露的赔偿。i 每前进一位，新暴露的村庄（预警列表里 right[j] == i-1 的那些）会让一部分候选 p 的赔偿变大：

  • j 失服务的前提是 p 也够不到它，即 p < left[j]（p 太靠左）；
  • 所以对每个新暴露的 j，给叶子区间 [1, left[j]-1] 整体加 warranty[j]；
  • 然后 dp[i] = min(dp[i], query(1, i-1) + fix[i])。

注意顺序：先查询、再处理本位置的预警。因为预警加的是「下一个位置才暴露」的赔偿，当前 i 的查询不该看到它们。

五、补一个无穷远村庄

边界处理有个省事的办法：在 dist 末尾补一个 dist = 无穷大 的虚拟村庄，fix、range、warranty 都是 0。最右基站必然有一个「建」在它上面（费用 0，也不产生赔偿），真实村庄最多 k 个基站对应外层循环跑 k+1 轮。这样就不用讨论「最后一个基站之后还有没人赔」：虚拟村庄兜住一切。虚拟村庄的预警列表也会正常生成，left/right 都是它自己，加的赔偿是 0，无副作用。

六、实现

预处理：二分求覆盖区间、生成预警列表（链式前向星）。注意 right[i] 求出来之后要复查一次，二分找到的位置可能恰好差一个距离，超出接收范围要往回退一格：

int search(int d) {
        int l = 1, r = n, m;
        int ans = 0;
        while (l <= r) {
            m = (l + r) / 2;
            if (dist[m] >= d) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans;
    }

    void addEdge(int u, int v) {
        nxt[cnt] = head[u];
        to[cnt] = v;
        head[u] = cnt++;
    }

    void prepare() {
        cnt = 1;
        for (int i = 1; i <= n; i++) {
            lft[i] = search(dist[i] - range[i]);
            rgt[i] = search(dist[i] + range[i]);
            if (dist[rgt[i]] > dist[i] + range[i]) {
                rgt[i]--;
            }
            addEdge(rgt[i], i);
        }
    }

线段树维护最小值，带区间加懒标记，和面包店那题只差 max 换成 min：

void up(int i) {
        segmin[i] = min(segmin[i << 1], segmin[i << 1 | 1]);
    }

    void down(int i) {
        if (lazyadd[i] != 0) {
            lazy(i << 1, lazyadd[i]);
            lazy(i << 1 | 1, lazyadd[i]);
            lazyadd[i] = 0;
        }
    }

    void lazy(int i, int v) {
        segmin[i] += v;
        lazyadd[i] += v;
    }

    void build(int l, int r, int i) {
        if (l == r) {
            segmin[i] = dp[l];
        } else {
            int mid = (l + r) >> 1;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            up(i);
        }
        lazyadd[i] = 0;
    }

    void add(int jobl, int jobr, int jobv, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            lazy(i, jobv);
        } else {
            down(i);
            int mid = (l + r) >> 1;
            if (jobl <= mid) add(jobl, jobr, jobv, l, mid, i << 1);
            if (jobr > mid) add(jobl, jobr, jobv, mid + 1, r, i << 1 | 1);
            up(i);
        }
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) return segmin[i];
        down(i);
        int mid = (l + r) >> 1;
        int ans = INT_MAX;
        if (jobl <= mid) ans = min(ans, query(jobl, jobr, l, mid, i << 1));
        if (jobr > mid) ans = min(ans, query(jobl, jobr, mid + 1, r, i << 1 | 1));
        return ans;
    }

主流程。t=1 层的 w 就是「只建一个基站时前面村庄的累计赔偿」；t>=2 层每轮把上一层的 dp 铺进线段树，边扫边查边加：

int compute() {
        for (int i = 1, w = 0; i <= n; i++) {
            dp[i] = w + fix[i];
            for (int ei = head[i]; ei != 0; ei = nxt[ei]) {
                w += warranty[to[ei]];
            }
        }
        for (int t = 2; t <= k + 1; t++) {
            build(1, n, 1);
            for (int i = 1; i <= n; i++) {
                if (i >= t) {
                    dp[i] = min(dp[i], query(1, i - 1, 1, n, 1) + fix[i]);
                }
                for (int ei = head[i], uncover; ei != 0; ei = nxt[ei]) {
                    uncover = to[ei];
                    if (lft[uncover] > 1) {
                        add(1, lft[uncover] - 1, warranty[uncover], 1, n, 1);
                    }
                }
            }
        }
        return dp[n];
    }

复杂度分析

预处理一次二分 O(n log n)；外层 t 循环 k+1 轮，内层 i 循环 n 次，每次一次查询（O(log n)）加若干次区间加（每个村庄的预警恰好被处理一次，总 O(n log n) 一层的量）。总时间 O(k n log n)，k = 100、n = 20000 时约 10 的 8 次方量级，能过。

空间：线段树两个 n×4 数组加各预处理数组，O(n)。

总结

基站选址把「枚举上一个基站 + 算动态赔偿」压成线段树上的「查询最小值 + 区间加」。三个关键装置：覆盖区间 [left, right] 把服务关系变成数轴上的区间；预警列表把「赔偿什么时候开始」挂在 right[j] 上，每个村庄只被处理一次；虚拟村庄把最后一个基站的边界兜掉。查询和区间加的顺序不能反。

这三题（玉米田、面包店、基站选址）合起来看，树状数组/线段树优化的本质是同一句：把转移内层的枚举换成数据结构维护的量，区别只在要维护的是前缀最值、区间加最值还是区间加最小值。
