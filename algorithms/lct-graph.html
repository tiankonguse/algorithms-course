LCT 维护图结构

LCT 只认树。遇到图上的问题，先得把图变成树能描述的样子：一条边变成 LCT 里的一个点，一整个点双变成一个新点（方点），一个历史版本存一棵可持久化线段树。这一节四道题，分别用到这几种手法，动态找重心、动态维护直径、区间边集上的连通块数，以及在不断加边的图上回答必经边和必经点。

零、背景

前面用到的 LCT 维护的都是一棵棵树。图的麻烦在于两点之间往往不止一条路径，而 LCT 里任意两点之间永远只有一条路径。

常用的转换有三个：

  1. 边转点。给每条边也发一个 LCT 里的编号，边拥有自己的权值和自己的贡献。
  2. 把一个分量压成一个点。出现环的时候，环上所有点从此在「割」的意义上是一整块，用一个方点代替它们。
  3. 给每个时间点存一份。询问来回就在某个版本上查，这种事情交给可持久化线段树。

这一节的四道题依次用到了这三种做法。

一、题目1：首都

初始 n 个点互不连通，m 次操作：

  • A x y：x 和 y 之间加一条边，保证之前不连通。
  • Q x：打印 x 所在连通区的重心编号。
  • Xor：打印当前所有连通区重心编号的异或和。

一个连通区就是一棵树。重心是到其他点距离总和最小的点；有多个重心时规定取编号最小的那个。

查询这件事交给并查集就够了：连通区的代表元就记成这个区的重心。于是 Q 是一次 find，异或和用一个全局变量跟着改。

真正的问题是加边之后，新连通区的重心是谁。

二、新重心在旧重心的路径上

重心有两个说法，这里用不提距离和的那个：一个点 c 是重心，等价于把 c 删掉之后，剩下的每个连通块大小都不超过总数的一半。

设旧的两个连通区重心是 a 和 b，点数分别是 n₁、n₂，这次连的是 x、y。新树可以看成这样一副样子：a 到 b 的那条唯一路径（中间经过 x-y）是主干，两棵旧树的其余部分都挂在这条主干上。

取一个不在主干上的点 c，它一定挂在某个主干节点的下面。把第一棵树以 a 为根来看，c 的整棵子树被包在「删掉 a 之后剩下的某个连通块」里，而 a 是重心，所以这棵子树的大小不超过 n₁/2。

于是删掉 c 之后，包含主干的那一块至少有 (n₁ + n₂) − n₁/2 个点，比总数的一半还多。c 出局。

结论是：新重心只可能落在 a 到 b 的路径上。

于是只要沿着这条路径逐个检查：这个点两边（加上所有虚子树）各有多大。

三、在辅助树上下滑

split(a, b) 之后，整条路径都在 b 的辅助树里，且 sum[b] 就是新连通区的总点数。

接下来就是在这棵 splay 里从上往下滑。滑到某个点时，需要知道它两侧各有多少点：

int newCenter(int a, int b) {
    split(a, b);
    int half = sum[b] >> 1;
    int lpass = 0;
    int rpass = 0;
    int ans = n + 1;
    int cur = b;
    while (cur != 0) {
        down(cur);
        int lsiz = sum[ls[cur]] + lpass;
        int rsiz = sum[rs[cur]] + rpass;
        if (lsiz <= half && rsiz <= half) {
            ans = min(ans, cur);
        }
        if (lsiz < rsiz) {
            lpass += sum[ls[cur]] + vir[cur] + 1;
            cur = rs[cur];
        } else {
            rpass += sum[rs[cur]] + vir[cur] + 1;
            cur = ls[cur];
        }
    }
    splay(ans);
    return ans;
}

lpass 是往左拐的时候攒下来的、已经在身后那部分的点数；rpass 同理是往右走时攒下的。每往下走一层，就得把「当前这个点带着它的虚子树」整体划到另一侧去。

这里有个细节：检查的时候只比了左右两侧，没比挂在 cur 上的那些虚子树。这是有依据的，路径外的分枝每一棵都不可能超过半数，否则重心早跑到那里面去了，与「重心在路径上」矛盾。题目还要求多个重心时取编号最小的，所以每碰到一个合格的点就用 min 更新答案。

splay(ans) 那一步是为了摊平复杂度，顺手把答案旋到辅助树的根。

完整代码：

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100001;
int n, m;

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];
bool rev[MAXN];
int sta[MAXN];

int father[MAXN];
int vir[MAXN];
int sum[MAXN];

int xorsum;

int find(int x) {
    if (x != father[x]) {
        father[x] = find(father[x]);
    }
    return father[x];
}

void up(int x) {
    sum[x] = sum[ls[x]] + sum[rs[x]] + vir[x] + 1;
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void reverse(int x) {
    if (x != 0) {
        swap(ls[x], rs[x]);
        rev[x] = !rev[x];
    }
}

void down(int x) {
    if (rev[x]) {
        reverse(ls[x]);
        reverse(rs[x]);
        rev[x] = false;
    }
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    int siz = 0;
    sta[++siz] = x;
    for (int y = x; !isroot(y); y = fa[y]) {
        sta[++siz] = fa[y];
    }
    while (siz != 0) {
        down(sta[siz--]);
    }
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        vir[x] += sum[rs[x]];
        vir[x] -= sum[y];
        rs[x] = y;
        up(x);
    }
}

void makeroot(int x) {
    access(x);
    splay(x);
    reverse(x);
}

int findroot(int x) {
    access(x);
    splay(x);
    down(x);
    while (ls[x] != 0) {
        x = ls[x];
        down(x);
    }
    splay(x);
    return x;
}

void split(int x, int y) {
    makeroot(x);
    access(y);
    splay(y);
}

void link(int x, int y) {
    makeroot(x);
    if (findroot(y) != x) {
        access(y);
        splay(y);
        fa[x] = y;
        vir[y] += sum[x];
        up(y);
    }
}

int newCenter(int a, int b) {
    split(a, b);
    int half = sum[b] >> 1;
    int lpass = 0;
    int rpass = 0;
    int ans = n + 1;
    int cur = b;
    while (cur != 0) {
        down(cur);
        int lsiz = sum[ls[cur]] + lpass;
        int rsiz = sum[rs[cur]] + rpass;
        if (lsiz <= half && rsiz <= half) {
            ans = min(ans, cur);
        }
        if (lsiz < rsiz) {
            lpass += sum[ls[cur]] + vir[cur] + 1;
            cur = rs[cur];
        } else {
            rpass += sum[rs[cur]] + vir[cur] + 1;
            cur = ls[cur];
        }
    }
    splay(ans);
    return ans;
}

void road(int x, int y) {
    int a = find(x);
    int b = find(y);
    link(x, y);
    int cur = newCenter(a, b);
    father[cur] = father[a] = father[b] = cur;
    xorsum ^= a ^ b ^ cur;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        sum[i] = 1;
        father[i] = i;
        xorsum ^= i;
    }
    string op;
    int x, y;
    for (int i = 1; i <= m; i++) {
        cin >> op;
        if (op == "A") {
            cin >> x >> y;
            road(x, y);
        } else if (op == "Q") {
            cin >> x;
            cout << find(x) << "\n";
        } else {
            cout << xorsum << "\n";
        }
    }
    return 0;
}

四、题目2：查询最远距离

一开始没有点，两种操作：

  • B p：新建一个点并接到 p 上，p 为 -1 时建一个孤立点。
  • Q x：打印 x 到它所在连通块中最远点的距离。

树上有个用得很熟的性质：距离某个点最远的点，一定是直径两个端点的其中之一。所以每个连通区只要维护直径的两个端点和长度就够了。

加一个点进来时，新的直径只有三种可能。

这三个距离都由 LCT 提供：split(x, a) 之后，路径上的点数减一就是距离。

int getDist(int x, int y) {
    split(x, y);
    return siz[y] - 1;
}

这里的 LCT 只有一个 siz，甚至连 vir 都不用，因为每次问的是路径而不是子树。完整代码：

int findroot(int x) {

    makeroot(x);
    access(y);

}

    makeroot(x);
    if (findroot(y) != x) {
        fa[x] = y;
    }
}

int getDist(int x, int y) {
    split(x, y);
    return siz[y] - 1;
}

void build(int p) {
    int x = ++cntn;
    siz[x] = 1;
    father[x] = x;
    dl[x] = x;
    dr[x] = x;
    diameter[x] = 0;
    if (p != -1) {
        int root = find(p);
        int a = dl[root];
        int b = dr[root];
        int best = diameter[root];
        int bestl = a;
        int bestr = b;
        link(x, p);
        int dista = getDist(x, a);
        if (dista > best) {
            best = dista;
            bestl = x;
            bestr = a;
        }
        int distb = getDist(x, b);
        if (distb > best) {
            best = distb;
            bestl = x;
            bestr = b;
        }
        father[x] = root;
        dl[root] = bestl;
        dr[root] = bestr;
        diameter[root] = best;
    }
}

int query(int x) {
    int fx = find(x);
    return max(getDist(x, dl[fx]), getDist(x, dr[fx]));
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> q;
    string op;
    int x;
    for (int i = 1; i <= q; i++) {
        cin >> op;
        cin >> x;
        if (op == "B") {
            build(x);
        } else {
            cout << query(x) << "\n";
        }
    }
    return 0;
}

五、题目3：须臾幻境

无向图 n 个点 m 条边，边的编号是 1 到 m。每次询问给 l、r：只保留编号在 [l, r] 里的边，问有多少个连通块。本题要求强制在线。

「在线」这两个字直接否掉了把询问排个序再做的那一类套路，得让任何一个历史版本都能随时拿来查。

边变成点

先把每条边也变成 LCT 里的一个点：原图的点编号是 x，权值记 INF；第 i 条边的编号是 n + i，权值就是 i。于是「路径上编号最小的边」变成了常规的路径最小值查询。

成环就替换最早出现的边

从 i = 1 到 m 顺序处理，手上始终维护着「前 i 条边的一棵生成森林」。加第 i 条边 (x, y)：

  1. x 和 y 不连通，直接连上。
  2. 已经连通，x 到 y 的路径加上这条边就是个环。这时候查路径上编号最小的那条边 e，把它删掉，再把新边连上。

这么做的意思是：尽量保留编号大的边。于是对任意的 l，当前森林里编号 ≥ l 的那些边，恰好构成 [l, i] 这批边的一棵生成森林。

为什么这件事成立：只要存在一条更晚出现的边能把更早的那条换下来，就一定当面换掉，这条规则换到底的结果，就是「保留的边编号尽可能大」。这样处理完前 i 条边之后，任取一个 l，森林里编号 ≥ l 的边恰好是 [l, i] 这批边的一棵生成森林，其中没有任何一条还能被更晚的边替换。

哪些边留在当前的森林里，用一棵可持久化线段树记录：处理完第 i 条边生成一个版本 root[i]，它是在 root[i-1] 的基础上改两条链。

最后这一步答案就很朴素了：n - query(l, r, 1, m, root[r])。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 300001;
const int MAXT = 10000001;
const int INF = 1000000001;
int n, m, q, t;

int eu[MAXN];
int ev[MAXN];

int fa[MAXN];
int ls[MAXN];
int rs[MAXN];
bool rev[MAXN];
int sta[MAXN];

int val[MAXN];
int minv[MAXN];

int root[MAXN];
int tl[MAXT];
int tr[MAXT];
int num[MAXT];
int cntt;

void up(int x) {
    minv[x] = min(val[x], min(minv[ls[x]], minv[rs[x]]));
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void reverse(int x) {
    if (x != 0) {
        swap(ls[x], rs[x]);
        rev[x] = !rev[x];
    }
}

void down(int x) {
    if (rev[x]) {
        reverse(ls[x]);
        reverse(rs[x]);
        rev[x] = false;
    }
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    int size = 0;
    sta[++size] = x;
    for (int y = x; !isroot(y); y = fa[y]) {
        sta[++size] = fa[y];
    }
    while (size != 0) {
        down(sta[size--]);
    }
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
    up(x);
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        rs[x] = y;
        up(x);
    }
}

void makeroot(int x) {
    access(x);
    splay(x);
    reverse(x);
}

int findroot(int x) {
    access(x);
    splay(x);
    down(x);
    while (ls[x] != 0) {
        x = ls[x];
        down(x);
    }
    splay(x);
    return x;
}

void split(int x, int y) {
    makeroot(x);
    access(y);
    splay(y);
}

void link(int x, int y) {
    makeroot(x);
    if (findroot(y) != x) {
        fa[x] = y;
    }
}

void cut(int x, int y) {
    makeroot(x);
    if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
        fa[y] = rs[x] = 0;
        up(x);
    }
}

int pathMin(int x, int y) {
    split(x, y);
    return minv[y];
}

int add(int jobi, int jobv, int l, int r, int i) {
    int rt = ++cntt;
    tl[rt] = tl[i];
    tr[rt] = tr[i];
    num[rt] = num[i];
    if (l == r) {
        num[rt] += jobv;
    } else {
        int mid = (l + r) >> 1;
        if (jobi <= mid) {
            tl[rt] = add(jobi, jobv, l, mid, tl[i]);
        } else {
            tr[rt] = add(jobi, jobv, mid + 1, r, tr[i]);
        }
        num[rt] = num[tl[rt]] + num[tr[rt]];
    }
    return rt;
}

int query(int jobl, int jobr, int l, int r, int i) {
    if (jobl <= l && r <= jobr) {
        return num[i];
    }
    int ans = 0;
    int mid = (l + r) >> 1;
    if (jobl <= mid) {
        ans += query(jobl, jobr, l, mid, tl[i]);
    }
    if (jobr > mid) {
        ans += query(jobl, jobr, mid + 1, r, tr[i]);
    }
    return ans;
}

void prepare() {
    for (int i = 0; i <= n; i++) {
        val[i] = minv[i] = INF;
    }
    for (int i = 1; i <= m; i++) {
        val[n + i] = minv[n + i] = i;
    }
    for (int i = 1; i <= m; i++) {
        int x = eu[i];
        int y = ev[i];
        root[i] = root[i - 1];
        if (x != y) {
            if (findroot(x) == findroot(y)) {
                int e = pathMin(x, y);
                cut(eu[e], n + e);
                cut(ev[e], n + e);
                root[i] = add(e, -1, 1, m, root[i]);
            }
            link(x, n + i);
            link(y, n + i);
            root[i] = add(i, 1, 1, m, root[i]);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m >> q >> t;
    for (int i = 1; i <= m; i++) {
        cin >> eu[i] >> ev[i];
    }
    prepare();
    for (int i = 1, lastAns = 0, l, r; i <= q; i++) {
        cin >> l >> r;
        if (t > 0) {
            l = (l + t * lastAns) % m + 1;
            r = (r + t * lastAns) % m + 1;
        }
        if (l > r) {
            swap(l, r);
        }
        lastAns = n - query(l, r, 1, m, root[r]);
        cout << lastAns << "\n";
    }
    return 0;
}

六、题目4：LCT 与动态图

初始 n 个孤立点，q 次操作：

  • 1 x y：加一条无向边，两点之前可能已经连通。
  • 2 x y：x 到 y 的路径上有几条必经边，不连通打印 -1。
  • 3 x y：x 到 y 的路径上有几个必经点（含 x 和 y 本身），不连通打印 -1。

必经边就是割边，必经点就是割点。这两个都是「某种意义下的割」，于是可以开两套完全独立的 LCT：一套管割边，一套管割点。两套共用同一套数组，只是编号错开。

割边那套很好理解：新边出现时它是割边，贡献记 1；一旦有环把它包进去，它从此再也不是割边，贡献改成 0。因为只加边不删边，这个「改成 0」是单向的，于是可以懒更新：zeroTag 打在整棵辅助树上，下次转到的时候再往下传。

割点那套维护的是一棵会随加边成长的圆方树。加边 x-y：

  1. x、y 不连通：直接连一条 x+n 到 y+n 的边即可。
  2. 已经连通：x+n 到 y+n 的路径上所有点从此同在一个点双里。把这条路径拎出来（中序遍历一遍），相邻的点之间的边全部断开，然后新建一个方点，把路径上所有点都连到这个方点上。

「收集整条路径」借的是 splay 的中序遍历：split(x, y) 之后从 y 开始中序，得到的顺序恰好就是路径上从浅到深的顺序。

查询也就各回各家：问必经边数就在割边 LCT 里 split(x, y) 读 sum；问必经点数就换到 x+n、y+n 上 split 读 sum（只有圆点贡献 1）。

#include <bits/stdc++.h>

using namespace std;

const int MAXN = 100001;
const int MAXT = 400001;
int n, q;

int father[MAXN];

int fa[MAXT];
int ls[MAXT];
int rs[MAXT];
bool rev[MAXT];
int sta[MAXT];

int cnt;

int val[MAXT];
int sum[MAXT];
bool zeroTag[MAXT];

int road[MAXT];
int roadLen;

int find(int x) {
    if (father[x] != x) {
        father[x] = find(father[x]);
    }
    return father[x];
}

void up(int x) {
    sum[x] = sum[ls[x]] + sum[rs[x]] + val[x];
}

bool isroot(int x) {
    return ls[fa[x]] != x && rs[fa[x]] != x;
}

int lr(int x) {
    return ls[fa[x]] == x ? 0 : 1;
}

void reverse(int x) {
    if (x != 0) {
        swap(ls[x], rs[x]);
        rev[x] = !rev[x];
    }
}

void setZero(int x) {
    if (x != 0) {
        val[x] = 0;
        sum[x] = 0;
        zeroTag[x] = true;
    }
}

void down(int x) {
    if (rev[x]) {
        reverse(ls[x]);
        reverse(rs[x]);
        rev[x] = false;
    }
    if (zeroTag[x]) {
        setZero(ls[x]);
        setZero(rs[x]);
        zeroTag[x] = false;
    }
}

void rotate(int x) {
    int f = fa[x], g = fa[f];
    if (lr(x) == 0) {
        ls[f] = rs[x];
        if (ls[f] != 0) {
            fa[ls[f]] = f;
        }
        rs[x] = f;
    } else {
        rs[f] = ls[x];
        if (rs[f] != 0) {
            fa[rs[f]] = f;
        }
        ls[x] = f;
    }
    if (!isroot(f)) {
        if (lr(f) == 0) {
            ls[g] = x;
        } else {
            rs[g] = x;
        }
    }
    fa[f] = x;
    fa[x] = g;
    up(f);
    up(x);
}

void splay(int x) {
    int size = 0;
    sta[++size] = x;
    for (int y = x; !isroot(y); y = fa[y]) {
        sta[++size] = fa[y];
    }
    while (size != 0) {
        down(sta[size--]);
    }
    while (!isroot(x)) {
        int f = fa[x];
        if (!isroot(f)) {
            if (lr(x) == lr(f)) {
                rotate(f);
            } else {
                rotate(x);
            }
        }
        rotate(x);
    }
    up(x);
}

void access(int x) {
    for (int y = 0; x != 0; y = x, x = fa[x]) {
        splay(x);
        rs[x] = y;
        up(x);
    }
}

void makeroot(int x) {
    access(x);
    splay(x);
    reverse(x);
}

void split(int x, int y) {
    makeroot(x);
    access(y);
    splay(y);
}

void link(int x, int y) {
    makeroot(x);
    fa[x] = y;
}

void cut(int x, int y) {
    split(x, y);
    fa[x] = 0;
    ls[y] = 0;
    up(y);
}

void inOrder(int x) {
    if (x != 0) {
        down(x);
        inOrder(ls[x]);
        road[++roadLen] = x;
        inOrder(rs[x]);
    }
}

void addEdge(int x, int y) {
    int fx = find(x);
    int fy = find(y);
    if (fx != fy) {
        father[fy] = fx;
        int edge = ++cnt;
        val[edge] = 1;
        sum[edge] = 1;
        link(x, edge);
        link(y, edge);
        link(x + n, y + n);
    } else {
        split(x, y);
        setZero(y);
        x = x + n;
        y = y + n;
        split(x, y);
        if (sum[y] > 2) {
            roadLen = 0;
            inOrder(y);
            for (int i = 2; i <= roadLen; i++) {
                cut(road[i - 1], road[i]);
            }
            int square = ++cnt;
            for (int i = 1; i <= roadLen; i++) {
                link(road[i], square);
            }
        }
    }
}

int queryCute(int x, int y) {
    if (find(x) != find(y)) {
        return -1;
    }
    split(x, y);
    return sum[y];
}

int queryCutv(int x, int y) {
    if (find(x) != find(y)) {
        return -1;
    }
    x = x + n;
    y = y + n;
    split(x, y);
    return sum[y];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> q;
    cnt = n << 1;
    for (int i = 1; i <= n; i++) {
        father[i] = i;
        val[i + n] = 1;
        sum[i + n] = 1;
    }
    for (int i = 1, lastAns = 0, curAns, op, x, y; i <= q; i++) {
        cin >> op;
        cin >> x;
        cin >> y;
        x ^= lastAns;
        y ^= lastAns;
        if (op == 1) {
            addEdge(x, y);
        } else {
            if (op == 2) {
                curAns = queryCute(x, y);
            } else {
                curAns = queryCutv(x, y);
            }
            cout << curAns << "\n";
            if (curAns != -1) {
                lastAns = curAns;
            }
        }
    }
    return 0;
}

不断往图上加边，看哪些边还是割边。真实的做法是用 LCT 一次把整条路径的贡献改成 0，这里演示的是这个逻辑本身。

割边（去掉它就不连通） 已经在环上，不再是割边

七、复杂度分析

设 n 为点数，m 为边数，q 为操作次数。

四道题的底层都是 LCT，makeroot、access、splay、link、cut、split 均摊 O(log n)。图结构题额外花的时间都在「把图翻译成树」这一步上。

环节时间复杂度
LCT 基本操作O(log n) 均摊
首都：找新重心 newCenterO(log n) 均摊（沿辅助树下滑）
最远距离：一次 getDistO(log n)
须臾幻境：预处理 m 条边O(m log n)，另有 O(m log m) 的可持久化线段树
须臾幻境：单次询问O(log m)
动态图：加边时成环O(log n) 均摊（方点需要把路径中序遍历一遍，路径总长摊到整套操作上是 O((n+q) log n)）

空间上：首都和最小距离是若干条 O(n) 的数组，O(n)。须臾幻境要给 m 条边各一个 LCT 点，数组开到 n + m，可持久化线段树每次加边改两条链，节点数 O(m log m)，约 10⁷ 级别。动态图要给边和方点编号，方案上界是 2n + m + 方点数，数组开到 4 × 10⁵ 左右。

八、最后

这四道题放在一起看，LCT 从头到尾没变过，变的是「怎么把题目翻译成一棵树」。

首都把公共应交给了并查集，LCT 只负责在路径上滑一下；最远距离连 vir 都用不上，只查路径长度；须臾幻境给边发了编号，让「删最早出现的那条边」变成一次路径最小值；动态图干脆开了两套 LCT，一套数割边、一套维护圆方树。

这些翻译技巧本身比 LCT 的代码更值钱，遇到新的图论题时先问一句：这里的「边」和「双连通分量」，能不能变成点。

LCT 这条线到这里收束。下一节换一种图：仙人掌，边可以落在环上，但每个环都能被驯服，要么在栈上现场算，要么压成圆方树上的一个方点。
