LCT 维护路径信息

LCT 的模板解决的是「哪条路径」：access 把路径拉成一棵辅助 splay，split 之后整条路径躺在树根上。这一节的四道题解决的是「路径上放什么」：加和乘要叠标记，颜色段要拼接，信号的翻转要找停止位置，根到点的染色干脆把差分写进 access。模板一行不改，改的全是 up、effect 和记录的字段。

零、背景

先把 201 课的几件旧家具搬过来。LCT 里每个点属于一条实链，实链用一棵辅助 splay 存，splay 的中序就是这条链在原树里从浅到深的顺序。实链之间用虚边连着：splay 根的 fa 指向上方实链里的某个点，但那个点不认它当孩子。

access(x) 把 x 到所在原树的根整条拉成实链；makeroot 换根；split(x, y) 之后，x 到 y 的路径完整地躺在一棵 splay 里，且 y 是树根。于是「路径操作」变成「在 splay 树根上打标记」。

剩下的问题只有一个：标记怎么定义、怎么叠加、下传时怎么改汇总值。四道题给出了四种答案。

一、题目1：动态树的加和乘

n 个点组成一棵树，初始每个点点权都是 1。q 条操作，四种：

  • + x y z：x 到 y 路径上所有点权加 z。
  • * x y z：x 到 y 路径上所有点权乘 z。
  • - x y a b：删掉边 (x, y)，加上边 (a, b)。
  • / x y：查询 x 到 y 的路径点权和，模 51061。

n、q 到 10⁵。

split 之后对树根 y 调一次 effect(y, mul, add) 就完了：加 z 就是 effect(y, 1, z)，乘 z 就是 effect(y, z, 0)，路径和就是 sum[y]。整道题的分量都在 effect 的三行里。

标记的语义固定为「先乘后加」：一个数打上 (m, a) 之后变成 原值×m+a。三件事要同时算清：

  1. 点权：arr[x] = arr[x] * mul + add。
  2. 区间和：siz 个点每个都变成 v×mul+add，所以 sum[x] = sum[x] * mul + siz[x] * add。
  3. 旧标记：子节点身上可能还压着没下传的 (m, a)，新来的要叠在外面，(m, a) → (m * mul, a * mul + add)。

还有一个细节是 down 的顺序。rev 先下传、乘加标记后下传：rev 换的是子树方向，乘加标记和方向无关，谁先谁后其实都不出错，固定一个顺序写死就行。

「-」操作是 cut 加 link。cut 的判定和模板课一样：makeroot(x) 之后 y 恰好在 x 的右孩子位置、y 没有左孩子，才是原树里直接相连的一条边。

#include <bits/stdc++.h>

    using namespace std;

    using ll = long long;

    const int MAXN = 100001;
    const int MOD = 51061;
    int n, q;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int sta[MAXN];
    bool rev[MAXN];

    int siz[MAXN];
    ll arr[MAXN];
    ll sum[MAXN];
    ll mulTag[MAXN];
    ll addTag[MAXN];

    void up(int x) {
        siz[x] = siz[ls[x]] + siz[rs[x]] + 1;
        sum[x] = (sum[ls[x]] + sum[rs[x]] + arr[x]) % MOD;
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            rev[x] = !rev[x];
        }
    }

    void effect(int x, ll mul, ll add) {
        if (x != 0) {
            arr[x] = (arr[x] * mul + add) % MOD;
            sum[x] = (sum[x] * mul + siz[x] * add) % MOD;
            mulTag[x] = mulTag[x] * mul % MOD;
            addTag[x] = (addTag[x] * mul + add) % MOD;
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
        if (mulTag[x] != 1 || addTag[x] != 0) {
            effect(ls[x], mulTag[x], addTag[x]);
            effect(rs[x], mulTag[x], addTag[x]);
            mulTag[x] = 1;
            addTag[x] = 0;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    void cut(int x, int y) {
        makeroot(x);
        if (findroot(y) == x && fa[y] == x && ls[y] == 0 && rs[x] == y) {
            fa[y] = rs[x] = 0;
            up(x);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> q;
        for (int i = 1; i <= n; i++) {
            siz[i] = 1;
            arr[i] = 1;
            sum[i] = 1;
            mulTag[i] = 1;
            addTag[i] = 0;
        }
        for (int i = 1, x, y; i < n; i++) {
            cin >> x >> y;
            link(x, y);
        }
        string op;
        int x, y, z, a, b;
        for (int i = 1; i <= q; i++) {
            cin >> op;
            if (op == "+") {
                cin >> x >> y >> z;
                z %= MOD;
                split(x, y);
                effect(y, 1, z);
            } else if (op == "*") {
                cin >> x >> y >> z;
                z %= MOD;
                split(x, y);
                effect(y, z, 0);
            } else if (op == "-") {
                cin >> x >> y >> a >> b;
                cut(x, y);
                link(a, b);
            } else {
                cin >> x >> y;
                split(x, y);
                cout << sum[y] << "\n";
            }
        }
        return 0;
    }

二、题目2：染色

n 个点组成一棵树，每个点有初始颜色。连续相同颜色算一段，比如 1 1 2 2 2 1 有三段。m 条操作：

  • C x y z：x 到 y 路径上每个点颜色改成 z。
  • Q x y：打印 x 到 y 路径上有几段颜色。

n、m 到 10⁵，颜色值到 10⁹。树链剖分能做，这里换 LCT 的版本。

splay 的中序是路径从浅到深，所以路径的颜色段数就是中序序列的段数。up 要维护三样：左端颜色 lcolor、右端颜色 rcolor、段数 colorAns。拼接时看两处接缝：

colorAns[x] = colorAns[ls] + colorAns[rs] + 1，然后左子树右端颜色和 x 相同就减一，x 和右子树左端颜色相同再减一。

覆盖标记 effect(x, c) 是区间覆盖的标准写法：lcolor、rcolor、arr 全设成 c，colorAns 变 1，标记记下 c。这里用 colorTag[x] == 0 表示没有标记，因为题目颜色值至少为 1，0 不会和真实颜色撞上。

容易漏的一处是 reverse。题目没有换根，makeroot 里有，所以 rev 标记还是得下传。翻转的是中序方向，lcolor 和 rcolor 要跟着 swap，colorAns 不动。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int sta[MAXN];
    bool rev[MAXN];

    int arr[MAXN];
    int colorAns[MAXN];
    int lcolor[MAXN];
    int rcolor[MAXN];

    int colorTag[MAXN];

    void up(int x) {
        lcolor[x] = ls[x] == 0 ? arr[x] : lcolor[ls[x]];
        rcolor[x] = rs[x] == 0 ? arr[x] : rcolor[rs[x]];
        colorAns[x] = colorAns[ls[x]] + colorAns[rs[x]] + 1;
        if (ls[x] != 0 && rcolor[ls[x]] == arr[x]) {
            colorAns[x]--;
        }
        if (rs[x] != 0 && arr[x] == lcolor[rs[x]]) {
            colorAns[x]--;
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void reverse(int x) {
        if (x != 0) {
            swap(ls[x], rs[x]);
            swap(lcolor[x], rcolor[x]);
            rev[x] = !rev[x];
        }
    }

    void effect(int x, int c) {
        if (x != 0) {
            arr[x] = c;
            lcolor[x] = c;
            rcolor[x] = c;
            colorAns[x] = 1;
            colorTag[x] = c;
        }
    }

    void down(int x) {
        if (rev[x]) {
            reverse(ls[x]);
            reverse(rs[x]);
            rev[x] = false;
        }
        if (colorTag[x] != 0) {
            effect(ls[x], colorTag[x]);
            effect(rs[x], colorTag[x]);
            colorTag[x] = 0;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void makeroot(int x) {
        access(x);
        splay(x);
        reverse(x);
    }

    int findroot(int x) {
        access(x);
        splay(x);
        down(x);
        while (ls[x] != 0) {
            x = ls[x];
            down(x);
        }
        splay(x);
        return x;
    }

    void split(int x, int y) {
        makeroot(x);
        access(y);
        splay(y);
    }

    void link(int x, int y) {
        makeroot(x);
        if (findroot(y) != x) {
            fa[x] = y;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
            lcolor[i] = arr[i];
            rcolor[i] = arr[i];
            colorAns[i] = 1;
        }
        for (int i = 1, x, y; i < n; i++) {
            cin >> x >> y;
            link(x, y);
        }
        for (int i = 1, x, y, c; i <= m; i++) {
            string op;
            cin >> op;
            if (op == "C") {
                cin >> x >> y >> c;
                split(x, y);
                effect(y, c);
            } else {
                cin >> x >> y;
                split(x, y);
                cout << colorAns[y] << "\n";
            }
        }
        return 0;
    }

三、题目3：三叉神经树

节点分两种：细胞编号 1 到 n，信号编号 n+1 到 3n+1。每个细胞恰有三个儿子，儿子可能是细胞或信号；信号没有儿子。每个信号有自己的值 0 或 1，向上输出给父节点；细胞没有自己的值，三个儿子里 1 多就输出 1，0 多就输出 0。q 次操作，每次翻转一个信号的值，操作完打印 1 号细胞（根）的输出。n、q 到 5×10⁵。

一次翻转的连锁反应可以先在纸上推。信号从 0 变 1，父细胞的 cnt（儿子里输出 1 的个数）加一。cnt 原来是 1，变成 2，输出从 0 变 1，于是再往上加一；cnt 原来是 0、2、3，输出不变，链条到此为止。可以发现传播有一个非常整齐的形状：从下往上，一段连续的 cnt 等于 1 的细胞整体变成 2、输出整体从 0 翻到 1，停在第一个 cnt 不等于 1 的细胞身上，它吸收这一下但输出不动。信号从 1 变 0 是对称的：一段连续的 cnt 等于 2 的细胞变成 1，停在第一个 cnt 不等于 2 的细胞。

这正好是 LCT 的活。这棵树是静态的：没有 link、没有 cut，连 makeroot 都用不上，rev 整个删掉。要的只是「把一段路径拉进一棵 splay，然后对其中连续的一段做整体翻转」。具体来说，change(x) 这样写：

  1. 翻转信号，delta 记 ＋1 或 −1；从它的父细胞起，access 加 splay，把父细胞到根的路径拉进一棵 splay。
  2. 在 splay 里找停止点。中序从浅到深，所以「从下往上第一个 cnt≠1」是先看右子树、再看自己、最后看左子树，这就是 up 里维护 stop1 的三步；stop2 对称地维护第一个 cnt≠2。
  3. splay(stop) 之后，stop 深侧的整棵右子树就是那段要翻转的连续细胞，effect(rs[stop]) 一次做完；cnt[stop] += delta。
  4. 找不到停止点，说明整条链都是 cnt＝1（或都是 cnt＝2）：整棵 splay 一起翻转，根的输出也变了，ans 直接异或 1。

effect 的翻转是三件事一起做：cnt ^= 3（0 和 3 互换、1 和 2 互换）、swap(stop1, stop2)、打 tag。cnt 从 1 变 2 后，「第一个 cnt≠1」和「第一个 cnt≠2」的答案正好互换，所以 stop1、stop2 交换即可，不必重算。

初始状态用拓扑序算一遍：信号先入队，细胞的三个儿子都处理完它才出队，出队时用 get01 汇总 cnt，顺手 up。所有询问都是 O(1) 读 ans。

三叉神经树：翻转一个信号，看传播停在哪

细胞1 的儿子是 细胞2、s1、s2；细胞2 的儿子是 细胞3、s3、s4；细胞3 的儿子是 s5、s6、s7。点按钮翻转一个信号，再用按钮逐步看传播停在哪、根的输出怎么变。

点上面的按钮翻转一个信号，再用左右按钮逐步看传播过程。
#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXT = MAXN * 3;
    int n, q;

    int parent[MAXT];

    int que[MAXT];
    int degree[MAXN];

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];

    int cnt[MAXN];
    int sig[MAXT];

    int stop1[MAXN];
    int stop2[MAXN];

    bool tag[MAXN];
    int sta[MAXN];

    int ans;

    void up(int x) {
        stop1[x] = stop1[rs[x]];
        if (stop1[x] == 0 && cnt[x] != 1) {
            stop1[x] = x;
        }
        if (stop1[x] == 0) {
            stop1[x] = stop1[ls[x]];
        }
        stop2[x] = stop2[rs[x]];
        if (stop2[x] == 0 && cnt[x] != 2) {
            stop2[x] = x;
        }
        if (stop2[x] == 0) {
            stop2[x] = stop2[ls[x]];
        }
    }

    void effect(int x) {
        if (x != 0) {
            cnt[x] ^= 3;
            swap(stop1[x], stop2[x]);
            tag[x] = !tag[x];
        }
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void down(int x) {
        if (tag[x]) {
            effect(ls[x]);
            effect(rs[x]);
            tag[x] = false;
        }
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        int siz = 0;
        sta[++siz] = x;
        for (int y = x; !isroot(y); y = fa[y]) {
            sta[++siz] = fa[y];
        }
        while (siz != 0) {
            down(sta[siz--]);
        }
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            rs[x] = y;
            up(x);
        }
    }

    void change(int x) {
        sig[x] ^= 1;
        int delta = sig[x] == 1 ? 1 : -1;
        x = parent[x];
        access(x);
        splay(x);
        int stop = delta == 1 ? stop1[x] : stop2[x];
        if (stop != 0) {
            splay(stop);
            effect(rs[stop]);
            cnt[stop] += delta;
            up(stop);
        } else {
            effect(x);
            ans ^= 1;
        }
    }

    int get01(int x) {
        if (x <= n) {
            return cnt[x] <= 1 ? 0 : 1;
        } else {
            return sig[x];
        }
    }

    void topo() {
        for (int i = 1; i <= n; i++) {
            degree[i] = 3;
        }
        int l = 1, r = 0;
        for (int i = n + 1; i <= 3 * n + 1; i++) {
            que[++r] = i;
        }
        while (l <= r) {
            int x = que[l++];
            if (x <= n) {
                up(x);
            }
            int p = parent[x];
            if (p != 0) {
                cnt[p] += get01(x);
                if (--degree[p] == 0) {
                    que[++r] = p;
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1, x; i <= n; i++) {
            for (int j = 1; j <= 3; j++) {
                cin >> x;
                parent[x] = i;
                if (x <= n) {
                    fa[x] = i;
                }
            }
        }
        for (int i = n + 1; i <= 3 * n + 1; i++) {
            cin >> sig[i];
        }
        topo();
        ans = get01(1);
        cin >> q;
        for (int i = 1, x; i <= q; i++) {
            cin >> x;
            change(x);
            cout << ans << "\n";
        }
        return 0;
    }

四、题目4：树点涂色

n 个点组成一棵树，1 号是根。初始所有点颜色互不相同，路径上的颜色数量叫路径权值。m 条操作：

  • 1 x：根到 x 的路径上所有点染上一种没用过的新颜色。
  • 2 x y：查询 x 到 y 的路径权值。
  • 3 x：x 的子树里选一个点，使它到根的路径权值最大，打印这个值。

n、m 到 10⁵。这题把 LCT、树链剖分、树上差分三样拼在一起，难在转换。

定义 g(v) 为 v 到根路径上的颜色数。三个操作先翻译：初始每点一色，g(v) 就是深度 dep(v)。操作 2 里 x 到 y 的路径颜色数等于 g(x) + g(y) - 2 * g(lca) + 1，lca 处被减了两次、补一个 1。操作 3 是子树内 g 的最大值。操作 1 改变的是「根到 x」这条链上所有点的 g，子树外的点不受影响。

查询都在静态的树上，树链剖分按 dfn 排好，线段树支持子树区间加、区间查最大值，操作 2 和 3 就解决了。剩操作 1：怎么知道染色改变了谁的 g、变了多少。

这里有个漂亮的对应。染色把根到 x 变成一色，access 把根到 x 变成一条实链，而「实链」和「颜色段」从此保持一一对应：初始时每点自成一条实链、颜色互不相同；每次染色恰好就是把根到 x 打成实链。于是 g(v) 的另一个身份是 v 到根跨过的实链条数，而 access 逐条切换实链的过程，就是 g 值变化的差分过程：

  • 断开一条旧实链（splay 根甩掉右子树）：这条链最浅的点 mostl[rs[x]] 的整个子树加一。链上所有点的 g 各加一，同一条链上 g 值本来相同，子树里的点跟着同样变化，这些子树并起来恰好是最浅那个点的子树。
  • 接入一条新实链（rs[x] = y）：新链最浅的点 mostl[y] 的子树减一。接入前这条链独立成段、g 里多算了一条，接上后并进上面的链，退回去。

于是操作 1 就是改写的 access：每次迭代先 splay，右子树非空就给 mostl[rs[x]] 的子树加一，接入的 y 非空就给 mostl[y] 的子树减一，再换右儿子。线段树按 dfn 建在静态树上，子树加就是 dfn 区间加。初始时线段树的值直接放 dep。

access 均摊切换 O(log n) 条实链，每次切换至多两次线段树区间加、每次 O(log n)，所以单次染色均摊 O(log² n)；查询 2 是 lca 加三个单点查询，查询 3 是一次区间最大值，都是 O(log n)。

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 100001;
    int n, m;

    int head[MAXN];
    int nxt[MAXN << 1];
    int to[MAXN << 1];
    int cntg;

    int pa[MAXN];
    int dep[MAXN];
    int siz[MAXN];
    int son[MAXN];
    int top[MAXN];
    int dfn[MAXN];
    int seg[MAXN];
    int cntd;

    int fa[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int mostl[MAXN];

    int maxVal[MAXN << 2];
    int addTag[MAXN << 2];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void dfs1(int u, int f) {
        pa[u] = f;
        dep[u] = dep[f] + 1;
        siz[u] = 1;
        for (int e = head[u], v; e != 0; e = nxt[e]) {
            v = to[e];
            if (v != f) {
                dfs1(v, u);
                siz[u] += siz[v];
                if (siz[v] > siz[son[u]]) {
                    son[u] = v;
                }
            }
        }
    }

    void dfs2(int u, int t) {
        top[u] = t;
        dfn[u] = ++cntd;
        seg[cntd] = u;
        if (son[u] != 0) {
            dfs2(son[u], t);
        }
        for (int e = head[u], v; e != 0; e = nxt[e]) {
            v = to[e];
            if (v != pa[u] && v != son[u]) {
                dfs2(v, v);
            }
        }
    }

    int lca(int x, int y) {
        while (top[x] != top[y]) {
            if (dep[top[x]] < dep[top[y]]) {
                y = pa[top[y]];
            } else {
                x = pa[top[x]];
            }
        }
        return dep[x] < dep[y] ? x : y;
    }

    void up(int x) {
        mostl[x] = ls[x] == 0 ? x : mostl[ls[x]];
    }

    bool isroot(int x) {
        return ls[fa[x]] != x && rs[fa[x]] != x;
    }

    int lr(int x) {
        return ls[fa[x]] == x ? 0 : 1;
    }

    void rotate(int x) {
        int f = fa[x], g = fa[f];
        if (lr(x) == 0) {
            ls[f] = rs[x];
            if (ls[f] != 0) {
                fa[ls[f]] = f;
            }
            rs[x] = f;
        } else {
            rs[f] = ls[x];
            if (rs[f] != 0) {
                fa[rs[f]] = f;
            }
            ls[x] = f;
        }
        if (!isroot(f)) {
            if (lr(f) == 0) {
                ls[g] = x;
            } else {
                rs[g] = x;
            }
        }
        fa[f] = x;
        fa[x] = g;
        up(f);
        up(x);
    }

    void splay(int x) {
        while (!isroot(x)) {
            int f = fa[x];
            if (!isroot(f)) {
                if (lr(x) == lr(f)) {
                    rotate(f);
                } else {
                    rotate(x);
                }
            }
            rotate(x);
        }
    }

    void upSeg(int i) {
        maxVal[i] = max(maxVal[i << 1], maxVal[i << 1 | 1]);
    }

    void build(int l, int r, int i) {
        if (l == r) {
            maxVal[i] = dep[seg[l]];
        } else {
            int mid = (l + r) >> 1;
            build(l, mid, i << 1);
            build(mid + 1, r, i << 1 | 1);
            upSeg(i);
        }
    }

    void lazy(int i, int v) {
        maxVal[i] += v;
        addTag[i] += v;
    }

    void down(int i) {
        if (addTag[i] != 0) {
            lazy(i << 1, addTag[i]);
            lazy(i << 1 | 1, addTag[i]);
            addTag[i] = 0;
        }
    }

    void add(int jobl, int jobr, int jobv, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            lazy(i, jobv);
        } else {
            down(i);
            int mid = (l + r) >> 1;
            if (jobl <= mid) {
                add(jobl, jobr, jobv, l, mid, i << 1);
            }
            if (jobr > mid) {
                add(jobl, jobr, jobv, mid + 1, r, i << 1 | 1);
            }
            upSeg(i);
        }
    }

    int query(int jobl, int jobr, int l, int r, int i) {
        if (jobl <= l && r <= jobr) {
            return maxVal[i];
        }
        down(i);
        int mid = (l + r) >> 1;
        int ans = 0;
        if (jobl <= mid) {
            ans = max(ans, query(jobl, jobr, l, mid, i << 1));
        }
        if (jobr > mid) {
            ans = max(ans, query(jobl, jobr, mid + 1, r, i << 1 | 1));
        }
        return ans;
    }

    void add(int x, int v) {
        add(dfn[x], dfn[x] + siz[x] - 1, v, 1, n, 1);
    }

    void access(int x) {
        for (int y = 0; x != 0; y = x, x = fa[x]) {
            splay(x);
            if (rs[x] != 0) {
                add(mostl[rs[x]], 1);
            }
            if (y != 0) {
                add(mostl[y], -1);
            }
            rs[x] = y;
            up(x);
        }
    }

    int pathQuery(int x, int y) {
        int xylca = lca(x, y);
        int a = query(dfn[x], dfn[x], 1, n, 1);
        int b = query(dfn[y], dfn[y], 1, n, 1);
        int c = query(dfn[xylca], dfn[xylca], 1, n, 1);
        return a + b - (2 * c) + 1;
    }

    int subtreeQuery(int x) {
        return query(dfn[x], dfn[x] + siz[x] - 1, 1, n, 1);
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        n = 0;
        m = 0;
        cin >> n >> m;
        for (int i = 1, x, y; i < n; i++) {
            cin >> x >> y;
            addEdge(x, y);
            addEdge(y, x);
        }
        dfs1(1, 0);
        dfs2(1, 1);
        build(1, n, 1);
        for (int i = 1; i <= n; i++) {
            fa[i] = pa[i];
            mostl[i] = i;
        }
        for (int i = 1, op, x, y; i <= m; i++) {
            cin >> op;
            cin >> x;
            if (op == 1) {
                access(x);
            } else if (op == 2) {
                cin >> y;
                cout << pathQuery(x, y) << "\n";
            } else {
                cout << subtreeQuery(x) << "\n";
            }
        }
        return 0;
    }

五、复杂度分析

设 n 为点数，m 为操作数。四个题的模板部分完全相同：access、splay、split、link、cut 都是均摊 O(log n)，up 是 O(1)。

操作时间复杂度
题目1：路径加 / 路径乘 / 查询和O(log n) 均摊
题目1：删边加边O(log n) 均摊
题目2：路径覆盖 / 查询段数O(log n) 均摊
题目3：拓扑建树O(n)
题目3：单次信号翻转O(log n) 均摊
题目4：树剖、线段树初始化O(n)
题目4：单次染色（access 加差分）O(log² n) 均摊
题目4：单次路径 / 子树查询O(log n)

空间上，题目1、2、4 都是 O(n) 的数组：fa、ls、rs、sta、rev 加各自的信息数组和标记数组。题目3 的信号编号到 3n+1，但 sig 独立开一个长数组，splay 相关的都只对细胞开 n，整体还是 O(n)。

六、最后

四道题共用一套骨架，改动集中在一处半：up 算什么、effect 打什么算一处，access 里顺手做什么算半处。

加和乘的题把标记语义钉死成先乘后加；染色的题盯住中序接缝；三叉神经树把「传播停在哪」变成两个 stop 数组；树点涂色干脆让 access 自己写差分。同一棵 splay，四个方向。

这一讲还有另一半：LCT 遇到图上的环。加边成环时，环上的点从此同进同出，把整条路径缩成一个代表点，就是下一页的内容。
