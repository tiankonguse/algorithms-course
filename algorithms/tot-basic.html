树套树：外层拆范围，内层维护信息

一维的区间问题，一棵线段树或树状数组就够了。一旦查询变成「在第一维的某个范围里，再对第二维做一次统计」，一维结构就管不住了。做法是把范围再切一层：外层结构负责切范围，外层切出来的每一段，各自挂一个内层结构。

零、为什么要把两棵树套起来

先看一维。数组上问「下标 [l, r] 的最大值」，线段树把 [l, r] 拆成 O(log n) 个节点，每个节点已经存好了自己那段的最大值，取 max 就行。

现在加一维。每个元素有 (x, y) 两个坐标和一个权值 v，问「x 在 [x₁, x₂]、y 在 [y₁, y₂] 的元素的 v 最大值」。线段树只能管一维，剩下的那一维得另找结构。

自然的想法是：外层还是按 x 建一棵线段树，外层节点管一段 x 范围；这段范围里的所有元素，它们的 y 又构成了一个一维问题，于是给这个节点再挂一棵按 y 建的树。这就是树套树。

一、树套树的形状

外部结构嵌套内部结构。外层组织范围，外层组织的每一个范围，其中的信息都对应着一个内部结构来维护。外层和内层都可以是树状数组、线段树、平衡树或分块结构，具体用哪个由题目决定。

单次操作的复杂度就是两层的乘积：外层单次操作的复杂度，乘上内层单次操作的复杂度。两维都是线段树时，就是 O(log n · log n)。

树套树的种类很多，具体问题具体分析：先确定外层怎么拆范围，再确定内层维护什么信息。思维难度不算大，代价在代码量和空间上，每个外层节点都要一整棵内层结构。

二、题目1：线段树套线段树

人有三种属性：身高（int，100 到 200）、活泼度和缘分值（double，最多一位小数，0 到 100.0）。两种操作：I a b c 加入一个人（身高 a、活泼度 b、缘分 c）；Q a b c d 查询身高范围 [a, b]、活泼度范围 [c, d] 的人里缘分最大值，没有人输出 -1。查询时如果 a > b 要交换，c > d 也要交换。测试链接：HDU 1823。

两维的范围都小得离谱：身高 101 个取值，活泼度乘 10 之后是 0 到 1000，也才 1001 个取值。所以两维都直接开满就行。外层按身高 [100, 200] 建线段树，外层的每个节点内部再按活泼度 [0, 1000] 建一棵线段树，叶子存缘分最大值。

加入一个人 (a, b, c)：外层沿根到身高 a 那条路径，路径上每个节点都在自己的内层里、活泼度 b 的位置更新一次最大值。查询：外层把身高区间拆成 O(log) 个节点，每个节点在自己的内层里查活泼度区间的最大值，最后再取一次 max。

三、代码

两层都写成标准的线段树递归，只不过内层的树编号要额外带一个外层节点编号 xi。建树时每个外层节点都把自己那棵内层树建出来。

void outerBuild(int xl, int xr, int xi) {
        innerBuild(MINY, MAXY, xi, 1);
        if (xl < xr) {
            int mid = (xl + xr) >> 1;
            outerBuild(xl, mid, xi << 1);
            outerBuild(mid + 1, xr, xi << 1 | 1);
        }
    }

    void outerUpdate(int jobx, int joby, int jobv, int xl, int xr, int xi) {
        innerUpdate(joby, jobv, MINY, MAXY, xi, 1);
        if (xl < xr) {
            int mid = (xl + xr) >> 1;
            if (jobx <= mid) {
                outerUpdate(jobx, joby, jobv, xl, mid, xi << 1);
            } else {
                outerUpdate(jobx, joby, jobv, mid + 1, xr, xi << 1 | 1);
            }
        }
    }
void innerUpdate(int jobi, int jobv, int yl, int yr, int xi, int yi) {
        if (yl == yr) {
            tree[xi][yi] = max(tree[xi][yi], jobv);
        } else {
            int mid = (yl + yr) >> 1;
            if (jobi <= mid) {
                innerUpdate(jobi, jobv, yl, mid, xi, yi << 1);
            } else {
                innerUpdate(jobi, jobv, mid + 1, yr, xi, yi << 1 | 1);
            }
            tree[xi][yi] = max(tree[xi][yi << 1], tree[xi][(yi << 1) | 1]);
        }
    }

    int innerQuery(int jobl, int jobr, int yl, int yr, int xi, int yi) {
        if (jobl <= yl && yr <= jobr) {
            return tree[xi][yi];
        }
        int mid = (yl + yr) >> 1;
        int ans = -1;
        if (jobl <= mid) {
            ans = max(ans, innerQuery(jobl, jobr, yl, mid, xi, yi << 1));
        }
        if (jobr > mid) {
            ans = max(ans, innerQuery(jobl, jobr, mid + 1, yr, xi, (yi << 1) | 1));
        }
        return ans;
    }

内层就是一棵普通的「单点取 max、区间查 max」线段树，唯一的区别是数组第一维是外层节点编号。outerQuery 里，只有外层节点被查询范围完整覆盖时才把内层整段查出来。

int outerQuery(int jobxl, int jobxr, int jobyl, int jobyr, int xl, int xr, int xi) {
        if (jobxl <= xl && xr <= jobxr) {
            return innerQuery(jobyl, jobyr, MINY, MAXY, xi, 1);
        }
        int mid = (xl + xr) >> 1;
        int ans = -1;
        if (jobxl <= mid) {
            ans = max(ans, outerQuery(jobxl, jobxr, jobyl, jobyr, xl, mid, xi << 1));
        }
        if (jobxr > mid) {
            ans = max(ans, outerQuery(jobxl, jobxr, jobyl, jobyr, mid + 1, xr, (xi << 1) | 1));
        }
        return ans;
    }

空间上这写法很奢侈：tree[n << 2][m << 2] 是 404 × 4004 个 int，约 6.5 MB。它能成立完全是因为两维的范围都只有一千出头。范围一大就得换开点，这是后面几道题的共同主题。

四、谁放在外层

题目1 的两维都是「求最大值」，谁在外层只影响常数。换一道题就不一定了。看题目2 要回答的是第 k 大。

如果外层是下标树、内层是值域树，那么问 [l, r] 的第 k 大时，外层拆出来的每个节点各有一棵值域树，得在每棵里各二分一次，没法合成一次判定。反过来，外层是值域树、内层是下标树，下潜时右儿子那棵内层树的总数就是「值大于 mid 的元素个数」，直接和 k 比一次就能决定往哪边走。

五、题目2：k 大数查询

初始有 n 个空集合，编号 1 到 n，一共 m 次操作。操作 1 l r v：把数字 v 放进编号范围 [l, r] 的每一个集合；操作 2 l r k：编号 [l, r] 的所有集合生成不去重的并集，返回第 k 大的数字。n、m ≤ 5 × 10⁴，−n ≤ v ≤ +n，k < 2⁶³，题目保证第 k 大存在。测试链接：P3332。

按上一节的结论，外层是值域线段树，内层是下标线段树。值域先离散化：把所有操作 1 里的 v 收进 sorted 去重排序，得到 s 个取值。

  • 外层：值域 [1, s]，节点数固定，用数组版线段树（root 开 4m）
  • 内层：下标 [1, n] 的动态开点线段树，维护每个位置被放了多少个数，支持区间加和懒标记

加入 (l, r, v)：外层沿根到 v 的路径，路径上每个节点都在自己的内层里把 [l, r] 加一。查询第 k 大：从外层根往下，rightsum 是右儿子那棵内层树在 [l, r] 上的总和；k > rightsum 就往左、k 减去 rightsum，否则往右。走到叶子得到离散下标，输出 sorted[idx]。

这里有个细节：外层用数组版是因为它的值域被离散化到了 1 到 s，节点数是固定的 4s；内层必须开点，因为每个外层节点都要一棵下标树，全开满是 4n × 4s，根本存不下。开点之后，一次「区间加」只新建 O(log n) 个节点。

int innerAdd(int jobl, int jobr, int l, int r, int i) {
        if (!i) i = ++cnt;
        if (jobl <= l && r <= jobr) {
            sum[i] += (long long)(r - l + 1);
            lazy[i]++;
        } else {
            int mid = (l + r) >> 1;
            down(i, mid - l + 1, r - mid);
            if (jobl <= mid) ls[i] = innerAdd(jobl, jobr, l, mid, ls[i]);
            if (jobr > mid) rs[i] = innerAdd(jobl, jobr, mid + 1, r, rs[i]);
            up(i);
        }
        return i;
    }

    void outerAdd(int jobl, int jobr, int jobv, int l, int r, int i) {
        root[i] = innerAdd(jobl, jobr, 1, n, root[i]);
        if (l < r) {
            int mid = (l + r) >> 1;
            if (jobv <= mid) {
                outerAdd(jobl, jobr, jobv, l, mid, i << 1);
            } else {
                outerAdd(jobl, jobr, jobv, mid + 1, r, i << 1 | 1);
            }
        }
    }
int outerQuery(int jobl, int jobr, long long jobk, int l, int r, int i) {
        if (l == r) {
            return l;
        }
        int mid = (l + r) >> 1;
        long long rightsum = innerQuery(jobl, jobr, 1, n, root[i << 1 | 1]);
        if (jobk > rightsum) {
            return outerQuery(jobl, jobr, jobk - rightsum, l, mid, i << 1);
        } else {
            return outerQuery(jobl, jobr, jobk, mid + 1, r, i << 1 | 1);
        }
    }

注意 innerAdd 里区间完整覆盖时直接 sum += r - l + 1 而不是逐点加，内层存的是「这一段上每个位置各被放了多少次」的总和，整段加一就是加段长。这个 sum 用 long long，因为 k 能到 2⁶³。

复杂度分析

树套树的复杂度就是两层相乘，空间则是「外层节点数 × 每个内层节点的空间」。

项目时间空间
题目1 单次操作O(log H · log A)O(H · A)
题目1 数组规模H = 101，A = 1001404 × 4004 个 int，约 6.5 MB
题目2 单次操作O(log s · log n)开点节点数 O(m log s · log n)
题目2 离散化O(m log m)O(m)
通用公式外层单次 × 内层单次外层节点数 × 内层单点开销

题目1 的 O(H · A) 是两维都开满的结果，只在范围很小时可用。题目2 换成开点之后，空间跟着实际操作数走，变成 O(m log s · log n)。外层从线段树换成树状数组，常数还能再降一截，下一节就把同一道题用两种外层各写一遍。

最后

这一节留下两个判断：一是单次复杂度等于两层的乘积，二是「谁在外层」由查询要怎么回答来决定，求极值随便，求第 k 大必须让值域当外层。后面几题反复在用的就是这两条。
