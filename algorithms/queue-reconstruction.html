重建队列：贪心 + 按序号插入的有序表

n 个人，每人两个数：身高 a，要求 b，代表站在自己左边的人里正好有 b 个人身高大于等于自己。把 n 个人排成一列满足所有要求。题解里绝大多数做法是 O(n²) 的数组插入，这一页用贪心把问题拆成「往第 b 个位置插一个人」，再靠 AVL 有序表把每次插入压到 O(log n)。

零、问题

输入 n 个 (a, b)：a 是身高，b 是站在左边的人中身高大于等于 a 的人数。要输出一种从左到右的排列，让每个人的要求都满足。数据保证一定存在这样的排列。

O(n²) 的做法是：排好序之后用一个可插入的数组，插到第 b 个位置，数组整体后移。n 有 1e4 量级时这个平方复杂度就悬了。

一、贪心：从高到低，插到第 b 个位置

排序规则：身高从高到低，身高相同按 b 从小到大。处理到某个人时，序列里已经放好的人身高都大于等于他：更高的全放完了，同身高的、b 更小的也放完了。这时把他插到当前序列的第 b 个位置（下标从 0 开始），他左边恰好有 b 个人，而且这 b 个人全部大于等于他，他的要求当场满足。

之后插入的人身高都小于等于他，不会破坏他的计数：更矮的人站在左边，不算「大于等于」。同身高的按 b 升序先小后大，先插的 b 小、位置靠前，后插的 b 大正好落在更右边，两边互不挤占。

如果有人问「为什么不能从矮到高处理」：那处理到高个子时，矮个子已经在队列里，高个子插进去会把矮个子左边的人数改变，要求就说不清了。从高到低是让「已经就位的人永远不会影响后插者左边的大于等于计数」。

二、有序表：按序号插入的 AVL

把「插到第 b 个位置」实现成有序表的操作。上一页的 AVL 按 key 大小比较左右，这里换成按左子树大小决定走向：siz[ls] >= rank 走左，否则走右并减去左子树大小加一。中序遍历出来的顺序就是从左到右的队列顺序。

为什么旋转在这里依然可行？上一页的观察：旋转不改变中序遍历的次序。按序号插入的 AVL 里，旋转同样只改结构不改中序，所以任意位置插入、任意次旋转之后，中序仍然是队列顺序。这正是不用普通数组、改用有序表的原因：插入一个元素是 O(log n)，整棵树的中序顺序却始终对。

实现上比上一页少两个数组：没有 key_count（每个人只出现一次，siz 就是子树人数），没有词频累加分支。height 和 siz 照常维护，maintain 完全一样。

三、复杂度

排序 O(n log n)，n 次插入每次 O(log n)，总计 O(n log n)。这就是「最优时间复杂度」：题目给 1e4 人也跑得动。

四、题目2：完整实现

LeetCode 406「根据身高重建队列」。上面分析的两步直接落地：

// 重建队列：贪心 + 按中序序号插入的 AVL 有序表
    // 一共 n 个人，每个人有 (a, b) 两个数据，a 表示身高
    // b 表示站在自己左边的人中，正好有 b 个人的身高大于等于自己
    // 返回任意一种满足全部要求的排列
    // 测试链接 : https://leetcode.cn/problems/queue-reconstruction-by-height/
    #include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 2001;

    int cnt = 0;
    int head = 0;
    int key[MAXN];
    int height[MAXN];
    int ls[MAXN];
    int rs[MAXN];
    int value[MAXN];
    int siz[MAXN];

    void up(int i) {
        siz[i] = siz[ls[i]] + siz[rs[i]] + 1;
        height[i] = max(height[ls[i]], height[rs[i]]) + 1;
    }

    int leftRotate(int i) {
        int r = rs[i];
        rs[i] = ls[r];
        ls[r] = i;
        up(i);
        up(r);
        return r;
    }

    int rightRotate(int i) {
        int l = ls[i];
        ls[i] = rs[l];
        rs[l] = i;
        up(i);
        up(l);
        return l;
    }

    int maintain(int i) {
        int lh = height[ls[i]];
        int rh = height[rs[i]];
        if (lh - rh > 1) {
            if (height[ls[ls[i]]] >= height[rs[ls[i]]]) {
                i = rightRotate(i);
            } else {
                ls[i] = leftRotate(ls[i]);
                i = rightRotate(i);
            }
        } else if (rh - lh > 1) {
            if (height[rs[rs[i]]] >= height[ls[rs[i]]]) {
                i = leftRotate(i);
            } else {
                rs[i] = rightRotate(rs[i]);
                i = leftRotate(i);
            }
        }
        return i;
    }

    // 把 (num, idx) 插到中序遍历的第 rank 个位置（rank 从 0 开始）
    // 这里不按 key 的大小比较左右，而是按左子树大小决定往哪边走
    int add(int i, int rank, int num, int idx) {
        if (i == 0) {
            key[++cnt] = num;
            value[cnt] = idx;
            siz[cnt] = height[cnt] = 1;
            return cnt;
        }
        if (siz[ls[i]] >= rank) {
            ls[i] = add(ls[i], rank, num, idx);
        } else {
            rs[i] = add(rs[i], rank - siz[ls[i]] - 1, num, idx);
        }
        up(i);
        return maintain(i);
    }

    void add(int num, int idx) {
        head = add(head, idx, num, idx);
    }

    // 中序遍历填答案：树的中序顺序就是最终的队列顺序
    int fi = 0;
    void inOrder(int ans[][2], int i) {
        if (i == 0) {
            return;
        }
        inOrder(ans, ls[i]);
        ans[fi][0] = key[i];
        ans[fi++][1] = value[i];
        inOrder(ans, rs[i]);
    }

    void clear() {
        memset(key + 1, 0, cnt * sizeof(int));
        memset(height + 1, 0, cnt * sizeof(int));
        memset(ls + 1, 0, cnt * sizeof(int));
        memset(rs + 1, 0, cnt * sizeof(int));
        memset(value + 1, 0, cnt * sizeof(int));
        memset(siz + 1, 0, cnt * sizeof(int));
        cnt = 0;
        head = 0;
        fi = 0;
    }

    int main() {
        int n;
        cin >> n;
        vector<pair<int, int>> people(n);
        for (int i = 0; i < n; i++) {
            cin >> people[i].first >> people[i].second;
        }
        // 身高从高到低，同身高按 b 从小到大
        sort(people.begin(), people.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
            return a.first != b.first ? (a.first > b.first) : (a.second < b.second);
        });
        for (int i = 0; i < n; i++) {
            add(people[i].first, people[i].second);
        }
        int ans[MAXN][2];
        inOrder(ans, head);
        for (int i = 0; i < n; i++) {
            cout << ans[i][0] << " " << ans[i][1] << endl;
        }
        clear();
        return 0;
    }

演示 · 贪心插入：逐个放到第 b 个位置，末帧验证每人要求

总结

重建队列把「排成一列满足 b 个大于等于」翻译成「按身高降序逐个插到第 b 个位置」，正确性靠一个事实：处理时队列里全是大于等于我的人，之后来的人都小于等于我。数组插入是 O(n²)，换成按序号插入的 AVL 有序表变成 O(n log n)，而旋转不改变中序次序这一点让有序表可以放心插在任意位置。这道题的意义不在题本身，在于展示了有序表能维护的不仅是 key 的大小序，还有中序这个位置序。
