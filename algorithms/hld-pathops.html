路径取反与范围重置

路径拆段这件事上一节已经做完，剩下的问题是线段树要支持什么标记。这一节两个题：一个要求整段取相反数，一个要求范围重置和范围增加同时进行。

零、背景

边权已经下放成点权，路径也已经是 O(log n) 段区间。这时题目问什么，就完全取决于线段树节点里存什么、标记怎么打。

区间加是最简单的：打个 addTag，查的时候累加。取反和重置要稍微想一下，因为它们会改变已有数据的「形状」。

一、题目2：国家集训队旅游

n 个点编号 0 到 n − 1，n − 1 条边编号 1 到 n − 1，每条边有初始边权。m 条操作：C x y 把第 x 条边的权改成 y；N x y 把 x 到 y 路径上所有边权变相反数；SUM、MAX、MIN 分别问路径上边权的和、最大值、最小值。1 ≤ n、m ≤ 2 × 10⁵，任何时候的边权在 −1000 到 +1000。测试链接：P1505。

单点改值不用标记，直接递归到底。整段取反才是这里的关键。

max 和 min 互换这件事容易写错：先取负会打乱大小关系。原来的最大值变成最小，原来的最小值变成最大，所以是「新 max = −旧 min、新 min = −旧 max」。

void lazy(int i) {
        sumv[i] = -sumv[i];
        int tmp = maxv[i];
        maxv[i] = -minv[i];
        minv[i] = -tmp;
        negativeTag[i] = !negativeTag[i];
    }

    void down(int i) {
        if (negativeTag[i]) {
            lazy(i << 1);
            lazy(i << 1 | 1);
            negativeTag[i] = false;
        }
    }

取反标记只影响自己这一段，下传时给两个儿子各做一次，然后把自己的 bool 清掉。路径求和与取反共用同一套拆段逻辑。

int pathSum(int x, int y) {
        int ans = 0;
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                ans += querySum(dfn[top[y]], dfn[y], 1, n, 1);
                y = fa[top[y]];
            } else {
                ans += querySum(dfn[top[x]], dfn[x], 1, n, 1);
                x = fa[top[x]];
            }
        }
        ans += querySum(min(dfn[x], dfn[y]) + 1, max(dfn[x], dfn[y]), 1, n, 1);
        return ans;
    }

这里有个细节：题目节点编号从 0 开始，读进来统一 +1 变成 1 到 n；边的编号保持 1 到 n − 1 不动，因为它是按输入顺序记的。

二、题目3：月下毛景树

n 个点编号 1 到 n，n − 1 条边编号 1 到 n − 1，每条边有初始边权。操作有四种：Change x v 把第 x 条边改成 v；Cover x y v 把 x 到 y 路径上所有边权改成 v；Add x y v 路径上所有边权加 v；Max x y 打印路径上最大的边权，读到 Stop 结束。1 ≤ n ≤ 10⁵。测试链接：P4315。

难点是覆盖和增加两个标记要共存。它们不对易：先加 3 再覆盖成 5，和先覆盖成 5 再加 3，结果不同。所以必须定死一条顺序。

void updateLazy(int i, int v) {
        maxv[i] = v;
        addTag[i] = 0;
        updateTag[i] = true;
        change[i] = v;
    }

    void addLazy(int i, int v) {
        maxv[i] += v;
        addTag[i] += v;
    }

    void down(int i) {
        if (updateTag[i]) {
            updateLazy(i << 1, change[i]);
            updateLazy(i << 1 | 1, change[i]);
            updateTag[i] = false;
        }
        if (addTag[i] != 0) {
            addLazy(i << 1, addTag[i]);
            addLazy(i << 1 | 1, addTag[i]);
            addTag[i] = 0;
        }
    }

下传时先处理覆盖再处理增加，顺序与打标记时一致。反过来会让孩子先被加一遍再被覆盖掉，答案就错了。

一次 N 操作与随后三次查询

树边 1-2 = 3、1-3 = −2、2-4 = 5、2-5 = 1，重链是 1-2-5。点「下一步」看路径 4 到 3 怎么拆成三段，取反之后 SUM、MAX、MIN 分别是多少。

复杂度分析

两个题的代价结构相同：一次路径操作拆成 O(log n) 段，每段线段树 O(log n)。标记都是 O(1) 打、O(1) 传。

操作时间说明
剖分 dfs1 + dfs2O(n)两个递归各遍历整棵树一遍
C x y（题2 单点改）O(log n)一次线段树单点修改
N x y（题2 取反）O(log² n)最多 2 log₂ n 段，每段 O(log n)
SUM / MAX / MINO(log² n)同上，逐段合并
Cover / Add / Max（题3）O(log² n)双标记仍然是常数次改写
空间O(n)题2 三个值数组加一个 bool，题3 两个标记各 4n

题2 里路径为空（x 等于 y）时，最后一段区间左端大于右端，查询会返回空区间的初值。真实数据一般不这么出，写的时候留意即可。

最后

到这里重链剖分的部分就结束了。剩下的半讲换一种剖分方式：不看子树大小，看子树高度。
