重构树接上线段树和主席树

删边不好做，倒过来变成加边就好做了。给每条边按「删掉的时刻」编个号，重构树就建起来了；叶子按 dfn 排成一列，连通块永远是其中一段，剩下的交给线段树和主席树。

零、题目6：删边和查询

图里有 n 个点、m 条无向边，初始时点权都不同，图里可能有若干个连通的部分。一共有 q 条操作，每条操作是如下两种类型中的一种。操作 1 x：点 x 所在的连通区域中，假设点 y 拥有最大的点权，打印 y 的点权，然后把 y 的点权修改为 0。操作 2 x：删掉第 x 条边。1 ≤ n ≤ 2 × 10⁵，1 ≤ m ≤ 3 × 10⁵，1 ≤ q ≤ 5 × 10⁵。测试链接：CF1416D。

删边这件事并查集做不了，但反过来加边是可以的。所以先把所有操作读进来，把删边变成「这条边在某一时刻之后才不存在」。

具体做法是给每条边分配一个边权：从没被删过的边，按编号从小到大分配 1、2、3……；被删过的边，按删除时刻从晚到早接着分配下去。也就是说，删得越晚的边，分到的边权越小。

分配完之后，limit 从 m 开始，每遇到一次删边就减 1。任何时刻存在的边，恰好是边权 ≤ limit 的全部边。这就是标准的升序 Kruskal 重构树。

一、连通块是 dfn 上的一段

dfs 时只给叶子编号：每遇到一个原始点就发一个 dfn，同时记 leafDfnMin 是子树里最小的 dfn。由于 dfs 是连续访问完一整棵子树的，一个节点的全部叶子必然占据一段连续的 dfn：[leafDfnMin, leafDfnMin + leafsiz - 1]。

于是「连通块里点权最大的点」就变成了「一段区间里值最大的位置」。线段树维护区间最大值所在的下标即可，取走之后把它改成 0（单点更新）。

二、题目7：边权上限内第 k 大点权

图里有 n 个点、m 条无向边，点有点权，边有边权，图里可能有若干个连通的部分。一共有 q 条查询，格式如下：查询 u x k，从点 u 开始，只能走过权值 ≤ x 的边，所有能到达的点中，打印第 k 大点权，如果不存在打印 -1。1 ≤ n ≤ 10⁵，0 ≤ m、q ≤ 5 × 10⁵，1 ≤ 点权、边权 ≤ 10⁹，强制在线。测试链接：P7834。

前半段是老样子：按边权升序建树，从 u 往上跳到 nodeKey ≤ x 的最高祖先，得到连通块。新问题只在这块里问第 k 大点权。

既然连通块是 dfn 上的一段 [l, r]，第 k 大就变成「数组区间 [l, r] 里第 k 大」。这是主席树的活：把点权离散化，按 dfn 顺序依次插入，建出 n 个前缀版本；查 [l, r] 时拿 root[r] 减 root[l - 1]，在两棵树的差上二分。

三、代码

题目6 的边权分配。先扫一遍删边操作打标记，再正着给没删过的边编号，最后倒着给删掉的边编号。

void prepare() {
        for (int i = 1; i <= q; i++) {
            if (ques[i][0] == 2) {
                edge[ques[i][1]].w = -1;
            }
        }
        int weight = 0;
        for (int i = 1; i <= m; i++) {
            if (edge[i].w != -1) {
                edge[i].w = ++weight;
            }
        }
        for (int i = q; i >= 1; i--) {
            if (ques[i][0] == 2) {
                edge[ques[i][1]].w = ++weight;
            }
        }
    }

dfs 里给叶子发 dfn，同时记下子树里最小的 dfn 和叶子个数。

void dfs(int u, int fa) {
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            dfs(to[e], u);
        }
        if (u <= n) {
            leafsiz[u] = 1;
            leafDfnMin[u] = ++cntd;
            leafseg[cntd] = u;
        } else {
            leafsiz[u] = 0;
            leafDfnMin[u] = n + 1;
        }
        for (int e = head[u]; e > 0; e = nxt[e]) {
            leafsiz[u] += leafsiz[to[e]];
            leafDfnMin[u] = min(leafDfnMin[u], leafDfnMin[to[e]]);
        }
    }

查询就是「上跳 → 得到区间 → 线段树取最大值 → 单点改成 0」。

int queryAndUpdate(int x, int limit) {
        int anc = getAncestor(x, limit);
        int dfn = query(leafDfnMin[anc], leafDfnMin[anc] + leafsiz[anc] - 1, 1, n, 1);
        int ans = node[leafseg[dfn]];
        update(dfn, 0, 1, n, 1);
        return ans;
    }

题目7 的收尾：上跳得到区间，两个前缀版本相减，在值域上二分找第 k 大。

int insert(int jobi, int l, int r, int i) {
        int rt = ++cntt;
        ls[rt] = ls[i];
        rs[rt] = rs[i];
        numcnt[rt] = numcnt[i] + 1;
        if (l < r) {
            int mid = (l + r) / 2;
            if (jobi <= mid) {
                ls[rt] = insert(jobi, l, mid, ls[rt]);
            } else {
                rs[rt] = insert(jobi, mid + 1, r, rs[rt]);
            }
        }
        return rt;
    }

    int query(int jobk, int l, int r, int pre, int post) {
        if (l == r) {
            return l;
        }
        int mid = (l + r) / 2;
        int rsize = numcnt[rs[post]] - numcnt[rs[pre]];
        if (rsize >= jobk) {
            return query(jobk, mid + 1, r, rs[pre], rs[post]);
        } else {
            return query(jobk - rsize, l, mid, ls[pre], ls[post]);
        }
    }

    int kthMax(int u, int x, int k) {
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[u][p] > 0 && nodeKey[stjump[u][p]] <= x) {
                u = stjump[u][p];
            }
        }
        if(leafsiz[u] < k) {
            return 0;
        }
        int idx = query(k, 1, s, root[leafDfnMin[u] - 1], root[leafDfnMin[u] + leafsiz[u] - 1]);
        return sorted[idx];
