树套树（树状数组套 K-D 树）

一个数据结构管不了一维以上的约束，就把维度拆开分给两层：外层管第一维，外层的每个节点背后再挂一棵 K-D 树管剩下的两维。这就是树套树。

零、背景

树状数组管前缀和，K-D 树管平面上的矩形。两个都只擅长自己那一摊：树状数组只认「下标的前缀」，K-D 树认「二维的盒子」。遇到三维、四维的约束，单独哪一个都不够。

把它们拼起来的办法很直接，让树状数组的每个下标背后不再是一个数，而是挂一整棵 K-D 树。外层负责把第一维切成一个个前缀，内层在每个前缀里回答剩下两维的问题。

一、问题

四维偏序最长链。一共 n 个点，每个点有四维坐标 (a, b, c, d)。可以任意挑点排成一列，每个点最多用一次；点 x 后面能放点 y 的条件是 x 的每一维都不超过 y 对应的那一维。问这列最长能有多长。

例子用 6 个点：

点编号123456
(a, b, c, d)(1, 2, 3, 4)(2, 3, 4, 5)(1, 1, 2, 3)(2, 2, 3, 5)(3, 1, 1, 2)(2, 4, 2, 6)

手算一下：3 号 (1,1,2,3) → 1 号 (1,2,3,4) → 4 号 (2,2,3,5) → 2 号 (2,3,4,5)，四维都是不减的，长度 4。答案就是 4。

二、朴素做法

把它当最长上升子序列做：dp[i] 表示以 i 号点结尾时最长能排多长，枚举所有 j 看能不能接到 i 后面。判断是 O(1)，枚举是 O(n²)，n = 5 × 10⁴ 时要比 2.5 × 10⁹ 次，过不去。

三维偏序有成熟的做法：CDQ 分治，O(n log² n)。四维要 CDQ 套 CDQ，O(n log³ n)，写得动但不好写。这一节走另一条路，用数据结构直接把三维的「前缀最大值」查出来。

三、先按 a 排序，剩下三维

先把所有点按 a、b、c、d 的字典序排一遍。排完之后，序列里位置靠前的点，a 一定不大于位置靠后的点，因为 a 是排序的第一关键字。于是 a 这一维不用再管了。

排好序之后，dp 的式子就变成：

dp[i] = 1 + max{ dp[j] : j 在 i 前面，且 bⱼ ≤ bᵢ、cⱼ ≤ cᵢ、dⱼ ≤ dᵢ }

剩下 b、c、d 三维，正好对应「在某个前缀里查三维的最大值」。前缀交给树状数组，剩下两维交给 K-D 树。

四、外层管 b，内层管 c 和 d

b 的值域很大（题目给到 ±10⁹），所以先离散化：把 b 值从小到大排一遍，用排名代替原值。这里有个细节，排名必须两两不同，否则 b 相等的点会互相贡献，把「不减」变成「严格小于」了。做法是排序时以 b 为主关键字、点的下标为次关键字。

于是结构是这样：树状数组的第 i 个下标，对应 b 排名 ≤ i 的那些点；它挂着的那棵 K-D 树，存的是这些点的 (c, d) 坐标，每个点上带着自己的 dp 值，子树上维护 maxdp。

改一个点的时候，外层走 i += lowbit(i)，把新状态加进沿途每一棵 K-D 树；查的时候走 i -= lowbit(i)，把沿途每棵的答案取最大值。和一维树状数组的写法完全一样，只是「维护的信息」从整数换成了一棵 K-D 树。

五、一次查询到底跳几棵

这里有个反直觉的结论：单次查询是 O(√n)，不是 O(log n · √n)。

原因在于树状数组跳的这些槽位，管辖的区间长度各不相同。以查询排名 7 为例，它访问槽 7、槽 6、槽 4，三个槽分别管 1 个、2 个、4 个点。在管 k 个点的 K-D 树里查一次是 O(√k)，于是总代价是：

也就是说，虽然访问了 O(log n) 棵 K-D 树，但除最大的那棵之外，其余都很小，加起来也翻不出 √n 这个量级。这一点是这题能过的关键，写复杂度的时候别顺手乘上 log n。

六、K-D 树里怎么查

内层的查询和上一节的矩形查询一个套路，只是这次要的不是最小编号，而是「c ≤ qc 且 d ≤ qd 的点里最大的 dp」。每个节点维护子树的 maxdp，剪枝条件对应变成四条：

  1. 子树里 c 的最小值已经大于 qc，或者 d 的最小值已经大于 qd，整棵剪掉。
  2. 子树的 maxdp 不大于当前答案，剪掉，再怎么找也超不过。
  3. 子树的包围盒完全落在 c ≤ qc、d ≤ qd 里，直接取整棵的 maxdp，不用往下走。
  4. 都不满足，看当前点自己满不满足，然后递归两个儿子。

注意 A 那棵虽然整棵被包住，但它下面挂的 C 号点 d = 5，本来是在范围里的（d ≤ 6），所以取它的 maxdp = 3 是对的，不需要再往下确认。反过来，如果查询是 d ≤ 4，A 的包围盒 dmax = 5 就包不住了，得往下走，走到 C 的时候 dmin = 5 > 4 才会被剪掉。

八、换个外层：权值线段树

树套树的外层不一定非得是树状数组。把第一维换成「权值」，外层就是一棵权值线段树，内层照样是 K-D 树。一道题正好是这个形状：崂山白花蛇草水。

网格 n × n，两种操作：在 (a, b) 加一个点权为 v 的点；查询以 (a, b) 为左下角、(c, d) 为右上角的矩形中第 k 大的点权。强制在线，所有参数都要异或上一次的答案。

强制在线带来的麻烦是：点权没法提前收集起来离散化。所以外层的权值线段树必须开点，值域取 1 到 10⁹，深度 30。加一个点时，沿着根到叶子的路径，每一层都往那棵 K-D 树里插一次坐标；一个点因此会进 31 棵 K-D 树。

查询时先数一下整棵里矩形内的点数够不够 k，不够直接输出题目要求的那串字符。够的话就在权值线段树上二分：右儿子（大权值那半）矩形内的点数 cnt 不小于 k，说明第 k 大在右边，往右走；否则第 k 大在左边，k 减去 cnt 再往左走。

九、代码

下面是四维偏序那题的完整实现。K-D 树用的是上一节那套动态实现，只是没有删除操作，维护的信息换成了 maxdp。

#include <bits/stdc++.h>
using namespace std;

struct ABCD {
    int a, b, c, d;
};

bool ABCDCmp(ABCD x, ABCD y) {
    if (x.a != y.a) return x.a < y.a;
    if (x.b != y.b) return x.b < y.b;
    if (x.c != y.c) return x.c < y.c;
    return x.d < y.d;
}

struct BI {
    int b, i;
};

bool BICmp(BI x, BI y) {
    if (x.b != y.b) return x.b < y.b;
    return x.i < y.i;
}

const int MAXN = 50001;
const int MAXT = 500001;    // 每个点进 O(log n) 棵 K-D 树
const int INF  = 1 << 30;
int n;

ABCD abcd[MAXN];
BI bi[MAXN];
int ranking[MAXN];

// K-D 树维护 c、d 坐标
int c[MAXT], d[MAXT], cntkdt;
int rootkdt[MAXN];        // 每个树状数组的下标，背后是一棵动态 kdt
int ls[MAXT], rs[MAXT];
int siz[MAXT];
int cmin[MAXT], cmax[MAXT], dmin[MAXT], dmax[MAXT];

int dp[MAXT];             // 单点结尾时的最长偏序链的长度
int maxdp[MAXT];          // 区域的最大 dp 值

double ALPHA = 0.7;
int top, topFather, topSide, topDimension;
int arr[MAXN], treeSiz;

int init(int qc, int qd, int qv) {
    cntkdt++;
    c[cntkdt] = qc;
    d[cntkdt] = qd;
    ls[cntkdt] = rs[cntkdt] = 0;
    siz[cntkdt] = 1;
    cmin[cntkdt] = cmax[cntkdt] = qc;
    dmin[cntkdt] = dmax[cntkdt] = qd;
    dp[cntkdt] = maxdp[cntkdt] = qv;
    return cntkdt;
}

void maintain(int i) {
    siz[i] = 1 + siz[ls[i]] + siz[rs[i]];
    cmin[i] = min(c[i], min(cmin[ls[i]], cmin[rs[i]]));
    cmax[i] = max(c[i], max(cmax[ls[i]], cmax[rs[i]]));
    dmin[i] = min(d[i], min(dmin[ls[i]], dmin[rs[i]]));
    dmax[i] = max(d[i], max(dmax[ls[i]], dmax[rs[i]]));
    maxdp[i] = max(dp[i], max(maxdp[ls[i]], maxdp[rs[i]]));
}

int compareNode(int i, int j, int dimension) {
    int v1 = dimension == 0 ? c[i] : d[i];
    int v2 = dimension == 0 ? c[j] : d[j];
    return v1 == v2 ? 0 : v1 < v2 ? -1 : 1;
}

struct Cmp {
    int dimension;

    bool operator()(int a, int b) const {
        return compareNode(a, b, dimension) < 0;
    }
};

int build(int l, int r, int dimension) {
    if (l > r) {
        return 0;
    }
    int mid = (l + r) >> 1;
    nth_element(arr + l, arr + mid, arr + r + 1, Cmp{dimension});
    int rt = arr[mid];
    ls[rt] = build(l, mid - 1, dimension ^ 1);
    rs[rt] = build(mid + 1, r, dimension ^ 1);
    maintain(rt);
    return rt;
}

bool balance(int i) {
    return ALPHA * siz[i] >= max(siz[ls[i]], siz[rs[i]]);
}

void dfs(int i) {
    if (i != 0) {
        arr[++treeSiz] = i;
        dfs(ls[i]);
        dfs(rs[i]);
    }
}

void rebuild(int version) {
    if (top != 0) {
        treeSiz = 0;
        dfs(top);
        int newRoot = build(1, treeSiz, topDimension);
        if (topFather == 0) {
            rootkdt[version] = newRoot;
        } else if (topSide == 1) {
            ls[topFather] = newRoot;
        } else {
            rs[topFather] = newRoot;
        }
    }
}

int addKdt(int insertNode, int u, int fa, int side, int dimension) {
    if (u == 0) {
        return insertNode;
    }
    if (compareNode(insertNode, u, dimension) <= 0) {
        ls[u] = addKdt(insertNode, ls[u], u, 1, dimension ^ 1);
    } else {
        rs[u] = addKdt(insertNode, rs[u], u, 2, dimension ^ 1);
    }
    maintain(u);
    if (!balance(u)) {
        top = u;
        topFather = fa;
        topSide = side;
        topDimension = dimension;
    }
    return u;
}

void addKdt(int version, int qc, int qd, int qv) {
    top = topFather = topSide = topDimension = 0;
    int insertNode = init(qc, qd, qv);
    rootkdt[version] = addKdt(insertNode, rootkdt[version], 0, 0, 0);
    rebuild(version);
}

int lowbit(int i) {
    return i & -i;
}

// 新增一个状态，b 排名为 rank，二维坐标为 (qc, qd)，dp 值为 qv
void add(int rank, int qc, int qd, int qv) {
    for (int i = rank; i <= n; i += lowbit(i)) {
        addKdt(i, qc, qd, qv);
    }
}

int queryAns;

// 一棵 KDT 中查询，c 坐标 <= qc，d 坐标 <= qd，最大的 dp 值
void updateAns(int qc, int qd, int i) {
    if (i == 0) {
        return;
    }
    if (cmin[i] > qc || dmin[i] > qd) {
        return;
    }
    if (maxdp[i] <= queryAns) {
        return;
    }
    if (cmax[i] <= qc && dmax[i] <= qd) {
        queryAns = max(queryAns, maxdp[i]);
        return;
    }
    if (c[i] <= qc && d[i] <= qd) {
        queryAns = max(queryAns, dp[i]);
    }
    updateAns(qc, qd, ls[i]);
    updateAns(qc, qd, rs[i]);
}

// 查询 b 排名 <= rank，c 坐标 <= qc，d 坐标 <= qd，最大的 dp 值
int query(int rank, int qc, int qd) {
    queryAns = 0;
    for (int i = rank; i > 0; i -= lowbit(i)) {
        updateAns(qc, qd, rootkdt[i]);
    }
    return queryAns;
}

void prepare() {
    sort(abcd + 1, abcd + n + 1, ABCDCmp);
    for (int i = 1; i <= n; i++) {
        bi[i].b = abcd[i].b;
        bi[i].i = i;
    }
    sort(bi + 1, bi + n + 1, BICmp);
    for (int i = 1; i <= n; i++) {
        ranking[bi[i].i] = i;
    }
    cmin[0] = dmin[0] = INF;
    cmax[0] = dmax[0] = -INF;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> abcd[i].a >> abcd[i].b >> abcd[i].c >> abcd[i].d;
    }
    prepare();
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        int cur = query(ranking[i], abcd[i].c, abcd[i].d) + 1;
        ans = max(ans, cur);
        add(ranking[i], abcd[i].c, abcd[i].d, cur);
    }
    cout << ans << '\n';
    return 0;
}

空间是这题最容易爆的地方。每个点要进 O(log n) 棵 K-D 树，n = 5 × 10⁴ 时节点总数是 n log n 量级，MAXT 开到 5 × 10⁵ 才够。重构用的临时数组 arr 只要开 MAXN，因为一次只重建其中一棵。

十、复杂度分析

操作时间复杂度
排序（a、b、c、d 一次，b 排名一次）O(n log n)
加入一个状态（外层 O(log n) 棵 × 内层插入）O(log² n) 摊还
查询一次（外层若干棵 × 内层 O(√k)）O(√n)
四维偏序整体O(n√n)
朴素做法（对照）O(n²)
崂山白花蛇草水单次操作O(log V · √n)，V 是权值值域
额外空间O(n log n)

查询那一行的 O(√n) 已经在第五节推导过：外层访问 O(log n) 棵，但它们的规模是 1、2、4、… 成倍变大，Σ√ 是收敛的等比数列，被最大的那一项卡住，总共约 2.41√n。

整体复杂度由查询主导。加入是 O(log² n)，n 次也才 n log² n，比 n√n 小。

空间上，K-D 树节点按「点数 × log n」算，每个点有坐标、左右儿子、子树大小、包围盒、dp 与 maxdp，十来个 int。n = 5 × 10⁴ 时约 5 × 10⁵ 个节点，二十兆上下，注意别开小了。

十一、最后

树套树的思路说穿了就是把维度分给不同的层：哪一维适合当「前缀」，就交给外层的树状数组或线段树；剩下几维适合当「盒子」，就交给内层的 K-D 树。外层选择哪种树，取决于第一维是下标、是权值，还是能不能离线离散化。

代价也很清楚：每个点要被复制进 O(log n) 棵 K-D 树，空间跟着涨一个 log。n 到 10⁵ 还撑得住，再往上就得换别的做法了。

还有一点值得记：这类题的瓶颈常常不是渐进复杂度，而是常数。K-D 树的重构、递归、包围盒比较都是实打实的开销，写的时候能剪的枝尽早剪，尤其是「maxdp 不大于当前答案」这一条，它让大量子树连递归都不用进。
