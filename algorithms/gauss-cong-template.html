高斯消元解同余方程组：乘逆元的消元

加法方程组换成同余方程组，消元动作从「除」变成「乘以逆元」；想要主元和自由元的正确关系，还要在消元时多做一件事。这一节把这两处讲透，再给一道网格刷 0 的题验证。

零、同余方程组：每行方程都带一个 mod

前置的三块内容：同余原理（加减乘都保同余）、逆元与除法同余（含逆元线性递推）、高斯消元的基本过程。本节只改一处：方程变成

a1x1 + a2x2 + … + anxn ≡ b (mod MOD)

系数、未知数、常数全部在模 MOD 的意义下运算。取模的数字保证是质数，因为后面要算逆元，只有模质数每个非 0 数才有逆元。逆元表用线性递推一次建好，这一节的模板统一用 mod 7 的逆元表：inv[1]=1，inv[i] = MOD - inv[MOD%i]×(MOD/i) % MOD。

一、消元模板：先约分，再乘逆元

加法版消元是「j 行减去 rate 倍 i 行」，同余版不能照抄：除法在模意义下是乘逆元，但直接用逆元会碰上一个麻烦：消元要保留主元和自由元的正确关系，纯按「乘逆元后相减」会把已经定好的主元行污染掉。

课程模板的做法是先约分再缩放：取 g = gcd(mat[j][i], mat[i][i])，a = mat[i][i]/g，b = mat[j][i]/g，然后

mat[j] = mat[j] × a − mat[i] × b

看第 i 列：mat[j][i]×a − mat[i][i]×b = c×a − a×c = 0，这一列被消干净。而两个系数的 gcd 约分保证 a、b 互质，消元过程中系数不会越滚越大。

下面是完整模板。选主元、gcd 缩放消元、最后归一化，三段结构。注意这一段是「完整版」，它把主元和自由元的关系也保留了：

// 高斯消元解决同余方程组模板（行最简形）
    // 系数保证非负，用 ((x % MOD) + MOD) % MOD 规整
    void gauss(int n) {
      for (int i = 1; i <= n; i++) {
        // 找第 i 列系数非 0 的行换到第 i 行，已成主元的行不参与
        for (int j = 1; j <= n; j++) {
          if (j < i && mat[j][j] != 0) {
            continue;
          }
          if (mat[j][i] != 0) {
            swap(mat[i], mat[j]);
            break;
          }
        }
        if (mat[i][i] == 0) {
          continue;
        }
        for (int j = 1; j <= n; j++) {
          if (i == j || mat[j][i] == 0) {
            continue;
          }
          // 消 j 行第 i 列：先约分，再用 gcd 缩放消元
          int g = gcd(mat[j][i], mat[i][i]);
          int a = mat[i][i] / g;
          int b = mat[j][i] / g;
          if (j < i && mat[j][j] != 0) {
            // j 行已成主元：把 j 列到 i-1 列系数都乘 a
            // 这样主元和自由元的关系仍然正确
            for (int k = j; k < i; k++) {
              mat[j][k] = (mat[j][k] * a) % MOD;
            }
          }
          // 正常消元：mat[j] = mat[j] * a - mat[i] * b
          for (int k = i; k <= n + 1; k++) {
            mat[j][k] = ((mat[j][k] * a - mat[i][k] * b) % MOD + MOD) % MOD;
          }
        }
      }
      // 求主元的值：不受自由元影响的主元直接归一化
      for (int i = 1; i <= n; i++) {
        if (mat[i][i] == 0) {
          continue;
        }
        bool flag = false;
        for (int j = i + 1; j <= n; j++) {
          if (mat[i][j] != 0) {
            flag = true;
            break;
          }
        }
        if (flag) {
          continue;  // 主元依赖自由元，保留关系不做归一化
        }
        // 除以主元系数 = 乘以逆元
        mat[i][n + 1] = (mat[i][n + 1] * inv[mat[i][i]]) % MOD;
        mat[i][i] = 1;
      }
    }

模板要求初始系数没有负数，读入时统一用 ((x % MOD) + MOD) % MOD 规整。上面的归一化段有个判断：主元行右侧（i+1 列起）还有非 0 系数，说明这个主元受自由元影响，不能直接除，要保留关系。

二、主元与自由元：受影响的主元不归一化

消元结束后，一个主元能不能确定值，看它右边还有没有自由元。没有 → 直接乘逆元归一化；有 → 保留原样，把「主元 = 若干自由元的组合」这个关系留在矩阵里。

例子里 x1 右侧全是 0，x1 = 2 直接确定；x2 右侧还有 6x3，6x2 + 6x3 ≡ 6，只有 x3 定了 x2 才能定。绝大多数教程的模板直接对每个主元乘逆元，这个关系就丢了。有些题需要多解情况下主元和自由元的正确关系（比如本节的题目2 之外的一些计数题），本节模板专门保住它。

如果题目不需要这个关系，逻辑可以化简，消元时 j 行只需调整自己的主元系数，自由元系数不用管。题目1 就是这种「怎么都行」的题。

三、题目1：格子全变 0（HDU5755）

n×m 网格，每格初始值 0、1、2 之一。刷子在某个格刷一下：该格 +2，上下左右各 +1，所有值随后 %3 落回 0、1、2。目标全部变 0。题目保证有解，不保证唯一解，打印总刷次数和每个格刷几下。n、m ≤ 30。

每个格子设一个变量 xid 表示刷的次数，一个格子最终收到的加成 = 2×自己 + Σ 邻居。目标加成 ≡ −初始值 (mod 3)，于是每个格子得到一行方程：

构造方程很简单：mat[cur][cur] = 2，四个方向内就 mat[cur][邻] = 1，常数 (3 − 初始值) % 3。下面是构造和消元：

// 题目1：构造模 3 线性方程组
    // 每个格子一个变量，刷自己一次得 2 加成，上下左右各得 1
    void prepare() {
      for (int i = 1; i <= s; i++) {
        for (int j = 1; j <= s + 1; j++) {
          mat[i][j] = 0;
        }
      }
      for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
          int cur = i * m + j + 1;
          mat[cur][cur] = 2;
          for (int d = 0; d < 4; d++) {
            int row = i + dir[d];
            int col = j + dir[d + 1];
            if (row >= 0 && row < n && col >= 0 && col < m) {
              mat[cur][row * m + col + 1] = 1;
            }
          }
        }
      }
      // 目标全变 0：加成 ≡ -初始值 (mod 3)
      for (int i = 1; i <= s; i++) {
        mat[i][s + 1] = (3 - value[i]) % MOD;
      }
    }
// 题目1的简化版：默认所有自由元都不操作
    // 于是消元时只需调整 j 行主元系数，不必维护自由元关系
    void gauss(int n) {
      for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
          if (j < i && mat[j][j] != 0) {
            continue;
          }
          if (mat[j][i] != 0) {
            swap(mat[i], mat[j]);
            break;
          }
        }
        if (mat[i][i] == 0) {
          continue;
        }
        for (int j = 1; j <= n; j++) {
          if (i == j || mat[j][i] == 0) {
            continue;
          }
          int g = gcd(mat[j][i], mat[i][i]);
          int a = mat[i][i] / g;
          int b = mat[j][i] / g;
          if (j < i && mat[j][j] != 0) {
            // 只调整 j 行主元系数，自由元系数不用管
            mat[j][j] = (mat[j][j] * a) % MOD;
          }
          for (int k = i; k <= n + 1; k++) {
            mat[j][k] = ((mat[j][k] * a - mat[i][k] * b) % MOD + MOD) % MOD;
          }
        }
      }
      // 主元值直接乘逆元，自由元保持 0
      for (int i = 1; i <= n; i++) {
        if (mat[i][i] != 0) {
          mat[i][n + 1] = (mat[i][n + 1] * inv[mat[i][i]]) % MOD;
        }
      }
    }

对比完整版：这里 j 行已有主元时只调 mat[j][j]，不碰 j+1 列到 i−1 列的自由元系数，因为最终默认所有自由元都不操作。归一化段也少一个判断，直接对每个主元乘逆元。这个简化成立的前提是「任何一种方案都可以」。

答案就是 Σ mat[i][s+1]，每个格子 mat[id][s+1] 次操作，逐格打印坐标。总操作次数最多 n×m×2 ≈ 1800 次，输出规模在可接受范围。

五、总结

同余方程组的消元模板比加法版多两处：消元用 gcd 约分后的缩放（mat[j] = mat[j]×a − mat[i]×b），主元求值用乘逆元。第三处是本课重点：主元右侧还有自由元时不归一化，把主元和自由元的关系留在矩阵里，绝大多数模板没做这一步。题目1 不需要这个关系，所以简化版只调主元系数，速度更快。下一节把完整版用到工具工厂题上：推断工具制作天数，还要区分矛盾、多解、唯一解三种输出。
