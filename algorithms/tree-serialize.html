二叉树的序列化与重建

把一棵树存成字符串，再从字符串把树原样读回来。LeetCode 297 的序列化反序列化，加上用先序和中序两段序列重建整棵树。

零、背景

序列化的场景很具体：树要跨进程传、要存盘、要进缓存，指针没法带走，得先变成一串字符。反序列化就是把这串字符还原成一棵一模一样的树。

难点不在「把节点值拼成串」，在「空位怎么记」。先序、后序、按层三种顺序都行，唯独中序不行，这一节会专门解释为什么。

节点定义沿用前面的课，这次带构造器，方便反序列化时直接 new TreeNode(v)。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

一、先序序列化与反序列化（LeetCode 297）

先序序列化：根 → 左子树 → 右子树，空节点写 #，每个值后面跟一个逗号。一棵 1 左 2、右 3 的树，序列是 1,2,#,#,3,#,#,。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 二叉树先序序列化和反序列化（LeetCode 297）
    // 空节点记 "#"，节点之间用 "," 隔开
    // 先序 / 后序 / 按层都能序列化；中序不行：
    // 1 只有右孩子 2 和 2 只有左孩子 1 这两棵树，
    // 补上空位后的中序序列都是 {null, 1, null, 2, null}，无法区分

    string Serialize(TreeNode* root) {
        string builder;
        F(root, builder);
        return builder;
    }

    void F(TreeNode* root, string& builder) {
        if (root == nullptr) {
            builder += "#,";
        } else {
            builder += to_string(root->val) + ",";
            F(root->left, builder);
            F(root->right, builder);
        }
    }

    // 反序列化：游标 cnt 从数组里依次取，取到 "#" 返回空，否则建节点后递归左右
    int cnt;

    TreeNode* Deserialize(string data) {
        vector<string> vals;
        string cur;
        for (char c : data) {
            if (c == ',') {
                vals.push_back(cur);
                cur.clear();
            } else {
                cur += c;
            }
        }
        cnt = 0;
        return G(vals);
    }

    TreeNode* G(vector<string>& vals) {
        string cur = vals[cnt++];
        if (cur == "#") {
            return nullptr;
        }
        TreeNode* head = new TreeNode(stoi(cur));
        head->left = G(vals);
        head->right = G(vals);
        return head;
    }

为什么 # 必须写全？因为先序本身分不清「左孩子为空」和「左孩子已经遍历完」。写全空位，反序列化才知道往哪一层、哪个位置放节点。

反序列化用一个游标 cnt 从头扫：取到 # 返回空，否则建节点、递归建左子树、再递归建右子树。先序里「根在左子树之前」这个顺序保证游标扫到的顺序正好是建树的顺序。

时间 O(n)、空间 O(n)，递归深度等于树高。

二、中序为什么不行

先序、后序、按层都能序列化，中序不能。原因是两棵不同的树可能得到同一个中序序列，补上空位也一样。

看这两棵树：1 只有右孩子 2，和 2 只有左孩子 1。补足空位后，两者的中序序列都是 #,1,#,2,#。

中序把根夹在中间，光看序列不知道哪个是根、左右子树各多长。先序和后序的「根在最前/最后」把这个信息带出来了。

三、按层序列化与反序列化（LeetCode 297）

按层序列化就是层序 BFS：根先写，然后一层层从左往右写，空节点写 #。上面那棵树写成 1,2,3,#,#,#,#,。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 二叉树按层序列化和反序列化（LeetCode 297）
    // 空节点记 "#"，节点之间用 "," 隔开
    // 序列化时 BFS 一层层走，孩子为空的直接写 "#"

    string Serialize(TreeNode* root) {
        string builder;
        if (root != nullptr) {
            builder += to_string(root->val) + ",";
            vector<TreeNode*> q;
            q.push_back(root);
            for (int l = 0, r = 1; l < r;) {
                TreeNode* cur = q[l++];
                if (cur->left != nullptr) {
                    builder += to_string(cur->left->val) + ",";
                    q.push_back(cur->left);
                    r++;
                } else {
                    builder += "#,";
                }
                if (cur->right != nullptr) {
                    builder += to_string(cur->right->val) + ",";
                    q.push_back(cur->right);
                    r++;
                } else {
                    builder += "#,";
                }
            }
        }
        return builder;
    }

    // 反序列化：也是 BFS。
    // 每个出队节点从数组里取两个孩子，孩子非空就入队继续取它的孩子
    TreeNode* Deserialize(string data) {
        if (data.empty()) {
            return nullptr;
        }
        vector<string> nodes;
        string cur;
        for (char c : data) {
            if (c == ',') {
                nodes.push_back(cur);
                cur.clear();
            } else {
                cur += c;
            }
        }
        int index = 0;
        TreeNode* root = Generate(nodes[index++]);
        vector<TreeNode*> q;
        q.push_back(root);
        for (int l = 0, r = 1; l < r;) {
            TreeNode* node = q[l++];
            node->left = Generate(nodes[index++]);
            node->right = Generate(nodes[index++]);
            if (node->left != nullptr) {
                q.push_back(node->left);
                r++;
            }
            if (node->right != nullptr) {
                q.push_back(node->right);
                r++;
            }
        }
        return root;
    }

    TreeNode* Generate(string& val) {
        return val == "#" ? nullptr : new TreeNode(stoi(val));
    }

反序列化也按层来：队列里装「待补孩子的节点」，每出一个节点，从数组里取两个孩子补上；补上的孩子非空就入队，继续给它补孩子。层序的「父亲先于儿子出现」保证了这个顺序成立。

按层序列化对斜树不友好：一棵 10000 层的右偏链，序列长度是 2 万个 token，先序也一样。两种写法没有绝对优劣，看树的形状。

四、用先序和中序重建二叉树（LeetCode 105）

这一题给两段序列：先序 preorder 和中序 inorder，要重建原树。先序的第一个元素一定是根；中序里，根把序列切成左子树区间和右子树区间。

有了根在中序里的位置 k，两棵子树的范围就全定了：中序左子树是 l2..k-1，长度 k-l2；先序里根后面 k-l2 个就是左子树，剩下的是右子树。递归下去即可。

struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    // 利用先序与中序遍历序列构造二叉树（LeetCode 105）
    // 先序的第一个元素是根；中序里根把序列切成左右两半
    // 先用哈希表记下每个值在中序里的下标，递归时 O(1) 找根
    TreeNode* BuildTree(vector<int>& pre, vector<int>& in) {
        unordered_map<int, int> map;
        for (int i = 0; i < (int)in.size(); i++) {
            map[in[i]] = i;
        }
        return F(pre, 0, pre.size() - 1, in, 0, in.size() - 1, map);
    }

    // l1..r1 是先序区间，l2..r2 是中序区间
    TreeNode* F(vector<int>& pre, int l1, int r1, vector<int>& in, int l2, int r2,
                unordered_map<int, int>& map) {
        if (l1 > r1) {
            return nullptr;
        }
        TreeNode* head = new TreeNode(pre[l1]);
        if (l1 == r1) {
            return head;
        }
        int k = map[pre[l1]];   // 根在中序里的位置
        // 中序左树区间是 l2..k-1，长度 k-l2，对应先序的 l1+1..l1+k-l2
        // 中序右树区间是 k+1..r2，对应先序的 l1+k-l2+1..r1
        head->left = F(pre, l1 + 1, l1 + k - l2, in, l2, k - 1, map);
        head->right = F(pre, l1 + k - l2 + 1, r1, in, k + 1, r2, map);
        return head;
    }

先序里找根是 O(1)（第一个元素），麻烦的是中序里找根的位置。每次都线性扫一遍，总代价 O(n²)。用一张哈希表预先把「值 → 中序下标」存下来，递归里查表 O(1)，整题 O(n)。

下标计算是最容易写错的地方：左子树先序区间 l1+1 .. l1+k-l2，右子树 l1+k-l2+1 .. r1。区间长度必须和对应中序区间一致，可以顺手数一遍再写。

五、复杂度分析

题目时间额外空间说明
先序序列化/反序列化O(n)O(h)递归栈深度等于树高

三个题的规模都是「每个节点处理常数次」，所以时间 O(n)。重建题如果不加哈希表直接在中序里扫根，最坏退化到 O(n²)。

六、总结

序列化三题的内核是同一个：先序、后序、按层都能序列化，因为它们把「根在哪」这个信息带在序列结构里；中序把根夹在中间，信息丢了。

反序列化分别是「游标递归」和「队列补孩子」两种姿势，都靠「父亲先于孩子出现」这个顺序保证。

重建题记一句：先序定根、中序切区间、哈希表把找根压到 O(1)。下标区间写的时候数一遍长度。
