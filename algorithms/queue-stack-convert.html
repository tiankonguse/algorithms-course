栈和队列相互实现

上一讲把队列和栈本身的数组实现写对了。这一讲加个限制：手里只有栈，要做出先来先走的队列；手里只有队列，要做出后来先走的栈。对应 LeetCode 232 和 225，也是面试里考均摊分析最常用的两道题。

零、背景

一串数过一遍栈，出来的顺序整个反过来；过一遍队列，顺序原样保留。这一讲的两个转换题，全部难度都从这一句话长出来。

一、栈反序，队列保序

把 1、2、3 依次 push 进栈，再依次 pop，出来是 3、2、1。栈只有顶一个口，先进去的被压在最底下，最后才轮到它。

队列两头开口，尾进头出，1、2、3 进去还是 1、2、3 出来，相对顺序一个不变。

那手里有两个栈，想还原原序怎么办？让一串数过两遍：过第一个栈反一次序，过第二个栈再反一次，次序就回来了。

二、用两个栈实现队列

两个栈分工：in 栈管进，所有 push 都压进 in；out 栈管出，pop、peek 都从 out 顶拿。out 空了，才把 in 里的元素挨个倒进 out。

跟着 1、2、3 走一遍。三次 push 之后，in 从顶到底是 3、2、1，out 空着。第一次 pop 触发倒数据：3 先从 in 顶出来压进 out，然后是 2、1；in 倒空，out 从顶到底变成 1、2、3，栈顶就是队头 1。之后三次 pop 依次拿到 1、2、3，队列的效果出来了。

#include <bits/stdc++.h>
    using namespace std;

    // 用两个栈实现队列：in 管进，out 管出
    class MyQueue {
    public:
        stack<int> in, out;

        // 倒数据：out 空了才能倒，要倒就把 in 倒完
        void inToOut() {
            if (out.empty()) {
                while (!in.empty()) {
                    out.push(in.top());
                    in.pop();
                }
            }
        }

        void push(int x) {
            in.push(x);
            inToOut();
        }

        int pop() {
            inToOut();
            int v = out.top();
            out.pop();
            return v;
        }

        int peek() {
            inToOut();
            return out.top();
        }

        bool empty() {
            return in.empty() && out.empty();
        }
    };

注意 push 里也调了一次 inToOut。out 非空时它是空操作；唯一的作用是第一个元素进队后立刻被倒进 out，之后随时 peek 都拿得到东西，不会对着空栈取顶。

每个元素从进到出走的是一条单行道：in 进一次、in 出一次、out 进一次、out 出一次，四次底层栈操作，没有回头路。这条性质第五节算账要用。

三、倒数据的两条规矩

inToOut 看起来就一个 while，规矩有两条，破哪一条顺序都错。

第一条，out 没空不能倒。out 里还压着没出队的旧元素，把 in 里的新元素倒过去，新元素会压在旧元素头上，后来的反倒先出。

第二条，要倒就把 in 一次倒完。倒一半，等于让 in 顶的元素插队到 out 顶，顺序同样乱。

还有一个小的：empty 得两个栈都空才算空。倒数据之后 in 是空的，元素全在 out 里，只看 in 会把非空报成空。

这几个笔误对数器抓不抓得到？把它们写进代码，用 2 万条随机序列（每条最多 40 个操作、六成概率入队）实测，抓取率如下。队列实现栈那边两个对应的笔误一并放进来。

笔误后果2 万条随机序列抓取率
倒数据不判 out 空新元素压过旧元素，peek 直接错100.00%
out 空了只倒一个in 顶元素插队到 out 顶99.995%（19999/20000）
empty 只看 in倒完数据后把非空报成空90.72%
栈版 push 不轮转退化成普通队列，pop 拿最老的元素100.00%
轮转多转一圈新元素又被转回队尾100.00%

前两个笔误，只要序列里出现「连续几次入队再出队」就现形，随机样本几乎必中。empty 那个有 9.28% 的漏网，因为它只在「in 恰好倒空、out 里还有货」的那几步问 empty 才错，问得早就问不出来。

操作台可以切到错误版本单步执行，看它到底从第几步开始给出错误答案，出错的格子和返回值会标红。随机序列每个版本用同一个种子，方便对照。

四、用队列实现栈

翻过来就没有「反两次」这种便宜事了：队列过一遍顺序不变，两个队列串起来还是不变。想让新来的 x 第一个被拿走，只能把排在它前面的老元素挨个挪到它身后。

一个队列就够。push 之前记住队列里有 n 个元素，x 从队尾进去，再把队头的 n 个元素逐个 poll 出来、重新 offer 回队尾。老元素绕着队列转了一圈，x 顶到队头，队头就是栈顶。

#include <bits/stdc++.h>
    using namespace std;

    // 用一个队列实现栈：新元素入队后，把老元素挨个转到它后面
    class MyStack {
    public:
        queue<int> q;

        // O(n)：第 k 次 push 要轮转 k-1 个老元素
        void push(int x) {
            int n = q.size();
            q.push(x);
            for (int i = 0; i < n; i++) {
                q.push(q.front());
                q.pop();
            }
        }

        int pop() {
            int v = q.front();
            q.pop();
            return v;
        }

        int top() {
            return q.front();
        }

        bool empty() {
            return q.empty();
        }
    };

题目说「两个队列」，一个队列就能做，转圈的时候队尾接着队头，帮手队列省了。写成两个队列的版本思路完全一样：x 先进空的 q2，老元素从 q1 整体搬到 q2、排在 x 后面，然后 swap 两个队列的名字，q2 重新变空。

#include <bits/stdc++.h>
    using namespace std;

    // 两个队列的版本：helper 永远只放新来的那一个，再换名字
    class MyStack2 {
    public:
        queue<int> q1, q2;   // q1 里始终按「栈顶在前」排好

        void push(int x) {
            q2.push(x);                  // 新元素先进空的 q2，它就在队头
            while (!q1.empty()) {        // 老元素整体搬过去，排在 x 后面
                q2.push(q1.front());
                q1.pop();
            }
            swap(q1, q2);                // 换名字，q2 重新变空
        }

        int pop() {
            int v = q1.front();
            q1.pop();
            return v;
        }

        int top() { return q1.front(); }
        bool empty() { return q1.empty(); }
    };

演示里连每次轮转都拆成了一帧，可以看着队头元素绕回队尾；切到两个错误版本，第一次 top 就会和正确答案对不上。

五、复杂度分析

双栈队列的单次操作最坏是 O(n)，就贵在倒数据那一下：out 倒空之后第一次出队，可能要搬 n 个元素。但每个元素只从 in 往 out 流一次，绝不回头，n 次入队加 n 次出队，底层栈操作总共 4n 次，实测 n=100 和 n=10⁶ 都是每元素 4.00 次。均摊下来每个操作 O(1)。

队列实现栈没有这笔均摊便宜：第 k 次 push 要转 k-1 个老元素，n 次 push 累计 0+1+…+(n-1) = n(n-1)/2 次轮转，push 实打实 O(n)，pop 和 top 是 O(1)。

操作双栈实现队列单队列实现栈
push均摊 O(1)，最坏 O(n)O(n)
pop均摊 O(1)，最坏 O(n)O(1)
peek / top均摊 O(1)，最坏 O(n)O(1)
emptyO(1)O(1)
额外空间O(n)O(n)；两队列版最多占 2n 个位置

实测计时（g++ -O2）看得更直接：双栈队列 100 万次入队加 100 万次出队 6.04ms，std::queue 是 2.36ms，只差常数倍。队列实现栈 n=2 万就要 321.15ms，std::stack 只用 0.06ms，差五千倍，n 再涨还按平方级拉开。这就是「栈能反转顺序、队列不能」的标价。

六、总结

  • 栈反序、队列保序。两个栈串起来反两次，次序还原，这是双栈队列的全部原理。
  • in 管进、out 管出；out 空了才倒，倒就一次倒完；empty 两个栈都要看。每个元素只倒一次，均摊 O(1)。
  • 队列实现栈只能让老元素转圈：新元素入队后把 n 个老元素转到它身后，push O(n)，没有更便宜的写法。

后面 BFS 的队列、单调栈、表达式求值，都默认你把这两个容器的脾气用熟了。这两道题本身也是均摊分析最好的入门例子：双栈队列为什么敢说 O(1)，看每个元素总共搬几次，不要盯着某一次操作搬了几个。
