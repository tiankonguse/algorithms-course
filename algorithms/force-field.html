离散化：把大坐标压成小下标

坐标值域到 10^9 时数组开不出来，但「真正用到的坐标」往往只有几条。把用到的坐标排序、去重、编成 1..k 的小编号，所有操作换到编号上做，这就是离散化。配合二维差分，它能处理坐标 10^9、个数只有 100 的覆盖问题。

零、背景

「最强祝福力场」这道题：有 n 个正方形力场，第 i 个以 (x, y) 为中心、边长 side，边缘也算覆盖。问整片区域里力场强度最大值，也就是「被最多力场覆盖的那个点，被多少个力场盖着」。

n ≤ 100，但 x、y、side 都能到 10^9。直接开 (10^9)×(10^9) 的数组，10^18 个格子，任何机器都装不下。

换个角度看：n 个正方形，总共只有 2n 个不同的左/右 x 边界、2n 个不同的下/上 y 边界。矩形之间的相对位置只由这些边界决定，中间的点没人关心。把这些边界收集起来排序去重，编成 1..k 的小编号，网格瞬间缩到 k_x × k_y。

一、先处理一个细节：乘 2

覆盖范围是 [x − side/2, x + side/2]。side 可能是奇数，比如 (0,0) 边长 1，覆盖 [−0.5, 0.5]。边界落在半整数上，离散化拿浮点数也能做，但麻烦。

全部坐标乘 2：中心 2x、2y，范围 [2x − side, 2x + side]。边界变成整数，闭区间语义不变。代价是坐标到 2×10^9，超出 int，要用 long long。

二、离散化：收集、排序去重、二分查编号

把 2n 个 x 边界收进数组 X，2n 个 y 边界收进 Y。对 X、Y 各自排序去重，得到 sizex、sizey 个不同坐标。每个坐标在排序数组里的下标就是它的新编号（从 1 开始，给差分数组留出 0 下标）。

查编号用二分：rank(nums, v) 返回 v 在去重数组里的位置。代码里 v 一定在数组里，所以二分找「第一个 ≥ v 的位置」就是 v 本身。

三、压缩网格上跑二维差分

每个力场在压缩网格上对应一个矩形：[rank(2x−side), rank(2x+side)] × [rank(2y−side), rank(2y+side)]。对每个矩形做二维差分 add 四点，全部做完后 build 一遍前缀和，扫出最大值。

这里 build 出来的每个格子是「覆盖这一小格的力场数量」。格子内部力场覆盖情况相同，所以格子里的任意一点都能代表它；最大值一定出现在某条矩形边界上，压缩网格把边界全保留了。

四、复杂度：为什么 n ≤ 100 才敢开网格

排序 O(n log n)，网格 sizex × sizey ≤ (2n)×(2n) = 4n²，差分和 build 都在网格大小内。总时间 O(n log n + n²)，空间 O(n²)。

n = 100 时网格约 200×200 = 4 万格，随便跑。但网格随 n 平方增长：n = 10^3 就 400 万格，n = 10^5 是 400 亿格，光遍历一遍就要几十秒（本机实测 400 亿格 build 一遍约 85 秒）。所以这题 n ≤ 100 不是拍脑袋定的，离散化后 O(n²) 网格就是这个规模才划算。

五、代码

compress 排序去重返回有效长度；rank 二分查编号；add 是标准二维差分四点；主流程收集坐标 → 压缩 → 每个力场 add → build 扫最大。

#include <bits/stdc++.h>
    using namespace std;

    long long X[200005], Y[200005];

    // 排序 + 去重，返回有效长度
    int compress(long long* nums, int len) {
        sort(nums, nums + len);
        int size = 1;
        for (int i = 1; i < len; i++)
            if (nums[i] != nums[size - 1])
                nums[size++] = nums[i];
        return size;
    }

    // 有序数组 nums[0..size-1] 无重复，v 一定在里面，返回编号
    int rank(long long* nums, long long v, int size) {
        int l = 0, r = size - 1, m, ans = 0;
        while (l <= r) {
            m = (l + r) / 2;
            if (nums[m] >= v) {
                ans = m;
                r = m - 1;
            } else {
                l = m + 1;
            }
        }
        return ans + 1;
    }

    void add(vector<vector<int>>& diff, int a, int b, int c, int d) {
        diff[a][b] += 1;
        diff[c + 1][d + 1] += 1;
        diff[c + 1][b] -= 1;
        diff[a][d + 1] -= 1;
    }

    int fieldOfGreatestBlessing(vector<vector<int>>& fields) {
        int n = fields.size();
        for (int i = 0, k = 0, p = 0; i < n; i++) {
            long long x = fields[i][0], y = fields[i][1], r = fields[i][2];
            X[k++] = (x << 1) - r;
            X[k++] = (x << 1) + r;
            Y[p++] = (y << 1) - r;
            Y[p++] = (y << 1) + r;
        }
        int sizex = compress(X, n << 1);
        int sizey = compress(Y, n << 1);
        vector<vector<int>> diff(sizex + 2, vector<int>(sizey + 2, 0));
        for (int i = 0; i < n; i++) {
            long long x = fields[i][0], y = fields[i][1], r = fields[i][2];
            int a = rank(X, (x << 1) - r, sizex);
            int b = rank(Y, (y << 1) - r, sizey);
            int c = rank(X, (x << 1) + r, sizex);
            int d = rank(Y, (y << 1) + r, sizey);
            add(diff, a, b, c, d);
        }
        int ans = 0;
        for (int i = 1; i < (int)diff.size(); i++)
            for (int j = 1; j < (int)diff[0].size(); j++) {
                diff[i][j] += diff[i - 1][j] + diff[i][j - 1] - diff[i - 1][j - 1];
                ans = max(ans, diff[i][j]);
            }
        return ans;
    }

六、一个可点的操作台

总结

离散化三步：收集所有可能用到的坐标 → 排序去重 → 二分把原坐标换成编号。之后数组大小从值域降到「用到过的坐标个数」，差分、前缀和、树状数组这些数据结构全都能上。

这题三个坑：坐标乘 2 对付半整数边界；边缘算覆盖所以是闭区间；网格 O(n²)，题目数据范围决定它可行。接下来就按这个套路，凡是「值域大、点数少」的题都先想一遍离散化。
