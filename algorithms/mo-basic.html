普通莫队的五个题目

排序和滑动是固定的，每题真正要设计的是窗口里维护的那个量。五个题给出五种维护方式：种类数、平方和、概率、众数次数、异或配对数。

零、背景

上一节把骨架搭好了：查询按 l 的块号分组、块内按 r 排序，两个指针在数组上接力滑动，总移动量 O((n+m)√n)。

骨架之外只剩一件事：窗口加进一个元素、拿掉一个元素时，答案跟着怎么变。这一步每题都不一样，也是莫队题真正的考点。

下面五个题，从最直白的种类数一路到需要绕一个弯的异或配对。

一、不同数字个数

给定一个长度为 n 的数组，q 条查询，每条问 [l, r] 上有几种不同的数字。（SP3267 / DQUERY）

窗口里维护 cnt[x] 表示 x 出现几次，kind 表示出现次数不为 0 的数有几种。答案就是 kind。

加进一个 x：cnt[x] 从 0 变 1 时，多出一种，kind 加一。拿掉一个 x：cnt[x] 从 1 变 0 时，少一种，kind 减一。其余情况 kind 不动。

完整代码如下，排序用的是奇偶优化版本。

    
#include <bits/stdc++.h>

    using namespace std;

    struct Query {
        int l, r, id;
    };

    const int MAXN = 30001;
    const int MAXV = 1000001;
    const int MAXQ = 200001;
    int n, q;
    int arr[MAXN];
    Query query[MAXQ];

    int bi[MAXN];
    int cnt[MAXV];
    int kind = 0;

    int ans[MAXQ];

    bool QueryCmp1(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        return a.r < b.r;
    }

    bool QueryCmp2(Query &a, Query &b) {
        if (bi[a.l] != bi[b.l]) {
            return bi[a.l] < bi[b.l];
        }
        if ((bi[a.l] & 1) == 1) {
            return a.r < b.r;
        } else {
            return a.r > b.r;
        }
    }

    void del(int num) {
        if (--cnt[num] == 0) {
            kind--;
        }
    }

    void add(int num) {
        if (++cnt[num] == 1) {
            kind++;
        }
    }

    void prepare() {
        int blen = (int)sqrt(n);
        for (int i = 1; i <= n; i++) {
            bi[i] = (i - 1) / blen + 1;
        }
        sort(query + 1, query + q + 1, QueryCmp2);
    }

    void compute() {
        int winl = 1, winr = 0;
        for (int i = 1; i <= q; i++) {
            int jobl = query[i].l;
            int jobr = query[i].r;
            while (winl > jobl) {
                add(arr[--winl]);
            }
            while (winr < jobr) {
                add(arr[++winr]);
            }
            while (winl < jobl) {
                del(arr[winl++]);
            }
            while (winr > jobr) {
                del(arr[winr--]);
            }
            ans[query[i].id] = kind;
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> arr[i];
        }
        cin >> q;
        for (int i = 1; i <= q; i++) {
            cin >> query[i].l;
            cin >> query[i].r;
            query[i].id = i;
        }
        prepare();
        compute();
        for (int i = 1; i <= q; i++) {
            cout << ans[i] << '\n';
        }
        return 0;
    }

两个比较函数都留在里面。QueryCmp1 是块内 r 恒升序；QueryCmp2 让奇数块的 r 升序、偶数块的 r 降序，右指针跨块时顺着往回扫，省掉一半左右的空跑。

二、出现次数的平方和

小B的询问（P2709）：所有数字在 [1, k] 内，f(i) 表示 i 出现几次，查询要的是 f(1) + ... + f(k) 上每项平方之后的和，也就是 Σ f(i)²。

窗口维护 sum = Σ cnt[x]²。加进一个 x，只有 cnt[x] 这一项变了，代码直接减掉旧的平方、加进新的平方。

    
void del(int num) {
        sum -= cnt[num] * cnt[num];
        cnt[num]--;
        sum += cnt[num] * cnt[num];
    }

    void add(int num) {
        sum -= cnt[num] * cnt[num];
        cnt[num]++;
        sum += cnt[num] * cnt[num];
    }

增量其实可以写成 2c + 1，c 是加之前的次数。写成减旧加新不用记公式，也不容易写错。

三、抽到同色的概率

小Z的袜子（P1494）：[l, r] 上随机选两个不同位置，问数值相同的概率，用最简分数输出。

设区间长度为 len。分子是 Σ C(cnt[x], 2)，分母是 C(len, 2)，两者都带一个 1/2，约掉之后变成 (Σ cnt[x]² − len) / (len × (len−1))，因为 Σ cnt[x] 正好等于 len。

所以窗口还是维护平方和 sum，回答时套一次 gcd 约分。

    
        if (jobl == jobr) {
                ans1[id] = 0;
                ans2[id] = 1;
            } else {
                ans1[id] = sum - (jobr - jobl + 1);
                ans2[id] = 1LL * (jobr - jobl + 1) * (jobr - jobl);
                long long g = gcd(ans1[id], ans2[id]);
                ans1[id] /= g;
                ans2[id] /= g;
            }

len 为 1 时分母是 0，这种情况直接输出 0/1。

四、众数出现了几次

大爷的字符串题（P3709）：查询 [l, r] 上众数出现几次，打印次数的相反数。值域到 10⁹，先离散化。

众数不能直接维护：加一个数时它只会变大，删一个数时它可能变小也可能不变，光看次数定不下来。于是再记一层。

cnt1[x] 是 x 在窗口里出现几次，cnt2[c] 是出现次数恰好为 c 的数有几种，maxCnt 是当前的最大出现次数。加一个数，把它在 cnt2 里从旧次数那一档搬到新的一档，再用 max 更新 maxCnt。删一个数时，如果它的次数就是 maxCnt、且这一档只有它一个（cnt2[maxCnt] == 1），那么拿掉之后众数次数必然降一，maxCnt 减一。

    
void del(int num) {
        if (cnt1[num] == maxCnt && cnt2[cnt1[num]] == 1) {
            maxCnt--;
        }
        cnt2[cnt1[num]]--;
        cnt1[num]--;
        cnt2[cnt1[num]]++;
    }

    void add(int num) {
        cnt2[cnt1[num]]--;
        cnt1[num]++;
        cnt2[cnt1[num]]++;
        maxCnt = max(maxCnt, cnt1[num]);
    }

这里有个细节：del 里 maxCnt 只减不加。加回来那一步由 add 里的 max 兜住，所以不会算漏。

五、异或和为 k 的子数组

异或序列（P4462）：查询 [l, r] 上有多少子数组的异或和等于 k。

先做前缀异或 pre[i] = a[1] ^ ... ^ a[i]，pre[0] = 0。子数组 [i, j] 的异或和就是 pre[j] ^ pre[i−1]。于是问题变成：pre[l−1 .. r] 这一段里，有多少对下标异或起来等于 k。

窗口改成在 pre 上滑，查询 [l, r] 对应的窗口是 [l−1, r]。窗口里记 cnt[v] 和配对数 num。

加进一个值 x，能和它配对的是 x ^ k，所以 num 多了 cnt[x ^ k] 个。代码同样写成先减后加：减掉含 x 的那部分贡献，改 cnt[x]，再加回来。k 为 0 时配对的是它自己，贡献是 C(cnt[x], 2)。

    
void del(int x) {
        if (k != 0) {
            num -= cnt[x] * cnt[x ^ k];
        } else {
            num -= (cnt[x] * (cnt[x] - 1)) >> 1;
        }
        cnt[x]--;
        if (k != 0) {
            num += cnt[x] * cnt[x ^ k];
        } else {
            num += (cnt[x] * (cnt[x] - 1)) >> 1;
        }
    }

    void add(int x) {
        if (k != 0) {
            num -= cnt[x] * cnt[x ^ k];
        } else {
            num -= (cnt[x] * (cnt[x] - 1)) >> 1;
        }
        cnt[x]++;
        if (k != 0) {
            num += cnt[x] * cnt[x ^ k];
        } else {
            num += (cnt[x] * (cnt[x] - 1)) >> 1;
        }
    }

六、复杂度分析

五个题的排序、指针移动完全一致，差别只在 add / del 里做了几步，都是常数级。

操作时间复杂度
预处理：块号与排序O(m log m)
窗口移动一步（add / del）O(1)
左指针总移动O(m√n + n)
右指针总移动O(n√n)
m 次查询合计O((n + m)√n)

题 3 每次回答还要一次 gcd，O(log n)，可以忽略。题 5 的离散化是 O(n log n)。

空间上主要是计数数组和查询数组。计数数组大小跟着值域走：题 1 是 10⁶，题 5 是 2²⁰，其余是 O(n)。查询数组 O(m)，答案数组 O(m)，额外空间 O(V + m)。

七、最后

回看这五个题，共同点是答案只跟窗口有关，窗口动一步、答案跟着动一步。设计 add / del 时先想清楚「多一个元素会改变什么」，剩下的就是排序加滑动。
