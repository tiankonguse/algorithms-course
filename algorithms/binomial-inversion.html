二项式反演：四种形式，一套证明

「恰好有 k 个满足」和「钦定至少 k 个满足」之间可以精确换算，不需要一层一层做容斥。换算公式有四种长相，但共享同一条组合恒等式和同一个证明套路：代入定义、交换求和、套恒等式，内和坍缩成 Kronecker delta，剩下 f(n)=f(n)。

零、四种形式

给定函数 f 与 g，下面四对公式两两互逆。前两对里指标 i 从 0 到 n 求和，后两对里指标 i 从 n 到某个固定的 N 求和。

形式一和形式三正反两个方向都带 (−1)^i，形式二、形式四只有反方向带符号（形式四是 (−1)^(i−n)）。区别只在 C(n,i) 还是 C(i,n)：C(n,i) 是「从 n 个里挑 i 个」，C(i,n) 是「从 i 个里挑 n 个」。前者配合 i 从 0 到 n，后者配合 i 从 n 到 N。

用得最多的是形式二和形式四。形式二处理「钦定至少 i 个 → 恰好 i 个」里指标从小到大增长的那类（错排是典型）；形式四处理「钦定 i 个且这 i 个必须包含目标」的那类，见后面几页的四道练习，全标形式四。

一、组合分解恒等式

四套证明共用的桥是这个：

C(j,i)·C(i,n) = C(j,n)·C(j−n,j−i)

两边都展开成阶乘，约分后一模一样：

j! / (i!(j−i)!) · i! / (n!(i−n)!) = j! / (n!(j−n)!) · (j−n)! / ((j−i)!(i−n)!)

两边都等于 j! / (n!(i−n)!(j−i)!)。成立范围是 n ≤ i ≤ j，超出范围组合数是 0，等式两边同时是 0，照样成立。它把「两层挑人」合并成「先挑大集合，再在剩下的里挑」：先钦定 i 个再在其中钦定 n 个，等于先钦定 n 个、剩下 i−n 个从 j−n 个里补。

二、形式一的证明

要证 f(n) = Σ_{i=0..n} (−1)^i C(n,i)·g(i)，把 g 的定义代进去：

f(n) = Σi=0..n (−1)^i C(n,i) Σj=0..i (−1)^j C(i,j)·f(j)

交换求和顺序，内层指标改成 i 从 j 到 n：

f(n) = Σj=0..n f(j)·(−1)^j Σi=j..n (−1)^i C(n,i)·C(i,j)

对 C(n,i)·C(i,j) 套恒等式（j 的角色换过来）：

= Σj=0..n f(j)·(−1)^j C(n,j) Σi=j..n (−1)^i C(n−j, n−i)

换元 k = n−i，k 从 0 到 n−j：

内和 = Σk=0..n−j (−1)^(n−k) C(n−j, k) = (−1)^n · (1−1)^(n−j)

(1−1)^(n−j) 是 Kronecker delta：j=n 时等于 1，j<n 时等于 0。所以整个和式只剩 j=n 一项，f(j) 变成 f(n)，系数 (−1)^n·(−1)^n·C(n,n)=1。于是 f(n)=f(n)，反演成立。

三、形式二的证明

形式二 g(n)=Σ C(n,i)f(i)（正方向无符号）。同样代入、交换、套恒等式，内和是：

Σi=j..n C(n−j, n−i) = Σk=0..n−j C(n−j,k) = 2^(n−j)

不是 (1−1) 而是 (1+1)，这一下子炸出 2^(n−j)，可 delta 想要的是「j=n 才留」。反方向的符号 (−1)^(n−i) 这时候起作用：

f(n) = Σj f(j)·(−1)^(n−j) Σi=j..n (−1)^(n−i) C(n,i)·C(i,j)…

把 (−1)^(n−j) 留到最外层后，内层多出来的 (−1)^i 正好把它拉回 (1−1)^(n−j)：

Σi=j..n (−1)^(i−j) C(n−j, n−i) = Σk=0..n−j (−1)^k C(n−j,k) = (1−1)^(n−j)

delta 一坍缩，又是只剩 f(n) 一项。形式二反方向的符号写在 C(n,i) 外面、系数是 (−1)^(n−i)，这正是为了让内层凑成 (1−1) 的幂。

四、形式三与形式四的证明

形式三、四的求和范围是 i 从 n 到 N（N 固定）。以形式三为例，g(n)=Σi=n..N (−1)^i C(i,n)·f(i)，代入后交换求和，指标 j 从 n 到 N：

f(n) = Σj=n..N f(j)·(−1)^j Σi=n..j C(i,n)·C(j,i)

注意这里 C(i,n)·C(j,i) 正是恒等式的左边（两层挑人），套恒等式后：

= Σj=n..N f(j)·(−1)^j C(j,n) Σi=n..j (−1)^i C(j−n, j−i)

换元 k=j−i：内和 = Σk=0..j−n (−1)^(j−k) C(j−n,k) = (−1)^j (1−1)^(j−n)，又是 delta（j=n 留、j>n 消）。系数 (−1)^j·(−1)^j·C(n,n)=1，f(n)=f(n)。

形式四正方向无符号，反方向 (−1)^(i−n)，证明和内层凑法跟形式二一个道理：正方向的 (1+1) 被反方向的 (−1)^(i−n) 拉回 (1−1)^(j−n)。四套证明的骨架完全相同：代入 → 交换 → 恒等式 → (1−1) 的幂 → delta → 只剩目标项。

五、怎么选形式

做题时的场景几乎都是「钦定至少/指定 i 个 → 恰好 i 个」。先写出好算的 g(n)（钦定 n 个满足时直接计数），再反演出 f(n)（恰好 n 个满足）。形式四对应「钦定 n 个指定元素必须满足」：g(n)=Σi=n..N C(i,n)·f(i) 里的 C(i,n) 表示从恰好 i 个里钦定 n 个，这个 i 是「实际满足的数量」，所以求和从 n 到 N。形式二对应「从 n 个里钦定 i 个」：g(n)=Σi=0..n C(n,i)·f(i)，这里的 i 是「被钦定的数量」，n 是总数。

判断用哪个：问自己 g(n) 好不好算。好算的那个方向当 g，另一个方向当 f，再挑对应的形式反演。后四页每题都标了用的哪种形式。

演示 · 数值互推：按定义算 g，再按反演推回 f

总结

二项式反演四组公式共享一条恒等式 C(j,i)C(i,n)=C(j,n)C(j−n,j−i) 和一套证明：代入 g 的定义、交换求和、套恒等式、内和坍缩成 (1−1) 的幂也就是 Kronecker delta、只剩目标项。形式一、三正反都带 (−1)^i；形式二、四只有反方向带符号，所以它们最常用：反方向的符号正好把正方向的 (1+1) 拉回 (1−1)。用的时候先把「钦定 i 个满足」的好算计数写成 g，反演得到「恰好 i 个」的 f。后面四道练习分别演示形式二（错排）和形式四（集合计数、分特产、糖果配对、树上游戏）怎么落地。
