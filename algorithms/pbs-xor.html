范围最大异或和：下标分治与线性基

这一题的代码和整体二分几乎一样，时间复杂度也差不多，但它不是整体二分，没有任何单调性可以依赖。分治切的是下标，查询在跨过中点的那一层直接算出答案。

一、题目6：范围最大异或和

给定一个长度为 n 的数组 arr，下标 1 到 n，接下来有 q 条查询，格式如下。查询 l r：arr[l..r] 中选若干个数，打印最大的异或和。1 ≤ n、q ≤ 5 × 10⁵，0 ≤ arr[i] ≤ 10⁶。测试链接：CF1100F、CF1100F。

区间里选若干个数求最大异或和，标准的工具是线性基。单个区间是 O(区间长 × 位宽)，q 个区间直接做是 O(n·q) 级别，必须批量。

二、线性基的两件事

一组数的线性基是另一组数，它们能异或出来的集合和原来那组完全一样，而且个数不超过位宽。插入一个数时从高位往低位看：这一位是 1 就查基里这一位有没有数，没有就放进去，有就异或掉继续往下。

有了基，求最大异或和是贪心：从高位到低位，如果异或上基里这一位的数能让结果变大就异或。合并两组基也很直接：把第二组里的每个数逐个插进第一组的副本。

于是区间查询有了个朴素的做法：把 arr[l..r] 每个数插进一个空基，再贪心求最大值。要省的就是「每个数插一遍」这段。

三、按下标分治

整体二分能成立，是因为判定关于 mid 单调，于是「成立去左、不成立去右」。这题没有这样的判定：一个区间的最优值关于任何参数都不单调，左右两半不能靠判定来选。

这题分治切的是下标。当前节点的下标区间是 [vl, vr]，取 mid，先把 baset 数组填好：baset[mid] 只含 arr[mid]，从 mid 往左，baset[i] 是 baset[i + 1] 再插一个 arr[i]，从 mid 往右，baset[i] 是 baset[i − 1] 再插一个 arr[i]。于是 baset[i] 就是区间 [i, mid]（i 在左边时）或者 [mid, i]（i 在右边时）的线性基。

接下来看查询。区间 [l, r] 与 mid 只有三种位置关系：r 小于 mid，整个区间在左边，去左半；l 大于 mid，整个区间在右边，去右半；剩下的情况一定满足 l ≤ mid ≤ r，这时 baset[l] 是 [l, mid] 的基，baset[r] 是 [mid, r] 的基，两个一合并就是 [l, r] 的基，答案当场算出来，不再往下走。

这里有个细节：合并两个基的时候不能就地改 baset[l]，代码里用一个 tmp 数组做中转，否则下一次查询拿到的 baset 就被污染了。

void insert(int* basis, int num) {
        for (int i = BIT; i >= 0; i--) {
            if ((num >> i) & 1) {
                if (basis[i] == 0) {
                    basis[i] = num;
                    return;
                }
                num ^= basis[i];
            }
        }
    }

    void clear(int* basis) {
        for (int i = 0; i <= BIT; i++) {
            basis[i] = 0;
        }
    }

    int maxEor(int* basis) {
        int ret = 0;
        for (int i = BIT; i >= 0; i--) {
            ret = max(ret, ret ^ basis[i]);
        }
        return ret;
    }

    void clone(int* b1, int* b2) {
        for (int i = 0; i <= BIT; i++) {
            b1[i] = b2[i];
        }
    }

    void merge(int* b1, int* b2) {
        clone(tmp, b1);
        for (int i = 0; i <= BIT; i++) {
            insert(tmp, b2[i]);
        }
    }
void compute(int ql, int qr, int vl, int vr) {
        if (ql > qr) {
            return;
        }
        if (vl == vr) {
            for (int i = ql; i <= qr; i++) {
                ans[qid[i]] = arr[vl];
            }
        } else {
            int mid = (vl + vr) >> 1;
            clear(baset[mid]);
            insert(baset[mid], arr[mid]);
            for (int i = mid - 1; i >= vl; i--) {
                clone(baset[i], baset[i + 1]);
                insert(baset[i], arr[i]);
            }
            for (int i = mid + 1; i <= vr; i++) {
                clone(baset[i], baset[i - 1]);
                insert(baset[i], arr[i]);
            }
            int lsiz = 0, rsiz = 0;
            for (int i = ql, id; i <= qr; i++) {
                id = qid[i];
                if (r[id] < mid) {
                    lset[++lsiz] = id;
                } else if (l[id] > mid) {
                    rset[++rsiz] = id;
                } else {
                    merge(baset[l[id]], baset[r[id]]);
                    ans[id] = maxEor(tmp);
                }
            }
            for (int i = 1; i <= lsiz; i++) {
                qid[ql + i - 1] = lset[i];
            }
            for (int i = 1; i <= rsiz; i++) {
                qid[ql + lsiz + i - 1] = rset[i];
            }
            compute(ql, ql + lsiz - 1, vl, mid);
            compute(ql + lsiz, ql + lsiz + rsiz - 1, mid + 1, vr);
        }
    }

主函数只要读入和调用，baset 是全局数组，每层覆盖着用。

四、复杂度分析

位宽 B 取 21（arr[i] 不超过 10⁶）。每层填 baset 的代价是区间长度乘 B，各节点的区间互不重叠，一层加起来是 O(n·B)。每个查询只在被解决的那层做一次合并，代价 O(B²)，其余各层只做 O(1) 判断。

操作时间复杂度空间复杂度
插入一个数 / 求最大异或和O(B)O(n·B + q)：baset 是 n × (B + 1) 的 int，5 × 10⁵ × 22 × 4 字节约 44MB，查询的 l、r 与答案各 O(q)
合并两个基（B + 1 次插入）O(B²)
一层填 baset（区间长度之和为 n）O(n·B)
所有查询的合并（每个查询一次）O(q·B²)
整体（共 log n 层）O(n·B·log n + q·B²)

n、q 都是 5 × 10⁵ 时，两部分各在 2 × 10⁸ 量级。位宽只有 21，常数比一般的 O(log n) 结构小不少，可以通过。

五、为什么不是整体二分

整体二分的每一次划分都要回答「答案是不是不超过 mid」，靠的是答案关于 mid 的单调性。这一题从头到尾没有这个判断：查询去左还是去右，只取决于它和下标中点的位置关系，和答案大小无关。

两者共用的只有「把一批查询按分治树摊开」这个想法。看到形如 compute(ql, qr, vl, vr) 的代码，先找判定和单调性，找不着就说明它是另一种分治。

六、最后

这一节六道题走完，整体二分露了五次面，最后一次只是长得像。共同点是判定结构：混合果汁是线段树二分，带修改第 k 小和树上那两题是树状数组，最小瓶颈是可撤销并查集。判定能用 O(log n) 的结构维护下来，整体二分才划算。
