2-SAT 的巧妙建图

跑强连通分量这一步是死的，难的是把题目的条件翻译成子句。这一节三道题，条件一道比一道绕：一道要把三选一变回二选一，一道要在非降数组上表达「不小于」这种阈值，一道要在算出一组解之后再数新解的个数。骨架还是那三步，区别全在建图。

零、背景

2-SAT 的骨架上一节讲过：一个变量两个取值假设各占一个点，一对点恰好一个成立；一条子句 (a ∨ b) 拆成两条边 ¬a → b、¬b → a；跑一遍强连通分量，某个变量的两个假设落进同一个分量就无解，否则按分量编号取靠后的假设。细节在2-SAT那页。

这一节不重复骨架，只看三道题怎么落到它上面。它们的共同点是：题目给的「选择」一开始挨不上变量，得先想清楚变量取什么、两个假设各代表什么，图才建得出来。

一、题目1：宇航员

n 个人，三个任务 A、B、C。每个人都能做 C；给定年龄后算出平均年龄 f，年龄 ≥ f 的人能做 A，年龄 < f 的人能做 B。再给 m 对互相讨厌的人，他们不能做同一个任务。每人恰好做一个任务，求一种分配，做不到输出 No solution.

麻烦在于一个人有三个选项，而 2-SAT 的变量只有两个取值。硬把「A、B、C」塞进一个变量是行不通的。

换个角度：C 对所有人开放，另外那个任务由年龄唯一决定，年龄够大就是 A，不够就是 B。所以每个人真正的选择只有「做 C」和「不做 C」两种。不做 C 时，结果被年龄锁死。变量就取「是否做 C」。

接下来看一对讨厌的人 (x, y) 怎么拆。两人任务不同才算数，分两种情形。

两人的年龄段相同，比如都偏大。那么他们不做 C 时都做 A。要保证任务不同，既不能都做 C，也不能都做 A：这正好是两条子句 (x ∨ y) 与 (¬x ∨ ¬y)，合起来就是「恰好一人做 A、另一人做 C」。

两人的年龄段不同，一个偏大一个偏小。这时不做 C 的话，一个做 A 一个做 B，本来就不同，只需要堵掉「都做 C」，一条子句 (x ∨ y) 就够了，再加 (¬x ∨ ¬y) 反而是错的。

判定和取解照旧。取解时若变量为真（不做 C），按年龄段打印 A 或 B；否则打印 C。

还剩一个小细节：平均年龄 f 不必真的算出来。年龄 ≥ f 等价于 年龄 × n ≥ 年龄总和，用整数乘法判断就行，避开了浮点误差。

演示走一遍这四步建图。

四份讨厌关系，怎么逼出一份任务表

4 个人：1、4 年龄偏大（A 或 C），2、3 偏小（B 或 C）。点「下一步」，逐条加入讨厌关系，看子句怎么加、解怎么被逼出来。

年龄偏大（A / C） 年龄偏小（B / C） 刚加入的讨厌关系

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXM = 500001;
    int n, m;
    int age[MAXN];
    int sumAge;

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int belong[MAXN];
    int sccCnt;

    void prepare() {
        sumAge = cntg = cntd = sccCnt = 0;
        top = 0;
        for (int i = 1; i <= n << 1; i++) {
            head[i] = dfn[i] = low[i] = belong[i] = 0;
        }
    }

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    bool older(int x) {
        return age[x] * n >= sumAge;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        while (n != 0 && m != 0) {
            prepare();
            for (int i = 1; i <= n; i++) {
                cin >> age[i];
                sumAge += age[i];
            }
            for (int i = 1, x, y; i <= m; i++) {
                cin >> x >> y;
                addEdge(x + n, y);
                addEdge(y + n, x);
                if (older(x) == older(y)) {
                    addEdge(x, y + n);
                    addEdge(y, x + n);
                }
            }
            for (int i = 1; i <= n << 1; i++) {
                if (dfn[i] == 0) {
                    tarjan(i);
                }
            }
            bool check = true;
            for (int i = 1; i <= n; i++) {
                if (belong[i] == belong[i + n]) {
                    check = false;
                    break;
                }
            }
            if (check) {
                for (int i = 1; i <= n; i++) {
                    if (belong[i] < belong[i + n]) {
                        if (older(i)) {
                            cout << "A" << "\n";
                        } else {
                            cout << "B" << "\n";
                        }
                    } else {
                        cout << "C" << "\n";
                    }
                }
            } else {
                cout << "No solution." << "\n";
            }
            cin >> n >> m;
        }
        return 0;
    }

二、题目2：约束条件

构造一个长度为 n 的数组 arr，每个元素在 1 到 k 之间，并且整个数组非降。再给 m 条约束，格式有三种：arr[i] != x；arr[i] + arr[j] <= x；arr[i] + arr[j] >= x。求一个满足全部约束的数组，做不到输出 −1。

最容易踩的坑是变量怎么设。直觉上想给「arr[i] 等于 v」配一个变量，但那样一个位置就要 k 个变量、且要额外保证「恰好一个成立」，非常难受。

换一个说法。一个位置的值落到 1..k，等价于对每个阈值 v 回答一个问题：arr[i] 到底有没有到 v。于是给每个位置 i、每个阈值 v 记两个假设：id[i][v][0] 表示 arr[i] < v，id[i][v][1] 表示 arr[i] ≥ v。阈值 v 从 1 取到 k+1，多出来的 k+1 用来表示「恒假」。

两族假设靠单调链对齐。同一个位置上，arr[i] < v 一定推出 arr[i] < v+1，所以 id[i][v][0] → id[i][v+1][0]；反过来 arr[i] ≥ v+1 一定推出 arr[i] ≥ v，所以 id[i][v+1][1] → id[i][v][1]。

数组非降也靠同样两条边传递：arr[i+1] < v 推出 arr[i] < v，即 id[i+1][v][0] → id[i][v][0]；arr[i] ≥ v 推出 arr[i+1] ≥ v，即 id[i][v][1] → id[i+1][v][1]。

两端要钉死：arr[i] < 1 是不可能成立的，arr[i] ≥ k+1 也不可能成立。代码里用两条边把它们和旁边的阈值绑在一起，取值时两族假设才不会打架。

三类约束逐个翻译。

arr[i] != x：把值 x 从位置 i 的可取集合里挖掉。arr[i] ≥ x 一旦成立就必须能推到 arr[i] ≥ x+1，arr[i] < x+1 一旦成立就必须能推到 arr[i] < x。两条边过去，x 就被跳过了。

arr[i] + arr[j] <= x：枚举 arr[i] 的值 w。若 w ≥ x，那么 arr[j] 至少是 1，和必然超过 x，于是 i 根本不能取 w，直接挖掉。若 w < x，则是「arr[i] ≥ w ⇒ arr[j] ≤ x − w」，翻成阈值就是 arr[i] ≥ w 推出 arr[j] < x − w + 1，一条边。

把 i 和 j 换过来再跑一遍，两个方向的枚举都补齐。arr[i] + arr[j] >= x 对称处理：w 太小就把 arr[i] = w 挖掉，否则把「arr[i] ≤ w ⇒ arr[j] ≥ x − w」翻成边。

输出时从 k 往下扫，取最大的那个使 arr[i] ≥ v 成立的 v，就是 arr[i] 的值。

完整代码（多组数据，每组开始前要清空数组）：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 20001;
    const int MAXM = 2000001;
    const int MAXK = 12;
    const int MAXT = MAXN * MAXK * 2;
    int t, n, m, k;

    int id[MAXN][MAXK][2];
    int cntt;

    int head[MAXT];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    void prepare() {
        cntg = cntd = sccCnt = 0;
        for (int i = 1; i <= cntt; i++) {
            head[i] = dfn[i] = low[i] = belong[i] = 0;
        }
        cntt = 0;
        for (int i = 1; i <= n; i++) {
            for (int v = 1; v <= k + 1; v++) {
                id[i][v][0] = ++cntt;
                id[i][v][1] = ++cntt;
            }
        }
        for (int i = 1; i <= n; i++) {
            for (int v = 1; v <= k; v++) {
                addEdge(id[i][v][0], id[i][v + 1][0]);
                addEdge(id[i][v + 1][1], id[i][v][1]);
            }
        }
        for (int i = 1; i < n; i++) {
            for (int v = 1; v <= k; v++) {
                addEdge(id[i + 1][v][0], id[i][v][0]);
                addEdge(id[i][v][1], id[i + 1][v][1]);
            }
        }
        for (int i = 1; i <= n; i++) {
            addEdge(id[i][1][0], id[i][1][1]);
            addEdge(id[i][k + 1][1], id[i][k + 1][0]);
        }
    }

    void notEqual(int i, int x) {
        addEdge(id[i][x][1], id[i][x + 1][1]);
        addEdge(id[i][x + 1][0], id[i][x][0]);
    }

    void lessEqual(int i, int j, int x) {
        for (int w = 1; w <= k; w++) {
            if (w >= x) {
                notEqual(i, w);
            } else {
                if (x - w + 1 <= k) {
                    addEdge(id[i][w][1], id[j][x - w + 1][0]);
                    addEdge(id[j][x - w + 1][1], id[i][w][0]);
                }
            }
        }
    }

    void moreEqual(int i, int j, int x) {
        for (int w = 1; w <= k; w++) {
            if (w <= x - k - 1) {
                notEqual(i, w);
            } else {
                if (x - w > 1) {
                    addEdge(id[i][w + 1][0], id[j][x - w][1]);
                    addEdge(id[j][x - w][0], id[i][w + 1][1]);
                }
            }
        }
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> t;
        for (int c = 1; c <= t; c++) {
            cin >> n >> m >> k;
            prepare();
            for (int i = 1, op, x, y, v; i <= m; i++) {
                cin >> op;
                if (op == 1) {
                    cin >> x >> v;
                    notEqual(x, v);
                } else if (op == 2) {
                    cin >> x >> y >> v;
                    lessEqual(x, y, v);
                    swap(x, y);
                    lessEqual(x, y, v);
                } else {
                    cin >> x >> y >> v;
                    moreEqual(x, y, v);
                    swap(x, y);
                    moreEqual(x, y, v);
                }
            }
            for (int i = 1; i <= cntt; i++) {
                if (dfn[i] == 0) {
                    tarjan(i);
                }
            }
            bool check = true;
            for (int i = 1; i <= n; i++) {
                for (int v = 1; v <= k + 1; v++) {
                    if (belong[id[i][v][0]] == belong[id[i][v][1]]) {
                        check = false;
                        break;
                    }
                }
                if (!check) {
                    break;
                }
            }
            if (check) {
                for (int i = 1; i <= n; i++) {
                    for (int v = k; v >= 1; v--) {
                        if (belong[id[i][v][1]] < belong[id[i][v][0]]) {
                            cout << v << " ";
                            break;
                        }
                    }
                }
                cout << "\n";
            } else {
                cout << -1 << "\n";
            }
        }
        return 0;
    }

三、题目3：同谋者

n 个人要分成两队。交流队要求队内任意两人都认识，保密队要求队内任意两人都不认识，两队都不能为空。问一共有多少种分法，没有就输出 0。

和「认识」有关的条件天生就是二值的，建模很顺：变量 i 表示「第 i 个人在交流队」。两人认识时，他们不能都在保密队，于是至少一个在交流队，子句 (i ∨ j)；两人不认识时，他们不能都在交流队，子句 (¬i ∨ ¬j)。

跑一遍强连通分量，若某人的两个假设同分量就无解，直接输出 0。否则得到一组解：按分量编号把人分进两队。注意这组解里可能某个队是空的，那也不合法，先记下来。

真正的难点在于数方案。要求的是所有合法分法的个数，而 2-SAT 只给了一组。做法是：盯着这一组解，看它经过哪些「局部改动」还能保持合法，把这些改动都数出来。

先看两队之间的「矛盾点」。取交流队里的 a 和保密队里的 b，看看 a、b 之间是认识还是不认识。

若 a 与 b 认识：a 想搬去保密队就会在 b 这里翻车（保密队内部不能有认识关系），b 想搬来交流队也会在 a 这里翻车。记下 a 的这个唯一障碍 b：代码里用 other[a] 记 b，若 a 同时有第二个这样的 b，就把 other[a] 标成 −1，表示不唯一。

若 a 与 b 不认识：反过来，b 想搬来交流队就会在 a 这里翻车（b 与交流队里的 a 不认识），这个障碍记在 other[b] 上。

于是数组 other 把矛盾整理了出来：other[x] == 0 表示 x 和对面队里所有人都不冲突，other[x] == 某个对面的人表示只和这一个冲突，other[x] == −1 表示和对面多人冲突。

数方案时有三种来源。

第一种是原解本身，前提是两队都非空。

第二种是单点搬家：交流队里的 a，如果 other[a] == 0，说明 a 和保密队里所有人都不认识，搬过去不会破坏保密队；前提是搬走后交流队还非空。保密队里的 b 若 other[b] == 0，说明 b 和交流队里所有人都认识，可以搬去交流队；前提同样是保密队还剩人。每有一个这样的点，方案数加一。

第三种是成对交换：交流队的 a 和保密队的 b 认识，other[a] == b（a 的唯一障碍就是 b），而 other[b] == 0（b 搬去交流队毫无问题）。把 a、b 对调，两队仍然合法。还有一种对称情形：a 与 b 不认识，other[b] == a 说明 b 唯一的陌生对象就是 a，other[a] == 0 说明 a 与保密队无人认识，对调同样合法。每找到一对，方案数加一。

完整代码（用邻接矩阵记认识关系）：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 5001;
    const int MAXT = MAXN << 1;
    const int MAXM = MAXN * MAXN;
    int n, k, x;
    bool know[MAXN][MAXN];

    int head[MAXT];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int dfn[MAXT];
    int low[MAXT];
    int cntd;

    int sta[MAXT];
    int top;

    int belong[MAXT];
    int sccCnt;

    int team1[MAXN];
    int team2[MAXN];
    int cnt1, cnt2;

    int other[MAXN];

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else {
                if (belong[v] == 0) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
        }
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }

    int compute() {
        for (int i = 1; i <= n; i++) {
            if (belong[i] == belong[i + n]) {
                return 0;
            }
        }
        for (int i = 1; i <= n; i++) {
            if (belong[i] < belong[i + n]) {
                team1[++cnt1] = i;
            } else {
                team2[++cnt2] = i;
            }
        }
        int ans = cnt1 > 0 && cnt2 > 0 ? 1 : 0;
        for (int i = 1, a, b; i <= cnt1; i++) {
            a = team1[i];
            for (int j = 1; j <= cnt2; j++) {
                b = team2[j];
                if (know[a][b]) {
                    other[a] = other[a] == 0 ? b : -1;
                } else {
                    other[b] = other[b] == 0 ? a : -1;
                }
            }
        }
        if (cnt1 > 1) {
            for (int i = 1; i <= cnt1; i++) {
                if (other[team1[i]] == 0) {
                    ans++;
                }
            }
        }
        if (cnt2 > 1) {
            for (int i = 1; i <= cnt2; i++) {
                if (other[team2[i]] == 0) {
                    ans++;
                }
            }
        }
        for (int i = 1, a, b; i <= cnt1; i++) {
            a = team1[i];
            for (int j = 1; j <= cnt2; j++) {
                b = team2[j];
                if (know[a][b]) {
                    if (other[a] == b && other[b] == 0) {
                        ans++;
                    }
                } else {
                    if (other[b] == a && other[a] == 0) {
                        ans++;
                    }
                }
            }
        }
        return ans;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> k;
            for (int j = 1; j <= k; j++) {
                cin >> x;
                know[i][x] = true;
            }
        }
        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                if (know[i][j]) {
                    addEdge(i + n, j);
                    addEdge(j + n, i);
                } else {
                    addEdge(i, j + n);
                    addEdge(j, i + n);
                }
            }
        }
        for (int i = 1; i <= n << 1; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        int ans = compute();
        cout << ans << "\n";
        return 0;
    }

四、复杂度分析

三道题的骨架都要跑一遍 Tarjan 求强连通分量，区别在点数和边数怎么长出来。

题目点数 / 边数时间复杂度空间复杂度
宇航员2n 点，最多 4m 条边O(n + m)O(n + m)
约束条件2n(k+1) 点，O(nk + mk) 条边O(nk + mk)O(nk + mk)
同谋者2n 点，O(n²) 条边O(n²)O(n²)

宇航员题每对讨厌关系固定加两条边，同龄段再多加两条，所以总边数是 m 的常数倍，整体线性。空间里占大头的是邻接表 head、nxt、to 与 Tarjan 的 dfn、low、sta、belong。

约束条件题的规模由 k 决定。每个位置铺 2(k+1) 个阈值点，n 到 2 × 10⁴、k 到 10，点数在 5 × 10⁵ 量级。每条约束按一侧的取值枚举 k 次、再交换枚举一次，单条 O(k) 条边。代码里给边表开的空间是 O(n k + m k) 这个量级。

同谋者题要给每一对人建边，n(n−1)/2 对、每对两条边，边数 O(n²)。n 到 5000 时边数约 2.5 × 10⁷，时间和空间都按 n² 算。这是这三道题里最重的一道，瓶颈不在 Tarjan 而在建图本身。

取解的代价都可以忽略。宇航员和同谋者取解是 O(n)，约束条件是 O(nk)。

五、最后

三道题的骨架是同一套，值钱的地方都在变量怎么设、条件怎么写。

宇航员题教的是「选项个数和变量取值个数不匹配时，先找到那个公共选项」。C 对所有人开放，把它单拎出来当变量的一边，另一边由年龄补全。

约束条件题教的是「不要给具体的值设变量，要给阈值设变量」。值之间的关系（非降、不等于、和的大小）都能翻译成阈值之间的蕴含，正好是 2-SAT 擅长的形状。这也是那道经典前置题，要重点掌握。

同谋者题教的是「2-SAT 给一组解，剩下的靠分析补」。得到解之后别急着交，先想清楚哪些局部改动还能保持合法：能搬家的点、能对调的对，逐个计数。

三题的具体建边见2-SAT那页的基础，前缀那一套技巧在前缀优化建图里。
