圆方树原理与模版

图上问「必经点」，最顺手的答案藏在点双连通分量里。把原图的每个点变成圆点、每个点双变成方点，连起来是一棵树，这就是圆方树。从此「两点之间的必经点」变成「树上路径的圆点」，LCA 一跳就能回答。这一节先把建树和性质讲透，再用三道模版题把性质用熟。

零、背景

点双连通分量是「删掉任意一个点都不会散开」的极大子图。上一课用 Tarjan 求割点时，栈里已经装着每个点双的全部成员，只是算完割点就丢掉了。圆方树做的事情，是把这份现成的信息留下来：每弹出一个点双，就新建一个方点把它接住。

具体来说，原图的 n 个点照原样保留，叫圆点；每个点双连通分量建一个方点，方点向点双里的每个圆点连边。割点同时属于多个点双，所以会在树上出现多次邻居；非割点只属于一个点双，在树上只挂在一个方点下面。

这里采用广义的约定：两个点一条割边，也看成一个点双，照样建方点。于是圆方树上没有圆点和圆点相邻的边，任何一条树边都是一圆一方。仙人掌那一课为了给环摊边权，割边没有建方点；一般图的圆方树建方点更整齐，后面题目里「每条边恰好属于一个点双」这条性质会反复用到。

建好之后，一批性质直接从定义里掉出来。

节点数是 n 加点双个数。圆点编号保持 1 到 n，方点编号从 n+1 开始，一个计数器顺次分配。圆点的邻居都是它归属的点双，方点的邻居都是这个点双里的点。

圆点邻居只有一个，说明它只属于一个点双，不是割点；邻居多于一个，说明它是好几个点双的公共点，正是割点。割点 3、5、6 在树上都有两个方点邻居，叶子圆点 2、4、7、8 只有一个。

最有用的性质是：原图中 x 到 y 的必经点，恰好等于圆方树上 x 到 y 简单路径中的圆点。绕路只能发生在点双内部，而点双被压成了方点，路径只要经过方点就「免费」获得整个点双的绕行能力；反过来，路径上的圆点是躲不掉的。

点双内部还有一个性质后面要用：点双内任意三点 a、b、c，存在 a 到 b、再从 b 到 c 的路径，沿途节点不重复。圆方树上表现为：b 的某个邻方点落在 a 到 c 的路径上时，a、c 就是从这个点双的两个不同方向过来的。

一、建树

建树只需要在求割点的 Tarjan 上加四行。每个点进入 dfs 时压栈；孩子 v 回来后如果 low[v] >= dfn[u]，说明 v 及其栈上方的点构成一个点双：开新方点连上 u，然后把栈一路弹出、弹到的每个点都连上，直到弹出 v 为止。注意 u 是当前点，不从栈里弹。

割边的情形值得单独看一眼。v 的子树回不到 u 及以上，v 的子树里别的点双早已弹光，栈里 v 上方没有任何点。这时弹栈只弹出 v 一个，方点只连 u 和 v。割边两点一边，也是一个点双。

编号用一个计数器 cntn，初始化为 n，每建一个方点自增一次。判断一个点是不是圆点，只要看编号是否小于等于 n，后面的题全靠这个判断。

二、题目1：道路相遇

给定 n 个点 m 条边的无向连通图，q 次查询，每次给 x 和 y，问 x 到 y 不管怎么走都必须经过的点有几个，x 和 y 自己也算。n 到 5×10⁵，m 到 10⁶，q 到 5×10⁵。

建出圆方树，必经点就是 x 到 y 树路径上的圆点。圆点方点在路径上交替出现，两端都是圆点，所以路径长度一定是偶数，设为 d，圆点个数就是 d/2 + 1。x 等于 y 时 d 为 0，答案是 1，公式不用特判。

树上距离用倍增求 LCA：dep[x] + dep[y] - 2 * dep[lca]。整题的代码就是「建树 + 倍增 + 一行除法」。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 500001;
    const int MAXM = 1000001;
    const int MAXP = 20;
    int n, m, q, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;

    int sta[MAXN];
    int top;

    int dep[MAXN << 1];
    int stjump[MAXN << 1][MAXP];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs(int u, int fa) {
        dep[u] = dep[fa] + 1;
        stjump[u][0] = fa;
        for (int p = 1; p < MAXP; p++) {
            stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
        }
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != fa) {
                dfs(v, u);
            }
        }
    }

    int getLca(int x, int y) {
        if (dep[x] < dep[y]) {
            swap(x, y);
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (dep[stjump[x][p]] >= dep[y]) {
                x = stjump[x][p];
            }
        }
        if (x == y) {
            return x;
        }
        for (int p = MAXP - 1; p >= 0; p--) {
            if (stjump[x][p] != stjump[y][p]) {
                x = stjump[x][p];
                y = stjump[y][p];
            }
        }
        return stjump[x][0];
    }

    int getDist(int x, int y) {
        return dep[x] + dep[y] - 2 * dep[getLca(x, y)];
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        cntn = n;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1);
        dfs(1, 0);
        cin >> q;
        for (int i = 1, x, y; i <= q; i++) {
            cin >> x >> y;
            cout << (getDist(x, y) / 2 + 1) << "\n";
        }
        return 0;
    }

三、题目2：通讯网破坏

给定 n 个点 m 条边的无向连通图，q 次查询，每次给 x、y、z，问删掉点 z 之后 x 和 y 是否断连。n 到 2×10⁴，m 到 10⁵，q 到 10⁵。

删 z 会断开 x 和 y，当且仅当 z 是 x 到 y 的必经点，也就是 z 这个圆点落在 x 到 y 的树路径上。树上「v 在 x 到 y 的路径上」有一个不需要特判的等价说法：dist(x,y) == dist(x,z) + dist(z,y)。z 等于 x 或 y 时公式同样成立，点被删掉自然断连。

代码和题目1 只差查询那一行，建树和倍增原封不动。

四、题目3：路径问题

给定 n 个点 m 条边的无向连通图，无重边自环，给三个不同的点 a、b、c，问是否存在一条路径从 a 到 b、再从 b 到 c，全程节点不重复。n、m 到 2×10⁵。

a 到 b 的路径和 b 到 c 的路径不能共用节点，直观上就是 a 和 c 要从 b 的「两个不同方向」过来。在圆方树上这句话有精确的表述：b 的邻居全是方点，每个邻方点代表 b 参与的一个点双；存在合法路径，当且仅当 b 的某个邻方点落在 a 到 c 的树路径上。

为什么？邻方点 f 在 a 到 c 的路径上，说明 a 和 c 分别挂在 f 的两个不同子方向上。从 a 走到 f 对应的入口圆点，在点双内绕到 b，再从 b 绕到 c 的入口圆点出发，三段拼起来节点不重复，这正是点双内「任意三点存在 a 到 b 再到 c 的不重复路径」的性质。反过来，a、c 若在同一个方向，任何 a 到 c 的路径都碰不到 b 的邻方点，经过 b 的两条路径必然共用节点。

判定过程很轻：把 b 在树上的所有邻居（全是方点）打上标记，然后让 a 和 c 里深的那个不断往父节点跳，跳一步查一次标记，两个点相遇为止。相遇点也就是 LCA，会被最后一步跳到，同样查过标记。整个过程是线性的。

完整代码：

#include <bits/stdc++.h>

    using namespace std;

    const int MAXN = 200001;
    const int MAXM = 200001;
    int n, m, a, b, c, cntn;

    int head1[MAXN];
    int next1[MAXM << 1];
    int to1[MAXM << 1];
    int cnt1;

    int head2[MAXN << 1];
    int next2[MAXM << 2];
    int to2[MAXM << 2];
    int cnt2;

    int dfn[MAXN];
    int low[MAXN];
    int cntd;
    int sta[MAXN];
    int top;

    int dep[MAXN << 1];
    int fa[MAXN << 1];
    bool flag[MAXN << 1];

    void addEdge1(int u, int v) {
        next1[++cnt1] = head1[u];
        to1[cnt1] = v;
        head1[u] = cnt1;
    }

    void addEdge2(int u, int v) {
        next2[++cnt2] = head2[u];
        to2[cnt2] = v;
        head2[u] = cnt2;
    }

    void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        for (int e = head1[u]; e > 0; e = next1[e]) {
            int v = to1[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    cntn++;
                    addEdge2(cntn, u);
                    addEdge2(u, cntn);
                    int pop;
                    do {
                        pop = sta[top--];
                        addEdge2(cntn, pop);
                        addEdge2(pop, cntn);
                    } while (pop != v);
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }

    void dfs(int u, int f) {
        dep[u] = dep[f] + 1;
        fa[u] = f;
        for (int e = head2[u]; e > 0; e = next2[e]) {
            int v = to2[e];
            if (v != f) {
                dfs(v, u);
            }
        }
    }

    bool check() {
        for (int e = head2[b]; e > 0; e = next2[e]) {
            int v = to2[e];
            flag[v] = true;
        }
        while (a != c) {
            if (dep[a] < dep[c]) {
                swap(a, c);
            }
            a = fa[a];
            if (flag[a]) {
                return true;
            }
        }
        return false;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m >> a >> b >> c;
        cntn = n;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            addEdge1(u, v);
            addEdge1(v, u);
        }
        tarjan(1);
        dfs(1, 0);
        cout << (check() ? "Yes" : "No") << "\n";
        return 0;
    }

五、复杂度分析

三道题共用一份「建树 + 倍增」的前缀，瓶颈都在预处理；题目3 连倍增都不需要。

操作时间复杂度空间复杂度
建圆方树O(n + m)O(n + m)
倍增表（题目1、2）O((n + m) log n)O((n + m) log n)
题目1、2 一次查询O(log n)圆方树点数不超过 2n + m 级，数组按 MAXN << 1 开
题目3 整个判定O(n + m)（单次询问）

方点个数等于点双个数，一个点双至少含两个原图点、每个点至多属于若干点双，总量由 m 线性约束，建树是严格线性的。倍增表按圆方树总点数开 MAXP 层，题目1 的 n 与 m 都到 10⁶ 级，表是空间大头，查询侧每次只要跳 log 层。

六、最后

这一页只用了圆方树的一条性质：必经点等于树路径上的圆点。题目1 数圆点，题目2 判圆点在不在路径上，题目3 把「b 的两侧」翻译成 b 的邻方点。建树成本一遍 Tarjan，之后每次询问一个 LCA。

圆方树真正的大力气花在后面：把整棵树当成树来做 DP、做差分、上树链剖分和线段树。下一页先看两道计数题和一道边权统计。
