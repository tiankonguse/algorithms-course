整树信息与颜色段拼接

前两节里，每一段查出来的东西（和、最大值）直接累加就是答案。这一节两个题不是这样：一个要的是整棵线段树的信息在操作前后的变化量，一个查出来的段数在拼接时还要再修正一次。

零、背景

把「处理一段」换成「对一段做覆盖」，能做的事已经不少。但要回答的问题一旦从「这段的统计值」变成「全局状态变了多少」或者「这条路径长什么样」，光有区间和就不够了。

区别只有两处：线段树节点上存什么，以及多段结果怎么合并。剖分那部分一个字都不用改。

一、题目4：软件包管理器

洛谷 P2146。n 个软件编号 0 到 n−1，0 号不依赖任何软件，其余每个软件恰好依赖一个，依赖不成环。一开始都没安装。install x：如果 x 装了打印 0，否则把 x 的所有依赖装上（含 x 自己），打印状态改变的软件数。uninstall x：如果 x 没装打印 0，否则把依赖 x 的全卸掉（含 x 自己），打印状态改变数。n、m 不超过 10⁶。

依赖关系本身就是一棵树，0 号是根。把「a 依赖 b」记成 b 是 a 的父亲，两句话就翻译完了：

install x 是把根到 x 的路径全部置 1；uninstall x 是把 x 的子树全部置 0。

关键是「状态改变了几个」怎么算。逐个点去数会很麻烦，但整棵树的已安装数就在线段树根节点上。操作前后各读一次 sum[1]，差的绝对值就是答案。

所以线段树只要支持区间覆盖（置 0 或置 1）和区间求和。覆盖标记是「整段重写」而不是「整段加」，下发时直接覆盖儿子的值与标记。

这里有个细节：题目编号从 0 开始，代码统一转成 1 起，输入的依赖关系也一起 +1。install 只会让 sum 变大、uninstall 只会让它变小，取绝对值只是图省事。

void pathUpdate(int x, int v) {
        int y = 1;
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                updateRange(dfn[top[y]], dfn[y], v, 1, n, 1);
                y = fa[top[y]];
            } else {
                updateRange(dfn[top[x]], dfn[x], v, 1, n, 1);
                x = fa[top[x]];
            }
        }
        updateRange(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]), v, 1, n, 1);
    }

    int install(int x) {
        int pre = sum[1];
        pathUpdate(x, 1);
        int post = sum[1];
        return abs(post - pre);
    }

    int uninstall(int x) {
        int pre = sum[1];
        updateRange(dfn[x], dfn[x] + siz[x] - 1, 0, 1, n, 1);
        int post = sum[1];
        return abs(post - pre);
    }

二、题目5：染色

洛谷 P2486。n 个节点的树，每个点有初始颜色。连续相同颜色算一段。C x y z 把路径 x 到 y 全部染成 z，Q x y 打印路径上有几个颜色段。n、m 不超过 10⁵。

「段数」这个量不能只看两段的和，还要看交界处。所以线段树每个节点存三样：lcolor（区间最左端的颜色）、rcolor（最右端的颜色）、sum（区间内段数）。

合并两个儿子时，左右各自内部的段数先加起来；如果左儿子的右端颜色和右儿子的左端颜色相同，这两段是连在一起的，要减掉 1。

区间染色是覆盖标记：整段染成 z 之后，lcolor 和 rcolor 都变成 z，段数变成 1。

路径查询跨多条重链时，段与段的交界处也要做同样的判断。代码里的做法是：每取完一段，记下这段链头的颜色 sonc，再取链头父亲的颜色 fac；下一段正是从这个父亲开始的，两者相同就说明接缝处同色，答案减 1。

合并两个儿子与取单点颜色：

void up(int i) {
        sum[i] = sum[i << 1] + sum[i << 1 | 1];
        if (rcolor[i << 1] == lcolor[i << 1 | 1]) {
        	sum[i]--;
        }
        lcolor[i] = lcolor[i << 1];
        rcolor[i] = rcolor[i << 1 | 1];
    }

路径查询里的接缝判断：

int pointColor(int jobi, int l, int r, int i) {
        if (l == r) {
            return lcolor[i];
        }
        down(i);
        int mid = (l + r) / 2;
        if (jobi <= mid) {
            return pointColor(jobi, l, mid, i << 1);
        } else {
            return pointColor(jobi, mid + 1, r, i << 1 | 1);
        }
    }

    void pathUpdate(int x, int y, int v) {
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                update(dfn[top[y]], dfn[y], v, 1, n, 1);
                y = fa[top[y]];
            } else {
                update(dfn[top[x]], dfn[x], v, 1, n, 1);
                x = fa[top[x]];
            }
        }
        update(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]), v, 1, n, 1);
    }

    int pathColors(int x, int y) {
        int ans = 0, sonc, fac;
        while (top[x] != top[y]) {
            if (dep[top[x]] <= dep[top[y]]) {
                ans += query(dfn[top[y]], dfn[y], 1, n, 1);
                sonc = pointColor(dfn[top[y]], 1, n, 1);
                fac = pointColor(dfn[fa[top[y]]], 1, n, 1);
                y = fa[top[y]];
            } else {
                ans += query(dfn[top[x]], dfn[x], 1, n, 1);
                sonc = pointColor(dfn[top[x]], 1, n, 1);
                fac = pointColor(dfn[fa[top[x]]], 1, n, 1);
                x = fa[top[x]];
            }
            if (sonc == fac) {
                ans--;
            }
        }
        ans += query(min(dfn[x], dfn[y]), max(dfn[x], dfn[y]), 1, n, 1);
        return ans;
    }

复杂度分析

两题的剖分部分完全一样，代价都花在线段树的段数与单点查询上。

操作时间说明
dfs1 + dfs2O(n)与前面几节完全相同
installO(log² n)根到 x 的路径覆盖，不超过 2 log₂ n + 1 段
uninstallO(log n)一次子树区间覆盖
路径染色O(log² n)区间覆盖，标记是重写不是累加
路径段数查询O(log² n)每段一次区间查询，另加每处接缝一次单点查询
空间O(n)剖分 7n；线段树存 sum 与两个颜色，再加标记，约 5 × 4n

P2146 的 n 到 10⁶，重链剖分加线段树仍然够用：单次操作几十次递归，一百万次操作在常数小的写法下能过。

最后

这两题的线段树节点都存了「形状」：一边是整棵树的总和，一边是区间两端的颜色。下一节的两个题把这件事再推一步，一个要同时维护正着走和反着走两种利润，一个是树的根会变。
