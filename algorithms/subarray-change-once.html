翻转一次与删掉一个：改动之后的最大累加和

两道题都是「先把数组动一下，再问最大累加和」。翻转一段看着要把 n² 种翻法都试一遍，删掉一个数字看着要把 n 个删法配 n 个窗口。两个都有 O(n) 的做法：前者靠一次翻转只改变相邻关系这个事实，后者靠把「删一个」翻译成「窗口里去掉最小值」。

零、翻转一段：只用关心谁和谁挨上了

给定数组，随意选一段翻转（逆序），翻转完之后整个数组的最大子数组累加和是多少。翻转可以让本来隔着一段的两个数贴到一起。

设翻转段是 [l..r]，翻转之后新数组长成「前缀 + 反过来的中段 + 后缀」。反过来的中段的最后一个数是原来的 a[l]，紧跟着它的是原来的 a[r+1]。所以一段跨过翻转边界的子数组，形如「中段里挑 a[l..t] 这一段」加上「从 r+1 开始的一段」。和跟顺序无关，两段各自取最大就行：

候选 = (0..r 范围内的最大子数组) + (从 r + 1 开始的最大子数组)

枚举 r 从 0 到 n − 2，取最大。前一半是扫描过程中「到目前为止所有以某处结尾的子数组的最大值」，记成 maxEnd；后一半要预先从右往左算好，记成 start[i]。

#include <bits/stdc++.h>
    using namespace std;

    // 可以翻转 1 次的情况下子数组最大累加和
    // 随意选一段翻转（逆序），翻转之后整个数组的子数组最大累加和最大是多少
    long long maxSumReverse(const vector<int>& nums) {
        int n = (int)nums.size();
        // start[i] : 所有必须以 i 开头的子数组里，最大累加和
        vector<long long> start(n, 0);
        start[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            start[i] = max((long long)nums[i], (long long)nums[i] + start[i + 1]);
        }
        // 翻转段是 [l..r]，翻转之后紧跟在它后面的是原来 r+1 位置开始的数
        // 所以答案 = (0..r 里的最大子数组) + (从 r+1 开始的最大子数组)
        long long ans = start[0];
        long long end = nums[0];      // 必须以 i 结尾的子数组的最大累加和
        long long maxEnd = nums[0];   // 0..i-1 里所有「以某处结尾」的最大累加和
        for (int i = 1; i < n; i++) {
            // 枚举翻转段的右端点 r = i - 1
            ans = max(ans, maxEnd + start[i]);
            end = max((long long)nums[i], end + nums[i]);
            maxEnd = max(maxEnd, end);
        }
        // 一次都不翻转（或者翻转之后最优子数组没跨过翻转段）
        ans = max(ans, maxEnd);
        return ans;
    }

start 数组从右往左填：start[i] = max(nums[i], nums[i] + start[i + 1])，和最大子段和的递推是同一个式子，只是方向反过来。从左往右这遍同时维护两个量：end 是「必须以 i 结尾」的最大累加和，maxEnd 是「0..i 里出现过的最大的 end」。

演示：start 预处理与从左往右的一次扫描

两个高频笔误，随机对拍 2 万组（长度 1~9，值域 ±15）：循环结束后忘了再取一次 max(ans, maxEnd)，错 12.8%，因为最优解可能压根没跨过翻转边界；把 maxEnd 写成当前 end（只记「必须以 i 结尾」而不记历史最大），错 50.7%。

暴力参考是枚举全部 n (n + 1) / 2 种翻转再各跑一次最大子段和，n = 200 时 3.74 毫秒、n = 400 时 29.37 毫秒；正式方法 n = 100 万 3.17 毫秒。

一、删掉一个数字：k + 1 的窗口里去掉最小值

给定数组和 k，必须删掉一个数字，问删完之后新数组里长度 k 的子数组最大累加和是多少。

删掉一个再取 k 个，等价于：在原数组里找一段连续的长度 k + 1 的窗口，从里面去掉一个最小的数。反过来也成立，删掉下标 d 之后取到的那 k 个数，一定是某个长度 k + 1 的窗口去掉 d 得到的。

于是问题变成：枚举每个长度 k + 1 的窗口，算「窗口和 − 窗口最小值」，取最大。窗口和是滑动窗口一次加法一次减法；窗口最小值用单调队列，队列里存下标、对应的值单调递增，队头就是当前窗口的最小值。

#include <bits/stdc++.h>
    using namespace std;

    // 删掉 1 个数字后长度为 k 的子数组最大累加和
    // 删哪个数字随意，删完之后在新数组里找长度 k 的最大子数组累加和
    long long maxSumDeleteOne(const vector<int>& nums, int k) {
        int n = (int)nums.size();
        if (n <= k) {
            return 0;
        }
        // 删 1 个再取 k 个 == 在长度为 k+1 的窗口里去掉一个最小值
        // 窗口最小值用单调队列维护，队列里存下标，值单调递增
        vector<int> window(n, 0);
        int l = 0, r = 0;
        long long sum = 0;
        long long ans = LLONG_MIN;
        for (int i = 0; i < n; i++) {
            while (l < r && nums[window[r - 1]] >= nums[i]) {
                r--;
            }
            window[r++] = i;
            sum += nums[i];
            if (i >= k) {
                // 窗口 nums[i-k .. i] 一共 k+1 个数
                ans = max(ans, sum - nums[window[l]]);
                if (window[l] == i - k) {
                    l++;
                }
                sum -= nums[i - k];
            }
        }
        return ans;
    }

队列里存下标而不是值，是因为过期判定要比较位置：窗口左端划过 i − k 时，只有队头下标正好等于 i − k 才弹出。存值的话无从判断这个值还在不在窗口里。

演示：单调队列的入队、过期与候选值

三个版本的差异在 [1, 2, 3, 4, 5]、k = 3 上就能看清：正确答案是 12（删掉 1，取 2 + 3 + 4 + 5 里的 2 + 3 + 4 + 5 中连续三个，最大 3 + 4 + 5 = 12）；不判过期的版本会把全局最小的 1 一直留在队头，第二个窗口 2 + 3 + 4 + 5 = 14 减去 1 得 13，比正确答案大。

随机对拍 2 万组（长度 2~20，值域 ±30，k 随机）：窗口大小写成 k（等价于只取 k − 1 个数）错 98.0%，队列存值不判过期错 38.0%。前者基本一跑就炸，后者要等窗口滑过最小值才现形。

性能上单调队列赢在窗口变宽的时候。n = 10 万：k = 100 时单调队列 1.28 毫秒、每个窗口重扫一遍求最小值 1.14 毫秒，两者持平；k = 1000 时单调队列 1.13 毫秒、重扫 7.24 毫秒，差 6.4 倍。

二、复杂度分析

问题时间额外空间
翻转一次后的最大子数组O(n)O(n)（start 数组）
删掉一个后长度 k 的最大子数组O(n)O(n)（队列数组，可写成 O(k) 的环）

空间说明：翻转那题要 start[i] 供扫描时随机访问，O(n) 省不掉（除非允许从右往左再扫一遍做双指针，那样代码会长一截）。删数字那题的队列这里开成 n 长的数组，实际同时最多 k + 1 个元素，竞赛里常写成静态数组或环形队列。实测：翻转 n = 100 万 3.17 毫秒，暴力 O(n³) 在 n = 200 时 3.74 毫秒、n = 400 时 29.37 毫秒；删数字单调队列 n = 100 万、k = 1000 时 6.56 毫秒，暴力枚举删哪个再枚举窗口在 n = 400 时 0.91 毫秒、n = 800 时 5.90 毫秒。

三、总结

两题的关键都是先做翻译再动手：翻转一段只改变相邻关系，所以枚举右端点 r，答案就是「左边最大子数组 + 从 r + 1 开始的最大子数组」；删掉一个数字等价于在长度 k + 1 的窗口里去掉最小值，窗口最小值交给单调队列。

单调队列那题还有个值得记的点：队列里存的一定是下标。最小值本身谁都能算，难的是知道它什么时候离开窗口，而这件事只有下标能回答。
