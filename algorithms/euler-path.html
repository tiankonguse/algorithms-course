欧拉路径的判定与 Hierholzer 算法

一笔画问题：每条边都经过一次、且只经过一次。起点终点重合叫欧拉回路，不重合叫欧拉路径。判定靠度数，构造靠 Hierholzer 算法。这一讲一共十一道题，先分四类：判定与模版、首尾相接、构造序列、难题分析。这一页把判定条件和 Hierholzer 模版讲透，后面三页看题目。

零、背景

欧拉路径是图论里最古老的问题之一，原型是柯尼斯堡七桥：能不能每座桥恰好走一次地逛完再回家。欧拉证明了不可能，判据就是现在用的这套度数条件。

整讲只依赖两件前置：链式前向星建图，以及基础的图概念。所有题目都会归结到同一个模版上，所以先把模版钉死。

先把记号说清楚。忽略入度和出度都是 0 的点，这句话在所有判定里都出现：孤立点对一笔画没有影响，度数为 0 的点怎么走都碰不到它，也不需要碰到它。

一、判定条件

有向图存在欧拉回路，要同时满足两条。第一，忽略入度和出度都是 0 的点后，剩下每个点入度等于出度。第二，剩下的图强连通，任意两点可以互相到达。

有向图存在欧拉路径的条件只改一处：除了起点和终点，其余点入度等于出度；起点的出度比入度大 1，终点的入度比出度大 1。起点的起点连一条终点向起点的有向边，就变回欧拉回路的判定，这是两个条件之间的桥梁。

无向图的版本更短。忽略度为 0 的点后剩下的图连通；再统计度为奇数的点的个数 odd。odd 为 0 存在欧拉回路，odd 为 2 存在欧拉路径，其余情况两者都不存在。

二、构造性的证明

判定过了，怎么把路径构造出来？证明本身就是算法。从任意点 s 出发，遇到出边就选一条继续走，最终走不动时一定回到 s，走过的边形成一条回路，叫主线。

如果有边没被走到，剩余的边和主线在同一个强连通块里，所以主线上一定存在某点 x，能碰到剩余的边。从 x 出发同样地走，又能得到一条回到 x 的回路，叫支线。

把支线在 x 处拼进主线，还是一个欧拉回路。主线不停地吸收支线，直到所有边走完，这就是 Hierholzer 算法的全过程。

三、Hierholzer 算法

算法只需要一个函数。当前点 u，看它还有没有剩余的出边，有就删掉一条、走进去；没有就把 u 追加到 path 数组末尾。全部结束后 path 倒序输出就是欧拉路径。

这里有个细节叫当前弧优化：每个点记一个 cur[u]，指向还没走过的第一条出边。递归回到 u 时不用重扫已经删掉的边，每条边整个过程中只被删一次。

为什么倒序输出？递归是先进后出的：主线先在外面，后走完的支线先入栈。最先压进 path 的点是整条路走不动时最深的点，它恰好是路径的终点，所以要把 path 整个反过来。

连通性不需要并查集。判定分两步：能不能按度数找到起点，以及生成完之后 cntp 是不是等于 m+1。路径数组长度是边数加一，少了就说明有边没走到，图不连通。

字典序最小的要求出现在很多题里。做法是给每个点的出边排好序。链式前向星是头插法，同一组边按从小到大的顺序插入后，链表里是逆序；所以排序后从大到小插入，链表里就是从小到大，走出来的就是字典序最小的路径。

无向图要多一个标记。一条无向边存成两条有向边，走过去还要防止立刻走回来。给每条无向边编号，用 vis[eid] 记录这条边是否用过，没用过才递归。

四、题目1：有向图的欧拉路径

图上有 n 个点、m 条有向边。如果存在欧拉路径，输出字典序最小的结果；如果不存在，打印 No。n 到 10⁵，m 到 2×10⁵。测试链接：Luogu P7771。

把上面整套东西合在一起：按 (u, v) 排序、从大到小插入建图、按度数找起点、Hierholzer 生成、检查 cntp。四条边 1→2、1→3、2→3、3→1 的答案是 1 2 3 1 3，代码实测一致。

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int u, v;
    };

    bool EdgeCmp(Edge e1, Edge e2) {
        if (e1.u != e2.u) {
            return e1.u < e2.u;
        }
        return e1.v < e2.v;
    }

    const int MAXN = 100001;
    const int MAXM = 200002;
    int n, m;
    Edge edgeArr[MAXM];

    int head[MAXN];
    int nxt[MAXM];
    int to[MAXM];
    int cntg;

    int cur[MAXN];
    int outDeg[MAXN];
    int inDeg[MAXN];

    int path[MAXM];
    int cntp;

    void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }

    void connect() {
        sort(edgeArr + 1, edgeArr + m + 1, EdgeCmp);
        for (int l = 1, r = 1; l <= m; l = ++r) {
            while (r + 1 <= m && edgeArr[l].u == edgeArr[r + 1].u) {
                r++;
            }
            for (int i = r, u, v; i >= l; i--) {
                u = edgeArr[i].u;
                v = edgeArr[i].v;
                outDeg[u]++;
                inDeg[v]++;
                addEdge(u, v);
            }
        }
        for (int i = 1; i <= n; i++) {
            cur[i] = head[i];
        }
    }

    int directedStart() {
        int start = -1, end = -1;
        for (int i = 1; i <= n; i++) {
            int v = outDeg[i] - inDeg[i];
            if (v < -1 || v > 1 || (v == 1 && start != -1) || (v == -1 && end != -1)) {
                return -1;
            }
            if (v == 1) {
                start = i;
            }
            if (v == -1) {
                end = i;
            }
        }
        if ((start == -1) ^ (end == -1)) {
            return -1;
        }
        if (start != -1) {
            return start;
        }
        for (int i = 1; i <= n; i++) {
            if (outDeg[i] > 0) {
                return i;
            }
        }
        return -1;
    }

    void euler(int u) {
        for (int e = cur[u]; e > 0; e = cur[u]) {
            cur[u] = nxt[e];
            euler(to[e]);
        }
        path[++cntp] = u;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> n >> m;
        for (int i = 1; i <= m; i++) {
            cin >> edgeArr[i].u >> edgeArr[i].v;
        }
        connect();
        int start = directedStart();
        if (start == -1) {
            cout << "No\n";
        } else {
            euler(start);
            if (cntp != m + 1) {
                cout << "No\n";
            } else {
                for (int i = cntp; i >= 1; i--) {
                    cout << path[i] << " ";
                }
                cout << "\n";
            }
        }
        return 0;
    }

五、题目2：无向图的欧拉路径

给定 m 条无向边。如果存在欧拉路径，输出字典序最小的结果，不存在打印 No。点编号范围 1 到 500，不是所有点都出现，以边为准，m 到 1024。测试链接：Luogu P2731。

规模小，直接开邻接矩阵也可以，不过这里仍然用链式前向星练模版。每条无向边加入两条有向边并带上编号 eid，遍历时跳过已经用过的无向边。四条边 1-2、2-3、3-1、1-4 的答案是 1 2 3 1 4，奇度点 1 和 4 正好是两端。

#include <bits/stdc++.h>

    using namespace std;

    struct Edge {
        int u, v, id;
    };

    bool EdgeCmp(Edge e1, Edge e2) {
        if (e1.u != e2.u) {
            return e1.u < e2.u;
        }
        return e1.v < e2.v;
    }

    const int MAXN = 501;
    const int MAXM = 2001;
    int n = 500, m, k;
    Edge edgeArr[MAXM << 1];

    int head[MAXN];
    int nxt[MAXM << 1];
    int to[MAXM << 1];
    int eid[MAXM << 1];
    int cntg;

    int cur[MAXN];
    int deg[MAXN];
    bool vis[MAXM];

    int path[MAXM];
    int cntp;

    void addEdge(int u, int v, int id) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        eid[cntg] = id;
        head[u] = cntg;
    }

    void connect() {
        sort(edgeArr + 1, edgeArr + k + 1, EdgeCmp);
        for (int l = 1, r = 1; l <= k; l = ++r) {
            while (r + 1 <= k && edgeArr[l].u == edgeArr[r + 1].u) {
                r++;
            }
            for (int i = r; i >= l; i--) {
                deg[edgeArr[i].u]++;
                addEdge(edgeArr[i].u, edgeArr[i].v, edgeArr[i].id);
            }
        }
        for (int i = 1; i <= n; i++) {
            cur[i] = head[i];
        }
    }

    int undirectedStart() {
        int odd = 0;
        for (int i = 1; i <= n; i++) {
            if ((deg[i] & 1) == 1) {
                odd++;
            }
        }
        if (odd != 0 && odd != 2) {
            return -1;
        }
        for (int i = 1; i <= n; i++) {
            if (odd == 0 && deg[i] > 0) {
                return i;
            }
            if (odd == 2 && (deg[i] & 1) == 1) {
                return i;
            }
        }
        return -1;
    }

    void euler(int u) {
        for (int e = cur[u]; e > 0; e = cur[u]) {
            cur[u] = nxt[e];
            if (!vis[eid[e]]) {
                vis[eid[e]] = true;
                euler(to[e]);
            }
        }
        path[++cntp] = u;
    }

    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        cin >> m;
        k = 0;
        for (int i = 1, u, v; i <= m; i++) {
            cin >> u >> v;
            edgeArr[++k] = { u, v, i };
            edgeArr[++k] = { v, u, i };
        }
        connect();
        int start = undirectedStart();
        if (start == -1) {
            cout << "No\n";
        } else {
            euler(start);
            if (cntp != m + 1) {
                cout << "No\n";
            } else {
                for (int i = cntp; i >= 1; i--) {
                    cout << path[i] << "\n";
                }
            }
        }
        return 0;
    }

六、复杂度分析

排序是主要开销，其余都是每条边扫常数次的线性过程。

操作时间复杂度空间复杂度
按度数找起点（扫全部点）O(n)O(n + m)（前向星、度数、path 数组）
排序与建图（含头插）O(m log m)
Hierholzer 生成路径（当前弧优化）O(n + m)
连通性检查（cntp 与 m+1 比较）O(1)

不要求字典序时可以省掉排序，整题线性。递归深度最坏 O(m)，m 到 2×10⁵ 时栈是安全的；到 10⁶ 级别就要写迭代版，第七题会碰到。

七、最后

判定看度数，构造看递归：出边走光才压栈，压完倒过来输出。当前弧让每条边只删一次，字典序靠排序加头插，连通性交给路径长度。
