分块算法

把一个大数组切成若干小块，用“整块打包、零散逐个”的方式加速区间查询与修改。

一、从一个问题说起

有一个长度为 n 的数组 a，需要反复处理两种操作：

  • 查询：给出区间 [l, r]，求 a[l] + a[l+1] + … + a[r]。
  • 修改：把某个位置 a[i] 的值改成一个新数。

两种操作交替出现，一共要进行 n 次。我们关心的是这 n 次操作的总耗时，问怎么处理才快？

二、先试试最朴素的做法

查询时，从 l 一路加到 r：

int query(int l, int r) {
    int ans = 0;
    for (int i = l; i <= r; i++)
        ans += a[i];
    return ans;
}

修改呢，直接改一个数就行：a[i] = x，一步完成。

单次查询最坏要走 n 个数，是 O(n)；单次修改是 O(1)。

问题在哪？ 一共 n 次操作，最坏情况下每次都是查询，总耗时 n × n = O(n²)。当 n 很大时这就太慢了。

三、分块：把数组切成小块

既然查询慢在“逐个累加”，那能不能提前把一部分和算好存起来，查询时直接拿来用？

分块的做法是：把数组切成若干个大小相近的块，每块约 √n 个元素；然后预处理出每一块的总和 block_sum。

四、分块之后怎么查询

查询区间 [l, r] 时，把区间里的元素分成三类：

  1. 完整块：整块都被 [l, r] 覆盖，直接取预存的 block_sum。
  2. 两端零散元素：左右两边没凑满整块的部分，只能逐个累加。

为什么两端都可能有零散元素？ 因为 l、r 未必正好落在块的边界上：

  • 左端：若 l 不在块首（l % BS ≠ 0），则 l 所在块里、位于 l 之前的元素不属于区间，不能整块打包，只能从 l 逐个累加到块尾。
  • 右端：若 r 不在块尾（(r+1) % BS ≠ 0），则 r 所在块里、位于 r 之后的元素也不属于区间，只能逐个累加。

只有当 l 恰好是块首时，左端才没有零散元素；r 恰好是块尾时，右端才没有零散元素。

完整块越多，越省时间。最坏情况下，完整块最多约 √n 个，两端零散元素各不超过 √n 个，所以查询总耗时约 O(√n)。

五、分块之后怎么修改

修改 a[i] 时，只要同步更新它所在块的和即可：

void update(int pos, int val) {
    block_sum[bid(pos)] += val - a[pos];  // 块和先减去旧值，加上新值
    a[pos] = val;
}

修改只需要动一个元素和一个块和，耗时 O(1)。

六、复杂度分析

先看为什么块大小取 √n。设块大小为 B，一次查询要处理的量约为：

完整块数 + 零散元素数 ≈ n / B + 2B

要让两者尽量均衡，取 n / B = 2B，即 B ≈ √n 时总耗时最小。于是三种操作的时间复杂度为：

操作时间复杂度
预处理 buildO(n)
查询 queryO(√n)
修改 updateO(1)

空间方面，只多开了一个存块和的数组 block_sum，大小约 n / √n = √n，即额外空间 O(√n)。

回到开头的问题：一共 n 次操作，朴素做法总耗时 O(n²)；分块后每次查询 O(√n)，总耗时约 n × √n = O(n√n)，明显更快。

七、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 16;
int a[N] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8, 9, 7, 9, 3};
int n = N;

// 1. 分块：每块约 √n 个元素
int BS = (int)sqrt(n);       // 块大小（这里 √16 = 4）
int BN = (n + BS - 1) / BS;   // 块的数量
int block_sum[100];           // 每个块的“预存和”

int bid(int i) {                // 第 i 个元素属于第几块
    return i / BS;
}

// 2. 预处理：算好每个块的和
void build() {
    for (int i = 0; i < n; i++)
        block_sum[bid(i)] += a[i];
}

// 3. 修改：改一个数，同时更新它所在块的和
void update(int pos, int val) {
    block_sum[bid(pos)] += val - a[pos];
    a[pos] = val;
}

// 4. 查询：区间 [l, r] 的和
int query(int l, int r) {
    int ans = 0;
    while (l <= r && l % BS != 0) {   // 左端零散元素，逐个累加
        ans += a[l]; l++;
    }
    while (l + BS - 1 <= r) {           // 完整块，直接取预存的和
        ans += block_sum[bid(l)]; l += BS;
    }
    while (l <= r) {                    // 右端零散元素，逐个累加
        ans += a[l]; l++;
    }
    return ans;
}

八、小结

  • 分块的核心是“整块打包、零散逐个”：预先把每块的和算好，查询时整块直接取，只有两端零散元素才逐个累加。
  • 块大小取 √n 时，查询 O(√n)、修改 O(1)，两者达到较好的平衡。
  • 它不需要任何高级数据结构，思路直白，是理解“预处理加速”的一个好起点。
