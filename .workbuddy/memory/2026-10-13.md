## 两条新教训（值得沉淀）

1. **页面 JS 别用 `var el` 循环挂 handler**。闭包共享同一个 `el`，循环结束后它停在最后一个元素上（往往是按钮），`el.value` 恒为空串，取 `PRESETS[parseInt('')]` 直接抛异常、演示白屏，而 `verify_pages` 只看 `.viz` 的 innerHTML 长度（标题 + 控件 + 图例就够长）看不出来。改成 `bind(id, ev, fn)` 辅助函数 + 处理函数里用 `this.value`。
2. **改 handler 时按行替换容易漏右括号**：`if (el) el.onclick = function(){...};` 的 `);` 属于被替换的文本，只换到 `function(){` 那一段就会留下 `render2(); };`，整段脚本 `SyntaxError: missing ) after argument list`。多行的 handler（如重置按钮）要连尾部一起换，改完立刻用 CDP 抓 `Runtime.exceptionThrown` 的 `exception.description` 确认。
