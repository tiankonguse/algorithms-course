- **踩坑一（值得记）**：`mt19937` 全范围随机时写 `ri(INT_MIN, INT_MAX)`，里头的 `hi - lo + 1` 在 int 下溢出成 UB，clang -O2 于是在不同调用点把同一个 `a` 算出不同的值 —— 表现为「同一对 a,b，`Div(a,b)` 返回 0 而手算/独立程序返回 2」，追了很久。**全 32 位随机直接用 `(int)rng()`，别走 `lo + rng() % (hi-lo+1)`**。
- **踩坑二**：页面代码内部一律用 `unsigned` 落笔（`(a & b) << 1` 左移进符号位在 C++ 里是 UB，`-O2` 下会真的算错），对拍时「真值」也要按 32 位回绕比：`(int)((unsigned)a + (unsigned)b)`，别拿 `(long long)a + b` 比，溢出样本会假 MISMATCH。
- **踩坑三（本环境 CDP）**：`Page.captureScreenshot` 带 `captureBeyondViewport:true` 或超大视口会把请求挂死（promise 永不 resolve、进程静默退出 exit 0、无任何报错）。稳的通道是「视口固定 1400×1000、`scrollIntoView` 后 sleep ≥1.4s、截视口」，再用 sips 按元素 rect（deviceScaleFactor=2 要 ×2，x 取元素在文档里的 left）裁。
- SVG `R()` 这类 helper 只要漏传 fill/stroke，`setAttribute(k, undefined)` 会把属性写成字符串 "undefined"，矩形渲染成**纯黑底**（文字全看不见），而 bbox 检查完全正常。凡是用 helper 批量画框，参数一个都不能省。
