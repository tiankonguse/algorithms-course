## 新增算法页：离散化（discretize.html）
- 新建 `discretize.html`，在 `algorithms.json` 中插入 id `discretize`（位于 segtree 与 mo 之间，共 12 个算法）。
- 教学主线沿用「会议室最少间数」问题：区间 [s,e) 端点值域可达 10⁹ → 差分数组开不下 → 离散化三步（收集 / sort+unique 去重 / 映射 valToIdx）→ 压缩后差分扫描求最大重叠（示例数据 [[5,12],[3,7],[7,15],[12,20],[3,10]]，k=7，答案 3）。
- 页面含 4 个交互演示：① 滑块展开会议收集端点；② 按钮执行 unique() 切换去重前后；③ 映射表 valToIdx 查下标（含哈希表 O(1) 与 lower_bound O(log k) 两种写法对比）；④ 压缩坐标上的差分扫描。
- 已含「复杂度分析」小节（表：收集 O(n) / 排序 O(k log k) / 去重 O(k) / 建映射 O(k) / 查下标 O(1) 或 O(log k)，整体 O(n log n)，空间 O(k)=O(n)）。

## 解读 algorithm-journey 第 206 课（K-D树的删除操作、树套树、优化建图）
- 素材：`algorithm-journey/src/class206/`（5 题 × Java 版 + 注释形式 C++ 版）+ `ppt/算法讲解206【挺难】K-D树的删除操作、树套树、优化建图.pptx`（8 页，同样用 python zipfile + `<a:t>` 提取）。
- 三个主题与题目对应：① 动态 KD 树（带删除）→ 题目1 射击场 CF44G、题目2 摄像头 P11716；② 树套树 → 题目3 四维偏序 P3769（树状数组套 KD）、题目4 崂山白花蛇草水 P4848（开点权值线段树套 KD）；③ KD 树优化建图 → 题目5 弹跳 P5471。
- 核心要点（后面若要写页面按这个讲）：
  - 删除用**替罪羊式重构 + 懒删除**：只置 `alive=false`，节点留树上当墓碑；`maintain` 里 alive=false 时包围盒设 `xmin=INF/xmax=-INF`；平衡只看 `aliveSiz`（`0.7*aliveSiz[i] >= max(aliveSiz[ls],aliveSiz[rs])`）；记录最高失衡点 top，最后 dfs 收存活点重新 build。
  - **比较规则必须带节点编号**：`compareNode` 先比当前维坐标，相等再比 `i-j`，建树/插入/删除三处共用，重构后删除仍能确定唯一方向，因此不需要先求 rank。
  - 题目3 的反直觉结论：单次查询是 O(√n) 而非 O(log n·√n)，因为树状数组跳的 lowbit 严格递减，Σ√2^k 是公比 1/√2 的等比数列。
  - 题目4 因强制在线不能离线收集点权 → 外层权值线段树必须开点（值域 1e9，深 30），一个点进 31 棵 KD 树，MAXT=3100001。
  - 题目5：区域虚点连自己的代表点 + 下级区域虚点；弹跳装置**延迟到 dijkstra 出堆时才展开**，配合 `dist[n+i] <= jdist` 剪枝，边数从 O(n·m) 降到 O(m√n)。
