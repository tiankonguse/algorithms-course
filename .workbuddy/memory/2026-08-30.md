## 新增「后缀数组」（Suffix Array，sa.html）
- 文件名 sa.html；导航顺序追加在末尾：分块 → 树状数组 → 线段树 → 莫队 → 后缀数组。
- 教学主线：后缀=子串的前缀 → sa/rk 互为反函数 → 朴素 O(n²log n) → 倍增（用旧 rk 比更长一段，log n 轮）→ 基数排序压到 O(n log n)（双关键字：第二关键字+第一关键字稳定计数排序）→ height/LCP（height[rk[i]]≥height[rk[i-1]]-1 线性求）→ 应用（二分匹配/出现次数/最长重复子串）→ 复杂度表 + 空间 O(n) → C++ 完整代码（倍增+基数排序+height）→ 小结。
- 示例串 "banana"（1 起始）：sa=[6,4,2,1,5,3]、rk=[4,3,6,2,5,1]、height=[_,1,3,0,0,2]；倍增三轮 w=1/2/4 的 rk 已校验正确。
- 三个交互演示（table 行高亮，非 SVG）：①点击 sa 行看对应后缀；②滑条选 w 展示每轮 rk 分组（同色=并列）；③滑条选 i 高亮相邻后缀公共前缀（黄色 .lcp）。新增 CSS `.mono/.lcp/table.str(.clickable/.sel)`。
