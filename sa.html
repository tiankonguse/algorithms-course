后缀数组

给一个字符串，把从每个位置切开的「后缀」都拿出来按字典序排好，这张表就是后缀数组。有了它，找子串、数出现次数、找重复串等一大类字符串问题都能快速解决。

一、从一个问题说起

给一个字符串 s，所谓后缀，就是从某个位置开始、一直切到结尾的那一段。比如 s = "banana" 一共有 6 个后缀：

  • 从位置 1 开始：banana
  • 从位置 2 开始：anana
  • 从位置 3 开始：nana
  • 从位置 4 开始：ana
  • 从位置 5 开始：na
  • 从位置 6 开始：a

这里有一个非常关键的观察：任何一个「子串」，都恰好等于「某个后缀的开头一段」。比如子串 "ana"，它既是后缀 "anana" 的前三个字符，也是后缀 "ana" 的全部。

既然所有子串都「藏」在后缀的开头里，那么只要把所有后缀按字典序排好，很多字符串问题就变成在有序表里「查找/定位」的简单操作了。

二、后缀数组是什么

把 n 个后缀按字典序从小到大排成一列，记下它们的「起点」和「排名」，就得到两个数组：

  • sa[i]：排第 i 小的后缀，是从哪个位置开始的（后缀数组）；
  • rk[i]：从位置 i 开始的后缀，排第几（排名数组）。

这两个数组互为「反函数」：sa[rk[i]] = i，rk[sa[i]] = i。知道一个，另一个就马上能推出来。

以 "banana" 为例，6 个后缀按字典序排好后是这样的：

可以看到，字典序比较是从第一个字符开始，第一个不同的字符决定大小；短串如果是长串的前缀，则短串更小（比如 "a" 排在 "ana" 前面）。

三、朴素做法：把后缀全拿出来排序

最直接的想法：把 n 个后缀一个一个复制出来，交给 sort 排序。

vector<string> suf;
for (int i = 0; i < n; i++) suf.push_back(s.substr(i));  // 共 n 个后缀
sort(suf.begin(), suf.end());                              // 按字典序排

但这样做很慢。原因有两点：

  • 比较贵：比较两个后缀，最坏要一个字符一个字符地比，是 O(n)；
  • 次数多：sort 大约要做 O(n log n) 次比较。

两者相乘，总复杂度是 O(n² log n)。字符串一长（比如 n = 100000）就直接爆掉，必须想更聪明的办法。

四、倍增法：每次把比较长度翻倍

朴素做法慢，是因为它每次都比较整个后缀。倍增法的思路是：别一次比完，先比「前 1 个字符」，再比「前 2 个」、前 4 个、前 8 个……每轮把比较的长度翻倍，一共只需要 O(log n) 轮。

关键技巧在于：比较两个后缀的前 2w 个字符时，可以把它拆成前后两半——「前 w 个」和「接下来的 w 个」。而这两半各自的排名，上一轮已经算出来了（就是上一轮的 rk）。所以比较两个后缀，只要比两个整数对 (rk[i], rk[i+w])，不必再逐字符去比。

一句话概括：用「上一轮的排名」去比「这一轮更长的一段」。这就是倍增——从长度为 1 的排名，一路「滚雪球」滚到整个后缀的排名。

每轮结束后，用本轮排序结果重算一遍 rk。当所有后缀的 rk 互不相同时，说明已经完全排好了，可以提前停。拖动滑条看每一轮「前 w 个字符」的排名如何一步步细化：

五、用基数排序压到 O(n log n)

如果每一轮都用 sort，一轮是 O(n log n)，乘上 log n 轮就变成 O(n log² n)，还不够快。

注意一个事实：每轮排序的「关键字」不是字符，而是 0 ~ n 之间的整数排名。对值域很小的整数排序，可以用计数排序（基数排序）在 O(n) 内完成，而不必用 O(n log n) 的 sort。

每一轮要排的是双关键字 (第二关键字, 第一关键字)，做法是两趟稳定排序：

  • 第一趟：按第二关键字 rk[i+w] 排。注意后半段没有字符的后缀，第二关键字是 0（最小），天然排最前；
  • 第二趟：在上面结果的基础上，稳定地按第一关键字 rk[i] 排。

两趟计数排序都是 O(n)，所以每轮 O(n)，总共 O(log n) 轮，合计 O(n log n)。

// 一轮倍增的核心（w 为本轮比较长度的一半）
int p = 0;
for (int i = n; i > n - w; i--) id[++p] = i;      // 第二关键字为 0 的，最小
for (int i = 1; i <= n; i++) if (sa[i] > w) id[++p] = sa[i] - w;  // 其余按上一轮 sa 排第二关键字

memset(cnt, 0, sizeof(cnt));
for (int i = 1; i <= n; i++) cnt[px[i] = rk[id[i]]]++;   // 按第一关键字计数
for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
for (int i = n; i >= 1; i--) sa[cnt[px[i]]--] = id[i];  // 稳定地回填，得到新 sa

六、height 数组：相邻后缀的公共前缀

光有 sa 还不够，很多问题需要知道「排在一起的两个后缀，开头有多长是相同的」。这就是 height 数组：

  • height[i] = 排第 i 的后缀，与排第 i-1 的后缀的最长公共前缀长度。

比如在 "banana" 里，排第 3 的后缀是 "anana"，排第 2 的是 "ana"，它俩的公共前缀是 "ana"，所以 height[3] = 3。

如果每对相邻后缀都从头比一遍，最坏又是 O(n²)。但 height 有一个漂亮的性质，让它能线性求出：

关键性质：height[rk[i]] ≥ height[rk[i-1]] - 1。
意思是：把比较的起点从 i-1 右移到 i，公共前缀长度最多只会少 1。于是每步的公共前缀可以在上一步的基础上「回退 1 再继续伸」，总伸缩量是 O(n)。

七、应用举例

  • 模式匹配：要找一个模式串 p 是否出现，可以在 sa 上二分：每次比较 p 与中间那个后缀的前缀。由于比较要逐字符，单次匹配是 O(m log n)（m 是 p 的长度）。
  • 子串出现次数：用两次二分找到「以 p 为前缀的后缀」在 sa 里占据的连续区间，区间长度就是出现次数。
  • 最长重复子串：出现至少两次的最长子串，就是 height 数组里的最大值（因为重复子串必然出现在某两个相邻后缀的公共前缀里）。

八、复杂度分析

构造采用倍增 + 基数排序，共 O(log n) 轮、每轮 O(n)；height 利用「最多回退 1」的性质线性求出：

操作时间复杂度
构造后缀数组（倍增 + 基数排序）O(n log n)
求 height 数组O(n)
单次模式匹配（二分）O(m log n)

空间方面，需要 sa、rk、oldrk、id、px、cnt、height 等数组，其中 oldrk 要为 rk[i+w] 越界留出余量、开到 2n。整体是额外空间 O(n)（常数略大）。

九、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m;                          // n 串长，m 当前排名个数
char s[N];
int sa[N], rk[N], oldrk[N << 1], id[N], px[N], cnt[N];

// 比较两个后缀的「前 2w 个字符」是否相同（用旧排名）
bool cmp(int x, int y, int w) {
    return oldrk[x] == oldrk[y] && oldrk[x + w] == oldrk[y + w];
}

int height[N];
void getHeight() {
    int k = 0;
    for (int i = 1; i <= n; i++) {
        if (rk[i] == 1) { k = 0; continue; }  // 排名第一，没有前一名
        if (k) k--;                          // 利用性质：至少 height[i-1]-1
        int j = sa[rk[i] - 1];               // 排在前一名的后缀
        while (i + k <= n && j + k <= n && s[i + k] == s[j + k]) k++;
        height[rk[i]] = k;
    }
}

int main() {
    scanf("%s", s + 1);                   // 从 1 开始存，读入串
    n = strlen(s + 1);
    m = 128;                           // 初始值域：ASCII 128 个字符

    // 第一轮：按单个字符计数排序
    for (int i = 1; i <= n; i++) cnt[rk[i] = s[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;

    for (int w = 1; w < n; w <<= 1) {        // 倍增：长度每次翻倍
        // 按第二关键字排
        int p = 0;
        for (int i = n; i > n - w; i--) id[++p] = i;   // 第二关键字为 0
        for (int i = 1; i <= n; i++) if (sa[i] > w) id[++p] = sa[i] - w;
        // 按第一关键字稳定计数排序
        memset(cnt, 0, sizeof(cnt));
        for (int i = 1; i <= n; i++) cnt[px[i] = rk[id[i]]]++;
        for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; i--) sa[cnt[px[i]]--] = id[i];
        // 重算 rk
        memcpy(oldrk, rk, sizeof(rk));
        p = 0;
        for (int i = 1; i <= n; i++)
            rk[sa[i]] = cmp(sa[i], sa[i - 1], w) ? p : ++p;
        m = p;                             // 新的排名个数
        if (m == n) break;                // 全部互不相同，已排好
    }

    for (int i = 1; i <= n; i++) cout << sa[i] << " ";   // 输出后缀数组
    return 0;
}

十、小结

  • 后缀数组 sa 是把所有后缀按字典序排好后的起点表，rk 是它的逆（排名表）。
  • 构造靠倍增：每轮把比较长度翻倍，用上一轮的 rk 当关键字去比更长的一段，只需 O(log n) 轮。
  • 每轮排序因为是「小值域整数」，用基数排序做到 O(n)，于是总复杂度 O(n log n)。
  • height 数组记录相邻后缀的公共前缀，靠「最多回退 1」的性质线性求出，是求最长重复子串等问题的利器。
