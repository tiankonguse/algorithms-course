优先队列

只关心“当前最小的数是谁”——用一棵完全二叉树存下所有数，插入和取最小值都只要 O(log n)。

一、从一个问题说起

有一堆果子，每堆重量不同。每次要挑出最轻的两堆合并成一堆，再把新堆放回去，直到只剩一堆。问：怎么快速找到“当前最轻的”？

把问题抽象一下，就是反复做三件事：

  • push：加入一个新数；
  • top：看一眼当前最小的数；
  • pop：删掉当前最小的数。

三种操作交替进行，一共 n 次。我们关心的是这 n 次操作的总耗时。

二、先试试最朴素的做法

方案 A：用普通数组，随便放。

  • push：放到末尾，O(1)；
  • top / pop：得从头到尾扫描一遍找最小值，O(n)。

方案 B：始终保持数组有序。

  • top：最小值就在开头，O(1)；
  • pop：删掉开头，再把后面的元素整体前移，O(n)；
  • push：先找到插入位置，再整体后移腾空位，O(n)。
问题在哪？ 两种方案里，都有一半的操作是 O(n)，n 次操作总耗时 O(n²)。而“每次操作前先排一遍序”要 O(n log n)，更贵。

关键在于：我们并不需要整个数组有序，只要随时知道“谁最小”就够了。维护全部顺序是浪费，只维护“最小的那个”就够用。

三、优先队列：只保证堆顶最小

优先队列（priority queue）就是这样一种结构：它只暴露 push / top / pop 三个操作，不保证整体有序，只保证第 1 个位置永远是最小的。

实现它的经典结构是二叉堆（小顶堆）。它满足两条要求：

  1. 结构性：是一棵完全二叉树——除最后一层外都是满的，最后一层从左往右紧挨着排。
  2. 堆性质：每个节点都 ≤ 它的两个孩子。

由堆性质可以推出：沿着任意一条从根往下的路径，值都不会变小，所以最小值一定在根，也就是堆顶。

四、用数组存这棵完全二叉树

完全二叉树有个好处：按“从上到下、从左到右”编号后，节点是连续的，中间没有空洞，可以直接塞进数组里。

下面统一从下标 1 开始存（下标 0 空着不用），于是父子关系就是几句算术：

  • 下标 i 的父亲：i / 2（整除）；
  • 下标 i 的左孩子：2 × i；
  • 下标 i 的右孩子：2 × i + 1。

五、插入：新数往上浮

要插入一个新数，先把它放到数组末尾——这样完全二叉树的形状不会被破坏，只是堆性质可能被打破（新数可能比父亲还小）。

然后做上浮：不断拿它和父亲比较，比父亲小就交换，直到父亲更小或者到达堆顶。

void push(int v) {
    heap[++sz] = v;              // 先放到末尾
    int i = sz;
    while (i > 1) {                  // 还没到堆顶
        int p = i / 2;               // 父亲的下标
        if (heap[p] <= heap[i]) break;  // 父亲更小，堆性质已经满足
        swap(heap[p], heap[i]);
        i = p;                       // 继续往上比
    }
}

树的高度是 ⌊log₂ n⌋，上浮最多走这么多层，所以插入是 O(log n)。

六、取出最小值：堆顶往下沉

弹出时不能直接删掉堆顶——那样堆里就出现两个根了，形状也乱了。做法是：

  1. 先把堆顶 heap[1] 的值取走（它就是最小值）；
  2. 把最后一个元素搬到堆顶，这样形状仍然是一棵完全二叉树；
  3. 再做下沉：不断和两个孩子中较小的那个比较，比它大就交换，直到满足堆性质或落到叶子。
void pop() {
    heap[1] = heap[sz--];            // 最后一个元素搬到堆顶，长度减 1
    int i = 1;
    while (i * 2 <= sz) {              // 还有孩子
        int c = i * 2;                   // 左孩子
        if (c + 1 <= sz && heap[c+1] < heap[c]) c++;  // 右孩子更小就选右孩子
        if (heap[i] <= heap[c]) break;  // 已经比两个孩子都小
        swap(heap[i], heap[c]);
        i = c;                       // 继续往下比
    }
}

注意第 2 步选的是“较小的那个孩子”：如果随便选一个大的孩子交换，那个大孩子当上父亲后仍会违反堆性质。

七、建堆：一次性把 n 个数摆好

如果手里一开始就有 n 个数，有两种办法把它们变成堆。

办法一：依次 push，每次 O(log n)，总共 O(n log n)。

办法二（更快）：先把所有数原样放进数组，然后从最后一个非叶节点 n / 2 开始，从右往左、从下往上对每个位置做一次下沉：

void build(int a[], int n) {
    sz = n;
    for (int i = 1; i <= n; i++) heap[i] = a[i];  // 原样放进数组
    for (int i = n / 2; i >= 1; i--)                // 从最后一个非叶节点倒着下沉
        sinkDown(i);
}

为什么从 n / 2 开始？因为下标大于 n / 2 的节点都是叶子，它们没有孩子，天然满足堆性质，不用管。而倒着做的好处是：处理某个节点时，它的左右子树已经是堆了，一次下沉就能让整棵子树变成堆。

为什么是 O(n) 而不是 O(n log n)？ 单次下沉最贵是 O(log n)，但越靠近底层的节点越多、下沉距离却越短：倒数第二层最多 n/4 个、最多下沉 1 层，倒数第三层最多 n/8 个、最多下沉 2 层……总代价 n/4×1 + n/8×2 + n/16×3 + … < n，所以是 O(n)。

八、复杂度分析

堆是一棵完全二叉树，n 个节点的高度是 ⌊log₂ n⌋，上浮和下沉都最多走树的高度这么多层。

操作时间复杂度说明
建堆 buildO(n)自底向上逐个下沉
插入 pushO(log n)末尾放数后上浮，最多走树高
取最小值 topO(1)堆顶就是 heap[1]
删除最小值 popO(log n)末尾元素搬到堆顶后下沉

空间方面，只用了数组 heap 存 n 个元素加上一个记录长度的变量，额外空间 O(1)（不计数据本身则整体为 O(n)）；所有操作都是原地交换，不需要额外数组。

回到开头的问题：n 次操作里，朴素做法总耗时 O(n²)；用优先队列后每次操作是 O(log n)，总耗时约 O(n log n)，快得多。

顺便一提： 不断执行 top 和 pop，会依次得到从小到大的所有数，这就是堆排序，总耗时 O(n log n)。

九、完整代码

#include <bits/stdc++.h>
using namespace std;

const int N = 100;
int heap[N];   // heap[1] 是堆顶（最小值），下标 0 空着不用
int sz = 0;    // 当前元素个数

// 上浮：把第 i 个位置的数往上交换到合适位置
void siftUp(int i) {
    while (i > 1) {
        int p = i / 2;
        if (heap[p] <= heap[i]) break;
        swap(heap[p], heap[i]);
        i = p;
    }
}

// 下沉：把第 i 个位置的数往下交换到合适位置
void sinkDown(int i) {
    while (i * 2 <= sz) {
        int c = i * 2;                                   // 左孩子
        if (c + 1 <= sz && heap[c+1] < heap[c]) c++;      // 取更小的孩子
        if (heap[i] <= heap[c]) break;
        swap(heap[i], heap[c]);
        i = c;
    }
}

// 插入一个数
void push(int v) {
    heap[++sz] = v;
    siftUp(sz);
}

// 看一眼最小值
int top() { return heap[1]; }

// 删除最小值
void pop() {
    heap[1] = heap[sz--];
    sinkDown(1);
}

// 用数组 a[1..n] 建堆
void build(int a[], int n) {
    sz = n;
    for (int i = 1; i <= n; i++) heap[i] = a[i];
    for (int i = n / 2; i >= 1; i--) sinkDown(i);
}

int main() {
    int a[] = {0, 5, 3, 8, 1, 9, 2, 7};  // a[0] 不用，实际是 7 个数
    build(a, 7);
    while (sz > 0) {                  // 不断取最小，得到升序输出
        cout << top() << " ";
        pop();
    }
    return 0;
}
// 输出：1 2 3 5 7 8 9

实际做题时可以直接用 STL，它内部就是二叉堆：

#include <queue>
priority_queue<int> q;                              // 默认大顶堆，top() 是最大值
priority_queue<int, vector<int>, greater<int>> q;   // 小顶堆，top() 是最小值

q.push(x);   // 插入，O(log n)
q.top();     // 取堆顶，O(1)
q.pop();     // 删除堆顶，O(log n)
q.size();    // 元素个数

十、小结

  • 优先队列只维护“谁最小”，不维护整体顺序，因此比“每次排序”省得多。
  • 它的实现是二叉堆：完全二叉树（可用数组紧凑存储）+ 堆性质（父 ≤ 子，最小值在根）。
  • 插入走上浮、弹出走下沉，都只沿着一条从根到叶的路径走，O(log n)；建堆自底向上下沉，O(n)。
  • 不断 top + pop 就得到有序序列，这就是堆排序，O(n log n)。
