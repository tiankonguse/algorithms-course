BFS 广度优先搜索

从起点出发，一层一层地向外扩散：先走完所有距离为 1 的点，再走距离为 2 的点……因此第一次到达终点时走过的步数，就是最短步数。

一、从一个问题说起

下面是一个 6 行 8 列的网格，S 是起点，T 是终点，# 是墙壁。每次只能向上、下、左、右走一格，不能穿墙。问：从 S 到 T 最少要走几步？

二、先试试朴素做法：一条路走到底

最自然的想法是「深度优先」：从一个方向一直走下去，走不通了再退回来换方向，把每条能走的路都试一遍，取最小的步数。

int ans = INF;
bool vis[N][N];

void dfs(int r, int c, int d) {   // 当前在 (r,c)，已走 d 步
    if (r < 0 || r >= n || c < 0 || c >= m) return;
    if (g[r][c] == '#' || vis[r][c]) return;
    vis[r][c] = true;
    if (g[r][c] == 'T') { ans = min(ans, d); return; }
    dfs(r + 1, c, d + 1);   // 下
    dfs(r - 1, c, d + 1);   // 上
    dfs(r, c + 1, d + 1);   // 右
    dfs(r, c - 1, d + 1);   // 左
}

这个做法能算出答案，但有两个问题：

  • 它会沿着一条路一头扎到底，很可能先绕到很远的地方，再回头慢慢试出真正的近路；
  • 因为 vis 一旦标记就不再回头，第一次走到 T 的路径未必是最短的，只能把所有路走完才能确定最小值。
浪费在哪？ 我们其实只关心「离 S 最近的点」，可 DFS 却按「走得最深」的顺序在走，顺序完全不对。

三、换个思路：一层一层向外扩散

如果换个顺序——先把离 S 最近的一圈全部走完，再走下一圈，那么第一次碰到 T 的时候，走的步数自然就是最少的。

怎么保证「一圈一圈」地走？用一个队列：

  • 把起点放进队列；
  • 反复从队首取出一个点，把它的所有还没访问过的邻居加到队尾，并把它们的距离记为「当前点距离 + 1」；
  • 队列空了，搜索结束。

队列是先进先出（FIFO）的，先被放进来的点距离小、会被先处理，所以整个队列里的点始终按距离从小到大排着队。核心代码只有十几行：

void bfs(int sr, int sc) {          // 从 (sr,sc) 出发
    memset(dist, -1, sizeof(dist));  // -1 表示还没访问过
    queue<pair<int,int>> q;
    dist[sr][sc] = 0;
    q.push({sr, sc});

    int dr[4] = {1, -1, 0, 0};       // 下 上 右 左
    int dc[4] = {0, 0, 1, -1};

    while (!q.empty()) {
        int r = q.front().first;    // 取出队首
        int c = q.front().second;
        q.pop();
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;  // 出界
            if (g[nr][nc] == '#') continue;                            // 墙
            if (dist[nr][nc] != -1) continue;                        // 已访问
            dist[nr][nc] = dist[r][c] + 1;           // 距离 +1
            q.push({nr, nc});                    // 排到队尾
        }
    }
}
关键一句： if (dist[nr][nc] != -1) continue; —— 每个点只在第一次被走到时入队。越早入队，距离越短，后面再遇到它就一定不划算，直接跳过。

四、为什么第一次到达就是最短

BFS 有两个始终成立的性质：

  1. 队列单调：队列中各点的距离要么是 d，要么是 d+1，绝不会乱序。因为距离小的点先入队、先被扩展，它产生的邻居距离是 d+1，只能排在队尾。
  2. 距离正确：一个点第一次被走到时，是从某个距离为 d 的点扩展来的，而所有距离更小的点都已经被扩展完了 —— 它们都没能到达这个点，说明不存在更短的路。

于是，当我们第一次给终点 T 赋上距离时，它就是全局最短距离。这也是 BFS 最重要的用途：求边权全为 1 的图上的最短路。

五、复杂度分析

设图有 V 个点、E 条边（用邻接表存储）。由于每个点恰好入队一次、出队一次，出队时会把它的所有邻居扫一遍，所有点的邻居数之和为 2E（无向图每条边被数两次）。

操作时间复杂度
入队 / 出队一次O(1)
扩展一个点（扫它的所有邻居）O(deg(v))
全部 V 个点各扩展一次O(V + E)
网格图（n 行 m 列）O(n·m)

空间方面，需要 dist 数组 O(V)、队列最多同时存放 O(V) 个点、邻接表 O(V + E)，因此额外空间 O(V + E)；网格图上为 O(n·m)。

对比一下：上面的 DFS 爆搜最坏要枚举所有路径，是指数级的 O(4^V)；而 BFS 只用 O(V + E) 就能拿到最短路。

六、完整代码

下面是本课开头那道迷宫题的完整解法：

#include <bits/stdc++.h>
using namespace std;

const int N = 1005;
char g[N][N];
int dista[N][N];
int n, m, sr, sc, tr, tc;
int dr[4] = {1, -1, 0, 0};
int dc[4] = {0, 0, 1, -1};

int bfs() {
    memset(dista, -1, sizeof(dista));
    queue<pair<int, int>> q;
    dista[sr][sc] = 0;
    q.push({sr, sc});

    while (!q.empty()) {
        int r = q.front().first;
        int c = q.front().second;
        q.pop();
        if (r == tr && c == tc) return dista[r][c];  // 第一次出队即最短
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
            if (g[nr][nc] == '#') continue;
            if (dista[nr][nc] != -1) continue;
            dista[nr][nc] = dista[r][c] + 1;
            q.push({nr, nc});
        }
    }
    return -1;                       // 走不到终点
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> g[i][j];
            if (g[i][j] == 'S') { sr = i; sc = j; }
            if (g[i][j] == 'T') { tr = i; tc = j; }
        }
    }
    cout << bfs() << endl;
    return 0;
}

七、通用图上的 BFS 模板

把「网格」换成「邻接表」，同一套写法可以跑在任意无权图上：

vector<int> adj[N];       // 邻接表：adj[u] 存 u 的所有邻居
int distv[N];              // 到起点的最短距离，-1 表示未访问

void bfs(int s) {
    fill(distv, distv + N, -1);
    queue<int> q;
    distv[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {          // 遍历 u 的每个邻居
            if (distv[v] != -1) continue;
            distv[v] = distv[u] + 1;
            q.push(v);
        }
    }
}

八、小结

  • BFS 用队列实现先进先出，保证「先近后远」的访问顺序。
  • 核心三件事：dist 数组记距离、vis 靠 dist != -1 判断、每个点只入队一次。
  • 第一次到达终点时的距离就是最短距离，前提是每条边的代价都相同（无权图）。
  • 复杂度 O(V + E)，空间 O(V + E)，是图论里最基础也最常用的搜索。
